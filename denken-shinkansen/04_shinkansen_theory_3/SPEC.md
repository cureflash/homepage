# 新幹線・電験三種「理論」教材仕様書

## 1. 目的

新幹線に電気が届き、車両内部へ取り込まれ、主回路・主電動機を通して走行し、その状態を電気的に測定するまでを一本の物語として追いながら、電験三種「理論」の主要分野を学習する。

本シリーズでは、公式や回路を先に並べるのではなく、新幹線側の疑問から電気理論へ入る。

```text
大量の電力が必要
↓
高電圧で送る
↓
架線を流れる
↓
高電圧なので電界・絶縁が必要
↓
パンタグラフから車内へ入る
↓
変圧する
↓
電磁力でモーターを回す
↓
交流・周波数・力率を理解する
↓
三相交流と電力変換を理解する
↓
半導体で波形を作る
↓
最後に電圧・電流・波形・設備状態を測る
```

電験三種「理論」の以下の分野を一連の教材として扱う。

- 電気数学
- 直流回路
- 静電気
- 電磁気
- 交流回路
- 三相交流回路
- 電子理論
- 電子回路
- 電気測定
- 電子計測

既存の機械編・電力編と内容が重複してもよいが、理論編では「なぜその現象が起こるか」「回路・電磁気としてどう計算するか」を主題とする。

## 2. 成果物

各テーマで以下を制作する。

- 解説プリント
- 練習プリント
- 解説画像PowerPoint

解説プリントでは実在する新幹線、架線、主変圧器、主電動機、主変換装置、変電設備、検測車等を優先して扱う。

練習プリントは通常の電験三種「理論」問題とし、新幹線を題材にする必要はない。

実車値を使用する場合は出典を明記する。

資料値から算出した値は「計算値」、教材用に置いた値は「仮定値」と明記する。

# 4. 第1章　新幹線1編成はどれだけ電気を食う？

## 主題

新幹線を一つの大電力負荷として扱い、電気数学と電気回路の基本量を導入する。

## 扱う内容

- V
- A
- Ω
- W
- kW
- MW
- J
- Wh
- kWh
- 電圧
- 電流
- 抵抗
- 電力
- 電力量
- 比例・反比例
- 指数表記
- 単位換算
- 有効数字

## 基本公式

```text
V = RI
P = VI
W = Pt
```

## 教材例

「新幹線1編成が10MWを使用すると仮定した場合、25kVで受電する電流はいくらか」のような仮定計算を使用してよい。

実車の編成出力・消費電力を使用する場合は、出力と入力電力を混同しない。

## 到達点

MW級の電力を25kVで扱うと電流が数百A規模になることを理解し、第2章の高電圧送電へつなげる。

# 5. 第2章　なぜ新幹線は25,000Vなのか

## 主題

同じ電力を送る場合、電圧を高くすることで電流と送電損失を抑えられることを回路計算で理解する。

## 基本構成

```text
必要電力が大きい
↓
低電圧では電流が大きくなる
↓
I²R損失が増える
↓
電圧を高くする
↓
電流を抑える
```

## 扱う内容

- オームの法則
- 電力
- ジュール熱
- 電力量
- 電線抵抗
- 電圧降下
- 電力損失
- 送電効率の基本

## 重要公式

```text
V = RI
P = VI
Ploss = I²R
Q = I²Rt
```

## 比較計算

同じ電力を、異なる電圧で送った場合の電流とI²R損失を比較する。

25kVが唯一絶対の最適値であるとは説明せず、高電圧化の一般原理を新幹線へ接続する。

# 7. 第4章　25,000Vでなぜ車体へ電気が飛ばない？

## 主題

架線と車体・大地の間に存在する高電圧を題材に、静電気・電界・電位・静電容量を学ぶ。

## 基本イメージ

```text
架線 25kV
↓
空間・碍子
↓
車体・大地
```

## 扱う内容

- 電荷
- クーロンの法則
- 電界
- 電気力線
- 電位
- 電位差
- 電気的な仕事
- 静電容量
- コンデンサ
- 誘電体
- 誘電率
- 電界エネルギー
- 直列・並列コンデンサ

## 重要公式

```text
F = k Q1Q2 / r²
E = F / Q
V = W / Q
C = Q / V
W = 1/2 CV²
```

## 方針

実車の特定部品を無理にコンデンサとして数値化しない。

「高電圧設備では、導通している回路だけでなく電界・絶縁も考える必要がある」という理解を優先する。

各章は「静電気」「交流回路」のような電験側の単元名から始めず、新幹線側の疑問をタイトルと導入にする。

プリント側で対応範囲を「電験三種 理論／静電気」等と明示する。

# 19. 他シリーズとの役割分担

## 理論編

物理法則・回路・波形・電磁気・半導体・測定の基礎を扱う。

例：

```text
0系主電動機
→ なぜ磁界中の電流に力が働くのか
```

## 機械編

実際の機器としての構造・特性・損失・制御を扱う。

例：

```text
0系主電動機
→ 逆起電力・トルク・速度制御をどう計算するか
```

## 電力編

発電所・送電・変電・き電・架線という巨大な電力インフラを扱う。

例：

```text
交流25kV
→ どのように変電所から列車へ送るか
```

同じ設備を複数シリーズで使ってよいが、解説の目的を混同しない。

# 20. 解説プリントの基本構成

各テーマは原則として以下の順で構成する。

1. 新幹線側の疑問
2. 実際の車両・設備
3. 現象を単純化したモデル
4. 電験三種で扱う理論
5. 基本公式
6. 公式の意味
7. 出典付き実データまたは明示した仮定値
8. 代表計算
9. 計算結果の実車上の意味
10. 電験三種ポイント
11. 出典

特に理論編では、公式暗記だけにならないよう、式中の各変数が新幹線のどの量に対応するかを示す。

# 21. 実データ・出典

実車・設備の仕様は以下を優先する。

1. JR各社
2. JRTT
3. 車両・電機メーカー公式資料
4. 鉄道総研
5. 電気学会等
6. 学術論文
7. 公的機関

以下のような値は一次資料で確認する。

- 架線電圧
- 電源周波数
- 主変圧器仕様
- 主電動機方式
- 主回路方式
- 主変換装置方式
- 検測車の実際の測定項目
- 架線材料・構造

公開資料にない回路定数や内部回路を推測して実車値として使用しない。

# 22. 数学の扱い

理論編では電気数学を各章へ分散して扱う。

必要に応じて以下をその場で説明する。

- 比例・反比例
- 一次方程式
- 連立方程式
- 平方根
- 指数
- 三角関数
- ベクトル
- 複素数
- 微分の基本
- 積分の基本

数学だけの独立した導入章は原則として作らない。

例えば複素数は交流インピーダンス、三角関数は正弦波、微分は電磁誘導やL・Cの基本式で導入する。

# 23. 計算検証

解説内計算と練習問題は独立に再計算する。

確認項目は以下とする。

- 使用公式
- 式変形
- 入力値
- 単位
- 中間計算
- 最終値
- 有効数字
- 丸め
- 正答
- 解説との整合性

複素数計算では極形式・直交形式の変換ミスを確認する。

三相交流では相値と線間値を混同しない。

交流では最大値・実効値・瞬時値を混同しない。

# 24. 練習プリント

各章に対応した通常の電験三種「理論」問題を制作する。

新幹線を題材にする必要はない。

重点分野は以下とする。

- 電気数学：単位換算、比例、複素数、三角関数
- 直流回路：オームの法則、合成抵抗、キルヒホッフ、テブナン
- 静電気：クーロン力、電界、電位、コンデンサ
- 電磁気：磁界、磁気回路、電磁誘導、インダクタンス
- 交流：実効値、位相、RLC、共振
- 交流電力：有効・無効・皮相電力、力率
- 三相交流：Y・Δ、線間・相値、三相電力
- 電子理論：pn接合、ダイオード、トランジスタ
- 電子回路：増幅、スイッチング、オペアンプの基本
- 測定：電圧・電流・抵抗・電力、計器誤差
