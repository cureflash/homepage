過去問対応上、固定範囲内の関係式として次を説明する。

```text
F = |Q1Q2| / (4πεr²)
E = F / q
V = Q / (4πεr)
C = Q / V
C = εS / d
Cparallel = C1 + C2 + ...
1/Cseries = 1/C1 + 1/C2 + ...
U = 1/2 CV² = 1/2 QV = Q²/(2C)
```
