## 過去問から逆算した教材で必要な説明

1. 抵抗率 `ρ [Ω·m]` を「材料固有の電流の流れにくさ」として定義し、導電率 `σ [S/m]` との `σ=1/ρ` の関係を示す。
2. `R=ρl/S` の各記号と単位を示し、同一材料なら `R∝l`、`R∝1/S` であることを式と比較計算で理解させる。
3. 断面積を `mm²` で与えられた場合の `m²` への換算、直径から断面積を作る場合の `S=πd²/4` を、必要な単位換算として扱う。
4. 直列合成 `R=R1+R2+...` と、2抵抗の並列合成 `R=R1R2/(R1+R2)` を導出または成立理由付きで説明する。並列では合成抵抗が最小の枝抵抗より小さくなることを検算に使う。
5. 全電圧・全電流から並列枝の未知抵抗を求めるため、`I=V/R1+V/R2` と合成抵抗式を未知量について変形できるようにする。
6. `Rt=R0{1+α(t-t0)}` の `R0, Rt, α, t0, t` の意味・単位・成立する線形近似の扱いを説明する。
7. 温度変化後の抵抗比を先に求め、一定電圧なら `I∝1/R` となることから電流変化率へ接続する解法手順を示す。
8. 温度係数が異なる複数抵抗では、各抵抗を温度補正してから直列・並列合成する順序を示す。
9. 発熱・消費電力は既習の `P=VI=I²R=V²/R` を使い、直列の「同一電流」と並列の「同一電圧」を見分けて大小比較する。
10. 導体抵抗による電圧降下を `ΔV=IR` として、`R=ρl/S` とつなぎ「長い・細い・抵抗率が大きい・温度上昇でRが増える場合ほど電圧降下が増える」ことを計算で示す。
11. 典型的な誤答として、`ρ` と `R` の混同、長さ/断面積の比例・反比例逆転、`mm²→m²` 換算ミス、温度差 `t-t0` の取り違え、直列/並列式の取り違えを扱う。
12. 新幹線への接続では、未確認実車値を使わず仮定した架線長・断面積・抵抗率・電流で抵抗と電圧降下を計算する。架線材料は導電率だけで決まらないことを短く示す。

# 解説本文

## 1. このテーマで電験は何を問うか

このテーマは電験三種「理論」の抵抗・直流回路計算に対応する。試験では、抵抗値そのものが与えられる問題だけでなく、材料の抵抗率、導体の長さ・断面積、温度から抵抗を作り、その後に直列・並列合成、電流、電力までつなぐ問題が出る。

この章を終えると、次をできるようにする。

- `R=ρl/S` で導体抵抗を求め、長さ・断面積による変化を比較する
- `σ=1/ρ` で抵抗率と導電率を結び付ける
- 直列・並列抵抗を合成し、未知抵抗を逆算する
- 温度係数から温度変化後の抵抗を求める
- 一定電圧時の抵抗変化から電流変化を求める
- `P=I²R` と `P=V²/R` を条件に応じて使い分ける
- 導体抵抗による電圧降下 `ΔV=IR` を求める

新幹線はこれらの理論を具体化するために使う。実際の架線材質・断面積・抵抗値を未確認のまま教材値にはしない。

## 2. 抵抗率と導電率

抵抗 `R [Ω]` は、ある具体的な導体全体の電流の流れにくさである。一方、抵抗率 `ρ [Ω·m]` は材料そのものの電流の流れにくさを表す物性値として扱う。

導電率 `σ [S/m]` は電流の流れやすさを表し、抵抗率とは逆数関係にある。

```text
σ = 1/ρ
ρ = 1/σ
```

したがって、同じ形状なら `ρ` が大きい材料ほど抵抗が大きく、`σ` が大きい材料ほど抵抗が小さい。

ここで `ρ` と `R` を混同しない。`ρ` は材料側の量、`R` は材料に加えて長さ・断面積でも決まる量である。

## 3. 長さ・断面積と電線抵抗

一様な材料・一様な断面積の導体を扱うとき、抵抗は

```text
R = ρl/S
```

で求める。

- `R`: 抵抗 [Ω]
- `ρ`: 抵抗率 [Ω·m]
- `l`: 長さ [m]
- `S`: 断面積 [m²]

同じ材料なら

```text
R ∝ l
R ∝ 1/S
```

なので、長さを2倍にすれば抵抗は2倍、断面積を2倍にすれば抵抗は1/2になる。

### 3.1 単位換算

断面積が `mm²` で与えられた場合は注意する。

```text
1 mm = 10^-3 m
1 mm² = 10^-6 m²
```

例えば

```text
100 mm² = 100 × 10^-6 m² = 1.00 × 10^-4 m²
```

である。

直径 `d` の円形導体なら断面積は

```text
S = πd²/4
```

である。直径が2倍なら断面積は4倍となるため、同じ材料・長さなら抵抗は1/4になる。

### 3.2 大小比較を先にする

選択式では、数値を全部計算する前に比例関係で候補を絞れる。

2本の導体A、Bについて

```text
RA/RB = (ρA/ρB)(lA/lB)(SB/SA)
```

と比を作れば、共通因子を消して比較できる。これは抵抗率・長さ・断面積を同時に変えた問題で有効である。

## 4. 直列・並列抵抗

### 4.1 直列接続

直列では各抵抗に同じ電流が流れ、各抵抗での電圧降下を足したものが全体の電圧降下になる。したがって

```text
V = IR1 + IR2 + ...
  = I(R1 + R2 + ...)
```

より合成抵抗は

```text
Rs = R1 + R2 + ...
```

となる。

### 4.2 並列接続

並列では各枝に同じ電圧 `V` が加わる。2抵抗なら全電流は各枝電流の和なので

```text
I = V/R1 + V/R2
  = V(1/R1 + 1/R2)
```

全体を `I=V/Rp` と表すと

```text
1/Rp = 1/R1 + 1/R2
```

よって

```text
Rp = R1R2/(R1+R2)
```

となる。

並列合成抵抗は必ず最小の枝抵抗より小さくなる。計算結果がそうなっていなければ、直列式との取り違えを疑う。

### 4.3 未知抵抗の逆算

全電圧 `V`、全電流 `I`、一方の抵抗 `R1` が分かる並列回路なら

```text
I = V/R1 + V/Rx
```

から未知抵抗 `Rx` を求められる。

また、全体の合成抵抗が分かるなら

```text
Rtotal = V/I
```

を先に求め、直列部分を引いて並列部分の合成抵抗を出してから

```text
Rp = R1Rx/(R1+Rx)
```

を `Rx` について解く方法も使える。

問題では「どこまでが直列部分で、どこが並列部分か」を先に分ける。複数電源や枝ごとの未知電流を一般的に解く方法にはここでは進まない。

## 5. 温度係数と抵抗の温度変化

基準温度 `t0` で抵抗 `R0`、その基準温度に対する抵抗温度係数を `α` とすると、扱う温度範囲で直線近似できる場合、温度 `t` の抵抗は

```text
Rt = R0{1 + α(t - t0)}
```

で求める。

- `R0`: 基準温度 `t0` での抵抗 [Ω]
- `Rt`: 温度 `t` での抵抗 [Ω]
- `α`: 基準温度 `t0` に対する抵抗温度係数 [1/℃] または [K^-1]
- `t - t0`: 温度差 [℃] または [K]

ここで使う式は、問題で与えられた温度係数を使う線形近似である。温度差には `t` そのものではなく `t-t0` を入れる。

### 5.1 抵抗比を先に求める

温度変化だけを見るなら

```text
Rt/R0 = 1 + α(t-t0)
```

と抵抗比を先に出すと計算しやすい。

例えば抵抗が1.20倍になり、電圧が一定なら

```text
I = V/R
```

より電流は

```text
It/I0 = R0/Rt = 1/1.20
```

となる。抵抗が20%増えたから電流が20%減る、とは限らない。逆数関係で処理する。

### 5.2 一定電圧と一定電流を混同しない

温度変化後の電流や電力を問われたら、何が一定かを見る。

一定電圧なら

```text
I = V/R
P = V²/R
```

なので抵抗が増えると電流・電力は減る。

一定電流なら

```text
P = I²R
```

なので抵抗が増えると電力は増える。

### 5.3 温度係数が異なる複数抵抗

2個以上の抵抗で温度係数が異なる場合、先に各抵抗を個別に温度補正する。

```text
R1t = R10{1 + α1(t-t0)}
R2t = R20{1 + α2(t-t0)}
```

その後で直列または並列の合成抵抗を計算する。

「最初に合成抵抗を出し、その合成抵抗へどちらか一方の温度係数を掛ける」のは誤りである。

## 6. 発熱・消費電力・電圧降下

抵抗で消費される電力は既習の

```text
P = VI = I²R = V²/R
```

を使う。

式の選択は回路条件で決める。

- 直列で比較する抵抗: 同じ電流が流れるので `P=I²R` が見やすい
- 並列で比較する抵抗: 同じ電圧が加わるので `P=V²/R` が見やすい

したがって、直列で同じ電流なら抵抗が大きい方の消費電力が大きい。一方、並列で同じ電圧なら抵抗が小さい方の消費電力が大きい。

導体抵抗 `R` に電流 `I` が流れると、その導体での電圧降下は

```text
ΔV = IR
```

である。`R=ρl/S` とつなげると

```text
ΔV = Iρl/S
```

となる。同じ電流なら、長い、細い、抵抗率が大きい導体ほど電圧降下が大きい。問題で温度上昇により抵抗が増える条件なら、その分だけ電圧降下も増える。

発熱量そのものを時間 `t` [s] まで含めて求めるときは

```text
Q = I²Rt
```

を使う。`I²R` は電力 [W]、`I²Rt` はエネルギー [J] であり、単位を混同しない。

## 7. 問題を見たときの解法手順

```text
1. 求める量が抵抗・電流・電力・電圧降下のどれか確認する
2. 抵抗率問題なら ρ, l, S を抜き出し、mm² は m² へ換算する
3. 温度指定があるなら各抵抗を Rt=R0{1+α(t-t0)} で補正する
4. 回路を直列部分と並列部分に分ける
5. 直列は和、2抵抗並列は R1R2/(R1+R2) で合成する
6. 未知抵抗なら合成抵抗式または I=V/R1+V/Rx を未知量について解く
7. 電力比較は「同一電流」か「同一電圧」かを見て I²R / V²/R を選ぶ
8. 電圧降下は ΔV=IR で求める
9. 並列合成抵抗が最小枝抵抗より小さいか、温度上昇時の増減方向、単位を検算する
```

# 3段階例題

## 例題1 基礎: 抵抗率から導体抵抗を求める

以下は教材用仮定値であり、実際の新幹線架線仕様ではない。

抵抗率 `ρ=2.0×10^-8 Ω·m`、長さ `l=500 m`、断面積 `S=100 mm²` の一様な導体がある。この導体の抵抗を求める。また、300 Aが流れるときの電圧降下と消費電力を求める。

### 解法

まず断面積をSI単位へ直す。

```text
100 mm² = 100×10^-6 m² = 1.00×10^-4 m²
```

抵抗は

```text
R = ρl/S
  = (2.0×10^-8)×500/(1.00×10^-4)
  = 0.100 Ω
```

電圧降下は

```text
ΔV = IR
   = 300×0.100
   = 30.0 V
```

消費電力は

```text
P = I²R
  = 300²×0.100
  = 9000 W
  = 9.0 kW
```

答え:

- 抵抗 `0.100 Ω`
- 電圧降下 `30.0 V`
- 消費電力 `9.0 kW`

この型では `mm²→m²` の換算を先に行う。`100 mm²=0.1 m²` とする誤りに注意する。

## 例題2 本試験標準: 直列＋並列から未知抵抗を逆算する

2 Ωの抵抗と、6 Ωと未知抵抗 `Rx` の並列回路が直列につながっている。回路全体の合成抵抗が4 Ωである。`Rx` を求める。

さらに、回路全体に20 Vを加えたとき、6 Ωと `Rx` で消費される電力をそれぞれ求める。

### 解法

全体4 Ωのうち、直列の2 Ωを除くと並列部分の合成抵抗は

```text
Rp = 4 - 2 = 2 Ω
```

並列合成式より

```text
2 = 6Rx/(6+Rx)
```

両辺を整理する。

```text
12 + 2Rx = 6Rx
4Rx = 12
Rx = 3 Ω
```

まず全電流を求める。

```text
I = 20/4 = 5 A
```

直列2 Ωでの電圧降下は

```text
Vseries = 5×2 = 10 V
```

したがって並列部分の電圧は

```text
Vp = 20 - 10 = 10 V
```

並列では両抵抗に同じ10 Vが加わるので

```text
P6 = Vp²/6
   = 100/6
   ≒ 16.7 W

Px = Vp²/3
   = 100/3
   ≒ 33.3 W
```

答え:

- `Rx = 3 Ω`
- 6 Ωの消費電力 `約16.7 W`
- 3 Ωの消費電力 `約33.3 W`

検算すると、並列合成2 Ωは3 Ωと6 Ωのどちらよりも小さい。また同一電圧の並列では、抵抗が小さい3 Ω側の消費電力が大きい。

## 例題3 複合・ひっかけ: 温度係数＋並列合成＋一定電圧

20 ℃で次の2抵抗が並列接続され、端子電圧24 Vが一定に保たれているとする。

- `R1=10 Ω`、`α1=0.0040 /℃`
- `R2=20 Ω`、`α2=0.0020 /℃`

温度が70 ℃になったとき、各抵抗、並列合成抵抗、全電流を求め、20 ℃時から全電流が何%減少したか求める。温度係数は20 ℃を基準とする。

### 解法

温度差は

```text
Δt = 70 - 20 = 50 ℃
```

まず各抵抗を個別に温度補正する。

```text
R1,70 = 10{1 + 0.0040×50}
      = 12 Ω

R2,70 = 20{1 + 0.0020×50}
      = 22 Ω
```

20 ℃での合成抵抗は

```text
Rp,20 = 10×20/(10+20)
      = 200/30
      ≒ 6.667 Ω
```

70 ℃での合成抵抗は

```text
Rp,70 = 12×22/(12+22)
      = 264/34
      ≒ 7.765 Ω
```

一定電圧24 Vなので

```text
I20 = 24/6.667
    ≒ 3.600 A

I70 = 24/7.765
    ≒ 3.091 A
```

減少率は

```text
(3.600 - 3.091)/3.600 × 100
≒ 14.1 %
```

答え:

- 70 ℃時 `R1=12 Ω`
- 70 ℃時 `R2=22 Ω`
- 70 ℃時の合成抵抗 `約7.765 Ω`
- 70 ℃時の全電流 `約3.091 A`
- 全電流の減少率 `約14.1 %`

ひっかけは、2抵抗の温度係数が異なる点である。各抵抗を温度補正する前に合成してはいけない。また、抵抗が増えた割合と電流が減る割合は同じではない。

## 8. 新幹線架線への接続

以下は理論の働きを見るための単一導体モデルで、数値はすべて教材用仮定値である。実際の新幹線の架線・き電回路の実測値ではない。

```text
ρ = 3.0×10^-8 Ω·m
l = 1000 m
S = 150 mm² = 1.50×10^-4 m²
I = 400 A
```

抵抗は

```text
R = ρl/S
  = (3.0×10^-8)×1000/(1.50×10^-4)
  = 0.20 Ω
```

電圧降下と抵抗損は

```text
ΔV = IR = 400×0.20 = 80 V
P = I²R = 400²×0.20 = 32000 W = 32 kW
```

この計算から、導体の抵抗が小さくても大電流では電圧降下と発熱が無視できなくなることが分かる。

ただし架線材料の選定は導電率だけでは決まらない。系列SPECで示されているとおり、張力、摩耗、機械的強度、高速集電性能も要求される。本Topicではそれらの材料設計へは踏み込まない。

## 9. 頻出ミス

- `ρ [Ω·m]` と導体全体の `R [Ω]` を混同する
- 長さが増えると抵抗が減ると逆に覚える
- 断面積が増えると抵抗も増えると逆に覚える
- `1 mm² = 10^-3 m²` と誤換算する。正しくは `10^-6 m²`
- 直径2倍を断面積2倍とする。円形断面なら断面積は4倍
- 並列合成抵抗が枝抵抗より大きい結果をそのまま採用する
- 温度式へ `t` をそのまま入れ、`t-t0` を使わない
- 異なる温度係数を持つ抵抗を先に合成してから一つの係数で補正する
- 直列の電力比較に `V²/R`、並列の比較に `I²R` を無条件で使い、同一電流・同一電圧の条件を見落とす

## 11. 公式・解法まとめ

```text
σ = 1/ρ
R = ρl/S
S = πd²/4

直列:
Rs = R1 + R2 + ...

2抵抗並列:
Rp = R1R2/(R1+R2)
1/Rp = 1/R1 + 1/R2

温度:
Rt = R0{1 + α(t-t0)}

電力・発熱:
P = VI = I²R = V²/R
Q = I²Rt

電圧降下:
ΔV = IR
```

解く順序は「単位をそろえる → 必要なら温度補正 → 直列/並列を整理 → 未知量について式変形 → 電流・電力・電圧降下 → 増減方向と単位を検算」とする。
