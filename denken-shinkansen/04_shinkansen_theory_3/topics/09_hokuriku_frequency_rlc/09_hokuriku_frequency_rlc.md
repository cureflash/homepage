# Topic 09 北陸新幹線は50Hzと60Hzをどう走る？

更新日: 2026-09-16
status: `COMPLETED`

## 1. SPEC固定範囲

主題は、50Hz・60Hzという異なる周波数を入口として、交流RLC回路・リアクタンス・インピーダンスを理解すること。

扱う内容:
- 抵抗R
- インダクタンスL
- 静電容量C
- 誘導リアクタンス
- 容量リアクタンス
- インピーダンス
- 位相差
- R-L回路
- R-C回路
- R-L-C回路
- 直列共振
- 並列共振の基本

SPEC固定公式:

```text
XL = 2πfL
XC = 1 / (2πfC)
Z = R + jX
f0 = 1 / (2π√LC)
```

## 6. 教材で必ず説明する事項

固定公式過去問と系列SPECから逆算し、本文では次を必須とする。

1. 抵抗・コイル・コンデンサの交流に対する役割と、`ZR=R`、`ZL=jXL`、`ZC=-jXC`の意味。
2. `XL=2πfL`は周波数に比例し、`XC=1/(2πfC)`は周波数に反比例すること。50Hz→60Hzの変化を式で比較できること。
3. `Z=R+jX`の実部・虚部、インピーダンスの大きさ、電圧・電流の位相差をフェーザと結び付けること。
4. RL・RC・RLC直列回路で`|Z|`を求め、`I=V/|Z|`へ接続する手順。
5. 並列回路では各枝に同じ電圧がかかり、枝電流をフェーザで合成すること。理想LC並列で条件がそろうと誘導性・容量性電流が打ち消し合うこと。
6. 直列共振で`XL=XC`、`f0=1/(2π√LC)`となり、理想的な直列RLCではインピーダンスが`R`となって電流が最大になること。
7. 共振周波数より低い側では容量性、高い側では誘導性となる直列RLCの位相関係を説明できること。
8. 並列共振は系列SPEC指定の「基本」に限定し、枝電流の打消しと合成インピーダンスの変化までを扱うこと。
9. 周波数が変わる問題では、まず`XL`・`XC`の変化を求め、次に回路構成から`Z`、最後に電流・電圧を求める解法手順を明示すること。
10. 固定R8上問8で使う`P=I²R`は既習の抵抗損失として接続し、力率・無効電力・皮相電力へは踏み込まないこと。
11. 新幹線との接続では、50Hz・60Hzという周波数差によって一般にL・Cのリアクタンスが変わることを示し、未確認の実車回路値や切替方式を真値として置かないこと。

## 8. 解説本文

### 8.1 このテーマで電験は何を問うか

電験三種「理論」では、交流回路の周波数が変わったときにコイルとコンデンサの作用がどう変わり、その結果としてインピーダンス・電流・位相・共振条件がどう変化するかを計算させる。本Topicで重要なのは、公式を暗記するだけでなく、回路が抵抗性・誘導性・容量性のどれになるかを判定してから数値計算へ進むことである。

この章を終えると、次の順序でRLC問題を処理できることを目標とする。

```text
周波数 f を確認
↓
XL と XC を求める
↓
回路の直列・並列を判定
↓
インピーダンスまたは枝電流を求める
↓
電流・電圧・位相を求める
↓
共振条件や周波数変化後と照合する
```

### 8.2 R・L・Cは交流に対してどう働くか

抵抗Rは、理想的には周波数によって値を変えない。本Topicでは

```text
ZR = R
```

と表す。電圧と電流は同相である。

コイルLは、交流の変化を妨げる向きに誘導起電力を生じるため、交流に対する妨げを誘導リアクタンス`XL`で表す。

```text
XL = 2πfL
ZL = jXL
```

`XL`は周波数`f`に比例する。したがって50Hzから60Hzへ変われば、同じLなら

```text
XL(60) / XL(50) = 60 / 50 = 1.2
```

となり、誘導リアクタンスは1.2倍になる。理想コイルでは電流は電圧より90°遅れる。

コンデンサCは、交流では充放電を繰り返す。交流に対する妨げを容量リアクタンス`XC`で表す。

```text
XC = 1 / (2πfC)
ZC = -jXC
```

`XC`は周波数`f`に反比例する。50Hzから60Hzへ変われば、同じCなら

```text
XC(60) / XC(50) = 50 / 60 = 5 / 6
```

となる。理想コンデンサでは電流は電圧より90°進む。

したがって、周波数が上がると「Lは通しにくくなり、Cは通しやすくなる」と整理できる。ただし実際の回路電流はR・L・Cの接続関係を含む合成インピーダンスで決まるため、この傾向だけで最終答案を決めてはいけない。

### 8.3 インピーダンスとフェーザ

直流回路の抵抗に相当する交流回路の量がインピーダンス`Z`で、単位はΩである。複素数で

```text
Z = R + jX
```

と書く。`R`は実部、`X`はリアクタンス成分である。

- 誘導性: `X > 0`
- 容量性: `X < 0`
- 純抵抗性: `X = 0`

大きさは

```text
|Z| = √(R² + X²)
```

であり、実効値を使うと電流の大きさは

```text
I = V / |Z|
```

で求められる。

位相角を`φ`とすれば

```text
φ = tan⁻¹(X / R)
```

である。`X>0`なら回路は誘導性で電流が電圧より遅れ、`X<0`なら容量性で電流が電圧より進む。

交流では、互いに90°ずれた電圧を単純加算してはいけない。例えばRC直列回路では抵抗電圧`VR`とコンデンサ電圧`VC`が直交するため、電源電圧の大きさは

```text
V = √(VR² + VC²)
```

となる。固定R8上問8で必要になるのはこのフェーザ合成である。

### 8.4 RL・RC・RLC直列回路

直列回路では各素子を流れる電流は同じであり、インピーダンスを加算して考える。

RL直列回路:

```text
Z = R + jXL
|Z| = √(R² + XL²)
```

誘導性なので電流は電圧より遅れる。

RC直列回路:

```text
Z = R - jXC
|Z| = √(R² + XC²)
```

容量性なので電流は電圧より進む。

RLC直列回路:

```text
Z = R + j(XL - XC)
|Z| = √{R² + (XL - XC)²}
```

ここでは`XL-XC`の符号が重要である。

- `XL > XC`: 誘導性、電流は遅れる
- `XL < XC`: 容量性、電流は進む
- `XL = XC`: リアクタンス成分が打ち消され、直列共振

固定過去問で抵抗損失が問われる場合は、既習式

```text
P = I²R
```

を用いる。本Topicではここから力率・無効電力・皮相電力へは拡張しない。

### 8.5 並列回路と理想LCの打消し

並列回路では各枝に同じ電圧がかかる。電流は各枝ごとに求め、位相を考えて合成する。

理想素子では

```text
IR = V / R
IL = V / XL
IC = V / XC
```

となる。ただし`IL`は電圧より90°遅れ、`IC`は90°進むため、L枝電流とC枝電流は互いに反対向きの無効成分として扱う。

理想LC並列回路で

```text
XL = XC
```

なら

```text
|IL| = |IC|
```

となり、L枝とC枝の電流が打ち消し合う。外部から見た合成電流は小さくなり、理想的には合成インピーダンスが大きくなる。ここでは系列SPECどおり、この枝電流の打消しまでを並列共振の基本として扱う。

周波数を大きくすると`XL`は大きく、`XC`は小さくなる。そのため理想L枝電流`V/XL`は小さくなり、C枝電流`V/XC`は大きくなる。低周波側では逆になる。固定R7下問8のような周波数比較では、この変化を各枝ごとに追う。

### 8.6 直列共振

RLC直列回路では

```text
XL = XC
```

のときリアクタンス成分が相殺される。

```text
2πfL = 1 / (2πfC)
```

より

```text
f0 = 1 / (2π√LC)
```

を得る。`f0`が共振周波数である。

共振時には

```text
Z = R
I = V / R
```

となるため、同じR・電源電圧なら直列RLC回路の電流は最大になる。またLとCの端子電圧は互いに逆位相で打ち消し合うが、それぞれの端子電圧自体は電源電圧より大きくなる場合がある。

共振前後は、`XL∝f`、`XC∝1/f`から判定できる。

- `f < f0`: `XL < XC` → 容量性 → 電流進み
- `f = f0`: `XL = XC` → 抵抗性
- `f > f0`: `XL > XC` → 誘導性 → 電流遅れ

LやCを合成したあとに共振周波数を比較する問題では、先に合成値を求めてから`f0=1/(2π√LC)`へ代入する。`f0`は`LC`の平方根に反比例するので、大小比較だけなら比を使うと速い。

### 8.7 周波数変化問題の解法アルゴリズム

50Hzから60Hzへ変化する問題では、次の順序を固定すると取り違えにくい。

1. R・L・Cと初期周波数、変更後周波数を整理する。
2. `XL=2πfL`、`XC=1/(2πfC)`で変更前後のリアクタンスを求める。
3. 直列なら`Z`を加算し、`|Z|`を求める。並列なら枝電流を別々に求めてフェーザ合成する。
4. `I=V/|Z|`などで必要な電流・電圧を求める。
5. `XL-XC`の符号または枝電流の向きから位相を判定する。
6. 共振が関係するなら`XL=XC`または`f0=1/(2π√LC)`と照合する。
7. 桁、Ω・H・F・Hz、mH・μFの単位換算を確認する。

周波数だけが変わりR・L・Cが同じなら、比を使うと計算を短くできる。

```text
XL2 = XL1 × f2/f1
XC2 = XC1 × f1/f2
```

50Hz→60Hzなら`XL`は1.2倍、`XC`は5/6倍である。

### 8.8 新幹線との接続

本Topicで新幹線から読み取るべき理論上の要点は、交流の周波数が50Hzと60Hzで異なれば、同じL・Cでもリアクタンスが変わるということである。

```text
50Hz → 60Hz
XL: 増える
XC: 減る
```

したがって交流機器を考えるときは、電圧の大きさだけでなく周波数も回路条件になる。ただし、北陸新幹線の具体的な周波数切替設備、車上機器構成、切替地点などは本Topicの理論範囲では扱わず、未確認情報を推測して補わない。

### 8.9 3段階例題

#### 例題1 基礎: 50Hzと60Hzでリアクタンスはどう変わるか

`L=0.10H`、`C=100μF`について、50Hzと60Hzの`XL`、`XC`を求める。

50Hzでは

```text
XL = 2π×50×0.10 = 31.4Ω
XC = 1 / (2π×50×100×10^-6) = 31.8Ω
```

60Hzでは

```text
XL = 2π×60×0.10 = 37.7Ω
XC = 1 / (2π×60×100×10^-6) = 26.5Ω
```

したがって50Hz→60Hzで`XL`は増加し、`XC`は減少する。比で確認すると

```text
37.7 / 31.4 ≈ 1.20
26.5 / 31.8 ≈ 0.833 = 5/6
```

となる。

#### 例題2 本試験標準: RC直列回路の周波数変化

`R=8Ω`、`C=530.5μF`のRC直列回路に`V=100V`を加える。50Hzと60Hzの電流を求める。Cは教材用仮定値である。

50Hzでは

```text
XC ≈ 6.00Ω
|Z| = √(8²+6²) = 10.0Ω
I = 100 / 10.0 = 10.0A
```

60Hzでは、比を使えば

```text
XC = 6.00×50/60 = 5.00Ω
|Z| = √(8²+5²) = 9.434Ω
I = 100 / 9.434 ≈ 10.6A
```

周波数上昇で`XC`が減り、RC直列回路の`|Z|`が小さくなったため電流が増えた。抵抗損失まで問われるなら50Hzでは

```text
P = I²R = 10.0²×8 = 800W
```

と求める。力率等は用いない。

#### 例題3 複合・ひっかけ: 直列共振と並列LCを区別する

`L=0.10H`、`C=100μF`を用いる。まず`R=5Ω`を加えた直列RLC回路の共振周波数を求め、`V=100V`で共振時電流を求める。次に同じLとCだけを理想並列接続したときの枝電流を考える。

共振周波数は

```text
f0 = 1 / (2π√(0.10×100×10^-6))
   ≈ 50.3Hz
```

このとき

```text
XL = XC ≈ 31.6Ω
```

直列RLCではリアクタンスが打ち消されるので

```text
Z = R = 5Ω
I = 100 / 5 = 20A
```

となる。コイル端子電圧は

```text
VL = IXL ≈ 20×31.6 = 632V
```

で、電源電圧100Vより大きい。LとCの端子電圧が逆位相で打ち消し合うためである。

同じL・Cを100Vの理想並列LCとした場合、共振点では

```text
IL = 100 / 31.6 ≈ 3.16A
IC = 100 / 31.6 ≈ 3.16A
```

で大きさが等しく、位相が反対なので打ち消し合う。直列共振では合成インピーダンスが最小になって電源電流が最大、理想並列LCでは枝電流が相殺され外部から見た合成電流が小さくなる。この違いを混同しない。

さらに60Hzなら

```text
XL ≈ 37.7Ω
XC ≈ 26.5Ω
```

なので直列RLCは`XL>XC`で誘導性となり、電流は遅れる。共振周波数より高い側だから、という判断とも一致する。

### 8.10 頻出ミス

- `XL`と`XC`の周波数依存を逆にする。
- μFをFへ直さず`10^-6`を落とす。
- RC・RLの電圧を算術和してしまい、フェーザ合成をしない。
- RLC直列で`XL+XC`としてしまう。符号を含めて`XL-XC`である。
- `Z=R+jX`の`j`を数値の単位と誤解する。`j`は90°位相差を表す複素数記号である。
- 共振時にLやCそのものが消えると考える。打ち消されるのは合成リアクタンスであり、各素子の端子電圧・枝電流は存在する。
- 直列共振と並列共振で「電流最大/最小」の対象を混同する。
- 50Hz→60Hzで回路電流も必ず一定方向に増減すると決めつける。最終的には回路構成と合成インピーダンスで判定する。

### 8.11 公式・解法まとめ

```text
ZR = R
ZL = jXL
ZC = -jXC

XL = 2πfL
XC = 1/(2πfC)

RLC直列:
Z = R + j(XL-XC)
|Z| = √{R²+(XL-XC)²}
I = V/|Z|

直列共振:
XL = XC
f0 = 1/(2π√LC)
Z = R

周波数変更:
XL2 = XL1(f2/f1)
XC2 = XC1(f1/f2)
```

問題を見たら「周波数 → `XL`,`XC` → 接続方式 → `Z`または枝電流 → 電流・電圧 → 位相・共振」の順で処理する。
