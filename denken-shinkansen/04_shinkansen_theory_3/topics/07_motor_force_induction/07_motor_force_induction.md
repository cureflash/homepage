# 解説本文

## 8. このテーマで電験は何を問うか

このTopicの中心は、「磁界の中に電流を置くと力が生じる」「その力をコイルの両側に作ると回転トルクになる」「逆に導体を磁界中で動かすと起電力が生じる」という三つのつながりである。電験三種では、モーターの構造名称を暗記するより、磁界・電流・速度の向きと、力・起電力の大きさを式から判断できることが重要になる。

本Topicを終えた時点で、次をできる状態を目標とする。

1. `F=BIl sinθ`を使い、磁界中の直線導体に働く力を求める。
2. フレミング左手則で磁界・電流・力の向きを判断する。
3. 平行導体が引き合うか反発するかを、各導体が作る磁界から説明する。
4. コイルの対向辺に働く力から偶力・トルクを求める。
5. `F=qvB sinθ`を使い、荷電粒子に働くローレンツ力と向きを判断する。
6. `e=Blv sinθ`を使い、運動導体の誘導起電力を求める。
7. フレミング右手則とレンツの法則から、誘導起電力の向きを判断する。
8. 電動機が回転すると逆起電力が生じる理由を説明する。

## 9. 磁界中の電流に働く力

磁束密度 `B [T]` の一様な磁界中に、長さ `l [m]` の直線導体を置き、電流 `I [A]` を流す。導体の電流方向と磁界方向のなす角を `θ` とすると、導体に働く力の大きさは

```text
F = BIl sinθ
```

である。

各量は次の意味を持つ。

| 量 | 意味 | 単位 |
|---|---|---|
| `F` | 導体に働く力 | `N` |
| `B` | 磁束密度 | `T` |
| `I` | 導体電流 | `A` |
| `l` | 磁界中にある有効導体長 | `m` |
| `θ` | 電流方向と磁界方向のなす角 | `rad` または角度 |

したがって、電流と磁界が平行なら `sin0°=0` なので力は0、直角なら `sin90°=1` なので力は最大になる。

### 9.1 向きはフレミング左手則

大きさだけでなく向きも問われる。フレミング左手則では、左手の三指を互いに直角にして

```text
人差し指: 磁界 B（N極→S極）
中指:     電流 I（正電荷が進む向き）
親指:     力 F
```

として判定する。

電子の移動方向をそのまま電流方向として使わない。金属導体では電子の移動方向と慣用電流の向きは逆である。

### 9.2 公式を使う手順

1. 問題図から磁界の向きと電流の向きを読む。
2. `θ` が電流と磁界のなす角であることを確認する。
3. 長さを `m`、磁束密度を `T`、電流を `A` にそろえる。
4. `F=BIl sinθ` で大きさを求める。
5. フレミング左手則で向きを決める。
6. `θ=0°` なら0、`90°` なら最大という極端条件で検算する。

## 10. 平行導体間に働く力

長い直線導体Aに電流 `IA` が流れると、その周囲には円周方向の磁界が生じる。導体から距離 `r` の点で、透磁率を `μ` とすると

```text
H = IA/(2πr)
B = μH = μIA/(2πr)
```

である。

その位置に、Aと平行な導体Bがあり電流 `IB` が流れていると、Bの単位長さ当たりに働く力は

```text
F/l = BIB
    = μIAIB/(2πr)
```

となる。

向きを右ねじの法則とフレミング左手則で追うと、

```text
同方向電流 → 引力
逆方向電流 → 反発力
```

となる。これは暗記だけでなく、「一方の導体が作る磁界中に、もう一方の導体電流が置かれている」と考えると再構成できる。

### 10.1 直線導体と矩形ループ

一本の長い直線導体の横に矩形ループがある場合、直線導体に近い辺と遠い辺では磁束密度が異なる。磁束密度は `1/r` に比例するので、近い辺に働く力の方が大きい。

近側までの距離を `d`、ループ幅を `a`、直線導体と平行な辺の長さを `h` とすると、近側と遠側の力の大きさは

```text
Fnear = μIAIBh/(2πd)
Ffar  = μIAIBh/{2π(d+a)}
```

である。両者が逆向きなら、合力は差で求める。

```text
Fnet = μIAIBh/(2π){1/d - 1/(d+a)}
```

方向は、近側と遠側の電流方向から引力・反発力を個別に判断し、大きい方の向きへ合成する。

## 11. コイルに働く力と回転トルク

一様磁界中に電流ループを置くと、ループの各辺に働く力を合成して回転作用を考えることができる。磁界と平行な辺では `F=BIl sin0°=0`、磁界と直角な二つの対向辺では等しい大きさで逆向きの力が働くことがある。

この二つの力は合力としては0でも、作用線が離れているため偶力となり、コイルを回転させる。

矩形コイルの面積を `A`、巻数を `N`、電流を `I`、磁束密度を `B` とし、コイル面の法線と磁界 `B` のなす角を `φ` とすると、トルクの大きさは

```text
τ = NIAB sinφ
```

となる。これは `F=BIl` を対向辺に適用し、各力と回転軸までの距離から偶力のモーメントを取ることで得られる。

特に1巻きの正方形コイルで、一辺を `h`、条件が最大トルク `sinφ=1` なら

```text
A = h²
τ = BIh²
```

である。

ここで重要なのは、`φ` を「コイル面と磁界の角度」と取り違えないことである。本稿の `φ` はコイル面の法線と磁界のなす角で定義する。

## 12. ローレンツ力

電流をさらに細かく見ると、導体中を移動する荷電粒子が磁界から力を受けている。電荷 `q [C]` が速度 `v [m/s]` で磁束密度 `B [T]` の磁界中を運動し、速度と磁界のなす角を `θ` とすると、ローレンツ力の大きさは

```text
F = |q|vB sinθ
```

である。符号まで含む向きはベクトルで

```text
F = q(v × B)
```

と表せる。正電荷なら `v×B` の向き、負電荷ならその逆向きである。

### 12.1 `F=BIl sinθ` とのつながり

短い導体要素 `Δl` を時間 `Δt` の間に電荷 `q` が通過すると考えると

```text
I = q/Δt
v = Δl/Δt
```

より

```text
IΔl = qv
```

となる。これを

```text
F = BIΔl sinθ
```

へ代入すると

```text
F = qvB sinθ
```

が得られる。導体に働く電磁力と荷電粒子に働くローレンツ力は別々の暗記事項ではなく、同じ磁気力を異なる尺度で表している。

### 12.2 磁気力が速度に直角なら円運動になる

`v` が `B` に垂直な場合、磁気力も速度に常に垂直になる。磁気力は速さの向きだけを変え、速さそのものを変えない。したがって一様磁界中では荷電粒子は円運動し、円運動の向きは電荷の正負で反転する。

電験の方向判定では、電子に対してフレミング左手則を使う場合、電子の速度方向と慣用電流方向が逆であることに注意する。

## 13. 運動導体の誘導起電力

電流を流して導体を動かすのが電動機側の見方なら、導体を磁界中で動かして起電力を得るのが電磁誘導側の見方である。

長さ `l` の直線導体が速度 `v` で一様磁界 `B` の中を動く。速度と磁界のなす角を `θ` とし、導体が `v×B` の向きに沿う基本配置では、導体両端に生じる誘導起電力の大きさは

```text
e = Blv sinθ
```

である。

この式は、磁界に垂直な速度成分

```text
v⊥ = v sinθ
```

だけが起電力に寄与することを表す。したがって

- `v` と `B` が平行 → `e=0`
- `v` と `B` が直角 → `e=Blv` で最大

となる。

一般の向きでは導体方向も含めて考える必要があるが、本Topicの固定過去問では上記の基本配置として扱う。

### 13.1 向きはフレミング右手則

フレミング右手則では、右手の三指を互いに直角にして

```text
人差し指: 磁界 B
親指:     導体の運動 v
中指:     誘導起電力・誘導電流の向き
```

として判断する。

左手則は「電流を流したときに力がどちらへ出るか」、右手則は「導体を動かしたときに誘導起電力がどちらへ出るか」で使い分ける。

## 14. 逆起電力の基本

電動機の導体は、磁界中で力を受けて回転すると同時に、磁界中を運動する導体でもある。そのため回転中の導体には誘導起電力が生じる。

レンツの法則により、その誘導作用は原因となる変化を妨げる向きになる。電動機では、外部から加えた電圧によって生じる電流と回転に対し、回転によって生じた誘導起電力は外部電圧に逆らう向きになる。このため逆起電力と呼ぶ。

本Topicでは、

```text
磁界中の電流 → 力 → 回転
回転する導体 → 誘導起電力 → 外部電圧に逆らう
```

という因果関係まで扱う。直流機の電圧方程式、界磁方式、速度制御の計算へは広げない。

## 15. 0系主電動機への接続

0系で直流主電動機が使われたことを、このTopicでは電磁力を実車へつなぐ入口として使う。主電動機が回転力を得る物理の根本は、磁界中の電流に力が働き、その力を回転トルクとして取り出すことである。

同時に、回転する電機子導体には誘導起電力が生じるので、電磁力と電磁誘導は別々の現象ではなく、同じ主電動機の中で両方が現れる。

ここでは0系主電動機の未確認の電流値、磁束密度、巻数、内部結線、制御方式を仮定して実車値として扱わない。数値例題は電磁気の一般問題として設定する。

## 16. 問題を見たときの解法アルゴリズム

### 16.1 磁界中の直線導体

1. `B`、`I`、`l`、電流と磁界の角度 `θ` を拾う。
2. `l` を `m` にそろえる。
3. `F=BIl sinθ` で大きさを求める。
4. フレミング左手則で向きを決める。
5. `θ=0°` で0、`90°` で最大になるか検算する。

### 16.2 平行導体・ループ

1. 力を受ける各辺について、他方の導体が作る磁界 `B=μI/(2πr)` を求める。
2. `F=BIl` で各辺の力を別々に求める。
3. 同方向電流は引力、逆方向電流は反発力として向きを付ける。
4. 近側と遠側の力をベクトル的に合成する。
5. `B∝1/r` なので、近側の方が大きいことを検算に使う。

### 16.3 コイルのトルク

1. 磁界と平行な辺、直角な辺を分ける。
2. 各辺に `F=BIl sinθ` を適用する。
3. 等大逆向きで作用線が離れた力を偶力として扱う。
4. 一般式を使うなら、コイル面の法線と磁界の角度 `φ` を確認して `τ=NIAB sinφ`。
5. 正方形なら `A=h²` を使う。

### 16.4 ローレンツ力

1. 荷電粒子の電荷の正負を確認する。
2. `v` と `B` の角度 `θ` を確認する。
3. 大きさは `F=|q|vB sinθ`。
4. 正電荷は `v×B`、負電荷はその逆方向。
5. `v⊥B` なら力は速度に直角で、円運動になることを使う。

### 16.5 運動導体の誘導起電力

1. `B`、`l`、`v`、`v` と `B` の角度 `θ` を拾う。
2. 基本配置であることを確認し、`e=Blv sinθ` を使う。
3. フレミング右手則で誘導起電力の向きを決める。
4. `v∥B` なら0、`v⊥B` なら最大であることを検算する。

## 17. 頻出ミス

- `F=BIl sinθ` の `θ` を電流と磁界以外の角度として使う。
- `cm`、`mm` を `m` に直さず `l` へ代入する。
- フレミング左手則と右手則を逆に使う。
- 電子の移動方向を慣用電流の向きとして左手則へ入れる。
- 平行導体で「同方向は反発」と逆に覚える。
- ループ問題で近側と遠側の磁束密度を同じとみなす。
- 偶力は合力0だから回転しないと誤る。合力0でもモーメントは残り得る。
- `τ=NIAB sinφ` の `φ` をコイル面そのものと磁界の角度として使う。本稿では面の法線と磁界の角度である。
- `F=qvB sinθ` で負電荷の向きを反転し忘れる。
- `e=Blv sinθ` で `θ` を導体と磁界の角度として扱う。固定過去問の基本配置では速度と磁界の角度である。
- `v∥B` でも誘導起電力が生じると考える。
- 逆起電力を直流機の速度制御計算まで広げる。本Topicでは基本概念までに留める。

## 18. 公式・解法まとめ

```text
磁界中の導体:
F = BIl sinθ

直線電流が作る磁界:
H = I/(2πr)
B = μI/(2πr)

平行導体の単位長さ当たりの力:
F/l = μI1I2/(2πr)

コイルのトルク:
τ = NIAB sinφ
（φ: コイル面の法線とBのなす角）

ローレンツ力:
F = |q|vB sinθ
向きは q(v×B)

運動導体の誘導起電力（基本配置）:
e = Blv sinθ
```

# 3段階例題

## 例題1 基礎: 磁界中の直線導体に働く力

磁束密度 `B=0.30 T` の一様磁界中に、長さ `l=0.25 m` の直線導体を磁界と直角に置き、`I=4.0 A` の電流を流した。導体に働く力の大きさを求めよ。

### 解法

電流方向と磁界方向は直角なので

```text
θ = 90°
sinθ = 1
```

である。したがって

```text
F = BIl sinθ
  = 0.30 × 4.0 × 0.25 × 1
  = 0.30 N
```

答え: `0.30 N`

向きは問題図の磁界方向・電流方向に対してフレミング左手則で決める。もし導体を磁界と平行にすれば `sin0°=0` となり、力は0になる。

## 例題2 本試験標準: 直線導体の横にある矩形ループの合成電磁力

十分長い直線導体Aに上向き `IA=10 A` の電流が流れている。その右側に矩形ループBがあり、Aと平行な辺の長さは `h=0.20 m`、近側辺までの距離は `d=0.10 m`、近側辺と遠側辺の間隔は `a=0.20 m` とする。ループ電流は `IB=5.0 A` で、近側辺では下向き、遠側辺では上向きに流れる。空気中として `μ0=4π×10^-7 H/m` とする。ループに働く水平方向の合力の大きさと向きを求めよ。

### 解法

近側辺はAと電流が逆方向なので反発し、右向きに力を受ける。遠側辺はAと同方向なので引力を受け、左向きに力を受ける。

近側の磁束密度は

```text
Bnear = μ0IA/(2πd)
```

遠側の距離は

```text
d+a = 0.10+0.20 = 0.30 m
```

なので

```text
Bfar = μ0IA/{2π(d+a)}
```

各辺に働く力は `F=BIh` だから、合力の大きさは

```text
Fnet
= μ0IAIBh/(2π){1/d - 1/(d+a)}

= (4π×10^-7 × 10 × 5.0 × 0.20)/(2π)
  × {1/0.10 - 1/0.30}

= 1.33×10^-5 N
```

近側の反発力の方が大きいので、向きは右向き、すなわち直線導体Aから遠ざかる向きである。

答え: `1.33×10^-5 N、右向き`

検算: 磁束密度は `1/r` に比例するため、距離 `0.10 m` の近側辺の力が距離 `0.30 m` の遠側辺より大きい。したがって合力は近側の力と同じ右向きになる。

## 例題3 複合・ひっかけ: コイルのトルクと運動導体の誘導起電力

### A. コイルの回転トルク

一様磁界 `B=0.50 T` 中に、1巻きの長方形コイルを置く。コイルは縦 `0.20 m`、横 `0.30 m`、電流 `I=2.0 A` とする。コイル面の法線と磁界のなす角が `φ=30°` のとき、コイルに働くトルクの大きさを求めよ。

面積は

```text
A = 0.20 × 0.30
  = 0.060 m²
```

したがって

```text
τ = NIAB sinφ
  = 1 × 2.0 × 0.060 × 0.50 × sin30°
  = 0.030 N·m
```

答え: `0.030 N·m`

ひっかけは角度の定義である。本稿の `φ` はコイル面の法線と磁界の角度であり、コイル面そのものと磁界の角度ではない。

### B. 運動導体の誘導起電力

長さ `l=0.40 m` の直線導体が、磁束密度 `B=0.25 T` の一様磁界中を速さ `v=3.0 m/s` で動く。速度と磁界のなす角は `60°` とし、導体は `v×B` の向きに沿う基本配置とする。誘導起電力の大きさを求めよ。

```text
e = Blv sinθ
  = 0.25 × 0.40 × 3.0 × sin60°
  = 0.260 V
```

答え: `0.260 V`

向きはフレミング右手則で判定する。速度と磁界が平行なら `sin0°=0` で起電力は0になるため、`sin60°` を掛け忘れないことが検算になる。

この導体が電動機の回転導体の一部なら、回転によって生じる誘導起電力は外部電圧に逆らう向きとなり、逆起電力として現れる。ただし本Topicでは直流機の電圧方程式や速度制御計算へは進まない。
