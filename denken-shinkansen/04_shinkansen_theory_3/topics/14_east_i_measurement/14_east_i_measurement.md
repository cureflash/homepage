## 6. 教材で必ず説明する事項

固定過去問と系列SPECから逆算し、本文では次を必須とする。

1. 電圧計は測定対象へ並列、電流計は直列に接続する基本と、理想計器・実計器の違い。
2. 電圧計の内部抵抗は十分大きく、電流計の内部抵抗は十分小さくする理由と、有限の内部抵抗が回路を変えること。
3. 測定値と真値の違い、絶対誤差・相対誤差の定義、計器を挿入したことによる誤差の求め方。
4. 電流計の測定範囲を分流器で広げる原理と、分流の法則から必要抵抗を逆算する手順。
5. 電圧計の測定範囲を倍率器で広げる原理と、分圧の法則から必要抵抗を逆算する手順。
6. 複数計器を接続したときは、全計器の最大目盛条件を確認し、最初に限界へ達する計器で全体の測定可能範囲が決まること。
7. 指示計器の基本と、整流形電圧計で平均値・実効値・波形率を区別する必要があること。
8. ホイートストンブリッジの平衡条件と、平衡を使って未知抵抗を求める手順。
9. 電位差計の基本を零位法の例として扱うこと。
10. 電力計の基本、電力を測定するときの電圧・電流の扱い。
11. CT・VTを用いて大電流・高電圧を測定側へ変換する基本概念。実設備の未確認結線・定数は推測しない。
12. オシロスコープ的な波形観測で、横軸時間・縦軸電圧から周期・周波数・振幅を読む基本。
13. A/D変換の基本として、標本化・量子化・符号化を区別すること。
14. センサは物理量を電気信号へ変換して計測へ渡す入口として扱い、East i固有の未確認センサ構成へ広げないこと。
15. 実際のEast iの検測項目を本文へ入れる場合は、JR等の公開一次資料で確認した項目だけを使用し、電気計測教材の全項目をEast iが直接測るようには書かないこと。

## 8. 解説本文

### 8.1 このテーマで電験は何を問うか

電気測定では、「計器をつないだら値が読める」だけでは足りない。本試験では、計器そのものを抵抗を持つ回路要素として扱い、接続によって回路がどう変わるかまで計算させる。

本Topicで特に重要なのは次の5点である。

1. 電圧計・電流計を正しく接続し、内部抵抗を含む等価回路へ直せる。
2. 分流器・倍率器で測定レンジを広げるとき、分流・分圧から抵抗値を逆算できる。
3. 真値、測定値、計器損失、誤差を区別できる。
4. ブリッジ、指示計器、波形観測、A/D変換を原理から判断できる。
5. 複数の計器がある場合、それぞれの最大目盛条件を同時に確認できる。

### 8.2 East iと「測る」という仕事

JR東日本の2025年10月7日公表資料では、現行の新幹線電気・軌道総合検測車East-i（E926形）について、軌道変位検測装置、動揺加速度計、軸箱加速度計、トロリ線状態測定装置、架線相互離隔測定装置、パンタグラフ衝撃検出装置、硬点検出装置、信号検測装置、通信検測装置を搭載していることが示されている。

同資料では、現行E926形のトロリ線状態測定は、レーザー光をトロリ線のしゅう動面へ当て、その反射から残存直径を測る方式であることも示されている。

ここで重要なのは、East iが「測定対象の物理状態をセンサで受け、信号として取得し、記録・解析して保守判断につなげる」という計測の流れを具体化している点である。

```text
設備の状態
↓
センサ・検出器
↓
電気信号・ディジタルデータ
↓
測定・記録
↓
解析
↓
保守判断
```

ただし、本Topicで学ぶ電圧計、電流計、分流器、倍率器、ホイートストンブリッジ、CT、VT等をEast iがすべて直接使用しているとは扱わない。East iの実装と、電験三種で学ぶ一般的な電気計測原理を区別する。

### 8.3 電圧計・電流計と内部抵抗

電圧計は測定したい2点間へ並列に接続する。理想電圧計は回路から電流を奪わないよう内部抵抗 `R_V → ∞` と考える。実際の電圧計は有限の内部抵抗を持つため、接続すると測定対象と並列になり、回路の合成抵抗を変える。

電流計は測定したい枝へ直列に接続する。理想電流計は電圧降下を生じないよう内部抵抗 `R_A → 0` と考える。実際の電流計は有限の内部抵抗を持つため、直列抵抗が増え、測定前より回路電流が小さくなる場合がある。

```text
電圧計: 並列、内部抵抗は大きいほどよい
電流計: 直列、内部抵抗は小さいほどよい
```

電子電圧計も、測定対象へ与える影響を小さくするには入力抵抗が大きいことが重要である。

問題では、計器を「理想計器」と勝手にみなさず、内部抵抗が与えられていれば必ず回路へ入れる。

### 8.4 測定レンジを広げる分流器・倍率器

#### 分流器

電流計の可動部を、内部抵抗 `R_A`、最大目盛電流 `I_A` の計器とする。これより大きい全電流 `I` を測るには、電流計と並列に分流器 `R_s` を接続する。

電流計と分流器の端子電圧は等しいので、

```text
I_A R_A = (I - I_A) R_s
```

したがって、

```text
R_s = I_A R_A / (I - I_A)
```

測定範囲を `n = I/I_A` 倍にするときは、

```text
R_s = R_A / (n - 1)
```

となる。

#### 倍率器

電圧計の内部抵抗を `R_V`、その最大目盛電流を `I_V` とする。最大測定電圧を `V` へ広げるには、直列に倍率器 `R_m` を入れる。

```text
V = I_V(R_V + R_m)
```

より、

```text
R_m = V/I_V - R_V
```

元の最大目盛電圧を `V_V = I_V R_V`、レンジ倍率を `n = V/V_V` とすると、

```text
R_m = (n - 1)R_V
```

である。

分流器は「並列」、倍率器は「直列」という接続を先に確定し、それからオームの法則へ戻す。

### 8.5 複数計器の最大目盛と測定可能範囲

複数の電圧計を直列に接続すると、同じ電流が流れ、各計器には内部抵抗に比例した電圧がかかる。

計器 `i` の内部抵抗を `R_i`、最大目盛電圧を `V_{i,max}` とすれば、その計器が許容できる電流は、

```text
I_{i,max} = V_{i,max}/R_i
```

である。

直列接続全体で流せる最大電流は、各計器の許容電流の最小値で決まる。

```text
I_max = min(I_{1,max}, I_{2,max}, ...)
```

全体の最大測定電圧は、

```text
V_max = I_max ΣR_i
```

となる。

「最大目盛を足せば全体レンジになる」とは限らない。先に限界へ達する計器がどれかを必ず確認する。並列抵抗を付加して計器の合成内部抵抗を変える問題でも、最初に等価抵抗を求めてから同じ考え方を使う。

### 8.6 真値・測定値・測定誤差

真値を `x_t`、測定値を `x_m` とする。

符号付き誤差は、

```text
e = x_m - x_t
```

絶対誤差は、

```text
|e| = |x_m - x_t|
```

相対誤差は、

```text
δ = (x_m - x_t)/x_t
```

百分率なら `δ×100 %` とする。

計器を接続したことで回路自体が変わる誤差もある。例えば内部抵抗 `R_A` の電流計を直列へ挿入すれば、計器で消費される電力は、

```text
P_A = I²R_A
```

である。測定回路の結線によっては、この計器損失が測定値へ含まれ、真の負荷電力との差になる。

誤差問題では次の順で解く。

1. 計器を入れない真の回路を求める。
2. 計器内部抵抗を入れた測定時の回路を求める。
3. 真値と測定値を同じ物理量で比較する。
4. 問題文の定義どおりに絶対誤差または相対誤差を計算する。

### 8.7 電力計の基本

直流では負荷電力は基本的に、

```text
P = VI
```

交流では有効電力を、

```text
P = VI cosφ
```

で表す。

電力を測定するときは、負荷を流れる電流と負荷両端の電圧を対応させる必要がある。電力計では電流を受ける回路を負荷と直列側、電圧を受ける回路を負荷と並列側へ接続するのが基本である。

実計器には内部抵抗・損失があるため、厳密な測定では接続法によって計器損失を含むかを確認する。本Topicでは、固定過去問で必要な「計器損失が誤差になり得る」範囲まで扱う。

### 8.8 抵抗測定とホイートストンブリッジ

ホイートストンブリッジは、零位法を用いて未知抵抗を求める代表的な回路である。

上側節点と下側節点の間に、左枝 `R1-R2`、右枝 `R3-Rx` を直列に置き、左右枝の中点間に検流計を接続する配置を考える。

平衡時は検流計電流が0で、左右の中点電位が等しい。このとき、

```text
R1/R2 = R3/Rx
```

したがって、

```text
Rx = R2 R3 / R1
```

となる。

平衡後に電源から見た合成抵抗を求める問題では、検流計枝に電流が流れないので、

```text
(R1 + R2) || (R3 + Rx)
```

として計算できる。

式を暗記するのではなく、「中点電位が等しい」という平衡条件から比を作ると、抵抗配置が変わっても対応しやすい。

### 8.9 電位差計・CT・VT

電位差計は零位法の代表例である。既知電圧と未知電圧を比較し、検流計電流が0になる平衡点を探す。平衡時には測定対象からほとんど電流を取り出さずに電圧を比較できる点が重要である。

CTは大電流を測定側で扱いやすい電流へ変換する計器用変流器、VTは高電圧を測定側で扱いやすい電圧へ変換する計器用変圧器である。理想変圧器の基本関係として、

```text
CT: I_p/I_s = N_s/N_p
VT: V_p/V_s = N_p/N_s
```

を使い、二次側の測定値から変成比を用いて一次側量へ戻す。

本Topicでは役割と変成比の基本までとし、East iや新幹線設備における具体的なCT・VT結線、定数、保護回路を推測しない。

### 8.10 指示計器、平均値、実効値、波形率

交流波形では「平均値」と「実効値」を混同しない。正負対称な交流の1周期の符号付き平均値は0になるため、整流形計器では全波整流後の平均値を用いる。

整流平均値を、

```text
V_av,rect = (1/T)∫|v(t)|dt
```

実効値を、

```text
V_rms = √{(1/T)∫v(t)²dt}
```

とする。

波形率は、

```text
K_f = V_rms / V_av,rect
```

である。正弦波では、

```text
K_f = π/(2√2) ≈ 1.11
```

となる。

平均値応答形で、正弦波の実効値目盛に校正した整流形電圧計は、入力の整流平均値へ約1.11を掛けて指示する。このため非正弦波では、指示値が真の実効値と一致するとは限らない。

例えば最大値60 Vの正負対称な方形波なら、整流平均値も真の実効値も60 Vである。しかし正弦波実効値目盛の平均値応答形整流計なら、

```text
指示値 ≈ 1.11×60 = 66.6 V
```

となる。非正弦波では「真の実効値」と「整流平均値から換算された指示値」を分ける。

### 8.11 オシロスコープ的な波形観測

波形表示では、横軸が時間、縦軸が電圧であることを先に確認する。

1周期が横方向 `n` 目盛、時間軸感度が `t_d` s/divなら、

```text
T = n t_d
f = 1/T
```

である。

最大値が中心線から縦方向 `m` 目盛、電圧感度が `v_d` V/divなら、

```text
V_m = m v_d
```

と読める。

正弦波なら `V_rms = V_m/√2` へ変換できるが、非正弦波へ無条件にこの式を使わない。

### 8.12 A/D変換の基本

ディジタル計測では、連続時間・連続振幅の信号をそのまま数値列にはできない。基本の流れを分けて覚える。

```text
アナログ信号
↓
標本化: 時間方向を離散化する
↓
量子化: 振幅方向を離散化する
↓
符号化: 離散値を2進数等の符号へ対応させる
↓
ディジタルデータ
```

Nビットでフルスケール範囲 `V_FS` を等間隔量子化する基本モデルでは、量子化幅は概ね、

```text
Δ = V_FS / 2^N
```

となる。

ディジタルオシロスコープは標本化した波形データを記憶・表示できる。FFTは周波数成分を解析する追加機能であり、時間波形を表示すること自体の必須条件ではない。

### 8.13 センサ

センサは、温度、変位、加速度、光、力、位置等の物理量を、後段で処理できる電気信号またはディジタルデータへ変換する入口である。

測定系では、

```text
物理量
→ センサ
→ 信号変換
→ A/D変換
→ 記録・解析
```

という流れを意識する。

East iでは一次資料で複数のセンサを用いる軌道変位検測やレーザーを用いるトロリ線状態測定が確認できるが、本Topicではその内部回路・センサ定数を推測しない。

### 8.14 問題を見たときの解法手順

測定問題は、計器名を見て公式を当てるのではなく、最初に回路へ戻す。

1. 何を測るかを確認する。電圧、電流、抵抗、電力、波形のどれかを分ける。
2. 計器の接続を確認する。電圧計は並列、電流計は直列。
3. 内部抵抗、分流器、倍率器をすべて抵抗として回路へ書き込む。
4. スイッチ状態がある場合は状態ごとに別回路として描く。
5. 最大目盛が複数ある場合は各計器の限界を個別に計算する。
6. 分流・分圧、ブリッジ平衡等の条件式を立てる。
7. 真値と測定値がある場合は、どちらの回路条件で得た値かを明記する。
8. 波形問題では、平均値、整流平均値、実効値、最大値を区別する。
9. ディジタル計測では、標本化・量子化・符号化のどの段階かを判定する。
10. 最後に単位、百分率、最大目盛超過、回路への計器負荷を検算する。

### 8.15 頻出ミス

- 電圧計を直列、電流計を並列にしてしまう。
- 電圧計を理想計器として扱い、与えられた内部抵抗を無視する。
- 分流器と倍率器の接続を逆にする。
- 分流器へ流れる電流を全電流 `I` としてしまい、`I-I_A` を使わない。
- 直列接続した複数電圧計の最大目盛を単純に加算する。
- 真値と測定値を逆にして誤差率の分母を変える。
- 計器の内部抵抗による損失 `I²R` を無視する。
- ホイートストンブリッジの抵抗配置を確認せず比の式だけ暗記する。
- 正負対称交流の符号付き平均値と整流平均値を混同する。
- 非正弦波で、整流形計器の指示値を真の実効値とみなす。
- 標本化と量子化を逆にする。
- ディジタルオシロスコープの波形表示にFFTが必須だと考える。
- East iが、本Topicで学ぶ全種類の電気計器を直接用いていると断定する。

## 9. 3段階例題

### 9.1 基礎例題: 分流器で電流計のレンジを広げる

内部抵抗 `R_A=100 Ω`、最大目盛電流 `I_A=1.0 mA` の直流電流計を使って、最大 `10 mA` まで測定したい。必要な分流器抵抗 `R_s` を求めよ。

分流器は電流計と並列なので、両端電圧は等しい。

```text
I_A R_A = (I-I_A)R_s
```

数値を代入する。

```text
R_s
= I_A R_A/(I-I_A)
= (1.0×10^-3×100)/(10×10^-3-1.0×10^-3)
= 0.100/0.009
≈ 11.1 Ω
```

答え: `約11.1 Ω`。

検算: 10 mA中、電流計へ1 mA、分流器へ9 mAを流す必要がある。分流器抵抗は電流計内部抵抗より十分小さく、9倍の電流を流す関係と整合する。

### 9.2 本試験標準例題: ホイートストンブリッジ

上側と下側を電源端子とし、左枝を上から `R1=120 Ω`、`R2=300 Ω`、右枝を上から `R3=80 Ω`、`Rx` とする。左右枝の中点を結ぶ検流計が0を示した。電源電圧が `12 V` のとき、`Rx` と電源電流を求めよ。

平衡条件は、

```text
R1/R2 = R3/Rx
```

なので、

```text
Rx = R2 R3/R1
   = 300×80/120
   = 200 Ω
```

平衡時は検流計枝に電流が流れない。

左枝:

```text
R_L = 120+300 = 420 Ω
I_L = 12/420 ≈ 28.6 mA
```

右枝:

```text
R_R = 80+200 = 280 Ω
I_R = 12/280 ≈ 42.9 mA
```

電源電流は、

```text
I = I_L + I_R
  ≈ 28.6+42.9
  ≈ 71.4 mA
```

答え: `Rx=200 Ω`、電源電流 `約71.4 mA`。

検算: 合成抵抗は `420||280=168 Ω` なので、`12/168=0.0714 A` となり一致する。

### 9.3 複合・ひっかけ例題: 電圧計をつないだことで生じる測定誤差

理想電圧源 `E=10 V` に直列抵抗 `R_s=10 kΩ` と負荷 `R_L=10 kΩ` が接続されている。負荷電圧を内部抵抗 `R_V=10 kΩ` の電圧計で測定する。電圧計を接続しないときの真の負荷電圧、電圧計の指示値、絶対誤差、真値に対する相対誤差を求めよ。

まず計器を接続しない真値を求める。

```text
V_t
= E R_L/(R_s+R_L)
= 10×10/(10+10)
= 5.0 V
```

次に電圧計を接続すると、負荷と電圧計が並列になる。

```text
R_L || R_V
= 10 kΩ || 10 kΩ
= 5.0 kΩ
```

したがって測定値は、

```text
V_m
= 10×5/(10+5)
= 3.33 V
```

符号付き誤差は、

```text
e = V_m - V_t
  = 3.33-5.00
  = -1.67 V
```

絶対誤差は、

```text
|e| = 1.67 V
```

相対誤差は、

```text
δ
= (3.33-5.00)/5.00×100
≈ -33.3 %
```

答え: 真値 `5.0 V`、測定値 `3.33 V`、絶対誤差 `1.67 V`、相対誤差 `約-33.3 %`。

検算: 電圧計を並列接続すると負荷側合成抵抗が10 kΩから5 kΩへ下がるため、負荷端子電圧が5 Vより低下する結果は物理的に妥当である。
