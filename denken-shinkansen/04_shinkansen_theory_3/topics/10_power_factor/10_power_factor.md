扱う内容:

- 無効電力
- 皮相電力
- 力率
- 位相差

SPEC固定公式:

```text
P = VI cosφ
Q = VI sinφ
S = VI
S² = P² + Q²
cosφ = P / S
```

## 9. 解説本文

### 9.1 このテーマで電験は何を問うか

本Topicは電験三種「理論」の単相交流電力を扱う。固定過去問では、単に`P=VI`を使うのではなく、電圧と電流の位相差から有効電力・無効電力・皮相電力を分け、力率、電流成分、リアクタンス、力率改善へ接続することが求められる。

本Topicを終えた時点で、次を教材だけで処理できることを目標とする。

```text
電圧V・電流I・力率cosφを読む
↓
P・Q・Sを求める
↓
必要なら電力三角形または電流成分へ分解する
↓
R・Xまたは並列負荷へ接続する
↓
力率改善なら補償前後のQまたは合成リアクタンスを比較する
```

以下の交流電力式は、正弦波定常状態の単相回路で、`V`と`I`を実効値として扱う。

### 9.2 W・var・VAは何が違うか

有効電力`P[W]`は、抵抗での発熱や機械出力へ変換されるなど、負荷で正味の仕事へ変わる平均電力である。

無効電力`Q[var]`は、コイルやコンデンサに蓄えられるエネルギーが電源との間を往復する成分を表す。本Topicでは誘導性負荷の遅れ無効電力を正、容量性負荷の進み無効電力を負として整理する。

皮相電力`S[VA]`は、実効電圧と実効電流の積である。

```text
S = VI
```

`S`は設備が扱う電圧・電流の大きさを示す量であり、すべてが有効電力へ変わるとは限らない。したがって交流設備では、Wだけを見ても必要な電流や容量は決まらない。

### 9.3 位相差と電力三角形

電圧を基準とし、電流が電圧より`φ`だけ遅れる誘導性負荷を考える。電流のうち電圧と同相の成分だけが平均有効電力へ寄与するため、

```text
P = VI cosφ
```

となる。電圧と90°直交する成分に対応する無効電力は

```text
Q = VI sinφ
```

である。また

```text
S = VI
```

なので、`P`と`Q`を直交成分として扱えば

```text
S² = P² + Q²
```

が成り立つ。よって2量が分かれば残り1量を求められる。

```text
P = √(S²-Q²)
Q = √(S²-P²)   （遅れ負荷で大きさを求める場合）
```

力率は

```text
cosφ = P/S
```

である。逆に有効電力と力率が与えられれば

```text
S = P/cosφ
```

とできる。

### 9.4 複素電力の基本

有効電力と無効電力を一つに表すとき、複素電力を

```text
S_complex = P + jQ
```

と表す。ここで実部が有効電力、虚部が無効電力であり、その大きさが皮相電力である。

```text
|S_complex| = √(P²+Q²) = S
```

本Topicではこの「有効分と無効分が直交し、複素数で一体として扱える」という基本までを扱う。三相交流や高調波を含む電力へは拡張しない。

### 9.5 力率が低いと、なぜ電流が増えるか

有効電力の式を電流について解くと

```text
I = P / (V cosφ)
```

となる。同じ`P`と`V`なら、力率`cosφ`が小さいほど電流`I`は大きくなる。

例えば`P=8.0kW`、`V=200V`で、力率1.0なら

```text
I = 8000/(200×1.0) = 40A
```

力率0.8なら

```text
I = 8000/(200×0.8) = 50A
```

である。有効電力は同じでも、低力率では皮相電力と電流が増える。系列SPECの導入例「10MWを使う列車なら電源設備も10MVAあればよいのか？」に対しては、一般論として「力率が1とは限らないため、有効電力だけでは必要な皮相電力を決められない」が答えになる。実車の具体的な力率値はここでは置かない。

### 9.6 R-X回路と電力をつなぐ

既習の`R-XL`直列回路では

```text
|Z| = √(R²+XL²)
cosφ = R/|Z|
```

である。インピーダンス三角形の斜辺`|Z|`に対する抵抗成分`R`の比が力率になる。

例として`R=8Ω`、`XL=6Ω`なら

```text
|Z| = √(8²+6²) = 10Ω
cosφ = 8/10 = 0.8
```

で、誘導性なので遅れ力率0.8である。

抵抗で消費される有効電力は既習式

```text
P = I²R
```

で求められる。理想リアクタンスの無効電力は

```text
Q = I²X
```

で、リアクタンスだけの枝に電圧`V`がかかる場合は`I=V/X`なので

```text
Q = V²/X
```

と書ける。固定H26問15では、この形で無効電力からリアクタンスを逆算できることが必要になる。

### 9.7 電流を同相成分と直交成分へ分ける

電流`I`が電圧より`φ`遅れるとき、電圧と同相の有効分電流と、90°遅れる無効分電流に分けられる。

```text
IP = I cosφ
IQ = I sinφ
I = √(IP²+IQ²)
```

ここで

```text
sinφ = √(1-cos²φ)
```

を使える。

抵抗を並列追加すると、その抵抗電流は電圧と同相なので`IP`側へ加わる。一方、元の誘導性負荷の`IQ`はそのままである。したがって並列追加後は、電流の大きさを算術和せず、

```text
Inew = √{(IP+IR)² + IQ²}
```

とフェーザ合成する。抵抗値が必要なら

```text
IR = V/R
R = V/IR
```

へ接続する。この手順が固定R7上問9の中心である。

### 9.8 コンデンサによる力率改善

誘導性負荷の力率をコンデンサで改善する問題には、無効電力を並列コンデンサで相殺する見方と、直列`R-L-C`回路で合成リアクタンスを小さくする見方がある。どちらも容量性成分が誘導性成分を打ち消して位相差を小さくする点は共通である。

#### 並列コンデンサ: 無効電力で考える

誘導性負荷では正の無効電力`Q`を必要とする。これと並列にコンデンサを接続すると、コンデンサの容量性無効電力は反対向きに働き、電源側から見た無効電力を小さくできる。

有効電力`P`を変えずに、遅れ力率を`cosφ1`から`cosφ2`へ改善する標準問題では、まず

```text
Q1 = P tanφ1
Q2 = P tanφ2
```

を求める。必要な補償無効電力の大きさは

```text
QC = Q1 - Q2
```

である。

理想コンデンサに電圧`V`がかかるとき、容量性無効電力の大きさは

```text
QC = V²/XC
```

なので

```text
XC = V²/QC
```

と逆算できる。必要なら既習の

```text
XC = 1/(2πfC)
```

へ接続する。

力率改善後は

```text
S2 = P/cosφ2
I2 = P/(V cosφ2)
```

となるため、改善前より皮相電力と電源電流が小さくなる。

#### 直列R-L-C: 合成リアクタンスで考える

固定H22問8のように、`R`と`XL`の直列回路へ`XC`を直列に加える場合は、インピーダンスを

```text
Z = R + j(XL-XC)
|Z| = √{R²+(XL-XC)²}
```

とする。回路がまだ遅れ力率なら`XL>XC`であり、

```text
cosφ = R/|Z|
tanφ = (XL-XC)/R
```

が成り立つ。

改善前が`R-XL`だけなら

```text
tanφ1 = XL/R
```

改善後も遅れ力率`φ2`なら

```text
tanφ2 = (XL-XC)/R
```

なので、差を取って

```text
XC = R(tanφ1-tanφ2)
```

と求められる。

例えば改善前の力率が`1/2`なら`φ1=60°`、`tanφ1=√3`である。改善後の遅れ力率が`√3/2`なら`φ2=30°`、`tanφ2=1/√3`なので

```text
XC = R(√3-1/√3)
   = 2R/√3
```

となる。ここでは力率の角度からリアクタンス比へ変換することが要点である。

本Topicでは、このような単相回路の基本補償計算までを扱う。三相調相設備や実設備の補償方式へは拡張しない。

### 9.9 解法アルゴリズム

単相交流電力の問題は次の順で処理する。

1. `V`、`I`、`P`、`Q`、`S`、力率のうち与えられた量を整理する。
2. 力率が遅れか進みか確認する。
3. `S=VI`、`P=VIcosφ`、`Q=VIsinφ`、`S²=P²+Q²`から最短の式を選ぶ。
4. 回路値が必要なら、`P=I²R`、`Q=I²X`、`cosφ=R/|Z|`へ接続する。
5. 並列負荷なら同相成分と直交成分に分けてからフェーザ合成する。
6. 並列コンデンサによる力率改善なら、改善前後で有効電力`P`を共通とし、`Q1-Q2`から補償量を求める。
7. 直列`R-L-C`の力率改善なら、`XL-XC`と`tanφ`から容量性リアクタンスを求める。
8. W・var・VA、A・V・Ωの単位を確認する。
9. `P≤S`、`0≤cosφ≤1`になっているかを検算する。

### 9.10 新幹線との接続

新幹線を交流で受電・使用する大電力負荷として考えるとき、設備が扱う電圧・電流の大きさは有効電力`W`だけでは決まらない。一般に力率が1未満なら、同じ有効電力に対して皮相電力`VA`と電流は大きくなる。

```text
有効電力Pが同じ
↓
力率が低い
↓
S = P/cosφ が大きい
↓
I = S/V が大きい
```

ここで理解すべきなのはこの交流電力の一般原理である。特定形式の新幹線の力率、無効電力、補償装置構成は一次資料で確認していないため、本Topicの数値例には用いない。

### 9.11 3段階例題

#### 例題1 基礎: P・Q・Sを分ける

単相交流負荷に`V=200V`、`I=62.5A`が流れ、力率は遅れ0.8である。有効電力、無効電力、皮相電力を求める。

まず

```text
S = VI = 200×62.5 = 12500VA = 12.5kVA
```

力率0.8なので

```text
P = S cosφ = 12.5×0.8 = 10.0kW
```

また

```text
sinφ = √(1-0.8²) = 0.6
Q = S sinφ = 12.5×0.6 = 7.5kvar
```

検算すると

```text
√(10.0²+7.5²) = 12.5kVA
```

で一致する。

#### 例題2 本試験標準: 並列抵抗追加後の電流をフェーザ合成する

`V=200V`の電源に、`I=10A`、遅れ力率0.8の誘導性負荷が接続されている。ここへ`R=50Ω`の抵抗を並列接続した。追加後の電源電流と力率を求める。

元の負荷電流を分解する。

```text
IP = 10×0.8 = 8A
sinφ = √(1-0.8²) = 0.6
IQ = 10×0.6 = 6A  （遅れ）
```

並列抵抗の電流は電圧と同相なので

```text
IR = V/R = 200/50 = 4A
```

したがって追加後の同相成分は

```text
IP,new = 8+4 = 12A
```

無効分は6Aのままである。よって電源電流は

```text
Inew = √(12²+6²)
     = √180
     ≈ 13.4A
```

力率は

```text
cosφnew = 12/13.4 ≈ 0.894
```

で、遅れ力率約0.894となる。`10A+4A=14A`と算術加算しないことが要点である。

#### 例題3 複合・ひっかけ: コンデンサで遅れ力率を改善する

単相`V=200V`で有効電力`P=8.0kW`を消費する負荷があり、力率は遅れ0.80である。並列コンデンサで遅れ0.95へ改善する。必要な容量性無効電力の大きさ、容量性リアクタンス、改善前後の電源電流を求める。数値は教材用仮定値である。

改善前は

```text
cosφ1 = 0.80
sinφ1 = 0.60
tanφ1 = 0.60/0.80 = 0.75
Q1 = P tanφ1 = 8.0×0.75 = 6.0kvar
```

改善後は

```text
cosφ2 = 0.95
sinφ2 = √(1-0.95²) ≈ 0.3122
tanφ2 ≈ 0.3122/0.95 ≈ 0.3287
Q2 = 8.0×0.3287 ≈ 2.63kvar
```

したがってコンデンサが打ち消すべき無効電力の大きさは

```text
QC = Q1-Q2
   = 6.0-2.63
   ≈ 3.37kvar
```

容量性リアクタンスは

```text
XC = V²/QC
   = 200²/3370
   ≈ 11.9Ω
```

改善前の電流は

```text
I1 = P/(V cosφ1)
   = 8000/(200×0.80)
   = 50.0A
```

改善後は

```text
I2 = P/(V cosφ2)
   = 8000/(200×0.95)
   ≈ 42.1A
```

有効電力8.0kWは変えず、容量性無効分で誘導性無効分の一部を相殺したため、電源側の皮相電力と電流が小さくなった。`Q2`そのものをコンデンサ容量と取り違えず、必要補償量は`Q1-Q2`である。

### 9.12 頻出ミス

- `P`、`Q`、`S`の単位をすべてWとする。`P[W]`、`Q[var]`、`S[VA]`である。
- `S=P+Q`と算術加算する。正弦波単相では大きさについて`S²=P²+Q²`である。
- `P=VI`を交流負荷へ無条件に使い、力率を落とす。
- 遅れ力率と進み力率を区別しない。
- 並列負荷の電流を大きさだけで足す。位相が異なる成分はフェーザ合成する。
- `cosφ=R/|Z|`で分母と分子を逆にする。
- 直列`R-L-C`で容量性リアクタンスを`XL+XC`とする。合成リアクタンスは`XL-XC`である。
- 力率改善で有効電力まで変わると考える。標準問題では負荷の有効電力を同一として無効分を補償する。
- 並列コンデンサの補償量を改善後の`Q2`とする。必要な大きさは`Q1-Q2`である。
- 低力率ほど同じ有効電力に必要な電流が小さくなると誤る。`I=P/(Vcosφ)`なので逆である。

### 9.13 公式・解法まとめ

```text
単相・正弦波・実効値:
S = VI
P = VI cosφ
Q = VI sinφ
S² = P² + Q²
cosφ = P/S

電流成分:
IP = I cosφ
IQ = I sinφ
I = √(IP²+IQ²)

R-XL直列:
|Z| = √(R²+XL²)
cosφ = R/|Z|

抵抗・リアクタンス:
P = I²R
Q = I²X
純リアクタンス枝では Q = V²/X

並列コンデンサによる力率改善:
Q1 = P tanφ1
Q2 = P tanφ2
QC = Q1-Q2
XC = V²/QC

直列R-L-Cによる力率改善:
Z = R + j(XL-XC)
tanφ = (XL-XC)/R
XC = R(tanφ1-tanφ2)  （改善前がR-XL、改善後も遅れの場合）
```

問題を見たら「与えられた`V,I,P,Q,S,cosφ`を整理 → 電力三角形または電流成分へ分解 → 必要なら`R,X`へ接続 → 力率改善なら並列Q補償か直列リアクタンス補償かを判定」の順で処理する。
