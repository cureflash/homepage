## 1. SPEC固定範囲

主題は、発電・送電で使われる三相交流を入口に、電験三種「理論」で必要な平衡三相交流、Y・Δ結線、線間値・相値、三相電力の基本計算を解けるようにすること。

扱う内容:
- 三相交流
- 相順
- 平衡三相
- Y結線
- Δ結線
- 相電圧
- 線間電圧
- 相電流
- 線電流
- 三相電力

SPEC固定公式:

```text
Y結線：VL = √3 Vp
Δ結線：IL = √3 Ip
P = √3 VL IL cosφ
```

## 9. 解説本文

### 9.1 このテーマで電験は何を問うか

本Topicは電験三種「理論」の平衡三相交流を扱う。固定過去問では、三相交流そのものの定義よりも、Y結線とΔ結線で相電圧・線間電圧、相電流・線電流の関係がどう変わるかを見抜き、1相分の回路計算から三相全体の電力へ接続できることが要求される。

本Topicを終えた時点で、次の順で三相問題を処理できることを目標とする。

```text
平衡三相か確認
↓
Y結線かΔ結線か判定
↓
各枝に加わる相電圧を決める
↓
1相分の電流・力率・電力を求める
↓
線電流または三相全体の電力へ変換
↓
必要ならTopic 08〜10のRLC・無効電力へ接続
```

本Topicの式は、特記しない限り正弦波定常状態の平衡三相回路で実効値を扱う。

### 9.2 三相交流・平衡・相順

三相交流は、同じ周波数の三つの交流を互いに120°ずつ位相をずらした交流方式である。三つの相の電圧の大きさが等しく、各相の負荷も同じ状態を平衡三相として扱う。

相を`a,b,c`とすると、`a→b→c`のように各相が最大値へ達する順序を相順という。本Topicでは相順の意味までを扱い、相順判定器や測定回路へは進まない。

平衡していることが重要なのは、三相全部を別々に解かなくても、1相分を解けば残り2相も同じ大きさとして扱えるからである。固定過去問の多くはこの性質を使って「1相回路へ落とす→3倍する」という計算になる。

### 9.3 相値と線間値を先に区別する

三相問題では、数値を式へ代入する前に「相」と「線」のどちらの量かを判定する。

- 相電圧`Vp`: 1相の負荷1個に実際に加わる電圧
- 線間電圧`VL`: 2本の線の間で測る電圧
- 相電流`Ip`: 1相の負荷枝を流れる電流
- 線電流`IL`: 電源から各線を流れる電流

Y結線とΔ結線ではこの対応が異なる。

```text
Y結線:
VL = √3 Vp
IL = Ip

Δ結線:
VL = Vp
IL = √3 Ip
```

三相問題で最も多い誤りは、問題文の`VL`をそのまま負荷1個へ加えること、または枝電流`Ip`をそのまま線電流`IL`とすることである。結線を見てから変換する。

### 9.4 Y結線

Y結線では、三つの負荷の一端を共通点へ接続し、他端を各線へ接続する。各負荷は線と中性点の間にあるため、負荷1個へ加わるのは相電圧`Vp`である。

相電圧ベクトル`Va`と`Vb`は大きさが等しく、位相が120°異なる。線間電圧はベクトル差

```text
Vab = Va - Vb
```

なので、その大きさは

```text
|Vab|
= √{Vp² + Vp² - 2Vp²cos120°}
= √3 Vp
```

となる。したがって

```text
VL = √3 Vp
Vp = VL/√3
```

である。

一方、各線と各負荷枝は直列につながっているので、線を流れる電流がそのまま負荷枝を流れる。

```text
IL = Ip
```

Y結線の問題は、最初に必ず

```text
Vp = VL/√3
```

へ変換してから1相分のインピーダンスへ加える。

### 9.5 Δ結線

Δ結線では、各負荷が2本の線の間へ直接接続される。したがって負荷1個へ加わる相電圧は線間電圧そのものである。

```text
Vp = VL
```

一方、1本の線へ出入りする線電流は、隣接する二つの枝電流のベクトル差になる。平衡時には二つの枝電流の大きさが等しく、位相が120°異なるため、その差の大きさは

```text
IL = √3 Ip
```

となる。よって

```text
Ip = IL/√3
```

も使える。

Δ結線の問題では、各枝に`VL`がそのまま加わる。まず

```text
Ip = VL/Z
```

で枝電流を求め、線電流が必要なら最後に`√3`倍する。

### 9.6 平衡三相電力

平衡三相では各相の有効電力が等しいため、三相全体の有効電力は1相分の3倍である。

```text
P = 3 Vp Ip cosφ
```

ここで`φ`は1相負荷の電圧と電流の位相差である。

Y結線では

```text
Vp = VL/√3
Ip = IL
```

だから

```text
P
= 3 × (VL/√3) × IL × cosφ
= √3 VL IL cosφ
```

となる。

Δ結線では

```text
Vp = VL
Ip = IL/√3
```

だから同様に

```text
P
= 3 × VL × (IL/√3) × cosφ
= √3 VL IL cosφ
```

となる。よって平衡三相負荷ではYでもΔでも

```text
P = √3 VL IL cosφ
```

を線間値・線電流で使える。

単位は`VL[V]`、`IL[A]`なら`P[W]`である。逆算では

```text
IL = P/(√3 VL cosφ)
```

として、三相有効電力・線間電圧・力率から線電流を求められる。

Topic 10で扱った無効電力も1相分を3倍できるので、平衡三相では

```text
Q = 3 Vp Ip sinφ
  = √3 VL IL sinφ
```

と書ける。本Topicで新しく覚える中心は、`√3`がどの結線・どの量に現れるかである。

### 9.7 平衡Y負荷を1相回路へ落とす

固定R1問16のように、Y結線の各相へ同じ`R-L`または`R-L-C`負荷が入る問題では、三相回路をそのまま追わず1相分へ落とす。

手順は次のとおり。

1. 問題文の線間電圧`VL`を読む。
2. `Vp=VL/√3`で相電圧へ変換する。
3. 1相分のインピーダンス`Z`をTopic 09の方法で求める。
4. `Ip=Vp/|Z|`を求める。
5. Y結線なので`IL=Ip`とする。
6. 有効電力なら`P=3VpIp cosφ`または`P=√3VLILcosφ`を使う。
7. 無効電力ならTopic 10の1相無効電力を3倍する。
ここで`VL`を直接`Z`で割ると、線電流を`√3`倍大きく計算してしまう。

### 9.8 Y負荷とΔ負荷が同時にある問題

固定R4下問15のように、同じ三相電源へY負荷とΔ負荷が接続される問題では、二つの負荷を同じ枝電圧で計算してはいけない。

最初に結線ごとに枝電圧を決める。

```text
Y負荷の各枝: Vp,Y = VL/√3
Δ負荷の各枝: Vp,Δ = VL
```

その後、それぞれを独立に1相分計算する。

```text
Y負荷:
Ip,Y = Vp,Y / ZY
PY = 3 × (1相分の有効電力)

Δ負荷:
Ip,Δ = Vp,Δ / ZΔ
PΔ = 3 × (1相分の有効電力)
```

同じ電源へ並列接続された負荷の全有効電力が必要なら

```text
Ptotal = PY + PΔ
```

とする。

ポイントは「YかΔかで枝にかかる電圧を先に決める」ことである。YとΔのインピーダンス変換を使わなくても、固定範囲の問題は各枝を直接計算すれば処理できる。

### 9.9 Δコンデンサと三相無効電力

固定H29・H26では、Y結線の誘導性負荷とΔ結線のコンデンサが同じ問題に現れる。力率改善の原理そのものはTopic 10の既習事項であり、本Topicでは三相化したときの相電圧と3倍が要点になる。

Δ結線コンデンサでは各コンデンサへ線間電圧`VL`がそのまま加わる。1枝の容量性無効電力の大きさは既習式

```text
QC,phase = VL²/XC
```

なので、三相全体では

```text
QC = 3 VL²/XC
```

となる。

一方、Y結線の誘導性負荷は

```text
Vp = VL/√3
```

として1相分の無効電力を求め、それを3倍する。

完全補償を求める問題なら、誘導性無効電力の大きさ`QL`と容量性無効電力の大きさ`QC`を

```text
QL = QC
```

と置けばよい。ここでも、Δコンデンサ1個へ`VL/√3`を加えないことが重要である。

### 9.10 解法アルゴリズム

平衡三相の標準問題は次の順で処理する。

1. 平衡三相であることを確認する。
2. 各負荷がY結線かΔ結線か判定する。
3. 問題文の電圧が線間電圧`VL`か相電圧`Vp`か確認する。
4. Yなら`Vp=VL/√3`、Δなら`Vp=VL`として各枝の電圧を確定する。
5. 1相分の`R,L,C,Z,Ip,cosφ`を既習の単相交流回路として計算する。
6. Yなら`IL=Ip`、Δなら必要に応じて`IL=√3Ip`へ変換する。
7. 三相全体の電力は1相分を3倍するか、`P=√3VLILcosφ`を使う。
8. Y負荷とΔ負荷が混在する場合は、負荷ごとに独立計算して最後に電力を合計する。
9. 力率改善が含まれる場合は、Topic 10の無効電力を各相へ適用し、三相分へ3倍する。
10. `√3`を二重に掛けていないか、Yで`VL`を枝へ直入れしていないか、Δで`Ip=IL`としていないかを検算する。

### 9.11 新幹線との接続

新幹線では、電力系統側の三相交流、架線へ供給される単相25 kV、車内で利用される三相交流が一つの流れの中に現れる。

```text
電力系統: 三相交流
↓
新幹線へ供給: 単相25 kV
↓
車内で利用: 三相交流
```

本Topicでは、この「三相・単相・三相という異なる交流の形が同じ電力供給の流れに現れる」ことを概念上の接続として使う。変電所で三相から単相へ変換する具体的な結線・方式、車内で三相を作る半導体回路・PWMは本Topicの範囲外なので扱わない。

### 9.12 3段階例題

#### 例題1 基礎: Y結線の相電圧・線電流・三相電力

線間電圧`VL=200V`の平衡三相電源に、1相あたり`R=10Ω`の抵抗をY結線した。相電圧、線電流、三相有効電力を求める。数値は教材用仮定値である。

Y結線なので

```text
Vp = VL/√3
   = 200/√3
   ≈ 115.5V
```

抵抗1相へ流れる相電流は

```text
Ip = Vp/R
   = 115.5/10
   ≈ 11.55A
```
Y結線では

```text
IL = Ip ≈ 11.55A
```

抵抗負荷なので`cosφ=1`。三相有効電力は

```text
P = √3 VL IL cosφ
  = √3 × 200 × 11.55 × 1
  ≈ 4.00kW
```

1相分を3倍しても

```text
P = 3 × Vp × Ip
  ≈ 3 × 115.5 × 11.55
  ≈ 4.00kW
```

で一致する。`200V`をそのまま10Ωへ加えないことが要点である。

#### 例題2 本試験標準: Δ結線負荷の枝電流と線電流

線間電圧`VL=200V`の平衡三相電源に、1相あたり

```text
Z = 8 + j6 Ω
```

の同一負荷をΔ結線した。枝電流の大きさ、線電流、三相有効電力を求める。数値は教材用仮定値である。

まず1相インピーダンスの大きさは

```text
|Z| = √(8²+6²) = 10Ω
cosφ = 8/10 = 0.8
```

Δ結線では各枝へ線間電圧がそのまま加わるので

```text
Vp = VL = 200V
Ip = Vp/|Z|
   = 200/10
   = 20A
```

線電流は

```text
IL = √3 Ip
   = √3 × 20
   ≈ 34.6A
```

三相有効電力は

```text
P = √3 VL IL cosφ
  = √3 × 200 × 34.6 × 0.8
  ≈ 9.60kW
```

または

```text
P = 3 Vp Ip cosφ
  = 3 × 200 × 20 × 0.8
  = 9.60kW
```

で一致する。Δ結線では`Ip=IL`ではない。

#### 例題3 複合・ひっかけ: Y結線R-L負荷をΔコンデンサで補償する

線間電圧`VL=200V`の平衡三相電源に、1相あたり

```text
R = 6Ω
XL = 8Ω
```

のR-L負荷をY結線した。これと並列に同一容量のコンデンサ3個をΔ結線し、電源側の無効電力を0にしたい。Y負荷の三相有効電力・無効電力と、各コンデンサに必要な容量性リアクタンス`XC`を求める。数値は教材用仮定値である。

Y負荷1相のインピーダンスは

```text
|Z| = √(6²+8²) = 10Ω
cosφ = 6/10 = 0.6
sinφ = 8/10 = 0.8
```

Y結線なので

```text
Vp = VL/√3
   = 200/√3
   ≈ 115.5V

Ip = IL = Vp/|Z|
        ≈ 115.5/10
        ≈ 11.55A
```

三相有効電力は

```text
P = √3 VL IL cosφ
  = √3 × 200 × 11.55 × 0.6
  ≈ 2.40kW
```

三相無効電力は

```text
QL = √3 VL IL sinφ
   = √3 × 200 × 11.55 × 0.8
   ≈ 3.20kvar
```

Δ結線コンデンサでは、各コンデンサへ`VL=200V`がそのまま加わる。三相全体の容量性無効電力の大きさは

```text
QC = 3 VL²/XC
```

完全補償では`QC=QL=3200var`なので

```text
XC = 3 VL²/QL
   = 3 × 200² / 3200
   = 37.5Ω
```

となる。

この問題のひっかけは、Δコンデンサへ`200/√3V`を加えること、またはコンデンサ1個分の無効電力を三相全体と取り違えることである。

### 9.13 頻出ミス

- Y結線で`Vp=VL`とする。Yでは`Vp=VL/√3`。
- Δ結線で`Ip=IL`とする。Δでは`IL=√3Ip`。
- `√3`を電圧と電流の両方へ掛ける。Yでは電圧側、Δでは電流側に現れる。
- 線間電圧と相電圧を区別せず、1相インピーダンスへ線間電圧を直入れする。
- 三相全体の電力を1相分と取り違える。平衡三相では1相分の3倍。
- `P=3VLILcosφ`とする。線間値・線電流を使う式は`P=√3VLILcosφ`。
- Y負荷とΔ負荷が混在するとき、両方の枝へ同じ相電圧を加える。
- Δコンデンサ1個へ`VL/√3`を加える。Δでは各枝へ`VL`が加わる。
- 既習のRLC・力率計算で出た1相量を、そのまま三相全体の量とする。
- 不平衡三相やY-Δインピーダンス変換を、本Topicの基本問題へ不要に持ち込む。

### 9.14 公式・解法まとめ

```text
平衡三相:

Y結線
VL = √3 Vp
Vp = VL/√3
IL = Ip

Δ結線
VL = Vp
IL = √3 Ip
Ip = IL/√3

三相有効電力
P = 3 Vp Ip cosφ
  = √3 VL IL cosφ

逆算
IL = P/(√3 VL cosφ)

既習の無効電力を三相化
Q = 3 Vp Ip sinφ
  = √3 VL IL sinφ

Δ結線コンデンサ
QC = 3 VL²/XC
```

問題を見たら「平衡確認 → Y/Δ判定 → 枝電圧確定 → 1相分を解く → 線電流・三相電力へ変換」の順で処理する。
