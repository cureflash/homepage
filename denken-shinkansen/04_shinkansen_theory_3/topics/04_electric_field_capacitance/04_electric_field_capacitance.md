## 過去問から逆算した教材で必要な説明

1. 電荷 `Q [C]` の正負と、同符号なら反発・異符号なら引力になることを、クーロン力の向きと結び付ける。
2. クーロンの法則 `F = |Q1Q2|/(4πεr²)` の各記号・単位・適用対象を示し、複数点電荷では各力を方向付きで求めてから合成する手順を示す。
3. 電界を `E=F/q` と定義し、正の試験電荷が受ける力の向きを電界の向きとする。電気力線は電界の向きを可視化するものとして扱う。
4. 点電荷が作る電位 `V=Q/(4πεr)` をクーロン力と電気的仕事から接続し、2点間の電位差は各点の電位を求めて差を取る手順を示す。
5. 電位差と仕事の関係を示し、符号を含める場合と「必要な仕事の大きさ」を問う場合を区別する。
6. 静電容量を `C=Q/V` と定義し、`C [F]` は形状・誘電率で決まる量であり、単に「蓄えた電荷量」そのものではないことを明示する。
7. 平行板コンデンサ `C=εS/d`、`ε=ε0εr` を示し、`C∝ε`、`C∝S`、`C∝1/d` を比較問題に使えるようにする。
8. 誘電体を電極面積の一部へ入れた場合は、同じ端子電圧を持つ領域に分けて並列コンデンサとして扱えることを、面積分割から説明する。
9. コンデンサの並列合成 `Ceq=C1+C2+...` と直列合成 `1/Ceq=1/C1+1/C2+...` を示し、並列では電圧共通、直列では各コンデンサの電荷の大きさが等しいことを結び付ける。
10. 問題文を読んだ最初に「電源につながったままか」「電源から切り離したか」を判定する。理想直流電源につながったままなら電圧一定、切り離して孤立した端子では総電荷保存を使う。

# 解説本文

## 1. このテーマで電験は何を問うか

このテーマは電験三種「理論」の静電気・コンデンサに対応する。本試験では、公式を暗記して代入するだけでなく、まず「何が一定なのか」を判定する力が必要になる。

特に頻出なのは次の流れである。

```text
点電荷の配置を読む
→ 力なら向きを付けてクーロン力を合成する
→ 電位なら各点のスカラー量を足し合わせる

コンデンサの形状・誘電率を読む
→ C を決める
→ 直列・並列を判定する
→ 電源接続中なら V 一定、切離し後なら Q 保存を使う
→ 必要なら静電エネルギーを比較する
```

この章を終えると、選定した6問で要求される「クーロン力」「点電荷の電位」「平行板コンデンサ」「誘電体部分挿入」「直並列合成」「電荷保存」「静電エネルギー」を、同じ判断手順で処理できることを目標とする。

## 2. 電荷とクーロン力

### 2.1 電荷と力の向き

電荷 `Q` の単位はクーロン `[C]` で、正負を持つ。同符号の電荷同士は反発し、異符号の電荷同士は引き合う。

誘電率 `ε [F/m]` の一様な媒質中で、距離 `r [m]` だけ離れた点電荷 `Q1, Q2 [C]` の間に働く力の大きさは

```text
F = |Q1Q2| / (4πεr²)
```

である。真空では `ε=ε0` とし、`1/(4πε0) ≒ 9.0×10^9 N·m²/C²` を使える。

重要なのは、式が与えるのはまず「大きさ」だという点である。実際の合力を求めるときは、各力の向きを反発・引力から決め、右を正などの基準を決めて符号付きで足す。

### 2.2 複数点電荷は1個ずつ計算して合成する

一直線上で、中央の `+1 μC` に対して左0.20 mに `+2 μC`、右0.40 mに `+8 μC` があるとする。

左の電荷から受ける力は反発なので右向きで、

```text
F1 = 9.0×10^9 × (2×10^-6)(1×10^-6) / 0.20²
   = 0.45 N
```

右の電荷から受ける力も反発なので左向きで、

```text
F2 = 9.0×10^9 × (8×10^-6)(1×10^-6) / 0.40²
   = 0.45 N
```

したがって合力は0 Nである。距離が2倍になると力は1/4になるため、電荷量が4倍なら同じ力になる。このように、複数電荷問題では「距離の二乗」と「向き」を別々に確認する。

未知電荷を逆算する問題でも、先に各力を `F=k|Qq|/r²` の形で置き、つり合い又は合力条件を立ててから未知量について解く。

## 3. 電界・電気力線・電位・仕事

### 3.1 電界

ある点に小さな正の試験電荷 `q [C]` を置いたとき、その電荷が受ける力 `F [N]` から電界を

```text
E = F / q
```

と定義する。単位は `[N/C]`。電界の向きは、正の試験電荷が力を受ける向きである。

電気力線は電界の向きを図で表すための線であり、正電荷から出て負電荷へ入る向きに描く。本Topicでは、電気力線を電界方向の可視化として扱う。

### 3.2 電位

電位は、その点における単位電荷当たりの電気的な位置エネルギーに対応するスカラー量である。基準を無限遠に取ると、一様な媒質中の点電荷 `Q` が距離 `r` の点に作る電位は

```text
V = Q / (4πεr)
```

となる。クーロン力が `1/r²` に比例するのに対し、点電荷の電位は `1/r` に比例する点を取り違えない。

複数の点電荷がある場合、電位は方向を持たないので、各電荷が作る電位を正負込みで代数的に加える。

### 3.3 電位差と電気的な仕事

A点とB点の電位を `VA, VB` とすると、BのAに対する電位差は

```text
VBA = VB - VA
```

である。正電荷 `q` をAからBへゆっくり移動させるとき、外力がする仕事は

```text
Wext = q(VB - VA)
```

電界がする仕事は符号が逆で、

```text
Wfield = q(VA - VB)
```

となる。「仕事の大きさ」を問う場合は、最終的に絶対値を取る。

例えば真空中の `+3 μC` の点電荷から0.30 mのA点と0.60 mのB点を考えると、

```text
VA = 9.0×10^9 × 3×10^-6 / 0.30 = 90 kV
VB = 9.0×10^9 × 3×10^-6 / 0.60 = 45 kV
VB - VA = -45 kV
```

となる。点電荷から遠ざかるほど正の点電荷が作る電位は低くなる。

## 4. 静電容量と平行板コンデンサ

### 4.1 静電容量は「蓄えた電荷そのもの」ではない

コンデンサに電位差 `V [V]` を与え、一方の極板に `+Q [C]`、他方に `-Q [C]` が蓄えられたとき、静電容量 `C [F]` を

```text
C = Q / V
```

と定義する。

したがって

```text
Q = CV
```

である。`C` はそのコンデンサの形状と誘電率で決まる量であり、`Q` そのものではない。同じコンデンサでも印加電圧を変えれば蓄えられる電荷は変わる。

### 4.2 平行板コンデンサ

端効果を無視できる平行板コンデンサで、極板面積を `S [m²]`、極板間距離を `d [m]`、極板間の誘電率を `ε [F/m]` とすると、

```text
C = εS / d
```

である。したがって

```text
C ∝ ε
C ∝ S
C ∝ 1/d
```

となる。面積を2倍にすればCは2倍、距離を2倍にすればCは1/2である。

誘電率は

```text
ε = ε0 εr
```

と書ける。`ε0` は真空の誘電率、`εr` は比誘電率で無次元である。

### 4.3 誘電体を面積の一部に入れる場合

極板間距離が同じで、極板面積の一部だけに誘電体を入れる場合、その領域どうしは同じ端子電圧を持つ。したがって「面積方向に分割した並列コンデンサ」として扱う。

全体面積 `S` のうち割合 `f` に比誘電率 `εr` の誘電体を入れ、残りを真空とすると、

```text
C1 = ε0 (1-f)S / d
C2 = ε0 εr fS / d
C = C1 + C2
  = (ε0 S/d){(1-f) + εr f}
```

となる。

例えば面積の半分に `εr=4` の誘電体を入れた場合、誘電体なしの容量を `C0=ε0S/d` とすれば、

```text
C = 0.5C0 + 4×0.5C0
  = 2.5C0
```

である。面積方向の部分挿入なのに直列合成を使うのが典型的な誤りである。

## 5. コンデンサの直列・並列

### 5.1 並列接続

並列では各コンデンサの端子電圧が同じ `V` である。全電荷は

```text
Q = Q1 + Q2 + ...
  = C1V + C2V + ...
  = (C1 + C2 + ...)V
```

だから、合成容量は

```text
Ceq = C1 + C2 + ...
```

となる。

### 5.2 直列接続

直列では各コンデンサに蓄えられる電荷の大きさが同じ `Q` になる。全電圧は

```text
V = V1 + V2 + ...
  = Q/C1 + Q/C2 + ...
```

だから、

```text
1/Ceq = 1/C1 + 1/C2 + ...
```

2個なら

```text
Ceq = C1C2 / (C1 + C2)
```

である。直列合成容量は各容量より小さくなるので、計算後の検算に使える。

## 6. 最初に「何が一定か」を判定する

コンデンサ問題では、式を選ぶ前に接続状態を読む。

### 6.1 電源につながったまま

理想直流電源につながったままなら、端子電圧 `V` は電源によって一定に保たれる。形状や誘電率が変わって `C` が変化すれば、

```text
Q = CV
```

に従って電荷が電源との間を移動する。

### 6.2 電源から切り離した後

電源から切り離され、電荷が逃げる経路のない孤立した端子では、総電荷 `Q` を保存する。この場合、`C` が変われば

```text
V = Q/C
```

によって電圧が変わる。

### 6.3 つなぎ替え

充電済みコンデンサをつなぎ替える問題では、次の順序で処理する。

```text
1. 接続前の各コンデンサの電荷 Qi=CiVi を求める
2. どの極性の端子どうしを接続するか確認する
3. 接続後に同じ節点となる端子の総電荷を求める
4. 電荷保存を使う
5. 並列なら接続後の共通電圧 Vf を求める
6. 必要なら最終電荷・静電エネルギーを求める
```

同極性を接続する場合は電荷を加える。逆極性なら符号を付けて扱う。極性を見ずに電荷の絶対値だけを足すと誤答になる。

## 7. 静電エネルギー

コンデンサに蓄えられる静電エネルギー `U [J]` は

```text
U = 1/2 CV²
  = 1/2 QV
  = Q²/(2C)
```

である。3式は同じ内容だが、問題の不変量に合わせて形を選ぶと計算しやすい。

- 電圧一定なら `U=1/2 CV²`
- 電荷一定なら `U=Q²/(2C)`
- QとVが直接分かるなら `U=1/2 QV`

特に、電源切離し後に極板間距離を変える問題ではQ一定である。`d` を増やすと `C=εS/d` は減少し、`U=Q²/(2C)` は増加する。電源につながったままのV一定問題と混同しない。

また、充電済みコンデンサ同士をつなぎ替える場合、電荷保存は必ず使えるが、静電エネルギーが接続前後で同じとは限らない。したがって、エネルギー保存を先に仮定せず、接続後の `C` と `V` から改めて `U` を計算する。

## 8. 本試験で使う解法手順

### 8.1 点電荷問題

```text
1. 電荷の正負と位置を図にする
2. 距離 r を確認する
3. 力なら F=|Q1Q2|/(4πεr²) を各組について計算する
4. 引力・反発から向きを付けて合成する
5. 電位なら V=Q/(4πεr) を各電荷について計算し、代数的に足す
6. 電位差なら終点電位－始点電位を取る
7. r² と r の取り違え、μC→Cの換算を検算する
```

### 8.2 コンデンサ問題

```text
1. 形状・誘電率から必要なら C=εS/d を求める
2. 直列か並列かを判定して Ceq を求める
3. 電源接続中か切離し後かを判定する
4. 一定量が V か Q かを決める
5. Q=CV で各状態をつなぐ
6. つなぎ替えなら極性と総電荷保存を確認する
7. U=1/2CV², 1/2QV, Q²/(2C) から条件に合う式を選ぶ
8. 直列Ceqが最小容量より小さいか、並列Ceqが各容量より大きいかを検算する
```

# 3段階例題

## 例題1 基礎: 点電荷が作る電位

真空中に `Q=+2.0 μC` の点電荷がある。点電荷から `r=0.30 m` 離れた点の電位を、無限遠を0 Vとして求める。`1/(4πε0)=9.0×10^9` とする。

### 解法

点電荷が作る電位なので

```text
V = Q/(4πε0r)
  = 9.0×10^9 × 2.0×10^-6 / 0.30
  = 6.0×10^4 V
  = 60 kV
```

答えは `60 kV`。

ここでは力ではなく電位を求めているため、距離は `r²` ではなく `r` で割る。

## 例題2 本試験標準: 電源切離し後に極板間距離を変える

真空中の平行板コンデンサを直流電源に接続して充電した。初期容量を `C0`、初期電圧を `V0` とする。その後、電源から完全に切り離してから極板間距離を2倍にした。最終容量 `C1`、最終電圧 `V1`、最終静電エネルギー `U1` を初期値との比で求める。端効果は無視する。

### 解法

まず形状から容量を判定する。

```text
C = εS/d
```

なので、距離を2倍にすると

```text
C1 = C0/2
```

次に、電源から切り離した後なので電荷が一定である。

```text
Q0 = C0V0
Q1 = Q0
V1 = Q1/C1
   = C0V0/(C0/2)
   = 2V0
```

静電エネルギーはQ一定に合わせて

```text
U = Q²/(2C)
```

を使う。

```text
U1/U0 = C0/C1 = 2
```

したがって

```text
C1 = C0/2
V1 = 2V0
U1 = 2U0
```

である。電源を切り離した後なのにV一定として処理しないことが核心である。

## 例題3 複合・ひっかけ: 直列充電後に同極性並列へつなぎ替える

`C1=6 μF`、`C2=3 μF` のコンデンサを直列に接続し、全体に12 Vを加えて十分に充電した。その後、電源から切り離し、各コンデンサの正極板同士、負極板同士を接続して並列にした。接続後の共通電圧 `Vf` と、接続前後の静電エネルギーを求める。

### 解法1 直列充電時の電荷

直列合成容量は

```text
Cs = C1C2/(C1+C2)
   = 6×3/(6+3)
   = 2 μF
```

したがって直列回路で各コンデンサに蓄えられる電荷の大きさは

```text
Q = CsV
  = 2 μF × 12 V
  = 24 μC
```

である。

### 解法2 並列へつなぎ替えた後の電圧

正極板同士を接続するので、正側節点の総電荷は

```text
Qtotal = 24 + 24 = 48 μC
```

接続後の並列合成容量は

```text
Cp = 6 + 3 = 9 μF
```

よって共通電圧は

```text
Vf = Qtotal/Cp
   = 48/9
   = 16/3 V
   ≒ 5.33 V
```

となる。

### 解法3 静電エネルギー

接続前は直列合成容量に12 Vが加わっているので

```text
Ui = 1/2 CsV²
   = 1/2 × 2 μF × 12²
   = 144 μJ
```

接続後は

```text
Uf = 1/2 CpVf²
   = 1/2 × 9 μF × (16/3)²
   = 128 μJ
```

したがって

```text
Vf ≒ 5.33 V
Ui = 144 μJ
Uf = 128 μJ
```

である。電荷は保存されるが、静電エネルギーを接続前後で同一と置いてはならない。

# 9. 新幹線への接続

新幹線の架線は25 kVの高電圧であり、車体・大地との間には大きな電位差が存在する。そのため、電流が実際に流れている導体だけでなく、その周囲に電界が存在することも考える必要がある。

本Topicで使うのは、この「電位差があれば電界を考える必要がある」という静電気の基礎までである。碍子や空間が高電圧部と他部分を電気的に分離するという構造上の役割には触れるが、実車の静電容量、電界強度、必要離隔距離、絶縁耐力を推定値で置かない。

また、実際の新幹線電源は交流だが、ここでは電荷・電位・静電容量の基礎関係を学ぶための入口として25 kVという電位差を用いる。交流波形・実効値はTopic 08、容量性リアクタンスやRLCは後続Topicで扱う。

# 10. 頻出ミス・ひっかけ

- クーロン力の `r²` と点電荷電位の `r` を取り違える。
- `μC` をCへ直さず、そのまま式へ代入する。
- 力を大きさだけで足し、引力・反発による向きを無視する。
- 電位をベクトルのように方向付きで合成する。
- `C` を「蓄えられた電荷量」と考え、形状・誘電率で決まる量であることを忘れる。
- `C=εS/d` で、dを増やすとCも増えると誤認する。
- 面積方向の誘電体部分挿入を直列合成する。
- 直列コンデンサと並列コンデンサの合成式を逆にする。
- 電源切離し後もV一定と置く。
- つなぎ替えで極性を確認せず、電荷の絶対値だけを足す。
- 静電エネルギーを常に `1/2CV²` だけで処理し、Q一定の状況を見落とす。
- つなぎ替え前後で静電エネルギーが必ず保存されると仮定する。

# 12. 公式・解法まとめ

```text
クーロン力:
F = |Q1Q2|/(4πεr²)

電界:
E = F/q

点電荷の電位:
V = Q/(4πεr)

電位差と仕事:
Wext = q(VB-VA)
Wfield = q(VA-VB)

静電容量:
C = Q/V
Q = CV

平行板コンデンサ:
C = εS/d
ε = ε0εr

並列コンデンサ:
Ceq = C1 + C2 + ...
電圧が共通

直列コンデンサ:
1/Ceq = 1/C1 + 1/C2 + ...
各コンデンサの電荷の大きさが等しい

静電エネルギー:
U = 1/2 CV² = 1/2 QV = Q²/(2C)

条件判定:
電源接続中 → V一定
電源切離し後の孤立系 → Q保存
つなぎ替え → 極性確認 → 節点の総電荷保存
```
