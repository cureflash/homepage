# 解説本文

## 1. 電験で問われる直流回路網の読み方

このTopicの中心は、複数の抵抗や電源がある回路を、節点・枝・閉回路に分けて読めるようにすることである。本試験では、単に `V=RI` を代入するだけでなく、どの抵抗が直列・並列か、どの電圧・電流が共通かを判定し、KCL・KVL、重ね合わせ、テブナン等価回路を使って未知量を求める。

最初に回路図を次の3要素で読む。

- 節点: 複数の枝が接続され、理想導線で同電位とみなす点。
- 枝: 2つの節点の間にある電源・抵抗などを含む経路。
- 閉回路（ループ）: 出発点から回路を一周して同じ点へ戻る経路。

問題を見たら、いきなり式を立てず、まず「直列・並列だけで簡単にできる部分があるか」「節点電圧が共通な枝はどこか」「複数電源があるか」「負荷端子から見れば等価回路にできるか」を確認する。

この章で使う回路は直流抵抗回路である。新幹線との接続では、実際の交流主回路をそのまま計算するのではなく、回路網の考え方を学ぶための教育用等価回路に置き換える。

## 2. 直列・並列、合成抵抗、分圧・分流

### 2.1 直列回路

抵抗 `R1, R2, ... [Ω]` が一本道に並び、その途中で電流が分岐しないときは直列である。各抵抗を流れる電流 `I [A]` は共通で、全電圧 `V [V]` は各抵抗の電圧降下の和になる。

```text
V = V1 + V2 + ...
  = IR1 + IR2 + ...
  = I(R1 + R2 + ...)
```

したがって合成抵抗は

```text
Rseries = R1 + R2 + ...
```

である。直列合成抵抗は各抵抗より大きくなるため、計算後の検算に使える。

2抵抗 `R1, R2` の直列回路に全電圧 `V` を加えたとき、`R1` の電圧は

```text
V1 = I R1
I = V/(R1+R2)
```

より

```text
V1 = R1/(R1+R2) V
V2 = R2/(R1+R2) V
```

となる。これが分圧である。直列では同じ電流が流れるため、抵抗が大きい方ほど電圧降下が大きい。

### 2.2 並列回路

抵抗の両端が同じ2節点へ接続されているときは並列である。各枝の端子電圧 `V` は共通で、全電流は枝電流の和になる。

```text
I = I1 + I2 + ...
  = V/R1 + V/R2 + ...
```

したがって

```text
1/Rparallel = 1/R1 + 1/R2 + ...
```

2抵抗なら

```text
Rparallel = R1R2/(R1+R2)
```

である。並列合成抵抗は最小の枝抵抗より小さくなる。

### 2.3 分流

2抵抗 `R1, R2` の並列回路へ全電流 `I` が流れ込むとする。両枝の電圧を `V` とすると

```text
I1 = V/R1
I2 = V/R2
I = I1 + I2
```

なので、

```text
I1 = R2/(R1+R2) I
I2 = R1/(R1+R2) I
```

となる。分流式では「求めたい枝とは反対側の抵抗」が分子に来る。これは電流が抵抗に反比例して分かれるためで、暗記だけでなく `I=V/R` から確認できるようにする。

### 2.4 同一電池を並列接続する基本

起電力 `E [V]`、内部抵抗 `r [Ω]` が同一の理想化した電池を、同じ極性で `n` 個並列に接続する。各電池の起電力は同じなので、等価起電力は `E` のままであり、内部抵抗だけが並列合成される。

```text
Eeq = E
req = r/n
```

例えば同一電池2個なら `req=r/2` である。「並列だから起電力も2倍」としない。ここで扱うのは試験用の理想化モデルであり、異なる起電力の電源を無条件に並列接続する一般論へ広げない。

## 3. KCL・KVLと枝電流法

### 3.1 キルヒホッフ第1法則 KCL

一つの節点で、流入電流の和と流出電流の和は等しい。

```text
ΣIin = ΣIout
```

または、流入を正、流出を負など一つの符号規約に統一すれば

```text
ΣI = 0
```

と書ける。

並列回路の未知抵抗問題では、節点電圧を `V` とすると各枝電流を `V/R` で表し、

```text
I = V/R1 + V/R2 + ...
```

の形から未知抵抗を逆算する。

### 3.2 キルヒホッフ第2法則 KVL

任意の閉回路を一周したとき、電圧上昇と電圧降下の代数和は0になる。

```text
ΣV = 0
```

例えば、起電力 `E` と抵抗 `R1, R2` が一つのループにあり、電流を `I` と仮定すれば

```text
+E - IR1 - IR2 = 0
```

である。大切なのは、ループを回る向きを先に決め、電源と抵抗の符号を途中で変えないこと。抵抗の電圧降下は、仮定した電流方向に進めば `-IR`、逆向きに進めば `+IR` とできる。

### 3.3 枝電流法

複数枝・複数電源の回路では、各枝の電流方向を仮定し、KCLとKVLで連立方程式を作る。

```text
1. 各枝電流の向きを仮定する
2. 独立な節点でKCLを立てる
3. 独立なループでKVLを立てる
4. 連立方程式を解く
5. 負の電流が出た枝は、実際の向きが仮定と逆と読む
```

負号は計算失敗ではない。最初の電流方向は自由に仮定できるので、負の結果は実際の向きを示す情報である。

## 4. 重ね合わせの理

線形な直流抵抗回路に複数の独立電源があるとき、ある枝の電流・電圧は、各独立電源が単独で働いたときの寄与を代数的に加えて求められる。

一つの電源だけを残すとき、他の独立電源を零にする。

- 理想電圧源 `V=0` → 短絡する。
- 理想電流源 `I=0` → 開放する。

手順は

```text
1. 求めたい電流・電圧の正方向を決める
2. 電源Aだけを残し、他の独立電源を零にして寄与を求める
3. 電源Bだけを残して同様に求める
4. 各寄与を向き付きで代数和する
```

電力は一般に電流・電圧の二乗や積を含むため、各電源による「電力」をそのまま足して重ね合わせるのではなく、まず電圧・電流を重ね合わせてから最終電力を計算する。

## 5. テブナン・ノートンの基本

### 5.1 テブナンの定理

複雑な線形二端子回路を、負荷端子から見て

```text
Vth ─ Rth ─ 負荷RL
```

という一つの理想電圧源 `Vth` と直列抵抗 `Rth` に置き換えられる。

`Vth` は負荷を外したときの端子間開放電圧である。

```text
Vth = 開放端子電圧
```

`Rth` は独立電源を零にして負荷端子から回路内部を見た等価抵抗である。

```text
Rth = 端子から見た等価抵抗
```

抵抗を求めるときは、理想電圧源を短絡、理想電流源を開放する。電源を元のまま残して抵抗を合成しない。

テブナン等価回路が得られれば、負荷電流は

```text
IL = Vth/(Rth+RL)
```

負荷電圧は

```text
VL = Vth RL/(Rth+RL)
```

となる。

### 5.2 ノートンの定理

同じ二端子回路を、理想電流源 `IN` と並列抵抗 `RN` に置き換えることもできる。

```text
      ┌─ RN ─┐
IN ───┤      ├── 端子
      └──────┘
```

テブナン等価回路との関係は

```text
RN = Rth
Vth = IN Rth
IN = Vth/Rth
```

である。どちらの等価回路を使っても、外部負荷から見た端子電圧・負荷電流は同じになる。

## 6. 本試験で使う解法手順

### 6.1 直並列回路

```text
1. 同じ2節点につながる抵抗を探して並列合成する
2. 一本道に並ぶ抵抗を直列合成する
3. 全電流または全電圧を求める
4. 必要に応じて分圧・分流で元の枝へ戻す
5. KCLで枝電流の和、KVLで電圧降下の和を検算する
6. 並列合成抵抗が最小抵抗より小さいか確認する
```

### 6.2 複数電源回路

```text
1. 電流方向を仮定する
2. 節点・独立ループを選ぶ
3. KCL・KVLで必要本数の式を立てる
4. 連立方程式を解く
5. 負の電流は仮定方向と逆と読む
6. 別解が必要なら重ね合わせで電圧・電流を確認する
```

### 6.3 テブナン等価回路

```text
1. 求めたい負荷RLを外す
2. 開放端子電圧Vthを求める
3. 独立電源を零にする
4. 端子から見た等価抵抗Rthを求める
5. VthとRthの直列回路へ置換する
6. RLを戻してIL, VL, PLを求める
7. 最大電力ならRL=Rthを確認する
```

## 7. 負荷電力と最大電力供給

### 7.1 負荷電力

抵抗負荷で使う電力は

```text
P = VI = I²R = V²/R
```

である。どの形を使うかは、既知量に合わせる。

- 枝電流が分かる → `P=I²R`
- 枝電圧が分かる → `P=V²/R`
- 電圧と電流が分かる → `P=VI`

並列枝では電圧が共通なので `V²/R`、直列枝では電流が共通なので `I²R` が比較に使いやすい。

### 7.2 最大電力供給の基本

テブナン等価回路で負荷 `RL` に流れる電流は

```text
IL = Vth/(Rth+RL)
```

だから負荷電力は

```text
PL = IL² RL
   = Vth² RL/(Rth+RL)²
```

となる。

`x=RL/Rth` と置くと、変化する部分は

```text
x/(1+x)²
```

である。`(x-1)² >= 0` より

```text
(1+x)² >= 4x
```

なので最大値は `x=1`、すなわち

```text
RL = Rth
```

のときに得られる。

このとき

```text
Pmax = Vth²/(4Rth)
```

である。負荷を短絡して `RL=0` にすると負荷電圧も負荷電力も0であり、最大にはならない。

# 3段階例題

## 例題1 基礎: 直並列合成・分圧・分流

24 Vの理想直流電源に、`R1=4 Ω` が直列接続され、その先に `R2=12 Ω` と `R3=6 Ω` が並列接続されている教育用回路を考える。全電流、並列部の電圧、`R2` と `R3` の枝電流を求める。

### 解法1 並列部を合成する

```text
Rp = R2R3/(R2+R3)
   = 12×6/(12+6)
   = 4 Ω
```

全抵抗は

```text
Req = R1 + Rp
    = 4 + 4
    = 8 Ω
```

したがって全電流は

```text
I = 24/8
  = 3 A
```

### 解法2 並列部の電圧

`R1` と `Rp` は同じ4 Ωなので、24 Vは等分される。

```text
Vp = I Rp
   = 3×4
   = 12 V
```

### 解法3 枝電流

並列では電圧が共通なので

```text
I2 = Vp/R2 = 12/12 = 1 A
I3 = Vp/R3 = 12/6  = 2 A
```

KCLで

```text
I2 + I3 = 1 + 2 = 3 A = I
```

となり検算できる。

答え:

```text
全電流 3 A
並列部電圧 12 V
R2枝 1 A
R3枝 2 A
```

## 例題2 本試験標準: KCL・符号・重ね合わせ

一つの節点Aが、`12 V` の理想電圧源の正端子へ `2 Ω` を介して接続され、`6 V` の理想電圧源の正端子へ `3 Ω` を介して接続され、基準点0 Vへ `6 Ω` を介して接続されている。節点Aの電位 `VA` と各枝電流を求める。電源負端子はすべて基準点へ接続されているものとする。

12 V側からAへ流れる電流を `I12`、6 V側からAへ流れる電流を `I6`、Aから基準点へ流れる電流を `I0` とする。

### 解法1 KCLを立てる

各枝電流は

```text
I12 = (12-VA)/2
I6  = (6-VA)/3
I0  = VA/6
```

節点Aで

```text
I12 + I6 = I0
```

だから

```text
(12-VA)/2 + (6-VA)/3 = VA/6
```

両辺を6倍して

```text
3(12-VA) + 2(6-VA) = VA
36 - 3VA + 12 - 2VA = VA
48 = 6VA
VA = 8 V
```

### 解法2 各枝電流

```text
I12 = (12-8)/2 = 2 A
I6  = (6-8)/3 = -2/3 A
I0  = 8/6 = 4/3 A
```

`I6` が負なので、実際にはAから6 V電源側へ `2/3 A` 流れる。

KCLは

```text
2 + (-2/3) = 4/3 A
```

で成立する。

### 解法3 重ね合わせによる確認

12 V電源だけを残すと、6 Vの理想電圧源は0 Vなので短絡する。Aから基準点へは `3 Ω` と `6 Ω` の並列、すなわち `2 Ω` が見える。よって

```text
VA(12) = 12 × 2/(2+2) = 6 V
```

6 V電源だけを残すと、12 V源を短絡する。Aから基準点へは `2 Ω || 6 Ω = 1.5 Ω` が見えるので

```text
VA(6) = 6 × 1.5/(3+1.5) = 2 V
```

したがって

```text
VA = VA(12) + VA(6)
   = 6 + 2
   = 8 V
```

となり、KCL解と一致する。

## 例題3 複合・ひっかけ: テブナン・ノートン・最大電力

24 Vの理想直流電源に `R1=6 Ω` が直列接続され、その先の出力端子Aから基準点へ `R2=3 Ω` が接続されている。端子Aと基準点の間へ可変負荷 `RL` を接続する。この二端子回路のテブナン等価回路、ノートン等価回路、最大電力となる `RL` とその最大電力を求める。

### 解法1 開放端子電圧 Vth

負荷 `RL` を外すと、`R1` と `R2` の分圧回路になる。

```text
Vth = 24 × R2/(R1+R2)
    = 24 × 3/(6+3)
    = 8 V
```

### 解法2 等価抵抗 Rth

独立電圧源24 Vを零にするので、理想電圧源を短絡する。端子Aから見ると `R1` と `R2` は並列になる。

```text
Rth = R1R2/(R1+R2)
    = 6×3/(6+3)
    = 2 Ω
```

したがってテブナン等価回路は

```text
Vth = 8 V
Rth = 2 Ω
```

である。

### 解法3 ノートン等価回路

```text
RN = Rth = 2 Ω
IN = Vth/Rth = 8/2 = 4 A
```

よってノートン等価回路は `4 A` の理想電流源と `2 Ω` の並列回路である。

### 解法4 最大電力

最大電力供給条件は

```text
RL = Rth = 2 Ω
```

である。

```text
Pmax = Vth²/(4Rth)
     = 8²/(4×2)
     = 8 W
```

答え:

```text
テブナン: Vth=8 V, Rth=2 Ω
ノートン: IN=4 A, RN=2 Ω
最大電力条件: RL=2 Ω
最大負荷電力: 8 W
```

`RL=0` は短絡であり、負荷電力は0 Wになるため最大電力条件ではない。

# 8. 新幹線への接続

系列SPECでは、架線からパンタグラフを通り、主変圧器、電力変換装置、主電動機を経て車輪・レール側へつながる流れを入口にする。ただし実際の新幹線主回路は交流機器・電力変換機器を含み、本Topicの直流抵抗回路そのものではない。

したがって本Topicでは、回路網の考え方だけを次の教育用等価回路に置き換える。

```text
【教育用等価回路】

理想直流源 E
   │
  Rs
   │
   ●──── RA ───┐
   │           │
   └──── RB ───┤
               │
            基準点
```

- `E`: 回路計算を行うための教材用直流電源。
- `Rs`: 電源側をまとめた教材用抵抗。
- `RA, RB`: 分岐負荷を表す教材用抵抗。

これらは実車部品や実車定数を表す値ではない。この図から学ぶのは、「一本道では電流が共通」「分岐点ではKCLが成り立つ」「同じ2節点間の枝は電圧が共通」「複雑な電源側は二端子等価回路へ置換できる」という一般的な回路理論である。

# 9. 頻出ミス・ひっかけ

- 直列回路で電圧が共通、並列回路で電流が共通だと逆に覚える。
- 並列合成抵抗が各枝抵抗より大きくなる計算をしても検算しない。
- 分流式で求めたい枝自身の抵抗を分子に置く。
- KCLで電流の向きを混在させ、流入・流出の符号規約を途中で変える。
- KVLでループ方向を変え、電源・抵抗電圧の符号を途中で変更する。
- 枝電流が負になったとき、計算誤りと決めつける。
- 重ね合わせで理想電圧源を開放する。理想電圧源を零にすると短絡である。
- 重ね合わせで理想電流源を短絡する。理想電流源を零にすると開放である。
- 各電源による電力を直接足して重ね合わせる。
- テブナン等価抵抗を求める際に独立電源を残したままにする。
- `Vth` を負荷接続時の端子電圧とする。`Vth` は負荷を外した開放電圧である。
- ノートン抵抗とテブナン抵抗を別物と考える。
- 最大電力条件を `RL=0` とする。最大電力の基本条件は `RL=Rth` である。
- 新幹線の教育用等価回路を実車主回路図として扱う。

# 11. 公式・解法まとめ

```text
直列抵抗:
Rseries = R1 + R2 + ...
電流が共通

並列抵抗:
1/Rparallel = 1/R1 + 1/R2 + ...
2抵抗なら Rparallel = R1R2/(R1+R2)
電圧が共通

分圧:
V1 = R1/(R1+R2) V
V2 = R2/(R1+R2) V

分流:
I1 = R2/(R1+R2) I
I2 = R1/(R1+R2) I

KCL:
ΣIin = ΣIout

KVL:
ΣV = 0

重ね合わせ:
理想電圧源を零 → 短絡
理想電流源を零 → 開放
各電圧・電流の寄与を向き付きで代数和

テブナン:
Vth = 開放端子電圧
Rth = 独立電源を零にして端子から見た等価抵抗
IL = Vth/(Rth+RL)

ノートン:
RN = Rth
IN = Vth/Rth
Vth = IN Rth

抵抗負荷電力:
P = VI = I²R = V²/R

テブナン等価回路の負荷電力:
PL = Vth² RL/(Rth+RL)²
最大電力条件 RL = Rth
Pmax = Vth²/(4Rth)

同一起電力・同一内部抵抗の電池n個を同極性並列:
Eeq = E
req = r/n
```
