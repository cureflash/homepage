# Topic 13 インバータはどうやって三相交流を作る？

更新日: 2026-09-17
status: `EXPLANATION_SOURCE_COMPLETE`

## 1. SPEC固定範囲

主題は、半導体スイッチを高速にON/OFFして、直流からモーター駆動用交流波形を作る考え方を、電験三種「理論」の電子回路・波形の観点から学ぶこと。

扱う内容は系列SPECどおり次に固定する。

- スイッチング
- 矩形波
- パルス
- デューティ比
- PWM
- 基本波
- 高調波の概念
- 三相インバータの基本
- トランジスタをスイッチとして使う考え方
- 電子回路
- 増幅回路の基本
- オペアンプの基本

基本構成:

```text
直流
↓
半導体スイッチのON/OFF
↓
パルス波形
↓
PWM
↓
基本波成分
↓
三相交流
```

## 6. 教材で必ず説明する事項

固定過去問と系列SPECから逆算し、本文では次を必須とする。

1. 半導体スイッチを理想的なON/OFFとして扱う基本モデルと、トランジスタをスイッチとして使う考え方。
2. 直流電圧をスイッチングすることで、0/E又は正負の段階的な電圧波形を作れること。
3. 矩形波・パルスの振幅、周期、周波数、ON時間、OFF時間の意味。
4. デューティ比 `D = T_ON / T` の定義と、0/Eの理想パルスでは平均値が `D E` となる関係。
5. PWMはパルスの幅を変えることで基本波成分を制御する考え方であり、詳細なPWM制御方式へ踏み込まないこと。
6. 非正弦波には基本波と高調波が含まれること、高調波の周波数は基本波周波数の整数倍であること。
7. 波形率 `実効値/平均値`、波高率 `最大値/実効値` の定義と、方形波等の波形形状との関係。
8. ひずみ波の電力は同じ次数の電圧・電流成分ごとに計算し、`P = Σ V_n I_n cosφ_n` として加えること。抵抗負荷では `P = RΣI_n²` と書けること。
9. ダイオード等を理想スイッチとして扱う回路では、各時間区間でON/OFFを判定してから出力電圧を求める波形追跡手順。
10. 三相インバータは三相分のスイッチングでU/V/W相の基本波を120°ずつずらして作る、という基本概念。
11. 増幅回路・オペアンプは系列SPECの範囲として基本概念だけ扱い、固定4問の品質ゲートへ無理に混在させないこと。
12. 新幹線への接続は「直流リンクから可変電圧・可変周波数の三相交流を作り主電動機へ供給する」という概念説明に留め、未確認実車回路・数値を真値化しない。

## 7. 解説本文

### 7.1 このテーマで電験は何を問うか

電験三種「理論」では、インバータの車両方式名そのものより、ON/OFFする電子素子、非正弦波の実効値・電力、波形率・波高率、ダイオード回路の区間別動作を使って波形を判断させる問題が重要である。本Topicの固定4問は、これらを「波形を分ける」「スイッチ状態を決める」「同じ次数の成分を組み合わせる」という共通手順で解く。

本Topicを終えた時点で、次ができることを到達点とする。

1. パルス波形の周期・周波数・ON時間・デューティ比を相互に換算できる。
2. 波形率・波高率を定義から判定できる。
3. 基本波と高調波を分け、ひずみ波の有効電力を計算できる。
4. 理想ダイオードや理想スイッチのON/OFFを時間区間ごとに判定し、出力波形を追跡できる。
5. 直流から三相交流を合成するインバータの基本概念を説明できる。

### 7.2 半導体を理想スイッチとして考える

Topic 12で扱った半導体素子は、ここではまず理想的な二状態のスイッチとして考える。

- ON: 電流を通す。理想モデルではスイッチ両端の電圧降下を0とする。
- OFF: 電流を通さない。理想モデルでは開放回路として扱う。

実際の素子には電圧降下、漏れ電流、切替時間、損失があるが、それらの詳細比較は本Topicの範囲外である。電験三種「理論」の波形問題では、まず理想モデルで回路状態を区分できることが重要である。

トランジスタをスイッチとして使う場合も、制御信号によって導通状態と非導通状態を切り替え、負荷へ加える電圧や流す電流を断続するという見方をする。

### 7.3 直流をON/OFFするとパルス波形になる

直流電源電圧を `E` とし、理想スイッチで負荷への接続を周期的に切り替える。ON中は出力が `E`、OFF中は0になるなら、出力は0とEを往復するパルス波形になる。

```text
1周期 T = T_ON + T_OFF
周波数 f = 1 / T
デューティ比 D = T_ON / T
```

`D` は0〜1の無次元量であり、百分率なら `100D %` と表す。

0/Eの理想パルスについて、1周期平均値は

```text
V_av = D E
```

実効値は

```text
V_rms = E√D
```

となる。平均値と実効値を混同しない。抵抗負荷の発熱を求めるときは実効値が必要である。

### 7.4 矩形波・パルスの波形量

波形問題では、グラフの横軸と縦軸から次を先に読む。

- 最大値 `V_m`
- 周期 `T`
- 周波数 `f=1/T`
- ON時間 `T_ON`
- OFF時間 `T_OFF`
- デューティ比 `D`
- 実効値
- 平均値

交流波形の波形率では、平均値は通常、整流平均値、すなわち絶対値を1周期で平均した値を用いる。

```text
波形率 = 実効値 / 整流平均値
波高率 = 最大値 / 実効値
```

代表的な対称波形では次の値になる。

| 波形 | 波形率 | 波高率 |
|---|---:|---:|
| 方形波 | 1 | 1 |
| 正弦波 | π/(2√2) ≈ 1.11 | √2 ≈ 1.41 |
| 三角波 | 2/√3 ≈ 1.15 | √3 ≈ 1.73 |

大小関係を丸暗記するだけでなく、波高率は「最大値が実効値に対してどれだけ大きいか」を表す量だと理解する。

### 7.5 PWMの基本

PWMはPulse Width Modulation、パルス幅変調である。スイッチング周期の中でON時間を変え、出力パルスの幅を変化させる。

単純な0/Eパルスでは、デューティ比が変われば1周期平均値 `DE` が変わる。インバータでは、時間とともにパルス幅を変化させることで、パルス列の中に目的とする交流の基本波成分を作る。

ここで必要なのは「半導体素子が正弦波そのものを連続的に出力する」のではなく、「高速なON/OFFで非正弦のパルス波形を作り、その中の基本波成分を利用する」という考え方である。変調率、キャリア比、具体的なPWM方式は扱わない。

### 7.6 基本波と高調波

周期的な非正弦波は、基本周波数の成分と、その整数倍周波数の高調波成分を含むと考えられる。

基本周波数を `f` とすれば、

```text
基本波: f
第2高調波: 2f
第3高調波: 3f
...
```

となる。本Topicではフーリエ級数の一般導出は行わない。試験では、問題文で与えられた基本波・第3高調波などを次数ごとに分けて扱えることが重要である。

異なる周波数成分は1基本周期で平均すると交差項が0になるため、各高調波の実効値二乗を分けて扱える。例えば電流の直流成分がなく、基本波と第3高調波だけなら、全実効値は

```text
I = √(I_1² + I_3²)
```

で求められる。

### 7.7 ひずみ波の有効電力

電圧と電流が複数の高調波を含む場合、有効電力は同じ次数同士の成分から求める。直流成分がない場合、

```text
P = Σ V_n I_n cosφ_n
```

ここで、

- `V_n`: n次電圧成分の実効値
- `I_n`: n次電流成分の実効値
- `φ_n`: 同じn次成分どうしの位相差

である。

例えば基本波と第3高調波だけなら、

```text
P = V_1 I_1 cosφ_1 + V_3 I_3 cosφ_3
```

と分けて計算する。基本波電圧と第3高調波電流を掛けるなど、異なる次数を組み合わせない。

抵抗 `R` に高調波を含む電流が流れる場合は各成分が同相なので、

```text
P = RΣI_n²
```

と書ける。基本波と第3高調波だけなら `P=R(I_1²+I_3²)` である。

### 7.8 理想ダイオード回路の波形追跡

ダイオード波形問題は、波形を見た印象で選ばず、時間区間ごとにON/OFFを判定する。

1. ダイオードのアノードとカソードの電位を仮定する。
2. 順方向になる区間ならON、逆方向ならOFFと置く。
3. ONなら理想ダイオードを短絡、OFFなら開放に置き換える。
4. その等価回路から出力電圧を求める。
5. 求めた電圧が最初のON/OFF仮定と矛盾しないか確認する。
6. 入力波形の全区間について繰り返す。

直流基準電圧を持つクリッパ回路でも手順は同じである。「入力が基準電圧を上回った区間だけ導通する」など、導通条件を式で先に決めてから出力波形を描く。

### 7.9 三相インバータの基本

直流から三相交流を作るには、U相、V相、W相の三相分についてスイッチングを行う。各相の出力電圧はパルス状でも、その基本波成分を120°ずつ位相をずらせば三相交流の基本波を作れる。

```text
U相基本波: 0°
V相基本波: -120°
W相基本波: -240° (= +120°)
```

重要なのは、直流電源から直接「滑らかな三相正弦波」が出るのではない点である。半導体スイッチが作る段階的・パルス状の波形から、目的周波数の三相基本波成分を得る。

スイッチの具体的な駆動順序、デッドタイム、変調方式、素子損失は本Topicでは扱わない。

### 7.10 新幹線への接続

新幹線の主回路を概念化すると、架線から取り込んだ交流を車内で電力変換し、直流リンクを経てインバータで三相交流を作り、主電動機へ供給する流れになる。

```text
交流入力
↓
電力変換
↓
直流リンク
↓
インバータ
↓
三相交流
↓
主電動機
```

本Topicでは、この「直流から半導体スイッチングで三相交流を作る」という一般原理だけを新幹線へ接続する。300系等の内部回路、PWM方式、スイッチング周波数、保護回路を公開確認なしに断定しない。

### 7.11 増幅回路・オペアンプの基本

系列SPECには増幅回路とオペアンプの基本も含まれるため、固定4問の品質ゲートを広げず、電子回路の基礎として必要最小限を確認する。

増幅回路は入力信号の変化を、より大きな電圧・電流・電力の変化として出力する回路である。電圧増幅率は

```text
A_v = V_o / V_i
```

で表す。

理想オペアンプは基本問題では、入力電流を0、開ループ利得を十分大きいとみなし、負帰還が成立して線形動作しているとき `V_+ ≈ V_-` と扱う。ここでは反転・非反転増幅回路の設計や周波数特性へは広げない。

### 7.12 問題を見たときの解法手順

本Topicの問題は、最初に「時間領域のスイッチ問題」か「周波数成分の問題」かを分ける。

1. 波形問題なら、周期、最大値、ON/OFF区間、基準電圧を読む。
2. パルスなら `T=1/f`、`D=T_ON/T` を先に計算する。
3. ダイオード・スイッチ回路なら区間ごとにON/OFFを仮定し、短絡/開放へ置換する。
4. 波形率・波高率なら、実効値、整流平均値、最大値のどれを使うか整理する。
5. 高調波問題なら、基本波、第3高調波などを次数別に表へ分ける。
6. 有効電力は同じ次数の `V_n` と `I_n` を組み合わせる。
7. 抵抗負荷なら `P=RΣI_n²` を使えるか確認する。
8. 最後に単位、次数、位相差、平均値/実効値の取り違えがないか検算する。

### 7.13 頻出ミス

- `f=1/T` の単位換算でms、μsをsへ直し忘れる。
- デューティ比を `T/T_ON` と逆にする。
- 0/Eパルスの平均値 `DE` と実効値 `E√D` を混同する。
- 波形率の分母に符号付き1周期平均値を使い、対称交流で0としてしまう。
- 波高率と波形率を逆にする。
- 基本波電圧と第3高調波電流を掛ける。
- 抵抗の高調波電力で電流実効値を単純加算してから二乗する。
- ダイオード波形をON/OFF判定なしに図形だけで選ぶ。
- パルス波形そのものと基本波成分を同一視する。
- 詳細PWM方式、V/f制御、素子損失を本Topicの解答根拠へ持ち込む。

## 8. 3段階例題

### 8.1 基礎例題: パルスとデューティ比

直流電圧 `E=200 V` を理想スイッチで周期的にON/OFFする。スイッチング周波数は `2.0 kHz`、ON時間は `150 μs` で、ON中の出力は200 V、OFF中は0 Vである。周期、デューティ比、平均値、実効値を求めよ。

周期:

```text
T = 1/f
  = 1/2000
  = 5.0×10^-4 s
  = 500 μs
```

デューティ比:

```text
D = T_ON/T
  = 150/500
  = 0.30
```

平均値:

```text
V_av = DE
     = 0.30×200
     = 60 V
```

実効値:

```text
V_rms = E√D
      = 200√0.30
      ≈ 1.10×10^2 V
```

答え: `T=500 μs`、`D=0.30`、平均値`60 V`、実効値`約110 V`。

検算: 実効値は平均値より大きく最大値200 Vより小さいので、パルス波形として妥当である。

### 8.2 本試験標準例題: 基本波と第3高調波の電力

ある周期的な電圧・電流に基本波と第3高調波だけが含まれる。各成分の実効値と位相差が次のとおりである。

```text
基本波: V1=100 V, I1=5.0 A, cosφ1=0.80
第3高調波: V3=20 V, I3=2.0 A, cosφ3=0.50
```

全有効電力を求めよ。

同じ次数同士を組み合わせる。

```text
P1 = V1 I1 cosφ1
   = 100×5.0×0.80
   = 400 W

P3 = V3 I3 cosφ3
   = 20×2.0×0.50
   = 20 W

P = P1 + P3
  = 420 W
```

答え: `420 W`。

検算: `V1I3` や `V3I1` のような異なる次数の積を加えていないことを確認する。

### 8.3 複合・ひっかけ例題: バイアス付きクリッパの波形追跡

入力 `v_i` から1 kΩの抵抗を通って出力節点 `v_o` へ接続されている。出力節点には理想ダイオードが接続され、アノードを `v_o`、カソードを理想直流電源の `+3 V` 点へ接続する。負荷は十分高抵抗とする。入力は最大値5 Vの正弦波である。出力波形を求め、`v_i=-4 V, 2 V, 4 V` の各瞬間の `v_o` を答えよ。

ダイオードOFFを仮定すると負荷電流はほぼ0なので、抵抗の電圧降下も0となり `v_o=v_i` である。ただし `v_o` が3 Vを超えようとすると、アノードがカソードより高くなって理想ダイオードがONになる。

したがって、

```text
v_i ≤ 3 V: ダイオードOFF → v_o = v_i
v_i > 3 V: ダイオードON  → v_o = 3 V
```

よって、

```text
v_i=-4 V → v_o=-4 V
v_i= 2 V → v_o= 2 V
v_i= 4 V → v_o= 3 V
```

出力は正側だけ3 Vでクリップされ、最小値は入力と同じ-5 V、最大値は3 Vとなる。

検算: ON区間では `v_o=3 V` なのでダイオードが入力の3 V超過分を抑える向きになり、OFF区間では `v_o≤3 V` なので逆方向又は無バイアスとなる。仮定と矛盾しない。
