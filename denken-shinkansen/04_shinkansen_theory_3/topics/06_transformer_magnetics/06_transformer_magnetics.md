# 解説本文

## 1. このテーマで電験は何を問うか

変圧器の入口にある理論は、「電流が磁界を作る」「磁気回路に磁束が生じる」「磁束が時間変化すると起電力が生じる」という3段階である。電験三種では、実際の変圧器構造を暗記するより、磁気量の区別、磁気抵抗、自己・相互インダクタンス、磁気エネルギー、ファラデーの法則を式から扱えることが重要になる。

本Topicを終えた時点で、次をできる状態を目標とする。

1. `H`、`B`、`Φ`、`μ` を単位まで区別する。
2. `ℱ=NI`、`Rm=l/(μA)`、`Φ=ℱ/Rm` から磁気回路を計算する。
3. `Ψ=NΦ` と `L=Ψ/I` から自己インダクタンスを求める。
4. `W=LI²/2` から電流変化と磁気エネルギーの関係を判断する。
5. `M=k√(L1L2)` と `L=L1+L2±2M` を使う。
6. `e=-N dΦ/dt` の意味とレンツの法則を説明する。
7. 同じ時間変化磁束を鎖交する理想変圧器で `V1/V2=N1/N2` となる理由を説明する。

## 2. 磁界・磁束密度・磁束・透磁率

### 2.1 磁界 `H`

磁界の強さを `H` で表し、単位は `A/m` である。コイルに電流を流したとき、巻数と電流の積が磁界を作る側の量になる。

### 2.2 磁束密度 `B`

磁束密度 `B` は単位面積当たりの磁束を表し、単位は `T`（テスラ）である。

```text
1 T = 1 Wb/m²
```

線形媒質の基本関係は

```text
B = μH
```

である。`μ` は透磁率で、単位は `H/m` である。

### 2.3 磁束 `Φ`

磁束 `Φ` は面を貫く磁束の総量で、単位は `Wb`（ウェーバ）である。磁束密度が一様で、面に垂直に貫く基本条件では

```text
Φ = BA
```

となる。したがって `B` と `Φ` は同じ量ではない。`B` は面積当たり、`Φ` は面全体を通る総量である。

単位関係として

```text
1 Wb = 1 V·s
```

も重要である。`Wb/s` は `V` であり、`Wb` そのものとは異なる。

## 3. アンペアの法則と起磁力

アンペアの法則の基本形は

```text
∮ H·dl = NI
```

である。磁界がほぼ一様で磁路長を `l` と置ける単純な磁気回路なら

```text
Hl = NI
```

とできる。

ここで

```text
ℱ = NI
```

を起磁力と呼ぶ。`N` は巻数、`I` は電流である。本Topicでは力 `F` と区別するため起磁力を `ℱ` と表す。

起磁力を一定としたとき、磁路長 `l` が長くなるほど同じ磁路内の `H=NI/l` は小さくなる。逆に巻数または電流を増やすと起磁力は増える。

## 4. 磁気抵抗と磁気回路

磁気回路では、磁束の通りにくさを磁気抵抗 `Rm` で表す。

```text
Rm = l / (μA)
```

したがって磁気抵抗は

- 磁路長 `l` に比例
- 透磁率 `μ` に反比例
- 断面積 `A` に反比例

する。

電気回路の `I=V/R` に対応させると、磁気回路では

```text
Φ = ℱ / Rm
  = NI / Rm
```

となる。対応関係は次のように整理できる。

| 電気回路 | 磁気回路 |
|---|---|
| 電圧 `V` | 起磁力 `ℱ=NI` |
| 電流 `I` | 磁束 `Φ` |
| 抵抗 `R` | 磁気抵抗 `Rm` |
| `I=V/R` | `Φ=ℱ/Rm` |

この対応は計算手順を理解するための類比であり、電流と磁束が物理的に同じ量という意味ではない。

### 4.1 磁気回路の解法手順

1. `l`、`μ`、`A`、`N`、`I` をSI単位へそろえる。
2. `ℱ=NI` で起磁力を求める。
3. `Rm=l/(μA)` で磁気抵抗を求める。
4. `Φ=ℱ/Rm` で磁束を求める。
5. 必要なら `B=Φ/A`、`H=B/μ` を求める。
6. `Hl=NI` と整合するか検算する。

## 5. 電磁誘導・ファラデーの法則・レンツの法則

巻線を鎖交する磁束が時間変化すると、巻線には誘導起電力が生じる。基本式は

```text
e = -N dΦ/dt
```

である。有限時間の平均値として扱う問題では、磁束変化が一定とみなせる区間について

```text
|e| = N |ΔΦ| / Δt
```

を使える。

負号はレンツの法則を表す。誘導作用の向きは、原因となった磁束変化を妨げる向きになる。大きさを求める問題と向きを問う問題を分けて考えることが重要である。

たとえば `N=200`、1巻き当たりの磁束が `4.0 mWb` から `1.0 mWb` へ `0.020 s` で変化するなら、誘導起電力の大きさは

```text
|e| = 200 × |(1.0-4.0)×10^-3| / 0.020
    = 30 V
```

である。向きは磁束減少を妨げる向きに定まる。

## 6. 自己誘導・鎖交磁束・自己インダクタンス

巻数 `N` のコイルを1巻き当たり磁束 `Φ` が鎖交するとき、鎖交磁束 `Ψ` は

```text
Ψ = NΦ
```

である。線形範囲で自己インダクタンス `L` を

```text
L = Ψ / I
  = NΦ / I
```

と定義する。したがって

```text
Ψ = LI
```

でもある。

ここで最も多い取り違えは、`Φ` と `Ψ` を同じものとして扱うことである。`Φ` は1巻き当たりの磁束、`Ψ=NΦ` は巻数を含んだ鎖交磁束である。

自己誘導とは、自分自身の電流変化によって自分自身の鎖交磁束が変化し、自分自身の巻線に誘導起電力が生じる現象である。

一定 `L` の線形条件では、電流が `a` 倍なら

```text
Ψ = LI
```

より鎖交磁束も `a` 倍になる。

## 7. 相互誘導・相互インダクタンス・結合係数

二つのコイルが磁気的に結合していると、一方の電流変化が作る磁束の一部が他方のコイルを鎖交し、他方にも誘導起電力を生じる。これが相互誘導である。

相互インダクタンスを `M`、各コイルの自己インダクタンスを `L1`、`L2`、結合係数を `k` とすると

```text
M = k√(L1L2)
0 ≤ k ≤ 1
```

である。

二つの結合コイルを直列接続すると、相互磁束が自己磁束を強める加極性接続では

```text
Lseries = L1 + L2 + 2M
```

相互磁束が打ち消す減極性接続では

```text
Lseries = L1 + L2 - 2M
```

となる。`+2M` と `-2M` は暗記だけでなく、「相互磁束が加わるか、逆向きに作用するか」で判定する。

## 8. 磁気エネルギー

線形なインダクタに蓄えられる磁気エネルギーは

```text
W = 1/2 LI²
```

である。`L` が一定なら電流が `a` 倍になったとき

```text
W' / W = a²
```

となる。一方、鎖交磁束 `Ψ=LI` は `a` 倍である。

したがって「電流が2倍なら鎖交磁束は2倍、磁気エネルギーは4倍」という区別が必要になる。本試験ではこの比例関係だけでも選択肢を絞れる。

## 9. 0系主変圧器と電磁誘導の接続

0系の主変圧器をこのTopicで扱う目的は、実車内部の詳細を再現することではなく、変圧器が電磁誘導を利用する機器であることを具体化することである。

一次巻線に時間変化する電流が流れると磁束が生じ、その磁束が鉄心を通じて一次・二次巻線を鎖交する。時間変化する磁束により各巻線へ誘導起電力が生じる。理想化して一次・二次が同じ磁束変化を鎖交すると、ファラデーの法則から起電力は巻数に比例するため

```text
V1 / V2 = N1 / N2
```

となる。

たとえば教材用仮定として `N1/N2=25`、一次側電圧 `V1=25 kV` とすれば

```text
V2 = V1 × N2/N1
   = 25 kV / 25
   = 1.0 kV
```

となる。これは理想変圧器の巻数比確認用の仮定計算であり、0系主変圧器の実値ではない。

本Topicでは、損失、効率、電圧変動率、詳細等価回路、実車内部結線へは進まない。

## 10. 問題を見たときの解法アルゴリズム

### 10.1 磁気回路

1. 問題文から `l`、`A`、`μ`、`N`、`I` を抜き出す。
2. `mm`、`cm²`、`mWb` 等をSI単位へ直す。
3. 起磁力が必要なら `ℱ=NI`。
4. 磁気抵抗が必要なら `Rm=l/(μA)`。
5. 磁束は `Φ=ℱ/Rm`。
6. 磁束密度は `B=Φ/A`、必要なら `H=B/μ`。
7. 長さ・断面積・透磁率に対する比例関係を式で検算する。

### 10.2 自己インダクタンス

1. 1巻き当たり磁束 `Φ` か鎖交磁束 `Ψ` かを判定する。
2. `Ψ=NΦ`。
3. `L=Ψ/I=NΦ/I`。
4. 電流変化なら `Ψ=LI` と `W=LI²/2` を別々に評価する。

### 10.3 相互インダクタンス

1. `L1`、`L2`、`k` を確認する。
2. `M=k√(L1L2)`。
3. 接続が加極性か減極性かを判定する。
4. `L=L1+L2±2M`。
5. `0≤k≤1`、`M≤√(L1L2)` を検算に使う。

### 10.4 電磁誘導

1. 変化しているのが磁束 `Φ` か鎖交磁束 `Ψ` か確認する。
2. 1巻き当たり磁束なら `|e|=N|ΔΦ|/Δt`。
3. 単位を `Wb`、`s` にそろえる。
4. 向きを問われたらレンツの法則で判断する。

## 11. 単位と頻出ミス

| 量 | 記号 | SI単位 | 注意 |
|---|---|---|---|
| 磁界の強さ | `H` | `A/m` | インダクタンスの単位 henry の `H` と文脈で区別 |
| 磁束密度 | `B` | `T = Wb/m²` | 磁束 `Φ` そのものではない |
| 磁束 | `Φ` | `Wb = V·s` | `Wb/s = V` と混同しない |
| 透磁率 | `μ` | `H/m` | `B=μH` |
| 磁気抵抗 | `Rm` | `A/Wb` 相当 | `l` に比例、`μA` に反比例 |
| インダクタンス | `L`,`M` | `H` | `1 H = 1 Wb/A` とみなせる |
| 磁気エネルギー | `W` | `J` | `W=LI²/2` |

頻出ミスは次の通り。

- `Φ=BA` で面積を掛け忘れ、`B` と `Φ` を混同する。
- `mWb` を `Wb` に直さず計算する。
- `Rm=l/(μA)` で断面積が分母にあることを逆に覚える。
- `L=NΦ/I` の巻数 `N` を落とす。
- `Ψ=NΦ` と `Φ` を同一視する。
- 電流が2倍なら磁気エネルギーも2倍と誤る。正しくは4倍。
- `M=k√(L1L2)` の平方根を落とす。
- 加極性と減極性で `±2M` の符号を逆にする。
- ファラデーの法則の負号を起電力の大きさの負値と誤解する。負号は向きを表す。

## 12. 公式・解法まとめ

```text
B = μH
Φ = BA
∮H·dl = NI
ℱ = NI
Rm = l/(μA)
Φ = ℱ/Rm = NI/Rm
Ψ = NΦ
L = Ψ/I = NΦ/I
W = 1/2 LI²
M = k√(L1L2)
Lseries = L1 + L2 ± 2M
e = -N dΦ/dt
V1/V2 = N1/N2
```

# 3段階例題

## 例題1 基礎: 鎖交磁束から自己インダクタンスを求める

500巻のコイルに `0.40 A` を流したとき、1巻き当たりの磁束が `0.80 mWb` であった。線形範囲とする。自己インダクタンス `L` を求めよ。

### 解法

まず磁束をSI単位へ直す。

```text
Φ = 0.80 mWb
  = 0.80×10^-3 Wb
```

鎖交磁束は

```text
Ψ = NΦ
  = 500 × 0.80×10^-3
  = 0.40 Wb·turn
```

したがって

```text
L = Ψ/I
  = 0.40 / 0.40
  = 1.0 H
```

答え: `1.0 H`

検算: `L=NΦ/I` へ直接代入しても同じ値になる。1巻き当たり磁束 `Φ` をそのまま `L=Φ/I` に入れないことが要点である。

## 例題2 本試験標準: 電流変化と鎖交磁束・磁気エネルギー

自己インダクタンス `L=0.20 H` のコイルが線形範囲で動作している。電流を `2.0 A` から `5.0 A` へ変えた。変化前後の鎖交磁束 `Ψ` と磁気エネルギー `W` を求め、各量が何倍になったか答えよ。

### 解法

鎖交磁束は

```text
Ψ = LI
```

なので、変化前は

```text
Ψ1 = 0.20 × 2.0
   = 0.40 Wb·turn
```

変化後は

```text
Ψ2 = 0.20 × 5.0
   = 1.0 Wb·turn
```

したがって鎖交磁束は

```text
Ψ2/Ψ1 = 1.0/0.40 = 2.5
```

より `2.5倍`。

磁気エネルギーは

```text
W = 1/2 LI²
```

なので

```text
W1 = 1/2 × 0.20 × 2.0²
   = 0.40 J

W2 = 1/2 × 0.20 × 5.0²
   = 2.5 J
```

倍率は

```text
W2/W1 = 2.5/0.40 = 6.25
```

より `6.25倍`。

答え: `Ψ: 0.40 → 1.0 Wb·turn（2.5倍）`、`W: 0.40 → 2.5 J（6.25倍）`

検算: 電流比は `5/2=2.5`。一定 `L` なら `Ψ` は電流に比例し、`W` は電流の2乗に比例するので倍率はそれぞれ `2.5`、`2.5²=6.25` となる。

## 例題3 複合・ひっかけ: 磁気回路と結合コイル

### A. 磁気回路

一様な磁路について、磁路長 `l=0.50 m`、透磁率 `μ=2.0×10^-3 H/m`、断面積 `A=2.5×10^-4 m²`、巻数 `N=400`、電流 `I=0.25 A` とする。漏れ磁束や飽和を考えない。磁気抵抗 `Rm`、起磁力 `ℱ`、磁束 `Φ`、磁束密度 `B` を求めよ。

磁気抵抗は

```text
Rm = l/(μA)
   = 0.50 / {(2.0×10^-3)(2.5×10^-4)}
   = 1.0×10^6 A/Wb
```

起磁力は

```text
ℱ = NI
  = 400 × 0.25
  = 100 A·turn
```

磁束は

```text
Φ = ℱ/Rm
  = 100/(1.0×10^6)
  = 1.0×10^-4 Wb
```

磁束密度は

```text
B = Φ/A
  = (1.0×10^-4)/(2.5×10^-4)
  = 0.40 T
```

答え: `Rm=1.0×10^6 A/Wb`、`ℱ=100 A·turn`、`Φ=1.0×10^-4 Wb`、`B=0.40 T`

検算として `H=B/μ=0.40/(2.0×10^-3)=200 A/m`、`Hl=200×0.50=100 A·turn=NI` となる。

ひっかけは `Rm` が断面積に比例すると考えること、`A` の指数を落とすこと、`Φ` と `B` を同じ値として扱うことである。

### B. 結合コイル

二つのコイルの自己インダクタンスが `L1=0.40 H`、`L2=0.90 H`、結合係数が `k=0.50` である。相互インダクタンス `M` と、直列加極性・減極性それぞれの合成インダクタンスを求めよ。

まず

```text
M = k√(L1L2)
  = 0.50√(0.40×0.90)
  = 0.50√0.36
  = 0.30 H
```

加極性では

```text
Ladd = L1 + L2 + 2M
     = 0.40 + 0.90 + 0.60
     = 1.90 H
```

減極性では

```text
Lsub = L1 + L2 - 2M
     = 0.40 + 0.90 - 0.60
     = 0.70 H
```

答え: `M=0.30 H`、加極性 `1.90 H`、減極性 `0.70 H`

検算: `0≤k≤1` かつ `M=0.30 H≤√(L1L2)=0.60 H` を満たす。加極性は相互磁束が強め合うため、減極性より大きくなる。
