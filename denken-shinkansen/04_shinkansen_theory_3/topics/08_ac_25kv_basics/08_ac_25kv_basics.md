# Topic 08 新幹線の交流25kVとは何なのか

更新日: 2026-09-15
status: `source_progress_synced`

## 1. SPEC固定範囲

主題は、「交流25kV」は瞬間的に常に25kVではないことから、正弦波交流の基本量を理解すること。

扱う内容:
- 交流 / 直流
- 正弦波
- 瞬時値 / 最大値 / 実効値 / 平均値
- 周期 / 周波数 / 角周波数
- 位相 / 位相差
- ベクトル表示の基本

SPEC固定公式:

```text
v = Vm sinωt
ω = 2πf
T = 1/f
V = Vm / √2
I = Im / √2
```

新幹線との接続は、「新幹線の25kVは実効値として扱われる」ことと、波形図上で瞬時値・最大値・実効値を区別することに限定する。

## 6. 教材で必ず説明する事項

固定公式過去問と系列SPECから逆算し、本文では次を必須とする。

1. 直流と交流の違い。正弦波交流では大きさと極性が時間とともに周期的に変わること。
2. `v=Vm sin(ωt+φ)`の`v`、`Vm`、`ω`、`t`、`φ`の意味・単位と、SPECの`v=Vm sinωt`が`φ=0`の形であること。
3. `T=1/f`、`ω=2πf`、したがって`ωt=2πft`となること。Hz、s、rad/sを取り違えないこと。
4. 瞬時値、最大値、実効値を波形上で区別し、正弦波では`V=Vm/√2`、`I=Im/√2`となること。最大値と実効値を逆にしないこと。
5. 平均値は「どの区間・どの波形を平均するか」を明示すること。正弦波の1周期平均は0であり、交流で実用上比較する実効値とは意味が異なること。
6. 位相`φ`と位相差の意味。波形の横方向のずれをrad/°で読み、進み・遅れを判定すること。
7. 同一周波数の正弦波だけを対象に、ベクトル表示で大きさと位相を表し、ベクトル合成と三角関数による合成を相互確認できること。
8. グラフから最大値、周期または周波数、零交差、位相を読み、瞬時値式へ戻す手順。
9. `sinθ=a`で最初に指定瞬時値へ到達する時刻を求める際、周期内の複数解から「最初」を選ぶ手順。
10. 新幹線の「25kV」は実効値として扱い、正弦波なら最大値は`25√2 kV`となることを、実効値と瞬時値の区別の例として示す。

# 解説本文

## 8. このテーマで電験は何を問うか

このTopicの中心は、「交流の瞬間の値」と「交流を代表する値」を混同せず、正弦波を式・波形・位相の三つの表現で往復できるようにすることである。電験三種では、正弦波の式から時刻を求める問題、波形から最大値・周波数・位相を読み取る問題、同一周波数の正弦波を合成する問題が出る。

本Topicを終えた時点で、次をできる状態を目標とする。

1. `v=Vm sin(ωt+φ)`の各記号を説明し、時刻から瞬時値を求める。
2. `T=1/f`、`ω=2πf`を相互変換する。
3. 最大値と実効値を`√2`で変換する。
4. 正弦波の1周期平均が0で、実効値とは別の量であることを説明する。
5. 波形の横方向のずれから位相の進み・遅れを判定する。
6. 同一周波数の二つの正弦波をベクトルまたは三角関数で合成する。
7. 波形から最大値・周波数・位相を読み、瞬時値式へ戻す。
8. 指定された瞬時値へ「最初に」到達する時刻を、周期内の複数解から選ぶ。

## 9. 直流と交流、正弦波

直流は、時間が経過しても電圧や電流の極性が変わらない。値が一定の直流なら、例えば`100 V`はどの時刻でも100 Vである。

交流は、時間とともに大きさと極性が変化する。本Topicでは電験三種で基本となる正弦波交流だけを扱う。正弦波は同じ形を一定時間ごとに繰り返し、正側と負側が対称になる。

正弦波交流を考えるときは、少なくとも次の三つを分ける。

- 瞬時値: ある時刻で実際に式がとる値
- 最大値: 正弦波が到達する正側の最大の大きさ
- 実効値: 同じ抵抗で同じ発熱効果を与える直流値に対応する代表値

したがって「交流25kV」という表示を、すべての瞬間で25kVと読むのは誤りである。

## 10. 正弦波の瞬時値式

位相を含む一般形を

```text
v = Vm sin(ωt + φ)
```

と書く。

| 記号 | 意味 | 単位 |
|---|---|---|
| `v` | 時刻`t`での瞬時値 | V |
| `Vm` | 最大値 | V |
| `ω` | 角周波数 | rad/s |
| `t` | 時刻 | s |
| `φ` | 初期位相 | rad または ° |

系列SPECの

```text
v = Vm sinωt
```

は`φ=0`の場合である。

### 10.1 何を与えられ、何を求めるか

- `Vm`、`ω`、`φ`、`t`が与えられれば、式へ代入して瞬時値`v`を求める。
- 瞬時値`v`が指定され、到達時刻`t`を求める場合は、まず`sin(ωt+φ)=v/Vm`へ変形する。
- `ω`ではなく周波数`f`が与えられた場合は、先に`ω=2πf`へ変換する。
### 10.2 よくある取り違え

`Vm`は実効値ではなく最大値である。問題文が実効値`V`を与えた場合、瞬時値式へ入れる最大値は

```text
Vm = √2 V
```

に変換してから使う。

## 11. 周期・周波数・角周波数

周期`T`は波形が1回繰り返す時間、周波数`f`は1秒間に繰り返す回数である。

```text
T = 1/f
f = 1/T
```

`T`の単位はs、`f`の単位はHzである。

正弦波は1周期で角度が`2π rad`進むので、角周波数は

```text
ω = 2πf
```

となる。したがって

```text
ωt = 2πft
```

であり、時刻`t`を正弦波の角度へ変換できる。

### 11.1 解法上のチェック

- `f`がHzなら`ω`は`2πf rad/s`。
- `ω`がrad/sなら`f=ω/(2π)`。
- `T`と`f`は逆数。
- `ωt`は角度なので無次元として正弦関数の中に入る。

例えば`f=50 Hz`なら

```text
T = 1/50 = 0.020 s
ω = 2π×50 = 100π rad/s
```

となる。

## 12. 最大値・実効値・平均値

### 12.1 最大値と実効値

正弦波では

```text
V = Vm/√2
I = Im/√2
```

である。逆に

```text
Vm = √2 V
Im = √2 I
```

である。

実効値は、同じ抵抗に加えたときに同じ発熱効果を生む直流値に対応する。正弦波の値を二乗して1周期平均を取り、その平方根を考えると、`sin²`の1周期平均が`1/2`なので`Vm/√2`になる。

### 12.2 平均値は区間を確認する

正弦波`v=Vm sinωt`を1周期全体で平均すると、正側と負側が打ち消し合うため0になる。

```text
正弦波の1周期平均 = 0
```

この0は「交流の大きさが0」という意味ではない。実効値は二乗を使って発熱効果を表すため0にはならない。

「平均値」と問われたときは、必ずどの区間を平均するのかを確認する。本Topicでは非正弦波や整流波形の平均値へは広げない。

### 12.3 波形上での位置

正弦波では、縦軸上の最大値が`+Vm`、最小値が`-Vm`である。実効値`V=Vm/√2`は波形の代表値であり、正弦波が時間中ずっとその高さにあるという意味ではない。

## 13. 位相と位相差

正弦波

```text
v = Vm sin(ωt + φ)
```

の`φ`を位相と呼ぶ。同じ周波数の二つの正弦波で`φ`が異なると、波形は横方向へずれる。

基準波`sinωt`に対して

- `φ>0`: 同じ状態へ早く到達するので進み
- `φ<0`: 同じ状態へ遅く到達するので遅れ

と判断する。

位相差は二つの位相の差であり、radまたは°で表す。

```text
2π rad = 360°
π rad = 180°
π/2 rad = 90°
```

### 13.1 時間差と位相差

周期`T`のうち`Δt`だけ横へずれているなら、位相差の大きさは

```text
2π × Δt/T
```

として読める。これは`ω=2π/T`より`ωΔt`と同じである。

### 13.2 波形から位相を読む

波形から位相を読むときは、上向き零交差を基準にするとよい。`sinωt`は`ωt=0`で0を上向きに通過する。

例えば、ある波形の上向き零交差が基準より`π/4`だけ右へずれているなら、その波形は`π/4`遅れているため

```text
v = Vm sin(ωt - π/4)
```

となる。

### 13.3 純抵抗では電圧と電流は同相

抵抗`R>0`だけなら`i=v/R`である。正弦波電圧を正の定数`R`で割るだけなので、電圧と電流の零交差や位相は変わらず同相になる。固定過去問の波形読取では、この関係を使って電圧波形から電流の位相を決める。

## 14. 同一周波数正弦波のベクトル合成

同じ角周波数`ω`をもつ二つの正弦波

```text
v1 = A sin(ωt + φ1)
v2 = B sin(ωt + φ2)
```

は、大きさと位相をもつ二つのベクトルとして表せる。ここでは最大値で表すなら両方とも最大値、実効値で表すなら両方とも実効値に統一する。

ベクトルを横・縦成分に分けると

```text
x = A cosφ1 + B cosφ2
y = A sinφ1 + B sinφ2
```

合成波の大きさ`C`と位相`φ`は

```text
C = √(x² + y²)
cosφ = x/C
sinφ = y/C
```

で決められる。

### 14.1 90°差の合成は三角関数でも確認できる

`x=ωt`とおき、

```text
v = A sinx + B sin(x + π/2)
```

なら`sin(x+π/2)=cosx`なので

```text
v = A sinx + B cosx
```

となる。これを

```text
v = C sin(x + φ)
  = C cosφ sinx + C sinφ cosx
```

と係数比較すると

```text
C cosφ = A
C sinφ = B
```

が得られ、ベクトル合成と同じ結果になる。

### 14.2 適用条件

本Topicでの一定ベクトルによる合成は、同一周波数の正弦波に限定する。周波数が異なる波形を、固定した一つの位相差だけで同じように処理しない。

## 15. 指定瞬時値に最初に到達する時刻

`sinθ=a`には1周期内で複数の解があり得る。したがって「最初に」「初めて」と指定された問題では、逆三角関数で一つの角度を得ただけで終わらない。

基本手順は次のとおり。

1. 瞬時値式を`sin(ωt+φ)=a`の形へする。
2. `|a|≤1`を確認する。
3. 1周期内の候補角を求める。
4. 各候補から`t`を求める。
5. 条件を満たす正の時刻のうち最小を選ぶ。

`φ=0`かつ`0<a<1`で、`t>0`の最初の到達時刻なら、第一象限の角度が最初の候補になる。

### 15.1 周期性による検算

得られた時刻`t`が`0<t<T`に入っているかを確認すると、最初の到達時刻を選べているか検算しやすい。式へ代入して指定瞬時値に戻ることも必ず確認する。

## 16. 波形から瞬時値式を作る手順

グラフを見て式を選ぶ問題では、次の順で読む。

1. 縦軸から最大値`Vm`または`Im`を読む。
2. 横軸から周期`T`を読み、`f=1/T`を求める。
3. `ω=2πf`を求める。
4. 上向き零交差または最大点の位置から位相`φ`を読む。
5. `v=Vm sin(ωt+φ)`または`i=Im sin(ωt+φ)`へ入れる。
6. 問題が実効値を与えているなら、最大値へ`√2`変換したか確認する。
7. 純抵抗の電圧・電流なら同相であることを確認する。

最大点だけを見るより、上向き零交差も併用すると位相の符号を誤りにくい。

## 17. 新幹線の「25kV」をどう読むか

本Topicでは、新幹線の「25kV」は交流電圧の実効値として扱う。正弦波で実効値が25kVなら、最大値は

```text
Vm = √2 V
   = 25√2 kV
   ≒ 35.4 kV
```

である。

したがって瞬時値は0、正側最大、0、負側最大というように時間とともに変化し、常に25kVではない。一方、設備の交流電圧を代表する値としては実効値25kVを用いる。

ここでは実効値と瞬時値の区別だけを新幹線へ接続し、周波数切替、RLC、力率、三相交流、電力変換には進まない。

## 18. 頻出ミス・ひっかけ

- 実効値`V`をそのまま`Vm`として瞬時値式へ入れる。
- `Vm=V/√2`と逆に覚える。正しくは`Vm=√2V`。
- `f`と`ω`を混同し、`ω=f`としてしまう。
- `T=f`としてしまう。正しくは`T=1/f`。
- 位相が正なら進み、負なら遅れという符号を逆にする。
- `sinθ=a`の解を一つだけ出し、「最初」の条件を確認しない。
- ベクトル合成で一方だけ最大値、他方だけ実効値を使う。
- 波形の最大値と実効値をグラフ上の同じ高さだと考える。
- 正弦波の1周期平均0を、実効値0と誤解する。

## 19. 3段階例題

### 例題1 基礎: 周波数・周期・実効値を読む

次の正弦波電圧を考える。

```text
v = 100√2 sin(100πt) V
```

最大値、実効値、角周波数、周波数、周期を求める。

#### 解答

式`v=Vm sinωt`と比較する。

```text
Vm = 100√2 V
ω = 100π rad/s
```

実効値は

```text
V = Vm/√2
  = 100 V
```

周波数は

```text
f = ω/(2π)
  = 100π/(2π)
  = 50 Hz
```

周期は

```text
T = 1/f
  = 1/50
  = 0.020 s
```

答え:

```text
最大値 100√2 V
実効値 100 V
角周波数 100π rad/s
周波数 50 Hz
周期 0.020 s
```

この問題では、瞬時値式の先頭係数は実効値ではなく最大値であることが第一の確認点である。

### 例題2 本試験標準: 指定値へ最初に到達する時刻

正弦波電流

```text
i = 6√2 sin(100πt) A
```

が`t>0`で最初に`6 A`になる時刻を求める。

#### 解答

指定値を瞬時値式へ入れる。

```text
6 = 6√2 sin(100πt)
```

したがって

```text
sin(100πt) = 1/√2
```

1周期内では複数解があるが、`t>0`で最初は

```text
100πt = π/4
```

である。よって

```text
t = (π/4)/(100π)
  = 1/400 s
  = 2.5 ms
```

検算として`f=50 Hz`なので`T=20 ms`。`2.5 ms`は1周期の`1/8`であり、その角度は`2π×1/8=π/4`となる。

答え: `2.5 ms`

### 例題3 複合: 位相の異なる二つの正弦波を合成する

同一周波数の二つの電圧

```text
v1 = 100 sinωt V
v2 = 100 sin(ωt + π/2) V
```

を加えた合成電圧について、最大値、基準`sinωt`に対する位相、実効値を求める。

#### 解答

`x=ωt`とおくと

```text
v = 100 sinx + 100 sin(x+π/2)
  = 100 sinx + 100 cosx
```

これを

```text
v = C sin(x+φ)
  = C cosφ sinx + C sinφ cosx
```

と比較する。

```text
C cosφ = 100
C sinφ = 100
```

よって

```text
C = √(100²+100²)
  = 100√2 V
```

また

```text
cosφ = sinφ = 1/√2
```

なので

```text
φ = π/4
```

であり、基準波より`π/4`進む。

合成波は

```text
v = 100√2 sin(ωt+π/4) V
```

最大値が`100√2 V`なので、実効値は

```text
V = 100√2/√2
  = 100 V
```

答え:

```text
最大値 100√2 V
位相 π/4 rad 進み
実効値 100 V
```

この例題では、二つの波形が同一周波数であることと、両方を同じ種類の大きさ（ここでは最大値）で合成していることが成立条件である。

## 20. 本試験での解法手順

### 20.1 瞬時値・時刻問題

```text
1. 最大値か実効値かを確認する
2. 必要なら Vm=√2V、Im=√2I へ変換する
3. f、T、ωのうち不足する量を T=1/f、ω=2πf で求める
4. 瞬時値式へ条件を入れる
5. sinθ=a を解く
6. 周期内の候補を確認する
7. 「最初」「正の時刻」等の条件に合う解を選ぶ
8. 元の式へ代入して検算する
```

### 20.2 波形読取問題

```text
1. 縦軸から最大値を読む
2. 横軸から周期を読む
3. f=1/T、ω=2πf を求める
4. 上向き零交差から位相の符号と大きさを読む
5. 瞬時値式を作る
6. 純抵抗なら電圧と電流は同相であることを使う
```

### 20.3 同一周波数正弦波の合成問題

```text
1. 二つの周波数が同じことを確認する
2. 最大値同士または実効値同士へ種類をそろえる
3. 位相差を読む
4. ベクトル成分または三角関数で合成する
5. 合成後の大きさと位相を確認する
6. 必要なら最大値と実効値を√2で変換する
```

## 21. 公式・解法まとめ

```text
正弦波瞬時値       v = Vm sin(ωt+φ)
周期と周波数       T = 1/f
角周波数           ω = 2πf
角度               ωt = 2πft
電圧実効値         V = Vm/√2
電流実効値         I = Im/√2
最大値への逆変換   Vm = √2V, Im = √2I
正弦波1周期平均    0
```

判定の要点:

- `φ>0`は進み、`φ<0`は遅れ。
- 純抵抗の電圧と電流は同相。
- 「最初の時刻」は周期内の複数解を比較する。
- 同一周波数正弦波の合成では大きさの種類をそろえる。
- 新幹線の25kVは実効値として扱い、正弦波なら最大値は`25√2 kV ≒ 35.4 kV`。
