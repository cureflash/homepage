# 過去問から逆算した必須説明

1. スカラーは大きさだけ、ベクトルは大きさと向きをもつ量であることを、電位・電流値などのスカラーと、電界・磁界・力などの空間ベクトルを対比して示す。
2. 2次元・3次元のベクトルを `(ax, ay)`、`(ax, ay, az)` または `ax ex + ay ey + az ez` と成分表示し、`ex, ey, ez` を単位ベクトルとして導入する。
3. 和・差は同じ軸の成分どうしで行い、反対向きの力・場を単なる大きさの足し算にしない。R8上問4、R7下問2、R6下問4へ直接接続する。
4. 大きさは `|a|=√(ax²+ay²+az²)` とし、2次元の合力を三平方・三角比・成分法の両方で処理できるようにする。
5. ベクトルを軸方向へ分解し、角度 `θ` に対する平行成分・垂直成分を `cosθ` / `sinθ` で求める。角度の基準軸を必ず確認する手順を示す。
6. 等大2ベクトルの合成と対称性を扱い、R4下問4の `60°` 合力を `x/y` 成分または余弦から再現できるようにする。
7. 内積 `a·b=|a||b|cosθ` は「一方のベクトル方向への成分・射影」を表す基本として扱う。三種の本テーマでは高度な線形代数へ進まない。
8. 外積 `a×b` は、結果が両ベクトルに垂直な空間ベクトルであり、大きさが `|a||b|sinθ`、向きが右手系で決まることを扱う。R7上問11・R4上問4へ接続する。
9. `F=q(v×B)`、`F=I(l×B)` を外積の適用例として示し、正負電荷では `q` の符号まで含めて向きを判定する。ホール素子や電磁力の装置詳細は本テーマの主題にしない。
10. 図に `+x/-x/+y/-y/+z/-z` を明示してから向きを判定する解法手順を示し、右手系・正負符号・視点の取り違えを頻出ミスとして扱う。
11. フェーザは同一周波数の正弦波を複素平面上の大きさ・位相として表した計算表現、空間ベクトルは物理空間の方向を表す量であることを区別する。Topic 04のフェーザを復習材料として使うが、両者を同一の「向き」として扱わない。
12. 新幹線との接続は自然な範囲に限定し、電界・磁界・力の向きを空間ベクトルで読む例を使う。確認できない実車の電界・磁界・力の数値は追加しない。

# 解説本文

## 1. このテーマで電験は何を問うか

電験三種の理論では、電界・磁界・力・速度などを「大きさだけ」で扱うと誤る問題がある。特に、複数の場や力を合成する問題、`xyz` 座標で方向を選ぶ問題、磁界に対して斜めに動く導体・電荷の問題では、向きを含めて処理する必要がある。

本テーマでは、次の順に判断できることを目標とする。

1. 量がスカラーかベクトルかを判断する。
2. ベクトルなら座標軸と正方向を決める。
3. 成分に分け、同じ軸の成分どうしを加減する。
4. 必要なら `sinθ` / `cosθ` で平行・垂直成分を取り出す。
5. 内積は射影、外積は垂直方向と `sinθ` を扱う計算として使う。
6. 最後に大きさと向きの両方を検算する。

## 2. スカラーとベクトル

スカラーは大きさだけで表せる量、ベクトルは大きさと向きをもつ量である。

| 種類 | 例 | 表し方 |
|---|---|---|
| スカラー | 電位、抵抗値、電流の大きさ、エネルギー | 数値と単位 |
| 空間ベクトル | 電界、磁界、力、速度 | 大きさ・単位・空間方向 |

例えば「5 N」とだけ書けば力の大きさしか分からない。`+x` 方向へ5 Nなら、向きまで含めて初めて空間ベクトルが確定する。

過去問では、まず各力・磁界がどちら向きかを決めてから合成する。大きさだけを先に足すと、R7下 理論 問2のような反対向きの力を誤る。

## 3. 成分表示・単位ベクトル・大きさ

3次元ベクトル `a` を

`a = ax ex + ay ey + az ez`

と表す。`ex, ey, ez` は、それぞれ `+x, +y, +z` 方向を向く大きさ1の単位ベクトルである。

成分だけで書けば

`a = (ax, ay, az)`

である。大きさは

`|a| = √(ax² + ay² + az²)`

となる。2次元なら `az=0` と考えればよい。

例として `a=(3,4,0)` なら

`|a| = √(3²+4²)=5`

である。

## 4. 和・差は同じ軸の成分どうしで行う

`a=(ax,ay,az)`、`b=(bx,by,bz)` のとき、

`a+b=(ax+bx, ay+by, az+bz)`

`a-b=(ax-bx, ay-by, az-bz)`

である。

一直線上だけなら、正方向を一つ決めて符号付きの1成分として扱えばよい。例えば右向きを正として、右向き5 Nと左向き2 Nの合力は

`5 + (-2) = 3 N`

だから右向き3 Nである。

R8上 理論 問4では2つの磁界が同じ向きなので加算、R7下 理論 問2では2つの力が反対向きなので差を取る。計算前に矢印の向きを確定することが重要である。

## 5. 成分分解と `sin` / `cos`

大きさ `A` のベクトルが `+x` 軸となす角を `θ` とすると、

`Ax = A cosθ`

`Ay = A sinθ`

である。

ただし、問題文の角度がどの軸から測られているかを必ず確認する。`sin` と `cos` を暗記で割り当てず、「角度に隣り合う成分が `cos`、向かい側の成分が `sin`」と判断する。

磁界 `B` に対して速度 `v` が角度 `θ` をもつとき、磁界に垂直な速度成分は

`v⊥ = v sinθ`

である。R4上 理論 問4では、この垂直成分だけが誘導起電力の大きさに効く。

## 6. 等大2ベクトルと対称性

大きさがともに `F`、なす角が `60°` の2ベクトルを考える。2本の中間方向を `x` 軸とすると、それぞれは `x` 軸に対して `±30°` である。

各ベクトルの `x` 成分は `F cos30°`、`y` 成分は `+F sin30°` と `-F sin30°` なので、`y` 成分は相殺する。

したがって合力は

`F0 = 2F cos30° = √3 F`

となる。R4下 理論 問4は、この対称性を使えば方向と大きさを同時に整理できる。

## 7. 内積は「その方向にどれだけ向いているか」

内積は

`a·b = |a||b|cosθ`

である。結果はベクトルではなくスカラーになる。

単位ベクトル `e` に対して `a·e` を計算すると、`a` の `e` 方向成分を取り出せる。つまり内積は、一方の方向への射影を数値として求める計算だと考えるとよい。

本テーマでは、内積はこの基本的な意味と成分抽出までに限定する。

## 8. 外積は「2本に垂直な向き」と `sinθ`

外積 `a×b` はベクトルであり、大きさは

`|a×b| = |a||b|sinθ`

となる。向きは `a` から `b` へ指を曲げる右手系で決める。

直交座標の基本関係は

`ex×ey=ez`

`ey×ez=ex`

`ez×ex=ey`

である。順番を逆にすると符号が反転する。例えば

`ex×ez = -ey`

である。

磁界中の電荷に働く力

`F = q(v×B)`

では、まず `v×B` の向きを求める。その後、`q<0` なら最終的な力の向きを反転する。

導体に働く力をベクトルとして読む場合も

`F = I(l×B)`

の形で、電流方向を表す `l` と磁界 `B` の順に外積を考える。

## 9. `xyz` 方向問題の解法手順

方向問題では、頭の中だけで向きを回転させない。次の順に処理する。

1. 図へ `+x/-x/+y/-y/+z/-z` を書く。
2. 与えられた電流、速度、磁界を単位ベクトルで置く。
3. 反対向きなら係数を負にする。
4. 外積なら順序を固定して右手系を使う。
5. 電荷が負なら最後に反転する。
6. 作用反作用や対称性と矛盾しないか確認する。

R6下 理論 問4では、同方向電流の平行導体は互いに引き合うので、AとBに働く力は互いに反対向きになる。座標軸を先に固定すれば、`+x` / `-x` の選択を取り違えにくい。

## 10. フェーザと空間ベクトルは別物

Topic 04のフェーザも矢印で描けるが、空間ベクトルとは意味が異なる。

- フェーザ: 同一周波数の正弦波を、複素平面上で大きさと位相として表す計算表現
- 空間ベクトル: 実際の物理空間での大きさと方向を表す量

フェーザの `30°` は時間波形の位相差を表し、空間ベクトルの `30°` は空間内での方向差を表す。どちらも矢印で表せるからといって、同じ「向き」として扱わない。

## 11. 電界・磁界・力への適用と新幹線への接続

本テーマでは、新幹線固有の未確認実値は使わない。車両・架線・主回路の周辺でも、電界、磁界、電磁力は空間方向をもつため、向きの判断にベクトルが必要になる、という接続だけを行う。

重要なのは車両固有値を覚えることではなく、電験問題で与えられた方向・角度・座標軸から、一般的なベクトル計算を再現できることである。

## 12. 本試験での解法アルゴリズム

1. 求める量がスカラーかベクトルかを判断する。
2. 座標軸と正方向を明示する。
3. 各ベクトルの向きを先に決める。
4. 必要なら `sin` / `cos` で成分分解する。
5. 同じ軸の成分どうしを加減する。
6. 必要なら `√(x²+y²+z²)` で合成後の大きさを求める。
7. 内積なら `cosθ`、外積なら `sinθ` と右手系を使う。
8. 正負電荷では符号を最後まで保持する。
9. 単位と向きを選択肢に照合する。

## 13. 頻出ミス

- 反対向きの2力を大きさだけで足す。
- `sin` / `cos` を角度の基準軸を見ずに選ぶ。
- 外積の順序を逆にする。
- `q<0` のときに力の向きを反転し忘れる。
- `+x` と `-x` を図へ書かず、視点だけで判断する。
- フェーザの位相角を物理空間の方向角と混同する。

# 3段階例題

## 例題1 基礎: 成分と大きさ

ベクトル `a=(6,8,0)` の大きさを求めよ。また、`+x` 方向の単位ベクトルを `ex` とするとき、`a` の `x` 成分を答えよ。

### 解答

大きさは

`|a| = √(6²+8²+0²) = √100 = 10`

である。

`x` 成分は6なので、`+x` 方向成分は `6ex` である。

検算として、6-8-10は三平方の関係を満たす。

## 例題2 本試験標準: 等大2力の合成

一点に、大きさ8 Nの2力が働いている。2力のなす角は60°で、配置は角の二等分線に対して対称である。合力の大きさと向きを求めよ。

### 解答

角の二等分線を `+x` 方向とすると、各力は `+x` 軸に対して `+30°` と `-30°` である。

各力の `x` 成分は

`8 cos30° = 4√3 N`

で、2本分を加えると

`Fx = 8√3 N ≈ 13.9 N`

となる。

`y` 成分は

`+8 sin30° = +4 N`

`-8 sin30° = -4 N`

で相殺する。

したがって、合力は角の二等分線方向に

`8√3 N ≈ 13.9 N`

である。

この解法はR4下 理論 問4の等大2ベクトル・60°合成へそのまま接続できる。

## 例題3 複合・ひっかけ: 外積と負電荷

負電荷 `q=-3.2×10^-19 C` が、`+x` 方向へ `v=2.0×10^5 m/s` で運動している。磁束密度 `B=0.50 T` は `+z` 方向である。磁気力の大きさと向きを求めよ。

### 解答

速度と磁界は直交するため、外積の大きさは

`|v×B| = vB sin90° = vB`

である。したがって力の大きさは

`|F| = |q|vB`

`= 3.2×10^-19 × 2.0×10^5 × 0.50`

`= 3.2×10^-14 N`

となる。

次に向きを決める。まず

`ex×ez = -ey`

なので、`v×B` は `-y` 方向である。しかし `q<0` だから

`F=q(v×B)`

では向きが反転し、最終的な力は `+y` 方向となる。

ひっかけは、右手系で `v×B` を求めた時点で答えにせず、負電荷の符号を最後に反映することである。
