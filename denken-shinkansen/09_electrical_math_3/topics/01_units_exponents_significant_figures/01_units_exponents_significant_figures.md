# 解説本文

## 1. このテーマで電験は何を問うか

電験三種では、単位・指数・有効数字だけを独立して問う問題もあるが、多くは理論・電力・機械の計算問題の途中で使う。公式を知っていても、`mH→H`、`mA→A`、`ms→s`、`m/min→m/s`、`W→kW` の換算を誤ると桁が `10^3` や `10^6` ずれる。

本テーマでは次の状態を目標とする。

- SI接頭語を10のべきへ直せる。
- 複数の単位を含む式で、単位全体をそろえられる。
- 計算結果の単位を式から検算できる。
- 有効数字の加減算と乗除算のルールを区別できる。
- 絶対誤差と百分率誤差を計算できる。
- 効率を百分率から小数へ直し、入力・出力の関係を正しく選べる。

選定した過去問では、R8上理論問3の `mH`、R5上理論問10の `mA` と `ms`、R4上機械問11の `m/min` と `kW`、H29理論問14の有効数字と単位、H28理論問16の誤差計算が直接この技能を要求する。

## 2. 必要な基礎概念

### 2.1 10の整数乗と科学表記

10のべきは桁を表す。

- `10^3 = 1000`
- `10^0 = 1`
- `10^-3 = 0.001`
- `10^-6 = 0.000001`

科学表記では、通常 `1≤|a|<10` となるように `a×10^n` と書く。

例:

- `25000 V = 2.5×10^4 V`
- `0.001 H = 1×10^-3 H`
- `0.0005 A = 5×10^-4 A`

10のべき同士は、掛け算では指数を足し、割り算では指数を引く。

`10^a × 10^b = 10^(a+b)`

`10^a / 10^b = 10^(a-b)`

したがって、`(5×10^-4 A)/(2×10^-3 s)=2.5×10^-1 A/s=0.25 A/s` となる。

### 2.2 SI接頭語

| 接頭語 | 記号 | 倍率 |
|---|---:|---:|
| giga | `G` | `10^9` |
| mega | `M` | `10^6` |
| kilo | `k` | `10^3` |
| milli | `m` | `10^-3` |
| micro | `μ` | `10^-6` |
| nano | `n` | `10^-9` |

大文字・小文字を区別する。`M` は mega、`m` は milli であり、倍率は `10^9` 倍違う。`k` は小文字で書く。

例:

- `25 kV = 25×10^3 V = 2.5×10^4 V`
- `1 mH = 1×10^-3 H`
- `500 μA = 500×10^-6 A = 5×10^-4 A`
- `2 MW = 2×10^6 W`

### 2.3 単位換算は「単位全体」を変換する

単位換算では数値だけを見ず、式の分子・分母を含めて変換する。

`0.5 mA / 2 ms`

を扱うなら、

`0.5 mA = 0.5×10^-3 A`

`2 ms = 2×10^-3 s`

なので、

`(0.5×10^-3)/(2×10^-3) A/s = 0.25 A/s`

となる。分子と分母の `10^-3` が相殺されるため、`1 mA/ms = 1 A/s` である。

長さの2乗・3乗では接頭語も2乗・3乗される。

- `1 cm^2 = (10^-2 m)^2 = 10^-4 m^2`
- `1 mm^3 = (10^-3 m)^3 = 10^-9 m^3`

速度 `100 m/min` は、`1 min=60 s` より、

`100/60 m/s = 5/3 m/s`

である。

### 2.4 電験で使う主な単位

| 物理量 | 単位 | 関係 |
|---|---|---|
| 電圧 | `V` | - |
| 電流 | `A` | - |
| 電力 | `W` | `W=V·A=J/s` |
| 電力量・エネルギー | `Wh`, `J` | `1 Wh=3600 J` |
| 電荷 | `C` | `C=A·s` |
| 抵抗 | `Ω` | `Ω=V/A` |
| インダクタンス | `H` | `H=V·s/A` |
| 磁束 | `Wb` | `Wb=V·s` |
| 静電容量 | `F` | `F=C/V` |

`W` と `Wh` は別の量である。`W` はその瞬間の電力、`Wh` は電力を時間にわたって積み上げた電力量を表す。

`1 kWh = 1000 W × 3600 s = 3.6×10^6 J = 3.6 MJ`

### 2.5 有効数字

有効数字は、測定値や与えられた値がどの桁まで意味を持つかを表す。

例:

- `1.600` は有効数字4桁。
- `50.00` は有効数字4桁。
- `0.040` は先頭の0を数えず、有効数字2桁。
- `2.50×10^3` は有効数字3桁。

換算係数 `1000 m=1 km`、`60 s=1 min` や、式に現れる厳密な整数係数 `1/2` は、通常、有効数字を制限する測定値として扱わない。

電験の選択問題で有効数字の指定がない場合、見た目の桁数だけを理由に途中値を過度に丸めない。十分な桁を保持して計算し、選択肢または問題の指定に合わせて最後に丸める。

### 2.6 絶対誤差と百分率誤差

測定値を `xm`、真値を `x` とすると、絶対誤差は

`|xm-x|`

百分率誤差は

`|xm-x|/|x| × 100 [%]`

である。

誤差を求める途中で測定値を早く丸めると、最後の百分率誤差が変わることがある。原則として途中値は必要な桁を保持する。

## 3. 公式と成立条件

### 3.1 単位の関係

次の関係は、計算結果の単位を確認するために使える。

`C=A·s`

`Ω=V/A`

`W=V·A=J/s`

`J=W·s`

`H=V·s/A`

`Wb=V·s`

`F=C/V`

例えば `L di/dt` の単位は、

`H × A/s = (V·s/A)×A/s = V`

となる。計算結果が電圧を求める問題なのに `A` や `J` になれば、式か換算に誤りがある。

選定過去問で使う代表式も、ここでは単位確認の文脈で整理する。

- 磁束鎖交数: `Ψ=LI`
- インダクタの磁気エネルギー: `W=(1/2)LI^2`
- インダクタ電圧: `v=L di/dt`
- 機械出力: `P=Fv`
- 効率: `η=Pout/Pin`

これらの物理理論自体を本テーマの主題にはしないが、式へ代入する前に単位をそろえ、結果の単位を検算する。

### 3.2 有効数字の計算規則

加減算では、有効数字の「個数」ではなく最も粗い桁位置に合わせる。

例:

`12.3 + 0.45 = 12.75 → 12.8`

`12.3` が小数第1位までなので、結果も小数第1位までとする。

乗除算では、有効数字の最も少ない値に桁数を合わせる。

例:

`2.4×0.50 = 1.20 → 1.2`

どちらかが有効数字2桁なので、結果も2桁とする。

複数段階の計算では各段階で丸め切らず、少なくとも余分な桁を保持し、最後に丸める。

### 3.3 百分率と効率

百分率は式へ代入するとき小数へ直す。

`75%=0.75`

効率は

`η=Pout/Pin`

なので、

`Pout=η Pin`

`Pin=Pout/η`

である。出力を入力で割るのか、入力を出力で割るのかを問題文から先に判定する。

## 4. 問題を見たときの解法手順

単位換算を含む計算問題は次の順で処理する。

1. 与えられた量と求める量を列挙する。
2. `m`, `μ`, `k`, `M` 等の接頭語を確認する。
3. 公式へ代入する前に、必要な量を同じ基準単位へそろえる。
4. 求める量に対応する式を選ぶ。
5. 数値と単位を一緒に代入する。
6. 単位演算を行い、求める量の単位になるか確認する。
7. 中間値を必要以上に丸めず計算する。
8. 最後に問題の指定または選択肢に合わせて有効数字を処理する。
9. `10^3`、`10^-3` の取り違えがないか、結果の桁を概算で確認する。

特に、`mA/ms` のように分子と分母の双方へ接頭語が付く場合は、各量を別々にSI単位へ直してから割ると安全である。

## 5. 典型例題

### 例題1 基礎: 接頭語と複合単位

電流が `0.50 mA` だけ `2.0 ms` の間に変化した。電流変化率の大きさを `A/s` で求める。

まず単位をそろえる。

`0.50 mA = 0.50×10^-3 A`

`2.0 ms = 2.0×10^-3 s`

したがって、

`|Δi/Δt|=(0.50×10^-3)/(2.0×10^-3)=0.25 A/s`

分子と分母の milli が相殺される。`0.25 mA/s` ではない。

### 例題2 本試験標準: 速度・効率・kW

負荷側とつり合いおもり側の質量差が `900 kg`、上昇速度が `100 m/min`、効率が `75%` の装置について、必要な入力電力を求める。重力加速度を `9.8 m/s^2` とする。

速度を換算する。

`100 m/min = 100/60 = 5/3 m/s`

機械出力は、

`Pout=Fv=mgv`

`=900×9.8×5/3`

`=14700 W=14.7 kW`

効率 `η=0.75` より、入力は

`Pin=Pout/η`

`=14.7/0.75`

`=19.6 kW`

ここでは `100 m/min→m/s`、`75%→0.75`、`W→kW` の三つを連続して処理している。

### 例題3 複合・ひっかけ: 有効数字と誤差

電圧 `50.00 V`、電流 `1.600 A` から抵抗を測定した。抵抗の真値を `31.21 Ω` とする。測定値、絶対誤差、百分率誤差を求める。

測定値は、

`Rm=50.00/1.600=31.25 Ω`

である。両方とも有効数字4桁なので、`31.25 Ω` も4桁で表せる。

絶対誤差は、

`|31.25-31.21|=0.04 Ω`

百分率誤差は、

`0.04/31.21×100=0.128...%`

したがって、指定精度に応じて `0.13%` とする。

`31.25 Ω` を途中で `31.3 Ω` などに丸めると誤差が変わるため、中間値を保持する。

## 6. 新幹線への接続

本系列SPECで指定されている `25 kV`、`MW`、`kWh` を単位・指数の例として使う。

`25 kV = 25×10^3 V = 2.5×10^4 V`

`1 MW = 10^6 W = 1000 kW`

`1 MWh = 10^6 Wh = 1000 kWh`

`kW` と `MW` は電力、`kWh` と `MWh` は電力量である。接頭語を変更しても物理量そのものは変わらず、数値と単位表記が変わるだけである。

例えば仮定として `2 MW` の電力を `0.5 h` 継続した場合、電力量は

`2 MW×0.5 h=1 MWh`

となる。これは単位計算を示す仮定例であり、特定車両の実値ではない。

## 7. 頻出ミス・ひっかけ

- `M` と `m` を同じものとして扱う。`M=10^6`、`m=10^-3` である。
- `mA` を `10^-6 A` と誤る。milli は `10^-3` である。
- `mA/ms` で分子だけを換算し、分母の `ms` を `s` に直さない。
- `100 m/min` をそのまま `100 m/s` として使う。
- `W` と `kW`、`W` と `Wh` を混同する。
- 面積・体積の単位換算で接頭語を2乗・3乗しない。
- 加減算に乗除算の有効数字ルールを使う。
- 中間計算を早く丸め、最終答が選択肢から外れる。
- `75%` を数値 `75` のまま式へ代入する。
- 効率問題で `Pout=Pin/η` と逆にする。
- 計算結果の単位を確認せず、式の選択ミスを見逃す。

## 9. 公式・解法まとめ

### SI接頭語

`G=10^9`

`M=10^6`

`k=10^3`

`m=10^-3`

`μ=10^-6`

`n=10^-9`

### 主要単位関係

`C=A·s`

`Ω=V/A`

`W=V·A=J/s`

`J=W·s`

`H=V·s/A`

`Wb=V·s`

`F=C/V`

`1 Wh=3600 J`

### 有効数字

- 加減算: 最も粗い桁位置に合わせる。
- 乗除算: 最少の有効数字の個数に合わせる。
- 中間値は早く丸めない。
- 厳密な換算係数や式の整数係数は通常、有効数字を制限しない。

### 誤差

`絶対誤差=|測定値-真値|`

`百分率誤差=絶対誤差/|真値|×100 [%]`

### 標準解法

`与えられた量確認 → 単位統一 → 式選択 → 数値と単位を代入 → 次元確認 → 有効数字処理 → 桁の妥当性確認`
