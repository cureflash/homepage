# 過去問から逆算した必須説明

1. `sin`, `cos`, `tan` を直角三角形と単位円の両方から定義し、代表角 `0, π/6, π/4, π/3, π/2` を扱う。
2. `180°=π rad`, `360°=2π rad` を示し、度とラジアンを相互変換できるようにする。
3. 正弦波 `v(t)=Vm sin(ωt+φ)` について、`Vm`、`ω`、`φ` の意味を波形と対応させる。
4. `T=1/f`, `ω=2πf=2π/T` を導き、式の `ω` から周期・周波数を求める。
5. 位相差の符号と「進み／遅れ」を波形上で確認し、時間差 `Δt=Δφ/ω` へ変換できるようにする。
6. `cos x=sin(x+π/2)`、`-cos x=sin(x-π/2)` を単位円から確認する。
7. 必要範囲の加法定理を扱い、`A sin x+B cos x` を `R sin(x+φ)` へまとめる手順を示す。
8. 正弦波の瞬時値を指定された値に等置し、単位円から複数解を意識しつつ「最初の正の時刻」を選ぶ手順を示す。
9. 交流応用として、90°位相差を直角三角形へ落とす方法と、力率 `cosφ` の幾何学的意味を扱う。
10. 最大値・瞬時値・実効値を混同しない。実効値は交流との接続に必要な範囲で区別するが、本テーマの中心は三角関数と位相とする。

# 典型ミス

- `ω` と `f` を同じものとして扱い、`2π` を落とす。
- 度とラジアンを混在させる。
- `+φ` を遅れ、`-φ` を進みと逆に読む。
- `sin x=1/√2` で一つの角だけを機械的に使い、問題が要求する最初の時刻を確認しない。
- 90°位相差の量を通常のスカラーとして足す。
- `-cos x` の位相を `+π/2` と誤る。
- 力率の三角形で斜辺 `Z` と隣辺 `R` を逆にする。
