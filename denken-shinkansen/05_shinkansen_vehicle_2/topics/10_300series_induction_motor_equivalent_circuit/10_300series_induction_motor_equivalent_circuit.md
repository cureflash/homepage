# 解説本文

## 1. このテーマで電験二種は何を問うか

誘導電動機の問題は、等価回路を描けるだけでは足りない。一次試験では等価回路定数、滑り、損失、トルク特性を選択肢へ落とせること、二次試験では一相分等価回路から電流、二次入力、機械出力、トルク、最大トルク条件まで途中式付きで導けることが必要である。

本テーマの解法の軸は次の4本に固定する。

1. 三相機を一相分等価回路へ落とす。
2. 滑り `s` を決め、二次抵抗項を `r2'/s` として扱う。
3. 二次入力 `P2` を基準に `Pc2=sP2`、`Pm=(1-s)P2` へ分ける。
4. `T=P2/ωs` または `T=Pm/ωm` でトルクへ接続する。

一次・二次とも、式を暗記するより「どの電力がどこで失われ、どこが機械出力になるか」を等価回路上で追えることが重要である。

## 2. 三相誘導電動機の一相分等価回路

平衡三相運転では、三相を一相分へ縮約して解析できる。一次側へ換算した基本要素は次のとおり。

- `r1 [Ω]`: 一次巻線抵抗。一次銅損を生む。
- `x1 [Ω]`: 一次漏れリアクタンス。
- 励磁枝: 鉄損を表す抵抗成分と、磁束を作る励磁リアクタンス成分。
- `r2' [Ω]`: 二次抵抗を一次側へ換算した値。
- `x2' [Ω]`: 二次漏れリアクタンスを一次側へ換算した値。

二次側量を一次側へ換算する目的は、変圧器作用を介した二次回路を一次電圧基準の同じ回路上で計算できるようにすることである。換算後も実際の電力関係が保たれるように抵抗・リアクタンス・電流を対応させる。

二次側の運転状態は抵抗項 `r2'/s` に集約される。したがって、同じ機械でも滑りが変わると等価回路上の見かけの二次抵抗が変化する。

## 3. 滑りと `r2'/s`

同期速度を `Ns [min^-1]`、回転速度を `N [min^-1]` とすると、滑りは

` s = (Ns - N) / Ns `

である。同期速度は

` Ns = 120 f / p `

で求める。`f [Hz]` は電源周波数、`p` は極数である。

電動機運転では通常 `0 < s < 1`。停止時は `N=0` なので `s=1`、同期速度へ近づくと `s→0` となる。

一次換算二次回路では抵抗項が `r2'/s` となる。この項は

` r2'/s = r2' + r2'(1-s)/s `

と分けられる。前半 `r2'` は二次銅損、後半 `r2'(1-s)/s` は電気入力から機械出力へ変換される部分に対応する。これが `P2 : Pc2 : Pm = 1 : s : (1-s)` の回路上の意味である。

## 4. 抵抗測定・無負荷試験・拘束試験から等価回路定数を求める

R8一次型では、試験結果から等価回路定数を逆算する。

### 4.1 一次抵抗

Y結線で二つの線端間から直流抵抗を測ると、二相分の巻線抵抗が直列に入るため、同温度で各相が等しい場合は

` r1 = RLL / 2 `

となる。基準巻線温度へ補正する必要がある問題では、問題文で指定された材料定数 `K` を使い

` r1,θ2 = r1,θ1 (K + θ2) / (K + θ1) `

とする。温度補正は等価回路定数を試験条件へそろえるために行うものであり、本テーマでは熱設計へ広げない。

### 4.2 無負荷試験

Y結線なら相電圧は `V0φ=V0L/√3`、線電流と相電流は等しい。無負荷入力から問題文で指定された補正・損失分離を行った有効電力を `P0'` とすると、励磁枝のコンダクタンス `G0` は

` G0 = P0' / (3 V0φ^2) `

励磁枝のアドミタンスの大きさは `I0/V0φ` なので、誘導性サセプタンスの大きさ `B0` は

` B0 = sqrt{(I0/V0φ)^2 - G0^2} `

となる。等価な抵抗・リアクタンスで表すなら `Rc=1/G0`、`Xm=1/B0` である。無負荷入力をそのまま鉄損だけと決め付けず、問題文で一次銅損や機械損の扱いを確認する。

### 4.3 拘束試験

回転子を拘束すると `s=1` であり、二次抵抗項は `r2'/s=r2'` となる。拘束試験では通常、励磁枝電流が主電流に比べて小さいという問題設定のもとで直列枝から定数を求める。

相電圧 `Vkφ`、電流 `Ik`、三相入力 `Pk` から

` Zk = Vkφ / Ik `

` Req = Pk / (3 Ik^2) = r1 + r2' `

` Xeq = sqrt(Zk^2 - Req^2) = x1 + x2' `

したがって

` r2' = Req - r1 `

である。`x1` と `x2'` を個別に分離するには追加条件または問題文の仮定が必要であり、拘束試験だけから勝手に等分しない。

## 5. 二次入力・二次銅損・機械出力

二次枝電流の一次換算値を `I2' [A]` とすると、三相分の二次入力は

` P2 = 3 I2'^2 (r2'/s) `

二次銅損は

` Pc2 = 3 I2'^2 r2' = s P2 `

電磁変換された機械出力は

` Pm = P2 - Pc2 = (1-s)P2 `

となる。よって

` P2 : Pc2 : Pm = 1 : s : (1-s) `

である。

ここで `Pm` は回転子内部で電磁変換された機械出力である。問題で機械損が与えられる場合、軸出力は `Pm` から機械損を差し引く。機械損を無視すると明記された問題では `Pout≈Pm` と置ける。

## 6. 等価回路から電流・出力まで解く手順

L形近似等価回路で励磁枝を入力端へ移し、直列枝だけを計算する場合、相電圧を `Vφ`、合成漏れリアクタンスを `X=x1+x2'` とすると直列枝電流は

` I2' = Vφ / sqrt{(r1+r2'/s)^2 + X^2} `

となる。

二種の数値問題では次の順に固定する。

1. 結線を確認し、線間値を相値へ直す。
2. 同期速度 `Ns` と滑り `s` を求める。
3. `r2'/s` を計算する。
4. 一相分等価回路から `I2'` または一次電流を求める。
5. `P2=3I2'^2(r2'/s)` を求める。
6. `Pc2=sP2`、`Pm=(1-s)P2` へ分ける。
7. 必要なら軸出力、トルク、効率へ進む。
8. 三相分か一相分か、線間値か相値か、WかkWかを検算する。

励磁枝を含む問題では、直列枝電流と励磁電流をベクトル加算して一次電流を求める。励磁枝を無視する近似問題と混同しない。

## 7. トルクと滑り

同期角速度を `ωs [rad/s]`、機械角速度を `ωm [rad/s]` とすると

` ωm = (1-s)ωs `

である。電磁トルクは

` T = Pm / ωm `

ここへ `Pm=(1-s)P2` を代入すると

` T = P2 / ωs `

となる。したがって二次入力が求まれば、回転速度を直接使わず同期角速度からトルクを求められる。

L形近似で励磁枝を直列枝計算から外した場合は

` T(s) = 3 Vφ^2 (r2'/s) / [ωs {(r1+r2'/s)^2 + X^2}] `

となる。

同期速度近傍では `s` が小さく `r2'/s` が大きいため、上式は近似的に

` T ∝ s `

となる。この低滑り域の直線的関係が一次試験の特性判断で問われる。

## 8. 最大トルクと最大トルク時滑り

上のL形近似トルク式で

` y = r2'/s `

と置くと

` T = 3Vφ^2 y / [ωs {(r1+y)^2+X^2}] `

である。`dT/dy=0` とすると最大トルク条件は

` y = sqrt(r1^2 + X^2) `

したがって

` sm = r2' / sqrt(r1^2 + X^2) `

となる。

最大トルクは

` Tmax = 3Vφ^2 / [2ωs {r1 + sqrt(r1^2+X^2)}] `

であり、この近似式では `r2'` を変えても `Tmax` 自体は変わらず、最大トルクを生じる滑り `sm` が `r2'` に比例して移動する。

さらに `r1` を無視できる近似では

` sm ≈ r2'/X `

` Tmax ≈ 3Vφ^2/(2ωsX) `

となる。どの近似を使うかは問題文・等価回路に合わせる。

## 9. 比例推移

トルク式は、他の条件を一定とすれば `r2'/s` の値で決まる。二次抵抗を `r2a'` から `r2b'` へ変え、同じトルクを与える対応点を取ると

` r2a'/sa = r2b'/sb `

したがって

` sb/sa = r2b'/r2a' `

となる。これが比例推移である。

二次抵抗を大きくするとトルク―滑り曲線は大きな滑り側へ移り、最大トルク時滑りも同じ比率で大きくなる。最大トルクの大きさは上の近似条件では変わらない。

## 10. 一次入力と効率

平衡三相の一次入力は

` P1 = √3 VL IL cosφ = 3 Vφ Iφ cosφ `

で求める。軸出力を `Pout` とすると効率は

` η = Pout / P1 `

である。

機械損を無視する問題では `Pout≈Pm`。機械損が与えられる場合は `Pout=Pm-Pmech_loss` とする。励磁枝を含む等価回路では鉄損・励磁電流を一次入力へ反映し、直列枝だけの簡略式と混同しない。

負荷が変わると滑りと電流が変わり、一次銅損・二次銅損・出力が変化する。SPEC指定の「効率―負荷率」は、同一の等価回路条件で負荷点を変え、各点の `P1` と `Pout` から `η` を計算して作る。

## 11. SPEC指定4グラフの計算条件

グラフ生成時は300系実車値を推定せず、教材用仮定値であることを明記する。説明用の統一条件は次とする。

- 三相Y結線、一相分相電圧 `Vφ=200 V`
- `f=50 Hz`, `p=4`
- `r1=0.20 Ω`
- `x1=0.50 Ω`, `x2'=0.50 Ω`, よって `X=1.00 Ω`
- 基準 `r2'=0.30 Ω`
- 励磁枝を使う効率計算では教材用仮定値 `Rc=800 Ω`, `Xm=40 Ω`
- 機械損はグラフ条件で別途明示し、与えない場合は0として扱う
- 以上はすべて教材用仮定値であり、300系実車値ではない

### 11.1 トルク―すべり

`0.005≤s≤1` で `T(s)` を計算し、低滑り域の `T∝s`、最大トルク、始動時 `s=1` の位置を示す。

### 11.2 出力―すべり

同じ条件で `P2(s)` と `Pm(s)=(1-s)P2(s)` を計算し、滑り増加で二次銅損割合 `sP2` が増えることを確認する。

### 11.3 効率―負荷率

安定運転側の負荷点を滑りで走査し、励磁枝を含む一次入力と軸出力から効率を計算する。負荷率は基準点の軸出力に対する比として定義し、定義と基準点をグラフへ明記する。実車定格負荷率と誤認させない。

### 11.4 二次抵抗変更時の特性

`r2'=0.20, 0.30, 0.45 Ω` を教材用比較値としてトルク―すべり曲線を重ね、`Tmax` の大きさがほぼ同じまま `sm` が二次抵抗に比例して移ることを示す。

本テーマでは、SPECで300系を誘導主電動機の導入題材としていることだけを接続点とする。実車の抵抗、リアクタンス、電圧、電流、周波数、効率、制御定数は、本段階で一次資料確認していないため数値として使用しない。

## 13. 頻出ミス

- 線間電圧をそのまま一相分相電圧として代入する。
- Y結線の線間直流抵抗を一相抵抗と誤認し、`RLL/2` を忘れる。
- 停止時を `s=0` とする。停止時は `s=1`。
- `r2'` と `r2'/s` を同じものとして扱う。
- `Pc2=(1-s)P2` と取り違える。二次銅損は `sP2`。
- `Pm` を機械損控除後の軸出力と常に同一視する。
- トルクを `Pm/ωs` とする。正しくは `Pm/ωm=P2/ωs`。
- 最大トルク時滑りだけを変える二次抵抗変更と、最大トルク値そのものの変化を混同する。
- 拘束試験だけから `x1=x2'` と勝手に決める。
- 無負荷入力を無条件に全て鉄損とみなす。

## 14. 3段階例題

### 14.1 基礎例題: 滑りと二次電力分配

4極、60 Hzの三相誘導電動機が `1746 min^-1` で運転し、二次入力が `200 kW` である。二次銅損と機械出力を求める。

同期速度は

` Ns = 120×60/4 = 1800 min^-1 `

したがって滑りは

` s = (1800-1746)/1800 = 0.030 `

二次銅損は

` Pc2 = sP2 = 0.030×200 = 6.0 kW `

機械出力は

` Pm = (1-s)P2 = 0.970×200 = 194 kW `

検算: `6+194=200 kW` となり二次入力と一致する。

### 14.2 本試験標準例題: L形等価回路から電流・出力・トルク・効率

教材用仮定値として、Y結線一相分の `Vφ=200 V`、`f=50 Hz`、4極、`r1=0.20 Ω`、`x1+x2'=1.00 Ω`、`r2'=0.30 Ω`、滑り `s=0.040` とする。励磁枝と機械損を無視するL形近似で求める。

二次抵抗項は

` r2'/s = 0.30/0.040 = 7.50 Ω `

直列枝電流は

` I2' = 200 / sqrt{(0.20+7.50)^2+1.00^2} = 25.76 A `

二次入力は

` P2 = 3×25.76^2×7.50 = 14.93 kW `

二次銅損は

` Pc2 = 0.040×14.93 = 0.597 kW `

機械出力は

` Pm = 0.960×14.93 = 14.33 kW `

同期速度は `1500 min^-1`、同期角速度は

` ωs = 2π×1500/60 = 157.08 rad/s `

したがってトルクは

` T = P2/ωs = 14930/157.08 = 95.0 N m `

直列枝への一次入力は

` P1 = 3 I2'^2 (r1+r2'/s) = 15.33 kW `

この近似条件では

` η = Pm/P1 = 14.33/15.33 = 0.935 ≈ 93.5 % `

検算: `P1-P2≈3I2'^2r1` で一次銅損に一致し、`P2-Pm=Pc2` も成立する。

### 14.3 複合・ひっかけ例題: 最大トルクと比例推移

前例と同じ `Vφ=200 V`、`f=50 Hz`、4極、`r1=0.20 Ω`、`X=1.00 Ω`、`r2'=0.30 Ω` とする。

` sqrt(r1^2+X^2) = sqrt(0.20^2+1.00^2) = 1.0199 Ω `

最大トルク時滑りは

` sm = 0.30/1.0199 = 0.294 `

最大トルクは

` Tmax = 3×200^2 / [2×157.08×(0.20+1.0199)] = 313 N m `

ここで二次抵抗を `0.45 Ω` に変更すると

` sm,new = 0.45/1.0199 = 0.441 `

となるが、この近似では `Tmax` は `313 N m` のままである。

さらに旧条件の `s=0.20` と同じトルクを得る新しい滑りは比例推移から

` snew = 0.20×0.45/0.30 = 0.30 `

である。実際、両条件とも `r2'/s=1.50 Ω` となるためトルク式の値は等しく、約 `295 N m` となる。

ひっかけは「二次抵抗を増すと最大トルクも増す」と判断すること。本近似では最大トルクの位置が移るのであり、最大値は変わらない。

## 16. 公式・解法まとめ

- 同期速度: `Ns=120f/p`
- 滑り: `s=(Ns-N)/Ns`
- 二次入力: `P2=3I2'^2(r2'/s)`
- 二次銅損: `Pc2=sP2=3I2'^2r2'`
- 機械出力: `Pm=(1-s)P2`
- 機械角速度: `ωm=(1-s)ωs`
- トルク: `T=Pm/ωm=P2/ωs`
- L形近似トルク: `T=3Vφ^2(r2'/s)/[ωs{(r1+r2'/s)^2+X^2}]`
- 最大トルク時滑り: `sm=r2'/sqrt(r1^2+X^2)`
- 比例推移: `sb/sa=r2b'/r2a'`
- 一次入力: `P1=√3VLILcosφ`
- 効率: `η=Pout/P1`

解法は「結線・相値確認 → 同期速度・滑り → `r2'/s` → 電流 → `P2` → `Pc2`,`Pm` → トルク・効率」の順に固定する。
