# 一次試験型

## 問1 滑りと二次電力分配

4極、60 Hzの三相誘導電動機が `1710 min^-1` で運転している。一次換算二次抵抗を `r2'=0.24 Ω`、二次入力を `P2=120 kW` とする。`r2'/s`、二次銅損、機械出力の組合せとして正しいものを選べ。

1. `4.8 Ω`, `6.0 kW`, `114 kW`
2. `4.8 Ω`, `114 kW`, `6.0 kW`
3. `0.012 Ω`, `6.0 kW`, `114 kW`
4. `0.24 Ω`, `120 kW`, `0 kW`
5. `0.24 Ω`, `6.0 kW`, `120 kW`

### 正答

1

### 完全解説

同期速度は

```text
Ns=120f/p
  =120×60/4
  =1800 min^-1
```

滑りは

```text
s=(1800-1710)/1800
 =0.050
```

したがって

```text
r2'/s=0.24/0.050
     =4.8 Ω
```

二次銅損と機械出力は

```text
Pc2=sP2
   =0.050×120
   =6.0 kW

Pm=(1-s)P2
  =0.950×120
  =114 kW
```

`6+114=120 kW` で二次入力と一致する。正答は1。

## 問2 Y結線の一次抵抗と温度補正

Y結線誘導電動機で、20 ℃における二つの線端間の直流抵抗が `0.48 Ω` であった。各相抵抗は等しいものとする。材料定数を `K=235 ℃` とし、75 ℃へ換算した一相当たり一次抵抗として最も近いものを選べ。

1. `0.146 Ω`
2. `0.240 Ω`
3. `0.292 Ω`
4. `0.480 Ω`
5. `0.584 Ω`

### 正答

3

### 完全解説

Y結線で二線間から測ると二相分が直列になるので、20 ℃での一相抵抗は

```text
r1,20=0.48/2
     =0.24 Ω
```

75 ℃へ補正すると

```text
r1,75=r1,20 (K+75)/(K+20)
     =0.24×310/255
     =0.2918 Ω
```

よって約 `0.292 Ω`、正答は3。線間測定値をそのまま一相抵抗にしない。

## 問3 無負荷試験から励磁枝を求める

Y結線誘導電動機の無負荷試験で、線間電圧 `400 V`、線電流 `5.0 A`、損失分離後に励磁枝の有効電力として扱う三相電力 `1200 W` が得られた。励磁コンダクタンス `G0` と誘導性サセプタンスの大きさ `B0` の組合せとして最も近いものを選べ。

1. `G0=7.50 mS`, `B0=20.31 mS`
2. `G0=20.31 mS`, `B0=7.50 mS`
3. `G0=15.00 mS`, `B0=15.00 mS`
4. `G0=7.50 mS`, `B0=5.00 mS`
5. `G0=30.00 mS`, `B0=40.00 mS`

### 正答

1

### 完全解説

Y結線の相電圧は

```text
V0φ=400/√3
   =230.94 V
```

したがって

```text
G0=P0'/(3V0φ^2)
  =1200/(3×230.94^2)
  =0.00750 S
  =7.50 mS
```

励磁枝アドミタンスの大きさは

```text
|Y0|=I0/V0φ
    =5.0/230.94
    =0.02165 S
```

よって

```text
B0=sqrt(|Y0|^2-G0^2)
  =0.02031 S
  =20.31 mS
```

正答は1。無負荷入力を無条件にすべて鉄損とせず、問題文で指定された損失分離後の値を使う。

## 問4 拘束試験から二次抵抗と漏れリアクタンスを求める

Y結線誘導電動機の拘束試験で、線間電圧 `173.2 V`、線電流 `20.0 A`、三相入力 `2400 W` を得た。基準温度の一相一次抵抗は `r1=0.50 Ω` とする。励磁枝電流を無視する近似で、一次換算二次抵抗 `r2'` と合成漏れリアクタンス `X=x1+x2'` の組合せとして最も近いものを選べ。

1. `r2'=0.50 Ω`, `X=2.00 Ω`
2. `r2'=1.00 Ω`, `X=4.00 Ω`
3. `r2'=1.50 Ω`, `X=4.58 Ω`
4. `r2'=2.00 Ω`, `X=5.00 Ω`
5. `r2'=4.50 Ω`, `X=1.50 Ω`

### 正答

3

### 完全解説

拘束時は `s=1`。相電圧は

```text
Vkφ=173.2/√3
   ≈100.0 V
```

したがって

```text
Zk=Vkφ/Ik
  =100.0/20.0
  =5.00 Ω

Req=Pk/(3Ik^2)
   =2400/(3×20^2)
   =2.00 Ω
```

`Req=r1+r2'` だから

```text
r2'=2.00-0.50
   =1.50 Ω
```

合成漏れリアクタンスは

```text
X=sqrt(Zk^2-Req^2)
 =sqrt(5.00^2-2.00^2)
 =4.58 Ω
```

よって正答は3。拘束試験だけから `x1=x2'` と勝手に分けてはいけない。

## 問5 最大トルク時滑りと停動トルク

教材用仮定値として、三相Y結線の一相分相電圧 `Vφ=200 V`、50 Hz、4極、`r1=0.20 Ω`、`X=x1+x2'=1.00 Ω`、`r2'=0.30 Ω` とする。L形近似で最大トルク時滑り `sm` と最大トルク `Tmax` の組合せとして最も近いものを選べ。

1. `sm=0.0294`, `Tmax=31.3 N m`
2. `sm=0.294`, `Tmax=313 N m`
3. `sm=0.300`, `Tmax=157 N m`
4. `sm=1.00`, `Tmax=313 N m`
5. `sm=0.294`, `Tmax=626 N m`

### 正答

2

### 完全解説

同期速度と同期角速度は

```text
Ns=120×50/4=1500 min^-1
ωs=2π×1500/60=157.08 rad/s
```

最大トルク条件は

```text
r2'/sm=sqrt(r1^2+X^2)
```

なので

```text
sm=0.30/sqrt(0.20^2+1.00^2)
  =0.294
```

最大トルクは

```text
Tmax=3Vφ^2/[2ωs{r1+sqrt(r1^2+X^2)}]
    =313 N m
```

よって正答は2。この近似では `Tmax` の式に `r2'` が残らない。

## 問6 比例推移

他の条件を一定とし、一次換算二次抵抗を `0.30 Ω` から `0.45 Ω` へ増加させる。旧条件で滑り `0.18` の点と同じトルクを得る新しい滑りとして正しいものを選べ。

1. `0.08`
2. `0.12`
3. `0.18`
4. `0.27`
5. `0.45`

### 正答

4

### 完全解説

同一トルクの対応点では `r2'/s` が等しいので

```text
snew/sold=r2,new'/r2,old'
```

したがって

```text
snew=0.18×0.45/0.30
    =0.27
```

正答は4。この近似では二次抵抗増加によりトルク―滑り曲線が大きな滑り側へ移るが、最大トルク値そのものは変わらない。

## 問7 三相入力と効率

線間電圧 `400 V`、線電流 `30 A`、力率 `0.85` で運転する平衡三相誘導電動機の軸出力が `16.0 kW` である。効率として最も近いものを選べ。

1. `78.4%`
2. `85.0%`
3. `90.6%`
4. `94.1%`
5. `108.7%`

### 正答

3

### 完全解説

一次入力は

```text
P1=√3 VL IL cosφ
  =√3×400×30×0.85
  =17.67 kW
```

したがって

```text
η=Pout/P1
 =16.0/17.67
 =0.9056
 ≈90.6%
```

よって正答は3。効率では機械出力 `Pm` と軸出力 `Pout` を問題条件に応じて区別する。

## 問8 等価回路とトルク特性の正誤

Topic 10 の固定範囲として正しい記述を選べ。

1. 誘導電動機の停止時は `s=0` であり、同期速度で `s=1` となる。
2. 二次銅損は常に `(1-s)P2` で表される。
3. 同期速度近傍の低滑り域では、L形近似のトルクはおおむね `T∝s` となる。
4. 拘束試験だけで、追加条件なしに必ず `x1=x2'` と決定できる。
5. 無負荷試験の三相入力は、問題条件を確認せず全て鉄損とみなしてよい。

### 正答

3

### 完全解説

停止時は `s=1`、同期速度近傍で `s→0`。二次銅損は `Pc2=sP2`。同期速度近傍では `r2'/s` が大きくなり、L形近似トルク式は `T∝s` へ近づく。拘束試験から直接得られるのは合成漏れリアクタンスであり、追加条件なしに `x1` と `x2'` を個別分離できない。無負荷入力も一次銅損・機械損等の扱いを問題条件で確認する必要がある。したがって正答は3。

# 二次試験型

## 問1 抵抗測定・無負荷試験・拘束試験から等価回路定数を求める

教材用のY結線三相誘導電動機について、次の試験値を得た。

- 20 ℃での線間直流抵抗: `0.50 Ω`
- 基準巻線温度: `75 ℃`
- 温度補正定数: `K=235 ℃`
- 無負荷試験: 線間電圧 `346.4 V`、線電流 `8.0 A`、損失分離後の励磁枝三相有効電力 `1800 W`
- 拘束試験: 線間電圧 `86.6 V`、線電流 `20.0 A`、三相入力 `1200 W`

無負荷試験では励磁枝だけを求め、拘束試験では励磁枝電流を無視する近似とする。次を求めよ。

1. 75 ℃へ補正した一相一次抵抗 `r1`
2. 励磁コンダクタンス `G0`、誘導性サセプタンスの大きさ `B0`
3. 拘束時の等価抵抗 `Req`、インピーダンス `Zk`、合成漏れリアクタンス `X=x1+x2'`
4. 一次換算二次抵抗 `r2'`

### 完全解説

20 ℃の一相抵抗は

```text
r1,20=0.50/2
     =0.25 Ω
```

75 ℃へ補正すると

```text
r1=0.25×(235+75)/(235+20)
  =0.3039 Ω
```

無負荷相電圧は

```text
V0φ=346.4/√3
   ≈200.0 V
```

よって

```text
G0=1800/(3×200.0^2)
  ≈0.0150 S
```

励磁枝アドミタンスの大きさは

```text
|Y0|=8.0/200.0
    =0.0400 S
```

したがって

```text
B0=sqrt(0.0400^2-0.0150^2)
  ≈0.0371 S
```

拘束相電圧は

```text
Vkφ=86.6/√3
   ≈50.0 V
```

拘束時は `s=1` なので

```text
Req=1200/(3×20.0^2)
   =1.000 Ω

Zk=50.0/20.0
  =2.500 Ω

X=sqrt(2.500^2-1.000^2)
 ≈2.291 Ω
```

よって

```text
r2'=Req-r1
   =1.000-0.3039
   =0.6961 Ω
```

検算: `r1+r2'=1.000 Ω=Req`。拘束試験だけから `x1` と `x2'` を個別に等分してはいけない。

## 問2 L形等価回路から電流・二次入力・機械出力・トルク・効率を求める

教材用仮定値として、Y結線一相分の相電圧 `Vφ=230 V`、60 Hz、4極、`r1=0.25 Ω`、`X=x1+x2'=1.20 Ω`、`r2'=0.36 Ω`、滑り `s=0.040` とする。励磁枝と機械損を無視するL形近似で、次を求めよ。

1. 同期速度 `Ns` と同期角速度 `ωs`
2. 直列枝電流 `I2'`
3. 二次入力 `P2`
4. 二次銅損 `Pc2` と機械出力 `Pm`
5. 電磁トルク `T`
6. この近似条件での一次入力 `P1` と効率 `η`

### 完全解説

同期速度と同期角速度は

```text
Ns=120×60/4
  =1800 min^-1

ωs=2π×1800/60
  =188.50 rad/s
```

二次抵抗項は

```text
r2'/s=0.36/0.040
     =9.00 Ω
```

したがって

```text
I2'=230/sqrt{(0.25+9.00)^2+1.20^2}
   =24.66 A
```

二次入力は

```text
P2=3×24.66^2×9.00
  =16.42 kW
```

二次銅損と機械出力は

```text
Pc2=0.040×16.42
   =0.657 kW

Pm=0.960×16.42
  =15.76 kW
```

トルクは

```text
T=P2/ωs
 =16420/188.50
 ≈87.1 N m
```

直列枝へ入る一次入力は

```text
P1=3×24.66^2×(0.25+9.00)
  =16.87 kW
```

機械損を無視するので `Pout≈Pm`。したがって

```text
η=15.76/16.87
 ≈0.934
 =93.4%
```

検算: `P2-Pm≈Pc2`、`P1-P2≈3I2'^2r1` が成立する。

## 問3 最大トルクと比例推移

問2と同じ `Vφ=230 V`、60 Hz、4極、`r1=0.25 Ω`、`X=1.20 Ω`、`r2'=0.36 Ω` を用いる。

1. 最大トルク時滑り `sm` を求めよ。
2. 最大トルク `Tmax` を求めよ。
3. `r2'` を `0.54 Ω` へ変更したときの新しい最大トルク時滑りを求めよ。
4. 旧条件の滑り `s=0.12` と同じトルクを得る新しい滑りを比例推移から求めよ。
5. この近似で二次抵抗を変えたとき、最大トルク値がどうなるか説明せよ。

### 完全解説

まず

```text
sqrt(r1^2+X^2)
=sqrt(0.25^2+1.20^2)
=1.2258 Ω
```

したがって

```text
sm=0.36/1.2258
  =0.2937
```

同期角速度は問2より `188.50 rad/s`。最大トルクは

```text
Tmax=3×230^2/[2×188.50×(0.25+1.2258)]
    ≈285 N m
```

`r2'=0.54 Ω` では

```text
sm,new=0.54/1.2258
      =0.4405
```

同一トルク対応点は

```text
snew/sold=0.54/0.36

snew=0.12×0.54/0.36
    =0.18
```

L形近似の `Tmax` の式には `r2'` が残らないため、二次抵抗変更で最大トルク時滑りは比例して移るが、最大トルク値自体は変わらない。

## 問4 `T=P2/ωs` と低滑り域 `T∝s` を導く

三相誘導電動機について、二次入力を `P2`、滑りを `s`、同期角速度を `ωs`、機械角速度を `ωm` とする。機械損は考えない。

1. `Pm=(1-s)P2` と `ωm=(1-s)ωs` から `T=P2/ωs` を導け。
2. L形近似トルク式

```text
T(s)=3Vφ^2(r2'/s)/[ωs{(r1+r2'/s)^2+X^2}]
```

について、同期速度近傍の低滑り域で `T∝s` となる理由を示せ。
3. 停止時と同期速度近傍の滑りを答えよ。

### 完全解説

電磁トルクは

```text
T=Pm/ωm
```

である。ここへ

```text
Pm=(1-s)P2
ωm=(1-s)ωs
```

を代入すると

```text
T={(1-s)P2}/{(1-s)ωs}
 =P2/ωs
```

となる。

同期速度近傍では `s` が小さく、`r2'/s` が `r1` や `X` より十分大きい領域を考える。このとき分母では `(r2'/s)^2` が支配的なので

```text
T(s)≈3Vφ^2(r2'/s)/[ωs(r2'/s)^2]
    =3Vφ^2 s/(ωs r2')
```

となり、他の条件が一定なら `T∝s` である。

停止時は `N=0` なので `s=1`。同期速度へ近づくと `s→0` となる。
