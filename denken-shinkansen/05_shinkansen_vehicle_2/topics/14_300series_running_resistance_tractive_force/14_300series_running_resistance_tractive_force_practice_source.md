## 問1 同期速度・滑り・機械トルク

4極、`50 Hz` の三相誘導電動機が `1440 min^-1` で回転し、機械出力が `30.0 kW` である。`N_s=120f/p`、`s=(N_s-N)/N_s` とする。滑り `s` と機械トルク `T` の組合せとして最も近いものを選べ。

1. `s=0.040`、`T=199 N·m`
2. `s=0.040`、`T=20.8 N·m`
3. `s=0.960`、`T=199 N·m`
4. `s=-0.040`、`T=199 N·m`
5. `s=0.040`、`T=314 N·m`

### 正答

1

### 完全解説

同期速度は

```text
N_s = 120f/p
    = 120×50/4
    = 1500 min^-1
```

したがって

```text
s = (1500-1440)/1500
  = 0.040
```

回転角速度は

```text
ω = 2πN/60
  = 2π×1440/60
  = 150.8 rad/s
```

よって

```text
T = P/ω
  = 30000/150.8
  = 198.9 N·m
  ≈ 199 N·m
```

正答は1。`min^-1` の数値をそのまま `ω` として使わない。滑りの分母は同期速度である。

## 問2 負荷トルクと慣性トルク

ある回転機で、慣性モーメント `J=50 kg·m^2`、角加速度 `dω/dt=6.0 rad/s^2`、負荷トルク `T_L=700 N·m` である。その瞬間の回転角速度を `ω=120 rad/s` とする。必要な電動機トルク `T_M` と機械出力 `P` の組合せとして正しいものを選べ。

1. `T_M=700 N·m`、`P=84 kW`
2. `T_M=1000 N·m`、`P=120 kW`
3. `T_M=300 N·m`、`P=36 kW`
4. `T_M=1000 N·m`、`P=8.33 kW`
5. `T_M=1700 N·m`、`P=204 kW`

### 正答

2

### 完全解説

加速時は負荷トルクだけでなく慣性トルクが必要である。

```text
T_M = J dω/dt + T_L
    = 50×6.0 + 700
    = 1000 N·m
```

その瞬間の機械出力は

```text
P = T_Mω
  = 1000×120
  = 120000 W
  = 120 kW
```

正答は2。選択肢1は慣性項を落としている。加速時は定速時より大きいトルク・出力が必要になり得る。

## 問3 発進瞬間の力・トルク・出力

平たんな線路で列車を静止状態から正の加速度で発進させる。発進瞬間 `v=0` でも走行抵抗が正であるとする。最も適切な記述を選べ。

1. `v=0` なので車輪周力は必ず0である。
2. `P=Fv=0` なので車輪周力・電動機トルクも必ず0である。
3. 発進瞬間の機械出力が0でも、抵抗に打ち勝ち加速するため正の車輪周力・大きな始動トルクを必要とし得る。
4. `v=0` なら加速抵抗 `m_eq a` は必ず0である。
5. `v=0` なら走行抵抗も必ず0である。

### 正答

3

### 完全解説

列車側の力のつり合いは、平たんなら

```text
F_w = R_run(0) + m_eq a
```

である。`R_run(0)>0` かつ `a>0` なら `F_w>0` である。一方、発進の厳密な瞬間は `v=0` なので

```text
P = F_w v = 0
```

となり得る。力・トルクが正であることと、速度ゼロの瞬間の機械出力がゼロであることは両立する。これが電気鉄道用駆動電動機に大きな始動トルクが求められることと矛盾しない。正答は3。

## 問4 平たん・定速時の必要けん引力と出力

2. `44.0 kN`、`2.20 MW`
3. `69.99 kN`、`3.50 MW`
4. `124.62 kN`、`6.23 MW`
5. `163.24 kN`、`8.16 MW`

### 正答

2

### 完全解説


```text
R_run = 25000 + 80×50 + 6×50^2
      = 44000 N
```

```text
F_req = R_run
```

必要出力は

```text
P_req = F_req v
```

正答は2。`180 km/h` の数値をそのまま `P=Fv` に代入しない。

共通教材用モデルの列車が `10‰` の上り勾配を `90 km/h` で定速走行する。小勾配近似 `R_g≈mgi` を用いる。必要けん引力と必要出力の組合せとして最も近いものを選べ。

```text
R_run = 25000 + 80×25 + 6×25^2
```

```text
R_g ≈ mgi
```

## 問6 走行抵抗・勾配抵抗・加速抵抗の合成

共通教材用モデルの列車が `5‰` の上り勾配を `180 km/h` で走行しながら、`0.20 m/s^2` で加速する。必要けん引力と必要出力の組合せとして正しいものを選べ。

1. `63.62 kN`、`3.18 MW`
2. `83.24 kN`、`4.16 MW`
3. `124.62 kN`、`6.23 MW`
4. `143.62 kN`、`7.181 MW`
5. `163.24 kN`、`8.162 MW`

### 正答

4

### 完全解説

`180 km/h=50.0 m/s` である。

走行抵抗は

```text
R_run = 44.00 kN
```

勾配抵抗は

```text
R_g = 4.00×10^5×9.81×0.005
    = 19620 N
    = 19.62 kN
```

加速抵抗は

```text
R_a = m_eq a
    = 4.00×10^5×0.20

    = 80.00 kN
```

したがって

```text
F_req = 44.00 + 19.62 + 80.00
```

```text
P_req = 143620×50.0

      = 7.181 MW
```

正答は4。問題で指定された三つの成分だけを加える。

## 問7 車輪周力から加速度を逆算する

共通教材用モデルの列車が `5‰` の上り勾配を `180 km/h` で走行している。この瞬間の車輪周力が `160 kN` である。加速度として最も近いものを選べ。

1. `0.0910 m/s^2`
2. `0.1591 m/s^2`
3. `0.2410 m/s^2`
4. `0.3500 m/s^2`
5. `0.4000 m/s^2`

### 正答

3

### 完全解説

`180 km/h=50.0 m/s` なので `R_run=44.00 kN`。また `R_g=19.62 kN` である。

力のつり合いから

```text
F_w - R_run - R_g = m_eq a
```

よって

```text
a = (160000-44000-19620)/(4.00×10^5)
  = 96380/(4.00×10^5)
  = 0.24095 m/s^2
  ≈ 0.2410 m/s^2
```

正答は3。車輪周力 `160 kN` に抵抗を足すのではなく、与えられた車輪周力から抵抗を差し引いて加速に使える正味の力を求める。

## 問8 4可視化の関係

共通教材用モデルを用いる。上り `5‰` を固定し、必要けん引力グラフでは目標加速度 `0.20 m/s^2`、加速曲線では車輪周力 `160 kN` を固定する。正しい記述を選べ。

1. `R_run(v)` は速度上昇とともに減少する。
2. 目標加速度を一定にした `F_req(v)` は速度上昇とともに減少する。
3. `v=0` では `F_req>0` なので `P_req=F_req v` も正の値になる。
4. 車輪周力を一定とした加速計算では、速度上昇で `R_run(v)` が増えるため加速度は低下し、`a(50 m/s)=0.24095 m/s^2`、`a(75 m/s)≈0.18908 m/s^2` となる。
5. 加速曲線では `F_w+R_run+R_g=m_eq a` とする。

### 正答

4

### 完全解説

共通式は

```text
R_run(v) = 25000 + 80v + 6v^2
```

なので、対象速度域では速度とともに増える。目標加速度を一定とした必要けん引力も

```text
F_req(v)=R_run(v)+R_g+m_eq a
```

に従って増える。一方、必要出力は `P_req=F_req v` なので `v=0` では0である。

車輪周力一定の加速計算では

```text
a(v) = {160000-R_run(v)-19620}/(4.00×10^5)
```

であり、速度上昇で抵抗が増えるほど加速度は低下する。

```text
a(50) = 0.24095 m/s^2

a(75) = (160000-64750-19620)/(4.00×10^5)
      = 0.189075 m/s^2
      ≈ 0.18908 m/s^2
```

よって正答は4。

6極、`60 Hz` の三相誘導電動機が、状態1で `N_1=1164 min^-1`、機械出力 `P_1=24.0 kW` で運転している。`N_s=120f/p`、`s=(N_s-N)/N_s` を用いる。


```text
s_1 = (1200-1164)/1200
    = 0.0300
```

```text
ω_1 = 2π×1164/60

```

したがって

```text
T_1 = P_1/ω_1
    = 24000/121.894
```

```text
s_2 = 0.5×0.0300
```

```text
N_2 = N_s(1-s_2)
```

## 問10（二次2）負荷トルク・慣性トルクと加速

ある電動機が、ある瞬間に機械出力 `15.0 kW`、回転速度 `1500 min^-1` で運転している。回転系の慣性モーメントは `J=2.00 kg·m^2`、負荷トルクは `T_L=60.0 N·m` とする。この瞬間の電動機トルクを用いて短時間の角加速度を評価する。

(a) 回転角速度 `ω` と電動機トルク `T_M` を求めよ。

(b) `T_M=J dω/dt+T_L` から角加速度を求めよ。

(c) 定速時と加速時の必要トルクの違いを説明せよ。

### 完全解説

(a)

```text
ω = 2π×1500/60
  = 157.080 rad/s
```

```text
T_M = P/ω
    = 15000/157.080
    = 95.49 N·m
```

(b)

```text
T_M = J dω/dt + T_L
```

より

```text
dω/dt = (T_M-T_L)/J
      = (95.49-60.0)/2.00
      = 17.75 rad/s^2
```

(c) 定速時は `dω/dt=0` なので `T_M=T_L` でよい。加速時は正の慣性トルク `J dω/dt` を加えて負担するため、`T_M>T_L` が必要になる。したがって短時間加速では定常時より大きなトルク・出力を出せる余裕が必要になり得る。これがH25一次の慣性項・短時間容量への接続である。

## 問12（二次4）車輪周力一定の加速曲線を2ステップ計算する

共通教材用モデルの列車が上り `5‰` を走行する。車輪周力を教材用仮定として `F_w=160 kN` 一定、初期速度を `v_0=50.000 m/s` とする。前進オイラー法

```text
v_(k+1)=v_k+a(v_k)Δt
```

を `Δt=1.00 s` で用い、2ステップ後まで計算する。

(b) `R_run(v_1)`、`a(v_1)`、`v_2` を求めよ。

(c) 加速度がわずかに低下する理由を説明せよ。

上り `5‰` の勾配抵抗は

```text
R_g = 19620 N
```

である。

(a) `v_0=50.000 m/s` では

```text
R_run(v_0) = 44000 N
```

なので

```text
a(v_0) = (160000-44000-19620)/(4.00×10^5)
       = 0.24095 m/s^2
```

したがって

```text
v_1 = 50.000 + 0.24095×1.00
    = 50.24095 m/s
```

(b)

```text
R_run(v_1)
= 25000 + 80×50.24095 + 6×50.24095^2
≈ 44164.19 N
```

よって

```text
a(v_1)
= (160000-44164.19-19620)/(4.00×10^5)
≈ 0.24054 m/s^2
```

```text
v_2 = 50.24095 + 0.24054×1.00
    ≈ 50.48149 m/s
```
