# EXAM_ALIGNMENT

資格: 第二種電気主任技術者

主科目: 一次試験「機械」、二次試験「機械・制御」

論点:
- 電動機トルク・回転角速度・機械出力の関係 `P=Tω`
- 電動機トルクと負荷トルク・慣性トルクのつり合い
- 始動時に大きなトルクを必要とする電気鉄道の負荷特性
- 列車側の抵抗・加速度から必要けん引力を立てる力のつり合い
- 必要けん引力と速度から車輪周出力を求める `P=Fv`
- 軸出力と車輪周出力を、問題で与えられた効率・伝達条件だけを用いて接続する

## 教材で欠落不可の説明

1. `P=Tω`、`ω=2πN/60` を記号・単位・逆算まで示し、出力・トルク・回転速度のどれを求める場合にも使えるようにする。
2. H25一次の `T_M=J dω_r/dt+T_L` を、慣性トルクと負荷トルクの和として説明する。列車側では同じ力学を、抵抗に打ち勝つ力と加速に必要な力の和として接続する。
3. 走行抵抗は `R_run(v)` として速度依存性を明示し、SPEC指定の空気抵抗を速度依存成分として説明する。実車係数や経験式は一次資料で確認できない限り固定しない。
4. 勾配抵抗は斜面方向の重力成分から `R_g=mg sinθ` を導き、勾配 `i` が十分小さく比で与えられる場合の `R_g≈mgi` は近似条件を明記する。
5. 加速抵抗は `R_a=m_eq a` とし、`m_eq` を回転部分の等価質量まで含める場合と単純な車両質量を使う場合を問題条件で区別する。勝手な補正係数は置かない。
6. 必要けん引力は問題で指定された抵抗成分だけを合算し、基本形を `F_req=R_run+R_g+R_a` とする。SPEC外の曲線抵抗・粘着限界等は追加しない。
7. 車輪周出力は `P_w=F_req v` とし、`km/h→m/s` の単位換算、`N×m/s=W` の次元確認まで示す。
8. 軸出力と車輪周出力は、問題で伝達効率 `η_t` が与えられる場合のみ `P_w=η_t P_shaft` と接続する。未確認の300系伝達効率を真値として置かない。
9. 速度―走行抵抗、速度―必要けん引力、速度―必要出力、勾配条件比較の4可視化は同じ仮定値・式系から生成し、グラフと例題の計算条件を一致させる。

| 種別 | 必須内容 |
|---|---|
| 用語・定義 | 走行抵抗、速度依存抵抗、空気抵抗、勾配抵抗、加速抵抗、必要けん引力、軸出力、車輪周出力 |
| 原理・現象 | 抵抗＋加速分を駆動力が負担すること、速度上昇で必要出力が変化すること |

| 計算手順 | 抵抗算定→加速分→必要けん引力→車輪周出力→条件があれば軸出力 |
| グラフ | 速度―走行抵抗、速度―必要けん引力、速度―必要出力、勾配条件比較 |

| 複合計算 | 速度依存抵抗＋勾配＋加速→けん引力→出力 |
