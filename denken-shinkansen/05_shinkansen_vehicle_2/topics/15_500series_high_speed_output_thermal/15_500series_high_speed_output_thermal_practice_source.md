# 一次試験型

## 問1 出力・回転速度・トルク

機械出力 `400 kW`、回転速度 `3000 min^-1` の回転機のトルクとして最も近いものを選べ。

1. `127 N·m`
2. `1.27 kN·m`
3. `7.64 kN·m`
4. `12.7 kN·m`
5. `120 kN·m`

### 正答

2

### 完全解説

回転角速度は

```text
ω = 2πN/60
  = 2π×3000/60
  = 314.159 rad/s
```

したがって

```text
T = P/ω
  = 400000/314.159
  = 1273 N·m
  = 1.27 kN·m
```

正答は2。`3000 min^-1` をそのまま `P=NT` に代入せず、`rad/s` へ換算する。

## 問2 高速域の定出力特性

共通教材用モデルで `N=5000 min^-1` とする。このときのトルクと出力の組合せとして正しいものを選べ。

1. `T=1200 N·m`、`P=377 kW`
2. `T=720 N·m`、`P=226 kW`
3. `T=600 N·m`、`P=377 kW`
4. `T=720 N·m`、`P=377 kW`
5. `T=1200 N·m`、`P=628 kW`

### 正答

4

### 完全解説

`5000 min^-1` は基準速度 `3000 min^-1` より高速なので定出力領域である。

```text
P_out = P_b = 376.991 kW
ω = 2π×5000/60 = 523.599 rad/s
T = 376991/523.599 = 720 N·m
```

正答は4。高速側で定出力なら、回転速度が上がるほどトルクは `1/N` に比例して低下する。

## 問3 電圧制限・電流制限と制御領域

三相かご形誘導電動機を変換装置で駆動する。解説sourceで扱うH26一次型の条件として最も適切なものを選べ。

1. 定加速域では `V` 一定、`I_M` 可変、`f_s` 一定とする。
2. 定加速域では `V/f` 一定、`I_M` 一定、`f_s` 可変とし、高速側で電圧上限に達した後は `V` 一定、`I_M` 一定、`f_s` 可変の定出力域として扱う。
3. 定出力域では速度上昇に合わせて `V` を無制限に増加させる。
4. 電圧制限と電流制限は同じ制約なので区別しない。
5. 高速域では必ず `I_M=0` とする。

### 正答

2

### 完全解説

解説sourceの固定条件では、低速側の定加速域は `V/f` 一定、`I_M` 一定、`f_s` 可変として扱う。速度上昇に伴い電圧が上限へ達した後は `V` をそれ以上増やせないため、`V` 一定、`I_M` 一定、`f_s` 可変の定出力域として読む。

電圧制限は高速側で電圧を増やせなくなる境界、電流制限は許容トルク側の制約である。正答は2。

## 問4 損失分類

回転機の損失について最も適切な記述を選べ。

1. 風損は冷却を助けるので損失には含めない。
2. 漂遊負荷損は負荷電流と無関係な固定損である。
3. 銅損は巻線電流により生じる損失である。
4. 固定損は部分負荷になると必ず0になる。
5. 機械損と無負荷鉄損を固定損として扱う問題は存在しない。

### 正答

3

### 完全解説

銅損は巻線電流による損失なので3が正しい。風損は機械損の一種であり、冷却との関係があっても損失である。漂遊負荷損は負荷電流に伴う追加的な負荷損である。固定損は負荷低下で直ちに0にはならない。問題によっては機械損と無負荷鉄損を固定損としてまとめる。

## 問5 入力・出力・全損失・効率

ある電動機の入力が `400 kW`、機械出力が `360 kW` である。全損失と効率の組合せとして正しいものを選べ。

1. `P_loss=40 kW`、`η=90.0%`
2. `P_loss=40 kW`、`η=111%`
3. `P_loss=760 kW`、`η=90.0%`
4. `P_loss=360 kW`、`η=10.0%`
5. `P_loss=40 kW`、`η=10.0%`

### 正答

1

### 完全解説

```text
P_loss = P_in-P_out
       = 400-360
       = 40 kW
```

効率は

```text
η = P_out/P_in
  = 360/400
  = 0.900
  = 90.0%
```

正答は1。効率を `P_in/P_out` と逆にしない。

## 問6 同期速度・滑り・機械トルク

4極、`50 Hz` の三相誘導電動機が `1440 min^-1` で回転し、機械出力が `30.0 kW` である。滑りと機械トルクの組合せとして最も近いものを選べ。

1. `s=0.0400`、`T=199 N·m`
2. `s=0.0400`、`T=20.8 N·m`
3. `s=0.960`、`T=199 N·m`
4. `s=-0.0400`、`T=199 N·m`
5. `s=0.0400`、`T=314 N·m`

### 正答

1

### 完全解説

```text
N_s = 120f/p
    = 120×50/4
    = 1500 min^-1
```

```text
s = (N_s-N)/N_s
  = (1500-1440)/1500
  = 0.0400
```

```text
ω = 2π×1440/60
  = 150.796 rad/s
T = 30000/150.796
  = 198.94 N·m
```

したがって正答は1。

## 問7 部分負荷の損失と効率

共通教材用モデルで出力を基準出力の `50%` とする。損失と効率の組合せとして最も近いものを選べ。

1. `P_loss=10.0 kW`、`η=94.9%`
2. `P_loss=20.0 kW`、`η=90.4%`
3. `P_loss=21.25 kW`、`η=89.9%`
4. `P_loss=25.0 kW`、`η=50.0%`
5. `P_loss=40.0 kW`、`η=82.5%`

### 正答

3

### 完全解説

50%出力なので

```text
P_out = 0.5P_b
      = 188.496 kW
```

損失モデルから

```text
P_loss = 15+25×0.5^2
       = 21.25 kW
```

入力は

```text
P_in = 188.496+21.25
     = 209.746 kW
```

したがって

```text
η = 188.496/209.746
  = 0.8987
  ≈ 89.9%
```

正答は3。出力が半分でも固定成分 `15 kW` が残るため、損失は全出力時 `40 kW` の半分 `20 kW` にはならない。

## 問8 簡略熱モデル

共通教材用モデルを全出力で運転し、損失を一定の `40 kW` とする。`R_th=0.80 K/kW`、`C_th=6000 kJ/K`、初期温度上昇 `θ_0=10 K` とする。定常温度上昇、時定数、30分後の温度上昇の組合せとして最も近いものを選べ。

1. `θ_ss=32 K`、`τ=80 min`、`θ(30 min)=16.9 K`
2. `θ_ss=50 K`、`τ=80 min`、`θ(30 min)=32 K`
3. `θ_ss=32 K`、`τ=8 min`、`θ(30 min)=31.5 K`
4. `θ_ss=40 K`、`τ=60 min`、`θ(30 min)=25 K`
5. `θ_ss=32 K`、`τ=80 min`、`θ(30 min)=32 K`

### 正答

1

### 完全解説

```text
θ_ss = R_th P_loss
     = 0.80×40
     = 32 K
```

```text
τ = R_th C_th
  = 0.80×6000
  = 4800 s
  = 80 min
```

30分 `=1800 s` 後は

```text
θ(t) = θ_ss+(θ_0-θ_ss)e^(-t/τ)
     = 32+(10-32)e^(-1800/4800)
     = 16.88 K
     ≈ 16.9 K
```

正答は1。30分ではまだ定常温度上昇に達していない。

# 二次試験型

## 問1 誘導電動機の滑り・トルク・損失・負荷変化

三相誘導電動機について次を仮定する。

- `f=50 Hz`
- `p=4`
- `N=1440 min^-1`
- `P_out=30.0 kW`
- `η=0.900`
- 負荷損は一次銅損と二次銅損だけとし、両者は等しい
- 機械損は無視する
- 低滑り域でトルクは滑りに比例する

(a) 同期速度、滑り、機械トルクを求めよ。

(b) 二次銅損、全損失、固定損を求めよ。

(c) 負荷トルクが50%になったときの滑り、回転速度、機械出力を求めよ。

### 完全解説

(a)

```text
N_s = 120×50/4
    = 1500 min^-1

s = (1500-1440)/1500
  = 0.0400

ω = 2π×1440/60
  = 150.796 rad/s

T = 30000/150.796
  = 198.94 N·m
```

(b) 機械損を無視するので `P_out=(1-s)P_2`。したがって

```text
P_c2 = {s/(1-s)}P_out
     = 0.04/0.96×30.0
     = 1.25 kW
```

一次銅損も条件より `1.25 kW`。

```text
P_in = P_out/η
     = 30.0/0.900
     = 33.333 kW

P_loss = 33.333-30.0
       = 3.333 kW

P_fixed = 3.333-1.25-1.25
        = 0.833 kW
```

(c) トルクが滑りに比例するという問題条件から

```text
s_2 = 0.0400×0.50
    = 0.0200
```

```text
N_2 = (1-s_2)N_s
    = 0.98×1500
    = 1470 min^-1
```

トルクは `T_2=198.94×0.50=99.47 N·m` なので

```text
P_out,2 = T_2×2πN_2/60
        = 99.47×2π×1470/60
        = 15.3125 kW
```

「一次銅損=二次銅損」「トルクは滑りに比例」は問題条件であり一般則ではない。

## 問2 加速時の短時間出力

慣性モーメント `J=60 kg·m^2`、角加速度 `dω/dt=5.0 rad/s^2`、負荷トルク `T_L=600 N·m`、その瞬間の角速度 `ω=150 rad/s` とする。

(a) 必要な電動機トルクを求めよ。

(b) その瞬間の機械出力を求めよ。

(c) この出力を連続定格と同一視してはいけない理由を、熱的制約と関連付けて説明せよ。

### 完全解説

(a)

```text
T_M = J dω/dt + T_L
    = 60×5.0+600
    = 900 N·m
```

(b)

```text
P = T_Mω
  = 900×150
  = 135000 W
  = 135 kW
```

(c) 加速中は負荷トルクに加えて慣性トルクが必要なため、短時間だけ定常運転より大きなトルク・出力を要求される場合がある。一方、連続定格は損失による発熱と冷却がつり合う熱平衡まで含めて継続可能な出力である。短時間負荷では温度上昇が定常値へ直ちに達しないが、許容温度・過負荷率・許容時間は問題文で与えられた条件だけを用いる。

## 問3 高速域の定出力と電圧・電流制限

共通教材用モデルについて、基準速度 `3000 min^-1` から `5000 min^-1` へ速度を上げる場合を考える。

(a) `3000 min^-1` と `5000 min^-1` のトルク・出力を求めよ。

(b) 高速側でトルクが低下する理由を `P=ωT` から説明せよ。

(c) 解説sourceで扱うH26一次型の条件に従い、定加速域と定出力域の `V`、`I_M`、`f_s` の扱いと、電圧制限・電流制限の役割を説明せよ。

### 完全解説

(a) 基準速度では

```text
T_3000 = 1200 N·m
P_3000 = (2π×3000/60)×1200
       = 376.991 kW
```

`5000 min^-1` は定出力領域なので

```text
P_5000 = 376.991 kW
ω_5000 = 2π×5000/60
       = 523.599 rad/s
T_5000 = 376991/523.599
       = 720 N·m
```

(b) 定出力なら

```text
T = P/ω
```

であり、`ω` が上がるほど `T` は小さくなる。したがって高速側では出力をほぼ一定に保ちながらトルクが低下する。

(c) 解説sourceのH26一次型では、定加速域は `V/f` 一定、`I_M` 一定、`f_s` 可変として扱う。速度上昇で電圧が上限に達した後は `V` 一定、`I_M` 一定、`f_s` 可変の定出力域として扱う。電圧制限は高速側で電圧をそれ以上増加できない境界を作り、電流制限は許容電流を超えないようトルク側を制約する。

## 問4 損失・部分負荷効率・簡略熱モデル

共通教材用モデルについて答えよ。

(a) 全出力時と50%出力時の損失を求めよ。

(b) 50%出力時の効率を求め、固定損が部分負荷効率に与える影響を説明せよ。

(c) 全出力で損失 `40 kW` が一定とするとき、定常温度上昇、熱時定数、30分後の温度上昇を求めよ。

(d) 風損と冷却の関係を、R8一次型の観点から説明せよ。

### 完全解説

(a) 全出力時は

```text
P_loss,100 = 15+25×1^2
           = 40 kW
```

50%出力時は

```text
P_loss,50 = 15+25×0.5^2
          = 21.25 kW
```

(b)

```text
P_out,50 = 0.5×376.991
         = 188.496 kW

η_50 = P_out,50/(P_out,50+P_loss,50)
     = 188.496/(188.496+21.25)
     = 0.8987
     ≈ 89.9%
```

固定成分 `15 kW` は出力を半分にしても残る。そのため、部分負荷では出力に対する固定損の割合が相対的に大きくなり、効率低下の要因となる。

(c)

```text
θ_ss = R_th P_loss
     = 0.80×40
     = 32 K

τ = R_th C_th
  = 0.80×6000
  = 4800 s
  = 80 min

θ(1800) = 32+(10-32)e^(-1800/4800)
        = 16.88 K
        ≈ 16.9 K
```

(d) 風損は機械損の一種であり損失である。冷却作用があるからといって、電力収支から除外してよいわけではない。冷却は発生した熱を外部へ逃がす働きであり、損失そのものと区別して扱う。
