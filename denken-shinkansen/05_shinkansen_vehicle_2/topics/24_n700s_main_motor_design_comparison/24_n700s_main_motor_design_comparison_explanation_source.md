## 1. N700Sへ接続するときの事実境界

富士電機「2019年度の技術成果と展望」（富士電機技報 2020 vol.93 no.2）では、N700S営業車両向けに主変換装置・主電動機・主変圧器を納入したこと、主電動機を6極化したことが明記されている。また、SiC素子搭載、主電動機の6極化、主変圧器の冷却方式見直しを合わせ、駆動システム全体で約20%軽量化したとしている。

- 富士電機技報: https://www.fujielectric.co.jp/about/company/gihou_2020/pdf/93-02/FEJ93-02-000-2020.pdf
- 掲載箇所: 2020 vol.93 no.2, p.95（5）

ここから実車事実として使うのは次だけである。

- N700S向け主電動機が6極化された。
- 駆動システム全体で約20%軽量化された。
- 約20%は「SiC主変換装置＋主電動機6極化＋主変圧器冷却方式見直し」を合わせた結果であり、主電動機単体の軽量化率でも、6極化単独の寄与率でもない。

JR東海はN700Sについて、SiC素子駆動システム、車両軽量化、走行抵抗低減等を合わせてN700Aタイプ比で電力消費量を約7%削減したとしている。これも主電動機6極化単独の効果へ読み替えない。

- JR東海: https://company.jr-central.co.jp/sustainability/environment/contribution/

N700S主電動機の実運転周波数、実回転速度、実トルク、寸法、質量は本sourceで一次資料確認していないため、実値として置かない。以下の計算条件は、明記したものを除き教材用条件である。

## 2. 記号・単位

| 記号 | 意味 | 単位 |
|---|---|---|
| `P` | 極数 | 無次元（偶数） |
| `p=P/2` | 極対数 | 無次元 |
| `f` | 電源周波数 | Hz |
| `n_s` | 同期速度 | min^-1 |
| `n` | 回転子の実回転速度 | min^-1 |
| `s` | すべり | 無次元、%表記時は100倍 |
| `ω_s` | 同期角速度 | rad/s |
| `ω` | 回転子の機械角速度 | rad/s |
| `T` | トルク | N·m |
| `P_m` | 機械出力 | W |
| `θ_m` | 機械角 | rad または ° |
| `θ_e` | 電気角 | rad または ° |

極数の `P` と電力の記号を混同しない。本sourceでは電力は `P_m` と書く。

## 3. 極数・周波数・同期速度

### 3.1 同期速度

極対数を `p=P/2` とすると、回転磁界は電気1周期で機械角 `1/p` 回転分進む。1秒に `f` 周期、1分に `60f` 周期なので、同期速度は

`n_s = 60f/p = 120f/P`

となる。

逆算は

`f = P n_s / 120`

`P = 120f / n_s`

である。極数を逆算した場合は、物理的に成立する偶数極かを確認する。

同期角速度は

`ω_s = 2πn_s/60 = 2πf/p`

である。

### 3.2 何が変わるか

- `f` 一定なら、極数 `P` を増やすほど `n_s` は下がる。
- `P` 一定なら、周波数 `f` を上げるほど `n_s` は上がる。

N700Sで確認できる実車値は「6極」である。実運転周波数は確認していないため、6極と任意周波数から計算した値をN700S実回転速度とは呼ばない。

### 指定可視化A: 極数・周波数―同期速度

教材用比較値:

| `f [Hz]` | 4極 | 6極 | 8極 |
|---:|---:|---:|---:|
| 20 | 600 | 400 | 300 |
| 40 | 1200 | 800 | 600 |
| 60 | 1800 | 1200 | 900 |
| 80 | 2400 | 1600 | 1200 |

単位はすべて `min^-1`。グラフ化時は横軸 `f`、縦軸 `n_s`、系列を4極・6極・8極とする。

## 4. すべりと実回転速度

誘導電動機では回転磁界と回転子の速度差が必要である。すべりは

`s = (n_s - n)/n_s`

したがって

`n = (1-s)n_s`

となる。

通常の電動機運転では `0<s<1`。停止時は `s=1`、同期速度では `s=0` である。同期速度では相対速度がなくなるため、通常の誘導機では誘導電流・電磁トルクは0へ近づく。`s<0` は発電側に対応するが、回生の詳細はTopic 13の範囲なのでここでは展開しない。

百分率すべりは必ず小数へ直す。`3.5% = 0.035` であり、式へ `3.5` をそのまま入れない。

### 指定可視化B: すべり―実回転速度

教材用条件 `n_s=1200 min^-1` とする。

| `s` | `s [%]` | `n [min^-1]` |
|---:|---:|---:|
| 0.00 | 0 | 1200 |
| 0.01 | 1 | 1188 |
| 0.02 | 2 | 1176 |
| 0.03 | 3 | 1164 |
| 0.04 | 4 | 1152 |
| 0.05 | 5 | 1140 |

`n=(1-s)n_s` なので直線となる。この `1200 min^-1` は教材条件であり、N700S実運転点ではない。

## 5. 回転速度・トルク・機械出力

回転速度 `n [min^-1]` を機械角速度へ直すと

`ω = 2πn/60`

機械出力は

`P_m = ωT`

したがって

`T = P_m/ω = 60P_m/(2πn)`

`n = 60P_m/(2πT)`

で相互に逆算できる。

ここで使う回転速度は、軸の機械出力を求めるなら実回転速度 `n` であり、同期速度 `n_s` と取り違えない。また `kW` は `W` へ直してから代入する。

### Topic 21 H26二次 問1(4)の丸め注記

同型式 `P_m=ωT`, `ω=2πn/60` は変更しない。H26二次「機械・制御」問1(4)の公式標準解答 `48.1 N·m` と通常の `π` で得る `48.0 N·m` の差は、公式標準解答が `π=3.14` 相当の数値処理を用いた過去問固有丸め差として扱う。一般式を公式解答値に合わせて変更しない。

## 6. R7一次型に必要なトルク―すべりの最小橋渡し

Topic 24では等価回路全体を再展開しないが、固定R7一次「機械」問2を教材だけで解くため、Topic 10で検証済みの関係を最小限再掲する。

L形近似等価回路で、相電圧 `V_φ`、一次抵抗 `r_1`、一次換算二次抵抗 `r_2'`、合成漏れリアクタンス `X=x_1+x_2'` とすると、トルクは

`T(s) = 3V_φ^2(r_2'/s) / {ω_s[(r_1+r_2'/s)^2+X^2]}`

で表される。

同期速度近傍では `s` が小さく、固定回路定数のもとで

`T ∝ s`

となる。したがって同期速度 `s=0` でトルク0、低滑り域では滑り増加にほぼ比例してトルクが増える。

`y=r_2'/s` と置いて最大条件を求めると

`y = sqrt(r_1^2+X^2)`

したがって最大トルク時滑りは

`s_m = r_2'/sqrt(r_1^2+X^2)`

である。さらに `r_1` を無視できる近似では

`s_m ≈ r_2'/X`

となる。この近似モデルでは二次抵抗 `r_2'` を変えても最大トルクの大きさは変わらず、最大トルクを生じる滑り位置が `r_2'` に比例して移る。

同一トルクの対応点では

`r_2a'/s_a = r_2b'/s_b`

より

`s_b/s_a = r_2b'/r_2a'`

となる。これが比例推移である。問題文が別の等価回路・近似条件を指定する場合は、その条件へ合わせる。

## 7. R2一次型に必要な `V/f` と磁束の最小橋渡し

Topic 12の制御全体は再展開しない。固定R2一次「機械」問3の答案要素に必要な関係だけを扱う。

交流機の誘起電圧は概略

`E ∝ fΦ`

である。固定子の電圧降下を無視できる範囲で `V≈E` とみなせば

`Φ ∝ V/f`

となる。したがって周波数を変えて同期速度を変えるとき、磁束を概ね一定に保つには `V/f` を概ね一定にする。

この節の目的は「周波数を変えると速度だけでなく磁束条件も変わる」ことを固定過去問へ接続することであり、PWM、基底速度、定トルク・定出力制御はTopic 12へ戻す。

## 8. 機械角と電気角

極対数 `p=P/2` の回転機では、機械角と電気角の一般関係は

`θ_e = pθ_m = (P/2)θ_m`

である。1機械回転に対して電気的には `p` 周期進む。

例: 6極なら `p=3`。機械角 `20°` の変化は

`θ_e = 3×20° = 60°`

となる。

これはSPEC必須の一般関係であり、今回固定した第二種5問の答案要素として直接出題されたと主張しない。また、誘導機のすべり周波数と機械位置に対する電気角を混同しない。

## 9. 条件変更問題の解法アルゴリズム

1. 極数 `P` と周波数 `f` を確認し、`n_s=120f/P` を求める。
2. すべりが%なら小数へ直し、`n=(1-s)n_s` を求める。
3. 角速度が必要なら `ω=2πn/60` へ変換する。
4. 出力とトルクは `P_m=ωT` で結ぶ。
5. トルク―すべり特性を問う場合だけ§6の近似条件を確認する。
6. 磁束条件を問う場合だけ§7の `Φ∝V/f` を使う。
7. 条件変更後も同じ量が一定とは限らない。問題文で何を一定としたかを確認する。
8. 最後に `P` と `p`、`n_s` と `n`、%と小数、WとkWを検算する。

### 指定可視化C: 条件変更時の速度比較

すべりを全ケース `3%` に固定した教材用比較:

| ケース | 極数 `P` | `f [Hz]` | `n_s [min^-1]` | `n [min^-1]` |
|---|---:|---:|---:|---:|
| A | 4 | 60 | 1800 | 1746 |
| B | 6 | 60 | 1200 | 1164 |
| C | 6 | 75 | 1500 | 1455 |
| D | 8 | 75 | 1125 | 1091.25 |

A→Bは同一周波数で極数増加、B→Cは同一極数で周波数増加、C→Dは同一周波数で極数増加を比較できる。6極という極数だけはN700Sで確認済みだが、60 Hz・75 Hz・3%すべりは教材用条件であり、N700S実運転点ではない。

## 10. 3段階例題

### 10.1 基礎例題 — 同期速度とすべり

6極、60 Hzの誘導電動機が `1158 min^-1` で回転している。同期速度とすべりを求める。

極数・周波数から同期速度を先に求める。

`n_s = 120×60/6 = 1200 min^-1`

次に

`s = (1200-1158)/1200 = 0.035 = 3.5%`

答: `n_s=1200 min^-1`, `s=3.5%`。

この条件は固定R7二次問題と同じ数値であり、N700S実運転値ではない。

### 10.2 本試験標準例題 — R7二次型

定格出力 `22 kW`、60 Hz、6極、定格回転速度 `1158 min^-1` の誘導電動機を考える。低滑り域でトルクがすべりに比例するとし、トルクを定格の50%へ下げたときの回転速度と機械出力を求める。

まず

`n_s=1200 min^-1`

` s_1=0.035 `

定格トルクは

`T_1 = 22000/(2π×1158/60) = 181.4... N·m ≒ 181 N·m`

低滑り域 `T∝s` より

`s_2=0.5s_1=0.0175`

`n_2=(1-0.0175)×1200=1179 min^-1 ≒ 1180 min^-1`

`T_2=0.5T_1`

`P_2=T_2×2πn_2/60 = 1.1199×10^4 W ≒ 11200 W`

答: `1180 min^-1`, `11200 W`。

計算順は「同期速度→すべり→トルク→条件変更後すべり→実回転速度→出力」で固定する。

### 10.3 複合・ひっかけ例題 — 極数変更と電気角

60 Hz、4極、すべり3%の条件Aと、60 Hz、6極、すべり3%の条件Bを比較する。また、各機械角 `30°` の変化に対応する電気角を求める。

条件A:

`n_sA=120×60/4=1800 min^-1`

`n_A=0.97×1800=1746 min^-1`

`p_A=2` なので `θ_eA=2×30°=60°`

条件B:

`n_sB=120×60/6=1200 min^-1`

`n_B=0.97×1200=1164 min^-1`

`p_B=3` なので `θ_eB=3×30°=90°`

同一周波数・同一すべりでも極数を増やすと同期速度・実回転速度は下がる。一方、同じ機械角変化に対応する電気角は極対数に比例して増える。

## 11. 頻出ミス

- 極数 `P` と極対数 `p=P/2` を取り違える。
- `n_s=120f/P` の `P` を出力と読む。
- 同期速度 `n_s` と実回転速度 `n` を混同する。
- すべり `3.5%` を `3.5` のまま代入する。
- `P_m=ωT` で `n_s` を使い、実軸速度 `n` を使わない。
- `min^-1` を `rad/s` へ直さず `P_m=ωT` へ代入する。
- `kW` をWへ変換しない。
- 低滑り域の `T∝s` を全運転域へ無条件に延長する。
- 二次抵抗を増やすと最大トルクそのものも増える、と近似条件を無視して判断する。
- `V/f` 一定を「周波数を変えても電圧一定」と取り違える。
- N700Sの6極という確認済み事実から、未確認の実周波数・実回転速度・実トルクを逆算して実値扱いする。
- 駆動システム約20%軽量化を、主電動機単体または6極化単独の20%軽量化と読む。

## 13. 公式・解法まとめ

`p=P/2`

`n_s=120f/P=60f/p`

`ω_s=2πn_s/60=2πf/p`

`s=(n_s-n)/n_s`

`P_m=ωT`

`T=60P_m/(2πn)`

`θ_e=pθ_m=(P/2)θ_m`
