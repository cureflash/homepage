## 問1 同期速度と同期角速度

4極、極対数 `p=2` の三相誘導電動機を `f=60 Hz` で運転する。同期速度 `n_s` と同期角速度 `ω_s` の組合せとして最も近いものを選べ。

1. `n_s=900 rpm`, `ω_s=94.2 rad/s`
2. `n_s=1200 rpm`, `ω_s=125.7 rad/s`
3. `n_s=1500 rpm`, `ω_s=157.1 rad/s`
4. `n_s=1800 rpm`, `ω_s=188.5 rad/s`
5. `n_s=3600 rpm`, `ω_s=377.0 rad/s`

### 正答

4

### 完全解説

極数を `P=4` とすると

```text
n_s = 120f/P
    = 120×60/4
    = 1800 rpm
```

極対数 `p=2` を使う角速度表示では

```text
ω_s = 2πf/p
    = 2π×60/2
    = 188.5 rad/s
```

よって正答は4。`P` と極対数 `p=P/2` を混同しない。

## 問2 すべりと電動機運転

4極誘導電動機を `50 Hz` で運転し、回転子速度が `1440 rpm` である。すべりと運転状態の組合せとして正しいものを選べ。

1. `s=-0.040`、同期速度より高速、正トルクの電動機運転
2. `s=0`、同期速度と一致、最大正トルク
3. `s=0.040`、同期速度より低速、正トルクの電動機運転
4. `s=0.060`、同期速度より低速、トルク0
5. `s=0.960`、同期速度より低速、トルク0

### 正答

3

### 完全解説

同期速度は

```text
n_s = 120×50/4
    = 1500 rpm
```

すべりは

```text
s = (n_s-n)/n_s
  = (1500-1440)/1500
  = 0.040
```

`0<n<n_s` なので正すべりであり、本テーマで扱う電動機運転側では正トルクとなる。同期速度ではすべり0で、理想化したトルク―速度特性の読み取りではトルク0の速度として使う。正答は3。

## 問3 V/f一定と磁束

教材用仮定として、基底周波数 `50 Hz`、基底電圧 `400 V` の誘導電動機を考える。固定子電圧降下を無視できる範囲で `30 Hz` としたときの指令電圧と磁束の説明として最も適切なものを選べ。

1. `V=160 V`、`V/f` が低下するので磁束は必ず0になる。
2. `V=240 V`、`V/f` を一定に保つので磁束は概ね一定に保てる。
3. `V=300 V`、周波数だけで磁束が決まり電圧は無関係である。
4. `V=400 V`、全速度域で電圧を一定にするのがV/f一定制御である。
5. `V=600 V`、周波数低下時ほど電圧を上げる。

### 正答

2

### 完全解説

基底点の比は

```text
V/f = 400/50 = 8 V/Hz
```

したがって30 Hzでは

```text
V = 8×30 = 240 V
```

誘導起電力を `E≈4.44fNΦ`、かつ固定子電圧降下を無視して `V≈E` とみれば `Φ∝V/f` である。よってV/fを一定にすると磁束を概ね一定に保てる。正答は2。

## 問4 低周波始動

インバータで誘導電動機を低周波から始動するときの説明として最も適切なものを選べ。

1. 低周波では固定子抵抗降下の影響が相対的に大きくなるため、必要に応じ低周波側の電圧を補正して磁束・始動トルクを確保する。また周波数を低い値から連続的に上げることで大きな始動電流を抑えやすい。
2. 低周波ほど固定子抵抗降下は必ず0になるので、端子電圧を0 Vにしても定格トルクが得られる。
3. 始動時は周波数を定格値へ固定し、電圧だけを0から上げることがVVVFの定義である。
4. 低周波ではV/fを大きく崩すほど磁束が必ず一定になる。
5. 始動電流は周波数・電圧の調整とは無関係である。

### 正答

1

### 完全解説

低周波では端子電圧が小さいため、固定子巻線の抵抗降下を無視しにくい。単純な `V∝f` だけでは誘導起電力が不足し、磁束と始動トルクが不足し得る。そのため必要に応じ低周波側の電圧を補正する。またインバータなら低い周波数から連続的に周波数を上げ、それに合わせて電圧を調整できるため、直接投入のような大きな始動電流を避けやすい。正答は1。

## 問5 定加速域・定トルク側の条件

H26型の条件判定として、基底速度までの定加速域・定トルク側の組合せで正しいものを選べ。

1. `V/f一定`、`I_M一定`、`f_s可変`
2. `V一定`、`I_M一定`、`f_s可変`
3. `V/f一定`、`I_M=0`、`f_s一定`
4. `V一定`、`I_M可変`、`f_s=0`
5. `V/f低下`、`I_M=0`、`f_s可変`

### 正答

1

### 完全解説

電圧上限へ達する前は、V/fを概ね一定にして磁束を概ね一定に保ち、主電動機電流を制限内で概ね一定条件とすることで定トルク側を作る。H26型ではこの領域を

```text
V/f一定・I_M一定・f_s可変
```

と読む。正答は1。`f_s` を一定と決めつけない。

## 問6 定出力域の条件

電圧上限へ達した後の定出力域について、H26型の条件判定として正しいものを選べ。

1. `V/f一定`、`I_M一定`、`f_s可変`
2. `V一定`、`I_M一定`、`f_s可変`
3. `V=0`、`I_M一定`、`f_s一定`
4. `V増加`、`I_M=0`、`f_s可変`
5. `V一定`、`I_M=0`、`f_s=0`

### 正答

2

### 完全解説

電圧上限到達後は周波数を上げても電圧を増やせないため

```text
V = V_max
```

となり、`V/f` は低下して磁束が弱まる。電流制限内で運転すると許容トルクは速度上昇に伴い低下し、理想化すれば `P=ωT` が概ね一定となる。H26型の条件は

```text
V一定・I_M一定・f_s可変
```

である。正答は2。

## 問7 電圧上限後のトルク

教材用仮定として、基底速度 `n_b=1440 rpm`、基底トルク `T_b=900 N·m` とする。基底速度後は定出力近似とする。`n=2160 rpm` におけるトルクとして最も近いものを選べ。

1. `400 N·m`
2. `600 N·m`
3. `900 N·m`
4. `1200 N·m`
5. `1357 N·m`

### 正答

2

### 完全解説

基底点の機械出力は

```text
P_b = (2π×1440/60)×900
    = 135.7 kW
```

定出力近似では

```text
T = P_b/ω
```

なので

```text
T = 135.7×10^3 /(2π×2160/60)
  = 600 N·m
```

となる。あるいは `T=T_b n_b/n` から `900×1440/2160=600 N·m` と求めてもよい。高速側で900 N·mを維持すると定出力近似にならない。正答は2。

## 問8 VVVFと誘導電動機

電気鉄道用のVVVFインバータ駆動について最も適切なものを選べ。

1. VVVFインバータは三相かご形誘導電動機へ与える交流の周波数と電圧を可変にでき、PWMは所要の基本波電圧・周波数を作る手段として用いられる。
2. VVVFは直流直巻電動機の界磁抵抗だけを連続可変にする装置である。
3. VVVFでは周波数を変えても同期速度は変化しない。
4. PWMを用いると出力は必ず直流になり、誘導電動機は駆動できない。
5. 三相かご形誘導電動機ではすべりを定義できない。

### 正答

1

### 完全解説

VVVFはVariable Voltage Variable Frequencyのとおり、誘導電動機へ与える交流電圧と周波数を可変にする。周波数は `n_s=120f/P` により同期速度へ直結し、電圧はV/fと磁束・トルク条件へ関係する。PWMは本テーマでは、インバータが所要の基本波電圧と周波数を作る手段として扱う。正答は1。

## 問9 同期速度・すべり・機械出力

教材用仮定として、6極三相誘導電動機を `45 Hz` で運転し、すべり `s=0.030`、電磁トルクを簡略的に軸トルクとみなして `T=700 N·m` とする。次を求めよ。

1. 同期速度 `n_s`
2. 同期角速度 `ω_s`
3. 回転子速度 `n`
4. 回転子角速度 `ω_m`
5. 機械出力 `P=ω_mT`
6. この運転点が正すべりの電動機運転側であることを確認せよ。

### 完全解説

極数 `P=6`、極対数 `p=3` である。

(1)

```text
n_s = 120f/P
    = 120×45/6
    = 900 rpm
```

(2)

```text
ω_s = 2πf/p
    = 2π×45/3
    = 94.25 rad/s
```

(3)

```text
n = (1-s)n_s
  = 0.970×900
  = 873 rpm
```

(4)

```text
ω_m = (1-s)ω_s
    = 0.970×94.25
    = 91.42 rad/s
```

(5)

```text
P = ω_m T
  = 91.42×700
  = 6.40×10^4 W
  = 64.0 kW
```

(6) `0<s=0.030<1` かつ `873<900 rpm` なので、同期速度より低速の正すべり側である。本テーマの電動機運転側の条件と一致する。

## 問10 定トルク域から定出力域への移行

教材用仮定として、基底周波数 `f_b=50 Hz`、電圧上限 `V_max=400 V`、基底速度 `n_b=1440 rpm`、基底トルク `T_b=800 N·m` とする。基底速度までは定トルク、基底速度後は定出力近似とする。次を求め、領域条件を説明せよ。

1. `25 Hz` におけるV/f一定指令電圧
2. 基底点の機械出力
3. `1920 rpm` における定出力近似トルク
4. 基底速度までの `V, I_M, f_s` の条件
5. 基底速度後の `V, I_M, f_s` の条件

### 完全解説

(1) 基底点のV/fは `400/50=8 V/Hz` なので

```text
V = 8×25
  = 200 V
```

(2)

```text
P_b = (2π×1440/60)×800
    = 120.6 kW
```

(3) 定出力近似なので

```text
T = T_b n_b/n
  = 800×1440/1920
  = 600 N·m
```

(4) 基底速度までの定加速域・定トルク側は

```text
V/f一定・I_M一定・f_s可変
```

と読む。

(5) 電圧上限到達後の定出力側は

```text
V一定・I_M一定・f_s可変
```

と読む。高速側までV/f一定を延長すると、電圧上限条件に反する。

## 問11 インバータ始動の記述

誘導電動機をインバータで始動するとき、一次周波数を低い値から定格値まで連続的に上げる方法について、次の2点を理由付きで説明せよ。

1. 低周波側で端子電圧を単純比例V/fだけでなく必要に応じ補正する理由
2. この始動法が大きな始動電流の抑制に有利な理由

### 完全解説

(1) 誘導起電力は概ね

```text
E ≈ 4.44 f N Φ
```

であり、固定子電圧降下を無視できる範囲では `Φ∝V/f` とみなせる。しかし低周波では端子電圧自体が小さく、固定子抵抗による電圧降下の割合を無視しにくい。単純比例V/fだけでは実際に磁束を作る誘導起電力が不足し、磁束と始動トルクが不足し得るため、必要に応じ低周波側の電圧を補正する。

(2) インバータなら始動時から周波数を低い値に設定し、電圧も磁束条件に合わせて調整しながら連続的に周波数を上げられる。したがって定格周波数・定格電圧を直接投入する場合のような大きな始動電流を避け、始動電流を抑制しながら必要な始動トルクを確保できる。

H30二次型では「磁束・始動トルクの維持」と「始動電流の抑制」の両方を理由付きで書くことが採点点になる。

## 問12 トルク―速度特性の読み取り

4極誘導電動機を `50 Hz` で運転している。正トルク側のトルク―速度特性で、トルクが0になる同期速度を求める。また `n=1440 rpm`、`T=600 N·m` の運転点について、次を求めよ。

1. 同期速度 `n_s`
2. すべり `s`
3. 運転状態の判定
4. 機械出力 `P=2πnT/60`

### 完全解説

(1)

```text
n_s = 120×50/4
    = 1500 rpm
```

理想化したトルク―速度特性では、すべり0となる同期速度がトルク0の速度である。

(2)

```text
s = (1500-1440)/1500
  = 0.040
```

(3) `n<n_s` で `s>0`、かつ問題文で正トルク側なので正すべりの電動機運転側である。

(4)

```text
P = (2π×1440/60)×600
  = 90.5 kW
```

同期速度の位置、すべりの符号、トルクの符号を順に確認して運転状態を判定する。
