## 教材で欠落不可の説明

1. VVVFインバータは誘導電動機へ与える交流の周波数と電圧を可変にし、周波数で同期速度、電圧との組合せで磁束・トルク条件を制御することを示す。
2. 極数 `P` の誘導電動機について `n_s=120f/P`、極対数 `p=P/2` なら `ω_s=2πf/p` を示し、周波数から同期速度を求められるようにする。
3. `s=(n_s-n)/n_s` と `n=(1-s)n_s` を示し、電動機運転域で回転子速度が同期速度より低いことをトルク―速度特性へ接続する。
4. 磁束が概ね `V/f` に比例するため、電圧制限に達するまではV/fを一定に保つ考え方を説明する。低周波域では巻線電圧降下を無視できず、単純比例だけでは始動トルクが不足し得ることをH30二次の記述要求へ接続する。
5. 基底速度まではV/f一定と電流制限の範囲で磁束を概ね一定に保ち、定トルク領域として扱うことを説明する。
6. 電圧上限に達した後は周波数を上げても電圧を増やせず磁束が弱まるため、電流制限下でトルクを下げ、`P=ωT` により概ね定出力領域へ移ることを説明する。
7. 電圧制限は周波数―電圧特性の折点、電流制限は低速側の最大トルク条件として扱い、両者を回転速度―トルク・回転速度―出力へつなぐ。

9. SPEC指定4可視化を本文から直接作れるよう、`f→n_s`、`f→V`、速度→トルク、速度→出力の計算手順と成立条件を説明する。

# 解説本文

## 1. このテーマで電験二種は何を問うか

VVVFインバータと誘導電動機の問題では、インバータが「電圧と周波数を変える装置」と分かるだけでは足りない。一次試験では同期速度、すべり、V/f一定、定トルク域・定出力域、電圧・電流制限を選択肢へ落とせること、二次試験ではインバータ始動の方法と利点を理由付きで記述できることが必要である。

本テーマの解法順序は次に固定する。

1. 極数と周波数から同期速度を求める。
2. すべりから回転子速度を求める、または逆算する。
3. 周波数に対して必要な電圧をV/f条件から決める。
4. 電圧上限に達したかを判定し、定トルク域か定出力域かを分ける。
5. 電流制限から許容トルクの上限を判断する。
6. `P=ωT` で速度―トルクと速度―出力を結ぶ。

## 2. VVVFインバータとPWMの役割

300系の主電動機駆動を題材に、本テーマでは「VVVFインバータ→三相かご形誘導電動機」という最小構成だけを使う。VVVFは Variable Voltage Variable Frequency のとおり、誘導電動機へ与える交流電圧と周波数を可変にする。

PWMは、直流から所要の交流基本波を作るためにスイッチングのパルス幅を変える手段として扱う。出力基本波の周波数を変えれば同期速度が変わり、基本波電圧を周波数と組み合わせて変えれば磁束条件を調整できる。本テーマではTopic 11のPWMコンバータで扱った高調波、力率制御、直流中間電圧制御を再展開しない。

## 3. 周波数と同期速度

極数を `P`、電源周波数を `f [Hz]` とすると、同期速度は

`n_s = 120 f / P [rpm]`

である。極対数を `p=P/2` とすれば、同期角速度は

`ω_s = 2π f / p [rad/s]`

となる。

例えば4極機を50 Hzで運転すると

`n_s = 120×50/4 = 1500 rpm`

である。極数 `P=4` と極対数 `p=2` を混同しないことが第一の典型ミスである。

トルク―速度特性で電動機側のトルクが0へ近づく基準速度は同期速度である。R4一次型では、グラフ上のこの交点を読めることが必要になる。

## 4. すべりと回転子速度

同期速度 `n_s` と回転子速度 `n` の差を無次元化した量がすべりである。

`s = (n_s - n) / n_s`

したがって

`n = (1-s)n_s`

である。角速度でも

`ω_m = (1-s)ω_s`

となる。

本テーマで扱う電動機運転では `0<s<1` であり、`n<n_s` となる。正のすべりをもつ電動機側では正トルクを発生する領域として読む。回生・発電側の象限はTopic 13で扱うため、ここでは展開しない。

すべり周波数は電源周波数との差を表す量で、問題文の記号に従えば `f_s` と書かれることがある。同期速度 `n_s` の添字と混同せず、電源周波数 `f` との関係を区別する。

## 5. V/f一定と磁束

誘導電動機の一相の誘導起電力を概略

`E ≈ 4.44 f N Φ`

とみれば、巻線電圧降下を無視できる範囲では `V≈E` なので

`Φ ∝ V/f`

となる。したがって、電圧上限に達するまでは `V/f` を概ね一定に保つと磁束も概ね一定に保てる。

ここでの成立条件は、固定子抵抗等による電圧降下が端子電圧に比べ十分小さいことである。低周波では端子電圧自体が小さくなるため、この電圧降下を無視しにくい。単純に `V∝f` を0 Hz近くまで延長すると、実際に磁束を作る誘導起電力が不足し、始動トルクが不足し得る。

## 6. 低周波始動と電圧補正

インバータ始動では、一次周波数を低い値から連続的に上げ、それに対応して電圧を調整する。低周波域では固定子巻線の抵抗降下の比率が大きくなるため、単純な比例V/fだけでなく、必要に応じて低周波側の電圧を補正して磁束と始動トルクを確保する。

H30二次型で理由付きに書く要点は次の二つである。

1. 周波数と電圧を合わせて調整することで磁束を維持し、始動トルクを確保できる。
2. 始動時から周波数を連続的に上げられるため、直接投入のような大きな始動電流を避け、始動電流を抑制できる。

固定EXAM_ALIGNMENTでは、公式標準解答との照合で「概ね定格の2倍以下へ始動電流を抑制できる」点を品質ゲート対象に含めている。本テーマではこの公式答案要素を超えて実車固有の制御定数は追加しない。

## 7. 基底速度までの定トルク領域

電圧上限へ達するまでの領域では、V/fを概ね一定に保つことで磁束を概ね一定にできる。さらに主電動機電流を電流制限内に保つと、許容トルクを概ね一定に置けるため、低速側を定トルク領域として扱う。

試験上は次の対応で読む。

- 周波数 `f`: 上昇
- 電圧 `V`: `V/f` 一定となるよう上昇
- 主電動機電流 `I_M`: 制限値以内で概ね一定条件
- トルク `T`: 概ね一定
- 出力 `P=ωT`: 速度とともに増加

H26一次型の「定加速域」では、問題文の条件として `V/f一定・I_M一定・すべり周波数 f_s 可変` を読み分ける。ここで `f_s` を一定と決めつけない。

## 8. 電圧上限後の定出力領域

周波数を上げ続けると、やがてインバータの出力電圧が上限へ達する。ここから先は

`V = V_max`

のまま `f` だけが増えるため、`V/f` は低下し、磁束は弱くなる。電流を上限以内に保つ条件では、速度上昇とともに許容トルクを下げる必要がある。

機械出力は

`P = ωT`

なので、理想化して出力を一定とみなすと

`T = P/ω`

となり、トルクは速度に反比例して低下する。これが定出力領域の基本形である。

試験上は次の対応で読む。

- 周波数 `f`: 上昇
- 電圧 `V`: 上限で一定
- 主電動機電流 `I_M`: 制限値以内で概ね一定条件
- 磁束: `V/f` 低下に伴い弱まる
- トルク `T`: 低下
- 出力 `P`: 概ね一定

H26一次型の定出力域は、問題文の条件として `V一定・I_M一定・すべり周波数 f_s 可変` と読む。

## 9. 電圧制限・電流制限と4特性

電圧制限と電流制限は別の役割を持つ。

- 電圧制限: 周波数―電圧特性の折点を決める。折点まではV/f一定、折点後は電圧一定になる。
- 電流制限: 許容トルクの上限を決める。磁束を概ね一定に保てる低速側では、電流上限が定トルク側の上限へつながる。

これをSPEC指定4可視化へ接続すると次の形になる。

1. 周波数―同期速度: `n_s=120f/P` なので原点を通る直線。
2. 周波数―電圧: 基底周波数まではV/f一定の直線、以後は `V_max` で水平。
3. 回転速度―トルク: 基底速度までは概ね一定、以後は定出力近似なら `1/ω` で低下。
4. 回転速度―出力: 定トルク域では速度に比例して上昇し、定出力域では概ね一定。

## 10. 本試験での条件判定

H26一次型のような文章問題では、式計算より先に領域を判定する。

### 定加速域・定トルク側

`V/f一定`、`I_M一定`、`f_s可変`

### 定出力側

`V一定`、`I_M一定`、`f_s可変`

「高速側でもV/f一定」と読んだ時点で誤りである。電圧上限に達した後は `V` を増やせないため、`V/f` は低下する。

R4一次型のトルク―速度特性では、トルク0の速度を同期速度として読み、同期速度より低い側で正すべり・正トルクとなる電動機運転を判定する。

## 11. 問題を見たときの解法手順

### 同期速度・すべり型

1. 極数 `P` か極対数 `p` かを確認する。
2. `n_s=120f/P` または `ω_s=2πf/p` を選ぶ。
3. `s=(n_s-n)/n_s` または `n=(1-s)n_s` を使う。
4. 電動機運転なら `n<n_s` になっているか検算する。

### V/f・領域判定型

1. 基底周波数または電圧上限条件を確認する。
2. 電圧上限前ならV/f一定で電圧を求める。
3. 電圧上限後なら `V=V_max` とする。
4. 低速側を定トルク、高速側を定出力近似として区別する。
5. 電流制限を超えるトルクを仮定していないか確認する。

### 出力・トルク型

1. rpmを `ω=2πn/60` でrad/sへ直す。
2. `P=ωT` を使う。
3. 定出力域なら `T=P/ω` でトルク低下を求める。
4. WとkW、rpmとrad/sを混同していないか検算する。

## 12. 3段階例題

### 12.1 基礎例題 — 同期速度とすべり

4極誘導電動機を50 Hzで運転し、すべりが `s=0.040` のとき、同期速度 `n_s` と回転子速度 `n` を求める。

同期速度は

`n_s = 120×50/4 = 1500 rpm`

回転子速度は

`n = (1-0.040)×1500 = 1440 rpm`

である。電動機運転なので `1440<1500` となり、正すべりであることも確認できる。

### 12.2 本試験標準例題 — V/f一定域の電圧・速度・出力

教材用仮定として、4極誘導電動機、基底周波数 `50 Hz`、基底電圧 `400 V` とする。`f=30 Hz`、すべり `s=0.030`、トルク `T=900 N·m` で運転するとき、V/f一定指令電圧、同期速度、回転子速度、機械出力を求める。これらは300系の実車値ではない。

V/f一定より

`V = 400×30/50 = 240 V`

同期速度は

`n_s = 120×30/4 = 900 rpm`

回転子速度は

`n = (1-0.030)×900 = 873 rpm`

角速度は

`ω = 2π×873/60 = 91.42 rad/s`

したがって機械出力は

`P = ωT = 91.42×900 = 82.3 kW`

となる。30 Hzは基底周波数50 Hzより低いので、電圧を400 VのままにせずV/f一定域として240 Vを使う。

### 12.3 複合・ひっかけ例題 — 電圧上限と定出力域

教材用仮定として、基底周波数 `f_b=50 Hz`、電圧上限 `V_max=400 V`、基底速度 `n_b=1440 rpm`、基底トルク `T_b=900 N·m` とする。速度―トルク特性は、基底速度までは定トルク、基底速度後は定出力近似とする。これらは300系の実車値ではない。

まず25 Hzでは

`V = 400×25/50 = 200 V`

であり、V/f一定域である。

一方75 Hzで単純比例すると600 Vが必要になるが、電圧上限が400 Vなので

`V = 400 V`

に制限され、V/f一定ではなく定出力側へ入る。

基底点の出力は

`P_b = (2π×1440/60)×900`

`= 135.7 kW`

である。定出力近似で回転速度が `2160 rpm` のとき

`T = P_b / (2π×2160/60)`

`= 600 N·m`

となる。高速側でもV/f一定を延長して600 Vとすること、定出力域でトルクを900 N·mのままとすることが典型的な誤りである。

## 13. SPEC指定4可視化の計算条件

以下は教材図を作るための仮定値であり、300系の実車基底周波数、最大電圧、最大電流、制御定数ではない。

- 極数: `P=4`
- 周波数範囲: `0〜75 Hz`
- 基底周波数: `f_b=50 Hz`
- 電圧上限: `V_max=400 V`
- 基底速度: `n_b=1440 rpm`
- 定トルク値: `T_b=900 N·m`
- 基底出力: `P_b=2πn_bT_b/60=135.7 kW`

### 13.1 周波数―同期速度

`n_s(f)=120f/4=30f [rpm]`

### 13.2 周波数―電圧

`0<=f<=50 Hz`:

`V(f)=8f [V]`

`50<f<=75 Hz`:

`V(f)=400 V`

### 13.3 回転速度―トルク

`0<n<=1440 rpm`:

`T(n)=900 N·m`

`n>1440 rpm`:

`T(n)=P_b/(2πn/60)=900×1440/n [N·m]`

### 13.4 回転速度―出力

`P(n)=2πnT(n)/60`

したがって基底速度までは速度に比例して増え、基底速度後は `135.7 kW` で一定となる理想化特性を描く。
