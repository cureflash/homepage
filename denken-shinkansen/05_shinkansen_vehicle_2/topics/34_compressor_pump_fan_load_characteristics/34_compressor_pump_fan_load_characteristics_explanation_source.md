## 1. このテーマで電験二種は何を問うか

補機を電動機で駆動する問題では、機械側の必要出力と電動機側のトルク・速度・損失・制御を一つの系として結ぶことが重要である。

解法の基本順序は次の通り。

1. 負荷が必要とする軸出力又は負荷トルクを整理する。
2. 回転速度を `min^-1` から `rad/s` へ変換する。
3. `P=Tω` で出力・トルク・速度を相互変換する。
4. 誘導電動機なら同期速度とすべりを求める。
5. 定常状態では電動機トルクと負荷トルクが釣り合うことを確認する。
6. 効率から入力電力・損失を逆算する。
7. インバータ駆動なら周波数、電圧、同期速度、`V/f` の関係を確認する。
8. ポンプ・ファンは三種既習の負荷式を必要最小限だけ接続し、二種過去問で直接問われた式と混同しない。

## 2. 電動機出力と負荷トルク

回転機の機械出力は

`P = Tω`

である。

- `P [W]`: 軸出力
- `T [N·m]`: 軸トルク
- `ω [rad/s]`: 回転角速度

回転速度を `N [min^-1]` とすると

`ω = 2πN/60`

したがって

`P = 2πNT/60`

`T = 60P/(2πN)`

となる。

### 単位の確認

`N·m × rad/s` は仕事率 `W` になる。`min^-1` をそのまま `P=Tω` に代入してはいけない。

### Topic 21との固定境界

一般式 `P=Tω`、`ω=2πN/60` は変更しない。Topic 21のH26二次「機械・制御」問1(4)で生じる `48.1 N·m / 48.0 N·m` の差は、公式標準解答が `π=3.14` 相当の数値処理を用いた過去問固有の丸め差として扱う。

## 3. 定常状態・過渡状態・動作点

回転系を簡略化すると

`J dω/dt = T_m - T_L`

と書ける。

- `J`: 慣性モーメント
- `T_m`: 電動機トルク
- `T_L`: 負荷トルク

定常状態では `dω/dt=0` なので

`T_m = T_L`

である。電動機のトルク－速度特性と負荷のトルク－速度特性が交わる点が定常動作点になる。

- `T_m > T_L`: 加速
- `T_m < T_L`: 減速
- `T_m = T_L`: 定常速度

負荷特性は機器によって異なるため、問題文で与えられた特性を優先する。コンプレッサについて、本Topicでは圧力比や圧縮過程から独自の負荷式を追加しない。

### 過負荷耐量

電動機では、定格トルクより大きい最大トルクを出せる余裕を過負荷耐量として扱う。具体的な定義・数値は問題文の条件に従う。誘導電動機では停動トルクと定格トルクの比が判断材料になる場合がある。

## 4. 誘導電動機の同期速度とすべり

極数を `p`、電源周波数を `f [Hz]` とすると同期速度は

`N_s = 120f/p [min^-1]`

である。

実回転速度を `N` とするとすべりは

`s = (N_s-N)/N_s`

となる。

- 電動機運転: 通常 `0<s<1`
- 同期速度: `s=0`
- 回生・発電領域: `N>N_s` となるため `s<0`

R6一次「機械」問2の電気鉄道論点では、誘導電動機がブラシを必要としないこと、回生時に負のすべりとなることが重要である。

## 5. 誘導電動機のトルク特性

一次側へ換算した簡略等価回路から、誘導電動機トルクは代表的に

`T = (1/ω_0) · {3V_1^2(r'_2/s)} / {(r_1+r'_2/s)^2 + (x_1+x'_2)^2}`

の形で表せる。

- `ω_0`: 同期角速度
- `V_1`: 一相当たり一次電圧
- `r_1`: 一次抵抗
- `r'_2`: 一次換算二次抵抗
- `x_1+x'_2`: 合成漏れリアクタンス

この式でR7一次「機械」問2へ接続する要点は次の五つである。

1. 分子は `3V_1^2(r'_2/s)` を含む。
2. 電動機運転では `s>0` である。
3. 最大トルクを停動トルクと呼ぶ。
4. 二次抵抗 `r'_2` を変えると最大トルクを生じるすべりは変わるが、最大トルク値そのものは理想化した式では `r'_2` に依存しない。
5. 同期速度近傍の小すべり領域では、他の条件が一定なら `T∝s` と近似できる。

停動トルクを与えるすべりは

`s_t = ±r'_2/sqrt(r_1^2+(x_1+x'_2)^2)`

で表せる。

## 6. 効率・入力・損失

電動機効率を `η` とすると

`η = P_out/P_in`

したがって

`P_in = P_out/η`

`P_loss = P_in-P_out`

である。

二種の損失問題では、総損失を一括して終わらせず、問題文の条件に従って一次銅損、二次銅損、鉄損・機械損等の固定損へ分解する。

誘導電動機の二次側では、二次入力 `P_2`、二次銅損 `P_c2`、機械出力へ変換される電力 `P_m` の間に

`P_c2 = sP_2`

`P_m = (1-s)P_2`

が成り立つため

`P_c2 = {s/(1-s)}P_m`

と変形できる。機械損を別に与えられる場合は、軸出力と内部機械出力を混同しない。

## 7. インバータ駆動とV/f制御

誘導電動機の同期速度は `N_s=120f/p` なので、インバータで周波数 `f` を変えれば同期速度を連続的に変えられる。

低速から基底速度まで磁束をほぼ一定に保つ基本的な考え方は

`V/f = constant`

である。周波数を1/2にするなら、理想的なV/f一定制御では電圧も1/2にする。

R6一次「機械」問2では、主変換装置の半導体素子としてIGBT、誘導電動機のブラシレス性、回生時の負のすべり、V/f一定が接続する。

### PWM電圧形インバータの最小ブリッジ

R4二次「機械・制御」問3型では、三相整流器、直流中間回路、PWM電圧形インバータ、誘導電動機を順に追う。

理想的な三相全波整流で線間実効電圧を `V_LL` とすると

`E_d = 1.35V_LL`

直流側電力を `P_d` とすると

`I_d = P_d/E_d`

交流側を力率1の理想条件で扱うなら

`I_1 = P_d/(sqrt(3)V_LL)`

である。

直流電圧を `E_d`、正弦波PWMの変調率を `m` とし、問題文で相電圧基本波最大値が

`V_ph,peak = mE_d/2`

と定義される場合、線間基本波実効値は

`V_LL,rms = (sqrt(3)/sqrt(2))V_ph,peak`

へ変換する。係数は変調方式・定義に依存するため、問題文の定義を優先する。

## 8. ベクトル制御で問われる最小事項

H25一次「機械」問3へ接続するため、次だけを押さえる。

- 電動機出力はトルクと回転角速度の積 `P=Tω` である。
- 定常状態では、平均的には電動機トルクと負荷トルクが釣り合う。
- ベクトル制御では電流を磁束成分とトルク成分へ分けて扱う。
- 滑り角周波数 `ω_sl` を積分すると滑り角が得られる。

`θ_sl = ∫ω_sl dt`

この滑り角は座標変換・磁束方向の把握に用いられる。ここから先の詳細な制御器設計はTopic 34の固定範囲へ追加しない。

## 9. ポンプ動力 — 三種既習からの接続

H25一次「機械」問3ではファン・ポンプ用途が明示されるが、ポンプ水動力式そのものが固定二種過去問で問われたわけではない。本Topicでは負荷側から電動機軸出力へ接続するための既習事項として扱う。

密度 `ρ [kg/m^3]` の流体を流量 `Q [m^3/s]`、全揚程 `H [m]` で送る理想水動力は

`P_h = ρgQH`

である。

ポンプ効率を `η_p` とすると必要軸動力は

`P_shaft = P_h/η_p`

さらに電動機効率を `η_m` とすると電動機入力は

`P_in = P_shaft/η_m`

となる。

効率を掛ける向きを逆にしない。負荷が必要とする水動力から上流の入力へ戻るほど、損失分だけ必要電力は増える。

## 10. ファン動力と回転速度 — 相似則の条件付き利用

同一ファン、同一流体、幾何形状不変、相似運転が成り立つ範囲では、回転速度 `N` に対して代表的なファン相似則を

`Q ∝ N`

`Δp ∝ N^2`

`P ∝ N^3`

と表せる。

したがって速度比を `k=N_2/N_1` とすると

`Q_2/Q_1 = k`

`Δp_2/Δp_1 = k^2`

`P_2/P_1 = k^3`

となる。

また `P=Tω` より、同じ相似条件では

`T ∝ N^2`

となる。

これはファン負荷とインバータ速度制御を結ぶ有用な既習事項だが、固定二種5問で相似則そのものが直接出題されたとは扱わない。ダンパ、系統抵抗、効率変化、運転点変化が大きい場合は単純な三乗則を無条件に適用しない。

## 11. コンプレッサの扱い

コンプレッサも電動機駆動負荷として

- 必要軸出力
- 負荷トルク
- 回転速度
- 電動機効率
- インバータによる速度制御

の関係を扱える。

ただし本Topicでは、圧縮比、吸込・吐出圧力、断熱効率、ポリトロープ指数、冷媒物性から軸動力を導く式は追加しない。問題で負荷トルク又は必要軸出力が与えられたところから電気機器側を解く。

## 12. 新幹線への接続

新幹線車両には空気・液体を動かす補機が存在し、それらは電動機負荷として考えられる。本教材では未確認の実車定格値・圧力・流量・回転速度を置かず、次の一般化だけを用いる。

`補機負荷 → 必要軸出力・負荷トルク → 電動機 → インバータ → 電源`

この流れで、負荷側の必要出力が変わると電動機トルク・速度・入力電力がどう変わるかを追う。新幹線固有値を暗記することは試験要件にしない。

## 13. 解法アルゴリズム

### 13.1 出力・トルク・速度問題

1. 出力が入力か軸出力かを確認する。
2. `N [min^-1]` を `ω=2πN/60` へ変換する。
3. `P=Tω` から未知量を求める。
4. 効率があれば入力・出力の向きを確認して適用する。
5. `W`, `kW`, `N·m`, `rad/s` の単位を検算する。

### 13.2 誘導電動機問題

1. `N_s=120f/p` を求める。
2. `s=(N_s-N)/N_s` を求める。
3. 電動機運転か回生かを符号で判定する。
4. 小すべり近似を使える条件か確認する。
5. `P=Tω`、二次銅損、効率の式を必要な順に使う。

### 13.3 インバータ問題

1. 整流器・直流中間回路・インバータ・電動機の電力流れを整理する。
2. 三相交流と直流の電圧・電流定義を区別する。
3. PWMの相電圧最大値と線間実効値を変換する。
4. 周波数変更時に `V/f` がどう保たれるか確認する。
5. 周波数から同期速度へ戻して負荷速度との関係を確認する。

## 14. 3段階例題

### 14.1 基礎 — 出力からトルクを求める

仮定の補機用電動機が軸出力 `15 kW`、回転速度 `1500 min^-1` で運転している。軸トルクを求める。

`ω = 2π×1500/60 = 157.1 rad/s`

`T = 15000/157.1 = 95.5 N·m`

ここでは入力電力ではなく軸出力を使う。

### 14.2 本試験標準 — 誘導電動機の速度・トルク・入力

仮定の三相誘導電動機が `50 Hz`、4極、回転速度 `1440 min^-1`、軸出力 `30 kW`、効率 `90 %` で運転している。

同期速度:

`N_s = 120×50/4 = 1500 min^-1`

すべり:

`s = (1500-1440)/1500 = 0.040 = 4.0 %`

角速度:

`ω = 2π×1440/60 = 150.8 rad/s`

軸トルク:

`T = 30000/150.8 = 199 N·m`

入力電力:

`P_in = 30/0.90 = 33.3 kW`

出力と入力を取り違えないことが検算点である。

### 14.3 複合・ひっかけ — ファン速度制御とV/f

同一ファンを相似運転できる仮定条件で、60 Hz時の回転速度を基準に45 Hzへ下げる。極数・すべり率は近似的に一定とし、60 Hz時の軸動力を `18 kW`、45 Hz時の電動機効率を `88 %` とする。

速度比:

`k = 45/60 = 0.75`

相似則より軸動力は

`P_2 = 18×0.75^3 = 7.59 kW`

電動機入力は

`P_in = 7.59/0.88 = 8.63 kW`

またV/f一定制御なら、45 Hz時の電圧は60 Hz時の `0.75` 倍を基本とする。

誤りやすい点は、速度を25%下げたから動力も25%だけ下がると考えること、効率を掛けて入力を小さくしてしまうこと、相似則の成立条件を無視することである。

## 16. 頻出ミス

- `min^-1` を `rad/s` に直さず `P=Tω` へ入れる。
- 軸出力と電動機入力を混同する。
- 効率を掛ける方向・割る方向を逆にする。
- `N_s` と実回転速度 `N` を混同する。
- 回生なのに `s>0` とする。
- 最大トルク値と最大トルクを生じるすべりを混同する。
- 相電圧最大値と線間電圧実効値を混同する。
- 周波数だけを下げ、V/f一定の電圧条件を落とす。
- ファン相似則を成立条件なしに適用する。
- ポンプ水動力式・ファン相似則を固定二種過去問の直接出題式と誤記する。

## 17. 公式・解法まとめ

- `P=Tω`
- `ω=2πN/60`
- `N_s=120f/p`
- `s=(N_s-N)/N_s`
- 電動機運転: `s>0`
- 回生・発電領域: `s<0`
- 小すべり域: `T∝s`
- `η=P_out/P_in`

- 理想三相整流: `E_d=1.35V_LL`
- `P_h=ρgQH`（三種既習のポンプ負荷接続）
- ファン相似運転: `Q∝N`, `Δp∝N^2`, `P∝N^3`（条件付き）
