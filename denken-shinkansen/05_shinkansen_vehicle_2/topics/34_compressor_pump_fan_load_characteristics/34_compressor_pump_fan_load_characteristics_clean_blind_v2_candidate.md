## 独立再解答 candidate

### R7一次「機械」問2

- (1) `3V1^2`（ハ）
- (2) `s > 0`（ヌ）
- (3) `停動`（ル）
- (4) `r2'`（チ）
- (5) `比例する`（ワ）

根拠:
- 誘導機の一相等価回路から `T = [3V1^2(r2'/s)] / {ω0[(r1+r2'/s)^2+(x1+x2')^2]}`。
- 電動機領域では正の滑り。
- 最大トルクは停動トルクで、二次抵抗値を変えても最大値自体は変化しない。
- 同期速度近傍の小滑り領域では `T ∝ s`。

### R6一次「機械」問2

- (1) `誘導`（ヌ）
- (2) `s < 0`（ニ）
- (3) `ブラシ`（ヲ）
- (4) `Insulated Gate Bipolar Transistor`（カ）
- (5) `V1/f1`（チ）

根拠:
- 近年の鉄道車両では誘導電動機のインバータ駆動が一般的。
- 誘導機回生は回転速度が同期速度を上回るため `s<0`。
- 直流機の摩耗部品はブラシ。
- IGBT = Insulated Gate Bipolar Transistor。
- 定磁束近似の定トルク領域は `V/f` 一定制御。

### H25一次「機械」問3

- (1) `回転角速度`（ヨ）
- (2) `過負荷耐量`（イ）
- (3) `定常状態`（ニ）
- (4) `トルク成分`（ル）
- (5) `滑り角周波数の積分値`（ヘ）

根拠:
- 機械出力は `P = T_M ω_r`。
- ファン・ポンプのように加速トルクが短時間だけ必要な負荷では、連続容量を加速分まで過大化せず必要な短時間過負荷耐量を持たせるのが経済的。
- 一相等価回路は定常状態の平均特性を表す。
- ベクトル制御では一次電流をトルク成分と磁束成分に分離する。
- 磁束軸は回転子位置に滑り角 `∫ω_s dt` を加えて求める。

### R7二次「機械・制御」問2

与条件: `P1=22 kW`, `f=60 Hz`, `p=6`, `N1=1158 min^-1`, `η=87.5 %`。

同期速度:
`Ns = 120f/p = 1200 min^-1`

(1)
- `s1 = (1200-1158)/1200 = 0.035 = 3.50 %`
- `T1 = P1/ω1 = 22000 / [2π(1158/60)] = 181.4 N·m`

(2)
- 入力 `Pin = 22000/0.875 = 25142.9 W`
- 総損失 `= 3142.9 W`
- 二次銅損 `Pc2 = [s1/(1-s1)]P1 = 797.9 W ≈ 798 W`
- 一次銅損 = 二次銅損より、固定損 `Pf = 3142.9 - 2×797.9 = 1547 W ≈ 1.55 kW`

(3)
- `T2 = 0.5T1`、かつ小滑り域で `T∝s` より `s2=0.5s1=0.0175`
- `N2 = 1200(1-0.0175) = 1179 min^-1`
- `P2 = T2×2πN2/60 = 1.1199×10^4 W ≈ 11.2 kW`

答案要素:
1. `3.50 %`
2. `181.4 N·m`
3. `798 W`
4. `1.55 kW`
5. `1179 min^-1`
6. `11.2 kW`

### R4二次「機械・制御」問3

(1)
- 三相ダイオードブリッジ平均直流電圧 `Ed = (3√2/π)VLL`
- `Ed = (3√2/π)×220 = 297.1 V`

(2)
- 損失なしなので `Ed Id = 10 kW`
- `Id = 10000/297.1 = 33.66 A`

(3)
- 基本波力率1より `P = √3 VLL Ia`
- `Ia = 10000/(√3×220) = 26.24 A`

(4)
- 正弦波PWMで変調率 `m=0.9`、相電圧基本波波高値 `Vup = mEd/2`
- `Vup = 0.9×297.1/2 = 133.7 V`

(5)
- 線間基本波実効値 `Vuve = (√3/√2)Vup`
- `Vuve = 163.7 V`

(6)
- V/f一定なので25 Hz時の信号振幅は50 Hz時の1/2。
- `v*u25 = 0.45 sin(2π·25t)`（基準化キャリア振幅1）。
- 50 Hz信号に対して振幅 `0.9→0.45`、周期 `20 ms→40 ms`。提示された `v*u50` 4周期に対して `v*u25` は同じ時間幅に2周期を描く。

答案要素:
1. `297.1 V`
2. `33.66 A`
3. `26.24 A`
4. `133.7 V`
5. `163.7 V`
6. `25 Hz・振幅0.45（50 Hz時の1/2）`
