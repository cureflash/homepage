## 1. このテーマで電験二種は何を問うか

空調・電熱では、電気エネルギーがどれだけ熱へ変わるか、熱がどこから入りどこへ出るか、ヒートポンプが入力電力に対してどれだけ熱を運ぶかを式で追えることが重要である。

解法の基本順序は次の通り。

1. 熱量 `Q [J]` と熱流率 `Qdot [W]` を区別する。
2. 電気入力なら `Q=Pt`、抵抗発熱なら `Q=I²Rt` を使う。
3. 物体の温度変化なら `Q=mcΔT` を使う。
4. 壁・空気・放射による熱移動を熱収支の流入・流出項へ分ける。
5. 冷房・暖房の必要熱量を合計する。
6. ヒートポンプなら `COP=熱輸送量/入力仕事` から消費電力を求める。
7. 電熱器の効率 `η` とヒートポンプのCOPを混同しない。

## 2. 熱量・熱流率・電力

電力 `P [W]` は単位時間当たりのエネルギーであり、

`1 W = 1 J/s`

である。一定電力 `P` を時間 `t` だけ加えたエネルギーは

`Q = Pt`

となる。

抵抗 `R [Ω]` に電流 `I [A]` を流す抵抗加熱では

`P = I²R`

なので

`Q = I²Rt`

である。

R8一次「機械」問6では1時間の発熱量を問うため、`t=3600 s` を入れて

`Q = 3600RI² [J]`

となる。

### 単位での検算

`W×s = J`、`A²×Ω = W` なので、`I²Rt` の最終単位はJになる。時間をhのまま式へ入れる場合は、Jへ直すなら秒換算が必要である。

## 3. 顕熱と温度変化

質量 `m [kg]`、比熱容量 `c [J/(kg·K)]` の物体を `ΔT [K]` だけ温度変化させる顕熱は

`Q = mcΔT`

である。

電熱器から物体へ実際に伝わる割合を効率 `η` とすると

`Q_use = ηPt`

なので

`mcΔT = ηPt`

`ΔT = ηPt/(mc)`

となる。

R8問6の水加熱では、入力 `1 kW×600 s=600 kJ` の90%が水へ伝わるので有効熱量は `540 kJ`。水2 kg、比熱 `4.186 kJ/(kg·K)` から

`ΔT = 540/(2×4.186) = 64.5 K`

初温15℃なので最終温度は約79.5℃となる。

## 4. 熱の伝わり方

熱移動は固定過去問上、伝導・対流・放射の三つを区別する。

### 4.1 熱伝導

厚さ `L [m]`、熱伝導率 `k [W/(m·K)]`、面積 `A [m²]` の平板で、両面温度差が `ΔT` のとき、一次元定常熱伝導は

`Qdot_cond = kAΔT/L`

である。

R8問6では `k=0.04 W/(m·K)`、`L=0.1 m`、`A=1 m²`、`ΔT=25 K` なので

`Qdot_cond = 0.04×1×25/0.1 = 10 W`

となる。

実際の車体のように複数層・表面熱伝達をまとめて扱うときは、教材上の一般形として総括熱貫流率 `U [W/(m²·K)]` を用い

`Qdot_trans = UAΔT`

と書ける。ただし新幹線実車の `U` や面積は一次資料なしに置かない。

### 4.2 対流

流体と表面の間では、簡略化すると

`Qdot_conv = hA(T_f-T_s)`

で表せる。`h [W/(m²·K)]` は熱伝達率である。

H30一次「機械」問4では、対流による熱流束が流体温度と表面温度の差に比例することが問われる。

### 4.3 放射

放射は電磁波による熱移動である。R8問6型では、面1から面2へ移る放射熱を

`Qdot_rad = εσS_1F_12(T_1^4-T_2^4)`

の形で扱う。

- `ε`: 放射率
- `σ`: Stefan-Boltzmann定数
- `S_1`: 面積
- `F_12`: 形態係数
- `T_1,T_2`: 絶対温度[K]

温度差だけでなく絶対温度の4乗差が入る点が伝導・対流との大きな違いである。

## 5. 熱平衡と熱収支

R3一次「機械」問7では、発生する熱と放散する熱が等しくなる状態を熱平衡と呼ぶ。

定常状態では、系に蓄えられる熱量が時間で変化しないので

`ΣQdot_in = ΣQdot_out`

と書ける。

車室を一つの系として見る場合、冷房負荷の簡略形を

`Qdot_load = Qdot_outside + Qdot_vent + Qdot_internal`

と整理できる。

ここで

- `Qdot_outside`: 車体境界を通って外部から入る熱
- `Qdot_vent`: 換気で外気を取り込むことによる熱
- `Qdot_internal`: 人・照明・機器等から車内で発生する熱

である。

実車の各値は固定仕様ではないため、教材では記号又は「仮定値」と明示した例題だけを使う。

## 6. 外気負荷

外気負荷は、外部との温度差や換気によって車内へ入る熱を熱収支へ加える考え方である。

壁面等の貫流負荷は

`Qdot_trans = UA(T_out-T_in)`

で整理できる。

換気空気の顕熱負荷は、空気質量流量を `mdot [kg/s]`、比熱を `c_p [J/(kg·K)]` とすると

`Qdot_vent = mdot c_p(T_out-T_in)`

である。

このTopicでは湿度・潜熱を独立主題へ拡張しない。固定7項目の熱収支を解くために必要な場合だけ補助的に扱う。

## 7. 車内負荷

車内負荷は、車室内部で発生する熱の合計である。

`Qdot_internal = ΣQdot_person + ΣP_equipment + ...`

電気機器で消費された電力のうち最終的に車室内の熱となる部分は、問題文の条件に従って熱収支へ入れる。

乗客一人当たり発熱量、照明・機器の実車電力などは、本教材では一次資料なしに真値化しない。

## 8. ヒートポンプの熱収支

H27一次「機械」問4では、低温側で吸収した熱量を `Q_L`、圧縮機などを動かすための仕事を `W`、高温側で放出する熱量を `Q_H` とすると

`Q_H = Q_L + W`

が成り立つ。

冷房では低温側から取り去る熱量が目的量なので

`COP_C = Q_L/W`

暖房では高温側へ供給する熱量が目的量なので

`COP_H = Q_H/W`

`= (Q_L+W)/W`

`= 1 + Q_L/W`

となる。

したがって理想化した同一サイクルでは

`COP_H = COP_C + 1`

となる。

### 構成要素

固定過去問を解くため、次の流れを押さえる。

1. 低温側熱交換器で冷媒が熱を吸収して蒸発する。
2. 圧縮機で高温・高圧にする。
3. 高温側熱交換器で熱を放出して凝縮する。
4. 膨張弁で低温・低圧に戻す。

H27問4の「逆カルノーサイクル」「HFC」は過去問固有の最小ブリッジとして扱う。現在の新幹線実車冷媒を示す根拠にはしない。

## 9. COPから消費電力を求める

冷房能力又は必要冷房負荷を `Qdot_C [kW]` とすると

`P_elec = Qdot_C/COP_C`

である。

暖房も同様に

`P_elec = Qdot_H/COP_H`

となる。

例えば冷房負荷10 kW、`COP_C=4` なら必要電力は2.5 kWである。

COPが4だから400%のエネルギー変換効率という意味ではない。ヒートポンプは投入仕事で外部の熱を運ぶため、目的側熱量が入力仕事より大きくなり得る。

## 10. 電熱器の効率とCOPの違い

電熱器で入力電気エネルギー `E_in=Pt` のうち有用熱が `Q_use` なら

`η = Q_use/E_in`

である。

損失を含む通常の効率としては `η≤1` である。

一方、ヒートポンプでは

`COP = Q_transferred/W`

であり、系外から運んだ熱を分子に含むので1を超え得る。

試験では、この二つを同じ「効率」として扱わない。

### 11.2 R1一次「機械」問7 — ヒートポンプ行

固定ゲートにするのはヒートポンプ加熱の行だけである。

- 電気の主な役割: 電動機による圧縮機の駆動
- 被加熱物の加熱: 凝縮器側から熱を受け取る

直接抵抗・赤外・誘導・誘電の他4方式はTopic 33固定範囲へ昇格させない。

### 11.3 R8一次「機械」問6 — 放射定数

放射式中の `σ` はStefan-Boltzmann定数である。Planck定数やBoltzmann定数と取り違えない。

## 12. 問題を見たときの解法手順

1. 求めるのが熱量[J]か、熱流率・電力[W]かを確認する。
2. 時間が絡むなら秒へ直す必要があるか確認する。
3. 電気入力は `Pt`、抵抗発熱は `I²Rt`、温度変化は `mcΔT` を候補にする。
4. 熱移動は伝導・対流・放射のどれかを判定する。
5. 定常熱収支なら流入項と流出項を同じ側へ整理する。
6. 外気負荷と車内負荷を二重計上しない。
7. COPが冷房側 `Q_L/W` か暖房側 `Q_H/W` かを確認する。
8. 電熱器効率 `η` とCOPを混同しない。
9. 最後にJ、W、kW、K、℃差の単位を検算する。

## 13. 典型例題1 — 基礎: 電熱器で水を加熱

消費電力1.2 kWの電熱器を8分運転し、入力エネルギーの85%が5.0 kgの水へ伝わった。水の比熱を `4.186 kJ/(kg·K)` とする。水の温度上昇を求める。

### 解答

時間は

`t = 8×60 = 480 s`

入力エネルギーは

`E_in = Pt = 1200×480 = 576000 J`

有効熱量は

`Q_use = 0.85×576000 = 489600 J`

したがって

`ΔT = Q_use/(mc)`

`= 489600/(5.0×4186)`

`= 23.39 K`

温度差は℃でも同じなので、約23.4℃上昇する。

### 検算

効率を100%とした場合の上昇幅より小さくなっているため向きは妥当である。

## 14. 典型例題2 — 標準: 外気負荷＋車内負荷＋COP

以下は実車値ではない仮定例である。

- 車室境界の総括熱貫流率 `U=1.8 W/(m²·K)`
- 対象面積 `A=120 m²`
- 外気と車内の温度差 `15 K`
- 換気空気質量流量 `mdot=0.18 kg/s`
- 空気比熱 `c_p=1.0 kJ/(kg·K)`
- 車内負荷 `4.5 kW`
- 冷房COP `3.2`

必要な冷房電力を求める。

### 解答

貫流負荷は

`Qdot_trans = UAΔT`

`= 1.8×120×15`

`= 3240 W = 3.24 kW`

換気顕熱負荷は

`Qdot_vent = mdot c_pΔT`

`= 0.18×1000×15`

`= 2700 W = 2.70 kW`

したがって冷房負荷は

`Qdot_load = 3.24+2.70+4.50`

`= 10.44 kW`

必要電力は

`P_elec = 10.44/3.2`

`= 3.2625 kW`

約3.26 kW。

### 検算

COPが1より大きいため、必要電力は除去熱量10.44 kWより小さくなる。これは効率100%超えを意味するのではなく、外部へ熱を運んでいるためである。

## 15. 典型例題3 — 発展: 暖房COPと熱収支

以下も実車値ではない仮定例である。

車室から外部へ失われる熱が18 kW、車内発熱が6 kWある。室温を一定に保つためヒートポンプ暖房で不足分を補う。暖房COPを4.0とする。

### 解答

室温一定なので熱収支より必要暖房量は

`Qdot_H = 18-6 = 12 kW`

必要電力は

`Wdot = Qdot_H/COP_H`

`= 12/4.0 = 3.0 kW`

ヒートポンプの熱収支

`Qdot_H = Qdot_L + Wdot`

より、外気側から吸収する熱は

`Qdot_L = 12-3 = 9 kW`

冷房側の比を計算すると

`COP_C = Qdot_L/Wdot = 9/3 = 3`

したがって

`COP_H = COP_C+1 = 4`

となり、与条件と一致する。

### 検算

高温側12 kWが「低温側から運んだ9 kW + 入力仕事3 kW」に分解され、エネルギー収支が閉じている。
