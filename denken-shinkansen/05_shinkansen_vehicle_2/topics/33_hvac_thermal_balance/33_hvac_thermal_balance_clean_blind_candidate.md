## R8 一次「機械」問6 — 5要素

1. `(1) = (ロ) 3 600RI² [J]`
   - 抵抗発熱は `P=RI²`。1時間は`3600 s`なので`Q=Pt=3600RI²`。
2. `(2) = (ニ) 10 W`
   - `Qdot=kAΔT/L=0.04×1×25/0.10=10 W`。
3. `(3) = (ト) 79.5 ℃`
   - 有効熱量`=1 kW×600 s×0.90=540 kJ`、`ΔT=540/(2×4.186)=64.5 K`、初温15℃より79.5℃。
4. `(4) = (リ) εσS₁F₁₂(T₁⁴-T₂⁴)`
5. `(5) = (ヲ) ステファン・ボルツマン定数`

## R3 一次「機械」問7 — 5要素

1. `(1) = (ヌ) ジュール熱`
2. `(2) = (ヘ) 熱平衡`
3. `(3) = (ワ) 熱伝導`
4. `(4) = (ヲ) 対流熱伝達`
5. `(5) = (ハ) 放射伝熱`

抵抗体内部で生じる熱はジュール熱であり、発生熱と放散熱が等しい定常状態が熱平衡。熱移動の三形態は熱伝導・対流熱伝達・放射伝熱で、物質移動を伴わない固体内伝熱、流体運動を伴う伝熱、電磁波による伝熱に対応する。

2. C欄 = `(f)` 凝縮器からの熱の吸収

## H30 一次「機械」問4 — 5要素

1. `(1) = (ワ) 位相制御`
2. `(2) = (ニ) 高調波`
3. `(3) = (カ) 伝導`
4. `(4) = (ロ) 赤外放射`
5. `(5) = (ヲ) に比例`

サイリスタでヒータ電力を調整する代表方式は位相制御で、高調波を生じる。熱移動は放射・対流・伝導で整理でき、熱放射は主に赤外域、対流熱流束は流体温度と表面温度の差に比例する。
