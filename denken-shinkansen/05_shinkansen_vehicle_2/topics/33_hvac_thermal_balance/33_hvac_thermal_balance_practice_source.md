## 共通式・成立条件

- 電気入力: `Q = Pt`
- 抵抗発熱: `P = I^2R`, `Q = I^2Rt`
- 顕熱: `Q = mcΔT`
- 有効熱量: `Q_use = ηPt`
- 一次元定常熱伝導: `Qdot_cond = kAΔT/L`
- 対流: `Qdot_conv = hA(T_f-T_s)`
- 放射: `Qdot_rad = εσS1F12(T1^4-T2^4)`
- 定常熱収支: `ΣQdot_in = ΣQdot_out`
- 貫流負荷: `Qdot_trans = UAΔT`
- 換気顕熱負荷: `Qdot_vent = mdot c_pΔT`
- 冷房負荷の簡略形: `Qdot_load = Qdot_outside + Qdot_vent + Qdot_internal`
- ヒートポンプ: `Q_H = Q_L + W`
- 冷房COP: `COP_C = Q_L/W`
- 暖房COP: `COP_H = Q_H/W = 1 + Q_L/W`
- 空調入力: `P_elec = Qdot_target/COP`
- 電熱器効率: `η = Q_use/E_in`

温度差はKと℃で同じ数値を使えるが、放射の4乗則に入れる温度は絶対温度[K]である。`W=J/s` なので、Jを求める場合は時間を秒へそろえる。

# 一次試験型

## 問1 電熱器・効率・水の温度上昇

消費電力 `1.5 kW` の電熱器を `10 min` 運転する。入力電気エネルギーの `80 %` が質量 `3.0 kg` の水へ伝わるものとし、水の比熱を `4.2 kJ/(kg·K)` とする。水の温度上昇に最も近いものを選べ。

1. `34.3 K`
2. `45.7 K`
3. `57.1 K`
4. `71.4 K`
5. `85.7 K`

### 正答
3

### 完全解説

まず時間を秒へ直す。

`t = 10×60 = 600 s`

入力電気エネルギーは

`E_in = Pt = 1500×600 = 900000 J = 900 kJ`

有効熱量は

`Q_use = ηE_in = 0.80×900 = 720 kJ`

水の顕熱式 `Q=mcΔT` より

`ΔT = Q_use/(mc)`

`= 720/(3.0×4.2)`

`= 57.14... K`

よって正答3。

効率80%を分母へ置くと温度上昇が増えてしまい、損失があるほど加熱が大きくなる不合理な結果になる。ここでの `η` は電熱器の有効熱量/入力電気エネルギーであり、ヒートポンプCOPではない。

## 問2 抵抗発熱と単位換算

抵抗 `12 Ω` に直流 `5.0 A` を `20 min` 流した。発生するジュール熱として最も適切なものを選べ。

1. `0.12 MJ`
2. `0.24 MJ`
3. `0.30 MJ`
4. `0.36 MJ`
5. `0.60 MJ`

### 正答
4

### 完全解説

抵抗での電力は

`P = I^2R = 5.0^2×12 = 300 W`

時間は

`t = 20×60 = 1200 s`

したがって

`Q = Pt = I^2Rt`

`= 300×1200 = 360000 J = 0.36 MJ`

よって正答4。

`W` は `J/s` なので、時間を20のまま代入せず秒へ直す。R8一次問6の `1 h` なら `3600 s` とし `Q=3600RI^2` となる。

## 問3 壁を通る定常熱伝導

熱伝導率 `k=0.045 W/(m·K)`、厚さ `L=0.090 m`、面積 `A=2.0 m^2` の平板の両面温度差が `24 K` で一定である。一次元定常熱伝導による熱流率に最も近いものを選べ。

1. `6 W`
2. `12 W`
3. `18 W`
4. `24 W`
5. `48 W`

### 正答
4

### 完全解説

一次元定常熱伝導は

`Qdot_cond = kAΔT/L`

だから

`Qdot_cond = 0.045×2.0×24/0.090`

`= 24 W`

よって正答4。

厚さ `L` は熱の通りにくさを増やすので分母に入る。面積と温度差は大きいほど熱流率が増える。ここで与えた値は教材用仮定値であり、実車車体の断熱性能ではない。

## 問4 放射伝熱

放射伝熱に関する記述として最も適切なものを選べ。

1. 放射熱流率は二面の摂氏温度差だけに比例する。
2. `σ` はPlanck定数であり、放射式では温度の2乗差を用いる。
3. 真空中では対流が支配的となるため放射伝熱は生じない。
4. `Qdot_rad = εσS1F12(T1^4-T2^4)` の形で表され、`σ` はStefan-Boltzmann定数である。
5. 放射は物体同士の直接接触がなければ生じない。

### 正答
4

### 完全解説

熱放射は電磁波による熱移動であり、真空中でも生じる。固定過去問で用いる形は

`Qdot_rad = εσS1F12(T1^4-T2^4)`

で、`T1`,`T2` は絶対温度[K]、`σ` はStefan-Boltzmann定数である。したがって4が正しい。

1は4乗差を落としている。2は定数名と温度依存が誤り。3は対流には流体が必要なので逆。5は直接接触を必要とする熱伝導との混同である。

## 問5 熱平衡・伝導・対流・放射

熱移動と熱平衡に関する記述として最も適切なものを選べ。

1. 定常熱平衡では必ず系内の温度が0℃になる。
2. 熱伝導は主として物質内部の温度勾配により生じ、対流熱流束は簡略化すれば流体温度と表面温度の差に比例する。
3. 対流は真空中でも流体運動によって生じる。
4. 放射伝熱は赤外域を含む電磁波とは無関係である。
5. 定常状態でも流入熱流率と流出熱流率が異なってよい。

### 正答
2

### 完全解説

2が正しい。熱伝導は物質内の温度差・温度勾配により生じ、対流は簡略化すると

`Qdot_conv = hA(T_f-T_s)`

なので熱流束は温度差に比例する。

定常熱平衡では蓄熱量が時間変化しないため

`ΣQdot_in = ΣQdot_out`

となる。温度が0℃になるという意味ではない。対流には流体が必要であり、放射は赤外域を含む電磁波による熱移動である。

## 問6 ヒートポンプの熱収支とCOP

ヒートポンプが低温側から `18 kW` の熱を吸収し、圧縮機などへの入力仕事率が `6 kW` である。冷房COP `COP_C` と暖房COP `COP_H` の組合せとして正しいものを選べ。

1. `COP_C=2, COP_H=3`
2. `COP_C=3, COP_H=3`
3. `COP_C=3, COP_H=4`
4. `COP_C=4, COP_H=3`
5. `COP_C=4, COP_H=5`

### 正答
3

### 完全解説

低温側吸収熱を `Q_L=18 kW`、仕事率を `W=6 kW` とすると

`COP_C = Q_L/W = 18/6 = 3`

高温側へ放出する熱は

`Q_H = Q_L + W = 18+6 = 24 kW`

したがって

`COP_H = Q_H/W = 24/6 = 4`

よって正答3。

同一の理想化した熱収支では `COP_H=COP_C+1` でも確認できる。COPが1を超えるのは外部から熱を運ぶからであり、電熱器のエネルギー変換効率が100%を超えたという意味ではない。

## 問7 外気負荷・換気負荷・車内負荷と冷房電力

以下は実車値ではない教材用仮定値である。車室を一つの系として、総括熱貫流率 `U=1.5 W/(m^2·K)`、対象面積 `A=100 m^2`、外気と室内の温度差 `12 K`、換気空気質量流量 `mdot=0.20 kg/s`、空気比熱 `c_p=1.0 kJ/(kg·K)`、車内負荷 `3.6 kW` とする。冷房COPが `3.0` のとき、必要な冷房入力電力に最も近いものを選べ。

1. `1.8 kW`
2. `2.0 kW`
3. `2.6 kW`
4. `3.6 kW`
5. `7.8 kW`

### 正答
3

### 完全解説

貫流負荷は

`Qdot_trans = UAΔT`

`=1.5×100×12 = 1800 W = 1.8 kW`

換気顕熱負荷は

`Qdot_vent = mdot c_pΔT`

`=0.20×1000×12 = 2400 W = 2.4 kW`

したがって総冷房負荷は

`Qdot_load = 1.8+2.4+3.6 = 7.8 kW`

入力電力は

`P_elec = Qdot_load/COP_C`

`=7.8/3.0 = 2.6 kW`

よって正答3。

5の `7.8 kW` は冷房能力側の熱流率であり電気入力ではない。外気由来の貫流・換気と車内発熱を分け、最後にCOPで入力電力へ変換する。

## 問8 ヒートポンプの構成

ヒートポンプの構成と過去問上の扱いに関する記述として最も適切なものを選べ。

1. 圧縮機は冷媒を低圧化するための機器であり、膨張弁が冷媒を圧縮する。
2. 暖房時、被加熱側は低温側蒸発器から熱を受け取る。
3. 電気の主な役割は電動機で圧縮機を駆動することであり、暖房時は凝縮器側から被加熱側へ熱を渡す。
4. H27過去問にHFCが出題されているので、現在の新幹線はすべてHFC冷媒であると断定できる。
5. 逆カルノーサイクルは熱機関として高温源から熱を受けて仕事だけを外部へ出すサイクルである。

### 正答
3

### 完全解説

3が正しい。ヒートポンプでは圧縮機を電動機等で駆動し、暖房では高温側の凝縮器から被加熱側へ熱を渡す。圧縮機は冷媒を高圧化し、膨張弁で低圧側へ落とす。

H27一次問4では圧縮機、膨張弁、逆カルノーサイクル、暖房COP、HFCが問われるが、HFCはその過去問を解くための固定知識であり、現行新幹線の採用冷媒を示す一次資料ではない。4のように実車へ一般化しない。

## 問9 間接抵抗加熱と位相制御

間接抵抗加熱に関する記述として最も適切なものを選べ。

1. サイリスタ位相制御では高調波が発生しないため対策は不要である。
2. ヒータの電力調整にサイリスタの位相制御を用いることがあり、高調波の発生を考慮する必要がある。
3. 被加熱物への熱移動は常に熱伝導だけであり、放射・対流は無視できる。
4. 放射伝熱は主として可視光だけで行われ、赤外放射は関係しない。
5. 対流熱流束は流体と表面の温度差に反比例する。

### 正答
2

### 完全解説

2が正しい。H30一次「機械」問4型では、サイリスタ位相制御によるヒータ電力調整と、それに伴う高調波を扱う。また被加熱物への熱移動には伝導・対流・放射があり、放射は主に赤外放射、対流熱流束は簡略化すれば温度差に比例する。

1は高調波について逆、3は熱移動様式を一つに限定している、4は赤外放射を否定している、5は比例関係を逆にしている。

## 問10 暖房時の熱収支と消費電力

以下は実車値ではない教材用仮定値である。車室から外部への定常熱損失が `20 kW`、車内発熱が `5 kW` ある。室温を一定に保つ不足分をヒートポンプ暖房で補い、暖房COPを `5.0` とする。ヒートポンプの入力電力と外気側から吸収する熱量率の組合せとして正しいものを選べ。

1. `3 kW, 12 kW`
2. `3 kW, 15 kW`
3. `4 kW, 11 kW`
4. `5 kW, 10 kW`
5. `15 kW, 3 kW`

### 正答
1

### 完全解説

室温一定なので、まず車内発熱を差し引く。

`Qdot_H = 20-5 = 15 kW`

暖房COPは

`COP_H = Qdot_H/Wdot`

だから入力電力は

`Wdot = 15/5.0 = 3 kW`

ヒートポンプ熱収支

`Qdot_H = Qdot_L + Wdot`

より

`Qdot_L = 15-3 = 12 kW`

よって正答1。

車内発熱5 kWを暖房負荷へ加算すると二重計上になる。暖房では室内へ必要な高温側熱量を先に熱収支から求め、その後COPで電気入力へ変換する。

## 解法アルゴリズム確認

1. 求める量が熱量[J]か熱流率・電力[W]かを確認する。
2. `Q=Pt` を使うなら時間を秒へそろえる。
3. 抵抗発熱なら `I^2R`、温度変化なら `mcΔT` を選ぶ。
4. 熱移動は伝導・対流・放射を区別する。
5. 車室熱収支では外気由来負荷、換気負荷、車内負荷を重複させない。
6. 冷房は `COP_C=Q_L/W`、暖房は `COP_H=Q_H/W` を使い分ける。
7. 電熱器の効率 `η` とヒートポンプCOPを同じ指標として扱わない。
8. 最後にJ、W、kW、K、℃差の単位を検算する。
