# EXAM_ALIGNMENT

資格: 第二種電気主任技術者

主科目:
- 一次試験「機械」

二次試験の扱い:
- 電気技術者試験センターの試験概要では、一次「機械」に「電熱」が明記されている。
- 二次「機械・制御」の科目内容は「電気機器、パワーエレクトロニクス、自動制御及びメカトロニクス」であり、「電熱」は含まれない。
- よってTopic 33は一次試験対応テーマとして固定し、二次問題を件数合わせで採用しない。これは二次未調査ではなく、公式試験範囲に基づく対象外判定である。

対象論点:
- ジュール熱と電気エネルギーから熱量を求める
- 比熱・質量・温度差による蓄熱量
- 熱伝導・対流・放射による熱移動
- 発熱と放熱が釣り合う熱平衡、熱収支
- ヒートポンプの熱収支 `Q_H = Q_L + W`
- 冷房・暖房のCOPと消費電力の関係
- 外気負荷・車内負荷を熱収支の流入項として扱う
- 有効熱量と入力電気エネルギーから効率を区別する

## SPEC 7項目への1対1マッピング

| SPEC項目 | 主ゲート | 教材で欠落不可の説明 |
|---|---|---|
| 熱量 | R8一次 問6 | `Q=I^2Rt`、`Q=mcΔT`、JとW・sの関係 |
| 熱収支 | R3一次 問7 / H27一次 問4 | 発熱=放熱の熱平衡、ヒートポンプで `Q_H=Q_L+W` |
| COP | H27一次 問4 | 冷房 `COP_L=Q_L/W`、暖房 `COP_H=Q_H/W=1+Q_L/W`。効率と混同しない |

| 外気負荷 | R8一次 問6 / H30一次 問4 | 外部との温度差により生じる熱移動を熱収支の流入項として扱う。実車換気量等は推測しない |
| 車内負荷 | R8一次 問6 | 発熱源からの熱量を熱収支へ加算する方法を固定し、乗客・機器等の実車発熱値は推測しない |
| 効率 | R8一次 問6 | 有効熱量/投入電気エネルギー。COPとは別指標として扱う |

## 範囲境界

1. R8問6・R3問7・H30問4で必要な伝導・対流・放射は熱収支を組むための前提として扱うが、伝熱工学の独立テーマへ拡張しない。
2. H27問4の冷媒種類・逆カルノーサイクルは固定過去問を解くための最小ブリッジとし、冷媒物性設計や冷凍サイクル詳細へ拡張しない。
3. R1問7はヒートポンプ加熱の行だけを固定ゲートとし、直接抵抗・赤外・誘導・誘電加熱の4行をTopic 33固定範囲へ昇格させない。
4. 外気負荷・車内負荷は系列SPECの固定項目として熱収支へ組み込むが、未確認の実車換気量、乗客発熱、機器発熱、断熱性能を置かない。
5. COPは熱輸送量/入力仕事であり1を超え得る。エネルギー変換効率 `η=Q_useful/E_in` と同一視しない。
6. 実車の空調方式、冷媒、能力、消費電力、COP、熱負荷を推測で補わない。
