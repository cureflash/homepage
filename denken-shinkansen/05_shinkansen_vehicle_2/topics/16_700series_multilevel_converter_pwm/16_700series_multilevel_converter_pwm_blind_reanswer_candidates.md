## 2. R4 一次「機械」問4 (1)〜(5)

オン状態では端子間電圧が大きいほど同一電流条件でオン損失が増える。オフ状態に流れる微小電流は漏れ電流である。ターンオン・ターンオフ遷移中に電圧と電流が同時に存在して生じる損失はスイッチング損失であり、1回当たりエネルギーが同程度なら繰返し周期が短いほど単位時間当たり回数が増えて損失が大きくなる。遷移損失を低減する方法としてソフトスイッチングを選ぶ。

- (1): `大きい` → 候補記号 `ハ`

- (3): `スイッチング損失` → 候補記号 `ト`
- (4): `が短いほど大きい` → 候補記号 `ロ`
- (5): `ソフトスイッチング` → 候補記号 `ル`

教材根拠: main source §8「スイッチング損失と変換効率」。`P_sw≈f_sw E_sw` の比例関係と、オン損失・オフ時損失・スイッチング損失の区別を使用した。

## 3. H29 一次「機械」問3 (1)〜(5)

## 4. H24 一次「機械」問3 (1)〜(5)

図の各ユニットは三相入力のダイオードブリッジ整流器と単相インバータで構成され、交流出力を直列合成するため各直流側を変圧器別巻線で絶縁する。直流電圧がほぼ一定の条件で最少スイッチング回数により交流出力を制御する記述からパルス幅制御を選ぶ。

2ユニットの第 `n` 次成分の合成係数は

`2 cos(nφ/2)`

である。候補 `φ=π/6` では5次・7次について

`|cos(5π/12)|=|cos(7π/12)|≈0.2588`

となり、両方を大幅に低減できる。基本波は

`2 cos(φ/2)=2 cos(π/12)≈1.932`

なので、単一ユニット基本波の2倍未満となる。

- (1): `三相ダイオードブリッジ整流器及び単相インバータ` → 候補記号 `カ`
- (2): `間を絶縁する` → 候補記号 `ロ`
- (3): `パルス幅` → 候補記号 `ニ`
- (4): `π/6 rad` → 候補記号 `ヲ`
- (5): `2倍未満の` → 候補記号 `ル`

教材根拠: main source §4「多レベル化・ユニット多重化で何が変わるか」、§5「位相差と高調波の合成」。

答案要素: `5 / 5` 固定。

## 5. H24 二次「機械・制御」問3 (1)〜(4)

与条件: 定格交流電流 `30 A`、`E_d=150 V`、`X=0.4 Ω`、`V_L=100 V`。問題文の定義 `v_v=E_d K sin(ωt+φ)`、電流向きはインバータから交流電源側。

### (1) フェーザ式

リアクトル電圧降下を加えるので

`V_v = V_L + jXI`

候補答案:

- `V_v = V_L + jXI`

### (2a) 力率1・有効電力3 kW時の `V_v`

力率1なので

`I=P/V_L=3000/100=30 A`

したがって

`V_v=100+j(0.4×30)=100+j12 V`

`|V_v|=sqrt(100^2+12^2)=100.717... V`

候補答案:

- フェーザ: `100+j12 V`
- 実効値: `V_v≈100.7 V`

### (2b) 変調率 `K`

問題文定義から基本波実効値は

`V_v=E_d K/√2`

なので

`K=√2 V_v/E_d=√2×100.717.../150=0.94957...`

候補答案:

- `K≈0.950`

### (2c) `tanφ`

`V_v=100+j12` より

`tanφ=12/100=0.120`

候補答案:

- `tanφ=0.120`

### (3) 一般の `I=I_P+jI_Q` に対する `V_v`

`V_v=V_L+jX(I_P+jI_Q)`

`=(V_L-XI_Q)+jXI_P`

したがって

`V_v=sqrt((V_L-XI_Q)^2+(XI_P)^2)`

候補答案:

- `V_v=sqrt((V_L-XI_Q)^2+(XI_P)^2)`

### (4) `I_P=0` での `I_Qmin`

`K≤1` より

`V_v≤E_d/√2=150/√2=106.066... V`

`I_P=0` かつ負側限界では

`100-0.4I_Q≤106.066...`

したがって

`I_Q≥(100-150/√2)/0.4=-15.165... A`

電流定格による下限 `-30 A` より電圧制約の方が厳しい。

候補答案:

- `I_Qmin≈-15.2 A`

教材根拠: main source §7「H24二次型: PWM基本波電圧とフェーザ式」、§10.3「H24二次型の電圧・電流制約」。

答案要素: `(1) 1 + (2) 3 + (3) 1 + (4) 1 = 6 / 6` 固定。
