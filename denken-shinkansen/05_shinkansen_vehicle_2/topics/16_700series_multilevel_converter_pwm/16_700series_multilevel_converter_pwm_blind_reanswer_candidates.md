### H24 二次「機械・制御」問3

問題条件: `V_L=100 V`、`X=0.4 Ω`、`E_d=150 V`、定格交流電流 `30 A`、`v_v=E_d K sin(ωt+φ)`。

| 要素 | 候補答案 | 教材だけでの導出 |
|---|---|---|
| 21 / (1) | `V_v = V_L + j X I`（フェーザ） | 電流はインバータから交流電源側へ流れるので、連系リアクトルの電圧降下を加えてインバータ側電圧を求める。 |
| 22 / (2a) | `V_v = sqrt(100^2+(0.4×30)^2) = 100.717... V ≈ 100.7 V` | 力率1・3 kWなので `I=3000/100=30 A`、したがって `V_v=100+j12 V`。 |
| 23 / (2b) | `K = sqrt(2)V_v/E_d = 0.949573... ≈ 0.950` | 教材式 `V_v=E_d K/sqrt(2)` をKについて解く。 |
| 24 / (2c) | `tan φ = 12/100 = 0.12` | `V_v=100+j12 V` の実部と虚部の比。 |
| 25 / (3) | `V_v = sqrt((V_L-X I_Q)^2+(X I_P)^2)` | `I=I_P+jI_Q` を `V_v=V_L+jXI` に代入すると `V_v=(V_L-XI_Q)+jXI_P`。 |
| 26 / (4) | `I_Qmin = -(E_d/sqrt(2)-V_L)/X = -15.165... A ≈ -15.2 A` | `I_P=0` では電流上限は `|I_Q|≤30 A`。負側は電圧上限 `V_v≤E_d/sqrt(2)=106.066... V` が先に効き、`100-0.4I_Q=106.066...` から求める。 |
