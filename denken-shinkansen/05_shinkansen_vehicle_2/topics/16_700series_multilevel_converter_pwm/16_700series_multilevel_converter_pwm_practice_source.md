## 問1 2レベル電圧形インバータと誘導性負荷

直流電圧 `E_d` をもつ理想ハーフブリッジ電圧形インバータで、負荷にインダクタンスが含まれる。最も適切な記述を選べ。

1. 主スイッチをOFFすると負荷電流は必ず瞬時に0になる。
2. 上下スイッチは直流電圧を最大利用するため同時ONさせる。
3. 誘導性負荷では主スイッチOFF後も電流が連続するため逆並列ダイオード等の還流経路が必要であり、電圧形インバータの代表的な自己消弧形スイッチング素子には IGBT や MOSFET がある。
4. デッドタイムは搬送波周波数を0にするために設ける。
5. 還流ダイオードは出力基本波電圧を必ず2倍にする。

### 正答

3

### 完全解説

インダクタンス電流は瞬時に変化できないため、主スイッチをOFFした後も電流経路が必要になる。逆並列ダイオード等が還流経路を与えるので3が正しい。

上下スイッチの同時ONは直流電源短絡につながるため避ける。デッドタイムは、一方をOFFしてから他方をONするまでの休止時間を設け、上下同時導通を防ぐためのものである。IGBT と MOSFET は自己消弧形スイッチング素子の代表例である。一方、逆並列ダイオードは誘導性負荷の還流経路を担うため、スイッチング素子の識別問題で混同しない。

## 問2 PWMと搬送波周波数

正弦波変調波の周波数を `60 Hz`、三角搬送波の周波数を `2.40 kHz` とする。1基本波周期当たりの搬送波周期数と、搬送波周波数の意味の組合せとして正しいものを選べ。

1. `4` 周期、搬送波周波数は出力基本波周波数そのものである。
2. `40` 周期、搬送波周波数はPWMパルス生成のスイッチング頻度を決める基準になる。
3. `400` 周期、搬送波周波数は直流電圧を決める。
4. `40` 周期、搬送波周波数を上げるとスイッチング回数は必ず減る。
5. `2400` 周期、搬送波周波数と基本波周波数は常に等しい。

### 正答

2

### 完全解説

基本波1周期は `1/60 s` なので、その間の搬送波周期数は

```text
N_c = f_c/f_1
    = 2400/60
    = 40
```

である。PWMでは変調波と搬送波を比較してパルス幅を決める。搬送波周波数は代表的なスイッチング頻度を決める基準となる。したがって正答は2。

## 問3 中点基準電圧とフルブリッジ差電圧

直流母線電圧 `E_d=400 V` とする。理想2レベルハーフブリッジの中点基準出力と、理想フルブリッジの差電圧について正しい組合せを選べ。

1. ハーフブリッジ `±400 V`、フルブリッジ `±200 V` のみ
2. ハーフブリッジ `±200 V`、フルブリッジは `+400 V, 0, -400 V` を取り得る
3. ハーフブリッジ `0 V` のみ、フルブリッジ `±200 V` のみ
4. ハーフブリッジ `±100 V`、フルブリッジ `±200 V` のみ
5. どちらも常に `+400 V` のみ

### 正答

2

### 完全解説

中点基準の理想ハーフブリッジでは

```text
v = ±E_d/2 = ±200 V
```

である。フルブリッジでは左右脚の出力差を取るため、スイッチ状態に応じて

```text
+E_d, 0, -E_d
```

すなわち `+400 V, 0, -400 V` を取り得る。基準点を確認せず `E_d/2` と `E_d` を混同しない。

## 問4 素子電圧・電圧ステップ・dv/dt

比較用理想モデルで `E_d=800 V`、立上り時間 `Δt=4 μs` とする。2レベルでは一度の直接遷移を `Δv=800 V`、理想分担3レベルでは隣接レベル間を `Δv=400 V` とする。理想分担3レベル側の各分担要素の遮断電圧も `400 V` とする。最も適切な組合せを選べ。

1. 2レベル `dv/dt=100 V/μs`、3レベル `200 V/μs`、分担要素 `800 V`
2. 2レベル `dv/dt=200 V/μs`、3レベル `100 V/μs`、分担要素 `400 V`
3. 2レベル `dv/dt=3200 V/μs`、3レベル `1600 V/μs`、分担要素 `400 V`
4. 両者とも `dv/dt=200 V/μs`、分担要素 `800 V`
5. `dv/dt` は電圧ステップと無関係である。

### 正答

2

### 完全解説

```text
(dv/dt)_2 = 800/4 = 200 V/μs
```

```text
(dv/dt)_3 = 400/4 = 100 V/μs
```

同じ立上り時間なら一段の電圧変化量が半分になると `dv/dt` も半分になる。比較用理想分担モデルでは各分担要素の遮断電圧を `E_d/2=400 V` と置く。これは700系実車の素子耐圧ではない。

## 問5 高調波比較

共通教材用モデルの多レベル比較波形で `α=π/8` とする。半波対称波形の奇数第 `n` 次成分について

```text
V_n/V_1 = |cos(nα)|/{n cos(α)}
```

を用いる。第5次成分の `V_5/V_1` と、2レベル矩形波の第5次比 `1/5` との比較として最も近いものを選べ。

1. `V_5/V_1≈0.0828` で、2レベルの `0.200` より小さい。
2. `V_5/V_1≈0.200` で、両者は同じである。
3. `V_5/V_1≈0.5556` で、2レベルより大きい。
4. `V_5/V_1≈1.00` である。
5. 第5次成分は必ず0になる。

### 正答

1

### 完全解説

```text
V_5/V_1
= |cos(5π/8)|/{5cos(π/8)}
= 0.0828427
```

2レベル矩形波では同じ比較で第5次比は `1/5=0.200` なので、共通教材用の多レベル比較波形では第5次成分の相対値が小さい。ただし、多レベル化すれば全高調波が0になるわけではない。

## 問6 ユニット多重化と絶縁

ユニット多重インバータについて最も適切な記述を選べ。

1. 交流側を直列合成する場合、各ユニットの出力電圧は加算できる。
2. 多重化すると各ユニットの直流側は必ず同一導体で短絡しなければならない。
3. 多重化すればPWMや位相差制御は使用できない。
4. 多重化すると高調波はすべて自動的に0になる。
5. 各ユニットの絶縁条件は回路構成と無関係である。

### 正答

1

### 完全解説

複数ユニットの交流出力を直列接続すれば瞬時出力電圧を加算でき、より細かな電圧段階を作れる。構成によって各ユニットの直流側を独立させる必要がある場合は、変圧器の別巻線等でユニット間を絶縁する。

多レベル化、PWM、位相差制御は別の手段であり、組合せて使う場合がある。高調波も自動的に全て0になるわけではない。

## 問7 半導体損失の分類

スイッチングデバイスの損失について最も適切な記述を選べ。

1. オン損失は素子OFF中の漏れ電流だけで決まる。
2. スイッチング損失はON/OFF遷移中に素子電圧と素子電流が同時に存在することで生じる。
3. スイッチング周波数を上げれば、1回当たりのエネルギーが同じでも単位時間当たりのスイッチング損失は必ず減る。
4. ソフトスイッチングはスイッチング遷移損失を増やすことだけを目的とする。
5. オフ時の漏れ電流による損失は存在しない。

### 正答

2

### 完全解説

オン損失は導通中の電圧降下と電流による。オフ中にも漏れ電流等による損失があり得る。スイッチング損失は遷移中に電圧と電流が重なることで生じるため2が正しい。

ソフトスイッチングは遷移時の電圧・電流の重なりを抑え、スイッチング損失を低減する方向で用いられる。Topic 16では原理と周波数依存までを扱い、素子材料別の詳細比較はTopic 17へ残す。

## 問8 スイッチング周波数と変換効率

1回の代表スイッチングエネルギーを `E_sw=6.0 mJ`、代表スイッチング周波数を `f_sw=3.0 kHz`、その他の損失を `1.00 kW`、変換器出力を `50.0 kW` とする簡略モデルを考える。スイッチング損失と変換効率の組合せとして最も近いものを選べ。

1. `P_sw=2.0 W`、`η=99.9%`
2. `P_sw=18 W`、`η≈98.0%`
3. `P_sw=18 kW`、`η≈72.5%`
4. `P_sw=500 W`、`η≈50.0%`
5. `P_sw=0 W`、`η=100%`

### 正答

2

### 完全解説

```text
P_sw = f_sw E_sw
     = 3000×0.006
     = 18 W
     = 0.018 kW
```

したがって総損失は

```text
P_loss = 1.00+0.018
       = 1.018 kW
```

変換効率は

```text
η = 50.0/(50.0+1.018)
  = 0.980046
  ≈ 98.0%
```

正答は2。`J×Hz=W` であることと、`W` と `kW` の単位換算を確認する。

## 問1 2レベル電圧形インバータの動作とPWM

直流母線 `E_d` をもつ理想2レベル電圧形インバータが誘導性負荷を駆動するとする。

(a) ハーフブリッジの中点基準出力電圧レベルを示せ。

(b) 主スイッチをOFFした直後も負荷電流が継続する理由と、逆並列ダイオードの役割を説明せよ。

(c) デッドタイムの目的を説明せよ。

(d) 正弦波変調波と三角搬送波を用いるPWMで、搬送波周波数とスイッチング頻度の関係を説明せよ。さらに、IGBT以外の代表的な自己消弧形スイッチング素子を1つ挙げ、逆並列ダイオードとの役割の違いを述べよ。

### 完全解説

(a) 理想ハーフブリッジの中点基準では

```text
v = +E_d/2, -E_d/2
```

の2レベルを取る。

(b) インダクタンス電流は瞬時に変化できないため、主スイッチをOFFしても電流は連続しようとする。逆並列ダイオード等がその還流経路を作る。したがって「スイッチOFF」と「負荷電流ゼロ」は同義ではない。

(c) 上下アームを同時ONすると直流電源を短絡するため、一方をOFFしてから他方をONするまで休止時間を設ける。これがデッドタイムである。

(d) PWMでは変調波と搬送波の大小比較でゲートパルスを作る。搬送波周波数を高くすると、一般に1秒当たりの代表スイッチング回数も増える。出力基本波周波数と搬送波周波数を混同しない。IGBT以外の代表的な自己消弧形スイッチング素子として MOSFET がある。逆並列ダイオードは誘導性負荷の還流経路を与える素子であり、自己消弧形スイッチング素子とは役割が異なる。

## 問2 多レベル波形・高調波・素子電圧

共通教材用モデルを用いる。

(a) `α=π/8` の多レベル比較波形が1周期で取る電圧レベルを示せ。

(b) 半波対称波形について `V_n/V_1=|cos(nα)|/{n cos α}` を用い、第3次、第5次、第7次の比を求め、2レベル矩形波の `1/n` と比較せよ。

(c) 2ユニットを位相差 `φ=π/8` で合成するとき、同相合成時を1とした第5次、第7次成分の比を求めよ。

(d) 比較用に `E_d=1000 V`、立上り時間 `Δt=5 μs` とする。2レベル直接遷移と理想分担3レベル隣接遷移の `dv/dt`、および理想分担側の各分担要素遮断電圧を求めよ。

### 完全解説

(a) 共通モデルの出力レベルは

```text
+0.5 pu, 0, -0.5 pu
```

の3段階である。これは700系実車回路のレベル数ではない。

(b) `α=π/8` なので

```text
V_3/V_1 = |cos(3π/8)|/{3cos(π/8)}
          = 0.138071

V_5/V_1 = |cos(5π/8)|/{5cos(π/8)}
          = 0.0828427

V_7/V_1 = |cos(7π/8)|/{7cos(π/8)}
          = 0.142857
```

2レベル矩形波の比はそれぞれ

```text
1/3 = 0.333333
1/5 = 0.200000
1/7 = 0.142857
```

である。この共通比較波形では第3次・第5次は小さくなるが、第7次は同じ比になる。多レベル化で全高調波が必ず減るとは限らないことも確認できる。

(c) 2ユニットの第 `n` 次成分は

```text
sin(nωt)+sin(n(ωt-φ))
=2cos(nφ/2)sin(nωt-nφ/2)
```

となる。同相合成時2を基準1とした比は `|cos(nφ/2)|` なので

```text
第5次 = |cos(5π/16)| = 0.555570
第7次 = |cos(7π/16)| = 0.195090
```

である。高調波次数ごとに位相差の効き方が異なる。

(d) 2レベルでは

```text
Δv = 1000 V
(dv/dt)_2 = 1000/5 = 200 V/μs
```

理想分担3レベルでは

```text
Δv = 500 V
(dv/dt)_3 = 500/5 = 100 V/μs
```

比較用理想分担では各分担要素の遮断電圧も

```text
E_d/2 = 500 V
```

と置く。これらは教育用比較値であり、700系実車の素子電圧ではない。

## 問3 PWM基本波電圧と電圧・電流制約

H24二次型の教材モデルで次を与える。

- `E_d=400 V`
- `V_L=200 V`
- `X=0.60 Ω`
- `I_P=30 A`
- `I_Q=-10 A`
- 変調率上限 `K_max=0.80`
- 電流上限 `I_max=35 A`

(a) `V_v=V_L+jXI` を用いて、必要なインバータ基本波電圧フェーザ、実効値、位相角を求めよ。

(b) `V_v=E_dK/√2` から必要変調率を求めよ。

(c) 電圧制約と電流制約をそれぞれ判定せよ。

(d) 両制約を別々に確認しなければならない理由を述べよ。

### 完全解説

(a) `I=I_P+jI_Q` より

```text
V_v = (V_L-XI_Q)+jXI_P
    = (200-0.60×(-10))+j(0.60×30)
    = 206+j18 V
```

したがって

```text
|V_v| = sqrt(206^2+18^2)
      = 206.785 V
```

位相角は

```text
φ = atan(18/206)
  = 4.99°
```

である。

(b)

```text
K = √2|V_v|/E_d
  = √2×206.785/400
  = 0.731095
```

(c) 電圧側は

```text
K=0.731<0.80
```

なので上限内である。

電流実効値は

```text
|I| = sqrt(30^2+(-10)^2)
    = 31.623 A
```

で、`31.623<35 A` だから電流上限内でもある。

(d) PWMが必要な基本波電圧を出せるかという電圧制約と、素子・回路が許容電流内かという電流制約は別条件である。一方が満足しても他方を自動的に満足するとは限らないため、個別に判定する。

## 問4 スイッチング損失と変換効率のトレードオフ

簡略モデルとして、1回当たり代表スイッチングエネルギー `E_sw=5.0 mJ`、その他の損失 `0.80 kW`、出力 `P_out=40.0 kW` とする。

(a) `f_sw=2.0 kHz` と `5.0 kHz` のときのスイッチング損失を求めよ。

(b) それぞれの変換効率を求めよ。

(c) オン損失、オフ時漏れ損失、スイッチング損失の発生状態を区別して説明せよ。

(d) ソフトスイッチングの目的と、スイッチング周波数を上げる際の波形側・損失側のトレードオフを説明せよ。

### 完全解説

(a)

```text
P_sw,2k = 2000×0.005
         = 10 W
         = 0.010 kW

P_sw,5k = 5000×0.005
         = 25 W
         = 0.025 kW
```

(b) 総損失はそれぞれ

```text
P_loss,2k = 0.80+0.010 = 0.810 kW
P_loss,5k = 0.80+0.025 = 0.825 kW
```

したがって

```text
η_2k = 40/(40+0.810)
     = 0.980152
     ≈ 98.02%

η_5k = 40/(40+0.825)
     = 0.979792
     ≈ 97.98%
```

(c) オン損失は導通中の電圧降下と電流による。オフ中にも漏れ電流等による損失があり得る。スイッチング損失はON/OFF遷移中に素子電圧と素子電流が同時に存在することで生じる。

(d) ソフトスイッチングは遷移時の電圧・電流の重なりを抑えてスイッチング損失を減らす方向で用いられる。一般にスイッチング周波数を上げるとPWM波形を細かく制御しやすくなる一方、1回当たりエネルギーが同じなら単位時間当たりのスイッチング損失は増える。この簡略問題では、その損失増加により効率がわずかに低下する。
