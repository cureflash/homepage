## 共通式・成立条件

- `f=1/T`
- `ω=2πf`
- `X_L=ωL`
- `X_C=1/(ωC)`
- 直列RLC共振: `ω0=1/sqrt(LC)`、`f0=1/(2πsqrt(LC))`
- 共振時: `I0=V/R`
- `Q=ω0L/R=1/(ω0CR)=(1/R)sqrt(L/C)`
- 共振時リアクタンス素子電圧の大きさ: `V_L=V_C=QV`
- 標本化: `f_s>2f_max`
- `N` bit量子化の代表レベル数: `2^N`
- `S/N=P_S/P_N`
- 電力比dB: `10log10(P_S/P_N)`
- 同一インピーダンスでの電圧比dB: `20log10(V_S/V_N)`

# 一次試験型

## 問1 周波数・角周波数・リアクタンス

`f=50 Hz`、`L=0.10 H` のコイルについて、角周波数 `ω` と誘導性リアクタンス `X_L` の組合せとして最も近いものを選べ。

1. `50 rad/s, 5.0 Ω`
2. `100 rad/s, 10 Ω`
3. `157 rad/s, 15.7 Ω`
4. `314 rad/s, 31.4 Ω`
5. `628 rad/s, 62.8 Ω`

### 正答
4

### 完全解説

`ω=2πf=2π×50≈314 rad/s`、`X_L=ωL≈314×0.10=31.4 Ω`。よって4。`f` と `ω` を同一数値として扱わない。

---

## 問2 RLC直列共振とQ

`R=20 Ω`、`L=0.20 H`、`C=50 μF` の直列RLC回路に実効値 `V=100 V` を加える。共振周波数 `f0`、Q、共振時コイル電圧の大きさ `V_L` の組合せとして最も近いものを選べ。

1. `15.9 Hz, 1.00, 100 V`
2. `31.8 Hz, 2.00, 200 V`
3. `50.3 Hz, 3.16, 316 V`
4. `100 Hz, 6.28, 628 V`
5. `316 Hz, 31.6, 3160 V`

### 正答
3

### 完全解説

`LC=0.20×50×10^-6=1.0×10^-5` なので `ω0=1/sqrt(LC)≈316.2 rad/s`、`f0=ω0/(2π)≈50.3 Hz`。`Q=ω0L/R≈316.2×0.20/20=3.16`。共振時は `V_L=QV≈316 V`。よって3。

## 問3 共振時の位相と電圧拡大

直列RLC回路が共振し、`Q=0.80` である。正しい記述を選べ。

1. コイル電圧とコンデンサ電圧の位相差は0 radで、どちらも電源電圧より必ず大きい。
2. コイル電圧とコンデンサ電圧の位相差は `π rad` で、各電圧の大きさは `0.80V` である。
3. 共振時電流は0 Aになる。
4. 共振時の合成インピーダンスは `jωL` になる。
5. `Q<1` でも `V_L>V` が必ず成立する。

### 正答
2

### 完全解説

共振時はLとCの電圧の大きさが等しく位相は反対なので、位相差は `π rad`。また `V_L=V_C=QV` だから `Q=0.80` なら各電圧の大きさは `0.80V`。`V_L>V` の条件は `Q>1` である。

## 問4 変調方式の識別

変調方式の説明として正しいものを選べ。

1. AMは搬送波の周波数を情報に応じて変える。
2. FMは搬送波の振幅だけを情報に応じて切り替える。
3. ASKはディジタル値に応じて搬送波の振幅を切り替える。
4. PSKは搬送波の周波数だけを切り替える。
5. QAMは振幅を一定に保ち、周波数だけを多値化する。

### 正答
3

### 完全解説

AMは振幅、FMは周波数、PMは位相を変える。ディジタル変調ではASKが振幅、FSKが周波数、PSKが位相を切り替える。QAMは直交する成分を使い、振幅と位相の組合せで多値を表す。よって3。

## 問5 標本化・量子化・サンプルホールド

最高周波数 `4 kHz` の帯域制限信号を8 bitでA-D変換する。正しい記述を選べ。

1. `f_s=6 kHz` なら標本化定理の基本条件を満たす。
2. 8 bitの代表的な量子化レベル数は64である。
3. 量子化誤差は外来ノイズと同一原因で生じる。
4. `f_s=10 kHz` は標本化定理の基本条件を満たし、8 bitの代表的な量子化レベル数は256である。
5. サンプルホールドは量子化bit数を自動的に倍増する回路である。

### 正答
4

### 完全解説

標本化の基本条件は `f_s>2f_max=8 kHz`。したがって10 kHzは条件を満たす。8 bitの代表レベル数は `2^8=256`。サンプルホールドはA-D変換中に標本化した入力値を保持する。量子化誤差は有限段階へ丸めることに起因し、外来ノイズとは原因が異なる。

## 問6 A-D変換方式

A-D変換方式について正しい記述を選べ。

1. 積分形は入力電圧を時間に対応する量へ変換して測る考え方を用いる。
2. 逐次比較形はLSB側からだけ比較し、MSBを最後に決める。
3. サンプルホールドは復調器の一種である。
4. 量子化では時間軸だけを離散化する。
5. 標本化では振幅を必ず `2^N` 段階へ丸める。

### 正答
1

### 完全解説

積分形は入力電圧を時間に対応する量へ変換して測る考え方を使う。逐次比較形はMSB側から比較を進める。標本化は時間軸、量子化は振幅軸の離散化であり、サンプルホールドは変換中の入力保持を担う。

## 問7 OSI層と中継機器

LANの一般原理として正しい組合せを選べ。

1. リピータ―ネットワーク層―IPアドレス
2. リピータ―物理層―信号の中継・波形劣化の補正
3. データリンク層―IPアドレス―ルーティング
4. ネットワーク層―MACアドレス―フレーム転送
5. 物理層―MACアドレス―経路選択

### 正答
2

### 完全解説

リピータは物理層で信号を中継する。データリンク層ではMACアドレス、ネットワーク層ではIPアドレスを扱う。物理層のリピータがMAC/IPアドレスを見て経路選択するわけではない。

## 問8 S/NのdB表示

同一インピーダンス条件で、信号実効値 `2.0 V`、雑音実効値 `0.20 V` とする。S/NのdB値として正しいものを選べ。

1. `10 dB`
2. `20 dB`
3. `40 dB`
4. `100 dB`
5. `200 dB`

### 正答
2

### 完全解説

同一インピーダンスの電圧比なので `20log10(V_S/V_N)=20log10(2.0/0.20)=20log10(10)=20 dB`。電力比に換算すれば100倍であり、`10log10(100)=20 dB` と一致する。

## 問9 デジタル判定とノイズ

教材用にしきい値 `V_th=2.5 V` とし、`V>=V_th` を1、`V<V_th` を0と判定する。ノイズなし受信値が `2.3 V`、そこへ `+0.3 V` の瞬時ノイズが重畳した場合の判定の変化として正しいものを選べ。

1. `0 → 1`
2. `1 → 0`
3. `0 → 0`
4. `1 → 1`
5. 判定規則からは決められない

### 正答
1

### 完全解説

ノイズなしでは `2.3<2.5` なので0。ノイズ重畳後は `2.6>=2.5` なので1となる。これはしきい値判定の教材モデルであり、ATC実設備の受信しきい値ではない。

## 問10 RAIDと冗長化

磁気ディスク・RAIDの一般原理として正しい記述を選べ。

1. プラッタはヘッドを目的トラックへ移動する時間である。
2. シーク時間は情報を記録する円板そのものである。
3. ストライピングは同一内容を必ず全ディスクへ複製する方式である。
4. ミラーリングは同一内容を複数ディスクへ複製する。
5. RAID5はパリティを一切使わない。

### 正答
4

### 完全解説

プラッタは記録円板、シーク時間はヘッドを目的トラック位置へ移動させる時間。ストライピングはデータを複数ディスクへ分散し、ミラーリングは同一内容を複製する。RAID5はデータと分散パリティを用いる代表方式である。これは冗長化の一般原理であり、ATC実設備の冗長構成を示すものではない。

## 問11 信号伝送の基本系列

一般的な情報伝送の流れとして最も適切なものを選べ。

1. 原信号 → 復調 → 変調 → 判定 → 伝送路
2. 原信号 → 変調 → 伝送路 → 復調 → 判定
3. 搬送波 → 判定 → 原信号 → RAID → 復調
4. 原信号 → 量子化誤差 → 搬送波消去 → 伝送路 → 変調
5. 伝送路 → 原信号 → 復調 → 変調 → 判定

### 正答
2

### 完全解説

基本系列は `原信号 → 変調 → 伝送路 → 復調 → 判定`。搬送波は情報を載せる基準となる周期信号で、受信側で元情報を取り出す操作が復調である。
