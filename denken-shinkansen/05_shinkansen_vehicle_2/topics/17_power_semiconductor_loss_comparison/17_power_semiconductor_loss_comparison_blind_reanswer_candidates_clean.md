## 1. R7 一次「機械」問4

教材根拠: 誘導性負荷では電流が連続し、IGBT/MOSFETと逆並列ダイオードで電流経路を確保する。PWMでは搬送波周波数がスイッチング頻度を決める。

- (1) `(ホ) 誘導性`
- (2) `(ル) 二つ`
- (3) `(チ) MOSFET`
- (4) `(イ) PWM`
- (5) `(ハ) スイッチング`

候補固定: `5 / 5`。

## 2. R4 一次「機械」問4

教材根拠: 導通損失はオン電圧が大きいほど増える。オフ時には微小な漏れ電流が流れる。切替中の `v(t)i(t)` 重なりがスイッチング損失であり、1回当たり損失が同じなら周期が短いほど単位時間当たり損失が増える。重なりを減らす方法がソフトスイッチングである。

- (1) `(ハ) 大きい`
- (2) `(イ) 漏れ電流`
- (3) `(ト) スイッチング損失`
- (4) `(ロ) が短いほど大きい`
- (5) `(ル) ソフトスイッチング`

候補固定: `5 / 5`。

## 3. R2 一次「機械」問2

教材根拠: `D` は通流率。降圧チョッパの理想波形ではダイオード電圧平均は `D V_dc`。切替中は電圧と電流が同時に正となり、区分線形の重なり面積を積分して1回当たり損失を得る。平均スイッチング損失は `(W_on+W_off)/T`。

- (1) `(カ) 通流率`
- (2) `(ト) D V_dc`
- (3) `(ヨ) 正である`
- (4) `(リ) (1/2)V_dc I_dc T_2`
- (5) `(ホ) (W_off+W_on)/T`

候補固定: `5 / 5`。

## 5. H24 二次「機械・制御」問1

問題条件:

- 直流電源 `V_dc=200 V`
- 直結時、軸出力 `3.75 kW`、回転速度 `1500 min^-1`、電機子電流 `20 A`
- 正負ブラシ全電圧降下 `2.5 V`
- IGBT電圧降下 `2 V`
- 逆並列ダイオード電圧降下 `1 V`
- 鉄損、界磁損、機械損、スイッチング損失、リアクトル抵抗、電流リプルは問題指示どおり無視

### (1) 電機子巻線抵抗

損失無視条件から電磁変換出力は軸出力に等しいので

`E I_a = 3.75 kW`

`E = 3750/20 = 187.5 V`

直結時の電圧式

`200 = E + I_a R_a + 2.5`

より

`R_a = (200-187.5-2.5)/20 = 0.500 Ω`

候補: `0.500 Ω`。

### (2) 1500 min^-1時の誘導起電力

(1)より

`E = 187.5 V`

候補: `187.5 V`（3桁表記なら `188 V`）。

### (3) 定格トルク時の最高回転速度

定格トルクなので `I_a=20 A`。S1連続ON時の電機子端子電圧最大値は

`V_a,max = 200-2 = 198 V`

よって

`E_max = 198 - 20×0.5 - 2.5 = 185.5 V`

一定界磁なので `E∝n` より

`n_max = 1500×185.5/187.5 = 1484 min^-1`

候補: `1.484×10^3 min^-1`（3桁表記 `1.48×10^3 min^-1`）。

### (4) 1000 min^-1・50%定格トルク時の電機子端子電圧

50%定格トルクなので `I_a=10 A`。

`E = 187.5×1000/1500 = 125 V`

`V_a = E + I_a R_a + 2.5 = 125+5+2.5 = 132.5 V`

候補: `132.5 V`（3桁表記 `133 V`）。

### (5) (4)運転状態のS1通流率

正方向電流時、S1 ON状態は `198 V`、S1 OFF時のD2還流状態は `-1 V`。

S1通流率を `D` とすると

`132.5 = 198D + (-1)(1-D) = 199D-1`

したがって

`D = 133.5/199 = 0.670854...`

候補: `0.671`。

### (6) 定格制動トルクを制御できる回転速度範囲

定格制動では `I_a=-20 A`。正回転時の端子電圧は

`V_a = E - 20×0.5 - 2.5 = E-12.5`

負方向電流時、S2 ON状態では `V_a=2 V`、D1回生状態では `V_a=201 V` なので、可逆チョッパが作れる平均端子電圧は

`2 ≤ V_a ≤ 201`

したがって

`14.5 ≤ E ≤ 213.5`

一定界磁で `E∝n` より

`1500×14.5/187.5 ≤ n ≤ 1500×213.5/187.5`

`116 ≤ n ≤ 1708 min^-1`

候補: `116 ≤ n ≤ 1.708×10^3 min^-1`（3桁表記 `116 ≤ n ≤ 1.71×10^3 min^-1`）。

候補固定: `6 / 6`。
