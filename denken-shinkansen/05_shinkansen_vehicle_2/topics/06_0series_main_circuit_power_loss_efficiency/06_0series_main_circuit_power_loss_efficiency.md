# EXAM_ALIGNMENT

資格: 第二種電気主任技術者

主科目:
- 一次試験「機械」
- 二次試験「機械・制御」

論点:
- 入力電力、出力、損失の電力収支 `P_in = P_out + ΣP_loss`
- 効率 `η = P_out / P_in` と、複数機器を直列に通るときの総合効率
- 変圧器の無負荷損・負荷損、鉄損・銅損、負荷率による損失変化
- 変圧器の規約効率と最大効率条件
- 回転機の機械損、鉄損、銅損、漂遊負荷損、固定損・負荷損の区別
- 各機器損失を発熱として集計し、冷却が必要になる理由を電力収支から説明すること
- 0系主回路では、Topic 01〜03で扱った主変圧器・整流器・直流主電動機を一つのエネルギーフローへ統合すること

# 教材へ反映する必須説明

1. 架線側入力から主変圧器、整流器、直流主電動機、軸出力までのエネルギーフローを一枚の収支として示す。
2. `P_in = P_out + ΣP_loss` を基本式とし、機器別損失を足し上げて総合効率を求める。
3. 主変圧器は無負荷損と負荷損を分け、負荷率により銅損が変化するため効率曲線が変わることを示す。
4. 主電動機は銅損・鉄損・機械損・必要な範囲の負荷損を区別し、電気入力と軸出力の差として説明する。
5. 整流器損失はTopic 02の結果を前提に、交流側入力電力と直流側出力電力の差として扱う。後世代のスイッチング損失モデルは導入しない。
6. 全損失は最終的に発熱へつながり、冷却はその熱を除去するために必要であることまでを扱う。冷却方式の詳細設計や熱RCモデルは追加しない。
7. `軸出力` と指定グラフの `車輪側出力` の境界を明記し、未確認の歯車・駆動系損失を勝手に数値化しない。
8. SPEC指定4グラフだけを作る。0系の未確認実値は使わず、実値を使う場合は一次資料で出典を確定してから代入する。
