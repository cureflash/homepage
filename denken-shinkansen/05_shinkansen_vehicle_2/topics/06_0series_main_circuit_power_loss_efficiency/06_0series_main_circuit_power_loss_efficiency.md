# 解説本文

## 1. このテーマで電験は何を問うか

このテーマは、個々の機器を別々に計算するのではなく、入力電力・有効出力・損失を同一の電力収支へまとめる問題に対応する。一次試験では、損失の名称、規約効率、無負荷損・負荷損、最大効率条件を選択肢から判定できることが必要である。二次試験では、試験値から損失を分離し、負荷率を変えたときの銅損と出力を計算し、効率または最大効率点まで途中式付きで求める必要がある。

この章を終えた時点で、次を自力で処理できることを目標とする。

- 入力・出力・損失を同じ単位で整理する。
- 主変圧器、整流器、主電動機の損失をエネルギーフロー上で追跡する。
- 固定損と負荷依存損を分け、負荷率を変えたときの効率を求める。
- 無負荷試験・短絡試験の値から変圧器損失を読み取る。
- 全損失を発熱量として読み替え、冷却が必要な理由を説明する。

## 2. 主回路全体のエネルギーフロー

計算の出発点は保存則である。

`P_in = P_out + ΣP_loss`

ここで、`P_in [W]` は対象区間へ入る有効電力、`P_out [W]` は対象区間から外へ取り出せる有効出力、`ΣP_loss [W]` はその区間内で失われる電力の総和である。

Topic 06では、架線側入力から主変圧器、整流器、直流主電動機、軸出力までを次の順に追う。

`架線側入力 → 主変圧器 → 整流器 → 直流主電動機 → 軸出力`

各段の出力は次段の入力になる。したがって、各段の損失を `P_Tloss`, `P_Rloss`, `P_Mloss` とすると、駆動系損失をまだ含めない軸出力は

`P_shaft = P_line - P_Tloss - P_Rloss - P_Mloss`

である。ここで `P_Mloss` には、問題で区分されている範囲に応じて主電動機の銅損、鉄損、機械損、漂遊負荷損を含める。

総合効率は

`η_total = P_shaft / P_line`

である。百分率表示では `η_total × 100 [%]` とする。

複数機器の効率が個別に与えられ、機器間で別の入出力がない場合は

`η_total = η_T η_R η_M`

とも書ける。ただし、損失が個別の kW 値で与えられた問題では、先に電力収支で各段を追う方が取り違えにくい。

## 3. 主変圧器の損失と負荷率

主変圧器では、少なくとも無負荷損と負荷損を分ける。

### 3.1 無負荷損

無負荷損の主体は鉄損であり、定格電圧・定格周波数付近では負荷率による変化を小さいものとして扱う。鉄損はヒステリシス損と渦電流損に分けられる。

選定過去問で必要な渦電流損の関係は

`P_e ∝ f^2 B_m^2 d^2`

である。`f` は周波数、`B_m` は最大磁束密度、`d` は鉄板厚さである。したがって、他条件が同じなら周波数、磁束密度、板厚の増加で渦電流損は増加する。

無負荷試験では、定格電圧を加えたときの入力電力を鉄損の近似値として扱う。電圧 `V_1`、無負荷電流 `I_0`、無負荷力率 `cosθ_0` が与えられるなら

`P_i ≈ V_1 I_0 cosθ_0`

で鉄損を求める。

### 3.2 負荷損

負荷損の中心は巻線の銅損であり、電流の二乗に比例する。

`P_c = I^2 R`

定格時の銅損を `P_c,r`、負荷率を `x` とし、電流が負荷率に比例するとき

`P_c(x) = x^2 P_c,r`

となる。ここが二次試験で最も重要な負荷率依存である。

### 3.3 規約効率

出力有効電力を `P_2` とすると、変圧器の規約効率は

`η_T = P_2 / (P_2 + P_i + P_c)`

である。負荷率 `x`、定格容量 `S_r [VA]`、負荷力率 `cosφ` を使えば

`P_2 = x S_r cosφ`

だから

`η_T(x) = x S_r cosφ / {x S_r cosφ + P_i + x^2 P_c,r}`

となる。

### 3.4 最大効率条件

上式で `P_i` を一定、銅損を `x^2 P_c,r` とする場合、効率が最大となる条件は

`P_i = x^2 P_c,r`

すなわち

`x = sqrt(P_i / P_c,r)`

である。これは「鉄損とその負荷率での銅損が等しいとき最大効率」という形で覚える。

## 4. 無負荷試験・短絡試験から何が分かるか

無負荷試験は主として鉄損を求める試験である。一方、短絡試験では二次側を短絡し、定格電流が流れるまで低い電圧を加える。印加電圧が低いため鉄損を小さいものとして扱え、入力電力を定格電流時の負荷損、実用上は主として銅損の近似値として使う。

インピーダンス電圧は、二次を短絡した状態で定格電流を流すために一次側へ必要な電圧である。百分率表示では、定格一次電圧に対する比で表す。Topic 06では等価回路定数の詳細導出へは戻らず、「短絡試験から負荷損を読み取る」という損失計算上の役割だけを使う。

## 5. 整流器損失

整流器はTopic 02で扱った交流入力を直流出力へ変換する段である。このテーマでは素子の詳細損失モデルへ進まず、整流器の交流側有効入力電力 `P_R,in` と直流側出力電力 `P_R,out` の差を損失と定義する。

`P_Rloss = P_R,in - P_R,out`

整流器効率が与えられる場合は

`η_R = P_R,out / P_R,in`

より

`P_Rloss = P_R,in (1 - η_R)`

と計算できる。

後世代のIGBTやSiCのスイッチング損失式は使わない。

## 6. 主電動機損失と軸出力

主電動機では、電気入力 `P_M,in` と軸出力 `P_shaft` の差が主電動機内の総損失である。

`P_M,in = P_shaft + P_Mloss`

`P_Mloss` を問題の条件に合わせて分解すると

`P_Mloss = P_Cu + P_Fe + P_mech + P_stray`

となる。

- `P_Cu`: 巻線抵抗による銅損。電流依存が強く、基本は `I^2R`。
- `P_Fe`: 鉄損。
- `P_mech`: 軸受、ブラシ等に伴う機械損として扱う範囲。
- `P_stray`: 漂遊負荷損。主損失で説明しきれない負荷依存分として問題文の定義に従う。

回転機一般の過去問では励磁回路損が別項目として示される場合がある。ここでは同期発電機固有理論へ広げず、0系の直流主電動機を計算するときは問題文で与えられた損失区分に従う。

軸出力が求まったら

`η_M = P_shaft / P_M,in`

で電動機効率を求められる。

## 7. 総合効率と負荷率

主回路全体では、固定的に存在する損失と、負荷に応じて増える損失を分けると効率曲線を理解しやすい。

簡略モデルとして

`P_loss(x) = P_f + P_1 x + P_2 x^2`

とする。

- `P_f`: 鉄損や一部の機械損など、負荷率によらず一定と近似する損失
- `P_1 x`: 問題条件上、負荷に比例すると置いた損失
- `P_2 x^2`: 銅損のように電流二乗に比例する損失

有効出力を `P_out = Kx` と置くと

`η_total(x) = Kx / {Kx + P_f + P_1 x + P_2 x^2}`

となる。低負荷では固定損の比率が大きいため効率が下がり、高負荷では二乗で増える損失が効いてくる。このため、条件によっては中間負荷に最大効率点が現れる。

上の簡略モデルで最大効率点を求めると、比例損失 `P_1x` は最大点の位置を変えず、

`x_max = sqrt(P_f / P_2)`

となる。ただし、これはこの簡略損失モデルを明示的に仮定した場合だけに使う。

## 8. 発熱と冷却

電気的・機械的な損失は、最終的には機器内部や周囲へ熱として現れる。損失電力が一定なら、時間 `t [s]` に発生する熱エネルギーは

`Q = P_loss t`

である。単位は `J` であり、`1 kW = 1 kJ/s` だから、kW と秒を使えば kJ へ直しやすい。

冷却の役割は、この発生熱を外へ移すことである。Topic 06では「損失が発熱となり、損失が大きいほど除去すべき熱量も増える」ところまで扱う。冷却容量、温度上昇時定数、熱抵抗・熱容量による詳細熱モデルは扱わない。

## 9. 軸出力と車輪側出力の境界

SPECには「入力電力―車輪側出力」のグラフが指定されている。一方、このテーマで確認済みなのは主電動機の軸出力までであり、0系固有の歯車・駆動系損失は未確認である。

したがって、

`P_wheel = P_shaft - P_drive_loss`

と式で境界を明示する。`P_drive_loss` が資料で確認できない限り、実車値として数値を置かない。後工程でグラフ化するときは、`P_drive_loss = 0` を「理想伝達の計算条件」と明記した基準線、または明示的な仮定値を用いた感度線として示し、実車の車輪側出力とは混同しない。

## 10. 本試験で使う解法手順

1. 入力、出力、損失をすべて W または kW にそろえる。
2. 無負荷損・固定損と、負荷依存損を分ける。
3. 負荷率 `x` があれば、銅損を `x^2` 倍する。
4. 力率がある場合、出力有効電力を `x S_r cosφ` で求める。
5. `P_in = P_out + ΣP_loss` で収支を作る。
6. `η = P_out / P_in` で効率を求める。
7. 最大効率を問われたら、変圧器では `鉄損 = その負荷率での銅損` を確認する。
8. 主回路全体なら、各機器の出力を次段の入力へ渡し、二重計上を避ける。
9. 発熱量なら `Q=P_loss t` まで変換する。
10. 答えの効率が0〜1、または0〜100 %の範囲に入ること、出力が入力を超えていないことを検算する。

# 3段階例題

以下の数値はすべて学習用の仮定値であり、0系実車値ではない。

## 例題1 基礎: 主回路の電力収支

架線側有効入力を `1200 kW` とする。主変圧器損失 `36 kW`、整流器損失 `24 kW`、主電動機の銅損 `54 kW`、鉄損 `18 kW`、機械損 `12 kW` とする。軸出力と総合効率を求めよ。

### 解法

損失総和は

`ΣP_loss = 36 + 24 + 54 + 18 + 12 = 144 kW`

したがって

`P_shaft = 1200 - 144 = 1056 kW`

総合効率は

`η_total = 1056 / 1200 = 0.880`

よって

`η_total = 88.0 %`

である。

この問題では、各損失を一度ずつ足し、入力から引くことが本質である。機器効率へ変換してから掛け合わせる必要はない。

## 例題2 本試験標準: 負荷率と最大効率

定格容量 `500 kVA` の変圧器について、鉄損を `1.6 kW`、定格銅損を `2.5 kW` とする。負荷力率を `0.8` 一定とする。最大効率となる負荷率と、そのときの効率を求めよ。

### 解法

最大効率条件は

`P_i = x^2 P_c,r`

だから

`1.6 = 2.5 x^2`

`x^2 = 0.64`

`x = 0.80`

となる。

この負荷率での出力有効電力は

`P_2 = x S_r cosφ`

`= 0.80 × 500 × 0.80`

`= 320 kW`

銅損は

`P_c = 0.80^2 × 2.5 = 1.6 kW`

で、鉄損と等しい。

したがって

`η = 320 / (320 + 1.6 + 1.6)`

`= 320 / 323.2`

`≈ 0.9901`

よって最大効率は約 `99.0 %` である。

負荷率をそのまま銅損へ掛けるのではなく、銅損は `x^2` 倍する点が頻出ミスである。

## 例題3 複合: 主回路全体の負荷率―効率

学習用モデルとして、負荷率を `x` とし、軸出力を

`P_shaft = 800x [kW]`

総損失を

`P_loss = 30 + 20x + 75x^2 [kW]`

とする。`30 kW` は固定損、`20x kW` は負荷比例損、`75x^2 kW` は銅損をまとめた二乗損とする。

(1) `x=0.50` の総合効率を求めよ。

(2) `x=1.00` の総合効率を求めよ。

(3) この簡略モデルで効率が最大となる負荷率を求めよ。

### 解法

(1) `x=0.50`

`P_shaft = 800 × 0.50 = 400 kW`

`P_loss = 30 + 20×0.50 + 75×0.50^2`

`= 30 + 10 + 18.75 = 58.75 kW`

`η = 400 / (400 + 58.75) ≈ 0.8719`

よって約 `87.2 %`。

(2) `x=1.00`

`P_shaft = 800 kW`

`P_loss = 30 + 20 + 75 = 125 kW`

`η = 800 / 925 ≈ 0.8649`

よって約 `86.5 %`。

(3) このモデルでは

`x_max = sqrt(P_f / P_2)`

だから

`x_max = sqrt(30 / 75)`

`≈ 0.632`

となる。

このとき

`P_shaft ≈ 506.0 kW`

`P_loss ≈ 72.65 kW`

`η_max ≈ 506.0 / (506.0 + 72.65) ≈ 87.4 %`

である。

この例題の狙いは、低負荷では固定損、高負荷では二乗損が効率を下げることを数値で確認することである。比例損 `20x` はこの簡略モデルの最大効率負荷率の位置を変えないが、効率の値そのものは低下させる。

# SPEC指定4グラフの作図条件

後工程で作図するときは、実車未確認値を使わず、本文の学習用仮定値または一次資料で確認済みの値だけを使う。

## 1. 負荷率―総合効率

- 横軸: 負荷率 `x`
- 縦軸: `η_total [%]`
- 例題3の `P_shaft=800x`, `P_loss=30+20x+75x^2` を学習用モデルとして使用可能
- `x=0` では有効出力が0なので効率を0除算しない。作図は正の小負荷から始める。

## 2. 機器別損失内訳

- 横軸: 負荷率または選定した運転条件
- 縦軸: 損失 `kW`
- 主変圧器、整流器、主電動機、機械損を別系列で示す。
- 各系列は「固定」「比例」「二乗」のどの仮定に基づくかを凡例または注記で明示する。

## 3. 入力電力―車輪側出力

- 横軸: 主回路入力電力 `P_line`
- 縦軸: 車輪側出力 `P_wheel`
- `P_wheel=P_shaft-P_drive_loss` を使用する。
- 未確認の0系駆動系損失を実値化しない。`P_drive_loss=0` を使う場合は「理想伝達」と明記する。

## 4. 条件変更時の損失比較

- 同一出力または同一負荷率を基準にする。
- 変更するのは一度に一つの仮定値だけとし、どの損失項を何%変更したかを明記する。
- 0系の改良効果と断定せず、「計算条件変更による感度比較」として扱う。

# 頻出ミス・ひっかけ

- `kVA` をそのまま有効出力 `kW` としない。力率が必要なら掛ける。
- 銅損を負荷率 `x` 倍ではなく `x^2` 倍する。
- 鉄損と定格銅損が等しい条件ではなく、鉄損と「その負荷率での銅損」が等しい条件が最大効率である。
- 同じ損失を機器効率と損失kWの両方で引いて二重計上しない。
- 主電動機の軸出力と車輪側出力を同一の実車値として扱わない。
- 効率の `0.95` と `95 %` を取り違えない。
- 発熱量 `Q` と損失電力 `P_loss` を取り違えない。前者はJ、後者はWである。
