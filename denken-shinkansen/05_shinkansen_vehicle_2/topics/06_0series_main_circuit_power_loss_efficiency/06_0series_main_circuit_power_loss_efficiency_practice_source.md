# 一次試験型

## 問1 主回路全体の電力収支

ある主回路について、架線側有効入力電力を `1500 kW` とする。主変圧器損失 `45 kW`、整流器損失 `30 kW`、主電動機銅損 `72 kW`、主電動機鉄損 `24 kW`、機械損 `15 kW` とする。その他の損失は無視する。

軸出力と架線入力から軸出力までの総合効率の組合せとして正しいものを選べ。

1. `1269 kW`, `84.6 %`
2. `1314 kW`, `87.6 %`
3. `1356 kW`, `90.4 %`
4. `1407 kW`, `93.8 %`
5. `1500 kW`, `100 %`

### 正答

2

### 完全解説

主回路全体では、各損失を一度ずつ合計して入力から引く。

```text
ΣP_loss
=45+30+72+24+15
=186 kW
```

したがって軸出力は

```text
P_shaft=1500-186
       =1314 kW
```

総合効率は

```text
η_total=P_shaft/P_in
       =1314/1500
       =0.876
       =87.6 %
```

よって正答は2である。

この問題では、損失を入力から引いた後に、さらに各損失を効率として重複して掛けないことが重要である。

## 問2 負荷率と変圧器効率

定格容量 `600 kVA` の変圧器について、鉄損を `2.0 kW`、定格電流時の銅損を `3.2 kW` とする。負荷率 `x=0.75`、負荷力率 `0.80` のとき、規約効率として最も近いものを選べ。

1. `97.85 %`
2. `98.35 %`
3. `98.65 %`
4. `98.96 %`
5. `99.42 %`

### 正答

4

### 完全解説

負荷率 `x` のとき、出力有効電力は

```text
P_2=xS_r cosφ
   =0.75×600×0.80
   =360 kW
```

銅損は電流二乗に比例するので、

```text
P_c=x^2P_c,r
   =0.75^2×3.2
   =1.8 kW
```

したがって規約効率は

```text
η=360/(360+2.0+1.8)
 =360/363.8
 ≈0.98955
 ≈98.96 %
```

よって正答は4である。

`3.2 kW` をそのまま使う、または `0.75×3.2` とするのは誤りである。銅損は `x^2` 倍する。

## 問3 最大効率となる負荷率

ある変圧器の鉄損が `1.8 kW`、定格銅損が `5.0 kW` である。鉄損を負荷率によらず一定、銅損を負荷率 `x` の二乗に比例するとする。

最大効率となる負荷率として正しいものを選べ。

1. `0.36`
2. `0.60`
3. `0.72`
4. `0.80`
5. `1.00`

### 正答

2

### 完全解説

変圧器の最大効率条件は

```text
P_i=x^2P_c,r
```

である。したがって

```text
1.8=5.0x^2
x^2=0.36
x=0.60
```

となる。よって正答は2である。

`0.36` は負荷率そのものではなく `x^2` である点に注意する。

## 問4 無負荷試験・短絡試験

変圧器の損失試験に関する記述として最も適切なものを選べ。

1. 無負荷試験では主として鉄損を求め、短絡試験では定格電流時の負荷損を求める。インピーダンス電圧は、二次側を短絡して定格電流を流すために一次側へ必要な電圧である。
2. 無負荷試験では主として定格銅損を求め、短絡試験では鉄損を求める。
3. 無負荷試験と短絡試験は、どちらも主として機械損を求める試験である。
4. 短絡試験では定格一次電圧を必ず加えるため、鉄損を無視できない。
5. インピーダンス電圧は、二次側を開放した状態で定格二次電圧を得るために一次側へ必要な電圧である。

### 正答

1

### 完全解説

無負荷試験では二次側を開放し、定格電圧を加える。無負荷電流は小さいため銅損を小さいものとして扱い、入力電力を主として鉄損とみなす。

短絡試験では二次側を短絡し、定格電流が流れるまで低い電圧を加える。磁束が小さいため鉄損を小さいものとして扱い、入力電力を定格電流時の負荷損、実用上は主として銅損の近似値として用いる。

また、インピーダンス電圧は二次短絡時に定格電流を流すために一次へ必要な電圧である。

したがって正答は1である。

## 問5 回転機の損失分類

回転機の効率計算で、鉄損と機械損を負荷率によらず一定と近似し、銅損を `I^2R` とする。電流が定格値の `50 %` になったときの損失変化として正しいものを選べ。

1. 銅損は `50 %`、鉄損と機械損も `50 %` になる。
2. 銅損は `25 %`、鉄損は `50 %`、機械損は一定である。
3. 銅損は `25 %`、鉄損と機械損は近似上ほぼ一定である。
4. 銅損は一定、鉄損と機械損は `25 %` になる。
5. 銅損、鉄損、機械損はすべて `25 %` になる。

### 正答

3

### 完全解説

銅損は

```text
P_Cu=I^2R
```

なので、電流が `0.5` 倍なら

```text
P_Cu/P_Cu,r=(0.5)^2=0.25
```

となる。

一方、この問題では鉄損と機械損を負荷率によらず一定と近似する条件を明示している。したがって正答は3である。

実際の機器では損失の依存性がさらに複雑になる場合があるが、本問では問題文の近似条件に従う。

## 問6 整流器の損失

整流器の交流側有効入力電力が `960 kW`、整流器効率が `97.5 %` である。直流側出力電力と整流器損失の組合せとして正しいものを選べ。

1. `960 kW`, `24 kW`
2. `936 kW`, `9.6 kW`
3. `936 kW`, `36 kW`
4. `936 kW`, `24 kW`
5. `984 kW`, `-24 kW`

### 正答

4

### 完全解説

整流器効率は

```text
η_R=P_R,out/P_R,in
```

だから、

```text
P_R,out=960×0.975
       =936 kW
```

損失は入力と出力の差なので、

```text
P_Rloss=960-936
       =24 kW
```

よって正答は4である。

このテーマでは整流器の詳細な素子損失モデルへは進まず、交流側入力と直流側出力の差として損失を扱う。

## 問7 損失電力と発熱量

主回路各機器の損失の合計が一定の `125 kW` で、同じ運転状態が `12 min` 続いた。発生する熱エネルギーとして正しいものを選べ。

1. `15 MJ`
2. `75 MJ`
3. `90 MJ`
4. `125 MJ`
5. `1500 MJ`

### 正答

3

### 完全解説

時間を秒へ直す。

```text
12 min=720 s
```

損失電力が一定なら

```text
Q=P_loss t
```

だから、

```text
Q=125 kW×720 s
 =90000 kJ
 =90 MJ
```

となる。正答は3である。

`kW×s=kJ` であることを使うと単位換算を誤りにくい。

## 問8 段階的な主回路電力収支

架線側有効入力電力を `2000 kW` とする。主変圧器損失が `60 kW`、整流器効率が `98.0 %`、主電動機内部の総損失が `120 kW` である。その他の損失を無視する。

主電動機軸出力と総合効率の組合せとして正しいものを選べ。

1. `1781.2 kW`, `98.0 %`
2. `1820.0 kW`, `91.0 %`
3. `1901.2 kW`, `95.1 %`
4. `1781.2 kW`, `89.1 %`
5. `1740.0 kW`, `87.0 %`

### 正答

4

### 完全解説

まず主変圧器出力は

```text
P_T,out=2000-60
       =1940 kW
```

これが整流器入力になる。整流器出力は

```text
P_R,out=1940×0.98
       =1901.2 kW
```

これが主電動機電気入力である。主電動機内部損失を引くと

```text
P_shaft=1901.2-120
       =1781.2 kW
```

総合効率は

```text
η_total=1781.2/2000
       =0.8906
       ≈89.1 %
```

よって正答は4である。

各段の出力を次段の入力へ順に渡し、損失を二重計上しないことが重要である。

## 問9 無負荷試験・短絡試験から最大効率点を求める

定格容量 `800 kVA` の単相変圧器について、次の試験結果が得られた。

- 無負荷試験入力: `2.40 kW`
- 短絡試験入力: 定格電流時に `6.00 kW`

無負荷試験では銅損を無視でき、短絡試験では鉄損を無視できるものとする。負荷力率は `0.90` 一定とする。

次を求めよ。

1. 鉄損 `P_i`
2. 定格銅損 `P_c,r`
3. 最大効率となる負荷率 `x`
4. そのときの出力有効電力
5. 最大効率

### 完全解説

#### (1) 鉄損

無負荷試験入力を主として鉄損とみなすので、

```text
P_i=2.40 kW
```

である。

#### (2) 定格銅損

定格電流での短絡試験入力を主として定格銅損とみなすので、

```text
P_c,r=6.00 kW
```

である。

#### (3) 最大効率負荷率

最大効率条件は

```text
P_i=x^2P_c,r
```

だから、

```text
2.40=6.00x^2
x^2=0.400
x=sqrt(0.400)
 ≈0.6325
```

となる。

#### (4) 出力有効電力

```text
P_2=xS_r cosφ
```

より、

```text
P_2=0.6325×800×0.90
   ≈455.4 kW
```

である。

#### (5) 最大効率

この負荷率では銅損が鉄損に等しいので、

```text
P_c=x^2P_c,r=2.40 kW
```

したがって

```text
η_max
=455.4/(455.4+2.40+2.40)
≈0.98957
≈98.96 %
```

となる。

#### 検算

- `0<x<1` を満たす。
- 最大効率点で `P_i=P_c=2.40 kW` になっている。
- 効率は100 %未満である。

この流れがR2二次・H22二次で要求される「試験値から損失分離→負荷率→最大効率」の基本アルゴリズムである。

## 問10 主回路全体の損失・効率・発熱

教材用の主回路モデルで、架線側有効入力電力を `1800 kW` とする。

- 主変圧器損失: `50 kW`
- 整流器効率: `97.5 %`
- 主電動機内部総損失: `110 kW`

その他の損失を無視する。同じ運転状態が `20 min` 続いたとする。

次を求めよ。

1. 主変圧器出力
2. 整流器出力
3. 主電動機軸出力
4. 架線入力から軸出力までの総合効率
5. 主回路全体の損失電力
6. 20分間の発熱量

### 完全解説

#### (1) 主変圧器出力

```text
P_T,out=1800-50
       =1750 kW
```

#### (2) 整流器出力

```text
P_R,out=1750×0.975
       =1706.25 kW
```

整流器損失は

```text
P_Rloss=1750-1706.25
       =43.75 kW
```

である。

#### (3) 主電動機軸出力

```text
P_shaft=1706.25-110
       =1596.25 kW
```

#### (4) 総合効率

```text
η_total=1596.25/1800
       ≈0.88681
       ≈88.68 %
```

#### (5) 主回路全体の損失電力

入力と軸出力の差から

```text
P_loss,total
=1800-1596.25
=203.75 kW
```

各損失を足しても

```text
50+43.75+110=203.75 kW
```

となり一致する。

#### (6) 20分間の発熱量

```text
20 min=1200 s
```

だから、

```text
Q=203.75 kW×1200 s
 =244500 kJ
 =244.5 MJ
```

となる。

#### 検算

- 各段で出力は入力を超えていない。
- 損失を機器別に足した値と、主回路入力―軸出力の差が一致する。
- 総合効率は100 %未満である。

## 問11 簡略損失モデルの最大効率

負荷率を `x` とする教材用モデルで、軸出力と主回路総損失を次のように置く。

```text
P_shaft=1000x [kW]
P_loss=36+24x+100x^2 [kW]
```

ここで `36 kW` は固定損、`24x kW` は負荷比例損、`100x^2 kW` は二乗損である。

次を求めよ。

1. 総合効率 `η(x)`
2. 最大効率となる負荷率 `x_max` を導け
3. `x=x_max` での総損失と最大効率
4. `x=1.0` での効率と比較せよ

### 完全解説

#### (1) 総合効率

入力は出力と損失の和だから、

```text
η(x)
=1000x/{1000x+36+24x+100x^2}
```

である。

#### (2) 最大効率負荷率

効率最大化は、出力1 kW当たりの損失

```text
P_loss/P_shaft
=(36+24x+100x^2)/(1000x)
=36/(1000x)+24/1000+100x/1000
```

を最小にすることと同値である。

`x` で微分すると

```text
d/dx(P_loss/P_shaft)
=-36/(1000x^2)+100/1000
```

最大効率点ではこれが0なので、

```text
36/x^2=100
x^2=0.36
x_max=0.60
```

となる。

これは一般形

```text
x_max=sqrt(P_f/P_2)
```

に一致する。比例損失 `P_1x` はこの簡略モデルでは最大効率点の位置を変えない。

#### (3) 最大効率点

`x=0.60` のとき、

```text
P_shaft=1000×0.60
       =600 kW
```

```text
P_loss
=36+24×0.60+100×0.60^2
=36+14.4+36
=86.4 kW
```

したがって

```text
η_max=600/(600+86.4)
     ≈0.87413
     ≈87.41 %
```

である。

#### (4) 定格負荷との比較

`x=1.0` では

```text
P_loss=36+24+100
      =160 kW
```

```text
η(1)=1000/(1000+160)
    ≈0.86207
    ≈86.21 %
```

よって、この仮定モデルでは `x=0.60` の方が高効率である。

#### 検算

`x=0.60` では固定損 `36 kW` と二乗損 `100x^2=36 kW` が等しくなっており、導出結果と整合する。

## 問12 条件変更時の損失・効率・発熱比較

同じ軸出力 `900 kW` を得る2つの教材用運転条件A・Bについて、機器別損失が次のように与えられている。

| 損失 | 条件A | 条件B |
|---|---:|---:|
| 主変圧器損失 | `25 kW` | `21 kW` |
| 整流器損失 | `15 kW` | `12 kW` |
| 主電動機銅損 | `40 kW` | `25 kW` |
| 主電動機鉄損 | `12 kW` | `12 kW` |
| 機械損 | `8 kW` | `8 kW` |

その他の損失は無視する。

次を求めよ。

1. 条件A・Bの総損失
2. 条件A・Bの必要入力電力
3. 条件A・Bの総合効率
4. 条件Bによる損失削減量
5. 30分運転したときの発熱量削減分

### 完全解説

#### (1) 総損失

条件A:

```text
P_loss,A=25+15+40+12+8
        =100 kW
```

条件B:

```text
P_loss,B=21+12+25+12+8
        =78 kW
```

#### (2) 必要入力電力

```text
P_in=P_shaft+P_loss
```

だから、

```text
P_in,A=900+100=1000 kW
P_in,B=900+78=978 kW
```

となる。

#### (3) 総合効率

条件A:

```text
η_A=900/1000
   =0.900
   =90.0 %
```

条件B:

```text
η_B=900/978
   ≈0.92025
   ≈92.0 %
```

である。

#### (4) 損失削減量

```text
ΔP_loss=100-78
       =22 kW
```

#### (5) 30分間の発熱量削減分

```text
30 min=1800 s
```

だから、

```text
ΔQ=22 kW×1800 s
   =39600 kJ
   =39.6 MJ
```

となる。

#### 検算

同じ軸出力で比較しているため、損失が小さい条件Bの方が必要入力が小さく、総合効率が高くなる。発熱量削減分も損失削減量と運転時間の積になっている。
