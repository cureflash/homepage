## 4. R2 二次 機械・制御 問2

問題条件:

```text
S_r = 100 kVA
V_1 = 6600 V
R = 2.72 Ω
I_0 = 0.173 A
cosθ_0 = 0.35
```

### (1) 鉄損

```text
W_i = V_1 I_0 cosθ_0
    = 6600 × 0.173 × 0.35
    = 399.63 W
    ≈ 400 W
```

PASS。

### (2) 定格銅損

定格一次電流は

```text
I_1r = 100000 / 6600
     = 15.1515 A
```

したがって

```text
W_c = R I_1r^2
    = 2.72 × 15.1515^2
    = 624.47 W
    ≈ 624 W
```

PASS。

### (3) 最大効率負荷率と最大効率

```text
W_i = x^2 W_c
x = sqrt(399.63 / 624.47)
  = 0.79997
  ≈ 0.800
```

最大効率負荷率は `80.0 %`。

力率1なので出力は約 `80.0 kW`。そのとき銅損は鉄損と等しいため、

```text
η_max = 80000 / (80000 + 399.63 + 0.8^2×624.47)
      ≈ 0.9901
      ≈ 99.0 %
```

PASS。

### (4) 負荷率30 %・力率60 %

```text
P_2 = 100000 × 0.30 × 0.60
    = 18000 W

W_c(0.3) = 0.30^2 × 624.47
         = 56.20 W

η = 18000 / (18000 + 399.63 + 56.20)
  ≈ 0.9753
  ≈ 97.5 %
```

PASS。

結果: `4 / 4 PASS`。

## 5. H22 二次 機械・制御 問2

問題条件:

```text
S_r = 300 kVA
V_1 = 6600 V
I_0 = 0.483 A
cosθ_0 = 0.325
η(負荷率0.3, 力率1) = η(負荷率0.7, 力率1)
```

### (1) 鉄損

```text
P_i = V_1 I_0 cosθ_0
    = 6600 × 0.483 × 0.325
    = 1036.0 W
    ≈ 1.04 kW
```

PASS。

### (2) 定格銅損

定格銅損を `P_c` とする。効率が等しい条件から、出力で除いた損失比を等置する。

```text
(P_i + 0.3^2 P_c) / 0.3
= (P_i + 0.7^2 P_c) / 0.7
```

整理すると

```text
P_c = 4.7619 P_i
    ≈ 4.93 kW
```

PASS。

### (3) 最大効率

```text
x_max = sqrt(P_i / P_c)
      = sqrt(1.04 / 4.93)
      ≈ 0.45826
```

最大効率点では負荷時銅損と鉄損が等しい。出力は

```text
P_2 = 300 × 0.45826
    ≈ 137.48 kW
```

総損失は約 `2×1.04 = 2.08 kW` なので、

```text
η_max ≈ 137.48 / (137.48 + 2.08)
      ≈ 0.985
      ≈ 98.5 %
```

PASS。

結果: `3 / 3 PASS`。
