# 一次試験型

## 問1 発電制動のエネルギーフロー

車両の発電制動について、本テーマで扱うエネルギーフローとして最も適切なものを選べ。

1. 電気エネルギー → 運動エネルギー → 架線へ返送
2. 運動エネルギー → 電気エネルギー → 制動抵抗のジュール熱
3. 位置エネルギー → 化学エネルギー → 制動抵抗のジュール熱
4. 運動エネルギー → 磁気エネルギー → 蓄電池へ蓄積
5. 電気エネルギー → 熱エネルギー → 運動エネルギー

### 正答

2

### 完全解説

R5一次機械問2の固定範囲で必要なのは、制動時に駆動用電動機を発電機として使い、車両の運動エネルギーを電気エネルギーへ変換すること、その電気エネルギーを車上抵抗で消費できることである。

```text
車両の運動エネルギー
→ 主電動機の発電機運転
→ 電気エネルギー
→ 制動抵抗のジュール熱
```

したがって正答は2である。架線へ電力を戻す回路・制御は本テーマの固定範囲外である。

## 問2 発電電圧と回転速度

一定磁束の直流機で、角速度 `120 rad/s` のとき発電電圧が `240 V` であった。磁束を一定のまま角速度を `75 rad/s` にしたときの発電電圧として正しいものを選べ。

1. `90 V`
2. `120 V`
3. `150 V`
4. `192 V`
5. `240 V`

### 正答

3

### 完全解説

直流機の誘導起電力は

```text
E=k_eΦω
```

である。磁束一定なら `E∝ω` なので、

```text
E_2/E_1=ω_2/ω_1
```

より

```text
E_2=240×75/120
   =150 V
```

となる。正答は3である。

## 問3 制動電流

発電制動中の直流機について、発電電圧 `E=180 V`、電機子抵抗 `R_a=0.40 Ω`、制動抵抗 `R_b=1.40 Ω` とする。ブラシ電圧降下とインダクタンスを無視したとき、制動電流として正しいものを選べ。

1. `75 A`
2. `90 A`
3. `100 A`
4. `120 A`
5. `129 A`

### 正答

3

### 完全解説

簡略回路では

```text
I_b=E/(R_a+R_b)
```

だから、

```text
I_b=180/(0.40+1.40)
   =180/1.80
   =100 A
```

となる。制動抵抗 `R_b` だけで割らず、電機子抵抗 `R_a` も含める。

## 問4 発電電力と抵抗発熱

問3と同じ条件 `E=180 V`, `I_b=100 A`, `R_a=0.40 Ω`, `R_b=1.40 Ω` とする。発電電力 `P_g`、制動抵抗電力 `P_R`、電機子銅損 `P_Cu` の組合せとして正しいものを選べ。

1. `P_g=18 kW`, `P_R=14 kW`, `P_Cu=4 kW`
2. `P_g=18 kW`, `P_R=18 kW`, `P_Cu=4 kW`
3. `P_g=14 kW`, `P_R=18 kW`, `P_Cu=4 kW`
4. `P_g=22 kW`, `P_R=14 kW`, `P_Cu=8 kW`
5. `P_g=14 kW`, `P_R=14 kW`, `P_Cu=0 kW`

### 正答

1

### 完全解説

発電電力は

```text
P_g=EI_b
   =180×100
   =18.0 kW
```

制動抵抗電力は

```text
P_R=I_b^2R_b
   =100^2×1.40
   =14.0 kW
```

電機子銅損は

```text
P_Cu=I_b^2R_a
    =100^2×0.40
    =4.0 kW
```

よって

```text
P_g=P_R+P_Cu
18=14+4 kW
```

となり、正答は1である。

## 問5 速度低下と制動トルク

一定磁束・固定抵抗の簡略発電制動モデルを考える。回転速度が初期値の50%になったとき、制動トルクの大きさは初期値のおよそ何%になるか。

1. `25%`
2. `50%`
3. `70.7%`
4. `100%`
5. `200%`

### 正答

2

### 完全解説

一定磁束では

```text
E∝ω
```

固定抵抗なら

```text
I_b=E/(R_a+R_b)∝ω
```

さらに

```text
T_b=k_tΦI_b
```

なので一定磁束では `T_b∝ω` である。したがって速度が50%なら制動トルクも50%になる。正答は2である。

## 問6 運動エネルギーと制動抵抗の発熱量

等価質量 `m_eq=1.60×10^5 kg` の車両が `25.0 m/s` から `15.0 m/s` まで減速した。機械損・ブラシ損等を無視し、電気側の合成抵抗に対する制動抵抗の割合が

```text
R_b/(R_a+R_b)=0.80
```

で一定とする。この間の制動抵抗発熱量として正しいものを選べ。

1. `6.40 MJ`
2. `20.0 MJ`
3. `25.6 MJ`
4. `32.0 MJ`
5. `40.0 MJ`

### 正答

3

### 完全解説

運動エネルギー減少は

```text
ΔK=1/2 m_eq(v_0^2-v_1^2)
```

だから、

```text
ΔK
=1/2×1.60×10^5×(25.0^2-15.0^2)
=3.20×10^7 J
=32.0 MJ
```

である。

その80%が制動抵抗へ入るので、

```text
Q_R=0.80×32.0
   =25.6 MJ
```

となる。正答は3である。

## 問7 時間―速度の簡略モデル

一定磁束・固定抵抗の教材用簡略モデルで、

```text
m_eq=2.00×10^5 kg
c_E=20.0 V/(m/s)
R_t=R_a+R_b=0.500 Ω
```

とする。速度時定数 `τ_b` と、速度が初期値の半分になるまでの時間 `t_1/2` の組合せとして最も近いものを選べ。

1. `τ_b=125 s`, `t_1/2=86.6 s`
2. `τ_b=200 s`, `t_1/2=138.6 s`
3. `τ_b=250 s`, `t_1/2=173.3 s`
4. `τ_b=250 s`, `t_1/2=250 s`
5. `τ_b=500 s`, `t_1/2=346.6 s`

### 正答

3

### 完全解説

速度時定数は

```text
τ_b=m_eqR_t/c_E^2
```

だから、

```text
τ_b
=(2.00×10^5×0.500)/20.0^2
=250 s
```

である。

速度は

```text
v(t)=v_0exp(-t/τ_b)
```

なので `v/v_0=1/2` とおくと、

```text
1/2=exp(-t/τ_b)
```

より

```text
t=τ_b ln2
 =250×0.693
 ≈173.3 s
```

となる。正答は3である。

## 問8 H24二次固定範囲の計算

端子電圧 `200 V`、電機子電流 `20 A`、軸出力 `3750 W`、ブラシ電圧降下 `2.5 V` の直流電動機がある。鉄損・機械損等は問題条件上無視され、残りを電機子銅損とする。

電機子抵抗 `R_a` と誘導起電力 `E` の組合せとして正しいものを選べ。

1. `R_a=0.250 Ω`, `E=192.5 V`
2. `R_a=0.500 Ω`, `E=187.5 V`
3. `R_a=0.500 Ω`, `E=190.0 V`
4. `R_a=1.00 Ω`, `E=177.5 V`
5. `R_a=1.25 Ω`, `E=172.5 V`

### 正答

2

### 完全解説

入力電力は

```text
P_in=VI_a
    =200×20
    =4000 W
```

ブラシ損は

```text
P_b=V_bI_a
   =2.5×20
   =50 W
```

したがって電機子銅損は

```text
P_Cu=4000-3750-50
    =200 W
```

よって

```text
R_a=P_Cu/I_a^2
   =200/20^2
   =0.500 Ω
```

誘導起電力は

```text
E=V-V_b-I_aR_a
 =200-2.5-20×0.500
 =187.5 V
```

となる。H24二次機械・制御問1(1)(2)の固定範囲と同じ計算経路であり、正答は2である。

## 問9 発電電圧から制動電力まで

一定磁束の直流機を発電制動に用いる。教材用仮定値として、

```text
k_eΦ=1.80 V·s/rad
k_tΦ=1.80 N·m/A
ω=100 rad/s
R_a=0.30 Ω
R_b=1.20 Ω
```

とする。ブラシ電圧降下、インダクタンス、機械損を無視する。

次を求めよ。

1. 発電電圧 `E`
2. 制動電流 `I_b`
3. 制動トルクの大きさ `T_b`
4. 発電電力 `P_g`
5. 制動抵抗電力 `P_R` と電機子銅損 `P_Cu`
6. 電力収支の検算

### 完全解説

まず発電電圧は

```text
E=(k_eΦ)ω
 =1.80×100
 =180 V
```

である。

合成抵抗は

```text
R_t=R_a+R_b
   =0.30+1.20
   =1.50 Ω
```

だから、

```text
I_b=E/R_t
   =180/1.50
   =120 A
```

である。

制動トルクの大きさは

```text
T_b=(k_tΦ)I_b
   =1.80×120
   =216 N·m
```

発電電力は

```text
P_g=EI_b
   =180×120
   =21600 W
   =21.6 kW
```

制動抵抗電力は

```text
P_R=I_b^2R_b
   =120^2×1.20
   =17280 W
   =17.28 kW
```

電機子銅損は

```text
P_Cu=I_b^2R_a
    =120^2×0.30
    =4320 W
    =4.32 kW
```

したがって、

```text
P_R+P_Cu
=17.28+4.32
=21.60 kW
=P_g
```

となり、電力収支が一致する。

## 問10 損失から電機子抵抗と誘導起電力を求める

直流電動機について、教材用仮定値として端子電圧 `240 V`、電機子電流 `30 A`、軸出力 `6750 W`、ブラシ電圧降下 `3.0 V` とする。鉄損・機械損等は問題条件上無視し、入力と軸出力・ブラシ損との差を電機子銅損とする。

1. 電機子抵抗 `R_a` を求めよ。
2. 誘導起電力 `E` を求めよ。
3. それぞれの式の単位を示せ。

### 完全解説

入力電力は

```text
P_in=VI_a
    =240×30
    =7200 W
```

ブラシ損は

```text
P_b=V_bI_a
   =3.0×30
   =90 W
```

よって電機子銅損は

```text
P_Cu=P_in-P_out-P_b
    =7200-6750-90
    =360 W
```

したがって

```text
R_a=P_Cu/I_a^2
   =360/30^2
   =0.400 Ω
```

である。

誘導起電力は電圧方程式

```text
V=E+V_b+I_aR_a
```

から

```text
E=V-V_b-I_aR_a
 =240-3.0-30×0.400
 =225 V
```

となる。

単位は `R_a [Ω]`, `E [V]` である。H24二次固定範囲と同じ解法順序で、まず損失から `R_a`、次に電圧方程式から `E` を求める。

## 問11 運動エネルギー減少と制動抵抗発熱量

等価質量 `m_eq=1.50×10^5 kg` の車両が `30.0 m/s` から `18.0 m/s` まで減速した。教材用簡略モデルとして、

```text
R_a=0.050 Ω
R_b=0.200 Ω
```

とし、一定磁束・固定抵抗、ブラシ損・機械損・他の走行抵抗を無視する。

1. 運動エネルギーの減少量 `ΔK` を求めよ。
2. 制動抵抗へ入るエネルギー割合を求めよ。
3. 制動抵抗の発熱量 `Q_R` を求めよ。
4. 電機子抵抗での発熱量との和が `ΔK` に一致することを確認せよ。

### 完全解説

運動エネルギー減少は

```text
ΔK
=1/2 m_eq(v_0^2-v_1^2)
=1/2×1.50×10^5×(30.0^2-18.0^2)
=4.32×10^7 J
=43.2 MJ
```

である。

合成抵抗は

```text
R_t=R_a+R_b
   =0.250 Ω
```

制動抵抗へ入る割合は

```text
R_b/R_t
=0.200/0.250
=0.80
```

だから、

```text
Q_R=0.80×43.2
   =34.56 MJ
```

となる。

電機子抵抗での発熱割合は

```text
R_a/R_t=0.050/0.250=0.20
```

なので、

```text
Q_Cu=0.20×43.2
    =8.64 MJ
```

である。

したがって

```text
Q_R+Q_Cu
=34.56+8.64
=43.20 MJ
=ΔK
```

となり、エネルギー収支が一致する。

## 問12 速度―制動力・時間―速度・累積発熱量

一定磁束・固定抵抗の教材用簡略モデルを考える。仮定値は次のとおり。

```text
m_eq=1.80×10^5 kg
c_E=24.0 V/(m/s)
R_a=0.060 Ω
R_b=0.300 Ω
v_0=27.0 m/s
v_1=9.0 m/s
```

ブラシ損・機械損・他の走行抵抗を無視する。

1. 合成抵抗 `R_t` を求めよ。
2. `F_b=(c_E^2/R_t)v` を用いて速度―制動力の比例係数と初期制動力を求めよ。
3. 速度時定数 `τ_b` を求めよ。
4. `27.0 m/s` から `9.0 m/s` まで低下する時間を求めよ。
5. この間の運動エネルギー減少 `ΔK` と制動抵抗発熱量 `Q_R` を求めよ。
6. 初期の発電電圧、制動電流、制動抵抗電力を求め、単位を確認せよ。

### 完全解説

合成抵抗は

```text
R_t=R_a+R_b
   =0.060+0.300
   =0.360 Ω
```

である。

速度―制動力の比例係数は

```text
c_E^2/R_t
=24.0^2/0.360
=1600 N·s/m
```

なので、

```text
F_b(v)=1600v
```

初期制動力は

```text
F_b(27.0)=1600×27.0
          =43200 N
          =43.2 kN
```

である。

速度時定数は

```text
τ_b=m_eqR_t/c_E^2
   =(1.80×10^5×0.360)/24.0^2
   =112.5 s
```

となる。

速度式

```text
v(t)=v_0exp(-t/τ_b)
```

から、

```text
t=τ_b ln(v_0/v_1)
 =112.5 ln(27.0/9.0)
 =112.5 ln3
 ≈123.6 s
```

である。

運動エネルギー減少は

```text
ΔK
=1/2×1.80×10^5×(27.0^2-9.0^2)
=5.832×10^7 J
=58.32 MJ
```

である。

制動抵抗へ入る割合は

```text
R_b/R_t
=0.300/0.360
=5/6
```

なので、

```text
Q_R=(5/6)×58.32
   =48.6 MJ
```

となる。

初期の発電電圧は

```text
E_0=c_Ev_0
   =24.0×27.0
   =648 V
```

初期制動電流は

```text
I_0=E_0/R_t
   =648/0.360
   =1800 A
```

初期制動抵抗電力は

```text
P_R(0)=I_0^2R_b
      =1800^2×0.300
      =972000 W
      =972 kW
```

である。

検算として、初期の発電電力は

```text
P_g(0)=E_0I_0
      =648×1800
      =1.1664 MW
```

一方、`F_bv` は

```text
F_b(27.0)×27.0
=43.2×10^3×27.0
=1.1664 MW
```

となり一致する。

この問題はSPEC指定4グラフのうち、速度―制動力、時間―速度、制動抵抗の累積発熱へ直接接続する。速度―制動電力は `P_R∝v^2` である。
