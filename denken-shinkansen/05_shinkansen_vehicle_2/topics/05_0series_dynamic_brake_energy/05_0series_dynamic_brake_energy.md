# EXAM_ALIGNMENT

資格: 第二種電気主任技術者

主科目:
- 一次試験「機械」
- 二次試験「機械・制御」

論点:
- 制動時に駆動用電動機を発電機として使い、車両の運動エネルギーを電気エネルギーへ変換すること
- 発電された電気エネルギーを車上抵抗で消費する発電制動のエネルギーフロー
- 直流機の誘導起電力 `E = k_e Φω` と、界磁一定なら `E ∝ ω` となること
- 制動抵抗を含む簡略回路での制動電流 `I_b = E / (R_a + R_b)`（ブラシ電圧降下等を無視する簡略条件）
- 制動トルク `T_b = k_t Φ I_b` と、一定磁束・固定抵抗なら速度低下に伴い制動電流・制動トルクも低下すること
- 抵抗での制動電力 `P_R = I_b^2 R_b` と発熱量 `Q_R = ∫ P_R dt`
- 車両側の運動エネルギー `K = 1/2 m_eq v^2` と、制動力から速度低下を求める運動方程式
- 発電電力、抵抗発熱、電機子銅損を区別すること。主回路全体の総合効率計算はTopic 06へ送ること

## R5 一次 機械 問2 固定範囲部分

公式問題では、制動時に駆動用電動機を使って運動エネルギーを電気エネルギーへ変換する記述になっている。公式解答から、固定範囲の空欄は次のとおり。

- (2) `ホ` = 制動
- (3) `チ` = 電気エネルギー

さらに問題文末尾に、電気鉄道で他列車が電気エネルギーを消費できない場合、制動車両で変換した電気エネルギーを車上の抵抗で消費する方法があると明記されている。

したがってTopic 05では、単に「発電ブレーキ」という用語を覚えるだけでなく、

`車両の運動エネルギー → 主電動機の発電機運転 → 電気エネルギー → 制動抵抗のジュール熱`

までを式と単位で追えるようにする必要がある。

R5問2の誘導電動機、バッテリー、回生ブレーキは本テーマから除外する。

## H24 二次 機械・制御 問1 固定範囲部分

(1) 定格時の入力は `200 V × 20 A = 4000 W`。軸出力3750 W、ブラシ損失 `2.5 V × 20 A = 50 W` を差し引くと電機子銅損は `200 W`。

したがって、

`R_a = 200 / 20^2 = 0.500 Ω`

で公式標準解答と一致する。

(2) 誘導起電力は、

`E = 200 - 2.5 - 0.500 × 20 = 187.5 V ≒ 188 V`

で公式標準解答と一致する。

この `E` と回転速度の比例関係を発電機運転側へ接続し、発電制動時の制動電流・制動トルク・抵抗電力を求める基礎とする。

(3)〜(6)は可逆チョッパの素子電圧降下、通流率、昇圧動作等が必要であり、Topic 05の固定範囲を越えるためゲート対象から除外する。

# 過去問から逆算した教材必須説明

本文には最低限、次を入れる。

1. 発電制動の物理的意味
   - 制動時は主電動機を発電機として使う
   - 車両の運動エネルギーが電気エネルギーへ変換され、制動抵抗等で熱になる
   - 回生制動との違いは最小限の境界説明に留め、回生の回路・制御は扱わない
2. 発電電圧
   - `E = k_e Φω`
   - 記号、単位、成立条件
   - 界磁一定なら `E ∝ ω`
3. 制動電流
   - 簡略抵抗回路で `I_b = E/(R_a+R_b)`
   - ブラシ電圧降下等を含める場合と無視する場合の条件を区別
4. 制動トルク
   - `T_b = k_t Φ I_b`
   - 一定磁束・固定抵抗なら速度低下に伴い `E`, `I_b`, `T_b` が低下する
5. 制動電力と発熱量
   - 発電電力 `P_g = E I_b`
   - 制動抵抗電力 `P_R = I_b^2 R_b`
   - 電機子銅損 `I_b^2 R_a` と区別
   - 発熱量 `Q_R = ∫P_R dt`
6. 車両のエネルギーと速度低下
   - `K = 1/2 m_eq v^2`
   - `m_eq dv/dt = -F_b` の簡略モデル
   - `v` はm/sへ換算して計算する
7. SPEC指定4グラフ
   - 速度―制動力
   - 速度―制動電力
   - 時間―速度
   - 制動抵抗の発熱量
8. 二次記述答案で必要な順序
   - 条件整理→発電電圧→制動電流→制動トルク/電力→エネルギー積分→速度低下
   - 各段階で単位と近似条件を明記
