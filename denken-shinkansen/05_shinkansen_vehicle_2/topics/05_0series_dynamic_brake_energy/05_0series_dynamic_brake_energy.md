論点:
- 制動時に駆動用電動機を発電機として使い、車両の運動エネルギーを電気エネルギーへ変換すること

- 抵抗での制動電力 `P_R = I_b^2 R_b` と発熱量 `Q_R = ∫ P_R dt`
- 車両側の運動エネルギー `K = 1/2 m_eq v^2` と、制動力から速度低下を求める運動方程式
- 発電電力、抵抗発熱、電機子銅損を区別すること。主回路全体の総合効率計算はTopic 06へ送ること

## H24 二次 機械・制御 問1 固定範囲部分

(1) 定格時の入力は `200 V × 20 A = 4000 W`。軸出力3750 W、ブラシ損失 `2.5 V × 20 A = 50 W` を差し引くと電機子銅損は `200 W`。

したがって、

```text
R_a = 200 / 20^2 = 0.500 Ω
```

で公式標準解答と一致する。

(2) 誘導起電力は、

```text
E = 200 - 2.5 - 0.500 × 20 = 187.5 V ≒ 188 V
```

で公式標準解答と一致する。

この `E` と回転速度の比例関係を発電機運転側へ接続し、発電制動時の制動電流・制動トルク・抵抗電力を求める基礎とする。

(3)〜(6)は可逆チョッパの素子電圧降下、通流率、昇圧動作等が必要であり、Topic 05の固定範囲を越えるためゲート対象から除外する。

# 解説本文

## 1. このテーマで電験は何を問うか

このテーマでは、直流主電動機を発電機として使う制動を、電圧・電流・トルク・電力・エネルギー・速度低下まで一つの計算鎖として扱う。

一次試験では、制動時に駆動用電動機を使って車両の運動エネルギーを電気エネルギーへ変換すること、その電気エネルギーを抵抗で消費できることを判断できる必要がある。二次試験では、直流機の電機子抵抗と誘導起電力を途中式付きで求め、その結果を発電機運転側の計算へ再利用できることが重要になる。

この章の到達目標は次のとおり。

1. `E=k_eΦω` から発電電圧を求められる。
2. 簡略抵抗回路で `I_b=E/(R_a+R_b)` を使える。
3. `T_b=k_tΦI_b` から制動トルクを求められる。
4. `P_g=EI_b`、`P_R=I_b^2R_b`、`I_b^2R_a` を区別できる。
5. `Q_R=∫P_Rdt` から制動抵抗の発熱量を求められる。
6. `K=1/2m_eqv^2` と運動方程式から速度低下を求められる。
7. 一定磁束・固定抵抗の簡略モデルでSPEC指定4グラフの形を説明できる。
8. 二次記述答案として、条件整理から速度低下まで途中式・単位・近似条件を示せる。

## 2. 発電制動のエネルギーフロー

力行中の直流機は電気エネルギーを機械エネルギーへ変換する。発電制動ではこの向きを逆にし、回転している主電動機を発電機として使う。

本テーマのエネルギーフローは

```text
車両の運動エネルギー
→ 主電動機の発電機運転
→ 電気エネルギー
→ 制動抵抗のジュール熱
```

である。

R5一次問2で必要なのは、この「運動エネルギー→電気エネルギー」と「車上抵抗で消費」という関係である。

本テーマでは抵抗で消費する発電制動だけを扱う。電気エネルギーを架線側へ戻す回路・制御は後続テーマの範囲であり、ここでは扱わない。

## 3. 発電電圧とH24二次に必要な直流機の式

直流機の誘導起電力は

```text
E = k_eΦω
```

で表す。

- `E`: 誘導起電力・発電電圧 `[V]`
- `k_e`: 機械構造で決まる起電力定数
- `Φ`: 1極当たり磁束 `[Wb]`
- `ω`: 角速度 `[rad/s]`

界磁一定なら

```text
E ∝ ω
```

であり、速度が半分になれば発電電圧も半分になる。

H24二次問1の固定範囲では、電動機運転時の電圧方程式

```text
V = E + V_b + I_aR_a
```

から

```text
E = V - V_b - I_aR_a
```

を使う。損失から `R_a` を求め、次に `E` を求める順序が重要である。

発電制動側では、回転によって生じた `E` が抵抗回路へ電流を流す原因になる。ブラシ電圧降下を無視する簡略モデルでは

```text
E = I_b(R_a+R_b)
```

となる。

## 4. 制動電流と制動トルク

電機子抵抗を `R_a`、外部の制動抵抗を `R_b` とし、ブラシ電圧降下・インダクタンスを無視する定常簡略回路では

```text
I_b = E/(R_a+R_b)
```

である。

したがって一定磁束なら

```text
E ∝ ω
→ I_b ∝ ω
```

となる。

電磁トルクの大きさは

```text
T_b = k_tΦI_b
```

である。制動時にはこのトルクが回転方向と反対向きに働く。ここでは `T_b` を制動トルクの大きさとして正値で扱う。

一定磁束・固定抵抗なら

```text
ω ↓
→ E ↓
→ I_b ↓
→ T_b ↓
```

となる。したがって抵抗値を固定した単純な発電制動モデルでは、低速になるほど制動トルクが小さくなる。

## 5. 発電電力・抵抗電力・電機子銅損

発電機の内部で電気エネルギーへ変換される電力は

```text
P_g = EI_b
```

である。

制動抵抗で熱になる電力は

```text
P_R = I_b^2R_b
```

電機子抵抗で熱になる銅損は

```text
P_Cu = I_b^2R_a
```

である。

簡略回路 `E=I_b(R_a+R_b)` では

```text
P_g
= EI_b
= I_b^2(R_a+R_b)
= P_Cu+P_R
```

となる。

したがって `P_g` と `P_R` を同じものとして扱ってはいけない。制動抵抗だけの発熱量を求めるなら

```text
Q_R = ∫P_Rdt
```

を積分する。

`P_R` が一定なら `Q_R=P_Rt` だが、一定磁束・固定抵抗で速度が低下する場合は `E` と `I_b` も低下するため、一般には `P_R` は一定ではない。

## 6. 運動エネルギーと速度低下

列車の等価質量を `m_eq`、速度を `v` とすると、並進運動としてまとめた運動エネルギーは

```text
K = 1/2 m_eq v^2
```

である。

速度は必ずSI単位 `[m/s]` に直して使う。

車輪周で列車へ働く制動力の大きさを `F_b` とすると、他の抵抗をここでは無視する簡略モデルでは

```text
m_eq dv/dt = -F_b
```

となる。

固定された歯車比・車輪径をまとめて、一定磁束時の発電電圧を車両速度で

```text
E = c_E v
```

と表す。`c_E` は `[V/(m/s)]` の等価定数であり、0系の実値ではなく問題条件から与える量として扱う。

さらに `R_t=R_a+R_b` とおけば

```text
I_b = c_Ev/R_t
```

である。機械損を無視し、電磁変換電力 `EI_b` が車輪側の制動仕事率 `F_bv` に対応する簡略モデルでは

```text
F_bv = EI_b
```

より

```text
F_b = (c_E^2/R_t)v
```

となる。

よって運動方程式は

```text
m_eq dv/dt = -(c_E^2/R_t)v
```

であり、初速度を `v_0` とすると

```text
v(t)=v_0 exp(-t/τ_b)
```

ただし

```text
τ_b = m_eqR_t/c_E^2
```

である。

この式は、一定磁束・固定抵抗・機械損等を無視した教材用簡略モデルである。実車の制動制御全体を表すものではない。

## 7. エネルギー収支から発熱量を検算する

時刻 `t_0` から `t_1` までに速度が `v_0` から `v_1` へ低下したとする。運動エネルギーの減少は

```text
ΔK = 1/2 m_eq(v_0^2-v_1^2)
```

である。

簡略抵抗回路では、発電電力のうち制動抵抗へ入る割合は

```text
R_b/(R_a+R_b)
```

なので、機械損・ブラシ損等を無視する同じモデルでは

```text
Q_R
= {R_b/(R_a+R_b)}ΔK
```

とも求められる。

これは

```text
Q_R = ∫I_b^2R_bdt
```

を時間積分した結果と一致する。二次記述では、時間積分による計算とエネルギー収支による検算を相互に使える。

## 8. SPEC指定4グラフの作図条件

以下は一定磁束・固定抵抗の教材用簡略モデルである。実車値を使う場合は一次資料で確認された値だけを用いる。

### 8.1 速度―制動力

`E=c_Ev` より

```text
F_b(v)=(c_E^2/R_t)v
```

となるため、原点を通る直線になる。

### 8.2 速度―制動電力

発電電力は

```text
P_g(v)
= EI_b
= (c_E^2/R_t)v^2
```

制動抵抗電力は

```text
P_R(v)
= I_b^2R_b
= {c_E^2R_b/R_t^2}v^2
```

であり、どちらも速度の2乗に比例する。

### 8.3 時間―速度

簡略モデルでは

```text
v(t)=v_0exp(-t/τ_b)
```

なので、速度は指数関数的に低下する。

### 8.4 制動抵抗の発熱量

累積発熱量は

```text
Q_R(t)=∫_0^t P_R(ξ)dξ
```

である。

`v(t)=v_0exp(-t/τ_b)` を使うと

```text
P_R(t)
= P_R(0)exp(-2t/τ_b)
```

なので

```text
Q_R(t)
= P_R(0)(τ_b/2){1-exp(-2t/τ_b)}
```

となる。グラフは0から単調に増加し、速度低下に伴って傾き `dQ_R/dt=P_R` が小さくなる。

## 9. 二次記述答案の組み立て方

答案は次の順にすると、式の意味と単位を追いやすい。

```text
1. 条件と近似を整理する
2. 発電電圧 E を求める
3. 制動電流 I_b を求める
4. 制動トルク T_b または制動力 F_b を求める
5. 発電電力 P_g と抵抗電力 P_R を分けて求める
6. Q_R=∫P_Rdt で発熱量を求める
7. K=1/2m_eqv^2 または m_eq dv/dt=-F_b で速度低下を求める
8. 電力収支・エネルギー収支で検算する
```

ブラシ電圧降下を無視するか、界磁一定か、抵抗値固定か、機械損を無視するかを答案の冒頭または該当式の直前に明記する。

## 10. 3段階例題

以下の数値は、H24二次の固定範囲として明示した値を使う標準例題を除き、すべて教材用の仮定値である。0系の実車値ではない。

### 10.1 基礎例題: 発電電圧から制動電流・トルク・発熱を求める

一定磁束の直流機を教材用に次のように仮定する。

```text
k_eΦ = 2.0 V·s/rad
k_tΦ = 2.0 N·m/A
ω = 100 rad/s
R_a = 0.50 Ω
R_b = 1.50 Ω
```

ブラシ電圧降下・機械損・インダクタンスは無視する。

発電電圧は

```text
E=(k_eΦ)ω
 =2.0×100
 =200 V
```

制動電流は

```text
I_b=E/(R_a+R_b)
   =200/(0.50+1.50)
   =100 A
```

制動トルクの大きさは

```text
T_b=(k_tΦ)I_b
   =2.0×100
   =200 N·m
```

発電電力は

```text
P_g=EI_b
   =200×100
   =20.0 kW
```

制動抵抗電力は

```text
P_R=I_b^2R_b
   =100^2×1.50
   =15.0 kW
```

電機子銅損は

```text
P_Cu=I_b^2R_a
    =100^2×0.50
    =5.0 kW
```

よって

```text
P_g=P_R+P_Cu
20.0=15.0+5.0 kW
```

となり、電力収支が一致する。

### 10.2 本試験標準例題: H24二次の固定範囲から電機子抵抗・誘導起電力を求める

H24二次問1の固定範囲として、端子電圧 `200 V`、電機子電流 `20 A`、軸出力 `3750 W`、ブラシ電圧降下 `2.5 V` の直流機を考える。固定範囲外の可逆チョッパ計算には進まない。

入力電力は

```text
P_in=200×20
    =4000 W
```

ブラシ損失は

```text
P_b=2.5×20
   =50 W
```

したがって電機子銅損は

```text
P_Cu=4000-3750-50
    =200 W
```

よって

```text
R_a=P_Cu/I_a^2
   =200/20^2
   =0.500 Ω
```

である。

誘導起電力は

```text
E=V-V_b-I_aR_a
 =200-2.5-20×0.500
 =187.5 V
 ≒188 V
```

となり、公式標準解答と一致する。

発電制動でこの直流機を同じ磁束のまま半分の速度で回すと仮定すれば

```text
E_g=187.5×0.5
   =93.75 V
```

となる。さらに教材用に `R_b=1.00 Ω` と仮定し、ブラシ電圧降下を無視する簡略回路なら

```text
I_b=93.75/(0.500+1.00)
   =62.5 A
```

となる。

この例題では、二次試験で求めた `R_a` と `E` を、発電機運転側の制動電流へ接続する。

### 10.3 複合例題: 速度低下と制動抵抗の発熱量を一つのモデルで求める

0系の実値ではない教材用仮定値として、車両側へ換算した簡略モデルを次のように置く。

```text
m_eq = 2.00×10^5 kg
c_E = 30.0 V/(m/s)
R_a = 0.050 Ω
R_b = 0.250 Ω
v_0 = 30.0 m/s
v_1 = 15.0 m/s
```

一定磁束、固定抵抗、ブラシ損・機械損・他の走行抵抗を無視する。

合成抵抗は

```text
R_t=R_a+R_b
   =0.300 Ω
```

速度―制動力係数は

```text
c_E^2/R_t
=30.0^2/0.300
=3000 N·s/m
```

なので

```text
F_b(v)=3000v
```

である。初速度と終速度では

```text
F_b(30)=90.0 kN
F_b(15)=45.0 kN
```

となる。

速度時定数は

```text
τ_b=m_eqR_t/c_E^2
   =(2.00×10^5×0.300)/30.0^2
   =66.7 s
```

である。

`v(t)=v_0exp(-t/τ_b)` より、30.0 m/sから15.0 m/sになる時間は

```text
t
=τ_b ln(v_0/v_1)
=66.7 ln(30.0/15.0)
≈46.2 s
```

となる。

初期の発電電圧・制動電流は

```text
E_0=c_Ev_0
   =30.0×30.0
   =900 V

I_0=E_0/R_t
   =900/0.300
   =3000 A
```

である。

初期の発電電力と制動抵抗電力は

```text
P_g(0)=E_0I_0
      =2.70 MW

P_R(0)=I_0^2R_b
      =2.25 MW
```

となる。

速度低下による運動エネルギー減少は

```text
ΔK
=1/2 m_eq(v_0^2-v_1^2)
=1/2×2.00×10^5×(30.0^2-15.0^2)
=67.5 MJ
```

である。

この簡略回路で制動抵抗へ入る割合は

```text
R_b/R_t
=0.250/0.300
=5/6
```

なので、30.0 m/sから15.0 m/sまでの制動抵抗発熱量は

```text
Q_R=(5/6)×67.5
   =56.25 MJ
```

となる。

この結果は `Q_R=∫P_Rdt` を積分しても同じになる。複合計算では

```text
速度
→ 発電電圧
→ 制動電流
→ 制動力・制動電力
→ 運動方程式
→ 速度低下
→ 発熱量
```

の順に追い、最後にエネルギー収支で検算する。

## 13. 公式・解法まとめ

発電電圧:

```text
E=k_eΦω
```

一定磁束:

```text
E∝ω
```

簡略抵抗回路:

```text
I_b=E/(R_a+R_b)
```

制動トルク:

```text
T_b=k_tΦI_b
```

電力:

```text
P_g=EI_b
P_R=I_b^2R_b
P_Cu=I_b^2R_a
P_g=P_R+P_Cu
```

制動抵抗発熱量:

```text
Q_R=∫P_Rdt
```

運動エネルギー:

```text
K=1/2m_eqv^2
```

速度低下:

```text
m_eq dv/dt=-F_b
```

一定磁束・固定抵抗・固定伝達条件をまとめた簡略モデル:

```text
E=c_Ev
R_t=R_a+R_b
I_b=c_Ev/R_t
F_b=(c_E^2/R_t)v
τ_b=m_eqR_t/c_E^2
v(t)=v_0exp(-t/τ_b)
```

制動抵抗の累積発熱:

```text
Q_R(t)=∫_0^t P_R(ξ)dξ
```

同じ簡略モデルで速度 `v_0→v_1` の間:

```text
Q_R
={R_b/(R_a+R_b)}
 × 1/2m_eq(v_0^2-v_1^2)
```

二次答案の流れ:

```text
条件・近似
→ E
→ I_b
→ T_b または F_b
→ P_g, P_R
→ Q_R
→ K または運動方程式
→ 速度低下
→ 電力・エネルギー収支で検算
```
