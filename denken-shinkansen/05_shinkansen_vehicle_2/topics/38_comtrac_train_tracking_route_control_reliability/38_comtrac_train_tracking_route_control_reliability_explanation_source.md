## 1. このテーマで電験二種は何を問うか

この章で必要な技能は次のとおり。

1. 組合せ回路と順序回路を区別し、基本ブール演算を使う。
2. フリップフロップと状態遷移を結び付ける。
3. 状態データ、割込み、FIFO、優先度、スループットを区別する。
4. シーケンス制御とフィードバック制御を区別し、センサ・アクチュエータの役割を説明する。
5. ウォーターフォール、結合試験、ボトムアップ、ドライバ、スタブ、ブラックボックス試験を区別する。

## 2. 状態データ・割込み・待ち行列

情報処理系では、現在状態と状態を変えるイベントを分ける。

教材用の抽象状態を `WAIT`, `READY`, `RUN`, `BLOCKED` とすれば、状態遷移は

`S_next = f(S_current, Event)`

と書ける。`READY` は実行可能だがCPUを使用していない状態、`RUN` は実行中である。この状態名はCOMTRAC内部仕様ではない。

割込みは、イベント発生に応じて通常処理から所定の処理へ制御を移す仕組みである。一定周期で状態を順番に確認するポーリングとは区別する。

FIFO（First In First Out）は先入れ先出し。同一優先度の待ち行列なら、先に入った要求から処理する。優先度方式では、高優先度処理が継続的に到着すると低優先度処理が長時間実行されない starvation（飢餓）が起こり得る。

スループットは単位時間当たりに処理できる仕事量であり、1要求の完了までの時間である応答時間とは異なる。

## 3. ブール代数

論理変数を `0`, `1` で表す。

- AND: `A・B`
- OR: `A+B`
- NOT: `Ā`

基本則:

- `A・0=0`, `A・1=A`
- `A+0=A`, `A+1=1`
- `A・A=A`, `A+A=A`
- `A・Ā=0`, `A+Ā=1`

ド・モルガン則:

`overline(A・B)=Ā+B̄`

`overline(A+B)=Ā・B̄`

真理値表、論理式、ゲート回路を相互変換できることが試験上重要である。

## 4. 組合せ回路・順序回路・状態遷移

組合せ回路は現在入力だけで出力が決まる。

`Y=f(X)`

順序回路は内部状態を持つ。

`S_next=f(S,X)`

`Y=g(S,X)`

フリップフロップは二つの安定状態を持ち、1 bitの状態を保持できる。複数のフリップフロップで状態を表し、状態遷移表・状態遷移図から次状態論理を作れる。

ASIC（Application Specific Integrated Circuit）は特定用途向けに機能を集積したICであり、汎用プロセッサとは用途の固定度が異なる。

## 5. 論理最小化

同じ真理値表を実現する論理式は複数ある。Quine–McCluskey法はmintermを体系的にまとめ、主 implicant を抽出して論理式を簡単化する方法である。

ここで扱う論理最小化は一般論理回路の学習用であり、実際の鉄道安全論理の設計手順ではない。安全系ではフェイルセーフ、検証可能性、共通原因故障等を別途考える必要がある。

## 6. シーケンス制御・フィードバック・メカトロニクス

シーケンス制御は、定めた順序・条件に従って動作を進める制御である。

`条件A成立 -> 動作1 -> 条件B確認 -> 動作2`

フィードバック制御は、出力を検出して目標値との差を求め、その偏差に応じて操作量を修正する。

`目標値 -> 比較 -> 制御器 -> 制御対象 -> 出力 -> 検出 -> 比較へ戻る`

マイクロコンピュータはCPU、メモリ、入出力等を用いてデジタル制御処理を実行する。角位置センサは回転位置を検出するセンサ、ステッピングモータは入力パルスに対応して離散的な角度だけ回転する位置決め用アクチュエータである。

R8一次「機械」問8では、この5語を関係付けて識別する。

## 7. 列車追跡・状態データ・時刻情報

JR東海一次資料では、COMTRACが列車運行状況・設備状態を把握し、進路制御・列車運行管理等を支援すること、到着時刻・発車時刻、番線、列車順序等の運行条件を扱うことが確認できる。

電験の情報処理として抽象化すると、

1. 列車位置・運行条件等の状態データを受け取る。
2. 現在状態と時刻条件を整理する。
3. 許容される処理を論理判断する。
4. 処理後の状態を更新・監視する。

と整理できる。

ただしCOMTRAC内部の処理順、周期、データ構造、OS、スケジューリング方式、時刻同期方式は公開一次資料から確定していないため断定しない。

## 8. 列車位置検知とインターロック

JRTT一次資料では、軌道回路は列車位置を検知し、連動装置は転てつ器・信号機等を互いに関連付けて衝突や誤進入を防ぐ設備として説明される。

教材用の単純論理として

`Route_OK = Request ・ Track_Clear ・ Point_Locked ・ Conflict̄`

を置く。

- `Request`: 進路要求
- `Track_Clear`: 対象区間に列車がいない
- `Point_Locked`: 転てつ器が所定位置で鎖錠済み
- `Conflict`: 競合進路成立中

これはブール代数とインターロック概念を学ぶための仮定式であり、実際のCOMTRAC・電子連動装置の論理式ではない。

同様に教材用状態遷移を

`IDLE -> REQUESTED -> LOCKED -> CLEARED -> OCCUPIED -> RELEASED -> IDLE`

と置けるが、実設備の状態名・遷移順ではない。

## 9. ソフトウェア開発・試験

ウォーターフォール型開発は、要求・設計・実装・試験などの工程を原則として上流から順に進める考え方である。

単体試験は個々のモジュールを確認し、結合試験は複数モジュール間のインタフェースやデータ受け渡しを確認する。

ボトムアップ試験は下位モジュールから結合する。未完成の上位側から呼び出す代わりにテスト用ドライバを使うことがある。トップダウン試験は上位モジュールから結合し、未完成の下位モジュールの代わりにスタブを使うことがある。

ブラックボックス試験は内部構造ではなく仕様に基づく入力と出力の関係を確認する。

H29一次「機械」問8の固定5要素をこの節で全て区別できる。

## 10. UPSと冗長化

オンライン形UPSの基本的な考え方では、交流入力を整流して直流母線を作り、その直流をインバータで交流へ戻して負荷へ供給する。蓄電池を直流側へ接続すれば、入力交流が失われたときも蓄電池からインバータへ電力を供給できる。これは一般的なUPS構成の説明であり、COMTRAC電源構成の断定ではない。

直流側の電源・蓄電池経路を切り替える方式では直流スイッチの役割を区別する。交流バイパスへ切り替える場合は、無理な切替を避けるため商用系統とインバータ出力の周波数・位相等の同期条件が重要になる。

並列冗長は複数装置を並列運転し、1系故障後も残りで必要機能・容量を維持する考え方。`n+1` は必要容量を `n` 台で満たし、さらに1台分の予備を加える構成である。

バイパスは主系統の故障・保守時に別経路で負荷へ供給する経路である。

ただしn+1や並列化だけで共通原因故障、切替失敗、共通電源・通信経路の故障が消えるわけではない。

H26一次「機械」問3の固定5要素は、蓄電池を含む直流側構成、直流スイッチ、バイパス・並列冗長、同期、n+1容量である。

## 11. 信頼性・保全性・可用性

信頼性は、所定条件・所定時間で機能を維持する性質。修理可能系ではMTBFを指標として使う場合がある。

保全性は、故障後に機能を復旧しやすい性質。平均修復時間MTTR等を使う。

可用性は、必要な時に機能を利用できる割合。単純な二状態・修理可能系の教材モデルでは

`A = MTBF/(MTBF+MTTR)`

`U = 1-A = MTTR/(MTBF+MTTR)`

と置ける。

独立した二系統の各可用性が `a` で、どちらか一方が利用可能ならシステム利用可能、かつ完全切替を仮定する教材モデルでは

`A_parallel = 1-(1-a)^2`

となる。

実設備では故障分布、共通原因、切替失敗、保守遅延、計画停止等を考慮する必要がある。この式をCOMTRAC実値へ適用しない。

## 13. 例題1 — 基礎: ブール論理

教材用条件

`R=A・B・C̄`

で `A=1`, `B=1`, `C=0` なら

`R=1・1・1=1`

である。`C=1` なら `C̄=0` となり `R=0`。

狙いはANDとNOTの組合せであり、実設備論理ではない。

## 14. 例題2 — 本試験標準: 状態・FIFO・割込み

同一優先度の要求 `P1`, `P2`, `P3` がこの順にFIFO待ち行列へ入るなら、取り出し順も

`P1 -> P2 -> P3`

である。

実行中に高優先度割込み `I` が発生し、割込み受理条件を満たす場合は通常処理を一時中断して割込み処理へ移る。

FIFOを優先度順と誤認しない。割込みを単なる一定周期ポーリングと混同しない。

## 15. 例題3 — 複合: 可用性と冗長化

教材用仮定:

`MTBF=1000 h`

`MTTR=2 h`

単純二状態モデルでは

`A=1000/(1000+2)=0.998003992...`

約 `99.8004 %`。

独立・完全切替を仮定した同可用性二並列では

`A_parallel=1-(1-0.998003992...)^2`

`=0.999996015...`

約 `99.9996 %`。

この数値はCOMTRAC・第二総合指令所の実可用性ではない。

## 20. 公式・解法まとめ

- 状態遷移: `S_next=f(S_current, X)`
- 組合せ回路: `Y=f(X)`
- 順序回路: `S_next=f(S,X)`, `Y=g(S,X)`
- ド・モルガン: `overline(A・B)=Ā+B̄`, `overline(A+B)=Ā・B̄`
- 可用性教材モデル: `A=MTBF/(MTBF+MTTR)`
- 独立二並列教材モデル: `A_parallel=1-(1-a)^2`
- FIFO: 先入れ先出し
- starvation: 低優先度処理が実行機会を失う状態
- `n+1`: 必要台数nに予備1台を加える構成

解法手順:

1. 論理、状態、OS、試験、信頼性のどの分野か判定する。
2. 用語を機能で区別する。
3. 状態問題は現在状態・イベント・次状態を分ける。
4. 論理問題は真理値表またはBoolean式へ落とす。
5. 冗長化問題は必要容量、予備、バイパス、同期条件を確認する。
6. 可用性計算では単位と成立仮定を確認する。
7. 鉄道へ接続するとき一般モデルと一次資料で確認済みの実設備事実を分離する。
