# 一次試験型

## 問1 負の滑りと発電機運転

鉄道用の4極三相誘導電動機を `50 Hz` で動作させ、回転子速度が `1560 rpm` である。滑りと動作の組合せとして正しいものを選べ。

1. `s=+0.040`、電動機運転
2. `s=-0.040`、発電機運転・回生側
3. `s=-0.040`、同期速度と一致してトルク0
4. `s=+0.960`、発電機運転・回生側
5. `s=0`、発電機運転・回生側

### 正答

2

### 完全解説

同期速度は

```text
N_s = 120f/P
    = 120×50/4
    = 1500 rpm
```

滑りは

```text
s = (N_s-N)/N_s
  = (1500-1560)/1500
  = -0.040
```

`N>N_s` なので `s<0` となり、誘導機は発電機運転へ入る。同じ回転方向に対して電磁トルクは逆向きの制動トルクとなるため、本テーマの符号規約では回生側である。よって正答は2。

## 問2 四象限運転

回転速度 `ω` とトルク `T` の符号から四象限運転を判定する。正しいものを選べ。

1. `ω>0, T>0` は前進回生である。
2. `ω>0, T<0` は前進回生である。
3. `ω<0, T<0` は後進回生である。
4. `ω<0, T>0` は後進力行である。
5. トルクが負なら回転方向に関係なく必ず回生である。

### 正答

2

### 完全解説

機械電力は

`P_m=Tω`

で判定する。

- `ω>0, T>0` → `P_m>0` → 前進力行
- `ω>0, T<0` → `P_m<0` → 前進回生
- `ω<0, T<0` → `P_m>0` → 後進力行
- `ω<0, T>0` → `P_m<0` → 後進回生

したがって正答は2。トルク符号だけでは力行・回生を判定できない。

## 問3 機械電力の符号

前進方向を正とし、回転角速度が `ω=120 rad/s`、電磁トルクが `T=-750 N·m` である。機械電力と動作の組合せとして正しいものを選べ。

1. `+90 kW`、前進力行
2. `+90 kW`、前進回生
3. `-62.5 kW`、前進回生
4. `-90 kW`、前進回生
5. `-90 kW`、後進力行

### 正答

4

### 完全解説

```text
P_m = Tω
    = -750×120
    = -90000 W
    = -90 kW
```

`ω>0` かつ `T<0` なので第II象限であり、`P_m<0` の前進回生である。正答は4。

## 問4 回生時の電力フロー

誘導電動機車の回生時のエネルギー・電力フローとして最も適切なものを選べ。

1. 架線側交流 → PWMコンバータ → 直流中間回路 → インバータ → 誘導電動機 → 車輪
2. 車輪 → PWMコンバータ → 直流中間回路 → インバータ → 誘導電動機 → 架線側交流
3. 車輪 → 誘導電動機 → インバータ → 直流中間回路 → PWMコンバータ → 架線側交流
4. 直流中間回路 → 車輪 → 誘導電動機 → 架線側交流
5. 回生時も力行時と電力の向きは変わらない。

### 正答

3

### 完全解説

力行時は

`架線側交流 → PWMコンバータ → 直流中間回路 → インバータ → 誘導電動機 → 車輪`

である。回生時は機械エネルギーを電気エネルギーへ変換するため、流れは逆向きになり

`車輪 → 誘導電動機 → インバータ → 直流中間回路 → PWMコンバータ → 架線側交流`

となる。正答は3。

## 問5 力率1で交流側へ送る有効電流

単相PWM変換器が交流電源側へ有効電力 `P=600 kW` を送り、交流電源実効値が `V_L=1200 V`、力率1である。変換器側から交流電源側へ流れる電流 `I` として正しいものを選べ。

1. `250 A`
2. `400 A`
3. `500 A`
4. `720 A`
5. `1200 A`

### 正答

3

### 完全解説

力率1なので

```text
P = V_L I
I = P/V_L
  = 600000/1200
  = 500 A
```

正答は3。ここではH24二次型と同じく、変換器側から交流電源側へ流れる電流を正とする。

## 問6 変換器基本波電圧

変換器側から交流電源側へ電流を出力する向きを正とし、`V_L=1000 V`、`X=0.25 Ω`、`I=400 A`、力率1とする。`V_v=V_L+jXI` で表される変換器基本波電圧の大きさと位相として最も近いものを選べ。

1. `|V_v|=900 V`、`δ=-5.71°`
2. `|V_v|=1005 V`、`δ=+5.71°`
3. `|V_v|=1100 V`、`δ=0°`
4. `|V_v|=1000 V`、`δ=+22.6°`
5. `|V_v|=1400 V`、`δ=+45°`

### 正答

2

### 完全解説

リアクトル電圧は

```text
XI = 0.25×400 = 100 V
```

したがって

```text
V_v = 1000 + j100 V
```

大きさは

```text
|V_v| = sqrt(1000^2+100^2)
      = 1005 V
```

位相は

```text
δ = tan^-1(100/1000)
  = 5.71°
```

よって正答は2。電流方向を逆に定義した式を混在させない。

## 問7 問題指定PWMモデルの変調率

H24二次型の問題指定モデル `|V_v|=E_dK/sqrt(2)` を用いる。`|V_v|=1005 V`、`E_d=1600 V` のとき、変調率 `K` として最も近いものを選べ。

1. `0.444`
2. `0.628`
3. `0.800`
4. `0.888`
5. `1.421`

### 正答

4

### 完全解説

与えられた問題指定モデルから

```text
K = sqrt(2)|V_v|/E_d
  = sqrt(2)×1005/1600
  = 0.888
```

よって正答は4。この式はH24二次型の問題前提に基づくものであり、すべてのPWM変換器へ一般化しない。

## 問8 架線へ戻した回生電力の利用

同じ給電系統内で、ある車両が `700 kW` を架線へ回生し、別の力行車が同時に `500 kW` を必要としている。両車間の損失を無視し、回生電力をその力行車が利用できる条件が成立しているとする。この力行車が回生電力から受け取れる最大電力として正しいものを選べ。

1. `0 kW`
2. `200 kW`
3. `350 kW`
4. `500 kW`
5. `700 kW`

### 正答

4

### 完全解説

力行車の需要は `500 kW` であり、回生側は `700 kW` を返しているため、その力行車が受け取れる最大は需要分の `500 kW` である。

H27一次の固定対象で必要なのは、「架線へ返した回生電力を他の力行車が消費できる」という基本関係である。本問では、その先の回生失効、電力貯蔵設備、運行間隔は扱わない。正答は4。

前進方向を正とする。次の4状態について、機械電力 `P_m=Tω` の符号と、力行／回生を判定せよ。

(b) `ω>0, T<0`

| (b) | + | - | - | 前進回生 |
| (c) | - | - | + | 後進力行 |
| (d) | - | + | - | 後進回生 |

`P_m>0` を力行、`P_m<0` を回生と判定する。トルクの正負だけでなく、速度との積を見ることが必要である。

## 問10（二次2）誘導機の発電機運転

鉄道用の4極三相誘導電動機を `50 Hz` で動作させ、回転子速度が `1560 rpm` である。

(a) 同期速度 `N_s` を求めよ。

(b) 滑り `s` を求めよ。

(c) 発電機運転か電動機運転かを判定し、その理由を述べよ。

(d) 前進方向を正としたときのトルク方向と四象限を述べよ。

### 完全解説

(a) 同期速度は

```text
N_s = 120f/P
    = 120×50/4
    = 1500 rpm
```

(b) 滑りは

```text
s = (N_s-N)/N_s
  = (1500-1560)/1500
  = -0.040
```

(c) `N>N_s` で `s<0` なので発電機運転である。回転子から機械エネルギーを受け、電気側へ返す領域になる。

(d) 前進中なので `ω>0`。発電機運転では電磁トルクは回転方向と逆向きの制動トルクとなるので `T<0`。したがって第II象限であり、`P_m=Tω<0` の回生側である。

## 問11（二次3）PWM変換器から交流側へ有効電力を送る

H24二次型の教材用仮定として、単相交流電源実効値 `V_L=1000 V`、リアクトルのリアクタンス `X=0.20 Ω`、交流側へ送る有効電力 `P=500 kW`、直流電圧 `E_d=1600 V` とする。力率1、電流は変換器側から交流電源側を正とし、問題指定PWMモデルを `|V_v|=E_dK/sqrt(2)` とする。これらは300系の実車値ではない。

(a) リアクトルを介したフェーザ関係を示せ。

(b) 交流側へ流れる電流 `I` を求めよ。

(c) 変換器基本波電圧 `V_v` の複素数表示、大きさ `|V_v|`、位相角 `δ` を求めよ。

(d) 変調率 `K` を求めよ。

### 完全解説

(a) 電流方向を変換器側から交流電源側へ正とするので

```text
V_v = V_L + jXI
```

となる。

(b) 力率1では

```text
P = V_L I
I = P/V_L
  = 500000/1000
  = 500 A
```

(c) リアクトル電圧は

```text
XI = 0.20×500
   = 100 V
```

したがって

```text
V_v = 1000 + j100 V
```

大きさは

```text
|V_v| = sqrt(1000^2+100^2)
      = 1004.99 V
      ≈ 1005 V
```

位相角は

```text
δ = tan^-1(100/1000)
  = 5.71°
```

(d) 問題指定PWMモデルから

```text
K = sqrt(2)|V_v|/E_d
  = sqrt(2)×1004.99/1600
  = 0.888
```

よって `K≈0.888`。このPWM式は本問の前提に限って使い、一般化しない。

## 問12（二次4）回生可能エネルギー

教材用仮定として、質量 `m=2.00×10^5 kg` の車両群が `90 km/h` から `54 km/h` へ減速する。機械側から架線側までの段効率が順に `0.90`、`0.95`、`0.96` と与えられているとする。これらは300系の実車質量・回生効率ではない。

(a) 減少する運動エネルギー `ΔE_k` をJとMJで求めよ。

(b) 総合効率を求めよ。

(c) 架線側へ返るエネルギーをMJとkWhで求めよ。

(d) 前進中の減速としたとき、速度・トルクの符号と象限を述べよ。

### 完全解説

(a) 速度をSI単位へ直す。

```text
v_1 = 90/3.6 = 25 m/s
v_2 = 54/3.6 = 15 m/s
```

したがって

```text
ΔE_k = 1/2 m(v_1^2-v_2^2)
     = 1/2×2.00×10^5×(25^2-15^2)
     = 4.00×10^7 J
     = 40.0 MJ
```

(b) 総合効率は

```text
η = 0.90×0.95×0.96
  = 0.8208
```

(c) 架線側へ返るエネルギーは

```text
E_reg = ΔE_kη
      = 40.0×0.8208
      = 32.832 MJ
```

`1 kWh=3.6 MJ` より

```text
E_reg = 32.832/3.6
      = 9.12 kWh
```

(d) 前進中なので `ω>0`。減速させる制動トルクは回転方向と逆なので `T<0`。したがって第II象限、`P_m=Tω<0` の回生側である。

機械側で減少した `40.0 MJ` と架線返送量 `32.832 MJ` を混同しない。与えられていない効率を実車値として補わない。
