## 教材で欠落不可の説明

1. 誘導機の同期速度 `N_s=120f/P` と滑り `s=(N_s-N)/N_s` を確認し、`N>N_s` なら `s<0` となる発電機運転へ移ること、電磁トルクが回転方向と逆向きの制動トルクになることを説明する。
2. 四象限運転は回転速度 `ω` とトルク `T` の符号で整理し、機械電力 `P_m=Tω` の符号から力行／回生を判定できるようにする。速度・トルク平面の4象限をSPEC指定可視化へ接続する。
3. 力行では `架線→コンバータ→直流中間回路→インバータ→誘導電動機→車輪`、回生では `車輪→誘導電動機→インバータ→直流中間回路→コンバータ→架線` とエネルギー流が逆になることを示す。
4. H24二次型では、変換器側から交流電源へ電流を出力する向きを採用し、リアクトルを介したフェーザ関係 `V_v=V_L+jXI` を使う。力率1では `P=V_L I` から有効電流を求める。
5. H24二次問題で与えられたPWMモデルでは `V_v=E_d K/√2` を用いて変調率を逆算する。この式は当該問題の前提に基づくものとして一般化し過ぎない。
6. 架線へ戻った回生電力は他の力行車で消費できることを説明する。ただしH27の回生失効対策、電力貯蔵設備、運行間隔は本テーマへ追加しない。
7. 回生可能エネルギーは、機械側から取り出せるエネルギーと各変換段の損失を区別する。問題条件に質量・速度が与えられる場合は `ΔE_k=1/2 m(v_1^2-v_2^2)` を起点にし、段効率が与えられる場合のみ積で架線返送分を求める。未確認の300系実車回生効率を真値として置かない。
8. 電力・トルク・速度の符号規約を先に固定し、力行と回生を符号だけで取り違えない解法手順を示す。

# 解説本文

## 1. このテーマで電験二種は何を問うか

回生と四象限運転では、「ブレーキ時に電気を戻す」と覚えるだけでは不十分である。一次試験では、誘導機の滑りが負になる条件、発電機運転、制動トルク、回生時の電力の向きを選択肢へ落とせることが必要になる。二次試験では、直流側からPWM変換器とリアクトルを介して交流側へ有効電力を送るときの電圧・電流のフェーザ関係を式で扱えることが必要になる。

本テーマでは、次の順で判断する。

1. 回転方向の正負を決める。
2. トルク方向の正負を決める。
3. `P_m=Tω` の符号から力行か回生かを判定する。
4. 誘導機では同期速度と実速度から滑りの符号を確認する。
5. 回生時は機械側から直流中間回路、架線側へ電力が戻る向きを追う。
6. 二次型では電流方向を先に固定し、フェーザ式、電力式、PWM条件の順で計算する。
7. エネルギー問題では運動エネルギー差と変換損失を分けて扱う。

## 2. 符号規約と四象限運転

速度・トルク平面では、前進方向の回転速度を `ω>0`、前進方向へ加速させるトルクを `T>0` と定める。機械電力は

`P_m=Tω`

である。本テーマでは、`P_m>0` を電気エネルギーから機械エネルギーへ変換する力行、`P_m<0` を機械エネルギーから電気エネルギーへ変換する発電・回生として読む。

| 象限 | `ω` | `T` | `P_m=Tω` | 動作 |
|---|---:|---:|---:|---|
| 第I象限 | + | + | + | 前進力行 |
| 第II象限 | + | - | - | 前進回生 |
| 第III象限 | - | - | + | 後進力行 |
| 第IV象限 | - | + | - | 後進回生 |

重要なのは「トルクが負なら必ず回生」ではないことである。回生かどうかは `T` 単独ではなく、`Tω` の符号で判定する。第III象限では速度もトルクも負なので `P_m>0` となり、後進方向への力行である。

## 3. 誘導機の滑りと発電機運転

極数を `P`、周波数を `f [Hz]` とすると同期速度は

`N_s=120f/P [rpm]`

である。回転子速度を `N` とすると滑りは

`s=(N_s-N)/N_s`

である。

通常の電動機運転では `N<N_s` なので `s>0` である。これに対し、同じ回転方向で回転子速度が同期速度を超えて

`N>N_s`

となると

`s<0`

となる。この領域では誘導機は発電機運転となり、電磁トルクは回転方向と逆向きの制動トルクになる。前進中を正方向とすれば `ω>0`、`T<0` なので第II象限、`P_m<0` となる。

一次試験では、`s<0`、発電機運転、回生制動の三つを切り離さずに結び付けて読む。

## 4. 力行と回生の電力フロー

本テーマでは主回路を次の最小構成で扱う。

力行:

`架線側交流 → PWMコンバータ → 直流中間回路 → インバータ → 誘導電動機 → 車輪`

回生:

`車輪 → 誘導電動機 → インバータ → 直流中間回路 → PWMコンバータ → 架線側交流`

力行では交流側から受け取った電力を機械出力へ変換し、回生では列車の機械エネルギーを誘導機で電気エネルギーへ変換して架線側へ返す。R5一次・H28一次では、この「運動エネルギーを電気エネルギーへ変換する」ことと、誘導電動機が発電機運転へ入ることを同じ流れとして理解する必要がある。

## 5. 直流中間回路の役割

直流中間回路は、誘導機側インバータと架線側PWMコンバータの間で電力を受け渡す共通の直流側として扱う。

力行時はPWMコンバータから直流中間回路へ電力が入り、インバータが誘導機へ送る。回生時は逆に、誘導機が発生した電力をインバータ経由で直流中間回路へ送り、PWMコンバータが交流側へ返す。

したがって、回生を考えるときは「インバータが逆向きに電力を流せる」だけでは説明が途中である。直流中間回路を経て、架線側変換器まで電力フローを追うことが必要になる。

## 6. H24二次型: PWM変換器から交流側へ有効電力を送る

H24二次の固定対象では、DC電圧源を持つ単相PWM制御電圧形変換器が、リアクトルを介して交流電源側へ有効電力を出力する。ここでは問題の符号規約に合わせ、変換器側から交流電源側へ流れる電流 `I` を正とする。

交流電源電圧を `V_L`、変換器基本波電圧を `V_v`、リアクトルのリアクタンスを `X` とすると、フェーザ関係は

`V_v=V_L+jXI`

となる。

力率1で交流側へ有効電力 `P` を送るなら、`I` は `V_L` と同相なので

`P=V_L I`

から

`I=P/V_L`

を求める。次に

`|V_v|=sqrt(V_L^2+(XI)^2)`

`δ=tan^-1(XI/V_L)`

として、変換器電圧の大きさと位相を求める。

H24問題で与えられたPWMモデル

`|V_v|=E_d K/sqrt(2)`

を使う場合だけ、変調率 `K` を

`K=sqrt(2)|V_v|/E_d`

と逆算する。この関係は当該問題の前提であり、すべてのPWM変換器へ一般化しない。

## 7. 架線へ戻る回生電力

回生時に交流側へ返された電力は、架線側へ流れ、同じ給電系統で力行している車両の消費電力へ回ることがある。H27一次の固定対象で必要なのは、直流側の回生電力を交流側へ逆変換することと、架線へ返した電力を力行車が消費できるという基本関係である。

本テーマでは、そこから先の回生失効、電力貯蔵設備、運行間隔による受電条件へは広げない。

## 8. 回生可能エネルギーと損失

速度 `v_1` から `v_2` へ減速するとき、質量 `m` の物体が失う運動エネルギーは

`ΔE_k=1/2 m(v_1^2-v_2^2)`

である。これは機械側で減少したエネルギーであり、その全量が架線へ戻るわけではない。

問題文で誘導機、インバータ、PWMコンバータ等の段効率 `η_1,η_2,...` が与えられた場合、架線側へ返るエネルギーは

`E_reg=ΔE_k η_1η_2...`

とする。効率が与えられていない段について勝手な実車値を補わない。

JからkWhへ直すときは

`1 kWh=3.6×10^6 J`

を使う。電力 `W` とエネルギー `J`・`kWh` を混同しない。

## 9. 問題を見たときの解法手順

### 滑り・発電機運転型

1. `N_s=120f/P` で同期速度を求める。
2. `s=(N_s-N)/N_s` を計算する。
3. `s<0` なら発電機運転と判定する。
4. 回転方向と逆向きに電磁トルクが働くことを確認する。
5. `Tω<0` なら回生側であることを確認する。

### 四象限判定型

1. 正方向を明示する。
2. `ω` と `T` の符号を決める。
3. `P_m=Tω` の符号を求める。
4. `P_m>0` なら力行、`P_m<0` なら回生と判定する。

### H24二次型

1. 電流の正方向を確認する。
2. 力率1なら `I=P/V_L` を求める。
3. `V_v=V_L+jXI` から `|V_v|` と位相角を求める。
4. 問題で指定されたPWMモデルに限り `K=sqrt(2)|V_v|/E_d` を使う。
5. W・V・Aと位相角の単位を確認する。

### 回生エネルギー型

1. km/hをm/sへ直す。
2. `ΔE_k=1/2m(v_1^2-v_2^2)` を求める。
3. 与えられた段効率だけを積で掛ける。
4. 必要なら `3.6×10^6` で割ってkWhへ変換する。
5. 機械側減少エネルギーより架線返送エネルギーが大きくなっていないか検算する。

## 10. 3段階例題

### 10.1 基礎例題 — 負の滑りと発電機運転

4極誘導機を50 Hzの交流で動作させ、回転子速度が `1560 rpm` であるとする。同期速度と滑りを求め、動作を判定する。

同期速度は

`N_s=120×50/4=1500 rpm`

である。滑りは

`s=(1500-1560)/1500=-0.040`

となる。

`N>N_s`、`s<0` なので発電機運転である。前進方向を正とすれば、回転方向と逆向きの制動トルクが働き、第II象限の回生側になる。

### 10.2 本試験標準例題 — PWM変換器から交流側へ500 kWを送る

H24二次型の教材用仮定として、単相交流電源の実効値を `V_L=1000 V`、リアクトルのリアクタンスを `X=0.20 Ω`、交流側へ送る有効電力を `P=500 kW`、直流電圧を `E_d=1600 V` とする。力率1、電流は変換器側から交流電源側を正とし、PWMモデルは `|V_v|=E_dK/sqrt(2)` とする。これらは300系の実車値ではない。

まず

`I=P/V_L=500000/1000=500 A`

である。したがって

`V_v=1000+j(0.20×500)=1000+j100 V`

なので

`|V_v|=sqrt(1000^2+100^2)=1005 V`

位相角は

`δ=tan^-1(100/1000)=5.71°`

となる。

変調率は

`K=sqrt(2)×1005/1600=0.888`

である。計算順序は「有効電力→電流→変換器電圧→変調率→位相角」であり、電流の向きを逆に定義した式を混在させない。

### 10.3 複合・ひっかけ例題 — 回生エネルギーと四象限

教材用仮定として、質量 `m=2.00×10^5 kg` の車両群が `90 km/h` から `54 km/h` へ減速する。機械側から架線側までの各段効率が順に `0.90`、`0.95`、`0.96` と与えられているとする。これらは300系の実車質量・回生効率ではない。

速度をSI単位へ直すと

`v_1=90/3.6=25 m/s`

`v_2=54/3.6=15 m/s`

である。失う運動エネルギーは

`ΔE_k=1/2×2.00×10^5×(25^2-15^2)`

`=4.00×10^7 J=40.0 MJ`

である。

総合効率は

`η=0.90×0.95×0.96=0.8208`

なので、架線側へ返るエネルギーは

`E_reg=40.0×0.8208=32.832 MJ`

`=32.832/3.6=9.12 kWh`

となる。

前進中の減速なら `ω>0`、制動トルクは `T<0` なので第II象限、`Tω<0` で回生側である。`40.0 MJ` をそのまま架線返送量とすること、効率を逆に割ること、kWとkWhを混同することが典型的な誤りである。
