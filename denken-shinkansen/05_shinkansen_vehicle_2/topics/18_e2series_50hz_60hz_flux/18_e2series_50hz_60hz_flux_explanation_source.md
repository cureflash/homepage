## 1. このテーマで電験は何を問うか

第二種一次「機械」では、変圧器の誘起電圧式から周波数・電圧・巻数・最大磁束の関係を判断する問題、誘導電動機の同期速度と V/f 一定制御を判断する問題が出る。第二種二次「機械・制御」では、周波数、極数、滑りから同期速度、回転速度、滑り速度、二次周波数、回転磁界間の相対速度まで連続して求める力が必要である。

この章の到達点は次のとおり。

- `E = 4.44 f N Φ_m` を使い、周波数変更時の最大磁束を比で求められる。
- `B_m = Φ_m/A` を使い、周波数変更時の最大磁束密度を判断できる。
- V/f 一定で磁束を概ね一定に保つ理由を説明できる。
- `N_s = 120f/P`、`s=(N_s-N)/N_s`、`f_2=sf` を一貫して使える。
- 極数 `P` と極対数 `p` の表記差を処理できる。
- 電源周波数とインバータ出力周波数を混同しない。
- 機器定格を電圧と周波数の組として判断できる。

## 2. 変圧器誘起電圧・磁束・磁束密度

### 2.1 正弦波磁束から誘起電圧式を作る

巻線鎖交磁束を正弦波

`Φ(t)=Φ_m sin(ωt)`

とする。巻数 `N` の巻線に生じる誘起電圧の大きさはファラデーの法則から

`e(t)=N dΦ/dt`

であり、最大値は

`E_max=ωNΦ_m=2πfNΦ_m`

となる。正弦波の実効値は最大値の `1/√2` なので

`E=E_max/√2`

`=√2 π f N Φ_m`

`≈4.44 f N Φ_m`

となる。

記号と単位:

- `E`: 誘起電圧実効値 [V]
- `f`: 周波数 [Hz]
- `N`: 巻数
- `Φ_m`: 最大磁束 [Wb]

この式は正弦波磁束を前提にした式である。比計算では定数4.44が消えるので、周波数変更問題は比で処理すると速い。

### 2.2 周波数を変えたときの最大磁束

誘起電圧式を最大磁束について解くと

`Φ_m = E/(4.44 f N)`

である。巻数 `N` が同じなら

`Φ_m ∝ E/f`

となる。さらに印加電圧も同じなら

`Φ_m ∝ 1/f`

である。

状態1から状態2への比は

`Φ_m2/Φ_m1 = (E_2/E_1)(f_1/f_2)(N_1/N_2)`

となる。同一巻線なら `N_1=N_2` なので

`Φ_m2/Φ_m1 = (E_2/E_1)(f_1/f_2)`

である。

例えば同じ電圧を保ったまま 50 Hz から 60 Hz に上げると、最大磁束は

`Φ_60/Φ_50 = 50/60 = 5/6`

となり減少する。逆に 60 Hz 用の同じ巻線へ同じ電圧のまま 50 Hz を加えるなら、最大磁束は `60/50=1.20` 倍になる。この比は一般モデルであり、E2系実機の磁束値ではない。

### 2.3 磁束密度

鉄心断面積を `A` [m²] とすると最大磁束密度は

`B_m=Φ_m/A` [T]

である。同一鉄心では `A` が一定なので、最大磁束と最大磁束密度は同じ比で変化する。

したがって同一電圧・同一巻数・同一鉄心では

`B_m ∝ 1/f`

となる。周波数を下げるのに電圧を下げなければ磁束密度は上昇し、鉄心を飽和側へ動かす。反対に同じ電圧で周波数を上げれば磁束密度は下がる。

### 2.4 機器定格の判断

「50 Hz 定格」「60 Hz 定格」という周波数だけを単独で見ない。変圧器の磁束条件は `E/(fN)` で決まるため、同じ機器を別周波数で使えるかは、少なくとも電圧、周波数、巻数、許容磁束・磁束密度の組で判断する。

同じ巻線に同じ電圧を加える条件なら、周波数上昇は磁束を減らす側、周波数低下は磁束を増やす側である。試験ではこの向きを取り違えないことが重要である。

## 3. 誘導電動機の周波数・同期速度・滑り

### 3.1 同期速度

電源周波数を `f` [Hz]、極数を `P` とすると同期速度は

`N_s=120f/P` [min^-1]

である。機械角速度では

`ω_s=2πN_s/60=4πf/P` [rad/s]

となる。

問題によって極数を `2p` と書くことがある。このとき `P=2p` だから

`ω_s=2πf/p`

である。`P` を極数、`p` を極対数として使う表記を混同しない。

### 3.2 滑りと回転速度

実回転速度を `N` [min^-1] とすると滑りは

`s=(N_s-N)/N_s`

である。したがって

`N=(1-s)N_s`

となる。

固定子回転磁界と回転子の相対速度、すなわち滑り速度は

`N_s-N=sN_s`

である。

### 3.3 二次周波数

回転子巻線に誘導される電流の周波数を二次周波数 `f_2` とすると

`f_2=sf`

である。停止時は `s=1` なので `f_2=f`、同期速度に近づくと `s→0` なので `f_2→0` となる。

### 3.4 二つの回転磁界を相対速度で整理する

R2二次型では「何と何の相対速度か」を一つずつ分ける。

極数を `P` とし、固定子電源周波数を `f`、滑りを `s` とする。

1. 固定子電流が作る回転磁界と固定子の相対速度: `N_s`
2. 回転子と固定子の相対速度: `N=(1-s)N_s`
3. 固定子回転磁界と回転子の相対速度: `N_s-N=sN_s`
4. 回転子巻線電流の周波数: `f_2=sf`
5. 回転子電流が作る回転磁界と回転子の相対速度: `120f_2/P=sN_s`
6. 回転子電流が作る回転磁界と固定子の相対速度: `N+sN_s=N_s`
7. 回転子電流の回転磁界と固定子電流の回転磁界の相対速度: `0`

つまり、回転子から見ると回転子磁界は滑り速度で回るが、固定子から見ると固定子磁界と同じ同期速度で回る。

## 4. V/f 一定制御と二つの周波数

### 4.1 V/f 一定で磁束を保つ理由

誘導機でも、巻線の誘起電圧を概略

`E ≈ 4.44 f N Φ_m`

とみなせる。電圧降下を無視できる範囲では端子電圧 `V≈E` なので

`Φ_m ∝ V/f`

である。したがってインバータ出力周波数を変えるとき、電圧も比例して変え

`V/f = 一定`

とすれば、磁束を概ね一定に保てる。

この近似は低周波域の抵抗電圧降下等を別途扱う詳細制御では修正が必要になるが、Topic 18では固定SPECどおり V/f と磁束の基本関係までを扱う。

### 4.2 電源周波数とインバータ出力周波数を分ける

このテーマでは二つの周波数を明確に分ける。

- `f_src`: 車両へ供給される交流電源側の周波数
- `f_inv`: インバータが誘導電動機へ与える出力周波数

変圧器の磁束条件を考えるときは、対象巻線へ加わる交流の周波数を使う。誘導電動機の同期速度を考えるときは、その電動機へ実際に加わる `f_inv` を使う。

したがって、電源側が 50 Hz または60 Hzであることから、誘導電動機の同期速度を直接 `50 Hz` または `60 Hz` で計算してはいけない。主変換装置を介する場合、電動機の同期速度を決めるのはインバータ出力周波数である。

## 5. 問題を見たときの解法アルゴリズム

### 5.1 変圧器・磁束問題

1. 与えられた量が `E, f, N, A, Φ_m, B_m` のどれか整理する。
2. 正弦波前提なら `E=4.44fNΦ_m` を選ぶ。
3. 同一機器の周波数変更なら、まず比 `Φ_2/Φ_1=(E_2/E_1)(f_1/f_2)` を使えるか確認する。
4. 磁束密度が必要なら `B_m=Φ_m/A` へ接続する。
5. 周波数低下・電圧一定なら磁束増加、周波数上昇・電圧一定なら磁束減少という向きを確認する。
6. 機器定格の可否を問う場合、周波数だけでなく電圧との組を確認する。

### 5.2 誘導機の速度・周波数問題

1. 問題文の `p` が極数か極対数か確認する。
2. 極数 `P` を確定し `N_s=120f/P` を求める。
3. `s=(N_s-N)/N_s` または `N=(1-s)N_s` を使う。
4. 滑り速度は `sN_s` とする。
5. 二次周波数は `f_2=sf` とする。
6. 回転子磁界の相対速度を問われたら、基準が回転子か固定子かを確認する。
7. 固定子基準では固定子磁界と回転子磁界はいずれも同期速度で回ることを検算に使う。

### 5.3 周波数の取り違え防止

1. 変圧器側なら対象巻線の入力周波数を使う。
2. 誘導電動機側ならインバータ出力周波数を使う。
3. V/f 制御では `V` と `f_inv` を対にして扱う。
4. 電源側 50/60 Hz と `f_inv` を同じ記号のまま計算しない。

## 6. 3段階例題

### 例題1 基礎：周波数変更と磁束密度

一般的な変圧器モデルで、巻数、鉄心断面積、印加電圧を変えずに周波数を 60 Hz から 50 Hz に下げる。60 Hz 時の最大磁束密度を `1.00 p.u.` としたとき、50 Hz 時の最大磁束密度を求める。

同一 `E, N, A` なので

`B_m ∝ 1/f`

したがって

`B_50/B_60=60/50=1.20`

よって

`B_50=1.20 p.u.`

となる。周波数低下で磁束密度が上がるため、飽和側へ移る。

### 例題2 本試験標準：同期速度から二次周波数まで

一般的な 6 極三相誘導電動機を、インバータ出力周波数 `f_inv=50 Hz` で運転する。滑りを `s=0.040` とする。同期速度、回転速度、滑り速度、二次周波数、回転子磁界の固定子に対する速度を求める。

同期速度:

`N_s=120×50/6=1000 min^-1`

回転速度:

`N=(1-0.040)×1000=960 min^-1`

滑り速度:

`sN_s=0.040×1000=40 min^-1`

二次周波数:

`f_2=sf=0.040×50=2.0 Hz`

回転子磁界の回転子に対する速度は

`120f_2/6=40 min^-1`

なので、固定子に対しては

`960+40=1000 min^-1=N_s`

となる。固定子磁界との相対速度は0である。

### 例題3 複合・ひっかけ：電源周波数とインバータ周波数を分ける

一般モデルとして、車両側交流電源の周波数を `60 Hz` とする。一方、誘導電動機へはインバータが `f_inv=30 Hz` を出力している。基準点 `50 Hz, 200 V` と同じ V/f を保つときのインバータ出力電圧を求める。さらに4極誘導電動機の同期速度を求め、実回転速度が `855 min^-1` のときの滑りと二次周波数を求める。

V/f一定より

`200/50=4.0 V/Hz`

したがって 30 Hz では

`V=4.0×30=120 V`

である。

同期速度には電源側60 Hzではなく、電動機へ加わる `f_inv=30 Hz` を使う。

`N_s=120×30/4=900 min^-1`

滑り:

`s=(900-855)/900=0.050`

二次周波数:

`f_2=0.050×30=1.5 Hz`

となる。

## 7. SPEC指定3可視化の再生成条件

以下はすべて一般教材モデルであり、E2系実車値ではない。

### 7.1 周波数―磁束密度

条件: 同一電圧、同一巻数、同一鉄心断面積。60 Hz 時を `B_m=1.00 p.u.` とする。

`B_m(f)=60/f` [p.u.]

横軸 `f=40〜70 Hz`。50 Hz では `1.20 p.u.`、60 Hz では `1.00 p.u.` となる。一定電圧のまま周波数を下げると磁束密度が増えることを示す。

### 7.2 V/f特性

基準点を `60 Hz, 1.00 p.u.` 電圧とする一般モデル。

`V(f)=f/60` [p.u.], `0≤f≤60 Hz`

したがって

`V/f=1/60` [p.u./Hz]

で一定である。横軸をインバータ出力周波数 `f_inv`、縦軸を出力電圧 `V` とし、原点から基準点まで直線になることを示す。

### 7.3 周波数―同期速度

一般的な4極誘導電動機モデルとする。

`N_s=120f/4=30f` [min^-1]

横軸 `f_inv=0〜80 Hz`。50 Hz で1500 min^-1、60 Hz で1800 min^-1 となる。ここで横軸は電源側周波数ではなく、誘導電動機へ加わるインバータ出力周波数である。

## 8. 新幹線への接続

Topic 18では、異なる電源周波数へ対応する車両を題材に、二つの設計条件を分けて理解する。

1. 交流入力を受ける磁気機器では、`E/(fN)` が磁束条件を決める。
2. 誘導電動機の速度制御では、主変換装置が作るインバータ出力周波数と V/f が磁束・同期速度を決める。

したがって「電源が50/60 Hzで変わること」と「誘導電動機の周波数を可変にすること」は別の論点である。E2系の具体的な巻数、磁束密度、極数、出力周波数範囲、定格値は一次資料で確認していないため数値化しない。

## 9. 頻出ミス・ひっかけ

- `E=4.44fNΦ_m` で、周波数が上がると磁束も上がると誤判断する。電圧一定なら逆である。
- `B_m=Φ_m/A` の鉄心断面積 `A` を無視して、別機器間の磁束密度を磁束だけで比較する。
- 50 Hz と60 Hzの可否を周波数だけで判断し、印加電圧を確認しない。
- `P` を極数、`p` を極対数とする表記を混同する。
- `N_s=120f/P` に回転子の実回転速度を代入する。
- 滑りを百分率のまま `f_2=sf` に代入する。
- 滑り速度 `sN_s` と回転速度 `(1-s)N_s` を逆にする。
- 回転子磁界は固定子から見ると滑り速度で回る、と誤認する。滑り速度は回転子に対する相対速度である。
- 電源側50/60 Hzを、そのまま誘導電動機の同期速度計算に使う。
- V/f一定を「周波数を変えても電圧一定」と取り違える。

## 11. 公式・解法まとめ

- 正弦波変圧器: `E=4.44fNΦ_m`
- 最大磁束: `Φ_m=E/(4.44fN)`
- 最大磁束密度: `B_m=Φ_m/A`
- 同一巻線: `Φ_2/Φ_1=(E_2/E_1)(f_1/f_2)`
- 極数 `P`: `N_s=120f/P`
- 機械角速度: `ω_s=4πf/P`
- 極数を `2p` と書く場合: `ω_s=2πf/p`
- 滑り: `s=(N_s-N)/N_s`
- 回転速度: `N=(1-s)N_s`
- 滑り速度: `sN_s`
- 二次周波数: `f_2=sf`
- V/f一定: `Φ_m∝V/f` より磁束を概ね一定に保つ
