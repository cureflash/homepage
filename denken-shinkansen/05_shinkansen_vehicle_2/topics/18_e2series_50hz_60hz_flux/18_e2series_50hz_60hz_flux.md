範囲境界:

- 変圧器は `E = 4.44 f N Φ_m` と `B_m = Φ_m / A` から周波数・電圧・磁束密度の関係を扱う。
- 誘導機は同期速度、滑り、滑り周波数とV/f一定制御を扱う。
- インバータ入力側の電源周波数と、誘導機へ与えるインバータ出力周波数を混同しない。
- 変圧器損失、誘導機トルク・銅損、詳細なベクトル制御は固定SPEC外なので、このTopicの品質ゲートへ追加しない。
- 未確認のE2系実車の変圧器巻数、磁束密度、モータ極数、インバータ出力周波数範囲、定格値を仮定しない。

# EXAM_ALIGNMENT

資格: 第二種電気主任技術者

主科目:

- 一次試験「機械」
- 二次試験「機械・制御」

対象論点:

- 変圧器誘起電圧 `E = 4.44 f N Φ_m`
- 同一巻数・同一印加電圧での `Φ_m ∝ 1/f` と `B_m ∝ 1/f`
- 定格周波数と異なる周波数で使うときの磁束・飽和側条件
- 誘導機の同期速度 `N_s = 120 f / p`
- 滑り `s = (N_s - N) / N_s` と滑り周波数 `f_2 = s f`
- V/f一定制御と磁束維持
- 電源周波数とインバータ出力周波数の役割の区別
- SPEC指定3可視化を上記式から再生成できること

## 本文へ必ず接続する要素

1. `E = 4.44 f N Φ_m` を起点に、同一V・Nなら `Φ_m ∝ 1/f` を示す。
2. `B_m = Φ_m/A` を接続し、鉄心断面積一定なら周波数―磁束密度グラフを描けるようにする。
3. V/f一定なら磁束を概ね一定に保てる理由を、誘導起電力式から説明する。
4. `N_s = 120 f / p`、`s=(N_s-N)/N_s`、`f_2=sf` を途中式付きで扱う。
5. 電源周波数50/60 Hzと、インバータが電動機へ与える出力周波数を別の量として明示する。
6. 機器定格は、周波数だけを切り離さず、電圧・巻数・磁束／磁束密度との組で判断する。
7. 指定3可視化「周波数―磁束密度」「V/f特性」「周波数―同期速度」を上記式と同じモデルから生成する。
