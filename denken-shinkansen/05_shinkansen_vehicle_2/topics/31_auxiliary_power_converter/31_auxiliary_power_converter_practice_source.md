## 共通式・成立条件

- 三相皮相電力: `S = √3 V_LL I`
- 三相有効電力: `P = √3 V_LL I cosφ`
- 三相無効電力: `Q = √3 V_LL I sinφ`
- H22型三相PWM: `V_LL1 = √3 E_d k / (2√2)`
- 総合力率（正弦波電圧・電流ひずみのみ）: `λ = (I_1/I) cosφ_1`
- 電流分解: `i_L = i_1 + i_H`
- 高調波補償: `i_c = -i_H`
- 対称方形波基本波: `I_1 = (2√2/π) I_L`
- 高調波合成実効値: `I_H = √(I_L^2-I_1^2)`
- 導通損失: `P_cond ≈ V_on I_avg,on` または問題指定モデル
- スイッチング損失: `P_sw = f_s(E_on+E_off)`
- 効率: `η = P_out/(P_out+P_loss)`
- 教材用固定損＋負荷依存損失: `P_loss = P_0 + x^2 P_vN`
- 同モデルの最大効率条件: `P_0 = x^2 P_vN`
- 直流中間エネルギー: `W_dc = (1/2) C V_dc^2`
- エネルギー収支: `dW_dc/dt = P_in-P_out-P_loss`

`V_LL1` の係数はH22一次問3型の問題定義に限る。PWM方式・直流電圧定義が異なる問題へ無条件に流用しない。

# 一次試験型

## 問1 電圧形インバータと誘導性負荷

電圧形インバータで誘導性負荷をPWM駆動するときの記述として最も適切なものを選べ。

1. 誘導性負荷の電流は主スイッチOFFと同時に必ず0になるため、逆並列ダイオードは不要である。
2. 逆並列ダイオードは主として直流中間電圧を一定にするためだけに用いられる。
3. MOSFETのような自己消弧形素子はPWMに使用できず、商用周波数でのみ動作させる。
4. 誘導性負荷では電流が連続しようとするため還流経路が必要であり、PWMの搬送波周波数はスイッチング頻度と関係する。
5. PWMでは出力パルス列そのものが高調波を含まない正弦波になる。

### 正答
4

### 完全解説

誘導性負荷ではインダクタ電流が瞬時に変化できない。主スイッチをOFFしても電流経路が必要で、逆並列ダイオードが還流経路を与える。MOSFETやIGBTなどの自己消弧形素子はPWMに使用できる。PWM出力はパルス列であり、基本波と高調波を含む。搬送波周波数を上げれば一般にスイッチング回数も増える。

よって4。

## 問2 三相PWMの線間基本波電圧

H22一次問3型の定義に従う三相PWM電圧形自励変換器で、直流電圧 `E_d=600 V`、変調率 `k=0.80` とする。線間基本波実効値 `V_LL1` に最も近いものを選べ。

1. `170 V`
2. `240 V`
3. `294 V`
4. `339 V`
5. `480 V`

### 正答
3

### 完全解説

問題指定式

`V_LL1 = √3 E_d k /(2√2)`

へ代入する。

`V_LL1 = √3×600×0.80/(2√2)`

`=293.94 V`

したがって約 `294 V`、正答3。

単相式、相電圧式、別定義の変調率を混用しない。

## 問3 三相負荷のP・Q・S

線間電圧 `400 V`、線電流 `40 A`、遅れ力率 `0.80` の平衡三相負荷がある。`P,Q,S` の組合せとして正しいものを選べ。

1. `P=12.8 kW, Q=9.60 kvar, S=16.0 kVA`
2. `P=16.0 kW, Q=12.0 kvar, S=20.0 kVA`
3. `P=22.2 kW, Q=16.6 kvar, S=27.7 kVA`
4. `P=27.7 kW, Q=16.6 kvar, S=22.2 kVA`
5. `P=27.7 kW, Q=20.8 kvar, S=34.6 kVA`

### 正答
3

### 完全解説

`S=√3×400×40=27.713 kVA`

`P=S×0.80=22.170 kW`

`sinφ=√(1-0.80^2)=0.60`

`Q=S×0.60=16.628 kvar`

よって3。

線間電圧を使う三相式には既に `√3` が含まれる。

## 問4 変位力率と総合力率

交流電圧は正弦波で、負荷電流だけに高調波が含まれる。基本波電流と全実効値の比が `I_1/I=0.95`、基本波変位力率が `cosφ_1=0.98` である。総合力率に最も近いものを選べ。

1. `0.760`
2. `0.882`
3. `0.931`
4. `0.950`
5. `0.980`

### 正答
3

### 完全解説

この条件では

`λ=(I_1/I)cosφ_1`

だから

`λ=0.95×0.98=0.931`

よって3。

変位力率が0.98でも、高調波によるひずみがあれば総合力率は0.98より低くなる。力率と変換効率も別の量である。

## 問5 半導体の導通損失とスイッチング損失

あるスイッチング素子について、オン時電圧降下 `V_on=1.5 V`、オン期間の平均電流 `20 A`、1回のターンオン損失エネルギー `E_on=4.0 mJ`、ターンオフ損失エネルギー `E_off=3.0 mJ`、スイッチング周波数 `f_s=10 kHz` とする。漏れ損失は無視できる。この素子1個の導通損失とスイッチング損失の合計に最も近いものを選べ。

1. `37 W`
2. `70 W`
3. `100 W`
4. `130 W`
5. `700 W`

### 正答
3

### 完全解説

導通損失は

`P_cond≈V_on I_avg,on=1.5×20=30 W`

スイッチング損失は

`P_sw=f_s(E_on+E_off)`

`=10000×(0.004+0.003)=70 W`

合計

`P=30+70=100 W`

よって3。

mJをJへ直すこと、1回当たりエネルギーをWへ変換するため `f_s` を掛けることが要点である。オフ時漏れ電流が指定される問題では別途その損失も評価する。

## 問6 基本波・高調波と補償電流

実効値 `I_L=20 A` の対称方形波電流を、基本波 `i_1` と高調波合成 `i_H` に分解する。基本波と高調波は直交し、`I_1=(2√2/π)I_L` とする。`I_1`,`I_H` と、高調波を打ち消す補償電流の組合せとして正しいものを選べ。

1. `I_1=12.7 A, I_H=15.4 A, i_c=+i_H`
2. `I_1=18.0 A, I_H=8.71 A, i_c=-i_H`
3. `I_1=18.0 A, I_H=2.00 A, i_c=+i_H`
4. `I_1=20.0 A, I_H=0 A, i_c=0`
5. `I_1=28.3 A, I_H=20.0 A, i_c=-i_H`

### 正答
2

### 完全解説

`I_1=(2√2/π)×20=18.01 A`

`I_H=√(I_L^2-I_1^2)`

`=√(20^2-18.01^2)=8.71 A`

高調波補償では

`i_c=-i_H`

とし、電源側を

`i_s=i_L+i_c=i_1`

にする。よって2。

## 問7 負荷率と変換効率

教材用変換器モデルで、定格出力 `P_N=120 kW`、固定損 `P_0=1.5 kW`、定格時負荷依存損失 `P_vN=3.0 kW` とする。負荷依存損失は `x^2` に比例する。50%負荷時の損失と効率の組合せとして正しいものを選べ。

1. `1.50 kW, 97.6 %`
2. `2.00 kW, 96.8 %`
3. `2.25 kW, 96.4 %`
4. `3.00 kW, 95.2 %`
5. `4.50 kW, 93.0 %`

### 正答
3

### 完全解説

`x=0.50`

`P_out=xP_N=60 kW`

`P_loss=P_0+x^2P_vN`

`=1.5+0.50^2×3.0=2.25 kW`

`η=60/(60+2.25)=0.96386`

したがって `96.4 %`、正答3。

この固定損＋電流二乗形負荷損モデルは教材用仮定であり、すべての補助電源変換器へ普遍化しない。

## 問8 負荷急増と直流中間電圧

直流中間コンデンサ `C=0.040 F`、初期電圧 `V_dc=700 V` とする。負荷が瞬時に `15 kW` 増加し、入力側が追従するまで `40 ms` かかる。この間の追加損失変化は無視する。40 ms後の直流中間電圧に最も近いものを選べ。

1. `622 V`
2. `650 V`
3. `678 V`
4. `700 V`
5. `721 V`

### 正答
3

### 完全解説

初期エネルギー

`W_0=(1/2)CV^2`

`=0.5×0.040×700^2=9800 J`

不足エネルギー

`ΔW=-15000×0.040=-600 J`

`W_1=9200 J`

`V_1=√(2W_1/C)`

`=√(18400/0.040)`

`=678.2 V`

よって3。負荷急増時はまず `dW_dc/dt<0` となることを確認し、電圧が低下する向きを判断する。

## 問9（二次1）三相PWM・力率1・電力方向

三相PWM電圧形自励変換器について、H22一次問3型の式

`V_LL1=√3 E_d k/(2√2)`

を用いる。直流電圧 `E_d=700 V`、交流側線間基本波実効値 `V_LL1=400 V`、交流側有効電力 `P=120 kW`、力率1とする。

1. 変調率 `k` を求めよ。
2. 交流側線電流 `I` を求めよ。
3. 直流側から交流系統へ有効電力を送るインバータ運転で、交流リアクトルを介して力率1とする場合、変換器基本波電圧の位相を系統電圧に対してどちらへ置くか述べよ。
4. PWMで三角搬送波を用いる意味を一文で述べよ。

### 完全解説

1. 変調率

`k = 2√2 V_LL1 /(√3 E_d)`

`=2√2×400/(√3×700)`

`=0.933`

2. 力率1なので

`P=√3 V_LL1 I`

`I=120000/(√3×400)`

`=173.2 A`

3. 直流側から交流系統へ電力を送るインバータ運転では、交流リアクトルを介して有効電力を送り出すため、変換器基本波電圧を系統電圧より進み位相側へ置く。電力方向を逆にすれば必要な位相関係も反転するため、問題文の電力方向を先に確認する。

4. 三角搬送波と指令波を比較してスイッチング時刻を決め、パルス列の基本波成分を制御するためである。

検算:
- `0<k<1` で線形変調域の想定と整合する。
- `√3×400×173.2≈120 kW`。

## 問10（二次2）高調波分離と補償

半導体電力変換装置を含む負荷が、実効値 `I_L=100 A` の対称方形波電流を取る。電源電圧は正弦波、基本波と高調波は直交するとする。

1. この種の半導体電力変換装置が高調波発生源となる理由を述べよ。
2. 高調波が電源系統・機器へ与える代表的影響を二つ挙げよ。
3. `I_1=(2√2/π)I_L` を用いて基本波実効値 `I_1` を求めよ。
4. 高調波合成実効値 `I_H` を求めよ。
5. 電源側電流を基本波だけにする理想補償電流 `i_c(t)` を示せ。

### 完全解説

1. スイッチングにより電圧・電流波形が非正弦波となり、基本波以外の周波数成分を含むためである。

2. 代表例は、配電線・変圧器・回転機などの追加損失・発熱、コンデンサとの共振、電圧ひずみ、通信・制御系への障害などである。二つを理由付きで挙げればよい。

3. 基本波

`I_1=(2√2/π)×100`

`=90.03 A`

約 `90.0 A`。

4. 直交条件より

`I_H=√(I_L^2-I_1^2)`

`=√(100^2-90.03^2)`

`=43.54 A`

約 `43.5 A`。

5. `i_L=i_1+i_H` だから

`i_c=-i_H`

とすれば

`i_s=i_L+i_c=i_1`

となる。補償装置の具体的な実車搭載を意味するものではなく、高調波分離・補償原理の一般問題である。

検算:

`90.03^2+43.54^2≈100^2`

## 問11（二次3）固定損・負荷依存損失と最大効率

教材用変換器モデルとして、定格出力 `P_N=100 kW`、固定損 `P_0=1.6 kW`、定格時負荷依存損失 `P_vN=3.6 kW` とする。負荷率を `x` とし、負荷依存損失は `x^2P_vN` とする。

1. 最大効率となる負荷率 `x` を求めよ。
2. そのときの出力、全損失、効率を求めよ。
3. 50%負荷時の効率を求め、(2)と比較せよ。
4. この最大効率条件を全ての補助電源変換器へ普遍化してはならない理由を述べよ。

### 完全解説

1. この教材モデルでは最大効率条件

`P_0=x^2P_vN`

より

`x=√(P_0/P_vN)`

`=√(1.6/3.6)`

`=0.6667`

したがって約 `66.7 %`負荷。

2. 出力

`P_out=xP_N=66.67 kW`

負荷依存損失

`x^2P_vN=(0.6667)^2×3.6=1.6 kW`

全損失

`P_loss=1.6+1.6=3.2 kW`

効率

`η=66.67/(66.67+3.2)`

`=0.9542`

約 `95.4 %`。

3. 50%負荷では

`P_out=50 kW`

`P_loss=1.6+0.50^2×3.6=2.5 kW`

`η=50/(50+2.5)=0.95238`

約 `95.2 %`。

したがって、このモデルでは66.7%負荷の方がわずかに高効率である。

4. 最大効率条件は「固定損が負荷に依存せず、変動損が負荷率の二乗に比例する」という指定モデルから導かれた結果である。実際の変換器ではスイッチング損失、補機損、磁気部品損失、温度依存などが別の負荷依存性を持ち得る。R2二次問2の変圧器固有条件を補助電源変換器の普遍則へ置換しない。

## 問12（二次4）半導体損失と変換効率

6個のスイッチング素子を用いる変換器を教材用に考える。各素子について、オン時電圧降下 `V_on=1.8 V`、オン期間平均電流 `8.0 A`、`E_on=2.5 mJ`、`E_off=1.5 mJ`、スイッチング周波数 `f_s=8.0 kHz` とする。各素子に同じ値を適用できるものとし、その他の固定損を装置全体で `120 W`、出力を `30.0 kW` とする。漏れ損失は無視する。

1. 6素子合計の導通損失を求めよ。
2. 6素子合計のスイッチング損失を求めよ。
3. 全損失と変換効率を求めよ。
4. 1回当たりの `E_on,E_off` が変わらないと仮定して `f_s` を半分にした場合、スイッチング損失と全損失がどう変化するか求めよ。
5. ソフトスイッチングの狙いを述べよ。

### 完全解説

1. 1素子の導通損失

`P_cond,1=V_on I_avg,on=1.8×8.0=14.4 W`

6素子で

`P_cond=6×14.4=86.4 W`

2. 1素子のスイッチング損失

`P_sw,1=f_s(E_on+E_off)`

`=8000×(0.0025+0.0015)=32.0 W`

6素子で

`P_sw=6×32.0=192 W`

3. 全損失

`P_loss=86.4+192+120=398.4 W`

効率

`η=30000/(30000+398.4)`

`=0.98689`

約 `98.7 %`。

4. `f_s=4.0 kHz` とすると、1回当たり損失一定の仮定ではスイッチング損失は半分になる。

`P_sw=96 W`

全損失は

`P_loss=86.4+96+120=302.4 W`

となる。実機では周波数変更に伴い電流リプルや素子温度等も変わるため、常に単純比例するとは限らない。

5. ソフトスイッチングは切替時の電圧と電流の重なりを小さくし、1回当たりのスイッチング損失エネルギーを低減することが狙いである。
