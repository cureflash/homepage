## 1. このテーマで電験二種は何を問うか

補助電源変換器では、単に「直流を交流へ変換する装置」と覚えるだけでは不十分である。二種では、インバータのスイッチングと誘導性負荷の電流経路、三相PWMの基本波電圧、力率、高調波、半導体損失、負荷率と効率を、式と回路条件から判断できる必要がある。

このテーマでは次の順に解く。

1. 入力側・直流中間回路・出力側・負荷を分ける。
2. 三相なら線間値／相値、線電流／相電流を判別する。
3. 基本波と高調波を分ける。
4. 力率と効率を別の量として扱う。
5. 半導体損失を導通損失とスイッチング損失へ分ける。
6. 負荷変動時は、損失モデルと直流中間回路のエネルギー収支を確認する。

## 2. 補助電源変換器の最小モデル

教材では補助電源変換器を次の一般モデルで扱う。

`入力電源 → コンバータ／整流段 → 直流中間回路 → インバータ → 三相補機負荷`

これは試験論点を整理するための一般モデルであり、特定の新幹線形式の実装回路を表すものではない。

- コンバータ／整流段: 入力側と直流中間回路の間で電力を変換する。
- 直流中間回路: コンデンサ等により電圧を保持し、瞬時の電力差を吸収する。
- インバータ: 直流から交流基本波を作り、負荷へ供給する。
- 三相負荷: 空調・送風機・ポンプ等を想定できるが、本テーマでは個別設備の設計計算へ踏み込まない。

## 3. インバータと誘導性負荷

電圧形インバータでは、IGBTやMOSFET等の自己消弧形スイッチング素子をオン・オフして交流電圧を作る。誘導性負荷では電流は瞬時に0へ変化できないため、主スイッチがオフした後も電流経路が必要になる。逆並列ダイオードは、その還流経路を与える。

R7一次「機械」問4では、この関係が直接問われる。教材で必要なのは次の5点である。

- 誘導性負荷では電流が連続しようとする。
- 主スイッチと逆並列ダイオードで電流経路が切り替わる。
- 自己消弧形素子としてMOSFET等を使える。
- PWMで出力基本波を制御する。
- 搬送波周波数はスイッチング頻度と関係する。

PWMでは、信号波と搬送波の比較でパルス列を作る。パルス列そのものを正弦波とみなさず、必要な基本波と高調波へ分解して考える。

## 4. 三相PWMと基本波電圧

H22一次「機械」問3型の三相PWM電圧形自励変換器では、問題文の定義に従い、直流電圧を `E_d`、変調率を `k` とすると、線間基本波実効値は

`V_LL1 = √3 E_d k / (2√2)`

である。

したがって

`k = 2√2 V_LL1 / (√3 E_d)`

と逆算できる。

この係数はPWM方式、単相／三相、相値／線間値、直流電圧の定義で変わる。別問題の式を混用しない。

### 三相平衡負荷

線間電圧 `V_LL`、線電流 `I`、力率角 `φ` の平衡三相負荷では

`S = √3 V_LL I`

`P = √3 V_LL I cosφ`

`Q = √3 V_LL I sinφ`

である。

- `S`: 皮相電力 [VA]
- `P`: 有効電力 [W]
- `Q`: 無効電力 [var]
- `cosφ`: 基本波の変位力率

線間電圧を使う式に相電圧を代入しないことが重要である。

## 5. 力率と高調波

### 5.1 力率と効率は別物

力率は交流側で有効電力が皮相電力のどれだけを占めるかを表す。

`λ = P / (V_rms I_rms)`

効率は装置の入力電力のうち、どれだけが出力へ届くかを表す。

`η = P_out / P_in`

力率が1でも変換損失があれば効率は1ではない。逆に高効率でも入力電流がひずめば総合力率が1とは限らない。

### 5.2 基本波と高調波を分ける

負荷電流を

`i_L(t) = i_1(t) + i_H(t)`

と分ける。`i_1` は基本波、`i_H` は高調波合成である。

基本波と高調波が直交する条件では

`I_L^2 = I_1^2 + I_H^2`

となる。

高調波補償の基本形では

`i_c(t) = -i_H(t)`

とすれば、電源側電流は

`i_s(t) = i_L(t) + i_c(t) = i_1(t)`

となる。R5二次「機械・制御」問3はこの原理を直接問う。

振幅が `±I_L` の対称方形波では

`I_1 = (2√2/π) I_L ≈ 0.900 I_L`

`I_H = √(I_L^2-I_1^2)`

`= √(1-8/π^2) I_L ≈ 0.435 I_L`

である。

正弦波電圧、基本波電流の位相差を `φ_1` とし、電流ひずみだけを考える条件では、総合力率は

`λ = (I_1/I) cosφ_1`

と書ける。さらに

`THD_I = I_H/I_1`

なら

`λ = cosφ_1 / √(1+THD_I^2)`

となる。これは成立条件付きの式であり、一般の非正弦波電圧へ無条件に適用しない。

## 6. 変換損失

半導体損失は少なくとも導通損失とスイッチング損失へ分ける。

### 6.1 導通損失

オン時電圧降下を一定値 `V_on` と近似できる条件では

`P_cond ≈ V_on I_avg,on`

と考えられる。MOSFETをオン抵抗モデルで扱う問題では

`P_cond ≈ I_rms,on^2 R_on`

となる。どちらを使うかは問題文の素子モデルに従う。

オフ時漏れ電流が与えられる場合は、オフ時も損失が0とは限らない。

### 6.2 スイッチング損失

1回のターンオンエネルギーを `E_on`、ターンオフを `E_off`、スイッチング周波数を `f_s` とすれば

`P_sw = f_s(E_on+E_off)`

`= (E_on+E_off)/T_s`

である。

同じ1回当たり損失なら、周期が短いほど単位時間当たりのスイッチング損失は増える。R4一次「機械」問4はこの関係を問う。

ソフトスイッチングは切替時の電圧と電流の重なりを減らし、1回当たりのスイッチングエネルギーを減らす考え方として理解する。

## 7. 変換効率と負荷変動

一般には

`η = P_out/P_in`

`= P_out/(P_out+P_loss)`

である。

### 7.1 教材用の固定損＋負荷依存損失モデル

定格出力を `P_N`、負荷率を `x`、固定損を `P_0`、定格時の負荷依存損失を `P_vN` とし、負荷依存損失が電流二乗に比例する教材モデルでは

`P_out = x P_N`

`P_loss = P_0 + x^2 P_vN`

`η(x) = xP_N / (xP_N + P_0 + x^2P_vN)`

となる。

このモデルでは最大効率条件が

`P_0 = x^2 P_vN`

となるが、これはこの損失モデルの結果であって、すべての補助電源変換器に共通する普遍則ではない。

R2二次「機械・制御」問2の変圧器問題では固定損と負荷損、負荷率、効率、最大効率を扱う。Topic 31ではその「損失を固定成分と負荷依存成分に分ける解法」だけを一般化し、変圧器固有の鉄損・銅損の関係を変換器へそのまま移さない。

## 8. 直流中間回路と負荷ステップ

直流中間コンデンサ `C`、直流電圧 `V_dc` の蓄積エネルギーは

`W_dc = (1/2) C V_dc^2`

である。

直流中間回路へ入る電力を `P_in`、負荷への出力を `P_out`、変換損失を `P_loss` とすると

`dW_dc/dt = P_in - P_out - P_loss`

である。

- 負荷が急増し、入力側制御がまだ追従していない間は `P_in < P_out + P_loss` となり、`W_dc` と `V_dc` は低下する。
- 負荷が急減すると一時的に余剰電力が生じ、`W_dc` と `V_dc` は上昇する。

このエネルギー収支を使えば、「負荷変動」を電圧変化として定量的に扱える。

## 9. 問題を見たときの解法手順

1. 変換器の入力側・直流中間・出力側・負荷を分ける。
2. 単相か三相か、線間値か相値かを確認する。
3. 電圧・電流が基本波量か、ひずみを含む実効値かを区別する。
4. 三相平衡なら `√3 V_LL I` を基準にP/Q/Sを整理する。
5. PWM式は問題文の変調率・直流電圧の定義を確認して選ぶ。
6. 高調波問題では `i_L=i_1+i_H` と分解する。
7. 損失は導通・スイッチング・その他の固定／負荷依存成分に分ける。
8. 効率は必ず入出力電力から求める。
9. 負荷急変では `dW_dc/dt` の符号から `V_dc` の増減を先に判断する。
10. 単位、百分率、線間／相、力率／効率を検算する。

## 10. 典型例題

以下の数値はすべて教材用仮定値であり、新幹線実車値ではない。

### 例題1 基礎: 三相負荷のP/Q/S

`V_LL=400 V`、`I=50 A`、`cosφ=0.80` の平衡三相負荷を考える。

`S = √3×400×50 = 34.64 kVA`

`P = 34.64×0.80 = 27.71 kW`

`sinφ = 0.60`

`Q = 34.64×0.60 = 20.78 kvar`

答え:
- `S≈34.6 kVA`
- `P≈27.7 kW`
- `Q≈20.8 kvar`

線間電圧400 Vを相電圧として再度 `√3` を掛けない。

### 例題2 本試験標準: 部分負荷効率

教材用変換器モデルとして

- 定格出力 `P_N=100 kW`
- 固定損 `P_0=2.0 kW`
- 定格時負荷依存損失 `P_vN=2.0 kW`

とする。

定格時 `x=1`:

`P_loss=2.0+1^2×2.0=4.0 kW`

`η=100/(100+4)=0.9615`

`η≈96.2 %`

50%負荷 `x=0.5`:

`P_out=50 kW`

`P_loss=2.0+0.5^2×2.0=2.5 kW`

`η=50/(50+2.5)=0.9524`

`η≈95.2 %`

負荷が下がると負荷依存損失は減るが、固定損の出力に対する割合が大きくなるため、この例では効率が低下する。

このモデルの最大効率条件は

`P_0=x^2P_vN`

より `x=1`。ただし、この条件はこの教材モデル内だけで成立する。

### 例題3 複合: 負荷急増と直流中間電圧

教材用仮定値として

- `C=0.050 F`
- 初期 `V_dc=600 V`
- 負荷出力が瞬時に20 kW増加
- 入力側が追従するまで `20 ms`
- この20 msでは追加損失変化を無視

とする。

初期エネルギー:

`W_0=(1/2)×0.050×600^2=9000 J`

不足エネルギー:

`ΔW=-20000×0.020=-400 J`

`W_1=8600 J`

`V_1=√(2W_1/C)`

`=√(2×8600/0.050)`

`≈586.5 V`

したがって、入力側が追従するまで直流中間電圧は約 `600 V → 587 V` に低下する。先にエネルギー収支の符号を判断すると計算ミスを防げる。

## 12. 頻出ミス・ひっかけ

- 力率と効率を同じ百分率として扱う。
- 線間電圧と相電圧を混同する。
- PWMパルス列の実効値と基本波実効値を同一視する。
- 単相用の基本波電圧式を三相へ持ち込む。
- 高調波があるのに `P=VIcosφ` の `cosφ` だけで総合力率を評価する。
- `E_on+E_off` を1回の損失エネルギーのままWとして扱い、`f_s` を掛け忘れる。
- 部分負荷で損失がすべて負荷率に比例すると決めつける。
- R2二次の変圧器最大効率条件を、変換器へ普遍則として流用する。
- 実車資料で確認していない定格・素子・効率を新幹線の実値として書く。

## 14. 公式・解法まとめ

- 三相皮相電力: `S=√3 V_LL I`
- 三相有効電力: `P=√3 V_LL I cosφ`
- 三相無効電力: `Q=√3 V_LL I sinφ`
- H22型三相PWM: `V_LL1=√3 E_d k/(2√2)`
- 電流分解: `i_L=i_1+i_H`
- 高調波補償: `i_c=-i_H`
- 方形波基本波: `I_1=(2√2/π)I_L`
- 方形波高調波合成: `I_H=√(1-8/π^2)I_L`
- スイッチング損失: `P_sw=f_s(E_on+E_off)`
- 効率: `η=P_out/(P_out+P_loss)`
- 教材用負荷損モデル: `P_loss=P_0+x^2P_vN`
- 直流中間エネルギー: `W_dc=(1/2)CV_dc^2`
- 電力収支: `dW_dc/dt=P_in-P_out-P_loss`
