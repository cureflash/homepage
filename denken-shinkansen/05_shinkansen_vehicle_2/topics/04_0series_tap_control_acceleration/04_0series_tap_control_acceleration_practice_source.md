# 一次試験型

## 問1 停止時の起動電流

電機子抵抗 `R_a=0.24 Ω` の直流電動機が停止している。電機子インダクタンスとブラシ電圧降下を無視し、端子電圧 `V_a=48 V` を加えた直後の電機子電流として正しいものを選べ。

1. `50 A`
2. `100 A`
3. `160 A`
4. `200 A`
5. `240 A`

### 正答

4

### 完全解説

停止時は `ω=0` なので

```text
E=k_eΦω=0
```

である。電圧方程式

```text
V_a=E+I_aR_a
```

より

```text
I_a=V_a/R_a
   =48/0.24
   =200 A
```

となる。起動時に電圧を低く始めるのは、逆起電力がまだない状態での過大電流を抑えるためである。

## 問2 速度上昇後のタップ切替

`R_a=0.20 Ω` の直流電動機を第1電圧段 `V_1=60 V` で運転している。速度上昇により逆起電力が `E=36 V` となった時点で、第2電圧段 `V_2=84 V` へ切り替えた。切替瞬間では速度、磁束、逆起電力は変化しないものとする。

切替直前の電機子電流 `I_1` と切替直後の電機子電流 `I_2` の組合せとして正しいものを選べ。

1. `I_1=120 A`, `I_2=240 A`
2. `I_1=120 A`, `I_2=420 A`
3. `I_1=180 A`, `I_2=240 A`
4. `I_1=300 A`, `I_2=240 A`
5. `I_1=300 A`, `I_2=420 A`

### 正答

1

### 完全解説

切替直前は

```text
I_1=(V_1-E)/R_a
   =(60-36)/0.20
   =120 A
```

である。

切替瞬間には機械速度は瞬時に変わらないため、基本モデルでは `E≈36 V` のまま扱う。

```text
I_2=(V_2-E)/R_a
   =(84-36)/0.20
   =240 A
```

したがって正答は1である。

同じ電圧段では速度上昇で `E` が増え、`I_a` は低下する。そこで電圧段を上げると、同じ速度で電流とトルクを再び増やせる。

## 問3 始動過渡の時定数と電流

一定界磁の直流電動機モデルで、`V_a=120 V`、`R_a=0.30 Ω`、`K_E=1.20 V·s/rad`、`K_T=1.20 N·m/A`、`J=4.8 kg·m²` とする。無負荷、電機子インダクタンス無視で停止状態から始動する。

時定数 `τ` と `t=τ` の電機子電流の組合せとして最も近いものを選べ。

1. `τ=0.50 s`, `i_a(τ)=147 A`
2. `τ=1.00 s`, `i_a(τ)=147 A`
3. `τ=1.00 s`, `i_a(τ)=200 A`
4. `τ=2.00 s`, `i_a(τ)=147 A`
5. `τ=2.00 s`, `i_a(τ)=400 A`

### 正答

2

### 完全解説

簡略始動過渡の時定数は

```text
τ=JR_a/(K_EK_T)
```

なので

```text
τ=4.8×0.30/(1.20×1.20)
 =1.00 s
```

である。

初期電流は

```text
i_a(0)=V_a/R_a
      =120/0.30
      =400 A
```

無負荷始動では

```text
i_a(t)=(V_a/R_a)exp(-t/τ)
```

だから

```text
i_a(τ)=400e^-1
      ≈147 A
```

となる。

## 問4 慣性モーメントと回転運動エネルギー

慣性モーメント `J=6.0 kg·m²` の回転体が角速度 `ω=20 rad/s` で回転している。回転運動エネルギーとして正しいものを選べ。

1. `120 J`
2. `600 J`
3. `1.20 kJ`
4. `2.40 kJ`
5. `12.0 kJ`

### 正答

3

### 完全解説

回転運動エネルギーは

```text
W=1/2 Jω²
```

より

```text
W=1/2×6.0×20²
 =1200 J
 =1.20 kJ
```

である。H28一次では `J` の物理的意味と `1/2 Jω²` の対応も問われるため、回転運動方程式と併せて確認する。

## 問5 直巻電動機の始動トルク

直巻直流電動機を未飽和域で考え、磁束が `Φ∝I_a` と近似できるものとする。電機子電流を `100 A` から `150 A` に増加させたとき、電磁トルクの比 `T_2/T_1` として正しいものを選べ。

1. `1.25`
2. `1.50`
3. `2.00`
4. `2.25`
5. `3.00`

### 正答

4

### 完全解説

直流機の電磁トルクは

```text
T=k_tΦI_a
```

である。直巻機の未飽和域では `Φ∝I_a` なので

```text
T∝I_a²
```

したがって

```text
T_2/T_1=(150/100)²
        =2.25
```

となる。

ただし `T∝I_a²` は未飽和域の近似である。磁気飽和が進んだ領域へ無条件に適用してはいけない。

## 問6 電圧段と速度―トルク特性

一定磁束の局所近似で `K_E=1.0 V·s/rad`、`K_T=1.0 N·m/A`、`R_a=0.50 Ω` とする。電磁トルク `T=40 N·m` のとき、端子電圧を `100 V` から `140 V` へ上げると定常角速度は何 `rad/s` 増加するか。

1. `20 rad/s`
2. `30 rad/s`
3. `40 rad/s`
4. `50 rad/s`
5. `80 rad/s`

### 正答

3

### 完全解説

一定磁束の局所近似では

```text
ω=V_a/K_E-{R_a/(K_EK_T)}T
```

である。

`V_a=100 V` のとき

```text
ω_1=100-0.50×40
   =80 rad/s
```

`V_a=140 V` のとき

```text
ω_2=140-0.50×40
   =120 rad/s
```

したがって

```text
Δω=120-80
   =40 rad/s
```

となる。同じ負荷トルクなら、高い電圧段ほど速度―トルク特性は上側へ移る。この直線は一定磁束の局所近似であり、直巻電動機の全域実特性ではない。

## 問7 電動機トルクから車輪周けん引力

電動機1台のトルク `T_m=500 N·m`、電動機台数 `N=8`、減速比 `G=ω_m/ω_w=3.0`、歯車伝達効率 `η_g=0.90`、動輪半径 `r_w=0.50 m` とする。

車輪周けん引力 `F_t` として正しいものを選べ。

1. `7.20 kN`
2. `10.8 kN`
3. `14.4 kN`
4. `21.6 kN`
5. `43.2 kN`

### 正答

4

### 完全解説

車輪周けん引力は

```text
F_t=Nη_gGT_m/r_w
```

である。代入すると

```text
F_t
=8×0.90×3.0×500/0.50
=21600 N
=21.6 kN
```

となる。

減速比は本教材では `G=ω_m/ω_w` と定義している。定義を逆にすると誤答になる。

## 問8 正味けん引力と時間―速度

等価質量 `m_eq=2.00×10^5 kg` の列車モデルで、一定区間の車輪周けん引力を `F_t=60.0 kN`、走行抵抗を `F_r=20.0 kN` とする。停止からこの条件を30 s維持したときの速度として正しいものを選べ。

1. `10.8 km/h`
2. `18.0 km/h`
3. `21.6 km/h`
4. `36.0 km/h`
5. `72.0 km/h`

### 正答

3

### 完全解説

正味力は

```text
F_t-F_r=40.0 kN
```

なので

```text
a=(F_t-F_r)/m_eq
 =40.0×10^3/(2.00×10^5)
 =0.200 m/s²
```

である。停止から30 s後は

```text
v=at
 =0.200×30
 =6.00 m/s
```

これを `km/h` へ直すと

```text
v=6.00×3.6
 =21.6 km/h
```

となる。けん引力そのものではなく、走行抵抗を差し引いた正味力で加速度を求める。

## 問9 簡略始動過渡の導出

一定界磁の直流電動機について

```text
V_a=R_ai_a+K_Eω
J dω/dt=K_Ti_a
```

が成り立つものとする。無負荷、電機子インダクタンス無視、`V_a=120 V`、`R_a=0.30 Ω`、`K_E=1.50 V·s/rad`、`K_T=1.50 N·m/A`、`J=7.5 kg·m²` とし、停止状態から一定電圧を加える。

次を求めよ。

1. 角速度の微分方程式
2. 時定数 `τ`
3. 電機子電流 `i_a(t)` と角速度 `ω(t)`
4. `t=1.50 s` の電機子電流と角速度

### 完全解説

電圧方程式から

```text
i_a=(V_a-K_Eω)/R_a
```

である。これを回転運動方程式へ代入すると

```text
J dω/dt
=(K_T/R_a)(V_a-K_Eω)
```

したがって

```text
dω/dt+(K_EK_T)/(JR_a)ω
=K_TV_a/(JR_a)
```

となる。

時定数は

```text
τ=JR_a/(K_EK_T)
 =7.5×0.30/(1.50×1.50)
 =1.00 s
```

である。

停止状態を初期条件とすると

```text
ω(t)=(V_a/K_E){1-exp(-t/τ)}
```

だから

```text
ω(t)=80{1-exp(-t)} rad/s
```

となる。

電機子電流は

```text
i_a(t)=(V_a/R_a)exp(-t/τ)
      =400exp(-t) A
```

である。

`t=1.50 s` では

```text
i_a(1.50)=400e^-1.5
          ≈89.3 A
```

```text
ω(1.50)=80(1-e^-1.5)
       ≈62.1 rad/s
```

となる。

検算として

```text
(V_a-K_Eω)/R_a
=(120-1.50×62.1)/0.30
≈89.5 A
```

となり、丸め差の範囲で一致する。

## 問10 所要速度・トルクから必要端子電圧を逆算

磁束一定の直流電動機が、動作点1で

```text
V_1=220 V
I_{a1}=40 A
R_a=0.50 Ω
n_1=1000 min^-1
```

で運転している。動作点2では回転速度を `n_2=1200 min^-1`、電磁トルクを動作点1の75%とする。

必要端子電圧 `V_2` を求めよ。ブラシ電圧降下等は無視する。

### 完全解説

まず動作点1の逆起電力を求める。

```text
E_1=V_1-I_{a1}R_a
   =220-40×0.50
   =200 V
```

磁束一定なので逆起電力は回転速度に比例する。

```text
E_2=E_1(n_2/n_1)
   =200×1200/1000
   =240 V
```

また磁束一定ならトルクは電機子電流に比例するため

```text
I_{a2}=0.75I_{a1}
       =30 A
```

である。

したがって必要端子電圧は

```text
V_2=E_2+I_{a2}R_a
   =240+30×0.50
   =255 V
```

となる。

答案では

```text
E_1
→ 速度比からE_2
→ トルク比からI_{a2}
→ V_2=E_2+I_{a2}R_a
```

の順で書けば、H24二次の固定範囲と同型の計算を再利用できる。

## 問11 けん引力・加速度・所要時間

教材用の簡略モデルとして、電動機1台のトルク `T_m=600 N·m`、電動機台数 `N=12`、減速比 `G=2.8`、歯車伝達効率 `η_g=0.92`、動輪半径 `r_w=0.46 m` とする。列車の等価質量は `m_eq=2.40×10^5 kg`、走行抵抗は `F_r=18.0 kN` とする。

この区間で各値を一定と近似し、速度 `15.0 m/s` から `18.0 m/s` まで加速する所要時間を求めよ。

### 完全解説

車輪周けん引力は

```text
F_t=Nη_gGT_m/r_w
```

より

```text
F_t
=12×0.92×2.8×600/0.46
=40320 N
=40.32 kN
```

である。

正味力は

```text
F_t-F_r
=40.32-18.0
=22.32 kN
```

したがって加速度は

```text
a=(F_t-F_r)/m_eq
 =22.32×10^3/(2.40×10^5)
 =0.0930 m/s²
```

となる。

速度差は

```text
Δv=18.0-15.0
   =3.0 m/s
```

なので、一定加速度近似では

```text
Δt=Δv/a
   =3.0/0.0930
   ≈32.3 s
```

である。

この計算は教材用仮定値による簡略モデルであり、0系の実加速性能を表すものではない。

## 問12 タップ切替を含む離散時間の簡略加速

等価質量 `m_eq=2.00×10^5 kg` の列車モデルを考える。時間刻みを `Δt=10 s` とし、初速度を `v_0=0 m/s` とする。

第1区間では

```text
F_t=50 kN
F_r=10 kN
```

とする。10 s後に次の電圧段へ切り替え、第2区間では

```text
F_t=70 kN
F_r=10 kN
```

とする。

各区間で力は一定と近似する。`v_1`、`v_2` を求め、タップ上昇が時間―速度計算へどう現れるか説明せよ。

### 完全解説

第1区間の加速度は

```text
a_0=(50-10)×10^3/(2.00×10^5)
   =0.200 m/s²
```

である。

離散更新式

```text
v_{k+1}=v_k+a_kΔt
```

より

```text
v_1=0+0.200×10
   =2.00 m/s
```

となる。

次の電圧段へ切り替えた第2区間では

```text
a_1=(70-10)×10^3/(2.00×10^5)
   =0.300 m/s²
```

なので

```text
v_2=2.00+0.300×10
   =5.00 m/s
```

である。

したがって時間―速度の代表点は

```text
(t, v)
(0 s, 0 m/s)
(10 s, 2.00 m/s)
(20 s, 5.00 m/s)
```

となる。

この簡略モデルでは、タップ上昇によって利用できるけん引力が増え、その結果として次区間の加速度が `0.200` から `0.300 m/s²` へ増えた形で時間―速度曲線へ現れる。実車の切替時刻・切替電流・けん引力値を表すものではない。
