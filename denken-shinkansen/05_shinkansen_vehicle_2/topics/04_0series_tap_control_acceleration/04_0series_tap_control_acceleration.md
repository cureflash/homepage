# 教材で必須にする説明

## 1. 起動電流

- 停止時は `ω=0` なので `E=k_eΦω=0`。
- 電機子インダクタンスを無視する定常近似では `I_a=V_a/R_a` となり、電圧を一度に高くすると大電流になりやすい。
- H28問1に対応する過渡では `J dω/dt = T-T_L` と電圧方程式を組み合わせ、速度上昇に伴う逆起電力の増加が電流を低下させることを示す。

## 2. タップ切替と主回路電圧

- 変圧器側のタップ条件を、直流主回路へ与える段階的な電圧条件としてモデル化する。
- 実際の0系のタップ段数・各段電圧は一次資料確認後にだけ記載する。
- タップを上げる目的を「同じ速度で電機子電圧を上げれば電流・トルクを増やせる」という電圧方程式から説明する。

## 3. 電流制限と動作点移動

- 各電圧段で `V_a = E + I_aR_a` を用い、速度が上がるほど `E` が増えて `I_a` が低下する流れを追う。
- 電流が下がった後に次の電圧段へ移ることで、過大な起動電流を避けつつ加速を継続する一般原理を示す。
- 実車の切替閾値や制御ロジックは資料が確認できるまで仮定しない。

## 4. 直巻電動機の速度―トルク特性

- `T=k_tΦI_a`、`E=k_eΦω`、`V_a=E+I_aR_a` を基礎とする。
- 未飽和域では `Φ∝I_a` のため概ね `T∝I_a^2`、飽和が進むと概ね `T∝I_a` に近づくことを条件付きで説明する。
- 各タップ電圧ごとに速度―トルク曲線が変わり、負荷側条件との交点が動作点になることを図示する。
- 磁束を一定と仮定する例題では、その仮定を明示し、直巻実機の全域特性と混同しない。

## 5. けん引力

- 電動機トルクを歯車・車輪へ換算して車輪周けん引力へつなぐ。
- 一般式は、問題文で与えられた歯車比・伝達効率・動輪半径・電動機台数を用いて組み立てる。
- 未確認の0系固有値は使わない。

## 6. 簡略加速計算

- 列車側は `m_eq dv/dt = F_t - F_r` を基本とする。
- 一定区間近似では `a=(F_t-F_r)/m_eq`、`v_{k+1}=v_k+a_k Δt` として時間―速度を積み上げる。
- 回転体換算質量、走行抵抗、勾配抵抗等は問題文または一次資料で与えられる場合だけ数値化する。

## 7. 指定グラフ

必須:
- タップ条件―主回路電圧
- タップ条件―速度トルク特性
- 速度―けん引力
- 時間―速度の簡略加速計算

グラフを実車特性として描く場合は一次資料値のみを使う。資料値が不足する場合は「模式図」または「仮定条件による計算例」と明示する。

# 解説本文

## 1. このテーマで電験は何を問うか

このテーマでは、直流電動機の式を静止した1点の計算だけで終わらせず、起動から速度上昇、電流低下、電圧段の切替、けん引力、列車加速まで一本につなぐ。

一次試験では、停止時の大電流、逆起電力、トルク、慣性、始動過渡、直巻電動機の大始動トルクが問われる。二次試験では、ある速度・トルク条件から必要な端子電圧を逆算する答案へ発展する。

この章の到達目標は次のとおり。

1. 停止時 `E=0` から起動電流を計算できる。
2. 速度上昇で `E` が増え、`I_a` が下がる因果関係を説明できる。
3. `J dω/dt=T-T_L` と電圧方程式を組み合わせ、簡略始動過渡を解ける。
4. タップ上昇で主回路電圧と速度―トルク特性がどう変わるか説明できる。
5. 直巻電動機の大始動トルクを `Φ` と `I_a` の関係から説明できる。
6. 電動機トルクを車輪周けん引力へ換算できる。
7. `m_eq dv/dt=F_t-F_r` から時間―速度を簡略計算できる。
8. 所要速度・所要トルクから必要主回路電圧を逆算できる。

## 2. 0系をどうモデル化するか

本テーマでは、0系の主変圧器側の段階的な電圧制御を、整流後の直流主回路に与えられる複数の電圧段 `V_a` としてモデル化する。

```text
架線
 ↓
主変圧器・タップ条件
 ↓
整流回路
 ↓  段階的な主回路電圧 V_a
直流主電動機
 ↓  T_m
歯車・車輪
 ↓  F_t
列車質量・走行抵抗
 ↓
加速度・速度
```

ここで扱うのは制御原理を試験問題へ接続するためのモデルである。0系の実タップ段数、各段電圧、切替閾値、主電動機定格、歯車比、車輪径、編成質量を仮定で実値化しない。

## 3. 停止時に起動電流が大きくなる理由

直流電動機の基本式は

```text
V_a = E + I_aR_a
E = k_eΦω
T = k_tΦI_a
```

である。

停止時は `ω=0` なので

```text
E=0
```

となる。電機子インダクタンスを無視した瞬時の定常近似では

```text
I_a = V_a/R_a
```

であり、`R_a` が小さい電動機へ高い電圧を一度に加えると大きな電流になる。

したがって、起動時に主回路電圧を低く始める意味は、単に速度を低くすることではなく、逆起電力がまだ生じていない状態の電機子電流を抑えることにある。

速度が上がると

```text
ω ↑
→ E=k_eΦω ↑
→ I_a=(V_a-E)/R_a ↓
```

となる。同一電圧段のままなら、速度上昇に伴って電流とトルクは低下する。

## 4. H28一次に必要な簡略始動過渡

H28一次問1では、起動直後だけでなく、速度が立ち上がって電流が低下する過渡まで必要になる。

一定界磁の試験モデルとして

```text
V_a = R_ai_a + K_Eω
J dω/dt = K_Ti_a - T_L
```

を用いる。

- `K_E`: 一定界磁時の起電力定数 `[V·s/rad]`
- `K_T`: 一定界磁時のトルク定数 `[N·m/A]`
- `J`: 慣性モーメント `[kg·m²]`

無負荷 `T_L=0`、電機子インダクタンス無視、`V_a` 一定とすると

```text
i_a = (V_a-K_Eω)/R_a
```

を回転運動方程式へ代入して

```text
J dω/dt
= (K_T/R_a)(V_a-K_Eω)
```

したがって

```text
dω/dt + (K_EK_T)/(JR_a) ω
= K_TV_a/(JR_a)
```

である。時定数を

```text
τ = JR_a/(K_EK_T)
```

とおけば、停止状態からの解は

```text
ω(t) = (V_a/K_E){1-exp(-t/τ)}

i_a(t) = (V_a/R_a)exp(-t/τ)
```

となる。

つまり電流は `V_a/R_a` から指数的に低下し、速度は `V_a/K_E` へ指数的に近づく。この形を理解しておけば、H28一次問1の始動電流波形を式から判定できる。

実際の直巻主電動機全体をこの一定界磁式で表すわけではない。この節はH28一次の試験モデルを解くための説明である。

## 5. 直巻電動機と大始動トルク

直巻電動機では、界磁巻線と電機子に同じ電流が流れる。未飽和域で磁束を

```text
Φ ∝ I_a
```

と近似できるなら

```text
T = k_tΦI_a
```

より

```text
T ∝ I_a²
```

となる。このため、始動時の大きな電流が大きな始動トルクへ結び付きやすい。

磁気飽和が進むと、電流を増やしても磁束は同じ割合では増えないため、トルク特性は `T∝I_a²` から外れ、概ね `T∝I_a` に近い性質へ移る。

重要なのは、直巻電動機で常に `T∝I_a²` と断定しないことである。未飽和という条件を必ず確認する。

## 6. タップ切替・電流制限・動作点移動

ある電圧段 `V_1` で加速しているとする。速度上昇により `E` が増えると

```text
I_a=(V_1-E)/R_a
```

が低下し、トルクも低下する。

そこで、電流が十分下がった段階で主回路電圧を `V_2>V_1` へ上げると、切替直後は速度がほぼ同じなので `E` もほぼ同じとみなせる。したがって

```text
I_a'=(V_2-E)/R_a
```

となり、電流とトルクを再び増やせる。

因果関係は

```text
低い電圧段で起動
→ 速度上昇
→ 逆起電力上昇
→ 電機子電流低下
→ 次の電圧段へ移行
→ 電流・トルク回復
→ さらに加速
```

である。

本教材ではこの一般原理だけを使う。実車の電流閾値や切替ロジックは仮定しない。

## 7. タップ条件と速度―トルク特性

### 7.1 一定磁束近似で見る電圧段の影響

磁束一定の局所近似では

```text
E=K_Eω
T=K_TI_a
V_a=E+I_aR_a
```

より

```text
ω
= V_a/K_E - {R_a/(K_EK_T)}T
```

となる。

したがって、同じ `R_a`、同じ磁束なら、`V_a` を高くした曲線ほど速度―トルク平面で上側へ移る。負荷条件との交点が新しい動作点になる。

この直線式は一定磁束の局所近似であり、直巻電動機の全速度域の実特性を表すものではない。直巻電動機では磁束が電流に依存するため、実際の曲線形状は非線形になる。

### 7.2 直巻未飽和域の考え方

未飽和域で `Φ=cI_a` と置くと

```text
T = k_tcI_a²
E = k_ecI_aω
V_a = k_ecI_aω + I_aR_a
```

である。速度が上がるほど逆起電力が増え、同じ電圧段では電流が低下するため、トルクも低下する。タップ上昇は、同じ速度で利用できる電流・トルクを増やす方向に働く。

## 8. 所要速度・所要トルクから必要電圧を逆算する

二次試験では、電圧段を順方向に追うだけでなく、「この速度とトルクを得るには何V必要か」を逆算する。

磁束一定なら、基準動作点1から

```text
E_2 = E_1(n_2/n_1)
I_{a2} = I_{a1}(T_2/T_1)
```

を求め、最後に

```text
V_2 = E_2 + I_{a2}R_a
```

へ戻す。

答案順は

```text
基準点のE_1
→ 速度比からE_2
→ トルク比からI_{a2}
→ 電圧方程式からV_2
```

とする。磁束一定条件がない場合、この比例計算を無条件に使わない。

## 9. 電動機トルクから車輪周けん引力へ

電動機1台のトルクを `T_m`、電動機回転速度を `ω_m`、車輪回転速度を `ω_w` とする。減速比を

```text
G = ω_m/ω_w
```

と定義し、歯車伝達効率を `η_g` とすると、車輪軸へ伝わるトルクは

```text
T_w = η_gGT_m
```

である。

動輪半径を `r_w` とすれば、1台分の車輪周力は

```text
F_1 = T_w/r_w
    = η_gGT_m/r_w
```

主電動機が `N` 台あり、同じ条件で力を出す簡略モデルでは

```text
F_t = Nη_gGT_m/r_w
```

となる。

また車両速度は

```text
v = r_wω_w
  = r_wω_m/G
  = 2πr_wn_m/(60G)
```

で電動機回転速度と接続できる。

これらの `G`、`η_g`、`r_w`、`N` は問題文または確認済み資料から与えられた値だけを使う。

## 10. けん引力から加速度・時間―速度へ

列車の等価質量を `m_eq`、車輪周けん引力を `F_t`、走行抵抗などの合計を `F_r` とすると

```text
m_eq dv/dt = F_t-F_r
```

である。

一定区間で `F_t` と `F_r` を一定と近似すれば

```text
a = (F_t-F_r)/m_eq
```

である。

さらに時間刻み `Δt` の簡略計算では

```text
v_{k+1}=v_k+a_kΔt
```

と積み上げる。

速度依存のけん引力や走行抵抗を扱う場合は、各刻みで

```text
F_t(v_k)
F_r(v_k)
a_k={F_t(v_k)-F_r(v_k)}/m_eq
```

を更新する。この離散計算がSPEC指定の時間―速度グラフの基礎になる。

## 11. 3段階例題

以下の数値はすべて教材用の仮定値であり、0系の実車値ではない。

### 11.1 基礎例題: 電圧段を上げると電流はどう変わるか

電機子抵抗を `R_a=0.20 Ω` とする。停止時に第1電圧段 `V_1=40 V` を加えた。さらに、速度上昇後に逆起電力が `E=24 V` まで上がった時点で、第2電圧段 `V_2=60 V` へ切り替える。電機子インダクタンスは無視する。

停止時は `E=0` なので

```text
I_{start}=V_1/R_a
         =40/0.20
         =200 A
```

である。

同じ第1電圧段のまま `E=24 V` まで上がると

```text
I_1=(40-24)/0.20
   =80 A
```

となる。

この瞬間に第2電圧段へ切り替えると、速度は瞬時には変化しないので `E≈24 V` とみなせる。

```text
I_2=(60-24)/0.20
   =180 A
```

したがって

```text
200 A
→ 加速して80 Aまで低下
→ 電圧段を上げて180 Aへ回復
```

となる。これが段階的な主回路電圧制御で電流・トルクを保ちながら加速する基本像である。

### 11.2 本試験標準例題: 始動電流の指数減衰

一定界磁の直流電動機モデルで、`V_a=120 V`、`R_a=0.40 Ω`、`K_E=1.20 V·s/rad`、`K_T=1.20 N·m/A`、`J=6.0 kg·m²` とする。無負荷、電機子インダクタンス無視、停止状態から一定電圧を加える。時定数、初期電流、`t=τ` における電流と角速度を求める。

時定数は

```text
τ = JR_a/(K_EK_T)
  = 6.0×0.40/(1.20×1.20)
  = 1.67 s
```

初期電流は `E=0` より

```text
i_a(0)=V_a/R_a
      =120/0.40
      =300 A
```

である。

`t=τ` では

```text
i_a(τ)
=300e^-1
≈110 A
```

となる。

角速度は

```text
ω(τ)
=(120/1.20)(1-e^-1)
=100(1-e^-1)
≈63.2 rad/s
```

である。

電圧方程式で検算すると

```text
(120-1.20×63.2)/0.40
≈110 A
```

となり一致する。

この例題では、電流波形を暗記せず、速度上昇→逆起電力増加→電流低下を微分方程式から確認する。

### 11.3 複合例題: 必要電圧・けん引力・加速時間をつなぐ

一定磁束の局所近似を用いる教材モデルとする。動作点1で

```text
V_1=300 V
R_a=0.25 Ω
I_{a1}=200 A
n_1=500 min^-1
```

で運転している。動作点2では `n_2=750 min^-1`、トルクを動作点1の80%とする。

さらに以下を仮定する。

```text
主電動機台数 N=16
減速比 G=2.5
歯車効率 η_g=0.90
動輪半径 r_w=0.45 m
等価質量 m_eq=2.00×10^5 kg
走行抵抗 F_r=21.1 kN
```

この区間では動作点2のトルク・走行抵抗を一定とする簡略近似で、動作点1相当速度から動作点2相当速度までの所要時間を求める。

まず動作点1の逆起電力は

```text
E_1=V_1-I_{a1}R_a
   =300-200×0.25
   =250 V
```

磁束一定なので

```text
E_2=E_1(n_2/n_1)
   =250×750/500
   =375 V
```

トルクが80%なので

```text
I_{a2}=0.80I_{a1}
       =160 A
```

したがって必要電圧は

```text
V_2=E_2+I_{a2}R_a
   =375+160×0.25
   =415 V
```

である。

次に、動作点1から一定磁束時のトルク定数を求める。`n_1=500 min^-1` なので

```text
ω_1=2π×500/60
   ≈52.36 rad/s
```

よって

```text
K_E=E_1/ω_1
   ≈250/52.36
   ≈4.775 V·s/rad
```

SIの整合した一定磁束モデルとして `K_T=4.775 N·m/A` とすると、動作点2の電動機トルクは

```text
T_{m2}=K_TI_{a2}
      ≈4.775×160
      ≈764 N·m
```

である。

車輪周けん引力は

```text
F_t
=Nη_gGT_{m2}/r_w
=16×0.90×2.5×764/0.45
≈61.1 kN
```

したがって加速度は

```text
a=(F_t-F_r)/m_eq
 =(61.1-21.1)×10^3/(2.00×10^5)
 ≈0.200 m/s²
```

である。

電動機回転速度から列車速度へ変換すると

```text
v_1=2πr_wn_1/(60G)
   ≈9.42 m/s
   ≈33.9 km/h

v_2=2πr_wn_2/(60G)
   ≈14.14 m/s
   ≈50.9 km/h
```

よってこの簡略近似での所要時間は

```text
Δt=(v_2-v_1)/a
   =(14.14-9.42)/0.200
   ≈23.6 s
```

となる。

この例題の要点は、

```text
速度・トルク条件
→ 必要主回路電圧
→ 電動機トルク
→ 車輪周けん引力
→ 加速度
→ 時間―速度
```

を一つの計算鎖としてつなぐことである。数値はすべて仮定値であり、0系の実性能を表さない。

## 12. SPEC指定4グラフの作図条件

### 12.1 タップ条件―主回路電圧

実タップ値は使わず、模式図では

```text
時間または切替段
→ V_1, V_2, V_3, ...
```

という階段状の主回路電圧として描く。

各段の数値を置く場合は「仮定値」と明示する。実車特性として描く場合だけ一次資料値を使う。

### 12.2 タップ条件―速度トルク特性

一定磁束の局所近似では

```text
ω = V_a/K_E - {R_a/(K_EK_T)}T
```

を用い、`V_1<V_2<V_3` の複数曲線を同一座標へ描く。高い電圧段ほど曲線が上側へ移ることを示す。

直巻電動機の全域特性としては扱わず、図中に「一定磁束局所近似」と明記する。

### 12.3 速度―けん引力

各電圧段について

```text
電圧段
→ I_a(v)
→ T_m(v)
→ F_t(v)=Nη_gGT_m(v)/r_w
```

の順に求める。

模式図では、同一段内で速度上昇に伴ってけん引力が低下し、電圧段を上げると再びけん引力が増える流れを示す。実車の切替点は仮定しない。

### 12.4 時間―速度の簡略加速計算

時間刻み `Δt` ごとに

```text
F_t(v_k)
F_r(v_k)
a_k={F_t(v_k)-F_r(v_k)}/m_eq
v_{k+1}=v_k+a_kΔt
```

を計算し、`t-v` を描く。

計算プログラムを作る段階では、入力値・単位・仮定条件を別途保存し、代表点を手計算で照合する。

## 13. 頻出ミス・ひっかけ

1. 停止時にも逆起電力があると考える。
   - `ω=0` なら `E=0`。
2. 起動電流を `V_a/E` などで求める。
   - 電機子インダクタンス無視の停止時は `I_a=V_a/R_a`。
3. 速度が上がると同じ電圧段で電流も上がると考える。
   - `E` が増えるため `I_a=(V_a-E)/R_a` は下がる。
4. タップ上昇時に逆起電力も瞬時に跳ね上がると考える。
   - 機械速度は瞬時に変わらないため、切替直後の `E` はほぼ連続とみなす基本モデルで考える。
5. 直巻電動機で常に `T∝I_a²` とする。
   - 未飽和域の近似であり、飽和が進むと外れる。
6. 一定磁束の速度―トルク直線を直巻電動機の全域実特性とみなす。
   - 本教材では局所近似としてだけ使う。
7. 減速比の向きを逆にする。
   - 本文では `G=ω_m/ω_w` と定義している。
8. `n [min^-1]` をそのまま `v=rω` に代入する。
   - `ω=2πn/60` を使う。
9. 車輪トルクとけん引力を同じ量として扱う。
   - `F=T_w/r_w` で変換する。
10. `F_t` だけで加速度を求める。
    - `F_t-F_r` の正味力を使う。
11. 実車タップ値・切替電流・編成質量を出典なしで置く。
    - 未確認値は実値化しない。

## 15. 公式・解法まとめ

停止時:

```text
ω=0
E=0
I_a=V_a/R_a
```

基本式:

```text
V_a=E+I_aR_a
E=k_eΦω
T=k_tΦI_a
```

一定界磁の簡略始動過渡:

```text
V_a=R_ai_a+K_Eω
J dω/dt=K_Ti_a-T_L
```

無負荷・インダクタンス無視:

```text
τ=JR_a/(K_EK_T)
ω(t)=(V_a/K_E){1-exp(-t/τ)}
i_a(t)=(V_a/R_a)exp(-t/τ)
```

直巻未飽和域:

```text
Φ∝I_a
T∝I_a²
```

一定磁束局所近似の速度―トルク:

```text
ω=V_a/K_E-{R_a/(K_EK_T)}T
```

必要電圧の逆算:

```text
E_2=E_1(n_2/n_1)
I_{a2}=I_{a1}(T_2/T_1)
V_2=E_2+I_{a2}R_a
```

車輪周けん引力:

```text
G=ω_m/ω_w
F_t=Nη_gGT_m/r_w
```

車両速度:

```text
v=2πr_wn_m/(60G)
```

加速:

```text
m_eq dv/dt=F_t-F_r

a=(F_t-F_r)/m_eq

v_{k+1}=v_k+a_kΔt
```

解法の流れ:

```text
低い電圧段で起動
→ E=0なので起動電流を確認
→ 加速でE増加・I_a低下
→ 次の電圧段へ移行
→ トルクを車輪周力へ換算
→ 正味けん引力から加速度
→ 時間―速度へ積分
```
