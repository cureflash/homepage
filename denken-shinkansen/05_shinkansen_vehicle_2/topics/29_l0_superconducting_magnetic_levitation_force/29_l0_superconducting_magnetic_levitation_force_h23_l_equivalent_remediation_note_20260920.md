## 1. 簡略二次回路とL形等価回路を区別する

既存教材の

`I_2 = sE_2 / sqrt(r_2^2+(s x_2)^2)`

` s_m = r_2/x_2 `

は、固定子側電圧降下を無視して二次側だけを見る簡略形である。

H23問1では一相L形等価回路として `r_1`, `x_1`, `r'_2`, `x'_2` がすべて与えられるため、この簡略形をそのまま最大トルク条件へ使わない。

## 2. H23の一相L形等価回路

三相線間電圧を `V_L` とし、公式標準解答と同じ一相Y換算で

`V_1 = V_L/sqrt(3)`

とする。

すべり `s` のとき、二次電流の一次側換算値は

`I'_2 = V_1 / sqrt((r_1+r'_2/s)^2+(x_1+x'_2)^2)`

である。

同期角速度は極数 `p`、周波数 `f` に対して

`ω_s = 2π f/(p/2) = 4πf/p`

したがって電磁トルクは

`T = 3 I'^2_2 (r'_2/s) / ω_s`

で求める。

## 3. H23 (1) — s=0.05 のトルク

与条件:

- `V_L=200 V`
- `f=50 Hz`
- `p=4`
- `r_1=0.10 Ω`
- `x_1=0.30 Ω`
- `r'_2=0.15 Ω`
- `x'_2=0.40 Ω`
- `s=0.05`

相電圧:

`V_1=200/sqrt(3)=115.47 V`

電流:

`I'_2 = 115.47 / sqrt((0.10+0.15/0.05)^2+(0.30+0.40)^2)`

`=115.47/sqrt(3.10^2+0.70^2)`

`≈36.33 A`

同期角速度:

`ω_s=2π×50/(4/2)=50π rad/s`

よって

`T=3×36.33^2×(0.15/0.05)/(50π)`

`≈75.7 N·m`

公式標準解答: `75.7 N·m`。

## 4. H23 (2) — 最大トルクすべり

L形等価回路では

`T(s) ∝ (r'_2/s) / [(r_1+r'_2/s)^2+(x_1+x'_2)^2]`

である。

`y=r'_2/s` と置いて最大条件を取ると

`y^2 = r_1^2+(x_1+x'_2)^2`

したがって

`s_max = r'_2 / sqrt(r_1^2+(x_1+x'_2)^2)`

となる。

数値代入:

`s_max = 0.15/sqrt(0.10^2+(0.30+0.40)^2)`

`=0.15/sqrt(0.50)`

`≈0.212`

公式標準解答: `0.212`。

ここでは簡略形 `r'_2/x'_2=0.375` を使わない。固定子側 `r_1`,`x_1` が無視されていないからである。

## 5. H23 (3) — 逆相制動中の最大制動トルク点

通常運転時のすべりを

`s=(N_s-N)/N_s`

とする。二相を入れ替えて回転磁界を逆向きにした直後の逆相制動すべりは

`s_p=2-s`

である。

同期速度から逆相制動を始めると

- 開始直後: `N=N_s`, `s_p=2`
- 停止時: `N=0`, `s_p=1`

となる。

本問の最大トルク条件は `s_max=0.212` であり、逆相制動中の区間 `1<=s_p<=2` の外にある。そのため区間内では停止側の `s_p=1` で制動トルクの大きさが最大となる。

したがって回転速度は

`N=0 min^-1`

である。

## 6. H23 (4) — 逆相制動開始直後

同期速度で運転中に二相を入れ替えた直後は

`s_p=2`

である。同じL形等価回路式に `s=2` を代入する。

`I'_2 = 115.47 / sqrt((0.10+0.15/2)^2+0.70^2)`

`≈160.03 A`

`T = 3×160.03^2×(0.15/2)/(50π)`

`≈36.7 N·m`

これは回転方向と反対向きに働く制動トルクの大きさである。

公式標準解答: `36.7 N·m`。

## 7. 過去問固有の見分け方

H23問1のように問題文が `r_1`, `x_1`, `r'_2`, `x'_2` を明示してL形等価回路を与えた場合は、固定子側を落とした `s_m=r'_2/x'_2` を使わない。

判断手順:

1. 線間電圧か相電圧か確認する。
2. 問題の等価回路に固定子 `r_1`,`x_1` が残っているか確認する。
3. 残っていれば `r_1+r'_2/s`, `x_1+x'_2` を使う。
4. 最大トルクはその `T(s)` から求める。
5. 逆相制動では `s_p=2-s` と実際に通過するすべり区間を照合し、数学的最大点が区間内にあるか確認する。
