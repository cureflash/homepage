## 1. このテーマで電験二種は何を問うか

照明設計では、用語暗記だけでなく、測光量を区別し、配光から光束・照度を求め、光束法で必要灯数を設計し、消費電力と `lm/W` を評価できる必要がある。

本テーマは次の順で解く。

1. 光束 `Φ`、光度 `I`、照度 `E` のどの量を問われているか判定する。
2. 単位 `lm`、`cd`、`lx` を対応させる。
3. 点光源なら逆二乗則と入射角余弦則を使う。
4. 配光が与えられたら、光度の角度分布として読む。
5. 面全体の平均照度を設計する問題では光束法を使う。
6. 照明率 `U` と保守率 `M` を別の係数として扱う。
7. 所要灯数は端数を切り上げ、器具当たり光源数も確認する。
8. 消費電力と全光束からエネルギー消費効率 `lm/W` を求める。

## 2. 測光量の基本

### 2.1 光束

光束 `Φ [lm]` は、放射エネルギーを人の明所視の分光感度で重み付けした「光としての量」である。電磁波の物理的な放射束そのものではない。

標準分光視感効率はおよそ555 nmで最大となる。R6一次「機械」問6では、この視感度と測光量の関係が前提になる。

### 2.2 光度

光度 `I [cd]` は、ある方向について単位立体角当たりに出る光束である。

微分形では

`I = dΦ/dΩ`

均一に光束 `Φ` が立体角 `Ω` へ分布する場合は

`I = Φ/Ω`

となる。

全方向へ等方的に放射する点光源では全立体角が `4π sr` なので

`I = Φ/(4π)`

である。

### 2.3 照度

照度 `E [lx]` は、面の単位面積へ入射する光束である。

`E = dΦ/dA`

`1 lx = 1 lm/m²`

点光源の直下など、光が面へ垂直に入る場合は

`E = I/r²`

である。

面法線と入射光のなす角を `θ` とすると、入射角余弦則により

`E = I cosθ / r²`

となる。距離だけでなく、面の傾きでも照度が変わる。

## 3. 固定過去問で必要な補助測光量

R8一次「機械」問7とR3一次「機械」問6を教材だけで解くため、固定9項目に直接含まれない次の2量も最小限扱う。

### 3.1 光束発散度

光束発散度 `M [lm/m²]` は、発光面から単位面積当たりに出る光束である。

`M = dΦ_out/dA`

照度が「面へ入る光束」、光束発散度が「面から出る光束」である点を区別する。

### 3.2 輝度

輝度 `L [cd/m²]` は、観測方向から見た発光面の投影面積当たりの光度である。

`L = dI/(dA cosθ)`

均等拡散面（Lambert面）では

`M = πL`

が成り立つ。

## 4. 配光

配光は、光源・照明器具の光度が方向によってどう変わるかを表す空間分布である。軸対称なら光度を `I(θ)` と書き、鉛直角 `θ` ごとの値を配光曲線として示せる。

軸対称配光の全光束は

`Φ = 2π ∫_0^π I(θ) sinθ dθ`

で求める。

下半球だけに光を出す場合は積分範囲をその配光範囲へ合わせる。式を暗記するだけでなく、微小立体角

`dΩ = 2π sinθ dθ`

に対し `dΦ = I(θ)dΩ` を積分していると理解する。

R7一次「機械」問7では、配光図を全光束と照度へ結び付ける。配光の値をそのまま光束や照度と取り違えない。

## 5. 点光源の照度計算

点光源から面上の点までの距離を `r`、その方向の光度を `I`、面法線との角度を `θ` とすれば

`E = I cosθ/r²`

である。

光源高さを `H`、水平距離を `D` とすると

`r = √(H²+D²)`

`cosθ = H/r`

なので、水平面照度は

`E_h = HI/(H²+D²)^(3/2)`

となる。

直下では `D=0` より

`E_h = I/H²`

へ戻る。

### 頻出ミス

- 光源から面までの鉛直高さ `H` を、そのまま斜距離 `r` として使わない。
- 光度 `cd` を光束 `lm` と取り違えない。
- 余弦を掛ける角度が面法線基準かを確認する。

## 6. 光束法

室内などの平均照度を設計するときは、光束法を使う。

`E = Φ N U M / A`

- `E`: 平均照度 [lx]
- `Φ`: 1光源当たり、または1器具当たりの設計上の光束 [lm]
- `N`: 上の `Φ` の定義に対応する光源数または器具数
- `U`: 照明率 [-]
- `M`: 保守率 [-]
- `A`: 被照面積 [m²]

所要数は

`N = EA/(ΦUM)`

と逆算する。

### 6.1 照明率

照明率 `U` は、光源・器具から出た光束のうち、被照面へ有効に到達する割合を表す。室の形状、器具の配光、反射率などの影響を受ける。

### 6.2 保守率

保守率 `M` は、ランプ・光源の光束低下や器具・室内の汚れなどによる経時低下を設計へ織り込む係数である。通常 `0 < M ≤ 1` の範囲で与えられる。

照明率は「光がどれだけ利用されるか」、保守率は「経時後にどれだけ維持されるか」であり、意味が異なる。

### 6.3 所要灯数と切上げ

計算結果が整数でなければ、要求照度を満たす側へ切り上げる。

器具1台に複数光源を収める場合、まず式の `N` が光源数か器具数かを問題文で確認する。光源数で求めた後に器具数へ換算するなら、器具単位で不足しないよう再度切り上げる。

## 7. 消費電力と効率

照明で問われる代表的な効率指標は、エネルギー消費効率（luminous efficacy）である。

`η_e = Φ/P`

- `Φ`: 全光束 [lm]
- `P`: 消費電力 [W]
- `η_e`: エネルギー消費効率 [lm/W]

`lm/W` は無次元の変換効率ではない。また、光束法の照明率 `U` とも別の量である。

同一の必要光束を得るとき、`lm/W` が高いほど必要な電力は小さくなる。ただし、実際の設備設計では配光、照明率、保守率、必要照度なども同時に満たす必要がある。

## 8. 固定過去問固有の最小ブリッジ

### 8.1 色温度

R7一次「機械」問7を全答案要素まで解くため、色温度は「ある光源の光色に対応する黒体の温度」として最小限理解する。Topic 32の固定項目へは追加しない。

### 8.2 LEDランプの寿命判定

同じR7問7では、LEDランプの定格寿命に関する70%基準が問われる。固定過去問の答案要素として扱うが、寿命設計を本テーマの独立論点へ拡張しない。

### 8.3 グローブ内の多重反射

R3一次「機械」問6型では、球形グローブ内で反射を繰り返す簡略モデルを扱う。入射光束を `F_p`、内面反射率を `ρ`、透過率を `τ` とすると、各反射後に残る光束が幾何級数になる条件では外部へ出る全光束 `F_s` は

`F_s = τF_p(1+ρ+ρ²+...)`

`= τF_p/(1-ρ)`

である。

外面から全方向へ均等に放射するとみなせる場合

`I = F_s/(4π)`

半径 `r_g` の球面で光束発散度が一様なら

`M = F_s/(4πr_g²)`

均等拡散面なら

`L = M/π`

となる。

これは固定過去問を解くための簡略条件であり、一般の照明器具へ無条件に適用しない。

## 9. 問題を見たときの解法手順

1. 求める量と単位を先に確認する。`lm / cd / lx / lm/W` を区別する。
2. 点光源か面光源か、配光が均一か方向依存かを判定する。
3. 点光源照度なら `E=I cosθ/r²` を使える条件か確認する。
4. 配光図なら、必要方向の `I(θ)` を読むか、全光束が必要なら立体角積分する。
5. 平均照度・必要灯数なら光束法 `E=ΦNUM/A` を選ぶ。
6. `U` と `M` の意味を取り違えない。
7. `N` が光源数か器具数か確認し、端数を不足側へ丸めない。
8. 消費電力が与えられたら `Φ/P [lm/W]` を計算する。
9. 答えの桁、単位、光束保存、距離二乗依存を検算する。

## 10. 典型例題1 — 基礎: 等方点光源

全光束 `800 lm` の等方点光源がある。光度と、光源直下2.0 mの水平面照度を求める。

### 解答

全方向の立体角は `4π sr` なので

`I = 800/(4π)`

`= 63.66 cd`

直下では入射角0°なので

`E = I/r²`

`= 63.66/2.0²`

`= 15.92 lx`

### 検算

距離を2倍にすると照度は1/4になる。照度は受光面の単位面積当たりに入射する光束なので、最終単位が `lx = lm/m²` であることを確認する。

## 11. 典型例題2 — 本試験標準: 光束法

面積 `40 m²` の室で平均照度 `500 lx` を確保したい。1光源の光束を `3200 lm`、照明率 `U=0.60`、保守率 `M=0.80` とする。1器具に2光源を収めるとき、必要器具数を求める。数値は教材用仮定値である。

### 解答

光源数を `N` として

`N = EA/(ΦUM)`

`= 500×40/(3200×0.60×0.80)`

`= 13.02...`

光源数は不足しないよう14本へ切り上げる。

1器具2光源なので

`14/2 = 7`

必要器具数は `7台`。

### 検算

7台=14光源を式へ戻せば、目標500 lx以上になる。13本へ切り下げるのは不可。

## 12. 典型例題3 — 複合: 配光・全光束・効率・照度

下半球だけへ光を出す軸対称光源を考え、配光を

`I(θ)=300 cosθ [cd]  (0≤θ≤π/2)`

とする。消費電力を `10 W` とする。全光束、エネルギー消費効率、直下3.0 mの照度を求める。これは教材用仮定モデルである。

### 解答

全光束は

`Φ = 2π∫_0^(π/2) 300 cosθ sinθ dθ`

`= 300π`

`= 942.48 lm`

したがって

`η_e = Φ/P = 942.48/10`

`= 94.25 lm/W`

直下では `θ=0` なので `I(0)=300 cd`。

`E = 300/3.0²`

`= 33.33 lx`

### 検算

配光積分では `sinθ` を落とさない。`lm/W` と照明率は別物である。

## 13. 新幹線への接続

本テーマでは車内照明を「限られた消費電力で必要な照度分布を作る照明設備」という一般的な設計題材として扱う。

電験の一般モデルでは、次を同じ式で評価できる。

ただし、特定新幹線形式の器具方式、灯数、全光束、配光、照度、照明率、保守率、消費電力、効率は一次資料で確認できない限り実値として使わない。本sourceの例題数値はすべて教材用仮定値である。

## 16. 頻出ミス

- `lm`、`cd`、`lx` を同じ量として扱う。
- `I=Φ/(4π)` を等方光源以外へ無条件に使う。
- 照度で逆二乗だけ使い、斜入射の `cosθ` を落とす。
- 配光積分で立体角要素の `sinθ` を落とす。
- 光束法の照明率と保守率を入れ替える。
- 所要灯数を切り下げる。
- 光源数と器具数を混同する。
- `lm/W` と無次元効率、照明率を混同する。
- 実車未確認値を教材例題値から逆輸入する。

## 17. 公式・解法まとめ

- `I = dΦ/dΩ`
- 等方点光源: `I = Φ/(4π)`
- `E = dΦ/dA`
- 点光源: `E = I cosθ/r²`
- 水平面: `E_h = HI/(H²+D²)^(3/2)`
- 軸対称配光: `Φ = 2π∫ I(θ)sinθ dθ`
- 均等拡散面: `M = πL`
- 光束法: `E = ΦNUM/A`
- 所要数: `N = EA/(ΦUM)`
- エネルギー消費効率: `η_e = Φ/P [lm/W]`
