## 共通式・成立条件

- 光度: `I = dΦ/dΩ`
- 等方点光源: `I = Φ/(4π)`
- 照度: `E = dΦ/dA`
- 点光源照度: `E = I cosθ/r²`
- 水平面照度: `E_h = HI/(H²+D²)^(3/2)`
- 軸対称配光の全光束: `Φ = 2π∫ I(θ)sinθ dθ`
- 光束法: `E = ΦNUM/A`
- 所要数: `N = EA/(ΦUM)`
- エネルギー消費効率: `η_e = Φ/P [lm/W]`
- 均等拡散面: `M = πL`
- 球形グローブ簡略モデル: `F_s = τF_p/(1-ρ)`

`U` は照明率、`M` は保守率であり、光束発散度の記号 `M` と同じ文字を使うことがある。問題ごとに定義を確認する。

# 一次試験型

## 問1 測光量と単位

測光量と単位の組合せとして最も適切なものを選べ。

1. 光束 `Φ`: `cd`、光度 `I`: `lm`、照度 `E`: `cd/m²`
2. 光束 `Φ`: `lm`、光度 `I`: `cd`、照度 `E`: `lx`
3. 光束発散度: `cd/m²`、輝度: `lm/m²`
4. 照度: `lm/W`、光束: `lx`
5. 輝度: `lx`、光度: `lm/m²`

### 正答
2

### 完全解説

光束は `lm`、光度は `cd`、照度は `lx = lm/m²` である。光束発散度は `lm/m²`、輝度は `cd/m²` なので3は逆である。`lm/W` はエネルギー消費効率の単位である。

よって2。

## 問2 逆二乗則と入射角余弦則

点光源から水平面上の点までの斜距離が `5.0 m`、その方向の光度が `300 cd` である。光源の高さは `4.0 m` とする。この点の水平面照度に最も近いものを選べ。

1. `4.8 lx`
2. `7.5 lx`
3. `9.6 lx`
4. `12.0 lx`
5. `15.0 lx`

### 正答
3

### 完全解説

水平面の法線は鉛直方向なので

`cosθ = H/r = 4/5 = 0.8`

点光源照度は

`E = I cosθ/r²`

`= 300×0.8/5²`

`= 9.6 lx`

よって3。

斜距離 `r` の代わりに高さ `H` を分母へ入れたり、余弦を落としたりしない。

## 問3 軸対称配光から全光束

ある照明器具は下半球 `0≤θ≤π/2` のみに光を出し、軸対称配光が

`I(θ)=120 cosθ [cd]`

で与えられる。全光束に最も近いものを選べ。

1. `120 lm`
2. `240 lm`
3. `377 lm`
4. `754 lm`
5. `1508 lm`

### 正答
3

### 完全解説

軸対称配光では

`Φ = 2π∫_0^(π/2) I(θ)sinθ dθ`

だから

`Φ = 2π×120∫_0^(π/2) cosθ sinθ dθ`

積分値は `1/2` なので

`Φ = 120π = 376.99 lm`

したがって約 `377 lm`、正答3。

光度 `cd` をそのまま光束 `lm` として扱わず、微小立体角を通じて積分する。

## 問4 光束法による所要光源数

床面積 `12 m × 8 m` の室で平均照度 `500 lx` を確保したい。1光源当たり全光束 `4000 lm`、照明率 `U=0.60`、保守率 `M=0.80` とする。必要光源数として最も適切なものを選べ。

1. `15`
2. `20`
3. `24`
4. `25`
5. `32`

### 正答
4

### 完全解説

床面積は

`A=12×8=96 m²`

光束法

`N = EA/(ΦUM)`

へ代入する。

`N = 500×96/(4000×0.60×0.80)`

`=25.0`

よって25光源、正答4。

照明率と保守率はいずれも分母側で有効光束を減少させる係数として働く。

## 問5 器具数への換算と消費電力

床面積 `200 m²`、設計平均照度 `300 lx` の室を照明する。1ランプの全光束 `3200 lm`、1器具に2ランプ、照明率 `0.65`、保守率 `0.80`、1ランプの消費電力 `28 W` とする。必要器具数と、その器具を全て点灯したときのランプ消費電力の組合せとして最も適切なものを選べ。

1. `18器具, 1008 W`
2. `19器具, 1064 W`
3. `19器具, 1120 W`
4. `20器具, 1064 W`
5. `20器具, 1120 W`

### 正答
2

### 完全解説

1器具当たりの全光束は

`Φ_f = 2×3200 = 6400 lm`

必要器具数は

`N = 300×200/(6400×0.65×0.80)`

`=18.0288...`

要求照度を下回らないため `19器具` へ切り上げる。

ランプ数は `19×2=38本` なので

`P = 38×28 = 1064 W`

よって2。

途中で18器具へ切り捨てないこと、器具数とランプ数を混同しないことが要点である。

## 問6 エネルギー消費効率

全光束 `3600 lm`、消費電力 `30 W` のランプがある。このランプのエネルギー消費効率と、同じ効率の光源で `18000 lm` を得るために必要な消費電力の組合せとして正しいものを選べ。

1. `60 lm/W, 150 W`
2. `90 lm/W, 200 W`
3. `120 lm/W, 120 W`
4. `120 lm/W, 150 W`
5. `150 lm/W, 120 W`

### 正答
4

### 完全解説

エネルギー消費効率は

`η_e = Φ/P = 3600/30 = 120 lm/W`

同じ効率で `18000 lm` を得るなら

`P = Φ/η_e = 18000/120 = 150 W`

よって4。

`lm/W` は無次元効率ではなく、照明率 `U` とも別の量である。

## 問7 球形グローブの多重反射と輝度

簡略球形グローブモデルで、内部入射光束 `F_p=1000 lm`、透過率 `τ=0.60`、内面反射率 `ρ=0.40`、グローブ半径 `r_g=0.20 m` とする。外部へ出る全光束 `F_s` と、均等拡散面とみなしたときの輝度 `L` の組合せとして最も近いものを選べ。

1. `600 lm, 380 cd/m²`
2. `600 lm, 633 cd/m²`
3. `1000 lm, 253 cd/m²`
4. `1000 lm, 633 cd/m²`
5. `1667 lm, 1055 cd/m²`

### 正答
4

### 完全解説

多重反射を幾何級数で足すと

`F_s = τF_p/(1-ρ)`

`=0.60×1000/(1-0.40)`

`=1000 lm`

球面積は `4πr_g²` なので光束発散度は

`M = F_s/(4πr_g²)`

`=1000/(4π×0.20²)`

`=1989.44 lm/m²`

均等拡散面では

`M=πL`

したがって

`L=M/π=633.26 cd/m²`

よって4。

この多重反射式は問題で与えた簡略条件に限定して使う。

## 問8 色温度とLED寿命の固定過去問ブリッジ

Topic 32の固定過去問で要求される知識として最も適切な記述を選べ。

1. 色温度は照明率を絶対温度で表した値である。
2. 色温度は光源の消費電力を絶対温度へ換算した値である。
3. 色温度は光源の光色に対応する黒体の温度として扱い、固定過去問ではLEDランプ寿命の70%光束基準も区別して問われる。
4. LEDランプの寿命は、初期光束が必ず0%になった瞬間だけで定義される。
5. 色温度と演色性は同一の物理量である。

### 正答
3

### 完全解説

色温度は、光源の光色に対応する黒体の温度として扱う。固定過去問ではLEDランプの定格寿命に関する70%光束基準も答案要素になる。色温度、演色性、照明率、消費電力は互いに別の量である。

よって3。

この2項目は固定過去問を解くための最小ブリッジであり、Topic 32のSPEC固定9項目へは追加しない。

## 問9 照明率・保守率・効率の識別

照明率 `U`、保守率 `M`、エネルギー消費効率 `η_e` に関する記述として最も適切なものを選べ。

1. `U` と `M` はともに単位 `lm/W` を持つ。
2. `U` は経時劣化だけを表し、`M` は配光だけを表す。
3. `η_e` は無次元であり、光束法では `U` と完全に同じ意味を持つ。
4. `U` は被照面へ有効に届く割合、`M` は経時低下を織り込む係数、`η_e` は全光束を消費電力で割った `lm/W` の量である。
5. `U` と `M` は必ず1を超える。

### 正答
4

### 完全解説

照明率 `U` と保守率 `M` はいずれも無次元係数だが、意味が異なる。`U` は光がどれだけ有効に被照面へ届くか、`M` は経時後にどれだけ光束・照度が維持されるかを表す。

エネルギー消費効率は

`η_e=Φ/P [lm/W]`

であり、照明率とは別物である。よって4。

## 問10 等方点光源から水平面照度

全光束 `800 lm` の等方点光源が、水平面から高さ `3.0 m` にある。光源直下から水平距離 `4.0 m` の点の水平面照度に最も近いものを選べ。

1. `0.61 lx`
2. `1.53 lx`
3. `2.55 lx`
4. `4.24 lx`
5. `7.07 lx`

### 正答
2

### 完全解説

等方点光源の光度は

`I = Φ/(4π) = 800/(4π) = 63.66 cd`

斜距離は

`r=√(3²+4²)=5.0 m`

水平面法線との余弦は

`cosθ=3/5=0.6`

よって

`E = I cosθ/r²`

`=63.66×0.6/25`

`=1.528 lx`

したがって約 `1.53 lx`、正答2。

同じ式を

`E_h = HI/(H²+D²)^(3/2)`

として計算しても同値になる。
