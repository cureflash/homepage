# 解説本文

## 1. このテーマで電験は何を問うか

整流回路では、回路記号を知っているだけでは足りない。どの素子がどの区間で導通するかを決め、その導通状態から出力電圧・素子電流・交流側電流の波形を組み立て、積分によって平均値・実効値・電力を求めることが中心になる。

一次試験では、波形、平均値、交流条件、直流偏磁などを選択式で判断する問題がある。二次試験では、単相・三相整流器について導通区間を示し、平均直流電圧、平滑要素の周期定常条件、交流側基本波、有効・無効電力まで途中式付きで導く問題が重要になる。

この章の到達目標は次のとおり。

1. 正弦波から半波・全波整流波形を作れる。
2. 平均値と実効値を積分から区別して求められる。
3. `L` と `C` の周期定常条件を使い、平滑後の平均量を求められる。
4. 単相・三相ブリッジの素子電流と素子電圧を判断できる。
5. 三相サイリスタ変換器の `Vdc` を制御角から導出できる。
6. 交流側方形波電流を基本波と高調波へ分け、力率・有効電力・無効電力へ接続できる。
7. 二次試験で仮定、積分区間、極性、単位を明記した答案を書ける。

以後、特記しない限り理想素子、電源インピーダンス0、転流重なりなしとして扱う。大リアクトルを置く問題では直流電流を一定、大容量コンデンサを置く問題ではリプルを十分小さい理想化として扱う。問題文が別条件を指定した場合はその条件を優先する。

## 2. 単相整流の導通と波形

交流電源を

```text
v_s(θ) = Vm sinθ
Vm = √2 Vs
```

とする。`Vs` は交流電圧の実効値、`Vm` は波高値である。

### 2.1 単相半波整流

理想ダイオードと抵抗負荷の半波整流では、正半周期 `0 < θ < π` だけダイオードが導通する。

```text
v_d(θ) = Vm sinθ    0 < θ < π
v_d(θ) = 0          π < θ < 2π
```

抵抗負荷なら

```text
i_d(θ) = v_d(θ) / R
```

である。負半周期では電源側から負荷へ電流は流れない。

この波形は正側だけを使うため、交流側電流に直流分が生じやすい。変圧器二次側でこのような非対称電流を流す場合は、後述する直流偏磁を必ず確認する。

### 2.2 単相全波ブリッジ整流

単相ブリッジでは、正半周期と負半周期で対角のダイオード対が交互に導通し、負荷側の極性は常に同じになる。

```text
v_d(θ) = |Vm sinθ|
```

抵抗負荷では負荷電流も全波整流正弦波となる。平滑リアクトルが十分大きく直流電流を `Id` 一定とみなせる場合、各ダイオードは180°ずつ導通し、交流側電流は正負に切り替わる方形波になる。

一定直流電流 `Id` の理想単相ブリッジでは、各ダイオードについて

```text
I_D,av = Id / 2
I_D,rms = Id / √2
```

となる。また、各ダイオードの最大逆電圧は交流波高値 `Vm` である。抵抗負荷では素子電流は正弦波状になるので、一定電流の場合の値をそのまま使わない。

## 3. 周期波形の平均値・実効値

周期 `T` の波形 `x(t)` の平均値は

```text
Xav = (1/T) ∫_0^T x(t) dt
```

実効値は

```text
Xrms = sqrt[(1/T) ∫_0^T x²(t) dt]
```

である。

平均値は直流成分を表す。実効値は、抵抗へ同じ発熱を与える直流値に対応する。整流波形では両者を混同しない。

### 3.1 半波整流の平均値・実効値

半波整流電圧の平均値は

```text
Vdc = (1/2π) ∫_0^π Vm sinθ dθ
    = Vm / π
    = (√2/π) Vs
    ≒ 0.450 Vs
```

実効値は

```text
Vrms = sqrt[(1/2π) ∫_0^π Vm² sin²θ dθ]
     = Vm / 2
     = Vs / √2
     ≒ 0.707 Vs
```

となる。

### 3.2 全波整流の平均値・実効値

全波整流では負半周期も正側へ折り返されるため

```text
Vdc = (1/π) ∫_0^π Vm sinθ dθ
    = 2Vm / π
    = (2√2/π) Vs
    ≒ 0.900 Vs
```

実効値は符号反転の影響を受けないので

```text
Vrms = Vs
```

である。

抵抗負荷の平均電力は

```text
P = Vrms² / R
```

で求める。無平滑の全波整流波形に対して `Vdc²/R` を使うと誤る。一方、十分平滑されて直流電圧が一定なら `Vdc=Vrms` となり、`P=Vdc²/R` を使える。

### 3.3 リプルの表し方

整流出力を「直流成分＋交流リプル成分」に分ける。全実効値を `Vrms`、平均直流値を `Vdc` とすると、リプル成分の実効値は

```text
Vr,rms = sqrt(Vrms² - Vdc²)
```

リプル率を

```text
r = Vr,rms / Vdc
  = sqrt[(Vrms / Vdc)² - 1]
```

と定義できる。

無平滑の理想波形では、半波整流で `r ≒ 1.21`、全波整流で `r ≒ 0.483` となる。平滑要素を大きくすると出力変動が小さくなり、リプル率も低下する。

リプル周波数は、単相半波では電源周波数 `f`、単相全波では `2f` である。三相6パルスブリッジでは転流が1周期に6回起こるため、主な低次リプルは `6f` を基本に現れる。

## 4. 平滑要素と周期定常条件

### 4.1 リアクトルの1周期平均電圧

リアクトルでは

```text
v_L = L di/dt
```

である。周期定常状態では `i(T)=i(0)` だから

```text
(1/T) ∫_0^T v_L dt
= (L/T){i(T)-i(0)}
= 0
```

となる。

したがって、直列平滑リアクトルの平均電圧降下は0である。理想的に `L` が十分大きい場合は直流電流のリプルが小さくなり、`Id` をほぼ一定として扱える。平均直流電圧は、整流器出力電圧の平均値から求める。

### 4.2 コンデンサの1周期平均電流

コンデンサでは

```text
i_C = C dv/dt
```

である。周期定常状態では `v(T)=v(0)` だから

```text
(1/T) ∫_0^T i_C dt
= (C/T){v(T)-v(0)}
= 0
```

となる。

したがって、コンデンサ自身へ1周期を通じて電荷が蓄積し続けることはなく、平均コンデンサ電流は0である。

大容量コンデンサを整流出力へ並列に置くと、整流電圧がコンデンサ電圧を上回る付近で充電し、それ以外の区間ではコンデンサが負荷へ放電する。理想的に容量が十分大きくリプルを無視できるなら、直流側電圧は交流波高値付近に保持される。

ただし、この場合の交流側電流は波高値付近へ集中したパルス状になりやすい。出力電圧のリプルは小さくなっても、入力電流高調波や力率まで自動的に改善するわけではない。

### 4.3 `L` 平滑と `C` 平滑を混同しない

大リアクトル平滑では「電流を一定に近づける」ことが主効果であり、大容量コンデンサ平滑では「電圧を一定に近づける」ことが主効果である。

単相全波ブリッジの理想化では、同じ `Vs` でも代表値は次のように異なる。

```text
無平滑:            Vdc = (2√2/π) Vs
大L・連続電流:     Vdc ≒ (2√2/π) Vs
大C・小リプル:     Vdc ≒ √2 Vs
```

負荷電力を比較するときは、それぞれの波形条件に合った実効値または一定直流値を使う。

## 5. 三相ブリッジの導通と素子定格

三相6パルスブリッジでは、上側群から瞬時電圧が最も高い相、下側群から瞬時電圧が最も低い相が導通する。導通する組合せは60°ごとに切り替わり、直流側電圧は対応する線間電圧の一部を順番につないだ波形になる。

直流電流 `Id` が十分平滑され一定とみなせる場合、各素子は120°ずつ導通する。したがって各素子の電流は

```text
I_T,av = Id / 3
I_T,rms = Id / √3
```

となる。

理想ブリッジで各非導通素子が阻止する最大電圧は、線間電圧の波高値

```text
V_RRM,ideal = √2 V_LL
```

を基準に判断する。実機の素子選定では過渡過電圧や余裕率が必要だが、本テーマでは過去問の理想条件を超えて設計仕様を追加しない。

### 5.1 ダイオードブリッジの平均直流電圧

線間電圧実効値を `V_LL` とする。1つの60°区間を線間電圧の頂点を中心に取り

```text
v_LL(θ) = √2 V_LL cosθ
```

と書けば、同じ形の区間が1周期に6回あるので

```text
Vd0
= (6/2π) ∫_-π/6^π/6 √2 V_LL cosθ dθ
= (3√2/π) V_LL
≒ 1.35 V_LL
```

となる。

この式は三相6パルスブリッジの基準となる。`V_LL` は相電圧ではなく線間電圧の実効値である。

## 6. サイリスタ制御角と平均直流電圧

全制御三相ブリッジで、自然転流点から点弧を `α` だけ遅らせ、直流電流が連続し転流重なりを無視できるとする。

積分区間を `α` だけ移動すると

```text
Vdc
= (6/2π) ∫_-π/6+α^π/6+α √2 V_LL cosθ dθ
= (3√2/π) V_LL cosα
≒ 1.35 V_LL cosα
```

となる。

`α=0` ならダイオードブリッジと同じ最大平均直流電圧になる。`α` を大きくすると `cosα` に従って平均直流電圧が低下する。

直流電流の向きを正に固定して考えると

```text
Pdc = Vdc Id
```

である。`Vdc` の符号が変われば `Pdc` の符号も変わり、電力方向が反転する。ここではH21二次で必要な極性・電力方向の判定までを扱い、Topic 02外のインバータ方式設計へは広げない。

## 7. 交流側電流のフーリエ成分と電力

### 7.1 120°通電の線電流

大リアクトルにより直流電流 `Id` を一定とみなす三相ブリッジでは、各交流線電流は

- `+Id` が120°
- `0` が60°
- `-Id` が120°
- `0` が60°

という方形波になる。

この線電流の全実効値は

```text
I = sqrt(240°/360°) Id
  = √(2/3) Id
```

である。

フーリエ分解した基本波実効値は

```text
I1 = (√6/π) Id
```

となる。したがって、基本波が全実効値に占める比率は

```text
I1 / I = 3/π ≒ 0.955
```

である。

理想6パルス波形には `5, 7, 11, 13, ...`、一般に `6k±1` 次の特性高調波が含まれる。高調波電流は全実効値を増やすが、電源電圧を正弦波とする本試験の理想条件では平均有効電力は基本波電流で評価できる。

### 7.2 有効電力・基本波無効電力

転流重なりなしの全制御ブリッジでは、交流側基本波電流の位相差は制御角 `α` で表される。したがって

```text
P = √3 V_LL I1 cosα
Q1 = √3 V_LL I1 sinα
```

である。

`I1=(√6/π)Id` を代入すると

```text
P
= √3 V_LL (√6/π Id) cosα
= (3√2/π) V_LL Id cosα
= Vdc Id
```

となり、損失を無視すれば交流側有効電力と直流側電力が一致する。

### 7.3 基本波力率と総合力率

基本波だけを見れば変位力率は

```text
cosα
```

である。しかし線電流には高調波が含まれるため、全実効電流 `I` を使う総合力率は別である。

```text
λ = P / (√3 V_LL I)
  = (I1/I) cosα
  = (3/π) cosα
```

理想120°方形波では `α=0` でも `λ=3/π≒0.955` であり、1にはならない。これは位相差ではなく電流波形ひずみによる低下分を含むためである。

問題文が「基本波力率」「基本波無効電力」「総合力率」のどれを求めているかを確認し、同じものとして扱わない。

## 8. 交流条件と直流分

変圧器を介した整流回路では、二次側電流波形が正負対称かを確認する。

半波整流のように一方向だけに電流が流れる波形は、1周期平均が0でない。二次巻線の電流に直流分が含まれると、その直流アンペアターンは鉄心磁束を一方向へ偏らせる要因になる。磁束が片側へ寄ると飽和余裕が減り、励磁電流増大や波形ひずみにつながる。

交流電源から見た定常一次電流は、1周期平均0となる交流条件を満たす必要がある。H27一次では、整流側電流だけを見るのではなく、変圧器の励磁電流と直流偏磁を含めて一次側波形を判断することが要求されている。

したがって波形問題では、次の順で確認する。

1. 各素子の導通区間を決める。
2. 二次巻線電流を描く。
3. 1周期平均を確認する。
4. 非零の直流分があるなら直流偏磁との関係を確認する。
5. 一次側が交流電源として満たすべき周期条件と整合するか確認する。

## 9. 本試験標準の解法アルゴリズム

整流回路の二次試験問題では、次の順序を固定すると途中式を落としにくい。

1. 電源電圧が実効値か波高値か、相電圧か線間電圧かを確認する。
2. 負荷が `R`、大 `L`、大 `C` のどれか、直流電流が連続かを確認する。
3. 理想素子、転流重なり無視など問題の仮定を明記する。
4. 0〜2πのどの区間でどの素子が導通するか決める。
5. 導通状態から `v_d(θ)`、素子電流、交流側電流を作る。
6. 平均値なら `∫x dθ`、実効値なら `∫x² dθ` を使う。
7. `L` または `C` があれば周期平均0の条件を使う。
8. 三相サイリスタなら60°区間を積分し、`Vdc=(3√2/π)V_LL cosα` を得る。
9. 一定 `Id` なら交流側基本波 `I1=(√6/π)Id` を使い、`P, Q1, λ` を求める。
10. 最後に極性、単位、平均値/実効値、基本波/全実効値を取り違えていないか検算する。

## 10. 3段階例題

### 10.1 基礎例題: 全波整流の平均値と実効値

理想単相ブリッジに実効値 `Vs=100 V` の正弦波電源を接続し、`R=20 Ω` の抵抗負荷を直接接続する。平滑要素はない。平均直流電圧、出力電圧実効値、負荷平均電力を求める。

交流波高値は

```text
Vm = √2 Vs
   = 141.4 V
```

全波整流平均値は

```text
Vdc = 2Vm/π
    = (2√2/π) × 100
    = 90.0 V
```

全波整流では二乗値が元の正弦波と同じなので

```text
Vrms = Vs = 100 V
```

である。したがって抵抗負荷の平均電力は

```text
P = Vrms² / R
  = 100² / 20
  = 500 W
```

となる。

`Vdc²/R=405 W` としてはいけない。出力は一定直流ではなく全波整流波形であり、発熱を決めるのは実効値だからである。

### 10.2 本試験標準例題: 三相サイリスタ変換器

理想三相全制御ブリッジに線間電圧実効値 `V_LL=200 V` の正弦波電源を接続する。直流側には十分大きいリアクトルがあり、`Id=10.0 A` 一定とする。制御角は `α=30°`、転流重なりと損失は無視する。平均直流電圧、交流側基本波電流、有効電力、基本波無効電力、総合力率を求める。

平均直流電圧は

```text
Vdc = (3√2/π) V_LL cosα
    = (3√2/π) × 200 × cos30°
    = 233.9 V
```

交流側基本波実効値は

```text
I1 = (√6/π) Id
   = (√6/π) × 10.0
   = 7.80 A
```

有効電力は

```text
P = √3 V_LL I1 cosα
  = √3 × 200 × 7.80 × cos30°
  = 2.34 kW
```

直流側から確認すると

```text
Pdc = Vdc Id
    = 233.9 × 10.0
    = 2.34 kW
```

となり一致する。

基本波無効電力は

```text
Q1 = √3 V_LL I1 sinα
   = √3 × 200 × 7.80 × sin30°
   = 1.35 kvar
```

交流側線電流の全実効値は

```text
I = √(2/3) Id
  = 8.16 A
```

よって総合力率は

```text
λ = P / (√3 V_LL I)
  = 0.827
```

または

```text
λ = (3/π) cos30°
  = 0.827
```

と求められる。`cos30°=0.866` は基本波の変位力率であり、総合力率そのものではない。

### 10.3 複合・ひっかけ例題: 無平滑・大C・大Lの負荷電力比較

理想単相ブリッジに実効値 `Vs=120 V` の正弦波電源を接続し、`R=24 Ω` の抵抗負荷へ給電する。次の3条件で負荷平均電力を比較する。

A. 平滑要素なし

B. 十分大きいコンデンサを負荷に並列接続し、リプルを無視する

C. 十分大きいリアクトルを直列接続し、直流電流を一定とみなす

Aでは全波整流波形の実効値が `120 V` なので

```text
P_A = Vs² / R
    = 120² / 24
    = 600 W
```

である。

Bではコンデンサ電圧が波高値付近に保持されるので

```text
V_B ≒ √2 Vs
    = 169.7 V

P_B ≒ V_B² / R
    = 169.7² / 24
    = 1.20 kW
```

となる。

Cではリアクトル平均電圧が0で、平均直流電圧は全波整流平均値に等しい。

```text
V_C ≒ (2√2/π) Vs
    = 108.0 V

Id ≒ V_C / R
   = 4.50 A

P_C ≒ Id² R
    = 486 W
```

したがって

```text
P_B > P_A > P_C
```

である。

ひっかけは、Aで平均電圧 `108.0 V` を使って `P=Vdc²/R` としてしまうこと、またBとCの平滑効果を同じものとして扱うことである。Aは脈動波形なので実効値、BとCはそれぞれの理想平滑条件に対応する一定値を使う。

## 11. 0系主変圧器二次側から直流主回路への接続

0系の本テーマで使う接続は、`主変圧器二次側の交流 → 整流回路 → 直流主回路` という役割関係である。ここで重要なのは車両固有の数値を暗記することではなく、変圧器二次側の交流波形が整流器の導通によって直流側電圧・電流へ変換される過程を、一般の整流回路として解析できることである。

前テーマの主変圧器等価回路で求めた二次側電圧を整流器の入力として見れば、本テーマの `Vs` または `V_LL` に相当する。整流後の平均直流電圧と電流は、次テーマの直流主電動機を解析する際の入力条件へつながる。

ただし、本文で扱った三相サイリスタ変換器は二種過去問の一般的な試験論点として扱っている。これを未確認の0系固有回路仕様として読み替えない。本テーマでは制作前に確定した範囲を超える0系実車値・回路方式を新たに実値化しない。

`SPEC.md` が指定する波形・グラフは、後工程の解説PDFで次の関係を同一条件から作図する。

- 入力交流波形
- 半波・全波・三相ブリッジの整流後電圧波形
- 大L時の直流電流と交流側線電流
- 120°方形波電流の基本波と主要高調波
- 制御角または平滑条件と平均直流電圧の関係

## 12. 頻出ミス・ひっかけ

1. `Vs` を実効値のまま波高値として積分する。
   - 正弦波瞬時値の振幅は `Vm=√2 Vs`。
2. 平均値と実効値を混同する。
   - 直流成分は平均値、抵抗発熱は実効値から求める。
3. 大Lと大Cを同じ平滑として扱う。
   - 大Lは電流を平滑し、大Cは電圧を波高値付近へ保持する。
4. 三相式へ相電圧を代入する。
   - `Vdc=(3√2/π)V_LL cosα` の `V_LL` は線間実効値。
5. 各サイリスタの導通角を180°とする。
   - 三相6パルス・連続電流では各素子120°。
6. `I1` と全実効電流 `I` を混同する。
   - `I1=(√6/π)Id`、`I=√(2/3)Id`。
7. `cosα` を総合力率と断定する。
   - 理想120°方形波では `λ=(3/π)cosα`。
8. `L` や `C` の平均量0を暗記だけで使う。
   - 周期定常条件 `i(T)=i(0)`、`v(T)=v(0)` から導く。
9. 波形に直流分があっても変圧器への影響を無視する。
   - 非対称電流では直流偏磁を確認する。
10. 二次試験答案で理想条件や極性を書かない。
   - 理想素子、重なり無視、電流連続、正方向を最初に置く。

## 13. 公式・解法まとめ

単相正弦波:

```text
Vm = √2 Vs
```

単相半波整流:

```text
Vdc = Vm/π = (√2/π)Vs
Vrms = Vm/2 = Vs/√2
```

単相全波整流:

```text
Vdc = 2Vm/π = (2√2/π)Vs
Vrms = Vs
```

周期平均条件:

```text
(1/T)∫v_L dt = 0
(1/T)∫i_C dt = 0
```

リプル:

```text
Vr,rms = sqrt(Vrms² - Vdc²)
r = Vr,rms / Vdc
```

三相6パルスブリッジ:

```text
Vd0 = (3√2/π)V_LL ≒ 1.35V_LL
Vdc = (3√2/π)V_LL cosα
```

一定直流電流時の三相交流側:

```text
I = √(2/3)Id
I1 = (√6/π)Id
I1/I = 3/π
```

電力:

```text
P = √3 V_LL I1 cosα = Vdc Id
Q1 = √3 V_LL I1 sinα
λ = (3/π)cosα
```

素子電流:

```text
単相ブリッジ・一定Id:
I_D,av = Id/2
I_D,rms = Id/√2

三相6パルス・一定Id:
I_T,av = Id/3
I_T,rms = Id/√3
```

二次試験では、公式だけを書くのではなく、導通区間、積分区間、理想条件、制御角の定義、極性、単位を答案中に残す。
