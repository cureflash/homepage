# 一次試験型

## 問1 単相全波整流の平均値と負荷電力

理想単相ダイオードブリッジに、実効値 `Vs=100 V` の正弦波電源を接続し、`R=20 Ω` の抵抗負荷を直接接続する。平滑要素はない。

平均直流電圧 `Vdc` と負荷平均電力 `P` の組合せとして正しいものを選べ。

1. `Vdc=45.0 V`, `P=250 W`
2. `Vdc=90.0 V`, `P=405 W`
3. `Vdc=90.0 V`, `P=500 W`
4. `Vdc=100 V`, `P=500 W`
5. `Vdc=141 V`, `P=1.00 kW`

### 正答

3

### 完全解説

全波整流の平均値は

```text
Vdc = (2√2/π)Vs
    = (2√2/π)×100
    = 90.0 V
```

である。

一方、全波整流は正弦波の負半周期を正側へ折り返すだけなので、二乗平均は元の正弦波と同じである。したがって

```text
Vrms = Vs = 100 V
```

抵抗負荷の平均電力は

```text
P = Vrms²/R
  = 100²/20
  = 500 W
```

となる。

選択肢2は、脈動波形に対して `P=Vdc²/R` を使った誤りである。平均値は直流成分を表すが、抵抗発熱は実効値で決まる。

## 問2 単相半波整流の平均値と実効値

実効値 `Vs=200 V` の正弦波を理想半波整流した。出力電圧の平均値 `Vdc` と実効値 `Vrms` の組合せとして正しいものを選べ。

1. `Vdc=45.0 V`, `Vrms=100 V`
2. `Vdc=90.0 V`, `Vrms=100 V`
3. `Vdc=90.0 V`, `Vrms=141 V`
4. `Vdc=127 V`, `Vrms=141 V`
5. `Vdc=180 V`, `Vrms=200 V`

### 正答

3

### 完全解説

波高値は

```text
Vm = √2 Vs
   = 282.8 V
```

半波整流の平均値は

```text
Vdc = Vm/π
    = (√2/π)Vs
    = 90.0 V
```

実効値は

```text
Vrms = Vm/2
     = Vs/√2
     = 141.4 V
```

である。

半波整流は正負対称ではないため、巻線電流について考える場合は1周期平均値、すなわち直流分の有無も確認する必要がある。

## 問3 周期定常状態のL・C

周期定常状態にある理想リアクトル `L` と理想コンデンサ `C` について、正しい記述を選べ。

1. リアクトル電流の1周期平均値は必ず0である。
2. リアクトル電圧の1周期平均値は0であり、コンデンサ電流の1周期平均値も0である。
3. リアクトル電圧の1周期平均値は電源周波数に比例する。
4. コンデンサ電圧の1周期平均値は必ず0である。
5. コンデンサ電流の1周期平均値は静電容量に比例して必ず正になる。

### 正答

2

### 完全解説

リアクトルでは

```text
vL = L di/dt
```

周期定常なら `i(T)=i(0)` なので

```text
(1/T)∫_0^T vL dt
= (L/T){i(T)-i(0)}
= 0
```

となる。

コンデンサでは

```text
iC = C dv/dt
```

周期定常なら `v(T)=v(0)` だから

```text
(1/T)∫_0^T iC dt
= (C/T){v(T)-v(0)}
= 0
```

となる。

「リアクトル電流の平均値」や「コンデンサ電圧の平均値」が必ず0になるわけではない。整流回路では、直流電流や直流電圧を含んだ周期定常状態が普通に存在する。

## 問4 三相6パルスブリッジの平均直流電圧

理想三相ダイオードブリッジに線間電圧実効値 `VLL=200 V` の正弦波電源を接続する。転流重なりと損失を無視したとき、平均直流電圧に最も近いものを選べ。

1. `90 V`
2. `156 V`
3. `200 V`
4. `270 V`
5. `346 V`

### 正答

4

### 完全解説

三相6パルスブリッジでは

```text
Vd0 = (3√2/π)VLL
    ≒ 1.35VLL
```

である。

したがって

```text
Vd0 ≒ 1.35×200
    = 270 V
```

となる。

ここへ代入する `VLL` は線間電圧の実効値であり、相電圧ではない。

## 問5 三相サイリスタ変換器の制御角

理想三相全制御ブリッジに線間電圧実効値 `VLL=400 V` を加え、直流電流は連続、転流重なりは無視できるものとする。制御角 `α=60°` のときの平均直流電圧に最も近いものを選べ。

1. `0 V`
2. `135 V`
3. `270 V`
4. `468 V`
5. `540 V`

### 正答

3

### 完全解説

平均直流電圧は

```text
Vdc = (3√2/π)VLL cosα
    ≒ 1.35×400×cos60°
    = 270 V
```

である。

`α=0°` なら約 `540 V` であり、制御角を60°へ増やしたことで `cos60°=0.5` 倍になる。

## 問6 120°方形波電流の実効値と基本波

三相6パルスブリッジで直流電流 `Id=10.0 A` が十分平滑され一定とみなせる。交流側線電流は120°通電の方形波になる。

線電流の全実効値 `I` と基本波実効値 `I1` の組合せとして正しいものを選べ。

1. `I=5.00 A`, `I1=5.00 A`
2. `I=7.80 A`, `I1=8.16 A`
3. `I=8.16 A`, `I1=7.80 A`
4. `I=10.0 A`, `I1=8.16 A`
5. `I=10.0 A`, `I1=10.0 A`

### 正答

3

### 完全解説

120°通電の線電流は1周期360°のうち240°で絶対値 `Id` を取るため

```text
I = sqrt(240/360)Id
  = √(2/3)Id
  = 8.16 A
```

である。

基本波実効値は

```text
I1 = (√6/π)Id
   = 7.80 A
```

となる。

したがって

```text
I1/I = 3/π ≒ 0.955
```

である。全実効値には基本波以外の高調波も含まれる。理想6パルス波形の特性高調波は `6k±1` 次、すなわち5次、7次、11次、13次などである。

## 問7 総合力率

問6と同じ理想三相全制御ブリッジで、制御角を `α=30°` とする。転流重なりを無視するとき、総合力率 `λ` に最も近いものを選べ。

1. `0.500`
2. `0.707`
3. `0.827`
4. `0.866`
5. `0.955`

### 正答

3

### 完全解説

基本波の変位力率は

```text
cosα = cos30° = 0.866
```

である。

しかし、交流側線電流は方形波で高調波を含むため、総合力率は基本波の変位力率と一致しない。

```text
λ = (I1/I)cosα
  = (3/π)cos30°
  = 0.827
```

したがって正答は3である。

選択肢4は `cosα` だけを総合力率とした誤り、選択肢5は `I1/I=3/π` だけを用いた誤りである。

## 問8 変圧器と直流分

変圧器二次側に接続された整流回路の電流波形について、最も適切な記述を選べ。

1. 二次電流に直流分があっても、変圧器鉄心の磁束には影響しない。
2. 半波整流のような非対称電流では1周期平均が0でない場合があり、直流アンペアターンが磁束を一方向へ偏らせる要因になる。
3. 全波整流では出力電圧が正なので、変圧器巻線電流も必ず直流分を持つ。
4. 一次電流の1周期平均値は、定常交流運転でも任意の値を取れる。
5. 直流偏磁はコンデンサの平均電流が0であることだけで判定できる。

### 正答

2

### 完全解説

半波整流のように巻線電流が正負非対称になると、その巻線電流の1周期平均が0でない場合がある。直流分によるアンペアターンは鉄心磁束を一方向へ偏らせ、飽和余裕を減らす要因になる。

波形問題では、整流器出力だけでなく

```text
素子の導通区間
→ 巻線電流波形
→ 1周期平均値
→ 直流分の有無
→ 変圧器磁束への影響
```

の順で確認する。

全波整流出力電圧が常に正であることと、変圧器交流巻線電流が直流分を持つことは同じではない。

# 二次試験型

## 問9 無平滑・大C・大Lの比較

理想単相ダイオードブリッジに実効値 `Vs=150 V` の正弦波電源を接続し、`R=30 Ω` の抵抗負荷へ給電する。次の3条件について、負荷平均電力を求めて大小関係を示せ。

A. 平滑要素なし

B. 十分大きいコンデンサを負荷と並列に接続し、出力電圧リプルを無視できる

C. 十分大きいリアクトルを直列に接続し、直流電流リプルを無視できる

理想素子とし、電源内部インピーダンス、素子電圧降下、転流重なりは無視する。

### 模範解答

#### A 無平滑

全波整流波形の実効値は元の正弦波と同じなので

```text
Vrms = Vs = 150 V
```

したがって

```text
PA = Vrms²/R
   = 150²/30
   = 750 W
```

である。

#### B 大容量コンデンサ

十分大きいコンデンサでリプルを無視できる理想条件では、出力電圧は波高値付近に保持される。

```text
VB ≒ √2 Vs
   = 212.1 V
```

よって

```text
PB ≒ VB²/R
   = 212.1²/30
   = 1.50 kW
```

となる。

周期定常状態では

```text
(1/T)∫iC dt = 0
```

であり、コンデンサ自身へ電荷が一方的に蓄積し続けるわけではない。

#### C 大リアクトル

周期定常状態では

```text
(1/T)∫vL dt = 0
```

である。したがって平均直流電圧は全波整流波形の平均値に等しい。

```text
VC ≒ (2√2/π)Vs
   = 135.0 V
```

直流電流は

```text
Id ≒ VC/R
   = 135.0/30
   = 4.50 A
```

よって

```text
PC ≒ Id²R
   = 4.50²×30
   = 608 W
```

となる。

以上より

```text
PB > PA > PC
```

である。

### 採点上の要点

- Aで平均値ではなく実効値を使う。
- Bでは波高値保持という理想条件を明記する。
- Cではリアクトル平均電圧0を示してから平均直流電圧を決める。
- `L` は電流平滑、`C` は電圧平滑であり、同じ扱いにしない。

## 問10 三相サイリスタ変換器の電力解析

理想三相全制御ブリッジに線間電圧実効値 `VLL=400 V` の正弦波電源を接続する。直流側には十分大きいリアクトルがあり、`Id=20.0 A` 一定とする。制御角 `α=30°`、転流重なりと損失は無視する。

次を求めよ。

1. 平均直流電圧 `Vdc`
2. 交流側線電流の基本波実効値 `I1`
3. 有効電力 `P`
4. 基本波無効電力 `Q1`
5. 交流側線電流の全実効値 `I`
6. 総合力率 `λ`

### 模範解答

平均直流電圧は

```text
Vdc = (3√2/π)VLL cosα
    = (3√2/π)×400×cos30°
    = 467.8 V
```

である。

基本波実効値は

```text
I1 = (√6/π)Id
   = (√6/π)×20.0
   = 15.59 A
```

有効電力は

```text
P = √3 VLL I1 cosα
  = √3×400×15.59×cos30°
  = 9.36 kW
```

損失を無視しているので

```text
Vdc Id = 467.8×20.0
         = 9.36 kW
```

とも一致する。

基本波無効電力は

```text
Q1 = √3 VLL I1 sinα
   = √3×400×15.59×sin30°
   = 5.40 kvar
```

である。

線電流全実効値は

```text
I = √(2/3)Id
  = √(2/3)×20.0
  = 16.33 A
```

したがって総合力率は

```text
λ = P/(√3 VLL I)
  = 9.356×10³/(√3×400×16.33)
  = 0.827
```

または

```text
λ = (3/π)cos30°
  = 0.827
```

と求められる。

### 採点上の要点

- `VLL` が線間実効値であることを明記する。
- `I1` と全実効値 `I` を区別する。
- `Q1` は基本波無効電力である。
- `cosα=0.866` を総合力率としない。
- 理想素子、連続直流電流、転流重なり無視を前提として明記する。

## 問11 制御角と電力方向

理想三相全制御ブリッジについて、線間電圧実効値を `VLL=600 V`、直流電流を正方向に `Id=15.0 A` 一定、制御角を `α=120°` とする。転流重なりと損失は無視する。

1. 平均直流電圧 `Vdc` を求めよ。
2. 直流側電力 `Pdc=VdcId` を求めよ。
3. 符号から電力方向を説明せよ。

### 模範解答

平均直流電圧は

```text
Vdc = (3√2/π)VLL cosα
    = (3√2/π)×600×cos120°
    = -405 V
```

となる。

直流電流の正方向を問題文どおり固定すると

```text
Pdc = Vdc Id
    = -405×15.0
    = -6.08 kW
```

である。

`Pdc<0` なので、ここで採った「交流側から直流側へ流れる電力を正」とする符号基準に対して電力方向は逆である。すなわち直流側から交流側へ電力が戻る向きとなる。

### 採点上の要点

- 制御角と `cosα` の符号を確認する。
- 電圧だけでなく、定義した電流正方向と積 `VdcId` から電力方向を判定する。
- 極性・正方向を答案中に明記する。
- ここからインバータ回路設計や車両固有制御へ範囲を広げない。

## 問12 半波電流と変圧器直流偏磁

変圧器二次巻線の基準方向に対し、理想化した電流波形が

```text
i2(θ) = Id     (0 < θ < π)
i2(θ) = 0      (π < θ < 2π)
```

で繰り返すものとする。

1. 二次巻線電流の1周期平均値を求めよ。
2. この平均値が0でないことが変圧器鉄心に与える影響を説明せよ。
3. 実際の波形問題で確認すべき手順を示せ。

### 模範解答

1周期平均値は

```text
I2,av
= (1/2π)∫_0^2π i2(θ)dθ
= (1/2π)∫_0^π Id dθ
= Id/2
```

であり、0ではない。

したがって、この巻線電流には直流分が含まれる。直流分によるアンペアターンは鉄心磁束を一方向へ偏らせる要因となり、磁束の片寄りによって飽和余裕が小さくなり、励磁電流増大や波形ひずみにつながり得る。

実際の問題では次の順で確認する。

```text
1. 各素子の導通区間を決める
2. 巻線電流波形を描く
3. 1周期平均値を積分して直流分の有無を判定する
4. 変圧器の励磁電流を含む一次側条件を確認する
5. 定常交流電源から見た一次電流が1周期平均0となる交流条件を満たすか確認する
6. 直流偏磁の有無を判定する
```

### 採点上の要点

- 「半波だから危険」と暗記だけで書かず、1周期平均値を積分して示す。
- 巻線電流の直流分と整流後の直流出力を混同しない。
- 整流器側波形だけでなく、変圧器励磁電流と一次側交流条件まで確認する。
