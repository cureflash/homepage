## 2. R7 二次「機械・制御」問1 — 6答案要素

公式問題: `20251116_ch_second_q02.pdf`

### (1) フェーザ図

- `(a) = V`
- `(b) = θ`
- `(c) = δ`
- `(d) = I`
- `(e) = jX_s I`
- `(f) = E`

電動機なので `E = V - jX_s I`、すなわち `V = E + jX_s I`。

### (2) Eの式

遅れ力率で `I=I(cosθ-j sinθ)` より、

`E = (V-X_s I sinθ) - jX_s I cosθ`

したがって

`E = sqrt(V^2 - 2 V X_s I sinθ + (X_s I)^2)`。

### (3) 定格運転時E

定格p.u.で `V=1`, `I=1`, `cosθ=0.8`, `sinθ=0.6`, `X_s=2.0`。

`E = sqrt(1 - 2×1×2×0.6 + 2^2) = sqrt(2.6) = 1.61 p.u.`

### (4) X_s Iの式

フェーザ三角形から

`(X_s I)^2 = E^2 + V^2 - 2EV cosδ`

よって

`X_s I = sqrt(E^2 + V^2 - 2EV cosδ)`。

### (5a) 同期調相機のI

損失無視・有効電力ほぼ0なので `δ=0`。端子電圧 `V=1 p.u.` より

`I = |E-V|/X_s = |E-1|/X_s`。

### (5b) I最小時のE

`I=|E-1|/X_s` が最小となるのは

`E = 1.00 p.u.`。

## 3. R5 二次「機械・制御」問1 — 6答案要素

公式問題: `20231112_ch_second_q02.pdf`

### (1) フェーザ図

- `(a) = E`
- `(b) = jX_s I`
- `(c) = δ`
- `(d) = θ`
- `(e) = I`

### (2) Eの式と定格値

発電機・遅れ力率なので

`E = sqrt(V^2 + 2 V X_s I sinθ + (X_s I)^2)`。

定格で `V=1`, `I=1`, `cosθ=0.8`, `sinθ=0.6`, `X_s=1.8` より

`E_n = sqrt(1 + 2×1×1.8×0.6 + 1.8^2) = sqrt(6.4) = 2.53 p.u.`

### (3) 有効電力式

`P = (VE/X_s) sinδ [p.u.]`。

### (4a) 定格負荷角

定格有効電力は `P_n=VI cosθ=0.8 p.u.`。

`sinδ_n = P_n X_s/(V E_n) = 0.8×1.8/2.52982 = 0.569`。

### (4b) 定態安定極限電力

`P_m = VE/X_s [p.u.]`。

定格時

`P_mn = 2.52982/1.8 = 1.405 p.u.`

15 MVA基準なので

`P_mn = 1.405×15 = 21.1 MW`。

### (5) 界磁80 %時

磁気飽和無視なので `E' = 0.8 E_n = 2.02386 p.u.`。

- `(5a)` `P'_m = VE'/X_s = 1.124 p.u. = 16.9 MW`。定格時より減少。
- `(5b)` 有効電力は定格運転の `0.8 p.u.` を維持すると、`sinδ' = 0.8/1.124 = 0.712`。負荷角が増え、定態安定度は低下。

## 4. H29 二次「機械・制御」問1 (1),(2),(5) — 6答案要素

公式問題: `20171119_ch_second_q02.pdf`

### (1) 電圧変動率

遅れ力率の発電機で

`E = sqrt(V^2 + 2 V X_s I sinφ + (X_s I)^2)`。

したがって

`ε = {sqrt(V^2 + 2 V X_s I sinφ + (X_s I)^2) - V}/V ×100 [%]`。

ここで `φ` は力率角であり、負荷角 `δ` ではない。

### (2) cosφを小さくしたとき

`0°≤φ≤90°` で `cosφ` を小さくすると `φ` が増加し `sinφ` が増える。`V,I,X_s` 一定なら上式の `E` が増加するので、`ε=(E-V)/V×100` も増加する。

### (5) K_SCR=0.6, V=1 p.u., δ=30°, cosφ=0.9遅れ

線形・飽和無視の定格p.u.モデルで

`X_s = 1/K_SCR = 1/0.6 = 1.6667 p.u.`。

フェーザ成分

`E cosδ = V + X_s I sinφ`

`E sinδ = X_s I cosφ`

を連立する。

- `E = 1.60 p.u.`
- `I = 0.534 p.u.`
- `P = VI cosφ = 0.481 p.u.`
- `ε = (E-V)/V×100 = 60.3 %`

## 5. H27 二次「機械・制御」問1 — 4答案要素

公式問題: `20151122_ch_second_q02.pdf`

初期状態では

`P_0 = 3EV_0/X_s sin45°`。

### (1a)

同じ `E,V_0,X_s` で `δ_1=30°` なので

`P_1/P_0 = sin30°/sin45° = 0.707`。

### (1b)

直列リアクトル `X_2=X_s` により伝送リアクタンスは `2X_s`。`δ_2=45°` なので

`P_2/P_0 = (X_s/2X_s)×sin45°/sin45° = 0.500`。

### (2a)

Y結線抵抗負荷では `I` と `V_3` は同相。`E=V_3+jX_s I`、`δ_3=60°` より

`E = V_3/cos60° = 2V_3`。

また `P_3=P_0` と `R/X_s=1/tan60°` を用いると

`V_3/V_0 = sqrt(2/3) = 0.816`。

### (2b)

`tanδ_3 = X_s/R = tan60°` より

`R/X_s = 1/tan60° = 1/sqrt(3) = 0.577`。
