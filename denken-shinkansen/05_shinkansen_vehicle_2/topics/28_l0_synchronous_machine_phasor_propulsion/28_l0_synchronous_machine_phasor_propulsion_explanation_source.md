## 0. この教材で到達すること

第二種一次・二次で、同期機のフェーザから有効・無効電力、負荷角、電力角特性を求め、最後に機械出力をリニア推進力へ接続できることを到達点とする。

- 複素平面上で `V`、`E`、`I`、`jX_sI` を扱える。
- 電機子抵抗を無視する基本モデルで、発電機 `E=V+jX_sI`、電動機 `E=V-jX_sI` を使い分けられる。
- `δ` を端子電圧と内部誘導起電力の位相差として定義し、発電機・電動機の符号規約を明示できる。
- 円筒形・損失無視モデルから `P=3VE/X_s sinδ` を導き、p.u.式 `P=VE/X_s sinδ` を使える。
- `P-δ` 曲線の意味、理想基本式での `|δ|=90°` 付近の静的安定限界を説明できる。
- 界磁変化が主に無効電力・力率へ現れ、機械入力・負荷角変化が有効電力へ現れることを区別できる。
- 同期調相機の過励磁・不足励磁をフェーザから判断できる。
- 同期発電機の並行運転で、電圧・周波数・位相・相順、同期化電流、無効横流を説明できる。
- 電気有効電力と推進力を無条件に等置せず、`P_mech=Fv` と効率条件から接続できる。

## 2. 記号・単位と基準

| 記号 | 意味 | 単位 |
|---|---|---|
| `V` | 端子相電圧の実効値 | V/相 または p.u. |
| `E` | 内部誘導起電力の実効値 | V/相 または p.u. |
| `I` | 電機子電流の実効値 | A/相 または p.u. |
| `X_s` | 同期リアクタンス | Ω/相 または p.u. |
| `δ` | `V` と `E` の位相差 | rad または ° |
| `θ` | 力率角 | rad または ° |
| `P` | 三相有効電力 | W または p.u. |
| `Q` | 三相無効電力 | var または p.u. |

本sourceでは特記しない限り、同期機の電機子抵抗を無視し、円筒形同期機、定常状態、正弦波、平衡三相を基本モデルとする。

## 3. フェーザの読み方

交流定常状態では、同一周波数の正弦波を複素数で表す。基準を `V=V∠0°` とすると、遅れ力率の電流は `I=I∠(-θ)`、進み力率の電流は `I=I∠(+θ)` と書ける。

`j` を掛けるとフェーザは反時計回りへ90°回転する。したがって `jX_sI` は、`I` を90°進ませた向きのリアクタンス降下である。

試験では図を暗記するより、

1. `V` を0°基準に置く。
2. 力率から `I` の向きを決める。
3. `I` を90°回して `jX_sI` を描く。
4. 発電機か電動機かで加減算する。

の順で描く方が符号ミスを減らせる。

## 4. 発電機と電動機の電圧方程式

### 4.1 発電機

発電機で電流を機外へ流れ出す向きを正とすると、電機子抵抗無視で

`E=V+jX_sI`

である。つまり内部誘導起電力 `E` から同期リアクタンス降下 `jX_sI` を差し引いたものが端子電圧 `V` になる。

遅れ力率 `I=I(cosθ-j sinθ)` なら

`jX_sI=X_sI sinθ+jX_sI cosθ`

なので

`E=(V+X_sI sinθ)+jX_sI cosθ`

`|E|=sqrt(V^2+2VX_sI sinθ+(X_sI)^2)`

となる。

### 4.2 電動機

電動機で端子から機内へ電流が流れ込む向きを正とすると

`E=V-jX_sI`

である。

遅れ力率なら

`E=(V-X_sI sinθ)-jX_sI cosθ`

`|E|=sqrt(V^2-2VX_sI sinθ+(X_sI)^2)`

となる。

固定R7二次型では、この符号を発電機式のまま使わないことが最重要である。

---

## 5. 負荷角 `δ`

`δ` は端子電圧 `V` と内部誘導起電力 `E` の位相差である。

- 発電機運転: 通常、`E` が `V` より進む向きを正とする。
- 電動機運転: 通常、`E` が `V` より遅れる。発電機と同じ正方向を使えば `δ<0` となる。

教材・問題によって「電動機の負荷角」を正の大きさとして定義する場合もあるため、数値代入前に必ず図と符号規約を確認する。

発電機で `V` を実軸基準とし、`E=E∠δ` とすれば

`tanδ = Im(E)/Re(E)`

で求められる。

---

## 6. 電力角特性の導出

発電機式

`E=V+jX_sI`

から

`I=(E-V)/(jX_s)`

とする。`V=V∠0`、`E=E(cosδ+j sinδ)` とおくと

`I=(E sinδ)/X_s - j(E cosδ-V)/X_s`

である。

端子から系統へ供給する三相複素電力を

`S=3VI* = P+jQ`

とすると

`P=3VE/X_s sinδ`

`Q=3[(VE/X_s)cosδ - V^2/X_s]`

を得る。

三相p.u.では

`P=VE/X_s sinδ`

`Q=(VE/X_s)cosδ - V^2/X_s`

である。

この `Q` の正負は「発電機から系統へ無効電力を供給する向きを正」とした場合である。別の電流方向・電力流入規約では符号が反転するため、公式だけを切り離して暗記しない。

---

## 7. `P-δ` 曲線と静的安定限界

`V,E,X_s` を一定とすれば

`P=P_max sinδ`

`P_max=3VE/X_s`

相値式である。p.u.では `P_max=VE/X_s`。

理想基本式では `0<δ<90°` で `δ` 増加とともに送出有効電力が増え、`δ=90°` で最大になる。`90°` を超えると `sinδ` が減るため、定常同期運転の静的安定余裕を失う方向になる。

ただし実機の運転限界は、過渡安定度、制御、電流、電圧、温度、保護等でも制限される。本Topicの `90°` は円筒形・損失無視の基本モデルの静的限界であり、L0系実機の許容負荷角ではない。

パラメータ比較では

- `E` を増すと `P_max` は比例して増える。
- `V` を増すと `P_max` は比例して増える。
- `X_s` を増すと `P_max` は反比例して減る。

複数条件を比較するときは

`P_2/P_1=(V_2E_2/X_2)/(V_1E_1/X_1) × sinδ_2/sinδ_1`

と比で処理すると計算を短くできる。

## 8. 有効電力と無効電力を分ける

同期機の並行運転・同期調相機では、有効電力と無効電力の役割分離が頻出である。

### 8.1 有効電力

有効電力は主に機械入力／機械負荷と負荷角に対応する。発電機なら機械入力を増やすと、同期を保つ範囲で `δ` が増えて有効電力送出が増える。

### 8.2 無効電力

界磁を変えて `E` を変えると、同一有効電力でも電機子電流の無効成分、力率、無効電力が変化する。

発電機の送出規約では、同じ `V,δ` なら `E` を大きくするほど

`Q=(VE/X_s)cosδ-V^2/X_s`

が増加する方向である。

### 8.3 同期調相機

軸から有効電力をほぼ取り出さず、界磁を調整して無効電力を授受する同期機を同期調相機として扱う。

理想化して `δ≈0` なら

`I=(E-V)/(jX_s)`

であり、`E=V` のときリアクタンス差による電流は最小になる。`E>V` と `E<V` で電流の無効成分の向きが反転する。

固定R7二次では「界磁を変えると何が変わるか」を有効電力と混同しないことが重要である。

## 9. 同期発電機の並行運転

並列投入前の基本同期条件は次の4つである。

1. 相順が同じ。
2. 電圧の大きさがほぼ等しい。
3. 周波数がほぼ等しい。
4. 対応相の位相角が投入瞬間にほぼ一致する。

位相差や周波数差を残して投入すると同期化電流が流れる。小さな位相ずれに対しては、同期リアクタンスを介した有効電力の変化が位相差を戻す方向に働き、同期化作用となる。

並列運転中に一方の界磁だけを変えると、主に無効電力分担が変わる。機械入力を大きく変えずに界磁を増減すると、発電機間に無効横流が生じる。したがって「界磁を増やしたから有効電力が同じ割合で増える」とはしない。

固定R4一次では、位相、界磁、無効横流、端子電圧・内部起電力、同期化電流を一つのフェーザ関係として判断する。

## 10. 電圧変動率と力率

同期発電機の代表的な電圧変動率は、回転速度と界磁を一定に保ち、負荷時端子電圧を `V_n`、無負荷端子電圧を `E_0` として

`ε=(E_0-V_n)/V_n ×100 [%]`

と表す。

同期リアクタンスモデルでは、遅れ力率負荷で `jX_sI` が端子電圧に対して内部起電力を大きくする方向へ加わるため、一般に力率低下に伴い必要内部起電力と電圧変動率が増える方向となる。

数値問題では

1. 力率角 `θ=acos(cosθ)` を求める。
2. `I` の位相を決める。
3. `E=V+jX_sI` で内部誘導起電力を求める。
4. 必要なら `δ`、`P`、`ε` を順に求める。

固定H29二次型では、電圧変動率・力率・同期リアクタンス・負荷角を別々の公式として扱わず、この順でつなぐ。

## 11. 直列リアクタンス・条件変更問題の解き方

外部リアクタンス `X_e` が直列に加わる場合、損失を無視できる範囲では電力角式の伝送リアクタンスを

`X_eq=X_s+X_e`

とまとめ、

`P=3VE/X_eq sinδ`

として比較できる。

ただし、端子電圧そのものが未知で負荷電流と連成する問題では、単純に `X` だけ置換して終わらせず、元のフェーザ方程式へ戻る。

抵抗負荷 `R` なら `I` は負荷端子電圧と同相であり、リアクタンス負荷とは位相関係が異なる。固定H27二次型のような条件変更問題では、各状態について `E,V,I,jX_sI` の幾何を作り直し、必要なら比で未知量を消去する。

## 12. リニア同期機の推進力へ接続する

回転機の機械出力は `P=Tω` だが、直線運動では

`P_mech=Fv`

である。したがって

`F=P_mech/v`

となる。

電気有効電力 `P_e` から推進力へ変換する場合、損失無視を明示した教材モデルなら

`F=P_e/v`

効率 `η` が与えられるなら

`P_mech=ηP_e`

`F=ηP_e/v`

である。

速度は必ず `m/s` に直す。`km/h` のまま `P/v` を計算すると単位がNにならない。

また `v→0` で `P/v` が発散する式を起動推力へそのまま使ってはならない。`P` 一定という仮定が成立する速度域に限る。

Topic 21 H26二次「機械・制御」問1(4)の `48.1 N·m / 48.0 N·m` 差は、公式標準解答が `π=3.14` 相当の数値処理を用いた過去問固有丸め差として維持する。一般式 `P=Tω`、`ω=2πN/60` は変更しない。

## 13. 問題を見たときの解法アルゴリズム

### フェーザ数値問題

1. 発電機か電動機かを判定する。
2. 相値か線間値か、実値かp.u.かを確認する。
3. `V` を0°基準に置く。
4. 力率から `I` の位相を決める。
5. `jX_sI` を90°回転させる。
6. 発電機 `E=V+jX_sI` / 電動機 `E=V-jX_sI` を選ぶ。
7. 実部・虚部から `|E|` と `δ` を求める。
8. `P,Q` または電圧変動率を求める。
9. 符号と物理的意味を確認する。

### 電力角問題

1. `V,E,X_s,δ` の既知量を確認する。
2. 相値式かp.u.式かを決める。
3. `P=P_max sinδ` を使う。
4. 条件変更問題は比を取る。
5. `|sinδ|≤1` を検算する。
6. `δ≈90°` を超える解を基本モデルの安定運転解として採用しない。

### 推進力問題

1. 電気入力・電気有効電力・機械出力のどれが与えられたか確認する。
2. 効率が必要なら `P_mech=ηP_e`。
3. 速度を `m/s` に換算する。
4. `F=P_mech/v`。
5. N、kN、MWの桁を検算する。

## 14. 3段階例題

### 14.1 基礎例題 — 発電機フェーザ

教材用仮定値として `V=1.00 p.u.`、`X_s=0.80 p.u.`、`I=0.60 p.u.`、力率 `0.80` 遅れとする。`E` と `δ` を求める。

`cosθ=0.80` なので `sinθ=0.60`。

`X_sI=0.80×0.60=0.48`

発電機だから

`E=(V+X_sI sinθ)+jX_sI cosθ`

`E=(1+0.48×0.60)+j(0.48×0.80)`

`E=1.288+j0.384`

`|E|=sqrt(1.288^2+0.384^2)=1.344 p.u.`

`δ=atan(0.384/1.288)=16.6°`

検算:

`P=(VE/X_s)sinδ=1×1.344/0.80×sin16.6°=0.480 p.u.`

これは `VI cosθ=1×0.60×0.80=0.480 p.u.` と一致する。

### 14.2 本試験標準例題 — 電力角特性と無効電力

教材用仮定値として `V=1.00 p.u.`、`E=1.20 p.u.`、`X_s=0.70 p.u.`、`δ=25°` の発電機を考える。送出有効電力と無効電力を求める。

`P=(VE/X_s)sinδ`

`P=(1.00×1.20/0.70)sin25°=0.724 p.u.`

`Q=(VE/X_s)cosδ-V^2/X_s`

`Q=(1.20/0.70)cos25°-1/0.70=0.125 p.u.`

有効電力と無効電力を別式で求め、`P` の増加をそのまま `Q` の増加とみなさない。

### 14.3 複合例題 — 負荷角から推進力まで

教材用仮定値として、同期機側 `V=1.00 p.u.`、`E=1.15 p.u.`、`X_s=0.60 p.u.`、電気有効電力 `P_e=0.80 p.u.`、三相ベース容量 `30 MW`、電気―機械変換効率 `η=0.88`、速度 `500 km/h` とする。負荷角と推進力を求める。

電力角式から

`sinδ=P_e X_s/(VE)`

`sinδ=0.80×0.60/(1.00×1.15)=0.41739`

`δ=24.67°`

実電力は

`P_e=0.80×30 MW=24.0 MW`

機械出力は

`P_mech=0.88×24.0=21.12 MW`

速度換算:

`500/3.6=138.89 m/s`

したがって

`F=21.12×10^6/138.89=1.52064×10^5 N`

`F≈152 kN`

この値は教材用仮定値から得た計算値であり、L0系実車推力ではない。

## 16. 頻出ミス

1. 線間電圧を相電圧式へそのまま入れる。
2. 発電機式と電動機式の符号を同じにする。
3. `jX_sI` を `I` と同方向に描く。
4. 遅れ・進み力率の電流角を逆にする。
5. `P` と `Q` を同じ機械入力・界磁操作で同様に変化すると考える。

8. `km/h` を `m/s` に直さず `F=P/v` を使う。
9. 効率が未指定なのに電気入力を機械出力へ無条件に等置する。
10. 教材用仮定値をL0系実車値として記述する。
