## R4 一次「機械」問1 — 5答案要素

候補 R4-1 `(1)`: `位相`（選択肢 ヲ）

候補 R4-2 `(2)`: `増加`（選択肢 ロ）

候補 R4-3 `(3)`: `無効`（選択肢 ホ）

候補 R4-4 `(4)`: `高い`（選択肢 ト）

候補 R4-5 `(5)`: `同期化`（選択肢 カ）

根拠: 並行運転中に界磁を増すと主に無効横流が生じ、端子電圧は調整前より高い側へ移る。速度差による位相差で有効電力を授受して同期へ戻す循環電流は同期化電流である。

## R7 二次「機械・制御」問1 — 6答案要素

候補 R7-1 `(1)` フェーザ図:
- `(a)=V`
- `(b)=θ`
- `(c)=δ`
- `(d)=I`
- `(e)=jX_s I`
- `(f)=E`

候補 R7-2 `(2)`:

`E = sqrt(V^2 - 2 V X_s I sinθ + (X_s I)^2)`

電動機の基本式 `E=V-jX_sI` を用いた。

候補 R7-3 `(3)`:

定格時 `V=1 p.u.`、`I=1 p.u.`、`cosθ=0.8`、`sinθ=0.6`、`X_s=2.0 p.u.` より

`E=sqrt(1-2×1×2×0.6+2^2)=sqrt(2.6)=1.61 p.u.`

候補 R7-4 `(4)`:

`X_s I = sqrt(E^2 + V^2 - 2EV cosδ)`

候補 R7-5 `(5)a`:

同期調相機では理想化して `δ=0` なので

`I = |E-V|/X_s`

端子電圧は定格値一定、p.u.では `V=1` より

`I = |E-1|/X_s`

候補 R7-6 `(5)b`:

`I` 最小は `E=V=1.00 p.u.`。

## R5 二次「機械・制御」問1 — 6答案要素

候補 R5-1 `(1)` フェーザ図:
- `(a)=E`
- `(b)=jX_s I`
- `(c)=δ`
- `(d)=θ`
- `(e)=I`

候補 R5-2 `(2)`:

発電機より

`E = sqrt(V^2 + 2 V X_s I sinθ + (X_s I)^2)`

定格時 `V=I=1 p.u.`、`cosθ=0.8`、`sinθ=0.6`、`X_s=1.8 p.u.` なので

`E_n=sqrt(1+2×1×1.8×0.6+1.8^2)=sqrt(6.4)=2.53 p.u.`

候補 R5-3 `(3)`:

三相p.u.で

`P = (VE/X_s) sinδ`

候補 R5-4 `(4)a`:

定格有効電力 `P_n=VI cosθ=0.8 p.u.` より

`sinδ_n = P_n X_s/(VE_n)=0.8×1.8/2.529822=0.569`

候補 R5-5 `(4)b`:

`P_m = VE/X_s`

定格時

`P_m=2.529822/1.8=1.405 p.u.`

基準容量15 MVAより

`P_mn=1.4054567×15=21.1 MW`

候補 R5-6 `(5)a,b`:

磁気飽和無視なので界磁80%では

`E'=0.8E_n=2.02386 p.u.`

`P'_m=VE'/X_s=1.12437 p.u.=16.9 MW`

したがって定態安定極限電力は `減少`。

有効電力を定格 `0.8 p.u.` に保つと

`sinδ' = 0.8×1.8/2.02386=0.712`

`δ` が増え、`P_m` が下がるため定態安定度は `低下`。

## H29 二次「機械・制御」問1 `(1),(2),(5)` — 6答案要素

候補 H29-1 `(1)`:

三角形 `E,V,X_sI` と負荷角 `δ` から

`E = V cosδ + sqrt((X_s I)^2 - V^2 sin^2δ)`

したがって

`ε = {cosδ - 1 + sqrt((X_s I/V)^2 - sin^2δ)}×100 [%]`

候補 H29-2 `(2)`:

遅れ力率で `V,I` 一定なら

`E^2 = V^2 + (X_sI)^2 + 2VX_sI sinφ`

である。`cosφ` を小さくすると `φ` と `sinφ` が増えるので `E` が増え、`ε=(E-V)/V×100` も増える。

候補 H29-3 `(5)` 内部誘導起電力:

`K_SCR=0.6` より `X_s=1/K_SCR=1.667 p.u.`。
`φ=acos(0.9)=25.84°`、`δ=30°`。

`tanδ = (X_s I cosφ)/(V+X_s I sinφ)`

から `X_sI=0.890507 p.u.`。

`E=sqrt(V^2+2V X_sI sinφ+(X_sI)^2)=1.60 p.u.`

候補 H29-4 `(5)` 電機子電流:

`I=0.890507/1.666667=0.534 p.u.`

候補 H29-5 `(5)` 出力:

`P=VI cosφ=1×0.534304×0.9=0.481 p.u.`

候補 H29-6 `(5)` 電圧変動率:

`ε=(1.602913-1)/1×100=60.3 %`

## H27 二次「機械・制御」問1 — 4答案要素

初期状態は

`P_0 = 3V_0E/X_s × sin45°`

で、界磁電流・回転速度一定より `E` は一定とする。

候補 H27-1 `(1)a`:

`P_1/P_0 = sin30°/sin45° = 1/sqrt(2) = 0.707`

候補 H27-2 `(1)b`:

外部リアクトル `X_2=X_s` により合成リアクタンスは `2X_s`、負荷角は45°なので

`P_2/P_0 = X_s/(2X_s) = 0.500`

候補 H27-3 `(2)a`:

抵抗負荷では `I` と `V_3` は同相、`tanδ_3=X_s/R`。`δ_3=60°` より `E=V_3/cos60°=2V_3`。

`P_3=P_0` と

`P_3=3V_3^2/R`

を用いると

`V_3/V_0 = sqrt(2/3) = 0.816`

候補 H27-4 `(2)b`:

`R/X_s = cot60° = 1/sqrt(3) = 0.577`
