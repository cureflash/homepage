# 一次試験型

## 問1 三相全制御ブリッジの平均直流電圧

三相全制御ブリッジに線間電圧実効値 `VLL=400 V` の平衡三相電源を接続し、点弧角を `α=60°` とする。理想素子、転流重なり無視、直流電流一定とする。平均直流電圧として最も近いものを選べ。

1. `135 V`
2. `234 V`
3. `270 V`
4. `468 V`
5. `540 V`

### 正答

3

### 完全解説

成立条件は、理想三相全制御ブリッジ、転流重なり無視、直流電流一定である。使用式は

```text
Vd=(3√2/π)VLL cosα
  ≒1.35047 VLL cosα
```

したがって

```text
Vd=1.35047×400×cos60°
  =1.35047×400×0.5
  =270.1 V
```

よって正答は3。`α=0°` の最大値は約 `540 V` であり、`α=60°` では `cos60°=0.5` なので半分になる。

## 問2 サイリスタと制御角

三相サイリスタ整流器について正しい記述を選べ。Topic 08では平均直流電圧が非負の整流範囲だけを扱う。

1. サイリスタは順方向電圧が加わればゲート信号なしで任意時刻に必ず導通する。
2. 平均直流電圧が非負となる範囲は `π/2<α<π` だけである。
3. ダイオード整流器は平均値式の上で `α=90°` に相当する。
4. サイリスタはゲート信号で導通開始を遅らせられ、`0≤α≤π/2` では平均直流電圧は非負、`α=0` は平均値式の上でダイオード整流に対応する。
5. 点弧角を大きくすると `cosα` が増加するため平均直流電圧は増加する。

### 正答

4

### 完全解説

サイリスタはゲート信号によりターンオン時刻を制御できる。三相全制御ブリッジの理想平均値は

```text
Vd=(3√2/π)VLL cosα
```

であり、Topic 08で扱う非負の整流範囲は `0≤α≤π/2`。`α=0` は平均値式の上でダイオード整流器に対応する。したがって正答は4。

## 問3 120°通電線電流

三相全制御ブリッジで直流電流が十分平滑で `Id=120 A` 一定とする。交流側線電流の全実効値 `I`、基本波実効値 `I1`、比 `I1/I` の組合せとして最も近いものを選べ。

1. `I=69.3 A`, `I1=66.2 A`, `I1/I=0.955`
2. `I=84.9 A`, `I1=93.6 A`, `I1/I=1.10`
3. `I=98.0 A`, `I1=93.6 A`, `I1/I=0.955`
4. `I=120 A`, `I1=98.0 A`, `I1/I=0.817`
5. `I=147 A`, `I1=120 A`, `I1/I=0.817`

### 正答

3

### 完全解説

120°通電線電流の全実効値は

```text
I=√(2/3) Id
 =√(2/3)×120
 =97.98 A
```

基本波実効値は

```text
I1=√6/π Id
  =√6/π×120
  =93.56 A
```

したがって

```text
I1/I=3/π
    =0.9549
```

よって正答は3。全実効値と基本波実効値を同一視しない。

## 問4 有効電力・無効電力・総合力率

三相全制御ブリッジで `VLL=400 V`、`Id=100 A`、`α=60°` とする。理想素子、転流重なり無視、直流電流一定とする。有効電力 `P`、基本波無効電力 `Q1`、総合力率 `λ` の組合せとして最も近いものを選べ。

1. `P=27.0 kW`, `Q1=46.8 kvar`, `λ=0.477`
2. `P=46.8 kW`, `Q1=27.0 kvar`, `λ=0.866`
3. `P=54.0 kW`, `Q1=0 kvar`, `λ=1.000`
4. `P=27.0 kW`, `Q1=27.0 kvar`, `λ=0.707`
5. `P=46.8 kW`, `Q1=46.8 kvar`, `λ=0.500`

### 正答

1

### 完全解説

まず平均直流電圧は

```text
Vd=(3√2/π)×400×cos60°
  =270.1 V
```

したがって直流側有効電力は

```text
P=VdId
 =270.1×100
 =27.01 kW
```

基本波実効電流は

```text
I1=√6/π×100
  =77.97 A
```

基本波無効電力は

```text
Q1=√3 VLL I1 sinα
  =√3×400×77.97×sin60°
  =46.78 kvar
```

総合力率は120°通電のひずみを含めて

```text
λ=(3/π)cosα
 =(3/π)×0.5
 =0.4775
```

よって正答は1。`cos60°=0.5` は基本波力率であり、総合力率ではない。

## 問5 高調波と総合力率

整流回路の交流側電流と高調波について正しい記述を選べ。

1. 単相ダイオードブリッジのキャパシタ入力では交流側電流は完全な正弦波となり、総合力率は常に1である。
2. 三相120°通電線電流では3次高調波だけが現れ、5次・7次は現れない。
3. キャパシタ入力ではコンデンサ電圧が高いほど常時ダイオードが導通し、交流側電流は平坦になる。
4. 交流側直列リアクトルは電流変化を急峻にするため、高調波を増やして総合力率を低下させる。
5. 単相キャパシタ入力では交流側電流がパルス状となり、R8一次の条件では基本波に次いで3次高調波が重要となる。交流側直列リアクトルは電流変化を緩やかにして高調波・総合力率を改善する方向に働く。一方、理想三相120°通電では代表的に `6k±1` 次が現れる。

### 正答

5

### 完全解説

キャパシタ入力では、電源瞬時値がコンデンサ電圧を上回る付近だけ充電電流が流れやすく、交流側電流は尖ったパルス状になる。そのため高調波を含み、基本波位相だけでは総合力率を評価できない。R8一次の対象条件では3次高調波が重要であり、交流側直列リアクトルは電流変化を緩やかにして改善方向に働く。

一方、理想三相120°通電線電流では代表高調波は `6k±1`、すなわち5次、7次、11次、13次…である。両者を混同しない。よって正答は5。

## 問6 単相交流電力調整の実効値と電力

逆並列サイリスタで抵抗 `R=20 Ω` を制御する。電源実効値 `V=200 V`、点弧角 `α=60°` とする。負荷実効電流 `IL` と負荷電力 `P` の組合せとして最も近いものを選べ。

1. `IL=5.00 A`, `P=0.500 kW`
2. `IL=8.97 A`, `P=1.61 kW`
3. `IL=10.0 A`, `P=2.00 kW`
4. `IL=12.7 A`, `P=3.23 kW`
5. `IL=17.9 A`, `P=6.42 kW`

### 正答

2

### 完全解説

抵抗負荷の負荷実効電圧は

```text
Vo=V√[(π-α+0.5sin2α)/π]
```

`α=60°=π/3` なので

```text
(π-α+0.5sin2α)/π
=(π-π/3+0.5sin(2π/3))/π
=0.80450
```

したがって

```text
Vo=200√0.80450
  =179.4 V

IL=Vo/R
  =179.4/20
  =8.97 A

P=Vo^2/R
 =1.609 kW
```

よって正答は2。平均値ではなく二乗平均平方根から実効値を求める点に注意する。

## 問7 1素子平均電流と最大素子電圧

逆並列サイリスタで抵抗 `R=20 Ω` を制御する。電源実効値 `V=200 V`、点弧角 `α=90°` とする。1個のサイリスタ平均電流 `IT,av` と最大素子電圧 `VT,max` の組合せとして最も近いものを選べ。

1. `IT,av=1.13 A`, `VT,max=200 V`
2. `IT,av=2.25 A`, `VT,max=200 V`
3. `IT,av=2.25 A`, `VT,max=283 V`
4. `IT,av=5.00 A`, `VT,max=283 V`
5. `IT,av=7.07 A`, `VT,max=400 V`

### 正答

3

### 完全解説

1個のサイリスタ平均電流は

```text
IT,av=V/(√2πR)(1+cosα)
```

`α=90°` では `cosα=0` なので

```text
IT,av=200/(√2π×20)
     =2.251 A
```

最大素子電圧は電源波高値で

```text
VT,max=√2V
      =282.8 V
```

よって正答は3。負荷実効電流と1素子平均電流を取り違えない。

## 問8 誘導性負荷の導通

逆並列サイリスタの単相交流電力調整回路で純インダクタンス負荷を扱うとき、Topic 08の対象条件に関する正しい記述を選べ。

1. 電流は必ず電圧零点 `θ=π` で瞬時にゼロになるため、抵抗負荷と同じ導通区間を使える。
2. インダクタンスに蓄えられたエネルギーにより電流は電圧零点を越えて継続し得る。対象過去問条件では制御可能範囲は `π/2<α<π` で、基本波電流は電圧に対して90°遅れるため無効電力の扱いが重要になる。
3. 純L負荷では有効電力だけが流れ、無効電力は常に0である。
4. 制御可能範囲は `0<α<π/2` のみである。
5. 誘導性負荷では点弧角は電流波形へ影響しない。

### 正答

2

### 完全解説

誘導性負荷では、インダクタンスに蓄えられたエネルギーのため電流が電圧零点を越えて継続する。したがって抵抗負荷の `θ=π` をそのまま消弧時刻にしてはいけない。H25二次の対象条件では純L負荷の制御可能範囲は

```text
π/2<α<π
```

である。また純Lの基本波電流は電圧に対して90°遅れるため、理想的には平均有効電力ではなく無効電力の授受が中心になる。よって正答は2。

# 二次試験型

## 問1 60°区間積分から平均直流電圧を導出する

三相全制御ブリッジに線間電圧実効値 `VLL=600 V` の平衡三相電源を接続し、点弧角 `α=30°` とする。理想素子、転流重なり無視、直流電流一定とする。

1. 60°の1導通区間を用いて平均直流電圧式 `Vd=(3√2/π)VLL cosα` を導出せよ。
2. 数値を代入して `Vd` を求めよ。

### 完全解説

線間電圧の1区間を

```text
vLL=√2 VLL cosθ
```

と表し、点弧角だけ移動した60°区間

```text
-π/6+α ≤ θ ≤ π/6+α
```

を積分する。1周期に同形の区間が6個あるので、平均値は

```text
Vd=6/(2π) ∫[-π/6+α, π/6+α] √2 VLL cosθ dθ
```

したがって

```text
Vd=(3√2 VLL/π)
   {sin(π/6+α)-sin(-π/6+α)}
```

括弧内は

```text
2cosα sin(π/6)=cosα
```

だから

```text
Vd=(3√2/π)VLL cosα
```

となる。

数値代入すると

```text
Vd=(3√2/π)×600×cos30°
  =701.7 V
```

答え: 約 `702 V`。

検算として `α=0` の最大値は約 `810 V` であり、30°遅らせた値がそれより小さいので妥当である。

## 問2 三相変換器の電流・P・Q・総合力率

三相全制御ブリッジで `VLL=400 V`、`Id=150 A`、`α=45°` とする。理想素子、転流重なり無視、直流電流一定とする。

1. 交流側線電流の全実効値 `I` と基本波実効値 `I1` を求めよ。
2. 平均直流電圧 `Vd` と直流電力 `Pd` を求めよ。
3. 交流側基本波から有効電力 `P` と基本波無効電力 `Q1` を求め、`P=Pd` を確認せよ。
4. 総合力率 `λ` を求め、基本波力率 `cosα` と異なる理由を説明せよ。

### 完全解説

120°通電線電流より

```text
I=√(2/3)Id
 =√(2/3)×150
 =122.5 A
```

基本波実効値は

```text
I1=√6/π Id
  =√6/π×150
  =116.95 A
```

平均直流電圧は

```text
Vd=(3√2/π)×400×cos45°
  =381.97 V
```

したがって

```text
Pd=VdId
  =381.97×150
  =57.30 kW
```

交流側基本波から

```text
P=√3 VLL I1 cos45°
 =√3×400×116.95×0.7071
 =57.30 kW
```

であり、直流側電力と一致する。

基本波無効電力は

```text
Q1=√3 VLL I1 sin45°
  =57.30 kvar
```

総合力率は

```text
λ=P/(√3 VLL I)
 =57.30 kW/(√3×400×122.5 VA)
 =0.675
```

また

```text
λ=(3/π)cos45°
 =0.675
```

でも確認できる。基本波力率は `cos45°=0.707` だが、線電流は120°通電の非正弦波で高調波を含むため、全実効電流を使う総合力率はそれより低い。

## 問3 単相位相制御の波形・実効値・素子定格

逆並列サイリスタで抵抗 `R=20 Ω` を制御する。電源実効値 `V=200 V`、点弧角 `α=90°` とする。

1. 正半波・負半波の導通区間を示し、負荷電圧・負荷電流の波形を言葉または模式図で説明せよ。
2. 負荷実効電流 `IL` と負荷電力 `P` を求めよ。
3. 1個のサイリスタ平均電流 `IT,av` と最大素子電圧 `VT,max` を求めよ。

### 完全解説

抵抗負荷なので電流と電圧は同相である。`α=π/2` のとき、正半波は

```text
π/2 ≤ θ ≤ π
```

負半波は

```text
3π/2 ≤ θ ≤ 2π
```

で導通し、それ以外は負荷電圧・電流とも0となる。

負荷実効電流は

```text
IL=(V/R)√[(π-α+0.5sin2α)/π]
```

より、`sinπ=0` を使って

```text
IL=(200/20)√[(π-π/2)/π]
  =10/√2
  =7.071 A
```

負荷電力は

```text
P=IL^2R
 =7.071^2×20
 =1000 W
 =1.00 kW
```

1個のサイリスタ平均電流は

```text
IT,av=V/(√2πR)(1+cosα)
     =200/(√2π×20)
     =2.251 A
```

最大素子電圧は

```text
VT,max=√2V
      =282.8 V
```

答え: `IL=7.07 A`、`P=1.00 kW`、`IT,av=2.25 A`、`VT,max=283 V`。

ここでは抵抗負荷なので電圧零点で電流もゼロになる。誘導性負荷へ条件が変わった場合にこの消弧条件を流用してはいけない。

## 問4 波形・高調波・力率と誘導性負荷

次の2点を理由付きで説明せよ。

1. 単相ダイオードブリッジのキャパシタ入力で交流側電流がパルス状となり、総合力率が低下する理由、R8一次の条件で重要となる高調波、交流側直列リアクトルの効果を述べよ。さらに、理想三相120°通電線電流の代表高調波との違いを述べよ。
2. 逆並列サイリスタの純インダクタンス負荷で、電流が電圧零点を越えて継続する理由と、H25二次の対象条件での制御可能な点弧角範囲を述べよ。

### 完全解説

1. キャパシタ入力では、平滑コンデンサに保持された直流側電圧が交流電源瞬時値より高い区間ではダイオードが導通せず、交流電源瞬時値がコンデンサ電圧を上回る付近だけ充電電流が集中する。そのため交流側電流は尖ったパルス状となり、高調波を含む。R8一次の対象条件では基本波に次いで3次高調波が重要で、基本波の位相差だけでは総合力率を評価できない。交流側に直列リアクトルを入れると `di/dt` が抑えられて電流変化が緩やかになり、高調波を減らして総合力率を改善する方向に働く。一方、理想三相120°通電線電流の代表高調波は `6k±1`、すなわち5次、7次、11次、13次…であり、単相キャパシタ入力の3次高調波と混同しない。

2. 純インダクタンス負荷では、インダクタンスに蓄えられた磁気エネルギーにより電流は瞬時にゼロへ変化できず、電源電圧が零点を通過した後も流れ続ける。このため抵抗負荷の `θ=π` をそのまま消弧時刻にできない。H25二次の対象条件では制御可能な点弧角範囲は

```text
π/2<α<π
```

である。二次答案では範囲だけでなく、電流継続の物理的理由まで記述する。
