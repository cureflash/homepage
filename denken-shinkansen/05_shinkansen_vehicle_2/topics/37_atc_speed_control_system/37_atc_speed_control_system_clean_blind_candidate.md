## R7二次「機械・制御」問4 — 5答案要素

前向き伝達関数を

`L(s)=Gc(s)Gp(s)=(2s+4)/{s(s+3)}`

とする。

1. `Ge(s)=E(s)/R(s)=1/{1+L(s)}=s(s+3)/(s^2+5s+4)=s(s+3)/{(s+1)(s+4)}`。
2. 大きさ`a`のステップ入力では最終値定理より定常偏差 `0`。
3. 傾き`b`のランプ入力では `R(s)=b/s^2` より、定常偏差 `3b/4`。
4. `Gy(s)=Y(s)/R(s)=L/(1+L)=2(s+2)/{(s+1)(s+4)}`。したがってインパルス応答は `gy(t)=(2/3)e^{-t}+(4/3)e^{-4t}` (`t>0`)。
5. 単位ステップ応答は `y(t)=1-(2/3)e^{-t}-(1/3)e^{-4t}`。`e^{-1}=0.3679` より `y(1)≈0.749`。

## R6二次「機械・制御」問4 — 5答案要素

`G1(s)=3/(s+2)`、`G2(s)=5/(s^2+5s+6)=5/{(s+2)(s+3)}`。

1. 直列結合: `Y1/U=G1G2=15/{(s+2)^2(s+3)}=15/(s^3+7s^2+16s+12)`。
2. 単位ステップ入力時の定常値は最終値定理より `15/12=1.25`。
3. 並列結合: `G1+G2=(3s+14)/{(s+2)(s+3)}=8/(s+2)-5/(s+3)`。インパルス応答は `y2(t)=8e^{-2t}-5e^{-3t}`。
4. `u(t)=2e^{-t}`、`U(s)=2/(s+1)` より `Y2(s)=11/(s+1)-16/(s+2)+5/(s+3)`。したがって `y2(t)=11e^{-t}-16e^{-2t}+5e^{-3t}`。
5. `ω→∞` では並列伝達関数は `3/(jω)` に漸近するため位相は `-90° (-π/2 rad)`。

## R4二次「機械・制御」問4 — 5答案要素

開ループ伝達関数は

`L(s)=100K/{s(s+1)(s+40)}`。

1. 特性方程式: `s(s+1)(s+40)+100K=0`、すなわち `s^3+41s^2+40s+100K=0`。
2. Routh条件より `K>0` かつ `41×40>100K`。したがって安定条件は `0<K<16.4`。
3. `TER(s)=E/R=1/(1+L)=s(s+1)(s+40)/{s(s+1)(s+40)+100K}`。
4. `K=2`、傾き2のランプ入力に対し速度定数 `Kv=lim[sL(s)]=5`。定常速度偏差 `ev=2/Kv=0.400`。
5. `K=2`、`r(t)=2sin t` に対し `|TER(j)|=sqrt(3202/26802)`。よって定常偏差振幅 `B=2|TER(j)|≈0.691`。

## R3二次「機械・制御」問4 — 5答案要素

内側ループについて、制御対象 `P(s)=1/{s(2s+1)}`、内側帰還 `H(s)=s`、前段 `K/(Ts+1)` である。

1. 内側閉ループを整理すると `P/(1+PH)=1/{2s(s+1)}`。したがって開ループ伝達関数 `G(s)=Y/E=K/{2s(s+1)(Ts+1)}`。
2. 外側単位負帰還より `W(s)=Y/R=G/(1+G)=K/{2s(s+1)(Ts+1)+K}`。
3. `T=0` では特性方程式 `2s^2+2s+K=0`。根が複素共役となり時間応答が振動的となる条件は `K>1/2`。
4. `T=0, K=1` では `W(s)=1/(2s^2+2s+1)`。単位インパルス応答は `y(t)=e^{-t/2}sin(t/2)` (`t≥0`)。
5. `T=2` では特性方程式 `4s^3+6s^2+2s+K=0`。Routh-Hurwitzより `K>0` かつ `6×2>4K`、したがって安定条件 `0<K<3`。
