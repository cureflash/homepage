## 1. このテーマで電験二種は何を問うか

固定過去問はATC装置そのものを出題した問題ではない。第二種の自動制御・安全制御を解くための一般理論を、JRTT一次資料で確認できる「速度信号を受け、列車速度がその速度信号より高い場合に自動的にブレーキを作用させ、信号速度以下へ制御する」というATCの一般原理へ接続する。

必要な技能は次のとおり。

1. 目標値 `r(t)`、検出値、制御量 `y(t)`、偏差 `e(t)`、操作量 `u(t)` を区別する。
2. 伝達関数を定義し、直列・並列・フィードバック結合を簡約する。
3. 閉ループ伝達関数と偏差伝達関数を求める。
4. ステップ、インパルス、ランプ、指数、正弦波入力に対する応答を求める。
5. 最終値の定理と周波数応答を条件付きで使う。
6. 特性方程式から安定性を判定し、三次系ではラウス表を構成する。
7. シーケンス制御、自己保持、PLC、ラダー図、フェイルセーフを識別する。
8. センサとブレーキ系をフィードバック制御の要素として説明するが、未確認の実車内部構成を断定しない。

本Topicは一次「機械」と二次「機械・制御」の双方へ直接対応する。

## 2. フィードバック制御の基本量

負帰還系を一般に

`r(t) -> [比較] -> e(t) -> 制御器 Gc(s) -> 操作量 u(t) -> 制御対象 Gp(s) -> y(t)`

と考え、出力側の検出要素を `H(s)` とする。

偏差は

`E(s) = R(s) - H(s)Y(s)`

である。前向き伝達関数を

`G(s)=Gc(s)Gp(s)`

とすれば、閉ループ伝達関数は

`Y(s)/R(s) = G(s) / [1 + G(s)H(s)]`

である。単位フィードバック `H(s)=1` では

`Y(s)/R(s) = G(s)/(1+G(s))`

`E(s)/R(s) = 1/(1+G(s))`

となる。

### ATCへの接続

教材上は、指示速度を目標値、速度検出値をフィードバック量、自動ブレーキ系を制御出力の例として対応付けられる。ただしこれは一般制御ブロックとしての対応付けであり、実車ATCの内部ブロック線図を示すものではない。

## 3. 伝達関数

初期値を0とし、線形時不変系で入力 `X(s)`、出力 `Y(s)` の関係が

`Y(s)=G(s)X(s)`

と書けるとき、

`G(s)=Y(s)/X(s)`

を伝達関数という。

分母多項式は自然応答と安定性に関係し、閉ループ伝達関数の分母を0とした式が特性方程式である。

伝達関数を使うときは、分子・分母の次数、極、零点、定常ゲイン、入力のラプラス変換を確認する。

## 4. ブロック線図の簡約

### 直列結合

`G1(s)`、`G2(s)` が直列なら

`G_series(s)=G1(s)G2(s)`

である。

### 並列結合

加算点で同符号に加算するなら

`G_parallel(s)=G1(s)+G2(s)`

である。

### 負帰還

前向き `G(s)`、帰還 `H(s)` なら

`G_closed(s)=G(s)/[1+G(s)H(s)]`

である。

正帰還では分母符号が変わる。試験では加算点の符号を見落とさない。

### 解法手順

1. 内側のループから簡約する。
2. 直列は積、並列は和・差へ置き換える。
3. 帰還ループを `G/(1+GH)` または問題の符号に従って簡約する。
4. 最後に入力から求める出力までの伝達関数を一本化する。
5. 分母を展開し、特性方程式と安定性を確認する。

## 5. 代表入力とラプラス変換

- 単位インパルス `δ(t)`: `1`
- 大きさ `a` のステップ: `a/s`
- 傾き `b` のランプ `bt`: `b/s^2`
- `Ae^{-αt}`: `A/(s+α)`
- `A sin ωt`: `Aω/(s^2+ω^2)`

入力の種類を誤ると定常偏差や応答計算が全て変わる。

## 6. 過渡応答と定常値

出力は

`Y(s)=G(s)X(s)`

から逆ラプラス変換して求める。部分分数分解では係数と極を対応させる。

安定で、最終値の定理を適用できる条件を満たすとき、

`lim[t->∞] y(t) = lim[s->0] sY(s)`

である。`sY(s)` が右半平面または虚軸上に不適切な極をもつ場合には機械的に使わない。

## 7. 定常偏差

単位フィードバック系では

`E(s)=R(s)/(1+G(s))`

である。

安定条件を満たすとき

`e_ss = lim[s->0] sE(s)`

を用いる。

積分要素の個数によってステップ・ランプ入力への定常偏差が変わるが、問題では暗記だけでなく `E/R` を作って最終値の定理で確認する。

## 8. 周波数応答

正弦波定常応答では `s=jω` を代入した `G(jω)` を用いる。

入力 `A sin ωt` に対し、安定な線形系の定常応答振幅は

`A |G(jω)|`

となり、位相差は `arg G(jω)` である。

分子次数より分母次数が1高い伝達関数では、十分高い周波数で位相が概ね `-90°` へ近づく例がある。次数差と係数を確認して判断する。

## 9. 安定性と特性方程式

閉ループ伝達関数の分母

`D(s)=0`

が特性方程式である。連続時間線形系では全極の実部が負なら漸近安定である。

三次式

`a3 s^3 + a2 s^2 + a1 s + a0 = 0`

について、係数が正である場合のラウス表は

` s^3 : a3   a1`

` s^2 : a2   a0`

` s^1 : (a2 a1 - a3 a0)/a2   0`

` s^0 : a0`

となる。第一列がすべて同符号、通常は正であることが安定条件である。

したがって正係数三次式では

`a2 a1 > a3 a0`

も必要になる。

## 10. 固定過去問接続① R7二次「機械・制御」問4

与えられる系を

`Gc(s)=(2s+4)/s = 2(s+2)/s`

`Gp(s)=1/(s+3)`

単位フィードバックとする。

開ループは

`G(s)=2(s+2)/[s(s+3)]`

である。

### (1) 偏差伝達関数

`E/R = 1/(1+G)` より

`E(s)/R(s) = s(s+3)/[(s+1)(s+4)]`

### (2) ステップ入力 `a` の定常偏差

`R(s)=a/s` なので

`e_ss = lim[s->0] s * [E/R] * a/s = 0`

### (3) ランプ入力 `bt` の定常偏差

`R(s)=b/s^2` より

`e_ss = lim[s->0] s * s(s+3)/[(s+1)(s+4)] * b/s^2 = 3b/4`

### (4) 閉ループのインパルス応答

`Y/R = 2(s+2)/[(s+1)(s+4)]`

部分分数分解すると

`Y/R = (2/3)/(s+1) + (4/3)/(s+4)`

したがって単位インパルス応答は

`y(t)=(2/3)e^{-t}+(4/3)e^{-4t}`

### (5) 単位ステップ `t=1 s` の出力

`Y(s)=2(s+2)/[s(s+1)(s+4)]`

`=1/s -(2/3)/(s+1) -(1/3)/(s+4)`

より

`y(t)=1-(2/3)e^{-t}-(1/3)e^{-4t}`

`t=1` では

`y(1)≈0.749`

固定5答案要素をすべて本文で再現できる。

`G2(s)=5/[(s+2)(s+3)]`

`G1+G2 = (3s+14)/[(s+2)(s+3)]`

## 12. 固定過去問接続③ R4二次「機械・制御」問4

前向き要素を

`K/s`

`100/[(s+1)(s+40)]`

単位フィードバックとする。

開ループは

`L(s)=100K/[s(s+1)(s+40)]`

である。

### (1) 特性方程式

`1+L(s)=0` より

`s^3+41s^2+40s+100K=0`

### (2) ラウス安定範囲

第一列が正となる条件から

`K>0`

`41*40 > 100K`

したがって

`0<K<16.4`

### (3) 偏差伝達関数

`E/R = 1/(1+L)` より

`E(s)/R(s)=s(s+1)(s+40)/[s(s+1)(s+40)+100K]`

### (4) `K=2`, `r(t)=2t` の定常偏差

`R(s)=2/s^2` とし最終値の定理を適用すると

`e_ss=0.4`

### (5) `K=2`, `r(t)=2 sin t` の定常偏差振幅

`Ge(j1)=E(j1)/R(j1)` の大きさを求め、入力振幅2を掛けると

`2|Ge(j1)|≈0.691`

となる。

## 13. 固定過去問接続④ R3二次「機械・制御」問4

問題の内部速度フィードバックを先に簡約し、外側単位フィードバックへ整理すると開ループは

`G(s)=K/[2s(s+1)(Ts+1)]`

閉ループ伝達関数は

`W(s)=K/[2Ts^3+(2T+2)s^2+2s+K]`

となる。

### (1) 開ループ伝達関数

`K/[2s(s+1)(Ts+1)]`

### (2) 閉ループ伝達関数

`K/[2Ts^3+(2T+2)s^2+2s+K]`

### (3) `T=0` の振動条件

分母は

`2s^2+2s+K`

であり、複素共役極となる条件は判別式

`2^2-4*2*K < 0`

より

`K>0.5`

### (4) `T=0, K=1` の単位インパルス応答

`W(s)=1/(2s^2+2s+1)`

`=1/[2{(s+0.5)^2+0.5^2}]`

したがって

`w(t)=e^{-0.5t} sin(0.5t)`

### (5) `T=2` の安定範囲

分母は

`4s^3+6s^2+2s+K`

ラウス条件より

`K>0`

`6*2 > 4K`

したがって

`0<K<3`

となる。

## 14. 固定過去問接続⑤ R4一次「機械」問7

固定5答案要素は次の用語関係である。

1. シーケンス制御: あらかじめ定めた順序・条件に従って各段階の制御を進める方式。
2. 自己保持回路: 起動条件が一時的に消えても補助接点等によって動作状態を保持する回路。
3. PLC: 入出力信号を取り込み、プログラムされた論理に従って制御する装置。
4. ラダー図: リレー回路を梯子状の記号で表現した制御プログラム表現。
5. フェイルセーフ: 故障が起きたとき、危険側ではなく安全側へ移行するように設計する考え方。

ATCへ接続するときも、ここから新幹線ATCの具体的PLC構成、自己保持回路、冗長構成を推測しない。扱うのは一般的な安全制御原理だけである。

## 15. 速度検出・目標速度・ブレーキ制御

JRTT一次資料で確認できる一般原理では、ATCは速度信号を列車へ送り、列車速度が受信した速度信号より高い場合に自動的にブレーキを作用させ、信号速度以下へ制御する。

教材上の制御量対応は次のように整理できる。

- 目標値: 受信した速度信号に対応する目標速度
- 検出値: 列車速度の検出値
- 偏差: 目標値と検出値の比較結果
- 操作量: ブレーキ側へ与える制御指令の一般概念
- 制御対象: 列車速度が変化する力学系の一般モデル

ただし実車では安全制御固有の論理・制約が存在し得るため、この単純な連続時間フィードバック図を実装図とみなさない。

## 16. フェイルセーフ

フェイルセーフは「故障しないこと」ではなく、「故障しても危険側へ移行しにくいよう、安全側の状態へ導くこと」を意味する。

試験では、単なる高信頼化、冗長化、故障検出と混同しない。冗長化は信頼度を上げる手段になり得るが、冗長であること自体がフェイルセーフの定義ではない。

本Topicでは実車ATCのフェイルセーフ回路、二重系・三重系構成、投票論理、故障時ブレーキ段を一次資料なしで具体化しない。

## 17. 3段階例題

### 基礎例題 — 一次遅れ系の閉ループ応答

教材用仮定モデルとして

`Gp(s)=1/(2s+1)`

比例制御器

`Gc(s)=4`

単位フィードバックとする。

閉ループは

`T(s)=4/(2s+5)`

単位ステップ応答は

`y(t)=0.8(1-e^{-2.5t})`

である。

定常値は `0.8`、定常偏差は `0.2`。比例ゲインを有限値にした0形系では、ステップ定常偏差が残る例である。

### 本試験標準例題 — R7型

`Gc(s)=2(s+2)/s`、`Gp(s)=1/(s+3)`、単位フィードバックから、偏差伝達関数、ランプ定常偏差、ステップ応答を順に求める。

解法順は

`開ループ -> 1+G -> E/R と Y/R -> 入力のラプラス変換 -> 最終値または逆変換`

で固定する。結果は第10節のとおり、ランプ `bt` の定常偏差 `3b/4`、単位ステップ `t=1 s` の出力 `≈0.749` となる。

### 複合・ひっかけ例題 — 三次系の安定範囲

特性方程式を

`s^3+6s^2+8s+12K=0`

とする。ラウス条件は

`K>0`

`6*8 > 12K`

であり

`0<K<4`

となる。

係数が全て正でも、三次以上ではそれだけで安定とは限らないことがひっかけである。

## 19. 系列SPEC固定計算・グラフ② 制動指令―速度応答

教材用仮定モデルとして、正規化した制動指令 `u_b(t)` に対する減速度応答を一次遅れ

`A(s)/U_b(s)=a_max/(τ_b s+1)`

とする。

速度変化は減速度を積分するので

`ΔV(s)/U_b(s) = -a_max/[s(τ_b s+1)]`

となる。

単位ステップ制動指令、初速度 `v0` に対して

`a(t)=a_max(1-e^{-t/τ_b})`

`v(t)=v0-a_max[t-τ_b(1-e^{-t/τ_b})]`

である。

グラフ作成用の教材仮定値:

- `v0=80 m/s`
- `a_max=0.8 m/s^2`
- `τ_b=1.5 s`

代表値:

| t [s] | a(t) [m/s^2] | v(t) [m/s] |
|---:|---:|---:|
| 0 | 0.000 | 80.000 |
| 1 | 0.389 | 79.784 |
| 2 | 0.589 | 79.284 |
| 5 | 0.771 | 77.157 |
| 10 | 0.799 | 73.198 |

このモデルは制動指令に対して減速度が即時に最大値へ跳ばず、一次遅れで立ち上がる一般的な教材モデルである。数値は全て仮定値であり、実車ATC・ブレーキ装置の減速度、遅れ、指令則を表さない。速度が0へ達した後まで式を外挿して負速度を生成することもしない。

## 20. 問題を見たときの解法アルゴリズム

1. 求める量が `Y/R`、`E/R`、時間応答、定常値、安定範囲のどれかを判定する。
2. ブロック線図の加算点と帰還符号を確認する。
3. 内側ループから簡約し、一本の伝達関数へ落とす。
4. 入力がステップ、ランプ、インパルス、指数、正弦波のどれかをラプラス変換する。
5. 定常値なら最終値の定理の適用条件を確認する。
6. 時間応答なら部分分数分解して逆ラプラス変換する。
7. 安定性なら特性方程式を作り、必要に応じてラウス表を作る。
8. 単位、極の位置、定常値、初期値、符号で検算する。

## 21. 頻出ミス

- `Y/R` と `E/R` を混同する。
- 負帰還の分母 `1+GH` を `1-GH` にする。
- ステップ `a/s` とランプ `b/s^2` を混同する。
- 最終値の定理を不安定系へ無条件に適用する。
- インパルス応答とステップ応答を同じものとして扱う。
- ラウス表で係数が全て正なら安定と早合点する。
- 一般制御モデルの仮定値をATC実車値と誤認する。
- フェイルセーフを単に「故障しにくいこと」と定義する。

## 24. 鉄道一次資料と境界

鉄道側の一般原理は固定EXAM_ALIGNMENT記載の一次資料に従う。

- JRTT「信号」: ATCが列車へ速度信号を送り、列車速度が受信速度より高い場合に自動ブレーキを作用させ、信号速度以下へ制御する一般原理。
- 鉄道総研「ATS-Dx」: 速度照査パターン、連続速度照査、安全性評価の関連原理を確認する補助資料。ATS-Dxは在来線ATSであり、新幹線ATC実装として扱わない。
