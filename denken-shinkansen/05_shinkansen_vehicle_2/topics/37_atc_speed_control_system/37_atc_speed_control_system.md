## EXAM_ALIGNMENT

資格: 第二種電気主任技術者

科目:
- 一次試験: 機械（自動制御及びメカトロニクス）
- 二次試験: 機械・制御（自動制御及びメカトロニクス）

論点: フィードバック制御、目標値・検出値・偏差、伝達関数、ブロック線図、直列・並列・フィードバック結合、ステップ・インパルス・ランプ・正弦波応答、最終値、特性方程式、ラウスの安定判別、センサ・アクチュエータ、フェイルセーフ。これらをATCの「速度信号を受け、列車速度が指示速度を超える場合に自動的にブレーキを作用させる」という一次資料で確認できる一般原理へ接続する。

重要: 固定過去問はATC装置そのものを出題した問題ではない。第二種の自動制御を解くための制御理論・安全制御を固定するために用いる。鉄道固有の実装は鉄道一次資料で別に境界を確認する。

### 二次試験の適用判定

電気技術者試験センターの第二種試験概要では、一次「機械」に自動制御及びメカトロニクスが含まれ、二次「機械・制御」にも自動制御及びメカトロニクスが明記されている。

したがって本Topicは一次・二次の双方へ直接対応する。二次は件数合わせではなく主題そのものに対応する記述式問題を固定する。

### 鉄道側の一次資料

鉄道固有の原理・位置づけは試験過去問から推測せず、鉄道事業・研究機関の一次資料で境界を固定する。

- 鉄道・運輸機構（JRTT）「信号」: https://www.jrtt.go.jp/construction/technology/signal.html
  - ATCを代表的な鉄道信号システムとして説明している。
  - 軌道回路を通じて列車へ情報を伝送すること、新幹線で利用されることを確認。
  - ATCは列車へ速度信号を送り、列車速度が受信した速度信号より高い場合に自動的にブレーキを作用させ、信号速度以下へ制御するという一般原理を確認。
- 鉄道総研「ATS-Dx」: https://www.rtri.or.jp/rd/division/rd47/rd4710/rd47100103.html
  - 速度照査パターンと連続的な速度照査、安全性評価という関連原理を確認する補助資料。
  - ATS-Dxは在来線ATSであり、新幹線ATCの実装資料として扱わない。

これらから実車の速度検出ハードウェア、サンプリング周期、制御器構造、ゲイン、ブレーキ則、減速度、遅れ時間、フェイルセーフ実装を推測しない。

## 制作前独立再解答

固定した公式5問について、問題条件から正答を独立に再構成し、公式標準解答と照合した。

### R4 一次「機械」問7 — 5要素

1. `(1) ト`: シーケンス制御。
2. `(2) ニ`: 自己保持回路。
3. `(3) カ`: プログラマブルロジックコントローラ（PLC）。
4. `(4) ヌ`: ラダー図。
5. `(5) ロ`: フェールセーフ。

判定: `5 / 5 PASS`。公式解答と一致。

### R7 二次「機械・制御」問4 — 5要素

`Gc(s)=(2s+4)/s`、`Gp(s)=1/(s+3)`、単位フィードバック。

1. 偏差伝達関数: `Ge(s)=E(s)/R(s)=s(s+3)/[(s+1)(s+4)]`。
2. ステップ入力 `a` の定常偏差: `0`。
3. ランプ入力 `bt` の定常偏差: `3b/4`。
4. 閉ループ伝達関数 `Gy(s)=2(s+2)/[(s+1)(s+4)]`、インパルス応答 `gy(t)=(2/3)e^{-t}+(4/3)e^{-4t}`。
5. 単位ステップ入力の `t=1 s` 出力: `1-(2/3)e^{-1}-(1/3)e^{-4}≈0.749`。

判定: `5 / 5 PASS`。公式標準解答と一致。

### R6 二次「機械・制御」問4 — 5要素

`G1(s)=3/(s+2)`、`G2(s)=5/[(s+2)(s+3)]`。

1. 直列結合: `G1G2=15/[(s+2)^2(s+3)]`。
2. 単位ステップ入力に対する直列結合の定常値: `15/12=1.25`。
3. 並列結合: `G1+G2=8/(s+2)-5/(s+3)`、インパルス応答 `8e^{-2t}-5e^{-3t}`。
4. 入力 `u(t)=2e^{-t}` の出力: `11e^{-t}-16e^{-2t}+5e^{-3t}`。
5. 高周波域の位相: `-90°`。

判定: `5 / 5 PASS`。公式標準解答と一致。

### R4 二次「機械・制御」問4 — 5要素

前向き要素 `K/s` と `100/[(s+1)(s+40)]`、単位フィードバック。

1. 特性方程式: `s^3+41s^2+40s+100K=0`。
2. ラウスの安定判別: `0<K<16.4`。
3. 偏差伝達関数: `E(s)/R(s)=s(s+1)(s+40)/[s(s+1)(s+40)+100K]`。
4. `K=2`、ランプ入力 `r(t)=2t` の定常偏差: `0.4`。
5. `K=2`、入力 `2 sin t` の定常偏差振幅: 約 `0.691`。

判定: `5 / 5 PASS`。公式標準解答と一致。

### R3 二次「機械・制御」問4 — 5要素

制御器 `K/(Ts+1)`、制御対象 `1/[s(2s+1)]`、速度フィードバック要素 `s`、外側単位フィードバック。

1. 内側ループ簡約後の開ループ伝達関数: `G(s)=K/[2s(s+1)(Ts+1)]`。
2. 閉ループ伝達関数: `W(s)=K/[2Ts^3+(2T+2)s^2+2s+K]`。
3. `T=0` でステップ応答が振動的となる条件: `K>0.5`。
4. `T=0, K=1` の単位インパルス応答: `y(t)=e^{-0.5t} sin(0.5t)`。
5. `T=2` の安定条件: `0<K<3`。

判定: `5 / 5 PASS`。公式標準解答と一致。

一次: `5 / 5 PASS`。
二次: `20 / 20 PASS`。
合計: `25 / 25 PASS`。

## 制作時に必ず教えること

- フィードバック系の目標値、検出値、偏差、操作量をブロック線図上で区別する。
- 伝達関数を定義するだけでなく、直列・並列・フィードバック結合を簡約できるようにする。
- ステップ、インパルス、ランプ、正弦波に対する応答をラプラス変換と最終値の定理から求める。
- 特性方程式とラウスの安定判別からゲインの安定範囲を求める。
- センサ入力、制御器、アクチュエータ出力、フェイルセーフの関係をR4一次問7へ接続する。
- JRTT一次資料で確認できるATCの「速度信号―列車速度―自動ブレーキ」の概念対応を示す。
- 教材用の簡略速度制御モデルと実車ATCの内部実装を明確に区別する。
- フェイルセーフを「故障時に安全側へ移行する」一般原理として扱い、一次資料なしに実車の具体的冗長構成を作らない。

## 禁止事項

- 未確認の新幹線ATC速度検出方式、制御周期、制御器構成・ゲイン、伝達関数、ブレーキ指令則、減速度、遅れ時間、しきい値を実車仕様として断定しない。
- 固定過去問をATCそのものの出題と表現しない。
- ATS-Dxを新幹線ATCの実装例として扱わない。
- 教材用仮定モデルの数値を実車値として扱わない。
- Topic 38の列車追跡・論理処理・インターロック・状態遷移へ進まない。
- 第三種・第一種の過去問を第二種の固定過去問数に算入しない。
