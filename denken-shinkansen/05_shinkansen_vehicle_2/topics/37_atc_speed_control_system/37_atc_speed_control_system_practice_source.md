# 一次試験型

## 問1 負帰還系の閉ループ伝達関数

`Gp(s)=1/(2s+1)`、比例制御器 `Gc(s)=4` を直列に接続し、単位負帰還とする。`Y(s)/R(s)` として正しいものを選べ。

1. `4/(2s+1)`
2. `4/(2s+4)`
3. `4/(2s+5)`
4. `(2s+1)/(2s+5)`
5. `1/(2s+5)`

### 正答
3

### 完全解説

前向き伝達関数は `G(s)=4/(2s+1)`。単位負帰還では `Y/R=G/(1+G)` なので、

`Y/R = [4/(2s+1)]/[1+4/(2s+1)] = 4/(2s+5)`。

したがって3。負帰還の分母を `1-G` としない。

## 問2 ステップ応答と定常偏差

問1の系へ単位ステップを入力する。定常出力と定常偏差の組合せとして正しいものを選べ。

1. `0.2, 0.8`
2. `0.5, 0.5`
3. `0.8, 0.2`
4. `1.0, 0`
5. `4.0, -3.0`

### 正答
3

### 完全解説

`T(s)=4/(2s+5)`、`R(s)=1/s` なので `Y(s)=4/[s(2s+5)]`。最終値の定理を適用できる安定系だから、

`y(∞)=lim[s→0]sY(s)=4/5=0.8`。

目標値が1なので定常偏差は `1-0.8=0.2`。よって3。比例ゲインが有限の0形系ではステップ定常偏差が残る例である。

## 問4 直列・並列結合

`G1(s)=2/(s+1)`、`G2(s)=3/(s+2)` とする。直列結合と同符号並列結合の組合せとして正しいものを選べ。

1. 直列 `6/[(s+1)(s+2)]`、並列 `(5s+7)/[(s+1)(s+2)]`
2. 直列 `5/[(s+1)(s+2)]`、並列 `(6s+6)/[(s+1)(s+2)]`
3. 直列 `6/(2s+3)`、並列 `5/(2s+3)`
4. 直列 `(5s+7)/[(s+1)(s+2)]`、並列 `6/[(s+1)(s+2)]`
5. 直列 `6/[(s+1)(s+2)]`、並列 `1/[(s+1)(s+2)]`

### 正答
1

### 完全解説

直列は積なので `G1G2=6/[(s+1)(s+2)]`。並列は和なので、

`G1+G2 = [2(s+2)+3(s+1)]/[(s+1)(s+2)] = (5s+7)/[(s+1)(s+2)]`。

よって1。

## 問5 最終値の定理

最終値の定理について最も適切な記述を選べ。

1. どの伝達関数にも無条件で使える。
2. `sY(s)` の極の位置を確認せず使ってよい。
3. 発散する出力でも有限の最終値を必ず返す。
4. 適用条件を満たす安定な応答で、`lim[s→0]sY(s)` から最終値を求められる。
5. 時間応答の初期値だけを求める定理である。

### 正答
4

### 完全解説

最終値の定理は機械的に適用できない。`sY(s)` に右半平面極や最終値を妨げる虚軸上の極がある場合などは成立しない。適用条件を確認したうえで `lim[s→0]sY(s)` を使うので4。

## 問6 三次系の安定範囲

特性方程式が

`s^3+6s^2+8s+12K=0`

である。漸近安定となる `K` の範囲として正しいものを選べ。

1. `K<0`
2. `0<K<4`
3. `0<K<6`
4. `K>4`
5. 全ての `K>0`

### 正答
2

### 完全解説

正係数よりまず `K>0`。三次ラウス条件は `a2a1>a3a0` だから、`6×8>1×12K`、すなわち `K<4`。よって `0<K<4` で2。係数がすべて正というだけでは三次以上の安定性を保証しない。

### 正答
3

シーケンス制御は、あらかじめ定めた順序や条件に従って制御を進める。自己保持は、起動条件が一時的に消えても補助接点などで動作状態を保持する代表的回路である。よって3。

## 問9 フェイルセーフ

フェイルセーフの説明として最も適切なものを選べ。

1. 故障が絶対に発生しないようにすること。
2. 故障時にも必ず通常運転を継続すること。
3. 故障が起きたとき危険側ではなく安全側へ移行しやすくする設計思想。
4. 冗長化と完全に同義である。

### 正答
3

### 完全解説

フェイルセーフは「故障しないこと」ではなく、故障時に安全側へ導く設計思想である。冗長化は信頼度向上の手段になり得るが、冗長化そのものがフェイルセーフの定義ではない。よって3。

## 問10 ATCと一般フィードバックモデルの境界

本教材でATCを一般フィードバック制御へ接続する説明として適切なものを選べ。

1. 教材用の一次遅れ伝達関数を、そのまま新幹線ATC実機の伝達関数と断定する。
2. 指示速度を目標値、速度検出値をフィードバック量、自動ブレーキを制御作用の例として整理するが、未確認の実機内部構成は断定しない。

### 正答

## 問11 一次遅れ系の周波数応答

`G(s)=1/(Ts+1)`、`T>0` とする。`s=jω` とした周波数応答について正しいものを選べ。

1. `|G(jω)|=sqrt(1+(ωT)^2)`、位相は正。
2. `|G(jω)|=1/sqrt(1+(ωT)^2)`、位相は `-tan^-1(ωT)`。
3. `|G(jω)|=1` で全周波数一定、位相0。
4. 高周波ほど振幅比が増大する。
5. 高周波で位相は `+90°` に近づく。

### 正答
2

### 完全解説

`G(jω)=1/(1+jωT)` だから、振幅比は `1/sqrt(1+(ωT)^2)`、位相は `-tan^-1(ωT)`。高周波で振幅比は0へ、位相は `-90°` へ近づく。よって2。

## 問12 教材用制動応答

教材用仮定モデルとして、

`a(t)=a_max(1-e^{-t/τ_b})`

`v(t)=v0-a_max[t-τ_b(1-e^{-t/τ_b})]`

とする。`v0=80 m/s`、`a_max=0.8 m/s^2`、`τ_b=1.5 s` のとき、`t=2 s` における減速度と速度の組合せとして最も近いものを選べ。

1. `0.211 m/s^2, 78.400 m/s`
2. `0.389 m/s^2, 79.784 m/s`
3. `0.589 m/s^2, 79.284 m/s`
4. `0.800 m/s^2, 78.400 m/s`
5. `1.067 m/s^2, 80.000 m/s`

### 正答
3

### 完全解説

`e^{-2/1.5}≈0.2636` なので、

`a(2)=0.8(1-0.2636)≈0.589 m/s^2`。

速度は

`v(2)=80-0.8[2-1.5(1-0.2636)]≈79.284 m/s`。

よって3。本問の値は教材用仮定値であり、新幹線ATC・ブレーキ装置の実値ではない。

## 二次1 偏差・定常偏差・時間応答

単位負帰還系で、

`Gc(s)=2(s+2)/s`

`Gp(s)=1/(s+3)`

とする。次を求めよ。

1. 偏差伝達関数 `E(s)/R(s)`
2. 大きさ `a` のステップ入力に対する定常偏差
3. ランプ入力 `r(t)=bt` に対する定常偏差
4. 閉ループ系の単位インパルス応答
5. 単位ステップ入力に対する `t=1 s` の出力

### 完全解説

前向き伝達関数は

`G(s)=2(s+2)/[s(s+3)]`。

1. 単位負帰還なので

`E/R=1/(1+G)=s(s+3)/[(s+1)(s+4)]`。

2. `R(s)=a/s`。安定性を確認して最終値の定理を使うと、

`e_ss=lim[s→0] s(E/R)(a/s)=0`。

3. `R(s)=b/s^2` だから、

`e_ss=lim[s→0] s(E/R)(b/s^2)=3b/4`。

4. 閉ループ伝達関数は

`Y/R=2(s+2)/[(s+1)(s+4)]`

`=(2/3)/(s+1)+(4/3)/(s+4)`。

よって単位インパルス応答は

`y(t)=(2/3)e^{-t}+(4/3)e^{-4t}`。

5. 単位ステップなら

`Y(s)=2(s+2)/[s(s+1)(s+4)]`

`=1/s-(2/3)/(s+1)-(1/3)/(s+4)`。

したがって

`y(t)=1-(2/3)e^{-t}-(1/3)e^{-4t}`、

`y(1)≈0.74864≈0.749`。

## 二次2 直列・並列系の応答

`G1(s)=3/(s+2)`、`G2(s)=5/[(s+2)(s+3)]` とする。次を求めよ。

1. 直列結合の伝達関数
2. 直列結合へ単位ステップを入力したときの定常値
3. 並列結合の伝達関数と単位インパルス応答
4. 並列結合へ `u(t)=2e^{-t}` を入力したときの出力
5. 並列伝達関数の高周波域での位相の極限

### 完全解説

1. 直列は積なので

`G1G2=15/[(s+2)^2(s+3)]`。

2. 単位ステップ入力 `1/s` と最終値の定理より、

`y(∞)=lim[s→0]G1G2=15/(2^2×3)=1.25`。

3. 並列は和なので

`G1+G2=(3s+14)/[(s+2)(s+3)]`

`=8/(s+2)-5/(s+3)`。

よって単位インパルス応答は

`g(t)=8e^{-2t}-5e^{-3t}`。

4. `U(s)=2/(s+1)` を掛け、部分分数分解すると

`Y(s)=11/(s+1)-16/(s+2)+5/(s+3)`。

したがって

`y(t)=11e^{-t}-16e^{-2t}+5e^{-3t}`。

5. `ω→∞` では並列伝達関数は `3/s` に漸近する。`s=jω` より位相は `-90°` へ近づく。

## 二次3 ラウス安定判別と定常偏差

単位負帰還系の開ループ伝達関数を

`L(s)=100K/[s(s+1)(s+40)]`

とする。次を求めよ。

1. 閉ループ系の特性方程式
2. ラウスの安定判別による `K` の安定範囲
3. 偏差伝達関数 `E(s)/R(s)`
4. `K=2`、`r(t)=2t` の定常偏差
5. `K=2`、`r(t)=2 sin t` の定常偏差の振幅

### 完全解説

1. `1+L(s)=0` より、

`s^3+41s^2+40s+100K=0`。

2. 三次ラウス条件から `K>0` と

`41×40>100K`。

したがって

`0<K<16.4`。

3. 単位負帰還なので、

`E/R=1/(1+L)=s(s+1)(s+40)/[s(s+1)(s+40)+100K]`。

4. `K=2`、`R(s)=2/s^2`。最終値の定理より

`e_ss=lim[s→0] s(E/R)(2/s^2)=0.4`。

5. `K=2` として `Ge(s)=E/R` に `s=j1` を代入する。正弦波入力の振幅は2なので、定常偏差振幅は

`2|Ge(j1)|≈0.691`。

## 二次4 内部速度フィードバックを含む系

内部速度フィードバックを簡約した後の外側単位負帰還系について、開ループ伝達関数が

`G(s)=K/[2s(s+1)(Ts+1)]`

となる教材モデルを考える。次を求めよ。

1. 開ループ伝達関数
2. 閉ループ伝達関数
3. `T=0` のとき閉ループ極が複素共役となる `K` の条件
4. `T=0, K=1` の単位インパルス応答
5. `T=2` のときの安定な `K` の範囲

### 完全解説

1. 開ループは問題文どおり

`G(s)=K/[2s(s+1)(Ts+1)]`。

2. 単位負帰還なので

`W(s)=G/(1+G)`

`=K/[2Ts^3+(2T+2)s^2+2s+K]`。

3. `T=0` では分母が `2s^2+2s+K`。複素共役極の条件は判別式が負だから、

`2^2-4×2×K<0`

より `K>0.5`。

4. `T=0, K=1` では

`W(s)=1/(2s^2+2s+1)`

`=1/[2{(s+0.5)^2+0.5^2}]`。

したがって単位インパルス応答は

`w(t)=e^{-0.5t}sin(0.5t)`。

5. `T=2` では特性式は

`4s^3+6s^2+2s+K=0`。

ラウス条件 `K>0` と `6×2>4K` より、

`0<K<3`。
