## 2. R7二次「機械・制御」問4

与式:

- `Gc(s) = (2s+4)/s = 2(s+2)/s`
- `Gp(s) = 1/(s+3)`
- 単位負帰還

開ループ伝達関数を

`L(s) = Gc(s)Gp(s) = 2(s+2) / {s(s+3)}`

とする。

### (1) R(s) から E(s) まで

`Ge(s) = E(s)/R(s) = 1/{1+L(s)}`

したがって

`Ge(s) = s(s+3) / {s^2+5s+4} = s(s+3)/{(s+1)(s+4)}`

### (2) 大きさ a のステップ入力の定常偏差

`R(s)=a/s` より

`E(s)=Ge(s)R(s)=a(s+3)/(s^2+5s+4)`

最終値定理から

`e(∞)=lim[s→0] sE(s)=0`

### (3) 傾き b のランプ入力の定常偏差

`R(s)=b/s^2` より

`E(s)=b(s+3)/{s(s^2+5s+4)}`

したがって

`e(∞)=lim[s→0] sE(s)=3b/4`

### (4) R(s) から Y(s) までとインパルス応答

`Gy(s)=Y(s)/R(s)=L(s)/{1+L(s)}`

よって

`Gy(s)=2(s+2)/{s^2+5s+4}`

部分分数分解すると

`Gy(s) = (2/3)/(s+1) + (4/3)/(s+4)`

したがって `t>0` で

`gy(t) = (2/3)e^(-t) + (4/3)e^(-4t)`

### (5) 単位ステップ入力に対する y(1)

単位ステップ応答は

`y(t)=1-(2/3)e^(-t)-(1/3)e^(-4t)`

`e^(-1)=3.679×10^-1` を用いると `e^(-4)≈0.01832` なので

`y(1) ≈ 0.7486 ≈ 0.749`

## 3. R6二次「機械・制御」問4

与式:

- `G1(s)=3/(s+2)`
- `G2(s)=5/(s^2+5s+6)=5/{(s+2)(s+3)}`

### (1) 直列結合の伝達関数

`Gseries(s)=G1(s)G2(s)`

`=15/{(s+2)^2(s+3)}`

`=15/(s^3+7s^2+16s+12)`

### (2) 単位ステップ入力時の定常値

最終値は直流ゲインに等しいため

`y1(∞)=Gseries(0)=15/12=5/4=1.25`

### (3) 並列結合にインパルス入力を加えたときの時間応答

`Gparallel(s)=G1(s)+G2(s)`

`=(3s+14)/{(s+2)(s+3)}`

`=8/(s+2)-5/(s+3)`

よって単位インパルス入力に対し

`y2(t)=8e^(-2t)-5e^(-3t)`

### (4) u(t)=2e^(-t) を加えたときの時間応答

`U(s)=2/(s+1)`

`Y2(s)=2(3s+14)/{(s+1)(s+2)(s+3)}`

部分分数分解すると

`Y2(s)=11/(s+1)-16/(s+2)+5/(s+3)`

したがって

`y2(t)=11e^(-t)-16e^(-2t)+5e^(-3t)`

### (5) 高周波極限の位相

`Gparallel(jω)` は高周波で分子が一次、分母が二次なので

`arg Gparallel(jω) → +90°-180° = -90°`

よって高周波極限の位相は `-90°`（`-π/2 rad`）。

## 4. R4二次「機械・制御」問4

開ループ伝達関数:

`L(s) = (K/s) · 100/{(s+1)(s+40)} = 100K/{s(s+1)(s+40)}`

### (1) 特性方程式

`1+L(s)=0` より

`s(s+1)(s+40)+100K=0`

すなわち

`s^3+41s^2+40s+100K=0`

### (2) 安定条件

三次式 `s^3+41s^2+40s+100K` にRouth-Hurwitz条件を適用する。

正係数条件と `41·40 > 100K` より

`0 < K < 16.4`

### (3) R(s) から E(s) までの伝達関数

`TER(s)=E(s)/R(s)=1/{1+L(s)}`

したがって

`TER(s)=s(s+1)(s+40)/{s(s+1)(s+40)+100K}`

### (4) K=2、傾き2のランプ入力の定常速度偏差

速度定数

`Kv = lim[s→0] sL(s) = 100K/40 = 2.5K`

`K=2` では `Kv=5`。傾き2のランプ入力なので

`ev = 2/Kv = 2/5 = 0.4`

### (5) K=2、r(t)=2sin t に対する定常偏差振幅 B

`K=2, ω=1` とする。

`L(j)=200/{j(j+1)(j+40)} = 200/(-41+39j)`

したがって

`TER(j)=1/{1+L(j)}=(-41+39j)/(159+39j)`

入力振幅は2なので

`B = 2|TER(j)|`

`=2 sqrt{(41^2+39^2)/(159^2+39^2)}`

`≈0.6913`

よって `B≈0.691`。

## 5. R3二次「機械・制御」問4

内側ループについて、`K/(Ts+1)` の出力を `v` とすると

`Y = [1/{s(2s+1)}] (v-sY)`

である。これを整理すると、内側帰還を含む `v→Y` は

`1/{2s(s+1)}`

となる。

### (1) 開ループ伝達関数 G(s)=Y(s)/E(s)

したがって

`G(s)=K/{2s(s+1)(Ts+1)}`

### (2) 閉ループ伝達関数 W(s)=Y(s)/R(s)

外側は単位負帰還なので

`W(s)=G(s)/{1+G(s)}`

よって

`W(s)=K/{2s(s+1)(Ts+1)+K}`

展開形は

`W(s)=K/{2Ts^3+2(T+1)s^2+2s+K}`

### (3) T=0 のときステップ応答が振動的となる K の条件

`T=0` では特性方程式は

`2s^2+2s+K=0`

複素共役極となる条件は判別式 `<0` なので

`2^2-4·2·K < 0`

したがって

`K > 1/2`

### (4) T=0, K=1、単位インパルス入力の時間応答

`W(s)=1/(2s^2+2s+1)`

`=(1/2)/{(s+1/2)^2+(1/2)^2}`

よって

`y(t)=e^(-t/2) sin(t/2)`

### (5) T=2 の安定条件

特性方程式は

`4s^3+6s^2+2s+K=0`

三次Routh-Hurwitz条件より

- `K>0`
- `6·2 > 4K`

したがって

`0 < K < 3`
