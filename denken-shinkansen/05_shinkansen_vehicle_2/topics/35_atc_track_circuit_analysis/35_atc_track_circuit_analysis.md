### R8 一次「理論」問3 — 5要素

1. `(1) ヨ`: 網目電流方程式は共有抵抗 `r` を含み、対角項が各ループ抵抗和、非対角項が `-r`。
2. `(2) ニ`: 開放端電圧は分圧より `V_ba = E R2/(R1+R2)`。
3. `(3) リ`: 線形受動回路の端子間関係として相反性を用いる。
4. `(4) ロ`: 平衡条件では対応する枝路電流関係を満たす。
5. `(5) ホ`: 指定条件から `I0 = E/(2R1)`。

判定: `5 / 5 PASS`。公式解答 `ヨ, ニ, リ, ロ, ホ` と一致。

### R7 一次「理論」問3 — 5要素

交流回路の基本は

- `Z_R = R`
- `Z_L = jωL`
- `Z_C = 1/(jωC)`

としてフェーザで扱う。

1. `(1) ヨ`: 位相差 `π/2 - φ`。
2. `(2) ト`: 面積・積に現れる係数 `sin(π/2 - φ)`。
3. `(3) ハ`: 指定条件で最大となる点は `P3`。
4. `(4) ヌ`: 最大条件 `R = ωL`。
5. `(5) リ`: 等価式の項は `1-ω^2LC`。

判定: `5 / 5 PASS`。公式解答 `ヨ, ト, ハ, ヌ, リ` と一致。

### R7 一次「理論」問4 — 5要素

1. `(1) ル`: 一方の分圧は `(1-k)E`。
2. `(2) チ`: 他方は `kE`。
3. `(3) ヌ`: 平衡条件から `Zx = {k/(1-k)} Zs`。
4. `(4) ヲ`: 回路方式は変成器ブリッジ。
5. `(5) ヨ`: 標準器の安定性に関する条件。

判定: `5 / 5 PASS`。公式解答 `ル, チ, ヌ, ヲ, ヨ` と一致。

### R6 一次「理論」問6 — 5要素

1. `(1) ヘ`: 指定接続条件で `Ix=I1`、かつ `I2≠I3`。
2. `(2) ハ`: Maxwell bridge。
3. `(3) ワ`: 漏れ経路を含む比は `Id/I2 = {1/(A+1)}(Z2/Xd)`。
4. `(4) チ`: 平衡条件から `Rx = R1R3/R2`。
5. `(5) ヲ`: `Lx = C2R1R3`。

判定: `5 / 5 PASS`。公式解答 `ヘ, ハ, ワ, チ, ヲ` と一致。

### R5 一次「理論」問4 — 5要素

1. `(1) ト`: 指定電流 `I=2 A`。
2. `(2) ヌ`: 開放端電圧 `V0=10-j10 V`。
3. `(3) ロ`: テブナン等価インピーダンス `Z0=5+j5 Ω`。
4. `(4) イ`: 負荷電流 `IL=-j A`。
5. `(5) ホ`: 負荷有効電力 `PL=5 W`。

## 教材で用いる簡略モデルの境界

教材では電験回路理論との接続のため、軌道回路を集中定数の簡略等価回路として扱う。

- レール区間の等価インピーダンスは一般に `Z_r = R_r + jX_r` と置く。
- 信号源側を必要に応じてテブナン等価 `V_th, Z_th` へ変換する。
- 列車なしでは受信器側へ電流が流れる回路を解析する。
- 列車ありでは車軸短絡を低インピーダンスの並列枝として追加し、受信端電圧・電流の低下を解析する。
- 漏れ経路を扱う場合は「仮定した漏れインピーダンス」と明示し、実設備値と混同しない。

実際のレール・軌道回路が分布定数・周波数依存等を持ち得ることを理由に、確認していないパラメータを導入しない。本Topicでは電験二種一次「理論」の回路解析へ必要な範囲に限定する。
