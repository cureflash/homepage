## 1. このテーマで電験二種は何を問うか

固定した電験二種一次「理論」5問は軌道回路そのものを出題したものではない。ここで必要なのは、軌道回路を一般の交流回路として読み替え、次の操作を確実に行えることである。

1. 回路状態を図に落とす。
2. 抵抗・リアクタンスを複素インピーダンスへまとめる。
3. 枝路追加や短絡で回路がどう変わるか判定する。
4. 網目電流法、節点法、テブナン等価回路から適切な方法を選ぶ。
5. 受信端の電圧・電流を求める。
6. 漏れ経路やインピーダンス変化が受信量へ与える影響を評価する。
7. 「信号が大きいほど安全」と単純化せず、故障時に危険側へ進まないフェイルセーフ原則を区別する。

電験で直接問われるのは一般回路理論であり、新幹線・ATCはその理論を具体化する題材として使う。

## 2. 軌道回路の基本構造

JRTT・鉄道総研の公開資料では、軌道回路はレールを電気回路の一部として利用し、列車の有無を電気的に検知する仕組みとして説明されている。

簡略化すると

`信号源 → レール回路 → 受信器`

という回路として考えられる。

列車がいないときは、送信側からの信号電流がレールを通って受信側へ届く。列車が進入すると、車輪・車軸が左右レール間を電気的に短絡するため、受信側へ現れる電圧・電流が低下する。この変化を列車検知へ利用する。

本教材では、この原理を電験の集中定数回路として簡略化する。実際の軌道回路の方式・周波数・設備定数を推測してモデルへ埋め込まない。

## 3. レールインピーダンス

交流回路では、レール区間の等価インピーダンスを一般に

`Z_r = R_r + jX_r`

と置く。

- `R_r [Ω]`: 抵抗成分
- `X_r [Ω]`: リアクタンス成分
- `j`: 虚数単位

問題でインダクタンス `L` と角周波数 `ω` が与えられ、誘導性リアクタンスとして扱う条件なら

`X_L = ωL = 2πfL`

を用いる。

コンデンサなら

`Z_C = 1/(jωC) = -j/(ωC)`

である。

### 複素数のまま計算する

交流回路では途中で絶対値だけにしてはいけない。直列回路なら

`Z_total = Z_1 + Z_2 + ...`

並列回路なら

`1/Z_p = 1/Z_1 + 1/Z_2 + ...`

で複素数のまま合成し、最後に必要な電圧・電流の大きさや位相を求める。

R7一次「理論」問3、R7問4、R5問4で必要な複素インピーダンス・フェーザ・等価回路の扱いを、この節で軌道回路へ接続する。

## 4. 列車なし時の最小等価回路

信号源をテブナン等価で

- 開放電圧 `V_th`
- 内部インピーダンス `Z_th`

とし、レール区間を `Z_r`、受信器入力インピーダンスを `Z_R` とする。

直列形の最小モデルなら信号電流は

`I = V_th/(Z_th + Z_r + Z_R)`

受信端電圧は

`V_R = IZ_R`

したがって

`V_R = V_th Z_R/(Z_th + Z_r + Z_R)`

となる。

この式から、レールインピーダンスが増えると一般に受信端電圧が低下すること、受信器入力インピーダンスも受信レベルへ影響することが分かる。

ただし、これは教材用の簡略回路である。実際の軌道回路の定数や構成がこの一式で完全に表されるとは扱わない。

## 5. テブナン等価回路を使う理由

R5一次「理論」問4型では、複雑な送信側回路を受信端から見て

`V_th` と `Z_th`

の二つに縮約できる。

負荷 `Z_L` を接続したとき

`I_L = V_th/(Z_th+Z_L)`

`V_L = I_L Z_L`

である。

軌道回路では、レール区間と送信回路を受信点から見た等価電源へまとめると、「車軸短絡という新しい枝路を追加したとき何が変わるか」を整理しやすい。

### 解法手順

1. 負荷を外して開放端電圧 `V_th` を求める。
2. 独立電源を零にして端子から見た `Z_th` を求める。
3. 受信器や短絡枝を接続する。
4. `I=V_th/(Z_th+Z_L)` で電流を求める。
5. 必要な端子電圧を戻す。

## 6. 車軸短絡を並列枝として読む

列車進入時は、車輪・車軸による左右レール間の短絡を、受信側へ並列に入る低インピーダンス `Z_s` として簡略化する。

受信器 `Z_R` と車軸短絡 `Z_s` の並列合成は

`Z_p = Z_R Z_s/(Z_R+Z_s)`

である。

`|Z_s| << |Z_R|`

なら

`Z_p ≈ Z_s`

となり、受信端から見た負荷インピーダンスは大きく低下する。受信端電圧は

`V_p = V_th Z_p/(Z_th+Z_r+Z_p)`

となるため、列車なし時より低下する。

重要なのは「短絡だから電流がゼロ」ではないことである。短絡枝には大きな電流が流れ得る一方、受信器へ現れる電圧・電流が低下する。電流の流れ先が変わると理解する。

## 7. 網目電流法・節点法で短絡を解く

R8一次「理論」問3では、共有抵抗を持つブリッジ状回路を網目電流で解く。

二つの網目電流を `I_1`, `I_2`、共有インピーダンスを `Z_c` とすると、共有枝の電圧降下は

`Z_c(I_1-I_2)`

となる。そのため連立方程式の非対角項には `-Z_c` が現れる。

軌道回路でも、車軸短絡や漏れ経路が新しい枝路として加わると、単純な直列回路ではなくなる。このとき

- 枝が少ない: 直並列合成
- ループが明瞭: 網目電流法
- 接続点が明瞭: 節点電位法
- 受信端だけ知りたい: テブナン等価

のように解法を選ぶ。

## 8. 受信レベルを何として扱うか

本Topicでは受信レベルを、受信端に現れる電圧又は電流の大きさとして扱う。

例えば

`L_V = |V_R|`

又は、教材用に列車なし時を基準とする相対値

`k_V = |V_R,condition| / |V_R,no-train|`

を定義できる。

この `k_V` は本教材の比較指標であり、実ATC設備の判定規格ではない。実設備の受信しきい値は一次資料で確認していないため数値化しない。

### 電圧と電流を混同しない

受信器入力インピーダンスが `Z_R` なら

`I_R = V_R/Z_R`

である。問題が「受信電圧」を求めるのか「受信電流」を求めるのかを先に確認する。

## 9. 信号電流とフェーザ

交流信号では

`I = V/Z`

をフェーザで計算する。

`Z=R+jX`

なら

`|Z| = sqrt(R^2+X^2)`

`angle Z = atan(X/R)`

である。

電流の大きさは

`|I|=|V|/|Z|`

位相は

`angle I = angle V - angle Z`

となる。

R7一次「理論」問3で要求される位相関係を、レール回路の信号電流へ一般化して使う。ただし、ATC固有の搬送周波数や変調方式はTopic 36で扱う。

## 10. 漏れ経路と回路条件

実際の回路では、目的の経路以外へ電流が流れる経路が存在すると受信量が変わる。教材では仮定した漏れインピーダンス `Z_leak` を並列枝として追加する。

受信器 `Z_R` と漏れ経路 `Z_leak` の合成は

`Z_p = Z_R Z_leak/(Z_R+Z_leak)`

となる。

`|Z_leak|` が小さくなるほど合成インピーダンスは下がり、電流分流が大きくなる。R6一次「理論」問6で扱う浮遊容量・漏れ電流によるブリッジ誤差は、「本来ないはずの枝路が測定結果を変える」という点で同じ回路解析技能を要求する。

ここで漏れインピーダンスの実設備値は置かない。問題では仮定値として明示する。

## 11. ブリッジ平衡から学ぶ回路条件

R7一次「理論」問4、R6問6では、ブリッジの平衡条件から未知インピーダンスを求める。

一般の四辺ブリッジで、平衡時に検出枝電流が零となる条件は、接続の定義に応じて対辺の積が等しい形

`Z_1 Z_3 = Z_2 Z_4`

へ整理できる。

この式を軌道回路の実回路構成式として使うわけではない。教材上の役割は、回路条件がわずかに変わると検出量が変化すること、未知インピーダンスを既知量から逆算できることを理解する点にある。

## 12. フェイルセーフ

鉄道総研の公開資料では、信号システムは故障や誤出力を検出し、故障時にも安全側状態を維持する考え方を重視している。

本Topicで押さえるべき区別は次である。

- 回路解析: ある故障・短絡・断線・漏れを仮定したとき電圧・電流がどう変わるか。
- フェイルセーフ: その故障が起きても危険側の制御を許さないようシステムを設計する原則。

「受信電圧が下がれば必ず安全」「どの故障でも列車あり判定になる」など、未確認の実装固有動作へ一般化しない。教材では、危険側出力を避ける設計原則までを固定する。

## 13. 本試験型の解法アルゴリズム

軌道回路題材を一般回路問題として解く手順は次の通り。

1. 列車なし／車軸短絡あり／漏れあり等の回路状態を確定する。
2. 問題文の実数・複素数表現と単位をそろえる。
3. 各素子を `Z=R+jX` へ変換する。
4. 直並列合成で解けるか確認する。
5. 解けなければ網目法・節点法・テブナン等価から最短の方法を選ぶ。
6. 受信端電圧・受信電流・枝路電流を複素数で求める。
7. 必要なら絶対値・位相へ変換する。
8. 列車なし状態との比を取り、増減方向を確認する。
9. 短絡なのに受信電圧が増える等、物理的に不自然な結果がないか検算する。
10. 実設備しきい値を問題文にないまま導入しない。

## 14. 典型ミス

- `R+jX` の虚数部を無視して抵抗だけで計算する。
- 並列合成を直列和にしてしまう。
- 短絡枝の電流と受信器電流を同じと考える。
- テブナン等価で独立電圧源を零にするとき短絡、独立電流源を零にするとき開放という操作を逆にする。
- フェーザの位相を途中で捨てる。
- 受信電圧低下と全回路電流低下を同一視する。
- 仮定した短絡抵抗や漏れインピーダンスを実設備値として記述する。
- Topic 36の搬送周波数・変調方式を本Topicへ持ち込む。

## 15. 3段階例題

以下の数値は回路計算訓練用の仮定値であり、新幹線実設備値ではない。

### 例題1 基礎 — 列車なし時の受信電圧

条件:

- `V_th = 12 V`
- `Z_th = 2 Ω`
- `Z_r = 4 Ω`
- `Z_R = 18 Ω`

求めるもの: 信号電流 `I` と受信端電圧 `V_R`。

合成抵抗は

`Z_total = 2+4+18 = 24 Ω`

よって

`I = 12/24 = 0.500 A`

`V_R = 0.500×18 = 9.00 V`

検算:

`2I + 4I + 18I = 1+2+9 = 12 V`

で電源電圧と一致する。

### 例題2 本試験標準 — 車軸短絡で受信量がどう変わるか

条件:

- `V_th = 10 V`
- `Z_th = 2 Ω`
- `Z_r = 4 Ω`
- `Z_R = 20 Ω`
- 車軸短絡の仮定値 `Z_s = 0.5 Ω`

列車なし:

`I_0 = 10/(2+4+20) = 0.3846 A`

`V_R0 = 0.3846×20 = 7.692 V`

列車ありでは

`Z_p = 20×0.5/(20+0.5) = 0.4878 Ω`

したがって

`I = 10/(2+4+0.4878) = 1.541 A`

受信端電圧は

`V_R = 1.541×0.4878 = 0.7519 V`

受信器電流は

`I_R = 0.7519/20 = 0.03759 A`

車軸短絡枝電流は

`I_s = 0.7519/0.5 = 1.504 A`

相対受信電圧は

`k_V = 0.7519/7.692 = 0.09775`

すなわち列車なし時の約 `9.78 %` まで低下する。

重要: 全回路電流は `0.3846 A → 1.541 A` と増えているのに、受信器電流は大きく低下している。短絡枝へ電流が分流するためである。

### 例題3 複合・ひっかけ — 複素レールインピーダンスと漏れ・短絡

条件:

- `V_th = 20∠0° V`
- `Z_th = 1+j1 Ω`
- `Z_r = 3+j4 Ω`
- `Z_R = 20 Ω`
- 漏れ経路の仮定値 `Z_leak = 100 Ω`

まず列車なし・漏れありを考える。

受信器と漏れ経路の並列合成は

`Z_p = 20 || 100 = 16.667 Ω`

直列側は

`Z_th+Z_r = 4+j5 Ω`

したがって

`I = 20/(20.667+j5) = 0.9142-j0.2212 A`

`|I| = 0.9406 A`

受信端電圧は

`V_R = I×16.667 = 15.237-j3.686 V`

`|V_R| = 15.677 V`

次に車軸短絡の仮定値 `Z_s=1 Ω` を追加する。

`Z_p' = 20 || 100 || 1 = 0.9434 Ω`

`I' = 20/(4+j5+0.9434) = 1.9999-j2.0228 A`

`|I'| = 2.844 A`

受信端電圧は

`V_R' = I'×0.9434 = 1.8867-j1.9083 V`

`|V_R'| = 2.683 V`

受信電圧比は

`2.683/15.677 = 0.1712`

である。

ひっかけは、短絡追加で全電流の大きさが増えている一方、受信端電圧は低下する点である。また、`4+j5` を単に `9 Ω` として計算してはいけない。

## 17. 新幹線・ATCへの接続

JRTT資料で確認できる範囲では、ATCは軌道回路を利用した情報伝送と列車検知に関係する。本Topicではそのうち、レールを回路として扱い、車軸短絡によって受信側の電気量が変化する部分だけを扱う。

電験二種の一般回路理論へ戻すと、見るべき量は

- 電源電圧
- 等価内部インピーダンス
- レール区間の等価インピーダンス
- 受信負荷
- 短絡枝
- 漏れ枝
- 受信端電圧・電流

である。

この構造を理解すれば、鉄道固有値を暗記せず、与えられた回路条件から一般式で解析できる。

## 18. 公式・解法まとめ

- `Z = R+jX`
- `Z_L = jωL`
- `Z_C = 1/(jωC)`
- 直列: `Z = ΣZ_k`
- 並列: `1/Z = Σ(1/Z_k)`
- `I = V/Z`
- テブナン負荷電流: `I_L = V_th/(Z_th+Z_L)`
- 受信電圧: `V_R = I_R Z_R`
- 二並列: `Z_p=Z_1Z_2/(Z_1+Z_2)`
- 相対受信電圧: `k_V=|V_R,condition|/|V_R,no-train|`（教材用比較指標）
- ブリッジ平衡: 回路定義に従い対辺インピーダンス積の関係を立てる

解法は「状態決定 → 複素インピーダンス化 → 回路縮約 → 電圧・電流計算 → 絶対値・位相 → 列車なし状態との比較 → 物理検算」の順で進める。
