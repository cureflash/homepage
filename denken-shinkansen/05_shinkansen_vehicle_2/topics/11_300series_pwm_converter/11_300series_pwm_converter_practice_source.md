# 一次試験型

## 問1 正弦波PWMの生成原理

正弦波PWMについて最も適切なものを選べ。

1. 正弦波信号波と三角搬送波を比較し、その大小関係でスイッチング状態を決める。線形変調域では基本波電圧は変調率にほぼ比例する。
2. 直流中間電圧を三角波に変換し、その実効値をそのまま交流基本波とする。
3. 搬送波周波数を低くするほど、基本波周波数も必ず同じ比率で低下する。
4. 変調率は常に `Ed/VLL1` と定義され、単相・三相で式は変わらない。
5. PWMパルス列には基本波しか含まれず、高調波は存在しない。

### 正答

1

### 完全解説

本テーマの正弦波PWMでは、正弦波信号波と三角搬送波を比較してスイッチング状態を決める。変調率を

```text
k = 信号波振幅 / 搬送波振幅
```

と定義する形式では、線形変調域で基本波電圧は `k` にほぼ比例する。PWMパルス列そのものは基本波と高調波を含むため、基本波だけとみなしてはならない。正答は1。

## 問2 三相PWMの基本波線間電圧

直流中間電圧 `Ed=800 V`、変調率 `k=0.75` の三相PWM電圧形変換器を考える。H22型の定義

```text
VLL1 = √3 Ed k / (2√2)
```

を使うとき、線間基本波実効値 `VLL1` として最も近いものを選べ。

1. `260 V`
2. `326 V`
3. `367 V`
4. `424 V`
5. `600 V`

### 正答

3

### 完全解説

```text
VLL1 = √3×800×0.75/(2√2)
     = 367.4 V
```

よって正答は3。`Ed×k=600 V` をそのまま線間基本波実効値としてはいけない。相値・線間値と実効値換算を問題文の式に従って区別する。

## 問3 必要直流中間電圧

三相PWM変換器で `VLL1=400 V` を生成したい。H22型の式を使い、線形変調域で変調率を `k<=0.90` とする。必要な直流中間電圧 `Ed` の最小値として最も近いものを選べ。

1. `566 V`
2. `628 V`
3. `693 V`
4. `726 V`
5. `800 V`

### 正答

4

### 完全解説

直流中間電圧は

```text
Ed = 2√2 VLL1/(√3 k)
```

である。必要 `Ed` を最小にするには許容最大変調率 `k=0.90` を使う。

```text
Ed = 2√2×400/(√3×0.90)
   = 725.8 V
```

よって約 `726 V`、正答は4。変調率上限を無視して `Ed` を小さくしてはいけない。

## 問4 連系リアクトルを含むフェーザ

単相系で電源基本波実効値 `Vs=230 V`、連系リアクタンス `X=0.60 Ω`、基本波電流 `I=80 A` とする。電流は `Vs` と同相で、規約を

```text
Vconv = Vs + jXI
```

とする。`|Vconv|` と `Vs` に対する位相角 `δ` の組合せとして最も近いものを選べ。

1. `182 V`, `11.8°遅れ`
2. `230 V`, `0°`
3. `235 V`, `11.8°進み`
4. `278 V`, `45.0°進み`
5. `278 V`, `11.8°遅れ`

### 正答

3

### 完全解説

リアクトル電圧は

```text
XI = 0.60×80 = 48 V
```

で、`Vs` と直交する。したがって

```text
|Vconv| = sqrt(230^2+48^2)
        = 235.0 V

δ = arctan(48/230)
  = 11.8°
```

`+jXI` の規約なので `Vconv` は `Vs` より進む。正答は3。電圧を `230+48=278 V` とスカラー加算しない。

## 問5 力率1と直流中間電圧制御

単相交流側で `Vs=200 V`、取り込む有効電力 `P=12.0 kW` とし、基本波力率を1に制御する。基本波電流 `I`、無効電力 `Q`、直流中間電圧制御の説明の組合せとして正しいものを選べ。

1. `I=60 A`, `Q=0`, 直流中間電圧の偏差に応じ交流側有効電力を調整する。
2. `I=60 A`, `Q=12 kvar`, 無効電力だけで直流中間電圧を維持する。
3. `I=100 A`, `Q=0`, 有効電力は一定で直流中間電圧と無関係である。
4. `I=60 A`, `Q=0`, 基本波電流は電源電圧と90°ずらす。
5. `I=30 A`, `Q=6 kvar`, 変調率だけを変えれば電力収支は不要である。

### 正答

1

### 完全解説

力率1では基本波電流と電源電圧は同相である。単相なので

```text
P = Vs I
I = 12000/200
  = 60 A
```

また `φ=0` だから

```text
Q = Vs I sinφ = 0
```

直流中間電圧はコンデンサの電力収支で変化するため、電圧偏差に応じて交流側から取り込む有効電力を調整して目標値へ戻す。正答は1。

## 問6 方形波の基本波と高調波実効値

振幅 `±120 A` の対称方形波電流を考える。方形波全体の実効値を `IL=120 A` とし、基本波実効値を

```text
I1 = (2√2/π) IL
```

で求める。高調波合成実効値を

```text
IH = sqrt(IL^2-I1^2)
```

とすると、`I1` と `IH` の組合せとして最も近いものを選べ。

1. `I1=76.4 A`, `IH=91.7 A`
2. `I1=108.0 A`, `IH=12.0 A`
3. `I1=108.0 A`, `IH=52.2 A`
4. `I1=120.0 A`, `IH=0 A`
5. `I1=169.7 A`, `IH=120.0 A`

### 正答

3

### 完全解説

```text
I1 = (2√2/π)×120
   = 108.0 A
```

高調波成分は基本波と直交する周波数成分なので、実効値は単純差ではなく二乗和から求める。

```text
IH = sqrt(120^2-108.0^2)
   = 52.2 A
```

よって正答は3。`120-108=12 A` としてはいけない。

## 問7 スイッチング周波数と損失

1素子の1回当たりターンオン・ターンオフ損失の合計を `Eon+Eoff=3.0 mJ`、スイッチング周波数を `fs=2.5 kHz` とする。平均スイッチング損失 `Psw` と、他条件一定で `fs` を2倍にしたときの `Psw` の組合せとして正しいものを選べ。

1. `3.0 W`, `3.0 W`
2. `7.5 W`, `3.75 W`
3. `7.5 W`, `7.5 W`
4. `7.5 W`, `15.0 W`
5. `15.0 W`, `30.0 W`

### 正答

4

### 完全解説

```text
Psw = fs(Eon+Eoff)
    = 2.5×10^3×3.0×10^-3
    = 7.5 W
```

1回当たり損失が一定なら `Psw` は `fs` に比例する。したがって `fs` を2倍にすると

```text
Psw = 15.0 W
```

となる。正答は4。周期が短くなるほど周波数は高くなる。

## 問8 半導体損失とソフトスイッチング

PWM変換器の損失について最も適切なものを選べ。

1. オン損失はターンオン瞬間だけに発生し、導通中には発生しない。
2. オフ状態では漏れ電流が必ず0なので、オフ損失は考えなくてよい。
3. 1回当たりスイッチング損失が一定なら、スイッチング周期を短くするほど平均スイッチング損失は小さくなる。
4. ソフトスイッチングは切替時の電圧・電流の重なりを小さくし、1回当たりのスイッチング損失低減に使われる。
5. スイッチング損失は直流中間電圧とは無関係なので、電圧・電流条件を確認する必要はない。

### 正答

4

### 完全解説

導通中はオン電圧降下によるオン損失、オフ中は漏れ電流によるオフ損失、切替中は電圧と電流が同時に存在することによるスイッチング損失が生じる。ソフトスイッチングは切替時の重なりを小さくし、1回当たりの切替損失を低減する。正答は4。

## 問9 変調率と三相基本波電圧

教材用仮定値として、三相PWM電圧形変換器の直流中間電圧を `Ed=700 V`、変調率を `k=0.85` とする。H22型の式

```text
VLL1 = √3 Ed k/(2√2)
```

を用いて次を求めよ。

1. 線間基本波実効値 `VLL1`
2. 同じ `Ed=700 V` で `VLL1=350 V` とするために必要な変調率 `k`
3. その `k` が `0<=k<=1` の線形変調域に入るか判定せよ。

### 完全解説

(1)

```text
VLL1 = √3×700×0.85/(2√2)
     = 364.4 V
```

(2) 式を `k` について解く。

```text
k = 2√2 VLL1/(√3 Ed)
  = 2√2×350/(√3×700)
  = 0.8165
```

(3) `0.8165<1` なので、指定した定義の線形変調域内である。

この問題では、三相線間基本波実効値の係数を単相式と混同しないこと、変調率を逆算した後に上限を検算することが採点点である。

## 問10 力率1運転時の交流端子電圧と必要直流中間電圧

単相交流側で、電源基本波実効値 `Vs=240 V`、交流側から取り込む有効電力 `P=18.0 kW`、連系リアクタンス `X=0.80 Ω` とする。基本波力率は1、電圧規約は

```text
Vconv = Vs + jXI
```

とする。PWM基本波式は

```text
Vconv = Ed K/√2
```

で、使用可能な最大変調率を `Kmax=0.95` とする。次を求めよ。

1. 基本波電流 `I`
2. リアクトル電圧 `XI`
3. 必要な `|Vconv|` と位相角 `δ`
4. 必要な直流中間電圧 `Ed` の最小値

### 完全解説

力率1なので単相有効電力は

```text
P = Vs I
```

である。

(1)

```text
I = P/Vs
  = 18000/240
  = 75.0 A
```

(2)

```text
XI = 0.80×75.0
   = 60.0 V
```

(3) `Vs` と `jXI` は直交するため、スカラー加算しない。

```text
|Vconv| = sqrt(240^2+60^2)
        = 247.4 V

δ = arctan(60/240)
  = 14.0°
```

(4) 必要 `Ed` を最小にするには最大許容変調率を使う。

```text
Ed = √2 |Vconv|/Kmax
   = √2×247.4/0.95
   = 368.3 V
```

したがって最小値は約 `368 V`。解法順序は `P→I→XI→Vconv→Ed` とする。力率1条件、フェーザ加算、変調率上限の三つを同時に確認する。

## 問11 高調波補償電流

振幅 `±150 A` の対称方形波を負荷電流 `iL` とする。全実効値を `IL=150 A`、基本波実効値を

```text
I1 = (2√2/π) IL
```

とする。負荷電流を

```text
iL = i1 + iH
```

と分解し、高調波成分を能動的に打ち消して電源電流を基本波だけにする。

1. `I1` を求めよ。
2. 高調波合成実効値 `IH` を求めよ。
3. 補償電流 `ic` と高調波電流 `iH` の関係を示せ。
4. 補償後の電源電流を示せ。
5. 高調波が機器へ与える代表的な影響を一つ述べよ。

### 完全解説

(1)

```text
I1 = (2√2/π)×150
   = 135.0 A
```

(2)

```text
IH = sqrt(IL^2-I1^2)
   = sqrt(150^2-135.0^2)
   = 65.3 A
```

(3) 高調波だけを打ち消すので

```text
ic = -iH
```

である。実効値の大きさは `Ic=IH=65.3 A`。

(4)

```text
is = iL + ic
   = i1 + iH - iH
   = i1
```

となり、電源電流は基本波だけになる。

(5) 代表例として、高調波電流による機器・配線の追加損失や発熱を挙げられる。

基本波と高調波の実効値は単純差で分離せず、二乗和で扱うことが重要である。

## 問12 スイッチング損失と総変換損失

あるスイッチ1素子について、ターンオン損失 `Eon=1.0 mJ`、ターンオフ損失 `Eoff=1.5 mJ`、スイッチング周期 `Ts=250 μs` とする。また、この素子の平均オン損失が `30.0 W`、平均オフ損失が `0.50 W` と既に求められているものとする。

1. スイッチング周波数 `fs` を求めよ。
2. 平均スイッチング損失 `Psw` を求めよ。
3. 三種類の損失の合計を求めよ。
4. `Ts` を半分にし、1回当たりの `Eon`,`Eoff` が同じなら `Psw` はどうなるか。
5. ソフトスイッチングがスイッチング損失を下げる理由を述べよ。

### 完全解説

(1)

```text
fs = 1/Ts
   = 1/(250×10^-6)
   = 4.00×10^3 Hz
   = 4.00 kHz
```

(2)

```text
Psw = fs(Eon+Eoff)
    = 4.00×10^3×(1.0+1.5)×10^-3
    = 10.0 W
```

(3)

```text
Ploss = 30.0+0.50+10.0
      = 40.5 W
```

(4) `Ts` を半分にすると `fs` は2倍になる。1回当たり損失が一定なら

```text
Psw = 20.0 W
```

となる。

(5) ソフトスイッチングは切替時に電圧と電流が同時に大きく存在する時間を減らし、1回当たりのターンオン・ターンオフ損失を小さくするため、平均スイッチング損失を低減できる。

オフ損失は漏れ電流、オン損失は導通時の電圧降下、スイッチング損失は切替過程に対応する。三者を混同しない。
