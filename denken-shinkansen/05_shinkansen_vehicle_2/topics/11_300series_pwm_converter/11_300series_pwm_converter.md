# 解説本文

## 1. このテーマで電験二種は何を問うか

PWMコンバータの問題では、「PWMなら交流を直流にできる」という説明だけでは不足する。一次試験ではPWM波形、変調率、基本波電圧、損失、直流電圧制御、力率制御を選択肢へ落とせること、二次試験では交流側リアクトルを含むフェーザ関係、高調波分離、実効値、直流中間電圧条件を途中式付きで導けることが必要である。

本テーマの解法は次の順に固定する。

1. PWM波形を基本波と高調波へ分ける。
2. 問題文のPWM方式に対応する「変調率―基本波電圧」の式を選ぶ。
3. 交流側リアクトルの電圧降下をフェーザで加える。
4. 電源電圧と基本波電流の位相から有効・無効電力を判定する。
5. 直流中間電圧が必要な交流側基本波電圧を生成できるか確認する。
6. デバイス損失を導通損失とスイッチング損失に分ける。

## 2. 最小回路と各部の役割

試験で必要な最小モデルは「交流電源―連系リアクトル―PWMブリッジ―直流中間コンデンサ」である。

- 交流電源 `Vs`: 交流側の基本波電圧。
- 連系リアクトル `X=ωL`: 電源とPWMブリッジの基本波電圧差を受け、交流電流の変化を制限する。
- PWMブリッジ: スイッチングによって交流端子電圧をパルス列として作る。
- 直流中間コンデンサ: 直流中間電圧 `Ed` を保持し、瞬時の電力差をエネルギーとして吸収する。

コンデンサの蓄積エネルギーは

`Wdc = (1/2) C Ed^2`

である。したがって、直流側負荷が消費する電力と交流側から入る有効電力が一致しないと `Ed` は変化する。直流電圧制御は、この電力差が長時間残らないよう交流側の有効電力を調整して `Ed` を目標値へ戻す制御として理解する。

## 3. 正弦波PWMとスイッチング

正弦波PWMでは、低周波の正弦波信号波と高周波の三角搬送波を比較してスイッチ状態を決める。信号波が搬送波より大きい区間と小さい区間で出力極性を切り替えると、出力は多数のパルスからなる電圧波形になる。

重要なのは、パルス列そのものを「正弦波」とみなさないことである。パルス列はフーリエ成分として見ると、必要な周波数の基本波と、それ以外の高調波に分けられる。線形変調域では信号波振幅を大きくすると基本波振幅も比例して増える。

変調率を

`k = 信号波振幅 / 搬送波振幅`

と定義する問題では、通常 `0 <= k <= 1` の線形変調域をまず確認する。式の係数は単相／三相、線間値／相値、PWM方式、問題文での `Ed` の定義により変わるため、別形式の式を混用しない。

## 4. 変調率と基本波電圧

H22一次型の三相PWM電圧形自励変換器では、直流中間電圧を `Ed`、変調率を `k` とすると、各相の基本波相電圧実効値は

`Vph1 = Ed k / (2√2)`

したがって線間基本波実効値は

`VLL1 = √3 Ed k / (2√2)`

となる。よって逆算は

`k = 2√2 VLL1 / (√3 Ed)`

である。

一方、H24二次型の単相PWMで問題文が

`Vv = Ed K / √2`

を使う定義なら、その式をそのまま使う。三相線間式の `√3/2` を単相問題へ持ち込まない。

## 5. 基本波と高調波を分ける

ひずみ波電流を

`iL(t) = i1(t) + iH(t)`

と分ける。`i1` は基本波、`iH` は基本波以外の高調波成分の合成である。基本波と各高調波は一周期平均で直交するため、実効値は

`IL^2 = I1^2 + IH^2`

と分けられる。

高調波補償を考える問題では、補償電流を

`ic(t) = -iH(t)`

とすれば、電源側電流は

`is(t) = iL(t) + ic(t) = i1(t)`

となる。これはR5二次型の基本的な考え方である。

振幅が `±IL` の対称方形波を例にすると、その基本波実効値は

`I1 = (2√2/π) IL`

であり、高調波合成実効値は

`IH = sqrt(IL^2 - I1^2)`

`= sqrt(1 - 8/π^2) IL ≈ 0.435 IL`

となる。高調波は機器の追加損失、発熱、電圧・電流波形のひずみ等の原因になるため、基本波だけで実効値を評価しない。

## 6. 交流側リアクトルのフェーザ関係

抵抗を無視し、問題文の電流方向・電圧極性を固定すると、リアクトル電圧は `jXI` となる。H24型の採用規約では

`Vconv = Vs + j X I`

を使う。電流方向を逆に定義すれば符号も逆転するため、式だけを暗記せず問題図の矢印を確認する。

力率1で `I` が `Vs` と同相なら、`jXI` は `Vs` に対して90度進むので

`|Vconv| = sqrt(Vs^2 + (XI)^2)`

`tan δ = XI / Vs`

となる。必要な交流側基本波電圧の大きさと位相を求め、次にPWMの基本波式から必要な直流中間電圧または変調率を逆算する。

## 7. 有効電力・無効電力と力率1制御

交流電源電圧を位相基準に取る。基本波電流のうち電源電圧と同相の成分を `IP`、90度成分を `IQ` とすれば、単相では符号規約を別として大きさは

`P = Vs IP`

`|Q| = Vs |IQ|`

三相平衡系では線間電圧 `VLL`、線電流 `I` を使い

`P = √3 VLL I cosφ`

`Q = √3 VLL I sinφ`

となる。

力率1では `φ=0` なので、基本波電流を電源電圧と同位相にする。したがって同じ有効電力を送るなら、無効電流を増やさないことが電流実効値の抑制につながる。

H22型では、直流電圧を維持するために交流側の有効電力を調整し、そのためにPWM変換器の交流端子基本波電圧の位相を電源電圧に対して適切にずらす。位相の進み・遅れは、問題図の電流方向と「交流側から直流側へ有効電力を取り込む」という条件から判定する。

## 8. 直流中間電圧条件

PWMブリッジが必要な交流側基本波電圧を作るには、直流中間電圧 `Ed` が十分でなければならない。

単相のH24型なら

`Vconv = Ed K / √2`

より

`Ed = √2 Vconv / K`

三相のH22型なら

`VLL1 = √3 Ed k / (2√2)`

より

`Ed = 2√2 VLL1 / (√3 k)`

である。`k<=1` または問題文で指定された変調率上限を満たすかを確認する。必要な `Ed` が不足すると、指定された基本波電圧を線形変調の範囲では生成できない。

R1二次型では「交流電源電圧にリアクトル電圧をフェーザ加算して必要な変換器交流端子電圧を求め、その基本波を生成できる最小直流中間電圧へ換算する」という2段階が重要である。

## 9. スイッチング損失と変換損失

実デバイスは理想スイッチではない。損失は少なくとも次の三つに分けて考える。

1. オン損失: オン状態でも電圧降下があるため、概略 `Pcond ≈ Von Ion` に比例する。実際の平均損失では導通率・電流波形を反映する。
2. オフ損失: オフ状態でも漏れ電流があるため、概略 `Poff ≈ Voff Ileak` が生じる。
3. スイッチング損失: ターンオン・ターンオフ中に電圧と電流が同時に存在するためエネルギー損失が生じる。

1回当たりのターンオン・ターンオフ損失を `Eon`、`Eoff`、スイッチング周波数を `fs` とすれば、単純化した平均スイッチング損失は

`Psw = fs (Eon + Eoff)`

である。周期 `Ts=1/fs` が短いほど、同じ1回当たり損失なら単位時間当たりのスイッチング回数が増え `Psw` は増える。ソフトスイッチングは切替時の電圧・電流重なりを小さくして1回当たりのスイッチング損失を低減する考え方である。

## 10. 問題を見たときの解法手順

### PWM・基本波電圧型

1. 単相か三相かを確認する。
2. `Ed`、変調率、求める電圧が相値か線間値かを確認する。
3. 問題文に対応する基本波式を選ぶ。
4. 変調率上限を確認する。
5. 電圧値の種別を混同していないか検算する。

### フェーザ・力率制御型

1. 電圧・電流の基準方向を図から読む。
2. 電源電圧を実軸基準に取る。
3. リアクトル電圧 `jXI` の向きを決める。
4. `Vconv` の大きさと位相を求める。
5. PWM基本波式から `Ed` または変調率を求める。
6. 力率条件・電圧制約・電流制約を検算する。

### 高調波型

1. `iL=i1+iH` に分解する。
2. 必要ならフーリエ係数から基本波実効値を求める。
3. `IH=sqrt(IL^2-I1^2)` で高調波合成実効値を求める。
4. 補償電流は `ic=-iH` とする。
5. 補償後の電源電流が基本波だけになっているか確認する。

### 損失型

1. 導通中・オフ中・切替中のどの損失か分類する。
2. スイッチング周期なら `fs=1/Ts` に直す。
3. `Psw=fs(Eon+Eoff)` を使う。
4. 周波数を変えたときの比例関係を確認する。

## 11. 3段階例題

### 11.1 基礎例題 — 変調率から三相線間基本波電圧を求める

直流中間電圧 `Ed=600 V`、変調率 `k=0.80` の三相PWM変換器を考える。H22型の定義を使うとき、線間基本波実効値 `VLL1` を求める。

使用式は

`VLL1 = √3 Ed k / (2√2)`

である。したがって

`VLL1 = √3 × 600 × 0.80 / (2√2)`

`= 293.9 V`

となる。`600×0.80` をそのまま交流実効値にしないこと、相電圧式と線間電圧式を混同しないことが要点である。

### 11.2 本試験標準例題 — 力率1時の交流端子電圧と必要直流中間電圧

単相系で、電源基本波実効値 `Vs=200 V`、連系リアクタンス `X=0.80 Ω`、入力基本波電流 `I=100 A` とする。電流は電源電圧と同相、H24型の規約 `Vconv=Vs+jXI`、PWM基本波式 `Vconv=Ed K/√2`、変調率 `K=0.90` を使う。必要な `|Vconv|`、位相角 `δ`、直流中間電圧 `Ed` を求める。

リアクトル電圧は

`XI = 0.80 × 100 = 80 V`

よって

`|Vconv| = sqrt(200^2 + 80^2) = 215.4 V`

`δ = arctan(80/200) = 21.8°`

である。さらに

`Ed = √2 |Vconv| / K`

`= √2 × 215.4 / 0.90`

`= 338.5 V`

となる。先にフェーザで必要交流端子電圧を求め、その後PWM式へ入れる順序を崩さない。

### 11.3 複合例題 — 方形波の高調波補償とスイッチング損失

振幅 `±100 A` の対称方形波電流を負荷電流とする。基本波以外を補償電流で打ち消すとき、基本波実効値 `I1` と補償電流の実効値 `Ic` を求める。さらに、あるスイッチ1素子について `Eon+Eoff=4.0 mJ`、`fs=1.0 kHz` とするとき平均スイッチング損失を求める。

方形波の基本波実効値は

`I1 = (2√2/π) × 100 = 90.0 A`

高調波合成実効値は

`IH = sqrt(100^2 - 90.0^2) = 43.5 A`

である。補償電流は波形として `ic=-iH` なので、実効値の大きさは

`Ic = IH = 43.5 A`

となる。

スイッチング損失は

`Psw = fs(Eon+Eoff)`

`= 1.0×10^3 × 4.0×10^-3`

`= 4.0 W`

である。スイッチング周波数を2倍にし、1回当たりの損失が同じなら `Psw` も2倍になる。高調波実効値を単純な差 `IL-I1` で求めないこと、mJをJへ換算することがひっかけである。

## 12. SPEC指定4可視化の計算条件

実車値と誤認しないよう、以下は教材用の正規化値・仮定値とする。300系の実車直流中間電圧、キャリア周波数、変調率、素子損失として扱わない。

### 12.1 PWM波形

- 基本波周波数: `f1=50 Hz`（教材用）
- 搬送波周波数: `fc=1000 Hz`（教材用）
- 正規化搬送波振幅: `1`
- 変調率: `k=0.80`
- 信号波: `m(t)=0.80 sin(2πf1 t)`
- 比較則: `m(t)>=carrier(t)` で上側状態、それ以外で下側状態

目的は「信号波と三角搬送波の比較からパルス列ができる」ことの可視化であり、実車スイッチング周波数を示すものではない。

### 12.2 基本波・高調波

- 方形波振幅: `IL=1 pu`
- 基本波実効値: `I1=2√2/π ≈0.900 pu`
- 高調波合成実効値: `IH=sqrt(1-8/π^2)≈0.435 pu`

基本波と原波形を重ね、残差を高調波成分として示す。

### 12.3 変調条件―基本波電圧

三相H22型の式

`VLL1/Ed = √3 k/(2√2)`

を使い、`k=0,0.1,...,1.0` で正規化基本波電圧を計算する。線形変調域で比例関係になることだけを示す。

### 12.4 入力電流波形

R5型の基本波・高調波分離を可視化するため、教材用に

`iL(t)=i1(t)+iH(t)`

`ic(t)=-iH(t)`

`is(t)=i1(t)`

を同一時間軸へ描く。具体値は正規化し、補償前のひずみ波と補償後の基本波電流の違いを示す。

## 15. 頻出ミス・まとめ

- PWMパルス列と基本波を同一視しない。
- 単相式と三相線間式を混用しない。
