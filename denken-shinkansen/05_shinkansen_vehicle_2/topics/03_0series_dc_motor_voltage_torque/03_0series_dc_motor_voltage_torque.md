# 解説本文

## 1. このテーマで電験は何を問うか

直流電動機では、電圧・電流・磁束・回転速度・トルクを別々に暗記するのではなく、電機子電圧方程式を中心に一つの動作点として結び付けることが重要である。

一次試験では、電磁トルクと逆起電力が何に比例するか、電圧方程式の各項が何を表すかを問われる。二次試験では、入力・軸出力から損失や電機子抵抗を求め、逆起電力を算出し、磁束一定条件の速度比・トルク比を使って別の動作点を求める形へ発展する。

この章の到達目標は次のとおり。

1. `V=E+I_aR_a` から未知量を逆算できる。
2. `E=k_eΦω` から磁束・回転速度と逆起電力の関係を説明できる。
3. `T=k_tΦI_a` から磁束・電機子電流とトルクの関係を説明できる。
4. `EI_a=Tω` を用いて電気量と機械量を接続できる。
5. `I_a²R_a` と入出力の電力収支から銅損・効率を計算できる。
6. 負荷変化時の新しい動作点を順序立てて求められる。
7. 磁気飽和が指定された問題で、磁束を界磁電流に単純比例させず与条件を使える。

本テーマでは定常状態の動作点だけを扱う。始動過渡、慣性、チョッパ、回生、整流作用、電機子反作用は扱わない。

## 2. 電機子回路と電圧方程式

電動機運転時、端子から加えた電圧 `V` は、回転によって生じる逆起電力 `E` と電機子抵抗による電圧降下 `I_aR_a` に分かれる。

```text
V = E + I_a R_a
```

記号と単位は次のとおり。

| 記号 | 意味 | 単位 |
|---|---|---|
| `V` | 電機子端子電圧 | V |
| `E` | 逆起電力（誘導起電力） | V |
| `I_a` | 電機子電流 | A |
| `R_a` | 電機子抵抗 | Ω |

逆算形も使えるようにする。

```text
E = V - I_a R_a
I_a = (V-E)/R_a
R_a = (V-E)/I_a
```

問題文でブラシ全電圧降下 `V_br` が明示される場合だけ、その与条件を加えて

```text
V = E + I_aR_a + V_br
```

とする。ブラシ電圧降下を本テーマの独立論点として一般化はしない。

この式で最も重要なのは、`E` が単なる損失電圧ではない点である。`E` と `I_a` の積は、電機子内で電気エネルギーから機械エネルギーへ変換される電力に対応する。

## 3. 逆起電力と回転速度

逆起電力は磁束と角速度に比例する。

```text
E = k_e Φ ω
```

- `k_e`: 機械構造で決まる起電力定数
- `Φ`: 1極当たり磁束。問題文の定義に従う
- `ω`: 機械角速度 `[rad/s]`

回転速度 `n [min^-1]` と角速度の関係は

```text
ω = 2πn/60
```

である。

したがって、磁束一定なら

```text
E ∝ ω ∝ n
```

となり、2つの動作点について

```text
E_2/E_1 = ω_2/ω_1 = n_2/n_1
```

を使える。

電圧方程式と組み合わせると

```text
ω = (V-I_aR_a)/(k_eΦ)
```

となる。端子電圧と磁束が一定なら、負荷増加により `I_a` が増えるほど抵抗降下 `I_aR_a` が増え、`E` と回転速度は低下する。

ただし `E∝n` を比で使えるのは磁束が同じと判断できる場合である。磁束が変化する問題では

```text
E_2/E_1 = (Φ_2/Φ_1)(n_2/n_1)
```

を使う。

## 4. 電磁トルク

直流電動機の電磁トルクは磁束と電機子電流に比例する。

```text
T = k_t Φ I_a
```

- `T`: 電磁トルク `[N·m]`
- `k_t`: 機械構造で決まるトルク定数
- `Φ`: 磁束
- `I_a`: 電機子電流 `[A]`

磁束一定なら

```text
T ∝ I_a
```

なので、2つの動作点で

```text
T_2/T_1 = I_{a2}/I_{a1}
```

を使える。

磁束が変わる場合は

```text
T_2/T_1
= (Φ_2/Φ_1)(I_{a2}/I_{a1})
```

である。二次試験では「トルクが何%になったか」から直ちに電流比へ移る前に、磁束一定条件があるかを確認する。

## 5. 電力・損失・効率

電機子内で電気から機械へ変換される電磁変換電力は

```text
P_em = E I_a
```

である。一方、機械側では

```text
P_em = Tω
```

だから

```text
E I_a = Tω
```

が成り立つ。

電機子銅損は

```text
P_Cu = I_a²R_a
```

である。ブラシ電圧降下など別の損失が問題文で指定されていない基本モデルでは、電機子入力は

```text
P_a = VI_a
```

であり、電圧方程式へ `I_a` を掛けると

```text
VI_a = EI_a + I_a²R_a
      = P_em + P_Cu
```

となる。

軸出力 `P_out` は、問題文で別の損失が指定される場合、その分を `P_em` から差し引く。別損失を無視すると指定されている場合は

```text
P_out = P_em
```

としてよい。

効率は

```text
η = P_out/P_in
```

である。ただし `P_in` の範囲は問題文に従う。電機子入力だけを扱うのか、別に与えられた入力電力まで含めるのかを先に確認し、無視すると指定された損失を勝手に復活させない。

### 電力収支から電機子抵抗を逆算する

二次試験では `R_a` が直接与えられず、入力と出力から求めることがある。電機子銅損以外を無視できるなら

```text
P_Cu = P_in - P_out
R_a = P_Cu/I_a²
```

と進む。

問題文でブラシ損などが明示される場合は、その指定損失も電力収支から差し引いてから `I_a²R_a` に対応する銅損を取り出す。

## 6. 負荷変化時の動作点の追い方

定常状態の負荷変化では、次の順序で追うと式の選択を誤りにくい。

1. 負荷トルクの変化を確認する。
2. 必要な電磁トルク `T` を決める。
3. `T=k_tΦI_a` から必要な `I_a` を求める。
4. `I_aR_a` を求める。
5. `E=V-I_aR_a` から逆起電力を求める。
6. `E=k_eΦω` から回転速度を求める。
7. `EI_a=Tω` と電力収支で検算する。

端子電圧 `V` と磁束 `Φ` が一定で、回転損失を無視するなら、負荷トルクが増えると `I_a` が増加し、抵抗降下が増え、回転速度は低下する。

式で直接つなぐと

```text
I_a = T/(k_tΦ)

ω
= (V-I_aR_a)/(k_eΦ)
= V/(k_eΦ) - {R_a/(k_e k_t Φ²)}T
```

となる。したがって、この条件では回転速度―トルク特性は直線になる。

## 7. 磁束一定近似と飽和

磁束一定と明記された問題では、`E∝n`、`T∝I_a` をそのまま比計算に使える。

一方、磁束が界磁条件によって変化し、さらに磁気飽和を考慮する問題では、界磁電流の増加率をそのまま磁束の増加率としてはいけない。問題文から

```text
Φ_2/Φ_1
```

が与えられる、または磁化特性から読み取れるなら、その磁束比を直接使う。

その場合の基本式は変わらない。

```text
E_2/E_1 = (Φ_2/Φ_1)(ω_2/ω_1)
T_2/T_1 = (Φ_2/Φ_1)(I_{a2}/I_{a1})
```

必要なのは、比例関係を使う前に「何が一定で、何が変化するか」を確定することである。本テーマでは飽和曲線そのものの解析や別の励磁方式の設計には広げない。

## 8. 3段階例題

### 8.1 基礎例題: 電圧・速度・トルク・電力を一つにつなぐ

直流電動機の端子電圧を `V=220 V`、電機子抵抗を `R_a=0.50 Ω`、電機子電流を `I_a=20 A` とする。ある磁束で `k_eΦ=1.50 V·s/rad`、`k_tΦ=1.50 N·m/A` とする。別損失は無視する。逆起電力、回転速度、電磁トルク、電磁変換電力を求める。

まず電圧方程式から

```text
E = V-I_aR_a
  = 220-20×0.50
  = 210 V
```

である。

逆起電力式から

```text
ω = E/(k_eΦ)
  = 210/1.50
  = 140 rad/s
```

したがって

```text
n = 60ω/(2π)
  = 1.34×10^3 min^-1
```

である。

トルクは

```text
T = (k_tΦ)I_a
  = 1.50×20
  = 30.0 N·m
```

電磁変換電力は

```text
P_em = EI_a
     = 210×20
     = 4.20 kW
```

機械側からも

```text
Tω = 30.0×140
   = 4.20 kW
```

となり一致する。`VI_a=4.40 kW` との差 `0.20 kW` は `I_a²R_a=20²×0.50=0.20 kW` の電機子銅損である。

### 8.2 本試験標準例題: 速度比とトルク比から別動作点を求める

磁束一定の直流電動機が、動作点1で `V_1=220 V`、`I_{a1}=40 A`、`R_a=0.20 Ω`、`n_1=1200 min^-1` で運転している。別損失とブラシ電圧降下は無視する。動作点2では回転速度が `1500 min^-1`、トルクが動作点1の75%になった。必要な端子電圧 `V_2` を求める。

磁束一定なので、まず動作点1の逆起電力は

```text
E_1 = V_1-I_{a1}R_a
    = 220-40×0.20
    = 212 V
```

速度比から

```text
E_2/E_1 = n_2/n_1
```

よって

```text
E_2 = 212×1500/1200
    = 265 V
```

である。

同じく磁束一定なので `T∝I_a` より

```text
I_{a2} = 0.75 I_{a1}
       = 30 A
```

となる。最後に電圧方程式へ戻して

```text
V_2 = E_2 + I_{a2}R_a
    = 265 + 30×0.20
    = 271 V
```

を得る。

二次試験では「速度比から `E_2`」「トルク比から `I_{a2}`」「最後に電圧方程式」という順を明記すると、比例関係の根拠が答案に残る。

### 8.3 複合・ひっかけ例題: 飽和時に界磁電流比を磁束比へ置き換えない

動作点1で `V=250 V`、`R_a=0.50 Ω`、`I_{a1}=20 A`、`n_1=1000 min^-1` とする。動作点2では負荷トルクが動作点1の1.50倍となった。界磁条件も変化し、与えられた磁化特性から `Φ_2=1.20Φ_1` と分かっている。端子電圧は同じで、別損失は無視する。動作点2の電機子電流と回転速度を求める。

トルク比は

```text
T_2/T_1
= (Φ_2/Φ_1)(I_{a2}/I_{a1})
```

なので

```text
1.50 = 1.20×I_{a2}/20
```

より

```text
I_{a2}=25.0 A
```

である。

各動作点の逆起電力は

```text
E_1 = 250-20×0.50
    = 240 V

E_2 = 250-25×0.50
    = 237.5 V
```

逆起電力比は磁束比と速度比の積なので

```text
E_2/E_1
= (Φ_2/Φ_1)(n_2/n_1)
```

したがって

```text
n_2
= n_1(E_2/E_1)(Φ_1/Φ_2)
= 1000×(237.5/240)/1.20
≈ 825 min^-1
```

となる。

この問題のひっかけは、界磁条件の変化から磁束を勝手に線形比例させることである。飽和が関係する場合は、与えられた磁束比 `1.20` を使い、別の比例則へ置き換えない。

## 9. 0系への接続

前テーマでは、主変圧器二次側の交流を整流して直流主回路へ渡すところまで扱った。本テーマでは、その直流側電圧を `V`、主電動機へ流れる電流を `I_a` と見て、直流主電動機の内部で何が起きるかを解析する。

```text
主変圧器二次側
    ↓
整流回路
    ↓  V, I_a
直流主電動機
    ↓
E, T, ω, P_out
```

電験として重要なのは、0系固有の数値を暗記することではない。整流後に得られた直流電圧・電流を、`V=E+I_aR_a`、`E=k_eΦω`、`T=k_tΦI_a`、`EI_a=Tω` へ接続し、一般の直流電動機問題として解けることである。

未確認の0系主電動機定格、抵抗値、磁束、実際の動作点は本テーマでは実値化しない。

## 10. 特性グラフ

以下の図は本テーマの固定範囲を理解するための模式図である。数値実車特性ではない。特記しない限り `V`、`R_a`、`Φ` 一定の定常状態を表す。

### 10.1 電機子電流―トルク

磁束一定なら

```text
T = k_tΦI_a
```

なので原点を通る直線になる。

```text
T
↑
│          /
│        /
│      /
│    /
│  /
└────────────→ I_a
```

磁束が変化する条件では、この直線関係をそのまま使わず `Φ` の与条件を反映する。

### 10.2 回転速度―トルク

`V` と `Φ` が一定なら

```text
ω = V/(k_eΦ) - {R_a/(k_e k_t Φ²)}T
```

なので、トルク増加とともに速度が低下する直線になる。

```text
ω, n
↑ ●
│   \
│     \
│       \
│         \
│           ●
└────────────→ T
```

傾きの原因は、トルク増加に必要な `I_a` が増え、`I_aR_a` が大きくなって `E` が下がることである。

### 10.3 回転速度―出力

同じ一定 `V`・一定 `Φ` の基本モデルで電磁変換電力を見ると

```text
I_a = (V-k_eΦω)/R_a

P_em
= E I_a
= {k_eΦω(V-k_eΦω)}/R_a
```

となるため、速度に対して上に凸ではなく下向きに開く放物線状になる。別の回転損失を無視する条件では `P_out≈P_em` とみなせる。

```text
P_em, P_out
↑
│        ●
│      /   \
│    /       \
│  /           \
│●               ●
└────────────────→ ω, n
```

この模式図は一定電圧・一定磁束の式から得たものであり、実車の全速度域特性を表すものではない。

### 10.4 負荷変化時の動作点

同じ電動機特性上で負荷トルクが `T_L1` から `T_L2` へ増えると、定常動作点はAからBへ移る。回転損失を無視する基本モデルでは交点で `T=T_L` と考える。

```text
ω, n
↑
│\
│ \      A ●──────── T_L1
│  \
│   \ B ●─────────── T_L2
│    \
│     \
└────────────────────→ T
       T_L1   T_L2
```

負荷増加時の因果関係は

```text
T_L ↑
→ 必要T ↑
→ I_a ↑
→ I_aR_a ↑
→ E ↓
→ ω, n ↓
```

で追う。

## 11. 頻出ミス・ひっかけ

1. `V=E+I_aR_a` の `E` を損失電圧とみなす。
   - `EI_a` は電磁変換電力である。
2. `E∝n` を無条件に使う。
   - 成立には磁束一定が必要。磁束が変わるなら `E∝Φn`。
3. `T∝I_a` を無条件に使う。
   - 成立には磁束一定が必要。磁束が変わるなら `T∝ΦI_a`。
4. `n [min^-1]` をそのまま `P=Tω` の `ω` に代入する。
   - `ω=2πn/60 [rad/s]` へ変換する。
5. 銅損を `I_aR_a` とする。
   - `I_aR_a` は電圧降下、銅損は `I_a²R_a`。
6. 入力と軸出力の差をすべて電機子銅損とする。
   - 問題文で別損失が指定されていないか先に確認する。
7. 飽和を考慮する条件でも磁束を界磁電流へ線形比例させる。
   - 与えられた磁化特性・磁束比を使う。
8. 速度比・トルク比だけ計算して電圧方程式へ戻らない。
   - 二次試験では最後に新しい動作点が `V=E+I_aR_a` を満たすか確認する。
9. H24のブラシ電圧降下を一般問題へ常に追加する。
   - 明示された与条件としてのみ使う。

## 12. 過去問でどう出るか

固定範囲に対応する(1)(2)では、直流電動機の式の各項が何を表すかを識別する。必要なのは

```text
T = k_tΦI_a
E = k_eΦω

```

の意味である。本テーマの4章・3章・2章で直接対応する。

### H24 二次 機械・制御 問1

固定範囲に対応する(1)(2)(4)では、まず電力収支から銅損と `R_a` を求め、次に電圧方程式から `E` を求める。その後、磁束一定条件の

```text
E∝n
T∝I_a
```

を使い、別動作点の端子電圧へ戻す。

```text
入力・出力
→ 損失
→ R_a
→ E_1
→ 速度比でE_2

```

である。可逆チョッパ、通流率、回生制動を扱う設問は本テーマでは扱わない。

## 13. 公式・解法まとめ

電圧方程式:

```text
V = E+I_aR_a
E = V-I_aR_a
```

逆起電力:

```text
E = k_eΦω
ω = 2πn/60

磁束一定:
E_2/E_1 = n_2/n_1
```

電磁トルク:

```text
T = k_tΦI_a

磁束一定:
T_2/T_1 = I_{a2}/I_{a1}
```

電磁変換電力:

```text
P_em = EI_a = Tω
```

電機子銅損:

```text
P_Cu = I_a²R_a
```

基本的な電力収支:

```text
VI_a = EI_a + I_a²R_a
```

効率:

```text
η = P_out/P_in
```

負荷変化時の解法順:

```text
負荷トルク
→ T
→ I_a
→ I_aR_a
→ E
→ ω, n
→ 電力収支で検算
```

二次試験では、比例式を使う前に磁束一定条件、損失条件、単位を明記し、最後に電圧方程式と電力収支へ戻って検算する。
