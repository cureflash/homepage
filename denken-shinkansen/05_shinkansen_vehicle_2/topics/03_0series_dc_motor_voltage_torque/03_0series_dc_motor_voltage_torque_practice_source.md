# 一次試験型

## 問1 電圧方程式と逆起電力

直流電動機の端子電圧を `V=220 V`、電機子電流を `I_a=20 A`、電機子抵抗を `R_a=0.50 Ω` とする。ブラシ電圧降下などは無視する。

逆起電力 `E` として正しいものを選べ。

1. `10 V`
2. `110 V`
3. `200 V`
4. `210 V`
5. `230 V`

### 正答

4

### 完全解説

電動機の電機子電圧方程式は

```text
V = E + I_a R_a
```

である。したがって

```text
E = V - I_a R_a
  = 220 - 20×0.50
  = 210 V
```

となる。

`I_aR_a=10 V` は電機子抵抗による電圧降下であり、逆起電力そのものではない。電動機運転では、端子電圧から抵抗降下を差し引いた値が逆起電力になる。

## 問2 電機子電流―トルク

磁束が一定の他励直流電動機で、電機子電流を `30 A` から `45 A` に変化させた。磁気飽和による磁束変化はないものとする。

電磁トルクの比 `T_2/T_1` として正しいものを選べ。

1. `0.667`
2. `1.00`
3. `1.22`
4. `1.50`
5. `2.25`

### 正答

4

### 完全解説

直流機の電磁トルクは

```text
T = k_t Φ I_a
```

である。磁束 `Φ` が一定なら

```text
T ∝ I_a
```

なので

```text
T_2/T_1 = I_a2/I_a1
        = 45/30
        = 1.50
```

となる。

`2.25` は電流比を誤って二乗した値である。銅損は `I_a²R_a` で電流の二乗に比例するが、磁束一定時のトルクは電機子電流の一次に比例する。

## 問3 逆起電力―回転速度

磁束一定の直流電動機で、`1500 min^-1` のとき逆起電力が `180 V` であった。同じ磁束のまま `1200 min^-1` で回転するときの逆起電力として正しいものを選べ。

1. `120 V`
2. `144 V`
3. `150 V`
4. `180 V`
5. `225 V`

### 正答

2

### 完全解説

逆起電力は

```text
E = k_e Φ ω
```

である。磁束一定なら `E∝ω` であり、回転速度 `n` にも比例する。

```text
E_2/E_1 = n_2/n_1
```

したがって

```text
E_2 = 180×1200/1500
    = 144 V
```

となる。

磁束が一定という条件を確認してから速度比を使うことが重要である。

## 問4 電磁変換電力と電磁トルク

直流電動機の逆起電力を `E=180 V`、電機子電流を `I_a=25 A`、回転速度を `1500 min^-1` とする。

電磁変換電力 `P_em` と電磁トルク `T` の組合せとして最も近いものを選べ。

1. `P_em=4.50 kW`, `T=14.3 N·m`
2. `P_em=4.50 kW`, `T=28.6 N·m`
3. `P_em=5.00 kW`, `T=28.6 N·m`
4. `P_em=5.00 kW`, `T=47.7 N·m`
5. `P_em=9.00 kW`, `T=57.3 N·m`

### 正答

2

### 完全解説

電磁変換電力は

```text
P_em = E I_a
     = 180×25
     = 4500 W
     = 4.50 kW
```

である。

回転角速度は

```text
ω = 2πn/60
  = 2π×1500/60
  = 157.1 rad/s
```

したがって

```text
T = P_em/ω
  = 4500/157.1
  = 28.6 N·m
```

となる。

`P_em=EI_a=Tω` は、電気側の逆起電力・電機子電流と機械側のトルク・角速度を結ぶ式である。

## 問5 回転速度―出力特性

ある直流電動機について、考える範囲では電磁トルク `T` が一定で、回転損失を無視できるものとする。回転速度 `n` と機械出力 `P` の関係として最も適切なものを選べ。

1. `P` は `n` に反比例する。
2. `P` は `n` の二乗に比例する。
3. `P` は `n` に比例し、原点を通る直線になる。
4. `P` は `n` によらず一定である。
5. `P` は `n` が増えるほど必ず低下する。

### 正答

3

### 完全解説

機械出力は

```text
P = Tω
```

であり、

```text
ω = 2πn/60
```

だから、トルク一定なら

```text
P ∝ n
```

となる。

したがって回転速度―出力グラフは、この条件では原点を通る直線になる。実機の全運転範囲が常に一定トルクという意味ではなく、問題文で指定された条件内の関係である。

## 問6 一定電圧・一定磁束時の回転速度―トルク

端子電圧 `V` と磁束 `Φ` が一定、電機子抵抗 `R_a>0` の直流電動機について、電機子反作用などは無視する。

負荷トルクが増加して新しい定常動作点へ移るときの説明として最も適切なものを選べ。

1. 電機子電流が減少し、逆起電力と回転速度が上昇する。
2. 電機子電流が増加し、抵抗降下が増えるため逆起電力と回転速度が低下する。
3. 電機子電流は変化せず、回転速度だけが低下する。
4. 電機子電流が増加すると逆起電力も必ず増加するため、回転速度は上昇する。
5. トルクは電機子電流の二乗に比例するため、回転速度は二乗則で低下する。

### 正答

2

### 完全解説

磁束一定なら

```text
T ∝ I_a
```

なので、より大きな負荷トルクと釣り合うには電機子電流が増える。

一方、端子電圧一定では

```text
E = V - I_aR_a
```

であるため、`I_a` が増えると抵抗降下 `I_aR_a` が増え、逆起電力 `E` は低下する。

さらに磁束一定なら

```text
E ∝ n
```

なので、定常回転速度も低下する。

この関係から、一定電圧・一定磁束の近似では回転速度―トルク特性は右下がりになる。

## 問7 磁気飽和を考慮したトルク

ある直流電動機で界磁電流を2倍にしたところ、与えられた磁化特性から磁束は `1.25` 倍になった。電機子電流は変化しないものとする。

電磁トルクの比 `T_2/T_1` として正しいものを選べ。

1. `1.00`
2. `1.25`
3. `1.50`
4. `2.00`
5. `4.00`

### 正答

2

### 完全解説

電磁トルクは

```text
T = k_t Φ I_a
```

である。電機子電流が同じなので

```text
T_2/T_1 = Φ_2/Φ_1
        = 1.25
```

となる。

界磁電流が2倍だからといって、磁束まで2倍と置いてはいけない。磁気飽和を考える場合は、問題で与えられた磁化特性または磁束比をそのまま使う。

## 問8 負荷変化時の動作点

磁束一定の直流電動機が、端子電圧 `V=220 V`、電機子抵抗 `R_a=0.50 Ω`、電機子電流 `I_a1=20 A`、回転速度 `n_1=1200 min^-1` で運転している。

負荷トルクが2倍となり、新しい定常状態で電機子電流も2倍になったものとする。端子電圧と磁束は一定である。新しい回転速度 `n_2` に最も近いものを選べ。

1. `600 min^-1`
2. `960 min^-1`
3. `1140 min^-1`
4. `1200 min^-1`
5. `1320 min^-1`

### 正答

3

### 完全解説

初期状態の逆起電力は

```text
E_1 = V - I_a1R_a
    = 220 - 20×0.50
    = 210 V
```

負荷トルクが2倍で磁束一定なら `T∝I_a` より

```text
I_a2 = 40 A
```

である。したがって新しい逆起電力は

```text
E_2 = 220 - 40×0.50
    = 200 V
```

磁束一定では `E∝n` なので

```text
n_2/n_1 = E_2/E_1
```

```text
n_2 = 1200×200/210
    = 1142.9 min^-1
```

よって最も近いのは `1140 min^-1` である。

負荷トルクが2倍になったから速度が半分になるわけではない。まずトルクから電流、電圧方程式から逆起電力、最後に逆起電力から速度へつなぐ。

# 二次試験型

## 問1 電力収支から電機子抵抗と逆起電力を求める

他励直流電動機の端子電圧が `240 V`、電機子電流が `30.0 A`、軸出力が `6.75 kW` である。鉄損、機械損、ブラシ損、界磁回路の入力は無視し、損失は電機子銅損だけとする。

次を求めよ。

1. 電機子銅損 `P_Cu`
2. 電機子抵抗 `R_a`
3. 逆起電力 `E`

### 完全解説

まず電機子入力は

```text
P_in = VI_a
     = 240×30.0
     = 7200 W
```

損失は電機子銅損だけという条件なので

```text
P_Cu = P_in - P_out
     = 7200 - 6750
     = 450 W
```

電機子銅損は

```text
P_Cu = I_a²R_a
```

だから

```text
R_a = P_Cu/I_a²
    = 450/30.0²
    = 0.500 Ω
```

逆起電力は電圧方程式から

```text
E = V - I_aR_a
  = 240 - 30.0×0.500
  = 225 V
```

となる。

検算として

```text
EI_a = 225×30.0 = 6750 W
```

であり、回転損失を無視した条件では軸出力 `6.75 kW` と一致する。

### 答

```text
P_Cu = 450 W
R_a  = 0.500 Ω
E    = 225 V
```

## 問2 別動作点の端子電圧

磁束一定の他励直流電動機が、状態1で

- 端子電圧 `V_1=220 V`
- 電機子電流 `I_a1=30.0 A`
- 電機子抵抗 `R_a=0.400 Ω`
- 回転速度 `n_1=1500 min^-1`

で運転している。

状態2では、電磁トルクを状態1の `70%`、回転速度を `1600 min^-1` とする。磁束と電機子抵抗は変化しない。

状態2の端子電圧 `V_2` を求めよ。

### 完全解説

磁束一定では

```text
T ∝ I_a
```

なので

```text
I_a2 = 0.70 I_a1
     = 0.70×30.0
     = 21.0 A
```

状態1の逆起電力は

```text
E_1 = V_1 - I_a1R_a
    = 220 - 30.0×0.400
    = 208 V
```

磁束一定では `E∝n` なので

```text
E_2 = E_1(n_2/n_1)
    = 208×1600/1500
    = 221.87 V
```

状態2の端子電圧は

```text
V_2 = E_2 + I_a2R_a
    = 221.87 + 21.0×0.400
    = 230.27 V
```

したがって

```text
V_2 ≒ 230 V
```

である。

答案では「トルク比→電機子電流」「速度比→逆起電力」「電圧方程式→端子電圧」の順に書くと、条件と使用式の対応が明確になる。

### 答

`V_2 ≒ 230 V`

## 問3 損失・効率・電磁トルク・軸トルク

直流電動機が次の条件で定常運転している。

- 端子電圧 `V=300 V`
- 電機子電流 `I_a=50.0 A`
- 電機子抵抗 `R_a=0.300 Ω`
- 回転速度 `n=1800 min^-1`
- 鉄損と機械損の合計 `P_rot=900 W`

界磁回路の入力とブラシ損は無視する。

次を求めよ。

1. 逆起電力 `E`
2. 電機子銅損 `P_Cu`
3. 電磁変換電力 `P_em`
4. 軸出力 `P_out`
5. 効率 `η=P_out/(VI_a)`
6. 電磁トルク `T_em`
7. 軸トルク `T_out`

### 完全解説

逆起電力は

```text
E = V - I_aR_a
  = 300 - 50.0×0.300
  = 285 V
```

電機子銅損は

```text
P_Cu = I_a²R_a
     = 50.0²×0.300
     = 750 W
```

電磁変換電力は

```text
P_em = EI_a
     = 285×50.0
     = 14250 W
     = 14.25 kW
```

軸出力は回転損失を差し引いて

```text
P_out = P_em - P_rot
      = 14250 - 900
      = 13350 W
      = 13.35 kW
```

電機子入力は

```text
VI_a = 300×50.0
     = 15000 W
```

したがって効率は

```text
η = 13350/15000
  = 0.890
  = 89.0 %
```

回転角速度は

```text
ω = 2πn/60
  = 2π×1800/60
  = 188.50 rad/s
```

電磁トルクは

```text
T_em = P_em/ω
     = 14250/188.50
     = 75.6 N·m
```

軸トルクは

```text
T_out = P_out/ω
      = 13350/188.50
      = 70.8 N·m
```

となる。

電磁トルクと軸トルクを混同しない。回転損失があるため、軸出力・軸トルクは電磁変換電力・電磁トルクより小さい。

### 答

```text
E      = 285 V
P_Cu   = 750 W
P_em   = 14.25 kW
P_out  = 13.35 kW
η      = 89.0 %
T_em   = 75.6 N·m
T_out  = 70.8 N·m
```

## 問4 磁気飽和を含む動作点計算

ある他励直流電動機について、状態1と状態2の磁束は磁化特性から次のように与えられている。

```text
Φ_1 = 1.00 pu
Φ_2 = 1.15 pu
```

これは界磁電流そのものの比ではなく、磁化特性から得た磁束比である。

共通条件と状態量は次のとおりである。

- 端子電圧 `V=200 V`（両状態で一定）
- 電機子抵抗 `R_a=0.400 Ω`
- 状態1: `I_a1=25.0 A`, `n_1=1000 min^-1`
- 状態2: `I_a2=30.0 A`

次を求めよ。

1. 逆起電力 `E_1`, `E_2`
2. 回転速度 `n_2`
3. 電磁トルク比 `T_2/T_1`

### 完全解説

両状態の逆起電力は電圧方程式から

```text
E_1 = 200 - 25.0×0.400
    = 190 V
```

```text
E_2 = 200 - 30.0×0.400
    = 188 V
```

逆起電力は

```text
E = k_e Φω
```

なので、回転速度比について

```text
E_2/E_1 = (Φ_2 n_2)/(Φ_1 n_1)
```

が成り立つ。したがって

```text
n_2 = n_1(E_2/E_1)(Φ_1/Φ_2)
    = 1000×(188/190)×(1.00/1.15)
    = 860.4 min^-1
```

となる。

また電磁トルクは

```text
T = k_t Φ I_a
```

なので

```text
T_2/T_1
= (Φ_2 I_a2)/(Φ_1 I_a1)
= (1.15×30.0)/(1.00×25.0)
= 1.38
```

である。

この問題で重要なのは、界磁電流比から磁束比を勝手に作らないことである。磁気飽和を考慮する場合は、与えられた磁化特性から得た `Φ_1`, `Φ_2` を使用する。

### 答

```text
E_1 = 190 V
E_2 = 188 V
n_2 = 860 min^-1（約）
T_2/T_1 = 1.38
```
