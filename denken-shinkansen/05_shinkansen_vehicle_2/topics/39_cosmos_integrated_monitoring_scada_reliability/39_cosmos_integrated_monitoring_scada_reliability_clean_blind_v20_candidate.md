## 独立解答

### R4 一次「機械」問3 — 計器用変成器

1. `(1) ハ: 負担`
   - 計器用変成器の二次側に接続される計器・継電器等の負荷を負担という。
2. `(2) ニ: 励磁`
   - 比・位相誤差を小さくするには、高透磁率鉄心で励磁電流を小さくする。
3. `(3) チ: 小さ`
   - 巻線抵抗と漏れリアクタンスは極力小さくする。
4. `(4) カ: 比誤差`
   - 公称変成比と真の変成比の差を真の変成比で規格化した百分率は比誤差である。
5. `(5) イ: 短絡`
   - CT二次負担を切り離す際は二次端子を短絡し、二次開放による過電圧を防ぐ。

### R3 一次「機械」問8 — A/D変換

1. `(1) チ: 2`
   - 標本化定理より、最高周波数成分の2倍を超えるサンプリングレートが必要。
2. `(2) ト: 誤差`
   - 量子化段階を増やすと量子化単位が小さくなり、量子化誤差も小さくなる。
3. `(3) カ: 時間`
   - 積分形は入力積分値と基準信号の積分値が等しくなるまでの時間を測る。
4. `(4) ヌ: MSB`
   - 逐次比較形はMSB側からビットを順に決定する。
5. `(5) ヘ: サンプルホールド`
   - 変換中に入力レベルを保持して変動を防ぐのはサンプルホールド回路。

### H30 一次「機械」問8 — LAN中継機器・アドレス

1. `(1) ル: リピータ`
   - 物理層で減衰した信号を増幅・再生して中継する。
2. `(2) ヨ: ブリッジ`
   - 複数LANをデータリンク層で接続する機器。
3. `(3) ヌ: MAC`
   - ブリッジ/スイッチはMACアドレスを参照して転送制御する。
4. `(4) チ: Wi-Fi`
   - IEEE 802.11系無線LANによる接続はWi-Fi。
5. `(5) イ: DHCP`
   - IPアドレス等をクライアントへ自動割当するサーバ機能はDHCP。

### H25 一次「機械」問8 — 変調・復調

1. `(1) ヨ: 搬送波`
   - 原信号に応じて振幅・周波数・位相等を変化させる高周波信号は搬送波。
2. `(2) ル: 復調`
   - 変調波から原信号を取り出す操作は復調。
3. `(3) ロ: AM`
   - 図1は搬送波の振幅包絡が入力信号に応じて変化するので振幅変調。
4. `(4) カ: 直交振幅変調`
   - QAMは直交する搬送波の振幅を組み合わせる直交振幅変調。
5. `(5) ト: ASK`
   - 図2はデジタル符号で搬送波振幅を切り替えるのでASK。

### R2 二次「電力・管理」問2 — 固定5群

1. 小問(1)前半
   - 計器用変成器は、高電圧・大電流を計器や保護リレーで扱える低電圧・小電流へ、一次量に対応する比で変成し、測定・保護に用いる。代表例は計器用変圧器 `VT (PT)` と変流器 `CT`。
2. 小問(1)後半
   - 比誤差は `ε = (K_n - K) / K × 100 [%]`。
3. 小問(2)
   - 信頼性とは、保護が必要な事故時には確実に正しく動作し、平常時・保護不要時には誤動作せず、不動作と誤動作の双方を避けて所要の保護機能を確実に果たす性質。
4. 小問(3)前半
   - 77又は66 kV系統の遮断器の定格遮断時間は `3サイクル`。保護リレーから事故除去指令を受ける箇所は `引外し装置（トリップ装置）`。
5. 小問(3)後半
   - 引外し自由（トリップフリー）は、投入操作中または投入指令が残っていても引外し指令を優先して直ちに開路し、投入指令をいったん解除するまで再投入させない機能。事故点への再投入・ポンピングを防ぎ、確実に事故を除去する。
