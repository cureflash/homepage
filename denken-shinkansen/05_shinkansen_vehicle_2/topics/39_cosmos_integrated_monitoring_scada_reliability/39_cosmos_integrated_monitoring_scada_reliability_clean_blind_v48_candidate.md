## 独立解答

### R4一次「機械」問3 — 計器用変成器

1. `(1) = 負担`（ハ）
2. `(2) = 励磁`（ニ）
3. `(3) = 小さ`（チ）
4. `(4) = 比誤差`（カ）
5. `(5) = 短絡`（イ）

根拠: 二次側計器・継電器の負荷は負担と呼ぶ。高透磁率鉄心により必要励磁電流を小さくし、巻線抵抗・漏れリアクタンスも小さくして変成比誤差を抑える。CT二次開放は高電圧発生の危険があるため、機器切離し時は先に二次を短絡する。

### R3一次「機械」問8 — A/D変換

1. `(1) = 2`（チ）
2. `(2) = 誤差`（ト）
3. `(3) = 時間`（カ）
4. `(4) = MSB`（ヌ）
5. `(5) = サンプルホールド`（ヘ）

根拠: 標本化定理では最高周波数の2倍を超える標本化周波数が必要。量子化幅が小さくなるほど量子化誤差は小さくなる。積分形は積分結果が基準積分値に達するまでの時間を測定する。逐次比較形はMSB側から比較し、変換中の入力保持にはサンプルホールド回路を用いる。

### H30一次「機械」問8 — LAN中継機器・アドレス

1. `(1) = リピータ`（ル）
2. `(2) = ブリッジ`（ヨ）
3. `(3) = MAC`（ヌ）
4. `(4) = Wi-Fi`（チ）
5. `(5) = DHCP`（イ）

根拠: 物理層で信号を再生中継するのがリピータ。データリンク層でLANを接続しMACアドレスを参照する代表機器がブリッジ／スイッチングハブ。IEEE 802.11はWi-Fi、IPアドレスの自動割当てはDHCP。

### H25一次「機械」問8 — 変調・復調

1. `(1) = 搬送波`（ヨ）
2. `(2) = 復調`（ル）
3. `(3) = AM`（ロ）
4. `(4) = 位相振幅変調`（ワ）
5. `(5) = ASK`（ト）

根拠: 情報信号で搬送波のパラメータを変える操作が変調、受信側で原信号を取り出す操作が復調。図1は搬送波振幅が連続的に変化するAM、QAMは位相振幅変調、図2は二値に応じて搬送波振幅を切り替えるASK。

### R2二次「電力・管理」問2 — 固定5群

#### 群1: 小問(1)前半
計器用変成器は、電力系統の高電圧・大電流を計器・保護リレーで安全かつ適切に扱える低い電圧・電流へ変成し、測定・保護回路を一次高圧回路から絶縁する。代表例は計器用変圧器（VT/PT）と変流器（CT）。

#### 群2: 小問(1)後半
公称変成比を `K_n`、真の変成比を `K` とすると、比誤差は

`ε = (K_n - K) / K × 100 [%]`

とする。

#### 群3: 小問(2)
保護リレーの信頼性とは、保護範囲内の事故時には必要なとき確実に動作し、正常時や保護範囲外の事故では不要動作しないことをいう。すなわち動作すべき場合の確実性と、動作すべきでない場合の安全性の双方を満たすことが必要である。

#### 群4: 小問(3)前半
77又は66 kV系統で用いる遮断器の定格遮断時間は `3サイクル`。保護リレーから事故除去指令を受ける箇所は `引外し装置（トリップ装置。引外しコイルを含む）`。

#### 群5: 小問(3)後半
引外し自由（トリップフリー）とは、投入操作中または投入指令が継続していても引外し指令が与えられれば、投入操作に拘束されず遮断器を開路できる機能である。事故状態の回路を投入状態のまま保持したり再投入し続けたりすることを防ぎ、事故回路を確実に切り離すことを目的とする。
