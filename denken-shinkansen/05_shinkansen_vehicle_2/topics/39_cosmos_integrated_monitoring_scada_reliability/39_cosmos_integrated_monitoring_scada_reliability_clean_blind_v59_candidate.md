## 独立再解答

### 1. R4一次「機械」問3 — 計器用変成器

1. `負担`
2. `励磁`
3. `小さ`
4. `比誤差`
5. `短絡`

根拠: 計器・継電器等の二次側接続容量は負担、比誤差低減には励磁電流と巻線抵抗・漏れリアクタンスを小さくする。CT二次開放は高電圧を生じ得るため、機器切離し前に二次端子を短絡する。

### 2. R3一次「機械」問8 — A/D変換

1. `2`
2. `誤差`
3. `時間`
4. `MSB`
5. `サンプルホールド`

根拠: 標本化定理は最高周波数の2倍超、量子化段階が細かいほど量子化誤差は小さい。積分形は基準信号との積分値一致までの時間を測る。逐次比較はMSB側から判定し、変換中の入力保持にサンプルホールドを用いる。

### 3. H30一次「機械」問8 — LAN中継機器・アドレス

1. `リピータ`
2. `ブリッジ`
3. `MAC`
4. `Wi-Fi`
5. `DHCP`

根拠: リピータは物理層、ブリッジ/スイッチングハブはデータリンク層でMACアドレスを参照、IEEE 802.11はWi-Fi、ネットワーク層のIPアドレス自動割当てにはDHCPを用いる。

### 4. H25一次「機械」問8 — 変調・復調

1. `搬送波`
2. `復調`
3. `振幅変調（AM）`
4. `直交振幅変調`
5. `直交振幅変調（QAM）`

根拠: 変調は搬送波の振幅・周波数・位相等を原信号に応じて変化させ、受信側で原信号を取り出す操作が復調。QAMは振幅と位相を組み合わせた変調である。図示部分は公式問題PDFの図形識別として上記を採用した。

### 5. R2二次「電力・管理」問2 — 固定5群

#### 群1: 小問(1)前半

計器用変成器は、系統の高電圧・大電流を計器・保護リレーが扱える標準的な低電圧・小電流へ変換し、測定・保護入力を得るために用いる。代表例は`計器用変圧器（VT/PT）`と`変流器（CT）`。

#### 群2: 小問(1)後半

比誤差は

`ε = (K_n - K) / K × 100 [%]`

とする。

#### 群3: 小問(2)

保護リレーの信頼性とは、保護対象で動作すべき事故が生じたときは確実に動作し、動作すべきでない正常時・保護範囲外事故では不要動作しない性質である。

#### 群4: 小問(3)前半

77又は66 kV系統用遮断器の定格遮断時間は`3サイクル`。保護リレーから事故除去指令を受ける箇所は`引外し装置（トリップコイル／引外しコイル）`。

#### 群5: 小問(3)後半

引外し自由（トリップフリー）は、投入操作中または投入指令が継続していても引外し指令が与えられた場合、投入動作より引外しを優先して遮断器を開放し、故障回路への再投入・投入保持を防ぐ機能である。
