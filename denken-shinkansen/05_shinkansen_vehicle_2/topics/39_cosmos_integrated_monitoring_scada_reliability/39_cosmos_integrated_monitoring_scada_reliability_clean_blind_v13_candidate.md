## R4 一次「機械」問3 — 計器用変成器

1. `(1) ハ / 負担`
   - 計器用変成器の二次側に接続する計器・継電器等の負荷は、一般の線路負荷と区別して負担という。
2. `(2) ニ / 励磁`
   - 変成比・変流比の誤差を小さくするには、高透磁率鉄心で必要磁束を得るための励磁電流を小さくする。
3. `(3) チ / 小さ`
   - 巻線抵抗と漏れリアクタンスによる電圧降下・位相差を抑えるため、これらを小さくする。
4. `(4) カ / 比誤差`
   - 公称変成比と真の変成比との差を真の変成比で除して百分率表示する量は比誤差である。
5. `(5) イ / 短絡`
   - CT二次を開放すると高電圧が発生し得るため、二次側機器を切り離す前に二次端子を短絡する。

candidate: `ハ / ニ / チ / カ / イ`

## R3 一次「機械」問8 — A/D変換

1. `(1) チ / 2`
   - 標本化定理より、入力最高周波数を完全復元するにはその2倍を超えるサンプリング周波数が必要。
2. `(2) ト / 誤差`
   - 量子化段数が増えて1LSBが小さくなるほど量子化誤差は小さくなる。
3. `(3) カ / 時間`
   - 積分形は入力積分値と基準信号の積分値が一致するまでの時間を測定し、その時間からディジタル値を得る。
4. `(4) ヌ / MSB`
   - 逐次比較形はMSB側から各ビットを順次仮決定して比較を繰り返す。
5. `(5) ヘ / サンプルホールド`
   - 変換中に入力レベルが変わらないよう標本値を保持する回路はサンプルホールド回路。

candidate: `チ / ト / カ / ヌ / ヘ`

## H30 一次「機械」問8 — LAN中継機器・アドレス

1. `(1) ル / リピータ`
   - 物理層で減衰した信号を増幅・整形して伝送距離を延長し、アドレスによる制御は行わない。
2. `(2) ヨ / ブリッジ`
   - 複数LANをデータリンク層で接続する中継機器はブリッジで、スイッチングハブも同層の機能を持つ。
3. `(3) ヌ / MAC`
   - データリンク層でフレーム転送判断に用いるのはMACアドレス。
4. `(4) チ / Wi-Fi`
   - IEEE 802.11系の無線LAN接続はWi-Fiとして利用される。
5. `(5) イ / DHCP`
   - IPアドレス等をクライアントへ自動割当するのはDHCPサーバ。

candidate: `ル / ヨ / ヌ / チ / イ`

## H25 一次「機械」問8 — 変調・復調

1. `(1) ヨ / 搬送波`
   - 原信号に応じて振幅・周波数・位相等を変化させる高周波信号は搬送波。
2. `(2) ル / 復調`
   - 変調波から原信号を取り出す操作は復調。
3. `(3) ロ / AM`
   - 図1は搬送波の振幅包絡が入力アナログ信号に応じて変化しており、振幅変調AM。
4. `(4) カ / 直交振幅変調`
   - QAMは直交する2搬送波の振幅を組み合わせて情報を表す直交振幅変調。
5. `(5) ト / ASK`
   - 図2は入力ビットに応じて搬送波振幅の有無を切り替える波形で、振幅偏移変調ASK。

candidate: `ヨ / ル / ロ / カ / ト`

## R2 二次「電力・管理」問2 — 固定5群

### 群1 — 小問(1)前半

計器用変成器は、高電圧・大電流の一次量を計器・保護リレーで安全かつ適切に扱える標準的な低電圧・小電流へ変換し、測定・保護回路を主回路から電気的に絶縁するために用いる。代表例は、電圧を変成する計器用変圧器 `VT（PT）` と、電流を変成する変流器 `CT`。

### 群2 — 小問(1)後半

公称変成比を `K_n`、真の変成比を `K` とすると、比誤差は

`ε = (K_n - K) / K × 100 [%]`

と表す。

### 群3 — 小問(2)

保護リレーに求められる信頼性とは、保護対象で事故が生じて動作が必要なときには確実に動作し、正常時や担当外の外部事故など動作すべきでないときには不要動作・誤動作しないことである。

### 群4 — 小問(3)前半

- 77又は66 kV系統用遮断器の定格遮断時間: `3サイクル`
- 保護リレーから事故除去の引外し指令を受ける箇所: `引外し装置（トリップ装置／トリップコイルを含む引外し機構）`

### 群5 — 小問(3)後半

引外し自由（トリップフリー）とは、投入操作・投入指令が継続していても引外し指令を受けたときは投入側の指令に拘束されず遮断器を開路できる機能である。事故継続中の再投入・再閉路による事故電流の反復や機器損傷を防ぎ、故障回路を確実に切り離すことを目的とする。
