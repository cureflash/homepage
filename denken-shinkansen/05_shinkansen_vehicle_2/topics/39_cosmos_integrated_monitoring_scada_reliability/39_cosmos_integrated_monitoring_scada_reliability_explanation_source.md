## 1. このテーマで電験二種は何を問うか

3. リピータ、ブリッジ、MAC、IP、Wi-Fi、DHCPの役割を混同しない。
4. 搬送波、変調・復調、AM/FM/PM、ASK/FSK/PSK/QAMを整理する。

## 2. 一般SCADAモデルと分散システム

SCADA（Supervisory Control And Data Acquisition）は、離れた設備やプロセスから状態・計測値を取得し、通信を介して監視し、必要に応じて操作指令を返す監視制御の一般概念である。NIST SP 800-82 Rev.3も、SCADAをデータ取得、データ伝送、HMI等を統合して分散した対象を中央から監視・制御するシステムとして整理している。

本章では次の一般モデルを使う。

`計測対象 → CT/VT・センサ → 信号調整 → A/D変換・データ収集 → 通信 → 監視表示/状態判定 → 操作指令 → 制御対象`

これはCOSMOS内部構成図ではない。

分散システムでは、複数ノードが通信路で結ばれ、計測、収集、演算、表示、操作などの役割を分担する。分散化の利点として、機能分担、拡張性、局所処理が挙げられる。一方で、通信断、時刻・状態の不一致、共通原因故障、障害箇所の切分けなど、単一装置だけでは生じにくい問題も考える必要がある。

試験では実際の特定SCADA製品名を暗記するより、`どこで計測し、どこでデジタル化し、どの層で伝送し、どの情報で監視・操作するか` を切り分ける。

## 3. 計器用変成器 CT・VT

高電圧・大電流をそのまま計器や保護リレーへ入力することはできない。計器用変成器は主回路と計測・保護回路を絶縁し、電圧・電流を扱いやすい値へ変成する。

- CT（Current Transformer）: 大電流を小電流へ変成する。
- VT（Voltage Transformer）: 高電圧を低電圧へ変成する。

### 3.1 変成比

公称変成比を `K_n`、真の変成比を `K` とする。固定過去問で用いる比誤差は

`ε = (K_n - K) / K × 100 [%]`

である。符号まで含め、問題文で採用されている定義を確認する。誤差率には分野・規格で異なる符号定義があり得るため、式を暗記して無条件に流用しない。

### 3.2 負担

CT・VTの二次側へ接続される計器、リレー、配線などが二次側から見せる負荷を負担という。負担が変わると二次電流・二次電圧、励磁状態、誤差へ影響するため、定格負担内で使用する。

### 3.3 励磁電流と誤差

理想変成器なら一次側の量は変成比だけで二次側へ写るが、実機では鉄心を磁化する励磁電流が必要である。CTでは二次側負担が大きくなって二次端子電圧が上昇すると、鉄心の磁束・励磁電流が増え、理想比からのずれが増え得る。したがって励磁インピーダンス、負担、鉄心特性が変成誤差に関係する。

### 3.4 CT二次開放の危険

CT一次に電流が流れている状態で二次側を開放してはならない。通常は二次電流の起磁力が一次側起磁力をほぼ打ち消すが、二次開放ではこの打消しが失われ、鉄心磁束が大きくなり、高い二次電圧、発熱、絶縁損傷等の危険につながる。保守時は所定の安全手順に従い二次側を短絡側で扱う。VT二次は逆に短絡してはならない。

## 4. CT/VT問題の解法手順

1. CTかVTかを判定する。
2. 一次・二次、公称値・真値を区別する。
3. 問題文の比誤差定義を確認する。
4. 負担と励磁の関係を確認する。
5. CT二次開放、VT二次短絡を安全上の禁則として確認する。
6. 数値問題では単位と百分率をそろえる。
7. 最後に、理想変成器の関係をそのまま実機へ適用していないか検算する。

## 5. A/D変換: 標本化・量子化・符号化

アナログ信号をデジタル処理するには、連続時間・連続値の信号を離散時間・離散値へ変換する。

### 5.1 標本化

最高周波数成分を `f_max`、標本化周波数を `f_s` とすると、帯域制限された信号を理想的に再構成するための基本条件は

`f_s > 2 f_max`

と整理する。実機ではアンチエイリアスフィルタや遷移帯域が必要なので、単に等号ぎりぎりへ置けばよいわけではない。

### 5.2 量子化

n bit A/D変換では、理想的には `2^n` 個のコードへ量子化する。入力フルスケール幅を `V_FS` と単純化すると、1 LSB相当の量子化幅は

`q = V_FS / 2^n`

である。丸め型の理想量子化では量子化誤差の大きさは概ね

`|e_q| ≤ q/2`

となる。実際のA/Dにはオフセット誤差、ゲイン誤差、非直線性等もあるため、量子化誤差だけを総合誤差としない。

A/D変換後のデジタル表現は通常2進数で扱う。MSB（Most Significant Bit）は最上位ビットで、数値への重みが最も大きい。

### 5.3 サンプルホールド

A/D変換には有限の変換時間が必要である。入力が変換中に変化すると正しいコードを得にくいため、サンプルホールド回路である時点の入力値を取り込み、変換中ほぼ一定に保持する。

### 5.4 代表的A/D方式

- 積分形: 入力を一定時間積分する等の方法で変換し、雑音平均化に有利だが高速用途には不利。
- 逐次比較形: MSB側から比較を繰り返してコードを決定し、速度・回路規模のバランスがよい。
- 並列比較形（フラッシュ形）: 多数の比較器を並列使用して高速変換するが、bit数増加で回路規模が急増する。

試験では方式名だけでなく、速度、比較器数、変換時間、用途の関係で判断する。

## 6. A/D問題の解法手順

1. 最高信号周波数から必要標本化周波数の条件を判断する。
2. bit数から量子化段数 `2^n` を求める。
3. 必要なら `q=V_FS/2^n` から分解能を計算する。
4. 量子化誤差と、オフセット・ゲイン等の別誤差を混同しない。
5. 変換中の入力保持が必要ならサンプルホールドを選ぶ。
6. 高速性、回路規模、積分時間等からA/D方式を識別する。
7. MSB/LSBの意味を取り違えない。

## 7. LANと情報伝送

ネットワーク問題では機器・アドレス・無線方式・設定プロトコルの層を混同しない。

### 7.1 リピータ

リピータは主に物理層で信号を再生・中継する。MACアドレスやIPアドレスで転送先を判断する装置ではない。

### 7.2 ブリッジ

ブリッジは主にデータリンク層でフレームを中継し、MACアドレスを用いて転送判断を行う。現在のEthernetスイッチの基本的な学習・転送動作はブリッジ機能の発展として理解できる。

### 7.3 MACとIP

MACアドレスはデータリンク層でフレーム転送に用いる識別子である。IPアドレスはネットワーク層で論理的な宛先を示し、異なるネットワーク間の経路選択に関係する。両者を同じアドレスとして扱わない。

### 7.4 Wi-FiとDHCP

Wi-FiはIEEE 802.11系の無線LAN技術で、物理層・データリンク層に関係する。DHCPは端末へIPアドレス、サブネットマスク、デフォルトゲートウェイ等のネットワーク設定を自動配布するためのプロトコルである。Wi-FiがIPアドレスを割り当てる、DHCPが無線信号を変調する、という理解は誤りである。

## 8. 搬送波・変調・復調

情報を伝送路へ載せるため、搬送波の振幅、周波数、位相等を情報に応じて変化させるのが変調である。受信側で搬送された情報を取り出す処理が復調である。

連続値情報を扱う代表例:

- AM: 振幅を変化させる。
- FM: 周波数を変化させる。
- PM: 位相を変化させる。

デジタル情報を扱う代表例:

- ASK: 離散的な振幅状態を使う。
- FSK: 離散的な周波数状態を使う。
- PSK: 離散的な位相状態を使う。
- QAM: 直交する2成分を用い、振幅と位相の組合せとして多値シンボルを表す。

AMとASK、PMとPSKはともに同じ物理量を変えるが、連続値変調とデジタルシンボル変調を区別する。

## 9. 遠隔計測と遠隔制御

遠隔計測では、現場量をセンサ・CT/VT等で電気信号へ変換し、必要に応じて信号調整、標本化、A/D変換を行い、通信路で監視側へ送る。したがって計測精度はセンサ、変成器、A/D、通信、演算の各段階の誤差・異常に影響される。

遠隔制御では、監視側から操作指令を送るだけでは足りない。対象状態、指令の妥当性、保護条件、安全側動作、通信異常時の扱いを考える必要がある。本章では一般原則だけを扱い、COSMOSの実指令プロトコル、連動条件、操作権限、フェイルセーフ論理を推測しない。

## 10. 状態監視と保護リレーの信頼性

保護リレーシステムでは、保護区間内事故に対して確実に動作する正動作性と、保護区間外事故や正常時に不要動作しない正不動作性の両方が必要である。

信頼性を高める代表的考え方は次のとおり。

- 定期点検・試験
- 自動監視・自己診断
- 部品・装置の低故障率化
- 必要箇所の冗長化
- 異常時の安全側処理

ただし冗長化すれば無条件に信頼性が上がるわけではない。共通電源、共通ソフトウェア、共通環境、切替器等に共通原因故障があると、独立並列モデルほどの改善は得られない。

R2二次「電力・管理」問2では、計器用変成器と保護リレーの信頼性に加え、遮断器・トリップ回路の知識も要求される。

- 77/66 kV級遮断器の代表的定格遮断時間: 5サイクル又は3サイクル。
- 事故除去のため遮断器を開放させる指令を受ける箇所: 引外しコイル（トリップコイル）。
- トリップフリー: 投入指令と引外し指令が競合しても引外しを優先し、事故状態で投入・開放を繰り返さないための機能。

これらはR2二次固定過去問への直接対応であり、COSMOS内部仕様ではない。

## 11. 故障率と信頼度

一定故障率 `λ [1/h]` を仮定する指数分布モデルでは、時刻0で正常な単一要素が時刻 `t [h]` まで故障しない確率、すなわち信頼度は

`R(t)=exp(-λt)`

である。

指数分布では故障率が時間によらず一定という強い仮定を置く。初期故障期や摩耗故障期まで同じ `λ` で表せるとは限らない。

独立故障する要素の直列系では、全要素が正常である必要があるため

`R_series = Π R_i`

独立故障する要素の理想並列系では、少なくとも1要素が正常なら系が機能すると仮定して

`R_parallel = 1 - Π(1-R_i)`

同一信頼度 `R` の2系並列なら

`R_parallel = 1-(1-R)^2`

となる。切替器故障、共通原因故障、負荷分担による故障率変化を無視した理想モデルである。

## 12. 可用性

可用性は、必要なときに系が使用可能である割合・確率を表す概念である。修理可能な単純二状態系を定常状態で扱い、平均故障間隔をMTBF、平均修復時間をMTTRとすると、定常可用性は

`A = MTBF / (MTBF + MTTR)`

で近似できる。

可用性を上げる方法は、MTBFを大きくするだけではない。MTTRを短縮する、故障検出を早める、交換を容易にするなど保全性の改善も有効である。

信頼度と可用性を混同しない。信頼度は一定時間故障せず機能し続ける確率を扱い、可用性は修復を含めて必要時に使用可能である度合いを扱う。

### 13.1 信頼度―時間

`λ = 1.0×10^-4 1/h`

| t [h] | R(t)=exp(-λt) |
|---:|---:|
| 0 | 1.000000 |
| 1000 | 0.904837 |
| 5000 | 0.606531 |
| 10000 | 0.367879 |

グラフでは横軸 `t [h]`、縦軸 `R(t)` とする。

### 13.2 単一系・冗長系比較

同一の独立2系並列、完全切替を仮定する。

`R_parallel = 1-(1-R)^2`

| t [h] | 単一系 R | 理想2並列 R_parallel |
|---:|---:|---:|
| 0 | 1.000000 | 1.000000 |
| 1000 | 0.904837 | 0.990944 |
| 5000 | 0.606531 | 0.845182 |
| 10000 | 0.367879 | 0.600424 |

この差を実設備の実績改善率として扱わない。

### 13.3 可用性比較

教材例として `MTBF=5000 h`, `MTTR=5 h` とすると

`A_single = 5000/(5000+5) = 0.999000999... = 99.9001 %`

同一可用性の2系が独立し、少なくとも1系が使用可能なら系全体が使用可能、切替失敗なしと単純化すると

`A_parallel = 1-(1-A_single)^2`

`= 0.999999001997... = 99.9999002 %`

| モデル | 可用性 |
|---|---:|
| 単一系 | 99.9001 % |
| 理想2並列 | 99.9999002 % |

共通原因故障、切替失敗、計画保守、依存故障を無視しているため、実設備の可用性予測値には使わない。

## 14. 問題を見たときの解法アルゴリズム

### 14.1 計測・A/D・通信問題

1. 問題文の量を `計測 → 変成 → A/D → 伝送 → 監視` のどの段階か分類する。
2. CT/VTなら負担、励磁、変成比、二次側安全条件を見る。
3. A/Dなら標本化、bit数、量子化幅、変換方式、サンプルホールドを見る。
4. LANなら物理層、データリンク層、ネットワーク層、設定プロトコルを分ける。
5. 変調なら何を変化させるか（振幅・周波数・位相）と、連続値/デジタルを分ける。
6. 最後に単位、bit数、百分率、用語の層を検算する。

### 14.2 信頼性・可用性問題

1. 修理を扱うかを確認する。
2. 修理なしの時間信頼度なら `R(t)`、修理を含む定常使用可能率なら `A` を使う。
3. 故障率一定か、独立故障か、直列か並列かを確認する。
4. `λ` と `t` の単位をそろえる。
5. 並列系では `1 - 全系故障確率` を使う。
6. 可用性ではMTBFとMTTRの単位をそろえる。
7. 共通原因・切替失敗を無視した理想モデルかを明記する。

### 14.3 二次記述問題

1. 用語の定義を書く。
2. 目的を書く。
3. なぜ必要かを物理・安全・信頼性の理由で説明する。
4. 必要なら式と単位を示す。
5. 成立条件・例外を書く。
6. 実設備に関する未確認事項を一般論で埋めない。

## 15. 3段階例題

### 15.1 基礎例題 — A/D分解能

0〜10 Vを12 bitで理想A/D変換する。1 LSB相当の量子化幅を求める。

`2^12 = 4096`

`q = 10/4096 = 0.00244140625 V`

したがって

`q ≈ 2.44 mV`

丸め型の理想量子化なら量子化誤差の大きさは概ね `q/2 ≈ 1.22 mV` 以下である。

### 15.2 本試験標準例題 — CT比誤差と安全

公称変成比 `K_n=200`、真の変成比 `K=199` とする。固定過去問で採用する定義に従って比誤差を求め、CT二次側の保守上の注意を述べる。

`ε = (200-199)/199 × 100`

`= 0.502512... %`

よって `ε ≈ +0.503 %`。

また一次に電流が流れているCTの二次側を開放してはならない。二次電流による起磁力の打消しが失われ、鉄心磁束増大、高電圧、発熱等の危険があるためである。

### 15.3 複合例題 — 信頼度と可用性

一定故障率 `λ=1.0×10^-4 1/h` の同一装置2台を独立並列とする。5000 h時点の単一系・理想2並列系の信頼度を求める。また修理可能な単一装置を `MTBF=5000 h`, `MTTR=5 h` とした定常可用性を求める。

単一系:

`R = exp(-1.0×10^-4 × 5000)`

`= exp(-0.5)=0.606531`

理想2並列:

`R_parallel = 1-(1-0.606531)^2`

`= 0.845182`

定常可用性:

`A=5000/(5000+5)=0.999000999...`

`=99.9001 %`

信頼度計算と可用性計算は目的が異なる。さらに並列信頼度は独立故障・完全切替等の理想条件を置いている。

- Wi-FiとDHCPを同じ役割と考える。

- 並列冗長式を共通原因故障がある系へそのまま適用する。
