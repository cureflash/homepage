### R2 二次「電力・管理」問2

固定答案要素は次の5群とする。

1. 計器用変成器は保護リレー・計器を高圧回路から絶縁し、電流・電圧を扱いやすい値へ変成する。代表例はCT・VT。

3. 保護リレーの信頼性には、保護区間内事故への正動作、区間外事故への正不動作、点検・自動監視、低故障率、冗長化が要求される。
4. 77/66 kV級遮断器の代表的定格遮断時間は5サイクル又は3サイクルで、事故除去指令を受ける箇所は引外しコイル（トリップコイル）。
5. トリップフリーは投入指令と引外し指令が競合しても引外しを優先し、事故状態で投入・開放を繰り返さないための機能。

## 教材で必須とする一般式・成立条件

### 信頼度

一定故障率 `λ` の指数分布を仮定すると、

`R(t)=exp(-λt)`

直列系で各要素の故障が独立なら、

`R_series = Π R_i`

並列冗長系で独立故障を仮定すると、

`R_parallel = 1 - Π(1-R_i)`

同一信頼度 `R` の2系並列では、

`R_parallel = 1-(1-R)^2`

共通原因故障や切替器故障を無視した理想モデルであることを明記する。

### 可用性

修理可能系を定常状態で扱い、平均故障間隔と平均修復時間で近似すると、

`A = MTBF / (MTBF + MTTR)`

実設備値ではなく、教材用仮定値で単一系・冗長系・保守性の違いを比較する。

## 教材で必須とする一般SCADAモデル

一般概念モデルとして次の情報フローを扱う。

`計測対象 → CT/VT・センサ → 信号調整 → A/D変換・データ収集 → 通信 → 監視表示/状態判定 → 操作指令 → 制御対象`

これはCOSMOSの内部構成図ではない。実設備の構成・名称・通信方式・配置は一次資料で確認できる範囲のみ別途記載する。
