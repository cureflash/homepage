## 独立解答

### 1. R4一次「機械」問3 — 計器用変成器

1. `(1) = (ハ) 負担`
   - 計器用変成器の二次側に接続される計器・継電器等の負荷は「負担」と呼ぶ。
2. `(2) = (ニ) 励磁`
   - 高透磁率鉄心により励磁電流を小さくして変成比・変流比の精度を高める。
3. `(3) = (チ) 小さ`
   - 巻線抵抗と漏れリアクタンスは極力小さくする。
4. `(4) = (カ) 比誤差`
   - 公称変成比と実際の変成比との差を実際の変成比で除し百分率で表す量は比誤差。
5. `(5) = (イ) 短絡`
   - CT二次側を開路すると過電圧を生じ得るため、機器切離し時は二次端子を短絡する。

### 2. R3一次「機械」問8 — A/D変換

1. `(1) = (チ) 2`
   - 標本化定理より、サンプリング周波数は入力最高周波数の2倍を超える必要がある。
2. `(2) = (ト) 誤差`
   - 量子化単位が小さいほど量子化誤差は小さくなる。
3. `(3) = (カ) 時間`
   - 積分形では入力積分値と基準信号積分値が等しくなるまでの時間を計測して変換値を得る。
4. `(4) = (ヌ) MSB`
   - 逐次比較形は最上位ビット（MSB）側から順に比較する。
5. `(5) = (ヘ) サンプルホールド`
   - 変換中に標本値が変動しないようサンプルホールド回路で保持する。

### 3. H30一次「機械」問8 — LAN中継機器・アドレス

1. `(1) = (ル) リピータ`
   - 物理層で減衰した信号を再生・中継し、アドレス解釈を行わない。
2. `(2) = (ヨ) ブリッジ`
   - データリンク層で複数LANを接続し、スイッチングハブは代表例。
3. `(3) = (ヌ) MAC`
   - データリンク層で参照するアドレスはMACアドレス。
4. `(4) = (チ) Wi-Fi`
   - IEEE 802.11対応無線中継器によるLAN接続はWi-Fi。
5. `(5) = (ヘ) IP`
   - ルータが属するネットワーク層で用いるアドレスはIPアドレスで、DHCPにより自動割当可能。

### 4. H25一次「機械」問8 — 変調・復調

1. `(1) = (ヨ) 搬送波`
   - 原信号に応じて振幅・周波数・位相を変化させる高周波信号は搬送波。
2. `(2) = (ル) 復調`
   - 変調波から原信号を取り出す操作は復調。
3. `(3) = (ロ) AM`
   - 図1は搬送波の振幅が入力アナログ信号に応じて変化しているため振幅変調（AM）。
4. `(4) = (カ) 直交振幅変調`
   - QAMは直交する2搬送波の振幅を組み合わせて情報を載せる直交振幅変調。
5. `(5) = (ト) ASK`
   - 図2はデジタル符号に応じて搬送波振幅を切り替えているため振幅偏移変調（ASK）。

### 5. R2二次「電力・管理」問2 — 固定5群

#### 群1: 小問(1)前半
計器用変成器は、電力系統の高電圧・大電流を計器・保護リレーで安全に扱える低い電圧・電流へ比例変換し、測定・保護に用いるとともに主回路と二次回路を絶縁する。代表例は計器用変圧器 `VT (PT)` と変流器 `CT`。

#### 群2: 小問(1)後半
公称変成比を `K_n`、真の変成比を `K` とすると、比誤差は

`ε = (K_n - K) / K × 100 [%]`

と表す。

#### 群3: 小問(2)
保護リレーに求められる信頼性とは、保護すべき事故が発生したときには確実に動作して事故区間を除去させる一方、正常時や保護範囲外事故では誤動作しないことである。すなわち必要時の確実動作と不要時の不動作の両方を満たすことが必要である。

#### 群4: 小問(3)前半
77又は66 kV系統で一般に用いられる遮断器の定格遮断時間は `3サイクル`。保護リレーから事故除去指令を受ける箇所は `引外し装置（トリップ装置／トリップコイル系）`。

#### 群5: 小問(3)後半
引外し自由（トリップフリー）とは、投入操作・投入指令が継続していても引外し指令を受ければ引外し動作を優先し、遮断器を開路させる機能である。事故が継続している回路への再投入・閉路保持を防ぎ、事故電流を確実に遮断することを目的とする。
