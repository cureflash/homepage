## 独立再解答

### 1. R4一次「機械」問3 — 計器用変成器

1. `(1) ハ：負担`
   - 計器・継電器など、計器用変成器二次側に接続される負荷を負担という。
2. `(2) ニ：励磁`
   - 変比精度を高めるには高透磁率鉄心で励磁電流を小さくする。
3. `(3) チ：小さ`
   - 巻線抵抗と漏れリアクタンスを極力小さくして変比誤差を抑える。
4. `(4) カ：比誤差`
   - 公称変比と実際の変比との差を実際の変比で除して百分率表示したもの。
5. `(5) イ：短絡`
   - CT二次側負荷を切り離す前に二次端子を短絡し、二次開放による危険な過電圧を防止する。

### 2. R3一次「機械」問8 — A/D変換

1. `(1) チ：2`
   - 標本化定理より、最高周波数成分の2倍を超えるサンプリングレートが必要。
2. `(2) ト：誤差`
   - 量子化段階を増やして量子化幅を小さくすると量子化誤差は小さくなる。
3. `(3) カ：時間`
   - 積分形では入力積分値と基準信号積分値が等しくなるまでの時間を測る。
4. `(4) ヌ：MSB`
   - 逐次比較形は最上位ビット側から順に比較する。
5. `(5) ヘ：サンプルホールド`
   - 変換中の入力レベルを保持して変換誤差を抑える。

### 3. H30一次「機械」問8 — LAN中継機器・アドレス

1. `(1) ル：リピータ`
   - 物理層で減衰した信号を増幅・補正して中継する。
2. `(2) ヨ：ブリッジ`
   - データリンク層で複数LANを接続する。
3. `(3) ヌ：MAC`
   - ブリッジ／スイッチングハブはMACアドレスを用いて転送を制御する。
4. `(4) チ：Wi-Fi`
   - IEEE 802.11に対応する無線LAN接続。
5. `(5) ヘ：IP`
   - ルータが扱うネットワーク層のアドレスで、DHCPサーバにより自動割当可能。

### 4. H25一次「機械」問8 — 変調・復調

1. `(1) ヨ：搬送波`
   - 原信号に応じて搬送波の振幅・周波数・位相を変化させるのが変調。
2. `(2) ル：復調`
   - 変調波から原信号を取り出す操作。
3. `(3) ロ：AM`
   - 図1は搬送波振幅が入力アナログ信号に応じて連続的に変化している。
4. `(4) カ：直交振幅変調`
   - QAMは直交する搬送波成分の振幅を組み合わせる変調方式。
5. `(5) ト：ASK`
   - 図2はデジタル符号に応じて搬送波振幅をオン／オフしている。

### 5. R2二次「電力・管理」問2 — 固定5答案要素

#### 群1: 小問(1)前半

計器用変成器は、高電圧・大電流を計器や保護リレーが扱える低い標準値へ変換し、高電圧回路から測定・保護回路を絶縁して安全に情報を取り出すために用いる。代表例は計器用変圧器 `VT（PT）` と変流器 `CT` である。

#### 群2: 小問(1)後半

公称変成比を `K_n`、真の変成比を `K` とすると、比誤差は

`ε = (K_n - K) / K × 100 [%]`

と表す。

#### 群3: 小問(2)

保護リレーの信頼性とは、保護すべき系統事故が発生したときには確実に動作して事故区間を除去し、正常時や保護範囲外事故など動作すべきでないときには誤動作しない性質である。すなわち必要時の確実動作と不要時の不動作の双方を満たすことをいう。

#### 群4: 小問(3)前半

77又は66 kV系統で一般に用いる遮断器の定格遮断時間は `5サイクル`。保護リレーから事故除去指令を受ける箇所は `引外し装置（トリップ装置）` である。

#### 群5: 小問(3)後半

引外し自由（トリップフリー）は、遮断器が投入操作中または投入指令が継続している状態でも、引外し指令を受ければ投入操作に拘束されず直ちに開路できる機能である。事故回路へ投入されたときに、投入指令が残っていても故障電流を確実に遮断し、投入状態へ保持されることを防ぐために必要である。
