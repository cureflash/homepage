## 独立再解答

### 1. R4一次「機械」問3 — 計器用変成器

1. `(1) 負担`。計器・継電器等の二次側接続負荷を、一般の線路負荷と区別していう。
2. `(2) 励磁`。変成比精度を高めるには高透磁率鉄心で励磁電流を小さくする。
3. `(3) 小さ`。巻線抵抗・漏れリアクタンスによる電圧降下を抑える。
4. `(4) 比誤差`。公称変成比と真の変成比との差を真の変成比で除した百分率。
5. `(5) 短絡`。CT二次を開放すると高電圧を生じ得るため、負担切離し時は二次端子を短絡する。

### 2. R3一次「機械」問8 — A/D変換

1. `(1) 2`。標本化定理より最高周波数の2倍を超えるサンプリング周波数が必要。
2. `(2) 誤差`。量子化刻みが小さいほど量子化誤差は小さい。
3. `(3) 時間`。積分形では基準電圧で積分結果を戻すのに要する時間を測る。
4. `(4) MSB`。逐次比較形は最上位ビット側から順に比較して決定する。
5. `(5) サンプルホールド`。変換中に入力レベルを保持して変動を防ぐ。

### 3. H30一次「機械」問8 — LAN中継機器・アドレス

1. `(1) リピータ`。物理層で減衰した信号を増幅・整形して再送する。
2. `(2) ブリッジ`。データリンク層で複数LANを接続する。
3. `(3) MAC`。スイッチングハブはMACアドレスを参照して転送する。
4. `(4) Wi-Fi`。IEEE 802.11系の無線LAN接続。
5. `(5) IP`。DHCPはクライアントにIPアドレス等を自動割当てする。

### 4. H25一次「機械」問8 — 変調・復調

1. `(1) 搬送波`。原信号に応じて搬送波の振幅・周波数・位相を変化させる。
2. `(2) 復調`。受信した変調波から原信号を取り出す操作。
3. `(3) AM`。図1は搬送波振幅が入力信号に応じ連続的に変化する。
4. `(4) 直交振幅変調`。QAMは直交する2搬送波成分の振幅を組み合わせる。
5. `(5) ASK`。図2はビットに応じ搬送波振幅が不連続に切り替わる。

### 5. R2二次「電力・管理」問2 — 固定5群

1. 小問(1)前半: 計器用変成器は、高電圧・大電流を計器・保護リレーで安全かつ適切に扱える低電圧・小電流へ比例変換し、一次高電圧回路と計測・保護回路を絶縁する。代表例は計器用変圧器 `VT (PT)` と変流器 `CT`。
2. 小問(1)後半: 比誤差は `ε = (K_n - K) / K × 100 [%]`。
3. 小問(2): 信頼性とは、保護すべき事故時には確実に動作し、健全時や保護区間外事故では不要動作しないこと。すなわち必要時の確実動作と不要時の誤動作防止を両立すること。
4. 小問(3)前半: 77又は66 kV系統で一般に用いる遮断器の定格遮断時間は `3サイクル`。保護リレーから事故除去指令を受ける箇所は遮断器の `操作機構（引外し機構）`。
5. 小問(3)後半: トリップフリーは、投入指令が継続・同時に存在していても引外し指令を受ければ投入状態に拘束されず直ちに開路できる機能。事故点への投入継続・再投入を防ぎ、事故を確実かつ速やかに除去することが目的。
