## 独立解答

### R4一次「機械」問3 — 計器用変成器

1. `(ハ) 負担`
2. `(ニ) 励磁`
3. `(チ) 小さ`
4. `(カ) 比誤差`
5. `(イ) 短絡`

根拠:
- 計器用変成器二次側の計器・継電器等は負担と呼ぶ。
- 変成比精度向上には高透磁率鉄心で励磁電流を小さくし、巻線抵抗・漏れリアクタンスも小さくする。
- 公称比と実比の差を実比で除した百分率は比誤差。
- CT二次側は開放すると高電圧を生じ得るため、機器切離し時は二次端子を短絡する。

### R3一次「機械」問8 — A/D変換

1. `(チ) 2`
2. `(ト) 誤差`
3. `(カ) 時間`
4. `(ヌ) MSB`
5. `(ヘ) サンプルホールド`

根拠:
- 標本化定理より標本化周波数は最高周波数の2倍を超える必要がある。
- 量子化段階を細かくすると量子化誤差が小さくなる。
- 積分形は積分結果を基準信号で戻し、その時間を測る方式。
- 逐次比較形はMSB側から順に比較する。
- 変換中の入力レベル保持にはサンプルホールド回路を用いる。

### H30一次「機械」問8 — LAN中継機器・アドレス

1. `(ル) リピータ`
2. `(ヨ) ブリッジ`
3. `(ヌ) MAC`
4. `(チ) Wi-Fi`
5. `(イ) DHCP`

根拠:
- 物理層で減衰信号を再生・中継するのはリピータ。
- データリンク層で複数LANを接続するのはブリッジで、MACアドレスを用いる。
- IEEE 802.11系無線LANはWi-Fiとして利用される。
- IPアドレス等の自動割当てにはDHCPを用いる。

### H25一次「機械」問8 — 変調・復調

1. `(ヨ) 搬送波`
2. `(ル) 復調`
3. `(ロ) AM`
4. `(カ) 直交振幅変調`
5. `(ト) ASK`

根拠:
- 原信号に応じて搬送波のパラメータを変えるのが変調で、受信側で原信号を取り出すのが復調。
- 図1は搬送波振幅がアナログ入力に応じ連続変化しているためAM。
- QAMは直交する2成分の振幅を組み合わせる直交振幅変調。
- 図2はディジタル値に応じ搬送波振幅がオン・オフしているためASK。

### R2二次「電力・管理」問2 — 固定5群

#### 群1: 小問(1)前半

計器用変成器は、電力系統の高電圧・大電流を計器・保護リレーが扱える低電圧・小電流へ一定の比で変成し、測定・保護回路を一次系統から絶縁して安全に情報を取り出すために用いる。代表例は計器用変圧器（VT/PT）と変流器（CT）。

#### 群2: 小問(1)後半

比誤差は

`ε = (K_n - K) / K × 100 [%]`

とする。

#### 群3: 小問(2)

信頼性とは、保護すべき事故が保護範囲内で発生したときには確実に動作し、平常時や保護範囲外の事故など動作すべきでない場合には誤動作しない性質である。

#### 群4: 小問(3)前半

77又は66 kV系統用遮断器の定格遮断時間は `3サイクル`。保護リレーから事故除去指令を受ける箇所は `引外し装置（トリップ装置／トリップコイル）`。

#### 群5: 小問(3)後半

引外し自由（トリップフリー）は、投入操作・投入指令が継続していても引外し指令を受けたときは投入操作に拘束されず直ちに遮断動作できる機能である。事故時に遮断器が投入状態へ保持されたり再投入動作と競合したりするのを防ぎ、事故電流を確実・迅速に遮断して機器損傷や事故拡大を防ぐことを目的とする。
