## 2. 記号・単位

| 記号 | 意味 | 単位 |
|---|---|---|
| `V_b` | 電池端子電圧または設計上の代表電圧 | V |
| `E_i` | 電池内部の起電力 | V |
| `R_i` | 電池内部抵抗 | Ω |
| `I` | 電池電流 | A |
| `Q_Ah` | Ah容量 | Ah |
| `Q_C` | 電気量 | C |
| `E` | 電力量 | Wh, kWh |

| `t` | 時間 | h |
| `r` | Cレートの倍率 | h^-1相当 |

## 3. Ah・Wh・電圧・直列並列

### 3.1 Ahは電気量

一定電流 `I` を `t` 時間流したとき

`Q_Ah = I t`

である。また

`1 Ah = 3600 C`

なので

`Q_C = 3600 Q_Ah`

となる。

ファラデー定数を `F ≈ 9.65×10^4 C/mol` とすると

`F/3600 ≈ 26.8 Ah/mol`

である。R8一次「機械」問5では、このCとAhの換算が直接必要になる。

### 3.2 Whはエネルギー

電圧を一定または代表値で扱える条件では

`E_Wh ≈ V_b Q_Ah`

である。電圧が大きく変化する場合、厳密には

`E = ∫ V(t) I(t) dt`

であり、`V×Ah` は一定電圧または平均電圧を用いた近似である。

電力は

`P = V I`

一定電力なら

`E = P t`

である。単位は

`W×h = Wh`

`Wh/V = Ah`

`A×h = Ah`

となる。

### 3.3 直列・並列

同一定格セルを理想的に組むとする。

直列 `N_s` 個:

`V_pack = N_s V_cell`

Ah容量は1セル分と同じである。

並列 `N_p` 個:

`Q_pack = N_p Q_cell`

電圧は1セル分と同じである。したがって

`E_pack ≈ N_s N_p V_cell Q_cell`

となる。

並列化は電流を分担できるが、実際の許容電流はセル仕様・温度・SOC等の制約を受ける。本教材では未確認のN700Sセル仕様を推測せず、問題文で与えられたCレート条件だけを使う。

## 4. 固定一次過去問を解くための最小電池知識

この節は固定過去問の答案要素を欠落させないための最小限の橋渡しであり、電池化学を独立主題として展開するものではない。

### 4.1 鉛蓄電池 — R8一次・R1一次

鉛蓄電池では、代表的に正極活物質が二酸化鉛 `PbO2`、負極が鉛 `Pb`、電解液が硫酸水溶液である。放電に伴って両極側で硫酸鉛 `PbSO4` が生成し、電解液中の硫酸濃度・比重は低下する。

R8一次で必要な要点:
- 1セルの公称電圧は約 `2.0 V`。
- ファラデー定数 `96500 C/mol` は約 `26.8 Ah/mol`。
- 放電状態の把握には電解液比重が使え、比重が小さいほど放電が進んでいる側である。
- 鉛蓄電池は水の理論分解電圧より高いセル電圧をもつため、自己放電・副反応との関係が論点になる。

R1一次で必要な要点:
- 放電で `PbSO4` が生成する。
- 放電に伴い硫酸濃度が低下する。
- `PbO2` 中のPbの酸化数は `+4`。
- 必要活物質量はファラデー則で電気量から物質量へ変換する。

例として、`200 Ah` を2電子反応で担う `PbO2` の理論量は

`Q = 200×3600 = 7.20×10^5 C`

`n(PbO2) = Q/(2F)`

`≈ 7.20×10^5 /(2×9.648×10^4) ≈ 3.73 mol`

`m ≈ 3.73×239.2 ≈ 8.93×10^2 g`

となり、約 `893 g` である。

### 4.2 リチウムイオン二次電池 — R4一次・R2一次

固定過去問で必要な一般事項は次である。

- リチウムイオン電池は充放電可能な二次電池である。
- 代表例では負極に炭素材料、正極にリチウム遷移金属酸化物、電解質にリチウム塩を含む有機電解液を用いる。
- 放電時、負極側では酸化、正極側では還元が進み、リチウムイオンが電解質中を移動する。
- R2一次の設問条件では公称電圧は約 `3.7 V` が論点となる。
- 大電流放電時は内部抵抗等による電圧降下のため、端子電圧は無負荷・公称値より低下する。
- 質量エネルギー密度 `Wh/kg` から必要質量を逆算できる。

R2一次型の計算例を設問文そのものではなく一般化して示す。平均電圧 `3.5 V`、電流 `0.5 A`、時間 `10 h`、質量エネルギー密度 `175 Wh/kg` とすると

`E = 3.5×0.5×10 = 17.5 Wh`

`m = 17.5/175 = 0.10 kg = 100 g`

となる。公称電圧ではなく、問題文で平均電圧が与えられたならその値を使う。

## 5. Cレート・放電電流・内部抵抗

### 5.1 Cレート

定格容量を `C_Ah [Ah]`、Cレートを `r C` とすると、理想化した電流は

`I = r C_Ah`

理想放電時間は

`t = 1/r [h]`

である。

例: `10 Ah` の電池を `2C` で放電するなら

`I = 2×10 = 20 A`

理想時間は `0.5 h` である。

Cレートは電流そのものではない。容量が異なれば、同じ1Cでも電流値は異なる。

### 5.2 内部抵抗を含む端子電圧

内部起電力 `E_i`、内部抵抗 `R_i` とする。

充電時、電池へ流れ込む電流の大きさを `I>0` とすれば

`V_terminal = E_i + I R_i`

放電時、外部へ流す電流の大きさを `I>0` とすれば

`V_terminal = E_i - I R_i`

である。

内部抵抗損失は

`P_R = I^2 R_i`

同じエネルギーをやり取りする場合でも、電流が大きいほど抵抗損失は二乗で増える。

### 5.3 H23二次 問3の数値橋渡し

固定二次問題で与えられる `10 Ah`, `R_i=0.005 Ω`、内部起電力がSOCに応じ `3.6→3.8 V` と変化するモデルを使う。

1C充電:
- `I=+10 A`
- 時間 `1 h`
- 充電開始端子電圧 `3.6+10×0.005 = 3.65 V`
- 充電終了直前 `3.8+10×0.005 = 3.85 V`

2C放電:
- 電流の大きさ `20 A`
- 時間 `0.5 h`
- 放電開始端子電圧 `3.8-20×0.005 = 3.70 V`
- 放電終了時 `3.6-20×0.005 = 3.50 V`

端子電圧と内部起電力を混同せず、充電時は `+IR_i`、放電時は `-IR_i` とする。

## 6. H23二次に必要な可逆チョッパの最小橋渡し

H23二次「機械・制御」問3は、二次電池だけでなく充放電用可逆チョッパの電圧関係を要求する。

### 6.1 充電 — 降圧動作

直流電源電圧を `E_p1`、電池側平均電圧を `E_b1` とし、周期を `T_on+T_off` とする。充電ではS1をスイッチングし、S1とD2を介して電流が連続する降圧チョッパとして

`D = T_on/(T_on+T_off)`

`E_b1 = D E_p1`

となる。

### 6.2 放電 — 昇圧動作

放電ではS2をスイッチングし、S2とD1を介する昇圧チョッパとして

`E_p2 = (T_on+T_off)/T_off × E_b2`

となる。`D=T_on/(T_on+T_off)` と書けば

`E_p2 = E_b2/(1-D)`

である。

### 6.3 充電損失の考え方

内部抵抗損失は `I^2R_i` である。同一の充電エネルギーを与える条件で、過大な端子電圧差によって大電流を流すほど抵抗損失が増える。H23の設定では、異常な過電圧条件を除けば、定電圧方式より定電流方式の方が内部抵抗損失を抑えやすいという理由を説明できるようにする。

ここで扱うのは固定過去問の充放電回路に必要な範囲だけであり、充電器設計を独立主題として追加しない。

## 7. 自走設計のエネルギー収支

### 7.1 各段効率を掛ける向き

車輪側へ必要な機械出力を `P_mech` とし、モーター効率 `η_m`、インバータ効率 `η_inv` とする。インバータ直流入力側で必要な電力は

`P_bat_terminal = P_mech/(η_m η_inv)`

である。

さらに、本教材では電池内部に保持されたエネルギーのうち端子側へ有効に取り出せる割合を放電側電池エネルギー効率 `η_b` と定義する。走行時間 `t [h]` に対して必要な電池内部側エネルギーは

`E_bat_required = P_mech t/(η_m η_inv η_b)`

となる。

効率は出力から入力へ逆算するとき「割る」。`0<η<1` なので、必要入力エネルギーは出力エネルギーより大きくなる。

### 7.2 必要Ah容量

設計上の代表電池電圧を `V_b` とし、一定または平均電圧近似が使えるなら

`Q_energy = E_bat_required/V_b`

で必要Ah容量を求める。`E` をWhで使う場合、`V` で割ればAhになる。

### 7.3 放電電流とCレート条件

端子電圧を `V_b` と近似すると、走行中の電池端子電流は

`I_bat ≈ P_bat_terminal/V_b`

である。

許容最大Cレート `r_max` が問題文で与えられるなら、電流条件から必要な定格容量は

`Q_Crate ≥ I_bat/r_max`

となる。

したがって、エネルギー条件と電流条件の両方を満たすには

`Q_design ≥ max(Q_energy, Q_Crate)`

とする。これは「電力量が足りる」ことと「必要電力を安全に出せる」ことが別条件であることを示す。

## 11. 問題を見たときの解法アルゴリズム

1. 求める量が `W/kW`、`Wh/kWh`、`Ah`、`A` のどれかを確認する。
2. 時間がminならhへ直す。
3. 車輪・軸側の必要出力 `P_mech` が与えられたら `E_mech=P_mech t` を求める。
4. 出力側から入力側へ戻るときは、対応する効率で割る。
5. 電池内部側必要電力量を求めたら、代表電圧で割ってAhへ変換する。
6. 端子側必要電力から `I≈P/V` で電池電流を求める。
7. Cレート上限が与えられたら `Q≥I/r_max` を確認する。
8. エネルギー条件とCレート条件の大きい方を必要容量とする。
9. `W×h=Wh`, `Wh/V=Ah`, `A×h=Ah` で単位を検算する。
10. 問題文にない余裕率、劣化率、SOC使用範囲、走行抵抗は勝手に追加しない。

## 12. 3段階例題

### 12.1 基礎例題 — Ah・Wh・Cレート

教材用電池を `400 V, 80 Ah` とする。理想近似で電力量と0.5C放電電流、理想放電時間を求める。

`E = 400×80 = 32000 Wh = 32 kWh`

`I = 0.5×80 = 40 A`

`t = 1/0.5 = 2 h`

答: `32 kWh`, `40 A`, `2 h`。

### 12.2 本試験標準例題 — エネルギー密度から質量

平均電圧 `3.5 V`、放電電流 `0.5 A`、放電時間 `10 h`、質量エネルギー密度 `175 Wh/kg` の電池について必要質量を求める。

まず電力量:

`E = VIt = 3.5×0.5×10 = 17.5 Wh`

次に

`m = 17.5/175 = 0.10 kg = 100 g`

答: `100 g`。

この例はR2一次型の要求技能へ接続する。平均電圧が与えられているとき、公称電圧へ置き換えない。

### 12.3 複合例題 — 自走エネルギーとCレート制約

以下はすべて教材用仮定値であり、N700S実車値ではない。

- 必要機械出力 `P_mech=300 kW`
- 自走時間 `5 min`
- `η_m=0.93`
- `η_inv=0.96`
- `η_b=0.95`
- 代表電池電圧 `V_b=600 V`
- 許容最大Cレート `2C`

まず機械側エネルギー:

`E_mech=300×5/60=25 kWh`

総合効率:

`η_total=0.93×0.96×0.95=0.84816`

電池内部側必要エネルギー:

`E_bat=25/0.84816=29.48 kWh`

エネルギーだけから必要Ah容量を求めると

`Q_energy=29.48×1000/600=49.13 Ah`

一方、インバータ直流入力側の必要電力は

`P_bat_terminal=300/(0.93×0.96)=336.0 kW`

したがって端子電流は

`I_bat≈336000/600=560 A`

2C以下に抑えるには

`Q_Crate≥560/2=280 Ah`

必要容量は両条件の大きい方なので

`Q_design≥max(49.13,280)=280 Ah`

となる。

この例では短時間なのでエネルギー量だけを見ると49.13 Ahで足りるが、必要電力を2C以内で出す条件が支配的になる。容量設計では `Wh` 条件と `A/C-rate` 条件を分けて確認する。

## 13. 頻出ミス・ひっかけ

- `Ah` と `Wh` を同じ「容量」として混同する。
- `1 Ah = 3600 C` を忘れる。
- `min` のまま `W×h` の式へ代入する。
- 効率を出力から入力へ逆算するとき掛けてしまう。
- 直列接続でAh容量も加算されると誤解する。
- 並列接続で電圧も加算されると誤解する。
- `1C` を常に `1 A` と考える。
- 充電・放電で内部抵抗電圧降下の符号を逆にする。
- 電池内部起電力 `E_i` と端子電圧を同一視する。
- 大電流時も公称電圧がそのまま維持されると考える。
- エネルギー条件だけで必要Ahを決め、Cレート・必要電流を確認しない。
- N700SにSCiBが使われるという確認済み事実から、未確認の電圧・容量・セル数・効率を推測して実値扱いする。
- Topic 25で未指定の走行抵抗モデルを追加し、仮定した速度―電力関係を実車特性とする。

## 15. 公式・解法まとめ

`Q_Ah = I t`

`Q_C = 3600 Q_Ah`

`E_Wh ≈ V_b Q_Ah` 〔一定電圧または平均電圧近似〕

`P = VI`

`E = Pt`

`V_pack=N_s V_cell`

`Q_pack=N_p Q_cell`

`I=r C_Ah`

`t=1/r`

充電: `V_terminal=E_i+IR_i`

放電: `V_terminal=E_i-IR_i`

`P_R=I^2R_i`

充電チョッパ: `E_b1={T_on/(T_on+T_off)}E_p1`

放電チョッパ: `E_p2={(T_on+T_off)/T_off}E_b2`

`P_bat_terminal=P_mech/(η_mη_inv)`

`E_bat_required=P_mech t/(η_mη_invη_b)`

`Q_energy=E_bat_required/V_b`

`I_bat≈P_bat_terminal/V_b`

`Q_Crate≥I_bat/r_max`

`Q_design≥max(Q_energy,Q_Crate)`
