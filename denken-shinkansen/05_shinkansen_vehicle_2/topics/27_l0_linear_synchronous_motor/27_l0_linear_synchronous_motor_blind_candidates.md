## 固定候補

### R7 一次「機械」問1 — 5答案要素

1. `(1)` = `ニ` 界磁起磁力
2. `(2)` = `ヲ` 無負荷誘導起電力
3. `(3)` = `ハ` 電機子反作用起磁力
4. `(4)` = `チ` 内部誘導起電力
5. `(5)` = `ヨ` 電機子漏れリアクタンス

根拠: 界磁電流→界磁起磁力→90°遅れの無負荷誘導起電力。電機子電流→電機子反作用起磁力を合成し、合成起磁力から内部誘導起電力が生じる。電機子反作用を内部起電力側へ織り込んだ図では、端子までの残りのリアクタンス降下は電機子漏れリアクタンスによる。

### R6 一次「機械」問1 — 5答案要素

1. `(1)` = `ト` 電機子反作用
2. `(2)` = `ロ` 増磁作用
3. `(3)` = `ハ` 交差磁化作用
4. `(4)` = `ヌ` 減磁作用
5. `(5)` = `ヨ` 小さくなる

根拠: 電機子電流がギャップ磁束へ及ぼす作用が電機子反作用。同方向成分は増磁、直交成分は交差磁化。同期発電機で遅れ電流は減磁成分をもち、内部誘導起電力は無負荷誘導起電力より小さくなる方向へ変化する。

### H29 一次「機械」問1 — 固定3答案要素

1. `(1)` = `リ` 極数
2. `(2)` = `ヌ` 電源周波数
3. `(5)` = `ト` 電機子反作用

根拠: 回転同期機の同期速度は `N_s=120f/P` で極数と電源周波数により決まる。永久磁石同期電動機の高速域では、電機子電流位相を進め、電機子反作用によって主磁束を弱める弱め界磁を行う。

### H21 一次「機械」問5 — 5答案要素

1. `(1)` = `ヨ` `△Oab と △Ocd`
2. `(2)` = `ホ` `E = E0 - jXa Ia`
3. `(3)` = `ロ` リアクタンス降下
4. `(4)` = `ト` 反作用リアクタンス
5. `(5)` = `カ` `Xa + Xl`

根拠: 図の比例関係と等角条件から`△Oab`と`△Ocd`が相似。`cd`は`Ia`に直交し大きさが`Xa Ia`なので、発電機の標準記号では`E=E0-jXa Ia`。この変化は電機子電流によるリアクタンス降下として表し、`Xa`は電機子反作用リアクタンス、同期リアクタンスは`Xs=Xa+Xl`。
