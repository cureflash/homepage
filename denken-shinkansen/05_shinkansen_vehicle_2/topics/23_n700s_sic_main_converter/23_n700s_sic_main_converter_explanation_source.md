## 0. この教材で到達すること

N700SのSiC主変換装置を題材に、第二種で要求されるパワー半導体の一般損失計算を使って、

`導通損失・スイッチング損失 → 総損失 → 変換効率 → 発熱 → 冷却 → 小型軽量化`

の因果を定量的に説明できるようにする。

固定品質ゲートは制作前EXAM_ALIGNMENTで確定した第二種一次4問＋二次1問、計5問・23答案要素のまま変更しない。Topic 17で一般損失理論は検証済みだが、本sourceだけでも完成後clean blindを解けるよう、必要な式と使い分けは再掲する。

N700S実車の未公表スイッチング周波数、オン電圧、オン抵抗、スイッチングエネルギー、接合温度、熱抵抗は置かない。教材内の比較数値はすべて「仮定値」と明示する。

## 1. N700SでSiCを見るときの境界

確認できる実車事実は次の範囲に限定する。

- 東芝インフラシステムズは、N700S量産車向けにSiC素子を使用した主変換装置を納入している。
  - https://www.global.toshiba/jp/news/infrastructure/2020/09/news-20200909-01.html
- 富士電機は、N700S主変換装置向けSiCパワー半導体モジュールについて、従来モジュールより発熱量が少ない特長を利用して冷却機構を簡素化し、車両用駆動システム全体で従来比20%の軽量化を実現したと説明している。
  - https://www.fujielectric.co.jp/products/blue_navigation/energy_conservation/case_semiconductor.html
- JR東海は、SiC素子駆動システム、車両軽量化、走行抵抗低減などを合わせて、N700Sの電力消費量をN700Aタイプから7%削減したとしている。
  - https://company.jr-central.co.jp/ir/greenbond/bond06/

重要なのは、`7%` をSiC単独の効率改善率へ読み替えないこと。また、富士電機の `20%` は同社資料が示す「車両用駆動システム全体」の従来比軽量化であり、N700S車両全体の重量20%減を意味しない。

SiC採用の教材上の接続は、実車定数を推定するのではなく、同一条件の一般モデルでSi系素子より損失を小さく置いたときに、発熱・冷却・重量へどう波及するかを計算することにある。

## 2. 主変換装置とパワー半導体の役割

主変換装置ではパワー半導体をオン・オフして電圧・電流を変換する。第二種でまず必要なのは、素子を「完全なスイッチ」とだけ見ず、実素子では次の損失が生じると分けて考えること。

1. オンして電流を流している間の導通損失
2. オンとオフの切替中に電圧と電流が重なることで生じるスイッチング損失
3. 必要に応じて漏れ・補助回路等の損失

瞬時電力の基本は

`p(t) = v(t)i(t)`

周期 `T` の平均損失は

`P_loss = (1/T) ∫_0^T v(t)i(t) dt`

である。導通区間と切替区間を分けると、

`P_loss ≈ P_cond + P_sw + その他`

として扱える。

R7一次「機械」問4で要求されるIGBT/MOSFET、逆並列ダイオード、PWM、スイッチング周波数は、この損失式に入る前提である。どの素子に電流が流れているか、1秒間に何回切り替わるかが分からなければ損失は求められない。

### 2.1 チョッパの素子電圧は「矢印極性→状態表→平均値」で読む

通流率問題では、`D` だけを見て `D V_dc` か `(1-D)V_dc` かを決めない。まず問題図の電圧矢印を正方向として、スイッチON/OFFそれぞれで対象素子の両端電圧を表に落とし、その後に時間平均する。

固定R2一次「機械」問2の図では、ダイオード電圧 `v` の矢印極性に対して次となる。

| 状態 | 継続時間 | ダイオード電圧 `v` |
|---|---:|---:|
| スイッチS ON | `DT` | `V_dc` |
| スイッチS OFF・還流 | `(1-D)T` | `0` |

したがって平均電圧は

`V = {V_dc·DT + 0·(1-D)T}/T = D V_dc`

である。一般式を暗記して図へ当てはめるのではなく、図の極性と各状態を先に確定する。

## 3. 導通損失

### 3.1 一定オン電圧モデル

問題でオン時電圧降下 `V_on` が与えられる場合、オン中の電流を一定 `I`、通流率を `D` と近似すれば、

`P_cond = V_on I D`

となる。

ダイオードも順方向電圧降下 `V_F` が与えられるなら同様に

`P_D = V_F I D_D`

と扱う。

H24二次「機械・制御」問1のように、IGBT・ダイオードの電圧降下、電流、通流率が与えられる問題はこの考え方への橋渡しである。

### 3.2 オン抵抗モデル

MOSFET等でオン抵抗 `R_on` が与えられる場合は、実効電流を使って

`P_cond = I_rms^2 R_on`

とする。

一定オン電圧モデルとオン抵抗モデルを混同しない。問題文で与えられた素子モデルに合わせる。

### 3.3 Si系とSiC系の比較条件

比較するときは、少なくとも電圧、電流、通流率、波形条件をそろえる。条件を変えたまま「SiCの方が低損失」と数値比較してはいけない。

#### 指定可視化A: 電流―導通損失

以下は実車値ではなく、比較用仮定値である。

- 通流率 `D = 0.60`
- Si系モデル: `V_on = 2.0 V`
- SiC系モデル: `V_on = 1.4 V`
- 電流 `I = 0, 50, 100, ... , 400 A`

再生成式:

- `P_cond,Si = 2.0 × I × 0.60`
- `P_cond,SiC = 1.4 × I × 0.60`

両者は原点を通る直線となり、この仮定では同一電流でSiC側の導通損失が30%小さい。ただし、この30%は教材の仮定値から得た結果であり、N700S実機の低減率ではない。

## 4. スイッチング損失とスイッチング周波数

オン・オフの切替は瞬時には終わらない。切替中に電圧 `v(t)` と電流 `i(t)` が同時に存在するため、1回の切替エネルギーは

`E_sw = ∫ v(t)i(t) dt`

となる。

ターンオンとターンオフを分ければ

`E_cycle = E_on + E_off`

1秒当たりのスイッチング回数を `f_s` とすると、平均スイッチング損失は

`P_sw = f_s(E_on + E_off)`

である。

R2一次「機械」問2で、ターンオン／ターンオフ波形から `∫vi dt` を求め、周期で割って平均損失へ変換する操作が、この式の直接ゲートになる。R4一次「機械」問4ではオン損失とスイッチング損失の区別、繰返し周期、ソフトスイッチングの意味を区別する。

ここで `1/2` や `1/6` の係数を暗記してはいけない。必ず問題で与えられた `v(t)`、`i(t)`、または積 `p(t)=v(t)i(t)` の波形をそのまま積分する。固定R2一次問2のターンオフ図では `p(t)=i_s v_s` 自体が底辺 `T_2`、高さ `V_dc I_dc` の三角波なので、

`W_off = (1/2)V_dc I_dc T_2`

となる。一方、電圧と電流が同時に相補的な直線ランプとなる別条件では、積が放物線となり `VI t_s/6` になる場合がある。波形条件が違えば係数も変わる。

スイッチング周波数を上げると、1回当たりエネルギーが同じなら `P_sw` は比例して増える。したがって「高周波化＝常に高効率」ではない。波形品質や受動部品小型化の利点と、スイッチング損失増加のトレードオフを分けて考える。

#### 指定可視化B: スイッチング周波数―総損失

以下も実車値ではなく、1個の等価素子を比較する仮定値である。

- Si系: `P_cond = 240 W`, `E_on+E_off = 0.12 J`
- SiC系: `P_cond = 168 W`, `E_on+E_off = 0.05 J`
- `f_s = 0.5, 1, 2, 3, 4 kHz`
- その他損失は比較から除外

再生成式:

- `P_total,Si = 240 + 0.12 f_s`
- `P_total,SiC = 168 + 0.05 f_s`

ここで `f_s` は Hz で代入する。

例として `f_s = 4 kHz` では、

- Si系: `240 + 0.12×4000 = 720 W`
- SiC系: `168 + 0.05×4000 = 368 W`

となる。この差も仮定モデル上の比較結果であり、実車主変換装置の損失値ではない。

## 5. 変換効率

変換器の入出力電力と損失の関係は

`P_in = P_out + P_loss`

したがって効率は

`η = P_out / P_in = P_out / (P_out + P_loss)`

である。

損失が小さくなれば、同一出力条件では効率は上がる。ただし、N700S車両全体の消費電力量は主変換装置だけで決まらない。走行抵抗、車両重量、補機、運転条件等も関係するため、JR東海公表のN700A比7%を上式のSiC単独 `η` 改善率として使わない。

## 6. 損失から発熱・冷却へ

電気的損失は最終的に熱になる。簡略熱抵抗モデルでは、周囲温度 `T_a`、損失 `P_loss`、接合部から周囲までの熱抵抗 `R_th` を用いて

`T_j ≈ T_a + P_loss R_th`

と表せる。

これは詳細な過渡熱解析ではなく、H24一次「機械」問6の放熱設計・半導体接合部温度を、損失計算へ接続するための最小モデルである。

同じ許容接合温度を守るなら、損失が下がるほど必要な熱抵抗条件は緩くできる。すなわち、冷却器・ヒートシンク・送風等に要求される放熱能力を下げられる余地が生じる。

`損失低減 → 発熱低減 → 冷却要求低減 → 冷却機構簡素化 → 小型軽量化`

という因果で読む。

富士電機のN700S向け説明は、この因果と整合しており、SiCモジュールの発熱量が少ない特長を利用して主変換装置の冷却機構を簡素化し、車両用駆動システム全体で従来比20%の軽量化を実現したとしている。ただし、教材の簡略熱抵抗式からこの20%を逆算したり、実車の熱抵抗を推定したりしない。

## 7. SiCとSi系素子を条件をそろえて比較する

SiCを学ぶ目的は「SiCはすごい」という暗記ではなく、同じ仕事をさせたときに損失差がどこから生じ、装置設計へどう波及するかを追うことにある。

比較手順は次の順序で固定する。

1. 同じ電圧・電流・通流率・スイッチング周波数を設定する。
2. 各素子モデルの `V_on` または `R_on` から `P_cond` を求める。
3. 各モデルの `E_on+E_off` と `f_s` から `P_sw` を求める。
4. `P_loss = P_cond + P_sw` を比較する。
5. 同一 `P_out` なら `η` を比較する。
6. 同一 `R_th` なら温度上昇 `ΔT = P_loss R_th` を比較する。
7. 損失低減分を、冷却簡素化・小型軽量化の「可能性」へ接続する。

#### 指定可視化C: 条件をそろえたSi系素子との比較

可視化A・Bと同じ仮定値を使う。代表点 `I=200 A`, `D=0.60`, `f_s=4 kHz` とすると、

- Si系 `P_cond = 240 W`, `P_sw = 480 W`, `P_total = 720 W`
- SiC系 `P_cond = 168 W`, `P_sw = 200 W`, `P_total = 368 W`

同一熱抵抗を仮に `R_th = 0.05 K/W` とすると、

- Si系 `ΔT = 36.0 K`
- SiC系 `ΔT = 18.4 K`

となる。

このグラフ・表には必ず「仮定モデル。N700S実車定数ではない」と注記する。

## 8. 3段階例題

### 例題1 基礎 — 導通損失

仮定: 素子のオン電圧 `V_on=1.5 V`、一定電流 `I=180 A`、通流率 `D=0.65`。

`P_cond = V_on I D`

より、

`P_cond = 1.5×180×0.65 = 175.5 W`

答え: `175.5 W`

確認点: 一定オン電圧モデルであること、通流率を掛けること。

### 例題2 標準 — 波形からスイッチング損失

仮定: 切替中の電圧・電流の重なりを三角形で近似する。`V=600 V`, `I=100 A`, ターンオン重なり時間 `2 μs`, ターンオフ重なり時間 `3 μs`, `f_s=2.0 kHz`。

1回の合計スイッチングエネルギーは

`E_on+E_off ≈ (1/2)VI(t_on+t_off)`

`=0.5×600×100×(2+3)×10^-6 = 0.15 J`

したがって

`P_sw = 2000×0.15 = 300 W`

答え: `300 W`

確認点: `J/回 × 回/s = W`。係数は波形条件から決め、固定R2一次問2では図示された `p(t)` 三角波をそのまま面積計算する。

### 例題3 複合 — Si系/SiC系の損失・効率・温度比較

以下は比較用仮定値。出力 `P_out=100 kW`、等価損失をSi系 `2.4 kW`、SiC系 `1.2 kW` とする。

効率:

- Si系 `η = 100/(100+2.4) = 0.9766 ≈ 97.66%`
- SiC系 `η = 100/(100+1.2) = 0.9881 ≈ 98.81%`

さらに、同一の等価熱抵抗 `R_th=0.020 K/W` を持つ1個の比較ユニットで損失をSi系 `600 W`、SiC系 `300 W` とした場合、

- Si系 `ΔT=600×0.020=12 K`
- SiC系 `ΔT=300×0.020=6 K`

となる。

結論は「この仮定ではSiC側が低損失・高効率・低温度上昇」である。N700Sの実効率や実接合温度の値には置き換えない。
