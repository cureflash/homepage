## 1. R7 一次「機械」問4 — 5要素

問題文のインバータ回路・文章から独立判定する。

1. `(1)` = `誘導性`
   - 方形波電圧に対し、インダクタンスを含む負荷では電流が連続し、逆並列ダイオードで電流経路を確保する。
2. `(2)` = `二つ`
   - 単相フルブリッジでは対角の2素子を同時ONして負荷へ一方向の電圧を与える。同一レグ上下の同時ONは短絡になる。
3. `(3)` = `MOSFET`
   - IGBT以外の代表的な電圧形インバータ用スイッチングデバイス。
4. `(4)` = `PWM`
   - 正弦波変調波と三角波搬送波を比較するパルス幅変調。
5. `(5)` = `スイッチング`
   - 搬送波周波数がインバータのスイッチング周波数を決める。

候補: `誘導性 / 二つ / MOSFET / PWM / スイッチング`

## 2. R4 一次「機械」問4 — 5要素

1. `(1)` = `大きい`
   - 同一電流条件ではオン電圧が大きいほど `p=vi` によりオン損失が増える。
2. `(2)` = `漏れ電流`
   - オフ状態でも実デバイスには微小な漏れ電流が流れる。
3. `(3)` = `スイッチング損失`
   - ターンオン／オフ中に電圧と電流が重なる期間の損失。
4. `(4)` = `が短いほど大きい`
   - 1回当たり切替エネルギーが同じなら `P_sw=f_s E_sw`。周期が短いほど `f_s=1/T` が高く、単位時間当たり損失は増える。
5. `(5)` = `ソフトスイッチング`
   - 電圧と電流の重なりを抑えてスイッチング損失を低減する。

候補: `大きい / 漏れ電流 / スイッチング損失 / が短いほど大きい / ソフトスイッチング`

## 3. R2 一次「機械」問2 — 5要素

1. `(1)` = `通流率`
   - `DT/T=D` はスイッチの通流率。
2. `(2)` = `D V_dc`
   - 問題図のダイオード電圧矢印を正方向に取る。S ON中 `DT` は `v=V_dc`、還流中 `(1-D)T` は `v=0`。したがって `V={V_dc·DT}/T=D V_dc`。
3. `(3)` = `正である`
   - ターンオン／オフ遷移中には `v_s` と `i_s` が同時に正となる重なり期間があり、`p=i_s v_s>0` となる。
4. `(4)` = `(1/2)V_dc I_dc T_2`
   - 問題図3のターンオフ時 `p=i_s v_s` は底辺 `T_2`、高さ `V_dc I_dc` の三角波。その面積が1回の損失エネルギー。
5. `(5)` = `(W_off + W_on)/T`
   - 1周期当たりの損失エネルギーを周期 `T` で割り、平均スイッチング損失にする。

候補: `通流率 / D V_dc / 正である / (1/2)V_dc I_dc T_2 / (W_off+W_on)/T`

## 4. H24 一次「機械」問6 `(2),(3)` — 2要素

1. `(2)` = `放熱`
   - LEDで可視光へ変換されない電力は損失・発熱になるため、筐体の放熱設計が必要。
2. `(3)` = `接合部`
   - 半導体LEDの特性・信頼性を支配する温度として接合部温度を管理する。

候補: `放熱 / 接合部`

## 5. H24 二次「機械・制御」問1 — 6要素

与条件: `V=200 V`, `P_out=3.75 kW`, `n=1500 min^-1`, `I_a=20 A`, ブラシ全電圧降下 `2.5 V`。可逆チョッパは `V_dc=200 V`, IGBT降下 `2 V`, ダイオード降下 `1 V`。鉄損・界磁損・機械損、リアクトル抵抗、電流リプル、スイッチング損失は無視。

1. `(1)` 電機子巻線抵抗
   - 電機子入力 `200×20=4000 W`
   - ブラシ損 `2.5×20=50 W`
   - 電機子銅損 `4000-3750-50=200 W`
   - `R_a=200/20^2=0.500 Ω`
   - 候補: `0.500 Ω`

2. `(2)` 定格トルク・1500 min^-1時の誘導起電力
   - `E=V-I_aR_a-V_brush`
   - `=200-20×0.500-2.5=187.5 V`
   - 候補: `188 V`（有効数字3桁。計算値 `187.5 V`）

3. `(3)` 可逆チョッパ接続・定格トルク時の最高回転速度
   - 正方向力行でS1連続ON時の最大電機子端子電圧は `200-2=198 V`。
   - 定格トルクなので `I_a=20 A`。
   - `E_max=198-20×0.500-2.5=185.5 V`
   - 界磁一定なので `n∝E`。
   - `n_max=1500×185.5/187.5=1484 min^-1`
   - 候補: `1.48×10^3 min^-1`

4. `(4)` 1000 min^-1・定格50%トルク時の電機子端子電圧
   - 界磁一定かつトルク50%より `I_a=10 A`。
   - `E=187.5×1000/1500=125 V`
   - `V_a=125+10×0.500+2.5=132.5 V`
   - 候補: `133 V`（有効数字3桁。計算値 `132.5 V`）

5. `(5)` 上記(4)状態のIGBT `S1` 通流率
   - S1 ON時: `V_a=200-2=198 V`
   - S1 OFF・D2還流時: `V_a=-1 V`
   - 平均 `132.5=198D+(-1)(1-D)=199D-1`
   - `D=133.5/199=0.670854...`
   - 候補: `0.671`

6. `(6)` 制動トルクを定格トルクに制御できる回転速度範囲
   - 定格回生制動では `|I_a|=20 A`。
   - 発電時の電機子端子電圧は `V_a=E-20×0.500-2.5=E-12.5`。
   - S2 ON時の下限端子電圧 `2 V`、D1回生時の上限端子電圧 `200+1=201 V`。
   - よって `2≤E-12.5≤201`、すなわち `14.5≤E≤213.5 V`。
   - `n=1500(E/187.5)` より `116≤n≤1708 min^-1`。
   - 候補: `116 ～ 1.71×10^3 min^-1`
