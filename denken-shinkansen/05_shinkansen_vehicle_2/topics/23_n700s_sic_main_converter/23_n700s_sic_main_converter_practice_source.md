## 共通式・判断基準

- 瞬時損失: `p(t)=v(t)i(t)`
- 平均損失: `P_loss=(1/T)∫vi dt`
- 一定オン電圧モデル: `P_cond=V_on I D`
- オン抵抗モデル: `P_cond=I_rms^2 R_on`。オン中電流一定 `I`、通流率 `D` なら `I_rms=sqrt(D)I` より `P_cond=I^2DR_on`
- オフ漏れ損失: `P_off=V_off I_leak(1-D)`
- スイッチングエネルギー: `E_on=∫vi dt`、`E_off=∫vi dt`
- スイッチング損失: `P_sw=f_s(E_on+E_off)`
- 総損失: `P_total=P_cond+P_sw+必要に応じてP_off`
- 変換効率: `η=P_out/(P_out+P_loss)`
- 簡略接合温度: `T_j=T_a+P_lossR_th`
- 比較条件: 電圧、電流、通流率、スイッチング周波数等をそろえる
- 冷却・小型軽量化の因果: `損失低減→発熱低減→必要冷却能力低減→冷却機構簡素化→小型軽量化の余地`

固定H24二次問1への橋渡しでだけ、`V_a=E+R_aI_a`、`E∝n`、`V_a=D V_state1+(1-D)V_state2` を用いる。直流機制御自体をTopic 23の新規主題にはしない。

# 一次試験型

## 問1 パワー半導体と還流経路

電圧形インバータが誘導性負荷を駆動している。最も適切な記述を選べ。

1. 主スイッチをOFFすると負荷電流は必ず瞬時に0になる。
2. 上下アームを同時ONして直流電源を短絡させることが通常運転で必要である。
3. IGBTやMOSFETは自己消弧形スイッチング素子として扱え、逆並列ダイオードは誘導性負荷電流の還流経路を担う。
4. 逆並列ダイオードはPWM搬送波を発生する素子である。
5. IGBTと逆並列ダイオードは常に同時に同じ電流を分担する。

### 正答

3

### 完全解説

誘導性負荷の電流は瞬時に0へ変化できないため、主スイッチが電流を受け持たない区間には還流経路が必要となる。IGBT/MOSFETと逆並列ダイオードは役割が異なる。上下アーム同時ONは直流短絡につながるため避ける。

## 問2 条件をそろえた導通損失比較

一般比較モデルで、通流率 `D=0.60`、電流 `I=200 A` とする。Si系モデルは `V_on=2.0 V`、SiC系モデルは `V_on=1.4 V` と仮定する。導通損失の組合せとして正しいものを選べ。

1. Si `120 W`、SiC `84 W`
2. Si `168 W`、SiC `240 W`
3. Si `240 W`、SiC `168 W`
4. Si `400 W`、SiC `280 W`
5. 両者とも `240 W`

### 正答

3

### 完全解説

`P_cond=V_onID` より、

Si系: `2.0×200×0.60=240 W`

SiC系: `1.4×200×0.60=168 W`

この仮定モデルではSiC側が30%小さい。ただし30%は教材仮定値による結果であり、N700S実車の低減率ではない。

## 問3 オン抵抗モデルの導通損失

一般素子で、オン抵抗 `R_on=8.0 mΩ`、オン中電流 `I=250 A`、通流率 `D=0.60` とする。オン中電流は一定とする。平均導通損失として最も近いものを選べ。

1. `120 W`
2. `240 W`
3. `300 W`
4. `500 W`
5. `750 W`

### 正答

3

### 完全解説

`R_on=0.008 Ω`。オン中電流一定なら `I_rms=sqrt(D)I` なので、

`P_cond=I^2DR_on=250^2×0.60×0.008=300 W`

となる。一定オン電圧モデル `V_onID` と混同しない。

## 問4 波形積分からスイッチング損失

一般素子で、ターンオン時に `v(t)=600(1-t/t_s) V`、`i(t)=150(t/t_s) A` が `t_s=2 μs` の間成り立つ。ターンオフ時は同形の電圧・電流重なりが `4 μs` 続く。スイッチング周波数を `4.0 kHz` とする。平均スイッチング損失として最も近いものを選べ。

1. `90 W`
2. `180 W`
3. `360 W`
4. `720 W`
5. `1.44 kW`

### 正答

3

### 完全解説

与えられた直線変化では

`E=∫_0^ts 600×150×(1-t/t_s)(t/t_s)dt=VI t_s/6`

となる。

`E_on=600×150×2×10^-6/6=0.030 J`

`E_off=600×150×4×10^-6/6=0.060 J`

したがって

`P_sw=4000×(0.030+0.060)=360 W`

である。`J/回 × 回/s = W` を確認する。

オフ時電圧 `V_off=800 V`、漏れ電流 `I_leak=2.0 mA`、通流率 `D=0.75` とする。オフ期間の平均漏れ損失として最も近いものを選べ。

1. `0 W`
2. `0.40 W`
3. `1.6 W`
4. `4.0 W`
5. `400 W`

### 正答

2

### 完全解説

オフ期間は `1-D=0.25` なので、

`P_off=800×0.002×0.25=0.40 W`

となる。問題条件で漏れ電流が与えられた場合は0と決めつけない。

## 問6 PWM・周波数・総損失

正弦波PWMで、正弦波の変調波と三角波の搬送波を比較してゲートパルスを生成し、搬送波周波数を代表スイッチング周波数 `f_s` とみなす。教材用仮定モデルを次とする。

- Si系: `P_cond=240 W`, `E_on+E_off=0.12 J`
- SiC系: `P_cond=168 W`, `E_on+E_off=0.05 J`
- `f_s=4.0 kHz`

正しい記述を選べ。

1. 総損失はSi `720 W`、SiC `368 W`。1回当たり切替エネルギー一定なら `P_sw` は `f_s` に比例し、ソフトスイッチングは切替時の `vi` 重なりを小さくする方向で用いる。
2. 総損失はSi `368 W`、SiC `720 W`。`P_sw` は `f_s` に反比例する。
3. 両者の総損失は `408 W`。搬送波周波数は損失と無関係である。
4. SiC系はスイッチング損失が必ず0になる。
5. ソフトスイッチングはオン抵抗を必ず0にする技術である。

### 正答

1

### 完全解説

Si系: `P_sw=4000×0.12=480 W`、`P_total=240+480=720 W`。

SiC系: `P_sw=4000×0.05=200 W`、`P_total=168+200=368 W`。

`E_on+E_off` が一定なら `P_sw=f_s(E_on+E_off)` なので周波数に比例する。ソフトスイッチングは切替時の電圧・電流重なりを低減し、1回当たり切替エネルギーを減らす方向で用いる。

## 問7 損失・接合温度・冷却

問6と同じ仮定モデルで、周囲温度 `T_a=40 °C`、等価熱抵抗 `R_th=0.050 K/W` とする。正しい組合せを選べ。

1. Si `76.0 °C`、SiC `58.4 °C`
2. Si `58.4 °C`、SiC `76.0 °C`
3. Si `54.4 °C`、SiC `48.4 °C`
4. 両者とも `40 °C`
5. SiC側の損失が小さくても冷却要求には影響しない。

### 正答

1

### 完全解説

`T_j=T_a+P_lossR_th` より、

Si系: `40+720×0.050=76.0 °C`

SiC系: `40+368×0.050=58.4 °C`

同じ熱抵抗なら損失が小さい側ほど温度上昇が小さい。同じ許容接合温度を守る設計では、損失低減により必要冷却能力を緩和できる余地が生じる。

## 問8 変換効率とN700S資料の読み方

同一出力 `P_out=100 kW` の一般比較モデルで、総損失をSi系 `2.4 kW`、SiC系 `1.2 kW` とする。最も適切な記述を選べ。

1. 効率はSi約 `97.66%`、SiC約 `98.81%`。JR東海公表のN700A比7%消費電力量低減はSiCだけの寄与とは扱わず、富士電機公表の20%軽量化は車両用駆動システム全体の従来比として扱う。
2. 効率はSi約 `98.81%`、SiC約 `97.66%`。7%はSiC単独効率改善率である。
3. 両者とも効率100%であり、損失は効率に影響しない。
4. 富士電機公表の20%はN700S車両全体の重量が20%減ったことを意味する。
5. JR東海の7%と富士電機の20%を足してSiC効果27%と扱える。

### 正答

1

### 完全解説

Si系:

`η=100/(100+2.4)=0.9765625≈97.66%`

SiC系:

`η=100/(100+1.2)=0.988142...≈98.81%`

実車資料の数値は対象範囲を変えない。N700Sの7%はSiC駆動システムだけでなく車体軽量化・走行抵抗低減等を含む。20%は富士電機資料が示す車両用駆動システム全体の従来比軽量化で、車両全体の重量低減率ではない。

(a)

`P_cond,Si=2.0×I×0.60=1.20I`

`P_cond,SiC=1.4×I×0.60=0.84I`

| 0 | 0 | 0 |
| 100 | 120 | 84 |

(b)

`P_total,Si=240+0.12f_s`

`P_total,SiC=168+0.05f_s`

(c)

## 問3 H24二次橋渡し — 可逆チョッパの平均電圧・導通損失

固定H24二次問1の6答案要素へ接続するための一般教材モデルとする。直流電源 `V_s=600 V`、IGBTオン電圧 `V_T=2.0 V`、ダイオード順方向電圧 `V_D=1.5 V`。状態1は `V_state1=V_s-V_T=598 V`、状態2は `V_state2=-V_D=-1.5 V` とする。直流機は `R_a=0.20 Ω`、一定界磁で `V_a=E+R_aI_a` とする。

(a) 電動時 `E=300 V`, `I_a=80 A` の必要端子平均電圧 `V_a` を求めよ。

(b) `V_a=D V_state1+(1-D)V_state2` から通流率 `D` を求めよ。

(c) 状態1ではIGBT損失 `V_T|I_a|`、状態2ではダイオード損失 `V_D|I_a|` として平均導通損失を求めよ。

(d) 制約確認用の抽象平均モデルとして、端子平均電圧が同じ二状態の凸結合で与えられるとする。`I_a=-80 A`、`E=400 V` at `1000 min^-1` のとき、`0≤D≤1` から許される `E` と速度範囲を求めよ。これはN700S実車回路を表す値ではない。

### 完全解説

(a)

`V_a=300+0.20×80=316 V`

(b)

`316=598D-1.5(1-D)=599.5D-1.5`

`D=317.5/599.5=0.5296`

(c)

状態1: `2.0×80=160 W`

状態2: `1.5×80=120 W`

`P_cond=160D+120(1-D)=120+40×0.5296≈141.2 W`

(d)

`I_a=-80 A` より `V_a=E-16`。

`0≤D≤1` から `-1.5≤V_a≤598`、したがって `14.5≤E≤614 V`。

一定界磁で `E∝n`、`E/n=400/1000=0.4 V/(min^-1)` なので、

`36.25≤n≤1535 min^-1`

となる。この問は固定過去問への橋渡しに必要な範囲だけを扱い、直流機制御をTopic 23の独立主題にはしない。

## 問4 損失低減から冷却・小型軽量化まで

同一出力 `P_out=100 kW`、周囲温度 `T_a=40 °C` の一般比較ユニットで、総損失をSi系 `720 W`、SiC系 `368 W` とする。

(a) 両者の変換効率を求めよ。

(b) `R_th=0.050 K/W` のとき接合温度を求めよ。

(c) 許容接合温度を `70 °C` とするとき、許される最大熱抵抗 `R_th,max` を両者について求めよ。

(d) この結果をN700S資料へ接続するとき、JR東海の7%と富士電機の20%をどう扱うべきか説明せよ。

### 完全解説

(a)

Si系: `η=100000/(100000+720)=99.29%`

SiC系: `η=100000/(100000+368)=99.63%`

(b)

Si系: `T_j=40+720×0.050=76.0 °C`

SiC系: `T_j=40+368×0.050=58.4 °C`

(c)

`R_th,max=(T_j,max-T_a)/P_loss`

Si系: `30/720=0.0417 K/W`

SiC系: `30/368=0.0815 K/W`

この仮定では、損失が小さいSiC側は同じ許容温度に対してより大きい熱抵抗を許容できる。すなわち必要冷却能力を緩和でき、冷却機構簡素化・小型軽量化へつながる余地が生じる。

(d)

JR東海のN700A比7%消費電力量低減はSiC駆動システム、車体軽量化、走行抵抗低減等を合わせた値であり、SiC単独の効率改善率へ置き換えない。富士電機の20%は車両用駆動システム全体の従来比軽量化であり、N700S車両全体の重量20%減とは扱わない。教材計算からこれらの実車値を逆算しない。
