## 固定候補

### R7 一次「機械」問4

1. `(1)` 誘導性 `(ホ)`
2. `(2)` 二つ `(ル)`
3. `(3)` MOSFET `(チ)`
4. `(4)` PWM `(イ)`
5. `(5)` スイッチング `(ハ)`

根拠: 誘導性負荷では電流が連続するため逆並列ダイオードで還流経路を確保する。単相ブリッジでは同時導通は対角の2素子、自己消弧形素子としてMOSFETも用いられる。正弦波変調波と三角波搬送波を比較するPWMでは搬送波が代表スイッチング周波数を決める。

### R4 一次「機械」問4

1. `(1)` 大きい `(ハ)`
2. `(2)` 漏れ電流 `(イ)`
3. `(3)` スイッチング損失 `(ト)`
4. `(4)` が短いほど大きい `(ロ)`
5. `(5)` ソフトスイッチング `(ル)`

根拠: オン損失は端子間オン電圧と電流の積で増え、オフ時には微小な漏れ電流が流れる。切替中の `v(t)i(t)` の重なりがスイッチング損失で、1回当たり切替エネルギーが同じなら `P_sw=f_s(E_on+E_off)` なので周期が短いほど単位時間損失は増える。電圧・電流の重なりを低減する代表手法がソフトスイッチング。

### R2 一次「機械」問2

1. `(1)` 通流率 `(カ)`
2. `(2)` `(1-D)V_dc` `(ロ)`
3. `(3)` 正である `(ヨ)`
4. `(4)` `(1/6)V_dc I_dc T_2` `(ヘ)`
5. `(5)` `(W_off+W_on)/T` `(ホ)`

根拠: スイッチSのオン期間は `DT`。ダイオード電圧はSオン中0、オフ中 `V_dc` なので平均は `(1-D)V_dc`。ターンオフの線形モデルでは `v` 上昇と `i` 下降が同時に正となり、`∫vi dt=V_dc I_dc T_2/6`。1周期当たりの切替エネルギーを周期 `T` で割れば平均スイッチング損失となる。

### H24 一次「機械」問6 — 固定対象 `(2),(3)`

1. `(2)` 放熱 `(ル)`
2. `(3)` 接合部 `(カ)`

根拠: LEDで発生した損失熱を外部へ逃がすため筐体の放熱設計が必要で、半導体の特性・信頼性に直接関係する代表温度は接合部温度。

### H24 二次「機械・制御」問1

与条件から、定格運転時の誘導起電力は機械出力と電機子電流より

`E_r=P_out/I_a=3750/20=187.5 V`

一定界磁なので `E∝n`、定格トルクでは `|I_a|=20 A` とする。正負ブラシ全電圧降下は電流方向に対する内部電圧降下として扱う。

1. `(1)` 電機子巻線抵抗 `R_a=0.50 Ω`
   - `200=187.5+20R_a+2.5`
2. `(2)` 誘導起電力 `E=187.5 V`
3. `(3)` 定格トルク時の最高回転速度 `n_max=1484 min^-1`
   - S1連続導通時の最大端子電圧 `V_a,max=200-2=198 V`
   - `E_max=198-20×0.50-2.5=185.5 V`
   - `n_max=1500×185.5/187.5=1484 min^-1`
4. `(4)` 1000 min^-1、50%定格トルク時の端子電圧 `V_a=132.5 V`
   - `E=187.5×1000/1500=125 V`
   - `I_a=10 A`
   - `V_a=125+10×0.50+2.5=132.5 V`
5. `(5)` IGBT S1の通流率 `D=0.67085… ≈ 0.671`
   - S1オン時 `198 V`、D2還流時 `-1 V`
   - `132.5=198D-1(1-D)=199D-1`
6. `(6)` 定格制動トルクを制御可能な回転速度範囲 `116 ≤ n ≤ 1708 min^-1`
   - 回生時 `I_a=-20 A` なので `V_a=E-20×0.50-2.5=E-12.5`
   - S2オン時 `V_a=2 V`、D1回生時 `V_a=201 V` より `2≤V_a≤201`
   - よって `14.5≤E≤213.5 V`
   - `E/n=187.5/1500=0.125 V/(min^-1)` より `116≤n≤1708 min^-1`
