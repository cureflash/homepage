## 検証で確定した要求式・条件

- 巻数比: `a=N1/N2≈V1/V2`。インピーダンスの一次換算は `Z'=a²Z`、アドミタンスは `Y'=Y/a²`。
- 無負荷試験: `g0=P0/V0²`, `Y0=I0/V0`, `b0=sqrt(Y0²-g0²)`。無負荷電流が小さく直列部の損失・電圧降下を無視できる条件で入力電力をほぼ鉄損とみなす。
- 短絡試験: `Z=Vsc/Isc`, `R=Psc/Isc²`, `X=sqrt(Z²-R²)`。短絡時の印加電圧が低く鉄損・励磁電流を無視できる条件で入力電力をほぼ銅損とみなす。
- 百分率量: `%z=100 Z I_N/V_N=100 Z S_N/V_N²`, `%r=100 R I_N/V_N`、`%x=sqrt(%z²-%r²)`。基準容量・基準電圧とオーム値の対応を明示する。
- 電圧変動率: 遅れ力率の一次近似は `ε≈p cosφ+q sinφ`。進みではリアクタンス項の符号が変わる。必要な問題では二次項を含む式を使い、負荷率 `k` では `p,q` が `k` 倍になる。
- 効率: `Pout=k S_N cosφ`, `Pcu=k²Pcu,N`, `η=Pout/(Pout+Pi+Pcu)`。最大効率条件は `Pi=k²Pcu,N`。

# 解説本文

## 1. このテーマで電験は何を問うか

変圧器問題で問われる中心は、銘板値を覚えることではなく、試験値や定格値から等価回路を組み立て、電圧変動率・損失・効率まで一貫して計算できるかである。

一次試験では、巻数比、換算抵抗、短絡試験、百分率インピーダンス、損失などを個別に問う選択式が多い。二次試験では、無負荷試験と短絡試験の測定値から `R, X, g0, b0` を求め、さらに `%r, %x`、電圧変動率、部分負荷効率まで連続して求める形が重要になる。

この章の到達目標は次のとおり。

1. 一次側・二次側の量を同一側へ正しく換算できる。
2. 無負荷試験から励磁枝、短絡試験から直列枝の定数を求められる。
3. オーム値と百分率量を相互変換できる。
4. 遅れ・進み力率を区別して電圧変動率を求められる。
5. 鉄損・銅損と負荷率から効率、最大効率条件を求められる。
6. 二次試験で、近似条件・途中式・単位を含む答案を書ける。

## 2. 理想変圧器から実変圧器へ

### 2.1 巻数比・電圧比・電流比

一次巻数を `N1`、二次巻数を `N2` とし、巻数比を

```text
a = N1 / N2
```

とする。理想変圧器では

```text
V1 / V2 = N1 / N2 = a
```

であり、損失がなければ

```text
V1 I1 = V2 I2
```

だから

```text
I1 / I2 = 1 / a
```

となる。電圧は巻数比に比例するが、電流は逆比になる。

### 2.2 実変圧器で追加される要素

実変圧器では理想変圧器に対して次の要素が加わる。

- 一次巻線抵抗 `r1`
- 二次巻線抵抗 `r2`
- 一次漏れリアクタンス `x1`
- 二次漏れリアクタンス `x2`
- 鉄損を表す励磁コンダクタンス `g0`
- 磁化に必要な無効電流を表す励磁サセプタンス `b0`

巻線抵抗では `I²R` の銅損が生じる。漏れリアクタンスは、一次・二次の双方に完全には鎖交しない漏れ磁束を回路量で表したものである。励磁電流は無負荷でも流れ、鉄損電流と磁化電流に分けて扱う。

交流時の巻線抵抗は、導体内で電流密度が一様でなくなる表皮効果などにより直流抵抗より大きくなる場合がある。そのため、直流抵抗から作った抵抗値と短絡試験から得る交流等価抵抗が一致しない場合、それだけで計算誤りとは判断しない。

## 3. 一次換算・二次換算と簡易等価回路

二次側量を一次側へ換算すると、理想変圧器部分を消して同一電圧レベルの回路として扱える。

二次側電圧・電流は

```text
V2' = a V2
I2' = I2 / a
```

となる。したがってインピーダンスは

```text
Z2' = V2' / I2'
    = a² Z2
```

である。逆に一次側インピーダンスを二次側へ換算すると `1/a²` 倍になる。

アドミタンスはインピーダンスの逆数なので、二次側アドミタンスを一次側へ換算すると

```text
Y2' = Y2 / a²
```

となる。

一次換算した直列等価定数は

```text
R = r1 + a² r2
X = x1 + a² x2
```

である。励磁枝を一次側へ置く簡易等価回路では、一次端子に `g0 - j b0` の並列枝、その先に `R + jX` の直列枝がある形で扱う。

重要なのは、どちら側へ換算した値かを途中で変えないことである。`V, I, R, X, g0, b0` は同一側の値にそろえてから式へ代入する。

## 4. 無負荷試験・短絡試験

### 4.1 無負荷試験から励磁枝を求める

二次側を開放し、試験を行う側へ定格周波数の電圧を加える。測定値を電圧 `V0 [V]`、無負荷電流 `I0 [A]`、入力電力 `P0 [W]` とする。

無負荷電流が定格電流に比べて小さいため直列巻線での銅損・電圧降下を無視できるとき、入力電力はほぼ鉄損とみなせる。

全励磁アドミタンスの大きさは

```text
Y0 = I0 / V0  [S]
```

鉄損に対応するコンダクタンスは

```text
g0 = P0 / V0²  [S]
```

したがって励磁サセプタンスの大きさは

```text
b0 = sqrt(Y0² - g0²)  [S]
```

となる。誘導性の励磁枝を複素数で書けば `Y0 = g0 - j b0` である。

必要なら鉄損抵抗と励磁リアクタンスは

```text
Rc = 1 / g0  [Ω]
Xm = 1 / b0  [Ω]
```

へ変換できる。

### 4.2 短絡試験から直列枝を求める

二次側を短絡し、定格電流が流れる程度まで低い電圧を加える。測定値を `Vsc [V]`, `Isc [A]`, `Psc [W]` とする。

印加電圧が定格電圧より十分低く、磁束と励磁電流が小さいため鉄損を無視できるとき、入力電力はほぼ直列抵抗による銅損とみなせる。

まず

```text
Z = Vsc / Isc  [Ω]
```

次に

```text
R = Psc / Isc²  [Ω]
```

最後に

```text
X = sqrt(Z² - R²)  [Ω]
```

の順で求める。

短絡試験が定格電流以外で行われた場合、`R=Psc/Isc²` はその測定から等価抵抗を求める式として使えるが、得られた電力 `Psc` 自体を定格銅損としてそのまま使ってよいとは限らない。定格銅損へ直す場合は電流比の二乗で換算する。

## 5. `%Z / %r / %x` と基準量

### 5.1 基準インピーダンス

単相変圧器で、ある側の定格電圧を `VN`、定格容量を `SN` とすると、定格電流は

```text
IN = SN / VN
```

基準インピーダンスは

```text
ZB = VN / IN
   = VN² / SN
```

である。

同じ側へ換算した `R, X, Z` を使えば

```text
%r = 100 R / ZB
%x = 100 X / ZB
%Z = 100 Z / ZB
```

または

```text
%r = 100 R IN / VN
%x = 100 X IN / VN
%Z = 100 Z IN / VN
```

と書ける。

直列回路では `Z²=R²+X²` なので

```text
%Z = sqrt((%r)² + (%x)²)
```

である。

定格電流で短絡試験を行った場合、`%Z` は「定格電流を流すのに必要な短絡試験電圧が定格電圧の何%か」と一致する。

### 5.2 `%r` と銅損

定格電流時には

```text
Pcu,N = IN² R
```

である。一方 `SN=VN IN` だから

```text
%r = 100 Pcu,N / SN
```

となる。短絡試験電力と百分率抵抗降下は直接つながっている。

### 5.3 基準容量を変更するとき

同じ物理インピーダンス `Z` を別の基準値へ換算する場合、単位法では

```text
zpu,new = zpu,old × (SB,new / SB,old) × (VB,old / VB,new)²
```

となる。同一基準電圧なら、基準容量を2倍にすると単位法インピーダンスも2倍になる。

変圧器の一次側・二次側で基準電圧を巻数比に合わせて選べば、理想変圧器をまたいでも単位法インピーダンスは同じ値として扱える。自己容量基準の `%Z` と、系統計算用に基準容量を変更した `%Z` を混在させない。

## 6. フェーザ図と電圧変動率

### 6.1 定義と一次近似

負荷による直列インピーダンスの電圧降下により、二次端子電圧は無負荷時と負荷時で変化する。百分率抵抗降下を `p [%]`、百分率リアクタンス降下を `q [%]`、力率を `cosφ` とする。

遅れ力率では、端子電圧と同相方向の電圧降下成分が

```text
p cosφ + q sinφ
```

となるため、一次近似の電圧変動率は

```text
ε ≈ p cosφ + q sinφ  [%]
```

である。

進み力率ではリアクタンス降下の同相成分が逆向きになるため

```text
ε ≈ p cosφ - q sinφ  [%]
```

となる。進み力率では `ε` が負になり、負荷時端子電圧が無負荷時より高くなる場合がある。

負荷率を `k` とすると電流は定格の `k` 倍なので、同じ力率なら一次近似の電圧変動率も

```text
εk ≈ k εN
```

と電流に比例する。

### 6.2 二次項を残す場合

二次試験では一次近似だけでなく、フェーザの直交成分を二次項まで残す場合がある。

遅れ力率について

```text
A = k(p cosφ + q sinφ)
B = k(q cosφ - p sinφ)
```

とおくと、小さい電圧降下を仮定した二次近似は

```text
ε ≈ A + B² / 200  [%]
```

となる。

進み力率では

```text
A = k(p cosφ - q sinφ)
B = k(q cosφ + p sinφ)
```

として同じ形を使う。

この式は `p, q` を百分率の数値で入れる形である。問題が厳密なフェーザ計算を要求している場合、近似式へ勝手に置き換えず、複素電圧の大きさから計算する。

## 7. 鉄損・銅損・効率・負荷率

### 7.1 鉄損と銅損

定格付近で電圧・周波数が一定なら、鉄損 `Pi` は負荷によらずほぼ一定として扱う。一方、銅損は `I²R` なので負荷率 `k` の二乗に比例する。

全負荷銅損を `Pcu,N` とすれば

```text
Pcu = k² Pcu,N
```

である。

### 7.2 規約効率

定格容量 `SN [VA]`、負荷率 `k`、負荷力率 `cosφ` のとき出力有効電力は

```text
Pout = k SN cosφ
```

したがって規約効率は

```text
η = Pout / (Pout + Pi + k² Pcu,N)
```

である。

`SN` を kVA、損失を kW で扱う場合、`Pout` も kW にそろえる。百分率と小数も混在させない。

### 7.3 最大効率条件

力率を一定として負荷率を変えるとき、効率最大条件は

```text
Pi = k² Pcu,N
```

すなわち

```text
kmax = sqrt(Pi / Pcu,N)
```

である。

「鉄損と全負荷銅損が等しい」とは限らない。最大効率点で等しいのは鉄損と、その負荷率における実際の銅損である。

## 8. 本試験標準の解法手順と3段階例題

### 8.1 再利用する解法手順

変圧器の複合問題では、次の順番を固定すると抜けが減る。

1. 定格容量、定格電圧、巻数比から定格電流と換算側を決める。
2. 無負荷試験から `g0, b0` と鉄損を求める。
3. 短絡試験から `Z, R, X` と銅損を求める。
4. `ZB=VN²/SN` から `%r, %x, %Z` を求める。
5. 力率の遅れ・進みを判定し、電圧変動率を求める。
6. 負荷率が指定されていれば、電圧降下は `k` 倍、銅損は `k²` 倍にする。
7. 出力有効電力と損失から効率を求める。
8. 指定桁へ丸める前の中間値を残し、単位と物理的妥当性を確認する。

### 8.2 基礎例題: 一次換算

教材用の仮定値として、巻数比 `a=10` の単相変圧器があり、二次巻線抵抗 `r2=0.020 Ω`、二次漏れリアクタンス `x2=0.030 Ω` とする。これらを一次側へ換算する。

インピーダンスは巻数比の二乗で換算するから

```text
r2' = a² r2
    = 10² × 0.020
    = 2.00 Ω

x2' = a² x2
    = 10² × 0.030
    = 3.00 Ω
```

一次巻線側に `r1=1.00 Ω`, `x1=2.00 Ω` があるなら、一次換算直列等価定数は

```text
R = r1 + r2' = 3.00 Ω
X = x1 + x2' = 5.00 Ω
```

となる。

ここで `r2` を単に10倍するのは誤りである。電圧は `a` 倍、電流は `1/a` 倍になるため、`Z=V/I` は `a²` 倍になる。

### 8.3 本試験標準例題: 無負荷・短絡試験から電圧変動率と効率まで

教材用の仮定値として、単相 `100 kVA`, `2000/200 V` の変圧器を考える。すべて2000 V側換算とし、次の試験値が得られたとする。

無負荷試験:

```text
V0 = 2000 V
I0 = 2.00 A
P0 = 1600 W
```

短絡試験:

```text
Vsc = 100 V
Isc = 50.0 A
Psc = 2500 W
```

2000 V側の定格電流は

```text
IN = 100000 / 2000
   = 50.0 A
```

なので、短絡試験は定格電流で行われている。

無負荷試験から

```text
g0 = P0 / V0²
   = 1600 / 2000²
   = 4.00×10^-4 S

Y0 = I0 / V0
   = 2.00 / 2000
   = 1.00×10^-3 S

b0 = sqrt(Y0² - g0²)
   = 9.17×10^-4 S
```

となる。

短絡試験から

```text
Z = Vsc / Isc
  = 100 / 50
  = 2.00 Ω

R = Psc / Isc²
  = 2500 / 50²
  = 1.00 Ω

X = sqrt(Z² - R²)
  = sqrt(2.00² - 1.00²)
  = 1.73 Ω
```

基準インピーダンスは

```text
ZB = VN² / SN
   = 2000² / 100000
   = 40.0 Ω
```

したがって

```text
%r = 100 × 1.00 / 40.0 = 2.50 %
%x = 100 × 1.73 / 40.0 = 4.33 %
%Z = 5.00 %
```

遅れ力率0.8では `sinφ=0.6` だから、全負荷の一次近似電圧変動率は

```text
ε ≈ 2.50×0.8 + 4.33×0.6
  = 4.60 %
```

二次項まで残すと

```text
A = 4.598
B = 4.33×0.8 - 2.50×0.6
  = 1.964

ε ≈ A + B²/200
  ≈ 4.62 %
```

となる。

鉄損は無負荷試験から約 `1.60 kW`、定格銅損は短絡試験から `2.50 kW` とみなせる。全負荷・力率0.8では

```text
Pout = 100×0.8 = 80.0 kW
η = 80.0 / (80.0 + 1.60 + 2.50)
  = 0.951
  = 95.1 %
```

最大効率となる負荷率は

```text
kmax = sqrt(1.60 / 2.50)
     = 0.800
```

である。

この例では、一つの無負荷・短絡試験データから「励磁枝→直列枝→百分率量→電圧変動率→効率」まで連続して求めている。二次試験では、この接続を途中式付きで書けることが重要である。

### 8.4 複合・ひっかけ例題: 基準変更と進み力率

教材用の仮定値として、単相 `500 kVA`, 一次定格電圧 `6.6 kV` の変圧器について、自己容量基準で

```text
%r = 1.20 %
%x = 4.60 %
```

とする。

自己容量基準の基準インピーダンスは

```text
ZB = 6600² / 500000
   = 87.12 Ω
```

したがって一次換算値は

```text
R = 0.0120 × 87.12
  = 1.05 Ω

X = 0.0460 × 87.12
  = 4.01 Ω
```

である。

これを同じ `6.6 kV`、基準容量 `1000 kVA` へ変更すると

```text
%r(new) = 1.20 × (1000/500) = 2.40 %
%x(new) = 4.60 × (1000/500) = 9.20 %
```

となる。物理的な `R, X` が変化したわけではなく、基準量だけが変化している。

次に自己容量基準へ戻り、負荷率 `k=0.75`、進み力率0.8とする。`sinφ=0.6` なので一次近似電圧変動率は

```text
ε ≈ 0.75(1.20×0.8 - 4.60×0.6)
  = -1.35 %
```

となる。

負の値は計算ミスではない。進み電流ではリアクタンスによる電圧変化が抵抗降下と反対向きになり、端子電圧が上昇し得るためである。

この種の問題では、`%Z` の基準と力率の遅れ・進みを式を書く前に明示することが、誤答防止と二次答案の採点上の両方で重要になる。

## 9. 0系主変圧器への接続

既存一次資料調査で確認済みの0系の値は次のとおりである。

- 電気方式: 交流60 Hz 25 kV
- 主変圧器容量: 1650 kVA
- 制御方式: 低圧タップ切換
- タップ制御: 25段

容量 `1650 kVA` と一次側 `25 kV` だけを使い、単相の皮相電力関係 `S=VI` で定格相当の一次電流を単純計算すると

```text
I = 1650 kVA / 25 kV
  = 66 A
```

となる。これは公開済みの容量・電圧から得た計算値であり、特定の走行状態で実測された架線電流を意味しない。

0系の主変圧器も、試験問題と同様に「架線側電圧を受け、巻数比とタップによって二次側電圧を作り、巻線抵抗・漏れリアクタンス・鉄損・銅損を持つ実変圧器」として考えられる。

一方、0系固有の `R, X, g0, b0, %Z`、鉄損、銅損については、このテーマで使える一次資料値を確認していない。したがって上の例題値を0系実値として扱ってはならない。実車への接続は確認済みの25 kV・60 Hz・1650 kVA・低圧タップ切換・25段までとする。

## 10. 頻出ミス・ひっかけ

- 換算側の混在: 二次側抵抗を一次側電圧・電流と直接組み合わせない。
- `a` と `a²` の混同: 電圧は `a`、電流は `1/a`、インピーダンスは `a²`。
- 無負荷試験と短絡試験の役割逆転: 無負荷試験は主に励磁枝・鉄損、短絡試験は主に直列枝・銅損。
- `Psc` を常に定格銅損とする誤り: 定格電流での試験か確認する。
- `%Z` とオーム値の混在: どの電圧・容量を基準にした百分率か確認する。
- 基準容量変更の方向ミス: 同一電圧なら基準容量を大きくすると同一物理インピーダンスのpu値・百分率値は大きくなる。
- 遅れ・進み力率の符号ミス: 遅れは `+q sinφ`、進みは `-q sinφ` が一次近似の基本。
- 負荷率の指数ミス: 電圧降下は概ね `k` 倍、銅損は `k²` 倍。
- `kVA` と `kW` の混同: 出力有効電力には力率を掛ける。
- 最大効率条件の誤読: `Pi=Pcu,N` ではなく `Pi=k²Pcu,N`。
- 表皮効果の見落とし: 交流等価抵抗と直流抵抗が異なる理由を説明できるようにする。
- 丸めの早過ぎ: 二次試験では途中値を保持し、最終段階で指定桁へ丸める。

## 12. 公式・解法まとめ

### 換算

```text
a = N1/N2 ≈ V1/V2
I1/I2 ≈ 1/a
Z2' = a² Z2
Y2' = Y2/a²
```

### 無負荷試験

```text
Y0 = I0/V0
g0 = P0/V0²
b0 = sqrt(Y0²-g0²)
```

成立条件: 無負荷電流が小さく、直列部の電圧降下・銅損を無視できること。

### 短絡試験

```text
Z = Vsc/Isc
R = Psc/Isc²
X = sqrt(Z²-R²)
```

成立条件: 短絡試験電圧が低く、励磁電流・鉄損を無視できること。

### 百分率量

```text
ZB = VN²/SN = VN/IN
%r = 100R/ZB
%x = 100X/ZB
%Z = sqrt((%r)²+(%x)²)
```

基準変更:

```text
zpu,new = zpu,old × (SB,new/SB,old) × (VB,old/VB,new)²
```

### 電圧変動率

遅れ力率の一次近似:

```text
ε ≈ k(p cosφ + q sinφ)
```

進み力率の一次近似:

```text
ε ≈ k(p cosφ - q sinφ)
```

必要な問題ではフェーザの二次項または厳密式まで使う。

### 効率

```text
Pout = k SN cosφ
Pcu = k² Pcu,N
η = Pout / (Pout + Pi + Pcu)
kmax = sqrt(Pi/Pcu,N)
```

### 二次試験答案の最終確認

```text
換算側を宣言
→ 既知量と単位を整理
→ 使用式を示す
→ 成立条件・近似条件を示す
→ 数値代入
→ 中間値を保持
→ 最終値と単位
→ 遅れ/進み、負荷率、基準量を再確認
```
