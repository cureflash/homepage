# Topic 21 H26二次 問1(4) トルク答案不一致診断

更新日: 2026-09-19

判定: `ROOT_CAUSE_IDENTIFIED / MATERIAL_REVISION_REQUIRED`

対象は固定EXAM_ALIGNMENTの H26二次「機械・制御」問1 `(4)` だけとする。候補固定ファイル、他5答案要素、固定EXAM_ALIGNMENT、固定SPEC範囲は変更しない。

## 1. 固定候補側の計算

固定候補は、問題条件

- 線間電圧 `200 V`
- `50 Hz`
- 4極（極対数 `p=2`）
- Y結線
- `r1=0.1 Ω`
- `x1=0.3 Ω`
- `r2'=0.15 Ω`
- `x2'=0.4 Ω`
- `s=0.03`

から、L形等価回路で

`V1=200/√3=115.4700538... V`

`I2'=V1 / sqrt{(r1+r2'/s)^2+(x1+x2')^2}`

`=22.4308861... A`

を得ている。

同期ワットからトルクを直接書けば、

`TL = P2/ω1 = {3p/(2πf1)} I2'^2 (r2'/s)`

である。

`π` を通常の高精度値で計算すると、

`TL = 48.046775... N·m`

したがって3桁では `48.0 N·m` となる。固定候補の式・単位・すべりの扱いに誤りはない。

## 2. 公式標準解答側

一般財団法人 電気技術者試験センターの平成26年度第二種二次試験標準解答は、問1(3)で

`I2' = 22.430 A`

とし、問1(4)で同じ式

`TL = {3p/(2πf1)} I2'^2 (r2'/s)`

を使い、

`48.067 → 48.1 N·m`

としている。

公式標準解答:
https://www.shiken.or.jp/chief/upload/20141123_ch_second_a01.pdf

公式問題:
https://www.shiken.or.jp/ecee-overview/news/upload/S2(K).pdf

問題冊子の一般注意事項では、計算問題の答は原則有効数字3桁、途中値は誤差が出ないよう多く取るよう指示されている。確認した問題面には `π=3.14` の明示指定はない。

## 3. 数値再現

公式標準解答に印字された `I2'=22.430 A` をそのまま使う。

`π=3.14159265...` なら

`TL = 48.042979... N·m`

で、3桁は `48.0 N·m`。

一方、`π=3.14` とすると

`TL = 48.067347... N·m`

となり、公式標準解答の掲載中間値 `48.067` と一致し、3桁で `48.1 N·m` になる。

したがって、`48.0` と `48.1` の差は、等価回路式・トルク式・単位換算・すべり処理の差ではなく、公式標準解答がこの計算で実質的に `π=3.14` を用いたことによる数値丸め差である。

## 4. 教材側修正要否

`MATERIAL_REVISION_REQUIRED` とする。

理由:
- `EXAM_ALIGNMENT_SPEC.md` は公式標準解答との独立再解答一致を品質ゲートとしている。
- 現行教材の `ω=2πN/60` 自体は正しく、一般式を変更する必要はない。
- ただし H26二次 問1(4) を公式標準解答と一致させるための過去問固有の数値処理差を、現行教材だけでは判別できない。

必要最小限の修正は、Topic 21の解説sourceに「H26二次 問1(4) は公式標準解答が `π=3.14` 相当の計算で `48.1 N·m` としている。高精度πでは `48.0 N·m` になるが、過去問照合では公式標準解答を正本として扱う」という注記を追加することとする。

一般公式、固定EXAM_ALIGNMENT、他5答案要素、練習問題、SPEC範囲は変更しない。
