# Topic 21 H26二次 問1(4) 数値不一致診断

更新日: 2026-09-19

判定: `ROOT_CAUSE_IDENTIFIED / MATERIAL_REVISION_REQUIRED`

対象は固定EXAM_ALIGNMENTの H26二次「機械・制御」問1 `(4)` の1答案要素だけ。候補固定ファイル、他5答案要素、固定EXAM_ALIGNMENT、固定SPECは変更しない。

## 正本確認

公式問題:
- https://www.shiken.or.jp/chief/upload/20141123_ch_second_q02.pdf
- 指定: 定格線間電圧 200 V、50 Hz、4極、Y結線、`r1=0.1 Ω`、`x1=0.3 Ω`、`r2'=0.15 Ω`、`x2'=0.4 Ω`、`s=0.03`
- 計算問題の答は特に指定がない限り有効数字3けた。途中値は誤差が出ないよう多く取る。

公式標準解答:
- https://www.shiken.or.jp/chief/upload/20141123_ch_second_a01.pdf
- `(3)` は `I2'=22.430 A → 22.4 A`
- `(4)` は `TL = (3p/(2πf1)) I2'^2 (r2'/s)` を用い、`48.067 → 48.1 N·m` と掲載。

## 独立再計算

問題文の値を丸めずに使用する。

`V1 = 200/√3 = 115.4700538379 V`

`I2' = V1 / √{(r1+r2'/s)^2 + (x1+x2')^2}`

`= 22.4308861637 A`

4極なので極対数 `p=2`。

`TL = (3p/(2πf1)) I2'^2 (r2'/s)`

`= 48.0467752730 N·m`

高精度の `π` を使うと有効数字3けたでは `48.0 N·m` となる。

Topic 10の別経路でも、`P2=3(r2'/s)I2'^2`、`Pm=(1-s)P2`、`ωm=(1-s)ωs` より `(1-s)` が相殺され、同じ値になる。

## 公式掲載値の再現

公式標準解答に印字された `I2'=22.430 A` をそのまま用いる。

- `π=3.14159265...` の場合: `48.042979... N·m → 48.0 N·m`
- `π=3.14` の場合: `48.067347... N·m → 48.1 N·m`

後者は公式掲載中間値 `48.067` を再現する。

したがって、公式標準解答の `48.067 → 48.1 N·m` は、掲載式に対して実質的に `π=3.14` を用いた数値処理と整合する。問題冊子で確認した一般注意事項には `π=3.14` の明示指定はない。

## 原因診断

- 教材の式誤り: `なし`
- Y結線の相電圧換算誤り: `なし`
- 極数/極対数の取り違え: `なし`
- すべりによる機械出力・回転速度の扱い誤り: `なし`
- 固定候補の計算誤り: `なし`
- 不一致原因: `公式標準解答が当該計算でπ=3.14相当の数値処理を採用したことによる丸め差`

## 教材側修正要否

`MATERIAL_REVISION_REQUIRED` とする。

`EXAM_ALIGNMENT_SPEC.md` は公式標準解答との一致を完成ゲートとするため、現行教材だけでこの過去問固有の数値処理差を判別できない状態を残さない。

必要最小限の修正は、Topic 21解説sourceに次の趣旨を注記することとする。

- H26二次 問1(4) は公式標準解答が `π=3.14` 相当の計算で `48.1 N·m` としている。

- 一般式 `P=Tω`、`ω=2πN/60` は変更しない。
- 当該過去問の公式照合では公式標準解答 `48.1 N·m` を正本として扱う。
