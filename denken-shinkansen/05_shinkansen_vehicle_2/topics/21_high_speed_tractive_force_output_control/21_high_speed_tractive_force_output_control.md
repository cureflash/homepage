## 教材で欠落不可の説明

1. `P=Tω`、`ω=2πN/60` を記号・単位・逆算まで示し、主電動機出力・トルク・回転速度を相互変換できるようにする。
2. 低速側の定トルク条件では、`P=Tω` により回転速度上昇とともに機械出力が増えることを説明する。
3. 電圧上限へ達した後の定出力条件では `T=P/ω` となり、速度上昇に対してトルクが低下することを説明する。電流制限と電圧制限を混同しない。
4. 車輪周側では一般の力学として `P=Fv` を示し、`F=P/v`、`v=P/F` へ逆算できるようにする。`km/h→m/s` と `N×m/s=W` の次元確認を含める。
5. 定出力なら `F=P/v` なので、同じ利用可能出力では速度上昇に伴ってけん引力が低下することを速度―けん引力特性へ接続する。
6. 主電動機出力から編成出力へは、問題条件で与えられた台数・出力を合計する。未指定の駆動効率・ギヤ比等を勝手に追加しない。
7. 走行抵抗は `R(v)` と一般形で表し、定速・平たん等の問題条件の範囲で必要けん引力と必要出力へ結ぶ。未確認のN700系実車抵抗式・係数は置かない。
8. 定速時の学習モデルでは、問題条件に従い `F_req=R(v)`、`P_req=F_req v` とし、編成側の利用可能出力と必要出力を比較できるようにする。
9. 速度―けん引力、速度―主電動機出力、速度―編成必要出力の3可視化は、同じ仮定値・式系から生成し、グラフと例題の条件を一致させる。
10. H26一次型では定加速域・定出力域を電圧・電流条件から判定し、二次型では `P=Tω` の途中式・単位を省略せず記述できるようにする。
11. N700系への接続では確認できた一次資料だけを実車値として使い、未確認値は「仮定値」「学習用モデル」と明記する。

| 種別 | 必須内容 |
|---|---|
| 用語・定義 | 定トルク、定出力、電圧制限、電流制限、けん引力、主電動機出力、編成出力、走行抵抗 |
| 原理・現象 | 定トルク側から定出力側への移行、高速側でトルク・けん引力が低下する理由 |

| 式の導出・成立理由 | 機械仕事率と回転運動、並進運動の仕事率から出力関係を説明 |
| 単位・換算 | `min^-1↔rad/s`、`km/h↔m/s`、`N·m×rad/s=W`、`N×m/s=W` |
| 特性曲線・グラフ | 速度―けん引力、速度―主電動機出力、速度―編成必要出力 |
| 計算手順 | 制約領域判定→出力/トルク換算→編成集約→必要けん引力/必要出力→単位・物理検算 |
| 正誤判定知識 | 定出力域で速度が上がってもトルク・けん引力は一定ではない、電圧制限と電流制限を取り違えない |
| 複数論点接続 | 電動機側 `P=Tω` と車両側 `P=Fv` を出力を介して接続する |
