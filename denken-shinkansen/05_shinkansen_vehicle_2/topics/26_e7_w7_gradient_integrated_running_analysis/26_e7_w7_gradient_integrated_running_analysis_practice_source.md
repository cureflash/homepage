## 共通式・判断基準

- 勾配抵抗: `R_g=mg sinθ`
- 小勾配近似: `R_g≈mgi`
- 定速必要けん引力: `F_req=R_run(v)+R_g`
- 車輪側必要出力: `P_w=F_req v`
- 力行効率: `η=P_w/P_in`, `P_in=P_w/η`
- 回転系: `P=Tω`, `ω=2πN/60`
- 同期速度: `N_s=120f/p`
- 滑り: `s=(N_s-N)/N_s`
- 二次銅損: `P_cu2=sP_2=s/(1-s) P_m`
- 条件付き小滑り近似: `T∝s`
- 定速維持条件: `F_req≤F_av` かつ `P_req≤P_av`
- 下り制動条件: `F_req<0`, `B_req=-F_req`, `P_brake=B_req v`
- 速度換算: `v[m/s]=v[km/h]/3.6`
- 勾配: `30‰=0.030`

# 一次試験型

## 問1 勾配抵抗と必要けん引力

教材用条件として、質量 `4.00×10^5 kg`、重力加速度 `9.8 m/s^2`、上り勾配 `25‰`、その速度での走行抵抗 `55 kN` とする。定速維持に必要なけん引力に最も近いものを選べ。

1. `43 kN`
2. `55 kN`
3. `98 kN`
4. `153 kN`
5. `208 kN`

### 正答
4

### 完全解説

`25‰=0.025`。

小勾配近似より

`R_g≈mgi=4.00×10^5×9.8×0.025=98.0 kN`

したがって

`F_req=R_run+R_g=55+98=153 kN`

である。勾配抵抗だけを答えると選択肢3になるが、問われているのは走行抵抗を含む必要けん引力である。

---

## 問2 必要出力と効率

定速 `72 km/h` で必要けん引力が `150 kN`、力行効率が `0.90` である。電気側必要入力に最も近いものを選べ。

1. `2.70 MW`
2. `3.00 MW`
3. `3.33 MW`
4. `4.17 MW`
5. `10.8 MW`

### 正答
3

### 完全解説

まず

`72 km/h=20 m/s`

車輪側必要出力は

`P_w=Fv=150×10^3×20=3.00 MW`

入力は効率で割る。

`P_in=P_w/η=3.00/0.90=3.33 MW`

効率を掛けて入力を小さくしない。

---

## 問3 出力制限による速度境界

教材用条件として、質量 `4.00×10^5 kg`、上り勾配 `20‰`、速度によらず走行抵抗 `60.0 kN`、車輪側利用可能出力 `10.0 MW` とする。けん引力側の制限はないものとしたとき、定速維持できる最大速度に最も近いものを選べ。

1. `180 km/h`
2. `220 km/h`
3. `260 km/h`
4. `300 km/h`
5. `360 km/h`

### 正答
3

### 完全解説

勾配抵抗は

`R_g=4.00×10^5×9.8×0.020=78.4 kN`

必要けん引力は

`F_req=60.0+78.4=138.4 kN`

出力限界で

`P_av=F_req v`

だから

`v=10.0×10^6/(138.4×10^3)=72.25 m/s`

`=260.1 km/h`

よって選択肢3。

## 問4 `P=Tω`

機械出力 `600 kW`、回転速度 `1500 min^-1` の電動機のトルクに最も近いものを選べ。

1. `382 N·m`
2. `955 N·m`
3. `1910 N·m`
4. `3820 N·m`
5. `6000 N·m`

### 正答
4

### 完全解説

`ω=2πN/60=2π×1500/60=157.08 rad/s`

したがって

`T=P/ω=600000/157.08≈3819.7 N·m`

よって約 `3820 N·m`。`1500 min^-1` をそのまま `ω` に代入してはならない。

`50 Hz`、6極の三相誘導電動機が `960 min^-1` で回転している。同期速度と滑りの組合せとして正しいものを選べ。

` s=(1000-960)/1000=0.04 `

## 問6 鉄道用電動機の定加速域・定出力域

VVVFインバータ駆動誘導電動機について、教材で固定した試験条件に最も適合する記述を選べ。

1. 定加速域では `V=一定`、定出力域では `V/f=一定` とする。
2. 定加速域では `V/f=一定`、`I_M=一定`、`f_s=可変`、定出力域では `V=一定`、`I_M=一定`、`f_s=可変` とする。
3. 定出力域では速度が上がるほどトルクも比例して増加する。
4. 鉄道用主電動機では始動トルクは小さいほどよい。
5. 定加速域・定出力域とも滑り周波数は必ず0である。

### 正答
2

### 完全解説

固定過去問H26一次問5へ接続する最小条件は、定加速域で `V/f=一定`、`I_M=一定`、`f_s=可変`、定出力域で `V=一定`、`I_M=一定`、`f_s=可変` である。定出力なら `P=Tω=一定` なので、高速化に伴いトルクは低下する。鉄道用駆動では発進・低速域に大きな始動トルクが要求される。

## 問7 下り勾配と回生

下り勾配を定速走行中、重力の進行方向成分が走行抵抗を上回り、`F_req<0` となった。最も適切な記述を選べ。

1. 必ず力行が必要である。
2. 必要制動力は `B_req=F_req` で負値のまま扱う。
3. 回生ブレーキでは機械エネルギーを電気エネルギーへ変換し得るが、電動機・主変換装置の回生可能条件と架線側受電条件の両方が必要である。
4. 下りなら架線側受電条件に関係なく全制動力を必ず回生で負担できる。
5. 回生時の電力は交流側から直流側への一方向だけに流れる。

### 正答
3

### 完全解説

`F_req<0` は重力成分が走行抵抗を上回り、定速維持に制動が必要な状態である。制動力の大きさは `B_req=-F_req>0`。回生では機械→電気へエネルギー変換するが、車両側の回生可能条件だけでなく架線側が電力を受け取れることも必要である。

---

## 問8 回生失効

鉄道回生について最も適切な記述を選べ。

1. 回生時は必ず交流側から直流側へ電力変換する。
2. 架線側に回生電力の受電先がなくても、返送電力は常に同じ値で維持される。
3. 回生電力は他の力行車等に消費され得るが、受電側がなく電力を受け取れない場合は回生失効が起こり得る。
4. 回生失効とは電動機の同期速度が0になる現象である。
5. 回生失効の有無は架線側条件と無関係である。

### 正答
3

### 完全解説

回生では主変換装置を介して直流側から交流側へ逆変換し、架線へ電力を返す。近傍の力行車などが受電先になり得るが、受電側がなく返送できない場合は回生失効が起こり得る。したがって「車両が回生可能」と「実際に架線へ返送できる」は区別する。

# 二次試験型

## 問9 上り勾配の総合走行解析

以下はすべて教材用条件である。

- `m=4.00×10^5 kg`
- `g=9.8 m/s^2`
- 上り勾配 `i=+0.030`
- `v=80 m/s`
- `R_run(v)=30+0.008v^2 [kN]`
- 力行効率 `η=0.90`

次を求めよ。

1. 勾配抵抗 `R_g`
2. 走行抵抗 `R_run`
3. 必要けん引力 `F_req`
4. 車輪側必要出力 `P_w`
5. 電気側必要入力 `P_in`

### 解答・完全解説

小勾配近似より

`R_g=mgi=4.00×10^5×9.8×0.030=117.6 kN`

走行抵抗は

`R_run=30+0.008×80^2=81.2 kN`

したがって

`F_req=81.2+117.6=198.8 kN`

車輪側必要出力は

`P_w=198.8×10^3×80=15.904 MW`

力行効率から

`P_in=15.904/0.90=17.671... MW≈17.67 MW`

となる。

検算として `P_in>P_w` を満たす。これらは教材用仮定値であり、E7・W7系実性能を表さない。

## 問10 誘導電動機の滑り・損失・負荷変化

三相誘導電動機について次の教材用条件を与える。

- 周波数 `f=50 Hz`
- 極数 `p=6`
- 定格回転速度 `N=960 min^-1`
- 軸出力 `P_out=480 kW`
- 効率 `η=0.80`
- 機械損は無視し、機械的変換電力 `P_m` を軸出力に等しいとする
- 固定損は `P_fixed=P_in-P_out-P_cu2` と定義する
- 負荷トルクが定格の75%になったとき、小滑り領域で `T∝s` が成立するとする

次を求めよ。

1. 同期速度 `N_s` と滑り `s`
2. 定格トルク `T`
3. 二次銅損 `P_cu2`
4. 固定損 `P_fixed`
5. 負荷75%時の回転速度 `N'`
6. 負荷75%時の軸出力 `P_out'`

### 解答・完全解説

同期速度は

`N_s=120f/p=120×50/6=1000 min^-1`

滑りは

`s=(1000-960)/1000=0.040`

角速度は

`ω=2π×960/60=100.531 rad/s`

したがって定格トルクは

`T=480000/100.531≈4.775×10^3 N·m`

機械損を無視する条件なので `P_m=P_out=480 kW`。

`P_cu2=s/(1-s) P_m`

`=0.04/0.96×480=20.0 kW`

入力は

`P_in=P_out/η=480/0.80=600 kW`

よって問題で定義した固定損は

`P_fixed=600-480-20=100 kW`

負荷トルク75%時、条件付きで `T∝s` だから

`s'=0.75×0.040=0.030`

`N'=1000(1-0.030)=970 min^-1`

`T'=0.75T`

よって

`P_out'=T'×2πN'/60`

または比で

`P_out'/P_out=0.75×970/960`

したがって

`P_out'=480×0.75×970/960=363.75 kW`

となる。

`T∝s` は問題が許した小滑り範囲だけで使う。

## 問11 下り勾配・回生電力・回生失効

問9と同じ教材用走行抵抗モデルを用い、勾配だけ `i=-0.030`、速度 `v=80 m/s` とする。また、教材用回生効率を `η_reg=0.85` とする。

1. `F_req` を求め、力行・つり合い・制動のどれが必要か判定せよ。
2. 必要制動力 `B_req` と機械制動電力 `P_brake` を求めよ。
3. 車両側回生条件と架線側受電条件がともに成立するとき、返送電力の上限を求めよ。
4. 架線側が回生電力を受け取れない場合を説明せよ。

### 解答・完全解説

`R_run(80)=81.2 kN`

下りなので

`R_g=-117.6 kN`

よって

`F_req=81.2-117.6=-36.4 kN`

負値なので定速維持には制動が必要である。

`B_req=-F_req=36.4 kN`

`P_brake=36.4×10^3×80=2.912 MW`

回生条件が成立するとき、単純化した返送上限は

`P_return≤η_reg P_brake`

`≤0.85×2.912=2.4752 MW≈2.48 MW`

である。

ただし架線側が受電できなければ、車両側が回生可能でもその電力を架線へ返送できず、回生失効が起こり得る。したがって `2.48 MW` を常に実返送できるとは結論しない。

## 問12 けん引力制限と出力制限の同時判定

教材用条件として、

- `m=4.00×10^5 kg`
- `g=9.8 m/s^2`
- 上り勾配 `i=+0.020`
- `R_run(v)=30+0.008v^2 [kN]`
- 利用可能けん引力 `F_av=150 kN`
- 利用可能車輪出力 `P_av=10.5 MW`

とする。定速維持可能な速度上限を、けん引力制限と出力制限の両方から判定せよ。

### 解答・完全解説

勾配抵抗は

`R_g=4.00×10^5×9.8×0.020=78.4 kN`

したがって

`F_req(v)=[30+0.008v^2+78.4] kN`

である。

けん引力限界は

`30+0.008v^2+78.4=150`

`0.008v^2=41.6`

`v=72.11 m/s≈259.6 km/h`

一方、出力限界は

`[30+0.008v^2+78.4]×10^3×v=10.5×10^6`

を解いて

`v≈70.74 m/s≈254.7 km/h`

となる。この速度で

`F_req≈148.43 kN<150 kN`

なのでけん引力条件も満たす。

したがって先に効くのは出力制限であり、教材用モデル上の定速維持速度上限は約 `254.7 km/h` である。

これはE7・W7系の実最高速度・実勾配性能を示す値ではない。
