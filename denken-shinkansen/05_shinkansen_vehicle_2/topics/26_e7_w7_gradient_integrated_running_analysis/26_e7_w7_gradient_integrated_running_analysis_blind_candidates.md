## 2. R7 二次「機械・制御」問2 — 6答案要素

問題条件:
- 定格軸出力 `P_out=22 kW`
- 周波数 `f=60 Hz`
- 極数 `p=6`
- 定格回転速度 `N=1158 min^-1`
- 定格効率 `η=87.5%`
- 負荷損は銅損のみ
- 一次銅損と二次銅損は常に等しい
- 機械損は無視
- (3)では滑りはトルクに比例

### (1) 滑り `s1` と定格トルク `T1`

同期速度:

`N_s=120f/p=120×60/6=1200 min^-1`

滑り:

`s1=(N_s-N)/N_s=(1200-1158)/1200=0.035`

候補:
- `s1=3.50 %`

角速度:

`ω=2πN/60=2π×1158/60`

定格トルク:

`T1=P_out/ω=22000/(2π×1158/60)=181.42... N·m`

候補:
- `T1=181 N·m`

### (2) 二次銅損 `P_c2` と固定損 `P_f`

機械損を無視できるので、機械的変換電力を定格軸出力とみなす。

`P_c2=s/(1-s)×P_out`

`=0.035/0.965×22000`

`=797.927... W`

候補:
- `P_c2=798 W`

入力:

`P_in=P_out/η=22000/0.875=25142.857... W`

全損失:

`P_loss=P_in-P_out=3142.857... W`

一次銅損=二次銅損なので

`P_f=P_loss-2P_c2`

`=3142.857...-2×797.927...`

`=1547.002... W`

候補:
- `P_f=1.55×10^3 W`

### (3) 50%定格出力トルク時の回転速度 `N2` と出力 `P2`

滑りがトルクに比例する条件より

`s2=0.5s1=0.0175`

`N2=N_s(1-s2)=1200×(1-0.0175)=1179 min^-1`

候補:
- `N2=1.18×10^3 min^-1`

トルクは `0.5T1` なので

`P2=(0.5T1)×2πN2/60`

`=11199.48... W`

候補:
- `P2=1.12×10^4 W`
