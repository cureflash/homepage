### H22 二次 機械・制御 問2 (1)〜(3)

定格容量 `300 kVA`、一次定格電圧 `6600 V`、無負荷電流 `0.483 A`、無負荷力率 `0.325`、負荷力率1、30%負荷時と70%負荷時の効率が等しい条件を用いた。

#### (1) 鉄損

無負荷入力を鉄損とみなす。

`P_i = 6600 × 0.483 × 0.325 = 1036.035 W`

独立解答: `約1.04 kW（1,040 W）` / 標準解答: `1,040 W` / `PASS`

#### (2) 定格負荷時の銅損

負荷率を `x`、定格銅損を `P_c` とすると、負荷力率1では

`η(x) = xP_2 / (xP_2 + P_i + x^2P_c)`

30%負荷と70%負荷で効率が等しいので、共通項を整理すると

`P_i = 0.3 × 0.7 × P_c`

したがって

`P_c = 1036.035 / 0.21 = 4933.5 W`

独立解答: `約4.93 kW（4,930 W）` / 標準解答: `4,930 W` / `PASS`

#### (3) 最大効率

最大効率条件は固定損と負荷依存損が等しいことなので

`P_i = x^2 P_c`

`x = sqrt(P_i/P_c) = sqrt(0.21) = 0.45826`

最大効率時の出力は

`P_out = 300 kW × 0.45826 ≈ 137.48 kW`

総損失は `2P_i` だから

`η_max = 137.48 / (137.48 + 2.072) ≈ 0.98515`

独立解答: `98.5 %` / 標準解答: `98.5 %` / `PASS`

小計: `3 / 3 PASS`
