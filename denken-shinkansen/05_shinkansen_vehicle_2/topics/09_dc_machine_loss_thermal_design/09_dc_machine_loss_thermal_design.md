# 解説本文

## 1. このテーマで電験二種は何を問うか

このテーマでは、直流機を「入力電力の一部が損失になり、その損失が発熱となって温度上昇を生む電気機器」として一つの収支で扱う。一次試験では、銅損・鉄損・機械損・雑負荷損、固定損、規約効率、冷却と部分負荷効率、ブラシ保守の語句判断が中心になる。二次試験では、負荷率による銅損の変化と効率式を組み合わせ、最大効率条件まで途中式付きで導く必要がある。

新幹線側では、Topic 07で確認済みの0系・100系・200系主電動機の定格出力と冷却方式を接続材料にする。ただし各系列の実損失値・実温度・冷却容量は確認できていないため、熱計算の数値例は教材用仮定値として扱う。

## 2. 電力収支と効率

入力電力を `P_in [W]`、軸出力を `P_out [W]`、全損失を `P_loss [W]` とすると、

`P_in = P_out + P_loss`

である。効率は

`η = P_out / P_in = P_out / (P_out + P_loss)`

となる。

この式から、同じ出力なら損失が小さいほど効率は高い。一方、損失の中に負荷にほぼ依存しない成分があると、軽負荷では出力に対する固定損の割合が大きくなるため効率が低下しやすい。R8一次の部分負荷効率判断はこの関係で説明できる。

規約効率は、規定された方法で個々の損失を求め、それらを使って算出する効率である。実負荷で入力と出力を直接測る実測効率とは区別する。

## 3. 損失の分類

Topic 09では損失を次の4群で整理する。

### 銅損

巻線抵抗によるジュール損で、基本式は

`P_Cu = I^2 R`

である。電流が2倍なら同じ抵抗条件で銅損は4倍になる。負荷率と電流が比例すると仮定できる問題では、定格電流時銅損を `P_Cu,N`、負荷率を `x` として

`P_Cu(x) = x^2 P_Cu,N`

と扱える。

### 鉄損

鉄心の交番磁束によって生じる損失で、ヒステリシス損と渦電流損を主成分として整理する。試験上、電圧・周波数・回転条件が一定の近似では、負荷電流に対して大きく変わらない損失として扱う場合がある。

### 機械損

軸受・ブラシ等の摩擦損と風損など、回転に伴う機械的損失である。冷却風を動かすことや回転体が気体をかき回すことも風損につながる。回転速度・冷却条件を一定とする簡略問題では固定損側に整理する。

### 雑負荷損

負荷時に生じる追加損失のうち、単純な巻線抵抗損などへ直接分類しにくい成分である。R5一次・H23一次では、銅損や鉄損・機械損と区別して識別できることが必要になる。

## 4. 固定損と負荷に依存する損失

試験用の簡略モデルでは、鉄損と機械損をまとめた固定損を `P_0`、負荷に依存する損失を `P_v` と置く。

負荷率 `x` と電流が比例し、負荷依存損を電流二乗に比例すると近似する場合、定格時の負荷依存損を `P_vN` として

`P_v(x) = x^2 P_vN`

全損失は

`P_loss(x) = P_0 + x^2 P_vN`

となる。

この `x^2` 則は「負荷率と電流が比例し、対象損失が電流二乗に比例する」という条件で使う。すべての損失が常に `x^2` で変わるわけではない。雑負荷損を同じ二乗則へ含める場合も、問題文または教材上の仮定を明示する。

## 5. 負荷率―効率と最大効率条件

定格出力を `P_N`、負荷率を `x` とし、出力を

`P_out = x P_N`

とする。固定損 `P_0`、定格時負荷依存損 `P_vN` の簡略モデルなら、

`η(x) = xP_N / (xP_N + P_0 + x^2P_vN)`

である。

最大効率条件は、分母を出力で割って

`1/η = 1 + P_0/(xP_N) + xP_vN/P_N`

とし、効率を最大にするには損失比

`P_0/(xP_N) + xP_vN/P_N`

を最小にすればよい。`x` で微分して0と置くと、

`-P_0/(x^2P_N) + P_vN/P_N = 0`

したがって

`P_0 = x^2 P_vN`

となる。つまり簡略条件では「固定損＝その負荷率での負荷依存損」のとき効率が最大である。

最大効率負荷率は

`x_max = sqrt(P_0/P_vN)`

で求められる。H22二次のような問題では、この条件を暗記するだけでなく、銅損が負荷率の二乗で変わることから式を組み立てる。

## 6. 損失を試験条件から分離する

H23一次では、運転条件を変えて「どの損失だけが残るか」を考え、測定値の差で損失を分離する。

- 無励磁で回転させる: 主に機械損が残る。
- 端子開放で定格電圧となるよう励磁する: 固定損が測定される。ここから機械損を差し引けば鉄損を求められる。
- 端子短絡で定格電流となる条件: 機械損、直接負荷損、雑負荷損が現れる。機械損を差し引けば直接負荷損と雑負荷損の和を得られる。

この問題の対象機器は同期機だが、Topic 09で使うのは「条件を変えて残る損失を判定し、差し引きで分離する」という考え方だけである。同期速度や同期機固有理論は追加しない。

## 7. 損失は発熱になる

機器内部で消費された損失電力は、最終的には熱として機器・周囲へ移る。簡略的には

`P_heat ≈ P_loss`

と置ける。

銅損が `I^2R` で増えるため、電流を20%増やしただけでも、抵抗一定なら銅損は

`1.2^2 = 1.44`

すなわち44%増える。定格を考えるときは「出力が出せるか」だけでなく、損失による温度上昇を許容範囲に抑えられるかを見る必要がある。

## 8. 簡略熱モデル

`SPEC.md` 指定の時間―温度上昇は、機器全体を一つの熱容量として扱う集中定数モデルで整理する。周囲温度からの温度上昇を `θ [K]`、損失電力を一定の `P_loss [W]`、熱抵抗を `R_th [K/W]`、熱容量を `C_th [J/K]` とする。

熱収支は

`C_th dθ/dt = P_loss - θ/R_th`

である。

熱時定数を

`τ = R_th C_th [s]`

と置き、初期温度上昇 `θ(0)=0` とすると、

`θ(t) = P_loss R_th (1 - exp(-t/τ))`

となる。

定常状態 `t→∞` では

`θ_inf = P_loss R_th`

である。`t=τ` では

`θ(τ) = 0.632 θ_inf`

となる。したがって損失が大きいほど定常温度上昇は大きく、同じ損失なら熱抵抗が小さい、すなわち冷却が強いほど定常温度上昇を小さくできる。

このモデルは温度分布、局所発熱、風量分布、材料ごとの熱容量を一つにまとめた教材用の近似である。`R_th`、`C_th` の数値例は実車値ではない。

## 9. 定格と冷却

定格は、指定された運転条件で電圧・電流・出力・温度などの制限を満たして使用するための基準である。連続運転では、損失による発熱と冷却による放熱が釣り合ったときの温度が許容範囲に収まる必要がある。

冷却を強くすれば一般に熱抵抗 `R_th` を小さくでき、同じ損失でも温度上昇を抑えやすい。一方、送風や回転による風損は機械損の一部なので、「冷やせば損失が必ずゼロに近づく」という理解は誤りである。R8一次で必要なのは、風損が機械損に含まれることと、固定損の割合が大きいと部分負荷効率が低下しやすいことの関係である。

## 10. 直流機の保守

直流電動機は整流子とブラシを用いる。ブラシは接触・摩擦を伴うため摩耗し、点検・交換が必要な部品である。R6一次の固定対象では、この保守負担を判断できればよい。

ここではブラシ材質、摩耗量、交換周期、整流火花の詳細診断へは広げない。100系・200系の実保守周期も確認できていないため数値化しない。

## 12. 問題を見たときの解法アルゴリズム

1. 入力、出力、損失、効率のどれが既知かを整理する。
2. 損失を銅損、鉄損、機械損、雑負荷損へ分類する。
3. 問題文が固定損・負荷損の簡略モデルを使っているか確認する。
4. 電流または負荷率が変わる場合、`I^2R` と `x^2` の成立条件を確認する。
5. 効率は `η=P_out/(P_out+P_loss)` で組み立てる。
6. 最大効率なら、簡略条件で `P_0=x^2P_vN` を導いて負荷率を求める。
7. 損失測定問題では、各運転条件で残る損失を書き出してから差し引く。
8. 温度問題では `P_loss` を熱入力とし、`R_th`,`C_th`,`τ` の単位をそろえる。
9. 定常温度上昇は `θ_inf=P_lossR_th`、過渡応答は `θ(t)=θ_inf(1-e^{-t/τ})` を使う。
10. 最後に、効率が0〜1、損失が非負、温度上昇が定常値を越えていないことを検算する。

# 3段階例題

## 例題1 基礎: 損失と効率

教材用仮定値として、直流電動機の電気入力を `250 kW`、軸出力を `230 kW` とする。全損失と効率を求める。

全損失:

`P_loss = P_in - P_out = 250 - 230 = 20 kW`

効率:

`η = 230/250 = 0.920 = 92.0%`

答え: 全損失 `20 kW`、効率 `92.0%`。

検算: 入力250 kWは出力230 kWより大きく、差20 kWは正なのでエネルギー収支として妥当である。

## 例題2 本試験標準: 負荷率と最大効率

教材用仮定値として、定格出力 `P_N=200 kW`、固定損 `P_0=6.0 kW`、定格時の負荷依存損 `P_vN=10.0 kW` とする。負荷率 `x` と電流は比例し、負荷依存損は電流の二乗に比例すると仮定する。最大効率となる負荷率と、そのときの効率を求める。

最大効率条件は

`P_0 = x^2 P_vN`

なので、

`x = sqrt(P_0/P_vN)`

`= sqrt(6.0/10.0)`

`= 0.7746`

したがって最大効率負荷率は約 `77.5%`。

そのときの出力は

`P_out = 200×0.7746 = 154.9 kW`

負荷依存損は

`P_v = 10.0×0.7746^2 = 6.0 kW`

全損失は

`P_loss = 6.0 + 6.0 = 12.0 kW`

効率は

`η = 154.9/(154.9+12.0) = 0.9281`

したがって約 `92.8%`。

検算: 最大効率点で固定損6.0 kWと負荷依存損6.0 kWが一致している。

## 例題3 複合: 損失から時間―温度上昇を求める

教材用仮定値として、一定損失 `P_loss=12.0 kW`、熱抵抗 `R_th=0.0040 K/W`、熱容量 `C_th=150 kJ/K` の簡略熱モデルを考える。初期温度は周囲温度と等しい。熱時定数、定常温度上昇、10分後・20分後の温度上昇を求める。

熱容量をSI単位へ直す。

`C_th = 150 kJ/K = 150000 J/K`

熱時定数:

`τ = R_th C_th`

`= 0.0040×150000 = 600 s = 10 min`

定常温度上昇:

`θ_inf = P_loss R_th`

`= 12000×0.0040 = 48 K`

10分後は `t=τ` なので、

`θ(10 min) = 48(1-e^-1) = 30.3 K`

20分後は `t=2τ` なので、

`θ(20 min) = 48(1-e^-2) = 41.5 K`

答え: `τ=10 min`、`θ_inf=48 K`、10分後 `30.3 K`、20分後 `41.5 K`。

検算: 温度上昇は時間とともに48 Kへ近づくが、有限時間で定常値を越えない。この `R_th`,`C_th` は教材用仮定値であり実車値ではない。

## 14. 頻出ミス

- `P_in` と `P_out` を逆にして損失を負にする。
- 銅損 `I^2R` を電流に一次比例すると誤る。
- 鉄損・機械損・雑負荷損をすべて銅損として扱う。
- 固定損を負荷率0で0になる損失だと誤解する。
- `x^2` 則を、電流比例の仮定がない問題へ無条件に使う。
- 最大効率条件 `固定損=可変損` を成立条件なしで一般化する。
- H23の損失測定で、開放・短絡・無励磁の各条件に残る損失を混同する。
- 熱抵抗 `K/W` と熱容量 `J/K` を混同する。
- `kJ/K` を `J/K` へ換算せず時定数を計算する。
- 温度上昇 `θ` と絶対温度・周囲温度を混同する。
- 教材用熱モデルの仮定値を100系・200系の実車値として扱う。
- 直流機のブラシを非接触・無摩耗部品と誤る。

## 16. 公式・解法まとめ

電力・効率:

- `P_in = P_out + P_loss`
- `η=P_out/P_in=P_out/(P_out+P_loss)`

損失:

- 銅損 `P_Cu=I^2R`
- 固定損近似 `P_0≈P_Fe+P_mech`
- 簡略負荷依存損 `P_v(x)=x^2P_vN`
- 全損失 `P_loss(x)=P_0+x^2P_vN`

最大効率の簡略条件:

- `P_0=x^2P_vN`
- `x_max=sqrt(P_0/P_vN)`

簡略熱モデル:

- `C_th dθ/dt=P_loss-θ/R_th`
- `τ=R_thC_th`
- `θ(t)=P_lossR_th(1-e^{-t/τ})` （初期温度上昇0、損失一定）
- `θ_inf=P_lossR_th`

問題では、これらの式を成立条件なしに機械的適用しない。特に負荷率―損失と熱モデルの値は、問題文または教材用仮定を明示して使う。
