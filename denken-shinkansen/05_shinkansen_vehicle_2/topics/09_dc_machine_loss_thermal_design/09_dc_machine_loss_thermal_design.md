資格: 第二種電気主任技術者

主科目:

- 一次試験「機械」
- 二次試験「機械・制御」

対象論点:

- 出力、入力、全損失から効率を構成すること
- 銅損を電流と抵抗から `P_Cu = I^2 R` として扱い、負荷率に伴う可変損の変化へ接続すること
- 鉄損、機械損、雑負荷損を区別すること
- 機械損と鉄損を負荷電流に依存しない固定損として扱う基本整理
- 規定された損失から求める規約効率の考え方
- 無励磁・無負荷・短絡等の試験条件から、どの損失が測定値に含まれるかを判定すること
- 負荷率を変えたとき、固定損と負荷に依存する損失の釣合いから最大効率条件を求めること
- 冷却条件と風損・固定損・部分負荷効率の関係を説明すること
- 直流電動機のブラシが摩耗部品であり、点検・交換が保守上必要になること
- 損失が発熱源となり、温度上昇と冷却・定格制約へつながること
- `SPEC.md` 指定の簡略熱モデルで、一定損失入力に対する時間―温度上昇を扱うこと

## 教材で必要な説明

固定過去問と `SPEC.md` から、本文作成時に最低限次を収録する。

1. 損失の全体像
   - `P_in = P_out + P_loss`
   - `η = P_out / P_in = P_out / (P_out + P_loss)`
   - 銅損、鉄損、機械損、雑負荷損の定義と負荷依存性
2. 銅損
   - `P_Cu = I^2R`
   - 電流増加で損失が二乗増加すること
   - 負荷率と電流の関係を仮定する場合は、その成立条件を明示すること
3. 固定損と負荷損
   - 機械損・鉄損を固定損として近似する試験上の整理
   - 雑負荷損を含む負荷側損失との区別
4. 効率と負荷率
   - 負荷率を変えたときの出力、固定損、可変損の関係
   - 最大効率条件を、適用する簡略条件を明示して導くこと
5. 損失測定の考え方
   - 運転条件で残る損失を整理し、差し引きで損失成分を分離すること
6. 発熱と温度上昇
   - 損失電力を熱入力として扱うこと
   - `SPEC.md` 指定の簡略熱モデルで時間―温度上昇を計算・グラフ化すること
   - 熱モデルの仮定値を実車値として扱わないこと
7. 定格・冷却・保守
   - 定格運転と熱的制約の関係
   - 冷却により温度上昇を抑える必要性
   - ブラシ摩耗・交換という直流機特有の保守要素
8. 指定グラフ
   - 負荷率―効率
   - 出力―損失
   - 簡略熱モデルによる時間―温度
