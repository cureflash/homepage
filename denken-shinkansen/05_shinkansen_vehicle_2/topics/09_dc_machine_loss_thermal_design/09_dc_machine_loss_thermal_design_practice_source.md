# 一次試験型

## 問1 入力・出力・全損失・効率

教材用条件として、直流電動機の電気入力が `250 kW`、軸出力が `230 kW` である。全損失と効率の組合せとして正しいものを選べ。

1. 全損失 `20 kW`、効率 `92.0%`
2. 全損失 `20 kW`、効率 `108.7%`
3. 全損失 `230 kW`、効率 `8.0%`
4. 全損失 `250 kW`、効率 `92.0%`
5. 全損失 `480 kW`、効率 `47.9%`

### 正答

1

### 完全解説

全損失は入力と出力の差である。

```text
P_loss=P_in-P_out
      =250-230
      =20 kW
```

効率は

```text
η=P_out/P_in
 =230/250
 =0.920
 =92.0%
```

したがって正答は1。電動機では損失が正なら `P_in>P_out`、効率は1未満になることも検算になる。

## 問2 損失の分類

回転機の損失分類について、Topic 09 の基本整理として正しいものを選べ。

1. 鉄損は常に電流の二乗に比例する負荷依存損であり、機械損は出力に比例する。
2. 電機子銅損は `I^2R` で扱える直接負荷損であり、鉄損と機械損は基本整理では固定損として扱う。雑負荷損は負荷に伴って生じる追加損失として区別する。
3. 風損は銅損の一種であり、ブラシ摩擦損は鉄損の一種である。
4. 雑負荷損は固定損に必ず含まれ、負荷電流に関係しない。
5. 固定損とは銅損だけを指す。

### 正答

2

### 完全解説

銅損は抵抗一定なら

```text
P_Cu=I^2R
```

で増加するため代表的な負荷依存損である。鉄損と機械損はTopic 09の基本的な試験整理では固定損として扱う。機械損には軸受摩擦や風損などが含まれる。雑負荷損は、主な計算で分離した損失だけでは説明できない負荷時の追加損失として区別する。したがって正答は2。

## 問3 負荷率と規定損失から求める効率

定格出力 `P_N=200 kW` の機器について、問題文で規定された固定損を `6.0 kW`、定格時の負荷依存損を `10.0 kW` とする。負荷率 `x=0.80` では出力が `xP_N`、負荷依存損が `x^2` に比例するとする。この規定損失から求める効率として最も近いものを選べ。

1. `88.0%`
2. `90.0%`
3. `91.3%`
4. `92.8%`
5. `96.2%`

### 正答

4

### 完全解説

出力は

```text
P_out=xP_N
     =0.80×200
     =160 kW
```

負荷依存損は

```text
P_v=x^2P_vN
   =0.80^2×10.0
   =6.4 kW
```

全損失は

```text
P_loss=6.0+6.4
      =12.4 kW
```

したがって

```text
η=160/(160+12.4)
 =0.9281
 ≒92.8%
```

よって正答は4。規約効率型の問題では、問題文や規定で指定された損失を使って入力を構成する。

## 問4 試験条件から機械損・鉄損を分離する

ある回転機で、無励磁で回転させたときの損失が `3.0 kW`、端子開放で所定電圧となるよう励磁したときに測定される固定損が `8.0 kW` であった。Topic 09 の簡略整理に従うと、機械損と鉄損の組合せとして正しいものを選べ。

1. 機械損 `3.0 kW`、鉄損 `5.0 kW`
2. 機械損 `5.0 kW`、鉄損 `3.0 kW`
3. 機械損 `8.0 kW`、鉄損 `3.0 kW`
4. 機械損 `8.0 kW`、鉄損 `5.0 kW`
5. 機械損 `11.0 kW`、鉄損 `8.0 kW`

### 正答

1

### 完全解説

無励磁で回転させる条件では主に機械損が残るので、

```text
P_mech=3.0 kW
```

端子開放・励磁条件の固定損 `8.0 kW` は、基本整理では機械損と鉄損の和として扱う。したがって

```text
P_fe=8.0-3.0
    =5.0 kW
```

よって正答は1。損失分離では「各条件で残る損失」を先に書くことが重要である。

端子短絡・定格電流条件で測定された入力が `15.0 kW` であり、この条件では機械損 `3.0 kW`、直接負荷損 `9.0 kW`、雑負荷損が含まれるものとする。雑負荷損として正しいものを選べ。

3. `6.0 kW`

測定値から既知の機械損と直接負荷損を差し引く。

P_stray=15.0-3.0-9.0
       =3.0 kW

したがって正答は2。H23一次型では、測定条件に含まれる損失を整理して差を取る。

## 問6 風損・固定損と部分負荷効率

定格出力 `100 kW` の機器A、Bがあり、定格時の負荷依存損はいずれも `8.0 kW` とする。固定損はAが `4.0 kW`、Bが `8.0 kW` である。負荷率 `x=0.50`、負荷依存損は `x^2` に比例するとき、正しい記述を選べ。

1. A、Bの部分負荷効率は等しい。
2. Aの効率は約 `83.3%`、Bは約 `89.3%` である。
3. Aの効率は約 `89.3%`、Bは約 `83.3%` であり、固定損が大きいBほど部分負荷効率が低い。
4. 風損は固定損と無関係なので、冷却方式は部分負荷効率に全く影響しない。
5. 固定損が大きいほど軽負荷時の効率は必ず高くなる。

### 正答

3

### 完全解説

負荷率0.5での出力は `50 kW`、負荷依存損は

```text
0.5^2×8.0=2.0 kW
```

A:

```text
η_A=50/(50+4+2)
   =0.8929
   =89.3%
```

B:

```text
η_B=50/(50+8+2)
   =0.8333
   =83.3%
```

したがって正答は3。風損は機械損の一部であり、固定損の割合が大きいと軽負荷時に効率へ与える影響が相対的に大きくなる。冷却を強くすると温度上昇を抑えやすい一方、送風による風損を無視できるとは限らない。

## 問7 直流電動機の保守

直流電動機の保守について正しいものを選べ。

1. ブラシは非接触部品なので摩耗せず、定期点検は不要である。
2. 整流子とブラシは接触を伴い、ブラシは摩耗するため点検・交換が必要になる。
3. ブラシ交換が必要なのは誘導電動機だけである。
4. ブラシの摩耗は鉄損に分類されるため、保守とは無関係である。
5. ブラシを持つ直流電動機では保守部品が存在しない。

### 正答

2

### 完全解説

直流電動機では整流子とブラシが接触する。ブラシは摩擦を伴う摩耗部品であり、点検・交換が必要になる。Topic 09では材質や交換周期の詳細へ広げず、「摩耗部品であるため保守負担がある」という試験論点を扱う。よって正答は2。

## 問8 簡略熱モデル

一定損失 `P_loss=10.0 kW`、熱抵抗 `R_th=0.0030 K/W`、熱容量 `C_th=200 kJ/K` の簡略熱モデルを考える。初期温度上昇は0とする。熱時定数、定常温度上昇、`t=τ` の温度上昇の組合せとして最も近いものを選べ。

1. `τ=60 s`、`θ_inf=3 K`、`θ(τ)=1.9 K`
2. `τ=600 s`、`θ_inf=30 K`、`θ(τ)=19.0 K`
3. `τ=600 s`、`θ_inf=30 K`、`θ(τ)=30 K`
4. `τ=2000 s`、`θ_inf=3 K`、`θ(τ)=1.9 K`
5. `τ=6000 s`、`θ_inf=300 K`、`θ(τ)=189.6 K`

### 正答

2

### 完全解説

まず熱容量をSI単位へそろえる。

```text
C_th=200 kJ/K=200000 J/K
```

熱時定数は

```text
τ=R_th C_th
 =0.0030×200000
 =600 s
```

定常温度上昇は

```text
θ_inf=P_loss R_th
     =10000×0.0030
     =30 K
```

`t=τ` では

```text
θ(τ)=θ_inf(1-e^-1)
    =0.632×30
    =18.96 K
```

したがって正答は2。温度上昇は `t=τ` で定常値の約63.2%であり、定常値そのものにはまだ達しない。

# 二次試験型

## 問1 最大効率となる負荷率

定格出力 `P_N=200 kW`、固定損 `P_0=6.0 kW`、定格時の負荷依存損 `P_vN=10.0 kW` の機器を考える。負荷率を `x` とし、出力は `xP_N`、負荷依存損は `x^2P_vN` とする。

1. 最大効率条件を導出せよ。
2. 最大効率となる負荷率を求めよ。
3. そのときの出力、全損失、効率を求めよ。

### 完全解説

効率は

```text
η=xP_N/(xP_N+P_0+x^2P_vN)
```

である。分母を出力 `xP_N` で割ると、

```text
1/η=1+P_0/(xP_N)+xP_vN/P_N
```

効率最大は右辺の損失比が最小となる条件なので、`x` で微分して

```text
d/dx {P_0/(xP_N)+xP_vN/P_N}=0

-P_0/(x^2P_N)+P_vN/P_N=0
```

よって

```text
P_0=x^2P_vN
```

が最大効率条件である。

負荷率は

```text
x=sqrt(P_0/P_vN)
 =sqrt(6.0/10.0)
 =0.7746
```

したがって約 `77.5%`。

出力:

```text
P_out=0.7746×200
     =154.9 kW
```

負荷依存損:

```text
P_v=0.7746^2×10.0
   =6.0 kW
```

全損失:

```text
P_loss=6.0+6.0
      =12.0 kW
```

効率:

```text
η=154.9/(154.9+12.0)
 =0.9281
 ≒92.8%
```

検算: 最大効率点で固定損 `6.0 kW` と負荷依存損 `6.0 kW` が一致している。

## 問2 損失分離と部分負荷効率

教材用の試験結果として、無励磁回転時の機械損が `3.0 kW`、端子開放・励磁時の固定損が `8.0 kW` と測定された。また、定格時の直接負荷損を `10.0 kW`、雑負荷損を `2.0 kW` とする。定格出力は `200 kW` である。

負荷率 `x=0.80` では、直接負荷損と雑負荷損はいずれも `x^2` に比例すると仮定する。

1. 鉄損を求めよ。
2. `x=0.80` のときの負荷依存損、全損失を求めよ。
3. 出力、入力、効率を求めよ。

### 完全解説

機械損は `3.0 kW`、固定損は `8.0 kW` なので、鉄損は

```text
P_fe=8.0-3.0
    =5.0 kW
```

定格時の負荷依存損は

```text
P_vN=10.0+2.0
    =12.0 kW
```

負荷率0.8では

```text
P_v=0.8^2×12.0
   =7.68 kW
```

全損失は

```text
P_loss=8.0+7.68
      =15.68 kW
```

出力は

```text
P_out=0.8×200
     =160 kW
```

入力は

```text
P_in=160+15.68
    =175.68 kW
```

効率は

```text
η=160/175.68
 =0.9107
 ≒91.1%
```

検算: 機械損 `3.0 kW` と鉄損 `5.0 kW` の和は固定損 `8.0 kW`。また入力は出力より全損失 `15.68 kW` だけ大きい。

## 問3 簡略熱モデルの過渡応答

一定損失 `P_loss=12.0 kW`、熱抵抗 `R_th=0.0040 K/W`、熱容量 `C_th=150 kJ/K` の簡略熱モデルを考える。初期温度上昇は0とする。

1. 熱時定数 `τ` を求めよ。
2. 定常温度上昇 `θ_inf` を求めよ。
3. 10分後、20分後の温度上昇を求めよ。

### 完全解説

SI単位へ変換する。

```text
P_loss=12000 W
C_th=150000 J/K
```

熱時定数:

```text
τ=R_th C_th
 =0.0040×150000
 =600 s
 =10 min
```

定常温度上昇:

```text
θ_inf=P_loss R_th
     =12000×0.0040
     =48.0 K
```

10分後は `t=τ` なので、

```text
θ(10 min)=48.0(1-e^-1)
         =30.34 K
```

20分後は `t=2τ` なので、

```text
θ(20 min)=48.0(1-e^-2)
         =41.50 K
```

検算: `0<30.34<41.50<48.0 K` であり、温度上昇は時間とともに定常値へ近づいている。

この `R_th`、`C_th` は教材用仮定値であり、実車の熱定数ではない。

## 問4 定格・冷却・部分負荷効率・保守

教材用条件として、直流電動機の定格軸出力を `230 kW`、定格時固定損を `7.0 kW`、定格時負荷依存損を `8.0 kW` とする。負荷率 `x` に対し出力は `x`、負荷依存損は `x^2` に比例するとする。

1. 定格時効率を求めよ。
2. `x=0.50` の部分負荷効率を求めよ。
3. 固定損の割合が部分負荷効率へ与える影響を説明せよ。
4. 冷却を強めることと風損の関係、直流機の保守上の注意をTopic 09の範囲内で説明せよ。

### 完全解説

定格時の全損失は

```text
P_loss,N=7.0+8.0
        =15.0 kW
```

したがって定格時効率は

```text
η_N=230/(230+15)
   =0.9388
   ≒93.9%
```

負荷率0.5では

```text
P_out=0.5×230
     =115 kW
```

負荷依存損は

```text
P_v=0.5^2×8.0
   =2.0 kW
```

全損失は

```text
P_loss=7.0+2.0
      =9.0 kW
```

よって

```text
η=115/(115+9)
 =0.9274
 ≒92.7%
```

固定損は出力が低下しても基本整理では残るため、軽負荷になるほど出力に対する固定損の比率が大きくなり、部分負荷効率を低下させやすい。

冷却を強めて熱抵抗を小さくできれば、同じ損失でも温度上昇を抑えやすい。ただし送風に伴う風損は機械損の一部であり、冷却を強めれば効率損失が必ず減るとは限らない。直流機は整流子とブラシを持ち、ブラシは摩耗するため点検・交換が必要である。ここでは冷却風量設計やブラシ交換周期など、確認していない実車固有値へは広げない。

検算: 定格時も50%負荷時も入力は出力より損失分だけ大きく、効率は0〜1の範囲にある。
