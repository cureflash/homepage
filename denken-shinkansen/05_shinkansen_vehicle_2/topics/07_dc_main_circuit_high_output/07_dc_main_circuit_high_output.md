# 解説本文

## 1. このテーマで電験二種は何を問うか

このテーマでは、車両の世代名を暗記するのではなく、定格電圧・定格電流・出力・損失・効率を同じ電力収支へ落とし込む力を扱う。一次試験では「直流直巻電動機が電気鉄道に使われた理由」「効率・損失の分類」「負荷率による損失変化」が問われ、二次試験では与えられた端子電圧・電流・軸出力・ブラシ電圧降下から、抵抗・損失・誘導起電力を途中式付きで求めさせる。

新幹線への接続では、0系から100系・200系へ主電動機1台当たりの連続定格出力が185 kWから230 kWへ増えた事実を使う。ただし、制御方式の詳細はTopic 08以降へ送る。

## 2. 直流主回路の共通骨格

Topic 07で比較する範囲は、架線から主変圧器・整流部を経て直流主電動機へ電力を渡し、主電動機が機械出力へ変換するまでである。

`交流入力 → 主変圧器 → 整流部 → 直流主電動機 → 軸出力`

0系・100系・200系はいずれも直流主電動機を使う世代として比較できる。主回路の細かな制御方式の差はここでは解かない。比較する量は、主電動機の定格電圧、定格電流、定格出力、損失と冷却である。

## 3. 実車で確認できた主電動機定格値

| 車両 | 主電動機 | 連続定格出力 | 定格電圧 | 定格電流 | 定格回転数 | 冷却 |
|---|---|---:|---:|---:|---:|---|
| 0系 | MT200B | 185 kW | 415 V | 490 A | 2,200 rpm | 自己通風 |
| 100系 | MT202 | 230 kW | 625 V | 405 A | 2,900 rpm | 他力通風 |
| 200系 | MT201 | 230 kW | 475 V | 530 A | 2,150 rpm | 強制風冷 14 m3/min |

0系185 kWに対して100系・200系は230 kWなので、1台当たり連続定格出力は

`230 / 185 = 1.243`

すなわち約24.3%増である。

重要なのは「高出力化＝電流だけを増やす」ではない点である。100系MT202は0系MT200Bより出力が大きい一方、定格電流は490 Aから405 Aへ小さく、定格電圧は415 Vから625 Vへ高くなっている。200系MT201は475 V・530 Aで230 kWである。定格出力は電圧・電流・損失・回転機設計をまとめて見る。

## 4. 電気入力・軸出力・損失・効率

直流電動機の端子電圧を `V [V]`、電流を `I [A]` とすると、電気入力は

`P_in = VI [W]`

軸出力を `P_out [W]`、全損失を `P_loss [W]` とすると、

`P_in = P_out + P_loss`

したがって、

`P_loss = P_in - P_out`

効率は

`η = P_out / P_in`

百分率なら `η×100 [%]` である。

主電動機単体の定格値から `VI-P_out` を計算する場合、それはその定格条件での単純な入力―軸出力差であり、主変圧器・整流器や送風機補機を含む編成全体の損失ではない。範囲を混同しない。

## 5. 直流電動機の電圧方程式と損失

電機子電流を `I_a`、電機子抵抗を `R_a`、ブラシ全電圧降下を `V_b`、誘導起電力を `E` とすると、電動機運転時は

`V = E + I_a R_a + V_b`

よって

`E = V - I_a R_a - V_b`

電機子銅損は

`P_Cu = I_a^2 R_a`

ブラシ損は

`P_b = V_b I_a`

である。H24二次のように鉄損・界磁損・機械損を無視する条件では、

`VI = P_out + I_a^2 R_a + V_b I_a`

から

`R_a = (VI - P_out - V_b I_a) / I_a^2`

と直接求められる。

問題文に「無視する損失」が指定されているかを必ず読む。無視してよいと書かれていない損失を勝手に0にしてはいけない。

## 6. 直流直巻電動機と電気鉄道

H28・H26一次で必要なのは、電気鉄道では大きな始動トルクが要求され、直流直巻電動機が長く用いられたという対応である。

直巻機では界磁巻線と電機子が直列で、未飽和域では磁束 `Φ` が概ね電流 `I_a` に比例する。電磁トルクは

`T ∝ Φ I_a`

なので、未飽和域では概ね

`T ∝ I_a^2`

となり、始動時に大きなトルクを得やすい。ここではこの原理までを使い、後続制御方式には進まない。

## 7. 実測効率・規約効率・損失分類

H22一次では用語の区別が必要である。

- 実測効率: 実負荷で入力と出力を直接測って求める効率。
- 規約効率: 個々の損失を測定・算出し、規約に従って入力・出力との関係から求める効率。
- 固定損: 負荷変化に対して大きく変化しない損失として扱う成分。
- 負荷損: 主に電流に依存して増える損失。
- 漂遊負荷損: 負荷時に生じるが、単純な巻線抵抗損などへ直接分類できない追加損失。

定格出力は「電気入力」と同じ意味ではない。回転機では通常、定格出力は機械側の有効出力を指し、入力との差が損失になる。

## 8. 負荷率と損失

H21一次で必要な基本は、電流に比例する負荷率を `m` とすると、抵抗損が電流二乗で変わることである。

定格電流時の負荷損を `P_c` とし、電流が定格の `m` 倍なら、

`P_load = m^2 P_c`

となる。

一方、変圧器の出力は定格容量 `S_n`、負荷率 `m`、力率 `cosφ` を使えば

`P_out = m S_n cosφ`

で表せる。Topic 07ではこの関係を「主回路で出力条件が変われば損失も同じ割合では変わらない」ことの理解に使う。変圧器の詳細導出はTopic 01・06の既習事項とする。

## 9. 出力・損失・発熱・冷却

損失電力は最終的に熱として機器内部や周囲へ放出される。定常的なエネルギー収支の入口として、

`P_heat ≈ P_loss`

と考えることができる。

特に銅損は `I^2R` なので、抵抗が同じなら電流を10%増やすと銅損は

`1.1^2 = 1.21`

すなわち21%増える。高出力化では出力値だけでなく、損失と冷却を同時に確認する必要がある。

実車資料でも、0系MT200Bは自己通風、100系MT202は他力通風、200系MT201は強制風冷である。200系資料は、雪害対策と容量増大のために自己通風から強制通風へ変更したことを明記している。ここでは冷却の必要性までを扱い、温度上昇・熱抵抗・時定数などの詳細熱設計はTopic 09へ送る。

## 10. 編成出力

同一の主電動機を `N` 台搭載し、1台当たりの定格出力が `P_m` なら、単純な主電動機定格出力合計は

`P_train = N P_m`

である。

ただし、`N` は実編成の資料で確認できた値だけを使う。現段階で0系・100系・200系の主電動機搭載数を一次資料で全系列同一条件にそろえて確認していないため、実編成の数値比較は行わない。教材例題では「教材用仮定値」と明示した `N` を使う。

## 11. 高速化と必要出力

車輪周のけん引力を `F [N]`、速度を `v [m/s]` とすると、機械出力は

`P = Fv`

である。

同じけん引力を維持すると仮定すれば、速度が10%高くなると必要機械出力も10%高くなる。実際の高速車両では走行抵抗も速度で変わるが、その詳細モデルはここでは追加しない。Topic 07で必要なのは「高速域で同じ力を出し続けるには大きな出力が必要」という電力関係である。

## 12. 問題を見たときの解法手順

1. `V`、`I`、`P_out`、`V_b`、負荷率 `m` など既知量を抜き出す。
2. 「定格出力」が入力か出力かを確認する。回転機では通常は機械出力。
3. kWとW、km/hとm/sをそろえる。
4. まず `P_in=VI` で電気入力を求める。
5. 損失が問われるなら `P_loss=P_in-P_out`。損失内訳の条件があるなら `I_a^2R_a`、`V_bI_a` を使う。
6. 誘導起電力なら `E=V-I_aR_a-V_b`。
7. 負荷率問題では、出力の一次比例と抵抗損の二乗比例を混同しない。
8. 高速化問題では `P=Fv` を用い、速度単位をm/sへ変換する。
9. 最後に、入力より出力が大きくなっていないか、効率が0〜1か、損失が負になっていないかを検算する。

# 3段階例題

## 例題1 基礎: 入力・損失・効率

教材用仮定値として、直流電動機の端子電圧600 V、電流400 A、軸出力220 kWとする。電気入力、全損失、効率を求めよ。

電気入力:

`P_in = VI = 600×400 = 240,000 W = 240 kW`

全損失:

`P_loss = P_in - P_out = 240 - 220 = 20 kW`

効率:

`η = 220 / 240 = 0.9167 ≒ 91.7%`

定常的な単純熱収支では発熱率も約20 kWとみなせる。ここで220 kWを電気入力と誤読しないことがポイントである。

## 例題2 本試験標準: 電機子抵抗と誘導起電力

端子電圧200 V、軸出力3.75 kW、電機子電流20 A、ブラシ全電圧降下2.5 Vの直流電動機がある。鉄損・界磁損・機械損を無視する。電機子抵抗と誘導起電力を求めよ。

まず入力は

`VI = 200×20 = 4,000 W`

ブラシ損は

`P_b = 2.5×20 = 50 W`

したがって電機子銅損は

`P_Cu = 4,000 - 3,750 - 50 = 200 W`

よって

`R_a = P_Cu / I_a^2 = 200 / 20^2 = 0.500 Ω`

誘導起電力は

`E = V - I_aR_a - V_b`

`= 200 - 20×0.500 - 2.5 = 187.5 V`

したがって `R_a=0.500 Ω`、`E=187.5 V ≒188 V`。

二次試験では、銅損だけでなくブラシ損を先に差し引くこと、最後に電圧方程式へ戻すことが重要である。

## 例題3 複合: 高速化・入力・発熱

教材用仮定値として、列車が180 kNのけん引力を維持し、200 km/hから220 km/hへ速度を上げるとする。主回路から車輪までの総合効率を一定90%と仮定し、必要車輪出力、入力電力、損失を比較せよ。これは実車値ではない。

速度変換:

`200 km/h = 200/3.6 = 55.56 m/s`

`220 km/h = 220/3.6 = 61.11 m/s`

200 km/h時:

`P_out = Fv = 180,000×55.56 ≒ 10.0 MW`

`P_in = 10.0/0.90 = 11.11 MW`

`P_loss = 11.11-10.0 = 1.11 MW`

220 km/h時:

`P_out = 180,000×61.11 ≒ 11.0 MW`

`P_in = 11.0/0.90 = 12.22 MW`

`P_loss = 12.22-11.0 = 1.22 MW`

速度が10%増え、けん引力と効率を一定と仮定したので、必要出力・入力・損失も10%増える。この例題では実車の走行抵抗曲線やけん引力特性を推定していない。
