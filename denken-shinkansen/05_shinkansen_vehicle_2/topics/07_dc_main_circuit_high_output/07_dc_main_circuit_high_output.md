# EXAM_ALIGNMENT

資格: 第二種電気主任技術者

主科目:
- 一次試験「機械」
- 二次試験「機械・制御」

対象論点:
- 電気鉄道で直流直巻電動機が用いられた理由として、大きな始動トルクを要求すること
- 定格出力、定格電圧、定格電流を区別し、電気入力・機械出力・損失を結ぶこと
- 直流電動機で `P_in = VI`、電機子銅損 `P_Cu = I_a^2 R_a`、ブラシ損 `P_b = V_b I_a`、逆起電力 `E = V - I_a R_a - V_b` を扱うこと
- 回転機の効率、実測効率、規約効率、固定損、負荷損、漂遊負荷損を区別すること
- 主回路全体では、変圧器を含む損失が出力条件で変化することを前提に、世代別の出力―損失―発熱比較へ接続すること
- 損失電力が発熱になるため、高出力化では冷却が必要になること。ただしTopic 09の詳細熱設計へは進まないこと
- 編成出力は、確認済みの主電動機定格出力と搭載数からのみ集計すること
- 高速化との関係は、出典付き実車値と `P=Fv` の電力・けん引力関係で説明し、未確認の実車性能を推定しないこと

## H22 一次 機械 問1

- 効率は百分率で表し、指定がなければ有効出力には定格出力を用いる。
- 実負荷で入出力を直接測定して求めるのは実測効率。
- 損失を測定・算出して求めるのは規約効率。
- 負荷で生じ、直接負荷損に含まれない導体・鉄心等の損失は漂遊負荷損。
- 独立判断: `(1)=ヌ, (2)=ヨ, (3)=カ, (4)=ワ, (5)=ホ`
- 公式解答: `(1)=ヌ, (2)=ヨ, (3)=カ, (4)=ワ, (5)=ホ`
- 判定: `5 / 5 PASS`

## H21 一次 機械 問2

- 無負荷損の大部分は鉄損。
- 負荷損は基準巻線温度へ補正する。
- 定格二次電圧・定格周波数で出力と全損失から求める効率は規約効率。
- 負荷率 `m`、定格容量 `S_n`、力率 `cosφ` なら出力は `m S_n cosφ`。
- 定格電流時負荷損を `P_c` とすると、負荷損は電流二乗則から `m^2 P_c`。
- 独立判断: `(1)=ハ, (2)=ヨ, (3)=ロ, (4)=チ, (5)=ヌ`
- 公式解答: `(1)=ハ, (2)=ヨ, (3)=ロ, (4)=チ, (5)=ヌ`
- 判定: `5 / 5 PASS`

## H24 二次 機械・制御 問1

選定は(1)(2)のみ。与条件は端子電圧200 V、軸出力3.75 kW、電機子電流20 A、ブラシ全電圧降下2.5 V。鉄損・界磁損・機械損は無視する。

(1) 電機子銅損:

`P_Cu = VI - P_out - V_b I_a`

`= 200×20 - 3750 - 2.5×20 = 200 W`

したがって、

`R_a = P_Cu / I_a^2 = 200 / 20^2 = 0.500 Ω`

(2) 誘導起電力:

`E = V - V_b - I_a R_a`

`= 200 - 2.5 - 20×0.500 = 187.5 V ≒ 188 V`

公式標準解答は(1) `0.500 Ω`、(2) `188 V`。判定 `2 / 2 PASS`。

(3)〜(6)は可逆チョッパ・IGBT・制動制御を含むためTopic 07では採用しない。

# 教材必須説明

解説本文では、固定過去問15対象項目を解ける状態を保った上で、`SPEC.md` のTopic 07固定内容へ次の順で接続する。

1. 0系・100系・200系の主回路構成を、確認できた実資料だけで比較する。
2. 定格電圧・定格電流・主電動機出力を表にし、単位と「1台当たり」「編成全体」を混同しない。
3. `P_in=VI`、`P_out`、損失、効率の関係を整理する。
4. 直流電動機では `I_a^2R_a` とブラシ損を含め、出力を上げる条件が損失・発熱へどう効くか説明する。
5. 編成出力は、出典付きの主電動機定格出力×搭載数として検算する。
6. 高速化との関係は `P=Fv` を用い、同じけん引力を高い速度で維持するほど必要出力が増えることを説明する。ただし実車のけん引力・速度特性は確認資料なしに補完しない。
7. 損失電力を発熱として扱い、冷却の必要性まで説明する。温度上昇・熱抵抗等の詳細熱設計はTopic 09へ送る。
8. 指定3グラフ「世代別出力比較」「出力―損失」「出力―発熱」を作る。
