実車値は次の一次資料・学会資料で直接確認したものだけを採用した。

- 日立評論 1986年3月号「最新技術を応用した100系新幹線電車の電気品」
  - 0系 MT200B: 185 kW / 415 V / 490 A / 2,200 rpm / 自己通風
  - 100系 MT202: 230 kW / 625 V / 405 A / 2,900 rpm / 他力通風
- 電気学会雑誌 102巻2号（1982）200系新幹線電車解説
  - 200系 MT201: 230 kW / 475 V / 530 A / 2,150 rpm / 強制風冷14 m3/min

0系185 kWから100系・200系230 kWへの1台当たり連続定格出力増加は約24.3%。高出力化を電流増加だけで説明せず、定格電圧・定格電流・損失・冷却を同時に扱った。

本文では以下を収録済み。
- `P_in=VI`、`P_loss=P_in-P_out`、`η=P_out/P_in`

- 実測効率・規約効率・固定損・負荷損・漂遊負荷損
- 負荷率 `m` と `m^2P_c`
- 損失→発熱→冷却の接続
- 編成出力 `P_train=NP_m` の計算法。ただし未確認の実車搭載数は使用していない
- 高速化の一般関係 `P=Fv`
- 基礎／本試験標準／複合の3段階例題
