## 教材で必要な説明

1. 光束`F [lm]`、光度`I [cd]`、照度`E [lx]`を、光源全体の光量・特定方向の強さ・面が受ける光の量として区別し、`1 lx = 1 lm/m^2`を示す。
2. 均等放射光源では全立体角が`4π sr`であるため`I=F/(4π)`となることを説明し、lmからcdへの変換手順を示す。
3. 点光源の直下では距離の逆二乗則`E=I/h^2`を使うこと、斜入射では`E_h=I(θ)cosθ/r^2`となることを説明する。
4. 斜入射問題は`r=√(h^2+x^2)`、`cosθ=h/r`を先に求めてから照度式へ入れる手順を固定する。
5. 複数光源では、同一点への各光源の照度を個別に求めて加算する。光束や光度を無条件に先に足す解法と区別する。
6. LEDは、H27問16のように配光特性が問題文で与えられる光源として扱う。`I(θ)=I(0)cosθ`はその問題で与えられた配光式であり、すべてのLEDに一般化しない。
7. 解法手順を、光源条件判定→lm/cd/lxの量と単位を整理→幾何量`r, cosθ`を算出→光度→照度→複数光源なら加算→単位・桁を検算、の順で示す。
8. 頻出ミスとして、lm・cd・lxの混同、距離を2乗しない、斜入射の`cosθ`を落とす、水平距離と光路距離を取り違える、複数光源の加算漏れを扱う。

## 解説本文

### §1 このテーマで電験は何を問うか

Topic 27は電験三種「機械」の照明計算に対応する。品質ゲート対象5問・8小問で繰り返し必要なのは、光束`F [lm]`、光度`I [cd]`、照度`E [lx]`を区別し、光源と受照点の位置関係から適切な式を選ぶ力である。

問題を見たら、最初に次を判定する。

1. 光源は均等放射か、方向ごとの光度が与えられているか。
2. 与えられている量は光束`F`か、光度`I`か、照度`E`か。
3. 受照点は光源の直下か、斜め位置か。
4. 光源は1個か複数か。
5. LEDの配光式が問題文で個別に与えられているか。

この判定ができれば、`lm → cd → lx`の順に変換する問題、直下照度、斜入射照度、複数光源の合成、問題文で配光式が与えられるLED問題を同じ手順で処理できる。

### §2 光束 F [lm]

光束`F`は、光源から出る光の量を表す量で、単位はルーメン`lm`である。電験の照明計算では、光源全体の光束が与えられ、それを方向ごとの光度へ変換してから受照点の照度を求める形が多い。

光束`F`と照度`E`は同じものではない。光束が同じでも、受照面までの距離や光の入射方向が変われば照度は変わる。

### §3 光度 I [cd]

光度`I`は、ある方向へ向かう光の強さを表す量で、単位はカンデラ`cd`である。照度計算式に入れるのは、原則として受照点方向の光度である。

均等放射光源なら全方向で光度が同じなので、全光束`F`から光度`I`を求められる。方向によって光度が変わる光源では、問題文で与えられた配光条件を使って受照点方向の`I(θ)`を求める。

### §4 照度 E [lx]

照度`E`は、面が受ける光の量を表し、単位はルクス`lx`である。

`1 lx = 1 lm/m^2`

照度は「面」に対する量なので、同じ光度の光源でも距離が大きくなるほど小さくなり、斜めから光が当たる場合も小さくなる。したがって照度問題では、光源の強さだけでなく距離と入射角を必ず確認する。

### §5 均等放射光源: F から I へ

光源が全方向へ均等に放射するとき、全立体角は`4π sr`である。したがって光度は

`I = F/(4π)`

となる。

ここで
- `F`: 全光束 `[lm]`
- `I`: 光度 `[cd]`

である。

例えば全光束`F=2400 lm`の均等放射光源なら、

`I = 2400/(4π) ≈ 191 cd`

となる。この変換をせずに`2400 lm`をそのまま照度式へ入れてはいけない。

### §6 直下照度: E = I/h^2

点光源の直下に水平面があり、光源から面までの高さを`h [m]`とする。直下では光が面へ垂直に入射するので、照度は

`E = I/h^2`

となる。

距離が2倍になると照度は`1/4`、3倍になると`1/9`になる。電験では距離を2乗することを忘れる誤りが頻出する。

均等放射光源で全光束しか与えられていない場合は、先に`I=F/(4π)`で光度へ変換してから`E=I/h^2`へ進む。

### §7 斜入射の水平面照度

光源が受照点の真上にない場合、光源から受照点までの実距離を`r`、鉛直方向からの角度を`θ`とする。水平面照度は

`E_h = I(θ) cosθ / r^2`

で求める。

斜入射では照度が小さくなる理由が二つある。

1. 光路距離が`r`となり、逆二乗で弱くなる。
2. 水平面に斜めから入射するので`cosθ`が掛かる。

均等放射光源なら`I(θ)=I`で一定だが、配光が与えられた光源ではその方向の`I(θ)`を使う。

### §8 幾何計算: r と cosθ を先に求める

光源の高さを`h`、受照点までの水平距離を`x`とすると、直角三角形から

`r = √(h^2+x^2)`

`cosθ = h/r`

となる。

斜入射問題では、いきなり照度式へ数値を入れず、まず`r`と`cosθ`を別に計算する。水平距離`x`を`r`の代わりに使うと誤答になる。

手順は

`h, x → r → cosθ → I(θ) → E_h`

と固定するとよい。

### §9 複数光源の照度

複数の光源が同じ点を照らす場合、その点での照度は各光源による照度を個別に求めて加算する。

`E_total = E_1 + E_2 + ... + E_n`

光源配置が対称なら、1灯分を計算して灯数倍できる。ただし、各光源から受照点までの距離や角度が同じことを確認してから使う。

光束や光度を無条件に先に合計するのではなく、「各光源がその受照点へ与える照度」を合計するのが基本である。

### §10 LED配光式が与えられる問題

LED問題では、方向によって光度が変わる配光条件が問題文で与えられる場合がある。品質ゲート対象のH27問16では

`I(θ) = I(0) cosθ`

という式が問題文で与えられている。

この場合、斜め方向の水平面照度は

`E_h = I(θ) cosθ / r^2`

なので、与えられた配光式を代入すると

`E_h = I(0) cos^2θ / r^2`

と整理できる。

ただし`I(θ)=I(0)cosθ`をすべてのLEDへ一般化してはいけない。Topic 27では「問題文で配光式が与えられたら、その式を使う」と理解する。

### §11 本試験で再利用する解法手順

1. 光源条件を確認する。均等放射か、方向別の配光式があるか。
2. 与えられた量と単位を整理する。`F [lm]`、`I [cd]`、`E [lx]`を混同しない。
3. 斜入射なら`r=√(h^2+x^2)`と`cosθ=h/r`を先に求める。
4. 全光束しかない均等光源なら`I=F/(4π)`で光度へ変換する。
5. 直下なら`E=I/h^2`、斜入射なら`E_h=I(θ)cosθ/r^2`を使う。
6. 複数光源なら各光源の照度を加算する。
7. 最後に単位が`lx`になっているか、距離を2乗したか、斜入射で`cosθ`を入れたかを確認する。

### §12 頻出ミス

- `lm`、`cd`、`lx`を同じ量として扱う。
- 均等放射光源で`I=F/(4π)`への変換を忘れる。
- `E=I/r`のように距離を2乗しない。
- 斜入射なのに`cosθ`を掛けない。
- 水平距離`x`を光路距離`r`として使う。
- 複数光源なのに1灯分で止める。
- LEDの個別配光式を一般法則と誤認する。

### §13 新幹線への接続

このテーマでは、新幹線の車内照明を「照明計算を具体化する設備」として扱う。車内の灯具が客室の面を照らす状況を、点光源と受照点のモデルに置き換えると、電験で扱う光束・光度・照度・距離・入射角の関係を同じ式で整理できる。

ただし、実車の器具数、光束、照度、消費電力などは本Topicでは一次資料で確定していないため、真値としては置かない。例題の数値は照明計算の理解用の仮定値であり、実車仕様を示すものではない。

### §15 公式・解法まとめ

- 均等放射光源: `I=F/(4π)`
- 直下照度: `E=I/h^2`
- 斜入射水平面照度: `E_h=I(θ)cosθ/r^2`
- 幾何: `r=√(h^2+x^2)`、`cosθ=h/r`
- 複数光源: `E_total=ΣE_i`
- LED配光式: 問題文で与えられた式をその問題に限って使う

解法の軸は、`光源条件 → 単位 → 幾何 → 光度 → 照度 → 加算 → 検算`である。

## 3段階例題

### 例題1 基礎: 全光束から直下照度

全方向へ均等に光を出す点光源の全光束が`2400 lm`である。この光源を水平面から`3.0 m`の高さに置いた。光源直下の照度を求めよ。

#### 解法

均等放射なので、まず全光束を光度へ変換する。

`I = F/(4π) = 2400/(4π) ≈ 190.99 cd`

直下なので

`E = I/h^2 = 190.99/3.0^2 ≈ 21.22 lx`

答え: 約`21.2 lx`。

この例題では、`lm`をそのまま照度式へ入れず、`lm → cd → lx`の順に変換する。

### 例題2 本試験標準: 斜入射水平面照度

全方向へ均等に光を出す点光源の全光束を`3600 lm`とする。光源は水平面から`3.0 m`の高さにあり、受照点は光源直下から水平に`4.0 m`離れている。受照点の水平面照度を求めよ。

#### 解法

まず光度を求める。

`I = 3600/(4π) ≈ 286.48 cd`

幾何量は

`r = √(3.0^2+4.0^2) = 5.0 m`

`cosθ = 3.0/5.0 = 0.6`

したがって

`E_h = I cosθ/r^2`

`= 286.48×0.6/5.0^2`

`≈ 6.88 lx`

答え: 約`6.88 lx`。

水平距離`4.0 m`ではなく光路距離`5.0 m`を逆二乗項に使い、さらに`cosθ`を掛けることが要点である。

### 例題3 複合・ひっかけ: 配光式付きLEDを2灯合成

同じLED灯具2灯が、ある受照点に対して左右対称に配置されている。各灯具の鉛直方向光度を`I(0)=250 cd`とし、問題文で配光式

`I(θ)=I(0)cosθ`

が与えられている。各灯具の高さは`3.0 m`、各灯具直下から受照点までの水平距離は`4.0 m`である。2灯による受照点の水平面照度を求めよ。

#### 解法

各灯具について

`r = √(3.0^2+4.0^2) = 5.0 m`

`cosθ = 3.0/5.0 = 0.6`

問題文の配光式から

`I(θ)=250×0.6=150 cd`

1灯による水平面照度は

`E_1 = I(θ)cosθ/r^2`

`=150×0.6/5.0^2`

`=3.6 lx`

左右対称の2灯なので

`E_total = 2E_1 = 7.2 lx`

答え: `7.2 lx`。

ひっかけは、配光式の`cosθ`と水平面照度式の`cosθ`が別々に必要な点、1灯分で止めず2灯分を加算する点である。
