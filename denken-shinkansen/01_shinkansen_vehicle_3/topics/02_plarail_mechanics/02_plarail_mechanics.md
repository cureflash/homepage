## 教材で必要な説明

- `min^-1` から `rad/s` への変換。
- `P=ωT` と `P=Fv` の関係。
- `T=Fr` で直径ではなく半径を使うこと。
- 減速比の定義と、減速による速度低下・トルク増大・効率損失。
- `η=Pout/Pin`、直列効率の積。
- 直流電動機の `V=E+IaRa`、`E∝φn`、`T∝φIa`。
- `EIa=ωT` と軸出力の違い。機械損を無視できる条件。
- 永久磁石界磁・分巻電動機で磁束一定と見なす条件。
- 回転運動エネルギー `Ek=1/2Jω^2`。

## 新幹線・プラレール側の実値と仮定値

### 実値として確認したもの

- タカラトミー公式の現行 S-02「ライト付500系新幹線（ハイパワーライト）」は、3両編成、2スピード、スイッチOFFで手転がし可能、単3乾電池1本使用。
- ニデック公式資料で、トルク・回転力、T/N特性・N/T特性を確認。

### 仮定値として隔離したもの

対象プラレールのモーター回転速度、ギヤ比、車輪径、軸トルク、ギヤ効率は公式公開値として確認できなかった。教材では次を学習用仮定値として使い、実製品性能値として扱わない。

- モーター回転速度 `Nm = 12000 min^-1`
- 減速比 `a = 30`
- 車輪直径 `D = 0.024 m`
- モータートルク `Tm = 0.00050 N m`
- ギヤ効率 `ηg = 0.70`

この仮定からの計算値:

- 車軸回転速度 `NL = 400 min^-1`
- 車輪周速度 `v = 0.503 m/s = 1.81 km/h`
- 車軸トルク `TL = 0.0105 N m`
- 車輪周の接線力 `F = 0.875 N`
- 車輪での機械出力 `P = 0.440 W`

## 公式過去問の独立再解答

保存済み正答を先に見ず、教材内容だけで再解答した。

- 令和7年度下期 機械 問1: 分巻電動機は `T∝Ia`、`n∝V-IaRa`。負荷電流増加に対しトルクは増加、速度はわずかに低下する特性曲線を選択。PASS。
- 令和7年度下期 機械 問2: 銅損から `Ra`、負荷時 `E=V-IaRa`、磁束一定で `n∝E` の順に処理。PASS。
- 令和3年度 機械 問2: 1回目条件から `E1=P/Ia`、`Ra=(V-E1)/Ia`、2回目で `E2=V-IaRa`、`P2=E2Ia`、`T=P2/(2πN/60)`。選択肢照合まで再現。PASS。
- 平成28年度 機械 問1: `E1=100-50×0.2=90 V`、`E2=115-50×0.2=105 V`、`n2=1500×105/90=1750 min^-1`。選択肢(4)。PASS。
- 令和5年度下期 機械 問11: `N/60`、`ω=2πn`、`T=P/ω`、`Ek=1/2Jω^2` の連鎖で再解答。PASS。
