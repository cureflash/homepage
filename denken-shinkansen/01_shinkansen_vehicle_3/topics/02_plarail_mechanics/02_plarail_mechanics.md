# 02 プラレール② 機械編

## この章の目的

この章の主目的は、プラレールのギヤ構造を詳しく知ることではない。

**電験三種「機械」で頻出する回転速度、角速度、トルク、機械出力、直流電動機の速度・トルク特性、損失・効率を、プラレールのモーター・歯車・車輪を入口にして理解し、初見の五肢択一問題を自力で解けるようにすること**を目的とする。

この章を終えた時点で、少なくとも次をできる状態を目標とする。

- `min^-1`、`s^-1`、`rad/s` を相互変換できる。
- `ω = 2πN/60` を使って回転速度から角速度を求められる。
- `P = ωT` を使って出力・トルク・回転速度を相互に求められる。
- `T = Fr` と `P = Fv` を使い、回転運動と直線運動を結び付けられる。
- 減速比から出力軸回転速度とトルクを計算できる。
- 減速機効率を含めて出力側トルク・出力を計算できる。
- 電動機の入力、電磁変換出力、軸出力、損失、効率を区別できる。
- 直流電動機の `V = E + I_aR_a`、`E ∝ φn`、`T ∝ φI_a` を使える。
- 分巻電動機で負荷が増えるとトルクが増え、回転速度がわずかに低下する理由を説明できる。
- 回転体の運動エネルギー `E_k = 1/2 Jω^2` を扱える。
- 電験三種の電動機・回転運動の典型問題を、与えられた量から順序立てて解ける。

# 1. プラレールの駆動系を一つのエネルギー変換として見る

プラレールでは、乾電池の電気エネルギーがモーターで機械エネルギーへ変換され、その回転が歯車を通って車輪へ伝わる。

概念的には次の流れになる。

```text
乾電池
  ↓ 電力
直流モーター
  ↓ 回転速度 N_m・トルク T_m
減速歯車
  ↓ 回転速度を下げ、トルクを増やす
車軸・車輪
  ↓ 接線力 F
車両の走行
```

この流れは、電験三種の「電動機の出力」「減速機の所要出力」「負荷トルク」を理解するための縮小模型として使える。

ただし、プラレール固有のギヤ比やモーター定数を暗記する必要はない。本試験で必要なのは、このエネルギー変換を一般式で扱う能力である。

---

# 2. 回転速度 `N` と角速度 `ω`

電動機の問題では、回転速度が `min^-1` で与えられることが多い。

例えば

```text
N = 1800 min^-1
```

は「1分間に1800回転」という意味である。

1秒当たりの回転数は

```text
n = N / 60
```

なので、

```text
1800 / 60 = 30 s^-1
```

となる。

1回転は `2π rad` だから、角速度は

```text
ω = 2πN / 60
```

である。

`N = 1800 min^-1` なら、

```text
ω = 2π × 1800 / 60
  = 60π
  ≒ 188.5 rad/s
```

となる。

## 電験での典型ミス

最も多いのは、`min^-1` のまま `2πN` としてしまうミスである。

`P=ωT` に入れる `ω` は `rad/s` なので、回転速度が `min^-1` なら必ず `/60` が必要になる。

---

# 3. トルクとは何か

トルクは、回転軸を回そうとする作用の大きさである。

半径 `r[m]` の位置に接線方向の力 `F[N]` が作用すると、

```text
T = Fr
```

となる。

したがって、

```text
F = T / r
```

とも書ける。

例えば車輪半径が `0.012 m`、車軸トルクが `0.0105 N·m` なら、理想化した車輪周の接線力は

```text
F = 0.0105 / 0.012
  = 0.875 N
```

となる。

ここで直径と半径を取り違えないことが重要である。

---

# 4. 回転機械の最重要式 `P = ωT`

回転軸が角速度 `ω[rad/s]`、トルク `T[N·m]` で回転しているとき、機械出力は

```text
P = ωT
```

である。

単位を確認すると、

```text
(rad/s) × (N·m)
```

となる。radは無次元なので、結果は `N·m/s = W` である。

回転速度 `N[min^-1]` を直接使うなら、

```text
P = 2πNT / 60
```

となる。

逆算も重要である。

```text
T = P / ω
ω = P / T
```

本試験では、出力と回転速度からトルクを求める形が頻出する。

## 基礎例題

出力 `2.0 kW`、回転速度 `1800 min^-1` の軸トルクを求める。

まず、

```text
ω = 2π × 1800 / 60
  = 60π rad/s
```

したがって、

```text
T = 2000 / (60π)
  ≒ 10.61 N·m
```

となる。

---

# 5. `P = Fv` と `P = Tω` は同じ仕事率を表す

車輪の半径を `r`、角速度を `ω` とすると、車輪周速度は

```text
v = rω
```

である。

また、

```text
T = Fr
```

だから、

```text
P = Tω
  = Frω
  = Fv
```

となる。

つまり、

```text
回転軸側: P = Tω
車両側:   P = Fv
```

は同じ機械出力を別の見方で表している。

この関係は、新幹線で「主電動機の軸出力」から「車輪周のけん引力」へつなぐときにも使う。

---

# 6. 歯車は速度とトルクを交換する

この章では減速比 `a` を

```text
a = N_m / N_L
```

と定義する。

`N_m` はモーター側回転速度、`N_L` は負荷側回転速度である。

したがって、

```text
N_L = N_m / a
```

となる。

減速比が30なら、モーターが12000 `min^-1` で回っていても出力軸は

```text
12000 / 30 = 400 min^-1
```

となる。

## 理想的な歯車

損失がないなら入力出力の機械出力は等しい。

```text
ω_m T_m = ω_L T_L
```

回転速度が `1/a` になるので、トルクは `a` 倍になる。

```text
T_L = aT_m
```

## 実際の歯車

実際には損失があるので、減速機効率を `η_g` とすると、

```text
P_L = η_g P_m
```

したがって、

```text
T_L = η_g a T_m
```

となる。

### 注意

減速比の定義は資料・問題によって逆数で定義されることがある。電験では式を丸暗記せず、**問題文が減速比をどちら向きに定義しているか確認する**。

---

# 7. 効率と損失

効率は

```text
η = P_out / P_in
```

である。

百分率なら、

```text
η[%] = P_out / P_in × 100
```

損失は

```text
P_loss = P_in - P_out
```

である。

例えば入力 `500 W`、出力 `400 W` なら、

```text
η = 400 / 500 = 0.80 = 80%
P_loss = 100 W
```

となる。

モーター効率 `η_m` と歯車効率 `η_g` が直列に存在するなら、総合効率は

```text
η_total = η_m η_g
```

である。

例えば、

```text
η_m = 0.90
η_g = 0.80
```

なら、

```text
η_total = 0.72 = 72%
```

となる。

---

# 8. ここからが電験本番: 直流電動機の電気と機械をつなぐ

プラレールのような小形直流モーターから、電験三種の直流電動機へ一般化する。

電機子回路では、

```text
V = E + I_aR_a
```

が基本である。

- `V`: 端子電圧[V]
- `E`: 逆起電力[V]
- `I_a`: 電機子電流[A]
- `R_a`: 電機子抵抗[Ω]

したがって、

```text
E = V - I_aR_a
```

となる。

## なぜ逆起電力が重要なのか

回転中の電動機は、発電機と同じ原理で電圧を発生する。その向きは電源電圧に逆らうので「逆起電力」と呼ぶ。

このため、回転中の電機子電流は単純な `V/R_a` ではない。

```text
I_a = (V-E) / R_a
```

で決まる。

停止中は `E=0` に近いため、何も対策しなければ大きな始動電流が流れる。この考え方は後の直流電動機の始動・速度制御へつながる。

---

# 9. 逆起電力と回転速度

直流電動機では、

```text
E = K_e φ n
```

と表せる。

したがって、

```text
n = E / (K_e φ)
```

である。

端子電圧式を代入すると、

```text
n = (V-I_aR_a) / (K_e φ)
```

となる。

つまり回転速度は、おおまかに

- 端子電圧 `V` を上げると上がる
- 電機子電流 `I_a` が増えると電圧降下が増えて下がる
- 磁束 `φ` を増やすと下がる

という関係になる。

## 平成28年度 機械 問1型

磁束と電機子電流が変わらないなら、

```text
n ∝ E
```

である。

例えば、

```text
V1 = 100 V
I_a = 50 A
R_a = 0.2 Ω
n1 = 1500 min^-1
```

なら、

```text
E1 = 100 - 50×0.2 = 90 V
```

端子電圧を115 Vへ上げ、電流・磁束が同じなら、

```text
E2 = 115 - 50×0.2 = 105 V
```

だから、

```text
n2 / n1 = E2 / E1
n2 = 1500 × 105/90
   = 1750 min^-1
```

となる。

この問題で重要なのは、単純に `115/100` を回転速度へ掛けないことである。回転速度に比例するのは端子電圧そのものではなく、磁束一定なら**逆起電力 `E`**である。

---

# 10. トルクと電機子電流

直流電動機の発生トルクは、

```text
T = K_t φ I_a
```

で表される。

分巻電動機では端子電圧と界磁抵抗が一定なら、界磁磁束 `φ` はほぼ一定と考えられる。

したがって、

```text
T ∝ I_a
```

となる。

負荷が増えると必要トルクが増え、電機子電流が増える。その結果、`I_aR_a` の電圧降下が少し増えるため、回転速度はわずかに低下する。

このため直流分巻電動機は、

```text
負荷電流 ↑ → トルク ↑（ほぼ直線）
負荷電流 ↑ → 回転速度 ↓（わずか）
```

という特性を持つ。

これは令和7年度下期機械問1で、そのまま特性曲線として問われている。

---

# 11. 電磁変換出力 `EI_a` と `ωT`

直流電動機では、電機子へ入る電力は

```text
VI_a
```

である。

電機子銅損は

```text
I_a^2R_a
```

だから、

```text
VI_a - I_a^2R_a
= (V-I_aR_a)I_a
= EI_a
```

となる。

この `EI_a` は電気から機械へ変換された電磁変換出力であり、

```text
EI_a = ωT
```

と結び付く。

ただし、軸受摩擦・風損などの機械損がある実機では、軸から取り出せる最終的な軸出力はさらに小さくなる。

```text
軸出力 = EI_a - 機械損など
```

問題文で「損失は銅損だけ」「機械損を無視」と指定されている場合だけ、`EI_a` をそのまま機械出力として扱える。

ここは本試験で非常に重要な条件判断である。

# 12. 本試験標準例題: 出力からトルクを求める

ある直流電動機について、

```text
V = 200 V
I_a = 50 A
R_a = 0.40 Ω
N = 1000 min^-1
```

とし、機械損は無視する。

## 1. 逆起電力

```text
E = V-I_aR_a
  = 200 - 50×0.40
  = 180 V
```

## 2. 電磁変換出力

```text
P = EI_a
  = 180×50
  = 9000 W
```

## 3. 角速度

```text
ω = 2π×1000/60
  ≒ 104.72 rad/s
```

## 4. トルク

```text
T = P/ω
  = 9000/104.72
  ≒ 85.9 N·m
```

### 解法の順番

```text
V, I_a, R_a
↓
E = V-I_aR_a
↓
P = EI_a
↓
N → ω
↓
T = P/ω
```

この順番を使えるようにすることが、本試験対策では重要である。

# 13. 令和7年度下期 問2型: 銅損から回転速度を求める

永久磁石界磁の直流電動機では、磁束を一定とみなせる。

無負荷で12 V、3000 `min^-1`、負荷時に電機子電流2 A、電機子銅損3 Wという条件を考える。

## 1. 電機子抵抗

銅損より、

```text
P_cu = I_a^2R_a
```

なので、

```text
R_a = 3 / 2^2
    = 0.75 Ω
```

## 2. 負荷時の逆起電力

```text
E = 12 - 2×0.75
  = 10.5 V
```

## 3. 回転速度

無負荷では電流が十分小さいとみなし、逆起電力を約12 Vとする。

永久磁石なので磁束一定で、

```text
n ∝ E
```

したがって、

```text
n = 3000 × 10.5/12
  = 2625 min^-1
```

となる。

ここでは、

```text
銅損
↓
抵抗
↓
逆起電力
↓
回転速度
```

という複数段階の処理が必要である。

# 14. 回転体に蓄えられる運動エネルギー

回転体の慣性モーメントを `J[kg·m^2]`、角速度を `ω[rad/s]` とすると、回転運動エネルギーは

```text
E_k = 1/2 Jω^2
```

である。

直線運動の

```text
E_k = 1/2 mv^2
```

に対応する式である。

令和5年度下期機械問11では、

```text
N[min^-1]
↓
N/60 [s^-1]
↓
ω [rad/s]
↓
T=P/ω
↓
E_k=1/2 Jω^2
```

という流れがまとめて問われている。

このため、角速度変換と `P=ωT` は単独公式ではなく、回転運動全体の計算言語として身につける必要がある。

---

# 15. プラレールを使って一連の計算をする

タカラトミー公式では、現行のS-02「ライト付500系新幹線（ハイパワーライト）」について、3両編成、2スピード、スイッチOFFで手転がし可能、単3乾電池1本使用であることが公開されている。

一方で、モーター回転数、ギヤ比、車輪径、軸トルク、ギヤ効率は公開仕様として確認できない。

そこで以下は**学習用仮定値**とする。

```text
モーター回転速度 N_m = 12000 min^-1
減速比 a = 30
車輪直径 D = 0.024 m
モータートルク T_m = 0.00050 N·m
ギヤ効率 η_g = 0.70
```

## 1. 車軸回転速度

```text
N_L = 12000/30
    = 400 min^-1
```

## 2. 車輪周速度

滑りがない理想条件なら、

```text
v = πDN_L/60
  = π×0.024×400/60
  ≒ 0.503 m/s
```

約 `1.81 km/h` である。

## 3. 車軸トルク

```text
T_L = η_g a T_m
    = 0.70×30×0.00050
    = 0.0105 N·m
```

## 4. 車輪周の接線力

車輪半径は `0.012 m` なので、

```text
F = T_L/r
  = 0.0105/0.012
  = 0.875 N
```

## 5. 車輪での機械出力

```text
P = Fv
  = 0.875×0.503
  ≒ 0.440 W
```

別ルートでも確認する。

モーター側の角速度は、

```text
ω_m = 2π×12000/60
    ≒ 1256.64 rad/s
```

モーター軸出力は、

```text
P_m = ω_mT_m
    = 1256.64×0.00050
    ≒ 0.628 W
```

ギヤ効率70%を掛けると、

```text
P_L = 0.628×0.70
    ≒ 0.440 W
```

となり、`Fv` から求めた値と一致する。

このように、同じ出力を別の式で再計算することで検算できる。

### 実機との差

実際には、

- モーター回転速度は負荷で変化する
- 歯車・軸受・タイヤに損失がある
- 車輪の滑りや変形がある
- 乾電池電圧も負荷によって変化する

ため、この数値を実製品の性能値として扱ってはいけない。

---

# 16. 本試験で使う解法アルゴリズム

電動機・回転問題では、次の順番で整理する。

```text
1. 求める量を確認する
   回転速度 / 角速度 / トルク / 出力 / 効率 / 力

2. 与えられた回転速度の単位を見る
   min^-1 なら必要に応じて rad/s へ変換

3. 直流電動機なら電機子回路を書く
   V = E + I_aR_a

4. 損失条件を確認する
   銅損だけか、機械損もあるか

5. 電気側から機械側へつなぐ
   E I_a = ωT

6. 歯車があれば減速比と効率を適用する

7. 車輪・巻上げなら
   T=Fr, P=Fv
   へ変換する

8. 単位と物理的妥当性を検算する
```

# 17. 頻出ミス

## ミス1: `min^-1` をそのまま角速度として使う

誤り:

```text
ω = 2πN
```

`N` が `min^-1` なら正しくは、

```text
ω = 2πN/60
```

である。

## ミス2: 出力とトルクを同じものだと思う

トルクが大きくても回転速度が低ければ出力が大きいとは限らない。

```text
P=ωT
```

で必ず両方を見る。

## ミス3: 減速すると出力まで減速比倍になると思う

理想歯車では出力は保存され、速度が下がる代わりにトルクが増える。

実際に減るのは効率による損失分である。

## ミス4: ギヤ効率を逆に掛ける

入力から出力を求めるなら、

```text
P_out = ηP_in
```

である。

## ミス5: 車輪径を `T=Fr` の `r` に入れる

使うのは直径ではなく半径である。

## ミス6: 直流電動機を単純な抵抗として扱う

回転中は逆起電力がある。

```text
I_a ≠ V/R_a
```

一般には、

```text
I_a = (V-E)/R_a
```

である。

## ミス7: `EI_a` と最終軸出力を常に同一視する

機械損がある場合、

```text
軸出力 < EI_a
```

となる。

問題文の損失条件を必ず読む。

## ミス8: 端子電圧と回転速度が単純比例すると決めつける

磁束一定なら回転速度に比例するのは、より正確には

```text
E = V-I_aR_a
```

で表される逆起電力である。

# 18. この章の公式まとめ

## 回転速度・角速度

```text
n = N/60
ω = 2πN/60
```

## 機械出力

```text
P = ωT
P = Fv
```

## トルクと力

```text
T = Fr
F = T/r
```

## 減速機

本章の減速比定義 `a=N_m/N_L` では、

```text
N_L = N_m/a
T_L = η_g aT_m
P_L = η_gP_m
```

## 効率

```text
η = P_out/P_in
P_loss = P_in-P_out
η_total = η_1η_2…
```

## 直流電動機

```text
V = E+I_aR_a
E = V-I_aR_a
E = K_eφn
T = K_tφI_a
EI_a = ωT
```

## 回転運動エネルギー

```text
E_k = 1/2 Jω^2
```

# 19. この章を終えたら解けるべき問題

この章の完成判定では、少なくとも次の型を教材だけで解けることを要求する。

1. 回転速度とトルクから電動機出力を求める。
2. 出力と回転速度からトルクを逆算する。
3. 銅損から電機子抵抗を求め、逆起電力から負荷時回転速度を求める。
4. 端子電圧変更前後の逆起電力比から回転速度を求める。
5. 分巻電動機の負荷電流―トルク―回転速度特性を選ぶ。
6. 減速比・効率から負荷側回転速度とトルクを求める。
7. 車輪トルクから接線力を求める。
8. `P=ωT` と `P=Fv` を相互検算する。
9. 複数効率を掛け合わせて総合効率を求める。
10. 慣性モーメントと角速度から回転運動エネルギーを求める。

ここまで扱って初めて、「プラレールの仕組みを知った」ではなく、**電験三種の機械問題に使える知識になった**と判定する。
