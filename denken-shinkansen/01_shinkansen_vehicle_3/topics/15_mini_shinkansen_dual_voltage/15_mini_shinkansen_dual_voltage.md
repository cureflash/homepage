# 15 400系・E3系・E6系・E8系 新在直通

## EXAM_ALIGNMENT

資格: 第三種電気主任技術者

科目: 機械（変圧器）

論点: 複電圧入力を、変圧器の巻数比・電流比・容量・損失・効率・等価回路・定格の一般問題へ接続する。

### 公式過去問

1. R5年度上期 / 機械 / 問9
   - 要求知識: 変圧器の鉄損・銅損、負荷率、最大効率条件
   - 使用式: `Pcu=x^2 Pcu,n`、最大効率条件 `Pcu=Pi`、`η=Pout/(Pout+Pi+Pcu)`
   - 設問型: 五肢択一計算
   - 典型ミス: 銅損を負荷率に比例させる、最大効率条件を全負荷条件と混同する
   - 教材で必要: 定格容量と負荷率、鉄損・銅損、最大効率
2. R4年度下期 / 機械 / 問8
   - 要求知識: 変圧器の無負荷損と負荷損、銅損の電流二乗則
   - 使用式: `Ploss=Pi+kI^2`
   - 設問型: 五肢択一・連立計算
   - 典型ミス: 全損失を電流に比例するとみなす、鉄損まで負荷電流で変化させる
   - 教材で必要: 無負荷損と負荷損の分離、2条件からの逆算
3. R4年度上期 / 機械 / 問8
   - 要求知識: 短絡試験、等価抵抗・漏れリアクタンス
   - 使用式: `Z=Vsc/Isc`、`R=Psc/Isc^2`、`X=sqrt(Z^2-R^2)`
   - 設問型: 五肢択一計算
   - 典型ミス: 電力計値から直接インピーダンスを求める、RとXの直線和を取る
   - 教材で必要: 短絡試験の意味、簡易等価回路、ベクトル合成
4. R3年度 / 機械 / 問9
   - 要求知識: 全負荷銅損、百分率抵抗降下、電圧変動率
   - 使用式: `p=Pcu/Sn×100`、力率1では近似的に `ε=p`
   - 設問型: 五肢択一計算
   - 典型ミス: kW/kVAをそろえない、百分率リアクタンスを不要なのに混ぜる
   - 教材で必要: 定格容量、百分率インピーダンス、電圧変動率の近似
5. R2年度 / 機械 / 問9
   - 要求知識: 三巻線変圧器、皮相電力・有効電力・無効電力、一次電流
   - 使用式: `S=P+jQ`、`P=sqrt(3)VIcosφ`、`Q=sqrt(3)VIsinφ`
   - 設問型: 五肢択一・複素電力計算
   - 典型ミス: kVAを有効電力として単純加算する、コンデンサの無効電力符号を誤る
   - 教材で必要: 複数巻線・複数負荷を一つの入力側へまとめる考え方、容量と電流

## 教材で必要な説明

- `E1/E2=N1/N2`、理想変圧器の `I1/I2=N2/N1` と容量保存の意味
- 20 kV入力と25 kV入力を「同じ二次側必要電圧へ合わせる」という複電圧入力の一般化
- 入力電圧が変わると、同じ皮相電力を扱う入力電流は `I=S/V`（三相なら `S=sqrt(3)VI`）に従って変わること
- 定格電圧・定格電流・定格容量を別物として扱うこと
- 鉄損は近似的に負荷によらず、銅損は `I^2` に比例すること
- 最大効率条件 `Pcu=Pi`
- 短絡試験から等価抵抗・漏れリアクタンスを求める手順
- 電圧変動率と百分率抵抗降下の関係
- 多巻線・複数負荷では有効電力と無効電力を分けて入力側へ集約すること
- 新幹線側は20 kV/25 kVという入力条件を例示するだけに留め、電験では一般の変圧器問題へ転用できるようにする

## 新幹線実例の調査状況

JR東日本公式資料で、400系・E3系に続く山形新幹線の新在直通車両としてE8系が運用され、東北新幹線と山形新幹線を直通することを確認した。JR東日本のE8系公式ページでは2024年3月16日運行開始、営業最高速度300 km/h、東京〜新庄間での運用が確認できる。

新在直通車両の電源条件については、公開技術資料・車両資料で新幹線区間の交流25 kVと在来線区間の交流20 kVへの対応が記述されている。ただし、現時点でJR東日本一次資料から各系列の主変圧器巻数・タップ構成・切替シーケンス・実二次電圧を確認できていないため、それらは真値として教材へ入れない。

一次資料で確認できた範囲と、二次資料で確認した20/25 kV複電圧条件を明確に分離して扱う。
