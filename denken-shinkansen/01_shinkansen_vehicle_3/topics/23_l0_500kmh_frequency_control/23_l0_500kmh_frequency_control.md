# 解説本文

## 1. このテーマで電験は何を問うか

このテーマの中心は、機械科目の「周波数を変えると磁界の同期速度がどう変わるか」と「その周波数を電力変換装置でどう作るか」である。本試験では、極数と周波数から同期速度を求める計算、`min^-1` と `rad/s` の換算、V/f一定制御、インバータによる可変周波数交流、電力とトルクの関係が出題される。

この章を終えた時点で、次を自力で処理できることを目標とする。

- 極数 `p` と周波数 `f` から同期速度 `Ns` を求める。
- 同期速度から周波数または極数を逆算する。
- 同期速度を同期角速度 `ωs` に換算する。
- 周波数を変えたとき、同期速度が何倍になるか判断する。
- V/fをほぼ一定にする目的を説明する。
- 整流器とインバータの役割を区別する。
- 電力と回転速度からトルクを求める。
- L0系で周波数が速度制御に使われる理由を、実車の未確認値を使わず説明する。

## 2. 周波数と同期速度

交流機では、固定子が作る磁界の回転速度を同期速度という。極数を `p`、電源周波数を `f [Hz]` とすると、同期速度 `Ns [min^-1]` は

`Ns = 120f / p`

で求める。

同じ極数なら、同期速度は周波数に比例する。周波数を0.8倍にすれば同期速度も0.8倍、1.2倍にすれば同期速度も1.2倍になる。一方、同じ周波数なら極数が多いほど同期速度は低くなる。

逆算では式を目的量について解く。

`f = pNs / 120`

`p = 120f / Ns`

極数は2、4、6、8極のような偶数になる。計算結果が不自然な極数になった場合は、単位または式変形を確認する。

## 3. 同期角速度への換算

回転速度 `N [min^-1]` を角速度 `ω [rad/s]` へ換算する式は

`ω = 2πN / 60`

である。同期速度を代入すれば

`ωs = 2πNs / 60 = 4πf / p`

となる。

本試験では `min^-1` のまま `P=ωT` に代入しないことが重要である。`P=ωT` で使う角速度の単位は `rad/s` である。

## 4. 回転磁界から移動磁界へ

通常の交流機では、交流電流によって磁界が円周方向に回転する。リニア同期モータでは、この考え方を直線方向へ展開し、磁界の山がガイドウェイに沿って移動する。

周波数は「1秒間に何回電気的な状態を繰り返すか」を表すため、空間配置が同じなら周波数を高くするほどN極・S極の切替が速くなり、移動磁界も速く進む。逆に周波数を下げると移動磁界は遅くなる。

回転機では極数が与えられれば `Ns=120f/p` で同期速度を数値化できる。リニア機で実際の直線速度を周波数から数値化するには、磁極の空間配置に関する寸法が必要である。Topic 23ではL0系の実機極ピッチを一次資料で確認できていないため、500 km/h時の実運転周波数を推定値で置かない。

## 5. V/fをほぼ一定にする理由

交流機の巻線では、電圧、周波数、磁束には概略

`V ∝ fΦ`

の関係がある。巻線条件が同じなら

`Φ ∝ V/f`

と考えられる。このため、周波数だけを下げて電圧をそのままにすると `V/f` が大きくなり、磁束が過大となって磁気飽和を起こしやすい。反対に、周波数だけを上げて電圧を変えなければ `V/f` は小さくなり、磁束は弱くなる。

そこで本試験の基本的な周波数制御では、周波数を変えるとき電圧も同じ比率で変え、`V/f ≈ 一定` とする考え方が用いられる。

例として、50 Hz・200 Vから40 Hzへ変えるなら

`200/50 = 4 V/Hz`

を保つため、電圧は

`V = 4 × 40 = 160 V`

とする。

ここで扱うV/f一定は電験で問われる一般的な交流機制御の原理であり、L0系実機の具体的な制御則をこの式だけで断定するものではない。

## 6. 可変周波数交流を作る電力変換

周波数を自由に変えるには、商用周波数の交流をそのまま負荷へ与えるだけでは足りない。基本的な電力変換の流れは、次のように整理できる。

`交流 → 整流器 → 直流 → インバータ → 可変周波数交流`

整流器は交流を直流へ変換する。インバータは直流を交流へ変換し、スイッチングによって出力周波数と電圧を制御する。PWMは半導体スイッチを高速にオン・オフし、平均的な出力電圧や交流波形を作る方法である。

H20機械問10のような穴埋め問題では、整流器とインバータの役割を逆にしないこと、可変周波数交流を作る側がインバータであることが重要になる。

## 7. 電力・回転速度・トルク

回転機の機械出力は

`P = ωT`

で表される。

- `P`: 機械出力 `[W]`
- `ω`: 角速度 `[rad/s]`
- `T`: トルク `[N·m]`

したがって

`T = P/ω`

である。同じ出力なら回転速度が低いほど必要トルクは大きく、同じトルクなら回転速度が上がるほど機械出力は大きくなる。

三相交流の入力有効電力は、線間電圧 `V`、線電流 `I`、力率 `cosφ` を用いて

`Pin = √3 VI cosφ`

と表す。効率を `η` とし、問題条件で入力から軸出力を求める場合は

`Pout = ηPin`

とする。その後、同期速度から `ω` を求め、`T=Pout/ω` へ進む。

## 8. L0系500km/hへの接続

JR東海の一次資料では、ガイドウェイの推進コイルへ流す電流の周波数を変え、N極・S極の切替速度を変えることで車両速度を調整すると説明されている。

電験の同期速度の考え方と対応させると、要点は「電気側の周波数を変えると、磁界が進む速さが変わる」である。L0系は回転軸を持つ通常の同期電動機とは構造が異なるが、周波数で同期する磁界の速度を決めるという考え方は共通する。

この教材では、一次資料で確認できた「500 km/h走行」と「周波数でN/S切替速度を制御する」までを実車事実として扱う。極ピッチや500 km/h時の具体的周波数は未確認なので実値として扱わない。

## 9. 問題を見たときの解法手順

### 同期速度問題
1. 周波数 `f [Hz]` と極数 `p` を抜き出す。
2. `Ns=120f/p` を使う。
3. 角速度が必要なら `ωs=2πNs/60` へ変換する。
4. 逆算問題なら、求める量について式を先に解く。
5. 周波数と速度の比例関係で桁を検算する。

### V/f問題
1. 変更前後の周波数比を求める。
2. `V/f≈一定` の条件があるか確認する。
3. 電圧も同じ比率で変える。
4. 問題文でトルクと電流の比例関係が与えられている場合だけ、その条件式を使う。
5. 「V/f一定」を実機一般の万能則として拡張しない。

### 電力・トルク問題
1. 入力電力が必要なら `Pin=√3VIcosφ` を計算する。
2. 効率が与えられていれば `Pout=ηPin` とする。
3. `Ns=120f/p` から回転速度を求める。
4. `ω=2πN/60` へ変換する。
5. `T=Pout/ω` を計算し、単位を確認する。

## 10. 3段階例題

### 基礎例題: 周波数から同期速度と同期角速度を求める

6極、50 Hzの同期機の同期速度 `Ns` と同期角速度 `ωs` を求める。

同期速度は

`Ns = 120×50/6 = 1000 min^-1`

角速度へ換算すると

`ωs = 2π×1000/60 ≈ 104.7 rad/s`

答え:
- `Ns = 1000 min^-1`
- `ωs ≈ 104.7 rad/s`

確認点は、`P=ωT` へ使う前に `min^-1` を `rad/s` へ変換することである。

### 本試験標準例題: 三相電力から同期機のトルクを求める

4極、60 Hzの三相同期電動機が、線間電圧400 V、線電流40 A、力率0.80、効率90%で運転している。軸トルクを求める。

まず同期速度を求める。

`Ns = 120×60/4 = 1800 min^-1`

角速度は

`ωs = 2π×1800/60 ≈ 188.5 rad/s`

入力有効電力は

`Pin = √3×400×40×0.80 ≈ 22.17 kW`

軸出力は

`Pout = 0.90×22.17 ≈ 19.95 kW`

したがってトルクは

`T = 19950/188.5 ≈ 105.9 N·m`

答え: 約 `106 N·m`。

ここでは、周波数から同期速度、三相入力から軸出力、最後に `P=ωT` という順に処理する。

### 複合・ひっかけ例題: V/f一定、同期速度、出力を一度に扱う

8極の交流機を50 Hz・200 Vで運転している。V/fを一定に保ったまま40 Hzへ変更する。新しい電圧、同期速度を求める。また、軸トルクを300 N·mに保つと仮定したときの機械出力を求める。

まず変更前のV/fは

`200/50 = 4 V/Hz`

なので、新しい電圧は

`V = 4×40 = 160 V`

同期速度は

`Ns = 120×40/8 = 600 min^-1`

角速度は

`ω = 2π×600/60 = 20π ≈ 62.83 rad/s`

したがって機械出力は

`P = ωT = 62.83×300 ≈ 18.85 kW`

答え:
- 電圧 `160 V`
- 同期速度 `600 min^-1`
- 機械出力 約 `18.8 kW`

ひっかけは、周波数だけを40/50倍にして電圧を200 Vのままにしないこと、また `600 min^-1` をそのまま `P=ωT` に代入しないことである。

なお、R7上機械問4のように問題文の近似条件として `T∝VI/f` が与えられる場合、Vとfを同じ比率で変えて定トルクを保つなら、式の比から電流は変化しない。この比例式は問題条件に従って使い、無条件の一般式として扱わない。

## 11. 頻出ミス・ひっかけ

- `Ns=120f/p` の `p` に極対数を入れない。ここで `p` は極数である。
- `min^-1` と `rad/s` を混同しない。
- 周波数を下げたのに、同期速度を上げない。
- V/f一定条件では、周波数だけでなく電圧も同じ比率で変える。
- 整流器とインバータの変換方向を逆にしない。
- `P=ωT` の `P` が入力電力か軸出力かを問題文から区別する。
- 効率が与えられている場合、入力電力をそのまま軸出力にしない。
- L0系の500 km/hから、未確認の極ピッチを仮定して実運転周波数を真値化しない。

## 13. 公式・解法まとめ

- 同期速度: `Ns=120f/p [min^-1]`
- 周波数逆算: `f=pNs/120 [Hz]`
- 同期角速度: `ωs=2πNs/60=4πf/p [rad/s]`
- V/f制御の基本: `V/f≈一定`
- 三相有効電力: `Pin=√3VIcosφ`
- 効率を含む軸出力: `Pout=ηPin`
- 機械出力: `P=ωT`
- トルク: `T=P/ω`
- 電力変換の基本: `交流 → 整流器 → 直流 → インバータ → 可変周波数交流`

L0系への接続では、「推進コイルへ流す電流の周波数を変えるとN/S切替速度が変わり、車両速度を調整できる」という一次資料確認済みの範囲だけを実車事実として使う。
