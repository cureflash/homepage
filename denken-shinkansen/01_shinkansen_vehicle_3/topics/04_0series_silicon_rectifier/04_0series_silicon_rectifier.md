# 04 0系② シリコン整流器

## この章の目的

0系のシリコン整流器を入口に、電験三種「機械」のパワーエレクトロニクスで要求される**ダイオードの整流作用、単相半波・全波整流、誘導性負荷、環流ダイオード、平滑コンデンサ、平均値と実効値、波形からの回路動作判定**を、初見問題へ転用できる形で学ぶ。

車両史や「交流を直流にする装置」という説明だけでは完成としない。回路図と波形から、どの素子が導通しているか、負荷電圧・電流がどうなるか、平均直流電圧をどう求めるかを自力で判断できることを完成条件とする。

### 過去問から逆算した教材必須範囲

1. ダイオードは「一方向に流す」だけでなく、**回路電圧と負荷状態から導通/遮断を判定する**。
2. 純抵抗負荷とR-L負荷を分ける。インダクタは `v_L=L di/dt` により電流変化を妨げるため、電源電圧の零交差後も電流が続き得る。
3. KVL `v=v_R+v_L` と `v_R=Ri` を波形読解へ使う。
4. 環流ダイオードは誘導性負荷電流の経路を確保し、負荷端子電圧の負側区間を抑え、電流を連続させやすくする。
5. ブリッジ全波整流では正負半周期で異なる対角ダイオードが導通し、負荷電流方向は同じになる。
6. 正弦波 `v=V_m sinωt` では `V_m=√2 V_rms`。理想単相半波・抵抗負荷の平均値は `V_d=V_m/π=√2 V_rms/π`、理想単相全波ブリッジ・抵抗負荷の平均値は `V_d=2V_m/π=2√2 V_rms/π`。
7. 平均値と実効値は別物。直流側で欲しい平均値を交流実効値のまま代用しない。
8. 平滑コンデンサは波高値付近で充電し、電源電圧が低い期間に負荷へ放電するため、直流電圧の脈動（リプル）を小さくする。一方、交流側電流は充電時に集中し非正弦波化しやすい。
9. サイリスタ整流はダイオード整流の「導通開始をゲートで遅らせる」拡張として位置付け、平成24・令和元年度問題を理解できる入口まで扱う。

# 1. このテーマで電験は何を問うか

電験三種では、整流器を単に「AC→DC」と暗記するだけでは足りない。典型的には、

```text
回路図を見る
→ 電源の極性を確認
→ 導通できるダイオードを決める
→ 電流経路を書く
→ R/L/Cが波形へ与える影響を判断
→ 平均値・実効値を区別して計算
```

という順で解く。

# 2. ダイオードの導通条件

理想ダイオードでは、アノード側電位がカソード側より高く、順方向電流が流せる回路条件ならONとみなす。逆方向ならOFFとみなす。

実際のシリコンダイオードには順方向電圧降下があるが、本試験では「電圧降下を無視する」と指定されることが多い。指定を必ず読む。

# 3. 単相半波整流と平均直流電圧

純抵抗負荷・理想ダイオードで、入力を

`v=V_m sinθ`

とする。正半周期だけ負荷へ現れるため、1周期平均は

`V_d=(1/2π)∫_0^π V_m sinθ dθ = V_m/π`

交流実効値 `V` を使えば `V_m=√2V` なので、

`V_d=√2V/π ≈0.450V`

となる。

# 4. 全波ブリッジ整流

ブリッジ回路では、正半周期と負半周期で別の対角ダイオード対が導通し、負荷電流の向きを同じにする。理想・純抵抗負荷なら出力は `|V_m sinθ|` となり、平均値は

`V_d=2V_m/π=2√2V/π≈0.900V`

である。

半波の約2倍になるが、「交流実効値の0.9倍」は理想単相全波・純抵抗・ダイオード降下無視という条件付きである。

# 5. R-L負荷では電流がすぐ止まらない

インダクタでは

`v_L=L di/dt`

である。電流が急に0へ変化しようとすると、それを妨げる向きの電圧が生じる。このため単相半波整流のR-L負荷では、入力電圧が負側へ入ってもダイオード電流が一定期間継続する場合がある。

KVLは

`v=v_R+v_L=Ri+L di/dt`

であり、令和3年度機械問16型では、この関係を電圧波形と電流増減へ結び付ける。

# 6. 環流ダイオード

誘導性負荷へ並列に環流ダイオードを置くと、電源側整流ダイオードがOFFになった後も、負荷のLに蓄えられたエネルギーで電流が環流できる。

解法では「環流ダイオードがあるから平滑になる」と丸暗記せず、**電源→負荷の経路が切れたとき、Lの電流がどの閉回路を通るか**を描く。

# 7. 平滑コンデンサとリプル

ブリッジ整流後にコンデンサを負荷と並列に入れると、整流電圧が高いときに充電し、低いときに負荷へ放電する。結果として出力電圧の谷が持ち上がり、リプルが小さくなる。

一方、電源側から見ると充電は主に波高値付近へ集中するので、入力電流は鋭いパルス状になりやすい。平成25年度機械問9では、この「直流側は電圧源的、交流側電流は非正弦波」という性質が重要になる。

# 8. 平均値と実効値を取り違えない

整流器問題では、
- 入力交流電圧: 実効値で与えられることが多い
- 整流後直流電圧: 平均値を問うことが多い
- 発熱・電力: 実効値が必要になる場合がある

という役割分担がある。

問題文に「平均値」「実効値」のどちらが書かれているかを最初に囲む。

# 9. サイリスタ整流への接続

サイリスタは順方向電圧が加わっただけではONせず、ゲート信号で導通開始を制御できる。ダイオード全波整流を理解したうえで、導通開始を制御遅れ角 `α` だけ遅らせると考えると、平成24年度・令和元年度の回路動作へ接続できる。

本テーマではダイオード整流を主軸とし、サイリスタの詳細な位相制御は `07 200系 サイリスタ制御` で本格的に扱う。

# 10. 問題を見たときの解法手順

```text
1. 素子を確認: ダイオード / サイリスタ / L / C
2. 入力の正負半周期を分ける
3. 各半周期で導通可能な素子を決める
4. 電流ループを描く
5. Lなら電流連続性、Cなら充放電を考える
6. 波形を描く・候補から選ぶ
7. 数値問題なら Vm=√2Vrms を先に処理
8. 半波/全波に対応する平均値式を選ぶ
9. 平均値と実効値を再確認
10. 素子電圧降下無視等の条件を検算
```

# 11. 0系への接続

0系は交流25 kV・60 Hzで受電し、主変圧器で降圧した交流をシリコン整流器で直流へ変換し、直流主電動機へ供給する方式を採用した。ここで重要なのは実車固有の整流器型式を暗記することではなく、

`交流受電 → 変圧 → 整流 → 直流主電動機`

という電力変換鎖を、03で学んだ変圧器と本章の整流回路で説明できることである。

実車の整流素子数、各素子定格、リプル率等について一次資料で確認できない値は推測で真値化しない。

# 12. 頻出ミス

- `V_rms` をそのまま半波/全波の平均値として使う。
- 半波 `V_m/π` と全波 `2V_m/π` を逆にする。
- R-L負荷で電源電圧の零交差と同時に電流が0になると考える。
- 環流ダイオードの電流方向を逆に描く。
- 平滑コンデンサを入れると交流側電流まで正弦波に近づくと思う。
- ブリッジで同じ枝の上下ダイオードを同時導通させる。
- 平均値と実効値を混同する。

# 13. 調査過去問での出題パターン

- R3機械問16: R-L負荷の波形と `Ri`, `Ldi/dt` の関係。
- H26機械問10: 環流ダイオード追加前後の波形・通流期間。
- H25機械問9: コンデンサ平滑と交流側電流波形。
- H24機械問10: 全波整流の平均直流電圧と制御遅れ角。
- R1機械問10: ブリッジ形サイリスタ整流の導通素子と転流。

# 14. 公式・解法まとめ

`V_m=√2V_rms`

理想単相半波・R負荷:
`V_d=V_m/π=√2V_rms/π`

理想単相全波ブリッジ・R負荷:
`V_d=2V_m/π=2√2V_rms/π`

誘導性負荷:
`v=Ri+L di/dt`

コンデンサ:
`i_C=C dv_C/dt`

最重要なのは公式暗記ではなく、**導通素子→電流経路→負荷素子の性質→波形→平均値/実効値**の順で解くことである。
