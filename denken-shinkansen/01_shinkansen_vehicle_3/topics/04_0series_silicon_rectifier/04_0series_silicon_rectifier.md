# 04 0系② シリコン整流器

# 交流で受けて、直流モーターを回す――0系のシリコン整流器から整流回路を理解する

## この章のゴール

0系は架線から交流25 kV・60 Hzを受け、主変圧器で電圧を下げ、その後シリコン整流器で直流へ変換して直流主電動機を駆動する。

この章では、整流器を「ACをDCにする箱」として終わらせない。

**交流電圧の極性が変わる → どのダイオードが順方向になるか決まる → 電流経路が切り替わる → 負荷がRだけかLを含むかで電流波形が変わる → 平均値と実効値の意味が分かれる → 平滑回路では入力電流まで変わる**

という順番で理解する。

最終的には、電験三種「機械」の次の論点を解ける状態を目指す。

- ダイオードの導通判定
- 半波整流・全波整流
- ブリッジ回路の電流経路
- 平均値と実効値
- `Vm=√2 Vrms`
- R-L負荷
- インダクタに蓄えられる磁気エネルギー
- 環流ダイオード
- 平滑コンデンサ
- リプル
- サイリスタ位相制御への接続

# 1. 交流をそのまま直流電動機へ入れられない

交流電圧は周期的に極性が反転する。

もし単純に交流を直流電動機へ加えれば、電機子電流や発生トルクの向きも周期的に変わろうとする。

そこで0系では、主変圧器で降圧した交流を**整流器**へ通し、一方向の電流へ変換して直流主電動機へ送る。

日本車輌製造の0系主要諸元では、主シリコン整流部としてRS200、RS200A、RS201、容量1627 kWが確認できる。

16次車ではシリコン整流器の大容量化によりRS200Aへ変更されたことも一次資料に記録されている。

整流器が0系の主回路で重要だった理由は、単に直流を作るからではない。

**主変圧器で電圧を段階的に変え、その交流を整流して直流主電動機へ送る**という制御系の中央に位置していたからである。

---

# 2. ダイオードは「電圧が正なら必ずON」ではない

理想ダイオードは、

- アノード電位 > カソード電位 → 順方向、ON可能
- アノード電位 < カソード電位 → 逆方向、OFF

と考える。

ただし本試験で重要なのは、素子単体の向きだけではない。

**そのダイオードがONしたとき、本当に電源から負荷を通って戻る閉回路ができるか**まで確認する。

整流回路の基本手順は次である。

1. その瞬間の交流電源の極性を書く。
2. 各ダイオードのアノード・カソード電位を比較する。
3. 順方向になる素子を候補にする。
4. 電源→素子→負荷→素子→電源の閉回路をたどる。
5. 負荷電流の向きを確認する。

この手順ができれば、回路図を暗記しなくても導通素子を判断できる。

---

# 3. 半波整流――まず「片側だけ通す」

交流電圧を

`v = Vm sinθ`

とする。

純抵抗負荷でダイオード1個なら、正半周期だけ電流が流れ、負半周期は0になる。

このとき出力電圧の平均値は、1周期全体で積分して

`Vd = (1/2π) ∫₀^π Vm sinθ dθ`

`= Vm/π`

となる。

入力交流の実効値が `Vrms` なら

`Vm = √2 Vrms`

なので、

`Vd = √2 Vrms/π ≒ 0.450 Vrms`

である。

ここで重要なのは、平均値と実効値を混同しないことである。

平均値は直流成分を表す。

実効値は同じ抵抗に同じ熱を生じさせる直流値である。

整流問題では「何を求める値なのか」を問題文から判断する必要がある。

---

# 4. 全波ブリッジ――負半周期も「ひっくり返して」利用する

ブリッジ整流器では4個のダイオードを使う。

正半周期と負半周期で、対角線上の2個ずつが交互に導通する。

しかし負荷を流れる電流方向は常に同じになる。

つまり交流の負半周期を捨てるのではなく、**負荷から見た極性を反転させて利用する**。

純抵抗負荷なら出力波形は `|sinθ|` となる。

平均値は

`Vd = 2Vm/π ≒ 0.900 Vrms`

である。

この `0.900` は便利だが、使えるのは「理想的な単相全波整流・純抵抗相当」のような条件である。

平滑コンデンサ付き回路や位相制御回路へ無条件に使ってはいけない。

---

# 5. R負荷とR-L負荷は、波形の世界が変わる

純抵抗では

`v = Ri`

なので、電圧と電流は同時に符号が変わる。

しかし電動機やコイルを含む負荷にはインダクタンス `L` がある。

R-L負荷では

`v = Ri + L di/dt`

である。

インダクタには

`W = 1/2 L i²`

の磁気エネルギーが蓄えられる。

したがって電源電圧が0になった瞬間、電流が急に0になることはできない。

電流を減らすには、蓄えた磁気エネルギーをどこかへ放出する時間が必要である。

このためR-L負荷では、交流電源が負側へ入っても電流がしばらく同じ向きに継続することがある。

### ここが本試験の波形問題の核心

電圧が正か負かだけでなく、

- `di/dt > 0` か
- `di/dt < 0` か
- インダクタがエネルギーを蓄えているか
- 放出しているか

を考える。

`vL = L di/dt`

なので、

- 電流増加中 → `vL > 0`
- 電流減少中 → `vL < 0`

である。

---

# 6. 環流ダイオードは「電流の逃げ道」を作る

R-L負荷へ環流ダイオードを付けると、電源からの供給が止まる区間でも、

`L → R → ダイオード → L`

のような閉回路を作って電流を循環させられる。

その結果、

- インダクタ電流が急減しにくい
- 負荷電流の脈動が小さくなる
- 負荷電圧が負側へ大きく振れにくい

という効果がある。

「環流ダイオードは逆電流を止める部品」とだけ覚えるのでは足りない。

**インダクタが持つ電流を継続させるための閉回路を確保する部品**と考える。

---

# 7. 平滑コンデンサは「谷を埋める」が、入力電流を尖らせる

整流波形の後ろへコンデンサ `C` を接続すると、波高値付近で充電され、電源電圧が下がる区間では負荷へ放電する。

そのため出力電圧の谷が持ち上がり、リプルが小さくなる。

しかし代償がある。

コンデンサはいつでも電源から電流を受けるわけではない。

整流電圧がコンデンサ電圧を上回った短い時間だけ充電される。

したがって交流側入力電流は、正弦波ではなく**波高値付近に集中したパルス状**になりやすい。

この点が電験三種の知識問題でよく狙われる。

平滑すると「全部きれいになる」のではない。

直流側電圧は平らになる一方で、交流側電流波形はむしろ歪むことがある。

---

# 8. 直流電動機は「R-L負荷＋逆起電力」を持つ

0系の主電動機は単純抵抗ではない。

直流電動機の電機子回路は概念的に

`Vd = E + IaRa + La dIa/dt`

と考えられる。

- `Vd`: 整流器からの直流電圧
- `E`: 逆起電力
- `Ia`: 電機子電流
- `Ra`: 電機子抵抗
- `La`: 電機子インダクタンス

したがって整流器から見た負荷は、単なるR負荷より電流が連続しやすい。

この考え方を持つと、なぜ電動機負荷の整流回路で「電圧波形」と「電流波形」が同じ形にならないのか理解できる。

---

# 9. 主変圧器と整流器は別々の章だが、実際には一つの系

0系の主回路は、

`交流25 kV`

`↓`

`主変圧器`

`↓ 低圧側タップ切換`

`可変交流電圧`

`↓`

`シリコン整流器`

`↓`

`可変直流電圧`

`↓`

`直流主電動機`

という流れである。

つまり03で学んだ巻数比・タップ切換と、04で学ぶ整流平均値は、実車では連続した一つの制御機構である。

主変圧器が交流電圧の大きさを変え、整流器が極性を一方向へそろえ、その直流電圧が05で扱う直流電動機の速度を決める。

---

# 10. 0系のシリコン整流器が当時重要だった理由

0系以前の交流電車では水銀整流器などの技術も存在したが、0系ではシリコン整流器を採用した。

半導体整流器は機械的接点を使わず、一方向導通という半導体特性で大電力を直流化する。

日本車輌製造の資料では主シリコン整流部容量1627 kW、16次車から大容量化したRS200Aが確認できる。

ここで教材上重要なのは素子型番そのものではない。

**大電力の交流を、主電動機へ供給できる直流へ変換するパワーエレクトロニクス機器だった**という位置付けである。

# 11. 本試験型の考え方

## 11.1 半波純抵抗

`Vrms=100 V`

なら

`Vm=√2×100=141.4 V`

`Vd=Vm/π=45.0 V`

## 11.2 全波純抵抗

同じ100 Vなら

`Vd=2Vm/π=90.0 V`

## 11.3 R-L負荷

電源電圧が0を通過しても、電流がまだ正ならインダクタに蓄積エネルギーが残っている。

その後 `di/dt<0` の区間ではインダクタ電圧は負になる。

波形問題では「電源電圧の符号」だけでなく「電流が増えているか減っているか」を読む。

---

# 12. サイリスタへつながる

ダイオードは順方向電圧が加わると自動的に導通する。

サイリスタは順方向電圧だけでなくゲート信号が必要で、導通開始時刻を遅らせられる。

純抵抗負荷の単相全波サイリスタ整流では、

`Vd = (Vm/π)(1+cosα)`

となる。

`α=0°` ならダイオード全波整流と同じ最大平均電圧、`α` を増やすほど平均電圧は低下し、`α=180°` で0へ近づく。

この考え方が07「200系 サイリスタ制御」へつながる。

---

# 13. 電験での解法アルゴリズム

1. 電源の瞬時極性を決める。
2. 導通可能なダイオード／サイリスタを決める。
3. 閉回路をたどり、負荷電流方向を決める。
4. 負荷がR、R-L、C平滑のどれか確認する。
5. Lがあれば `di/dt` とエネルギーの行先を考える。
6. Cがあれば充電区間と放電区間を考える。
7. 求める量が平均値か実効値か確認する。
8. 制御角があれば導通開始角を反映する。
9. `α=0°`、`α=180°`、L=0などの極限で検算する。

---

# 14. 頻出ミス

- 電源の零交差でR-L負荷電流も0になると考える。
- ダイオードの向きだけ見て閉回路を確認しない。
- ブリッジの対角導通ペアを暗記だけで処理する。
- 平均値と実効値を混同する。
- `Vd=0.900Vrms` を平滑C付き回路へ無条件に使う。
- 平滑コンデンサを付けると交流入力電流も滑らかになると思う。
- 制御角 `α` を増やすと平均電圧が増えると考える。

# 15. 公式まとめ

`v = Vm sinθ`

`Vm = √2 Vrms`

半波純抵抗:

`Vd = Vm/π`

全波純抵抗:

`Vd = 2Vm/π`

R-L負荷:

`v = Ri + L di/dt`

インダクタエネルギー:

`W = 1/2 Li²`

直流電動機負荷の概念式:

`Vd = E + IaRa + La dIa/dt`

純抵抗・単相全波サイリスタ:

`Vd = (Vm/π)(1+cosα)`
