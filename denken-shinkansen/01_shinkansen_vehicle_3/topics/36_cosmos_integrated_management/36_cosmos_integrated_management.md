## §1 このテーマで電験は何を問うか

Topic 36で電験三種に直接接続するのは、COSMOS固有の内部構成ではなく、情報伝送、ネットワーク、コンピュータ構成、データ処理である。本試験では、通信方式の性質、アナログ/ディジタル変換、インタフェース、CPU・記憶装置、配列処理、フローチャート、基数表現、符号付き2進数、D-A変換までが問われる。

この章を終えた時点で、次を自力で処理できることを目標にする。

1. 入力・記憶・処理・出力の役割を区別する。
2. CPUの処理速度とLANの通信速度を別物として判断する。
3. RAM、ROM、DRAM、SRAM、EPROM、EEPROMの基本特性を区別する。
4. 有線/無線、アナログ/ディジタル、光ファイバ、パリティチェックを説明する。
5. A-D変換、D-A変換、インタフェースの向きを判断する。
6. 配列から最大値・平均値を求め、比較・交換で並べ替える。
7. r進数を10進数の式へ展開し、未知の基数を求める。
8. 絶対値表示、2の補数、オフセットバイナリを区別して計算する。

## §2 COSMOSを「統合された情報処理」として捉える

JR東日本の公開資料では、COSMOSは新幹線に関係する業務を7つのサブシステムで統合し、計画・当日実施・実績を一元的に管理するシステムとして説明されている。公開図で確認できる7サブシステムは、輸送計画、運行管理、構内作業管理、保守作業管理、車両管理、電力系統制御、集中情報監視である。

系列SPECの「運行管理」「車両管理」「保守管理」は、この公開名称へ直接接続できる。「設備管理」は教材上の整理語であり、COSMOSにその名称の独立サブシステムがあるとは断定しない。設備に関係する公開範囲は、保守作業管理、電力系統制御、集中情報監視などの公開機能名を越えて説明しない。

電験学習上は、複数の業務で発生する情報を「入力→記憶→処理→出力」という共通構造で捉えるとよい。ただし、COSMOS内部のデータ形式、サーバ構成、データベース構造、通信プロトコル、更新周期、ネットワークトポロジは公開資料から確認できないため、本教材では作らない。

## §3 コンピュータの基本構成とICメモリ

コンピュータのハードウェアは、機能面から入力装置、出力装置、記憶装置、中央処理装置に分けて考える。中央処理装置（CPU）は主に制御機能と演算機能を担う。入力装置は外部の情報をコンピュータ内部で扱える形へ取り込み、出力装置は処理結果を外部へ渡す。記憶装置はデータや命令を保持する。

CPUのクロック周波数は、CPU内部の動作タイミングを示す指標である。LANの通信速度は通信規格・伝送方式・回線条件などで定まり、CPUクロックを上げただけでLANの通信速度そのものが同じ比率で上がるわけではない。磁気ディスクの回転速度もCPUクロックとは別の機器仕様である。

ICメモリは次の基本を押さえる。

- RAM: アドレスを指定して読み書きするメモリ。一般的な主記憶用RAMは電源断で内容を失う揮発性メモリである。
- DRAM: コンデンサの電荷で情報を保持し、保持のためにリフレッシュが必要。大容量化しやすく、主記憶に広く用いられる。
- SRAM: フリップフロップ等で状態を保持し、通電中はDRAMのような周期的リフレッシュを必要としない。高速だが回路規模が大きい。
- ROM: 基本的に読み出しを主目的とし、電源を切っても内容を保持する不揮発性メモリとして扱う。
- EPROM: 書込み後、紫外線照射で内容を消去して再利用できるROM。
- EEPROM: 電気的に消去・再書込みできるROM。読み出しと書込み・消去は別動作であり、「書込み時の印加電圧を読み出し時より低くすればよい」と単純化しない。

電験では、略号だけでなく「揮発性か」「書換え可能か」「どの方法で消去するか」を対応させる。

## §4 情報伝送とネットワークの基本

文字、音声、画像、計測値などの情報は、電気信号や光信号などへ変換して伝送する。

- 有線通信: ケーブルなどを伝送路として使う。
- 無線通信: 空間を伝送路として電波などを使う。
- アナログ信号: 時間や振幅が連続的に変化する信号。
- ディジタル信号: 0/1など離散的な状態として扱う信号。

ディジタル方式は、しきい値判定や再生が可能な範囲では雑音の影響を抑えやすく、コンピュータ処理にも適する。ただし「雑音の影響を全く受けない」という意味ではない。

光ファイバでは、屈折率の異なるコアとクラッドの境界で光を閉じ込めながら伝送する。伝送損失が小さく、電磁誘導による雑音を受けにくいため長距離・高速伝送に適する。電波は周波数・波長によって伝搬性質が変わる。一般に短波長・高周波側ほど直進性・指向性が強くなりやすいため、「低周波で波長が長いほど直進性が強い」と機械的に判断しない。

ネットワークは、複数の装置・計算機を通信で接続し情報をやり取りする仕組みである。LANは限定された範囲内のネットワークを表す。ここでは一般概念までとし、COSMOS内部のLAN構成や通信規格は推測しない。

## §5 パリティチェックによる誤り検出

パリティチェックは、送るデータに検査用の1 bitを付加し、1の個数が偶数または奇数になるようにそろえる誤り検出法である。

偶数パリティなら、データとパリティbitを合わせた1の個数が偶数になるようにする。奇数パリティなら奇数になるようにする。伝送中に1 bitだけ反転すれば1の個数の偶奇が変わるため、受信側で誤りを検出できる。

ただし、単純なパリティだけではすべての複数bit誤りを検出できず、誤り位置の特定・訂正もできない。「誤り検出」と「誤り訂正」を混同しない。

## §6 A-D変換・D-A変換・インタフェース

温度、圧力、位置などを測るセンサは、電圧・電流など時間的に連続するアナログ信号を出すことが多い。一方、コンピュータ内部はディジタル値として処理するため、両者の間に変換が必要になる。

基本の流れは

`センサのアナログ信号 → A-D変換 → ディジタル処理 → D-A変換 → アクチュエータ側のアナログ信号`

である。

- A-D変換器: アナログ信号をディジタル値へ変換する。
- D-A変換器: ディジタル値をアナログ量へ変換する。
- インタフェース: センサ・アクチュエータとコンピュータの間で、信号形式や信号レベルなどを橋渡しする。

インタフェースとネットワークは同じ意味ではない。インタフェースは機器間の接続・信号整合の役割、ネットワークは複数装置間で情報をやり取りする通信の仕組みとして区別する。

## §7 配列から最大値と平均値を求める

`k` 個のデータを配列 `d[1], d[2], ..., d[k]` に格納したとする。最大値 `s` と合計 `t`、平均値 `a` を求める基本手順は次のとおりである。

1. `s ← d[1]`
2. `t ← 0`
3. `i=1` から `k` まで繰り返す。
4. `t ← t + d[i]`
5. `d[i] > s` なら `s ← d[i]`
6. 反復終了後に `a ← t/k`

平均値は

`a = (d[1]+d[2]+...+d[k]) / k = t/k`

である。

最大値の初期値を常に0とするのは安全ではない。負の値を含む配列では、本当の最大値が負なのに0が残ってしまう。最初の要素 `d[1]` を初期値にすれば、配列に実際に存在する値から比較を開始できる。

## §8 比較・交換による降順並べ替え

大きい値を前へ送る単純な比較・交換では、例えば次の処理を使える。

```text
for i = 1 to k-1
  for j = i+1 to k
    if d[i] < d[j]
      w ← d[i]
      d[i] ← d[j]
      d[j] ← w
```

`d[i] < d[j]` のとき、後ろにある大きい値 `d[j]` を前の `d[i]` へ移すので、処理後は大きい順へ近づく。

交換では一時変数 `w` が重要である。先に `d[i] ← d[j]` とすると元の `d[i]` が失われるため、その前に `w ← d[i]` と退避する。代入の順序を変えると正しく交換できない。

## §9 r進数の位取り記数法

基数 `r` の数

`(a_n a_{n-1} ... a_1 a_0)_r`

は、10進数では

`N = a_n r^n + a_{n-1} r^{n-1} + ... + a_1 r + a_0`

と表す。各桁は

`0 <= a_i < r`

を満たす必要がある。

未知の基数 `r` を求める問題では、各r進数をこの式へ展開し、左右を同じ10進数の代数式に直してから `r` を解く。最後に、使われている最大の数字より `r` が大きいかを確認する。例えば桁に5が現れるなら `r>=6` でなければならない。

## §10 符号付き2進数と2の補数

8 bitなど固定長で正負の整数を表す方法は複数あり、方式を混同しないことが重要である。

### 絶対値表示方式

最上位bit（MSB）を符号bitとし、残りのbitで絶対値を表す。通常、MSB=0を正、MSB=1を負と約束する。例えば7 bit分の絶対値が `0001101` なら、負の符号を付けた8 bit絶対値表示は先頭を1にする。

### 2の補数方式

n bitの正数 `x` から `-x` を作る基本手順は

1. `x` をn bitで書く。
2. 全bitを反転する。
3. 1を加える。

である。

n bit 2の補数の表現範囲は

`-2^(n-1) <= x <= 2^(n-1)-1`

である。MSB=1のビット列を符号付き整数として読むとき、ビット列を符号なし整数 `D` として読んだ値から `2^n` を引けばよい。

絶対値表示方式と2の補数方式では、同じ負の10進数でもビット列が異なる。

## §11 オフセットバイナリとD-A変換

オフセットバイナリでは、中央のコードを0に対応させる表現がよく使われる。n bitで中央コードを `D0=2^(n-1)` とし、そのとき出力が0 Vになる線形D-A変換を考える。

問題文から2点 `(D1,V1)`、`(D2,V2)` が与えられた場合は、まず1コード当たりの変化量

`q = (V2-V1)/(D2-D1)`

を求め、

`V = V1 + (D-D1)q`

で任意コード `D` の出力を求める。

中央コード `D0=2^(n-1)` が0 Vで、コード0が `-V_F` と与えられている場合は

`q = V_F / 2^(n-1)`

`V = (D-2^(n-1))q`

と書ける。この式は問題文でその線形対応が与えられた場合に使う。D-A変換器一般に、常に同じ電圧範囲・同じ端点対応になると決めつけない。

## §12 本試験での解法手順

固定5問の範囲では、次の順で処理すると取り違えが減る。

1. 問題が「通信」「コンピュータ構成」「配列処理」「数表現」「A-D/D-A」のどれかを判定する。
2. 用語問題は、対象と役割を分ける。CPU、LAN、記憶装置、インタフェースを一つの性能指標で結ばない。
3. r進数は必ず位取り記数法で10進の代数式へ展開する。
4. 符号付き2進数は、絶対値表示か2の補数か方式を先に確認する。
5. D-A変換は、与えられた2点から1コード当たりの変化量を求める。
6. 配列問題は、初期値、反復範囲、比較条件、代入順序を表へ書く。
7. 並べ替えは一時変数への退避を含め、交換後の配列を逐次更新する。
8. 最後に単位・bit数・配列要素数・降順/昇順を検算する。

## §13 例題1 基礎 — r進数と2の補数

### 問題

次を求めよ。

1. `(31)_r - (12)_r = (15)_r` が成り立つときの基数 `r`。
2. 10進数 `-13` を8 bitで、絶対値表示方式と2の補数方式のそれぞれで表せ。

### 解答

r進数を10進の式へ展開する。

`(31)_r = 3r+1`

`(12)_r = r+2`

`(15)_r = r+5`

したがって

`(3r+1)-(r+2)=r+5`

`2r-1=r+5`

`r=6`

である。最大の数字5を使っているので `r=6` は桁の条件 `0<=a_i<r` も満たす。

次に `13` を8 bitで書くと

`0000 1101`

である。

絶対値表示方式では、7 bitの絶対値 `0001101` の先頭へ負符号1を付けるので

`1000 1101`

となる。

2の補数方式では

`0000 1101`

を反転して

`1111 0010`

さらに1を加えて

`1111 0011`

となる。符号なし整数として243なので、`243-256=-13` と逆確認できる。

## §14 例題2 本試験標準 — 最大値・平均値・降順並べ替え

### 問題

配列

`d=[18,25,11,32,24]`

について、最大値、平均値を求め、§8の比較・交換手順で降順に並べ替えよ。

### 解答

最大値は最初の要素から比較する。

`s=18`

合計は

`t=18+25+11+32+24=110`

したがって

`a=t/5=110/5=22`

最大値は

`s=32`

である。

降順並べ替えは `d[i] < d[j]` のとき交換する。外側反復ごとの配列は次のようになる。

| 外側反復後 | 配列 |
|---|---|
| `i=1` | `[32,18,11,25,24]` |
| `i=2` | `[32,25,11,18,24]` |
| `i=3` | `[32,25,24,11,18]` |
| `i=4` | `[32,25,24,18,11]` |

したがって最終結果は

`[32,25,24,18,11]`

である。

### 検算

- 要素数は5のまま。
- 合計は並べ替え前後とも110。
- 隣り合う要素はすべて左側が右側以上なので降順。

## §15 例題3 複合・ひっかけ — A-D/D-A・パリティ・LAN

### 問題

これはCOSMOS実機仕様ではなく、電験学習用の一般的な計測・通信システムとする。

センサの連続電圧をコンピュータで処理し、処理結果を別のアナログ機器へ出力する。通信データには偶数パリティを付ける。また、8 bitの線形D-A変換器はコード128で0 V、コード0で-4.000 Vを出力する。

1. センサ側と出力側に必要な変換器を答えよ。
2. データ `1011001` に付ける偶数パリティbitを求めよ。
3. D-A入力コード `0110 0000` の出力電圧を求めよ。
4. CPUクロック周波数を2倍にすればLANの通信速度も必ず2倍になる、という記述の正誤を答えよ。

### 解答

センサのアナログ信号をコンピュータへ入れるので、入力側はA-D変換器を使う。コンピュータのディジタル値をアナログ機器へ渡すので、出力側はD-A変換器を使う。両者とコンピュータの橋渡しにはインタフェースが必要になる。

`1011001` に含まれる1は4個で、すでに偶数である。偶数パリティでは全体の1の個数を偶数に保つため、パリティbitは0となる。1 bitだけ反転すれば全体が奇数になり、誤りを検出できる。

`0110 0000` は10進数で96である。1コード当たりの電圧は

`q=(0-(-4.000))/(128-0)=4/128=0.03125 V/code`

したがって

`V=(96-128)×0.03125=-1.000 V`

となる。

CPUクロックとLAN通信速度は別の性能指標なので、「CPUクロックを2倍にすればLANの通信速度も必ず2倍になる」は誤りである。

### ひっかけ

- A-DとD-Aの向きを逆にしない。
- パリティは誤り検出であり、単純なパリティだけで誤り訂正はできない。
- 8 bitだから1コード幅を機械的に電圧範囲/255とせず、問題文で与えられた2点から傾きを求める。
- CPU内部処理とネットワーク伝送を同一速度で考えない。

### 公式・解法まとめ

- 位取り記数法: `N = Σ a_i r^i`, `0<=a_i<r`
- 平均値: `a=t/k`
- n bit 2の補数範囲: `-2^(n-1) <= x <= 2^(n-1)-1`
- 2の補数で負数を作る: bit反転→1加算
- 線形D-A変換: `q=(V2-V1)/(D2-D1)`, `V=V1+(D-D1)q`
- 最大値探索: 実データ `d[1]` を初期値にし、比較のたびに更新
- 降順交換: `d[i]<d[j]` なら一時変数へ退避して交換
- 偶数/奇数パリティ: 1の個数の偶奇を検査bitでそろえて誤りを検出
- 基本データ流れ: `入力→記憶→処理→出力`
- 計測・制御信号: `アナログ→A-D→ディジタル処理→D-A→アナログ`
