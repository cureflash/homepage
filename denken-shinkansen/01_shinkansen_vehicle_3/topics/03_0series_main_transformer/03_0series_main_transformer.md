# 03 0系① 主変圧器

## テーマ
架線から受けた交流25 kVを、0系新幹線の主回路で使える電圧へ変換する主変圧器を題材に、電験三種の変圧器計算を扱う。

  - URL: https://www.n-sharyo.co.jp/museum/tec0/tec0-transition.html

## 教材内計算
### 定格一次電流
S = 1,650 kVA, V1 = 25 kV として、単相相当の見かけ電流は I1 = S/V1 = 1,650,000 / 25,000 = 66.0 A。

### 変圧比と二次電流
低圧側最大電圧2,261 Vを使うと、電圧比は 25,000 / 2,261 = 11.06。理想変圧器では電流比は逆比なので、二次電流は 1,650,000 / 2,261 = 729.8 A。

### 容量と出力の比較
1単位2両の連続定格出力1,480 kWを主変圧器容量1,650 kVAと単純比較すると、1,480 / 1,650 = 0.897 = 89.7%。これは効率ではなく、kWとkVAの見かけ比較である。

### 学習用仮定による効率計算
公開資料から0系主変圧器の鉄損・銅損の個別値は確認できなかった。例題では、鉄損12 kW、全負荷銅損33 kWを学習用仮定値とする。

全負荷・力率1の規約効率: η = 1,650 / (1,650 + 12 + 33) = 97.35%。

0.8負荷・力率0.85の規約効率: 出力 = 1,650×0.8×0.85 = 1,122 kW。銅損 = 33×0.8^2 = 21.12 kW。η = 1,122 / (1,122 + 12 + 21.12) = 97.13%。

### 電圧変動率の例
%抵抗降下2.0%、%リアクタンス降下3.0%、力率0.85遅れの仮定例では、ε ≒ p cosθ + q sinθ = 2.0×0.85 + 3.0×sqrt(1-0.85^2) = 3.28%。

## 非公開値の扱い
0系主変圧器の鉄損、銅損、巻数、正確な巻線構成、タップ各段の電圧は今回確認できなかった。鉄損・銅損・電圧変動率は電験三種の計算練習用仮定値として扱い、実機真値として扱わない。
