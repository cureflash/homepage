# 03 0系① 主変圧器

# 25 kVをそのままモーターへ入れない――0系の主変圧器から変圧器を理解する

## この章のゴール

0系は架線から交流25 kV・60 Hzを受ける。しかし直流主電動機へ25 kVをそのまま加えるわけではない。

0系の2両ユニットでは、偶数車にパンタグラフ・主変圧器・主シリコン整流器を持ち、主変圧器の低圧側タップを切り替えながら、主電動機へ送る電圧を段階的に変えていた。

この章では、主変圧器を「電圧を下げる箱」として暗記しない。

**一次巻線へ交流電圧を加える → 鉄心磁束ができる → 二次巻線へ起電力が生じる → 負荷をつなぐと二次電流が流れる → 一次電流も増える → 巻線抵抗と漏れ磁束で電圧が下がる → 鉄損と銅損が発生する**

という一連の現象として理解する。

最終的には、電験三種「機械」で問われる次の問題へ対応する。

- 巻数比・電圧比・電流比
- 一次側／二次側への換算
- インピーダンス・アドミタンス換算
- 簡易等価回路
- 無負荷試験・短絡試験
- 鉄損・銅損
- 規約効率・最大効率
- 電圧変動率
- 三相Y/Δ結線
- タップ切換の意味

# 1. 変圧器の本質は「交流磁束を共有する二つの巻線」

変圧器は、一次巻線と二次巻線が電気的に直接つながっていない。

両者を結び付けているのは鉄心中の**時間変化する磁束**である。

一次巻線へ交流電圧を加えると、鉄心に交番磁束 `Φ` が生じる。

ファラデーの電磁誘導則から、巻数 `N` の巻線に生じる瞬時起電力は

`e = -N dΦ/dt`

である。

磁束を正弦波とすれば、実効値としてよく使う式

`E = 4.44 f N Φm`

が得られる。

ここで、

- `E [V]`: 巻線起電力
- `f [Hz]`: 周波数
- `N`: 巻数
- `Φm [Wb]`: 最大磁束

である。

この式は非常に重要である。

電圧だけでなく、**周波数が下がると同じ電圧でも磁束が増える**ことが分かるからだ。

`Φm = E/(4.44 f N)`

したがって、定格60 Hz用の変圧器へ同じ電圧のまま低い周波数を加えると、鉄心磁束が過大になり、磁気飽和や励磁電流増大へつながる。

0系が東海道・山陽新幹線の交流60 Hz・25 kV系で設計されているという事実は、単なる周波数表記ではなく、変圧器の磁束設計そのものに関係する。

# 2. なぜ巻数比で電圧が変わるのか

一次巻線と二次巻線は同じ鉄心磁束を共有する。

したがって、

`E1 = 4.44 f N1 Φm`

`E2 = 4.44 f N2 Φm`

である。

両式を割れば、

`E1/E2 = N1/N2`

となる。

巻数比を

`a = N1/N2`

と定義すると、理想変圧器では

`V1/V2 ≒ E1/E2 = a`

である。

ここで大事なのは「電圧を勝手に小さくしている」のではないことである。

**同じ磁束変化を、異なる巻数で受けるから、1巻線全体の誘導起電力が違う。**

これが変圧の物理的な意味である。

---

# 3. 電圧を下げると、なぜ電流は増えるのか

理想変圧器では損失がないので、入力と出力の皮相電力は等しい。

`V1 I1 = V2 I2`

したがって、

`I1/I2 = V2/V1 = 1/a`

となる。

つまり降圧変圧器では、

- 二次電圧は低くなる
- 二次電流は大きくなる

という関係になる。

0系の主変圧器容量は1650 kVAである。単純な容量計算として一次側25 kVなら、

`I1 ≒ 1650 kVA / 25 kV = 66 A`

となる。

一方、公開資料に示される低圧側最大電圧2261 Vを学習用代表値として使うと、

`I2 ≒ 1650 kVA / 2.261 kV = 730 A`

程度になる。

これは実際の内部結線やタップ運転を単純化した**容量からの計算値**だが、「高電圧・小電流から低電圧・大電流へ変換する」という主変圧器の役割をよく表している。

---

# 4. 負荷をつなぐと、一次電流が勝手に増えるのはなぜか

ここは変圧器で最も理解しておきたいところである。

二次側を開放している無負荷状態でも、一次巻線には鉄心磁束を作るための小さな励磁電流が流れる。

そこへ二次負荷を接続すると、二次電流 `I2` が流れる。

二次電流が作る磁束は、レンツの法則により元の主磁束変化を打ち消す向きに働く。

しかし一次電圧と周波数が一定なら、主磁束はほぼ一定に保たれなければならない。

そこで一次側から追加の電流が流れ、二次電流の作る起磁力を打ち消す。

理想的には

`N1 I1 ≒ N2 I2`

である。

つまり変圧器は、負荷が増えると**一次側から必要な電力を自動的に吸い込む**。

これは「二次側の電流が一次側へ伝わる」のではない。

磁束をほぼ一定に保つために、一次電流が電磁誘導の結果として増えるのである。

---

# 5. 実際の変圧器は理想ではない

実機には主に四つの非理想要素がある。

## 5.1 巻線抵抗

銅線には抵抗があるため、

`Pcu = I²R`

の銅損が生じる。

負荷電流が2倍になると銅損は4倍になる。

したがって負荷率 `x` のとき、全負荷銅損を `Pc` とすれば

`Pcu = x² Pc`

である。

## 5.2 漏れ磁束

一次・二次すべてと鎖交しない磁束がある。

これを回路上では漏れリアクタンス `X` として表す。

負荷電流が流れると `jXI` の電圧降下が生じる。

## 5.3 鉄損

鉄心にはヒステリシス損と渦電流損が生じる。

電圧・周波数一定なら、試験計算では鉄損をほぼ一定とみなすことが多い。

## 5.4 励磁電流

主磁束を作るための電流と鉄損に相当する電流が必要である。

簡易等価回路では並列励磁枝として表す。

---

# 6. なぜ「一次側へ換算」するのか

実際の変圧器には一次側と二次側に別々の抵抗・リアクタンスがある。

そのままでは巻数比をまたいで計算しにくい。

そこで二次側の量を一次側へ仮想的に移す。

二次量を一次側へ換算すると、

`V2' = a V2`

`I2' = I2/a`

`Z2' = a² Z2`

となる。

なぜインピーダンスだけ二乗なのか。

`Z = V/I`

だから、

`Z2' = V2'/I2' = (aV2)/(I2/a) = a²(V2/I2)`

となるからである。

アドミタンス `Y=1/Z` は逆数なので、

`Y2' = Y2/a²`

である。

倍率を暗記するより、`V/I=Z` でその場で復元できる方が本試験に強い。

---

# 7. 無負荷試験と短絡試験は「損失を分離する実験」

変圧器の内部抵抗や鉄損を直接測りにくいので、運転状態を極端にして別々に取り出す。

## 7.1 無負荷試験

二次側を開放し、一次側へ定格電圧を加える。

負荷電流がないため銅損は小さい。

したがって入力電力はほぼ鉄損とみなせる。

`P0 ≒ Pi`

## 7.2 短絡試験

二次側を短絡し、一次側に低い電圧を加えて定格電流を流す。

印加電圧が低いため主磁束が小さく、鉄損を小さいとみなせる。

入力電力はほぼ銅損である。

さらに、

`Zeq = Vsc/Isc`

`Req = Psc/Isc²`

`Xeq = √(Zeq²-Req²)`

から等価直列インピーダンスを求められる。

### 本試験型例

`Vsc=80 V, Isc=40 A, Psc=1200 W`

なら、

`Zeq=80/40=2.00 Ω`

`Req=1200/40²=0.75 Ω`

`Xeq=√(2.00²-0.75²)=1.85 Ω`

となる。

---

# 8. 効率は「鉄損一定、銅損は電流二乗」が核心

負荷率を `x`、定格容量を `S`、力率を `cosφ` とすると、

`Pout = x S cosφ`

である。

鉄損 `Pi` はほぼ一定、全負荷銅損を `Pc` とすると負荷時銅損は `x²Pc`。

したがって規約効率は

`η = Pout / (Pout + Pi + x²Pc)`

である。

最大効率になる条件は、

`Pi = x² Pc`

である。

これは「固定損である鉄損」と「負荷とともに増える銅損」が釣り合う点である。

公式だけでなくこの意味を覚えると、最大効率問題を復元しやすい。

---

# 9. なぜ負荷をつなぐと二次電圧が下がるのか

負荷電流が流れると、巻線抵抗と漏れリアクタンスに電圧降下が生じる。

単純な抵抗だけなら `IR` だが、交流ではリアクタンス降下 `jIX` が90度ずれて加わる。

そのため本来はフェーザで考える。

近似的な百分率電圧変動率は、百分率抵抗降下を `p`、百分率リアクタンス降下を `q` とすると、遅れ力率負荷で

`ε ≒ p cosφ + q sinφ`

進み力率負荷で

`ε ≒ p cosφ - q sinφ`

となる。

進み負荷ではリアクタンス成分が逆向きに働くため、場合によっては負荷をつないだ方が端子電圧が上昇することもある。

この符号の理由まで理解しておく。

# 10. 0系では「変圧器そのものが速度制御の一部」だった

日本車輌製造の0系主要諸元では、

- 電気方式: 交流60 Hz 25 kV
- 2両ユニット全電動方式
- 主変圧器: TM200 / TM201 / TM201A
- 容量: 1650 kVA
- 主シリコン整流部: RS200 / RS200A / RS201
- 主シリコン整流部容量: 1627 kW
- 制御方式: 低圧タップ切換
- タップ制御段数: 25

が確認できる。

つまり0系では、主変圧器は単に25 kVを一度だけ降圧する装置ではなかった。

**低圧側タップを段階的に切り替え、整流器へ送る交流電圧そのものを変えることで、整流後の直流電圧を変え、主電動機を制御した。**

この話は05「0系③ 速度制御」へ直接つながる。

変圧器の巻数比の式が、そのまま列車の速度制御機構の一部になっているのである。

# 11. 0系を題材にした計算

主変圧器容量1650 kVA、架線25 kVから、単純な単相容量換算として

`I1 = 1650 kVA / 25 kV = 66.0 A`

公開資料に示される低圧側最大2261 Vを代表値として、

`a = 25000/2261 = 11.06`

`I2 = 1650 kVA / 2.261 kV ≒ 730 A`

となる。

ここで注意する。

- 66.0 A、11.06、730 Aは公開仕様からの**計算値**
- 実際の運転ではタップ位置が変化する
- 巻線損失、励磁電流、整流器、主電動機負荷がある
- 低圧側最大電圧を常時使用しているわけではない

したがって実機電流を断定する値ではない。

# 12. 電験での解法アルゴリズム

1. 巻数比 `a` の定義方向を確認する。
2. 単相か三相か、Y/Δかを確認する。
3. 線間値と相値を分離する。
4. すべての量を一次側または二次側へ換算する。
5. 理想変圧器問題か、等価回路問題か判定する。
6. 無負荷試験なら鉄損、短絡試験なら銅損・直列インピーダンスを考える。
7. 負荷率問題では銅損が `x²` で変化することを確認する。
8. 力率を含む電圧降下はフェーザを意識する。
9. 単位と倍率を検算する。

---

# 13. 頻出ミス

- 巻数比の向きを確認せず逆数を使う。
- 電圧比と電流比を同方向にする。
- インピーダンス換算の `a²` を忘れる。
- アドミタンスまで `a²` 倍にする。
- 銅損を負荷率 `x` に比例させる。正しくは `x²`。
- 無負荷試験と短絡試験の目的を逆にする。
- `Psc/Isc` を抵抗とする。正しくは `Psc/Isc²`。
- Y/Δで線間値と相値を混同する。
- 電圧変動率をスカラーの `IR+IX` として扱う。

# 15. この章を終えたら説明できるべきこと

「変圧器は巻数比で電圧を変える」だけでは不十分である。

次を言葉と式で説明できれば、本試験へつながる。

- なぜ二次負荷が増えると一次電流も増えるのか
- なぜ降圧すると電流を大きく取り出せるのか
- なぜインピーダンス換算は巻数比の二乗なのか
- なぜ銅損は負荷率の二乗で変わるのか
- なぜ無負荷試験で鉄損、短絡試験で銅損を分離できるのか
- なぜ遅れ力率と進み力率で電圧変動率の符号が変わるのか
- なぜ0系では主変圧器のタップ切換が速度制御に使えたのか
