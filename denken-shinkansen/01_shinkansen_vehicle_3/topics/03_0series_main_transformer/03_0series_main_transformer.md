# 03 0系① 主変圧器

## この章の目的
この章は0系の車両史を覚える章ではない。電験三種「機械」で問われる変圧器の巻数比・電圧比・電流比、一次/二次換算、簡易等価回路、無負荷試験・短絡試験、鉄損・銅損、規約効率、最大効率、電圧変動率を、0系主変圧器を具体例として初見問題に転用できる形で学ぶ。

# 1. 電験で何を問うか
変圧器問題は「理想変圧器の比」だけで終わらない。巻数比から電圧・電流・インピーダンスを換算し、等価回路へ落とし、損失・効率・電圧降下を計算する流れが本試験の中心である。

# 2. 用語と理想変圧器
巻数比 a=N1/N2 とする。理想変圧器では E1/E2=V1/V2=N1/N2=a、I1/I2=1/a。見かけ電力は V1I1=V2I2。実機では励磁電流、巻線抵抗、漏れリアクタンス、鉄損が存在する。

# 3. 三相結線で線間値と相値を分ける
Y結線: V_L=sqrt(3)V_phase, I_L=I_phase。Δ結線: V_L=V_phase, I_L=sqrt(3)I_phase。三相電力は S=sqrt(3)V_L I_L。巻数比は各単相変圧器の相電圧比で考える。

# 4. 一次側/二次側換算
二次量を一次側へ換算: V2'=aV2, I2'=I2/a, Z2'=a^2 Z2, Y2'=Y2/a^2。一次量を二次側へ換算: V1''=V1/a, I1''=aI1, Z1''=Z1/a^2, Y1''=a^2Y1。
倍率を丸暗記せず、V/I=Zで整合するか検算する。

# 5. 無負荷試験と短絡試験
無負荷試験は定格電圧を加え、入力電力からほぼ鉄損を求める。短絡試験は二次短絡で定格電流を流し、低電圧なので鉄損を無視して銅損と等価直列インピーダンスを求める。
短絡試験: Z_eq=Vsc/Isc, R_eq=Psc/Isc^2, X_eq=sqrt(Z_eq^2-R_eq^2)。

# 6. 損失・規約効率・最大効率
鉄損 Pi は電圧・周波数一定ならほぼ一定。全負荷銅損 Pc は電流二乗に比例し、負荷率xでは x^2 Pc。出力 Pout=x S cosφ。規約効率 η=Pout/(Pout+Pi+x^2Pc)。最大効率条件は Pi=x^2Pc。
銅巻線抵抗の温度補正は R_T/R_t=(235+T)/(235+t)。

# 7. 電圧変動率
簡易式では、百分率抵抗降下p、百分率リアクタンス降下q、力率cosφに対して遅れ負荷: ε≈p cosφ+q sinφ、進み負荷: ε≈p cosφ-q sinφ。符号が変わる理由はリアクタンス降下の位相関係にある。

# 8. 解法アルゴリズム
1. 単相/三相、Y/Δ、線間/相を判定。
2. 巻数比aの定義方向を確認。
3. 一つの側へ換算して等価回路を作る。
4. 試験条件なら無負荷/短絡の近似を選ぶ。
5. 損失は鉄損一定、銅損x^2を確認。
6. 力率問題はフェーザまたは電圧変動率近似を使う。
7. 単位・倍率・物理的妥当性を検算。

# 9. 例題
基礎: a=10, V1=6600VならV2=660V。理想でI2=100AならI1=10A。
標準: 短絡試験Vsc=80V,I=40A,P=1200W。Z=2Ω,R=0.75Ω,X=sqrt(4-0.5625)=1.85Ω。
複合: 10kVA、全負荷銅損と鉄損比2:1、全負荷力率1でη=97%。全損失=10000(1/0.97-1)=309.3W、Pc=206.2W, Pi=103.1W。最大効率負荷率 x=sqrt(Pi/Pc)=1/sqrt(2)=0.707。

# 10. 0系新幹線への接続
日本車輌製造の0系主要諸元では電気方式は交流60Hz 25kV、主変圧器TM200/TM201/TM201A、容量1650kVA。公開資料に示される低圧側最大電圧2261Vを学習上の代表値として用いると、電圧比25,000/2,261=11.06、容量から単相相当一次電流66.0A、二次側相当729.8Aとなる。これは理想比の理解用計算であり、実機のタップ構成・損失を単純化している。

- 日本車輌製造 0系変遷 https://www.n-sharyo.co.jp/museum/tec0/tec0-transition.html

# 11. 頻出ミス
- 巻数比aの向きを確認せず逆数を使う。
- 電流比までa倍とする。
- インピーダンス換算のa^2を忘れる。
- アドミタンスもインピーダンスと同じ倍率にする。
- 銅損を負荷率xに比例させる（正しくはx^2）。
- 遅れ/進みでリアクタンス降下の符号を取り違える。
- 三相Y/Δで線間値と相値を混同する。
