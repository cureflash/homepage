# 1. 変圧器の本質

一次巻線と二次巻線は電気的に直接接続されず、鉄心中の時間変化する磁束を共有する。ファラデーの法則は

`e = -N dΦ/dt`

正弦波磁束では実効値として

`E = 4.44 f N Φm`

となる。したがって同じ電圧でも周波数が下がると磁束が増え、磁気飽和や励磁電流増大につながる。

# 2. 巻数比・電圧比・電流比

`a=N1/N2`

理想変圧器では

`V1/V2 ≒ a`

`I1/I2 = 1/a`

となる。降圧すれば電圧は下がるが、同じ容量を伝えるなら二次電流は大きくなる。電圧比と電流比の向きを混同しない。

# 3. 負荷をつなぐと一次電流が増える理由

二次電流の起磁力はレンツの法則により主磁束変化を打ち消す向きに働く。一次電圧・周波数が一定なら主磁束はほぼ一定に保たれるため、一次側から追加電流が流れる。理想化すれば

`N1 I1 ≒ N2 I2`

である。

# 4. 一次・二次換算

二次量を一次側へ換算すると

`V2' = a V2`

`I2' = I2/a`

`Z2' = a² Z2`

`Y2' = Y2/a²`

となる。インピーダンスの二乗倍率は `Z=V/I` から復元できる。アドミタンスは逆数なので倍率も逆になる。

# 5. 等価回路と損失

巻線抵抗による銅損は

`Pcu=I²R`

であり、負荷率xなら

`Pcu=x²Pc`

となる。漏れ磁束は漏れリアクタンスとして扱い、鉄損はヒステリシス損と渦電流損をまとめて、電圧・周波数一定の試験問題ではほぼ一定とみなすことが多い。

# 6. 無負荷試験・短絡試験

無負荷試験では二次を開放し定格電圧を加える。負荷電流が小さいため銅損は小さく、入力電力はほぼ鉄損。

`P0 ≒ Pi`

短絡試験では二次を短絡し、低電圧で定格電流を流す。鉄心磁束が小さいため鉄損を小さいとみなし、入力電力をほぼ銅損とする。

`Zeq=Vsc/Isc`

`Req=Psc/Isc²`

`Xeq=√(Zeq²-Req²)`

例: `Vsc=80 V, Isc=40 A, Psc=1200 W` なら `Zeq=2.00 Ω`, `Req=0.75 Ω`, `Xeq=1.85 Ω`。

# 7. 規約効率・最大効率

負荷率x、定格容量S、力率cosφなら

`Pout=xS cosφ`

`η=Pout/(Pout+Pi+x²Pc)`

最大効率条件は

`Pi=x²Pc`

である。鉄損はほぼ固定、銅損は電流二乗で増えるという物理的意味から復元する。

# 8. 電圧変動率

抵抗降下とリアクタンス降下は位相が異なる。百分率抵抗降下p、百分率リアクタンス降下qなら、遅れ力率で

`ε ≒ p cosφ + q sinφ`

進み力率で

`ε ≒ p cosφ - q sinφ`

となる。`IR+IX`を単純なスカラー和にしない。

# 9. 三相Y/Δ

三相ではまず線間値と相値を分ける。

Y結線: `VL=√3 Vφ`, `IL=Iφ`

Δ結線: `VL=Vφ`, `IL=√3 Iφ`

三相電力は

`P=√3 VL IL cosφ`

である。巻数比は各巻線の相電圧同士で比較する。

# 10. 本試験の解法アルゴリズム

1. 巻数比aの定義方向を確認する。  
2. 単相か三相か、Y/Δかを確認する。  
3. 線間値と相値を分離する。  
4. すべての量を一次側または二次側へ換算する。  
5. 理想変圧器か等価回路問題か判定する。  
6. 無負荷試験なら鉄損、短絡試験なら銅損・直列インピーダンスを考える。  
7. 負荷率問題では銅損がx²で変化する。  
8. 力率を含む電圧降下はフェーザで扱う。  
9. 単位、倍率、選択肢を検算する。

# 11. 0系への接続

日本車輌製造の0系資料で、電気方式は交流60 Hz 25 kV、主変圧器容量1650 kVA、制御方式は低圧タップ切換、タップ制御段数25段と確認できる。

主変圧器容量1650 kVA、架線25 kVから単純容量換算すると

`I1=1650 kVA/25 kV=66.0 A`

低圧側最大2261 Vを代表値にすると

`a=25000/2261=11.06`

`I2=1650 kVA/2.261 kV≈730 A`

である。66 A、11.06、730 Aは公開仕様からの計算値であり、実運転電流の断定ではない。実際にはタップ位置、損失、励磁電流、整流器・主電動機負荷が影響する。

0系では低圧側タップを段階的に切り替え、整流器へ送る交流電圧を変えることで整流後の直流電圧を変えた。巻数比の概念がそのまま速度制御へ接続する。

# 12. 頻出ミス

- 巻数比の向きを確認せず逆数を使う。
- 電圧比と電流比を同方向にする。
- インピーダンス換算のa²を忘れる。
- アドミタンスをインピーダンスと同倍率にする。
- 銅損を負荷率xに比例させる。
- 無負荷試験と短絡試験の目的を逆にする。
- `Psc/Isc`を抵抗とする。
- Y/Δで線間値と相値を混同する。
- 電圧変動率をスカラーの`IR+IX`として扱う。
