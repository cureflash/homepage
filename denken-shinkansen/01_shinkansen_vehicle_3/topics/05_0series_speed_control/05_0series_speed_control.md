# 05 0系③ 速度制御

## この章の目的

この章の主目的は0系の制御器やタップ切換装置の歴史紹介ではない。

電験三種「機械」で問われる直流電動機の端子電圧、逆起電力、電機子電流、磁束、トルク、回転速度、始動、速度制御を一つの系として理解し、初見の過去問・典型問題を自力で解けるようにすることを目的とする。

0系は「交流受電→変圧→整流→直流主電動機」という実例として使い、速度制御そのものは一般化した直流電動機の理論として学ぶ。

# 過去問から逆算した必須説明

## 1. 直流電動機の基本式

電機子回路:

```text
V = E + I_a R_a
E = V - I_a R_a
```

逆起電力:

```text
E = K_e φ n
n = E/(K_e φ)
```

したがって速度式は、比例関係として

```text
n ∝ (V-I_aR_a)/φ
```

トルク:

```text
T = K_t φ I_a
```

この3式を別々に暗記せず、問題文の条件に応じて連結する。

## 2. 負荷条件の読み方

定トルク負荷かつ磁束一定なら、`T∝φI_a` より電機子電流 `I_a` も一定と判断できる。

この条件があると、端子電圧変更前後で `I_aR_a` を同じ値として逆起電力を比較できる。

一方、負荷条件が変わる問題では `I_a` を勝手に一定と置かない。

## 3. 電圧制御法

磁束と負荷条件を一定に保ち、端子電圧を変える。

```text
n ∝ (V-I_aR_a)/φ
```

なので、電圧を下げれば一般に回転速度は低下する。

重要なのは、速度が端子電圧 `V` そのものではなく、逆起電力 `E=V-I_aR_a` に比例する点である。

## 4. 抵抗制御法

電機子回路へ直列抵抗を追加し、電圧降下を増やして電動機内部の逆起電力を下げる。

概念的には

```text
E = V - I_a(R_a+R_s)
```

となる。

抵抗で電力損失が発生するため効率面で不利であり、負荷電流によって速度が変動しやすい。

## 5. 界磁制御法

端子電圧・電機子条件が同程度なら、

```text
n ∝ 1/φ
```

なので界磁磁束を弱めると速度は上昇する。

ただしトルクは

```text
T ∝ φI_a
```

なので、同じ電機子電流で磁束を弱めれば発生トルクは低下する。

## 6. 始動

停止時は `n=0` なので逆起電力 `E≈0` である。

したがって始動時の電機子電流は

```text
I_a ≈ V/R_a
```

となり、通常の運転時より非常に大きくなり得る。始動抵抗は電機子回路に直列に入れ、始動電流を制限する。

## 7. 0系への接続

0系では交流受電を主変圧器で変圧し、シリコン整流器で直流化して直流主電動機を駆動する。

本テーマではタップ制御を、主電動機へ供給する電圧を段階的に変える実例として扱う。

実車のタップ段数、各段の内部電圧、主電動機の電機子抵抗等は、一次資料で確認できた値だけを実値とする。確認できない数値は真値化しない。

# 本テーマで必要な解法アルゴリズム

```text
1. 電動機の種類を確認する
   分巻 / 他励 / 永久磁石界磁 / 直巻

2. 問題文の負荷条件を確認する
   定トルクか、電機子電流一定指定か、磁束一定指定か

3. トルク式 T∝φI_a から I_a・φの変化を判定する

4. 逆起電力 E=V-I_aR_a を求める

5. 速度式 n∝E/φ で前後比を取る

6. 速度制御法を問う問題では
   Vを変える→電圧制御
   電機子直列抵抗を変える→抵抗制御
   φを変える→界磁制御
   と対応させる

7. 単位、速度の増減方向、トルク条件で検算する
```
