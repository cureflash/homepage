# 1. このテーマで電験は何を問うか
名称暗記ではなく、問題文の負荷条件から`Ia`と`φ`の変化を判定し、`E=V-IaRa`、`n∝E/φ`へ接続して速度を求める。知識問題では始動抵抗と三つの速度制御法、逆転、回生制動まで問われる。

# 2. 用語・物理的意味・単位
- `V [V]`: 電機子端子電圧
- `E [V]`: 逆起電力。回転により発生し電源電圧に逆らう。
- `Ia [A]`: 電機子電流
- `Ra [Ω]`: 電機子抵抗
- `φ [Wb]`: 一極あたり磁束
- `n [min^-1]`: 回転速度
- `T [N·m]`: 電磁トルク

# 3. 公式と成立条件
`V=E+IaRa`, `E=Keφn`, `T=KtφIa`。
したがって `n∝(V-IaRa)/φ`。ブラシ降下等を無視する条件ではこの形を直接使える。定トルクかつ磁束一定なら`T∝φIa`から`Ia`一定。

# 4. 問題文から式を選ぶ解法手順
1. 分巻/他励/永久磁石/直巻を確認。
2. 定トルク、磁束一定、電流一定などを確認。
3. `T∝φIa`から`Ia`・`φ`の変化を判定。
4. 前後の`E=V-IaRa`を求める。
5. `n2/n1=(E2/φ2)/(E1/φ1)`で速度を求める。
6. 増減方向、単位、選択肢で検算する。

# 5. 例題
基礎: `Ra=0.20Ω, Ia=50A, V=110V`なら`E=100V`。
本試験標準: 同条件で`n1=1200min^-1`、Vを80Vにすると`E2=70V`、磁束一定なので`n2=840min^-1`。
複合: 永久磁石界磁、`Ra=1Ω, V1=120V, Ia=20A, n1=1000min^-1`、定トルクで`V2=100V`ならIa一定、`E1=100V, E2=80V`、よって`n2=800min^-1`。

# 6. 電圧制御法
Vを変える。磁束・負荷条件一定ならV低下→E低下→速度低下。速度はVではなく`E=V-IaRa`に比例する。

# 7. 抵抗制御法・界磁制御法
抵抗制御は電機子直列抵抗`Rs`を変え`E=V-Ia(Ra+Rs)`を調整する。抵抗損失が生じ効率が悪い。
界磁制御は`φ`を変える。界磁を弱めれば`n∝1/φ`で速度上昇するが、同じIaでは`T∝φIa`によりトルク低下。

# 8. 始動・逆転・回生
停止時は`n=0→E≈0`なので`Ia≈V/Ra`となり過大電流になりやすい。始動抵抗は電機子回路へ直列に入れる。逆転は電機子または界磁の片方を反転し、一般には応答の速い電機子側を反転する。回生制動は電動機を発電機として運転し電源へエネルギーを返す。

# 9. 0系新幹線への接続
0系は交流25kV受電→主変圧器→シリコン整流器→直流主電動機という系統を持つ。本章ではタップ制御を「主電動機へ供給する電圧を段階的に変える実例」として扱う。タップ段数、内部電圧、電機子抵抗など一次資料で未確認の値は真値化しない。

# 10. 頻出ミス
- `V2/V1`を速度比にする。
- 定トルク・磁束一定からIa一定を導かない。
- 界磁弱めで速度上昇する方向を逆にする。
- 始動抵抗を界磁回路へ入れる。
- 未飽和直巻で`φ∝Ia`なのに`T∝Ia`とする。正しくは`T∝Ia^2`。

# 11. 調査過去問での出題パターン
R6上は電圧変更計算、R4上は始動/制御/逆転/回生の知識、R1とH28は定トルクからIa一定を導く速度計算、H25は直流機特性の正誤判定。

# 12. 公式・解法まとめ
`V=E+IaRa`, `E=Keφn`, `T=KtφIa`, `n∝(V-IaRa)/φ`。
解法は「電動機種類→負荷条件→Ia/φ判定→E→n」。
