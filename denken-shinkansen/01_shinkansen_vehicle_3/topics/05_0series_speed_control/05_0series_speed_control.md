# 05 0系③ 速度制御

# 0系はどうやって速度を変えたのか――タップ制御から直流電動機の速度式を理解する

## この章のゴール

0系の速度制御を「タップを切り替えた」で終わらせない。

この章では、

**主変圧器の低圧側タップを切り替える → 整流器へ送る交流電圧が変わる → 整流後の直流電圧が変わる → 電機子電流が変わる → トルクが変わる → 加速する → 回転速度が上がる → 逆起電力が増える → 電流が再び落ち着く**

という一連の現象を追う。

最終的には電験三種「機械」の次を自力で解ける状態を目指す。

- `V = E + IaRa`
- `E = Ke φ n`
- `T = Kt φ Ia`
- 電圧変更後の回転速度
- 定トルク時の電機子電流
- 始動電流
- 抵抗制御・電圧制御・界磁制御
- 分巻・他励・永久磁石・直巻電動機の特性
- 直並列制御・タップ制御の考え方
- 弱め界磁
- 逆転・回生制動への接続

# 1. 速度制御の前に「モーターは勝手に電流を調整する」と理解する

直流電動機の電機子回路は、ブラシ降下などを無視すれば

`V = E + IaRa`

である。

つまり

`Ia = (V-E)/Ra`

である。

一方、逆起電力は

`E = Ke φ n`

なので、回転速度が上がるほど `E` は大きくなる。

トルクは

`T = Kt φ Ia`

である。

磁束が一定なら、トルクはほぼ電機子電流に比例する。

この三式をつなぐと、直流電動機は次のように自動調整していることが分かる。

### 負荷が増えた瞬間

負荷トルクが増える。

まだ電磁トルクが追い付かないので少し減速する。

`n` が下がる。

`E=Keφn` が下がる。

`Ia=(V-E)/Ra` が増える。

`T=KtφIa` が増える。

増えたトルクが新しい負荷と釣り合うところで回転速度が落ち着く。

つまり、

**負荷増加 → 少し減速 → 逆起電力低下 → 電流増加 → トルク増加**

というフィードバックが自然に起きる。

ここを理解すると、速度特性のグラフを暗記しなくてよくなる。

---

# 2. 始動時に大電流が流れる理由

停止時は `n=0` なので

`E≈0`

である。

したがって

`Ia≈V/Ra`

となる。

直流機の電機子抵抗は通常小さいため、そのまま定格電圧を加えると非常に大きな電流が流れようとする。

これが始動電流である。

古典的な直流電動機では、始動時に電機子回路へ始動抵抗を直列に入れ、

`Ia = V/(Ra+Rs)`

として電流を制限する。

回転速度が上がって逆起電力が生じるにつれ、始動抵抗を段階的に抜いていく。

「始動抵抗を界磁回路へ入れる」と考えてはいけない。

---

# 3. 速度式を導く

`V = E + IaRa`

`E = Ke φ n`

より、

`V-IaRa = Ke φ n`

したがって

`n = (V-IaRa)/(Ke φ)`

となる。

比例関係だけなら

`n ∝ (V-IaRa)/φ`

である。

この式から直流電動機の三つの代表的な速度制御法がすべて出てくる。

1. `V` を変える → 電圧制御
2. 電機子回路の抵抗を変える → 抵抗制御
3. `φ` を変える → 界磁制御

---

# 4. 電圧制御――0系のタップ制御はここへつながる

磁束 `φ` と負荷条件がほぼ一定なら、端子電圧 `V` を下げると逆起電力 `E` の平衡値も下がり、回転速度は低下する。

ただし速度は端子電圧そのものに比例するわけではない。

`E = V-IaRa`

なので、電機子抵抗による電圧降下を差し引く必要がある。

### 本試験型例

`V1=100 V, Ia=50 A, Ra=0.20 Ω, n1=1500 min^-1`

なら

`E1 = 100-50×0.20 = 90 V`

端子電圧を115 Vへ上げ、電流・磁束が同じなら

`E2 = 115-10 = 105 V`

`n2/n1 = E2/E1`

より

`n2 = 1500×105/90 = 1750 min^-1`

となる。

`1500×115/100` ではない。

---

# 5. 0系の低圧タップ切換は「電源側から電圧を段階的に変える」

日本車輌製造の0系主要諸元では、

- 主変圧器: 1650 kVA
- 主シリコン整流部: 1627 kW
- 制御方式: 低圧タップ切換
- タップ制御段数: 25

が確認できる。

0系では主変圧器低圧側のタップを切り替えて、整流器へ入る交流電圧を段階的に変える。

整流器はその交流を直流へ変換する。

その結果、主電動機へ加わる直流電圧を段階的に上げられる。

イメージは次である。

`低いタップ`

`↓`

`低い交流電圧`

`↓ 整流`

`低い直流電圧`

`↓`

`電機子電流・トルクを制御`

`↓`

`速度上昇`

`↓`

`逆起電力増加`

`↓`

`次のタップへ`

つまりタップ制御は、変圧器の巻数比を運転中に段階的に選び直す電圧制御である。

---

# 6. なぜ最初から高いタップへ入れないのか

停止時は逆起電力 `E≈0` である。

ここでいきなり高い直流電圧を加えると

`Ia≈V/Ra`

によって大電流が流れ、大きなトルクと発熱を生じる。

したがって低い電圧から始め、速度上昇とともに逆起電力が大きくなるのを待ちながら電圧を上げる方が電流を制御しやすい。

0系のタップ切換を理解するには、

**「速度を直接25段にしている」のではなく、電圧を25段階で変え、その結果として電流・トルク・速度を制御している**

と考える。

---

# 7. 抵抗制御――電圧を抵抗で捨てる

電機子回路へ直列抵抗 `Rs` を入れると

`E = V-Ia(Ra+Rs)`

となる。

同じ負荷電流なら `Rs` を増やすほど `E` は下がり、速度も低くなる。

しかし抵抗には

`Ploss = Ia²Rs`

の損失が生じる。

つまり速度を下げるために電力を熱として捨てる。

そのため連続的な速度制御としては効率が悪い。

0系が主変圧器タップで供給電圧側を変えるのは、単純な抵抗制御とは性格が異なる。

---

# 8. 界磁制御――磁束を弱めると速くなる

速度式

`n ∝ (V-IaRa)/φ`

から、電圧・電流条件が同じなら磁束 `φ` を弱くすると速度が上がる。

これが弱め界磁である。

しかしトルク式

`T = Kt φ Ia`

より、同じ電流なら磁束を弱めるとトルクは小さくなる。

したがって弱め界磁は、低速大トルクよりも高速側の速度拡大に向く。

「界磁を弱めると磁力が弱くなるのだから遅くなる」と直感だけで判断すると逆になる。

速度式とトルク式をセットで使う。

---

# 9. 分巻・他励・永久磁石界磁では磁束がほぼ一定

分巻電動機や他励電動機では、界磁回路が電機子回路から独立しているため、通常の範囲では磁束をほぼ一定とみなす問題が多い。

永久磁石界磁も同様に磁束一定として扱いやすい。

この場合、

`T ∝ Ia`

`n ∝ V-IaRa`

となる。

負荷が増えると電流・トルクは増え、速度は少し低下する。

比較的定速度特性を持つ。

---

# 10. 直巻電動機では電流が磁束まで変える

直巻電動機では界磁巻線と電機子が直列なので、同じ電流が流れる。

磁気飽和していない範囲では

`φ ∝ Ia`

と近似できる。

したがって

`T ∝ φIa ∝ Ia²`

となる。

大きな始動トルクを得やすい。

一方、負荷が軽くなり電流・磁束が減ると、速度式の分母 `φ` が小さくなって回転速度が大きく上昇する可能性がある。

そのため直巻電動機は無負荷運転を避ける必要がある。

ここは電験の正誤問題で頻出である。

---

# 11. 「電流を一定にする」と加速が分かりやすい

磁束一定なら `T∝Ia` である。

したがって力行時に電機子電流をある範囲へ保てれば、電動機トルクもある程度保てる。

列車側では車輪トルクがけん引力へ変わる。

`F = T_w/r`

そして

`m dv/dt = F_tractive - F_resistance`

で加速が決まる。

つまり電流を制御することは、実質的に加速力を制御することでもある。

0系のタップ制御を「電圧だけの話」にせず、**電流→トルク→けん引力→加速度**までつなげる。

---

# 12. 速度が上がるほど同じトルクを出し続けるのは難しくなる

軸出力は

`P = Tω`

である。

同じトルクのまま回転速度を2倍にすれば、機械出力も2倍必要になる。

しかし電動機・整流器・変圧器には定格がある。

したがって高速域まで無制限に同じトルクを維持できるわけではない。

一般的な電動機制御では、低速側でトルクを確保し、高速側では出力や電圧の制約を受けながらトルクが低下する領域が現れる。

この考え方は後のVVVF・誘導電動機の定トルク／定出力制御にもつながる。

---

# 13. 逆転は「電機子と界磁の片方だけ」を反転する

トルク方向は

`T ∝ φ Ia`

で決まる。

したがって回転方向を逆にするには、

- 磁束 `φ` の向き
- 電機子電流 `Ia` の向き

のどちらか片方だけを反転する。

両方を同時に反転すると積 `φIa` の符号は変わらず、トルク方向も変わらない。

この論点も本試験で問われる。

---

# 14. 速度制御と発電ブレーキは同じ式の裏表

力行時は

`V > E`

となり、電源から電動機へ電流が流れる。

回転速度が高くなり、何らかの回路切換で

`E > 外部回路側電圧`

となれば、電流方向を発電側へ変えられる。

つまり05の速度式・逆起電力は、そのまま06の発電ブレーキへつながる。

電動機と発電機は別の機械ではなく、同じ直流機の運転状態の違いである。

---

# 15. 電験での解法アルゴリズム

1. 電動機の種類を確認する。
2. 磁束が一定か、電流で変化するか判定する。
3. 定トルクなどの負荷条件から `Ia` の変化を決める。
4. `E=V-IaRa` を前後条件で求める。
5. `n∝E/φ` で回転速度を求める。
6. 始動なら `E≈0` を使う。
7. 抵抗制御なら追加抵抗の損失も確認する。
8. 界磁制御なら速度とトルクが逆方向へ変化することを確認する。
9. 直巻なら未飽和範囲で `φ∝Ia` を使う。

---

# 16. 頻出ミス

- 端子電圧比をそのまま速度比にする。
- `E=V-IaRa` の `IaRa` を無視する。
- 定トルク・磁束一定から `Ia` 一定を導けない。
- 始動時にも通常運転と同じ逆起電力があると思う。
- 始動抵抗を界磁回路へ入れる。
- 弱め界磁で速度が下がると考える。
- 未飽和直巻で `T∝Ia` とする。正しくは `T∝Ia²`。
- 電機子と界磁を両方反転して逆転できると考える。

---

# 17. 公式まとめ

`V = E + IaRa`

`E = Ke φ n`

`T = Kt φ Ia`

`n = (V-IaRa)/(Keφ)`

抵抗制御:

`E = V-Ia(Ra+Rs)`

抵抗損:

`Ploss = Ia²Rs`

機械出力:

`P = Tω`

車輪力:

`F = T_w/r`

運動方程式:

`m dv/dt = F_tractive-F_resistance`
