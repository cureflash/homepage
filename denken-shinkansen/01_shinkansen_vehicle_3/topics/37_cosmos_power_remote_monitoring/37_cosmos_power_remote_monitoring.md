# 解説本文

## §1 このテーマで電験は何を問うか

Topic 37で電験三種に直接接続するのは、COSMOS-SCADA固有の内部構成ではなく、「測る」「数値化する」「伝える」「制御する」という一般技術である。本試験では、A-D変換、デジタル計測、2進数・16進数、シーケンス制御、通信回線を介した遠方機器の制御が問われる。また固定法規問題を解くため、遠隔遮断に接続する最小限の系統連系保護用語も扱う。

この章を終えた時点で次を自力で処理できることを目標にする。

1. SCADAの一般的な役割を監視・データ収集・制御に分ける。
2. センサで得たアナログ量がA-D変換を経てデジタル情報になる流れを説明する。
3. A-D変換の分解能と量子化を説明する。
4. 二重積分形A-D変換の入力電圧・基準電圧・積分時間・クロック数の関係を導く。
5. 2進数・10進数・16進数を相互変換する。
6. センサ/スイッチ入力→制御装置→出力機器というシーケンス制御を判断する。
7. 遮断信号を通信回線で遠方へ送り、別地点の機器を動作させる原理を説明する。
8. 固定法規問題に必要な系統連系保護と関連用語を定義から判定する。

## §2 COSMOS-SCADAを公開範囲で捉える

JR東日本の公開資料では、COSMOS-SCADAは新幹線電力設備の状態監視・制御を行うシステムと説明されている。別の公開資料では、従来のDECSからCOSMOS-SCADAへ更新し、中央電力指令から変電所等を直接制御・監視できるようにしたことが示されている。

本教材では、COSMOS-SCADAを「新幹線電力設備の状態・計測情報を指令側へ集め、指令側から必要な制御を行うシステム」と位置付ける。内部の通信プロトコル、データ形式、ネットワーク構成、更新周期、サーバ構成、データベース構造は推測しない。

## §3 SCADAの一般的な役割

SCADAは Supervisory Control And Data Acquisition の略で、設備の状態・計測値を収集し、監視し、必要な制御を行う仕組みの総称として扱う。

電験向けには次の3機能へ分ける。

1. Data Acquisition: 現地のセンサ、計器、スイッチ状態などから情報を得る。
2. Supervisory Monitoring: 得た情報を指令側で表示・監視する。
3. Control: 指令側から操作指令を送り、現地機器を動作させる。

「現地情報→指令側」と「指令側の操作→現地機器」の向きを区別する。

## §4 変電所の遠隔監視を情報の流れとして考える

```text
物理量・設備状態
    ↓
センサ・計測入力
    ↓
必要な信号変換 / A-D変換
    ↓
デジタル情報
    ↓
通信による伝送
    ↓
指令側で監視
```

逆方向の制御は次のように捉える。

```text
指令側の制御指令
    ↓
通信による伝送
    ↓
現地制御装置
    ↓
対象機器の動作
```

これは一般的な情報の流れであり、COSMOS-SCADA内部の具体的装置構成や通信方式を示すものではない。

## §5 センサと遠隔計測

センサは温度、圧力、位置、レベル、電気量などの物理量・状態を電気的に扱える信号へ変換する。遠隔計測では、現地の測定量を指令側で扱える情報へ変換して送る。

連続値のアナログ信号はコンピュータやデジタル計器で扱うためA-D変換する。開/閉、ON/OFF、上限到達/未到達のような状態は0/1のデジタル状態として扱える。

センサは「測る」、制御装置は「判断する」、出力機器は「動作する」。役割を混同しない。

## §6 A-D変換の基本

A-D変換は連続的なアナログ量を離散的なデジタル値へ変換する。n bitで表せるコード数は

```text
L = 2^n
```

入力範囲を `Vmin ≤ V < Vmax` とし、範囲を等間隔の `2^n` 区間へ分ける定義なら量子化幅は

```text
q = (Vmax - Vmin) / 2^n
```

となる。端点条件が別に指定される問題では、その条件を優先する。

## §7 二重積分形A-D変換

未知入力電圧 `Vx` を固定時間 `T1` 積分し、その後に反対極性の既知基準電圧 `Vr` を積分して元の基準位置へ戻す。

第1期間の積分量と第2期間の戻し量が等しいため

```text
k Vx T1 = k Vr T2
Vx = (T2 / T1) Vr
```

同一クロックで `T1` 中に `N1` パルス、`T2` 中に `N2` パルスを数えるなら

```text
T1 = N1 / f
T2 = N2 / f
Vx = (N2 / N1) Vr
```

となる。

## §8 二重積分形A-D変換の解法手順

1. 第1期間に未知入力 `Vx` を積分しているか確認する。
2. 固定積分時間 `T1` を読む。
3. 第2期間の基準電圧 `Vr` と極性を確認する。
4. `kVxT1 = kVrT2` を立てる。
5. `Vx = (T2/T1)Vr` へ変形する。
6. 共通クロックなら `T2/T1 = N2/N1` とする。
7. 電圧単位、時間比、クロック数比を検算する。

異なるクロックを使う場合はパルス数比へ機械的に置き換えない。

## §9 デジタル情報と2進数・16進数

r進数の位取り記数法は

```text
(a_n ... a_1 a_0)_r
= a_n r^n + ... + a_1 r + a_0
```

である。2進数から10進数へは各bitの重みを加える。16進数では1桁が4 bitに対応するため、2進数を右から4 bitずつ区切る。

```text
(10110110)_2 = 182 = (B6)_16
```

`A=10, B=11, C=12, D=13, E=14, F=15` とする。

## §10 シーケンス制御とPLC

シーケンス制御は、あらかじめ定められた順序・条件に従って制御を進める方式である。PLCは入力機器の状態を取り込み、プログラムされた論理・手順に従って演算し、出力機器を動作させる。

```text
スイッチ / センサ
    ↓ 入力
PLC・制御装置
    ↓ 判断
リレー / 電磁接触器 / モータ等
    ↓ 出力
設備の動作
```

上限・下限レベルスイッチでポンプを起動・停止する例はシーケンス制御として考えられる。一方、測定値と目標値の偏差に応じて操作量を連続調整する説明はフィードバック制御である。

## §11 遠隔制御と通信による遮断信号

遠隔制御では、ある地点で生成した制御情報を通信回線等で別地点へ伝え、受信側で対象機器を動作させる。

```text
異常・事故を検出
    ↓
遮断などの制御信号を生成
    ↓
通信回線で遠方へ伝送
    ↓
受信側で信号を識別
    ↓
遠方側の遮断器などを動作
```

転送遮断装置は、遮断信号を通信回線で別地点へ伝送し、遠方側の遮断器や連系機器を動作させる仕組みとして理解する。固定R6上 法規 問7では、配電用変電所の遮断信号を通信回線で伝送し、分散型電源を解列する用途が示される。

この一般原理をCOSMOS-SCADAの具体的実装方式とは断定しない。

### §11-A R6上 法規 問7を解くための系統連系保護

固定問題では、逆変換装置を用いた高圧連系・逆潮流有りの場合について、保護リレーと検出対象の対応を問う。問題文の表と注記から、次を判定できる必要がある。

| 検出対象 | 対応する保護・考え方 | 判定ポイント |
|---|---|---|
| 発電電圧の異常上昇 | 過電圧リレー | 分散型電源自体の電圧異常を監視する。 |
| 発電電圧の異常低下 | 不足電圧リレー | 同じく発電設備側の電圧異常を監視する。 |
| 系統側の短絡事故 | 不足電圧リレー | 系統事故による電圧低下を受電点等で検出する。 |
| 系統側の地絡事故 | 地絡過電圧リレー | 零相電圧を用いる地絡検出へ接続する。 |
| 単独運転 | 周波数上昇/低下リレー、転送遮断装置、単独運転検出装置 | 系統電源が失われた後も分散型電源だけで系統の一部を加圧し続ける状態を検出・解列する。 |

したがって固定問題の空欄は「発電電圧」「系統側」「地絡過電圧」「単独運転」の組合せに絞れる。

### §11-B H23 法規 問6を解くための用語定義

固定問題は5つの用語定義から誤りを選ぶ形式である。用語は電力や信号の向きまで含めて区別する。

- 逆潮流: 一般送配電側ではない発電設備から、連系する電力系統側へ有効電力が流れること。
- 自立運転: 発電設備が系統から解列された状態で、設置者の構内負荷だけへ電力を供給する運転。
- 単独運転: 連系していた系統が上位電源から切り離された後も、分散型電源が運転を続け、その系統の一部の負荷へ有効電力を供給している状態。
- 逆充電: 一般送配電側ではない発電設備だけで系統を加圧しているが、その系統へ有効電力を供給していない状態。
- 転送遮断装置: ある地点の遮断信号を通信回線で別地点へ伝送し、別地点の遮断器等を動作させる装置。

判定では「逆潮流は有効電力の流れ」である点が重要である。無効電力だけの流れを逆潮流とする説明は誤りになる。

## §12 遠隔監視・遠隔制御の問題を解く手順

1. 何を検出するか確認する。
2. 検出結果がアナログ量かON/OFF状態か確認する。
3. デジタル処理が必要ならA-D変換や状態符号化を考える。
4. どこからどこへ情報が送られるか確認する。
5. 「計測情報」か「制御指令」かを区別する。
6. 受信側で何を動作させるか確認する。
7. 系統連系保護問題なら「発電設備側の異常」「系統側事故」「単独運転」を分ける。
8. 用語問題なら有効電力・加圧・解列・通信信号の向きを定義と照合する。

## §13 例題1 基礎 — 2進数・16進数と量子化

### 問題

8 bitのA-D変換で、入力範囲 `0 ≤ V < 5.12 V` を256等分する。量子化幅 `q` を求める。また、コード `(10101100)_2` を10進数と16進数で表せ。

### 解法

```text
L = 2^8 = 256
q = 5.12 / 256 = 0.020 V = 20 mV
(10101100)_2 = 128 + 32 + 8 + 4 = 172 = (AC)_16
```

8 bitのコード範囲0〜255に172が入ることも確認する。

## §14 例題2 本試験標準 — 二重積分形A-D変換

### 問題

`T1 = 20 ms`、`Vr = 2.5 V`、`T2 = 12 ms` の二重積分形A-D変換器で `Vx` を求める。共通クロックで第1期間が5000パルスなら第2期間のパルス数も求める。

### 解法

```text
Vx = (T2 / T1) Vr
   = (12 / 20) × 2.5
   = 1.5 V

N2 = 5000 × 12 / 20
   = 3000
```

## §15 例題3 複合・ひっかけ — 遠隔計測から遠隔制御まで

### 問題

入力範囲 `0 ≤ V < 10.24 V` を1024等分する10 bit A-D変換器で、センサ出力が `6.40 V` のときの量子化幅と理想コード番号を求める。さらに、上限スイッチONでPLCが停止指令を出し、その指令を通信回線で別地点へ伝えて機器を停止させる場合の役割を整理する。

### 解法

```text
L = 2^10 = 1024
q = 10.24 / 1024 = 0.01 V
D = 6.40 / 0.01 = 640
```

役割は次のとおり。

1. センサ: 連続量を検出する。
2. A-D変換器: アナログ電圧をデジタルコードへ変換する。
3. 上限スイッチ: ON/OFF状態を入力する。
4. PLC: 入力条件に基づき停止指令を生成する。
5. 通信: 停止指令を遠方へ伝える。
6. 遠方側機器: 受信指令に従って停止する。

この例は一般的な遠隔監視制御モデルであり、COSMOS-SCADA内部構成を示すものではない。
