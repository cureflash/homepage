# 解説本文

## §1 このテーマで電験は何を問うか

Topic 37で電験三種に直接接続するのは、COSMOS-SCADA固有の内部構成ではなく、「測る」「数値化する」「伝える」「制御する」という一般技術である。本試験では、A-D変換の原理、デジタル計測、2進数・16進数、センサ入力を用いたシーケンス制御、通信回線を介した遠方機器の制御が問われる。

この章を終えた時点で、次を自力で処理できることを目標にする。

1. SCADAの一般的な役割を、監視・データ収集・制御に分けて説明する。
2. センサで得たアナログ量がA-D変換を経てデジタル情報になる流れを説明する。
3. A-D変換の分解能と量子化の意味を説明する。
4. 二重積分形A-D変換で入力電圧、基準電圧、積分時間、クロック数の関係を導く。
5. 2進数・10進数・16進数を相互変換する。
6. センサ/スイッチ入力→制御装置→出力機器というシーケンス制御の流れを判断する。
7. 遮断信号などを通信回線で遠方へ伝え、別地点の機器を動作させる遠隔制御の原理を説明する。

## §2 COSMOS-SCADAを公開範囲で捉える

JR東日本の公開資料では、COSMOS-SCADAはJR東日本管内の新幹線電力設備の状態監視・制御を行うシステムと説明されている。別のJR東日本公開資料では、従来のDECSからCOSMOS-SCADAへ更新し、高性能化した計算機・遠制装置の導入によって中央電力指令から変電所等を直接制御・監視できるようにしたことが示されている。

したがって本教材では、COSMOS-SCADAを「新幹線の電力設備について、現地の状態・計測情報を指令側へ集め、指令側から必要な制御を行うシステム」として位置付ける。これは公開資料で確認できる範囲である。

一方、内部の通信プロトコル、データ形式、ネットワーク構成、更新周期、サーバ構成、データベース構造は公開資料から確定できない。本教材では推測しない。

## §3 SCADAの一般的な役割

SCADAは Supervisory Control And Data Acquisition の略で、設備の状態・計測値を収集し、監視し、必要な制御を行う仕組みの総称として扱う。一般的な変電所SCADAでは、リアルタイム監視・制御、自動計測、運転履歴の収集などが行われる。

電験向けには、次の3機能へ分けると整理しやすい。

1. Data Acquisition: 現地のセンサ、計器、スイッチ状態などから情報を得る。
2. Supervisory Monitoring: 得た情報を指令側で表示・監視する。
3. Control: 指令側から必要な操作指令を送り、現地機器を動作させる。

ここで重要なのは、SCADAという名称だけを暗記することではなく、「現地情報→指令側」「指令側の操作→現地機器」という双方向の情報の流れを区別できることである。

## §4 変電所の遠隔監視を情報の流れとして考える

変電所では、電圧・電流などの計測量と、機器の開閉状態などの状態情報を扱う。電験学習上は、これらを次の流れで整理する。

```text
物理量・設備状態
    ↓
センサ・計測入力
    ↓
必要な信号変換 / A-D変換
    ↓
デジタル情報
    ↓
通信による伝送
    ↓
指令側で監視
```

逆方向の制御は次のように捉える。

```text
指令側の制御指令
    ↓
通信による伝送
    ↓
現地制御装置
    ↓
対象機器の動作
```

この流れはSCADAの一般原理を示すものであり、COSMOS-SCADA内部の具体的装置構成や通信方式を表したものではない。

## §5 センサと遠隔計測

センサは温度、圧力、位置、レベル、電気量などの物理量・状態を電気的に扱える信号へ変換する。電験で重要なのは、センサの種類を大量に暗記することより、「何を検出して、どの信号が制御装置へ入るか」を追うことである。

遠隔計測では、現地の測定量を指令側で扱える情報へ変換して送る。測定量が連続値のアナログ信号なら、コンピュータやデジタル計器で扱うためにA-D変換を行う。開/閉、ON/OFF、上限到達/未到達のような状態は、0/1のデジタル状態として扱いやすい。

センサは「測る」側であり、制御装置は入力された情報に基づいて「判断する」側、アクチュエータや開閉器などの出力機器は「動作する」側である。この役割を混同しない。

## §6 A-D変換の基本

A-D変換は、連続的なアナログ量を離散的なデジタル値へ変換する処理である。一般には、時間方向を離散化する標本化と、振幅方向を離散化する量子化を考える。

n bitで表せるコード数は

```text
L = 2^n
```

である。入力範囲を `Vmin ≤ V < Vmax` とし、その範囲を等間隔の `2^n` 区間へ分けるという定義なら、1量子化幅を

```text
q = (Vmax - Vmin) / 2^n
```

と置ける。

この式は「入力範囲を2^n個の等しい区間へ分ける」という定義で使う。問題によって最大コード値と端点の対応方法が異なる場合があるため、端点条件が明示されている問題ではその条件を優先する。

bit数が1増えるとコード数は2倍になり、同じ入力範囲なら量子化幅は1/2になる。したがって、より細かい値を区別できる。

## §7 二重積分形A-D変換

二重積分形A-D変換では、未知入力電圧を一定時間積分し、その後に極性が反対の既知基準電圧を積分して、積分器出力が基準位置へ戻るまでの時間を測る。

入力電圧を `Vx`、基準電圧の大きさを `Vr`、最初の固定積分時間を `T1`、戻りに要する時間を `T2`、積分比例定数を `k` とする。

第1期間では、積分器出力の変化量の大きさは

```text
Vm = k Vx T1
```

となる。

第2期間で極性を反転した基準電圧を積分し、元の基準位置へ戻る条件は

```text
k Vx T1 = k Vr T2
```

である。`k`を消去すると

```text
Vx = (T2 / T1) Vr
```

を得る。

同一クロックで `T1` 中に `N1` パルス、`T2` 中に `N2` パルスを数えるなら

```text
T1 = N1 / f
T2 = N2 / f
```

なので

```text
Vx = (N2 / N1) Vr
```

となる。

この方式の問題では、積分器、比較器、基準電圧、クロックパルスの役割を図から読み取り、「第1期間で未知入力を積分」「第2期間で既知基準電圧を逆向きに積分」という順序を押さえる。式だけを暗記しない。

## §8 二重積分形A-D変換の解法手順

本試験で図と波形が与えられたら、次の順で処理する。

1. 第1期間に積分されている電圧が未知入力 `Vx` か確認する。
2. 固定積分時間 `T1` を読み取る。
3. 第2期間の基準電圧の大きさ `Vr` と極性を確認する。
4. 第1期間の積分量 `kVxT1` を書く。
5. 第2期間の戻し量 `kVrT2` を書く。
6. 元の基準位置へ戻る条件 `kVxT1 = kVrT2` を立てる。
7. `Vx = (T2/T1)Vr` へ変形する。
8. クロック数が与えられるなら `T2/T1 = N2/N1` へ置き換える。
9. 電圧単位、時間比、クロック数の比を検算する。

発振周波数 `f` が共通なら時間比をパルス数比へ置換できる。異なるクロックを使う問題ではこの置換を機械的に使わない。

## §9 デジタル情報と2進数・16進数

デジタル情報では、0と1の2状態を基本として数値を表す。r進数の位取り記数法は

```text
(a_n ... a_1 a_0)_r
= a_n r^n + ... + a_1 r + a_0
```

である。

2進数から10進数へは各bitに `2^0, 2^1, 2^2, ...` の重みを掛けて加える。16進数では1桁が4 bitに対応するため、2進数を右から4 bitずつ区切ると変換しやすい。

例:

```text
(10110110)_2
= 1×2^7 + 0×2^6 + 1×2^5 + 1×2^4 + 0×2^3 + 1×2^2 + 1×2 + 0
= 182
= (B6)_16
```

16進数では `A=10, B=11, C=12, D=13, E=14, F=15` とする。10進数と16進数を見た目だけで比較せず、同じ基数へ変換してから比較する。

## §10 シーケンス制御とPLC

シーケンス制御は、あらかじめ定められた順序・条件に従って制御を進める方式である。スイッチ、リレー、タイマ、センサなどの入力状態を条件として、出力機器をON/OFFする問題が代表的である。

PLC（Programmable Logic Controller）は、入力機器の状態を取り込み、プログラムされた論理・手順に従って演算し、出力機器を動作させる制御装置である。電験では次の流れを追う。

```text
スイッチ / センサ
    ↓ 入力
PLC・制御装置
    ↓ 判断
リレー / 電磁接触器 / モータ等
    ↓ 出力
設備の動作
```

例えば、上限・下限のレベルスイッチでポンプを起動・停止する制御は、センサ状態とあらかじめ定めた手順で出力を切り替えるシーケンス制御として考えられる。

一方、測定値と目標値の偏差に応じて操作量を連続的に調整し続ける説明はフィードバック制御である。固定過去問では、この区別が重要になる。

## §11 遠隔制御と通信による遮断信号

遠隔制御では、ある地点で生成した制御情報を通信回線等で別地点へ伝え、受信側で対象機器を動作させる。

電力設備の試験問題では、事故や異常の検出と、遠方側機器の動作を次の順に分けて読む。

```text
異常・事故を検出
    ↓
遮断などの制御信号を生成
    ↓
通信回線で遠方へ伝送
    ↓
受信側で信号を識別
    ↓
遠方側の遮断器などを動作
```

転送遮断装置は、このように通信回線を用いて遮断信号を別地点へ送り、遠方側の遮断器を動作させる考え方に接続できる。

ただし、本教材で転送遮断装置を扱うのは「通信による遠隔制御」という電験論点を理解するためである。転送遮断装置の具体方式がCOSMOS-SCADAに実装されているとは断定しない。

## §12 遠隔監視・遠隔制御の問題を解く手順

知識問題は、装置名から暗記で選ぶより、情報の向きと役割を分ける。

1. 何を検出するかを確認する。
2. 検出結果がアナログ量かON/OFF状態かを確認する。
3. デジタル処理が必要ならA-D変換や状態符号化を考える。
4. どこからどこへ情報が送られるかを確認する。
5. 「計測情報を送る」のか「制御指令を送る」のかを区別する。
6. 受信側で何を動作させるかを確認する。
7. センサ、制御装置、通信、出力機器の役割が入れ替わっていないか検算する。

変電所の設備名が出ても、問われている中心が通信・計測・制御なら、情報の流れへ分解することで判断しやすくなる。

## §13 例題1 基礎 — 2進数・16進数と量子化

### 問題

8 bitのA-D変換で、入力範囲 `0 ≤ V < 5.12 V` を256等分する。量子化幅 `q` を求める。また、A-D変換後のコード `(10101100)_2` を10進数と16進数で表せ。

### 解法

8 bitなのでコード数は

```text
L = 2^8 = 256
```

量子化幅は

```text
q = 5.12 / 256
  = 0.020 V
  = 20 mV
```

2進数は

```text
(10101100)_2
= 128 + 32 + 8 + 4
= 172
```

4 bitずつ区切ると

```text
1010 1100
  A    C
```

なので

```text
(10101100)_2 = (172)_10 = (AC)_16
```

### 検算

8 bitのコードは0〜255の範囲なので172は範囲内。`5.12 V / 256 = 0.02 V` で単位も整合する。

## §14 例題2 本試験標準 — 二重積分形A-D変換

### 問題

二重積分形A-D変換器で、未知入力 `Vx` を固定時間 `T1 = 20 ms` 積分した後、反対極性の基準電圧 `Vr = 2.5 V` で積分器出力を基準位置へ戻した。戻り時間が `T2 = 12 ms` だった。`Vx` を求める。さらに、クロック周波数が一定で第1期間のクロック数が5000なら、第2期間のクロック数を求める。

### 解法

二重積分形では、同じ積分器を使うため比例定数 `k` は両期間で共通である。

```text
k Vx T1 = k Vr T2
```

よって

```text
Vx = (T2 / T1) Vr
   = (12 / 20) × 2.5
   = 1.5 V
```

同一クロックなので

```text
N2 / N1 = T2 / T1
```

したがって

```text
N2 = 5000 × 12 / 20
   = 3000
```

### 検算

`T2/T1 = 0.6` であるから、`Vx` は `Vr` の0.6倍、クロック数も第1期間の0.6倍になる。両方とも同じ比となり整合する。

## §15 例題3 複合・ひっかけ — 遠隔計測から遠隔制御まで

### 問題

ある一般的な遠隔監視設備で、現地センサが `0〜10 V` のアナログ信号を出力し、10 bit A-D変換器でデジタル値にする。入力範囲は `0 ≤ V < 10.24 V` を1024等分する定義とする。センサ出力が `6.40 V` のとき、量子化幅と理想的なコード番号を求める。また、上限スイッチがONになったときにPLCが停止指令を出し、その指令を通信回線で別地点へ伝えて機器を停止させる場合、各要素の役割を整理せよ。

### 解法

10 bitなので

```text
L = 2^10 = 1024
```

量子化幅は

```text
q = 10.24 / 1024
  = 0.01 V
```

`6.40 V` は

```text
D = 6.40 / 0.01 = 640
```

に対応する。

制御の情報の流れは次のとおり。

1. センサ: 連続量 `6.40 V` を検出する。
2. A-D変換器: アナログ電圧をデジタルコードへ変換する。
3. 上限スイッチ: 上限到達というON/OFF状態を入力する。
4. PLC: 入力条件に基づき停止指令を生成する。
5. 通信: 停止指令を遠方側へ伝える。
6. 遠方側の機器: 受信した指令に従い停止動作する。

### ひっかけ確認

- センサが制御判断を行うわけではない。
- A-D変換はアナログ→デジタルであり、逆ではない。
- 通信回線は「判断装置」ではなく情報を伝える役割である。
- この例は一般的な遠隔監視制御の学習用モデルであり、COSMOS-SCADAの内部構成を示すものではない。
- 冗長化、バックアップ、フェイルセーフ、障害検知、切替はTopic 38なので追加しない。

## 公式・解法まとめ

```text
n bitのコード数:
L = 2^n

入力範囲を2^n等分する定義での量子化幅:
q = (Vmax - Vmin) / 2^n

二重積分形A-D変換:
kVxT1 = kVrT2
Vx = (T2 / T1) Vr

同一クロックなら:
T2 / T1 = N2 / N1
Vx = (N2 / N1) Vr

r進数:
(a_n ... a_0)_r = Σ a_i r^i
```

情報の流れは次の2方向を区別する。

```text
遠隔計測:
現地の物理量・状態 → センサ → A-D/状態符号化 → デジタル情報 → 通信 → 指令側監視

遠隔制御:
指令側の制御情報 → 通信 → 現地制御装置 → 対象機器の動作
```
