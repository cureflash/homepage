## blind独立解答

### R6上 法規 問7

独立答案: `5`

根拠:
- 発電設備側の電圧異常上昇・異常低下を過電圧・不足電圧リレーで検出するため、(ア)は「発電電圧」。
- 配電系統側の短絡・地絡事故を対象とするため、(イ)は「系統側」。
- 地絡事故の検出には地絡過電圧リレーを用いるため、(ウ)は「地絡過電圧」。
- 転送遮断装置と並記され、能動方式を含む検出装置は「単独運転」検出装置であるため、(エ)は「単独運転」。
- 組合せは選択肢(5)。

### R3 機械 問14

独立答案: `5`

根拠:
- (6)16 × 16 = (60)16 は正しい。
- (1010101)2 = 85、(57)16 = 87 なので後者が大きく、(2)は正しい。
- (1011)2 = 11、(12)10 = (C)16 で、(3)(4)も正しい。
- (3D)16 = 3×16+13 = 61 = (111101)2 であり、提示された (111011)2 ではない。
- 誤りは選択肢(5)。

### R1 理論 問18(a)

独立答案: `1`

根拠:
- S1期間 T1 では入力 Vx を積分するため、Vm = k Vx T1。
- S2期間では基準電圧 -Vr を積分して傾きを反転し、Vo = Vm - k Vr (t-T1)。
- Vo = 0 となる t = T1+T2 で kVxT1 = kVrT2 なので、Vx = (T2/T1)Vr。
- クロック周期 Ts は発振周波数に反比例する。
- 以上の組合せは選択肢(1)。

### R1 理論 問18(b)

独立答案: `4`

根拠:
- 同一クロックなので T2/T1 = N2/N1。
- Vx = (T2/T1)Vr = (2.0×10^3 / 1.0×10^3) × 2.0 = 4.0 V。
- 選択肢(4)。

### H26 機械 問13

独立答案: `3`

根拠:
- スイッチ・リレー・タイマ等であらかじめ定めた工程を順に進める制御はシーケンス制御。
- エレベータや上下限レベルスイッチによる送水制御もシーケンス制御で実現できる。
- PLCはリレー・タイマ等の論理をソフトウェアで実現できる。
- 一方、炉温を測定値と設定値で比較し、ヒータ発熱量を連続的に調節して一定温度に保つのはフィードバック制御の説明であり、シーケンス制御ではない。
- 誤りは選択肢(3)。

### H23 法規 問6

独立答案: `1`

根拠:
- 逆潮流は発電設備設置者側から一般電気事業者側へ流れる有効電力の流れをいう。
- 選択肢(1)は「無効電力の流れ」としているため誤り。
- 転送遮断装置は通信回線で遮断信号を別地点へ送り遮断器を動作させる装置であり、他の定義と整合する。
- 誤りは選択肢(1)。
