## 教材で必要な説明

1. 電熱では電気エネルギーを熱へ変換すること、抵抗加熱の基本となるジュール熱を`Q=I^2Rt=VIt=Pt=V^2t/R`として、各式の成立条件・単位とともに示す。
2. 物体の温度上昇に必要な顕熱を`Q=mcΔT`で求め、`m [kg]`、`c [J/(kg·K)]`、`ΔT [K]`を区別する。温度差では`1 K`と`1 ℃`が同じ大きさであることを扱う。
3. 問題文で融解熱・蒸発潜熱`L`が与えられた場合は`Q=mL`で相変化の熱量を求める。潜熱の物性値を暗記対象にせず、問題文提示値を使う。
4. 複数の加熱過程では顕熱・潜熱等を過程別に求め、`Q_total=ΣQ`として加算する。R8上問17のように対象質量が過程で異なる場合は先に質量収支を整理する。
5. 熱効率を`η=Q_use/(Pt)`とし、`Q_use=ηPt`、`P=Q_use/(ηt)`、`t=Q_use/(ηP)`へ逆算できるようにする。
6. 空調に接続するヒートポンプでは、過去問で直接要求される成績係数を`COP=Q_out/W_in`として扱い、`Q_out=COP·P·t`、`P=Q_out/(COP·t)`、`t=Q_out/(COP·P)`を使い分ける。冷媒の状態量・p-h線図等へは広げない。
7. 単位換算を`1 kW=1 kJ/s`、`1 kWh=3.6 MJ`、`1 h=3600 s`、`1 min=60 s`として固定し、体積から質量への換算は問題文で与えられる密度を使う。
8. 解法手順を、加熱対象・過程の分解→質量と温度差の整理→必要熱量→効率またはCOP→電力・時間へ逆算→単位・桁・物理的妥当性の検算、の順で示す。
9. 頻出ミスとして、効率を掛ける/割る方向の逆転、COPと効率の混同、kWとkWhの混同、MJとkJの換算、時間の秒換算漏れ、潜熱対象質量の取り違えを扱う。

## 解説本文

### §1 このテーマで電験は何を問うか

Topic 28は電験三種「機械」の電熱・ヒートポンプ計算に対応する。品質ゲート対象5問・10小問で共通するのは、必要熱量を先に求め、その熱量を電力・時間・熱効率またはCOPへ接続する手順である。

問題を見たら、最初に次を判定する。

1. 温度変化だけか、融解・蒸発などの相変化を含むか。
2. 加熱対象の質量は過程ごとに同じか、途中で変わるか。
3. 抵抗加熱の熱効率`η`を使うか、ヒートポンプの`COP`を使うか。
4. 求める量は熱量、電力、時間、温度上昇のどれか。
5. `J`、`kJ`、`MJ`、`kW`、`kWh`、秒、分、時間の単位がそろっているか。

この判定ができれば、固定5問・10小問を同じ解法手順で処理できる。

### §2 電力・電力量と熱量

電力`P [W]`は単位時間当たりのエネルギーであり、一定電力を時間`t [s]`だけ使った電気エネルギーは

`W_in = Pt`

である。`1 W = 1 J/s`なので、`P`をW、`t`をsで入れれば`W_in`はJになる。

電熱問題では、この入力電気エネルギーの全部または一部が有効な熱量になる。したがって、まず必要熱量を求め、その後で効率またはCOPを通して入力電力・時間へつなぐのが基本である。

### §3 抵抗加熱とジュール熱

抵抗`R [Ω]`に電流`I [A]`が流れるとき、抵抗で発生するジュール熱は

`Q = I^2Rt`

である。オームの法則`V=IR`と電力`P=VI`を用いれば

`Q = VIt = Pt = V^2t/R`

とも表せる。

各式は同じ抵抗加熱を別の与条件から計算するための形である。`I`と`R`が与えられれば`I^2Rt`、`V`と`I`なら`VIt`、電力が直接与えられれば`Pt`を使う。

ここでの`Q`は抵抗で発生した熱量であり、被加熱物へ実際に利用される熱量がこれより小さい場合は、後述の熱効率を考える。

### §4 顕熱 Q = mcΔT

物体の温度を変えるのに必要な熱量は

`Q = mcΔT`

で求める。

- `m`: 質量 `[kg]`
- `c`: 比熱 `[J/(kg·K)]`または`[kJ/(kg·K)]`
- `ΔT`: 温度差 `[K]`
- `Q`: 熱量 `[J]`または`[kJ]`

温度差では`1 K`と`1 ℃`の大きさは同じなので、例えば20 ℃から80 ℃への加熱なら`ΔT=60 K`としてよい。

比熱を`kJ/(kg·K)`で使えば、質量kg、温度差Kとの積から熱量はkJで得られる。単位を途中で混在させないことが重要である。

### §5 潜熱 Q = mL

融解や蒸発では、温度が変化していなくても相を変えるために熱量が必要である。問題文で単位質量当たりの潜熱`L`が与えられたら

`Q = mL`

を使う。

- `m`: 相変化する質量 `[kg]`
- `L`: 潜熱 `[kJ/kg]`など
- `Q`: 相変化に必要な熱量 `[kJ]`

Topic 28では潜熱の物性値を暗記範囲へ追加しない。過去問で与えられた融解熱・蒸発潜熱をそのまま使用する。

### §6 複数の加熱過程と質量整理

温度上昇と相変化が連続する場合、各過程の熱量を個別に計算してから加算する。

`Q_total = Q_1 + Q_2 + ... = ΣQ`

例えば、氷を融かしてから水を加熱する問題なら

`Q_total = mL + mcΔT`

となる。

乾燥問題のように「最初に含まれている水」と「実際に蒸発させる水」の質量が異なる場合は、式へ代入する前に質量を整理する。同じ`m`をすべての過程へ機械的に入れない。

### §7 熱効率 η

抵抗加熱装置へ入力した電気エネルギーのうち、被加熱物へ有効に伝わる割合を熱効率`η`とすると

`η = Q_use/(Pt)`

である。したがって

`Q_use = ηPt`

`P = Q_use/(ηt)`

`t = Q_use/(ηP)`

と変形できる。

効率が`η<1`なら、必要な入力電気エネルギーは有効熱量より大きい。したがって電力や時間を逆算するときは、必要熱量を`η`で割る方向になる。

### §8 ヒートポンプと COP

空調・給湯のヒートポンプでは、電気入力に対して供給した熱量の比を成績係数`COP`で表す。

`COP = Q_out/W_in`

一定の消費電力`P`で時間`t`運転するなら`W_in=Pt`なので

`Q_out = COP·P·t`

となる。逆算形は

`P = Q_out/(COP·t)`

`t = Q_out/(COP·P)`

である。

COPは熱効率`η`とは別の量である。`η`を百分率の効率として扱う抵抗加熱問題と、`COP`を用いるヒートポンプ問題を混同しない。Topic 28では冷媒物性や冷凍サイクル詳細へは広げない。

### §9 単位換算

固定5問では単位換算が正答を左右する。最低限、次を固定する。

- `1 kW = 1 kJ/s`
- `1 kWh = 3.6 MJ = 3600 kJ`
- `1 h = 3600 s`
- `1 min = 60 s`

例えば`Q [kJ]`を`P [kW]`で割ると、`kW=kJ/s`なので時間は秒で得られる。時間で答えるなら最後に`3600`で割る。

体積が与えられて質量へ変換する場合は、問題文で与えられた密度を使う。未提示の物性値を勝手に補わない。

### §10 何を求めるかで式を逆算する

同じ関係式でも、設問が変われば未知量が変わる。

抵抗加熱:

- 熱量を求める: `Q=ηPt`
- 電力を求める: `P=Q/(ηt)`
- 時間を求める: `t=Q/(ηP)`

ヒートポンプ:

- 供給熱量を求める: `Q_out=COP·P·t`
- 電力を求める: `P=Q_out/(COP·t)`
- 時間を求める: `t=Q_out/(COP·P)`

温度差を求める場合は`Q=mcΔT`から

`ΔT = Q/(mc)`

とする。公式を暗記するだけでなく、求める量を左辺へ出す。

### §11 本試験で再利用する解法手順

1. 加熱対象と加熱過程を分ける。温度上昇か、相変化かを判定する。
2. 各過程で使う質量、比熱、温度差、潜熱を整理する。
3. `Q=mcΔT`または`Q=mL`で各熱量を求め、必要なら`Q_total=ΣQ`で加算する。
4. 抵抗加熱なら熱効率`η`、ヒートポンプなら`COP`を選ぶ。
5. 求める量に応じて電力・時間・温度差へ式を変形する。
6. `kJ/kW/s`または`MJ/kWh/h`など、単位系をそろえて数値代入する。
7. 効率が1未満なら入力が有効熱量より大きくなるか、COPが大きいほど同じ入力で供給熱量が増えるかを検算する。

この順序を固定すれば、熱量を出す前に効率やCOPを掛けて混乱することを防げる。

### §12 頻出ミス

- `Q=mcΔT`の`ΔT`へ最終温度そのものを入れる。
- 顕熱と潜熱をどちらか一方しか足さない。
- 蒸発・融解する質量を全質量と取り違える。
- 効率問題で`P=Qη/t`としてしまう。必要入力は`Q/(ηt)`である。
- `COP`と`η`を同じものとして扱う。
- `kW`をエネルギー量、`kWh`を電力と取り違える。
- `MJ`と`kJ`の`1000`倍、時間と秒の`3600`倍を落とす。
- `kJ`を`kW`で割って得た秒を、そのまま時間として答える。

### §13 新幹線への接続

新幹線の車内空調・電熱設備も、車内で電力を消費する負荷として考えられる。電験の計算では、設備固有の制御や冷媒詳細へ入る前に、「電力を何時間使うか」「必要熱量はいくらか」「効率またはCOPを介して入力と出力がどう結ばれるか」を整理する。

本Topicでは新幹線車内の具体的な空調容量、COP、電圧、消費電力、設定温度などを一次資料で固定していないため、実車値としては扱わない。新幹線への接続は、電力・熱量・効率・COPという電験の一般式を車内設備へ結び付ける範囲に限定する。

### §15 公式・解法まとめ

- 電力量: `W_in=Pt`
- ジュール熱: `Q=I^2Rt=VIt=Pt=V^2t/R`
- 顕熱: `Q=mcΔT`
- 潜熱: `Q=mL`
- 複数過程: `Q_total=ΣQ`
- 熱効率: `η=Q_use/(Pt)`、`Q_use=ηPt`
- 抵抗加熱の逆算: `P=Q_use/(ηt)`、`t=Q_use/(ηP)`
- ヒートポンプ: `COP=Q_out/W_in`、`Q_out=COP·P·t`
- ヒートポンプの逆算: `P=Q_out/(COP·t)`、`t=Q_out/(COP·P)`
- 単位: `1 kW=1 kJ/s`、`1 kWh=3.6 MJ`

解法の軸は、`加熱過程 → 質量・温度差 → 必要熱量 → 効率/COP → 電力・時間 → 単位・桁の検算`である。

## 3段階例題

### 例題1 基礎: ジュール熱

抵抗`10 Ω`の電熱器に`100 V`を加え、`5 min`通電した。発生するジュール熱を求めよ。損失は考えない。

#### 解法

電圧と抵抗が与えられているので

`P = V^2/R = 100^2/10 = 1000 W`

通電時間は

`t = 5×60 = 300 s`

したがって

`Q = Pt = 1000×300 = 300000 J = 300 kJ`

答え: `300 kJ`。

電力Wに秒を掛ければJになることを確認する。

### 例題2 本試験標準: 融解＋顕熱＋熱効率

`0 ℃`の氷`5.0 kg`をすべて融かし、その水を`50 ℃`まで加熱する。氷の融解熱を`334 kJ/kg`、水の比熱を`4.2 kJ/(kg·K)`とする。消費電力`2.0 kW`、熱効率`70 %`の電熱装置を使うとき、必要時間を求めよ。

#### 解法

まず融解に必要な潜熱を求める。

`Q_1 = mL = 5.0×334 = 1670 kJ`

次に融けた水を`0 ℃→50 ℃`へ上げる顕熱を求める。

`Q_2 = mcΔT = 5.0×4.2×50 = 1050 kJ`

必要な有効熱量は

`Q_total = 1670+1050 = 2720 kJ`

有効加熱電力は

`ηP = 0.70×2.0 = 1.4 kW = 1.4 kJ/s`

したがって

`t = Q_total/(ηP) = 2720/1.4 ≈ 1943 s`

`1943/60 ≈ 32.4 min`

答え: 約`32.4 min`。

潜熱と顕熱を加算し、必要時間の逆算では効率を分母側へ置くことが要点である。

### 例題3 複合・ひっかけ: ヒートポンプのCOPと単位換算

水`0.300 m^3`を`20 ℃`から`65 ℃`まで加熱する。水の密度を`1000 kg/m^3`、比熱を`4.18 kJ/(kg·K)`とする。消費電力`1.5 kW`、COP`4.0`のヒートポンプを使うとき、必要時間を求めよ。

#### 解法

まず体積を質量へ直す。

`m = 0.300×1000 = 300 kg`

温度差は

`ΔT = 65-20 = 45 K`

必要熱量は

`Q = mcΔT = 300×4.18×45 = 56430 kJ`

ヒートポンプの供給熱率は

`COP·P = 4.0×1.5 = 6.0 kW = 6.0 kJ/s`

したがって

`t = 56430/6.0 = 9405 s`

`9405/3600 = 2.6125 h`

答え: 約`2.61 h`。

COPを熱効率70 %などと同じ形で扱わず、`Q_out=COP·P·t`から時間を逆算する。`kJ/kW`で得た時間は秒である点にも注意する。
