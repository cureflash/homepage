# 解説本文

## 1. このテーマで電験は何を問うか
このテーマの中心は機械科目の交流機である。本試験では、対称三相交流から回転磁界が生じる理由、極数・周波数・同期速度の関係、同期電動機の始動、同期発電機の並列運転が問われる。数値問題では `Ns=120f/p` と角速度換算を確実に使えること、知識問題では誘導機と同期機を混同しないことが重要である。

この章を終えた時点で、次を自力で処理できることを目標とする。

- 周波数と極数から同期速度を求める。
- 同期速度から周波数または極数を逆算する。
- `min^-1` を `rad/s` に換算する。
- 誘導電動機の滑りと同期電動機の同期運転を区別する。
- 三相の相順と回転方向の関係を判断する。
- 同期電動機の自己始動法を説明する。
- 同期発電機を並列するための条件と同期検定器の役割を説明する。

## 2. 対称三相交流と回転磁界
三相巻線を空間的に電気角120°ずつずらして配置し、時間的にも120°ずれた対称三相交流を流すと、合成磁束の向きが連続的に移動する。これが回転磁界である。磁石という物体が回っているのではなく、空間内の磁束分布の最大位置が移動していると考える。

三相電源の3線のうち任意の2線を入れ換えると相順が反転する。相順が反転すれば回転磁界の向きも逆転する。したがって、三相誘導電動機では2線を入れ換えることで回転方向を反転できる。

一相が断線すると、残る作用は単相の交番磁界として扱う。交番磁界は正転・逆転の回転磁界の合成として表せるが、停止状態では両方向の始動トルクが打ち消し合うため、自力で回転を開始できない。H25機械問3ではここが誤答判定点になる。

## 3. 磁極、電気角、機械角
極数 `p` はN極とS極を合わせた磁極の総数で、通常は偶数である。極対数は `p/2` なので混同しない。

隣接するN極とS極の間は電気角180°である。一方、機械角は極数で変わる。1回転の機械角360°に対して電気角は極対数だけ繰り返されるため、

`電気角 = (p/2) × 機械角`

となる。したがって4極機では、隣接N-S間の機械角は90°だが電気角は180°である。6極機では同じN-S間の機械角は60°になる。

## 4. 同期速度と同期角速度
交流1周期で回転磁界は電気角360°進む。極対数が多いほど、同じ電気角360°に対応する機械角は小さくなるため、極数が多い機械ほど同一周波数での回転磁界の速度は低くなる。

同期速度は

`Ns = 120 f / p`

で求める。

- `Ns`: 同期速度 `[min^-1]`
- `f`: 周波数 `[Hz]`
- `p`: 極数

逆算は

`f = p Ns / 120`

`p = 120 f / Ns`

である。周波数一定なら同期速度は極数に反比例し、極数一定なら同期速度は周波数に比例する。

角速度へ換算する場合は

`ωs = 2πNs / 60 = 4πf / p`

を使う。`min^-1` の値をそのまま `rad/s` として扱わない。

## 5. 同期機と誘導機の違い
誘導電動機では、回転磁界と回転子の間に相対速度がなければ回転子に誘導電流が生じず、誘導トルクも得られない。したがって通常運転では回転子速度 `N` は同期速度 `Ns` よりわずかに低い。

滑りは

`s = (Ns - N) / Ns`

である。例えば同期速度1500 min^-1、実回転速度1440 min^-1なら、

`s = (1500 - 1440) / 1500 = 0.04`

なので滑り4%である。

同期電動機は定常状態で回転子磁極が回転磁界に引き込まれ、回転子速度が同期速度と一致する。したがって定常時は `N=Ns` である。誘導機のようにトルク発生のための定常滑りを必要としない。

## 6. 同期電動機の自己始動と同期引込み
励磁した同期電動機を停止状態のまま三相交流電源へ接続すると、回転磁界に対して回転子磁極が受けるトルクの向きが交互に変わる。停止状態では平均トルクが零となるため、そのままでは自力始動できない。

自己始動法では回転子磁極面に制動巻線を設ける。この制動巻線をかご形誘導電動機の二次導体と同じように働かせ、始動時は誘導トルクで回転子を加速する。

始動時には回転磁束によって界磁巻線へ高電圧が誘導されるおそれがあるため、界磁巻線を抵抗で短絡しておく。回転速度が同期速度付近まで上昇したら短絡を外し、界磁巻線を直流で励磁する。すると回転子磁極が回転磁界へ引き込まれ、同期速度で回転する。

覚える順序は次の通りである。

1. 制動巻線を使う。
2. かご形誘導電動機と同じ原理で加速する。
3. 始動中は界磁巻線を抵抗で短絡する。
4. 同期速度付近で短絡を外す。
5. 直流励磁して同期へ引き込む。

## 7. 同期発電機の並列運転
2台の同期発電機を同じ母線へ並列する場合、本試験でまず確認する基本3条件は次である。

- 周波数が一致している。
- 電圧の大きさが一致している。
- 位相が一致している。

条件が一致していない状態で並列すると大きなじょう乱が生じる。同期検定器を使い、同期状態にあることを確認してから並列する。

ここで「周波数が同じ」は「回転速度が同じ」とは限らない。同期速度は `Ns=120f/p` なので、同じ周波数でも極数が異なれば必要な回転速度は異なる。R5下機械問6はこの点を数値で問う。

## 8. 問題を見たときの解法手順
1. 問題文から `f`、`p`、`N` の既知量を抜き出す。
2. 回転磁界・同期機・誘導機のどれを扱う問題か判定する。
3. 同期速度が必要なら `Ns=120f/p` を選ぶ。
4. 周波数または極数を問われたら式を目的変数について解く。
5. 角速度を問われたら `ωs=2πNs/60` へ換算する。
6. 誘導機なら `s=(Ns-N)/Ns` で実回転速度との差を扱う。
7. 同期機なら定常時 `N=Ns` を使う。
8. 並列運転なら周波数・電圧・位相の一致と同期検定器を確認する。
9. `Hz`、`min^-1`、`rad/s` の単位を確認する。
10. 極数が偶数であること、計算結果が周波数・極数との比例関係に合うことを検算する。

## 9. L0系への接続
JR東海の公式資料では、リニアモータは通常の回転モータを切り開いて直線状に展開したものとして説明される。Topic 22ではこの対応関係だけを使う。

- 回転機の固定子巻線 → 地上の推進コイル
- 回転機の回転子磁極 → 車上の超電導磁石
- 回転磁界 → 直線方向へ進む移動磁界
- 回転方向の電磁力 → 直線方向の推進力

地上の推進コイルへ電流を流してN極・S極を形成し、車上の超電導磁石との吸引・反発で推進する。同期機を直線状に展開したものとして理解すれば、回転同期機で学んだ「磁界と磁極の同期」という考え方をリニア同期モータへ接続できる。

ここではL0系の実際の極ピッチ、実運転周波数、500 km/h時の具体的な周波数計算は扱わない。それらはTopic 23の範囲である。

## 10. 頻出ミス・ひっかけ
- 極数 `p` と極対数 `p/2` を取り違える。
- 同期速度式を `60f/p` とする。
- `min^-1` をそのまま `rad/s` とする。
- 誘導電動機の実回転速度を同期速度と同一視する。
- 三相の2線入替えで回転方向が反転することを忘れる。
- 一相断線後も停止状態から自力始動できると考える。
- 同期電動機が界磁励磁だけで停止状態から自力始動できると考える。
- 同期発電機の並列条件で「回転速度そのもの」を周波数の代わりに選ぶ。
- 同期機の「同期」を単なる一定速度運転と理解する。

# 3段階例題

## 基礎例題: 同期速度と角速度
60 Hz、4極の同期電動機の同期速度 `Ns` と同期角速度 `ωs` を求める。

### 解法
同期速度は

`Ns = 120f/p`

なので、

`Ns = 120×60/4 = 1800 min^-1`

角速度は

`ωs = 2πNs/60`

より、

`ωs = 2π×1800/60 = 60π ≒ 188.5 rad/s`

### 答え
`Ns = 1800 min^-1`、`ωs ≒ 188.5 rad/s`。

### 検算
60 Hzの2極なら3600 min^-1なので、4極ではその半分の1800 min^-1となり妥当である。

## 本試験標準例題: 極数の異なる同期発電機
10極の同期発電機Aが600 min^-1で運転している。同じ母線へ8極の同期発電機Bを並列する。Bの同期速度を求める。

### 解法
まずAの周波数を求める。

`f = pNs/120 = 10×600/120 = 50 Hz`

同じ母線へ並列するBも50 Hzでなければならない。したがって、

`Ns,B = 120×50/8 = 750 min^-1`

### 答え
`750 min^-1`。

### 検算
同一周波数では同期速度は極数に反比例する。Aは10極600 min^-1、Bは8極なのでBの方が高速になる。750 min^-1はこの関係に合う。

## 複合・ひっかけ例題: 同期機と誘導機を区別する
60 Hz、6極の回転磁界を考える。同じ回転磁界で、同期電動機は定常運転し、誘導電動機は1164 min^-1で運転している。次を求める。

1. 回転磁界の同期速度。
2. 同期角速度。
3. 誘導電動機の滑り。
4. 同期電動機の定常回転速度。

### 解法
同期速度は

`Ns = 120×60/6 = 1200 min^-1`

同期角速度は

`ωs = 2π×1200/60 = 40π ≒ 125.7 rad/s`

誘導電動機の滑りは

`s = (1200-1164)/1200 = 36/1200 = 0.03`

よって3%。同期電動機は定常状態で回転磁界へ同期するため、

`N = Ns = 1200 min^-1`

である。

### 答え
1. `1200 min^-1`
2. `40π rad/s ≒ 125.7 rad/s`
3. `s=0.03 = 3%`
4. `1200 min^-1`

### ひっかけ確認
1164 min^-1を同期速度として使わない。これは誘導電動機の実回転速度であり、同期速度との差から滑りを求める。

## 基礎確認

### 問1
50 Hz、4極の同期機の同期速度 `[min^-1]` として正しいものはどれか。

1. 750
2. 1000
3. 1500
4. 1800
5. 3000

解答: 3

解説: `Ns=120f/p=120×50/4=1500 min^-1`。極数を極対数2と取り違えて計算しない。

### 問2
60 Hzの電源に接続された同期電動機が900 min^-1で同期運転している。この電動機の極数として正しいものはどれか。

1. 2
2. 4
3. 6
4. 8
5. 10

解答: 4

解説: `p=120f/Ns=120×60/900=8`。極数は8極である。

### 問3
6極の同期機が1000 min^-1で同期運転している。電源周波数 `[Hz]` はいくらか。

1. 25
2. 40
3. 50
4. 60
5. 75

解答: 3

解説: `f=pNs/120=6×1000/120=50 Hz`。

### 問4
50 Hz、4極の同期機の同期角速度として正しいものはどれか。

1. `25π rad/s`
2. `40π rad/s`
3. `50π rad/s`
4. `60π rad/s`
5. `100π rad/s`

解答: 3

解説: まず `Ns=1500 min^-1`。`ωs=2πNs/60=2π×1500/60=50π rad/s`。`1500 rad/s`ではない。

## 本試験標準

### 問5
同期速度1500 min^-1の回転磁界に対し、誘導電動機の回転子が1440 min^-1で回転している。滑りとして正しいものはどれか。

1. 0.02
2. 0.04
3. 0.06
4. 0.96
5. 1.04

解答: 2

解説: `s=(Ns-N)/Ns=(1500-1440)/1500=0.04`。4%である。

### 問6
対称三相交流で生じる回転磁界の回転方向を逆転させる方法として正しいものはどれか。

1. 三相すべての線を同じ位置へつなぎ直す。
2. 三相のうち任意の2線を入れ換える。
3. 周波数だけを半分にする。
4. 電圧だけを半分にする。
5. 極数だけを2倍にする。

解答: 2

解説: 任意の2線を入れ換えると相順が反転し、回転磁界の向きも反転する。周波数や極数の変更は速度に影響するが、相順反転そのものではない。

### 問7
4極機で隣接するN極とS極の間の機械角と電気角の組合せとして正しいものはどれか。

1. 機械角45°、電気角90°
2. 機械角90°、電気角90°
3. 機械角90°、電気角180°
4. 機械角180°、電気角180°
5. 機械角180°、電気角360°

解答: 3

解説: 4極機では極対数が2なので `電気角=2×機械角`。隣接N-S間は電気角180°だから、機械角は90°である。

### 問8
三相誘導電動機が停止している状態で三相電源の1線が断線した。回転磁界と始動について正しい記述はどれか。

1. 正常な三相回転磁界が残り、自力始動する。
2. 回転磁界の速度だけ半分になり、自力始動する。
3. 単相の交番磁界となり、停止状態からは自力始動できない。
4. 直流磁界となり、同期速度で始動する。
5. 磁界が完全に消滅する。

解答: 3

解説: 一相断線時は単相の交番磁界として扱う。交番磁界は正転・逆転の回転磁界の合成だが、停止状態では始動トルクが打ち消し合うため自力始動できない。

### 問9
回転界磁形同期電動機の自己始動法として正しい組合せはどれか。

1. 補償巻線―巻線形誘導電動機―固定子巻線を短絡―交流励磁
2. 制動巻線―かご形誘導電動機―界磁巻線を抵抗で短絡―同期速度付近で直流励磁
3. 制動巻線―同期発電機―固定子巻線を開放―交流励磁
4. 電機子巻線―かご形誘導電動機―界磁巻線を開放―直流励磁
5. 補償巻線―かご形誘導電動機―界磁巻線を抵抗で短絡―交流励磁

解答: 2

解説: 制動巻線をかご形誘導電動機の二次導体と同様に働かせて誘導トルクで加速する。始動中は界磁巻線を抵抗で短絡し、同期速度付近で短絡を外して直流励磁し、同期へ引き込む。

### 問10
2台の同期発電機を並列運転する際、本テーマで扱う基本3条件と確認器具の組合せとして正しいものはどれか。

1. 回転速度・力率・電流―電流計
2. 周波数・電圧の大きさ・位相―同期検定器
3. 周波数・有効電力・無効電力―電力計
4. 回転速度・電圧の大きさ・力率―速度計
5. 周波数・トルク・位相―周波数計

解答: 2

解説: 並列前に周波数、電圧の大きさ、位相を一致させ、同期検定器で同期状態を確認する。極数が異なる場合があるため、回転速度そのものの一致を条件として選ばない。

### 問11
10極の同期発電機が600 min^-1で運転している。同じ周波数の母線へ8極の同期発電機を並列する。8極機の回転速度 `[min^-1]` として正しいものはどれか。

1. 400
2. 550
3. 750
4. 950
5. 1200

解答: 3

解説: 10極機から `f=10×600/120=50 Hz`。8極機は `Ns=120×50/8=750 min^-1`。同一周波数では極数と同期速度が反比例する。

### 問12
誘導電動機と同期電動機の定常運転について正しい記述はどれか。

1. 誘導電動機も同期電動機も必ず `N=Ns` で回る。
2. 誘導電動機では通常 `N<Ns`、同期電動機では定常時 `N=Ns` である。
3. 誘導電動機では通常 `N>Ns`、同期電動機では `N<Ns` である。
4. 同期電動機だけが滑りを必要とする。
5. 誘導電動機では滑りは常に0である。

解答: 2

解説: 誘導電動機は回転磁界との相対速度によって誘導トルクを得るため、通常は同期速度より低速で回る。同期電動機は定常状態で回転磁界へ同期する。

## 複合・応用

### 問13
JR東海の超電導リニアを通常の回転モータとの対応で理解したとき、正しい組合せはどれか。

1. 車上超電導磁石＝固定子、地上推進コイル＝回転子
2. 車上超電導磁石＝回転子、地上推進コイル＝固定子
3. 車上超電導磁石＝整流子、地上推進コイル＝ブラシ
4. 車上超電導磁石＝制動抵抗、地上推進コイル＝界磁抵抗
5. 車上超電導磁石＝変圧器一次、地上推進コイル＝変圧器二次

解答: 2

解説: JR東海公式資料では、車上の超電導磁石が通常モータの回転子、地上の推進コイルが固定子に対応する。Topic 22ではこの構造対応までを扱う。

### 問14
リニア同期モータを回転同期機から概念的に展開した説明として最も適切なものはどれか。

1. 回転磁界を直線方向へ進む移動磁界として展開し、磁極との電磁力を直線推進力として利用する。
2. 回転磁界を静止磁界へ変え、摩擦だけで推進する。
3. 誘導電動機の滑りを常に1にして推進する。
4. 周波数を使わず直流だけで移動磁界を作る。
5. 回転子を機械的に車輪へ接続してのみ推進する。

解答: 1

解説: 回転同期機の回転磁界を直線方向の移動磁界へ展開し、車上磁石との吸引・反発を直線方向の推進力として利用する。本問では実際の極ピッチや運転周波数の数値は扱わない。

### 問15
60 Hz、6極の回転磁界があり、同じ磁界中で誘導電動機が1164 min^-1で運転している。同期速度、同期角速度、誘導電動機の滑りの組合せとして正しいものはどれか。

1. `600 min^-1`、`20π rad/s`、`0.03`
2. `1200 min^-1`、`20π rad/s`、`0.03`
3. `1200 min^-1`、`40π rad/s`、`0.03`
4. `1200 min^-1`、`40π rad/s`、`0.30`
5. `1800 min^-1`、`60π rad/s`、`0.03`

解答: 3

解説: `Ns=120×60/6=1200 min^-1`。`ωs=2π×1200/60=40π rad/s`。滑りは `s=(1200-1164)/1200=0.03`。三つの量を別々に計算してから組合せを選ぶ。
