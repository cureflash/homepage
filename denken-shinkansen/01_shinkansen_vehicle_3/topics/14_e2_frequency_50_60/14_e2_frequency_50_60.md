# 14 E2系 50Hz・60Hz対応

## EXAM_ALIGNMENT
資格: 第三種電気主任技術者
科目: 機械
論点: 周波数、誘導電動機の同期速度・すべり・二次周波数、V/f制御、変圧器の周波数と磁束

### 公式過去問
1. 令和6年度上期 / 機械 / 問4
   - 要求知識: V/f一定制御、同期速度、すべり、実回転速度
   - 使用式: `Ns=120f/p`, `n=(1-s)Ns`
   - 設問型: 五肢択一計算
   - 典型ミス: 66Hzと6極から同期速度だけを出して終わる、5%を5として代入する
2. 令和5年度下期 / 機械 / 問15
   - 要求知識: 60Hz時のすべり周波数、インバータ40Hz運転、一定すべり周波数
   - 使用式: `s=(Ns-n)/Ns`, `f2=s f1`, `Ns=120f/p`
   - 設問型: B問題・2段階計算
   - 典型ミス: 一次周波数と二次周波数の混同、周波数変更後に同期速度を再計算しない
3. 令和5年度上期 / 機械 / 問4
   - 要求知識: 同期速度、すべり、軸出力とトルク
   - 使用式: `Ns=120f/p`, `n=(1-s)Ns`, `T=P/(2πn/60)`
   - 設問型: 五肢択一計算
   - 典型ミス: 同期速度で軸トルクを計算する
4. 平成28年度 / 機械 / 問4
   - 要求知識: 50Hz・6極の同期速度、同期ワット（二次入力）
   - 使用式: `Ns=120f/p`, `P2=T(2πNs/60)`
   - 設問型: 五肢択一計算
   - 典型ミス: 実回転速度と同期角速度の取り違え
5. 令和6年度上期 / 機械 / 問3
   - 要求知識: 三相誘導機の回転磁界、すべり、電動機・発電機運転領域
   - 使用式/判定: `s=(Ns-n)/Ns` と速度関係
   - 設問型: 正誤選択
   - 典型ミス: 回転子構造、すべり符号、同期速度との大小関係の混同

正答の正本: 一般財団法人 電気技術者試験センター公式過去問題・公式解答。参照日: 2026-08-29。

## 教材で必要な説明
- `Ns=120f/p` の意味、極数と極対数の区別
- `s=(Ns-n)/Ns`, `n=(1-s)Ns`, `f2=s f1`
- 周波数変更時に同期速度を再計算する手順
- V/f一定と磁束の概念
- 変圧器 `E=4.44fNΦm` と50/60Hzの磁束関係
- 架線周波数とインバータ出力周波数の区別
- 同期速度・実速度・同期角速度を使う式の区別

## 新幹線実例
JR東日本公式「E2系 やまびこ／なすの」では、E2系0番代について、北陸新幹線の軽井沢付近に50/60Hzの異周波条件があり、両周波数で安定した性能を発揮する電気機器を採用したと説明されている。

一次資料:
- https://www.jreast.co.jp/train/shinkan/e2.html （参照日2026-08-29）

教材では、架線50/60Hzは主変圧器・主変換装置の入力条件であり、主電動機の駆動周波数は主変換装置が生成することを明確にする。公開資料で確認できない主変圧器巻数、実磁束密度、実インバータ周波数、異周波切替シーケンスは真値として扱わない。
