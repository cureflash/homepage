# 1. このテーマで電験は何を問うか
電験では、(1)どの極性で導通可能か、(2)いつゲートを与えるか、(3)いつ消弧するか、(4)導通区間の波形、(5)平均値・実効値・電力まで一つの問題として問われる。

# 2. 用語・物理的意味・単位
- サイリスタ: A-K間が順方向のときゲートでターンオンする電力用半導体。
- 自己保持: 一度ONすると保持電流以上ならゲートを除いても導通継続。
- 自然転流: 交流で主電流が零となり逆電圧が加わってターンオフ。
- 制御遅れ角 alpha [rad, deg]: 電源零点から点弧までの遅れ角。
- 平均直流電圧 Vd [V]: 整流波形の1周期平均。
- 実効値 Vrms [V]: 抵抗で同じ発熱を生む直流相当値。

# 3. 公式と成立条件
純抵抗負荷・単相全波サイリスタブリッジ、`v=Vm sinθ`、`0<=alpha<=pi` のとき、各半周期で `alpha` から `pi` まで導通する。
`Vd=(1/pi)∫[alpha->pi]Vm sinθ dθ=(Vm/pi)(1+cosalpha)=(sqrt(2)Vs/pi)(1+cosalpha)`。
alpha=0で最大、alpha=pi/2で半分、alpha=piで0。これはR負荷の式で、誘導性負荷では波形・平均値式が変わる場合がある。

# 4. 問題文から式を選ぶ解法手順
1. 素子を判定する。
2. 負荷をRのみかL含有か判定する。
3. 電源極性から導通候補対を決める。
4. サイリスタなら零点からalphaだけ待って点弧。
5. R負荷は電流零で自然消弧。L負荷は電流継続を確認。
6. 波形を描き、平均値か実効値かを確認。
7. 平均値は波形面積、実効値は二乗平均平方根。
8. alpha=0,90,180°など端点で検算。

# 5. 基礎例題
Vs=100 V、alpha=60°なら `Vm=141.4 V`、`Vd=(141.4/pi)(1+0.5)=67.5 V`。

# 6. 本試験標準例題
Vs=200 V、Vd=90.0 V。`90=(sqrt(2)*200/pi)(1+cosalpha)` より `cosalpha approx 0`、したがって `alpha approx 90°`。

# 7. 複合・ひっかけ例題
「ゲート信号を取り去れば直ちにOFF」は誤り。通常サイリスタは自己消弧能力を持たず、主電流が保持電流未満まで下がるなどの消弧条件が必要。

# 8. 200系新幹線への接続
日本車輌製造「新幹線車両の変遷」は200系の制御装置を「サイリスタ位相制御」と記載する。0系の低圧タップ制御から、半導体の点弧時刻で整流平均電圧を連続調整する方式へ進んだ。試験では「alphaを変える->平均直流電圧が変わる->直流主電動機の電機子電圧制御へつながる」と一般化する。
一次資料: https://www.n-sharyo.co.jp/business/tetsudo/shinkansen/tec-mechanism.html

# 9. 頻出ミス
VsとVm、deg/rad、平均値と実効値、R/L負荷の消弧時刻、正負半周期の導通ペアを取り違えない。

# 10. 調査過去問での出題パターン
H24問10: alpha-Vdグラフ。H28問16: 欠相波形＋平均値。H29問10: 素子特性。H29問16: R/L波形＋電力。R1問10: 導通組＋自然転流。

# 11. 公式・解法まとめ
`Vm=sqrt(2)Vs`
`Vd=(Vm/pi)(1+cosalpha)`（単相全波・R負荷）
サイリスタ: 順方向＋ゲートでON、通常ゲートだけではOFF不可。
R負荷: 点弧後、電源零点で電流も零となり自然消弧。
L負荷: 電流が遅れ、零点を越えて導通し得る。
