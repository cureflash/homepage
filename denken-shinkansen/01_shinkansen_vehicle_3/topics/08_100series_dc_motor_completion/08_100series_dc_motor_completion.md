# 1. このテーマで電験は何を問うか

直流機では、(A)構造・名称、(B)起電力・電流・トルク、(C)損失・効率、(D)整流・電機子反作用を別々に暗記しても本試験に弱い。問題文から「何が入力で、どこに損失が出て、どの現象が次の不具合を起こすか」を追えることが必要である。

# 2. 直流機の構造とエネルギー変換

界磁磁極・継鉄は基本的に固定子、電機子鉄心・電機子巻線・整流子は回転子、ブラシは静止側で整流子に接触する。電動機では電気→機械、発電機では機械→電気へエネルギー流が逆になるが、同じ電磁誘導・電磁力を利用する。

界磁方式は他励と自励に分かれ、自励には分巻・直巻・複巻がある。永久磁石機は界磁巻線を持たない。

# 3. 直流電動機の三式と成立条件

- 電動機の電圧式: `V = E + Ia Ra` [V]
- 逆起電力: `E = K φ n` [V]（磁束φが一定ならE∝n）
- トルク: `T = Kt φ Ia` [N·m]

V: 端子電圧、E: 逆起電力、Ia: 電機子電流、Ra: 電機子回路抵抗、φ: 1極磁束、n: 回転速度。

始動直後はn=0なのでE=0。したがって `Ia=V/Ra` となり、Raが小さい直流機では大きな始動電流が問題になる。これはH29問1型の最重要条件である。

# 4. 入力→損失→出力の電力フロー

問題文の損失条件を最初に読む。

`電気入力 Pin → 電機子銅損・界磁銅損 → 電磁変換電力 → 鉄損・機械損 → 軸出力 Pout`

分巻・他励では電機子入力と界磁入力を区別する場合がある。永久磁石機で「損失は電機子銅損のみ」と指定された場合、`Pout = Pin - Ia²Ra = E Ia` とできる。

# 5. 銅損・鉄損・機械損と発熱

- 銅損: `Pcu=I²R`。電流2倍で4倍。
- 鉄損: ヒステリシス損＋渦電流損。回転電機子鉄心は磁極下を通過し交番磁束を受けるため積層鉄心で渦電流を抑える。
- 機械損: 軸受摩擦、ブラシ摩擦、風損など。

損失は最終的に主として熱になる。効率計算と熱設計は同じ損失を別の観点から見ている。

# 6. 定格・温度上昇・冷却

定格は単に「壊れない最大値」ではない。規定条件で温度上昇、絶縁、整流などを許容範囲に保ちながら使用する基準である。連続運転では発生熱と放熱がつり合う定常温度へ近づく。電流増加によるI²R発熱を見落とさない。

# 7. 整流子・ブラシと整流

回転する電機子導体では起電力・電流の向きが位置に応じて変わる。整流子は外部端子から見た電流方向を機械的に切り替え、電動機ではトルクを同じ回転方向に保つ。ブラシは静止側から回転整流子へ電流を受け渡す摺動接点である。

# 8. 電機子反作用→中性軸→火花→対策

負荷電流が流れると電機子自身の磁界が主磁束をゆがめる。これが電機子反作用である。結果として電気的中性軸が移動し、ブラシ位置が適切でなくなると整流途中のコイルに不要な電圧が生じ、火花・整流子損傷の原因になる。

補極は整流帯の磁界を補い整流を改善する。補償巻線は主磁極下で電機子反作用を打ち消す。名称ではなく「どこで何を打ち消すか」で判定する。

# 9. 問題文から式・損失を選ぶ解法アルゴリズム

1. 電動機/発電機、界磁方式、永久磁石かを判定。
2. 始動か定常回転かを判定。始動ならE=0。
3. 与えられたV, Ia, Ra, n, φと無視できる損失を列挙。
4. 電圧式 `V=E+IaRa` でEまたはIaを求める。
5. 必要なら `E∝φn`, `T∝φIa` を使う。
6. 入力 `Pin`、銅損 `I²R`、その他損失を電力フローへ置く。
7. `Pout=Pin-Ploss`, `η=Pout/Pin` を計算。
8. 0<η<1、損失>0、始動時E=0などで検算。
9. 構造問題は「電機子反作用→中性軸→火花→補極/補償巻線」の因果をたどる。

# 10. 基礎例題

V=200 V、Ia=50 A、Ra=0.20 Ω、その他損失を無視する永久磁石直流電動機。

`E=200-50×0.20=190 V`  
`Pin=200×50=10.0 kW`  
`Pcu=50²×0.20=0.50 kW`  
`Pout=9.50 kW`  
`η=9.50/10.0=95.0%`

# 11. 本試験標準例題（H29型）

12 Vの永久磁石直流電動機が静止時4 A、定格運転時1 A。損失は電機子銅損のみ。

静止時E=0なので `Ra=12/4=3 Ω`。定格時 `E=12-1×3=9 V`。入力12 W、銅損3 W、出力9 W。よって `η=9/12=0.75=75%`。

式を暗記するより「始動時だけE=0」を見抜くことが核心である。

# 12. 複合・ひっかけ例題

仮定値: V=500 V、Ia=300 A、Ra=0.05 Ω、鉄損＋機械損=8.0 kW。これは100系実値ではない。

`Pin=150 kW`、`Pcu=300²×0.05=4.5 kW`、`Pout=150-4.5-8.0=137.5 kW`、`η=91.7%`。

「E Ia=145.5 kW」をそのまま軸出力とすると鉄損・機械損を落とす。問題文にどの損失が存在するかが公式選択を決める。

# 13. 100系実例と0系・200系比較

一次資料値として、日立資料は100系を4S-2P、連続定格出力1,840 kW×6/編成としている。ここから `1,840×6=11,040 kW=11.04 MW` は計算値であり、資料に「11.04 MW」と直接書かれた実値ではない。

制御方式は0系の低圧タップ制御、200系のサイリスタ位相制御、100系のサイリスタ連続位相制御へ進化した。一方、100系でも直流主電動機のブラシ・整流子という保守対象は残る。この「電力制御は高度化したが、直流機の摺動接点は残った」という点が300系の交流誘導機への接続になる。

# 14. ブラシ・整流子保守と300系への接続

鉄道総研資料で確認できる一般論として、直流主電動機はブラシ・整流子の摩擦・摩耗部の保守を必要とする。インバータ駆動誘導機では整流子・ブラシを不要にできる。100系固有の交換周期など公開確認できない値は扱わない。

# 15. 頻出ミス

- 始動時にもEがあるとする。
- `VI`を無条件に軸出力とする。
- 銅損と鉄損を混同する。
- 積層鉄心の目的を銅損低減とする。
- 電気的中性軸と幾何学的中性軸を混同。
- 補極と補償巻線を同じ役割とみなす。
- 分巻・直巻を他励式に分類する。
- 「定格=瞬間最大値」と考える。

# 17. 公式・解法まとめ

`V=E+IaRa`  
`E=Kφn`  
`T=KtφIa`  
`Pcu=I²R`  
`Pout=Pin-Ploss`  
`η=Pout/Pin×100[%]`

数値問題は「状態→電圧式→電力フロー→効率」、知識問題は「構造→原因→現象→対策」の順で解く。
