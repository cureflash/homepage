# 解説本文

## 1. このテーマで電験は何を問うか

このテーマでは、理論科目の電磁誘導・相互インダクタンスと、機械科目の交流電力変換・効率を扱う。本試験では、磁束変化から誘導起電力を求める計算、二つのコイルの結合係数、インダクタンスから交流リアクタンスを求める計算、整流器の電圧降下・導通損失、変圧器の鉄損・銅損と効率が問われる。

この章を終えた時点で、次を自力で処理できることを目標とする。

- `e=-N dΦ/dt` から誘導起電力を求め、レンツの法則で向きを説明する。
- `M=k√(L1L2)` と和動接続 `L_0=L_1+L_2+2M` を使い、`M` と `k` を逆算する。
- 非接触給電を「交流→時間変化する磁界→誘導起電力→電力」という流れで説明する。
- `X_L=2πfL` を使い、`mH` を `H` へ換算して交流リアクタンスを求める。
- 問題文で与えられた三相ダイオード整流式を読み、リアクタンス・順電圧降下・導通損失を計算する。
- `η=P_out/P_in`、鉄損・銅損、`P_c=x^2P_cN` を使って負荷変化時の効率を求める。
- L0系の誘導集電を、一次資料で確認できた範囲だけで電験一般論へ接続する。

## 2. ファラデーの法則とレンツの法則

コイル1巻を貫く磁束を `Φ [Wb]`、巻数を `N` とすると、誘導起電力は

`e = -N dΦ/dt`

で表される。一定時間 `Δt` の間に磁束が `ΔΦ` だけ変化する問題では、大きさを

`|e| = N|ΔΦ|/Δt`

として計算できる。

マイナス符号は、誘導起電力が元の磁束変化を妨げる向きに生じることを示す。これがレンツの法則である。大きさだけを問う問題では絶対値で計算し、向きを問う場合は「元の磁束が増えているか、減っているか」を先に判定する。

非接触給電では、送る側の電流を時間変化させることで磁界が時間変化し、受ける側のコイルを貫く磁束も変化する。この磁束変化が受電側コイルの誘導起電力になる。導体同士を接触させなくても電力を受け取れる入口が、この電磁誘導である。

## 3. 相互誘導・相互インダクタンス・結合係数

一方のコイルの電流が変化すると、そのコイルが作る磁束も変化する。その磁束の一部が別のコイルと鎖交すると、別のコイルに誘導起電力が生じる。これを相互誘導という。

コイル1の電流 `i_1` の変化によってコイル2に生じる起電力は、相互インダクタンス `M [H]` を用いて

`e_2 = -M di_1/dt`

と表せる。

二つのコイルの自己インダクタンスを `L_1, L_2`、結合係数を `k` とすると、

`M = k√(L_1L_2)`

である。`k` は磁気的な結合の強さを表す無次元量で、電験の計算では `M` と `L_1, L_2` から逆算させる問題がある。

選定過去問で必要な和動接続では、二つのコイルを直列につないだ合成インダクタンス `L_0` は

`L_0 = L_1 + L_2 + 2M`

となる。したがって、合成インダクタンスが与えられたときは

`M = (L_0-L_1-L_2)/2`

`k = M/√(L_1L_2)`

の順で求めればよい。

## 4. 非接触給電とL0系の誘導集電

非接触給電の基本的な流れは次のとおりである。

`送電側の交流 → 時間変化する磁界 → 受電側コイルの磁束変化 → 誘導起電力 → 受電側の電力`

電気的な接点を直接つながなくても、磁界を介して受電側へ電力を渡せる。ここで重要なのは、磁界が存在するだけではなく、受電側コイルを貫く磁束が時間変化することである。

JR東海は、超電導リニアで架線・パンタグラフによる接触給電ではなく、電磁誘導を応用した非接触の誘導集電を採用すると説明している。また、地上側コイルの電流で磁界を作り、電磁誘導によって車両側コイルに電気を生じさせる方式として説明している。

L0系改良型試験車では誘導集電方式を全面採用し、従来の先頭車に搭載していたガスタービンを搭載しない。国土交通省の実用技術評価委員会は2011年9月13日、誘導集電について車上電源として実用化に必要な技術が確立していると評価した。

この教材では、実機のコイル寸法、周波数、定格電力、電圧・電流、伝送効率の具体値を置かない。今回確認した一次資料からそれらの値を確定できないためである。

## 5. 交流リアクタンス `X_L=2πfL`

インダクタンス `L [H]` をもつコイルに周波数 `f [Hz]` の交流を流すとき、誘導性リアクタンスは

`X_L = 2πfL`

で表され、単位は `Ω` である。周波数 `f` またはインダクタンス `L` が大きくなるほど `X_L` も大きくなる。

計算では単位換算を先に行う。例えば `0.60 mH` は

`0.60×10^-3 H`

である。`mH` の数値をそのまま式へ代入すると1000倍の誤差になる。

選定したR7下機械問16では、交流側リアクタンスによる転流の影響が直流出力電圧の低下項として式に入る。ここで `X_L` を求めるために `2πfL` が必要になる。リアクタンスそのものを抵抗損失と同一視せず、問題文で与えられた式の各項が何を表すかを分けて読む。

## 6. 三相ダイオード整流と電力変換

交流から直流へ電力を変換する代表的な回路として三相ダイオード整流回路がある。Topic 25では、R7下機械問16で与えられた次の式を読めることを目標にする。

`V_d = (3√2/π)V_L - (3/π)X_LI_d - 2V_F`

ここで、

- `V_d`: 直流側平均電圧 `[V]`
- `V_L`: 交流側線間電圧の実効値 `[V]`
- `X_L`: 交流側リアクタンス `[Ω]`
- `I_d`: 直流電流 `[A]`
- `V_F`: ダイオード1個の順電圧降下 `[V]`

である。

第1項は理想的な整流による直流平均電圧、第2項は選定問題で扱う交流リアクタンス・転流による電圧低下、第3項は同時に導通する2個のダイオードの順電圧降下を表す。これは選定問題の条件で使う与式であり、L0系の実機回路がこの構成であるとは断定しない。

同じ選定問題の条件では、1個のダイオードが1周期の `1/3` だけ電流 `I_d` を導通し、順電圧降下を `V_F` とみなすと、1素子当たりの平均導通損失は

`P_D = V_F I_d/3`

となる。式を暗記するより、`瞬時の導通損失 V_FI_d × 導通率1/3` と分解すると再構成しやすい。

### 三相整流問題の解法手順

1. `f` と `L` の単位を確認し、`X_L=2πfL` を求める。
2. 問題文の整流電圧式へ `V_L, X_L, I_d, V_F` を代入する。
3. 理想電圧、リアクタンスによる低下、ダイオードによる低下を別々に計算する。
4. 導通損失は、問題文の導通期間・導通率を確認して平均化する。
5. 最後に単位が `V` または `W` になっているか確認する。

## 7. 効率・鉄損・銅損・負荷率

効率は、入力電力のうちどれだけが有効な出力になったかを表す。

`η = P_out/P_in`

損失 `P_loss` を使えば

`P_in = P_out + P_loss`

なので

`η = P_out/(P_out+P_loss)`

と書ける。

変圧器の電験問題では、損失を鉄損 `P_i` と銅損 `P_c` に分ける。

`η = P_out/(P_out+P_i+P_c)`

固定された電圧・周波数条件で扱う典型問題では鉄損を一定として扱い、銅損は電流の二乗に比例する。定格電流に対する負荷率を `x`、定格負荷時の銅損を `P_cN` とすると、

`P_c = x^2P_cN`

である。

定格容量を `S [VA]`、負荷率を `x`、負荷力率を `cosφ` とすると、出力有効電力は問題条件に従って

`P_out = xS cosφ`

と置ける。同じ全負荷電流なら銅損は同じでも、力率が下がると有効出力は小さくなるため、効率も変化する。`kVA` をそのまま `kW` として扱わず、力率を確認する。

### 効率の短い計算例

定格容量 `20 kVA` の変圧器を全負荷、力率 `0.8` で運転し、鉄損 `150 W`、全負荷銅損 `250 W` とする。

`P_out = 20×0.8 = 16 kW`

`η = 16000/(16000+150+250)`

`≈0.9756 = 97.56%`

負荷率が `0.5` なら銅損は `0.5^2×250=62.5 W` になる。負荷率を半分にしたから銅損も半分、としてはいけない。

## 8. 過去問を解くための手順

### 8.1 電磁誘導・相互インダクタンス

1. 磁束変化から起電力を求めるのか、二つのコイルの結合を求めるのかを判定する。
2. 磁束変化なら `|e|=N|ΔΦ|/Δt` を使う。
3. 和動接続の合成インダクタンスが与えられたら `M=(L_0-L_1-L_2)/2` を使う。
4. `k=M/√(L_1L_2)` で結合係数を求める。
5. `H, mH` などインダクタンスの単位をそろえてから計算する。

### 8.2 交流・整流

1. `mH` を `H` へ換算する。
2. `X_L=2πfL` を計算する。
3. 問題文に与えられた整流式の各項を分けて計算する。
4. 電圧降下項の符号を確認する。
5. 導通損失は導通率を掛けて平均化する。

### 8.3 効率

1. 定格容量、負荷率、力率から `P_out` を求める。
2. 鉄損を確認する。
3. 定格銅損から負荷時銅損 `x^2P_cN` を求める。
4. `η=P_out/(P_out+P_i+P_c)` へ代入する。
5. 最後に百分率へ変換し、`kVA` と `kW` を混同していないか確認する。

## 9. 3段階例題

### 9.1 基礎例題 — ファラデーの法則

40巻のコイルを貫く1巻当たりの磁束が、`0.030 s` の間に `0.012 Wb` から `0.006 Wb` へ一様に減少した。誘導起電力の大きさを求める。

磁束変化量の大きさは

`|ΔΦ| = |0.006-0.012| = 0.006 Wb`

なので、

`|e| = N|ΔΦ|/Δt`

`= 40×0.006/0.030`

`= 8.0 V`

答えは `8.0 V`。向きを問われた場合は、減少する元の磁束を保とうとする向きに誘導起電力が生じる。

### 9.2 本試験標準例題 — 相互インダクタンスと結合係数

自己インダクタンス `L_1=50 mH`、`L_2=18 mH` の二つのコイルを和動直列接続したところ、合成インダクタンスが `L_0=116 mH` であった。相互インダクタンス `M` と結合係数 `k` を求める。

和動接続なので

`L_0=L_1+L_2+2M`

より、

`M=(116-50-18)/2=24 mH`

次に、

`k=M/√(L_1L_2)`

`=24/√(50×18)`

`=24/30`

`=0.80`

したがって、`M=24 mH`、`k=0.80`。`M` を求めずに `k` へ直接進まないこと、各インダクタンスの単位をそろえることがポイントである。

### 9.3 複合・ひっかけ例題 — 三相整流の電圧と導通損失

三相ダイオード整流回路について、次の条件が与えられている。

- 線間電圧 `V_L=200 V`
- 周波数 `f=50 Hz`
- 交流側インダクタンス `L=0.60 mH`
- 直流電流 `I_d=30 A`
- ダイオード順電圧降下 `V_F=1.0 V`
- 直流平均電圧は `V_d=(3√2/π)V_L-(3/π)X_LI_d-2V_F`
- 各ダイオードは1周期の `1/3` 導通する

まず `L` を `H` へ直す。

`L=0.60×10^-3 H`

したがって、

`X_L=2πfL`

`=2π×50×0.60×10^-3`

`≈0.1885 Ω`

理想整流電圧は

`(3√2/π)×200 ≈270.1 V`

リアクタンスによる低下は

`(3/π)×0.1885×30 ≈5.40 V`

ダイオード順電圧降下は

`2V_F=2.0 V`

よって、

`V_d≈270.1-5.40-2.0=262.7 V`

1個のダイオードの平均導通損失は

`P_D=V_FI_d/3`

`=1.0×30/3=10 W`

答えは `V_d≈262.7 V`、1素子当たり `10 W`。`0.60 mH` を `0.60 H` と誤って代入しないこと、`2V_F` と1素子損失の導通率 `1/3` を混同しないことがひっかけになる。

## 10. プラレールからL0系までの駆動・給電方式

この系列で既に扱った内容を、駆動と給電の違いが分かるように整理する。

| 段階 | 電力を受ける・持つ方法 | 駆動までの主な流れ |
|---|---|---|
| プラレール | 車上の乾電池 | 直流電源 → 直流モータ → ギヤ → 車輪 |
| 0系・直流電動機世代 | 架線からパンタグラフで受電 | 交流受電 → 主変圧器 → 整流・制御 → 直流主電動機 |
| 300系以降のVVVF・誘導電動機世代 | 架線からパンタグラフで受電 | 交流受電 → 電力変換 → VVVFインバータ → 三相誘導電動機 |
| L0系 | 車上電源は電磁誘導を応用した非接触の誘導集電 | 推進はリニア同期モータ、車上電源は誘導集電で非接触に受電 |

ここでL0系の「誘導集電」は車上電源の話であり、推進用リニア同期モータの速度制御そのものとは区別する。L0系の推進についてはTopic 22・23で扱った範囲にとどめ、このTopicでは新しい制御方式を追加しない。

## 11. 頻出ミス・ひっかけ

- ファラデーの法則で巻数 `N` を落とす。
- レンツの法則のマイナス符号を、単なる「数値が負になる」という意味で扱う。
- `M=k√(L_1L_2)` で `mH` と `H` を混在させる。
- 和動接続の `+2M` を落とす。
- `X_L=2πfL` で `mH` を `H` へ直さない。
- 三相整流の与式を使う問題で、リアクタンスによる電圧低下項や `2V_F` を落とす。

- `η=P_out/P_in` の分子・分母を逆にする。
- `kVA` をそのまま `kW` とみなし、力率を落とす。
- 負荷率 `x` のとき銅損を `xP_cN` とする。正しくは `x^2P_cN`。

## 13. 公式・解法まとめ

- ファラデーの法則: `e=-N dΦ/dt`
- 有限時間の大きさ: `|e|=N|ΔΦ|/Δt`
- 相互誘導: `e_2=-M di_1/dt`
- 相互インダクタンス: `M=k√(L_1L_2)`
- 和動接続: `L_0=L_1+L_2+2M`
- 逆算: `M=(L_0-L_1-L_2)/2`
- 誘導性リアクタンス: `X_L=2πfL`
- 選定問題の三相整流式: `V_d=(3√2/π)V_L-(3/π)X_LI_d-2V_F`
- 選定問題の1素子平均導通損失: `P_D=V_FI_d/3`
- 効率: `η=P_out/P_in=P_out/(P_out+P_loss)`
- 変圧器型問題: `η=P_out/(P_out+P_i+P_c)`
- 負荷率 `x` の銅損: `P_c=x^2P_cN`
- 非接触給電は `交流 → 時間変化する磁界 → 受電側の磁束変化 → 誘導起電力 → 電力` の順で理解する。
- 実車値は一次資料で確認できたものだけを使用し、未確認値は置かない。
