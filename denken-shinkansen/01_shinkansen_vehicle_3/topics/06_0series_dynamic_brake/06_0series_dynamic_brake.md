# 06 0系④ 発電ブレーキ

## この章の目的

この章の主目的は、0系のブレーキ装置を紹介することではない。

第三種電気主任技術者試験「機械」で問われる、直流機の電動機運転と発電機運転の切替え、発電制動・回生制動・逆転制動の区別、電機子電流とトルクの向き、制動抵抗でのジュール損、運動エネルギーから電気・熱へのエネルギー変換を、0系新幹線の発電ブレーキを実例として理解し、初見の同型問題を解けるようにすることを目的とする。

# 過去問から逆算した必須説明

## 1. 直流機は電動機にも発電機にもなる

同じ直流機でも、機械エネルギーを受けて電気エネルギーを出すと発電機、電気エネルギーを受けて機械エネルギーを出すと電動機として働く。

磁束 `phi` と回転方向が一定なら、誘導起電力の極性は回転方向と磁束方向で決まり、電動機運転から発電運転へ移るだけで自動的に反転するわけではない。

## 2. `E` と `V` の大小で電力の向きを読む

単純化した他励・永久磁石界磁直流機では、電動機運転時に

```text
V = E + Ia Ra
Ia = (V-E)/Ra
```

となる。

`V > E` なら電源から直流機へ電流が入り、電動機として機械出力を生む。

一方、同じ極性で `E > V` となれば、

```text
Ia = (V-E)/Ra < 0
```

となり、電機子電流が反転して直流機から外部回路へ電力を送り出す発電運転となる。

## 3. トルク方向

直流機の電磁トルクは

```text
T = K phi Ia
```

で表される。

磁束方向が一定なら、電機子電流が反転するとトルク方向も反転する。したがって走行方向と逆向きのトルクを発生させれば制動になる。

## 4. 三つの電気制動を区別する

### 発電制動

直流機を発電機として働かせ、発生した電力を制動抵抗へ流し、ジュール熱として消費する。

```text
運動エネルギー → 電気エネルギー → 抵抗の熱
```

### 回生制動

直流機を発電機として働かせ、発生電力を電源・架線側へ返す。

```text
運動エネルギー → 電気エネルギー → 電源側
```

### 逆転制動

電動機の回転方向と逆向きの電磁トルクを強制的に発生させる。電源からもエネルギーを受けるため、発電制動・回生制動とはエネルギーの扱いが異なる。

## 5. 制動抵抗

抵抗 `R` に電流 `I` が流れると、

```text
P_R = I^2 R = VI = V^2/R
```

の電力が熱になる。

一定電力 `P` が時間 `t` 続くと発生熱量は

```text
Q = Pt
```

である。

制動抵抗問題では、電流・抵抗・電圧・時間のどれが与えられたかを見て式を選ぶ。

## 6. 運動エネルギー

列車の並進運動を単純化すれば

```text
Ek = 1/2 m v^2
```

である。

速度を `v1` から `v2` へ落とすときに失われる運動エネルギーは

```text
Delta Ek = 1/2 m (v1^2 - v2^2)
```

である。

発電制動では、このうち電気制動へ回った分が最終的に抵抗で熱になる。効率 `eta` を仮定する場合は

```text
Q_R = eta Delta Ek
```

とし、機械損・電気損を別途扱う場合は問題条件に従う。

## 7. 制動力と制動出力

速度 `v` で制動力 `F` が作用するとき、瞬時の制動出力は

```text
P = Fv
```

である。

車輪軸では

```text
P = T omega
```

とも表せる。

同じ制動出力でも速度が下がると必要な力・トルクとの関係が変わることを確認する。

## 8. チョッパ回生

直流チョッパではスイッチング素子のオン・オフ時間から平均電圧を制御する。

電動機運転と回生運転では、電流経路と有効なスイッチング素子が異なる。問題ではまず

1. 電力が電源→機械か、機械→電源か
2. 電機子電流の向き
3. どのスイッチがオン・オフ制御されるか
4. 1周期とオン時間からデューティ比を求める

の順で読む。

# 本試験で使う解法アルゴリズム

```text
1. 電動機運転か発電運転かを判定する
2. E と V の大小を確認する
3. 電機子電流の向きを決める
4. T = K phi Ia でトルク方向を確認する
5. 発電制動 / 回生制動 / 逆転制動のどれかを判定する
6. 抵抗へ流すなら P=I^2R、Q=Pt を使う
7. 車両の速度変化なら Delta Ek=1/2 m(v1^2-v2^2) を使う
8. 必要なら効率を掛ける
9. エネルギー収支と単位で検算する
10. 選択肢と照合する
```

# 頻出ミス

- 発電制動と回生制動を同じものと考える。
- 発電運転に移ると `E` の極性そのものが必ず反転すると考える。
- 電機子電流が反転してもトルク方向は同じと考える。
- 制動抵抗の電力に機械出力を無条件でそのまま代入する。
- km/hをm/sへ直さず運動エネルギーを計算する。
- 速度が半分なら運動エネルギーも半分と考える。実際は `v^2` に比例する。
- 回生制動で発生電力が抵抗ですべて熱になると考える。
- 発電制動で電力を架線へ返していると考える。
