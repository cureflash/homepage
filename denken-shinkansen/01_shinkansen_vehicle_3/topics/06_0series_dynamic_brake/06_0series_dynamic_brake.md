## この章のゴール

0系を題材に、直流機の電動機運転と発電機運転、発電制動・回生制動・逆転制動、制動抵抗、運動エネルギー、制動力と電力、チョッパ回生を本試験へ転用できる形で学ぶ。

重要なのは車両史ではなく、問題文から次の順で判断できることである。

1. 磁束方向と回転方向から起電力 `E` の極性を固定する。
2. 外部電圧 `V` と `E` の大小から電機子電流 `Ia` の向きを決める。
3. `T = Kt φ Ia` から電磁トルクの向きを決める。
4. 発電した電力の行先が抵抗か電源かを判定する。
5. 必要なら `P=I²R`、`Q=Pt`、`Ek=1/2 mv²`、`P=Fv`、`P=Tω` へ進む。

# 1. このテーマで電験は何を問うか

「モーターが発電機になる」という用語説明だけでは本試験は解けない。電験では、直流機の電圧式・トルク式を使い、電流方向、トルク方向、電力方向を判定させる。また、発電電力を抵抗で熱にする発電制動と、電源へ返す回生制動を区別させる。近年型ではチョッパのデューティ比と平均電圧を組み合わせる。

# 2. 用語・物理的意味・単位

- 逆起電力 `E [V]`: 回転する電機子に生じる起電力。`E = Ke φ n`。
- 電機子電流 `Ia [A]`: 力行・発電の判定で向きが重要。
- 電磁トルク `T [N·m]`: `T = Kt φ Ia`。磁束一定なら電流方向が変わるとトルク方向も変わる。
- 発電制動: 発電した電力を制動抵抗で熱へ変える。
- 回生制動: 発電した電力を電源側へ返す。
- 逆転制動: 接続を切り替え、回転方向と逆のトルクを発生させる。電源からもエネルギーを消費し得る。

# 3. 公式と成立条件

単純な他励・永久磁石界磁直流機では、磁束一定近似のもとで

`E = Ke φ n`

`V = E + Ia Ra`  （電動機運転の符号）

`T = Kt φ Ia`

を使う。

発電制動で電源から切り離し、電機子抵抗 `Ra` と制動抵抗 `Rb` の閉回路を作る単純モデルなら

`Ia = E / (Ra + Rb)`

となる。抵抗損失は

`P = I²R = VI = V²/R`

一定電力を時間 `t` だけ吸収すると

`Q = Pt`

列車の運動エネルギーは

`Ek = 1/2 mv²`

速度 `v1` から `v2` への減速で

`ΔEk = 1/2 m(v1²-v2²)`

直線運動・回転運動では

`P = Fv`

`P = Tω`

を使う。

チョッパの理想化では

`Tsw = 1/f`

降圧側 `Vout = D Vin`

昇圧側 `Vout = Vin/(1-D)`

を使う。回路トポロジと問題文の定義を確認せず式だけ適用してはいけない。

# 4. 問題文から式を選ぶ解法手順

1. 界磁方式と磁束方向を確認する。
2. 回転方向を確認し、`E` の極性を固定する。
3. 外部電圧と `E` の大小を比較する。
4. `Ia` の向きを決める。
5. `T=KtφIa` で電磁トルクが駆動か制動かを判断する。
6. 電気エネルギーの行先を確認し、発電制動・回生制動・逆転制動を分類する。
7. 数値問題なら抵抗熱、運動エネルギー、`P=Fv`、`P=Tω`、チョッパ式へ進む。
8. 電力・エネルギー保存と単位で検算する。

# 5. 基礎例題

制動抵抗 `R=0.50 Ω` に `I=200 A` が10秒流れたとする。

`P = I²R = 200²×0.50 = 20 kW`

`Q = Pt = 20 kW×10 s = 200 kJ`

これは教材計算用の仮定値であり、0系実車の抵抗値・電流ではない。

# 6. 本試験標準例題

R7上機械問16型として、`Vin=200 V`、`f=500 Hz`、力行時平均電圧150 Vを考える。

`Tsw = 1/500 = 2.0 ms`

`D = 150/200 = 0.75`

`Ton = 0.75×2.0 = 1.50 ms`

回生側でON時間0.4 msなら `D=0.4/2.0=0.20`。昇圧関係を使い電源側200 Vなら

`200 = Vmotor/(1-0.20)`

`Vmotor = 160 V`

となる。

# 7. 複合・ひっかけ例題

永久磁石直流機が同じ磁束方向・同じ回転方向のまま力行から回生へ移ったとする。このとき「発電機運転だから `E` の極性が反転する」は誤り。`E` の極性は磁束方向と回転方向で決まる。回生では回路条件により電流方向が変わり、それによりトルク方向が反転して制動トルクになる。

# 8. 新幹線実例

日本車輌製造の0系資料では、0系は低圧タップ切換方式で直流主電動機を制御し、発電ブレーキを常用したこと、低速域では摩擦ブレーキへ受け渡すことが確認できる。

一次資料:  
https://www.n-sharyo.co.jp/business/tetsudo/shinkansen/tec0.html

直流機では `E=Keφn` なので速度低下とともに起電力も下がる。同じ回路条件では制動電流・制動トルクを確保しにくくなるため、低速域で摩擦ブレーキへ受け渡すという実車の挙動を、逆起電力の速度依存と結び付けて理解する。

公開されていない0系の制動抵抗値、実運転電流、詳細内部回路値は真値化しない。

# 9. 頻出ミス

- 発電機運転へ移ると `E` の極性が自動的に反転すると考える。
- 電流方向とトルク方向を別々に暗記し、`T=KtφIa`でつながない。
- 発電制動と回生制動を同義扱いする。
- `P` [W] と `Q` [J] を混同する。
- km/hをm/sへ直さず `P=Fv` に入れる。
- 運動エネルギーが速度の二乗に比例することを忘れる。
- チョッパで周期 `1/f` とON時間を混同する。
- 昇圧・降圧の式を回路確認なしに使う。

- H27問2: 分巻直流機の電動/発電切替と回生条件。
- R4上問1: 始動・速度制御・逆転・回生制動をまとめて穴埋め。

# 11. 公式・解法まとめ

`E = Keφn`

`V = E + IaRa`

`T = KtφIa`

`P = I²R`, `Q = Pt`

`Ek = 1/2 mv²`

`P = Fv`, `P = Tω`

`Tsw=1/f`, 降圧 `Vout=D Vin`, 昇圧 `Vout=Vin/(1-D)`

判定順は `Eの極性 → Vとの大小 → Ia方向 → T方向 → エネルギーの行先`。
