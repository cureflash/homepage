# 06 0系④ 発電ブレーキ

# モーターが発電機に変わる瞬間――0系の発電ブレーキから電気制動を理解する

## この章のゴール

0系は力行時には直流主電動機で車輪を回し、減速時には同じ主電動機を発電機として使う発電ブレーキを常用した。

この章では「発電ブレーキ＝モーターを発電機にする」という一文で終わらせない。

**列車が惰性でモーターを回す → 回転速度に応じた逆起電力が生じる → 回路を制動側へ切り替える → 電機子電流の向きが力行時と変わる → 電磁トルクが進行方向と逆向きになる → 運動エネルギーが電気へ変換される → その電気を抵抗で熱にするか、電源へ戻す**

というエネルギーの流れで理解する。

最終的には電験三種「機械」の次に対応する。

- 電動機運転と発電機運転
- `V`, `E`, `Ia` の大小関係
- 電流方向とトルク方向
- 発電制動・回生制動・逆転制動の違い
- 制動抵抗の電力・熱量
- 運動エネルギー
- `P=Fv`, `P=Tω`
- チョッパ回生
- 速度低下で電気ブレーキが弱くなる理由

# 1. 電動機と発電機は別物ではない

直流機では、磁束中で電機子が回転すれば起電力

`E = Ke φ n`

が生じる。

力行中でもこの起電力は存在する。

力行時には外部電源電圧 `V` が逆起電力 `E` より高く、

`Ia = (V-E)/Ra`

によって電源から電動機へ電流が流れる。

その電流によって

`T = Kt φ Ia`

の電磁トルクが生じ、車輪を回す。

一方、列車の運動によって電動機軸が回され、回路条件を変えて発電側へ電流を流せば、同じ直流機が発電機として働く。

機械が交換されたのではない。

**エネルギーの流れる向きが逆になった**のである。

---

# 2. 力行と制動は「電流の向き」で見分ける

単純な他励・永久磁石界磁直流機で、磁束方向と回転方向が一定とする。

力行側では

`V > E`

なので

`Ia = (V-E)/Ra > 0`

となり、電源→電動機へ電力が流れる。

発電・回生側では外部回路条件によって

`E > V_external`

となれば、電流は力行時と逆向きに流れる。

磁束方向が同じなら

`T = Kt φ Ia`

より電磁トルクの向きも逆になる。

この逆向きトルクが制動トルクになる。

つまり制動問題では、

1. `E` の極性
2. 外部電圧との大小
3. `Ia` の方向
4. `T` の方向

を順番に判断する。

---

# 3. 発電機運転になったからといって、起電力の極性が勝手に反転するわけではない

ここは本試験で狙われやすい。

誘導起電力の極性は、

- 磁束方向
- 回転方向

で決まる。

運転モードを「電動機」から「発電機」と呼び替えただけで、`E` の極性が自動的に反転するわけではない。

回路接続と外部電圧の関係によって電流方向が変わり、その結果として電磁トルクの向きが変わる。

---

# 4. 発電制動・回生制動・逆転制動の違いは「電力の行先」で覚える

## 4.1 発電制動

列車の運動エネルギーを電気へ変換し、その電気を制動抵抗で熱として消費する。

`運動エネルギー → 電気エネルギー → ジュール熱`

## 4.2 回生制動

列車の運動エネルギーを電気へ変換し、架線・電源側へ戻す。

`運動エネルギー → 電気エネルギー → 電源側`

## 4.3 逆転制動

電機子接続などを切り替え、電源電圧と起電力が大きな電流を流す向きに作用させ、回転方向と逆向きのトルクを作る。

制動は強いが、列車の運動エネルギーだけでなく電源からのエネルギーも消費する。

したがって三方式は名称ではなく、

**運動エネルギーが最後に抵抗へ行くのか、電源へ戻るのか、さらに電源からもエネルギーを使うのか**

で判定する。

# 5. 0系の発電ブレーキは「抵抗へ捨てる」方式

日本車輌製造の0系主要諸元では、発電ブレーキと電磁直通空気ブレーキが確認できる。

同資料では、発電ブレーキを常用し、低速域では摩擦ブレーキへ切り替えて停止する構成が説明されている。

初期仕様ではおおむね50 km/h以下で摩擦ブレーキへ切替、22次車では発電ブレーキ下限速度が50 km/hから30 km/hへ変更されたことも記録されている。

これは電気制動の物理と関係する。

逆起電力は

`E = Ke φ n`

なので、回転速度が低下すると `E` も小さくなる。

発電機として取り出せる電圧が低くなれば、同じ回路条件では制動電流と制動トルクを確保しにくくなる。

そのため低速になるほど電気ブレーキだけで停止まで持っていくのが難しくなり、摩擦ブレーキへ受け渡す必要がある。

0系の低速切替は、単なる制御仕様ではなく**逆起電力が速度に比例する直流機の性質**と結び付いている。

---

# 6. なぜ発電するとブレーキになるのか

発電時には、車輪が主電動機を回している。

主電動機が電気エネルギーを外へ出すには、機械側からエネルギーを受け取らなければならない。

そのため回転を妨げる方向の電磁トルクが発生する。

エネルギー保存で考えると、

`列車の運動エネルギー減少 = 発電された電気エネルギー + 損失`

である。

発電制動では発電電力が抵抗器へ流れ、熱になる。

電気を作っているからブレーキが掛かるのではない。

**列車の運動エネルギーを電気へ持ち去るため、その分だけ列車が減速する。**

---

# 7. 制動抵抗では何が起きるか

抵抗へ電流 `I` が流れると、

`P = I²R`

の電力が熱へ変換される。

抵抗両端電圧 `V_R` が分かるなら

`P = V_R I = V_R²/R`

でもよい。

一定電力を時間 `t` だけ吸収すると、熱エネルギーは

`Q = Pt`

である。

### 例

制動抵抗へ200 Aが流れ、抵抗値0.50 Ωなら

`P = 200²×0.50 = 20 kW`

10秒継続すれば

`Q = 20 kW×10 s = 200 kJ`

となる。

実際の0系の抵抗値を示す計算ではなく、一般的な電験計算例である。

---

# 8. 列車側から見ると、運動エネルギーを減らしている

質量 `m`、速度 `v` の列車の運動エネルギーは

`Ek = 1/2 mv²`

である。

速度 `v1` から `v2` へ減速すると、失われた運動エネルギーは

`ΔEk = 1/2 m(v1²-v2²)`

である。

この一部が電気エネルギーへ変換され、残りは機械損・電気損などになる。

速度は二乗で効く。

したがって高速域では列車が持つ運動エネルギーが非常に大きい。

例えば同じ質量なら、速度が2倍になると運動エネルギーは4倍になる。

高速鉄道で電気制動が重要になる理由の一つである。

---

# 9. 制動力・電力・速度をつなぐ

直線運動では

`P = Fv`

である。

したがって同じ制動電力 `P` なら

`F = P/v`

となる。

逆に、同じ制動力を高速域で維持するには大きな制動電力が必要になる。

回転軸側では

`P = Tω`

である。

車輪半径 `r` について

`v=rω`

`T=Fr`

なので

`Tω = Frω = Fv`

となる。

つまりモーター軸の制動トルクと、列車側の制動力は同じ機械電力を別の座標で見ているだけである。

---

# 10. 発電ブレーキ時の運転点

発電制動では主電動機の起電力 `E` が速度に比例する。

磁束一定なら

`E ∝ n`

である。

制動抵抗を含む回路を単純化して

`I ≒ E/R_total`

と考えると、

`I ∝ n`

となる。

さらに

`T ∝ φI`

なので磁束一定なら

`T ∝ n`

となる傾向がある。

つまり速度が下がるほど起電力・電流・制動トルクが下がりやすい。

実車では回路切換や制御によって広い速度域で必要な制動力を確保するが、基礎物理として「低速では発電制動が弱くなりやすい」ことは重要である。

0系の発電ブレーキ下限速度が存在する理由を、この式で説明できる。

---

# 11. 発電制動と回生制動は何が違うのか

両方とも主電動機を発電側で使う点は同じである。

違うのは発生した電力の行先である。

発電制動:

`主電動機 → 制動抵抗 → 熱`

回生制動:

`主電動機 → 電力変換装置 → 架線・電源`

0系は基本的に発電ブレーキであり、後世の交流電動機・電力変換装置を使う新幹線では回生ブレーキが一般化していく。

したがって0系の発電ブレーキは、後の300系などの回生ブレーキを理解するための比較対象になる。

---

# 12. 回生するには「電源側へ押し返せる条件」が必要

回生制動は、発電機が電圧を作るだけでは成立しない。

電源側へ電力を送り返すためには、電力変換装置と回路条件によって電源方向へ電流を流す必要がある。

直流系を単純化すれば、発電側の起電力や昇圧動作によって外部電圧を上回る条件を作る。

チョッパ回生では、インダクタへ一度エネルギーを蓄え、スイッチOFF時に電源側へ放出することで昇圧的に電力を返すことができる。

この考え方が電験のチョッパ回生問題へつながる。

---

# 13. チョッパ回生を「スイッチの暗記」にしない

チョッパ問題では、まず

`D = ton/T`

のデューティ比を求める。

しかし力行側の `Vavg=DVs` を回生側へそのまま当てはめるのではなく、必ず各ON/OFF区間の電流経路を確認する。

見るべきものは、

- ON時にインダクタへエネルギーを蓄えるのか
- OFF時にどこへエネルギーを放出するのか
- 電源へ戻る電流経路があるか

である。

回生問題は公式暗記より**エネルギーがどこへ流れるか**を追う方が強い。

---

# 14. 発電ブレーキから停止まで

0系では高速・中速域で発電ブレーキを使い、低速では摩擦ブレーキへ移る。

電気ブレーキだけで完全停止すると考えると、速度0では

`E = Keφn = 0`

となり、発電するための起電力がなくなる。

したがって最終停止には別の制動手段が必要である。

この事実を式で説明できれば、0系のブレーキ構成は「そういう仕様だから」ではなくなる。

---

# 15. 電験での解法アルゴリズム

1. 力行・発電制動・回生・逆転制動のどれか判定する。
2. エネルギーの流れを矢印で書く。
3. `E` と外部電圧の大小から電流方向を判断する。
4. `T=KφIa` でトルク方向を判断する。
5. 抵抗なら `I²R`、列車なら `1/2mv²`、力なら `Fv`、軸なら `Tω` を選ぶ。
6. 速度低下に伴う `E` の低下を考える。
7. チョッパならON/OFFごとの電流経路を描く。
8. 最後に「電力がどこへ行ったか」で検算する。

---

# 16. 頻出ミス

- 発電制動と回生制動を同じものとする。
- 発電機運転になった瞬間に起電力極性まで反転すると考える。
- 電流方向だけ反転したのにトルク方向を確認しない。
- `I²R` のRが制動回路全体か個別抵抗か確認しない。
- km/hをm/sへ直さず `1/2mv²` に入れる。
- 速度0でも逆起電力が残ると考える。
- チョッパ回生を力行側公式だけで処理する。

---

# 17. 公式まとめ

逆起電力:

`E = Ke φ n`

電機子電流の基本:

`Ia = (V-E)/Ra`

トルク:

`T = Kt φ Ia`

抵抗電力:

`P = I²R = VI = V²/R`

熱量:

`Q = Pt`

運動エネルギー:

`Ek = 1/2 mv²`

制動で失う運動エネルギー:

`ΔEk = 1/2 m(v1²-v2²)`

機械電力:

`P = Fv = Tω`

デューティ比:

`D = ton/T`
