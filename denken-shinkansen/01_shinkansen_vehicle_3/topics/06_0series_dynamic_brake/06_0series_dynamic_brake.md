# 1. 電動機運転と発電機運転

同じ直流機は、電気→機械なら電動機、機械→電気なら発電機として働く。磁束と回転方向が同じなら、運転モードが変わるだけで誘導起電力の極性が自動反転するわけではない。

# 2. EとVで電流方向を判定する

単純化した他励・永久磁石界磁直流機では

`V = E + IaRa`, `Ia = (V-E)/Ra`

- `V > E`: `Ia > 0`、電源→直流機、電動機運転
- `E > V`: `Ia < 0`、直流機→外部、発電/回生方向

ここで `V` は端子電圧[V]、`E` は誘導起電力[V]、`Ia` は電機子電流[A]、`Ra` は電機子抵抗[Ω]。

# 3. トルク方向

`T = KφIa`

磁束 `φ` が一定なら、電機子電流の反転により電磁トルクも反転する。走行方向と逆の電磁トルクが制動トルクになる。

# 4. 三つの電気制動

- 発電制動: 運動エネルギー→電気→制動抵抗の熱。
- 回生制動: 運動エネルギー→電気→電源/架線側へ返送。
- 逆転制動: 電源も使って回転方向と逆の電磁トルクを作る。上二つとエネルギー収支が異なる。

名称だけでなく「電力が最後にどこへ行くか」で判定する。

# 5. 制動抵抗・熱量

`P = I^2R = VI = V^2/R`

一定電力なら `Q = Pt`。

問題文から与えられた量を確認して、余計な式を使わず選択する。

# 6. 運動エネルギー

`Ek = 1/2 mv^2`

速度 `v1` から `v2` へ減速すると

`ΔEk = 1/2 m(v1^2-v2^2)`

電気制動へ変換される割合を `η` とする学習モデルでは `Q = ηΔEk`。実車の損失配分は問題条件または一次資料がない限り仮定しない。

# 7. 制動力・軸出力

直線運動: `P = Fv`
回転軸: `P = Tω`

速度、力、トルクのどの量を求めるかで使い分ける。

# 8. チョッパ回生

スイッチング周期 `T` とオン時間 `ton` からデューティ比 `D=ton/T` を得る。理想降圧チョッパの力行側では平均電圧 `Vavg = DVs`。回生側は問題図の電流経路を読み、電源へ電力が戻る区間とインダクタ/電機子側の電圧関係を立てる。

R7上問16型では `f=500 Hz` なので `T=2.0 ms`。平均150 Vを200 V電源から得る力行では `D=0.75`, `ton=1.5 ms`。回生側でスイッチON 0.4 ms、OFF 1.6 msの条件から、教材で示した理想的な昇圧回生関係を使うと電動機側電圧160 Vとなる。

# 9. 解法アルゴリズム

1. 求めるものが電流、トルク、電力、熱量、エネルギー、デューティ比のどれか確認。
2. 電力の向き（電源→機械 / 機械→抵抗 / 機械→電源）を図示。
3. 直流機なら `E` と `V` を比較し `Ia` の符号を決める。
4. `T=KφIa` でトルク方向を確認。
5. 抵抗なら `I²R`、運動なら `1/2mv²`、力なら `Fv`、軸なら `Tω` を選ぶ。
6. チョッパなら周期→オン/オフ時間→電流経路→平均電圧の順で処理。
7. 単位とエネルギーの行先で検算。

# 11. 0系新幹線への接続

日本車輌製造の0系主要諸元では、交流25 kV受電、主変圧器・主シリコン整流器・直流主電動機を使用し、発電ブレーキと電磁直通空気ブレーキを備える。発電ブレーキを常用し、低速域では摩擦ブレーキへ切り替える構成が一次資料で確認できる。

一次公開資料で確認できない制動抵抗値、詳細制動電流、内部電圧、速度別制動力は実値として扱わない。教材中の数値は一般化した学習用条件であり、0系実車値ではない。

# 12. 頻出ミス

- 発電制動と回生制動を同義扱いする。
- 発電運転へ変わると誘導起電力の極性まで必ず反転すると考える。
- `E>V` なのに電源→機械方向の電流として計算する。
- `Ia` が反転したのにトルク方向を変えない。
- km/hをm/sへ変換せず `1/2mv²` に入れる。
- `I²R` と `V²/R` の電圧がどの抵抗両端電圧か確認しない。
- チョッパの力行/回生スイッチを図を読まず丸暗記する。
