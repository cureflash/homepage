## 解説本文

### §1 このテーマで電験は何を問うか

Topic 32は機械科目の自動制御・情報処理を中心に扱う。本試験では、ブロック線図から閉ループ伝達関数を求める問題、一次遅れ系の周波数応答とボード線図、P・I・D各動作の性質、AND・OR・NOTを含む論理式とタイムチャート、シーケンス制御とインタロックの識別が問われる。

この章で必要なのは、ATC固有の機器名を暗記することではない。`目標と現在値を比較する → 必要な制御量を決める → 出力結果を検出して戻す` というフィードバック制御の骨格と、`複数条件を論理演算で判定する` という情報処理の骨格を、一般問題へ転用できる形で理解することである。

### §2 ATCの速度制御を一般的な制御系として見る

JRTTの公開説明では、ATCは地上から受けた速度信号より列車速度が高い場合、自動的にブレーキをかけ、速度信号以下へ制御する。また新しい方式では、先行列車位置の情報を車上へ送り、自列車位置と先行列車との間隔に応じて速度を制御し、停止パターンを用いる方式が示されている。

この関係を電験の一般的な制御用語へ置き換えると、概念的には次の流れになる。

`許容速度・速度パターン → 比較・照査 → ブレーキ側の制御出力 → 列車速度 → 速度検出 → 比較・照査へ戻る`

ここで実際のATC内部回路、具体的な検出器、制御周期、減速度、しきい値を仮定しない。上の流れは電験のフィードバック制御を理解するための対応付けである。

### §3 フィードバック制御の基本量

一般的な負帰還系では、目標値を `R`、出力を `C`、前向き伝達関数を `G`、フィードバック伝達関数を `H`、偏差を `E` とする。

`E = R - HC`

`C = GE`

なので、

`C = G(R - HC)`

`C + GHC = GR`

`C(1 + GH) = GR`

したがって閉ループ伝達関数は

`C/R = G/(1 + GH)`

となる。負帰還では分母が `1+GH` になることが重要である。

ATCへの概念的な対応では、速度検出値がフィードバック量に相当し、許容速度または速度パターンとの比較が照査に相当する。ただし、ここから実車の制御器構成や伝達関数を推定してはいけない。

### §4 ブロック線図の整理

ブロック線図問題では、図を見たまま暗算せず、直列・並列・フィードバックに分解する。

- 直列: `G1G2`
- 並列加算: `G1+G2`
- 並列減算: `G1-G2`
- 負帰還: `G/(1+GH)`

分岐点では同じ信号が枝分かれし、加え合わせ点では各入力の符号を必ず確認する。複雑な図でも、内部信号を `x`、`e` などと置いて信号関係式を書くと確実に整理できる。

試験では、図形的にブロックを移動するより、`各信号 = 入力 × 伝達関数` と `加え合わせ点の式` を順に立てる方が符号ミスを防ぎやすい。

### §5 固定過去問型の伝達関数導出

固定過去問で必要な型として、誤差を

`e = R - x`

積分枝を

`x = e/(jωT2)`

出力を

`C = x + (T1/T2)e`

とする。

まず `e=R-x` に `x=e/(jωT2)` を代入する。

`e = R - e/(jωT2)`

両辺を整理すると、

`e/R = jωT2/(1+jωT2)`

また、

`x/R = 1/(1+jωT2)`

である。したがって、

`C/R = x/R + (T1/T2)(e/R)`

`= 1/(1+jωT2) + jωT1/(1+jωT2)`

`= (1+jωT1)/(1+jωT2)`

となる。重要なのは結果を暗記することではなく、内部信号を置き、加え合わせ点から連立することである。

### §6 一次遅れ系と周波数応答

一次遅れ系を

`W(jω) = K/(1+jωT)`

とする。`K` は低周波側の利得、`T [s]` は時定数、`ω [rad/s]` は角周波数である。

振幅は

`|W(jω)| = K/sqrt(1+(ωT)^2)`

で、利得をdBで表すと

`20log10|W(jω)|`

となる。低周波側では `ωT << 1` なので `|W| ≈ K`、したがって低周波利得は

`20log10K [dB]`

である。折点角周波数は

`ωc = 1/T`

で、折点より十分高い領域では利得線図の傾きは `-20 dB/dec` となる。

ボード線図問題は、`K → 低周波利得`、`T → 折点角周波数`、`一次遅れ → 折点後 -20 dB/dec` の順で読む。

### §7 P・I・D各動作

制御偏差を `e(t)` とすると、P・I・Dの基本的な作用は次のように整理できる。

- P動作: 現在の偏差に比例して操作量を変える。
- I動作: 偏差を時間積分し、偏差が残り続けることに反応する。固定過去問では定常特性の改善と結び付ける。
- D動作: 偏差の変化速度に反応する。固定過去問では過渡特性の改善と結び付ける。

代表的な形は

`u(t)=Kp e(t)+Ki∫e(t)dt+Kd de(t)/dt`

である。ただし本Topicでは、この式を使ったPID調整法、安定余裕、実車ATCの制御定数には進まない。また、新幹線ATCがこのPID式をそのまま用いると断定しない。ここでは固定過去問を解くための一般的な自動制御知識として扱う。

### §8 速度検出・速度照査・ブレーキ指令

速度検出は、現在の列車速度を制御側へ返す役割として捉える。速度照査は、その現在速度と許容速度または速度パターンを比較し、条件を満たしているかを判断する処理である。

JRTTが説明する速度信号方式では、列車速度が地上から受けた速度信号より高い場合、自動的にブレーキをかけて速度信号以下へ制御する。新しい方式では、先行列車位置情報と自列車位置から速度を制御し、停止パターンを用いる。

ここで試験の一般知識へ接続するポイントは、`検出 → 比較 → 制御出力 → 制御対象 → 再検出` の循環である。実車の速度検出方式、照査しきい値、ブレーキ段、減速度、応答時間は確認値なしに置かない。

### §9 AND・OR・NOT

論理回路では、0を偽、1を真として扱う。

| A | B | `A AND B` | `A OR B` |
|---:|---:|---:|---:|
| 0 | 0 | 0 | 0 |
| 0 | 1 | 0 | 1 |
| 1 | 0 | 0 | 1 |
| 1 | 1 | 1 | 1 |

NOTは入力を反転する。

| A | `NOT A` |
|---:|---:|
| 0 | 1 |
| 1 | 0 |

ANDは「両方成立」、ORは「少なくとも一方成立」、NOTは「成立/不成立の反転」と読む。論理式ではANDを積 `A·B`、ORを和 `A+B` と表すことがある。

### §10 論理式とタイムチャート

固定過去問型の論理式

`X = A·C + B·NOT(C)`

は、`C` の値で先に場合分けすると速い。

`C=0` のとき、`NOT(C)=1` なので

`X = A·0 + B·1 = B`

`C=1` のとき、`NOT(C)=0` なので

`X = A·1 + B·0 = A`

したがってこの式は、`C=0` ではB、`C=1` ではAを出力する形として追跡できる。

タイムチャート問題では、時間区間ごとに `A,B,C` の0/1を表にし、その区間ごとに論理式を計算する。入力変化点をまたいで一度に判断しない。

### §11 シーケンス制御・インタロック・フェイルセーフ

シーケンス制御は、あらかじめ定めた条件や順序に従って動作を進める制御である。フィードバック制御は、出力を検出して目標との差へ戻し、連続的または逐次的に制御量を調整する。両者を混同しない。

インタロックは、同時に成立すると危険または不都合な動作を、条件によって成立させないための考え方である。試験ではリレーや論理回路の条件として現れる。

鉄道信号ではフェイルセーフが重要である。本Topicでは「故障が起きても危険側へ移行させない」という一般原則までを扱う。どの故障時に新幹線ATCのどの接点がどの状態になるかなど、公開資料で確認していない具体回路は作らない。

### §12 本試験での解法アルゴリズムと頻出ミス

ブロック線図問題は次の順で解く。

1. 入力、出力、内部信号を記号で置く。
2. 各ブロックについて `出力=伝達関数×入力` を書く。
3. 加え合わせ点の `+/-` をそのまま式にする。
4. 内部信号を消去して `C/R` を求める。
5. 負帰還なら分母の符号が `1+GH` になることを確認する。

一次遅れ・ボード線図問題は、`K` と `T` を読み取り、`20log10K` と `ωc=1/T` を先に求める。Hzとrad/sを勝手に同一視しない。

PID問題は、Iを定常特性、Dを過渡特性と結び付ける。論理回路問題は、NOTを先に処理し、必要なら制御入力で場合分けする。タイムチャートは入力が変化する時刻ごとに区切る。

ATCとの接続では、一般制御理論を実車内部構成そのものだと読み替えないことが最重要の範囲境界である。

### §13 基礎例題 — 一次遅れ系の折点と低周波利得

一次遅れ系

`W(jω)=8/(1+j0.25ω)`

について、低周波利得と折点角周波数を求める。

`K=8`、`T=0.25 s` なので、

`20log10K = 20log10(8) ≈ 18.1 dB`

`ωc = 1/T = 1/0.25 = 4 rad/s`

答え: 低周波利得 `約18.1 dB`、折点角周波数 `4 rad/s`。折点より高い領域では一次遅れなので利得線図は `-20 dB/dec` で低下する。

### §14 本試験標準例題 — 内部信号から伝達関数を求める

ブロック線図から次の関係が得られたとする。

`e=R-x`

`x=e/(jωT2)`

`C=x+(T1/T2)e`

`C/R` を求める。

まず、

`e=R-e/(jωT2)`

より

`e/R=jωT2/(1+jωT2)`

また、

`x/R=1/(1+jωT2)`

したがって、

`C/R = x/R + (T1/T2)(e/R)`

`= 1/(1+jωT2) + jωT1/(1+jωT2)`

`= (1+jωT1)/(1+jωT2)`

答え: `C/R=(1+jωT1)/(1+jωT2)`。

この型は、複雑なブロック線図でも内部信号を式にして消去すれば解けることを示している。

### §15 複合・ひっかけ例題 — 論理式とシーケンス判断

次の論理式を考える。

`X=A·C+B·NOT(C)`

時間区間1では `(A,B,C)=(1,0,0)`、時間区間2では `(0,1,0)`、時間区間3では `(1,0,1)` とする。各区間の `X` を求める。また、この論理式が実際の新幹線ATC内部回路を示すか答える。

`C=0` では `X=B` なので、

- 区間1: `X=0`
- 区間2: `X=1`

`C=1` では `X=A` なので、

- 区間3: `X=1`

よって出力は `0 → 1 → 1`。

この式は固定過去問を解くための一般的な論理回路例であり、実際の新幹線ATC内部論理式だとは扱わない。ここを混同しないことが、本Topicの範囲上の重要なひっかけである。
