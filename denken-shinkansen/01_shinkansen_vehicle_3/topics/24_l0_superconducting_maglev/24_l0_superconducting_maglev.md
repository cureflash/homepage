# 解説本文

## 1. このテーマで電験は何を問うか

このテーマの中心は、理論科目の磁界・電磁誘導・電磁力である。機械科目では、磁界中を導体が動くときの誘導起電力も問われる。本試験では、導体形状に応じた磁界式の選択、磁界の向きと重ね合わせ、磁束変化から誘導起電力を求める計算、運動起電力、電流に働く力の方向判定が出題される。

この章を終えた時点で、次を自力で処理できることを目標とする。

- `H` と `B` を区別する。
- 点磁極、直線導体、円形コイル、円弧電流の式を形状から選ぶ。
- 磁界の向きを決め、同方向なら加算、逆方向なら減算する。
- `e=-N dΦ/dt` から誘導起電力の大きさと向きを判断する。
- `e=Blv` を使う条件を判断し、回転運動では周速度へ変換する。
- `F=BIl sinθ` から力の大きさを求め、磁界と電流から向きを判断する。
- L0系の浮上・案内を、磁界・電磁誘導・電磁力の流れとして説明する。

## 2. 磁界 `H` と磁束密度 `B`

磁界の強さ `H` の単位は `A/m`、磁束密度 `B` の単位は `T` である。両者は媒質の透磁率 `μ` を使って

`B = μH`

で結ばれる。空気中では通常 `μ≈μ0` として扱う。

電験では、問題文が `H` を求めているのか `B` を求めているのかを最初に確認する。`H` の式で値を求めた後、`T` を答える必要があるなら `B=μH` へ変換する。単位が `A/m` と `T` で異なることが最も基本的な確認点である。

複数の磁界があるときは重ね合わせる。同じ向きなら大きさを加え、逆向きなら差を取る。数値だけを足すのではなく、先に各磁界の向きを決める。

## 3. 形状ごとの磁界式

### 3.1 点磁極

磁極の強さを `m`、磁極からの距離を `r` とすると、空気中で点磁極が作る磁界の強さは

`H = m / (4πμ0 r^2)`

で表される。距離が2倍になると `H` は1/4になる。N極から出る向き、S極へ入る向きを基準に、観測点での向きを決める。

この式を使う問題では、各磁極から観測点までの距離を別々に求め、各磁界の向きを決めてから合成する。

### 3.2 無限長直線導体

電流 `I` が流れる十分長い直線導体から距離 `r` の点では

`H = I / (2πr)`

となる。向きは右ねじの法則で決める。親指を電流方向に向けたとき、指が巻く向きが磁界の向きである。

### 3.3 一巻円形コイル

半径 `r` の一巻円形コイルの中心では

`H = I / (2r)`

となる。同じ `I` と `r` でも直線導体の式とは係数が違うため、導体形状を見て式を選ぶ。

### 3.4 円弧電流

半径 `r`、中心角 `θ` [rad] の円弧に電流 `I` が流れるとき、円弧中心の磁界は

`H = Iθ / (4πr)`

となる。半円なら `θ=π`、1/4円なら `θ=π/2` を代入する。中心を通る放射状の直線部分は、各微小部分の電流方向と中心への位置ベクトルが平行になるため、中心の磁界への寄与は0となる。

## 4. ファラデーの法則とレンツの法則

コイル1巻を貫く磁束を `Φ` [Wb]、巻数を `N` とすると、誘導起電力は

`e = -N dΦ/dt`

で表される。一定時間 `Δt` の間に磁束が `ΔΦ` だけ変化する問題では、大きさを

`|e| = N |ΔΦ| / Δt`

として計算できる。

マイナス符号は「磁束変化を妨げる向きに起電力が生じる」というレンツの法則を表す。数値計算で起電力の大きさだけを問う場合は絶対値を使い、向きを問う場合は「元の磁束が増えているか、減っているか」を先に判定する。

回路が閉じていれば誘導起電力によって誘導電流が流れる。その誘導電流が作る磁界は、元の磁束の変化を妨げる向きになる。

## 5. 運動起電力 `e=Blv`

長さ `l` の導体が磁束密度 `B` の一様磁界を速度 `v` で横切り、導体・速度・磁界が互いに直交する場合、導体に生じる運動起電力の大きさは

`e = Blv`

である。

回転する導体では、まず回転速度を導体の周速度へ直す。直径 `D` [m]、回転速度 `n` [min^-1] なら

`v = πDn / 60`

である。1巻コイルの両側に同じ大きさの起電力が直列に加わる構成なら、1本分の `Blv` を求めた後に有効導体数を掛ける。

`e=Blv` を使う前に、磁界と速度が直交しているか、`l` が磁界中にある有効導体長かを確認する。

## 6. 磁界中の電流に働く力

磁束密度 `B` の磁界中に、長さ `l` の導体を置き、電流 `I` を流す。磁界と電流のなす角を `θ` とすると、導体に働く電磁力の大きさは

`F = BIl sinθ`

である。直交すると `sinθ=1` なので `F=BIl`、平行なら `sinθ=0` なので力は0になる。

方向問題では次の順に処理する。

1. 電流が作る磁界の向きを右ねじの法則で決める。
2. 外部磁界または相手導体が作る磁界の向きを決める。
3. 電流方向と磁界方向から力の向きを決める。

平行な2本の導体では、電流が同方向なら互いに引き合い、逆方向なら反発する。暗記だけでなく、一方の導体が作る磁界中にもう一方の導体が置かれていると考えると方向を再構成できる。

## 7. 過去問を解くための手順

### 7.1 磁界計算

1. 求める量が `H` か `B` か確認する。
2. 導体または磁極の形状を確認する。
3. 対応する式を選ぶ。
4. 各磁界の向きを決める。
5. 同方向は加算、逆方向は減算する。
6. 必要なら `B=μH` で変換する。

### 7.2 電磁誘導

1. 磁束が時間変化する問題か、導体が磁界を横切る問題かを判定する。
2. 磁束変化なら `|e|=N|ΔΦ|/Δt`、運動なら条件を確認して `e=Blv` を使う。
3. 回転運動なら `v=πDn/60` へ変換する。
4. 巻数・有効導体数を確認する。
5. 向きを問う場合はレンツの法則で判定する。

### 7.3 電磁力

1. `B, I, l, θ` を抜き出す。
2. `F=BIl sinθ` で大きさを求める。
3. 向きは電流と磁界の向きから判定する。
4. 平行導体なら、同方向電流は引力、逆方向電流は反発で検算する。

## 8. 3段階例題

### 8.1 基礎例題 — 直線導体の磁界

空気中で十分長い直線導体に `I=10 A` が流れている。導体から `r=0.20 m` の点の磁界の強さ `H` を求める。

直線導体なので

`H = I/(2πr)`

を使う。

`H = 10 / (2π×0.20) ≈ 7.96 A/m`

答えは約 `7.96 A/m`。`B` を問われていないので `μ0` を掛ける必要はない。

### 8.2 本試験標準例題 — ファラデーの法則

20巻のコイルを貫く1巻当たりの磁束が、`0.030 s` の間に `0.018 Wb` から `0.006 Wb` へ一様に減少した。誘導起電力の大きさを求める。

磁束変化量の大きさは

`|ΔΦ| = |0.006-0.018| = 0.012 Wb`

なので

`|e| = N|ΔΦ|/Δt`

`= 20×0.012/0.030`

`= 8.0 V`

答えは `8.0 V`。向きを問う場合は、減少する元の磁束を保とうとする向きに誘導電流が流れる。

### 8.3 複合・ひっかけ例題 — 回転導体の運動起電力

直径 `D=0.40 m` の回転子が `n=1200 min^-1` で回転している。磁束密度 `B=0.25 T` の一様磁界中に、磁界と速度に直交する有効長 `l=0.30 m` の導体がある。1巻コイルの2本の有効導体に生じる起電力が直列加算されるとき、1巻の起電力を求める。

まず周速度を求める。

`v = πDn/60`

`= π×0.40×1200/60`

`≈25.13 m/s`

導体1本の起電力は

`e1 = Blv`

`=0.25×0.30×25.13`

`≈1.885 V`

2本の有効導体が直列加算されるため

`e = 2e1 ≈3.77 V`

答えは約 `3.77 V`。回転速度 `1200 min^-1` をそのまま `v` に代入しないこと、有効導体が2本あることがひっかけになる。

## 9. L0系の超電導磁気浮上へ接続する

### 9.1 超電導磁石

JR東海は、車上の超電導磁石にニオブチタン合金を使い、液体ヘリウムで約-269℃まで冷却して超電導状態を保つと説明している。超電導状態では電気抵抗がゼロとなり、電流を流し続けて強い磁石として利用できる。

このテーマでは超電導材料の詳細な臨界条件へ広げず、「強い車上磁界を作る超電導磁石」として、磁界・電磁誘導・電磁力へ接続する。

### 9.2 浮上

ガイドウェイ両側には浮上・案内コイルがある。車上の超電導磁石が高速でコイルの前を通過すると、コイルを貫く磁束が変化する。これはファラデーの法則に対応し、コイルに誘導起電力が生じる。閉回路では誘導電流が流れ、その電流によりコイルが電磁石として働く。

JR東海の説明では、この磁気作用によって車両を押し上げる力と引き上げる力が生じ、車両の自重と磁力が釣り合う位置で安定して浮上する。浮上高は10 cmである。浮上・案内コイルへ浮上用の外部電力を供給する必要はない。

電験の流れに直すと、

`超電導磁石の移動 → コイルの磁束変化 → 誘導起電力 → 誘導電流 → 磁界 → 電磁力`

となる。

### 9.3 案内

車両がガイドウェイ中央から片側へずれると、左右の超電導磁石と浮上・案内コイルの位置関係が変わる。JR東海は、遠ざかった側に吸引力、近づいた側に反発力が働き、車両を中央へ戻す力が生じると説明している。

ここでも試験上の中心は「磁界中の電流に力が働く」「磁界と電流の向きで力の向きが決まる」という一般原理である。実車固有のコイル電流値や磁束密度を推測して計算しない。

## 10. 頻出ミス・ひっかけ

- `H [A/m]` と `B [T]` を混同する。
- 直線導体、円形コイル、円弧電流で同じ式を使う。
- 円弧角 `θ` を度のまま式へ入れる。`θ` はradで扱う。
- 磁界の大きさだけ計算し、向きを確認せず足し算する。
- ファラデーの法則で巻数 `N` を落とす。
- レンツの法則のマイナス符号を、単なる「答えが負」と誤解する。
- `e=Blv` に回転速度 `min^-1` を直接入れる。先に `m/s` の周速度へ直す。
- 1巻コイルで有効導体が複数あるのに、1本分の起電力で終える。
- `F=BIl` を常に使い、角度がある場合の `sinθ` を落とす。
- L0系の説明で、一次資料にない磁束密度・コイル電流・寸法を実値として置く。

## 12. 公式・解法まとめ

- `B=μH`
- 点磁極: `H=m/(4πμ0 r^2)`
- 無限長直線導体: `H=I/(2πr)`
- 一巻円形コイル中心: `H=I/(2r)`
- 円弧電流中心: `H=Iθ/(4πr)`、`θ` はrad
- ファラデーの法則: `e=-N dΦ/dt`
- 有限時間の大きさ: `|e|=N|ΔΦ|/Δt`
- 運動起電力: `e=Blv`（相互に直交する場合）
- 周速度: `v=πDn/60`
- 電磁力: `F=BIl sinθ`
- 磁界計算は「形状 → 式 → 向き → 合成」の順で処理する。
- 電磁誘導は「磁束変化か運動か → 公式選択 → 巻数・有効導体数 → 向き」の順で処理する。
- L0系の浮上・案内は、`磁束変化 → 誘導電流 → 磁界 → 電磁力` の流れで試験知識へ接続する。
