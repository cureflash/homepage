# 練習問題

## 問1 基礎: パワー半導体の制御性
パワー半導体について正しい記述はどれか。

1. ダイオードはゲート信号でターンオン・ターンオフを制御する。
2. サイリスタは一般的な基本回路で、ゲート信号だけにより任意の瞬間にターンオフできる。
3. GTOはゲートでターンオンできるが、ターンオフはできない。
4. IGBTはゲート信号によってターンオン・ターンオフを制御できる。
5. ダイオード、サイリスタ、GTO、IGBTはすべて同じ制御性を持つ。

### 解答・解説
正答: 4

IGBTはゲート信号によってオン・オフを制御できる自己消弧形素子であり、インバータやチョッパのスイッチングに用いられる。

1は誤り。ダイオードは順方向電圧で自然に導通する非制御素子である。2は誤り。基本的なサイリスタはゲートでターンオンできるが、ターンオフには電流を保持電流以下へ下げるなど回路側の条件が必要である。3は誤り。GTOはゲートでターンオフもできる。5も誤りである。

## 問2 基礎: 電力変換回路の分類
入力と出力の組合せについて正しいものはどれか。

1. 整流器: DC→AC
2. インバータ: AC→DC
3. インバータ: DC→AC
4. 直流チョッパ: AC→AC
5. 直流チョッパ: AC→DC

### 解答・解説
正答: 3

インバータは直流を交流へ変換する。整流器・コンバータは交流を直流へ変換し、直流チョッパは直流から別の平均直流電圧を得る。

したがって1、2、4、5は入出力の分類が誤っている。

## 問3 基礎: VVVFと同期速度
4極の三相誘導電動機へ、インバータから `75 Hz` の交流を供給する。同期速度として正しいものはどれか。

1. `900 min^-1`
2. `1500 min^-1`
3. `1800 min^-1`
4. `2250 min^-1`
5. `3000 min^-1`

### 解答・解説
正答: 4

同期速度は、

```text
Ns = 120f/P
```

で求める。

```text
Ns = 120×75/4
   = 2250 min^-1
```

よって正答は4。極数Pには極対数ではなく極数そのものを代入する。

## 問4 本試験標準: R-L負荷と環流ダイオード
単相半波ダイオード整流回路がR-L負荷を給電している。理想的な環流ダイオードを負荷へ並列に接続したときの説明として正しいものはどれか。

1. 電源電圧が負になる瞬間、負荷電流も必ず瞬時に0になる。
2. 環流中は負荷電圧がほぼ0になり、Lに蓄えられたエネルギーにより負荷電流は減衰しながら継続する。
3. 環流ダイオードを付けると、負荷電圧は常に電源の負半周期と同じ負電圧になる。
4. Lは電流変化を促進するため、R負荷より電流が急激に変化する。
5. 環流ダイオードは交流電源を直流電源へ変えるための主スイッチである。

### 解答・解説
正答: 2

インダクタンスLは電流の急変を妨げる。電源からの供給が途切れても、環流ダイオードがあればLに蓄えられたエネルギーによる電流の経路が確保される。理想素子なら環流中の負荷電圧はほぼ0で、負荷電流は減衰しながら流れ続ける。

1と4はLの性質と逆である。3は環流ダイオードのクランプ作用と矛盾する。5も役割が異なる。

## 問5 本試験標準: 三相整流の線間電圧と平均値
三相交流の相電圧実効値を `V_s=100 V` とする。理想的な三相ダイオード全波整流回路について、線間電圧実効値 `V_LL` と直流平均電圧 `Vd,avg` の組合せとして最も近いものはどれか。

1. `V_LL=100 V`, `Vd,avg=135 V`
2. `V_LL=173 V`, `Vd,avg=234 V`
3. `V_LL=173 V`, `Vd,avg=173 V`
4. `V_LL=245 V`, `Vd,avg=234 V`
5. `V_LL=300 V`, `Vd,avg=405 V`

### 解答・解説
正答: 2

相電圧から線間電圧へ変換する。

```text
V_LL = √3 V_s
     = √3×100
     ≈ 173.2 V
```

三相ダイオード全波整流の理想平均値は、

```text
Vd,avg = (3√6/π)V_s
       ≈ 2.339×100
       ≈ 233.9 V
```

または `Vd,avg≈1.35V_LL` としても、

```text
1.35×173.2 ≈ 233.8 V
```

となる。よって正答は2。

## 問6 本試験標準: 三相整流の脈動率
理想的な三相ダイオード全波整流回路で、相電圧実効値を `V_s` とする。次の定義、

```text
δ = (Vmax - Vmin) / Vd,avg
```

を用いるとき、脈動率δとして最も近いものはどれか。

ただし、

```text
Vmax = √6 V_s
Vmin = √6 V_s cos(π/6)
Vd,avg = (3√6/π)V_s
```

とする。

1. 0.050
2. 0.100
3. 0.140
4. 0.318
5. 0.707

### 解答・解説
正答: 3

定義式へ代入すると `V_s` と `√6` は約分できる。

```text
δ = [1-cos(π/6)] / (3/π)
  = π[1-√3/2]/3
  ≈ 0.1403
```

よって正答は3。

例えば `V_s=100 V` と置いて検算すると、

```text
Vmax ≈ 244.9 V
Vmin ≈ 212.1 V
Vd,avg ≈ 233.9 V
δ ≈ (244.9-212.1)/233.9 ≈ 0.140
```

となる。

## 問7 本試験標準: 直流チョッパの通流率とオン時間
入力直流電圧 `E=200 V` の理想降圧チョッパで、平均出力電圧を `120 V` とする。スイッチング周波数は `1.0 kHz` である。通流率Dとオン時間 `t_on` の組合せとして正しいものはどれか。

1. `D=0.40`, `t_on=0.40 ms`
2. `D=0.60`, `t_on=0.60 ms`
3. `D=0.60`, `t_on=1.67 ms`
4. `D=1.20`, `t_on=1.20 ms`
5. `D=1.67`, `t_on=0.60 ms`

### 解答・解説
正答: 2

理想降圧チョッパでは、

```text
Vavg = DE
```

より、

```text
D = 120/200 = 0.60
```

周期は、

```text
T = 1/f_s
  = 1/1000
  = 1.0 ms
```

したがって、

```text
t_on = DT
     = 0.60×1.0
     = 0.60 ms
```

よって正答は2。`0<D<1`、`t_on<T` も満たす。

## 問8 本試験標準: オン時間から平均電圧を求める
入力直流電圧 `E=250 V`、スイッチング周波数 `f_s=500 Hz` の理想降圧チョッパがある。オン時間が `t_on=1.20 ms` のとき、平均出力電圧として正しいものはどれか。

1. 100 V
2. 120 V
3. 125 V
4. 150 V
5. 200 V

### 解答・解説
正答: 4

周期は、

```text
T = 1/f_s
  = 1/500
  = 2.00 ms
```

したがって通流率は、

```text
D = t_on/T
  = 1.20/2.00
  = 0.60
```

平均出力電圧は、

```text
Vavg = DE
     = 0.60×250
     = 150 V
```

よって正答は4。オン時間が周期を超えていないこと、平均電圧が入力電圧以下であることも検算になる。

## 問9 本試験標準: 単相ブリッジインバータの通流経路
選定過去問と同じ番号付けのIGBT単相ブリッジ電圧形インバータがR-L負荷を駆動している。ある瞬間に出力電圧が `v0>0`、負荷電流が `i0<0` のとき、通流する素子対として正しいものはどれか。

1. `Q1-Q4`
2. `Q2-Q3`
3. `D2-D3`
4. `Q1-D3`
5. `D1-D4`

### 解答・解説
正答: 5

出力電圧は正だが、R-L負荷の電流はLのため負方向へ継続している。電圧と電流の符号が逆なので逆並列ダイオード側が導通し、選定過去問の番号付けでは、

```text
D1-D4
```

となる。よって正答は5。

`v0>0, i0>0` なら `Q1-Q4`、`v0<0, i0>0` なら `D2-D3`、`v0<0, i0<0` なら `Q2-Q3` である。

## 問10 本試験標準: R-L負荷の時定数
R-L負荷の抵抗を `R=2 Ω`、インダクタンスを `L=8 mH` とする。時定数τとして正しいものはどれか。

1. 4 ms
2. 8 ms
3. 16 ms
4. 250 ms
5. 4000 ms

### 解答・解説
正答: 1

R-L回路の時定数は、

```text
τ = L/R
```

である。`8 mH=8×10^-3 H` なので、

```text
τ = 8×10^-3 / 2
  = 4×10^-3 s
  = 4 ms
```

よって正答は1。mHをHへ換算してから計算する。

## 問11 複合・応用: 制御整流と三相整流値
交流を直流へ変換する回路について、次の記述のうち正しいものはどれか。

1. 平滑リアクトルが十分大きく直流側電流がほぼ連続でも、交流側電流は必ず正弦波になる。
2. 自然転流を前提とする制御整流回路で、交流側電流の切替位相をゲート信号で変える基本的な素子としてダイオードを用いる。
3. 自然転流を前提とする制御整流回路では、サイリスタブリッジを用いて点弧位相を制御できる。
4. 三相ダイオード全波整流は1周期に1個の山だけを持つ。
5. 三相ダイオード全波整流の平均直流電圧は、相電圧実効値 `V_s` に等しい。

### 解答・解説
正答: 3

サイリスタはゲート信号で点弧できるため、自然転流を用いる制御整流回路で点弧位相を変えられる。平滑リアクトルが十分大きいと直流側電流はほぼ連続となり、交流側電流は正弦波ではなく、回路と点弧位相に応じて矩形状の電流になる基本問題がある。

1は誤り。平滑リアクトルは直流側電流を平滑化するが、交流側電流を必ず正弦波にするものではない。2は誤り。ダイオードにはゲート制御端子がない。4は誤り。三相ダイオード全波整流は6パルスである。5も誤りで、理想平均値は `Vd,avg=(3√6/π)V_s≈2.34V_s` である。

## 問12 複合・応用: PWM・VVVFとチョッパ計算
6極の三相誘導電動機の同期速度を `1800 min^-1` にしたい。また、別の理想降圧チョッパでは入力直流電圧 `E=600 V` から平均 `420 V` を得たい。必要なインバータ出力周波数fとチョッパ通流率Dの組合せとして正しいものはどれか。

1. `f=45 Hz`, `D=0.50`
2. `f=60 Hz`, `D=0.70`
3. `f=75 Hz`, `D=0.60`
4. `f=90 Hz`, `D=0.60`
5. `f=90 Hz`, `D=0.70`

### 解答・解説
正答: 5

同期速度の式、

```text
Ns = 120f/P
```

をfについて解く。

```text
f = NsP/120
  = 1800×6/120
  = 90 Hz
```

理想降圧チョッパでは、

```text
Vavg = DE
```

なので、

```text
D = Vavg/E
  = 420/600
  = 0.70
```

したがって正しい組合せは `f=90 Hz, D=0.70` で、正答は5。

検算すると、`120×90/6=1800 min^-1`、`0.70×600=420 V` となる。
