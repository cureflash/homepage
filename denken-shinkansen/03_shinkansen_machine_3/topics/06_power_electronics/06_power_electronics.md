# 解説本文

## 1. このテーマで電験は何を問うか

電験三種「機械」のパワーエレクトロニクスでは、半導体素子の名称だけでなく、電力の変換方向、スイッチング状態、波形、平均値を組み合わせて判断させる。

本テーマで解けるようにする対象は次のとおり。

- ダイオード・サイリスタ・GTO・IGBTの制御性を区別する。
- 整流器、コンバータ、インバータ、チョッパを入出力で分類する。
- R-L負荷で電流が遅れる理由と環流ダイオードの働きを説明する。
- 三相ダイオード全波整流の相電圧、線間電圧、6パルス出力、平均値、脈動率を計算する。
- 直流チョッパで周期、通流率、オン時間、平均電圧を求める。
- 単相ブリッジ電圧形インバータで電圧・電流の極性から通流素子を判断する。
- PWMとVVVFを、スイッチングによる電圧・周波数制御として理解する。
- インバータ出力周波数と誘導電動機の同期速度を `Ns=120f/P` で結び付ける。

問題を見たら最初に「AC→DCか、DC→ACか、DC→DCか」を判定し、その後で素子、波形、平均値の順に見る。

## 2. パワー半導体の役割

### 2.1 ダイオード

ダイオードは順方向に電圧が加わると導通し、逆方向は遮断する。ゲート信号でオン・オフを指令する素子ではない。したがって、ダイオード整流回路では交流電源の極性に応じて導通する素子が自動的に切り替わる。

### 2.2 サイリスタ

サイリスタは順方向電圧が加わっている状態でゲート信号を与えると導通を開始する。通常のサイリスタは、ゲートだけで任意の時刻にターンオフする自己消弧形素子ではない。交流回路では電流が零になるなどして導通が終わる。

点弧時刻を変えられるため、ダイオードだけの整流器より直流側平均電圧を制御できる。

### 2.3 GTO

GTOはゲート信号でターンオンだけでなくターンオフも制御できる自己消弧形のサイリスタである。スイッチングする電力変換回路に用いる素子として、通常のサイリスタとの違いを押さえる。

### 2.4 IGBT

IGBTもゲート信号でオン・オフを制御できる自己消弧形素子である。チョッパやインバータでは、IGBTを周期的にスイッチングして平均電圧や交流出力を作る。

誘導性負荷では電流が急に零になれないため、IGBTと逆並列に接続されたダイオードが電流経路になる場合がある。この「出力電圧の極性」と「負荷電流の極性」を別々に見ることが、インバータ問題の要点である。

## 3. 電力変換回路を入出力で分類する

| 回路 | 入力 | 出力 | 本テーマで見る要点 |
|---|---|---|---|
| 整流器・コンバータ | AC | DC | ダイオード・サイリスタ、平均直流電圧、波形 |
| インバータ | DC | AC | IGBT、逆並列ダイオード、極性切替、PWM |
| 直流チョッパ | DC | DC | 通流率、オン時間、平均電圧 |

新幹線側では、系列SPECにある次の流れだけを使う。

`架線交流 → 主変圧器 → コンバータ → 直流中間回路 → インバータ → 可変電圧・可変周波数三相交流 → 誘導電動機`

直流中間回路は、交流をいったん直流へ変換した側と、そこから交流を作り直すインバータ側をつなぐ。ここでは車両固有の未確認電圧値や固定範囲外の制御方式は扱わない。

## 4. 単相整流とR-L負荷

### 4.1 R負荷とR-L負荷の違い

抵抗Rだけなら、電圧が変われば電流も同じ極性で直ちに変わる。インダクタンスLを含むR-L負荷では、Lに磁気エネルギーが蓄えられ、電流の急変を妨げる。そのため電源電圧の極性が変わっても、負荷電流はすぐに零にならず継続する。

この性質を波形問題で見落とすと、「電圧が零だから電流も直ちに零」と誤判定する。

### 4.2 環流ダイオード

R-L負荷に環流ダイオードを接続すると、電源からの供給が途切れた後も負荷電流が環流できる経路ができる。理想素子として扱う基本問題では、環流中の負荷電圧はほぼ0となる一方、Lに蓄えられたエネルギーによって電流は減衰しながら流れ続ける。

したがって波形を判定するときは、次の順序で考える。

1. 電源の極性を確認する。
2. ダイオードが順方向か逆方向かを確認する。
3. Lの電流は瞬時に変化できないことを確認する。
4. 環流経路があれば、その経路へ電流が移る。
5. 負荷電圧と負荷電流を別々に決める。

## 5. 三相ダイオード全波整流

### 5.1 相電圧と線間電圧

三相交流の相電圧実効値を `V_s`、線間電圧実効値を `V_LL` とすると、

`V_LL = √3 V_s`

である。相電圧と線間電圧の取り違えは頻出ミスなので、問題文の「相電圧」「線間電圧」を先に確認する。

### 5.2 6パルス波形

三相ダイオード全波整流では、その瞬間に最も高い相と最も低い相の間の線間電圧が直流側へ現れる。導通するダイオード対は60°ごとに切り替わり、1周期に6個の山を持つ6パルス波形になる。

相電圧実効値を `V_s` とすると、理想回路での主要値は、

`Vmax = √6 V_s`

`Vmin = √6 V_s cos(π/6)`

`Vd,avg = (3√6/π) V_s`

である。平均値は線間電圧実効値を使えば、

`Vd,avg = (3√2/π) V_LL ≈ 1.35 V_LL`

とも書ける。

選定過去問で使われる脈動率の定義は、

`δ = (Vmax - Vmin) / Vd,avg`

である。別の定義を勝手に混用せず、問題文の定義に従う。

### 5.3 計算手順

1. 与えられた値が相電圧か線間電圧か確認する。
2. 必要なら `V_LL=√3V_s` で変換する。
3. 求める量に応じて最大値、最小値、平均値の式を選ぶ。
4. 脈動率なら最後に定義式へ代入する。
5. 電圧の種類と単位Vを確認する。

## 6. 直流チョッパ

直流チョッパは直流をスイッチングして別の平均直流電圧を得る回路である。本テーマでは理想的な降圧チョッパの基本関係を使う。

スイッチング周波数を `f_s`、周期を `T` とすると、

`T = 1 / f_s`

オン時間を `t_on`、通流率を `D` とすると、

`D = t_on / T`

したがって、

`t_on = DT`

である。

入力直流電圧を `E` とし、オン中の出力電圧をE、オフ中を0とする理想波形なら、1周期の平均値は面積から、

`Vavg = (E t_on + 0×(T-t_on)) / T = DE`

となる。

つまり、通流率Dを大きくすると平均出力電圧は高くなる。計算では周波数Hzと周期s、msの単位換算に注意する。

## 7. 単相ブリッジ電圧形インバータ

### 7.1 直流から交流を作る

単相ブリッジ電圧形インバータでは、直流電源に対してブリッジの対角素子を交互に導通させ、負荷へ正負の電圧を加える。抵抗負荷なら電流極性は電圧と同じ向きに変わりやすいが、R-L負荷ではLのため電流が遅れ、電圧と電流の符号が異なる区間が生じる。

### 7.2 IGBTか逆並列ダイオードかを判定する

選定過去問の素子番号に従うと、通流経路は次のように整理できる。

| 出力電圧 `v0` | 負荷電流 `i0` | 通流経路 |
|---|---|---|
| `v0 > 0` | `i0 > 0` | `Q1 - Q4` |
| `v0 > 0` | `i0 < 0` | `D1 - D4` |
| `v0 < 0` | `i0 > 0` | `D2 - D3` |
| `v0 < 0` | `i0 < 0` | `Q2 - Q3` |

丸暗記より、「指定された電圧極性を作るブリッジ側」と「実際の電流方向」を別々に追う。電圧と電流の符号が逆なら、誘導性負荷から電流が継続するため逆並列ダイオード側を疑う。

### 7.3 R-L回路の時定数

R-L回路の時定数は、

`τ = L / R`

である。Lの単位をH、RをΩで代入するとτはsになる。例えば `L=2 mH`、`R=1 Ω` なら、

`τ = 2×10^-3 / 1 = 2×10^-3 s = 2 ms`

となる。mHをHへ直さずに代入しない。

## 8. PWM・VVVFと誘導電動機の速度

### 8.1 PWM

PWMはスイッチングのパルス幅を変えることで、一定の直流電圧から出力側の平均的・実効的な電圧を調整する考え方である。本テーマでは詳細な高調波解析へ進まず、「スイッチングのオン時間を変えると出力電圧を変えられる」ところまで扱う。

チョッパの `Vavg=DE` は、オン時間の割合で平均電圧を変える最も単純な例であり、PWMを理解する入口になる。

### 8.2 VVVF

VVVFは可変電圧・可変周波数の交流を作る。インバータのスイッチングによって出力電圧の大きさと交流の繰返し周波数を変え、誘導電動機へ供給する。

誘導電動機の同期速度は、

`Ns = 120f / P`

- `Ns`: 同期速度 [min^-1]
- `f`: 電源周波数 [Hz]
- `P`: 極数

である。極数Pが一定なら、インバータ出力周波数fを上げると同期速度Nsも比例して上がる。ここではベクトル制御や回生制動へ範囲を広げない。

## 9. 新幹線への接続

本テーマでは系列SPECどおり、次の機能対応だけを使う。

1. 架線交流を主変圧器へ入れる。
2. コンバータで交流を直流側へ変換する。
3. 直流中間回路を介してインバータへ送る。
4. インバータで可変電圧・可変周波数の三相交流を作る。
5. 誘導電動機へ供給する周波数を変える。
6. `Ns=120f/P` により同期速度が変わり、速度制御へつながる。

この流れはパワーエレクトロニクスの一般理論を具体化するために使う。300系の車両固有電圧、素子定格、スイッチング周波数など、一次資料で固定していない値は教材へ入れない。

## 10. 本試験で使う解法アルゴリズム

### 10.1 回路分類問題

1. 入力がACかDCか確認する。
2. 出力がACかDCか確認する。
3. 整流器・インバータ・チョッパのどれかを決める。
4. ゲートでターンオンだけを制御するか、オン・オフ双方を制御するかを見る。
5. Lがあれば電流継続を考える。
6. 指定された波形と一致する回路を選ぶ。

### 10.2 三相整流計算

1. 相電圧か線間電圧かを確認する。
2. `V_LL=√3V_s` で必要な電圧へ変換する。
3. `Vmax`、`Vmin`、`Vd,avg` を求める。
4. 指定された脈動率定義へ代入する。
5. 数値の大小関係 `Vmin < Vavg < Vmax` を検算する。

### 10.3 チョッパ計算

1. `T=1/f_s` で周期を求める。
2. `D=Vavg/E` または `D=t_on/T` で通流率を求める。
3. `t_on=DT` でオン時間を求める。
4. `0≤D≤1`、`0≤t_on≤T` を検算する。

### 10.4 インバータ回路動作

1. 出力電圧の符号を決める。
2. 負荷電流の符号を別に決める。
3. 両者が同符号か逆符号かを見る。
4. IGBTか逆並列ダイオードかを判断する。
5. R-Lの時間変化が問われたら `τ=L/R` を使う。

## 11. 3段階例題

### 例題1 基礎 — 直流チョッパの通流率

直流電源 `E=240 V` を理想降圧チョッパで平均 `Vavg=144 V` にする。スイッチング周波数は `f_s=1.0 kHz` とする。通流率D、周期T、オン時間 `t_on` を求めよ。

#### 解法

平均電圧はオン時間の割合で決まるので、

`Vavg = DE`

より、

`D = Vavg/E = 144/240 = 0.60`

周期は、

`T = 1/f_s = 1/1000 = 1.0×10^-3 s = 1.0 ms`

オン時間は、

`t_on = DT = 0.60×1.0 ms = 0.60 ms`

#### 答

- `D=0.60`
- `T=1.0 ms`
- `t_on=0.60 ms`

検算すると `0<D<1`、`t_on<T` を満たす。

### 例題2 本試験標準 — 三相ダイオード全波整流

三相交流の相電圧実効値が `V_s=100 V` である。理想的な三相ダイオード全波整流回路について、線間電圧実効値 `V_LL`、直流出力の最大値 `Vmax`、最小値 `Vmin`、平均値 `Vd,avg`、脈動率 `δ=(Vmax-Vmin)/Vd,avg` を求めよ。

#### 解法

まず相電圧から線間電圧へ変換する。

`V_LL = √3×100 = 173.2 V`

最大値は、

`Vmax = √6×100 = 244.9 V`

最小値は、

`Vmin = √6×100×cos(π/6) = 212.1 V`

平均値は、

`Vd,avg = (3√6/π)×100 = 233.9 V`

脈動率は、

`δ = (244.9-212.1)/233.9 = 0.140`

#### 答

- `V_LL≈173 V`
- `Vmax≈245 V`
- `Vmin≈212 V`
- `Vd,avg≈234 V`
- `δ≈0.140`

検算すると `212 < 234 < 245` で、平均値が最大値と最小値の間にある。

### 例題3 複合・ひっかけ — インバータの電流経路と同期速度

選定過去問と同じ番号付けの単相ブリッジ電圧形インバータがR-L負荷を駆動している。ある瞬間に `v0>0`、`i0<0` であった。また負荷は `R=2 Ω`、`L=6 mH` とする。さらに別の三相誘導電動機を4極、インバータ出力周波数 `f=75 Hz` で駆動するとする。

(1) 単相ブリッジで通流する素子対を答えよ。
(2) R-L負荷の時定数τを求めよ。
(3) 4極誘導電動機の同期速度Nsを求めよ。

#### 解法

(1) `v0>0` でも電流は `i0<0` であり、電圧と電流の符号が逆である。Lの電流が継続して逆並列ダイオードを流れる区間なので、選定過去問の番号付けでは、

`D1 - D4`

となる。

(2) 時定数は、

`τ=L/R`

`L=6 mH=6×10^-3 H` なので、

`τ = 6×10^-3 / 2 = 3×10^-3 s = 3 ms`

(3) 同期速度は、

`Ns = 120f/P`

`Ns = 120×75/4 = 2250 min^-1`

#### 答

- 通流素子: `D1-D4`
- `τ=3 ms`
- `Ns=2250 min^-1`

ひっかけは、正の出力電圧だから必ずIGBTが流れると決め付けること、mHをHへ換算しないこと、極対数ではなく極数Pを式へ入れることである。

## 12. 頻出ミス

- 相電圧と線間電圧を混同する。
- 三相整流の平均値式へ線間電圧と相電圧を二重に変換して入れる。
- 脈動率の定義を問題文と違う定義へ置き換える。
- `f_s` を周期Tと取り違える。
- kHz→Hz、ms→s、mH→Hの換算を落とす。
- 通流率Dを百分率のまま式へ代入する。
- R-L負荷で電圧が切り替わった瞬間に電流も反転すると考える。
- インバータで電圧極性だけを見てIGBTかダイオードか決める。
- `Ns=120f/P` のPへ極対数を入れる。

## 14. 公式・解法まとめ

- 相電圧→線間電圧: `V_LL=√3V_s`
- 三相ダイオード全波整流最大値: `Vmax=√6V_s`
- 同最小値: `Vmin=√6V_s cos(π/6)`
- 同平均値: `Vd,avg=(3√6/π)V_s=(3√2/π)V_LL`
- 選定過去問の脈動率: `δ=(Vmax-Vmin)/Vd,avg`
- チョッパ周期: `T=1/f_s`
- 通流率: `D=t_on/T`
- 理想降圧チョッパ平均電圧: `Vavg=DE`
- R-L時定数: `τ=L/R`
- 誘導電動機同期速度: `Ns=120f/P`

回路問題では「入出力のAC/DC → 素子の制御性 → Lによる電流継続 → 電圧・電流極性」の順に判定する。
