# 解説本文

## 1. このテーマで電験は何を問うか
電験三種「機械」の直流機では、構造名を覚えるだけでなく、起電力・逆起電力・電機子電流・磁束・トルク・回転速度・損失を一つの流れとして扱えることが必要になる。

本試験では主に次を問われる。

- 磁界中を動く導体の誘導起電力を求める。
- `E=kΦN` と `V=E+IaRa` から逆起電力や回転速度を求める。
- `T=kΦIa` から分巻機・直巻機のトルク特性を判定する。
- 他励・分巻・直巻・複巻の結線と特徴を区別する。
- 始動時に逆起電力が0になることから始動電流を扱う。
- 銅損、機械損、入力、電磁変換電力、軸出力、効率を整理する。
- 分巻発電機の自己励磁や、整流子・ブラシとブラシレスDCモータの違いを判定する。

この章を終えた時点で、EXAM_ALIGNMENTで選定した6問を解くための基礎と解法手順をそろえる。速度制御法そのものはTopic 03へ送る。

## 2. 直流機の構造と整流
直流機は、発電機として使う場合も電動機として使う場合も、基本構造は共通している。

- 界磁: 主磁束 `Φ` を作る。
- 電機子: 起電力が誘導され、また電流が流れて力を受ける回転部分。
- 整流子: 回転子側のコイルと外部回路の接続を回転に合わせて切り替える。
- ブラシ: 静止側から整流子へ電流を出し入れする接触子。

電機子コイル自体では、回転に伴って各導体の誘導起電力の向きが周期的に変わる。整流子は外部端子から見た極性が一定になるよう接続を切り替えるため、直流発電機では外部へ直流を取り出せる。直流電動機では、回転位置に応じて電機子導体の電流方向を切り替え、同じ回転方向のトルクを保つ。

整流子とブラシは機械的に接触するため、摩耗、保守、整流時の火花などを伴う。ブラシレスDCモータでは、この機械的な整流を半導体スイッチによる電子的な転流へ置き換える。ここでは構造差の判定までとし、インバータの詳細はTopic 06以降で扱う。

## 3. 発電機作用と誘導起電力
磁束密度 `B[T]` の磁界中を、有効長 `l[m]` の導体が速度 `v[m/s]` で磁界と直角に動くとき、導体に生じる誘導起電力は

`e = Blv`

である。一般には角度を考えるが、電験の基本問題で導体の運動方向・磁界・導体が互いに直角と示される場合はこの形を使う。

回転子直径を `D[m]`、回転速度を `N[min^-1]` とすると、円周上の速度は

`v = πDN / 60`

である。したがって図問題では、まず回転速度を周速度へ直してから `e=Blv` に入れる。1巻きコイルには有効導体が2本あるため、問題が「導体1本の起電力」を聞くのか「1巻きコイル全体の起電力」を聞くのかを区別する。

直流機全体では、多数の導体と巻線配置を機械定数へまとめて

`E = kE Φ N`

と表す。`E[V]` は誘導起電力、`Φ[Wb]` は1極当たり磁束、`N[min^-1]` は回転速度、`kE` は極数・導体数・巻線方式等で決まる定数である。同じ機械では `E` は磁束と回転速度に比例する。

## 4. 電動機作用・逆起電力・電機子回路
電機子導体に電流を流すと、磁界中の導体には力が働き、回転トルクが生じる。回転し始めると、電機子は同時に発電機としても働き、印加電圧と反対向きの起電力を生じる。これが逆起電力 `E` である。

ブラシ電圧降下などを問題文で無視できる基本形では、電動機の電機子回路は

`V = E + IaRa`

したがって

`E = V - IaRa`

となる。`V[V]` は電機子端子電圧、`Ia[A]` は電機子電流、`Ra[Ω]` は電機子抵抗である。

さらに `E=kEΦN` と合わせると

`N = E / (kEΦ) = (V-IaRa)/(kEΦ)`

となる。磁束が一定なら、回転速度はほぼ逆起電力に比例する。負荷が増えて `Ia` が増えると `IaRa` が増え、`E` が少し下がるため、分巻電動機の回転速度はわずかに低下する。

始動直後は `N=0` なので `E=0` である。したがって外部抵抗等を考えない瞬間の電機子電流は

`Ia,start = V/Ra`

となり、`Ra` が小さい直流電動機では大電流になり得る。ここでは「なぜ始動電流が大きいか」までを扱い、始動抵抗や速度制御方式の体系的説明はTopic 03へ送る。

## 5. 電磁トルクと機械出力
直流電動機の電磁トルクは

`T = kT Φ Ia`

で表される。`T[N·m]` は電磁トルク、`kT` は機械定数である。同じ機械では、トルクは磁束と電機子電流の積に比例する。

回転速度 `N[min^-1]` を角速度へ直すと

`ω = 2πN/60 [rad/s]`

であり、電磁変換された機械電力は

`Pdev = Tω`

となる。理想化した直流機では、電磁変換電力は

`Pdev = EIa`

とも表せる。つまり、電機子へ入った電力 `VIa` のうち `Ia^2Ra` が電機子銅損となり、残り `EIa` が電磁変換される。

機械損がある場合は、`Pdev` がそのまま軸出力ではない。

`Pshaft = Pdev - Pmech`

である。問題文が「機械損を無視する」と指定した場合だけ、`Pshaft=Pdev` としてよい。

## 6. 他励・分巻・直巻・複巻
### 他励機
界磁巻線を電機子とは別の電源で励磁する。界磁電流を独立に与えられるため、電機子側と界磁側を分けて考える。

### 分巻機
界磁巻線を電機子と並列に接続する。端子電圧がほぼ一定なら界磁電流も大きく変わらず、磁束 `Φ` はほぼ一定とみなせる。

したがって分巻電動機では

`T ∝ Ia`

となり、`N=(V-IaRa)/(kEΦ)` から、負荷が増えても速度変化は比較的小さい。このため定速度特性を持つ。

分巻発電機では、磁極の残留磁束による小さな起電力が最初に生じ、その電圧で界磁電流が流れ、界磁磁束が増えて電圧が立ち上がる自己励磁が起こる。自己励磁には残留磁気があり、界磁電流が残留磁束を強める向きに流れることが必要である。

### 直巻機
界磁巻線と電機子を直列に接続するため、界磁電流と電機子電流は同じである。磁気飽和前の範囲では

`Φ ∝ Ia`

と近似できるので

`T ∝ ΦIa ∝ Ia^2`

となり、大きな始動トルクを得やすい。

一方、負荷が軽く電流が小さくなると磁束も弱くなるため、`N=(V-IaRa)/(kEΦ)` から回転速度が大きく上がり得る。直巻電動機を無負荷で運転してはいけない理由はここにある。

直巻発電機では負荷電流がそのまま界磁電流となるため、出力電流と磁束が連動する。磁気飽和の前後で電圧特性が変わることを押さえる。

### 複巻機
分巻界磁と直巻界磁を併せ持つ。両者の磁束が同じ向きに働くものが累積複巻、反対向きに働くものが差動複巻である。結線図では、分巻・直巻のどちらを持つかだけでなく、直巻界磁の磁束が分巻界磁を助けるか打ち消すかを見る。

## 7. 損失・入力・出力・効率
直流電動機の計算では、どの電力を「入力」「出力」としているかを明確にする。

電機子だけを見ると

`VIa = Ia^2Ra + EIa`

である。

- `VIa`: 電機子入力
- `Ia^2Ra`: 電機子銅損
- `EIa`: 電磁変換電力

分巻界磁が同じ電源につながる場合は界磁入力 `VIf` も必要で、線電流は

`I = Ia + If`

となる。電源から見た入力は

`Pin = VI = V(Ia+If)`

である。機械損 `Pmech` を考える場合、軸出力は

`Pout = EIa - Pmech`

となり、効率は

`η = Pout/Pin`

で求める。

他励機では界磁電源が別なので、効率計算で界磁入力を含めるかどうかを問題文の定義に従う。永久磁石直流電動機では界磁銅損はない。ブラシ損、鉄損、漂遊負荷損等についても、問題文が与えた損失だけを加減し、勝手に追加しない。

## 8. 問題を見たときの解法手順
直流機の数値問題では、次の順で整理すると式の取り違えを減らせる。

1. 発電機か電動機かを確認する。
2. 他励・分巻・直巻・複巻・永久磁石のどれかを確認する。
3. 線電流、電機子電流、界磁電流を区別する。
4. 始動時なら `N=0 → E=0` を最初に置く。
5. 銅損が与えられたら `Pcu=Ia^2Ra` から `Ra` を求める。
6. 電動機なら `E=V-IaRa` で逆起電力を求める。
7. 同じ機械・同じ磁束なら `N∝E` を使って速度比を取る。
8. トルク問題では `T=kTΦIa` を使い、分巻なら `Φ≈一定`、未飽和直巻なら `Φ∝Ia` を判定する。
9. 電力問題では `VIa → Ia^2Ra + EIa → 機械損 → 軸出力` の順に収支を追う。
10. 最後に単位と物理的妥当性を確認する。電動機運転で通常 `0<E<V`、効率は1未満である。

図問題では、式に入る前に「導体1本か、1巻きコイルか」「速度 `N` は min^-1 か」「磁界と運動方向が直角か」を確認する。

## 9. 3段階例題
### 基礎例題: 誘導起電力
磁束密度 `B=0.50 T` の磁界中で、有効長 `l=0.30 m` の導体が直径 `D=0.40 m` の円周上を `N=1200 min^-1` で回転している。導体の運動方向と磁界は直角とする。導体1本に生じる瞬時起電力を求める。

まず周速度を求める。

`v=πDN/60`

`=π×0.40×1200/60`

`≈25.13 m/s`

したがって

`e=Blv`

`=0.50×0.30×25.13`

`≈3.77 V`

答えは約 `3.77 V`。1巻きコイル全体を問う場合は、有効導体本数を図から確認して合成する。

### 本試験標準例題: 銅損から抵抗を求め、速度比へつなぐ
永久磁石直流電動機を `V=100 V` で運転する。運転点Aでは電機子電流 `Ia1=20 A`、電機子銅損 `Pcu1=80 W`、回転速度 `N1=1440 min^-1` である。同じ端子電圧で電機子電流が `Ia2=10 A` になったときの回転速度を求める。磁束は一定とする。

まず銅損から電機子抵抗を求める。

`Ra=Pcu1/Ia1^2`

`=80/20^2`

`=0.20 Ω`

運転点Aの逆起電力は

`E1=V-Ia1Ra`

`=100-20×0.20`

`=96 V`

運転点Bでは

`E2=100-10×0.20=98 V`

同じ機械で磁束一定なので `N∝E`。したがって

`N2/N1=E2/E1`

`N2=1440×98/96`

`=1470 min^-1`

答えは `1470 min^-1`。電流が減ると電機子抵抗降下が小さくなり、逆起電力が増えるため速度が少し上がる。

### 複合例題: 始動電流、損失、効率
直流分巻電動機を `V=200 V` で使用する。始動時の電機子電流は `400 A` で、始動時には外部抵抗を考えない。定常運転時の電機子電流は `40 A`、界磁電流は `2 A`、機械損は `600 W` とする。ブラシ損など他の損失は無視する。定常運転時の効率を求める。

始動時は `E=0` なので

`Ra=V/Ia,start`

`=200/400`

`=0.50 Ω`

定常時の電機子銅損は

`Pcu,a=Ia^2Ra`

`=40^2×0.50`

`=800 W`

逆起電力は

`E=V-IaRa`

`=200-40×0.50`

`=180 V`

電磁変換電力は

`Pdev=EIa=180×40=7200 W`

軸出力は

`Pout=7200-600=6600 W`

分巻機なので線電流は

`I=Ia+If=40+2=42 A`

入力は

`Pin=VI=200×42=8400 W`

したがって

`η=Pout/Pin`

`=6600/8400`

`≈0.786`

答えは約 `78.6 %`。検算すると、界磁銅損は `VIf=400 W` なので、全損失は `800+400+600=1800 W`、`8400-1800=6600 W` となり軸出力と一致する。

## 10. 新幹線への接続
系列SPECで確定している0系の電力経路は、ここでは次の範囲だけを使う。

```text
交流25 kV
↓
主変圧器
↓
整流
↓
直流
↓
直流主電動機
↓
車輪
```

Topic 01で扱った主変圧器の後段で交流を整流し、直流主電動機へ電力を与える。直流主電動機では、電源から流れた電機子電流と界磁磁束からトルクを発生させ、その一方で回転により逆起電力を生じる。この `電流 → トルク` と `回転 → 逆起電力` の二つを同時に見るのが直流電動機計算の中心である。

整流子・ブラシを持つ直流機では機械的整流が必要で、接触部の摩耗や保守が発生する。半導体電力変換と交流電動機を用いる方式では主電動機の機械的整流を不要にできるため、現在の鉄道主回路を理解するうえでも「なぜ直流機から交流機へ移ったか」の基礎になる。具体的な世代比較やパワー半導体は後続Topicで扱う。

0系主電動機の具体的形式・定格電圧・電流・出力・回転速度は、今回の一次資料確認範囲では真値化していないため記載しない。

## 11. 頻出ミス・ひっかけ
- `N[min^-1]` をそのまま `Tω` に入れない。`ω=2πN/60` へ直す。
- `e=Blv` で、導体1本と1巻きコイルを混同しない。
- 電動機で `E=V+IaRa` としない。基本形は `E=V-IaRa`。
- 始動時は `N=0` なので `E=0`。定常運転時の逆起電力を始動時へ持ち込まない。
- 分巻機で線電流 `I` と電機子電流 `Ia` を同一視しない。`I=Ia+If`。
- 直巻機の `T∝Ia^2` は磁気飽和前の `Φ∝Ia` が成り立つ範囲の近似である。
- `EIa` は電磁変換電力であり、機械損がある場合の軸出力ではない。
- 効率計算では、問題文が含める損失と入力範囲を確認する。与えられていない損失を勝手に追加しない。
- 累積複巻と差動複巻は、直巻界磁が分巻界磁を強めるか弱めるかで区別する。
- ブラシレスDCモータは「直流機と同じ機械式整流子を使う」のではなく、半導体スイッチで電子的に転流する。

## 13. 公式・解法まとめ
- 誘導起電力: `e=Blv`
- 周速度: `v=πDN/60`
- 直流機の起電力: `E=kEΦN`
- 電動機の電機子回路: `V=E+IaRa`
- 逆起電力: `E=V-IaRa`
- 電磁トルク: `T=kTΦIa`
- 角速度: `ω=2πN/60`
- 電磁変換電力: `Pdev=Tω=EIa`
- 電機子銅損: `Pcu,a=Ia^2Ra`
- 軸出力: `Pout=Pdev-Pmech`（問題文で与えられた損失を反映）
- 効率: `η=Pout/Pin`
- 分巻電動機: `Φ≈一定` → `T∝Ia`、速度は負荷に対して比較的一定
- 未飽和直巻電動機: `Φ∝Ia` → `T∝Ia^2`
- 始動時: `N=0` → `E=0`

数値問題では、`機種判定 → 電流の区別 → 逆起電力 → トルクまたは速度 → 電力収支 → 検算` の順に処理する。
