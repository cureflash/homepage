### 教材で必要な説明
- 電機子・界磁・整流子・ブラシの位置と役割を、発電機作用／電動機作用と結び付ける。
- 磁界中を動く導体の誘導起電力から `E=kΦN` へつなぐ。
- 電動機の逆起電力と端子電圧の関係 `V=E+IaRa` を説明し、始動時 `E=0` の意味を示す。
- `T=kΦIa` と `P=Tω` を用いて電流・磁束・トルク・回転速度・出力を相互に計算できるようにする。
- 他励・分巻・直巻・複巻の結線差と、分巻／直巻の速度・トルク特性を説明する。
- 銅損、機械損、入力、機械出力、効率のエネルギー収支を説明する。
- 新幹線側は系列SPECで確定している0系の直流主電動機を入口にし、未確認の実車定格値は使わない。

## 過去問とSPECから確定した教材必須範囲

### 1. 直流機の構造と整流
- 固定子側の界磁、回転子側の電機子、整流子、ブラシの役割。
- 発電機と電動機で共通する基本構造。
- 整流子・ブラシによる機械的な整流の意味。
- R8上問1で必要な範囲として、機械的整流と半導体スイッチングによるブラシレス化の違いを概念レベルで扱う。

### 2. 発電機作用と誘導起電力
- フレミング右手則と発電機作用。
- 磁界中を速度 `v` で動く長さ `l` の導体に生じる起電力 `e=Blv`。
- 回転運動では周速度 `v=πDN/60` を使う。
- 直流機全体では系列SPECの `E=kΦN` を用い、磁束 `Φ` と回転速度 `N` が起電力を決めることを説明する。

### 3. 電動機作用・逆起電力・電機子回路
- フレミング左手則と電動機作用。
- 回転によって電源電圧に逆向きの逆起電力が生じる理由。
- 電動機の基本式 `V=E+IaRa`、したがって `E=V-IaRa`。
- `E=kΦN` と組み合わせ、一定磁束なら回転速度が逆起電力に比例すること。
- 始動直後は `N=0`、したがって `E=0` となり、電機子電流が大きくなり得ること。

### 4. 電磁トルクと機械出力
- `T=kΦIa` の各記号と物理的意味。
- `ω=2πN/60`、`Pout=Tω` により回転速度・トルク・機械出力を結ぶ。
- 分巻機で磁束がほぼ一定ならトルクは概ね電機子電流に比例する。
- 未飽和の直巻機で `Φ∝Ia` と近似できる範囲では `T∝Ia^2` となり、大きな始動トルクにつながる。

### 5. 他励・分巻・直巻・複巻
- 他励、分巻、直巻、複巻の界磁回路の接続関係。
- 分巻電動機の速度が負荷に対して比較的一定である理由。
- 直巻電動機の負荷電流・磁束・トルク・速度の定性的関係。
- 複巻機の累積複巻・差動複巻の区別。
- 発電機についても自己励磁、残留磁気などR8上問1で要求された範囲を扱う。

### 6. 損失・出力・効率
- 電機子銅損 `Ia^2Ra` と、系列SPECで指定された機械損。
- 問題文で損失条件が限定されている場合、その条件に従って入力・損失・出力の収支を立てる。
- 電動機の入力 `Pin=VI`、機械出力、効率 `η=Pout/Pin`。
- 始動電流から電機子抵抗を逆算し、定格時銅損と効率へつなぐ手順。

### 7. 新幹線への接続とTopic 03との境界
系列SPECで確定している `交流25 kV → 主変圧器 → 整流 → 直流 → 0系の直流主電動機 → 車輪` を導入に使う。

0系主電動機の具体的な形式、定格電圧、電流、出力、回転速度等は、この段階では一次資料で真値化していないため追加しない。

Topic 02では、過去問を解くために必要な `V=E+IaRa`、`E=kΦN` と速度・トルク特性までは扱う。電機子電圧制御、界磁制御、直列抵抗、タップ制御、弱め界磁、定トルク／定出力運転の体系的な速度制御はTopic 03の範囲なので先取りしない。
