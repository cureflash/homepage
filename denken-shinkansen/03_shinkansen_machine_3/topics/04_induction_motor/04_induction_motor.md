- 三相交流を固定子巻線へ加えると回転磁界が生じる。

- 回転磁界が回転子導体を切り、誘導起電力・二次電流が生じ、トルクが発生する流れを説明する。
- 固定子側と回転子側を変圧器の一次側・二次側に対応させる。

### 2. 同期速度・滑り・二次周波数
- `Ns=120f/p`。
- `s=(Ns-N)/Ns`、`N=(1-s)Ns`。
- `f2=sf1`。
- 停止時 `s=1`、同期速度に近づくと `s→0` となる意味を説明する。
- 二次誘導起電力は滑りに比例し、`E2s=sE20` とする。

### 3. トルク・出力
- `ωm=2πN/60`、`T=Pout/ωm`。
- 同期角速度 `ωs=2πNs/60` と二次入力 `P2` の関係 `P2=Tωs` を扱う。
- 周波数・極数・滑りから速度を決め、その速度と出力からトルクへつなぐ手順を示す。

### 4. 損失・効率
- 三相入力 `P1=√3 VI cosφ`。
- 一次入力から鉄損・一次銅損を差し引いたものを二次入力 `P2` とする。
- `Pc2=sP2`、機械的に変換される電力 `Pm=(1-s)P2`。
- 機械損が与えられる場合は `Pout=Pm-Pmec`、無視指定なら `Pout=Pm`。
- `η=Pout/P1`。
- 問題文で無視すると指定された損失と、計上すべき損失を区別する。

### 5. 再利用可能な解法手順
1. 周波数 `f` と極数 `p` から `Ns` を求める。
2. 実回転速度 `N` または滑り `s` のどちらが与えられているか確認し、`s=(Ns-N)/Ns` または `N=(1-s)Ns` を使う。

# 解説本文

## §1 このテーマで電験は何を問うか
Topic 04では、三相誘導電動機を「回転磁界で回る機械」として覚えるだけでは不十分である。本試験では、周波数と極数から同期速度を求め、実回転速度との差から滑りを求め、その滑りを二次周波数・二次銅損・機械出力へつなぐ計算が繰り返し出る。

この章で使う中心関係は次の4本である。

```text
Ns = 120f / p
s = (Ns - N) / Ns
f2 = sf1
Pc2 = sP2,  Pm = (1-s)P2
```

`Ns` と `N`、`P2` と `Pout` を区別できることが重要である。同期速度は回転磁界の速度であり、回転子の実速度ではない。二次入力 `P2` は回転子へ電磁的に渡った電力であり、軸から取り出す出力そのものではない。

## §2 固定子・回転子・回転磁界
三相誘導電動機は、固定された固定子と、その内側で回転する回転子から成る。固定子の三相巻線へ位相のずれた三相交流を流すと、磁界の合成結果が空間内を回転する。この磁界を回転磁界という。

かご形誘導電動機の回転子には、導体棒とそれらを両端で短絡する導体があり、外部から回転子へ電源を直接つながない。回転磁界が回転子導体に対して相対運動すると誘導起電力が生じ、回転子電流が流れる。その回転子電流と磁界の相互作用でトルクが発生する。

電磁誘導の見方では、固定子側を変圧器の一次側、回転子側を二次側に対応させて考えられる。ただし誘導電動機では回転子が回転するため、固定子磁界との相対速度が二次側の周波数と誘導起電力を決める。

## §3 同期速度と滑り
回転磁界の速度である同期速度 `Ns` は、電源周波数 `f` と極数 `p` で決まる。

```text
Ns = 120f / p   [min^-1]
```

ここで `p` は極対数ではなく極数である。例えば50 Hz、4極なら、

```text
Ns = 120 × 50 / 4 = 1500 min^-1
```

誘導電動機が電動機としてトルクを出すには、回転磁界と回転子の間に相対速度が必要である。その差を無次元量で表したものが滑り `s` である。

```text
s = (Ns - N) / Ns
N = (1-s)Ns
```

停止時は `N=0` なので `s=1`。回転子速度が同期速度へ近づくほど `s` は0へ近づく。もし `N=Ns` なら相対運動がなくなり、回転子に誘導起電力を生じさせる原因がなくなるため、誘導電動機は負荷を負ったまま同期速度そのものでは回り続けない。

## §4 二次周波数と二次誘導起電力
回転子に現れる二次周波数 `f2` は、固定子側周波数 `f1` と滑り `s` の積である。

```text
f2 = sf1
```

停止時は `s=1` なので `f2=f1`。回転子が同期速度へ近づくと `s→0` となり、二次周波数も低下する。

停止時の二次誘導起電力を `E20`、滑り `s` のときの二次誘導起電力を `E2s` とすると、Topic 04の範囲では次の比例関係を使う。

```text
E2s = sE20
```

したがって、滑りが半分なら二次周波数も二次誘導起電力も停止時の半分になる。この「滑りが二次側の電気量を決める」という対応が、知識問題でも計算問題でも重要である。

## §5 回転速度・角速度・トルク
回転速度 `N [min^-1]` を角速度へ直すときは、

```text
ωm = 2πN / 60   [rad/s]
```

軸出力 `Pout` と軸トルク `Tout` の関係は、

```text
Tout = Pout / ωm
```

である。`Pout` をkWで与えられた場合はWへ直してから代入する。

一方、二次入力 `P2` と電磁トルク `T` の関係では同期角速度を使う。

```text
ωs = 2πNs / 60
P2 = Tωs
T = P2 / ωs
```

機械損を無視できる場合、同じ電磁トルクについて、

```text
Pm = Tωm = (1-s)P2
```

となる。試験では `Pout/ωm` と `P2/ωs` のどちらを使う問題かを、与えられた電力の種類から判定する。

## §6 誘導電動機の電力の流れ
三相平衡負荷として線間電圧 `V`、線電流 `I`、力率 `cosφ` が与えられると、一次入力は、

```text
P1 = √3 VI cosφ
```

である。ここから固定子側の鉄損 `Pi` と一次銅損 `Pc1` を差し引くと、回転子へ渡る二次入力 `P2` になる。

```text
P2 = P1 - Pi - Pc1
```

二次入力は、二次銅損と機械的に変換される電力へ分かれる。

```text
Pc2 = sP2
Pm  = (1-s)P2
```

したがって、

```text
P2 = Pc2 + Pm
```

が必ず成り立つ。機械損 `Pmec` が与えられる場合、軸出力は、

```text
Pout = Pm - Pmec
```

である。機械損を無視する指定なら `Pout=Pm` としてよい。

効率は、

```text
η = Pout / P1
```

で求める。百分率で答える場合だけ最後に100を掛ける。

## §7 本試験での解法アルゴリズム
誘導電動機の標準計算は、式を個別に覚えるより順序を固定した方がよい。

1. `f` と `p` を確認し、`Ns=120f/p` で同期速度を求める。
2. `N` が与えられたら `s=(Ns-N)/Ns`、`s` が与えられたら `N=(1-s)Ns` を使う。
3. 二次周波数なら `f2=sf1`、二次誘導起電力なら `E2s=sE20` へ進む。
4. 三相入力が必要なら `P1=√3VIcosφ` を使う。
5. 電力は `P1 → P2 → Pm → Pout` の順に追う。
6. 二次銅損は `sP2`、機械変換電力は `(1-s)P2` とする。
7. トルクでは、軸出力なら `ωm`、二次入力なら `ωs` を使う。
8. 最後に `0<s<1`、`P1>Pout`、単位がW・rad/s・N·mで整っているかを確認する。

## §8 300系への接続
この系列SPECでは、0系などの直流主電動機方式から300系の三相誘導電動機方式への転換を入口にする。ここで重要なのは車両史そのものではなく、電験で扱う誘導電動機の構造差である。

直流電動機では整流子とブラシを使って電機子へ電流を供給する。かご形誘導電動機では、回転子側へブラシで給電せず、固定子が作る回転磁界によって回転子に電流を誘導する。この構造差が、整流子・ブラシを不要にし、保守・高速回転・小型軽量化との関係を理解する入口になる。

このTopicでは、300系主電動機の未確認定格値や具体的な制御方式を計算へ持ち込まない。速度制御やインバータの詳細は後続Topicの範囲とする。

## §9 頻出ミス
- `p` に極対数を入れない。`Ns=120f/p` の `p` は極数。
- 同期速度 `Ns` と実回転速度 `N` を同じものとして扱わない。
- 滑りを百分率のまま式へ入れない。4%なら `s=0.04`。
- `f2=sf1` である。`f2=(1-s)f1` ではない。
- 二次銅損は `sP2`、機械変換電力は `(1-s)P2`。
- `P1` と `P2` を取り違えない。一次側損失を引いた後が `P2`。
- 軸出力からトルクを出すときは `ωm`、二次入力から電磁トルクを出すときは `ωs`。
- kWをWに直さず `T=P/ω` へ代入しない。
- 機械損の「無視する／与えられる」を問題文で確認する。

# 3段階例題

## 例題1 基礎 — 同期速度・滑り・二次周波数
50 Hz、4極の三相誘導電動機が1440 min^-1で回転している。同期速度、滑り、二次周波数を求める。

### 解法
まず同期速度を求める。

```text
Ns = 120f/p
   = 120×50/4
   = 1500 min^-1
```

次に滑り。

```text
s = (Ns-N)/Ns
  = (1500-1440)/1500
  = 0.04
```

二次周波数は、

```text
f2 = sf1
   = 0.04×50
   = 2.0 Hz
```

### 答
- 同期速度: `1500 min^-1`
- 滑り: `0.04 = 4%`
- 二次周波数: `2.0 Hz`

### 検算
実回転速度は同期速度より少し低く、滑りは正で1未満。通常の電動機運転として整合する。

## 例題2 本試験標準 — 回転速度からトルクまで
60 Hz、6極、滑り3%で運転する三相誘導電動機がある。機械損を無視し、軸出力を45 kWとする。同期速度、実回転速度、軸トルクを求める。

### 解法
同期速度は、

```text
Ns = 120×60/6
   = 1200 min^-1
```

実回転速度は、

```text
N = (1-s)Ns
  = (1-0.03)×1200
  = 1164 min^-1
```

実回転角速度は、

```text
ωm = 2πN/60
   = 2π×1164/60
   ≈ 121.9 rad/s
```

軸出力45 kWを45 000 Wへ直し、

```text
Tout = Pout/ωm
     = 45000/121.9
     ≈ 369 N·m
```

### 答
- 同期速度: `1200 min^-1`
- 実回転速度: `1164 min^-1`
- 軸トルク: 約 `369 N·m`

### 検算
`N<Ns` であり、45 kWを約122 rad/sで出すので数百N·m程度となる。単位・桁とも妥当。

## 例題3 複合 — 三相入力から損失・効率・トルクまで
50 Hz、4極の三相誘導電動機が、線間電圧400 V、線電流50 A、力率0.85、滑り4%で運転している。鉄損1.0 kW、一次銅損0.8 kW、機械損0.5 kWとする。二次入力、二次銅損、軸出力、効率、軸トルクを求める。

### 解法
一次入力は、

```text
P1 = √3VIcosφ
   = √3×400×50×0.85
   ≈ 29.45 kW
```

二次入力は一次側損失を引く。

```text
P2 = P1-Pi-Pc1
   = 29.45-1.0-0.8
   = 27.65 kW
```

二次銅損は、

```text
Pc2 = sP2
    = 0.04×27.65
    ≈ 1.11 kW
```

機械変換電力は、

```text
Pm = (1-s)P2
   = 0.96×27.65
   ≈ 26.54 kW
```

軸出力は機械損を引いて、

```text
Pout = Pm-Pmec
     = 26.54-0.50
     ≈ 26.04 kW
```

効率は、

```text
η = Pout/P1
  = 26.04/29.45
  ≈ 0.884
  = 88.4%
```

同期速度と実回転速度は、

```text
Ns = 120×50/4 = 1500 min^-1
N  = (1-0.04)×1500 = 1440 min^-1
```

したがって、

```text
ωm = 2π×1440/60
   ≈ 150.8 rad/s
```

軸トルクは、

```text
Tout = 26040/150.8
     ≈ 173 N·m
```

### 答
- 二次入力: 約 `27.65 kW`
- 二次銅損: 約 `1.11 kW`
- 軸出力: 約 `26.04 kW`
- 効率: 約 `88.4%`
- 軸トルク: 約 `173 N·m`

### 検算
`P2 = Pc2 + Pm ≈ 1.11 + 26.54 = 27.65 kW`。また `P1>P2>Pout` なので電力の流れとして妥当である。
