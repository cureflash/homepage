# 練習問題

## 問1 基礎: 回転原理
かご形三相誘導電動機について正しい記述はどれか。

1. 回転子へ外部電源から三相交流を直接供給して回転磁界を作る。
2. 固定子の三相巻線が回転磁界を作り、回転子導体に誘導起電力と電流を生じさせてトルクを発生する。
3. 回転子は必ず整流子とブラシを備える。
4. 回転子速度が同期速度と等しいとき、回転子導体を横切る磁束の相対速度は最大になる。
5. 固定子は変圧器の二次側、回転子は一次側に相当する。

### 解答・解説
正答: 2

固定子の三相巻線へ三相交流を流すと回転磁界が生じる。回転磁界と回転子との相対運動によって回転子導体に誘導起電力が生じ、二次電流と磁界の相互作用でトルクが発生する。

1は誤り。かご形回転子は外部から回転子へ電源を直接接続しない。3も誤りで、かご形誘導電動機は整流子・ブラシを必要としない。4は逆で、同期速度では相対速度が0となり、誘導起電力も0へ近づく。5も逆で、固定子側を変圧器の一次側、回転子側を二次側に対応させて考える。

## 問2 基礎: 同期速度
周波数50 Hz、4極の三相誘導電動機の同期速度 `Ns` はどれか。

1. 750 min^-1
2. 1000 min^-1
3. 1200 min^-1
4. 1500 min^-1
5. 3000 min^-1

### 解答・解説
正答: 4

同期速度は

```text
Ns = 120f/p
```

である。`f=50 Hz`、`p=4` を代入すると

```text
Ns = 120×50/4
   = 1500 min^-1
```

よって正答は4。`p` は極対数ではなく極数である。

## 問3 基礎: 滑り
周波数60 Hz、6極の三相誘導電動機が `1140 min^-1` で回転している。滑り `s` はどれか。

1. 0.02
2. 0.03
3. 0.04
4. 0.05
5. 0.06

### 解答・解説
正答: 4

まず同期速度を求める。

```text
Ns = 120×60/6
   = 1200 min^-1
```

滑りは

```text
s = (Ns-N)/Ns
  = (1200-1140)/1200
  = 60/1200
  = 0.05
```

よって正答は4。電動機運転では実回転速度 `N` は同期速度 `Ns` より少し低いので、正の小さな滑りになることも検算になる。

## 問4 本試験標準: 二次周波数
一次周波数 `f1=50 Hz`、滑り `s=0.04` で運転する誘導電動機の二次周波数 `f2` はどれか。

1. 0.8 Hz
2. 2.0 Hz
3. 4.0 Hz
4. 12.5 Hz
5. 48 Hz

### 解答・解説
正答: 2

二次周波数は滑りに比例し、

```text
f2 = sf1
```

である。したがって

```text
f2 = 0.04×50
   = 2.0 Hz
```

よって正答は2。5の48 Hzは `f1(1-s)` としてしまった誤りで、これは二次周波数の式ではない。

## 問5 本試験標準: 二次誘導起電力
停止時の二次誘導起電力を `E20=100 V` とする誘導電動機が、滑り `s=0.03` で運転している。運転中の二次誘導起電力 `E2s` はどれか。

1. 3 V
2. 30 V
3. 33.3 V
4. 97 V
5. 100 V

### 解答・解説
正答: 1

運転中の二次誘導起電力は滑りに比例するので、

```text
E2s = sE20
    = 0.03×100
    = 3 V
```

よって正答は1。滑りが小さい通常運転では、回転子と回転磁界の相対速度が小さくなるため、停止時より二次誘導起電力も小さくなる。

## 問6 本試験標準: 実回転速度
周波数50 Hz、6極、滑り `s=0.04` の誘導電動機の実回転速度 `N` はどれか。

1. 900 min^-1
2. 940 min^-1
3. 960 min^-1
4. 1000 min^-1
5. 1040 min^-1

### 解答・解説
正答: 3

同期速度は

```text
Ns = 120×50/6
   = 1000 min^-1
```

実回転速度は

```text
N = (1-s)Ns
  = (1-0.04)×1000
  = 960 min^-1
```

よって正答は3。誘導電動機の電動機運転では `N<Ns` であるため、1000 min^-1を超える選択肢は不適切である。

## 問7 本試験標準: 軸出力からトルク
誘導電動機の軸出力が `15.0 kW`、回転速度が `1440 min^-1` である。軸トルクとして最も近いものはどれか。

1. 79.6 N·m
2. 89.5 N·m
3. 99.5 N·m
4. 104 N·m
5. 157 N·m

### 解答・解説
正答: 3

軸出力と実回転角速度の関係は

```text
Pout = Tωm
ωm = 2πN/60
```

である。

```text
ωm = 2π×1440/60
   ≈ 150.8 rad/s
```

したがって

```text
T = 15000/150.8
  ≈ 99.5 N·m
```

よって正答は3。ここでは軸出力が与えられているため、同期角速度ではなく実回転速度から求めた `ωm` を使う。

## 問8 本試験標準: 同期ワットと機械出力
50 Hz、4極の誘導電動機が電磁トルク `100 N·m`、滑り `s=0.04` で運転している。機械損を無視するとき、二次入力 `P2` と機械出力 `Pout` の組合せとして最も近いものはどれか。

1. `P2=9.42 kW`, `Pout=9.04 kW`
2. `P2=15.7 kW`, `Pout=15.1 kW`
3. `P2=15.1 kW`, `Pout=15.7 kW`
4. `P2=25.1 kW`, `Pout=24.1 kW`
5. `P2=157 kW`, `Pout=151 kW`

### 解答・解説
正答: 2

同期速度は

```text
Ns = 120×50/4
   = 1500 min^-1
```

同期角速度は

```text
ωs = 2πNs/60
   = 2π×1500/60
   ≈ 157.1 rad/s
```

同期ワットの関係から

```text
P2 = Tωs
   = 100×157.1
   ≈ 15.7 kW
```

機械損を無視すると

```text
Pout = (1-s)P2
     = 0.96×15.7
     ≈ 15.1 kW
```

よって正答は2。二次入力 `P2` は軸出力より大きく、その差が二次銅損となる。

## 問9 本試験標準: 三相入力から二次入力
三相誘導電動機の線間電圧が `200 V`、線電流が `40 A`、力率が `0.80` である。鉄損 `500 W`、一次銅損 `300 W` とする。二次入力 `P2` として最も近いものはどれか。

1. 8.09 kW
2. 9.49 kW
3. 10.29 kW
4. 11.09 kW
5. 12.29 kW

### 解答・解説
正答: 3

三相入力は

```text
P1 = √3 VI cosφ
```

より、

```text
P1 = √3×200×40×0.80
   ≈ 11.09 kW
```

二次入力は一次入力から固定子側の鉄損と一次銅損を差し引く。

```text
P2 = P1-Pi-Pc1
   = 11.09-0.50-0.30
   ≈ 10.29 kW
```

よって正答は3。4は固定子損失を差し引いていない誤りである。

## 問10 本試験標準: 二次銅損と機械変換電力
二次入力 `P2=20.0 kW`、滑り `s=0.05` の誘導電動機について、二次銅損 `Pc2` と機械変換電力 `Pm` の組合せとして正しいものはどれか。

1. `Pc2=0.5 kW`, `Pm=19.5 kW`
2. `Pc2=1.0 kW`, `Pm=19.0 kW`
3. `Pc2=1.0 kW`, `Pm=20.0 kW`
4. `Pc2=19.0 kW`, `Pm=1.0 kW`
5. `Pc2=20.0 kW`, `Pm=19.0 kW`

### 解答・解説
正答: 2

二次入力は、二次銅損と機械変換電力に分かれる。

```text
Pc2 = sP2
    = 0.05×20.0
    = 1.0 kW
```

```text
Pm = (1-s)P2
   = 0.95×20.0
   = 19.0 kW
```

よって正答は2。`Pc2+Pm=20.0 kW=P2` となることが検算になる。

## 問11 複合・応用: 損失と効率
誘導電動機の一次入力が `30.0 kW`、鉄損が `0.80 kW`、一次銅損が `0.70 kW`、滑りが `0.04`、機械損が `0.50 kW` である。その他の損失を無視するとき、効率として最も近いものはどれか。

1. 85.0 %
2. 87.4 %
3. 89.5 %
4. 91.2 %
5. 95.0 %

### 解答・解説
正答: 3

まず二次入力を求める。

```text
P2 = P1-Pi-Pc1
   = 30.0-0.80-0.70
   = 28.5 kW
```

二次銅損を差し引いた機械変換電力は

```text
Pm = (1-s)P2
   = 0.96×28.5
   = 27.36 kW
```

さらに機械損を差し引く。

```text
Pout = 27.36-0.50
     = 26.86 kW
```

したがって効率は

```text
η = Pout/P1
  = 26.86/30.0
  ≈ 0.895
  = 89.5 %
```

よって正答は3。滑りをそのまま全損失率とみなして `η=96%` とするのは、固定子損失や機械損を無視する誤りである。

## 問12 複合・応用: 同期速度・滑り・同期ワット
60 Hz、4極の誘導電動機が `1710 min^-1` で回転し、電磁トルクが `120 N·m` である。機械損を無視するとき、滑り `s` と軸出力 `Pout` の組合せとして最も近いものはどれか。

1. `s=0.03`, `Pout=21.9 kW`
2. `s=0.05`, `Pout=21.5 kW`
3. `s=0.05`, `Pout=22.6 kW`
4. `s=0.10`, `Pout=20.4 kW`
5. `s=0.95`, `Pout=1.13 kW`

### 解答・解説
正答: 2

同期速度は

```text
Ns = 120×60/4
   = 1800 min^-1
```

したがって滑りは

```text
s = (1800-1710)/1800
  = 0.05
```

同期角速度は

```text
ωs = 2π×1800/60
   ≈ 188.5 rad/s
```

二次入力は同期ワットの関係から

```text
P2 = Tωs
   = 120×188.5
   ≈ 22.62 kW
```

機械損を無視するので、

```text
Pout = (1-s)P2
     = 0.95×22.62
     ≈ 21.49 kW
```

よって正答は2。3は二次入力をそのまま軸出力とした誤りである。
