# 練習問題

## 問1 基礎: 回転原理
三相かご形誘導電動機について正しい記述はどれか。

1. 回転子へ外部電源から三相交流を直接供給して回転磁界を作る。
2. 固定子の三相巻線が回転磁界を作り、回転子導体に誘導起電力と電流を生じさせ、その相互作用でトルクが発生する。
3. 回転子速度が同期速度に一致すると誘導起電力が最大になる。
4. 電動機運転では滑りは常に負になる。
5. トルク発生には整流子とブラシが必須である。

### 解答・解説
正答: 2

固定子の三相巻線へ三相交流を流すと回転磁界が生じる。回転磁界と回転子導体の間に相対速度があるため回転子に誘導起電力と電流が生じ、その電流と磁界の相互作用で電磁トルクが発生する。

1は誤り。かご形回転子へ外部から三相電源を直接接続しない。3は逆で、同期速度では相対速度が0となるため誘導起電力・回転子電流・トルクは0へ近づく。4も誤りで、通常の電動機運転では `0<s<1` である。5も誤りで、誘導電動機は整流子・ブラシを必要としない。

## 問2 基礎: 同期速度・滑り・二次周波数
周波数 `50 Hz`、4極の三相誘導電動機が `1440 min^-1` で回転している。二次周波数 `f2` はどれか。

1. 1.0 Hz
2. 2.0 Hz
3. 3.0 Hz
4. 4.0 Hz
5. 48 Hz

### 解答・解説
正答: 2

まず同期速度を求める。

```text
Ns = 120f/p
   = 120×50/4
   = 1500 min^-1
```

滑りは

```text
s = (Ns-N)/Ns
  = (1500-1440)/1500
  = 0.04
```

二次周波数は

```text
f2 = sf1
   = 0.04×50
   = 2.0 Hz
```

よって正答は2。5の48 Hzは `50×(1-s)` とした値であり、二次周波数ではない。

## 問3 基礎: `r2/s` の意味
三相誘導電動機の二次抵抗を一相当たり `r2=0.15 Ω`、滑りを `s=0.03` とする。三種範囲の二次等価回路で用いる `r2/s` はどれか。

1. 0.0045 Ω
2. 0.045 Ω
3. 0.15 Ω
4. 4.85 Ω
5. 5.00 Ω

### 解答・解説
正答: 5

運転時の二次電流は

```text
I2 = E20 / sqrt((r2/s)^2 + x20^2)
```

の形で扱える。したがって

```text
r2/s = 0.15/0.03
      = 5.00 Ω
```

よって正答は5。

さらに

```text
r2/s = r2 + r2(1-s)/s
     = 0.15 + 4.85
```

と分けられ、`r2` に対応する部分が二次銅損、残りが機械的に変換される電力へ対応する。4の4.85 Ωは機械変換側に対応する部分だけであり、`r2/s` 全体ではない。

## 問4 本試験標準: 三相一次入力から二次入力
三相誘導電動機の線間電圧が `400 V`、線電流が `30 A`、力率が `0.80` である。鉄損を `0.80 kW`、一次銅損を `0.60 kW` とすると、二次入力 `P2` として最も近いものはどれか。

1. 13.8 kW
2. 14.4 kW
3. 15.2 kW
4. 16.6 kW
5. 18.0 kW

### 解答・解説
正答: 3

三相一次入力は

```text
P1 = sqrt(3)VIcosφ
```

である。

```text
P1 = sqrt(3)×400×30×0.80
   ≈ 16.63 kW
```

二次入力は固定子側の損失を差し引く。

```text
P2 = P1-Pi-Pc1
   = 16.63-0.80-0.60
   = 15.23 kW
```

よって最も近い3が正答。4は固定子側損失を差し引いていない値である。

## 問5 本試験標準: 二次銅損と機械変換電力
二次入力 `P2=18.0 kW`、滑り `s=0.04` の誘導電動機について、二次銅損 `Pc2` と機械変換電力 `Pm` の組合せとして正しいものはどれか。

1. `Pc2=0.36 kW`, `Pm=17.64 kW`
2. `Pc2=0.72 kW`, `Pm=17.00 kW`
3. `Pc2=0.72 kW`, `Pm=17.28 kW`
4. `Pc2=4.50 kW`, `Pm=13.50 kW`
5. `Pc2=17.28 kW`, `Pm=0.72 kW`

### 解答・解説
正答: 3

二次銅損は

```text
Pc2 = sP2
    = 0.04×18.0
    = 0.72 kW
```

機械変換電力は

```text
Pm = (1-s)P2
   = 0.96×18.0
   = 17.28 kW
```

また `Pc2+Pm=P2=18.0 kW` となり、電力収支も一致する。よって正答は3。

## 問6 本試験標準: 同期ワットからトルク
周波数 `60 Hz`、6極の三相誘導電動機の二次入力が `25.1 kW` である。電磁トルクとして最も近いものはどれか。

1. 100 N·m
2. 150 N·m
3. 200 N·m
4. 250 N·m
5. 300 N·m

### 解答・解説
正答: 3

同期速度は

```text
Ns = 120×60/6
   = 1200 min^-1
```

同期角速度は

```text
ωs = 2πNs/60
   = 2π×1200/60
   ≈ 125.7 rad/s
```

二次入力と電磁トルクの関係は

```text
P2 = Tωs
```

なので、

```text
T = P2/ωs
  = 25100/125.7
  ≈ 200 N·m
```

よって正答は3。二次入力に対しては実回転角速度ではなく同期角速度を使う。

## 問7 本試験標準: 効率
三相誘導電動機の一次入力が `30.0 kW`、固定子側損失の合計が `1.20 kW`、滑りが `0.05`、機械損が `0.36 kW` である。効率として正しいものはどれか。

1. 85.0 %
2. 88.0 %
3. 90.0 %
4. 91.2 %
5. 95.0 %

### 解答・解説
正答: 3

まず二次入力は

```text
P2 = 30.0-1.20
   = 28.8 kW
```

機械変換電力は

```text
Pm = (1-s)P2
   = 0.95×28.8
   = 27.36 kW
```

軸出力は機械損を差し引き、

```text
Pout = 27.36-0.36
     = 27.00 kW
```

したがって効率は

```text
η = Pout/P1
  = 27.00/30.0
  = 0.900
  = 90.0 %
```

よって正答は3。機械損を二次入力の前で差し引かないことが重要である。

## 問8 本試験標準: 最大トルクと二次抵抗
巻線形三相誘導電動機について、簡略等価回路・同一電源条件で二次抵抗を増加させたときのトルク-滑り特性の説明として正しいものはどれか。

1. 最大トルクは必ず0になる。
2. 最大トルクは小さくなり、そのときの滑りも小さくなる。
3. 最大トルクは大きくなり、そのときの滑りは変化しない。
4. 最大トルクの大きさはほぼ変わらず、最大トルクを生じる滑りは大きくなる。
5. 二次抵抗を変えてもトルク-滑り特性は全く変化しない。

### 解答・解説
正答: 4

三種で用いる簡略等価回路では、同一電源条件で二次抵抗を増やすと、最大トルクを生じる滑りは大きい側へ移る。一方、最大トルクの大きさはほぼ変わらない。

これはトルク特性が `r2/s` に強く支配され、同じ比を保つには二次抵抗 `r2` が大きいほど滑り `s` も大きくなるためである。1、2、3、5はいずれもこの比例推移と矛盾する。

## 問9 本試験標準: 比例推移
巻線形誘導電動機が、二次抵抗 `r2=0.20 Ω` のとき滑り `s=0.030` であるトルクを発生している。電源条件を変えず、二次抵抗を `0.30 Ω` に増加させた後も同じトルクを発生するとする。比例推移による新しい滑りはどれか。

1. 0.020
2. 0.030
3. 0.040
4. 0.045
5. 0.060

### 解答・解説
正答: 4

比例推移では、同一トルク点について

```text
r2/s = 一定
```

とみなせる。したがって

```text
0.20/0.030 = 0.30/s'
```

より、

```text
s' = 0.030×0.30/0.20
   = 0.045
```

よって正答は4。二次抵抗を1.5倍にすると、同一トルク点の滑りも1.5倍となる。

## 問10 本試験標準: 未知損失を含む電力フロー
三相誘導電動機の一次入力が `25.0 kW`、鉄損が `1.0 kW`、滑りが `0.04` である。一次銅損は二次銅損 `Pc2` の `0.5` 倍であるとする。二次銅損 `Pc2` として最も近いものはどれか。

1. 0.80 kW
2. 0.94 kW
3. 1.00 kW
4. 1.20 kW
5. 1.50 kW

### 解答・解説
正答: 2

二次入力を `P2` とすると、固定子側損失を差し引いて

```text
P2 = 25.0-1.0-0.5Pc2
   = 24.0-0.5Pc2
```

また、二次銅損は

```text
Pc2 = sP2
    = 0.04P2
```

なので、

```text
Pc2 = 0.04(24.0-0.5Pc2)
Pc2 = 0.96-0.02Pc2
1.02Pc2 = 0.96
Pc2 ≈ 0.941 kW
```

よって正答は2。未知の二次銅損が固定子側損失にも含まれる条件では、`Pc2=sP2` と電力フローを同時に立式する。

## 問11 複合・応用: 二次銅損から軸出力まで逆算
三相誘導電動機の二次銅損が `0.80 kW`、滑りが `0.04`、機械損が `0.20 kW` である。軸出力 `Pout` はどれか。

1. 18.0 kW
2. 18.4 kW
3. 19.0 kW
4. 19.2 kW
5. 20.0 kW

### 解答・解説
正答: 3

二次銅損は

```text
Pc2 = sP2
```

なので、二次入力は

```text
P2 = Pc2/s
   = 0.80/0.04
   = 20.0 kW
```

機械変換電力は

```text
Pm = (1-s)P2
   = 0.96×20.0
   = 19.2 kW
```

軸出力は機械損を差し引いて

```text
Pout = Pm-Pmec
     = 19.2-0.20
     = 19.0 kW
```

よって正答は3。4は機械損を差し引く前の機械変換電力である。

## 問12 複合・応用: 微小滑り領域と比例推移
周波数 `50 Hz`、4極の巻線形誘導電動機が `1455 min^-1` で運転している。問題文で、対象範囲ではトルク `T` が滑り `s` に比例するとする。負荷トルクを2倍にした後、同じ負荷トルクのまま二次抵抗を元の `1.5` 倍にした。全過程がこの近似の適用範囲内にあるとき、最終的な回転速度として正しいものはどれか。

1. 1275 min^-1
2. 1335 min^-1
3. 1365 min^-1
4. 1410 min^-1
5. 1455 min^-1

### 解答・解説
正答: 3

同期速度は

```text
Ns = 120×50/4
   = 1500 min^-1
```

初期滑りは

```text
s1 = (1500-1455)/1500
   = 0.030
```

問題文で `T∝s` が成立するとされているので、負荷トルクを2倍にすると、二次抵抗を変える前の滑りは

```text
s2 = 2s1
   = 0.060
```

次に同じトルクのまま二次抵抗を1.5倍にする。比例推移より同一トルク点では `r2/s` が一定なので、滑りも1.5倍になる。

```text
s3 = 1.5s2
   = 0.090
```

最終回転速度は

```text
N = (1-s3)Ns
  = 0.91×1500
  = 1365 min^-1
```

よって正答は3。`T∝s` は常に使える一般式ではなく、問題文で微小滑り領域として与えられた条件内だけで使う。
