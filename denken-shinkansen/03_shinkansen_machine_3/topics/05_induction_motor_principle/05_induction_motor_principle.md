## 過去問とSPECから確定した教材必須範囲

### 1. 回転磁界からトルク発生まで
- 三相固定子電流が回転磁界を作ることを説明する。
- 回転磁界と回転子導体の相対運動により誘導起電力・回転子電流が生じる流れを説明する。
- 回転子電流と回転磁界の相互作用で電磁トルクが生じることを説明する。
- 負荷時に回転子が同期速度へ完全一致すると相対速度、誘導起電力、回転子電流、トルクが失われるため、電動機運転では正の滑りが必要になることを説明する。

### 2. 同期速度・滑り・二次周波数
- `Ns=120f/p`。
- `s=(Ns-N)/Ns`、`N=(1-s)Ns`。
- `f2=sf1`。
- 停止時 `s=1`、同期速度へ近づくと `s→0` となる意味を説明する。

### 3. 三種で必要な範囲の等価回路
- 停止時二次誘導起電力を `E20`、停止時二次リアクタンスを `x20` とし、運転時は `E2=sE20`、`x2=sx20` となることを示す。
- 二次電流を `I2=sE20/√(r2^2+(sx20)^2)` と表し、分子・分母を `s` で割って `I2=E20/√((r2/s)^2+x20^2)` と見られることを示す。
- `r2/s = r2 + r2(1-s)/s` の形が、二次銅損と機械的に変換される電力の分担へつながることを説明する。
- 詳細な円線図、複雑な厳密等価回路計算は追加しない。

### 4. 電力フロー・損失・効率
- 三相一次入力 `P1=√3VIcosφ`。
- 固定子側損失を差し引き、`P2=P1-Pi-Pc1` とする。
- `Pc2=sP2`。
- `Pm=(1-s)P2`。
- 機械損が与えられるとき `Pout=Pm-Pmec`、無視指定なら `Pout=Pm`。
- `η=Pout/P1`。
- `P1 → 固定子損失 → P2 → Pc2/Pm → 機械損 → Pout` の順で追えるようにする。

### 5. トルク
- 同期角速度 `ωs=2πNs/60` と二次入力の関係 `P2=Tωs` を扱う。
- 実回転角速度 `ωm=2πN/60` と機械変換電力の関係 `Pm=Tωm` を扱う。
- 軸出力からトルクを求める場合は機械損の有無を確認し、電磁トルクと軸トルクを混同しない。

### 6. 最大トルクと比例推移
- トルク-速度（またはトルク-滑り）特性上の最大トルクを停動トルクとして説明する。
- 電源条件と他の定数が同じなら、二次抵抗を変えても最大トルクの大きさは変わらず、その発生滑りが移動する関係を扱う。
- 同一トルク点では `r2/s` が同じになるため、二次抵抗を `k` 倍すると対応する滑りも `k` 倍になる比例推移を説明する。
- 問題文で微小滑り領域の `T∝s` が与えられる場合、その条件内でのみ使用する。
- Y-Δ始動、始動補償器、インバータによる速度制御等へ広げない。

### 7. 再利用可能な解法手順
1. 周波数・極数から同期速度を求める。
2. 実回転速度または滑りから、残りの一方を求める。
3. 電力問題では `P1 → P2 → Pm → Pout` のどこが与えられ、どこを求めるかを整理する。
4. `Pc2=sP2` と `Pm=(1-s)P2` を使い、損失を差し引く位置を間違えない。
5. トルク問題では同期角速度と実回転角速度のどちらを使う式かを判定する。
6. 比例推移では「同一トルク」「他条件一定」を確認してから二次抵抗比と滑り比を対応させる。
7. 最後に `0<s<1`、入力が出力より大きいこと、単位と桁を検算する。
