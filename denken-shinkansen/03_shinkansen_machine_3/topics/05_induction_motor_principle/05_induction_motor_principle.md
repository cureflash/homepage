## 過去問とSPECから確定した教材必須範囲

### 1. 回転磁界からトルク発生まで
- 三相固定子電流が回転磁界を作ることを説明する。
- 回転磁界と回転子導体の相対運動により誘導起電力・回転子電流が生じる流れを説明する。
- 回転子電流と回転磁界の相互作用で電磁トルクが生じることを説明する。
- 負荷時に回転子が同期速度へ完全一致すると相対速度、誘導起電力、回転子電流、トルクが失われるため、電動機運転では正の滑りが必要になることを説明する。

### 2. 同期速度・滑り・二次周波数
- `Ns=120f/p`。
- `s=(Ns-N)/Ns`、`N=(1-s)Ns`。
- `f2=sf1`。
- 停止時 `s=1`、同期速度へ近づくと `s→0` となる意味を説明する。

### 3. 三種で必要な範囲の等価回路
- 停止時二次誘導起電力を `E20`、停止時二次リアクタンスを `x20` とし、運転時は `E2=sE20`、`x2=sx20` となることを示す。
- 二次電流を `I2=sE20/√(r2^2+(sx20)^2)` と表し、分子・分母を `s` で割って `I2=E20/√((r2/s)^2+x20^2)` と見られることを示す。
- `r2/s = r2 + r2(1-s)/s` の形が、二次銅損と機械的に変換される電力の分担へつながることを説明する。
- 詳細な円線図、複雑な厳密等価回路計算は追加しない。

### 4. 電力フロー・損失・効率
- 三相一次入力 `P1=√3VIcosφ`。
- 固定子側損失を差し引き、`P2=P1-Pi-Pc1` とする。
- `Pc2=sP2`。
- `Pm=(1-s)P2`。
- 機械損が与えられるとき `Pout=Pm-Pmec`、無視指定なら `Pout=Pm`。
- `η=Pout/P1`。
- `P1 → 固定子損失 → P2 → Pc2/Pm → 機械損 → Pout` の順で追えるようにする。

### 5. トルク
- 同期角速度 `ωs=2πNs/60` と二次入力の関係 `P2=Tωs` を扱う。
- 実回転角速度 `ωm=2πN/60` と機械変換電力の関係 `Pm=Tωm` を扱う。
- 軸出力からトルクを求める場合は機械損の有無を確認し、電磁トルクと軸トルクを混同しない。

### 6. 最大トルクと比例推移
- トルク-速度（またはトルク-滑り）特性上の最大トルクを停動トルクとして説明する。
- 電源条件と他の定数が同じなら、二次抵抗を変えても最大トルクの大きさは変わらず、その発生滑りが移動する関係を扱う。
- 同一トルク点では `r2/s` が同じになるため、二次抵抗を `k` 倍すると対応する滑りも `k` 倍になる比例推移を説明する。
- 問題文で微小滑り領域の `T∝s` が与えられる場合、その条件内でのみ使用する。
- Y-Δ始動、始動補償器、インバータによる速度制御等へ広げない。

### 7. 再利用可能な解法手順
1. 周波数・極数から同期速度を求める。
2. 実回転速度または滑りから、残りの一方を求める。
3. 電力問題では `P1 → P2 → Pm → Pout` のどこが与えられ、どこを求めるかを整理する。
4. `Pc2=sP2` と `Pm=(1-s)P2` を使い、損失を差し引く位置を間違えない。
5. トルク問題では同期角速度と実回転角速度のどちらを使う式かを判定する。
6. 比例推移では「同一トルク」「他条件一定」を確認してから二次抵抗比と滑り比を対応させる。
7. 最後に `0<s<1`、入力が出力より大きいこと、単位と桁を検算する。

# 解説本文

## 1. このテーマで電験は何を問うか

このテーマの中心は、誘導電動機で「電気入力がどこで損失になり、どこから機械出力になるか」を、滑りと等価回路で追えるようにすることである。

本試験では主に次を問う。

- 周波数と極数から同期速度を求める。
- 同期速度と実回転速度から滑りを求める、または逆算する。
- 滑りから二次周波数を求める。
- 一次入力から固定子損失を引いて二次入力を求める。
- `Pc2=sP2`、`Pm=(1-s)P2` を使って二次銅損・機械変換電力を求める。
- 同期角速度または実回転角速度を使い分けてトルクを求める。
- 二次抵抗を変えたときの最大トルクと比例推移を判定する。

暗記すべき式だけでなく、`P1 → P2 → Pm → Pout` のどこを計算しているかを毎回確認する。

## 2. なぜ回転子は回るのか

三相交流を固定子巻線へ流すと、空間的に回転する磁界が生じる。この回転磁界の速度が同期速度 `Ns` である。

停止している回転子から見ると、回転磁界が回転子導体を横切るため誘導起電力が生じる。回転子回路が閉じているので回転子電流が流れ、その電流と回転磁界の相互作用によって電磁トルクが生じる。

回転子が回転磁界と完全に同じ速度になれば相対速度が0となり、誘導起電力、回転子電流、電磁トルクも0になる。したがって負荷を持って電動機として運転するには、回転子速度 `N` は同期速度 `Ns` より少し低くなり、正の滑りが必要である。

## 3. 同期速度・滑り・二次周波数

極数を `p`、一次周波数を `f1 [Hz]` とすると、同期速度は

`Ns = 120 f1 / p  [min^-1]`

である。

滑りは

`s = (Ns - N) / Ns`

したがって実回転速度は

`N = (1-s)Ns`

である。停止時は `N=0` なので `s=1`、同期速度へ近づくと `s→0` となる。

回転子から見た磁界の相対速度は滑りに比例するため、二次周波数は

`f2 = s f1`

となる。滑りを百分率で与えられた場合は、必ず小数へ直してから式へ代入する。

## 4. 三種で必要な二次等価回路

停止時の二次誘導起電力を `E20`、停止時二次リアクタンスを `x20`、二次抵抗を `r2` とする。運転時は相対速度が滑り `s` 倍なので、

`E2 = sE20`

`x2 = sx20`

となる。したがって二次電流は

`I2 = sE20 / √(r2^2 + (sx20)^2)`

である。分子・分母を `s` で割ると、

`I2 = E20 / √((r2/s)^2 + x20^2)`

と書ける。

ここで重要なのは `r2/s` である。

`r2/s = r2 + r2(1-s)/s`

と分けると、前半 `r2` は二次銅損、後半 `r2(1-s)/s` は機械的に変換される電力に対応する。この見方が `Pc2=sP2` と `Pm=(1-s)P2` につながる。

## 5. 誘導電動機の電力フロー

三相一次入力は、線間電圧 `V`、線電流 `I`、力率 `cosφ` を使って

`P1 = √3 V I cosφ`

で求める。

固定子側の鉄損 `Pi` と一次銅損 `Pc1` を差し引いたものが二次入力 `P2` である。

`P2 = P1 - Pi - Pc1`

二次入力は二次銅損 `Pc2` と機械変換電力 `Pm` に分かれる。

`Pc2 = sP2`

`Pm = (1-s)P2`

したがって

`P2 = Pc2 + Pm`

である。さらに機械損 `Pmec` がある場合、軸出力は

`Pout = Pm - Pmec`

となる。効率は

`η = Pout / P1`

である。

計算では必ず次の順を描いてから数値を入れる。

`P1 → [鉄損・一次銅損] → P2 → [二次銅損] → Pm → [機械損] → Pout`

## 6. 二次銅損から逆算する

`Pc2=sP2` は、二次銅損から二次入力を逆算するときにも使う。

`P2 = Pc2 / s`

さらに

`Pm = P2 - Pc2 = (1-s)P2`

である。

過去問では `Pc2` と `s` だけを与え、二次入力や軸出力を順に求めさせる形がある。機械損が与えられている場合は、最後に `Pm` から差し引く。

## 7. トルクと「どの角速度を掛けるか」

誘導電動機では、二次入力と電磁トルクの間に

`P2 = Tωs`

の関係がある。ここで

`ωs = 2πNs/60`

は同期角速度である。

一方、機械変換電力は実際の回転速度に対応するため、

`Pm = Tωm`

`ωm = 2πN/60`

である。

この2式は矛盾しない。`N=(1-s)Ns` と `Pm=(1-s)P2` を使えば同じ電磁トルク `T` が得られる。

軸出力 `Pout` からトルクを求める場合は、機械損を差し引いた後の軸トルクを求めていることになる。問題文が電磁トルクを問うのか軸トルクを問うのかを区別する。

## 8. 最大トルクと比例推移

三種で扱う簡略二次等価回路では、電源条件と他の定数を一定とすると、トルクは概略

`T ∝ (r2/s) / {(r2/s)^2 + x20^2}`

で表せる。

この式は `r2/s = x20` のとき最大になる。したがって最大トルクが生じる滑りは

`s_m = r2 / x20`

となる。

ここから次の2点が重要である。

1. 二次抵抗 `r2` を大きくすると、最大トルクを生じる滑り `s_m` は大きくなる。
2. 同じ電源条件・他定数一定の簡略モデルでは、最大トルクの大きさ自体は二次抵抗によらない。

また同一トルク点では `r2/s` が同じなので、二次抵抗を `k` 倍すると対応する滑りも `k` 倍となる。

`r2' = k r2 → s' = k s`

これが比例推移である。適用時は「同一トルク」「電源条件など他条件一定」を確認する。

問題文が微小滑り領域について `T∝s` と明示している場合は、その条件内だけでトルク比と滑り比を直接対応させる。

## 9. 解法アルゴリズム

### 速度・滑り問題
1. `Ns=120f1/p` で同期速度を求める。
2. `s=(Ns-N)/Ns` または `N=(1-s)Ns` を使う。
3. 必要なら `f2=sf1` を使う。
4. `0<s<1` になっているか確認する。

### 電力・効率問題
1. 必要なら `P1=√3VIcosφ` で一次入力を求める。
2. 鉄損・一次銅損を引いて `P2` を求める。
3. `Pc2=sP2`、`Pm=(1-s)P2` へ分ける。
4. 機械損を引いて `Pout` を求める。
5. `η=Pout/P1` で効率を求める。
6. `P1>P2>Pm≥Pout` の大小関係を検算する。

### トルク問題
1. 問われているのが二次入力、機械変換電力、軸出力のどれかを判定する。
2. 二次入力なら `P2=Tωs`、機械変換電力なら `Pm=Tωm` を使う。
3. `ω=2πN/60` の `N` が同期速度か実回転速度かを確認する。

### 比例推移問題
1. 同一トルク・他条件一定か確認する。
2. `r2/s=一定` を使う。
3. `s'=(r2'/r2)s` を求める。
4. 必要なら `N'=(1-s')Ns` で回転速度へ戻す。

## 10. 3段階例題

### 例題1 基礎: 同期速度・滑り・二次周波数
50 Hz、4極の三相誘導電動機が1440 min^-1で回転している。同期速度、滑り、二次周波数を求める。

#### 解法
同期速度は

`Ns = 120×50/4 = 1500 min^-1`

滑りは

`s = (1500-1440)/1500 = 0.040`

したがって4.0 %である。

二次周波数は

`f2 = sf1 = 0.040×50 = 2.0 Hz`

#### 答
- 同期速度: `1500 min^-1`
- 滑り: `0.040 = 4.0 %`
- 二次周波数: `2.0 Hz`

#### 検算
実回転速度は同期速度より低く、`0<s<1` を満たす。

### 例題2 本試験標準: 入力から軸出力・効率まで
三相誘導電動機の線間電圧が200 V、線電流40 A、力率0.80である。鉄損300 W、一次銅損400 W、滑り4.0 %、機械損270 Wとする。二次入力、二次銅損、機械変換電力、軸出力、効率を求める。

#### 解法
一次入力は

`P1 = √3×200×40×0.80 = 11085 W`

固定子側損失を引く。

`P2 = 11085-300-400 = 10385 W`

二次銅損は

`Pc2 = sP2 = 0.040×10385 = 415 W`

機械変換電力は

`Pm = (1-s)P2 = 0.960×10385 = 9970 W`

軸出力は

`Pout = 9970-270 = 9700 W`

効率は

`η = 9700/11085 = 0.875 ≒ 87.5 %`

#### 答
- 二次入力: `約10.39 kW`
- 二次銅損: `約0.415 kW`
- 機械変換電力: `約9.97 kW`
- 軸出力: `約9.70 kW`
- 効率: `約87.5 %`

#### 検算
`P2 = Pc2 + Pm = 0.415+9.970 ≒ 10.385 kW` で電力収支が一致する。

### 例題3 複合・ひっかけ: 比例推移とトルクの角速度
60 Hz、6極の巻線形誘導電動機が、ある負荷トルクで滑り3.0 %で運転している。電源条件と他の定数を変えず、二次抵抗を2倍にして同じ負荷トルクで運転する。新しい滑りと回転速度を求める。また、このとき電磁トルクが150 N·mであるとして二次入力と機械変換電力を求める。

#### 解法1 同期速度

`Ns = 120×60/6 = 1200 min^-1`

#### 解法2 比例推移
同一トルク点では `r2/s` が一定である。二次抵抗が2倍なので滑りも2倍になる。

`s' = 2×0.030 = 0.060`

実回転速度は

`N' = (1-0.060)×1200 = 1128 min^-1`

#### 解法3 二次入力
二次入力には同期角速度を使う。

`ωs = 2π×1200/60 = 40π rad/s`

`P2 = Tωs = 150×40π = 18850 W ≒ 18.85 kW`

#### 解法4 機械変換電力

`Pm = (1-s')P2 = 0.940×18.85 = 17.72 kW`

実回転角速度から確認すると、

`ωm = 2π×1128/60 = 37.6π rad/s`

`Tωm = 150×37.6π ≒ 17.72 kW`

となり一致する。

#### 答
- 新しい滑り: `0.060 = 6.0 %`
- 新しい回転速度: `1128 min^-1`
- 二次入力: `約18.85 kW`
- 機械変換電力: `約17.72 kW`

#### ひっかけ
`P2=Tωs` に実回転速度を入れない。また、比例推移は二次抵抗を2倍にしたからトルクも2倍になるという意味ではない。
