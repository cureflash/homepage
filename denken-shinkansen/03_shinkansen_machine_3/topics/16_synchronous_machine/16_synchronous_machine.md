# 解説本文

## 1. このテーマで電験は何を問うか

電験三種「機械」の同期機では、同期速度の計算だけでなく、同期発電機と同期電動機で界磁・電機子・力率がどう関係するか、同期リアクタンスを含むベクトル関係をどう読むか、V曲線をどう判断するか、同期発電機を系統へ並行投入するとき何を一致させるかが問われる。

固定EXAM_ALIGNMENTの6問では、同期速度、同期電動機のベクトル図、V曲線、電機子反作用、同期発電機の並行運転が必要である。本章を終えた時点で、次をできることを目標にする。

- 周波数 `f [Hz]` と極数 `P` から同期速度 `Ns [min^-1]` を求め、逆算もできる。
- 同期機では定常運転時の回転子速度が同期速度と一致し、誘導機のような定常すべりを必要としないことを区別する。
- 同期発電機・同期電動機で界磁と電機子の役割を説明する。
- 同期電動機の `V = E + jXsI` を用い、遅れ・進み力率を含むベクトル関係を判断する。
- 力率による電機子反作用の向きを区別する。
- V曲線の横軸・縦軸と、低励磁・力率1・過励磁の関係を判断する。
- 同期発電機を並行投入するとき、周波数・電圧の大きさ・位相を合わせ、同期検定器で確認する理由を説明する。
- 変圧器・直流機・誘導機・同期機の違いを、系列SPECで指定された項目だけで比較する。

## 2. 回転磁界と同期速度

三相交流を固定子巻線へ加えると、固定子には回転する磁界が生じる。その回転磁界の速度が同期速度 `Ns` であり、周波数 `f [Hz]`、極数 `P` との関係は

```text
Ns = 120f / P   [min^-1]
```

である。逆算すると、

```text
f = PNs / 120
P = 120f / Ns
```

となる。

例えば `f = 50 Hz`、`P = 4` なら、

```text
Ns = 120×50/4 = 1500 min^-1
```

である。

誘導電動機では、回転子に誘導電流を生じさせるため、電動機運転時の回転速度は同期速度より少し低く、すべりが生じる。これに対し同期電動機は、定常運転では回転子が回転磁界と同期して回るので、

```text
N = Ns
s = 0
```

として扱う。同期発電機も、発生周波数と極数に対応した同期速度で回転する。

## 3. 同期発電機・同期電動機、界磁・励磁・電機子

同期機では、回転磁界と回転子の磁界が同期して動く。三相同期機の基本モデルでは、固定子側の三相巻線を電機子、回転子側で磁界を作る部分を界磁として考える。

- 電機子: 三相交流の電圧・電流を扱う側。
- 界磁: 回転子に磁界を作る側。
- 励磁: 界磁を作るために界磁電流を与えること。

同期発電機では、原動機で回転子を同期速度で回し、界磁による磁束と電機子巻線の相対運動によって三相交流の起電力を得る。同期電動機では、固定子の回転磁界と回転子の界磁が同期し、電気入力を機械出力へ変換する。

界磁電流を変えると、同期機内部の誘導起電力 `E` の大きさが変わる。この関係は、同期発電機の並行運転で電圧の大きさを合わせるときや、同期電動機のV曲線で力率を変化させるときに重要になる。

## 4. 同期リアクタンスとベクトル関係

同期機の一相分を簡略化すると、電機子反作用と漏れリアクタンスの影響をまとめて同期リアクタンス `Xs [Ω]` として扱う。固定過去問では、この同期リアクタンスを含むベクトル関係を読めることが必要である。

本章では電機子巻線抵抗を無視する基本モデルを使う。同期電動機では、電機子電流 `I` の向きを電源から電動機へ流れ込む向きとして、

```text
V = E + jXsI
E = V - jXsI
```

とする。

ここで、

- `V`: 端子相電圧
- `E`: 内部誘導起電力
- `I`: 電機子電流
- `Xs`: 同期リアクタンス
- `j`: ベクトルを90°進める演算

である。したがって `jXsI` は、電流 `I` より必ず90°進んだ向きになる。

遅れ力率では `I` が `V` より遅れる。まず `I` を描き、その `I` を90°進めた向きに `jXsI` を定める。次に、式 `V = E + jXsI` をベクトル和として尾→頭で確認する。

```text
共通の始点 O から E を描く
E の終点を jXsI の始点にする
jXsI の終点が V の終点に一致する
```

つまり、正しい候補図では `jXsI` の矢印は「Eの終点 → Vの終点」を向く。`V` と `E` を共通の始点から描いたとき、二つの終点を結ぶ矢印を逆に読まない。`V` の終点から `E` の終点へ向く矢印なら `V = E + jXsI` を満たさない。この始点・終点確認を、位相角の確認とは別に必ず行う。

同期発電機では、電機子電流 `I` の正方向を発電機から外部へ流れ出す向きとして、同じ抵抗無視モデルを

```text
E = V + jXsI
```

と表す。発電機と電動機で式を混同しないため、問題文がどちらの運転か、電流の向きをどう定義しているかを先に確認する。

## 5. 電機子反作用と力率

電機子に電流が流れると、電機子電流自身も磁界を作り、界磁による主磁束へ影響する。これが電機子反作用である。同期発電機について三種の基本的な極限状態を整理すると、

| 発電機の力率状態 | 電機子反作用の基本 |
|---|---|
| 力率1 | 主磁束にほぼ直交する交差磁化作用 |
| 遅れ力率0 | 主磁束を弱める減磁作用 |
| 進み力率0 | 主磁束を強める増磁作用 |

中間の力率では、これらの作用が組み合わさると考える。

電験では「遅れだから増磁」「進みだから減磁」と逆に覚える誤りが起きやすい。固定過去問H26では、発電機としての力率と電機子反作用の対応を問うため、発電機・電動機のどちらを扱っているかを必ず確認する。

同期リアクタンス `Xs` は、この電機子反作用などによる電圧変化を等価回路上で扱うためのリアクタンスとして使う。本章では `Xs` の求め方を試験法へ広げず、与えられた `Xs` をベクトル関係に使う範囲に限定する。

## 6. 同期電動機のV曲線

同期電動機では、端子電圧と機械的な負荷を一定として界磁電流 `If` を変えると、電機子電流 `Ia` がV字状に変化する。この関係がV曲線である。

```text
縦軸: 電機子電流 Ia
横軸: 界磁電流 If
```

三種の基本モデルでは、

```text
界磁電流が小さい側（低励磁）  → 遅れ力率
電機子電流が最小付近          → 力率1
界磁電流が大きい側（過励磁）  → 進み力率
```

となる。

V曲線の問題では、横軸と縦軸を逆にしないことが第一である。次に、谷の位置を力率1、その左側を低励磁・遅れ、その右側を過励磁・進みとして読む。

V曲線は、界磁電流を変えると電機子電流と力率が変わることを示すためのグラフとして扱う。本章では同期調相機へ話を広げない。

## 7. 同期発電機の並行運転

複数の同期発電機を同じ交流系統へ接続して運転することを並行運転という。固定過去問で確認する並列投入前の基本条件は、次の三つである。

- 発電機電圧の大きさを系統電圧に合わせる。
- 発電機周波数を系統周波数に合わせる。
- 発電機電圧と系統電圧の位相を合わせる。

これらが合っているかを確認する器具として同期検定器を使う。

同期発電機の誘導起電力の大きさは、界磁電流を変えて調整する。投入前に位相を合わせるときは、原動機の回転速度を調整して発電機周波数と位相の進み遅れを整える。

並行運転へ入ると、各発電機は同じ系統周波数で運転する。したがって極数が異なる発電機同士でも、各機の回転速度は

```text
Ns = 120f / P
```

から決まる。極数が多い機ほど、同じ系統周波数では同期速度が低い。

また、並行運転中に発電機同士の起電力の大きさが不適切に異なると、無効横流が生じる。固定過去問では、起電力の大きさを界磁で調整することまでを扱う。

## 8. 問題を見たときの解法手順

### 同期速度・並行運転の計算

1. 問題文から極数 `P`、回転速度 `N`、周波数 `f` の既知量を抜き出す。
2. 同期機の定常状態なら `N = Ns` と判断する。
3. `Ns = 120f/P` を使い、最初の機から周波数を求める。
4. 並行運転なら他の同期発電機も同じ系統周波数を使う。
5. 別の極数を `Ns = 120f/P` へ代入し、必要な同期速度を求める。
6. 極数が増えれば同じ周波数で速度が下がることを検算する。

### 同期電動機のベクトル図

1. 電動機か発電機かを確認する。
2. 力率が遅れ・進み・1のどれかを確認する。
3. 同期電動機では `V = E + jXsI` を使う。
4. `I` を `V` に対して遅れ・進みの指定どおり配置する。
5. `jXsI` の向きを `I` より90°進みとして決める。
6. `V` と `E` の始点を共通に取り、`E` の終点から `jXsI` を尾→頭で置く。
7. `jXsI` の終点が `V` の終点に一致する候補だけを残す。`V` の終点から `E` の終点へ向く逆向き矢印は除外する。
8. 最後に `E + jXsI = V` と読めるかを式へ戻して検算する。

### V曲線・電機子反作用

1. V曲線なら横軸が界磁電流、縦軸が電機子電流か確認する。
2. 谷付近を力率1とし、低励磁側を遅れ、過励磁側を進みとして読む。
3. 電機子反作用なら、まず同期発電機の問題か確認する。
4. 力率1=交差磁化、遅れ力率0=減磁、進み力率0=増磁を基準に判断する。

### 並列投入の知識問題

1. 合わせる量が電圧の大きさ・周波数・位相か確認する。
2. 電圧の大きさは界磁電流で調整する。
3. 投入前の周波数・位相は原動機の回転速度を調整して合わせる。
4. 同期状態の確認器具は同期検定器と判断する。
5. 並行運転中は同一系統周波数を使う。

## 9. 典型例題（3段階）

### 基礎例題 — 同期速度

50 Hz、4極の同期機の同期速度を求める。

```text
Ns = 120f/P
   = 120×50/4
   = 1500 min^-1
```

答えは `1500 min^-1`。極数を極対数と取り違えない。

### 本試験標準例題A — 並行運転する別極数機の回転速度

6極の同期発電機Aが `1000 min^-1` で運転されている。Aと同じ交流系統へ4極の同期発電機Bを並行運転する。Bの同期速度を求める。

まずAから系統周波数を求める。

```text
f = PNs/120
  = 6×1000/120
  = 50 Hz
```

並行運転するBも同じ50 Hzなので、

```text
Ns = 120×50/4
   = 1500 min^-1
```

答えは `1500 min^-1`。AとBの極数が違っても、並行運転だから回転速度まで同じになるわけではない。同じなのは系統周波数である。

### 本試験標準例題B — 遅れ力率の同期電動機

同期電動機の一相分について、端子相電圧を `V = 200 + j0 V`、同期リアクタンスを `Xs = 2.0 Ω`、電機子電流を `I = 40 - j30 A` とする。電機子巻線抵抗を無視し、内部誘導起電力 `E` を求める。

電動機なので、

```text
V = E + jXsI
E = V - jXsI
```

を使う。

まず、

```text
jXsI = j2(40 - j30)
      = 60 + j80 V
```

したがって、

```text
E = (200 + j0) - (60 + j80)
  = 140 - j80 V
```

大きさは、

```text
|E| = √(140² + 80²)
    ≒ 161 V
```

となる。作図では `E` を共通原点から描き、その終点から `jXsI` を描いたときに `V` の終点へ到達する。`jXsI` を `I` と同じ向きに描くこと、またはVの終点からEの終点へ逆向きに描くことのどちらも誤りである。

### 複合・ひっかけ例題 — V曲線と並行運転の判断

次の記述の正誤を判断する。

1. 同期電動機のV曲線では、横軸が界磁電流、縦軸が電機子電流である。
2. 一定負荷の基本モデルでは、V曲線の電機子電流最小付近は力率1である。
3. 同期電動機を低励磁にすると進み力率になる。
4. 同期発電機を系統へ並列投入するとき、電圧の大きさ・周波数・位相を合わせる。
5. 同じ系統へ接続された4極機と6極機は、極数が違っても必ず同じ回転速度になる。

判断は、

```text
1 正しい
2 正しい
3 誤り: 低励磁は遅れ力率、過励磁が進み力率
4 正しい
5 誤り: 同じなのは系統周波数。同期速度は Ns = 120f/P で極数により異なる
```

となる。V曲線と並行運転を別々の暗記にせず、界磁・力率・同期速度の関係へ戻して判断する。

## 10. 新幹線への接続 — L0系リニア同期モータ

従来型の新幹線を学んできた本系列では、0系等で直流主電動機、300系以降の代表例で誘導電動機を扱った。同期機は、新幹線の主電動機だけに限定すると全体像をつかみにくいため、発電所の同期発電機と中央新幹線L0系のリニア同期モータを入口にする。

JR東海の公開説明では、リニアモーターを通常のモーターを開いて直線状にしたものとして説明している。本章では系列SPECどおり、回転同期機の「回転する磁界と磁極が同期する」という考え方を直線運動へ展開したものとして概念接続する。

ここではL0系の車上・地上設備の詳細構成、電圧・電流・推力・周波数等の未確認数値は扱わない。目的はL0系固有技術の解説ではなく、同期機の「同期」という考え方を具体化することである。

## 11. 四機比較

系列SPECで指定された比較項目だけを使い、変圧器・直流機・誘導機・同期機を整理する。

| 比較項目 | 変圧器 | 直流機 | 誘導機 | 同期機 |
|---|---|---|---|---|
| 固定子 | 回転機ではないため該当なし | 一般的な基本構成では界磁側 | 三相巻線、回転磁界を作る | 三相電機子巻線、回転磁界を作る |
| 回転子 | 回転機ではないため該当なし | 一般的な基本構成では電機子側 | 回転磁界により電流が誘導される | 界磁を持ち回転磁界と同期する |
| 励磁 | 一次側へ交流を加える | 界磁方式に応じて与える | かご形の基本では回転子へ外部励磁しない | 界磁を励磁する |
| 回転磁界 | なし | 三相回転磁界を基本原理としない | あり | あり |
| 同期速度 | 該当なし | 基本速度式は別 | `Ns = 120f/P`、電動機時は通常 `N < Ns` | `Ns = 120f/P`、定常時 `N = Ns` |
| すべり | 該当なし | 該当なし | 電動機運転で必要 | 定常同期時は0 |
| 整流子 | なし | あり | なし | なし |
| ブラシ | なし | 整流子と組み合わせて使用 | かご形では不要 | 界磁給電方式により有無が異なる |
| 速度制御 | 該当なし | 電機子電圧・界磁など | 主に供給周波数を変える | 同期速度は周波数・極数で決まる |
| 発電機運転 | 該当なし | 可能 | 可能 | 可能 |
| 主な用途 | 電圧変換 | 電動機・発電機 | 電動機 | 発電機・電動機 |

新幹線との接続は、変圧器=交流新幹線の主変圧器、直流機=0系等の直流主電動機、誘導機=300系以降の代表的主電動機、同期機=発電所の同期発電機とL0系リニア同期モータとして整理する。

## 12. 頻出ミス・ひっかけ

- `Ns = 120f/P` の `P` を極対数として代入する。
- 同期機でも誘導機と同じように定常すべりが必要だと思う。
- 並行運転で「同じ周波数」と「同じ回転速度」を混同する。
- 同期電動機の式 `V = E + jXsI` と同期発電機の式を、電流方向を確認せず混同する。
- `jXsI` を `I` と同じ向きに描き、90°進める操作を忘れる。
- `V = E + jXsI` の作図で、`jXsI` をEの終点からVの終点ではなく、Vの終点からEの終点へ逆向きに読む。
- V曲線の横軸と縦軸を逆にする。
- 低励磁=進み、過励磁=遅れと逆に覚える。
- 同期発電機の遅れ力率で電機子反作用を増磁と誤る。
- 並列投入前に電圧の大きさだけを合わせればよいと考える。
- 起電力の大きさを原動機速度で、位相を界磁で調整すると逆に覚える。
- 同期検定器の役割を電圧計と混同する。
