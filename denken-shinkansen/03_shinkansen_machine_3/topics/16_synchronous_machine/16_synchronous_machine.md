同期速度は既習の誘導機と同じ関係 `Ns = 120f / P` を用い、同期機では定常運転時に回転子が回転磁界と同期して回ることを比較する。四機比較は系列SPECにある固定子、回転子、励磁、回転磁界、同期速度、すべり、整流子、ブラシ、速度制御、発電機運転、主な用途だけを比較項目とする。

固定範囲外として、始動法・制動巻線、短絡比、無負荷飽和曲線・三相短絡曲線、同期インピーダンスを求める試験法、同期調相機、負荷角・脱出トルク・乱調、永久磁石同期機の詳細、突極機・円筒機の詳細理論は追加しない。過去問にこれらが正答要件として含まれる場合は品質ゲート対象から外す。
