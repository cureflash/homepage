# 練習問題

## 問1 基礎: 同期速度
周波数 `60 Hz`、6極の同期機の同期速度として正しいものはどれか。

1. 600 min^-1
2. 900 min^-1
3. 1200 min^-1
4. 1800 min^-1
5. 3600 min^-1

### 解答・解説
正答: 3

同期速度は、

`Ns = 120f/P`

より、

`Ns = 120×60/6 = 1200 min^-1`

となる。

`P` は極数であり、極対数ではない。6極を3として代入すると誤答になる。

## 問2 基礎: 同期機と誘導機
同期電動機と誘導電動機の定常運転時の回転速度について、正しいものはどれか。

1. 同期電動機は必ず同期速度より低く、誘導電動機は同期速度と等しい。
2. 同期電動機は同期速度と等しく、誘導電動機は通常、電動機運転では同期速度より低い。
3. 両者とも同期速度より必ず高い。
4. 両者とも同期速度と等しく、すべりは常に0である。
5. 同期電動機の速度は周波数と無関係である。

### 解答・解説
正答: 2

同期電動機は定常状態で回転子が回転磁界と同期して回るため `N = Ns`、すべりは0である。誘導電動機は通常の電動機運転では `N < Ns` で、すべりが必要になる。

4は誘導電動機まで同期速度と等しいとしている点が誤り。5も `Ns = 120f/P` から誤りである。

## 問3 基礎: 界磁と電機子
同期機の基本について正しいものはどれか。

1. 同期機では回転磁界を作らず、直流だけで電機子を回す。
2. 界磁電流を変えても内部誘導起電力の大きさは変化しない。
3. 同期機では整流子が必須である。
4. 同期機の定常速度は負荷だけで決まり、周波数と極数には無関係である。
5. 基本的な同期機では三相電機子巻線が回転磁界を作り、界磁を持つ回転子がその磁界と同期する。

### 解答・解説
正答: 5

基本的な同期機では、三相電機子巻線が回転磁界を作り、界磁を持つ回転子がその回転磁界と同期する。界磁電流を変えると内部誘導起電力 `E` の大きさも変化する。

1、3、4は同期機の基本構成・同期速度の関係に反する。2は界磁調整の役割を否定しているため誤りである。

## 問4 本試験標準: 並列投入条件
同期発電機を交流系統へ並列投入するとき、基本的に一致させる量と、それを確認する器具の組合せとして正しいものはどれか。

1. 電流の大きさ・有効電力・無効電力 / 電力計
2. 電圧の大きさ・電流の大きさ・力率 / 力率計
3. 周波数・有効電力・回転速度 / 周波数計
4. 電圧の大きさ・周波数・位相 / 同期検定器
5. 電圧の大きさ・極数・回転子電流 / 電圧計

### 解答・解説
正答: 4

並列投入前には、発電機電圧と系統電圧について、電圧の大きさ、周波数、位相を合わせる。同期状態の確認には同期検定器を用いる。

極数や有効電力を「一致させる量」とするのは誤りである。

## 問5 本試験標準: 別極数機の並行運転
10極の同期発電機Aが `600 min^-1` で運転している。Aと同じ交流系統へ4極の同期発電機Bを並行運転する。Bの同期速度として正しいものはどれか。

1. 600 min^-1
2. 1000 min^-1
3. 1500 min^-1
4. 1800 min^-1
5. 3000 min^-1

### 解答・解説
正答: 3

Aから系統周波数を求める。

`f = PNs/120 = 10×600/120 = 50 Hz`

並行運転するBも同じ `50 Hz` なので、

`Ns = 120f/P = 120×50/4 = 1500 min^-1`

となる。

同じ系統へ接続されても、極数が異なれば回転速度まで同じになるわけではない。同じなのは系統周波数である。

## 問6 本試験標準: 同期電動機のベクトル計算
同期電動機の一相分について、端子相電圧を `V = 200 + j0 V`、同期リアクタンスを `Xs = 1.5 Ω`、電機子電流を `I = 30 - j40 A` とする。電機子巻線抵抗を無視するとき、内部誘導起電力 `E` として正しいものはどれか。

1. `260 + j45 V`
2. `140 + j45 V`
3. `260 - j45 V`
4. `140 - j45 V`
5. `200 - j60 V`

### 解答・解説
正答: 4

同期電動機なので、

`V = E + jXsI`

したがって、

`E = V - jXsI`

を使う。

`jXsI = j1.5(30 - j40) = 60 + j45 V`

よって、

`E = (200 + j0) - (60 + j45) = 140 - j45 V`

となる。

検算として `E + jXsI = (140 - j45) + (60 + j45) = 200 + j0 = V` となる。発電機の式と混同しない。

## 問7 本試験標準: 電機子反作用
同期発電機の電機子反作用について、基本的な極限状態の対応として正しいものはどれか。

1. 力率1: 交差磁化、遅れ力率0: 減磁、進み力率0: 増磁
2. 力率1: 減磁、遅れ力率0: 増磁、進み力率0: 交差磁化
3. 力率1: 増磁、遅れ力率0: 交差磁化、進み力率0: 減磁
4. 力率1: 交差磁化、遅れ力率0: 増磁、進み力率0: 減磁
5. 力率によらず常に交差磁化だけである。

### 解答・解説
正答: 1

同期発電機では、三種の基本整理として、力率1で交差磁化、遅れ力率0で減磁、進み力率0で増磁となる。

4は遅れ・進みを逆にしている。発電機か電動機かを確認せず暗記だけで判断すると取り違えやすい。

## 問8 本試験標準: 並行運転の調整
同期発電機を系統へ並列投入する前の調整について、正しいものはどれか。

1. 起電力の大きさは原動機回転速度で、周波数と位相は界磁電流で調整する。
2. 起電力の大きさも周波数と位相も、すべて界磁電流だけで調整する。
3. 起電力の大きさも周波数と位相も、すべて原動機回転速度だけで調整する。
4. 界磁電流は同期速度だけを変え、原動機回転速度は起電力の大きさだけを変える。
5. 起電力の大きさは界磁電流で調整し、投入前の周波数・位相は原動機回転速度を調整して合わせる。

### 解答・解説
正答: 5

起電力の大きさは界磁電流で調整する。投入前の周波数と位相の進み遅れは、原動機の回転速度を調整して合わせる。

1と4は役割を逆にしている。2、3は一つの操作量ですべてを合わせるとしているため誤りである。

## 問9 本試験標準: V曲線
一定負荷・一定端子電圧の同期電動機のV曲線について、正しいものはどれか。

1. 横軸は電機子電流、縦軸は界磁電流で、谷の左側が進み力率である。
2. 横軸は界磁電流、縦軸は電機子電流で、電機子電流最小付近が力率1となる。
3. 横軸は回転速度、縦軸は電機子電流で、谷の位置は同期速度を示す。
4. 低励磁側が進み力率、過励磁側が遅れ力率となる。
5. 界磁電流を変えても電機子電流と力率は変化しない。

### 解答・解説
正答: 2

V曲線は横軸が界磁電流 `If`、縦軸が電機子電流 `Ia` で、電機子電流の最小付近が力率1に対応する。

低励磁側は遅れ力率、過励磁側は進み力率である。1と4はこの対応を逆にしている。

## 問10 本試験標準: 同期リアクタンスのベクトル関係
電機子巻線抵抗を無視した同期電動機について、正しいものはどれか。

1. `V = E - jXsI` で、`jXsI` は `I` より90°遅れる。
2. `E = V + jXsI` だけを用い、発電機と電動機で式は同じである。
3. `V = E + XsI` で、リアクタンス降下は電流と同相である。
4. `V = E + jXsI` で、`jXsI` は `I` より90°進む。
5. `Xs` は界磁電流そのものを表す。

### 解答・解説
正答: 4

同期電動機の基本モデルでは、

`V = E + jXsI`

である。`j` を掛けることはベクトルを90°進める操作なので、`jXsI` は `I` より90°進む。

発電機では電流の正方向の取り方に対応して `E = V + jXsI` と表すため、運転状態と電流方向を確認する必要がある。

## 問11 複合・応用: 同期速度と並列投入調整
8極の同期発電機Aが `750 min^-1` で運転している系統へ、12極の同期発電機Bを並列投入する。Bの端子電圧の大きさが系統より低く、位相もまだ一致していない。正しい組合せはどれか。

1. Bの同期速度は `500 min^-1`。電圧の大きさは界磁電流、周波数・位相は原動機回転速度を調整する。
2. Bの同期速度は `500 min^-1`。電圧の大きさは原動機回転速度、周波数・位相は界磁電流を調整する。
3. Bの同期速度は `750 min^-1`。電圧の大きさは界磁電流、周波数・位相は原動機回転速度を調整する。
4. Bの同期速度は `1000 min^-1`。電圧の大きさは界磁電流、周波数・位相は原動機回転速度を調整する。
5. Bの同期速度は `1500 min^-1`。電圧の大きさも周波数・位相も界磁電流だけで調整する。

### 解答・解説
正答: 1

まずAから系統周波数を求める。

`f = PNs/120 = 8×750/120 = 50 Hz`

したがってBの同期速度は、

`Ns = 120×50/12 = 500 min^-1`

となる。

並列投入前は、電圧の大きさを界磁電流で、周波数・位相を原動機回転速度の調整で合わせる。速度計算と調整量を別々に確認する。

## 問12 複合・応用: V曲線と電機子反作用
次の記述A〜Eについて、正しい記述だけを全て含む組合せはどれか。

A. 同期電動機のV曲線では、横軸を界磁電流、縦軸を電機子電流とする。  
B. 同期電動機の低励磁側は進み力率である。  
C. 同期発電機の遅れ力率0では、電機子反作用は減磁作用となる。  
D. 同期発電機の進み力率0では、電機子反作用は減磁作用となる。  
E. 同期電動機のV曲線では、電機子電流最小付近が力率1となる。

1. A、B
2. B、D
3. A、C
4. C、D、E
5. A、C、E

### 解答・解説
正答: 5

Aは正しい。V曲線は横軸が界磁電流、縦軸が電機子電流である。Bは誤りで、低励磁側は遅れ力率である。

Cは正しい。同期発電機の遅れ力率0では減磁作用となる。Dは誤りで、進み力率0では増磁作用となる。Eは正しく、V曲線の谷付近が力率1に対応する。

したがって正しい組合せはA、C、Eである。
