# 練習問題

## 問1 基礎: パワー半導体のオン・オフ
パワー半導体について正しい記述はどれか。

1. ダイオードはゲート電圧によって任意の時刻にターンオン・ターンオフできる。
2. 通常のサイリスタは、ゲート信号を除けば保持電流以上の順方向電流が流れていても直ちにターンオフする。
3. GTOはゲート信号によってターンオフできる自己消弧形素子である。
4. IGBTは電流駆動形であり、ゲートへ連続して大電流を流してオン状態を保つ。
5. パワーMOSFETはゲートでは制御できない。

### 解答・解説
正答: 3

GTOは Gate Turn-Off Thyristor であり、ゲート信号によってターンオフできる自己消弧形素子である。

1は誤り。ダイオードにはゲートがない。2は誤り。通常のサイリスタは一度オンすると、電流が保持電流未満になるなど回路側の条件が必要である。4は誤り。IGBTは絶縁ゲートを持つ電圧駆動形である。5も誤りで、パワーMOSFETはゲート電圧でオン・オフを制御する。

## 問2 基礎: MOSFETとIGBT
MOSFETとIGBTについて誤っているものはどれか。

1. パワーMOSFETは絶縁ゲートを持つ電圧駆動形である。
2. IGBTも絶縁ゲートを持つ電圧駆動形である。
3. パワーMOSFETはユニポーラ素子として扱い、高速スイッチングに向く。
4. IGBTではターンオフ時のキャリア蓄積によりテイル電流が生じることがある。
5. IGBT単体はMOSFETのボディーダイオードと同じ逆方向導通機能を必ず内蔵するため、逆並列ダイオードは不要である。

### 解答・解説
正答: 5

通常のIGBT単体をMOSFETのボディーダイオードと同一視してはいけない。誘導性負荷を扱うインバータでは、逆方向電流経路として逆並列ダイオードを組み合わせる。

1〜4は固定EXAM_ALIGNMENTで要求される基本特性として正しい。

## 問3 基礎: 逆方向電流の経路
インバータで誘導性負荷を駆動するときの逆方向電流について正しいものはどれか。

1. 通常のIGBT単体は常に逆方向電流を自由に流せるため、別の素子は不要である。
2. IGBTには逆並列ダイオードを組み合わせ、スイッチがオフした後も誘導性負荷電流の経路を確保する。
3. サイリスタは逆方向電流を流すために使う素子である。
4. ダイオードは逆バイアス時に大電流を流すことを目的とする。
5. 誘導性負荷ではスイッチをオフした瞬間に電流が必ず0になる。

### 解答・解説
正答: 2

インダクタンスを含む負荷では電流は瞬時に変化できない。IGBTなどをオフした後の電流経路を確保するため、逆並列ダイオードを組み合わせる。

1は通常のIGBT単体の扱いとして誤り。3と4は逆方向導通の理解が逆である。5は誘導性負荷の性質に反する。

## 問4 本試験標準: MOSFETの導通損失
パワーMOSFETに `25 A` の一定電流が流れ、オン抵抗を `0.040 Ω`、通流率を `0.80` とする。導通損失の平均値として正しいものはどれか。

1. `0.80 W`
2. `20 W`
3. `25 W`
4. `31.3 W`
5. `50 W`

### 解答・解説
正答: 2

MOSFETはオン抵抗モデルなので、オン中の損失は

```text
P_on = I²R_on
     = 25² × 0.040
     = 25 W
```

通流率が0.80なので平均導通損失は

```text
Pcond = 25 × 0.80
      = 20 W
```

よって正答は2。

検算: 通流率1のとき25 Wなので、通流率0.80の平均値は25 Wを超えない。

## 問5 本試験標準: スイッチング損失
ある素子の1回当たりのターンオン損失を `1.5 mJ`、ターンオフ損失を `2.5 mJ`、スイッチング周波数を `12 kHz` とする。平均スイッチング損失として正しいものはどれか。

1. `4.0 W`
2. `12 W`
3. `30 W`
4. `48 W`
5. `300 W`

### 解答・解説
正答: 4

使用式は

```text
Psw = (Eon + Eoff)fs
```

である。

```text
Eon + Eoff = 4.0 mJ = 4.0×10^-3 J
fs = 12 kHz = 1.2×10^4 Hz

Psw = 4.0×10^-3 × 1.2×10^4
    = 48 W
```

よって正答は4。

検算: `J × 1/s = W` となる。mJ、kHzをSI単位へ直してから掛ける。

## 問6 本試験標準: 総損失と変換効率
出力電力が `9.90 kW` の変換器で、導通損失が `40 W`、スイッチング損失が `60 W`、その他の損失を無視する。変換効率として正しいものはどれか。

1. `90.0 %`
2. `97.0 %`
3. `98.0 %`
4. `99.0 %`
5. `101.0 %`

### 解答・解説
正答: 4

総損失は

```text
Ploss = 40 + 60 = 100 W
```

入力電力は

```text
Pin = Pout + Ploss
    = 9900 + 100
    = 10000 W
```

したがって

```text
η = Pout / Pin
  = 9900 / 10000
  = 0.990
  = 99.0 %
```

よって正答は4。

`Pout/Ploss` を効率としない。

## 問7 本試験標準: スイッチング周波数を2倍にしたとき
ある素子の導通損失は `30 W` で一定とする。`Eon+Eoff=2.0 mJ`、`fs=10 kHz` のとき、周波数だけを `20 kHz` に変更した。変更後の総損失として正しいものはどれか。

1. `40 W`
2. `50 W`
3. `60 W`
4. `70 W`
5. `100 W`

### 解答・解説
正答: 4

変更後のスイッチング損失は

```text
Psw = 2.0×10^-3 × 2.0×10^4
    = 40 W
```

導通損失30 Wは条件上変化しないので、

```text
Ploss = 30 + 40
      = 70 W
```

よって正答は4。

周波数が2倍になっても、この条件で2倍になるのはスイッチング損失であり、総損失そのものではない。

## 問8 本試験標準: IGBTの導通損失
IGBTのオン電圧降下を `1.7 V`、オン中の電流を `40 A`、通流率を `0.75` とする。平均導通損失として正しいものはどれか。

1. `31 W`
2. `40 W`
3. `51 W`
4. `68 W`
5. `91 W`

### 解答・解説
正答: 3

IGBTを一定オン電圧降下で近似するので、オン中の損失は

```text
P_on = V_on I
     = 1.7 × 40
     = 68 W
```

平均値は通流率を掛けて

```text
Pcond = 68 × 0.75
      = 51 W
```

よって正答は3。

MOSFETの `I²R_on` と混同しない。

## 問9 本試験標準: SiCの特徴
SiCを用いるパワーデバイスについて最も適切なものはどれか。

1. SiCを使えば導通損失とスイッチング損失は必ず0になる。
2. SiCを使えば発熱がなくなるため冷却装置は不要になる。
3. SiCは高耐圧・高耐熱化や低損失化に有利で、SiC MOSFETでは高耐圧用途でも低オン抵抗と高速スイッチングを両立しやすい。
4. SiCは低電圧・低温用途にしか使えない。
5. SiC化では損失が増えることが主目的である。

### 解答・解説
正答: 3

本テーマで押さえるSiCの要点は、高耐圧・高耐熱化や低損失化に有利であること、SiC MOSFETでは高耐圧用途でも低オン抵抗と高速スイッチングを両立しやすいことである。

1と2は「損失ゼロ」「冷却不要」とするため誤り。4と5も特徴と逆である。材料物性の詳細までは扱わない。

## 問10 本試験標準: パワートランジスタのスイッチ動作
パワートランジスタを電力スイッチとして用いるとき、基本的に切り換えて使う動作領域の組合せとして正しいものはどれか。

1. 遮断領域と飽和領域
2. 遮断領域と能動領域
3. 能動領域と降伏領域
4. 飽和領域と降伏領域
5. 能動領域だけ

### 解答・解説
正答: 1

電力スイッチでは、オフに相当する遮断領域とオンに相当する飽和領域を基本的に使う。能動領域は増幅動作に用いる領域であり、オン・オフする電力スイッチの基本動作領域ではない。

H23機械問10で必要な範囲だけを扱い、トランジスタ物性の詳細へは拡張しない。

## 問11 複合・応用: インバータとPWM
直流電源から可変交流を作るインバータについて正しい記述はどれか。

1. IGBTはオン・オフできないため、PWMには使用できない。
2. 誘導性負荷ではスイッチをオフした瞬間に電流が0になるので、逆並列ダイオードは不要である。
3. PWMはパルス幅を変えることで平均的な電圧や基本波成分を制御する。
4. インバータは交流を直流へ変換する回路である。
5. 逆並列ダイオードはIGBTのゲート電圧を発生するために接続する。

### 解答・解説
正答: 3

PWMではパルス幅を変えて平均的な電圧や基本波成分を制御する。IGBTは自己消弧形でオン・オフ制御でき、誘導性負荷では逆並列ダイオードが電流経路を確保する。

1、2、4、5はいずれも役割を取り違えている。H30機械問11で要求される「IGBT＋逆並列ダイオード＋インバータ＋PWM」の関係を確認する問題である。

## 問12 複合・応用: 損失低減と小型軽量化
同じ `20.0 kW` を出力する二つの変換器A、Bを比較する。その他の損失は無視する。

- A: 導通損失 `180 W`、`Eon+Eoff=6.0 mJ`、`fs=10 kHz`
- B: 導通損失 `100 W`、`Eon+Eoff=2.5 mJ`、`fs=10 kHz`

正しい記述はどれか。

1. Aの総損失は `186 W` である。
2. Bの総損失は `102.5 W` である。
3. Bの総損失は `125 W`、効率は約 `99.4 %` で、Aより損失が `115 W` 小さい。
4. BはAより損失が小さいため、必ず車両全体の質量が `115 kg` 減る。
5. 損失低減は発熱や冷却装置の大きさと無関係である。

### 解答・解説
正答: 3

Aのスイッチング損失は

```text
Psw,A = 6.0×10^-3 × 1.0×10^4
      = 60 W
```

したがって

```text
Ploss,A = 180 + 60
        = 240 W
```

Bでは

```text
Psw,B = 2.5×10^-3 × 1.0×10^4
      = 25 W

Ploss,B = 100 + 25
        = 125 W
```

Bの効率は

```text
ηB = 20000 / (20000 + 125)
   ≈ 0.9938
   ≈ 99.4 %
```

損失差は

```text
240 - 125 = 115 W
```

よって正答は3。

損失低減は発熱低減につながり、必要な冷却能力を小さくしやすい。その結果として主変換装置の小型軽量化へつながる。ただし、損失差をそのまま車両質量の減少量へ換算することはできないので4は誤りである。
