### 制作前検証

問題文の各選択肢を固定範囲の知識で判定し、その後に公式解答と照合した。

1. R5上 問10
   - 通常のIGBT単体はMOSFETのボディーダイオードのような逆方向導通を前提としないため、(1)が誤り。
   - 解答: `(1)` → 公式 `(1)`、PASS。
2. R2 問10
   - パワーMOSFETは電圧駆動形で、キャリア蓄積効果がないため高速スイッチングに向く。「電流駆動形でキャリア蓄積によりスイッチング損失が大きい」とする(2)が誤り。
   - 解答: `(2)` → 公式 `(2)`、PASS。
3. H30 問11
   - 直流から交流へ変換するのでインバータ。IGBTはオンオフ制御可能で、逆並列素子はダイオード。直流電圧変更は交流波形の波高値を変え、多数パルスの幅を変える方式はPWM制御。
   - 解答: `(5)` → 公式 `(5)`、PASS。
4. H29 問10
   - サイリスタは一度ターンオンすると保持電流以上の順方向電流ではゲート電流を除いても導通を続けるが、逆方向電流を流せるわけではないため(2)が誤り。
   - 解答: `(2)` → 公式 `(2)`、PASS。
5. H23 問10
   - パワートランジスタを電力スイッチとして使うときは遮断領域と飽和領域を切り換える。能動領域とする(3)が誤り。
   - 解答: `(3)` → 公式 `(3)`、PASS。

答案列: `(1), (2), (5), (2), (3)`

公式解答との一致: `5 / 5 PASS`

### 過去問から逆算した教材で必要な説明

1. デバイスのオン・オフ
   - ダイオード、サイリスタ、GTO、IGBT、MOSFETについて、何でオン・オフを制御できるか、自己消弧できるか、逆方向電流をどう扱うかを比較する。
2. MOSFETとIGBT
   - 電圧駆動、ユニポーラ/バイポーラ、キャリア蓄積、テイル電流、スイッチング速度の違いを本試験の正誤判定に使える粒度で説明する。
3. GTOとの接続
   - サイリスタとの違いとしてゲートでターンオフできる自己消弧形素子であることを押さえ、IGBTへの世代比較につなぐ。
4. 損失
   - オン状態で生じる導通損失と、ターンオン・ターンオフ遷移で生じるスイッチング損失を区別する。
   - 基本計算として、MOSFET型のオン損失は `Pcond ≈ I²R_on`、電圧降下型は `Pcond ≈ V_on I`、1回当たりのスイッチングエネルギーが与えられる場合は `Psw=(Eon+Eoff)fs` として扱う。
   - `Ploss=Pcond+Psw`、`η=Pout/Pin` の関係で変換効率へ接続する。
5. スイッチング周波数・発熱・冷却
   - `fs` が増えると1秒当たりのスイッチング回数が増え、他条件一定ならスイッチング損失が増えることを説明する。
   - 損失が熱になることから冷却容量へ接続する。熱設計の詳細計算や半導体物性へは拡張しない。
6. SiC
   - 本試験で要求される範囲として、高耐圧・高耐熱、低オン抵抗化に接続する。材料物性の詳細は扱わない。
7. インバータでの使われ方
   - IGBT等の自己消弧形素子と逆並列ダイオード、PWMの役割をH30問11の粒度で整理する。
8. 新幹線への接続
   - 系列SPECの世代イメージ `300系: GTO → 700系・N700系: IGBT → N700S: SiC` を入口とし、実際の採用素子・回路方式は一次資料で確認した内容だけを書く。
   - `損失減少 → 発熱減少 → 冷却装置小型化 → 主変換装置小型化 → 車両軽量化` を主題とし、未確認実車値を持ち込まない。
