## 解説本文

### 1. このテーマで電験は何を問うか

電験三種「機械」の自動制御では、装置名の暗記よりも、ブロック線図から信号の関係式を立て、合成伝達関数を求める力が重要である。特に固定5件では、負帰還、並列経路、加算点の符号、一次遅れ、時定数、R-C・R-L回路の伝達関数が直接問われている。

この章では、次を自力で行えることを到達目標とする。

- ブロック線図を式へ変換する。
- 直列・並列・負帰還を合成する。
- `G(s)/(1+G(s)H(s))` を丸暗記ではなく導く。
- 一次遅れと時定数を読み取る。
- R-C、R-L回路を伝達関数へ整理する。
- 二次遅れ、定常偏差、安定性の意味を固定範囲内で判定する。

### 2. 制御系の基本用語

教材上の速度制御モデルを次のように置く。これは電験の制御概念を新幹線へ接続するための概念図であり、実車の制御アルゴリズムを表すものではない。

```text
目標速度 r
    ↓
  [比較] ←──────── 検出速度 b
    ↓ 偏差 e
 [制御装置]
    ↓ 操作量 u
 [主変換装置・主電動機・車両]
    ↓
 車両速度 c
    ↓
 [速度検出]
    └──────────────→ 比較部へ
```

- 目標値: 制御で実現したい値。ここでは目標速度に相当する。
- 制御量: 制御した結果として保ちたい量。ここでは車両速度に相当する。
- 操作量: 制御対象を動かすために制御装置が与える量。
- 外乱: 制御対象へ外から加わり、制御量を変化させる要因。教材上は勾配や走行抵抗の変化などを概念例とする。
- 偏差: 目標値とフィードバック信号との差。負帰還なら `e=r-b` である。

新幹線側で重要なのは具体的な実車ロジックではなく、「目標速度と検出速度を比較し、偏差に応じて操作し、速度を再び検出する」という閉ループの考え方である。

### 3. 開ループ・閉ループ、フィードバック・フィードフォワード

開ループ制御は、出力を測って目標値との差を訂正する経路を持たない。入力を決めたら、その入力に応じて制御対象を動かす。

閉ループ制御は、出力を検出して入力側へ戻し、目標値と比較して訂正する。出力を戻すことがフィードバックである。

```text
開ループ:
r → 制御装置 → 制御対象 → c

閉ループ:
r → 比較 → 制御装置 → 制御対象 → c
     ↑                         │
     └────── 検出 ────────────┘
```

フィードフォワードは、出力のずれを待ってから訂正するのではなく、目標値や測定できる外乱などから必要な操作を前もって与える考え方である。フィードバックとは経路の役割が異なる。

このTopicでは両者の概念差までを扱い、実車で両者をどのように組み合わせているかは推測しない。

### 4. 伝達関数とは何か

入力を `R(s)`、出力を `C(s)` とし、初期値を0として線形な関係を扱うとき、伝達関数は

```text
G(s) = C(s) / R(s)
```

で表す。

ブロック `G(s)` に信号 `R(s)` が入れば、出力は

```text
C(s) = G(s)R(s)
```

である。電験のブロック線図問題では、この関係を各ブロックと加算点へ順に書き、最後に `C/R` の形へ整理する。

正弦波定常状態の周波数伝達関数では `s=jω` と置き、`G(jω)` として扱う。ブロック線図の直列・並列・負帰還の代数は同じである。

### 5. ブロック線図を式へ変換する

#### 5.1 直列

同じ信号が `G1`、`G2` を順番に通るなら

```text
X = G1R
C = G2X
```

なので

```text
C/R = G1G2
```

となる。

#### 5.2 並列

同じ入力 `R` が2経路へ分岐し、加算点で足すなら

```text
C = G1R + G2R
  = (G1+G2)R
```

したがって

```text
C/R = G1 + G2
```

一方、片方が加算点の負号へ入るなら

```text
C/R = G1 - G2
```

となる。R7下問13では、この加算点の符号判定が重要になる。

#### 5.3 分岐点

分岐点は同じ信号を複数経路へ取り出す。分岐しただけでは信号の値は変わらない。加算点と混同しない。

### 6. 負帰還の合成を関係式から導く

前向き伝達関数を `G(s)`、帰還伝達関数を `H(s)` とする。負帰還では

```text
e = r - b
b = Hc
c = Ge
```

なので

```text
e = r - Hc
c = G(r-Hc)
```

これを整理すると

```text
c + GHc = Gr
c(1+GH) = Gr
```

よって閉ループ伝達関数は

```text
C(s)/R(s) = G(s) / {1 + G(s)H(s)}
```

となる。分母が `1+GH` になる理由は、負帰還の式が `e=r-Hc` だからである。

帰還経路が `H=1` のときは単位負帰還であり、

```text
C/R = G/(1+G)
```

となる。

### 7. 加算点と並列経路を含む典型合成

固定過去問で必要な形を、信号方程式から整理する。

#### 7.1 正負の並列経路と外部負帰還

加算点後の信号を `E` とし、出力側に正の経路 `G1` と負の経路 `G2` があるとする。帰還経路を `G3` とすると

```text
E = R - G3C
C = (G1-G2)E
```

である。2式を代入すると

```text
C = (G1-G2)(R-G3C)
```

よって

```text
C/R = (G1-G2) / {1 + G1G3 - G2G3}
```

となる。公式を先に当てるのではなく、まず加算点の `+/-` を式へ落とす。

#### 7.2 帰還経路自身に動特性がある形

加算点後を `E` とし、`E/(sT2)` が負帰還される場合、

```text
E = R - E/(sT2)
```

なので

```text
E/R = sT2/(1+sT2)
```

出力側が

```text
C = E{T1/T2 + 1/(sT2)}
```

なら、

```text
C/R = (1+sT1)/(1+sT2)
```

となる。R8上問13で必要なのは、このように各信号を一つずつ式へ変換する手順である。周波数伝達関数なら最後に `s=jω` と置けばよい。

### 8. 一次遅れと時定数

一次遅れの基本形は

```text
G(s) = K/(1+Ts)
```

である。`K` は定常的な入出力比、`T[s]` は時定数である。

入力を0から一定値へ急に変えたとき、初期値0の一次遅れ応答は指数的に最終値へ近づく。単位ステップ入力なら

```text
c(t) = K{1-exp(-t/T)}
```

となる。`t=T` では

```text
c(T) = K(1-e^-1) ≈ 0.632K
```

なので、最終値の約63.2 %へ達する時間が時定数 `T` である。

- `T` が小さい: 最終値へ早く近づく。
- `T` が大きい: 最終値へゆっくり近づく。

固定過去問では、グラフ上の63.2 %到達時刻から時定数を読み、R-L回路の `L/R` へ結び付ける。

### 9. R-L回路の一次遅れ

直列R-L回路へ電圧 `V(s)` を加え、電流 `I(s)` を出力とする。

インピーダンスは

```text
R + Ls
```

なので

```text
I(s)/V(s) = 1/(R+Ls)
```

これを一次遅れ形へ整理すると

```text
I/V = (1/R) / {1+(L/R)s}
```

したがって

```text
K = 1/R
T = L/R
```

である。

周波数伝達関数は `s=jω` と置いて

```text
I/V = 1/(R+jωL)
    = (1/R) / {1+jω(L/R)}
```

となる。

### 10. R-C回路の周波数伝達関数

コンデンサと抵抗を直列に接続し、抵抗両端の電圧を出力とする。コンデンサのインピーダンスを

```text
ZC = 1/(sC)
```

とすると、分圧より

```text
VR/V = R / {R + 1/(sC)}
```

である。分子・分母へ `sC` を掛けると

```text
VR/V = sRC/(1+sRC)
```

となる。周波数伝達関数では

```text
VR/V = jωRC/(1+jωRC)
```

である。

これは `K/(1+Ts)` そのものではないが、分母には `1+sRC` という一次式が現れ、`RC` が時間の次元を持つ。R5下問18(a)では、インピーダンスを使った分圧からこの形へ整理することが必要である。

### 11. 内部負帰還を先に合成する

複雑なブロック線図では、一度に全体を式変形せず、内側から合成する。

例えば制御対象が

```text
1/(sT)
```

で、その周囲に単位負帰還があるとする。内側の閉ループ伝達関数は

```text
{1/(sT)} / {1 + 1/(sT)}
= 1/(1+sT)
```

となる。

その前段に定数ゲイン `K` が直列にあるなら、その区間の伝達関数は

```text
K/(1+sT)
```

である。R4上問15(a)では、まず内側の負帰還を一次遅れ要素へまとめ、その後に直列要素を掛ける順序が重要になる。

### 12. 二次遅れ

伝達関数の分母に `s²` の項を含む系を、このTopicでは二次遅れとして扱う。一般に

```text
G(s) = N(s) / (a2s² + a1s + a0)
```

のように分母が二次式になる。

一次遅れでは一つの時定数で応答の基本的な速さを捉えられるが、二次遅れでは分母の二次式全体が応答を決める。このTopicでは、二次式であることの判定と、安定性との接続までを扱う。行過ぎ量、ボード線図、ベクトル軌跡等へは広げない。

### 13. 定常偏差

目標値と制御量の差が時間が十分経過しても残るとき、その差を定常偏差という。

単位負帰還で、定常状態における前向き経路の入出力比を定数 `K` として考えると

```text
e = r-c
c = Ke
```

より

```text
e = r/(1+K)
c = Kr/(1+K)
```

となる。したがって `K` が有限なら、条件によっては目標値との差が残る。ここでは定常偏差の意味と基本的な代数関係までを扱う。

### 14. 安定性

安定な制御系では、一定入力や小さな変化を与えた後、出力や偏差が発散せず有限値へ落ち着く。不安定な系では、出力が増大し続けるなど、目標値へ収束しない。

伝達関数で見ると、分母を0とする根が応答の減衰・増大を決める。連続時間の基本系では、その根の実部が負なら対応する成分は時間とともに減衰する。このTopicではこの判定原理までとし、ナイキスト線図やボード線図による安定判別は扱わない。

一次遅れ

```text
G(s)=K/(1+Ts)
```

では `T>0` のとき分母の根は

```text
s=-1/T
```

となり負であるため、応答は減衰して最終値へ近づく。

### 15. 新幹線への接続

この教材では、新幹線の速度制御を次の概念モデルとして使う。

```text
目標速度
↓
比較
↓
制御装置
↓
主変換装置
↓
主電動機
↓
車両速度
↓
速度検出
└──── フィードバック
```

電験として見ると、重要なのは装置名ではなく信号の役割である。

- 目標速度: 目標値
- 車両速度: 制御量
- 制御装置から制御対象側へ与える量: 操作量
- 速度検出値: フィードバック信号
- 走行条件の変化: 外乱の概念例

ここから先の実車の制御則、ゲイン、時定数、検出方式、内部ソフトウェア等は一次資料で確定していないため、本教材では推測しない。

### 16. 本試験の解法アルゴリズム

1. 入力 `R`、出力 `C`、中間信号 `E` 等を図へ書き込む。
2. 加算点の `+/-` を確認し、まず信号方程式を書く。
3. 直列は積、同一入力の並列は和または差として整理する。
4. 負帰還なら `e=r-Hc`、`c=Ge` から `G/(1+GH)` を導く。
5. 複雑な系は内側の帰還から先に合成する。
6. 周波数伝達関数なら `s=jω` として同じ代数を使う。
7. R-L回路は `I/V=1/(R+sL)` から `T=L/R` を読む。
8. R-C回路はインピーダンスと分圧から伝達関数を作る。
9. 一次遅れのグラフでは最終値の約63.2 %へ達する時間を時定数と読む。
10. 最後に、分母の次数、定常値、安定に収束する形かを確認する。

### 17. 頻出ミス

- 加算点の負号を見落として `G1+G2` と `G1-G2` を取り違える。
- 分岐点を加算点と同じものとして扱う。
- 負帰還の分母を `1-GH` としてしまう。
- 複雑なブロック線図を一度に公式へ当てはめ、内側の帰還を合成しない。
- `s=jω` に変わってもブロック線図代数そのものまで変わると考える。
- 時定数を「最終値へ完全に到達する時間」と誤解する。
- R-L回路で `T=R/L` と逆にする。
- R-C回路でコンデンサのインピーダンス `1/(jωC)` を取り違える。
- 定常偏差と一時的な過渡変化を同一視する。
- 実車の制御アルゴリズムを、教材上の概念ブロック線図から推測する。

## 3段階例題

### 例題1 基礎 — 単位負帰還と定常偏差

前向き経路の定常的な入出力比を `K=4` とし、単位負帰還をかける。一定の目標値 `r=1` に対する定常出力 `c` と定常偏差 `e` を求めよ。

負帰還なので

```text
e = r-c
c = 4e
```

である。代入すると

```text
e = 1-4e
5e = 1

e = 0.2
```

したがって

```text
c = 4e = 0.8
```

答え: 定常出力 `0.8`、定常偏差 `0.2`。

検算: `c+e=1` で目標値に一致する。また `C/R=K/(1+K)=4/5=0.8` と同じ結果になる。

### 例題2 本試験標準 — R-L回路の時定数と伝達関数

直列R-L回路へ1 Vの単位ステップ電圧を加えたところ、定常電流は `0.200 A`、最終値の約63.2 %に達する時刻は `0.0200 s` だった。`R`、`L` と `I(s)/V(s)` を求めよ。

定常状態ではインダクタの電圧降下は0となるため

```text
R = V/I
  = 1/0.200
  = 5.00 Ω
```

一次遅れの63.2 %到達時刻が時定数なので

```text
T = 0.0200 s
```

R-L回路では

```text
T = L/R
```

だから

```text
L = RT
  = 5.00×0.0200
  = 0.100 H
```

伝達関数は

```text
I/V = 1/(R+sL)
    = 1/(5.00+0.100s)
    = 0.200/(1+0.0200s)
```

答え: `R=5.00 Ω`、`L=0.100 H`、`I/V=0.200/(1+0.0200s)`。

検算: `L/R=0.100/5.00=0.0200 s` で観測した時定数と一致する。

### 例題3 複合 — 正負の並列経路＋外部負帰還

前向き側に同じ入力 `E` を受ける2経路があり、出力加算点で上側を正、下側を負とする。

```text
G1(s) = 3/(1+2s)
G2(s) = 1/(1+2s)
H(s)  = 2
```

外部は負帰還である。閉ループ伝達関数 `C/R` を求め、一次遅れ形に整理して時定数を求めよ。

まず並列経路を符号どおりに合成する。

```text
F(s) = G1-G2
     = 2/(1+2s)
```

外部負帰還なので

```text
C/R = F/(1+FH)
```

したがって

```text
C/R = {2/(1+2s)} / {1 + 4/(1+2s)}
    = 2/(5+2s)
    = 0.4/(1+0.4s)
```

よって時定数は

```text
T = 0.4 s
```

答え: `C/R=0.4/(1+0.4s)`、時定数 `0.4 s`。

検算: 分母の根は `s=-2.5` で負なので、この一次遅れ系は安定に減衰する。
