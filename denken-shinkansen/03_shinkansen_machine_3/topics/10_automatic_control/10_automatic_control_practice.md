# 練習問題

## 問1 基礎: 制御系の用語
一定速度を保つ制御系を考える。運転者または上位装置が与える速度指令を `r`、実際の速度を `c`、制御装置から制御対象へ与える量を `u`、走行抵抗の変化など制御対象へ外部から加わる影響を `d` とする。用語の対応として最も適切なものはどれか。

1. `r`: 制御量、`c`: 目標値、`u`: 外乱、`d`: 操作量
2. `r`: 操作量、`c`: 外乱、`u`: 目標値、`d`: 制御量
3. `r`: 目標値、`c`: 制御量、`u`: 操作量、`d`: 外乱
4. `r`: 外乱、`c`: 操作量、`u`: 制御量、`d`: 目標値
5. `r`: 目標値、`c`: 操作量、`u`: 外乱、`d`: 制御量

### 解答・解説
正答: 3

- 目標値: 制御系が目指す値。
- 制御量: 実際に制御したい出力。
- 操作量: 制御装置が制御対象へ与える量。
- 外乱: 制御対象へ外部から加わり、制御量を変化させる影響。

したがって `r` は目標値、`c` は制御量、`u` は操作量、`d` は外乱である。他の選択肢はこれらの役割を入れ替えている。

## 問2 基礎: 単純な負帰還
前向き伝達関数が `G=4`、帰還伝達関数が `H=0.5` の負帰還系がある。閉ループ伝達関数 `C/R` として正しいものはどれか。

1. `2/3`
2. `1`
3. `2`
4. `4/3`
5. `8/3`

### 解答・解説
正答: 4

負帰還系では

```text
C/R = G/(1+GH)
```

である。したがって

```text
C/R = 4/(1+4×0.5)
    = 4/3
```

よって4。

分母を `1-GH` とするのは正帰還側の符号と混同した誤りである。

## 問3 基礎: 一次遅れの時定数
一次遅れ系へステップ入力を与えたところ、出力の最終値は `10.0` で、`t=0.500 s` のとき出力が約 `6.32` になった。この系の時定数として正しいものはどれか。

1. `0.316 s`
2. `0.500 s`
3. `0.632 s`
4. `1.00 s`
5. `1.58 s`

### 解答・解説
正答: 2

一次遅れ

```text
G(s)=K/(1+Ts)
```

では、ステップ応答が最終値の約63.2%へ達する時刻が時定数 `T` である。

```text
10.0×0.632 = 6.32
```

となる時刻が `0.500 s` なので

```text
T = 0.500 s
```

よって2。時定数は最終値へ完全に到達する時間ではない。

## 問4 本試験標準: 正負の並列経路と外部負帰還
同じ入力 `E` を受ける二つの経路

```text
G1(s)=3/(1+s)
G2(s)=1/(1+s)
```

があり、出力加算点で `G1` 側を正、`G2` 側を負とする。この合成経路に `H=0.5` の外部負帰還をかける。閉ループ伝達関数 `C/R` として正しいものはどれか。

1. `2/(1+s)`
2. `1/(1+s)`
3. `2/(1+2s)`
4. `1/(1+s/2)`
5. `1/(1+0.5s)`

### 解答・解説
正答: 5

まず正負の並列経路を合成する。

```text
F(s)=G1-G2
    =2/(1+s)
```

外部が負帰還なので

```text
C/R = F/(1+FH)
```

したがって

```text
C/R = {2/(1+s)} / {1 + 1/(1+s)}
    = 2/(2+s)
    = 1/(1+0.5s)
```

よって5。

加算点の負号を見落として `G1+G2` とすると別の式になり、正答しない。

## 問5 本試験標準: R-L回路の時定数
直列R-L回路へ `10.0 V` のステップ電圧を加えたところ、定常電流は `2.00 A`、電流が定常値の約63.2%へ達する時刻は `0.0400 s` だった。`R`、`L`、伝達関数 `I(s)/V(s)` の組合せとして正しいものはどれか。

1. `R=5.00 Ω`、`L=0.200 H`、`I/V=0.200/(1+0.0400s)`
2. `R=5.00 Ω`、`L=0.0400 H`、`I/V=0.200/(1+0.00800s)`
3. `R=2.00 Ω`、`L=0.0800 H`、`I/V=0.500/(1+0.0400s)`
4. `R=20.0 Ω`、`L=0.800 H`、`I/V=0.0500/(1+0.0400s)`
5. `R=5.00 Ω`、`L=0.200 H`、`I/V=5.00/(1+0.0400s)`

### 解答・解説
正答: 1

定常状態ではインダクタの電圧降下は0なので

```text
R = V/I
  = 10.0/2.00
  = 5.00 Ω
```

一次遅れの時定数は

```text
T = L/R = 0.0400 s
```

だから

```text
L = RT
  = 5.00×0.0400
  = 0.200 H
```

R-L回路の伝達関数は

```text
I/V = 1/(R+sL)
    = 1/(5.00+0.200s)
    = 0.200/(1+0.0400s)
```

よって1。

検算: `L/R=0.200/5.00=0.0400 s` で観測時定数と一致する。

## 問6 本試験標準: R-C回路の周波数伝達関数
抵抗 `R=2.00 kΩ` とコンデンサ `C=50.0 μF` を直列接続し、入力電圧を全体へ加え、出力電圧を抵抗両端から取り出す。角周波数 `ω=10.0 rad/s` のとき、周波数伝達関数 `VR/V` として正しいものはどれか。

1. `1`
2. `0.5-j0.5`
3. `0.5+j0.5`
4. `j`
5. `1+j`

### 解答・解説
正答: 3

抵抗出力なので

```text
VR/V = jωRC/(1+jωRC)
```

である。

```text
RC = 2000×50.0×10^-6
   = 0.100 s

ωRC = 10.0×0.100
     = 1
```

したがって

```text
VR/V = j/(1+j)
     = j(1-j)/{(1+j)(1-j)}
     = (1+j)/2
     = 0.5+j0.5
```

よって3。

`0.5-j0.5` はコンデンサ出力側の形と混同した誤りである。

## 問7 本試験標準: 内部負帰還の合成
制御対象 `1/(2s)` の周囲に単位負帰還があり、その前段に定数ゲイン `K=3` が直列に接続されている。まず内部負帰還を合成した後の、`K` を含む前向き経路の伝達関数として正しいものはどれか。

1. `3/(2s)`
2. `3/(1+2s)`
3. `1/(1+6s)`
4. `3/(1+6s)`
5. `6/(1+2s)`

### 解答・解説
正答: 2

内部の制御対象を

```text
G0 = 1/(2s)
```

とすると、単位負帰還後は

```text
Ginner = G0/(1+G0)
       = {1/(2s)}/{1+1/(2s)}
       = 1/(1+2s)
```

である。

前段の `K=3` を直列に掛けると

```text
Geq = 3/(1+2s)
```

よって2。複雑なブロック線図では内側の帰還から合成する。

## 問8 本試験標準: 定常偏差
単位負帰還系で、定常状態における前向き経路の入出力比を `K=9` とする。一定の目標値 `r=1` に対する定常偏差 `e` と定常出力 `c` の組合せとして正しいものはどれか。

1. `e=0`、`c=1`
2. `e=0.9`、`c=0.1`
3. `e=1/9`、`c=8/9`
4. `e=0.1`、`c=0.9`
5. `e=1`、`c=9`

### 解答・解説
正答: 4

単位負帰還なので

```text
e = r-c
c = Ke
```

である。`r=1`、`K=9` より

```text
e = 1-9e
10e = 1

e = 0.1
```

したがって

```text
c = 9e = 0.9
```

よって4。

検算: `e+c=0.1+0.9=1` で目標値に一致する。

## 問9 本試験標準: 二次遅れと安定性
伝達関数

```text
G(s)=5/(s^2+4s+3)
```

について、最も適切な説明はどれか。

1. 分母は一次式なので一次遅れ系である。
2. 分母の根は `+1` と `+3` なので安定である。
3. 分母の根は `-1` と `+3` なので安定である。
4. 分母は二次式だが、安定性は分母と無関係である。
5. 分母は二次式で、根は `-1` と `-3` なので、この基本判定では安定である。

### 解答・解説
正答: 5

分母を因数分解すると

```text
s^2+4s+3
=(s+1)(s+3)
```

なので根は

```text
s=-1, -3
```

である。分母に `s^2` を含むので二次遅れとして扱う。このTopicで扱う連続時間の基本判定では、根の実部がすべて負なので応答成分は減衰し、安定と判断できる。よって5。

ボード線図やナイキスト線図は使用しない。

## 問10 本試験標準: フィードバックとフィードフォワード
制御方式の説明として最も適切なものはどれか。

1. フィードバック制御は制御量を検出して目標値との差を利用し、フィードフォワード制御は検出した外乱等の情報を利用して出力誤差が現れる前に操作量へ反映させる考え方である。
2. フィードバック制御では制御量を検出しない。
3. フィードフォワード制御では必ず制御量と目標値の偏差を帰還させる。
4. 開ループ制御は必ず出力を入力へ戻す閉ループを持つ。
5. 閉ループ制御では出力側の情報を一切利用しない。

### 解答・解説
正答: 1

フィードバックは制御量を検出し、目標値との差などを利用して訂正する。フィードフォワードは外乱等を事前に検出できる場合、その情報から操作量を補正する考え方である。

2、3は両者の役割を取り違えている。4、5は開ループと閉ループの定義に反する。

## 問11 複合・応用: 正負の並列経路＋外部負帰還
同じ入力 `E` を受ける二経路

```text
G1(s)=4/(1+3s)
G2(s)=1/(1+3s)
```

があり、出力加算点で `G1` 側を正、`G2` 側を負とする。さらに帰還伝達関数 `H=2/3` の外部負帰還をかける。閉ループ伝達関数 `C/R` として正しいものはどれか。

1. `3/(1+3s)`
2. `1/(1+3s)`
3. `1/(1+s)`
4. `3/(1+s)`
5. `1/(3+s)`

### 解答・解説
正答: 3

まず並列経路を符号どおり合成する。

```text
F(s)=G1-G2
    =3/(1+3s)
```

外部負帰還なので

```text
C/R = F/(1+FH)
```

ここで

```text
FH = {3/(1+3s)}×(2/3)
   = 2/(1+3s)
```

したがって

```text
C/R = {3/(1+3s)} / {1+2/(1+3s)}
    = 3/(3+3s)
    = 1/(1+s)
```

よって3。一次遅れ形から時定数は `1 s` と読める。

検算: 分母の根は `s=-1` で負なので、この一次遅れ系は安定に減衰する。

## 問12 複合・応用: ステップ応答からR-L回路を決める
直列R-L回路へ `2.00 V` のステップ電圧を加えたところ、定常電流は `0.400 A`、定常値の約63.2%へ達する時刻は `0.0200 s` だった。この回路の `R`、`L`、角周波数 `ω=50.0 rad/s` における周波数伝達関数 `I/V` の組合せとして正しいものはどれか。

1. `R=5.00 Ω`、`L=0.100 H`、`I/V=0.1+j0.1 S`
2. `R=5.00 Ω`、`L=0.100 H`、`I/V=0.1-j0.1 S`
3. `R=5.00 Ω`、`L=0.0200 H`、`I/V=0.2-j0.2 S`
4. `R=2.00 Ω`、`L=0.0400 H`、`I/V=0.25-j0.25 S`
5. `R=5.00 Ω`、`L=0.100 H`、`I/V=0.2 S`

### 解答・解説
正答: 2

定常状態から

```text
R = V/I
  = 2.00/0.400
  = 5.00 Ω
```

63.2%到達時刻が時定数なので

```text
T = L/R = 0.0200 s
```

よって

```text
L = RT
  = 5.00×0.0200
  = 0.100 H
```

周波数伝達関数は

```text
I/V = 1/(R+jωL)
```

だから

```text
I/V = 1/(5.00+j×50.0×0.100)
    = 1/(5+j5)
    = (5-j5)/50
    = 0.1-j0.1 S
```

よって2。

検算: `L/R=0.100/5.00=0.0200 s` で観測時定数と一致する。
