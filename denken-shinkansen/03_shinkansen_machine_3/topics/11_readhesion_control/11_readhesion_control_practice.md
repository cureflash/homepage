# 練習問題

## 問1 基礎: センサ・制御装置・アクチュエータ
次の役割A〜Cと要素の対応として最も適切なものはどれか。

- A: 回転速度などの物理量を計測・検出する。
- B: 計測情報を処理し、制御指令を生成する。
- C: 指令に従い、エネルギーを機械的な動き・作用へ変える。

1. A=制御装置、B=センサ、C=アクチュエータ
2. A=アクチュエータ、B=制御装置、C=センサ
3. A=センサ、B=制御装置、C=アクチュエータ
4. A=センサ、B=アクチュエータ、C=制御装置
5. A=制御装置、B=アクチュエータ、C=センサ

### 解答・解説
正答: 3

センサは「測る」、制御装置は「情報を処理して指令する」、アクチュエータは「動かす・作用させる」要素である。したがってA=センサ、B=制御装置、C=アクチュエータとなる。

1、4、5はセンサと制御装置またはアクチュエータの役割を入れ替えている。2は測定要素と作用要素が逆である。

## 問2 基礎: 粘着・空転・滑走・再粘着
用語の説明として最も適切なものはどれか。

1. 空転は制動時に車輪の回転が車両の進みに対して不足する状態である。
2. 滑走は駆動時に車輪の回転が車両の進みに対して過大になる状態である。
3. 再粘着とは、粘着状態から必ず空転へ移ることである。
4. 空転は駆動時に車輪の回転が過大になる方向、滑走は制動時に車輪の回転が不足する方向の状態である。
5. 粘着とは車輪が完全に停止している状態だけをいう。

### 解答・解説
正答: 4

この教材では、粘着を車輪とレールの間で駆動力・制動力を安定して伝えられる状態として扱う。空転は駆動時に車輪回転が過大になる方向、滑走は制動時に車輪回転が不足する方向である。再粘着は空転・滑走から再び力を安定して伝えられる状態へ戻ることをいう。

1と2は空転・滑走を逆にしている。3は再粘着の向きが逆。5は粘着の意味を誤っている。

## 問3 基礎: フィードバックの流れ
再粘着制御をフィードバックの例として表した流れとして最も適切なものはどれか。

1. 制御指令 → 終了
2. 状態検出 → 判断・指令 → 作用 → 状態変化 → 再検出
3. 作用 → 状態検出 → 終了
4. 状態検出 → 記録のみ → 終了
5. 判断・指令 → 状態検出を行わず連続作用

### 解答・解説
正答: 2

フィードバックでは、作用後の状態を再び検出し、その結果を次の判断・指令へ戻す。Topic 11では `状態検出 → 判断・指令 → 作用 → 状態変化 → 再検出` の閉じた流れを押さえる。

1、3、4は作用結果の再検出がなく、閉じたフィードバックになっていない。5は状態を見ずに作用を続けるため、この教材で扱うフィードバックの考え方に反する。

## 問4 本試験標準: メカトロニクス
メカトロニクスの説明として最も適切なものはどれか。

1. 機械系だけを電子系・情報系から切り離して扱う考え方である。
2. センサだけで判断・指令・機械的作用まで全て行う仕組みである。
3. 制御装置を使わず、アクチュエータだけで状態を判定する仕組みである。
4. 情報系だけで機械状態を変化させ、機械系を含まない考え方である。
5. 機械系・電子系・情報系を組み合わせ、一つの目的に沿って動作させる考え方である。

### 解答・解説
正答: 5

メカトロニクスは、機械系・電子系・情報系を統合したシステムとして理解する。R4下 機械 問14でも、この統合概念と各要素の役割分担が問われる。

1と4は統合ではなく一部を切り離している。2と3はセンサ・制御装置・アクチュエータの役割を混同している。

## 問5 本試験標準: センサの役割
車輪の回転状態を知るための系で、回転速度などの物理量を検出し、その情報を制御装置へ渡す要素の役割として最も適切なものはどれか。

1. センサ
2. 制御装置
3. アクチュエータ
4. 車輪そのもの
5. 制御指令そのもの

### 解答・解説
正答: 1

物理量を計測・検出する役割はセンサである。センサは状態情報を得る側であり、その情報を処理して指令を作るのは制御装置である。

2は「考える・指令する」側、3は「作用させる」側。4は状態が変化する機械系であり、5は要素ではなく制御装置が生成する情報である。

## 問6 本試験標準: 制御装置の役割
センサから得た回転状態の情報を処理し、必要な制御指令を生成する要素として最も適切なものはどれか。

1. 車輪
2. センサ
3. 制御装置
4. アクチュエータ
5. 粘着状態

### 解答・解説
正答: 3

制御装置は、センサから得た情報を処理し、目的に応じた制御指令を生成する。センサは検出、アクチュエータは機械的作用への変換を担当する。

1と5は制御要素ではなく機械系の状態・対象。2は測る役割、4は動かす役割である。

## 問7 本試験標準: アクチュエータの役割
制御指令を受け、エネルギーを機械的な動き・作用へ変換する要素として最も適切なものはどれか。

1. センサ
2. 回転速度
3. 制御装置
4. アクチュエータ
5. フィードバック

### 解答・解説
正答: 4

アクチュエータは、電気・油圧・空気圧などのエネルギーを機械的な動き・作用へ変える要素である。この教材では車種固有の機器構成を断定せず、制御指令を機械的作用へ移す側として抽象化する。

1は検出、3は情報処理と指令生成、2は物理量、5は制御の流れを表す概念である。

## 問8 本試験標準: 駆動時の車輪状態
駆動中、車輪の回転が車両の進みに対して過大になる方向の状態が生じた。この状態の呼び方として最も適切なものはどれか。

1. 滑走
2. 空転
3. 再粘着
4. 応答速度
5. メカトロニクス

### 解答・解説
正答: 2

駆動時に車輪回転が車両の進みに対して過大になる方向の状態を空転という。滑走は制動時に車輪回転が不足する方向の状態である。

3は空転・滑走から粘着状態へ戻ること、4は制御の速さ、5は統合システムの考え方である。

## 問9 本試験標準: 制動時の車輪状態
制動中、車輪の回転が車両の進みに対して不足する方向の状態が生じた。この状態の呼び方として最も適切なものはどれか。

1. 空転
2. 再粘着
3. メカトロニクス
4. 粘着
5. 滑走

### 解答・解説
正答: 5

制動時に車輪回転が車両の進みに対して不足する方向の状態を滑走という。空転は駆動時の過大回転側である。

2は異常状態から再び力を安定して伝えられる状態へ戻ること。3は統合システムの概念、4は力を安定して伝えられる状態である。

## 問10 本試験標準: 応答速度
この教材における「応答速度」の説明として最も適切なものはどれか。

1. 状態変化を検出し、指令・作用へ反映するまでの速さ
2. 車輪の最高回転速度だけを表す値
3. アクチュエータの名称
4. 車種固有の再粘着しきい値
5. センサが生成する制御指令そのもの

### 解答・解説
正答: 1

Topic 11では、応答速度を「状態変化を検出し、指令・作用へ反映するまでの速さ」として扱う。実車固有のしきい値、時定数、応答時間の数値は公開資料で確認できない限り導入しない。

2は回転速度との混同、3は要素名との混同、4は本教材で推測しない実車固有値、5はセンサと制御装置の役割混同である。

## 問11 複合・応用: 再粘着制御の役割分担
次の再粘着制御の説明のうち、役割分担とフィードバックの流れがともに適切なものはどれか。

1. センサが状態を検出し、そのまま機械的作用まで担当して制御を終了する。
2. アクチュエータが状態を検出し、センサが制御指令を生成する。
3. センサが状態を検出し、制御装置が情報を処理して指令を生成し、アクチュエータが作用し、その後の状態を再び検出する。
4. 制御装置が回転速度を物理的に計測し、センサが機械的作用へ変換する。
5. 状態検出後に一度指令を出せば、その後の状態を再検出する必要はない。

### 解答・解説
正答: 3

正しい流れは `検出 → 判断・指令 → 作用 → 状態変化 → 再検出` である。検出はセンサ、情報処理と指令生成は制御装置、機械的作用への変換はアクチュエータが担当する。

1と5は再検出がなくフィードバックになっていない。2と4は各要素の役割が逆である。

## 問12 複合・応用: 正誤の組合せ
次の記述A〜Dについて、正しいものの組合せとして最も適切なものはどれか。

- A: メカトロニクスは、機械系・電子系・情報系を統合する考え方である。
- B: センサは計測情報を処理して最終的な制御指令を生成する要素である。
- C: フィードバックでは、作用後の状態を再検出して次の指令へ反映する。
- D: Topic 11では、公開資料にない車種固有の再粘着しきい値を仮定して覚えることが必須である。

1. Aのみ
2. BとD
3. AとBとC
4. AとC
5. AとCとD

### 解答・解説
正答: 4

Aは正しい。メカトロニクスは機械・電子・情報を統合する。Bは誤りで、センサは物理量を計測・検出する側であり、計測情報を処理して制御指令を生成するのは制御装置である。Cは正しい。作用後の状態を再検出することで閉じたフィードバックになる。Dは誤りで、公開資料にない車種固有のしきい値や判定式は推測しない。

したがって正しいのはAとCで、4。
