## スライド構成
1. メカトロニクスは「測る・考える・動かす」
   - センサ / 制御装置 / アクチュエータの役割分担を可視化
   - メカトロニクス = 機械系 + 電子系 + 情報系の統合を明示
   - R4下 機械 問14の判別軸へ直接接続
2. 空転・滑走・再粘着を区別する
   - 粘着 = 駆動力・制動力を安定して伝えられる状態
   - 空転 = 駆動時の車輪回転が進みに対して過大
   - 滑走 = 制動時の車輪回転が進みに対して不足
   - 再粘着 = 空転・滑走から安定伝達へ戻ること
3. 再粘着制御は「戻ってくる」からフィードバック
   - 状態検出 → 判断・指令 → 作用 → 状態変化 → 再検出を可視化
   - 応答速度を「検出から指令・作用へ反映するまでの速さ」と整理
   - 実車固有の応答時間・しきい値・トルク低減量は設定しない
4. R4下 機械 問14は「役割の言い換え」を読む
   - 計測・検出 → センサ
   - 情報を処理・指令 → 制御装置
   - 機械的な動きへ変換 → アクチュエータ
   - 機械 + 電子 + 情報を統合 → メカトロニクス
   - 固定範囲外論点を追加しない境界を明示
