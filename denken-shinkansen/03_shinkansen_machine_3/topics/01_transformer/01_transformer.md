## 過去問とSPECから確定した教材必須範囲

### 1. 変圧器の原理と理想変圧器
- 一次巻線・二次巻線・鉄心・磁束・電磁誘導。
- 巻数比 `a=N1/N2`。
- 理想変圧器で `V1/V2=N1/N2=a`、`I1/I2=N2/N1=1/a`。
- 定格容量 `S=VI` の意味と、電圧を下げると同じ容量では電流が大きくなる関係。

### 2. 一次側換算と簡易等価回路
- 二次電圧・電流・抵抗・リアクタンス・負荷インピーダンスを一次側へ換算する。
- 電圧は `a` 倍、電流は `1/a` 倍、インピーダンスは `a^2` 倍。
- 一次・二次を混在させず、同じ側へ換算して回路計算する理由を説明する。

### 3. 損失と効率
- 鉄損: ヒステリシス損＋渦電流損。定格電圧・周波数一定なら負荷によらず概ね一定として扱う。
- 銅損: 巻線抵抗による `I^2R`。負荷率 `x` に対して `x^2` 倍。
- 効率 `η=Pout/(Pout+Pi+Pcu)`。
- 最大効率条件 `Pi=Pcu`。
- 異なる負荷条件の全損失から鉄損・銅損を分離する連立計算。

### 4. 無負荷試験・短絡試験
- 無負荷試験で主に鉄損・励磁回路を求める考え方。
- 短絡試験で主に等価抵抗・漏れリアクタンス・銅損を求める考え方。
- 短絡試験: `Z=V/I`, `r=P/I^2`, `x=sqrt(Z^2-r^2)`。
- 電圧計・電流計・電力計のどの値をどの式へ入れるかを明示する。

### 5. 励磁回路
- 励磁電流を鉄損電流と磁化電流へ分ける。
- 励磁コンダクタンスは鉄損側、励磁サセプタンスは磁化側に対応する。
- 磁気飽和・ヒステリシスにより励磁電流が非正弦波となり高調波を含むこと。

### 6. 電圧変動率
系列SPECの必須項目として扱う。無負荷二次電圧と負荷時二次電圧の差を定格二次電圧に対する割合で表す意味、抵抗分・リアクタンス分と負荷力率の関係を、三種で必要な範囲まで説明する。

### 7. 新幹線への接続
系列SPECで確定している範囲のみ、`架線25 kV → パンタグラフ → 主変圧器 → 二次側交流 → 主変換装置 → 主電動機` を導入に使う。

実車の主変圧器容量、巻数比、二次電圧、損失、効率などの具体値は今回まだ真値化していない。本文へ入れる場合はJR各社・メーカー・鉄道総研・学会資料等の一次資料で確認した値だけを使用する。

# 解説本文

## 1. このテーマで電験は何を問うか
電験三種「機械」の変圧器問題では、単に「交流電圧を変える機器」と知っているだけでは足りない。主に次を計算・判定できることが必要になる。

- 巻数比から一次・二次の電圧と電流を求める。
- 二次側の量を一次側へ換算して等価回路を作る。
- 鉄損と銅損を区別し、負荷率が変わったときの損失と効率を求める。
- 最大効率条件を使う。
- 無負荷試験・短絡試験の測定値から等価定数を求める。
- 励磁電流、鉄損電流、磁化電流、励磁アドミタンスの関係を判定する。
- 電圧変動率を負荷力率と結び付けて扱う。

この章では、新幹線の「25 kVを受け、そのまま主電動機へ入れず主変圧器を通す」という流れを導入にするが、試験で解く対象は一般の変圧器問題である。

## 2. 変圧器を機器として見る
変圧器は、交流電力を同じ周波数のまま別の電圧・電流へ変換する静止機器である。一次巻線へ交流電圧を加えると鉄心に交番磁束が生じ、その磁束が二次巻線を鎖交して誘導起電力を生じる。

理想変圧器では損失も漏れ磁束もないと考える。実際の変圧器では、巻線抵抗、漏れ磁束、鉄心損失、励磁に必要な電流があるため、等価回路で補正する。

新幹線側では、系列SPECで確定している次の流れだけを前提とする。

```text
架線 交流25 kV
↓
パンタグラフ
↓
主変圧器
↓
二次側交流
↓
主変換装置
↓
主電動機
```

主変圧器の具体的な二次電圧・容量等は車種で異なるため、本章では一次資料未確認の数値を実値として置かない。

## 3. 理想変圧器の巻数比・電圧比・電流比
一次巻数を `N1`、二次巻数を `N2` とし、巻数比を

```text
a = N1 / N2
```

と定義する。

理想変圧器では

```text
V1 / V2 = N1 / N2 = a
```

したがって

```text
V2 = V1 / a
```

である。

一方、損失がないので入力皮相電力と出力皮相電力は等しい。

```text
V1 I1 = V2 I2
```

電圧比を代入すると

```text
I1 / I2 = N2 / N1 = 1 / a
```

となる。電圧を `a` 倍に換算すると電流は逆に `1/a` 倍になる。

### 定格容量
単相変圧器の定格容量は

```text
S = VI  [V·A]
```

で表す。定格容量は有効電力 `P=VI cosφ` ではなく皮相電力で指定される。負荷力率が変わっても、巻線を流れる電流による熱的制約は残るからである。

## 4. 一次側換算と簡易等価回路
一次側と二次側には電圧レベルの差があるため、そのまま同じ回路として計算しにくい。そこで二次側の量を一次側へ換算する。

巻数比 `a=N1/N2` のとき、二次側量を一次側へ換算すると

```text
V2' = a V2
I2' = I2 / a
r2' = a^2 r2
x2' = a^2 x2
ZL' = a^2 ZL
```

となる。

インピーダンスが `a^2` 倍になる理由は、

```text
Z = V / I
```

に対し、換算後は電圧が `a` 倍、電流が `1/a` 倍だからである。

```text
Z' = (aV) / (I/a) = a^2 Z
```

これにより一次巻線抵抗 `r1` と換算二次巻線抵抗 `r2'` を同じ側で足し、

```text
r = r1 + r2'
```

同様に漏れリアクタンスを

```text
x = x1 + x2'
```

とまとめられる。

試験では「電圧・電流・インピーダンスの倍率を同じにする」誤りが頻出する。電圧は `a`、電流は `1/a`、インピーダンスは `a^2` と分けて覚える。

## 5. 鉄損・銅損・効率
変圧器の主要損失は鉄損と銅損である。

### 鉄損
鉄心で発生し、主に次の二つからなる。

- ヒステリシス損
- 渦電流損

定格付近で電源電圧と周波数を一定とみなす問題では、鉄損は負荷電流によらずほぼ一定として扱う。無負荷損の主成分も鉄損である。

### 銅損
一次・二次巻線の抵抗で生じる `I^2R` 損である。定格電流時の全負荷銅損を `Pcu,n`、負荷率を `x` とすると

```text
Pcu = x^2 Pcu,n
```

となる。負荷率が半分なら銅損は半分ではなく4分の1になる。

### 効率
出力有効電力を `Pout`、鉄損を `Pi`、銅損を `Pcu` とすれば

```text
η = Pout / (Pout + Pi + Pcu)
```

である。

定格容量を `Sn`、負荷率を `x`、負荷力率を `cosφ` とすると、単相変圧器の出力有効電力は

```text
Pout = x Sn cosφ
```

となる。

### 異なる負荷で全損失が与えられる場合
電圧・周波数一定で鉄損を `P0`、銅損係数を `k` と置けば

```text
Ptotal = P0 + k I^2
```

と書ける。異なる2点の電流と全損失があれば連立方程式で `P0` と `k` を求められる。

## 6. 最大効率条件
変圧器では、一定電圧・周波数の条件で

```text
鉄損 = 銅損
Pi = Pcu
```

となる負荷率で効率が最大になる。

全負荷銅損を `Pcu,n` とすると

```text
Pi = x^2 Pcu,n
```

なので

```text
x = sqrt(Pi / Pcu,n)
```

で最大効率となる負荷率を求められる。

ここで「最大効率だから損失がゼロ」ではない。一定に近い鉄損と、負荷で増える銅損が等しくなる点が最大効率点である。

## 7. 無負荷試験・短絡試験
変圧器の等価定数を求める代表的な試験が無負荷試験と短絡試験である。

### 無負荷試験
二次側を開放し、一方の巻線へ定格周波数の電圧を加える。無負荷電流は定格電流より小さく、巻線銅損が小さいため、入力電力は主に鉄損とみなす。

測定する代表量:

- 電圧 `V0`
- 無負荷電流 `I0`
- 入力電力 `P0`

鉄損電流を `Iw` とすれば

```text
Iw = P0 / V0
```

磁化電流を `Im` とすれば、基本波のフェーザ近似では

```text
I0^2 = Iw^2 + Im^2
Im = sqrt(I0^2 - Iw^2)
```

となる。

### 短絡試験
二次側を短絡し、定格電流が流れるまで一次側へ低い電圧を加える。印加電圧が低いため磁束が小さく、鉄損は小さい。したがって入力電力は主として銅損とみなせる。

短絡試験の測定値を `V`, `I`, `P` とすると、試験を行った側から見た等価値は

```text
Z = V / I
r = P / I^2
x = sqrt(Z^2 - r^2)
```

の順で求める。

解法順序は `Z → r → x` と固定する。電力計の指示 `P` をそのままリアクタンスへ結び付けない。

## 8. 励磁電流と励磁回路
無負荷でも一次側には小さな励磁電流が流れる。基本波成分を考えると、励磁電流は

- 鉄損電流 `Iw`: 一次電圧と同相
- 磁化電流 `Im`: 一次電圧より約90°遅れ

に分けられる。

等価回路をアドミタンスで表すと、

```text
Y0 = G0 - jB0
```

と書ける。ここで

- 励磁コンダクタンス `G0`: 鉄損に対応
- 励磁サセプタンス `B0`: 磁化に対応

である。

したがって

```text
G0 = P0 / V0^2
```

また基本波近似では

```text
B0 = Im / V0
```

と求められる。

実際の鉄心は磁気飽和やヒステリシスのため非線形であり、励磁電流は完全な正弦波にはならず高調波を含む。正誤問題では「コンダクタンスとサセプタンスの役割を逆にする」選択肢に注意する。

## 9. 電圧変動率
負荷電流が流れると、巻線抵抗と漏れリアクタンスの電圧降下により二次端子電圧が変化する。

無負荷二次電圧を `V20`、負荷時二次電圧を `V2`、定格二次電圧を `V2n` とすると、電圧変動率を

```text
ε = (V20 - V2) / V2n × 100 [%]
```

と表す。

等価抵抗による百分率抵抗降下を `p[%]`、等価リアクタンスによる百分率リアクタンス降下を `q[%]` とすると、近似的に

遅れ力率負荷:

```text
ε ≈ p cosφ + q sinφ
```

進み力率負荷:

```text
ε ≈ p cosφ - q sinφ
```

となる。進み力率ではリアクタンス成分が差し引かれるため、条件によって電圧変動率が負になることもある。

## 10. 問題を見たときの解法手順
1. 問題が「巻数比」「一次側換算」「損失・効率」「試験」「励磁回路」「電圧変動率」のどれかを判定する。
2. 一次側・二次側のどちらの量かを確認する。
3. 巻数比 `a=N1/N2` を定義する。
4. 等価回路では必要な量を同じ側へ換算する。
5. 損失問題では鉄損を一定、銅損を電流の二乗比例として整理する。
6. 最大効率なら `Pi=Pcu` を使う。
7. 短絡試験では `Z→r→x` の順に求める。
8. 無負荷試験では `P0` を鉄損の近似値とし、`Iw` と `Im` を分ける。
9. 電圧変動率では遅れか進みかを確認し、リアクタンス項の符号を決める。
10. 最後に一次/二次、V/kV、A、W/kW、VA/kVAを確認する。

## 11. 新幹線への接続
新幹線では架線の交流25 kVをそのまま主電動機へ入れるのではなく、主変圧器を介して主変換装置へ電力を渡す。ここで学ぶ巻数比、電流比、容量、損失、効率、電圧降下は、主変圧器も同じ変圧器として考えるための基礎である。

ただし、本章の試験対策に不要な車種別構造や未確認の実値は入れない。新幹線は理論を具体化する入口として使い、練習問題は一般の変圧器問題で構成する。

## 12. 頻出ミス
- 電圧比と電流比を同じ向きにする。
- インピーダンス換算を `a` 倍とし、`a^2` を落とす。
- 銅損を負荷率 `x` に比例させ、`x^2` を落とす。
- 最大効率条件を「損失ゼロ」と考える。
- 短絡試験の入力電力を鉄損とみなす。
- 無負荷試験の入力電力を銅損とみなす。
- 励磁コンダクタンスを磁化側、励磁サセプタンスを鉄損側と逆に覚える。
- 一次側換算量と二次側実量を同じ等価回路に混在させる。
- 進み力率でも電圧変動率のリアクタンス項を加算する。

# 3段階例題

## 例題1 基礎: 巻数比・電圧比・電流比
一次巻数1000、二次巻数100、一次電圧2000 Vの理想単相変圧器がある。二次側へ10 kVAの負荷を接続した。二次電圧、二次電流、一次電流を求めよ。

### 解答
巻数比は

```text
a = N1/N2 = 1000/100 = 10
```

二次電圧は

```text
V2 = V1/a = 2000/10 = 200 V
```

二次電流は

```text
I2 = S/V2 = 10000/200 = 50 A
```

理想変圧器では

```text
I1 = I2/a = 50/10 = 5 A
```

検算すると

```text
V1I1 = 2000×5 = 10000 VA
V2I2 = 200×50 = 10000 VA
```

で一致する。

答え: `V2=200 V`, `I2=50 A`, `I1=5 A`。

## 例題2 本試験標準: 短絡試験から等価定数
単相変圧器の一方の巻線側で短絡試験を行った。電圧計60 V、電流計30 A、電力計900 Wを示した。試験を行った側から見た等価インピーダンス `Z`、等価抵抗 `r`、等価漏れリアクタンス `x` を求めよ。

### 解答
短絡試験では、まず `Z`、次に `r`、最後に `x` を求める。

```text
Z = V/I = 60/30 = 2.00 Ω
```

```text
r = P/I^2 = 900/30^2 = 900/900 = 1.00 Ω
```

```text
x = sqrt(Z^2-r^2)
  = sqrt(2.00^2-1.00^2)
  = sqrt(3)
  ≈ 1.73 Ω
```

答え: `Z=2.00 Ω`, `r=1.00 Ω`, `x≈1.73 Ω`。

## 例題3 複合: 最大効率となる負荷率と効率
定格容量40 kVAの単相変圧器がある。鉄損200 W、全負荷銅損800 Wである。負荷力率0.8を保ったまま負荷率を変える。最大効率となる負荷率と、そのときの効率を求めよ。その他の損失は無視する。

### 解答
最大効率条件は

```text
Pi = Pcu
```

である。負荷率を `x` とすると

```text
Pcu = x^2 × 800
```

なので

```text
200 = 800x^2
x^2 = 0.25
x = 0.50
```

最大効率時の出力有効電力は

```text
Pout = x Sn cosφ
     = 0.50×40 kVA×0.8
     = 16 kW
```

このとき鉄損200 W、銅損200 Wなので全損失は400 W。

```text
η = 16000/(16000+400)
  ≈ 0.9756
  = 97.56 %
```

答え: 負荷率 `0.50`、効率 `約97.6 %`。

## 問1 基礎: 二次電圧
巻数比 `a=N1/N2=20` の理想単相変圧器がある。一次電圧が6.6 kVのとき、二次電圧として最も近いものはどれか。

1. 110 V
2. 220 V
3. 330 V
4. 440 V
5. 660 V

### 解答
正答: 3

```text
V2 = V1/a = 6600/20 = 330 V
```

電圧は巻数比に比例する。`20` を掛けるのではなく割る。

## 問2 基礎: 一次電流と二次電流
定格容量30 kVA、一次電圧3000 V、二次電圧300 Vの理想単相変圧器が定格運転している。一次電流 `I1` と二次電流 `I2` の組合せとして正しいものはどれか。

1. `I1=1 A, I2=10 A`
2. `I1=10 A, I2=10 A`
3. `I1=10 A, I2=100 A`
4. `I1=100 A, I2=10 A`
5. `I1=100 A, I2=100 A`

### 解答
正答: 3

```text
I1 = S/V1 = 30000/3000 = 10 A
I2 = S/V2 = 30000/300 = 100 A
```

電圧を10分の1にすると、同じ容量では電流は10倍になる。

## 問3 基礎: インピーダンス換算
巻数比 `a=N1/N2=5` の変圧器で、二次側負荷インピーダンスが

```text
ZL = 2 + j3 Ω
```

である。これを一次側へ換算した値として正しいものはどれか。

1. `0.08+j0.12 Ω`
2. `0.4+j0.6 Ω`
3. `10+j15 Ω`
4. `25+j25 Ω`
5. `50+j75 Ω`

### 解答
正答: 5

インピーダンスは `a^2` 倍する。

```text
ZL' = a^2 ZL
    = 25(2+j3)
    = 50+j75 Ω
```

`a` 倍ではない。

## 問4 本試験標準: 短絡試験
単相変圧器の短絡試験で、電圧100 V、電流50 A、入力電力2000 Wを得た。試験側から見た等価漏れリアクタンスとして最も近いものはどれか。

1. 0.80 Ω
2. 1.20 Ω
3. 1.50 Ω
4. 1.83 Ω
5. 2.00 Ω

### 解答
正答: 4

```text
Z = V/I = 100/50 = 2.00 Ω
r = P/I^2 = 2000/50^2 = 0.80 Ω
x = sqrt(Z^2-r^2)
  = sqrt(4-0.64)
  = sqrt(3.36)
  ≈ 1.83 Ω
```

2.00 Ωは等価インピーダンスであり、リアクタンスそのものではない。

## 問5 本試験標準: 最大効率負荷率
ある単相変圧器の鉄損は300 W、全負荷銅損は1200 Wである。最大効率となる負荷率として正しいものはどれか。

1. 0.25
2. 0.50
3. 0.60
4. 0.75
5. 1.00

### 解答
正答: 2

最大効率条件は

```text
300 = x^2×1200
x^2 = 0.25
x = 0.50
```

である。

## 問6 本試験標準: 効率
定格容量50 kVAの単相変圧器を負荷率0.6、力率0.8で運転する。鉄損200 W、全負荷銅損500 W、その他の損失は無視できる。効率として最も近いものはどれか。

1. 96.8 %
2. 97.5 %
3. 98.0 %
4. 98.4 %
5. 99.2 %

### 解答
正答: 4

出力は

```text
Pout = 0.6×50 kVA×0.8 = 24 kW
```

銅損は

```text
Pcu = 0.6^2×500 = 180 W
```

全損失は

```text
200+180 = 380 W
```

したがって

```text
η = 24000/(24000+380)
  ≈ 0.9844
  = 98.4 %
```

## 問7 本試験標準: 全損失から無負荷損を分離
一定電圧・一定周波数で運転する単相変圧器について、負荷電流200 Aのとき全損失1200 W、負荷電流100 Aのとき全損失600 Wであった。無負荷損として最も近いものはどれか。

1. 200 W
2. 300 W
3. 400 W
4. 500 W
5. 600 W

### 解答
正答: 3

```text
Ptotal = P0+kI^2
```

より

```text
1200 = P0+k×200^2
600  = P0+k×100^2
```

差を取ると

```text
600 = k(40000-10000)
k = 0.02
```

したがって

```text
P0 = 600-0.02×10000 = 400 W
```

となる。

## 問8 本試験標準: 無負荷試験と励磁電流
単相変圧器の無負荷試験で、印加電圧1000 V、無負荷電流1.00 A、入力電力500 Wを得た。基本波成分で考えた磁化電流として最も近いものはどれか。

1. 0.25 A
2. 0.50 A
3. 0.71 A
4. 0.87 A
5. 1.12 A

### 解答
正答: 4

鉄損電流は

```text
Iw = P0/V0 = 500/1000 = 0.50 A
```

したがって

```text
Im = sqrt(I0^2-Iw^2)
   = sqrt(1.00^2-0.50^2)
   = sqrt(0.75)
   ≈ 0.866 A
```

である。

## 問9 本試験標準: 励磁回路の正誤
変圧器の励磁回路に関する記述として正しいものはどれか。

1. 励磁コンダクタンスは主として磁化電流に対応する。
2. 励磁サセプタンスで消費される有効電力が鉄損に対応する。
3. 鉄損電流の基本波成分は一次電圧とほぼ同相である。
4. 磁化電流の基本波成分は一次電圧とほぼ同相である。
5. 理想変圧器でも鉄損を表すため励磁コンダクタンスが必ず必要である。

### 解答
正答: 3

鉄損電流は有効電力成分なので一次電圧とほぼ同相である。励磁コンダクタンスは鉄損側、励磁サセプタンスは磁化側に対応する。理想変圧器では損失・励磁電流を無視するため励磁枝を必要としない。

## 問10 本試験標準: 遅れ力率時の電圧変動率
百分率抵抗降下 `p=1.5%`、百分率リアクタンス降下 `q=4.0%` の変圧器がある。力率0.8遅れの負荷に対する近似電圧変動率として最も近いものはどれか。ただし `sinφ=0.6` とする。

1. 1.2 %
2. 2.4 %
3. 3.0 %
4. 3.6 %
5. 4.4 %

### 解答
正答: 4

遅れ力率では

```text
ε ≈ p cosφ + q sinφ
  = 1.5×0.8 + 4.0×0.6
  = 1.2+2.4
  = 3.6 %
```

である。

## 問11 複合・応用: 進み力率時の電圧変動率
問10と同じ変圧器を力率0.8進みの負荷で運転する。近似電圧変動率として最も近いものはどれか。

1. -1.2 %
2. 0 %
3. 1.2 %
4. 2.4 %
5. 3.6 %

### 解答
正答: 1

進み力率ではリアクタンス項を差し引く。

```text
ε ≈ p cosφ - q sinφ
  = 1.5×0.8 - 4.0×0.6
  = 1.2-2.4
  = -1.2 %
```

負になること自体は誤りではない。進み電流により端子電圧が上昇する条件があり得る。

## 問12 複合・応用: 試験法と損失の判定
変圧器の試験と損失に関する記述として誤っているものはどれか。

1. 無負荷試験では、通常、入力電力を主として鉄損とみなす。
2. 短絡試験では、定格電流を流すために定格電圧よりかなり低い電圧を加える。
3. 短絡試験では、入力電力を主として銅損とみなす。
4. 電圧・周波数一定なら、鉄損は負荷率の二乗に比例するとみなす。
5. 全負荷銅損が既知なら、負荷率 `x` での銅損は `x^2` 倍で求める。

### 解答
正答: 4

鉄損は電圧・周波数が一定なら負荷によらず概ね一定として扱う。負荷率の二乗に比例するのは銅損である。1・2・3・5は標準的な近似と試験法の説明として正しい。

# 公式・解法まとめ

```text
巻数比                 a = N1/N2
電圧比                 V1/V2 = a
電流比                 I1/I2 = 1/a
一次側換算電圧         V2' = aV2
一次側換算電流         I2' = I2/a
一次側換算インピーダンス Z2' = a^2 Z2
銅損                   Pcu = x^2 Pcu,n
効率                   η = Pout/(Pout+Pi+Pcu)
最大効率条件           Pi = Pcu
最大効率負荷率         x = sqrt(Pi/Pcu,n)
短絡試験               Z=V/I, r=P/I^2, x=sqrt(Z^2-r^2)
無負荷試験の鉄損電流   Iw = P0/V0
磁化電流               Im = sqrt(I0^2-Iw^2)
励磁コンダクタンス     G0 = P0/V0^2
遅れ力率の電圧変動率   ε ≈ p cosφ + q sinφ
進み力率の電圧変動率   ε ≈ p cosφ - q sinφ
```
