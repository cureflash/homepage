# 練習問題

## 問1 基礎: 発電制動と回生制動
発電制動と回生制動の違いについて、最も適切なものはどれか。

1. 発電制動では電動機を発電機として使用しない。
2. 回生制動では発生した電気エネルギーを必ず抵抗で熱にする。
3. 発電制動では発生電力を電源へ返し、回生制動では抵抗で消費する。
4. 発電制動では発生電力を抵抗などで消費し、回生制動では電源側へ返還する。
5. 両者はエネルギーの処理先まで同一である。

### 解答・解説
正答: 4

どちらも制動時に電動機を発電機として利用できるが、発生した電気エネルギーの処理先が異なる。

```text
発電制動: 運動エネルギー → 電気エネルギー → 抵抗などで熱として消費
回生制動: 運動エネルギー → 電気エネルギー → 電源側へ返還
```

1、2、3、5はこの違いと逆である。

## 問2 基礎: 制動力と速度から機械出力
制動力の大きさが `60.0 kN`、速度が `20.0 m/s` のとき、機械側の制動出力の大きさとして正しいものはどれか。

1. `0.30 MW`
2. `0.60 MW`
3. `1.20 MW`
4. `3.00 MW`
5. `12.0 MW`

### 解答・解説
正答: 3

制動力と速度から機械出力の大きさを求めるので

```text
P = Fv
  = 60000×20.0
  = 1.20×10^6 W
  = 1.20 MW
```

よって3。`60.0 kN=60000 N` の換算が必要である。

## 問3 基礎: 誘導機の発電機運転
ある誘導機の同期速度が `1500 min^-1`、回転子速度が `1530 min^-1` である。このときの滑りと運転状態の組合せとして正しいものはどれか。

1. `s=+0.020`、電動機運転
2. `s=+0.020`、発電機運転
3. `s=0`、同期運転
4. `s=-0.020`、発電機運転
5. `s=-0.020`、電動機運転

### 解答・解説
正答: 4

```text
s = (Ns-N)/Ns
  = (1500-1530)/1500
  = -0.020
```

`N>Ns` なので滑りは負となり、誘導機は発電機運転になる。よって4。

## 問4 本試験標準: 回転速度とトルク
回転速度 `1200 min^-1` で機械出力の大きさが `75.0 kW` の回転機がある。トルクの大きさとして最も近いものはどれか。

1. `99.5 N·m`
2. `298 N·m`
3. `597 N·m`
4. `900 N·m`
5. `1257 N·m`

### 解答・解説
正答: 3

まず回転速度を角速度へ直す。

```text
ω = 2πN/60
  = 2π×1200/60
  ≈ 125.66 rad/s
```

`P=Tω` より

```text
T = P/ω
  = 75000/125.66
  ≈ 596.8 N·m
```

よって3。`1200 min^-1` をそのまま `P=Tω` に代入してはならない。

## 問5 本試験標準: 回転体の運動エネルギー
慣性モーメント `J=200 kg·m²` の回転体が `900 min^-1` で回転している。回転運動エネルギーとして最も近いものはどれか。

1. `88.8 kJ`
2. `444 kJ`
3. `628 kJ`
4. `888 kJ`
5. `1.78 MJ`

### 解答・解説
正答: 4

```text
ω = 2π×900/60
  ≈ 94.25 rad/s
```

したがって

```text
E = Jω²/2
  = 200×94.25²/2
  ≈ 8.88×10^5 J
  ≈ 888 kJ
```

よって4。運動エネルギーは回転速度ではなく角速度の2乗に比例する。

## 問6 本試験標準: 減速時の平均機械出力
慣性モーメント `J=120 kg·m²` の回転体が `1500 min^-1` から `900 min^-1` まで `4.00 s` で減速した。放出された回転運動エネルギーだけを考えるとき、平均機械出力の大きさとして最も近いものはどれか。

1. `94.7 kW`
2. `158 kW`
3. `237 kW`
4. `379 kW`
5. `947 kW`

### 解答・解説
正答: 3

```text
ω1 = 2π×1500/60 ≈ 157.08 rad/s
ω2 = 2π×900/60  ≈ 94.25 rad/s
```

エネルギー差は

```text
ΔE = J(ω1²-ω2²)/2
   ≈ 120×(157.08²-94.25²)/2
   ≈ 9.47×10^5 J
   ≈ 947 kJ
```

平均機械出力は

```text
Pavg = ΔE/t
     ≈ 947/4.00
     ≈ 237 kW
```

よって3。

## 問7 本試験標準: 並進運動エネルギーと回収電力量
質量 `2.00×10^4 kg` の物体が `20.0 m/s` から `10.0 m/s` まで減速する。減少した並進運動エネルギーの `80 %` を電気側へ回収できるとき、回収電力量として最も近いものはどれか。

1. `0.167 kWh`
2. `0.333 kWh`
3. `0.500 kWh`
4. `0.667 kWh`
5. `0.833 kWh`

### 解答・解説
正答: 4

まず運動エネルギー差は

```text
ΔE = m(v1²-v2²)/2
   = 2.00×10^4×(20.0²-10.0²)/2
   = 3.00×10^6 J
   = 3.00 MJ
```

回収エネルギーは

```text
Erec = ηΔE
     = 0.80×3.00
     = 2.40 MJ
```

`1 kWh=3.6 MJ` より

```text
Erec = 2.40/3.6
     ≈ 0.667 kWh
```

よって4。回生時は機械エネルギーから電気エネルギーへ変換するので、効率は掛ける。

## 問8 本試験標準: 機械出力から制動力
速度 `25.0 m/s` で走行中、機械側の制動出力の大きさが `800 kW` である。制動力の大きさとして正しいものはどれか。

1. `16.0 kN`
2. `32.0 kN`
3. `40.0 kN`
4. `64.0 kN`
5. `200 kN`

### 解答・解説
正答: 2

`P=Fv` を制動力について解く。

```text
F = P/v
  = 800000/25.0
  = 32000 N
  = 32.0 kN
```

よって2。

## 問9 本試験標準: 回生時の電流・トルク方向
直流機で界磁方向と回転方向を保ったまま、電動機運転から回生運転へ移る場合の説明として最も適切なものはどれか。

1. 回生運転では回転方向を必ず逆転させる。
2. 回生運転では誘導起電力の方向を必ず反転させる。
3. 回生運転では電流方向とトルク方向が電動機運転時から反転し、電力は電源側へ戻る。
4. 回生運転ではトルク方向は電動機運転時と同じでなければならない。
5. 回生運転では電力は常に抵抗だけで消費される。

### 解答・解説
正答: 3

界磁方向と回転方向を保ったままでも、発電機側の誘導起電力が電源電圧を上回る条件では電流が電源側へ流れ、電機子電流の向きが電動機運転時から反転する。界磁方向が同じなら電磁トルクも反転し、回転を妨げる制動トルクとなる。よって3。

1と2は必須条件ではない。4は制動トルクの向きと逆。5は発電制動の説明であり、回生制動ではない。

## 問10 本試験標準: 四象限運転の概念
回転方向を正とし `ω>0` で回転している機械について、正転制動・回生に対応する組合せとして正しいものはどれか。

1. `T>0`、`Tω>0`
2. `T<0`、`Tω<0`
3. `T=0`、`Tω>0`
4. `T>0`、`Tω<0`
5. `T<0`、`Tω>0`

### 解答・解説
正答: 2

正転中は `ω>0`。制動ではトルクが回転方向と逆なので `T<0` となる。

```text
P = Tω < 0
```

したがって正転制動・回生は `T<0`、`Tω<0` であり、2が正しい。四象限運転はこの符号関係の概念までを扱う。

## 問11 複合・応用: 回転エネルギー・効率・平均回収電力
慣性モーメント `J=300 kg·m²` の回転体が `1800 min^-1` から `900 min^-1` まで `6.00 s` で減速する。減少した回転運動エネルギーの `75 %` を電気側へ回収できるとき、平均回収電力として最も近いものはどれか。

1. `250 kW`
2. `375 kW`
3. `500 kW`
4. `750 kW`
5. `1.00 MW`

### 解答・解説
正答: 3

まず

```text
ω1 = 2π×1800/60 ≈ 188.50 rad/s
ω2 = 2π×900/60  ≈ 94.25 rad/s
```

回転運動エネルギー差は

```text
ΔE = J(ω1²-ω2²)/2
   ≈ 300×(188.50²-94.25²)/2
   ≈ 4.00×10^6 J
   = 4.00 MJ
```

回収エネルギーは

```text
Erec = 0.75×4.00
     ≈ 3.00 MJ
```

したがって平均回収電力は

```text
Prec,avg = Erec/t
         ≈ 3.00 MJ/6.00 s
         ≈ 0.500 MW
         = 500 kW
```

よって3。回生効率を考えるので、平均回収電力は平均機械制動出力より小さい。

## 問12 複合・応用: 車両モデルの減速と平均回収電力
計算練習用の仮定値として、質量 `4.00×10^4 kg` の車両が `25.0 m/s` から `15.0 m/s` まで `10.0 s` で減速し、減少した並進運動エネルギーの `80 %` を電気側へ回収できるものとする。他のエネルギー項は考えない。平均回収電力として正しいものはどれか。

1. `320 kW`
2. `400 kW`
3. `512 kW`
4. `640 kW`
5. `800 kW`

### 解答・解説
正答: 4

運動エネルギー差は

```text
ΔE = m(v1²-v2²)/2
   = 4.00×10^4×(25.0²-15.0²)/2
   = 8.00×10^6 J
   = 8.00 MJ
```

回収エネルギーは

```text
Erec = 0.80×8.00
     = 6.40 MJ
```

平均回収電力は

```text
Prec,avg = Erec/t
         = 6.40 MJ/10.0 s
         = 0.640 MW
         = 640 kW
```

よって4。この数値は計算練習用の仮定値であり、特定の新幹線車両の実値ではない。
