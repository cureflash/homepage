## 解説本文

### 1. このテーマで電験は何を問うか

このテーマは機械科目の電動機応用・発電機作用・回生制動である。本試験では、電動機と発電機でエネルギーとトルクの向きがどう変わるか、発電制動と回生制動を区別できるか、速度・力・トルクから機械出力を求められるか、並進・回転の運動エネルギー差から制動時の平均出力や回収可能エネルギーを計算できるかが問われる。

中心式は次のとおりである。

```text
P = Fv
P = Tω
ω = 2πN / 60
Etrans = mv² / 2
Erot = Jω² / 2
Pavg = ΔE / t
Erec = ηΔE
```

`P[W]` は機械出力、`F[N]` は力、`v[m/s]` は速度、`T[N·m]` はトルク、`ω[rad/s]` は角速度、`N[min^-1]` は回転速度、`m[kg]` は質量、`J[kg·m²]` は慣性モーメント、`E[J]` はエネルギー、`t[s]` は時間、`η` は回生経路の効率である。

### 2. 電動機作用と発電機作用

電動機は電気エネルギーを受け取り、軸から機械エネルギーを出す。発電機は逆に、軸から機械エネルギーを受け取り、電気エネルギーを出す。

```text
電動機作用: 電気 → 電動機 → 機械
発電機作用: 機械 → 発電機 → 電気
```

制動時に主電動機へ発電機作用をさせると、車輪から主電動機へ機械エネルギーが入り、回転方向とは逆向きの電磁トルクが生じる。この逆向きトルクが制動トルクになる。

直流機で界磁方向と回転方向を保ったまま回生へ移る場合、誘導起電力そのものの向きを逆にする必要はない。発電機側の誘導起電力が電源電圧を上回る条件になると電流が電源側へ流れ、電機子電流の向きが電動機運転時と反転する。界磁方向が同じなら `T∝ΦIa` よりトルク方向も反転し、回転を妨げる制動トルクとなる。

### 3. 発電制動と回生制動の違い

どちらも電動機を発電機として使って制動する点は共通する。違いは発生した電気エネルギーの処理先である。

```text
発電制動:
運動エネルギー → 発電機作用 → 電気エネルギー → 抵抗などで熱として消費

回生制動:
運動エネルギー → 発電機作用 → 電気エネルギー → 電源側へ返還
```

したがって、「電気で止める」だけでは両者を区別できない。試験では、発生電力を抵抗で消費するのか、電源へ返すのかを見る。

新幹線の回生をこの教材では次のエネルギーフローで捉える。

```text
運動エネルギー
→ 車輪
→ 主電動機の発電機作用
→ 電気エネルギー
→ 主変換装置
→ 架線側
```

主変換装置内部の詳細回路や制御方式はこのTopicの固定範囲外なので扱わない。

### 4. 力・速度と機械出力

直線運動で力 `F` が速度 `v` の向きに仕事をするとき、機械出力の大きさは

```text
P = Fv
```

である。制動では力の向きは速度と逆なので、符号を付ければ機械出力は負になるが、電験の選択問題で「制動時に取り出せる出力の大きさ」を求める場合は `|P|=Fv` として大きさを計算する。

効率が与えられたら、どちら向きの変換かを確認する。力行時に電気入力から機械出力を得るなら

```text
η = Pmech / Pelec
```

回生時に機械入力から電気出力を得るなら

```text
η = Pelec / Pmech
```

である。回生時の回収電力は `Pelec=ηPmech` となる。効率を掛けるか割るかを、エネルギーの向きで判断する。

### 5. 回転速度・トルクと機械出力

回転速度 `N[min^-1]` は、そのまま `P=Tω` に代入できない。まず

```text
ω = 2πN / 60
```

で角速度へ変換する。その後

```text
P = Tω
T = P / ω
```

を使う。

例えば、`N=1500 min^-1`、機械出力の大きさ `P=30.0 kW` なら

```text
ω = 2π×1500/60
  ≈ 157.1 rad/s

T = 30000/157.1
  ≈ 191 N·m
```

となる。制動時はトルクが回転方向と逆向きなので、符号を付けるなら `T` は負、大きさだけなら `191 N·m` と扱う。

### 6. 並進と回転の運動エネルギー

車両全体の並進運動エネルギーは

```text
Etrans = mv² / 2
```

である。速度 `v1` から `v2` へ減速したときに減少する運動エネルギーは

```text
ΔEtrans = m(v1² - v2²) / 2
```

となる。

回転体の運動エネルギーは

```text
Erot = Jω² / 2
```

である。角速度 `ω1` から `ω2` へ減速したときは

```text
ΔErot = J(ω1² - ω2²) / 2
```

である。

このエネルギー差を時間 `t` で放出するなら平均機械出力の大きさは

```text
Pavg = ΔE / t
```

で求められる。実際の瞬時制動出力が一定とは限らないため、これは指定区間の平均値である。

### 7. 効率を含む回収電力量

回生経路全体の効率を `η` とすると、機械側から失われた運動エネルギー `ΔE` のうち電気側へ回収できるエネルギーは

```text
Erec = ηΔE
```

である。回収電力量を `kWh` で表すときは

```text
1 kWh = 3.6 MJ
```

で換算する。

また、制動時間 `t` が与えられれば平均回収電力は

```text
Prec,avg = Erec / t = ηΔE / t
```

となる。回生時は「機械エネルギーから電気エネルギーへ変換」なので、損失がある限り回収電力量は元の運動エネルギー差より小さい。

### 8. 誘導機の発電機運転

誘導機の同期速度を `Ns`、回転子速度を `N` とすると滑りは

```text
s = (Ns - N) / Ns
```

である。

電動機運転では通常 `N<Ns` なので `s>0` である。回転子を同期速度より速く回す、すなわち

```text
N > Ns
```

になると

```text
s < 0
```

となり、誘導機は発電機運転になる。このとき電磁トルクは回転方向と逆向きになり、機械側から入ったエネルギーを電気側へ返す。回生ブレーキでは、この発電機運転を制動に利用する。

ここでは負の滑りとエネルギー・トルク方向の関係までを扱う。等価回路、二次入力・二次銅損、ベクトル制御の詳細は扱わない。

### 9. 四象限運転の概念

回転速度 `ω` とトルク `T` の符号で運転状態を整理すると、機械出力 `P=Tω` の符号で力行と制動を区別できる。

| 回転方向 | トルク方向 | `Tω` | 状態 |
|---|---|---:|---|
| `ω>0` | `T>0` | 正 | 正転力行 |
| `ω>0` | `T<0` | 負 | 正転制動・回生 |
| `ω<0` | `T<0` | 正 | 逆転力行 |
| `ω<0` | `T>0` | 負 | 逆転制動・回生 |

重要なのは、回転方向とトルク方向が同じなら力行、逆なら制動という判定である。四象限の詳細な回路解析は行わない。

### 10. 本試験の解法アルゴリズム

1. 問題が力行か制動か、発電制動か回生制動かを判定する。
2. 並進問題なら `F` と `v`、回転問題なら `N` と `T` または `J` を拾う。
3. `N[min^-1]` は `ω=2πN/60` で `rad/s` に直す。
4. 出力問題は `P=Fv` または `P=Tω` を使う。
5. エネルギー問題は `mv²/2` または `Jω²/2` を使い、減速前後の差 `ΔE` を取る。
6. 平均出力なら `Pavg=ΔE/t` を使う。
7. 回収電力量なら回生経路の向きを確認し、`Erec=ηΔE` を使う。
8. 誘導機なら `s=(Ns-N)/Ns` の符号を見て、`N>Ns`、`s<0` なら発電機運転と判断する。
9. 最後に、エネルギーの流れ、トルク方向、効率を掛ける/割る、単位を検算する。

### 11. 頻出ミス

- 発電制動と回生制動を「どちらも電気ブレーキ」で同一視する。
- 回生時に誘導起電力の向きそのものが必ず反転すると考える。
- 制動時の電流・トルク方向の反転と、回転方向の反転を混同する。
- `N[min^-1]` をそのまま `P=Tω` に代入する。
- `P=Fv` で `kN` を `N` へ直さない。
- 回転エネルギーで `E=Jω²/2` ではなく `JN²/2` とする。
- 減速時のエネルギー差で `E2-E1` として負値をそのまま回収量にする。
- 回生効率を `ηΔE` ではなく `ΔE/η` とする。
- `s<0` を計算ミスと判断する。誘導機では `N>Ns` の発電機運転で負の滑りになる。

## 3段階例題

### 例題1 基礎 — 制動力・速度・回収電力

仮定した制動条件として、制動力の大きさを `12.0 kN`、速度を `25.0 m/s`、回生経路の効率を `0.85` とする。機械側の制動出力の大きさと、電気側へ回収される電力を求めよ。

```text
F = 12.0 kN = 12000 N

Pmech = Fv
      = 12000×25.0
      = 300000 W
      = 300 kW

Prec = ηPmech
     = 0.85×300
     = 255 kW
```

答え: 機械側 `300 kW`、回収電力 `255 kW`。

検算: 回生効率が1未満なので、回収電力は機械側の制動出力より小さい。

### 例題2 本試験標準 — 回転体の減速と平均制動出力

慣性モーメント `J=25.0 kg·m²` の回転体が `1800 min^-1` から `1200 min^-1` まで `3.00 s` で減速した。失われた回転運動エネルギーと平均制動出力の大きさを求めよ。

まず回転速度を角速度へ変換する。

```text
ω1 = 2π×1800/60
   ≈ 188.50 rad/s

ω2 = 2π×1200/60
   ≈ 125.66 rad/s
```

運動エネルギー差は

```text
ΔE = J(ω1²-ω2²)/2
   = 25.0×(188.50²-125.66²)/2
   ≈ 2.467×10^5 J
   ≈ 246.7 kJ
```

したがって平均制動出力は

```text
Pavg = ΔE/t
     = 246.7/3.00
     ≈ 82.2 kW
```

答え: エネルギー差 約 `246.7 kJ`、平均制動出力 約 `82.2 kW`。

検算: 回転速度が下がっているため `ω1²-ω2²>0` で、放出されるエネルギーは正の大きさになる。

### 例題3 複合 — 車両の減速、回収電力量、平均回収電力

仮定値として、質量 `m=2.00×10^5 kg` の車両が `30.0 m/s` から `10.0 m/s` まで `20.0 s` で減速し、減少した並進運動エネルギーの `80 %` を電気側へ回収できるものとする。他のエネルギー項は考えない。運動エネルギー差、回収電力量、平均回収電力を求めよ。

```text
ΔE = m(v1²-v2²)/2
   = 2.00×10^5×(30.0²-10.0²)/2
   = 8.00×10^7 J
   = 80.0 MJ
```

回収エネルギーは

```text
Erec = ηΔE
     = 0.80×80.0
     = 64.0 MJ
```

`1 kWh=3.6 MJ` より

```text
Erec = 64.0/3.6
     ≈ 17.8 kWh
```

平均回収電力は

```text
Prec,avg = Erec/t
         = 64.0 MJ / 20.0 s
         = 3.20 MW
```

答え: 運動エネルギー差 `80.0 MJ`、回収電力量 約 `17.8 kWh`、平均回収電力 `3.20 MW`。

この数値は計算練習用の仮定値であり、特定の新幹線車両の実値ではない。
