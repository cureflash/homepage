### 制作前独立検証

公式解答との照合前に、問題文と固定範囲の関係だけで再導出した。

1. R8上 機械 問11
   - 荷重側に必要な機械出力は `P=mgv=1000×9.8×0.5=4.9 kW`。
   - 機械効率 `η=0.90` なので、電動機出力は `4.9/0.90≈5.44 kW`。
   - 答案 `(4)` → 公式 `(4)`、PASS。
2. R2 機械 問11
   - `ω1=2π×1500/60≈157.1 rad/s`、`ω2=2π×1000/60≈104.7 rad/s`。
   - `ΔE=J(ω1²-ω2²)/2≈343 kJ`。
   - 2 sで放出する平均出力は `P≈343/2≈171.5 kW`。
   - 答案 `(3)` → 公式 `(3)`、PASS。
3. H29 機械 問2
   - 回転方向と界磁が同じなら誘導起電力の向き自体は反転しない。
   - 回生時は電流とトルクの向きが電動機時から反転し、電力は直流機から電源へ戻る。
   - 誤りは「誘導起電力の方向が反転する」。
   - 答案 `(2)` → 公式 `(2)`、PASS。
4. H25 機械 問10
   - `n=N/60`、`ω=2πn`。
   - `P=Tω` より `T=P/ω`。
   - 回転体の運動エネルギーは `E=Iω0²/2`。
   - 答案 `(5)` → 公式 `(5)`、PASS。
5. H24 機械 問11
   - 減速時に電動機側から戻るエネルギーは慣性モーメントの大きい負荷ほど大きい。
   - 抵抗で電力を熱として消費するのが発電制動、電源へ戻して再利用するのが回生制動。
   - 答案 `(1)` → 公式 `(1)`、PASS。

## 過去問とSPECから確定した教材必須範囲

1. 力行と回生でエネルギーの流れが反転することを示す。
2. 発電機作用では、回転方向を維持したまま電流・トルク・電力の向きが電動機運転時と変わることを説明する。
3. 誘導機では `s=(Ns-N)/Ns` が負、すなわち `N>Ns` の領域で発電機運転となり、回転方向と逆向きの制動トルクが生じることを説明する。
4. 発電制動は発生電力を抵抗等で消費し、回生制動は電源側へ返還するという違いを明示する。
5. `P=Fv`、`P=Tω`、`ω=2πN/60` を使って制動力・トルク・機械出力を相互に計算できるようにする。
6. `E=mv²/2` と `E=Jω²/2` を使い、減速前後の運動エネルギー差を求められるようにする。
7. `P=ΔE/t` と効率を使い、制動時間、回生可能電力量、回収電力量を計算できるようにする。
8. 四象限運転は、回転方向とトルク方向の組合せを概念図で示すところまでとする。
9. 新幹線側では `運動エネルギー → 主電動機 → 電気エネルギー → 主変換装置 → 架線` の流れを主軸にし、未確認実車値や詳細な主変換回路解析は追加しない。
