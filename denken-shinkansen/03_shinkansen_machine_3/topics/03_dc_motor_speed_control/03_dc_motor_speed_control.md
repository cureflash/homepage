## 過去問とSPECから確定した教材必須範囲

### 1. 速度式と成立条件
- `V=E+IaRa`
- `E=kΦN`
- よって `N=(V-IaRa)/(kΦ)`。
- 電機子回路へ直列抵抗 `R` を入れる場合は `N={V-Ia(Ra+R)}/(kΦ)`。
- 一定磁束なら速度は逆起電力に比例し、電機子電圧を変えると速度が変わる。
- 電機子抵抗による電圧降下を無視できる条件と、無視してはいけない計算を区別する。

### 2. 始動と始動抵抗
- 始動直後は `N=0` なので `E=0`。
- 抵抗を入れなければ `Istart=V/Ra` となり、大電流になり得る。
- 分巻電動機では始動抵抗を電機子回路に直列に入れて始動電流を制限する。
- 回転速度が上がって逆起電力が増えるにつれ、始動抵抗を段階的に減らす理由を説明する。

### 3. 電機子電圧制御
- 磁束を一定とし、電機子電圧 `V` を変えて速度を制御する。
- R6上問2・R1問1型では、各運転点で逆起電力を求めて速度比を取る。
- R4上問1で要求される範囲として、静止レオナード方式が電圧制御法であることを扱う。

### 4. 界磁制御・弱め界磁
- 界磁磁束 `Φ` を変えて速度を制御する。
- `N∝1/Φ` の関係から、界磁を弱めると速度が上がることを説明する。
- `T=kΦIa` と組み合わせ、弱め界磁では同じ電機子電流でもトルクが低下することを示す。

### 5. 抵抗制御
- 電機子回路に直列抵抗を入れ、`IaR` の電圧降下を利用して速度を下げる。
- 抵抗で電力損失が生じることを式から説明する。
- 始動抵抗と速度制御用抵抗は、目的を区別して説明する。

### 6. タップ制御と新幹線への接続
系列SPECで確定している次の関係だけを使う。

```text
変圧器側で電圧を変える
↓
主電動機へ加わる電圧が変わる
↓
電流・トルク・速度が変化する
```

0系の体系的な速度制御の入口としてタップ制御を扱うが、未確認のタップ数、主電動機定格値、具体的な回路定数は追加しない。

### 7. 定トルク運転・定出力運転の基本
- 系列SPECで指定されている範囲として、低速側の電機子電圧制御と定トルク運転、高速側の弱め界磁と定出力運転の基本関係を扱う。
- `T=kΦIa` と `P=Tω` を使い、定出力域では速度上昇に伴ってトルクが低下することを説明する。
- 高度な駆動制御則や現代VVVF車の制御へは広げない。

### 8. 再利用可能な解法手順
1. 電動機形式と、一定とみなせる量（磁束・トルク・電機子電流）を読む。
2. 始動問題なら `N=0 → E=0` を適用する。
3. 運転中は `E=V-IaRa`、直列抵抗があればその電圧降下も引く。
4. 一定磁束なら `E∝N`、磁束が変わるなら `E=kΦN` で速度比を立てる。
5. トルク条件がある場合は `T=kΦIa` で電機子電流との関係を確定する。
6. 単位と物理的傾向（電圧を下げれば速度が下がる、弱め界磁なら速度が上がる等）で検算する。

### 9. 頻出ミス
- 端子電圧 `V` をそのまま逆起電力 `E` と置く。
- 始動時にも逆起電力があると考える。
- 始動抵抗を界磁回路へ入れると誤認する。
- 界磁を弱めると速度も下がると逆に覚える。
- 一定トルク条件で、一定磁束なら `Ia` も一定になることを見落とす。
- 電機子電圧制御・界磁制御・抵抗制御を混同する。

# 解説本文

## 1. このテーマで電験は何を問うか
直流電動機の速度問題では、速度そのものを暗記するのではなく、端子電圧 `V`、逆起電力 `E`、電機子電流 `Ia`、電機子抵抗 `Ra`、磁束 `Φ`、回転速度 `N` の関係を使って運転点の変化を追う。

本試験で中心になるのは次の4種類である。

1. 電機子電圧を変えたときの回転速度を求める。
2. 始動時に大電流が流れる理由と、始動抵抗の働きを説明・計算する。
3. 電機子電圧制御・界磁制御・抵抗制御を区別する。
4. 弱め界磁で速度・トルク・出力がどう変わるか判断する。

このテーマでは、問題文から「何が一定か」を先に決め、`V=E+IaRa`、`E=kΦN`、`T=kΦIa` の3本を必要な順に使えることを到達点とする。

## 2. 必要な基礎概念
### 2.1 端子電圧と逆起電力
電動機に加える端子電圧を `V [V]`、回転によって電機子に生じる逆起電力を `E [V]` とする。運転中は電機子抵抗 `Ra [Ω]` に `IaRa` の電圧降下が生じるため、

`V = E + IaRa`

となる。したがって、逆起電力は

`E = V - IaRa`

である。速度計算で `V=E` と置いてよいのは、問題上 `IaRa` を無視できると明示されるか、十分小さい近似として扱える場合だけである。

### 2.2 逆起電力と速度
磁束を `Φ`、回転速度を `N`、機械定数を `k` とすると、

`E = kΦN`

である。同じ機械で磁束が一定なら `E∝N` となるため、2つの運転点では

`N2/N1 = E2/E1`

とできる。磁束も変わる場合は、

`N2/N1 = (E2/E1) × (Φ1/Φ2)`

を使う。

### 2.3 トルクと電機子電流
直流電動機の電磁トルクは

`T = kΦIa`

で表す。同じ機械で磁束一定なら、トルク一定は電機子電流一定と読み替えられる。永久磁石直流電動機のように磁束が一定の問題でも同じ考え方を使える。

### 2.4 始動時だけ条件が違う
始動直後は回転していないため `N=0` であり、`E=kΦN` から `E=0` である。したがって抵抗を追加しなければ、

`Istart = V/Ra`

となる。`Ra` は小さいため、始動電流が大きくなり得る。そこで電機子回路に始動抵抗 `Rstart` を直列に入れ、

`Istart = V/(Ra+Rstart)`

として電流を制限する。

回転速度が上がると `E` が増え、同じ抵抗のままでは電流が小さくなる。そのため始動抵抗は速度上昇に合わせて段階的に減らし、最終的には外す。

## 3. 公式と成立条件
### 3.1 速度式
`V=E+IaRa` と `E=kΦN` を組み合わせると、

`N = (V-IaRa)/(kΦ)`

となる。速度を変える方法は、この式の分子または分母を変える方法として整理できる。

| 制御法 | 変える量 | 速度への主な作用 | 注意点 |
|---|---|---|---|
| 電機子電圧制御 | `V` | `V` を下げると速度低下、上げると速度上昇 | `IaRa` の電圧降下を無視できるか確認する |
| 界磁制御 | `Φ` | 磁束を弱めると速度上昇 | 同じ `Ia` なら `T=kΦIa` によりトルク低下 |
| 抵抗制御 | 電機子直列抵抗 `R` | 抵抗を増やすと速度低下 | `Ia^2R` の損失が生じる |

電機子回路に直列抵抗 `R` があるときは、

`N = {V-Ia(Ra+R)}/(kΦ)`

となる。

### 3.2 電機子電圧制御
磁束を一定に保ち、端子電圧を変える方法である。同じ負荷トルクかつ磁束一定なら `Ia` も一定なので、各運転点で

`E1=V1-IaRa`

`E2=V2-IaRa`

を求め、`N2/N1=E2/E1` とする。静止レオナード方式は、本テーマで必要な分類上は電圧制御法として扱う。

### 3.3 界磁制御と弱め界磁
端子電圧と電機子電流が同じなら `E` も同じなので、`E=kΦN` から

`N∝1/Φ`

となる。磁束を弱めるほど速度は上がる。一方、`T=kΦIa` から、同じ `Ia` ではトルクは磁束に比例して小さくなる。

### 3.4 抵抗制御
電機子回路に抵抗 `R` を追加すると、`IaR` の電圧降下だけ逆起電力に使える電圧が減るため速度が下がる。ただし抵抗では `Ia^2R` の電力が熱として失われる。

始動抵抗も電機子回路に直列に入れるが、目的は始動時の大電流制限である。速度制御用抵抗とは目的を区別する。

### 3.5 定トルク運転と定出力運転の基本
磁束を一定に保ち、電機子電圧で速度を上げる低速側では、`T=kΦIa` より、電流上限の範囲でトルクをほぼ一定に扱える。

さらに高速側で弱め界磁を行うと、速度は上がるが同じ電流で得られるトルクは下がる。`P=Tω` なので、速度上昇とトルク低下が対応する領域を定出力運転の基本として捉える。

## 4. 問題を見たときの解法手順
1. 電動機形式を確認し、磁束が一定か、変化するかを判定する。
2. 「トルク一定」があれば、磁束一定の条件で `T=kΦIa` から `Ia` 一定と判断する。
3. 始動問題なら `N=0 → E=0` を最初に適用する。
4. 運転中は必ず `E=V-IaRa` を確認する。直列抵抗があれば `IaR` も引く。
5. 磁束一定なら `N2/N1=E2/E1`、磁束変化なら `N2/N1=(E2/E1)(Φ1/Φ2)` を立てる。
6. トルクを問われたら `T=kΦIa`、出力の傾向を問われたら `P=Tω` を使う。
7. 最後に、電圧低下で速度が上がっていないか、弱め界磁で速度が下がっていないかを物理的に検算する。

## 5. 典型例題
### 5.1 基礎例題 — 電機子電圧を下げたときの速度
他励直流電動機が `V1=200 V`、`Ia=20 A`、`Ra=0.50 Ω`、`N1=1000 min^-1` で運転している。磁束と負荷トルクを一定に保ったまま、電機子電圧を `V2=170 V` に下げた。新しい回転速度 `N2` を求める。

磁束一定かつトルク一定なので、`T=kΦIa` から `Ia` は一定である。

最初の逆起電力は

`E1 = 200 - 20×0.50 = 190 V`

変更後は

`E2 = 170 - 20×0.50 = 160 V`

磁束一定なので `E∝N`。

`N2 = 1000×160/190 = 842 min^-1`

よって約 `842 min^-1`。端子電圧比 `170/200` をそのまま速度比にしてはいけない。`IaRa` を引いた逆起電力の比を使う。

### 5.2 本試験標準例題 — 始動抵抗
分巻直流電動機の端子電圧を `220 V`、電機子抵抗を `0.40 Ω` とする。始動電流を `50 A` 以下に制限するために必要な始動抵抗を求める。また、回転上昇後に逆起電力が `100 V` になった時点で電流を再び `50 A` とするには、始動抵抗を何 `Ω` まで減らせばよいか。

始動直後は `E=0` なので、必要な全抵抗は

`Ra+Rstart = 220/50 = 4.40 Ω`

したがって

`Rstart = 4.40-0.40 = 4.00 Ω`

逆起電力が `100 V` まで増えた後、`50 A` を流すのに必要な全抵抗は

`Ra+Rstart = (220-100)/50 = 2.40 Ω`

よって

`Rstart = 2.40-0.40 = 2.00 Ω`

始動時は `4.00 Ω`、速度上昇後は `2.00 Ω`。逆起電力が増えるほど、同じ電流を保つために始動抵抗を減らす必要がある。

### 5.3 複合・ひっかけ例題 — 弱め界磁と定出力の基本
他励直流電動機が `V=200 V`、`Ia=25 A`、`Ra=0.40 Ω`、`N1=1200 min^-1` で運転している。端子電圧と電機子電流をそのままにして、磁束を `Φ2=0.80Φ1` に弱めた。回転速度比、トルク比、`P=Tω` で見た出力比を求める。機械損は比較から除く。

端子電圧、電機子電流、電機子抵抗が同じなので、

`E1=E2=200-25×0.40=190 V`

である。`E=kΦN` より、

`N2/N1 = Φ1/Φ2 = 1/0.80 = 1.25`

したがって

`N2 = 1200×1.25 = 1500 min^-1`

トルクは `T=kΦIa` だから、`Ia` 一定より

`T2/T1 = Φ2/Φ1 = 0.80`

出力比は `P=Tω` から、回転速度比を角速度比として使えば

`P2/P1 = 0.80×1.25 = 1.00`

となる。弱め界磁では速度が上がり、同じ電流でのトルクは下がる。この組合せが定出力運転の基本関係である。

## 6. 新幹線への接続
Topic 03で使う新幹線側の接続は、系列SPECで確定している次の範囲に限定する。

```text
変圧器側で電圧を変える
↓
主電動機へ加わる電圧が変わる
↓
電流・トルク・速度が変化する
```

0系の速度制御を入口として見ると、変圧器側で電圧を変えることは、直流電動機の電機子電圧を変えて運転点を動かす考え方につながる。速度が上がった後は、弱め界磁によってさらに高速側へ移るという基本関係を理解する。

ここでは、0系の具体的なタップ数、主電動機の定格値、回路定数は扱わない。確認できていない実車値を仮定して真値のように使わない。

## 7. 頻出ミス・ひっかけ
- `V=E` と決めつけず、まず `E=V-IaRa` を確認する。
- 始動時は `N=0` なので `E=0`。運転中の式をそのまま始動時へ当てはめない。
- 始動抵抗は電機子回路へ直列に入れる。界磁回路ではない。
- 界磁を弱めると `N∝1/Φ` により速度は上がる。
- 弱め界磁では `T=kΦIa` により、同じ電機子電流でもトルクは下がる。
- 「トルク一定」と「電機子電流一定」は、磁束一定という条件を確認してから結び付ける。
- 抵抗制御は速度を下げられるが、抵抗損失を伴う。
- 始動抵抗と速度制御用抵抗は同じ「直列抵抗」でも目的が違う。

## 9. 公式・解法まとめ
- 電機子回路: `V=E+IaRa`
- 逆起電力: `E=kΦN`
- 速度: `N=(V-IaRa)/(kΦ)`
- 直列抵抗あり: `N={V-Ia(Ra+R)}/(kΦ)`
- トルク: `T=kΦIa`
- 始動時: `N=0 → E=0`
- 始動電流: `Istart=V/(Ra+Rstart)`
- 電機子電圧制御: `Φ` を一定にして `V` を変える
- 界磁制御: `Φ` を変える。弱め界磁では速度上昇・同電流時トルク低下
- 抵抗制御: 電機子直列抵抗の電圧降下で速度低下、抵抗損失あり
- 定トルク側: 磁束一定で `Ia` を保つ基本関係
- 定出力側: 弱め界磁で速度上昇、トルク低下。`P=Tω` で対応を確認
