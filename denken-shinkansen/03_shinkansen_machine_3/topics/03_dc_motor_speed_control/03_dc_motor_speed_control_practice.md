# 練習問題

## 問1 基礎: 逆起電力
他励直流電動機を端子電圧 `V=220 V` で運転している。電機子電流 `Ia=20 A`、電機子抵抗 `Ra=0.50 Ω` とし、ブラシ電圧降下を無視する。逆起電力 `E` として正しいものはどれか。

1. 10 V
2. 200 V
3. 210 V
4. 220 V
5. 230 V

### 解答・解説
正答: 3

運転中の電機子回路では、端子電圧の一部が電機子抵抗の電圧降下 `IaRa` に使われ、残りが逆起電力となる。

```text
V = E + IaRa
```

したがって

```text
E = V - IaRa
  = 220 - 20×0.50
  = 210 V
```

よって正答は3。

1は `IaRa` だけを答えた誤り。4は `V=E` として電機子抵抗降下を無視した誤り。5は電圧降下の符号を逆にした誤りである。

検算すると `210+20×0.50=220 V` となり、端子電圧に戻る。

## 問2 基礎: 始動時の電流
直流分巻電動機の始動について正しい記述はどれか。

1. 始動直後は回転速度が最大なので逆起電力も最大である。
2. 始動直後は `N=0` なので `E=0` となり、電機子抵抗が小さいと大きな電機子電流が流れ得る。
3. 始動電流を制限する抵抗は界磁回路へ直列に入れる。
4. 速度が上がって逆起電力が増えるほど、始動抵抗を増やしていく。
5. 始動時だけは `V=E+IaRa` が成立しない。

### 解答・解説
正答: 2

始動直後は回転していないため

```text
N = 0
E = kΦN = 0
```

である。このとき外部抵抗がなければ

```text
Istart = V/Ra
```

となり、`Ra` が小さいため大電流になり得る。

1は逆で、始動直後の逆起電力は0。3は誤りで、始動抵抗は電機子回路へ直列に入れる。4も逆で、速度上昇に伴って `E` が増えれば始動抵抗は段階的に減らす。5も誤りで、始動時も電圧方程式は成立し、`E=0` を代入して使う。

## 問3 基礎: トルクと電機子電流
磁束一定で運転している他励直流電動機の電機子電流を `25 A` から `30 A` に増やした。磁束が変わらないとき、電磁トルクは元の何倍になるか。

1. 0.80倍
2. 0.833倍
3. 1.00倍
4. 1.20倍
5. 1.44倍

### 解答・解説
正答: 4

直流電動機の電磁トルクは

```text
T = kΦIa
```

である。磁束 `Φ` が一定なので、トルクは電機子電流に比例する。

```text
T2/T1 = Ia2/Ia1
       = 30/25
       = 1.20
```

よって正答は4。

5の1.44倍は電流比を二乗した誤りで、直巻機の未飽和域など別条件の関係と混同している。

## 問4 本試験標準: 電機子電圧変更後の速度
他励直流電動機が `V1=200 V`、`Ia=30 A`、`Ra=0.40 Ω`、`N1=1000 min^-1` で運転している。磁束と負荷トルクを一定に保ったまま、電機子電圧を `V2=164 V` に下げた。新しい回転速度 `N2` として最も近いものはどれか。

1. 760 min^-1
2. 809 min^-1
3. 820 min^-1
4. 872 min^-1
5. 1000 min^-1

### 解答・解説
正答: 2

磁束一定かつトルク一定なので、`T=kΦIa` より電機子電流 `Ia` も一定である。

最初の逆起電力は

```text
E1 = V1 - IaRa
   = 200 - 30×0.40
   = 188 V
```

変更後は

```text
E2 = V2 - IaRa
   = 164 - 30×0.40
   = 152 V
```

磁束一定なので `E∝N`。したがって

```text
N2 = N1×E2/E1
   = 1000×152/188
   ≈ 808.5 min^-1
```

よって正答は2。

端子電圧比 `164/200=0.82` をそのまま速度比にすると820 min^-1となるが、これは `IaRa` の電圧降下を無視した誤答である。電圧を下げたので速度が元の1000 min^-1より低くなることも検算になる。

## 問5 本試験標準: 永久磁石直流電動機の電圧制御
永久磁石直流電動機が `V1=240 V`、`Ia=40 A`、`Ra=0.50 Ω`、`N1=1200 min^-1` で一定トルク運転している。負荷トルクを変えずに電源電圧を `V2=180 V` に下げた。新しい回転速度として最も近いものはどれか。

1. 720 min^-1
2. 800 min^-1
3. 873 min^-1
4. 900 min^-1
5. 1100 min^-1

### 解答・解説
正答: 3

永久磁石機では磁束が一定である。さらに負荷トルク一定なので、`T=kΦIa` から `Ia` も一定となる。

変更前の逆起電力は

```text
E1 = 240 - 40×0.50
   = 220 V
```

変更後は

```text
E2 = 180 - 40×0.50
   = 160 V
```

磁束一定なので

```text
N2 = 1200×160/220
   ≈ 872.7 min^-1
```

よって正答は3。

電圧比だけを使うと `1200×180/240=900 min^-1` となるが、電機子抵抗降下を考慮していない。正しい速度はそれより少し低い873 min^-1付近になる。

## 問6 本試験標準: 必要な始動抵抗
直流電動機を `220 V` の電源で始動する。電機子抵抗は `Ra=0.20 Ω` である。始動電流を `100 A` 以下に制限するため、電機子回路へ直列に入れる始動抵抗 `Rstart` として必要な値はどれか。

1. 0.20 Ω
2. 1.80 Ω
3. 2.00 Ω
4. 2.20 Ω
5. 22.0 Ω

### 解答・解説
正答: 3

始動直後は `E=0` なので

```text
Istart = V/(Ra+Rstart)
```

である。始動電流を100 Aとするために必要な全抵抗は

```text
Ra+Rstart = V/Istart
          = 220/100
          = 2.20 Ω
```

したがって

```text
Rstart = 2.20 - 0.20
       = 2.00 Ω
```

よって正答は3。

4の2.20 Ωは必要な全抵抗をそのまま始動抵抗とした誤り。始動抵抗は既存の電機子抵抗を差し引いて求める。

検算すると `220/(0.20+2.00)=100 A` である。

## 問7 本試験標準: 始動抵抗の段階的切外し
問6と同じ電動機が回転を始め、逆起電力が `E=110 V` まで増えた。電機子電流を再び `100 A` とするために必要な始動抵抗 `Rstart` はどれか。

1. 0.40 Ω
2. 0.80 Ω
3. 0.90 Ω
4. 1.10 Ω
5. 2.00 Ω

### 解答・解説
正答: 3

運転中は逆起電力を差し引いて電流を求める。

```text
Ia = (V-E)/(Ra+Rstart)
```

したがって必要な全抵抗は

```text
Ra+Rstart = (V-E)/Ia
          = (220-110)/100
          = 1.10 Ω
```

よって

```text
Rstart = 1.10 - 0.20
       = 0.90 Ω
```

正答は3。

始動直後の `Rstart=2.00 Ω` をそのまま残すと

```text
Ia = (220-110)/(0.20+2.00)
   = 50 A
```

まで電流が下がる。速度上昇で逆起電力が増えるにつれて始動抵抗を減らす理由がここにある。

## 問8 本試験標準: 速度制御法の分類
直流電動機の速度制御に関する記述として正しいものはどれか。

1. 静止レオナード方式は界磁制御法に分類される。
2. 界磁を弱めると、他の条件が同じなら回転速度は低下する。
3. 電機子回路の直列抵抗を増やすと、抵抗損失なしで速度を上げられる。
4. 電機子電圧制御は、磁束をおおむね一定に保ちながら電機子に加える電圧を変えて速度を制御する。
5. 始動抵抗は界磁回路へ入れて逆起電力を増やすために用いる。

### 解答・解説
正答: 4

電機子電圧制御は、磁束を一定に保ちながら電機子端子電圧 `V` を変える方法であり、速度式

```text
N = (V-IaRa)/(kΦ)
```

の分子を変える制御と整理できる。

1は誤り。静止レオナード方式は本テーマで必要な分類では電圧制御法である。2は誤りで、`N∝1/Φ` なので弱め界磁では速度が上がる。3は誤りで、抵抗制御は `Ia^2R` の損失を伴い、通常は速度を下げる。5は誤りで、始動抵抗は電機子回路へ直列に入れ、始動電流を制限する。

## 問9 本試験標準: 抵抗制御と抵抗損失
直流電動機が `V=200 V`、`Ia=20 A`、`Ra=0.50 Ω`、`N1=1000 min^-1` で運転している。磁束と電機子電流を一定とし、電機子回路へ `R=2.0 Ω` の抵抗を直列に追加した。追加後の回転速度と、追加抵抗で生じる損失の組合せとして最も近いものはどれか。

1. `632 min^-1`, `400 W`
2. `789 min^-1`, `800 W`
3. `800 min^-1`, `400 W`
4. `1000 min^-1`, `800 W`
5. `1267 min^-1`, `800 W`

### 解答・解説
正答: 2

追加前の逆起電力は

```text
E1 = V-IaRa
   = 200-20×0.50
   = 190 V
```

追加後は電機子抵抗と追加抵抗の両方で電圧が落ちる。

```text
E2 = V-Ia(Ra+R)
   = 200-20×(0.50+2.0)
   = 150 V
```

磁束一定なので

```text
N2 = 1000×150/190
   ≈ 789 min^-1
```

追加抵抗の損失は

```text
PR = Ia^2R
   = 20^2×2.0
   = 800 W
```

したがって正答は2。

抵抗を追加すると速度は下がり、同時に抵抗で熱損失が生じる。抵抗制御が損失を伴うことを、速度式と `Ia^2R` の両方で確認できる。

## 問10 本試験標準: 弱め界磁と定出力の基本
他励直流電動機で端子電圧、電機子電流、電機子抵抗を変えず、磁束を `Φ2=0.80Φ1` に弱めた。機械損は比較から除く。回転速度比 `N2/N1`、トルク比 `T2/T1`、電磁出力比 `P2/P1` の組合せとして正しいものはどれか。

1. `0.80, 0.80, 0.64`
2. `0.80, 1.25, 1.00`
3. `1.00, 0.80, 0.80`
4. `1.25, 0.80, 1.00`
5. `1.25, 1.25, 1.56`

### 解答・解説
正答: 4

端子電圧、電機子電流、電機子抵抗が同じなので逆起電力 `E=V-IaRa` も同じである。

`E=kΦN` より

```text
N2/N1 = Φ1/Φ2
       = 1/0.80
       = 1.25
```

また `T=kΦIa` で `Ia` 一定だから

```text
T2/T1 = Φ2/Φ1
       = 0.80
```

角速度比は回転速度比と同じなので、`P=Tω` より

```text
P2/P1 = 0.80×1.25
       = 1.00
```

したがって正答は4。弱め界磁では速度が上がり、同じ電流でのトルクは下がる。この組合せが定出力運転の基本関係である。

## 問11 複合・応用: 電圧変更と弱め界磁を同時に行う
他励直流電動機が `V1=250 V`、`Ia=25 A`、`Ra=0.40 Ω`、`N1=1000 min^-1` で運転している。電機子電流を一定に保ったまま、電機子電圧を `V2=230 V` に変更し、同時に磁束を `Φ2=0.80Φ1` に弱めた。新しい回転速度 `N2` とトルク比 `T2/T1` の組合せとして最も近いものはどれか。

1. `917 min^-1`, `0.80`
2. `1146 min^-1`, `0.80`
3. `1146 min^-1`, `1.25`
4. `1250 min^-1`, `0.80`
5. `1375 min^-1`, `1.00`

### 解答・解説
正答: 2

まず各運転点の逆起電力を求める。

```text
E1 = 250-25×0.40
   = 240 V
```

```text
E2 = 230-25×0.40
   = 220 V
```

今回は磁束も変わるため、単純な `E2/E1` だけでは速度比にならない。

```text
N2/N1 = (E2/E1)×(Φ1/Φ2)
       = (220/240)×(1/0.80)
       ≈ 1.1458
```

したがって

```text
N2 ≈ 1000×1.1458
   ≈ 1146 min^-1
```

トルクは `T=kΦIa`。電機子電流は一定なので

```text
T2/T1 = Φ2/Φ1
       = 0.80
```

よって正答は2。

電機子電圧だけを見ると速度は下がる方向だが、磁束を20%弱めた効果の方が大きいため、結果として速度は上がる。複数の制御量が変化するときは、速度式の分子と分母を両方確認する。

## 問12 複合・応用: 定トルク域・定出力域とタップ制御
本テーマで扱う直流電動機の速度制御と新幹線への接続について、正しい記述はどれか。

1. 低速側では弱め界磁だけを用いて磁束を減らし、トルクを増加させるのが定トルク運転の基本である。
2. 高速側で弱め界磁を行うと、同じ電機子電流でもトルクが増え、速度は下がる。
3. 磁束一定で電機子電圧を変える低速側では、電流上限の範囲で定トルク運転の基本関係を作りやすく、高速側では弱め界磁による速度上昇とトルク低下が定出力運転の基本につながる。
4. タップ制御は主電動機の界磁磁束だけを直接変更する方式として扱う。
5. タップ制御では変圧器側の電圧を変えても主電動機へ加わる電圧は変化しない。

### 解答・解説
正答: 3

磁束一定では `T=kΦIa` より、電機子電流の上限内でトルクをほぼ一定に扱える。低速側で電機子電圧を上げて速度を上げる考え方が、定トルク運転の基本につながる。

さらに高速側で弱め界磁を行うと、`N∝1/Φ` により速度は上がる一方、同じ `Ia` では `T∝Φ` によりトルクは下がる。速度上昇とトルク低下が対応すると `P=Tω` はほぼ一定となり、定出力運転の基本関係になる。

系列SPECで確定している新幹線との接続は次の範囲だけである。

```text
変圧器側で電圧を変える
↓
主電動機へ加わる電圧が変わる
↓
電流・トルク・速度が変化する
```

したがって4と5は誤り。未確認の0系実車タップ数や回路定数はこの問題では使用しない。
