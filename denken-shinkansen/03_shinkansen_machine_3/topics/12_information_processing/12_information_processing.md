基本構成は `センサ → 電気信号 → A/D変換 → デジタルデータ → 演算・論理判断 → 制御指令 → 機器` とする。

過去問要求から、上記固定範囲内の詳細として「基数変換」「2進数の加減算」「基本論理式の簡単化」「真理値表と論理式・論理回路の相互変換」「組合せ論理回路の入力から出力を追う」までを扱う。カルノー図、フリップフロップ、記憶装置、プログラム・フローチャート、符号付き2進数・補数表現、通信プロトコル、インタフェース規格は固定範囲へ追加しない。

## 過去問とSPECから確定した教材必須範囲

1. 位取り記数法を使い、2進数・10進数・16進数を相互変換できるようにする。
2. 16進1桁と2進4bitの対応を使って、2進数↔16進数を短時間で変換できるようにする。
3. bit と byte の意味・関係を説明する。
4. 2進数の加減算を行い、和・差から未知の2進数を逆算できるようにする。
5. AND / OR / NOT / NAND / NOR / XOR の図記号、論理式、真理値表を相互に対応させる。
6. 論理式の相補・分配・吸収・ド・モルガン則を、過去問の簡単化に必要な範囲で使えるようにする。
7. 真理値表から論理式を判別し、論理回路から真理値表・出力を導出できるようにする。
8. 組合せ論理回路について、入力が時間変化する場合も各区間の0/1を順に評価できるようにする。
9. A/D変換はセンサ等のアナログ電気信号をディジタルデータへ変換する役割、D/A変換はその逆方向として説明する。
10. `センサ → 電気信号 → A/D変換 → デジタルデータ → 演算・論理判断 → 制御指令 → 機器` の流れを説明する。
11. 情報伝送は、車両内で必要なデータ・指令を機器間で受け渡す概念までに限定し、通信規格・プロトコルを追加しない。
12. 新幹線側の説明は公開資料で確認できる状態監視・情報処理の概念に限定し、車種固有仕様を推測しない。
