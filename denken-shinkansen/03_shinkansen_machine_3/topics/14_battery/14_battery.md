# 解説本文

## 1. このテーマで電験は何を問うか

電験三種「機械」の電池分野では、電池の構成、一次電池と二次電池の違い、リチウムイオン二次電池の基本構造、容量と電力量、直列・並列接続、内部抵抗、充放電効率を区別して扱えることが必要になる。

このテーマの品質ゲートであるH30 機械 問12は計算問題ではなく、リチウムイオン二次電池について次の五つを正しく組み合わせる知識問題である。

1. 正極の代表的材料
2. 負極の代表的材料
3. 電解液の種類
4. 放電時のリチウムイオンの移動方向
5. セル電圧の代表的な範囲

一方、系列SPECは電池容量、電力量、直列・並列、放電時間、必要容量の計算も要求する。したがって本章では、H30問12の知識判断と、電池を電源として扱う基本計算の両方を身につける。

## 2. 電池・正極・負極・電解質

電池は、正極、負極、電解質を基本要素として電気エネルギーを外部回路へ供給する電源である。端子間には電位差が生じ、負荷を接続すると外部回路へ電流を流せる。

- 正極: 放電時に外部回路側で高い電位となる電極。
- 負極: 放電時に外部回路側で低い電位となる電極。
- 電解質: 電池内部でイオンが移動するための媒体。
- 起電力 `E [V]`: 電池が電荷を移動させる能力を電圧として表した量。理想電源モデルでは電池内部の電圧源として扱う。
- 端子電圧 `V [V]`: 実際に電池端子間で得られる電圧。
- 電流 `I [A]`: 単位時間に移動する電荷量を表す。

内部抵抗を `r [Ω]` とし、放電時に電池から外部へ流れる電流を `I` とする単純な等価回路では、

```text
V = E - Ir
```

となる。`Ir` は内部抵抗による電圧降下である。したがって、同じ起電力でも放電電流が大きいほど端子電圧は低くなる。この式は本章で内部抵抗の基本的影響を理解するためのモデルであり、N700S実機の電池特性を表すものではない。

## 3. 一次電池・二次電池・充電・放電

一次電池は、基本的に放電して使用する電池であり、繰り返し充電して使うことを前提としない。二次電池は、放電後に外部から電気エネルギーを与えて充電し、繰り返し利用する電池である。

- 放電: 電池に蓄えられたエネルギーを外部回路へ取り出す。
- 充電: 外部電源から電気エネルギーを電池へ与え、再び取り出せる状態にする。

N700Sのバッテリ自走システムを考えるときも、電験上はまず「充電してエネルギーを蓄え、必要時に放電して負荷へ供給する二次電池」という一般モデルで理解する。実機の電池化学系、容量、電圧、直並列構成は本章では断定しない。

## 4. リチウムイオン二次電池 — H30 問12で必要な知識

H30 機械 問12で要求された代表的知識は次のとおりである。

| 項目 | 覚える内容 |
|---|---|
| 正極 | リチウムを含む金属酸化物 |
| 負極 | 主に黒鉛 |
| 電解液 | 有機電解液 |
| 放電時のリチウムイオン | 負極から正極へ移動 |
| セル当たり電圧 | 3〜4 V程度 |

放電時には、リチウムイオンが電解液中を負極側から正極側へ移動する。充電時はその逆向きに移動する。試験では、電極材料・電解液・移動方向・電圧範囲をばらして選択肢に入れるため、単語を個別に暗記せず一組として整理する。

H30問12では、この五項目をすべて満たす組合せが正答になる。固定EXAM_ALIGNMENTで公式正答 `(1)` と照合済みである。

## 5. AhとWhを混同しない

電池容量を `C [Ah]`、一定電流を `I [A]`、放電時間を `t [h]` とする理想化条件では、

```text
C = It
```

したがって、

```text
t = C / I
I = C / t
```

と変形できる。

`Ah` は電荷量に対応する容量であり、エネルギーそのものではない。電力量は `Wh` で表す。電圧を一定値 `V [V]` とみなす基本計算では、

```text
W = VC
```

ここで `W [Wh]`、`V [V]`、`C [Ah]` である。また、負荷電力 `P [W]` が一定なら、

```text
W = Pt
```

となる。

例として、48 V・20 Ahの電池を理想的に扱えば、電力量は

```text
W = 48 × 20 = 960 Wh
```

である。20 Ahだけを見て「大きなエネルギー」と判断してはいけない。同じ20 Ahでも電圧が異なればWhは変わる。

## 6. 直列接続と並列接続

同一仕様の電池を理想的に接続する条件で考える。

### 直列接続

セル電圧を `V_c`、容量を `C_c`、直列数を `n_s` とすると、

```text
V = n_s V_c
C = C_c
```

直列では電圧が加算され、Ah容量はそのままである。

### 並列接続

並列数を `n_p` とすると、

```text
V = V_c
C = n_p C_c
```

並列では電圧はそのままで、Ah容量が加算される。

### 直並列

同一セルを `n_s` 直列、`n_p` 並列とする理想化条件では、

```text
V = n_s V_c
C = n_p C_c
W = VC = n_s n_p V_c C_c
```

となる。

## 7. 充放電効率

電池へ入れた電力量のすべてを後で取り出せるとは限らない。本章では、効率を0〜1の比で扱う。

充電効率を `η_ch` とし、充電器から電池へ入力した電力量を `W_ch,in`、電池に蓄えられる電力量を `W_stored` とすると、

```text
η_ch = W_stored / W_ch,in
W_ch,in = W_stored / η_ch
```

放電効率を `η_dis` とし、電池側で必要な蓄積電力量を `W_stored`、負荷へ供給できる電力量を `W_load` とすると、

```text
η_dis = W_load / W_stored
W_stored = W_load / η_dis
```

負荷電力 `P [W]`、運転時間 `t [h]`、電池電圧を一定値 `V [V]` とする基本計算では、必要な電池容量は

```text
C = Pt / (V η_dis)
```

で求められる。効率80%なら `η_dis = 0.80` として計算し、80をそのまま代入しない。

## 8. 問題を見たときの解法手順

### 知識問題

1. 一次電池か二次電池かを確認する。
2. 問われている項目を、正極・負極・電解質・充放電方向・電圧に分ける。
3. リチウムイオン二次電池なら、H30問12の五項目を一組で照合する。
4. 一項目だけ合う選択肢ではなく、全項目が一致するものを選ぶ。

### 計算問題

1. 求める量が `Ah` か `Wh` かを先に決める。
2. 時間の単位を `h` にそろえる。
3. 直列数と並列数があれば先に電圧と容量を整理する。
4. `C = It`、`W = VC`、`W = Pt` から必要な式を選ぶ。
5. 効率が与えられたら、負荷へ必要な量を効率で割って電池側必要量へ戻す。
6. 内部抵抗問題では、放電時の `V = E - Ir` で端子電圧を確認する。
7. 最後に単位と桁を確認する。

## 9. 典型例題

### 基礎例題 — 容量と放電時間

48 V・20 Ahの電池を、理想的に一定4 Aで放電する。放電時間と電力量を求める。

容量より、

```text
t = C / I = 20 / 4 = 5 h
```

電力量は、

```text
W = VC = 48 × 20 = 960 Wh
```

答えは5 h、960 Wh。`20 Ah = 20 Wh` としてはいけない。

### 本試験標準例題 — 直列・並列

1セルを3.7 V・2.5 Ahとし、同一セルを10直列4並列で理想的に接続する。全体の電圧、容量、電力量を求める。

直列で電圧が加算されるので、

```text
V = 10 × 3.7 = 37 V
```

並列で容量が加算されるので、

```text
C = 4 × 2.5 = 10 Ah
```

したがって、

```text
W = 37 × 10 = 370 Wh
```

答えは37 V、10 Ah、370 Wh。

### 複合・ひっかけ例題 — 必要電力から必要容量

2.0 kWの負荷を1.5 h動かす。電池系の電圧を100 V一定、放電効率を80%とする。必要な電池容量を求める。

まず負荷へ必要な電力量は、

```text
W_load = Pt = 2.0 × 1.5 = 3.0 kWh
```

放電効率80%なので、電池側に必要な蓄積電力量は、

```text
W_stored = 3.0 / 0.80 = 3.75 kWh = 3750 Wh
```

必要容量は、

```text
C = 3750 / 100 = 37.5 Ah
```

答えは37.5 Ah。効率を掛けて `3.0 × 0.80` とすると必要容量を過小評価する。

さらに充電効率が90%で、この3.75 kWhを電池へ蓄えるのに必要な入力電力量を求めるなら、

```text
W_ch,in = 3.75 / 0.90 = 4.17 kWh
```

となる。

## 10. N700Sへの接続

JR東海の公式N700S案内では、N700Sが高速鉄道で世界初となるバッテリ自走システムを搭載すると明記されている。本章では、この事実を電池理論の入口として使う。

電験の考え方へ一般化すると、外部から通常どおり給電できない場面でも、二次電池に蓄えた電気エネルギーを放電して負荷へ供給できる、という電源の役割で理解できる。必要なエネルギーを考えるときは `W = Pt`、電池容量へ直すときは `W = VC`、効率を考慮するときは `C = Pt/(Vη_dis)` へ接続する。

ただし、これは電験計算へ接続する一般化モデルである。N700S実機について、搭載電池の化学系、実容量、直並列数、定格電圧、自走速度・距離・時間、詳細な電力経路は本章では断定しない。

## 11. 頻出ミス・ひっかけ

- `Ah` と `Wh` を同じ量として扱う。
- `A` と `Ah` を混同する。
- 分をそのまま `h` として式へ入れる。
- 直列接続でAh容量まで加算する。
- 並列接続で電圧まで加算する。
- 効率80%を `80` として代入する。
- 必要容量計算で効率を掛け、必要量を小さくしてしまう。
- リチウムイオン電池の放電時イオン移動方向を逆にする。
- 正極と負極の代表材料を逆に覚える。
- セル電圧を1〜2 V程度と誤認する。
