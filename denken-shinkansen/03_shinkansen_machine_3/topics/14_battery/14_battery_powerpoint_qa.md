## スライド構成
1. 停電してもN700Sが走れるのはなぜ？
   - `蓄電池 → 直流電力 → 主変換装置 → 主電動機 → 低速自走` の基本構成を可視化
   - JR東海一次資料で確認済みの「高速鉄道で世界初となるバッテリ自走システム」搭載だけを実車事実として表示
   - 電池容量・電圧・セル数・自走条件は推測しないことを明示
   - H30 機械 問12の固定5項目へ接続
2. H30 問12：リチウムイオン二次電池は「5項目を一組」で覚える
   - 正極=`Liを含む金属酸化物`
   - 負極=`主に黒鉛`
   - 電解液=`有機電解液`
   - 放電時 `Li+` 移動=`負極 → 正極`
   - セル電圧=`3〜4 V程度`
   - 選択肢では5項目すべて一致する組合せを選ぶことを可視化
3. Ah と Wh、直列と並列を混同しない
   - `C = It [Ah]`、`W = VC = Pt [Wh]`
   - 48 V・20 Ah、4 A放電の本文例 `5 h / 960 Wh` を再現
   - 同一仕様セルの理想接続で、直列は電圧加算、並列はAh容量加算
   - 3.7 V・2.5 Ahを10直列4並列とした本文例 `37 V / 10 Ah / 370 Wh` を再現
4. 内部抵抗と効率：必要容量は「負荷側から逆算」する
   - 放電時 `V = E - Ir`
   - `Wload = Pt → Wbat = Wload / η放電 → C = Wbat / V` の解法を可視化
   - 本文の複合例題 `2.0 kW × 1.5 h = 3.0 kWh → 3.75 kWh → 37.5 Ah` を再現
   - 効率80%を掛けず、必要量を`0.80`で割るひっかけを明示
