### 新幹線側の扱い

系列SPECに列挙されたコンプレッサ、冷却ブロワ、冷却ファン、ポンプ、空調機、ドア駆動装置を「主電動機以外にも電動機負荷がある」ことを示す導入候補とする。車種固有の補機形式、定格出力、電圧、周波数、回転速度、インバータ方式等は真値として固定しない。

## 過去問とSPECから確定した教材必須範囲

1. `P = ωT` と `ω = 2πN/60` を結び付け、出力・回転速度・トルクを相互に計算できるようにする。
2. 電動機トルクと負荷トルクの差で加速・減速が決まり、両者の交点が動作点になることを説明する。
3. トルク－速度曲線の交点について、速度が少しずれたとき元へ戻るか離れるかで安定・不安定を判定できるようにする。
4. ポンプの水動力 `P_h = ρgQH` を、各記号・単位・成立条件とともに説明する。
5. `m³/min`・`m³/h` を `m³/s` へ換算し、実揚程・全揚程・損失水頭を取り違えない解法手順を示す。
6. ポンプ効率と電動機効率をどちら側の電力に掛けるかをエネルギーの流れで説明し、必要入力・必要出力を逆算できるようにする。
7. 余裕係数を要求出力へ掛ける理由と、複数台のポンプでは必要台数を整数へ切り上げることを説明する。
8. ファン・ポンプ系の代表的な負荷特性として `Q ∝ N`、`T ∝ N²`、`P ∝ N³` を扱い、回転速度を下げたとき所要動力がどう変わるか計算できるようにする。
9. インバータ駆動・可変速運転は、ファン・ポンプの必要流量に合わせて回転速度を変える電動機応用として扱う。車種固有の補機制御方式は推測しない。
10. 新幹線側の補機は電験論点を具体化する導入に限定し、補機そのものの技術紹介を主目的にしない。

## 解説本文

### 1. このテーマで電験は何を問うか

電験三種「機械」の電動機応用では、電動機単体の原理だけでなく、電動機がポンプやファンなどの負荷を回したときの出力、トルク、回転速度、効率、所要動力が問われる。特に、回転機械の機械出力 `P = ωT`、ポンプの水動力 `ρgQH`、効率を含む所要入力、ファン・ポンプの速度変化に対する負荷特性が重要である。

この章を終えたとき、次を自力で行えるようにする。

- 回転速度 `N` から角速度 `ω` を求め、`P = ωT` で出力・トルクを計算する。
- 電動機トルクと負荷トルクから加速・減速・動作点を判断する。
- トルク－速度曲線の交点が安定か不安定かを判断する。
- 流量を `m³/s` に換算し、全揚程からポンプ水動力を求める。
- ポンプ効率、電動機効率、余裕係数を正しい順序で反映する。
- 必要台数を定格出力から整数へ切り上げる。
- `Q ∝ N`、`T ∝ N²`、`P ∝ N³` を使い、可変速時の流量・トルク・動力を求める。

### 2. 回転速度・角速度・トルク・出力

回転機械では、回転速度 `N [min^-1]` を角速度 `ω [rad/s]` へ直してから、トルク `T [N·m]` と組み合わせる。

`ω = 2πN / 60`

`P = ωT`

したがって、

`P = (2πN/60)T`

である。`N` が同じならトルクが大きいほど出力は大きく、`T` が同じなら回転速度が高いほど出力は大きい。逆算すると、

`T = P/ω`

`N = 60P/(2πT)`

となる。ここで `P` は機械出力であり、電動機への電気入力とは区別する。効率 `η_m` を含めて電気入力を求める場合は、

`P_in = P/η_m`

とする。

### 3. 電動機トルクと負荷トルク

電動機が発生するトルクを `T_m`、ポンプやファンなど負荷が要求するトルクを `T_L` とする。

- `T_m > T_L` なら、回転を増やす向きの余力があるため加速する。
- `T_m < T_L` なら、負荷の要求が大きいため減速する。
- `T_m = T_L` なら、トルクが釣り合い、その回転速度が動作点になる。

試験では、電動機と負荷のトルク－速度曲線を同じグラフに描き、その交点を読む問題がある。交点は単に「曲線が交わった場所」ではなく、速度が少し変化したときに元へ戻るかまで確認する。

### 4. 動作点の安定・不安定

ある交点より少し低速側で `T_m > T_L` となり加速し、少し高速側で `T_m < T_L` となり減速するなら、速度変化が交点へ戻されるのでその動作点は安定である。

逆に、低速側で減速し、高速側で加速するなら、いったんずれた速度がさらに交点から離れるので不安定である。

安定性は曲線の見た目だけで暗記せず、「少し低速にずらす」「少し高速にずらす」の二方向で `T_m - T_L` の符号を確認する。

### 5. ポンプの水動力

流体を流量 `Q [m³/s]` で全揚程 `H [m]` だけ持ち上げるとき、水へ与える有効な動力は、

`P_h = ρgQH`

で求める。

- `P_h`: 水動力 `[W]`
- `ρ`: 流体密度 `[kg/m³]`
- `g`: 重力加速度 `[m/s²]`
- `Q`: 流量 `[m³/s]`
- `H`: 全揚程 `[m]`

水の場合、試験では `ρ = 1000 kg/m³`、`g = 9.8 m/s²` など問題文の指定値を使う。重要なのは `Q` を必ず `m³/s` にそろえることである。

`m³/min → m³/s`: 60で割る。

`m³/h → m³/s`: 3600で割る。

### 6. 実揚程・損失水頭・全揚程

ポンプが必要とする全揚程は、単純な高低差だけとは限らない。問題で実揚程と損失水頭が別々に与えられた場合は、指定された条件に従い、

`H = H_actual + H_loss`

として全揚程を作る。過去問では、流量換算そのものよりも「実揚程だけを代入して損失水頭を落とす」ミスが典型的である。

また、問題文が「全揚程は実揚程の何倍」と与える場合は、その倍率を使う。式を使う前に、どの値が最終的な `H` なのかを確定する。

### 7. ポンプ効率と電動機効率

水動力は流体へ実際に渡った有効動力である。ポンプに損失があるため、ポンプ軸へ必要な機械入力は、

`P_pump = P_h/η_p`

となる。さらに電動機にも損失があるため、電動機の電気入力は、

`P_in = P_pump/η_m = P_h/(η_pη_m)`

となる。

エネルギーの流れで書くと、

`電気入力 → 電動機 → 軸出力 → ポンプ → 水動力`

である。出力側から入力側へ逆算するときは効率で割る。効率を掛けるか割るか迷ったときは、損失があるので「入力は出力より大きい」という大小関係で検算する。

### 8. 余裕係数と必要台数

問題で余裕係数 `k (>1)` が指定される場合、必要な電動機出力は、

`P_required = k P_h/η_p`

とする。電動機効率まで与えられ、電気入力を求める場合はさらに、

`P_in = P_required/η_m`

とする。

複数台の同一定格電動機で必要出力をまかなう場合、1台の定格出力を `P_r` とすると、

`n = P_required/P_r`

を計算し、結果が整数でなければ上の整数へ切り上げる。`1.01台` でも1台では不足するので2台必要である。

### 9. ファン・ポンプ系の負荷特性

固定過去問で扱う代表的なファン・ポンプ系では、回転速度 `N` を変えると、

`Q ∝ N`

`T ∝ N²`

`P ∝ N³`

の関係を使う。三つ目は `P = ωT`、`ω ∝ N`、`T ∝ N²` から、

`P ∝ N × N² = N³`

と導ける。

回転速度比を `r = N_2/N_1` とすると、

`Q_2/Q_1 = r`

`T_2/T_1 = r²`

`P_2/P_1 = r³`

となる。たとえば回転速度を80%へ下げると、流量は80%、トルクは64%、動力は51.2%になる。

### 10. インバータ駆動と可変速運転

ファンやポンプで必要流量が小さいとき、電動機を可変速で運転できれば、必要流量に合わせて回転速度を下げられる。固定範囲では、インバータ駆動を「電動機の回転速度を変え、ファン・ポンプ負荷の流量と所要動力を調整する方法」として扱う。

試験上の要点は、速度比を求めてから `Q ∝ N`、`T ∝ N²`、`P ∝ N³` を適用することである。車種固有の補機用インバータ回路、電圧、周波数、制御則は扱わない。

### 11. 新幹線の補機へどうつながるか

新幹線には主電動機以外にも、系列SPECで対象候補とされたコンプレッサ、冷却ブロワ、冷却ファン、ポンプ、空調機、ドア駆動装置などがある。このTopicでは、それらを補機の実機構造として詳説するのではなく、「電動機が負荷を回す」という共通構造を理解する入口として使う。

冷却ファンやブロワはファン負荷、ポンプは流体搬送負荷として、トルク・回転速度・所要動力・効率・可変速運転の考え方へ接続できる。コンプレッサ、空調機、ドア駆動装置は電動機応用の例として位置付けるが、圧縮仕事、冷凍サイクル、空調負荷計算、ドア制御シーケンスへは拡張しない。

### 12. 問題を見たときの解法手順

ポンプ所要動力問題は次の順で処理する。

1. 流量 `Q` を `m³/s` に換算する。
2. 実揚程、損失水頭、倍率条件から全揚程 `H` を確定する。
3. `P_h = ρgQH` で水動力を求める。
4. ポンプ効率で割って必要軸出力を求める。
5. 余裕係数があれば掛ける。
6. 電動機効率があり電気入力を求めるなら、その効率で割る。
7. 台数問題なら1台の定格出力で割り、上の整数へ切り上げる。
8. 入力電力が有効出力より大きいこと、単位がWまたはkWになっていることを検算する。

ファン・ポンプの可変速問題は、

1. 流量比から速度比 `r` を決める。
2. トルク比は `r²`、動力比は `r³` とする。
3. 求める量へ元の定格値を掛ける。
4. 電気入力なら最後に電動機効率を反映する。

トルク－速度曲線問題は、

1. `T_m` と `T_L` の交点を探す。
2. 交点より少し低速側で加速か減速か確認する。
3. 交点より少し高速側でも確認する。
4. 両側から交点へ戻るなら安定、離れるなら不安定と判断する。

### 13. 基礎例題 — `P = ωT` とトルクの釣合い

電動機が `N = 1500 min^-1` で回転し、電動機トルク `T_m = 20 N·m`、負荷トルク `T_L = 20 N·m` である。機械出力と運転状態を求める。また、負荷トルクだけが `22 N·m` へ増加した直後の加速・減速を答える。

角速度は、

`ω = 2π×1500/60 = 157.08 rad/s`

機械出力は、

`P = ωT_m = 157.08×20 = 3141.6 W ≒ 3.14 kW`

最初は `T_m = T_L` なのでトルクが釣り合い、定常の動作点にある。負荷トルクが22 N·mへ増えると、

`T_m < T_L`

となるため減速する。

検算: `1500 min^-1 = 25 s^-1` なので角速度は `2π×25 ≒ 157 rad/s` と整合する。

### 14. 本試験標準例題 — ポンプ所要動力・効率・余裕係数・台数

水を `1.2 m³/min` の流量で送るポンプがある。実揚程は24 m、損失水頭は6 m、ポンプ効率は80%、余裕係数は1.10、電動機効率は90%である。必要な電動機軸出力、電気入力を求める。また、1台の定格出力が5.5 kWなら必要台数を求める。`ρ = 1000 kg/m³`、`g = 9.8 m/s²` とする。

まず流量を換算する。

`Q = 1.2/60 = 0.020 m³/s`

全揚程は、

`H = 24+6 = 30 m`

水動力は、

`P_h = 1000×9.8×0.020×30 = 5880 W = 5.88 kW`

ポンプ効率を反映した必要軸出力は、

`P_pump = 5.88/0.80 = 7.35 kW`

余裕係数を含む必要電動機軸出力は、

`P_required = 7.35×1.10 = 8.085 kW`

電動機の電気入力は、

`P_in = 8.085/0.90 = 8.983... kW ≒ 8.98 kW`

必要台数は、

`8.085/5.5 = 1.47`

なので整数へ切り上げて2台である。

検算: `電気入力 > 電動機軸出力 > 水動力` となっており、効率を含むエネルギーの流れと一致する。

### 15. 複合・ひっかけ例題 — 可変速ファン

あるファンが基準回転速度で流量100%、軸動力20 kWで運転している。必要流量が基準の70%になったため、インバータで回転速度を調整する。代表的なファン負荷として `Q ∝ N`、`T ∝ N²`、`P ∝ N³` が成り立つとする。新しい回転速度比、トルク比、軸動力を求める。また電動機効率が92%なら電気入力を求める。

流量比と速度比は等しいので、

`r = N_2/N_1 = Q_2/Q_1 = 0.70`

トルク比は、

`T_2/T_1 = r² = 0.70² = 0.49`

軸動力比は、

`P_2/P_1 = r³ = 0.70³ = 0.343`

したがって新しい軸動力は、

`P_2 = 20×0.343 = 6.86 kW`

電気入力は、

`P_in = 6.86/0.92 = 7.456... kW ≒ 7.46 kW`

ひっかけは「流量70%だから動力も70%」としないことである。固定した相似関係では動力は回転速度の3乗に比例する。

## 公式・解法まとめ

- `ω = 2πN/60`
- `P = ωT`
- `T_m > T_L`: 加速
- `T_m < T_L`: 減速
- `T_m = T_L`: 動作点
- 安定動作点: 速度が上下へずれたとき両側から交点へ戻る
- `P_h = ρgQH`
- `P_pump = P_h/η_p`
- `P_in = P_h/(η_pη_m)`
- 余裕係数あり: `P_required = kP_h/η_p`
- 台数: `P_required/P_r` を上の整数へ切り上げる
- `Q ∝ N`
- `T ∝ N²`
- `P ∝ N³`

## 頻出ミス

- `m³/min`、`m³/h` をそのまま `ρgQH` へ代入する。
- 実揚程だけを使い、指定された損失水頭や倍率を落とす。
- 出力側から入力側へ戻るのに効率を掛けてしまう。
- 余裕係数を効率と同じように割る。
- 必要台数の小数を四捨五入して不足台数にする。
- ファンの動力を回転速度に比例すると誤認し、3乗則を使わない。
- トルク曲線の交点を見つけるだけで、安定・不安定を判定しない。
- 電動機の機械出力と電気入力を同じ値として扱う。
