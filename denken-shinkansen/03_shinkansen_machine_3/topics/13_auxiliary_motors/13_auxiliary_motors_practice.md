# 練習問題

## 問1 基礎: 回転速度・トルク・機械出力
電動機が `1800 min^-1` で回転し、軸トルクが `12 N·m` である。機械出力として最も近いものはどれか。

1. 1.13 kW
2. 1.88 kW
3. 2.26 kW
4. 3.39 kW
5. 4.52 kW

### 解答・解説
正答: 3

角速度は、

`ω = 2πN/60 = 2π×1800/60 = 188.50 rad/s`

したがって、

`P = ωT = 188.50×12 = 2261.9 W ≒ 2.26 kW`

となる。回転速度をそのまま `P=NT` へ代入してはいけない。`1800 min^-1 = 30 s^-1` なので、`ω = 2π×30` としても同じ値になる。

## 問2 基礎: コンプレッサ用電動機の効率
あるコンプレッサを駆動する電動機の軸出力が `4.5 kW`、電動機効率が `90%` である。電動機の電気入力として正しいものはどれか。

1. 4.05 kW
2. 4.50 kW
3. 4.95 kW
4. 5.00 kW
5. 5.40 kW

### 解答・解説
正答: 4

電気入力から損失を差し引いたものが軸出力なので、入力側へ戻るときは効率で割る。

`P_in = P_out/η_m = 4.5/0.90 = 5.00 kW`

効率を掛けて4.05 kWとすると、入力が出力より小さくなり物理的に矛盾する。この問題ではコンプレッサを電動機負荷の例として扱うだけであり、圧縮仕事や熱力学サイクルは用いない。

## 問3 基礎: 流量換算と水動力
水を `0.60 m³/min`、全揚程 `15 m` で送る。`ρ=1000 kg/m³`、`g=9.8 m/s²` とすると、水動力として正しいものはどれか。

1. 0.147 kW
2. 0.980 kW
3. 1.47 kW
4. 9.80 kW
5. 14.7 kW

### 解答・解説
正答: 3

まず流量を秒単位へ直す。

`Q = 0.60/60 = 0.010 m³/s`

水動力は、

`P_h = ρgQH = 1000×9.8×0.010×15 = 1470 W = 1.47 kW`

である。`m³/min` をそのまま式へ代入しないことが重要である。

## 問4 本試験標準: ポンプ効率・電動機効率
水を `1.5 m³/min` で送るポンプがある。実揚程は `28 m`、損失水頭は `4 m`、ポンプ効率は `80%`、電動機効率は `90%` である。`ρ=1000 kg/m³`、`g=9.8 m/s²` とすると、電動機の電気入力として最も近いものはどれか。

1. 7.84 kW
2. 8.71 kW
3. 9.80 kW
4. 10.89 kW
5. 12.25 kW

### 解答・解説
正答: 4

流量は、

`Q = 1.5/60 = 0.025 m³/s`

全揚程は、

`H = 28+4 = 32 m`

水動力は、

`P_h = 1000×9.8×0.025×32 = 7840 W = 7.84 kW`

電気入力はポンプ効率と電動機効率の双方で割る。

`P_in = 7.84/(0.80×0.90) = 10.888... kW ≒ 10.89 kW`

1は効率を無視した水動力、2や3は効率の反映が不十分である。検算として `電気入力 > ポンプ軸入力 > 水動力` となる。

## 問5 本試験標準: 余裕係数と必要台数
水を `1.8 m³/min`、全揚程 `25 m` で送る。ポンプ効率は `75%`、余裕係数は `1.10` とする。`ρ=1000 kg/m³`、`g=9.8 m/s²` である。必要な電動機軸出力と、1台の定格出力が `5.5 kW` のときの必要台数の組合せとして正しいものはどれか。

1. 9.80 kW、2台
2. 10.78 kW、1台
3. 10.78 kW、2台
4. 10.78 kW、3台
5. 11.76 kW、2台

### 解答・解説
正答: 3

流量は、

`Q = 1.8/60 = 0.030 m³/s`

水動力は、

`P_h = 1000×9.8×0.030×25 = 7350 W = 7.35 kW`

ポンプ効率と余裕係数を反映すると、

`P_required = 7.35/0.75×1.10 = 10.78 kW`

必要台数は、

`10.78/5.5 = 1.96`

なので上の整数へ切り上げて2台である。四捨五入ではなく、必要出力を満たす整数台数へ切り上げる。

## 問6 本試験標準: ファン負荷の相似関係
代表的なファン負荷で `Q ∝ N`、`T ∝ N²`、`P ∝ N³` が成り立つとする。回転速度を基準の `80%` にしたとき、トルク比と軸動力比の組合せとして正しいものはどれか。

1. 0.80、0.80
2. 0.80、0.64
3. 0.64、0.512
4. 0.512、0.64
5. 0.64、0.80

### 解答・解説
正答: 3

速度比を `r=0.80` とすると、

`T_2/T_1 = r² = 0.80² = 0.64`

`P_2/P_1 = r³ = 0.80³ = 0.512`

である。軸動力は回転速度に単純比例せず、固定した代表的なファン負荷では3乗に比例する。

## 問7 本試験標準: 必要流量から可変速時の動力を求める
基準流量 `60 m³/min`、基準軸動力 `16 kW` のファンをインバータで可変速運転する。代表的なファン負荷の相似関係が成り立つとして、必要流量を `45 m³/min` にしたときの軸動力として最も近いものはどれか。

1. 4.00 kW
2. 6.75 kW
3. 9.00 kW
4. 12.0 kW
5. 13.5 kW

### 解答・解説
正答: 2

流量比と速度比は等しいので、

`r = 45/60 = 0.75`

軸動力比は、

`r³ = 0.75³ = 0.421875`

したがって、

`P_2 = 16×0.421875 = 6.75 kW`

となる。流量が75%だから動力も75%とする4の考え方は誤りである。

## 問8 本試験標準: 電動機と負荷の安定動作点
ある回転速度 `N0` で `T_m=T_L` となっている。`N0` より少し低速側では `T_m>T_L`、少し高速側では `T_m<T_L` である。この動作点について正しいものはどれか。

1. 低速側では減速し、高速側では加速するので不安定である
2. 低速側では加速し、高速側では減速するので安定である
3. 両側で加速するので安定である
4. 両側で減速するので不安定である
5. `T_m=T_L` の交点は条件にかかわらず必ず安定である

### 解答・解説
正答: 2

低速側では `T_m>T_L` なので加速し、速度は `N0` へ戻る。高速側では `T_m<T_L` なので減速し、やはり `N0` へ戻る。したがって両側から交点へ戻される安定動作点である。

交点であることだけでは安定性は決まらない。交点の両側で `T_m-T_L` の符号を確認する。

## 問9 本試験標準: 出力と回転速度からトルクを逆算
電動機の機械出力が `5.5 kW`、回転速度が `1450 min^-1` である。軸トルクとして最も近いものはどれか。

1. 18.1 N·m
2. 27.5 N·m
3. 36.2 N·m
4. 52.7 N·m
5. 72.4 N·m

### 解答・解説
正答: 3

角速度は、

`ω = 2π×1450/60 = 151.84 rad/s`

したがって、

`T = P/ω = 5500/151.84 = 36.22 N·m ≒ 36.2 N·m`

となる。`P` はWへ直して計算する。検算として `151.84×36.22 ≒ 5500 W` で元の出力に戻る。

## 問10 本試験標準: 毎時流量とポンプ軸入力
水を `72 m³/h`、全揚程 `20 m` で送るポンプがある。ポンプ効率は `80%` とする。`ρ=1000 kg/m³`、`g=9.8 m/s²` のとき、ポンプ軸入力として正しいものはどれか。

1. 3.14 kW
2. 3.92 kW
3. 4.90 kW
4. 5.88 kW
5. 7.84 kW

### 解答・解説
正答: 3

毎時流量を秒単位へ変換する。

`Q = 72/3600 = 0.020 m³/s`

水動力は、

`P_h = 1000×9.8×0.020×20 = 3920 W = 3.92 kW`

ポンプ軸入力は、

`P_pump = 3.92/0.80 = 4.90 kW`

となる。2は水動力をそのまま答えた値である。

## 問11 複合・応用: 可変速ファンと電動機効率
基準回転速度で軸動力 `18 kW` のファンがある。必要流量を基準の `75%` とし、インバータで回転速度を調整する。代表的なファン負荷として `Q ∝ N`、`P ∝ N³` が成り立ち、電動機効率を `90%` とする。新しい電気入力として最も近いものはどれか。

1. 6.75 kW
2. 7.59 kW
3. 8.44 kW
4. 10.1 kW
5. 13.5 kW

### 解答・解説
正答: 3

流量比から速度比は、

`r=0.75`

軸動力は、

`P_2 = 18×0.75³ = 18×0.421875 = 7.59375 kW`

電気入力は、

`P_in = 7.59375/0.90 = 8.4375 kW ≒ 8.44 kW`

となる。2は電動機効率を反映していない軸動力である。入力側へ戻るため効率で割る。

## 問12 複合・応用: ポンプ・効率・余裕係数・台数
水を `0.90 m³/min` で送るポンプ設備がある。実揚程は `18 m`、損失水頭は `2 m`、ポンプ効率は `75%`、余裕係数は `1.15`、電動機効率は `90%` とする。`ρ=1000 kg/m³`、`g=9.8 m/s²` である。必要な電気入力と、1台の定格出力が `3.0 kW` の電動機で必要軸出力をまかなう場合の必要台数の組合せとして正しいものはどれか。

1. 4.51 kW、1台
2. 4.51 kW、2台
3. 5.01 kW、1台
4. 5.01 kW、2台
5. 5.57 kW、2台

### 解答・解説
正答: 4

流量は、

`Q = 0.90/60 = 0.015 m³/s`

全揚程は、

`H = 18+2 = 20 m`

水動力は、

`P_h = 1000×9.8×0.015×20 = 2940 W = 2.94 kW`

ポンプ効率と余裕係数を反映した必要軸出力は、

`P_required = 2.94/0.75×1.15 = 4.508 kW`

電気入力は、

`P_in = 4.508/0.90 = 5.008... kW ≒ 5.01 kW`

必要台数は、

`4.508/3.0 = 1.50...`

なので上の整数へ切り上げて2台である。台数判定には電気入力ではなく、各電動機が供給できる軸出力と必要軸出力を比較する。
