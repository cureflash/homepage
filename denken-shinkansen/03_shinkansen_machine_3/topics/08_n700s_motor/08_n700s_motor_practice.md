# 練習問題

## 問1 基礎: 6極機の同期速度
一次周波数 `60 Hz`、極数 `6` の誘導電動機の同期速度として正しいものはどれか。

1. `600 min^-1`
2. `900 min^-1`
3. `1200 min^-1`
4. `1800 min^-1`
5. `3600 min^-1`

### 解答・解説
正答: 3

同期速度は

```text
Ns = 120f/P
   = 120×60/6
   = 1200 min^-1
```

よって3。同じ周波数なら、極数が増えるほど同期速度は低くなる。

## 問2 基礎: 同じ同期速度に必要な周波数
4極誘導電動機を `60 Hz` で運転したときと同じ同期速度を、6極誘導電動機で得たい。必要な一次周波数として正しいものはどれか。

1. `30 Hz`
2. `40 Hz`
3. `60 Hz`
4. `90 Hz`
5. `120 Hz`

### 解答・解説
正答: 4

4極・60 Hzの同期速度は

```text
Ns = 120×60/4
   = 1800 min^-1
```

6極で同じ同期速度にするには

```text
f = NsP/120
  = 1800×6/120
  = 90 Hz
```

よって4。同一同期速度なら必要周波数は極数に比例する。

## 問3 基礎: 滑り
6極誘導電動機を `60 Hz` で運転し、実回転速度が `1170 min^-1` であった。滑りとして正しいものはどれか。

1. `0.010`
2. `0.020`
3. `0.025`
4. `0.030`
5. `0.050`

### 解答・解説
正答: 3

まず

```text
Ns = 120×60/6
   = 1200 min^-1
```

したがって

```text
s = (Ns-N)/Ns
  = (1200-1170)/1200
  = 0.025
```

よって3。分母は実回転速度 `N` ではなく同期速度 `Ns` である。

## 問4 本試験標準: 滑り周波数
4極誘導電動機を `60 Hz` で運転し、回転速度が `1746 min^-1` であった。滑り周波数として正しいものはどれか。

1. `0.90 Hz`
2. `1.20 Hz`
3. `1.80 Hz`
4. `3.00 Hz`
5. `54.0 Hz`

### 解答・解説
正答: 3

同期速度は

```text
Ns = 120×60/4
   = 1800 min^-1
```

滑りは

```text
s = (1800-1746)/1800
  = 0.030
```

滑り周波数は

```text
f2 = sf
   = 0.030×60
   = 1.80 Hz
```

よって3。

## 問5 本試験標準: 滑り周波数一定の周波数変更
問4の電動機について、滑り周波数 `1.80 Hz` を一定に保ったまま一次周波数を `40 Hz` にした。回転速度として正しいものはどれか。

1. `1146 min^-1`
2. `1170 min^-1`
3. `1200 min^-1`
4. `1746 min^-1`
5. `1800 min^-1`

### 解答・解説
正答: 1

40 Hz時の同期速度は

```text
Ns = 120×40/4
   = 1200 min^-1
```

滑り周波数一定なので

```text
s = f2/f
  = 1.80/40
  = 0.045
```

したがって

```text
N = (1-s)Ns
  = (1-0.045)×1200
  = 1146 min^-1
```

よって1。変更後周波数を使って滑りを求める。

## 問6 本試験標準: 回転速度からトルク
8極誘導電動機を `60 Hz`、滑り `0.04` で運転し、軸出力が `36.0 kW` である。トルクとして最も近いものはどれか。

1. `199 N·m`
2. `300 N·m`
3. `398 N·m`
4. `500 N·m`
5. `796 N·m`

### 解答・解説
正答: 3

同期速度と実回転速度は

```text
Ns = 120×60/8
   = 900 min^-1

N = (1-0.04)×900
  = 864 min^-1
```

角速度は

```text
ω = 2πN/60
  = 2π×864/60
  ≈ 90.48 rad/s
```

したがって

```text
T = Pout/ω
  = 36000/90.48
  ≈ 397.9 N·m
```

よって3。`min^-1` をそのまま `Pout=Tω` へ代入しない。

## 問7 本試験標準: 周波数変更後の実回転速度
6極誘導電動機を `50 Hz`、滑り `0.05` で運転する。実回転速度として正しいものはどれか。

1. `900 min^-1`
2. `950 min^-1`
3. `1000 min^-1`
4. `1140 min^-1`
5. `1200 min^-1`

### 解答・解説
正答: 2

```text
Ns = 120×50/6
   = 1000 min^-1

N = (1-0.05)×1000
  = 950 min^-1
```

よって2。電動機運転時は実回転速度が同期速度より低いことも検算になる。

## 問8 本試験標準: 同一トルク時の出力比
ある誘導電動機を二つの運転点A、Bで同じトルクで運転する。Aの実回転速度が `1500 min^-1`、Bが `1200 min^-1` である。Bの軸出力はAの何倍か。

1. `0.64倍`
2. `0.80倍`
3. `1.00倍`
4. `1.25倍`
5. `1.56倍`

### 解答・解説
正答: 2

```text
Pout = Tω
```

で、同一トルクなら出力は角速度、したがって回転速度に比例する。

```text
PB/PA = NB/NA
      = 1200/1500
      = 0.80
```

よって2。

## 問9 本試験標準: 問題文限定の `T∝s`
ある誘導電動機の定格滑りが `0.025` である。問題文で「この運転範囲ではトルク `T` は滑り `s` に比例する」と与えられた。トルクを定格の80 %にしたときの滑りとして正しいものはどれか。

1. `0.005`
2. `0.020`
3. `0.025`
4. `0.03125`
5. `0.080`

### 解答・解説
正答: 2

問題文の条件 `T∝s` を使い、

```text
s = 0.80×0.025
  = 0.020
```

よって2。この比例関係は問題文で与えられた運転範囲だけに使い、誘導電動機全般へ一般化しない。

## 問11 複合・応用: 周波数変更と滑り周波数
4極誘導電動機を `60 Hz` で運転したところ、回転速度は `1746 min^-1` であった。滑り周波数を一定に保ったまま `50 Hz` に変更したときの回転速度として正しいものはどれか。

1. `1425 min^-1`
2. `1446 min^-1`
3. `1470 min^-1`
4. `1500 min^-1`
5. `1746 min^-1`

### 解答・解説
正答: 2

60 Hz時は

```text
Ns = 1800 min^-1
s = (1800-1746)/1800 = 0.030
f2 = 0.030×60 = 1.80 Hz
```

50 Hz時は

```text
Ns = 120×50/4
   = 1500 min^-1

s = 1.80/50
  = 0.036

N = (1-0.036)×1500
  = 1446 min^-1
```

よって2。滑り一定ではなく滑り周波数一定である点がひっかけである。

## 問12 複合・応用: 周波数変更と同一トルクの出力
6極誘導電動機を `60 Hz`、滑り `0.020` で運転したとき、軸出力が `30.0 kW` であった。トルクを同じに保ったまま `50 Hz`、滑り `0.050` で運転した。変更後の軸出力として最も近いものはどれか。

1. `20.0 kW`
2. `24.2 kW`
3. `25.0 kW`
4. `28.5 kW`
5. `30.0 kW`

### 解答・解説
正答: 2

60 Hz時は

```text
Ns = 120×60/6 = 1200 min^-1
N = (1-0.020)×1200 = 1176 min^-1
ω = 2π×1176/60 ≈ 123.15 rad/s
T = 30000/123.15 ≈ 243.6 N·m
```

50 Hz時は

```text
Ns = 120×50/6 = 1000 min^-1
N = (1-0.050)×1000 = 950 min^-1
ω = 2π×950/60 ≈ 99.48 rad/s
Pout = 243.6×99.48 ≈ 2.423×10^4 W ≈ 24.2 kW
```

よって2。周波数比だけで出力を決めず、滑りを含む実回転速度から求める。
