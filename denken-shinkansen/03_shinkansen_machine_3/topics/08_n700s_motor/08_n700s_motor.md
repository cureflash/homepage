## 解説本文

### 1. このテーマで電験は何を問うか

このテーマは機械科目の誘導電動機とインバータ周波数制御である。本試験では、極数 `P` と一次周波数 `f` から同期速度 `Ns` を求め、滑り `s` を使って実回転速度 `N` へ変換する計算が中心になる。さらに、回転速度から角速度 `ω` を求め、出力 `Pout` とトルク `T` を結ぶ複数段階計算が出る。

この章で使う中心式は次の5つである。

```text
Ns = 120f / P
s = (Ns - N) / Ns
N = (1 - s)Ns
f2 = sf
ω = 2πN / 60
Pout = Tω
```

`Ns` と `N` の単位は `min^-1`、`f` と `f2` は `Hz`、`ω` は `rad/s`、`T` は `N·m`、`Pout` は `W` とする。

### 2. 同期速度は周波数と極数で決まる

三相交流による回転磁界の同期速度は

```text
Ns = 120f / P
```

で求める。`f` は一次周波数、`P` は極数である。電気角1周期と機械角の関係から、機械的な1回転に必要な電気周期数は `P/2` となるため、1秒当たりの回転数は `2f/P`、1分当たりでは `120f/P` になる。

したがって、同じ周波数なら極数が多いほど同期速度は低くなる。逆に、同じ同期速度を保ったまま極数を増やすには周波数を上げる必要がある。

### 3. 4極と6極を比較する

一次周波数を `60 Hz` とする。

```text
4極: Ns = 120×60/4 = 1800 min^-1
6極: Ns = 120×60/6 = 1200 min^-1
```

同じ `60 Hz` なら、6極機の同期速度は4極機より低い。

次に、同期速度を `1800 min^-1` にそろえる。

```text
4極: f = NsP/120 = 1800×4/120 = 60 Hz
6極: f = 1800×6/120 = 90 Hz
```

同じ同期速度を得るなら、6極機には4極機の `1.5倍` の一次周波数が必要になる。この比較が、極数とインバータ周波数制御を同時に考える基本である。

### 4. 誘導電動機では実回転速度は同期速度より低い

電動機運転時の滑りは

```text
s = (Ns - N) / Ns
```

で定義する。したがって

```text
N = (1 - s)Ns
```

と変形できる。例えば `Ns=1200 min^-1`、`s=0.025` なら

```text
N = (1 - 0.025)×1200 = 1170 min^-1
```

となる。

問題文で「この範囲ではトルク `T` が滑り `s` に比例する」と条件が与えられた場合だけ、その条件を使う。例えば定格時 `s=0.025` で、トルクを定格の80 %とするなら

```text
s = 0.80×0.025 = 0.020
```

と計算する。この比例関係を誘導電動機の全運転範囲へ一般化してはいけない。

### 5. 滑り周波数とインバータ周波数変更

滑り周波数は

```text
f2 = sf
```

である。周波数変更問題では、問題文が「滑り一定」なのか「滑り周波数一定」なのかを先に読む。

滑り周波数 `f2` が一定なら、一次周波数を `f` から別の値へ変えたとき

```text
s = f2 / f
```

として新しい滑りを求める。その後、`Ns=120f/P`、`N=(1-s)Ns` の順で実回転速度を求める。

### 6. 回転速度・出力・トルクを結ぶ

回転速度 `N[min^-1]` を角速度へ直す式は

```text
ω = 2πN / 60
```

である。機械出力は

```text
Pout = Tω
```

だから、トルクは

```text
T = Pout / ω
```

で求められる。

同一トルクなら出力は回転速度に比例し、同一出力なら回転速度が高いほど必要トルクは小さくなる。これは高速回転と小型軽量化を考える際の一般的な機械関係だが、実機の小型化をこの式だけで断定してはならない。N700Sについては一次資料で公表された駆動システム・6極化の事実と分けて扱う。

### 7. N700Sでは6極モーターとSiC駆動システムを組み合わせた

JR東海はN700Sについて、SiC素子を駆動システムへ採用し、主電動機の電磁石を従来の4極から6極へ増やした新幹線初の6極駆動モーターを採用したと公表している。電磁石を小さくすることで駆動モーターを小型・軽量化し、N700A比で1台車当たり約140 kgの軽量化を実現したとしている。

また、JR東海はSiC素子の採用による新幹線車両用駆動システムの小型軽量化を公表しており、東芝インフラシステムズもN700SへSiC素子を使用した主変換装置を納入したことを公表している。

ここで電験の式へ戻す。6極化は「極数を増やしただけで小さくなる」という一般法則ではない。`Ns=120f/P` より、6極は同じ周波数なら4極より同期速度が低く、同じ同期速度を得るなら高い一次周波数が必要である。N700Sは、SiCを使う主変換装置と6極主電動機を組み合わせた駆動システムとして小型軽量化している、と理解する。

公表資料で確認していないN700S主電動機の実回転速度や寸法は教材値として使用しない。

### 8. 本試験の解法アルゴリズム

1. 極数 `P` と一次周波数 `f` を抜き出す。
2. `Ns=120f/P` で同期速度を求める。
3. 滑り `s` が与えられていれば `N=(1-s)Ns`、回転速度 `N` が与えられていれば `s=(Ns-N)/Ns` を使う。
4. 滑り周波数が必要なら `f2=sf` を使う。
5. 周波数変更後は、問題文が「滑り一定」か「滑り周波数一定」かを確認してから新しい `s` を決める。
6. トルク・出力問題では `ω=2πN/60` で `min^-1` を `rad/s` に直す。
7. `Pout=Tω` または `T=Pout/ω` を使う。
8. 最後に、同期速度と実回転速度の大小、単位、桁を確認する。

### 9. 頻出ミス

- `P` を極対数と取り違える。式の `P` は極数である。
- `Ns=120f/P` の `120` を `60` とする。
- 同じ周波数で極数を増やすと同期速度も上がると考える。
- 同じ同期速度を得るのに6極の方が低い周波数でよいと考える。
- `s=(Ns-N)/Ns` の分母を `N` にする。
- `f2=sf` の `f` を変更前周波数のまま使う。
- `N[min^-1]` をそのまま `Pout=Tω` に代入する。
- 問題文限定の `T∝s` 条件を誘導電動機一般の全範囲へ拡張する。
- N700Sの小型化を「6極化だけ」が原因と説明する。

## 3段階例題

### 例題1 基礎 — 4極と6極の同期速度・必要周波数

一次周波数 `60 Hz` のとき、4極誘導電動機と6極誘導電動機の同期速度を求めよ。また、6極機で4極機の `60 Hz` 時と同じ同期速度を得るために必要な一次周波数を求めよ。

```text
4極:
Ns = 120×60/4
   = 1800 min^-1

6極:
Ns = 120×60/6
   = 1200 min^-1
```

4極60 Hz時の `1800 min^-1` を6極で得るには

```text
f = NsP/120
  = 1800×6/120
  = 90 Hz
```

答え: 4極 `1800 min^-1`、6極 `1200 min^-1`、6極で同じ同期速度を得るには `90 Hz`。

検算: 同一同期速度なら必要周波数は極数に比例するため、`6/4=1.5` 倍で `60×1.5=90 Hz`。

### 例題2 本試験標準 — 滑り周波数一定で周波数を変える

6極誘導電動機を `60 Hz` で運転したとき、回転速度が `1170 min^-1` であった。

(1) 滑りと滑り周波数を求めよ。

```text
Ns = 120×60/6
   = 1200 min^-1

s = (1200-1170)/1200
  = 0.025

f2 = sf
   = 0.025×60
   = 1.50 Hz
```

(2) 滑り周波数 `1.50 Hz` を一定に保ったまま一次周波数を `45 Hz` にした。回転速度を求めよ。

```text
Ns = 120×45/6
   = 900 min^-1

s = f2/f
  = 1.50/45
  = 0.0333

N = (1-s)Ns
  = (1-0.0333)×900
  = 870 min^-1
```

答え: (1) `s=0.025`、`f2=1.50 Hz`、(2) `870 min^-1`。

(3) さらに、60 Hz時の定格トルクを100 %とし、問題文で「この運転範囲では `T∝s`」と与えられた場合、80 %トルク時の滑りを求めよ。

```text
s = 0.80×0.025
  = 0.020
```

答え: `s=0.020`。この比例式は問題文で与えられた条件としてだけ使う。

### 例題3 複合・ひっかけ — 周波数変更と出力・トルク

6極誘導電動機を `60 Hz`、滑り `0.020` で運転したとき、軸出力が `30.0 kW` であった。

(1) 回転速度とトルクを求めよ。

```text
Ns = 120×60/6
   = 1200 min^-1

N = (1-0.020)×1200
  = 1176 min^-1

ω = 2π×1176/60
  ≈ 123.15 rad/s

T = 30000/123.15
  ≈ 243.6 N·m
```

(2) 同じトルクを保ったまま `50 Hz`、滑り `0.050` で運転した。出力を求めよ。

```text
Ns = 120×50/6
   = 1000 min^-1

N = (1-0.050)×1000
  = 950 min^-1

ω = 2π×950/60
  ≈ 99.48 rad/s

Pout = Tω
     = 243.6×99.48
     ≈ 2.423×10^4 W
     ≈ 24.2 kW
```

答え: (1) `1176 min^-1`、`243.6 N·m`、(2) 約 `24.2 kW`。

同じトルクなら、回転速度が下がれば `Pout=Tω` に従って出力も下がる。「周波数が50/60になったから出力も必ず50/60」と機械的に比率だけ掛けず、滑りを含めた実回転速度から計算する。
