# 練習問題

## 問1 基礎: 光の量と単位
光束・光度・照度・輝度と単位の組合せとして正しいものはどれか。

1. 光束 lm、光度 cd、照度 lx、輝度 cd/m²
2. 光束 cd、光度 lm、照度 lx、輝度 lm/m²
3. 光束 lx、光度 cd、照度 lm、輝度 cd/m²
4. 光束 lm、光度 lx、照度 cd、輝度 W/m²
5. 光束 W、光度 cd、照度 lm/W、輝度 lx

### 解答・解説
正答: 1

光束は `lm`、光度は `cd`、照度は `lx`、輝度は `cd/m²` で表す。照度 `lx` は面が受ける光の密度、輝度は発光面・反射面をある方向から見た明るさに対応する。

2〜5は量と単位を入れ替えている。発光効率の単位 `lm/W` を照度の単位にしてはいけない。

## 問2 基礎: 逆二乗則
光度 `180 cd` の点光源の真下 `3.0 m` にある水平面の照度として正しいものはどれか。

1. 6.7 lx
2. 20 lx
3. 60 lx
4. 180 lx
5. 540 lx

### 解答・解説
正答: 2

真下なので `cosθ = 1`。点光源の照度は、

`E = I/r² = 180/3.0² = 180/9 = 20 lx`

となる。

距離を二乗せず `180/3 = 60 lx` とするのは逆二乗則の誤用である。距離が3倍なら照度は `1/9` になる。

## 問3 基礎: ジュール熱
抵抗 `8 Ω` に `3 A` の電流を `120 s` 流した。発生するジュール熱として正しいものはどれか。

1. 0.864 kJ
2. 2.88 kJ
3. 8.64 kJ
4. 28.8 kJ
5. 86.4 kJ

### 解答・解説
正答: 3

ジュール熱は、

`Q = I²Rt = 3²×8×120 = 8640 J = 8.64 kJ`

となる。

電流は二乗する。検算として電力は `I²R = 72 W`、`72 W×120 s = 8640 J` で一致する。

## 問4 本試験標準: 全光束から光度・直下照度
全方向へ均等に放射する点光源の全光束が `800π lm` である。この光源の平均光度と、真下 `2.0 m` の水平面照度の組合せとして正しいものはどれか。

1. 100 cd、25 lx
2. 100 cd、50 lx
3. 200 cd、25 lx
4. 200 cd、50 lx
5. 800 cd、200 lx

### 解答・解説
正答: 4

均等放射なので、

`I = Φ/(4π) = 800π/(4π) = 200 cd`

真下では、

`E = I/r² = 200/2.0² = 50 lx`

となる。

全光束 `lm` をそのまま距離の二乗で割らない。`I = Φ/(4π)` は均等放射条件があるときに使う。

## 問5 本試験標準: 斜め入射と複数光源
同一の均等放射点光源が2個あり、各光源の全光束は `400π lm` である。2個はある点の左右対称位置にあり、その点から見て各光源は高さ `3.0 m`、水平距離 `4.0 m` にある。水平面上のその点の合成照度として正しいものはどれか。

1. 2.4 lx
2. 4.0 lx
3. 4.8 lx
4. 8.0 lx
5. 16 lx

### 解答・解説
正答: 3

各光源の光度は、

`I = 400π/(4π) = 100 cd`

距離は、

`r = √(3²+4²) = 5 m`

入射角について、

`cosθ = 3/5 = 0.6`

したがって1個による水平面照度は、

`E1 = I cosθ/r² = 100×0.6/25 = 2.4 lx`

2個は対称で同じ照度を与えるから、

`E_total = 2×2.4 = 4.8 lx`

となる。1は片側だけ、4は `cosθ` を落とした計算に近い誤答である。

## 問6 本試験標準: 輝度と投影面積
ある平面発光面の面積は `0.50 m²` である。面の法線から `60°` の方向への光度が `240 cd` のとき、その方向の輝度として正しいものはどれか。

1. 120 cd/m²
2. 240 cd/m²
3. 480 cd/m²
4. 960 cd/m²
5. 1920 cd/m²

### 解答・解説
正答: 4

その方向から見た投影面積は、

`A_proj = A cosθ = 0.50×cos60° = 0.50×0.50 = 0.25 m²`

よって、

`L = I/A_proj = 240/0.25 = 960 cd/m²`

となる。

実面積 `0.50 m²` をそのまま使うと480 cd/m²となるが、設問では見る方向が傾いているため投影面積を使う。

## 問7 本試験標準: 照明率・保守率・所要灯数
床面積 `48 m²` の場所で平均照度 `500 lx` を確保したい。1灯当たり光束を `4000 lm`、照明率を `0.60`、保守率を `0.80` とする。必要最小灯数として正しいものはどれか。

1. 10灯
2. 11灯
3. 12灯
4. 13灯
5. 14灯

### 解答・解説
正答: 4

所要灯数は、

`N = EA/(FUM)`

より、

`N = 500×48/(4000×0.60×0.80)`

`= 24000/1920 = 12.5`

となる。必要平均照度以上を確保する最小灯数なので切り上げて `13灯`。

12灯へ四捨五入すると必要照度を満たさない。照明率・保守率は60、80ではなく0.60、0.80として使う。

## 問8 本試験標準: 複数過程の熱量と加熱効率
ある材料 `1.5 kg` を `40 K` 昇温し、さらに材料中の液体 `0.20 kg` を蒸発させる。問題文で、材料の比熱を `2.0 kJ/(kg·K)`、液体の蒸発潜熱を `1000 kJ/kg` とする。ヒーター入力を `1.0 kW`、加熱効率を `80%` としたとき、必要時間として正しいものはどれか。

1. 160 s
2. 256 s
3. 320 s
4. 400 s
5. 500 s

### 解答・解説
正答: 4

昇温に必要な熱量は、

`Q1 = mcΔT = 1.5×2.0×40 = 120 kJ`

蒸発に必要な熱量は、

`Q2 = ml = 0.20×1000 = 200 kJ`

したがって総熱量は、

`Q = 120+200 = 320 kJ`

有効加熱電力は、

`ηP = 0.80×1.0 = 0.80 kW = 0.80 kJ/s`

よって、

`t = Q/(ηP) = 320/0.80 = 400 s`

となる。320 sは効率を無視した誤答である。比熱・潜熱は設問で与えられた値だけを用いる。

## 問9 本試験標準: COPと温度上昇
入力電力 `1.5 kW` のヒートポンプを `2.0 h` 運転する。COPは `3.0` とする。加熱対象の体積は `1.0 m³`、密度は `1000 kg/m³`、比熱は `4.05 kJ/(kg·K)` と問題文で与えられ、熱損失は無視する。このとき加熱対象の温度上昇として正しいものはどれか。

1. 2 K
2. 4 K
3. 6 K
4. 8 K
5. 12 K

### 解答・解説
正答: 4

入力電力量は、

`W_in = Pt = 1.5×2.0 = 3.0 kWh`

COPより供給熱量は、

`Q = COP×W_in = 3.0×3.0 = 9.0 kWh`

`1 kWh = 3.6 MJ` なので、

`Q = 9.0×3.6 = 32.4 MJ = 32400 kJ`

質量は、

`m = ρV = 1000×1.0 = 1000 kg`

したがって、

`ΔT = Q/(mc) = 32400/(1000×4.05) = 8 K`

となる。COPは効率0〜1として扱わず、`Q/W_in` の性能係数として使う。

## 問10 本試験標準: 必要熱量から入力電力を逆算
`720 kJ` の有効熱量を `10 min` で対象へ与えたい。加熱効率を `75%` とすると、必要なヒーター入力電力として正しいものはどれか。

1. 0.90 kW
2. 1.20 kW
3. 1.60 kW
4. 2.13 kW
5. 9.60 kW

### 解答・解説
正答: 3

時間を秒へ直す。

`10 min = 600 s`

効率込みの関係は、

`Q = ηPt`

なので、

`P = Q/(ηt) = 720 kJ/(0.75×600 s)`

`= 1.6 kJ/s = 1.6 kW`

となる。

効率100%未満なら入力電力は `720/600 = 1.2 kW` より大きくなる。1.20 kWは効率を無視した誤答である。

## 問11 複合・応用: 所要灯数から総消費電力まで
床面積 `72 m²` の場所で平均照度 `450 lx` を確保する。1灯当たり光束 `3600 lm`、照明率 `0.75`、保守率 `0.80`、発光効率 `120 lm/W` とする。必要最小灯数と総消費電力の組合せとして正しいものはどれか。

1. 12灯、360 W
2. 15灯、360 W
3. 15灯、450 W
4. 16灯、480 W
5. 18灯、540 W

### 解答・解説
正答: 3

所要灯数は、

`N = EA/(FUM)`

`= 450×72/(3600×0.75×0.80)`

`= 32400/2160 = 15灯`

1灯当たりの消費電力は、

`P = Φ/K = 3600/120 = 30 W`

したがって総消費電力は、

`P_total = 15×30 = 450 W`

となる。

発光効率 `lm/W` は光束と消費電力をつなぐ値であり、照明率・保守率とは別に扱う。

## 問12 複合・応用: 加熱効率とCOPの比較
対象へ `18 MJ` の熱量を `1.0 h` で与える。方式Aは加熱効率 `90%` の電気ヒーター、方式BはCOP `3.0` のヒートポンプとする。両者の平均入力電力の組合せとして最も近いものはどれか。

1. A: 4.50 kW、B: 1.50 kW
2. A: 5.00 kW、B: 1.67 kW
3. A: 5.56 kW、B: 1.67 kW
4. A: 5.56 kW、B: 5.40 kW
5. A: 6.17 kW、B: 6.00 kW

### 解答・解説
正答: 3

まず `18 MJ = 18000 kJ`、`1.0 h = 3600 s` とする。

方式Aでは、

`Q = ηPt`

より、

`P_A = Q/(ηt)`

`= 18000/(0.90×3600)`

`= 5.56 kJ/s = 5.56 kW`

方式Bでは、

`COP = Q/W_in`

なので、1時間当たりの入力電力は、

`P_B = Q/(COP×t)`

`= 18000/(3.0×3600)`

`= 1.67 kW`

となる。

効率 `η` とCOPを同じ意味の係数として扱わない。COPは1を超え得るため、方式Bの入力電力は供給熱量を時間で割った `5.0 kW` より小さくなり得る。
