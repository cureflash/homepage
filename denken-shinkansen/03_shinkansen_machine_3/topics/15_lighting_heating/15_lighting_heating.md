#### R8上 機械 問17

- (a): 乾燥木材30 kgの昇温 `30×1.25×80 = 3000 kJ`、水70 kgの昇温 `70×4.19×80 = 23464 kJ`、蒸発水65 kgの潜熱 `65×2260 = 146900 kJ`。合計 `173364 kJ ≈ 173×10³ kJ` → `(5)`。
- (b): 有効加熱電力 `22×0.55 = 12.1 kW`。`173364/12.1 = 14327.6 s = 3.98 h` → `(2)`。
- 公式解答: (a) `(5)` / (b) `(2)`。
- 判定: `2 / 2 PASS`。

#### R7上 機械 問12

- 均等放射光源の光度 `I = 5000/(4π) = 397.9 cd`。
- 長方形中心から各隅直下までの水平距離は `√(3²+4²) = 5 m`、光源高さ5 mなので `r² = 50 m²`、`cosθ = 5/√50`。
- 1灯の水平面照度は `397.9×(5/√50)/50 = 5.63 lx`、4灯で `22.5 lx` → `(4)`。
- 公式解答: `(4)`。
- 判定: `1 / 1 PASS`。

#### R7上 機械 問17

- (a): 氷5 kgの融解熱 `5×334 = 1670 kJ`。30 min = 1800 s、効率70%より入力電力 `1670/(0.70×1800) = 1.33 kW`、最も近い値 → `(2)`。
- (b): 5 kgの水を0→50 ℃にする熱量 `5×4.2×50 = 1050 kJ`。有効加熱電力 `1.7×0.70 = 1.19 kW`、時間 `1050/1.19 = 882 s = 14.7 min` → `(2)`。
- 公式解答: (a) `(2)` / (b) `(2)`。
- 判定: `2 / 2 PASS`。

#### R6下 機械 問17

- (a): 均等放射点光源の平均光度 `I = 3000/(4π) = 238.7 cd` → `(2)`。
- (b): B点まで `r = √(2²+1.5²) = 2.5 m`、`cosθ = 2/2.5 = 0.8`。`E = 238.7×0.8/2.5² = 30.6 lx` → `(3)`。
- 公式解答: (a) `(2)` / (b) `(3)`。
- 判定: `2 / 2 PASS`。

#### R6上 機械 問17

- (a): `I = 12000/(4π) = 954.9 cd`、直下3 mなので `E = 954.9/3² = 106.1 lx` → `(2)`。
- (b): 球半径0.15 m、投影面積 `π×0.15² = 0.07069 m²`。`L = 954.9/0.07069 = 1.35×10⁴ cd/m²`。光度との組合せ → `(1)`。
- 公式解答: (a) `(2)` / (b) `(1)`。
- 判定: `2 / 2 PASS`。

#### R4上 機械 問17

- (a): 入力電力量 `1.00 kW×6 h = 6 kWh = 21.6 MJ`。COP 4.5より加熱熱量 `21.6×4.5 = 97.2 MJ` → `(5)`。

- 公式解答: (a) `(5)` / (b) `(5)`。

## 過去問とSPECから確定した教材必須範囲

1. 光束・光度・照度・輝度の意味と `lm / cd / lx` を区別する。
2. 均等放射光源について、全光束から光度を求め、逆二乗則と入射角を用いて水平面照度を計算する。
3. 複数光源の照度を加算する。
4. 光度と発光面の投影面積から輝度を扱う。
5. 照明率・保守率・面積・光束から所要灯数を求め、必要最小数では切り上げる。
6. 発光効率・LED・消費電力を系列SPECの固定範囲で扱う。
7. ジュール熱・電力量・熱量・ヒーター・電熱・効率を区別し、`Q = I²Rt`、`Q = Pt` 等で計算する。
8. 問題文で比熱・潜熱・密度が数値として与えられる場合、それらを与条件として必要熱量へ換算し、効率を考慮して消費電力・時間へ接続する。
9. COPの基本を扱い、入力電力量と空調・ヒートポンプ側の熱量を相互に計算する。
10. 新幹線の照明・空調は導入に限定し、一次資料で確認できない器具仕様・灯数・消費電力・空調能力・COPを推測しない。

## 範囲境界

- 光束発散度、立体角を独立学習項目として追加しない。均等放射光源の `I = Φ/(4π)` は固定された光束・光度の関係として扱う。
- 熱伝導・熱放射・熱抵抗・温度こう配を追加しない。
- 比熱・潜熱・密度は、固定過去問で問題文から与えられた数値を熱量換算に使う範囲に限定し、熱力学・相変化理論へ拡張しない。
- 誘導加熱、誘電加熱、アーク炉等の工業電熱へ拡張しない。
- N700S等の車内照明器具の型式・灯数・実消費電力、空調装置の実能力・実COP等を推測で補わない。
- Topic 16「同期機」を先取りしない。
