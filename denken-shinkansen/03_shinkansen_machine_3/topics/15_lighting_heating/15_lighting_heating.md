# 解説本文

## 1. このテーマで電験は何を問うか

電験三種「機械」の照明・電熱では、用語の暗記だけでなく、光の量をどの物理量で表すか、距離や入射角で照度がどう変わるか、必要な灯数をどう逆算するか、電気エネルギーを熱量へどう換算するか、効率やCOPをどちら向きに使うかまで問われる。

固定EXAM_ALIGNMENTでは、照明が光束・光度・照度・輝度、点光源の逆二乗則、複数光源、照明率・保守率・所要灯数まで、電熱・空調がジュール熱、熱量、効率、電力量、COPまで要求している。本章を終えた時点で、次をできることを目標にする。

- `lm / cd / lx / cd/m²` を取り違えない。
- 全光束から均等放射光源の光度を求める。
- 距離と入射角から水平面照度を求め、複数光源なら加算する。
- 光度と投影面積から輝度を求める。
- 平均照度から所要灯数を逆算し、必要最小数へ切り上げる。
- 発光効率から光束と消費電力を相互に計算する。
- `Q = I²Rt`、`Q = Pt` と効率を使って熱量・電力・時間を相互に求める。
- 問題文で与えられた比熱・潜熱・密度を使って必要熱量へ換算する。
- COPから空調側の熱量と入力電力量を相互に求める。

## 2. 光束・光度・照度・輝度を区別する

照明問題では、まず四つの量を区別する。

| 量 | 記号 | 単位 | 意味 |
|---|---|---|---|
| 光束 | `Φ` | `lm` | 光源から出る光の総量を表す量 |
| 光度 | `I` | `cd` | ある方向への光の強さ |
| 照度 | `E` | `lx` | 面が受ける光の量。`1 lx = 1 lm/m²` |
| 輝度 | `L` | `cd/m²` | ある方向から見た発光面の明るさを表す量 |

典型的な誤りは、光源そのものを表す光束・光度と、照らされる面を表す照度を混同することである。問題文に「全光束」とあれば `Φ [lm]`、「光源の光度」とあれば `I [cd]`、「床面・作業面の照度」とあれば `E [lx]` を探す。

均等に全方向へ放射する点光源として扱う条件では、全光束と光度の関係は

```text
I = Φ / (4π)
Φ = 4πI
```

である。この式は「均等放射」という条件がある場合に使う。一般の光源へ無条件に適用しない。

## 3. 点光源の照度 — 距離と入射角

光度 `I [cd]` の点光源から距離 `r [m]` にある面が、光を面の法線方向から受けるとき、照度は

```text
E = I / r²
```

となる。距離が2倍なら照度は `1/4`、3倍なら `1/9` になる。これが逆二乗則である。

光が斜めに入る場合は、光線と面の法線との角を `θ` として

```text
E = I cosθ / r²
```

を使う。水平面の上方に光源があり、光源の高さを `h`、水平距離を `x` とすると、

```text
r = √(h² + x²)
cosθ = h / r
```

なので、距離と角度を別々に処理できる。

例として `I = 200 cd`、高さ `h = 2.0 m`、水平距離 `x = 1.5 m` なら、

```text
r = √(2.0² + 1.5²) = 2.5 m
cosθ = 2.0 / 2.5 = 0.8
E = 200 × 0.8 / 2.5² = 25.6 lx
```

となる。

同じ点を複数の光源が照らす場合、各光源による照度を個別に求めて加算する。

```text
E_total = E1 + E2 + ...
```

上の条件と同じ光源が対称位置に2個あるなら、その点の合成照度は `25.6 × 2 = 51.2 lx` である。

## 4. 輝度 — 投影面積を使う

輝度 `L [cd/m²]` は、ある方向への光度 `I [cd]` を、その方向から見た発光面の投影面積 `A_proj [m²]` で割る。

```text
L = I / A_proj
```

発光面の実面積を `A`、面の法線と見る方向の角を `θ` とすると、問題条件に応じて

```text
A_proj = A cosθ
L = I / (A cosθ)
```

とする。真正面なら `θ = 0` なので `A_proj = A` である。

問題文で投影面積そのものが与えられている場合は、それをそのまま使う。さらに `cosθ` を掛けて二重に補正しない。

## 5. 照明率・保守率・所要灯数

部屋や作業面の平均照度を求める照明設計では、光源の全光束がすべて作業面へ届くわけではないことを照明率 `U`、汚れや経年による低下を保守率 `M` として扱う。

灯数を `N`、1灯当たり光束を `F [lm]`、床面積を `A [m²]` とすると、平均照度 `E [lx]` は

```text
E = NFUM / A
```

したがって所要灯数は

```text
N = EA / (FUM)
```

で求める。

`U` と `M` は0〜1の比で扱う。60%なら `0.60` とする。計算結果が `12.5灯` のように整数でないとき、「必要な平均照度以上を確保する最小灯数」を問うなら13灯へ切り上げる。四捨五入して12灯にしてはいけない。

## 6. 発光効率・LED・消費電力

発光効率を、本章では光束 `Φ [lm]` と消費電力 `P [W]` の比

```text
K = Φ / P   [lm/W]
```

として扱う。したがって、

```text
P = Φ / K
Φ = KP
```

と逆算できる。

同じ必要光束なら、発光効率 `K` が高いほど必要な電力は小さい。LEDは、電験では高い発光効率をもつ光源として扱われることがあるが、本章では特定車両のLED器具の実光束・実消費電力を断定しない。

複数灯の総消費電力は、同一光源なら

```text
P_total = NP
```

で求める。所要灯数を先に決め、1灯当たり消費電力を発光効率から求める順序にすると整理しやすい。

## 7. ジュール熱・電力量・熱量・効率

抵抗 `R [Ω]` に電流 `I [A]` を時間 `t [s]` 流したときのジュール熱は

```text
Q = I²Rt
```

である。電圧 `V [V]`、電力 `P [W]` を使えば、一定値として扱う条件で

```text
Q = VIt = Pt
```

とも書ける。

`P [W]` に `t [s]` を掛ければ `Q [J]` になる。電力量を `kWh` で扱う場合は

```text
1 kWh = 3.6 MJ
```

を使ってJへ換算できる。

電気入力のすべてが目的の加熱へ使われるとは限らない。加熱効率を `η`、有効に使われる熱量を `Q_use` とすると、

```text
Q_use = ηPt
P = Q_use / (ηt)
t = Q_use / (ηP)
```

となる。効率80%なら `η = 0.80` とする。

## 8. 問題文で与えられた比熱・潜熱・密度を使う

固定過去問では、加熱対象の比熱、蒸発潜熱、密度などが問題文に数値として与えられ、その数値を使って必要熱量を組み立てる問題がある。本章ではこれらを独立した熱力学論点へ広げず、与条件から熱量へ換算するために使う。

質量 `m [kg]`、問題文で与えられた比熱 `c [J/(kg·K)]`、温度上昇 `ΔT [K]` なら、

```text
Q_temp = mcΔT
```

問題文で潜熱 `l [J/kg]` が与えられ、質量 `m [kg]` の相変化に必要な熱量を求める条件なら、

```text
Q_latent = ml
```

とする。複数の過程があれば、必要熱量は各過程を加算する。

```text
Q_total = Q1 + Q2 + ...
```

密度 `ρ [kg/m³]` と体積 `V [m³]` が与えられている場合は、

```text
m = ρV
```

で質量へ直してから、問題文で指定された比熱等を使う。

## 9. COPの基本

空調・ヒートポンプでは、入力した電力量と移動させた熱量の関係をCOPで表す。入力電力量を `W_in`、空調側で扱う熱量の大きさを `Q` とすると、

```text
COP = Q / W_in
Q = COP × W_in
W_in = Q / COP
```

一定の入力電力 `P` で時間 `t` 運転するなら

```text
W_in = Pt
Q = COP × Pt
```

である。

COPは加熱効率 `η` と同じ量ではない。効率は入力エネルギーのうち有効に変換された割合として0〜1で扱うのに対し、COPは熱を移動する装置の性能係数なので1を超える値を取り得る。問題で効率とCOPが出たら、同じ式へ代入しない。

## 10. 問題を見たときの解法手順

### 照明問題

1. 求める量が光束 `lm`、光度 `cd`、照度 `lx`、輝度 `cd/m²` のどれかを確認する。
2. 均等放射の条件があれば `I = Φ/(4π)` で光束と光度を変換する。
3. 点光源問題では距離 `r` を求め、斜め入射なら `cosθ` も求める。
4. `E = I cosθ/r²` で各光源の照度を計算する。
5. 複数光源なら照度を加算する。
6. 輝度なら `L = I/A_proj` を使う。
7. 平均照度・所要灯数なら `E = NFUM/A` を使い、必要灯数は条件に応じて切り上げる。
8. 発光効率が与えられたら `K = Φ/P` で消費電力へ接続する。
9. 最後に単位と桁を確認する。

### 電熱・空調問題

1. 求める量が熱量 `J`、電力量 `Wh・kWh`、電力 `W・kW`、時間のどれかを確認する。
2. 問題文で与えられた比熱・潜熱・密度があれば、必要な質量・温度差と組み合わせて熱量を求める。
3. 複数の加熱過程があれば熱量を合算する。
4. 電気加熱なら `Q = ηPt`、抵抗値と電流が直接与えられたら `Q = I²Rt` を使う。
5. 空調・ヒートポンプなら `Q = COP × W_in` を使う。
6. `s / h`、`J / kJ / MJ`、`Wh / kWh` をそろえる。
7. 効率は0〜1、COPは性能係数として別々に扱う。
8. 最後に、求めた電力・時間が正の値で、単位が設問と一致するか確認する。

## 11. 典型例題（3段階）

### 基礎例題 — 全光束から直下照度

全方向へ均等に放射する点光源の全光束が `400π lm` である。光源の真下2.0 mの水平面照度を求める。

均等放射なので、

```text
I = Φ/(4π) = 400π/(4π) = 100 cd
```

真下では `cosθ = 1` だから、

```text
E = I/r² = 100/2.0² = 25 lx
```

答えは `25 lx`。`400π lm` をそのまま距離の二乗で割らない。

### 本試験標準例題A — 所要灯数と消費電力

床面積 `60 m²` の場所に平均照度 `300 lx` を確保したい。1灯当たり光束 `3000 lm`、照明率 `0.60`、保守率 `0.80` とする。必要最小灯数を求める。また、光源の発光効率を `120 lm/W` とすると総消費電力はいくらか。

所要灯数は、

```text
N = EA/(FUM)
  = 300×60/(3000×0.60×0.80)
  = 12.5
```

必要最小灯数なので切り上げて `13灯`。

1灯当たり消費電力は、

```text
P = F/K = 3000/120 = 25 W
```

したがって総消費電力は、

```text
P_total = 13×25 = 325 W
```

答えは `13灯、325 W`。灯数を12灯へ四捨五入しない。

### 本試験標準例題B — 熱量と加熱効率

質量 `2.0 kg` の物体を `40 K` 昇温する。問題文で比熱 `4.2 kJ/(kg·K)` が与えられているものとする。1.0 kWのヒーターを使い、加熱効率は84%とする。必要時間を求める。

必要熱量は、

```text
Q = mcΔT
  = 2.0×4.2×40
  = 336 kJ
```

有効加熱電力は、

```text
ηP = 0.84×1.0 = 0.84 kW = 0.84 kJ/s
```

したがって、

```text
t = Q/(ηP)
  = 336/0.84
  = 400 s
```

答えは `400 s`。効率84%を `84` として代入しない。

### 複合・ひっかけ例題 — COPと電力量

空調装置が対象へ `6.0 kWh` 相当の熱量を与える必要がある。COPを3.0、運転時間を2.0 hとする。必要な入力電力量と平均入力電力を求める。

COPの定義より、

```text
W_in = Q/COP
     = 6.0/3.0
     = 2.0 kWh
```

平均入力電力は、

```text
P = W_in/t
  = 2.0/2.0
  = 1.0 kW
```

答えは `2.0 kWh、1.0 kW`。COPを効率と同じ0〜1の値だと考えたり、必要入力を `Q×COP` としたりしない。

## 12. 新幹線への接続

新幹線の客室には照明や空調など、走行用主電動機以外にも電力を使う設備がある。本章では、それらを照明・電熱・空調の一般計算へ接続する入口として使う。

照明については、必要照度が与えられれば `N = EA/(FUM)` で必要灯数を求め、発光効率が与えられれば `P = Φ/K` から消費電力へつなげられる。空調については、必要な熱量とCOPが与えられれば `W_in = Q/COP` で電気入力へ戻せる。

ただし、これは電験計算の一般モデルである。N700S等について、客室照明器具の型式・灯数・実光束・実消費電力、空調装置の実能力・実COPは、一次資料で確認していない値を本章で実値化しない。

## 13. 頻出ミス・ひっかけ

- `lm / cd / lx / cd/m²` を取り違える。
- 均等放射の条件を確認せず `I = Φ/(4π)` を使う。
- 逆二乗則で距離を二乗し忘れる。
- 水平面照度で `cosθ` を落とす。
- 複数光源の照度を加算しない。
- 輝度で実面積と投影面積を取り違える。
- 照明率・保守率を60、80のまま代入する。
- 所要灯数を四捨五入し、必要照度を下回る灯数にする。
- 発光効率 `lm/W` と電気的な効率を混同する。
- `W` と `Wh`、`kW` と `kWh` を混同する。
- `kWh` と `J` を変換せず同じ式へ混在させる。
- 加熱効率を掛ける向きと割る向きを逆にする。
- 複数の加熱過程の熱量を一部だけ計上する。
- COPを0〜1の効率として扱う。
