# 電験×新幹線 試験対応品質仕様書

## 1. 目的

本仕様は、電験×新幹線教材を「新幹線の技術紹介」で終わらせず、**電験三種・二種の本試験問題を解くための教材**にするための必須品質基準である。

`MASTER_SPEC.md` と本仕様は、各系列SPECより上位に置く。

## 2. 制作前リサーチ

各テーマは本文を書き始める前に、次の順で調査する。

### 2.1 公式試験資料

最優先は一般財団法人 電気技術者試験センターの公式過去問題・公式解答とする。

三種:
- https://www.shiken.or.jp/chief/third/qa/

二種:
- https://www.shiken.or.jp/chief/second/qa/

対象テーマに関連する過去問を直近年度から遡って探し、年度、上期/下期、科目、問番号を記録する。

### 2.2 電験解説サイト

説明の粒度、論点分解、典型問題への接続方法を確認するため、複数の解説資料を比較する。

代表参考先:

- 基礎からわかる電気技術者の知識と資格
  - https://e-sysnet.com/
- 電験王
  - https://denken-ou.com/
- 電験三種まとめました
  - https://yaku-tik.com/denken/kako-kamoku/
- TAC 電験講座の公開過去問・講評
  - https://www.tac-school.co.jp/kouza_denken/
- オーム社の公開目次・講座情報
  - https://www.ohmsha.co.jp/

参考サイトは最低2系統を確認する。`e-sysnet.com` に対応論点がある場合は原則として確認対象に含める。

参考サイトの文章・図・例題をコピーしない。確認するのは、どこまで説明すれば本試験問題につながるか、どの論点が頻出か、どの順序で説明すると理解しやすいかである。

## 3. EXAM_ALIGNMENT 記録

各テーマのsource Markdownには、本文作成前に次の表を作る。

```text
EXAM_ALIGNMENT
資格:
科目:
論点:

公式過去問:
- 年度 / 期 / 科目 / 問番号 / 要求知識 / 使用式 / 設問型
- ...

参考教材:
- URL / 参照日 / 参考にした説明観点
- ...

教材で必要な説明:
- ...
```

三種は原則5問以上の関連公式過去問を調べる。該当問題が5問未満しか確認できない場合は確認できた全件を扱う。

二種は一次・二次を合わせ原則5問以上を調べる。二次試験に対応する論点では、確認できる場合は記述式問題を最低1問含める。

## 4. 過去問から逆算して教材範囲を決める

過去問調査で確認した要求事項を、次の種類に分解する。

- 用語・定義
- 原理・現象
- 公式
- 式の導出
- 単位・換算
- 回路図・等価回路
- ベクトル図・フェーザ図
- 特性曲線・グラフ
- 計算手順
- 正誤判定知識
- 典型的なひっかけ
- 複数論点をつなぐ複合計算

この一覧に1項目でも教材未収録があれば、そのテーマの説明は不十分である。

## 5. 解説の書き方

### 5.1 まず試験論点を説明する

新幹線の話から長く始めない。

冒頭で次を明示する。

- このテーマは電験の何科目か
- 本試験では何を問われるか
- 何を求められる問題が多いか
- この章を終えると何が解けるようになるか

### 5.2 用語は関係を説明する

用語一覧だけを置かない。

例:

- すべりを定義するだけでなく、同期速度、回転速度、二次周波数、トルクとどうつながるか説明する。
- 変圧器の巻数比だけでなく、電圧比、電流比、容量、損失、効率、電圧変動率へ接続する。
- 力率を定義するだけでなく、有効電力、無効電力、皮相電力、位相角、複素電力と結び付ける。

### 5.3 公式は「使い方」まで書く

各公式について最低限、次を示す。

- 記号の意味
- 単位
- 成立条件
- どの値が問題文で与えられるか
- 何を求めるとき使うか
- 逆算するときの式変形
- よくある取り違え

必要なテーマでは公式の導出または成立理由を示す。

### 5.4 解法アルゴリズムを示す

本試験標準問題について、受験者が再利用できる解法手順を示す。

例:

```text
1. 問題文から既知量を抜き出す
2. 単位をそろえる
3. 回路・機器の状態を判定する
4. 使用公式を選ぶ
5. 求める量について式を解く
6. 数値代入する
7. 桁・単位・物理的妥当性を検算する
8. 選択肢と照合する
```

テーマ固有の手順へ具体化すること。

## 6. 例題

解説PDFには原則として最低3段階の例題を入れる。

### 基礎例題

公式1つの意味と使い方を確認する。

### 本試験標準例題

実際の電験で要求される複数段階の計算または知識判断を扱う。

### 複合・ひっかけ例題

単位換算、条件判断、複数公式、グラフ、結線、符号等の典型ミスを含む問題を扱う。

各例題は「式を並べて答えを出す」だけでなく、なぜその式を選ぶかを説明する。

## 7. 新幹線の使い方

新幹線は、試験論点を具体化するために使う。

良い使い方:

- 0系主変圧器の実値を使い、変圧比・一次電流・容量計算を行う。
- 300系誘導電動機を例に、同期速度・すべり・周波数の関係を説明する。
- N700Sの主変換装置を例に、損失・効率・PWMを説明する。
- 新幹線の回生を例に、運動エネルギーと電力量を結ぶ。

悪い使い方:

- 車両史を長く説明して電験公式が数行しかない。
- 実車の数値を代入しただけで、一般問題への解法が説明されていない。
- 新幹線固有の知識を覚えないと練習問題が解けない。
- 電験にほぼ出ない車両雑学を中心にする。

## 8. 練習問題仕様

### 三種

原則12問以上。

- 20〜30%: 基礎
- 50〜60%: 本試験標準
- 約20%: 複合・応用

少なくとも半数は五肢択一形式とし、本試験と同じように選択肢から解を選ぶ訓練を入れる。

テーマに応じ、次を組み合わせる。

- 数値計算
- 公式逆算
- 正誤問題
- 図・回路問題
- グラフ・特性問題
- 複数段階計算

### 二種

一次試験型に加え、`05〜07` で二次試験に接続する論点は記述式問題も含める。

記述式では、答えだけでなく途中式、前提、単位、理由説明まで採点可能な形で示す。

## 9. 解答解説仕様

数値問題:

1. 使用公式
2. 公式を選ぶ理由
3. 数値と単位の代入
4. 中間計算
5. 最終値
6. 選択肢番号
7. 検算

知識・正誤問題:

1. 正答
2. 正しい理由
3. 重要な誤答肢が誤りである理由
4. 関連する頻出論点

「答えは○○」だけの解説は禁止する。

## 10. 完成後の独立試験

テーマ完成後、生成時に見た公式解答や保存済み正答を先に見ず、EXAM_ALIGNMENTで選定した過去問をもう一度解く。

確認する項目:

- 教材だけで公式を選べるか
- 教材だけで途中式を組み立てられるか
- 教材だけで選択肢を絞れるか
- 教材で説明した知識が問題文の言い換えにも対応できるか
- 正答の理由を説明できるか

正解しても、教材に書かれていない知識を作成者が外部知識で補って解いた場合はFAILとする。

## 11. QA判定

### PASS

- 過去問マッピングがある
- 対応過去問を教材だけで独立再解答できる
- 公式の意味と使い方が説明されている
- 本試験標準例題がある
- 練習問題が本試験形式・難易度へ接続している
- 新幹線は試験理解を助ける役割になっている

### NEEDS_REVISION

- 説明は正しいが、過去問を解くための中間知識が不足
- 公式一覧だけで解法がない
- 例題が簡単すぎる
- 新幹線説明が長く試験論点が薄い
- 過去問で頻出する形式を練習できない

### REJECT

- 公式・正答が誤っている
- 複数解がある練習問題
- 実車仮定値を実値として扱う
- 他サイトの文章や図を無断で複製する
- 電験対象外の内容が大半を占める
