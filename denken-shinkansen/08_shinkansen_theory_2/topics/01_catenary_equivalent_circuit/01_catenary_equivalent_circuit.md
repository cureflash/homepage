## 検証で確定した中間知識・典型ミス

- R8問3: 共有抵抗 `r` の係数符号を誤らないこと。相反定理は「電源と応答を交換すれば常に成立」ではなく、適用条件を確認すること。平衡ブリッジでは中央枝電流が0になる。
- R7問5: 電流源と並列抵抗を電圧源と直列抵抗へ変換するとき、電源極性を電流方向から決める。最大条件を暗記せず `P(R)` を作って微分できること。
- R6問3: 仮定した矢印方向と実際の電流方向を分離し、0や負値をそのまま物理的に解釈する。端子電圧 `Vab` と矢印の取り違えを避ける。
- R5問3: 入力インピーダンスは端子から見た直並列を段階的に縮約する。縦続接続では電圧比を掛け合わせる。
- R5問4: 開放端電圧と等価インピーダンスを別々に求める。交流の並列計算では複素数のまま処理し、有効電力は `|I|^2 Re(Z)` で評価する。
- R4問3: 節点法では枝電流の正方向を統一し、消費電力は各抵抗の `I^2R` または電圧差平方/Rを合計する。
- R3問3: 独立電圧源は短絡、独立電流源は開放。各電源による寄与は大きさではなく符号付きで加算する。

# 新幹線への接続

Topic 01では、新幹線から見た上流側電源を次の教育用モデルへ簡略化する。

```text
変電所・き電系統
      ↓
    Vth
     ─ Zth ─ 負荷（列車）
```

このモデルは回路網定理を学ぶための抽象化であり、実際の新幹線き電回路のATき電、複数変電所、線路分布定数、列車位置によるインピーダンス変化等をそのまま表したものではない。

本テーマでは実車の未確認値を推測して `Vth` や `Zth` の真値にしない。数値例が必要な場合は「教材上の仮定値」と明記する。

# 解説本文

## 1. このテーマで電験は何を問うか

回路網の問題で重要なのは、回路を見てすぐ計算を始めることではなく、どの方法で簡単にできるかを判断することである。電験二種一次「理論」では、複数の電源と抵抗・インピーダンスからなる回路について、節点法、閉路法、重ね合わせ、電源変換、テブナン／ノートン等価回路などを使い分ける力が問われる。

このテーマで到達すべき点は次のとおり。

- KCL・KVLから符号を崩さず方程式を立てられる。
- 節点法と閉路法を回路に応じて選べる。
- 重ね合わせで独立電源ごとの寄与を分離できる。
- 電圧源と電流源を端子特性を保ったまま変換できる。
- 任意の線形二端子回路をテブナン形またはノートン形へ置き換えられる。
- 相反定理を適用できる条件を判断できる。
- 直流だけでなく複素インピーダンスを含む交流回路でも同じ考え方を使える。
- 負荷へ供給される電力を式にし、最大電力条件を導ける。

過去問では、一つの定理だけを単独で問うとは限らない。例えば「閉路方程式で一部を求める→端子から見た等価回路を作る→負荷電流や電力を求める」というように、複数の操作をつなぐ問題が出る。このため公式暗記ではなく、端子から見た回路の振る舞いを一貫して追えることが必要である。

## 2. KCL・KVLと符号規約

キルヒホッフの電流則 KCL は、節点に流れ込む電流と流れ出す電流の代数和が0になるという電荷保存則である。

`Σ I = 0`

キルヒホッフの電圧則 KVL は、一つの閉路を一周した電圧上昇と電圧降下の代数和が0になるというエネルギー保存則である。

`Σ V = 0`

回路計算では、電流方向を最初から正しく当てる必要はない。未知電流の向きを自分で仮定し、その向きを正として式を立てればよい。計算結果が負なら、実際の電流は仮定と逆方向である。電圧も `Vab = Va - Vb` のように定義を固定する。

抵抗 `R` で、電流が電圧の正端子へ流れ込む受動符号規約を用いれば

`V = RI`

である。閉路を回る向きを途中で変えたり、同じ枝の電圧極性を別の式で反転させたりすると誤答につながる。

検算では、抵抗の消費電力

`P = I^2 R = V^2/R`

が負になっていないか、節点で流入・流出が一致しているかを確認する。

## 3. 節点法と閉路法

### 節点法

未知節点電位が少ない回路では節点法が有効である。

1. 一つの節点を基準節点 `0 V` とする。
2. 他の節点電位を未知数 `V1, V2, ...` とする。
3. 各枝電流を節点電位差とインピーダンスで表す。
4. 各未知節点でKCLを立てる。
5. 連立方程式を解く。

抵抗 `R` で節点 `a` から `b` へ流れる電流を正に取れば

`Iab = (Va - Vb)/R`

である。交流なら `R` を複素インピーダンス `Z` に置き換える。

### 閉路法

独立閉路の数が少ない平面回路では閉路法が有効である。

1. 各独立閉路へ閉路電流 `I1, I2, ...` を仮定する。
2. 各閉路にKVLを適用する。
3. 二つの閉路で共有する枝では、枝電流を閉路電流の差で表す。
4. 連立方程式を解く。

例えば二つの閉路が抵抗 `r` を共有し、両方の閉路電流を時計回りに取ると、共有枝の電圧降下は一方の式では `r(I1-I2)`、他方では `r(I2-I1)` となる。行列表現では非対角成分が負になる形が多い。

### 基礎例題

節点 `a` は、`4 Ω` を介して `12 V` の節点に、`6 Ω` を介して接地に接続され、さらに接地から節点 `a` へ `1 A` の電流源が流れ込んでいる。節点電位 `Va` を求める。

節点 `a` から流れ出す向きを正にしてKCLを立てる。

`(Va-12)/4 + Va/6 - 1 = 0`

両辺を12倍すると

`3Va - 36 + 2Va - 12 = 0`

したがって

`5Va = 48`

`Va = 9.6 V`

確認すると、12 V側から節点へ流れ込む電流は

`(12-9.6)/4 = 0.6 A`

電流源から `1 A` が流れ込むので合計流入は `1.6 A`。`6 Ω` へ流れ出す電流は

`9.6/6 = 1.6 A`

で一致する。

## 4. 重ね合わせの理

線形回路では、複数の独立電源があるとき、ある電流または電圧の応答は各独立電源による応答の代数和として求められる。

手順は次のとおり。

1. 一つの独立電源だけを残す。
2. 他の独立電圧源を `0 V` にするので短絡する。
3. 他の独立電流源を `0 A` にするので開放する。
4. 残した電源による応答を求める。
5. 全独立電源について繰り返し、符号付きで加える。

電圧源を「取り外して開放」、電流源を「短絡」とするのは逆である。零にするのは電源値であり、理想電圧源の内部抵抗は0、理想電流源の内部抵抗は無限大だからである。

制御電源は回路の応答に依存するため、重ね合わせで独立電源を一つずつ残す場合でも勝手に零化しない。

また、重ね合わせを電力へ直接適用してはいけない。電圧・電流は線形に重ね合わせられるが、電力 `P=I^2R` は二乗を含む非線形量である。まず合成後の電圧・電流を求め、その後で電力を計算する。

## 5. 電源変換

端子から見た電圧電流特性が同じなら、内部構成が違っても外部負荷に対して同じ回路として扱える。

電圧源 `E` と直列抵抗 `R` は、電流源

`I_N = E/R`

と並列抵抗 `R` に変換できる。逆に、電流源 `I_N` と並列抵抗 `R` は

`E = I_N R`

の電圧源と直列抵抗 `R` に変換できる。

極性は電流源の矢印から決める。変換後も開放端電圧と短絡電流が同じでなければならない。

電源変換は、複数の電圧源・電流源が混在する回路を一つの形式へそろえ、直列・並列合成を可能にするために使う。単に公式を当てはめるのではなく、「端子から見た `V-I` 関係を保存する操作」と理解する。

## 6. テブナン・ノートン等価

任意の線形二端子回路は、外部端子から見れば次のいずれかへ置き換えられる。

テブナン形:

```text
Vth ─ Zth ─ 負荷
```

ノートン形:

```text
      ┌─ Zth ─┐
In ───┤       ├── 負荷端子
      └───────┘
```

テブナン電圧 `Vth` は負荷を外したときの開放端電圧である。

`Vth = Voc`

ノートン電流 `In` は端子を短絡したときの短絡電流である。

`In = Isc`

等価インピーダンスは

`Zth = Vth/In`

であり、独立電源だけを含む回路なら独立電圧源を短絡、独立電流源を開放して端子から見たインピーダンスを求めてもよい。

制御電源がある場合、制御電源を零にしてはいけない。独立電源だけを零にしたうえで端子へ試験電圧 `Vt` または試験電流 `It` を加え、

`Zth = Vt/It`

から求める。

テブナン形とノートン形は

`Vth = In Zth`

`In = Vth/Zth`

で相互変換できる。

### 本試験標準例題

`18 V` の理想電圧源と `3 Ω` の抵抗が直列に接続され、その先の端子 `a` から接地へ `6 Ω` が接続されている。端子 `a`-接地へ可変負荷 `RL` を接続する。

まず負荷を外すと、`3 Ω` と `6 Ω` の分圧より

`Vth = 18 × 6/(3+6) = 12 V`

独立電圧源を短絡すると、端子から見える抵抗は

`Rth = 3 || 6 = 3×6/(3+6) = 2 Ω`

したがってノートン電流は

`In = 12/2 = 6 A`

である。

例えば `RL=4 Ω` を接続すると

`IL = 12/(2+4) = 2 A`

となる。元の回路を直接解いても同じ電流になる。

## 7. 相反定理

相反定理は、線形かつ双方向の回路網で、ある枝に電源を置いたとき別の枝に生じる応答と、電源位置と応答位置を交換したときの応答が等しくなる性質である。

抵抗、インダクタンス、キャパシタンスなどの線形・双方向素子で構成された相反回路が代表例である。非線形素子や一方向性をもつ素子を含む場合にはそのまま適用できない。電源と測定位置を交換すれば無条件で成立する、と覚えてはいけない。

ブリッジ回路では、相反性と対称性を利用すると計算量を減らせる場合がある。また抵抗ブリッジが平衡し、中央枝の両端電位が等しい場合、その中央枝電流は0になる。

平衡条件を比で書ける形では、接続の対応を確認したうえで

`R1/R2 = R3/R4`

のような関係を使う。どの抵抗が対向・隣接しているかを図で確認せず式だけ暗記すると誤る。

## 8. 二端子回路を外から見る

複雑な回路を解くとき、内部の全電流を毎回求める必要はない。外部端子から必要な特性だけを見ることで計算を段階化できる。

二端子回路なら主に、端子電圧と端子電流の関係、すなわち入力インピーダンスを考える。二端子対回路では入力側と出力側の関係を分け、負荷を接続した状態で入力インピーダンスや電圧比を順に求める。

T形抵抗回路のような回路では、出力側の負荷から逆向きに直列・並列合成し、まず入力インピーダンスを求める。その後、各段の分圧比を求めればよい。

縦続接続された二段回路で、第1段の電圧比が `k1`、第2段が `k2` なら、負荷条件を含めてそれぞれの比が定義されているとき全体の電圧比は

`Vout/Vin = k1 k2`

となる。各段を切り離した無負荷電圧比をそのまま掛けてよいとは限らず、後段が前段の負荷になることに注意する。

## 9. 交流回路への拡張

正弦波定常状態では、抵抗だけの直流回路で使った回路網定理を複素インピーダンスへ拡張できる。

`Z = R + jX`

`I = V/Z`

とし、電圧・電流を実効値フェーザで扱う。KCL、KVL、重ね合わせ、電源変換、テブナン／ノートン等価は、線形回路であれば複素数のまま同様に適用できる。

交流テブナン等価では

- `Vth`: 開放端電圧フェーザ
- `Zth`: 端子から見た複素インピーダンス

を別々に求める。負荷 `ZL` を接続した電流は

`IL = Vth/(Zth + ZL)`

である。

負荷の有効電力は

`PL = Re(VL IL*)`

または

`PL = |IL|^2 Re(ZL)`

で求める。電流の複素数そのものを二乗して `I^2R` としない。

## 10. 最大電力伝送

直流抵抗回路をテブナン形 `Vth, Rth` に置き換え、負荷を純抵抗 `RL` とすると

`I = Vth/(Rth+RL)`

負荷電力は

`PL = I^2 RL = Vth^2 RL/(Rth+RL)^2`

である。`RL` で微分すると

`dPL/dRL = Vth^2 (Rth-RL)/(Rth+RL)^3`

したがって最大条件は

`RL = Rth`

であり、最大電力は

`Pmax = Vth^2/(4Rth)`

となる。

一般の交流回路で `Zth = Rth + jXth` とし、負荷側のリアクタンスも自由に選べるなら、平均有効電力の最大条件は共役整合

`ZL = Zth* = Rth - jXth`

である。直流抵抗回路の `RL=Rth` を、リアクタンスをもつ交流回路へそのまま適用してはいけない。

### 複合・ひっかけ例題

実効値フェーザ `E=100∠0° V` の電源から `Z1=4+j3 Ω` を介して端子 `a` へ接続し、端子 `a` から接地へ内部インピーダンス `Z2=6-j2 Ω` が接続されている。端子 `a`-接地へ負荷を接続する。

開放端電圧は分圧より

`Vth = 100 Z2/(Z1+Z2)`

`= 57.43 - j25.74 V`

`= 62.93∠-24.1° V`

独立電圧源を短絡したときの等価インピーダンスは

`Zth = Z1 || Z2`

`= (Z1 Z2)/(Z1+Z2)`

`= 3.069 + j0.693 Ω`

最大有効電力を受ける負荷は共役整合より

`ZL = 3.069 - j0.693 Ω`

である。このとき

`Pmax = |Vth|^2/(4 Re(Zth))`

`= 62.93^2/(4×3.069)`

`≈ 322.6 W`

となる。`ZL=Zth` とするとリアクタンスが相殺されず、最大条件にならない。

## 11. 問題を見たときの解法選択

回路網問題では、次の順で判断する。

1. 求める量を確認する。節点電位、枝電流、端子電圧、負荷電力のどれか。
2. 電流方向と電圧極性を図へ書く。
3. 未知節点数と独立閉路数を比較する。
4. 一部の枝だけが必要なら、重ね合わせやテブナン等価で切り出せないか考える。
5. 電圧源と電流源が混在していれば、電源変換で簡単になるか確認する。
6. 交流なら最初から複素インピーダンスとフェーザで扱う。
7. 方程式を解いた後、符号・単位・KCL/KVL・電力の妥当性を検算する。

使い分けの目安は次のとおり。

| 回路の特徴 | 第一候補 |
|---|---|
| 未知節点が少ない | 節点法 |
| 独立閉路が少ない平面回路 | 閉路法 |
| 複数電源の寄与を分けたい | 重ね合わせ |
| 一つの負荷だけを何度も変える | テブナン／ノートン |
| 電圧源・電流源が混在 | 電源変換 |
| 電源位置と応答位置の交換が使えそう | 相反定理の適用条件を確認 |
| 負荷電力を最大化 | まずテブナン等価 |

典型的な誤りは、式を立てる前に電流方向を頭の中だけで処理すること、独立電源の零化を逆にすること、制御電源まで零化すること、交流回路で位相を捨てて大きさだけで計算することである。

## 12. 新幹線への接続

新幹線の列車側から上流のき電系統を見ると、教育上は多数の設備を一つの等価電源として抽象化できる。

```text
実際の上流側
変電所・変圧器・き電線・架線など
              ↓ 端子から見た等価化
          Vth ─ Zth ─ 列車負荷
```

この見方を使えば、列車端子電圧や負荷電流の基本関係は

`I = (Vth - Vload)/Zth`

または負荷を `ZL` とする単純モデルなら

`I = Vth/(Zth+ZL)`

の形で考えられる。

ただし、これは回路網定理を理解するための教育用抽象モデルである。実際の新幹線き電回路には、ATき電、複数の変電所、線路の分布定数、列車位置に伴うインピーダンス変化、複数列車などが関係する。本Topicではそれらを単純な一つの `Vth-Zth` と同一視しない。

実設備の `Vth` や `Zth` の値を一次資料なしに推測して真値として扱わない。数値計算を行う場合は教材上の仮定値と明記する。
