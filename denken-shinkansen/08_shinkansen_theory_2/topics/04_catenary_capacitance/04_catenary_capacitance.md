# 解説本文

## 1. このテーマで電験は何を問うか

二種一次「理論」では、単に `C=Q/V` を暗記しているかではなく、導体形状と誘電体配置から電界・電位差・静電容量・静電エネルギーを順に組み立てられるかが問われる。

本テーマで必要なのは次の判定である。

1. 平行板、同軸円筒、複数容量のどのモデルかを判定する。
2. 電源接続中なら原則として電圧 `V`、切離し後なら電荷 `Q` が固定されることを確認する。
3. 誘電体が複数ある場合は境界条件から共通量を決める。
4. `D`、`E`、`V`、`C` の順に必要量をつなぐ。
5. 最後に既知量に適した式で静電エネルギーを求める。

固定EXAM_ALIGNMENTの5問・22小問は、この流れで解けるようにする。

## 2. 静電容量 `C=Q/V`

静電容量 `C` は、導体間に電位差 `V` を与えたときに蓄えられる電荷 `Q` の比である。

`C = Q/V`

単位はファラド `[F] = [C/V]` である。静電容量は、電圧を高くしたから値そのものが増える量ではなく、線形な誘電体を用いる通常の問題では導体形状と誘電率で決まる。

問題では `Q` と `V` のどちらが未知かを最初に確認する。とくに電源から切り離された後の導体では、外へ電荷が逃げない条件なら `Q` を保存量として扱う。

## 3. 平行板コンデンサと誘電体

面積 `S`、極板間隔 `d`、誘電率 `ε` の平行板コンデンサを、端効果を無視できる一様電界として扱う。

`E = V/d`

極板自由表面電荷密度を `σ=Q/S` とすると、電束密度は

`D = σ = Q/S`

線形等方誘電体では

`D = εE`

であるから、

`Q/S = εV/d`

より

`C = Q/V = εS/d`

を得る。ここで

`ε = ε0 εr`

であり、`ε` は誘電率 `[F/m]`、`εr` は無次元の比誘電率である。

### 分極

誘電体では外部電界によって正負の電荷中心がわずかにずれ、分極 `P` が生じる。電束密度は

`D = ε0E + P`

で表す。線形等方誘電体では

`P = ε0(εr-1)E`

なので、

`D = ε0εrE = εE`

となる。本テーマではこの関係までを使い、材料物性の詳細には広げない。

## 4. 異種誘電体を電界方向に積層する場合

厚さ `d1`,`d2`、誘電率 `ε1`,`ε2` の誘電体を電界方向に積層した平行板を考える。境界に自由表面電荷がない場合、法線方向の電束密度 `D` は連続する。

`D1 = D2 = D`

したがって各層の電界は

`E1 = D/ε1`

`E2 = D/ε2`

となり、一般に `E1=E2` ではない。誘電率が小さい層ほど、同じ `D` に対して電界が大きくなる。

各層の電圧は

`V1 = E1 d1 = D d1/ε1`

`V2 = E2 d2 = D d2/ε2`

全電圧は

`V = V1 + V2 = D(d1/ε1 + d2/ε2)`

である。極板面積を `S` とすれば `Q=DS` なので、合成静電容量は

`C = Q/V = S / (d1/ε1 + d2/ε2)`

となる。これは各層を

`C1 = ε1S/d1`, `C2 = ε2S/d2`

とした直列合成

`1/C = 1/C1 + 1/C2`

と一致する。

各誘電体の許容電界 `Emax,i` が与えられる場合は、共通の `D` に対して

`D <= εi Emax,i`

を各層で確認し、最も小さい `εi Emax,i` が全体の上限を決める。その上限 `Dmax` を全電圧式へ戻せば最大印加電圧を求められる。

## 5. 直列・並列の合成静電容量

直列接続では各コンデンサに蓄えられる電荷の大きさが共通で、電圧が分担される。

`1/C = 1/C1 + 1/C2 + ...`

並列接続では電圧が共通で、電荷が分担される。

`C = C1 + C2 + ...`

図が複雑でも、まず「共通なのは電荷か電圧か」を決める。中間導体がある問題では、その導体が外部回路から絶縁されているなら、その導体全体の電荷保存を先に置く。

## 6. 同軸円筒導体

半径 `a` の内導体と内半径 `b` の外導体をもつ十分長い同軸円筒を考え、単位長さ当たりの自由電荷を `λ [C/m]` とする。

半径 `r`、長さ1 mの円筒面を考えると面積は `2πr` なので、

`D(r) 2πr = λ`

より

`D(r) = λ/(2πr)`

となる。球面積 `4πr²` は使わない。

誘電率が一様なら

`E(r) = D(r)/ε = λ/(2πεr)`

電位差は

`V = ∫_a^b E(r)dr = λ/(2πε) ln(b/a)`

したがって単位長さ当たり静電容量は

`C' = λ/V = 2πε/ln(b/a)`

であり、単位は `[F/m]` である。長さ `l` の全体容量が必要なら、一様な同軸形状を仮定できる範囲で `C=C'l` とする。

### 誘電率が半径方向に変化する場合

`ε=ε(r)` でも、自由電荷から決まる

`D(r)=λ/(2πr)`

は変わらない。変化するのは

`E(r)=D(r)/ε(r)=λ/{2πrε(r)}`

である。したがって問題文で `ε(r)` が与えられたら、

`V = ∫_a^b λ/{2πrε(r)} dr`

をそのまま評価し、最後に `C'=λ/V` とする。導電率やコンダクタンスへは広げない。

## 7. 静電エネルギー

コンデンサに蓄えられる静電エネルギーは

`W = 1/2 CV²`

である。`Q=CV` を使えば、同じ内容を

`W = 1/2 QV`

`W = Q²/(2C)`

とも表せる。

どの式を使うかは固定量で決める。電源につながれたまま電圧一定なら `V` を使う形が便利であり、電源から切り離され電荷一定なら `Q²/(2C)` が直接使える。

たとえば `C=200 pF`, `V=5.0 kV` のコンデンサを充電後に電源から切り離し、極板間隔を2倍にして `C=100 pF` にしたとする。切離し前の電荷は

`Q = CV = 1.0 μC`

で保存される。初期エネルギーは

`W1 = 1/2 CV² = 2.5 mJ`

変化後は

`W2 = Q²/(2C) = 5.0 mJ`

である。固定電荷条件で容量が小さくなると、静電エネルギーは増える。

### エネルギー密度

線形誘電体中の電界エネルギー密度は

`u = 1/2 εE²`

である。`D=εE` を用いれば

`u = D²/(2ε)`

とも書ける。異種誘電体を直列配置し、両層で同じ `D` が流れる条件では、誘電率の小さい層ほどエネルギー密度が大きい。

## 8. 問題を見たときの解法手順

1. 導体形状を平行板、同軸円筒、複数容量のどれとして扱うか判定する。
2. 電源接続中か切り離し後かを確認し、固定される量が `V` か `Q` かを決める。
3. 誘電体が複数ある場合、自由表面電荷の有無を確認し、境界で共通になる `D` を決める。
4. `D=εE` で各領域の電界を求める。
5. 一様電界なら `V=Ed`、非一様なら `V=∫E·dl` で電位差を求める。
6. `C=Q/V`、平行板式、同軸円筒式、直並列合成のいずれかで容量を求める。
7. エネルギーは既知量に合わせて `1/2CV²`、`1/2QV`、`Q²/(2C)` を選ぶ。
8. `F` と `F/m`、`ε` と `εr`、mm・cm・m、面積単位を確認して検算する。

## 9. 新幹線への接続

架線、車体、レールなどは導体であり、異なる電位にある導体間には静電容量が形成される。ただし実際の架線・車体・レールは平行板でも同軸円筒でもなく、周辺構造も複雑である。

本教材では、

- 高電圧導体と周囲導体を平行板へ置き換えるモデル
- 高電圧導体を同軸円筒へ置き換えるモデル

だけを使い、静電容量・誘電体・静電エネルギーの理解に接続する。これらは電験理論用の教育用簡略モデルであり、実在新幹線の容量や電界を表す真値ではない。

## 10. 頻出ミス

- `ε` と比誘電率 `εr` を混同する。
- 直列配置の異種誘電体で `E` が同じだと決めつける。
- 自由表面電荷がない境界で法線方向 `D` が連続する条件を落とす。
- 直列では電荷共通、並列では電圧共通という条件を逆にする。
- 同軸円筒で `4πr²` を使う。
- `ln(b/a)` を `ln(a/b)` として符号を反転させる。
- 単位長さ当たり静電容量 `[F/m]` と全体容量 `[F]` を混同する。
- 電源接続中の固定電圧と、切離し後の固定電荷を区別しない。
- `W` `[J]` とエネルギー密度 `u` `[J/m³]` を混同する。

# 3段階例題

## 例題1 基礎: 平行板コンデンサ

面積 `S=0.020 m²`、極板間隔 `d=5.0 mm`、比誘電率 `εr=4.0` の誘電体を満たした平行板コンデンサに `V=3.0 kV` を加える。静電容量 `C`、電荷 `Q`、静電エネルギー `W` を求める。`ε0=8.854×10^-12 F/m` とする。

まず `d=5.0×10^-3 m` とする。

`C = ε0εrS/d`

`= 8.854×10^-12 × 4.0 × 0.020 / (5.0×10^-3)`

`= 1.42×10^-10 F = 142 pF`

次に

`Q = CV = 1.42×10^-10 × 3.0×10^3`

`= 4.25×10^-7 C = 0.425 μC`

エネルギーは

`W = 1/2 CV²`

`= 1/2 × 1.42×10^-10 × (3.0×10^3)²`

`= 6.38×10^-4 J = 0.638 mJ`

この問題では電圧が与えられているので、`C` を形状から求め、`Q=CV`、`W=1/2CV²` へ進む。

## 例題2 本試験標準: 同軸円筒

内導体半径 `a=5.0 mm`、外導体内半径 `b=15 mm`、比誘電率 `εr=2.5` の一様誘電体を満たした十分長い同軸円筒を考える。内導体の単位長さ当たり電荷を `λ=0.20 μC/m` とする。単位長さ当たり静電容量 `C'`、電位差 `V`、単位長さ当たり静電エネルギー `W'` を求める。

円筒対称より

`D(r)=λ/(2πr)`

`E(r)=λ/(2πεr)`

である。電位差は

`V = ∫_a^b E(r)dr = λ/(2πε) ln(b/a)`

したがって

`C' = λ/V = 2πε/ln(b/a)`

`= 2π × 8.854×10^-12 × 2.5 / ln(15/5)`

`= 1.27×10^-10 F/m`

よって

`V = λ/C'`

`= 0.20×10^-6 / 1.27×10^-10`

`≈ 1.58×10^3 V`

単位長さ当たりエネルギーは

`W' = λ²/(2C')`

`≈ 1.58×10^-4 J/m`

である。同軸円筒ではガウス面が円筒側面なので `2πr` が現れ、積分で `ln(b/a)` になる点が本試験の要点である。

## 例題3 複合・ひっかけ: 二層誘電体と最大電圧

面積 `S=0.010 m²` の平行板間を、電界方向に二つの誘電体で満たす。誘電体1は `d1=2.0 mm`, `εr1=2.0`、誘電体2は `d2=3.0 mm`, `εr2=6.0` とする。全体に `V=10 kV` を加えたときの `D`,`E1`,`E2`,`C` を求める。また許容電界が `Emax1=4.0 MV/m`,`Emax2=1.5 MV/m` のとき、最大印加電圧を求める。

境界に自由表面電荷がないので、両層で `D` は共通である。

`V = D(d1/ε1 + d2/ε2)`

より

`D = V / (d1/ε1 + d2/ε2)`

`= 5.90×10^-5 C/m²`

したがって

`E1 = D/ε1 = 3.33×10^6 V/m = 3.33 MV/m`

`E2 = D/ε2 = 1.11×10^6 V/m = 1.11 MV/m`

となる。誘電率が小さい誘電体1の方が電界が大きい。

電荷は

`Q=DS=5.90×10^-7 C`

なので

`C=Q/V=5.90×10^-11 F=59.0 pF`

である。

最大電圧は、各層の許容 `D` を比較する。

`Dmax1 = ε1Emax1 = 7.08×10^-5 C/m²`

`Dmax2 = ε2Emax2 = 7.97×10^-5 C/m²`

したがって誘電体1が先に上限へ達し、全体の `Dmax` は `7.08×10^-5 C/m²` である。

`Vmax = Dmax(d1/ε1 + d2/ε2)`

`= 1.20×10^4 V = 12.0 kV`

となる。許容電界そのものを直接比較するのではなく、直列積層では共通量 `D` に直して比較することが重要である。
