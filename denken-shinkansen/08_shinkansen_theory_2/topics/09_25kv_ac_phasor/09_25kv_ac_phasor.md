# 解説本文

## 1. このテーマで電験は何を問うか

本Topicでは、交流の時間波形を「大きさと位相」に分け、複素数として計算できる状態にする。二種一次「理論」では、正弦波の実効値・最大値・瞬時値の変換、R・L・Cの複素インピーダンス、フェーザの加減算、`V̇=Żİ`、並列回路のアドミタンスが直接問われる。

最低限、次の式を相互に使えることが必要である。

```text
ω = 2πf
T = 1/f
V = Vm/√2
I = Im/√2
ŻR = R
ŻL = jωL
ŻC = 1/(jωC) = -j/(ωC)
V̇ = Ż İ
Ẏ = 1/Ż
```

本教材ではフェーザの大きさを実効値とする。瞬時値へ戻すときだけ `√2` を掛けて最大値へ変換する。

## 2. 正弦波の瞬時値・周期・位相

正弦波は、正弦基準なら

```text
v(t) = Vm sin(ωt + φ)
```

余弦基準なら

```text
v(t) = Vm cos(ωt + φ)
```

と書ける。`Vm` は最大値 [V]、`ω` は角周波数 [rad/s]、`φ` は初期位相 [rad] または [°] である。周波数 `f[Hz]`、周期 `T[s]` との関係は

```text
ω = 2πf
T = 1/f
```

である。

二つの正弦波が同じ `ω` を持つとき、位相差は初期位相の差で表せる。例えば `φ1-φ2=30°` なら、第1波形は第2波形より30°進んでいる。フェーザ法は同一角周波数の定常正弦波を対象とする。

## 3. 実効値と平均値

正弦波の実効値は、同じ抵抗に同じ発熱作用を与える直流値に対応し、

```text
V = Vm/√2
I = Im/√2
```

である。逆に最大値は `Vm=√2V`、`Im=√2I` で求める。

正弦波を1周期そのまま平均すると正負が打ち消し合うため平均値は0である。一方、正弦波の正の半周期だけを平均する場合は

```text
Vav(半周期) = 2Vm/π
```

となる。問題文が「平均値」とだけ書いてあるときは、どの区間・どの波形を平均しているか確認する。実効値を単純な算術平均だと考えない。

## 4. 25kV交流を時間波形へ戻す

本Topicの題材である25 kV交流について、25 kVを実効値とし、余弦基準で位相を0°に置くと

```text
V̇ = 25∠0° kV
```

と表せる。対応する最大値は計算値として

```text
Vm = √2×25 = 35.4 kV
```

なので、瞬時値は

```text
v(t) = 35.4 cos(ωt) kV
```

となる。25 kVと35.4 kVを混同しないことが重要である。ここでは25 kV交流をフェーザ法の導入にだけ用い、実設備の未確認回路定数は置かない。

## 5. 複素数表示

複素数は直交形式、極形式、指数形式を使い分ける。

```text
a + jb
= r(cosθ + j sinθ)
= r e^(jθ)
= r∠θ
```

ここで

```text
r = √(a²+b²)
θ = atan2(b,a)
```

である。逆に

```text
a = r cosθ
b = r sinθ
```

で直交形式へ戻せる。

加減算は `a+jb` の直交形式が扱いやすく、乗除算は `r∠θ` の極形式が扱いやすい。例えば

```text
(10∠30°)/(2∠-20°) = 5∠50°
```

のように、大きさは除算、偏角は減算する。

## 6. フェーザとは何か

同一角周波数の正弦波について、時間変化する共通部分を省き、大きさと位相だけを複素数で表したものがフェーザである。本教材では余弦基準・実効値フェーザを標準とする。

```text
v(t)=√2 V cos(ωt+φ)
↔
V̇=V∠φ
```

例えば

```text
v(t)=100√2 cos(ωt-30°) V
```

なら

```text
V̇=100∠-30° V
```

である。

正弦基準の式を余弦基準へ直すときは

```text
sinθ = cos(θ-90°)
```

を使う。基準を途中で混在させない。

## 7. `j` は90°回転を表す

複素平面で `j` を掛けることは+90°回転、`-j` を掛けることは-90°回転に対応する。

```text
j = 1∠90°
-j = 1∠-90°
```

したがって、あるフェーザ `Ȧ` に対して

```text
jȦ
```

は `Ȧ` より90°進み、

```text
-jȦ
```

は90°遅れる。この関係がインダクタとコンデンサの位相関係へ直接つながる。

## 8. R・L・Cの複素インピーダンス

抵抗、インダクタ、コンデンサはフェーザ領域でそれぞれ

```text
ŻR = R
ŻL = jωL = ωL∠90°
ŻC = 1/(jωC) = -j/(ωC) = (1/ωC)∠-90°
```

と表す。単位はすべて `Ω` である。

`V̇=Żİ` より、抵抗では電圧と電流は同相、インダクタでは電圧が電流より90°進み、コンデンサでは電圧が電流より90°遅れる。

特にコンデンサでは

```text
1/j = -j
```

なので符号を誤らない。

## 9. 直列回路の合成

直列回路では同じ電流が流れるため、複素インピーダンスを加算する。

```text
Ż = Ż1 + Ż2 + ...
İ = V̇/Ż
```

例えば

```text
Ż = 8 + j6 Ω
```

なら

```text
|Ż| = √(8²+6²) = 10 Ω
∠Ż = tan^-1(6/8) = 36.87°
```

より

```text
Ż = 10∠36.87° Ω
```

と書ける。

## 10. 並列回路とアドミタンス

並列回路では各枝に同じ電圧がかかり、電流が加算されるため、アドミタンスを使うと計算しやすい。

```text
Ẏ = 1/Ż
İ = ẎV̇
```

各素子のアドミタンスは

```text
ẎR = 1/R
ẎL = 1/(jωL) = -j/(ωL)
ẎC = jωC
```

である。並列なら

```text
Ẏ = Ẏ1 + Ẏ2 + ...
```

と加算し、必要なら最後に `Ż=1/Ẏ` へ戻す。

## 11. フェーザの加減算と大きさ

フェーザの和差を求めるときは直交形式へ直す。

```text
Ȧ = a1 + jb1
Ḃ = a2 + jb2
Ȧ - Ḃ = (a1-a2) + j(b1-b2)
```

大きさは

```text
|a+jb| = √(a²+b²)
```

で求める。特に `jωL İ` のような項は電流フェーザを90°回転させるため、実軸・虚軸に分けたベクトル三角形として扱える。

H26問3のような

```text
V̇S - V̇R = jωL İ
```

では、差フェーザを複素数として直接扱うか、互いに直交する成分の三角形として大きさを求める。

## 12. フェーザから瞬時値へ戻す

実効値フェーザ

```text
V̇ = V∠φ
```

が得られたら、余弦基準の瞬時値は

```text
v(t) = √2 V cos(ωt+φ)
```

である。フェーザの大きさ `V` をそのまま瞬時値の最大値にしない。

逆に

```text
v(t)=Vm cos(ωt+φ)
```

からフェーザへ直すときは

```text
V̇ = (Vm/√2)∠φ
```

となる。

## 13. 問題を見たときの解法手順

1. 与えられた量が瞬時値・最大値・実効値のどれか判定する。
2. 正弦基準か余弦基準かを確認し、途中で統一する。
3. フェーザの大きさは実効値にそろえる。
4. R・L・Cを `R`、`jωL`、`1/(jωC)` へ置き換える。
5. 直列はインピーダンス、並列は必要に応じてアドミタンスで合成する。
6. 加減算は直交形式、乗除算は極形式を優先する。
7. `V̇=Żİ` または `İ=ẎV̇` で未知量を求める。
8. 絶対値と偏角を読み取る。
9. 瞬時値を問われた場合のみ、実効値を `√2` 倍して最大値へ戻す。
10. Lは+90°、Cは-90°、単位は `V/A=Ω` になることを検算する。

## 14. 頻出ミス

- 実効値フェーザと最大値を混同し、瞬時値へ戻すときの `√2` を落とす。
- 正弦基準と余弦基準を途中で混在させ、位相が90°ずれる。
- `1/j=-j` を忘れ、コンデンサの虚部を正にする。
- LとCの位相関係を逆にする。
- 複素数の加算を極形式の大きさ同士・角度同士で行う。
- 並列回路でインピーダンスをそのまま加算する。
- `atan(b/a)` だけで象限を決め、偏角を誤る。符号を見て象限まで確認する。
- 平均値と実効値を同じものと考える。

# 3段階例題

## 例題1 基礎: 25kV交流をフェーザと瞬時値で表す

25 kVの正弦波交流を、実効値25 kV、余弦基準、位相0°とする。フェーザ、最大値、瞬時値、1周期平均値を求めよ。

### 解答

フェーザは実効値を大きさに取るので

```text
V̇ = 25∠0° kV
```

最大値は

```text
Vm = √2V = √2×25 = 35.4 kV
```

したがって瞬時値は

```text
v(t) = 35.4 cos(ωt) kV
```

である。正弦波を1周期平均すると正負が打ち消し合うので平均値は

```text
0 kV
```

となる。`25 kV` は最大値ではなく実効値、`35.4 kV` はそこから求めた計算上の最大値である。

## 例題2 本試験標準: RL直列回路のフェーザ計算

実効値フェーザ `V̇=100∠0° V` を、`R=8 Ω`、`ωL=6 Ω` の直列回路へ加える。合成インピーダンス、電流フェーザ、抵抗電圧、インダクタ電圧を求め、電圧の和を検算せよ。

### 解答

合成インピーダンスは

```text
Ż = R + jωL
   = 8 + j6
   = 10∠36.87° Ω
```

したがって

```text
İ = V̇/Ż
   = (100∠0°)/(10∠36.87°)
   = 10∠-36.87° A
```

抵抗電圧は

```text
V̇R = Rİ
    = 80∠-36.87° V
    = 64 - j48 V
```

インダクタ電圧は

```text
V̇L = jωL İ
    = 60∠53.13° V
    = 36 + j48 V
```

よって

```text
V̇R + V̇L
= (64-j48) + (36+j48)
= 100 + j0
= 100∠0° V
```

となり、電源電圧と一致する。インダクタ電圧は電流より90°進むことも確認できる。

## 例題3 複合・ひっかけ: 並列回路をアドミタンスで解き瞬時値へ戻す

実効値フェーザ `İ=5∠0° A` の電流源が、抵抗 `R=10 Ω` とコンデンサの並列回路へ流れ込む。コンデンサについて `ωC=0.10 S` とする。合成アドミタンス、端子電圧フェーザ、余弦基準の瞬時電圧を求めよ。

### 解答

抵抗のアドミタンスは

```text
ẎR = 1/R = 0.10 S
```

コンデンサのアドミタンスは

```text
ẎC = jωC = j0.10 S
```

したがって合成アドミタンスは

```text
Ẏ = 0.10 + j0.10
   = 0.1414∠45° S
```

電流源と端子電圧の関係は `İ=ẎV̇` なので

```text
V̇ = İ/Ẏ
   = (5∠0°)/(0.1414∠45°)
   = 35.36∠-45° V
```

ここで35.36 Vは実効値である。瞬時値の最大値は

```text
Vm = √2×35.36 = 50.0 V
```

だから

```text
v(t)=50.0 cos(ωt-45°) V
```

となる。並列回路でインピーダンスを直接加算しないこと、フェーザの実効値を瞬時値の最大値として使わないことがひっかけ点である。
