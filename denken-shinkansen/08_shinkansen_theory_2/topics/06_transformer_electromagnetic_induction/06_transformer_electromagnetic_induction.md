# 解説本文

## 1. このテーマで電験は何を問うか

この章では「磁束が変化すると起電力が生じる」という電磁誘導を、鎖交磁束、自己インダクタンス、相互インダクタンス、磁気エネルギーへつないで計算できるようにする。

本試験で必要なのは、主に次の判断である。

1. 1巻きを貫く磁束 `Φ` と、巻数を含む鎖交磁束 `Ψ=NΦ` を区別する。
2. `e=-dΨ/dt=-N dΦ/dt` から誘導起電力の大きさと符号を求める。
3. 自己インダクタンスを `Ψ=Li` と置き、一定 `L` なら `e=-L di/dt` を使う。
4. `L` が位置などで変化する場合は `Ψ=Li` 全体の変化を追う。
5. 2巻線では自己分と相互分を分け、`M`、`k`、結合コイルの磁気エネルギーを扱う。
6. 位置変化や回転で鎖交磁束が変わる問題では、連鎖律で空間変化を時間変化へ変換する。

0系主変圧器は、一次側の電流・磁束の変化が別巻線の鎖交磁束を変え、誘導起電力を生むという流れを具体化する入口として使う。変圧器等価回路やフェーザ解析へは広げない。

## 2. ファラデーの法則: 起電力は鎖交磁束の時間変化で決まる

1巻きを貫く磁束を `Φ [Wb]`、巻数を `N` とすると、全巻数が同じ磁束と鎖交する簡略モデルで鎖交磁束は

`Ψ = NΦ [Wb・turn]`

である。ファラデーの法則は

`e = -dΨ/dt`

したがって

`e = -N dΦ/dt`

となる。

平均値で扱う場合は

`e_avg = -ΔΨ/Δt = -N ΔΦ/Δt`

を使う。問題文が「磁束」なのか「鎖交磁束」なのかを最初に判定することが重要で、鎖交磁束にさらに `N` を掛けてはいけない。

電験の過去問では鎖交磁束を `Φ` という記号で置く場合もある。記号そのものではなく、問題文の定義を読む。本教材では混同を避けるため、1巻きの磁束を `Φ`、鎖交磁束を `Ψ` とする。

## 3. レンツの法則: 負号は「変化を妨げる向き」

`e=-dΨ/dt` の負号は、誘導現象が元の鎖交磁束の変化を妨げる向きに生じることを表す。

計算では、まず磁束・電圧の正方向を自分で固定する。そのうえで

- `dΨ/dt > 0` なら `e < 0`
- `dΨ/dt < 0` なら `e > 0`

と読む。負号を単に「答えは負になる」と暗記してはいけない。正方向を逆に定めれば数値の符号も逆になるため、重要なのは基準方向と誘導起電力の向きが整合していることである。

## 4. 自己インダクタンス

あるコイル自身の電流 `i` によって、そのコイルに鎖交磁束 `Ψ` が生じる。線形範囲で

`Ψ = Li`

と書けるとき、比例係数 `L` が自己インダクタンスで、単位は `H` である。

`L` が一定なら

`e = -d(Li)/dt = -L di/dt`

となる。したがって電流変化が速いほど、変化を妨げる向きの自己誘導起電力が大きい。

一方、`L` 自体が位置 `x` や配置で変化する問題では

`e = -d(Li)/dt`

の形へ戻る。積の微分を用いれば

`e = -(L di/dt + i dL/dt)`

である。`e=-L di/dt` は `L` 一定の場合の式であり、R2問2のような位置依存 `L(x)` へ無条件に使ってはいけない。

## 5. 抵抗ゼロの短絡コイルでは鎖交磁束が保存される

抵抗がゼロの閉回路で、外部端子電圧がなく、理想化して他の損失も無視する。回路に沿った起電力がゼロでなければ電流は変化し続けるため、ファラデーの法則から

`dΨ/dt = 0`

したがって

`Ψ = Li = 一定`

となる。

初期位置で `L(0)=L0`、電流 `I`、移動後に `L(x)`、電流 `i` なら

`L0 I = L(x) i`

ゆえに

`i = L0 I / L(x)`

である。位置が変化する問題では「電流一定」と思い込まず、短絡・抵抗ゼロという条件から何が保存されるかを読む。

## 6. 相互インダクタンスと結合係数

コイル1の電流 `i1` が作る磁束の一部がコイル2にも鎖交すると、コイル2には相互鎖交磁束が生じる。線形範囲では

`Ψ21 = M i1`

と書き、`M [H]` を相互インダクタンスという。同様に、相反性が成り立つ受動的な2巻線では同じ相互インダクタンス `M` で扱える。

自己インダクタンスを `L1`、`L2` とし、結合の強さを表す結合係数を `k` とすると、相互インダクタンスの大きさは

`M0 = k√(L1L2)`

`0 <= k <= 1`

である。`k=1` は理想的に完全結合、`k=0` は相互結合なしを表す。

配置や基準方向により相互項の符号が変わる問題では、結合の大きさ `M0` と符号を分けて考える。R7問2のように角度 `θ` で結合が変化するモデルでは

`M(θ)=M0 cosθ`

と表される。

## 7. 同一磁路で巻数から `L` と `M` を比べる

同じ磁路を共有し、磁路の条件が変わらない複数巻線では、共通の磁気抵抗を `R` と置けば、巻数 `N1` の巻線1だけに電流 `i1` を流したとき

`Φ = N1 i1 / R`

コイル1の自己鎖交磁束は

`Ψ11 = N1Φ = N1² i1 / R`

したがって

`L1 = Ψ11/i1 = N1²/R`

となる。同じ磁路条件なら `R` は共通なので、自己インダクタンス比は巻数比の二乗で決まる。

同じ磁束 `Φ` が巻数 `N2` のコイル2にも鎖交する簡略モデルなら

`Ψ21 = N2Φ = N1N2 i1/R`

より

`M = Ψ21/i1 = N1N2/R`

となる。同じ磁路条件なら、相互インダクタンス比は二つの巻数の積の比で決まる。H21問2(2)(3)はこの比例関係だけで解け、磁気抵抗そのものの数値計算は必要ない。

## 8. 2巻線の鎖交磁束と磁気エネルギー

2巻線が結合しているとき、巻線1の鎖交磁束は自己分と相互分の和として

`Ψ1 = L1 i1 ± M i2`

巻線2も

`Ψ2 = L2 i2 ± M i1`

と書ける。相互項の符号は、各電流の正方向をどちらに取ったか、二つの磁束が加勢するか反発するかで決まる。

線形な結合コイルに蓄えられる磁気エネルギーは、加勢方向を正に取れば

`W = 1/2 L1 i1² + 1/2 L2 i2² + M i1 i2`

反発方向なら相互項が負になる。

結合係数の上限 `k<=1` は、相互インダクタンスの大きさが

`M0 <= √(L1L2)`

を超えないことと同値である。計算で `k>1` が出た場合は、与えられた値の読み違いか式の誤りを疑う。

## 9. 配置が変わる結合コイル

相互インダクタンスが

`M(θ)=M0 cosθ`

で変化するモデルを考える。巻線1の鎖交磁束を

`Ψ1 = L1 i1 + M(θ)i2`

と置けば、誘導起電力は

`e1 = -dΨ1/dt`

で求める。

`L1`、`i1`、`i2` が一定で、角度だけが時間変化するなら

`e1 = -i2 dM/dt`

`= -i2 (dM/dθ)(dθ/dt)`

となる。`M=M0 cosθ` なら

`dM/dθ = -M0 sinθ`

なので、角速度が与えられれば誘導起電力へ進める。

ここでは鎖交磁束と誘導起電力までを扱い、エネルギーからトルクを求める処理はTopic 07へ譲る。

## 10. 移動コイル: 空間変化を時間変化へ変える

R5問2のように、コイルが移動することで鎖交磁束が位置 `l` の関数 `Ψ(l)` になる場合、ファラデーの法則は

`e = -dΨ/dt`

である。ここで連鎖律を使うと

`dΨ/dt = (dΨ/dl)(dl/dt)`

速度を

`v = dl/dt`

とすれば

`e = -(dΨ/dl) v`

となる。

解法は「位置による鎖交磁束の増減を求める → 速度を掛けて時間変化率へ変換する → 最後にレンツの法則の負号を付ける」の順である。

`dΨ/dl` が負、`v` が正なら `dΨ/dt` は負で、`e` は正になる。符号はこの順序で追う。

## 11. 磁気エネルギー

単一コイルで線形範囲、自己インダクタンス `L` がその状態で定まるとき、磁気エネルギーは

`W = 1/2 L i²`

である。

鎖交磁束 `Ψ=Li` を用いれば

`W = Ψ²/(2L)`

とも書ける。したがって、抵抗ゼロの短絡コイルで `Ψ` が保存される場合、`L` が大きくなると電流 `i=Ψ/L` は小さくなり、磁気エネルギー `W=Ψ²/(2L)` も小さくなる。

損失を無視する理想化では、この磁気エネルギーの増減は機械側とのエネルギー授受として整合させる。ここではエネルギー差までを扱い、力やトルクの導出へは進まない。

## 12. 0系主変圧器との接続

0系主変圧器を本Topicで見るときは、次の連鎖だけを見る。

`一次側の電流変化 → 鉄心を通る磁束の変化 → 二次巻線の鎖交磁束の変化 → 誘導起電力`

二次巻線に鎖交する磁束が時間変化すれば

`e2 = -N2 dΦ/dt`

が成り立つ。ここで重要なのは、25 kVという電圧値そのものを使った実車計算ではなく、別巻線へ電圧が現れる根本が「鎖交磁束の時間変化」であることを理解することである。

実車の巻数、磁束、結合係数等は本Topicの一次資料で確認していないため真値として置かない。等価回路、漏れリアクタンス、フェーザ等にも広げない。

## 13. 問題を見たときの解法手順

### ファラデー則型

1. 問題文の `Φ` が1巻きの磁束か鎖交磁束か確認する。
2. 1巻きの磁束なら `Ψ=NΦ` を作る。
3. 正方向を固定する。
4. `e=-dΨ/dt` または平均値 `-ΔΨ/Δt` を使う。
5. 符号をレンツの法則と照合する。

### 自己インダクタンス型

1. `Ψ=Li` を置く。
2. `L` が一定か、位置等で変化するか確認する。
3. 一定なら `e=-L di/dt`。
4. 変化するなら `e=-d(Li)/dt` へ戻る。
5. 抵抗ゼロ短絡なら `dΨ/dt=0` から鎖交磁束保存を使う。

### 相互インダクタンス型

1. `L1`、`L2`、`k` から必要なら `M0=k√(L1L2)` を求める。
2. 自己分と相互分を分けて `Ψ1=L1i1±Mi2` と書く。
3. 配置で `M` が変わるなら `M(θ)` を代入する。
4. `e=-dΨ/dt` で誘導起電力を求める。
5. エネルギーなら `1/2 L1i1² + 1/2 L2i2² ± Mi1i2` を使う。

### 移動コイル型

1. `Ψ(l)` の変化を確認する。
2. `dΨ/dl` を求める。
3. `v=dl/dt` を使い `dΨ/dt=(dΨ/dl)v` とする。
4. `e=-dΨ/dt` で符号を決める。

## 14. 頻出ミス

- 既に鎖交磁束 `Ψ` が与えられているのに、さらに巻数 `N` を掛ける。
- `e=-N dΦ/dt` の負号を、正方向を決めずに機械的に処理する。
- `L` が位置で変化するのに `e=-L di/dt` をそのまま使う。
- 抵抗ゼロ短絡コイルで「電流が一定」と誤認する。保存されるのは条件下の鎖交磁束 `Li` である。
- `M=k√(L1L2)` から `k>1` を許してしまう。
- 相互項の符号を、加勢・反発の基準方向を見ずに固定する。
- `M(θ)` が時間変化するのに `dM/dt` を落とす。
- 移動問題で `dΨ/dl` と `dΨ/dt` を同じものとして扱い、速度 `v` を掛け忘れる。
- 磁気エネルギー `W=Li²/2` と鎖交磁束 `Ψ=Li` を混同する。

# 3段階例題

## 例題1 基礎: 磁束変化から平均誘導起電力を求める

500回巻きのコイルを貫く1巻き当たりの磁束が、正方向に `0.80 mWb` から `0.20 mWb` へ `10 ms` で変化した。平均誘導起電力を求める。

### 解法

与えられているのは1巻き当たりの磁束なので、まず変化量は

`ΔΦ = 0.20×10^-3 - 0.80×10^-3`

`= -0.60×10^-3 Wb`

ファラデーの法則より

`e_avg = -N ΔΦ/Δt`

`= -500 × (-0.60×10^-3)/(10×10^-3)`

`= +30 V`

答え: 基準方向に対して `+30 V`。

磁束が正方向に減少しているので `dΦ/dt<0`、その変化を妨げる向きに誘導起電力が生じ、設定した基準では正になる。

## 例題2 本試験標準: 結合係数・相互インダクタンス・磁気エネルギー

二つのコイルの自己インダクタンスが `L1=0.80 H`、`L2=0.20 H`、結合係数が `k=0.50` である。電流は `i1=2.0 A`、`i2=1.0 A` で、相互磁束が加勢する向きを正とする。相互インダクタンスと全磁気エネルギーを求める。

### 解法

相互インダクタンスの大きさは

`M = k√(L1L2)`

`= 0.50√(0.80×0.20)`

`= 0.20 H`

加勢方向なので

`W = 1/2 L1 i1² + 1/2 L2 i2² + M i1 i2`

`= 1/2×0.80×2.0² + 1/2×0.20×1.0² + 0.20×2.0×1.0`

`= 1.60 + 0.10 + 0.40`

`= 2.10 J`

答え:

- `M = 0.20 H`
- `W = 2.10 J`

検算: `M/√(L1L2)=0.50` で `0<=k<=1` を満たす。反発方向なら相互項の符号だけが負になる。

## 例題3 複合・ひっかけ: 位置依存インダクタンスと移動による誘導起電力

### (a) 抵抗ゼロ短絡コイル

抵抗ゼロの短絡コイルがあり、初期自己インダクタンス `L0=0.20 H`、初期電流 `I=4.0 A` とする。ゆっくり位置を変えた結果、自己インダクタンスが `L=0.50 H` になった。理想化して損失を無視する。移動後の電流と、移動前後の磁気エネルギーを求める。

短絡・抵抗ゼロなので鎖交磁束が保存される。

`Ψ = L0 I = 0.20×4.0 = 0.80 Wb・turn`

したがって

`i = Ψ/L = 0.80/0.50 = 1.6 A`

移動前:

`W0 = 1/2 L0 I²`

`= 1/2×0.20×4.0² = 1.6 J`

移動後:

`W1 = 1/2 L i²`

`= 1/2×0.50×1.6² = 0.64 J`

よって

`ΔW = W1-W0 = -0.96 J`

答え:

- 移動後電流 `1.6 A`
- 移動前 `1.6 J`
- 移動後 `0.64 J`
- 磁気エネルギー変化 `-0.96 J`

電流一定ではなく、`Li` 一定である。損失なしなら減少した `0.96 J` は機械側とのエネルギー授受に対応する。

### (b) 移動コイル

ある区間でコイルの鎖交磁束が位置 `l [m]` に対し

`Ψ(l)=0.040-0.50l [Wb・turn]`

と変化する。コイルが正の `l` 方向へ `v=3.0 m/s` で移動するときの誘導起電力を求める。

位置微分は

`dΨ/dl = -0.50 Wb・turn/m`

時間変化率は

`dΨ/dt = (dΨ/dl)v`

`= -0.50×3.0`

`= -1.5 Wb・turn/s`

したがって

`e = -dΨ/dt = +1.5 V`

答え: 基準方向に対して `+1.5 V`。

`dΨ/dl` だけでは起電力にならない。必ず `v=dl/dt` を掛けて時間変化率へ変換する。
