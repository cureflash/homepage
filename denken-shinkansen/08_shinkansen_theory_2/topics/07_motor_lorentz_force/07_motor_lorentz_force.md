# EXAM_ALIGNMENT

資格: 第二種電気主任技術者

中心科目: 一次試験「理論」

論点:
- 荷電粒子が電界から受ける力 `F = qE`
- 荷電粒子が磁界から受けるローレンツ力 `F = q(v × B)`
- 電子では電荷が負であることによる力の向き
- 磁界に垂直に入射した荷電粒子の等速円運動
- `|q|vB = mv²/r`
- 軌道半径 `r = mv/(|q|B)`
- 角周波数 `ωc = |q|B/m`
- 周波数 `f = |q|B/(2πm)` と周期 `T = 2πm/(|q|B)`
- 加速電圧と運動エネルギー `|q|V = mv²/2`
- 電子の比電荷 `e/m`
- 電界中の電子運動と運動方程式
- 電流が磁界から受ける力 `F = BIl`（直交時）
- 磁束密度 `B` と磁界の強さ `H` の区別。真空では `B = μ0H`

## 過去問ごとの教材内必要説明

### 1. R7 問7

- 電子の電荷を `q=-e` と置き、右手則で `v×B` を決めた後、負電荷なので力の向きが反転すること。
- 真空中では `B=μ0H` として、ローレンツ力の大きさを `eμ0Hv0` と書けること。
- 磁気力は速度に垂直で仕事をしないため速さは変えず、向心力だけを与えること。
- `v0²/r = |q|v0B/m` から円運動を導くこと。
- `f=|q|B/(2πm)`、`T=2πm/(|q|B)` を導き、周期が初速度に依存しないことを説明すること。

### 2. R5 問6

- 電子が電界 `E(t)` から受ける力を `F=-eE(t)` と書くこと。
- `m dv/dt = -eE0 sinωt` を立て、初期条件を使って速度を積分すること。
- さらに速度を積分して位置を求めること。
- 交流電界の周期と電子運動の周期条件を結び付けること。
- 電界の時間変化そのものを別論点へ広げず、与えられた `E(t)` から粒子運動を解く範囲に留めること。

### 3. R3 問6

- x方向速度が一定である条件から、電界領域の通過時間を幾何学的に求めること。
- y方向は `F=qE` と `a=F/m` で等加速度運動として扱うこと。
- 電子の負電荷による加速度方向を誤らないこと。
- 出口でのy方向速度とy変位を順に求め、電界を出た後は等速直線運動へ切り替えること。
- x運動とy運動を独立成分として分解する解法手順を示すこと。

### 4. R1 問7

- `F=|q|vB` と向心力 `mv²/r` を等置して `r=mv/(|q|B)` を導くこと。
- `v=rω` を用いて `ω=|q|B/m` を導くこと。
- サイクロトロン共鳴条件を、外部電界の角周波数と荷電粒子の円運動角周波数の一致として説明すること。
- `ω` が速度に依存しないことを説明すること。

### 5. H25 問6

- 向心力 `mv²/r` と磁気力 `|q|vB` を等置すること。
- 軌道半径 `r=mv/(|q|B)` を使うこと。
- 加速電圧によるエネルギー変換 `|q|V=mv²/2` から `v=√(2|q|V/m)` を導くこと。
- 軌道半径と加速電圧を組み合わせ、`V=|q|B²r²/(2m)` を導くこと。
- `ω=|q|B/m` を用い、測定量から比電荷 `|q|/m` を求める考え方へ接続すること。

## SPECから必須となる説明

選定過去問だけでは不足し得るため、系列SPECの固定範囲として次も教材へ必ず収録する。

1. ベクトル形 `F=q(v×B)` と、大きさ `F=|q|vB sinθ`。
2. 正電荷・負電荷での力の向きの違い。
3. 電界による力 `F=qE` と磁界による力の違い。
4. 磁気力が仕事をせず、速度の大きさを変えないこと。
5. 電流が受ける力。直交時 `F=BIl`、一般には `F=BIl sinθ`。
6. `F=BIl` を多数の移動電荷に働くローレンツ力の総和として接続すること。
7. 0系直流主電動機は「磁界中の電流に力が働く」導入例として用いること。
8. 直流機の等価回路・速度特性・トルク特性・始動・速度制御へ広げないこと。
9. 電子の円運動、サイクロトロン周波数、加速電圧、比電荷の関係。
10. `B[T]` と `H[A/m]` を混同しないこと。

## 解法アルゴリズム

### 電界中の荷電粒子

1. 電荷の符号を確定する。
2. `F=qE` で力の向きと大きさを求める。
3. `a=F/m` で加速度へ変換する。
4. x・y成分を分離する。
5. 問題の電界が一定か時間変化するかを確認する。
6. 初期条件を用いて速度、位置の順に積分する。
7. 電界領域を出た後は、その後の力の有無を再判定する。

### 磁界中の荷電粒子

1. `v` と `B` のなす角を確認する。
2. `F=q(v×B)` で方向を決める。電子なら最後に向きを反転する。
3. 垂直入射なら `|q|vB=mv²/r` と置く。
4. `r=mv/(|q|B)`、`ω=|q|B/m`、`f=|q|B/(2πm)` を必要量へ使い分ける。
5. 加速電圧が与えられたら `|q|V=mv²/2` を先に使う。
6. 単位、電荷の絶対値、`B` と `H` の区別を検算する。
