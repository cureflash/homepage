## 解法アルゴリズム

### 電界中の荷電粒子

1. 電荷の符号を確定する。
2. `F=qE` で力の向きと大きさを求める。
3. `a=F/m` で加速度へ変換する。
4. x・y成分を分離する。
5. 問題の電界が一定か時間変化するかを確認する。
6. 初期条件を用いて速度、位置の順に積分する。
7. 電界領域を出た後は、その後の力の有無を再判定する。

### 磁界中の荷電粒子

1. `v` と `B` のなす角を確認する。
2. `F=q(v×B)` で方向を決める。電子なら最後に向きを反転する。
3. 垂直入射なら `|q|vB=mv²/r` と置く。
4. `r=mv/(|q|B)`、`ω=|q|B/m`、`f=|q|B/(2πm)` を必要量へ使い分ける。
5. 加速電圧が与えられたら `|q|V=mv²/2` を先に使う。
6. 単位、電荷の絶対値、`B` と `H` の区別を検算する。

# 解説本文

## 1. このテーマで電験は何を問うか

このテーマの中心は、電界・磁界の中で荷電粒子がどの向きに、どの大きさの力を受け、どのように運動するかである。一次「理論」では、電子の負電荷による向きの反転、電界中の運動方程式、磁界中の等速円運動、サイクロトロン周波数、加速電圧と運動エネルギー、比電荷 `e/m` を連続して問う形が多い。

解法では、最初に「電界による力」か「磁界による力」かを分ける。電界では力が速度と同じ向き・逆向きにもなり得るため速さが変化する。一方、磁界によるローレンツ力は速度に垂直な成分だけを持つため、磁界だけなら仕事をせず速さを変えない。この違いが、直線・放物運動と円運動を見分ける基準になる。

## 2. 電界中の荷電粒子

電荷 `q[C]` が電界 `E[V/m]` から受ける力は

`F = qE`

である。正電荷なら電界と同方向、電子では `q=-e` なので逆方向となる。質量を `m[kg]` とすれば、運動方程式は

`m dv/dt = qE`

である。一定電界なら加速度 `a=qE/m` は一定で、初速度 `v0`、初期位置 `x0` に対し

`v = v0 + (qE/m)t`

`x = x0 + v0 t + (qE/2m)t²`

となる。電子では `q=-e` を最後まで符号付きで扱う。

## 3. x・y成分に分ける電界中の運動

粒子がx方向へ初速度 `v0` で入り、y方向だけに一様電界 `E` があるとする。x方向には力がないので

`x = v0 t`

であり、長さ `L` の電界領域を通過する時間は

`t = L/v0`

である。y方向の初速度が0なら

`a_y = qE/m`

`v_y = (qE/m)t`

`y = (qE/2m)t²`

となる。出口では

`v_y = qEL/(mv0)`

`y = qEL²/(2mv0²)`

である。電子なら `q=-e` なので、正負を含めて偏向方向を判定する。電界領域を出た後に電界・磁界がなければ、その時点の速度成分を保って等速直線運動へ切り替える。

## 4. 時間変化する電界中の電子

電界が位置ではなく時間で変化し、例として

`E(t)=E0 sinωt`

と与えられる場合でも、出発点は `F=qE` である。電子では

`m dv/dt = -eE0 sinωt`

となる。初期条件 `v(0)=v0` を用いて積分すると

`v(t)=v0 + (eE0/(mω))(cosωt-1)`

であり、さらに `x(0)=x0` として積分すれば

`x(t)=x0+v0t+(eE0/(mω²))sinωt-(eE0/(mω))t`

となる。実際の問題では与えられた初期条件に合わせて積分定数を決める。重要なのは、力→加速度→速度→位置の順に積分し、途中で初期条件を必ず適用することである。

交流電界の周期は `2π/ω` である。粒子運動の周期性を問われたら、速度または位置の式に含まれる `sinωt`、`cosωt` と、定数項・時間に比例する項を区別して判定する。

## 5. 磁界中の荷電粒子とローレンツ力

磁束密度 `B[T]` 中を速度 `v[m/s]` で運動する電荷 `q` が受ける力は、ベクトルで

`F = q(v × B)`

である。`v` と `B` のなす角を `θ` とすると大きさは

`F = |q|vB sinθ`

である。方向はまず正電荷として `v×B` を右手則で求め、電子では `q<0` なので反転する。

`θ=0` または `π` なら `F=0`、`θ=π/2` なら `F=|q|vB` で最大となる。

## 6. `B` と `H` を混同しない

ローレンツ力に直接入る量は磁束密度 `B[T]` である。磁界の強さ `H[A/m]` が与えられたとき、真空中では

`B = μ0H`

を用いて `B` に直してからローレンツ力へ代入する。`B` と `H` は単位も物理量も異なる。

## 7. 磁気力は仕事をしない

ローレンツ力 `q(v×B)` は常に速度 `v` に垂直であるため

`F·v = 0`

である。したがって磁界だけが作用するとき、磁気力は粒子へ仕事をせず、運動エネルギーと速さは変わらない。変わるのは速度の向きである。

この性質により、粒子が磁界へ垂直に入射すると等速円運動になる。

## 8. 磁界中の等速円運動

磁界に垂直に速度 `v` で入射した荷電粒子では、磁気力が向心力となる。

`|q|vB = mv²/r`

したがって軌道半径は

`r = mv/(|q|B)`

である。速度が大きいほど半径は大きく、磁束密度または比電荷 `|q|/m` が大きいほど半径は小さい。

また `v=rωc` を代入すれば

`ωc = |q|B/m`

となる。よって

`f = |q|B/(2πm)`

`T = 2πm/(|q|B)`

である。`ωc`、`f`、`T` は非相対論的なこのモデルでは速度に依存しない。これがサイクロトロン共鳴を扱うときの重要点である。

## 9. 加速電圧と運動エネルギー

電荷の大きさ `|q|` の粒子が電位差 `V` で静止状態から加速され、損失を無視できるとき

`|q|V = mv²/2`

である。したがって

`v = √(2|q|V/m)`

となる。これを円運動半径へ代入すると

`r = (1/B)√(2mV/|q|)`

であり、変形すれば

`V = |q|B²r²/(2m)`

`|q|/m = 2V/(B²r²)`

を得る。またサイクロトロン角周波数からは

`|q|/m = ωc/B`

と求められる。電子なら `|q|=e` として `e/m` を求める。

## 10. 電流が磁界から受ける力

長さ `l` の直線導体に電流 `I` が流れ、磁束密度 `B` と導体のなす角を `θ` とすると

`F = BIl sinθ`

である。直交するときは

`F = BIl`

となる。

この式は荷電粒子のローレンツ力と別物ではない。導体の断面積を `A`、単位体積当たりの移動電荷数を `n`、各電荷の大きさを `|q|`、ドリフト速度を `vd` とする。長さ `l` の導体中の移動電荷数は `nAl`、各電荷への磁気力の大きさは `|q|vdB sinθ` なので総和は

`F = nAl|q|vdB sinθ`

となる。一方

`I = nA|q|vd`

だから

`F = BIl sinθ`

を得る。すなわち電流が受ける力は、多数の移動電荷に働くローレンツ力をまとめた表現である。

## 11. 0系主電動機への接続

0系の直流主電動機を本Topicで使う目的は、磁界中の電流に力が働く現象を具体化することだけである。磁界中に置かれた電機子導体へ電流が流れれば、導体には `F=BIl` に対応する電磁力が働く。これが「モーターが力を出す」最小の物理的説明になる。

ここでは直流機の等価回路、速度特性、トルク特性、始動法、速度制御へは進まない。それらは機械系列の担当範囲である。

## 12. 問題を見たときの解法手順

### 電界問題

1. 粒子の電荷と符号を確認する。
2. `F=qE` を立てる。
3. `a=F/m` に変換する。
4. x・y成分を分け、力が働く方向を特定する。
5. 一定電界なら等加速度運動、時間変化電界なら運動方程式を積分する。
6. 初期条件を速度、位置の積分ごとに適用する。
7. 電界領域の出口では、その後に働く力をもう一度判定する。

### 磁界問題

1. 与えられているのが `B[T]` か `H[A/m]` か確認する。
2. `H` なら必要に応じ `B=μ0H` へ変換する。
3. `v` と `B` の角度を確認する。
4. `F=q(v×B)` で方向を決め、電子なら反転する。
5. 垂直入射なら `|q|vB=mv²/r` を立てる。
6. `r`、`ωc`、`f`、`T` のうち必要な式を選ぶ。
7. 加速電圧があるなら `|q|V=mv²/2` と結合する。
8. `e/m` を求める問題では、`2V/(B²r²)` または `ωc/B` の形まで整理する。

## 13. 頻出ミス

- 電子なのに正電荷と同じ向きへローレンツ力を描く。
- `F=qE` と `F=q(v×B)` を混同する。
- 磁界だけで粒子の速さが増減すると考える。
- `B[T]` と `H[A/m]` をそのまま同じ式へ代入する。
- `ω`、`f`、`T` の `2π` を落とす。
- 円運動で `q` の符号を半径の大きさへそのまま入れ、負の半径を作る。半径計算では `|q|` を使う。
- 加速電圧で `qV=mv²/2` の符号に拘泥し、エネルギー増加量の大きさ `|q|V` を使えなくなる。
- 電界中の二次元運動で、x方向の等速運動とy方向の等加速度運動を混ぜる。

# 3段階例題

## 例題1 基礎: ローレンツ力と円運動

電子が真空中の一様磁界 `B=2.0×10^-3 T` に垂直に、速さ `v=3.0×10^6 m/s` で入射する。電子の電荷の大きさを `e=1.60×10^-19 C`、質量を `m=9.11×10^-31 kg` とする。磁気力の大きさと軌道半径を求めよ。

磁界へ垂直なので

`F = evB`

`= 1.60×10^-19 × 3.0×10^6 × 2.0×10^-3`

`= 9.6×10^-16 N`

である。向きは `v×B` で求めた正電荷の向きと逆である。

半径は

`r = mv/(eB)`

`= (9.11×10^-31 × 3.0×10^6)/(1.60×10^-19 × 2.0×10^-3)`

`≈ 8.54×10^-3 m`

したがって約 `8.5 mm` である。磁気力は速さを変えず、向きだけを変えるので円運動として扱える。

## 例題2 標準: 一様電界を通過する電子

電子がx方向へ `v0=2.0×10^7 m/s` で進み、長さ `L=4.0 cm` の領域でy正方向の一様電界 `E=5.0×10^3 V/m` を受ける。入口でy方向速度は0とする。電子の出口でのy方向速度とy変位を求めよ。`e=1.60×10^-19 C`、`m=9.11×10^-31 kg` とする。

電子は負電荷なので

`a_y = -eE/m`

である。x方向には力がないから通過時間は

`t = L/v0 = 0.040/(2.0×10^7) = 2.0×10^-9 s`

となる。

`a_y = -(1.60×10^-19 × 5.0×10^3)/(9.11×10^-31)`

`≈ -8.78×10^14 m/s²`

したがって

`v_y = a_y t ≈ -1.76×10^6 m/s`

`y = (1/2)a_y t² ≈ -1.76×10^-3 m`

である。y正方向の電界に対し電子はy負方向へ偏向する。x運動とy運動を独立に解くのが要点である。

## 例題3 複合: 加速電圧・円運動・比電荷

電子を電位差 `V=1.00 kV` で静止状態から加速し、その後 `B=2.00×10^-2 T` の一様磁界へ垂直に入射させたところ、半径 `r` の円運動をした。`e/m=1.76×10^11 C/kg` として、速さ、軌道半径、サイクロトロン周波数を求めよ。また、逆に `V`、`B`、`r` を測定した場合の `e/m` の式を示せ。

加速電圧から

`eV = mv²/2`

なので

`v = √(2(e/m)V)`

`= √(2 × 1.76×10^11 × 1.00×10^3)`

`≈ 1.88×10^7 m/s`

である。

円運動半径は

`r = v/((e/m)B)`

`= 1.88×10^7/(1.76×10^11 × 2.00×10^-2)`

`≈ 5.34×10^-3 m`

である。

角周波数は

`ωc = (e/m)B = 3.52×10^9 rad/s`

周波数は

`f = ωc/(2π) ≈ 5.60×10^8 Hz`

となる。

また

`r² = 2mV/(eB²)`

より

`e/m = 2V/(B²r²)`

である。したがって加速電圧、磁束密度、軌道半径を測れば電子の比電荷を求められる。
