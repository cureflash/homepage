## R7 一次「理論」問7 (1)〜(5)

教材から使う事項: `F=q(v×B)`、真空中 `B=μ0H`、`|q|vB=mv²/r`、`f=|q|B/(2πm)`、`T=2πm/(|q|B)`。

1. 速度を右、磁界を上とすると正電荷に対する `v×B` は紙面の裏から表。電子は負電荷なので反転し、紙面の表から裏となる。選択肢 `イ`。
2. 力の大きさは `F=e v0 B=e μ0 H v0`。選択肢 `ハ`。
3. 等速円運動の向心加速度は `v0²/r`。選択肢 `ル`。
4. `e v0 B=m v0²/r` より `r=m v0/(eB)`、したがって `f=v0/(2πr)=eB/(2πm)=eμ0H/(2πm)`。選択肢 `ヨ`。
5. `T=2πm/(eB)` なので周期は初速度 `v0` に依存しない。選択肢 `ホ`。

再解答: `イ / ハ / ル / ヨ / ホ`
公式解答: `イ / ハ / ル / ヨ / ホ`
判定: `5 / 5 PASS`

## R5 一次「理論」問6 (1)〜(5)

教材から使う事項: `F=qE`、電子では `q=-e`、運動方程式、初期条件を用いた速度・位置の積分。

1. `E(t)=E0 sinωt`、`q=-e` より `F=-eE0 sinωt`。係数は `-eE0`。公式選択肢へ対応すると `ル`。
2. `m dv/dt=-eE0 sinωt` より `dv/dt=-(eE0/m)sinωt`。公式選択肢 `カ`。
3. `v(0)=v0` を用いて積分すると `v(t)=v0-[eE0/(mω)](1-cosωt)`。公式選択肢 `ヨ`。
4. `x(0)=0` を用いてさらに積分すると `x(t)=[v0-eE0/(mω)]t+[eE0/(mω²)]sinωt`。公式選択肢 `ワ`。
5. 原点を中心に周期運動するには時間比例項が消える必要があるため `v0-eE0/(mω)=0`、すなわち `ω=eE0/(mv0)`。公式選択肢 `ニ`。

再解答: `ル / カ / ヨ / ワ / ニ`
公式解答: `ル / カ / ヨ / ワ / ニ`
判定: `5 / 5 PASS`

## R3 一次「理論」問6 (1)〜(5)

教材から使う事項: x・y運動の分離、`F=qE`、`a=F/m`、等加速度運動、電界領域外での等速直線運動。

1. x方向には力がなく `vx=vx0` なので、幅 `a` の電界領域の通過時間は `t=a/vx0`。選択肢 `リ`。
2. 電界は下向き、電子は負電荷なので力は上向きで大きさ `eE`。選択肢 `ヘ`。
3. `ay=eE/m` より出口のy方向速度は `vy=eEa/(m vx0)`。選択肢 `ハ`。
4. 出口のy変位は `y=(1/2)(eE/m)(a/vx0)²`。選択肢 `ル`。
5. 出口後は `vy` を保って距離 `L-a` を進むため、追加変位を加えると `d=eEa(2L-a)/(2m vx0²)`。選択肢 `ロ`。

再解答: `リ / ヘ / ハ / ル / ロ`
公式解答: `リ / ヘ / ハ / ル / ロ`

## R1 一次「理論」問7 (1)〜(5)

教材から使う事項: `F=q(v×B)`、`F=|q|vB`、`r=mv/(|q|B)`、`ωc=|q|B/m`。

1. 速度を右、磁界を下とすると正電荷の `v×B` は紙面の表から裏。電子では反転して紙面の裏から表となる。選択肢 `ヌ`。
2. 力の大きさは `e v0 B`。選択肢 `ワ`。
3. `e v0 B=m v0²/r` より `r=m v0/(eB)`。選択肢 `ホ`。
4. `v0=rω` を使うと `ω=eB/m`。選択肢 `イ`。
5. `ω=eB/m` は `v0` を含まないので、初速度を増加させても角周波数は変わらない。選択肢 `ヲ`。

再解答: `ヌ / ワ / ホ / イ / ヲ`
公式解答: `ヌ / ワ / ホ / イ / ヲ`

## H25 一次「理論」問6 (1)〜(5)

教材から使う事項: 磁気力と向心力の等置、`r=mv/(qB)`、加速電圧 `qV=mv²/2`、`ωc=qB/m`。

1. 等速円運動の向心力は `mv²/r`。公式選択肢 `ワ`。
2. `mv²/r=qvB` より `r=mv/(qB)`。公式選択肢 `ヲ`。
3. 静止電子を電圧 `V` で速度 `v` まで加速すると `qV=mv²/2` なので `v=√(2qV/m)`。公式選択肢 `ト`。
4. `r=mv/(qB)` と `qV=mv²/2` を結ぶと `V=qB²r²/(2m)`。公式選択肢 `チ`。
5. `v=rωc` を向心力と磁気力の式へ入れると `ωc=qB/m`。公式選択肢 `ヨ`。

再解答: `ワ / ヲ / ト / チ / ヨ`
公式解答: `ワ / ヲ / ト / チ / ヨ`
判定: `5 / 5 PASS`
