## 根拠

### R8 一次 理論 問8

理想オペアンプの入力電流0、負帰還線形動作時の `V+=V-`、重ね合わせを用いた。

1. `V2=0` とすると反転増幅なので `Vout' = -(R2/R1)V1` → ニ。
2. `V1=0` とすると `V+ = R4/(R3+R4) V2`、非反転利得は `(R1+R2)/R1`。したがって `Vout'' = ((R1+R2)/R1)(R4/(R3+R4))V2` → ヨ。
3. 重ね合わせより `Vout = -(R2/R1)[V1-((R1+R2)/R2)(R4/(R3+R4))V2]` → ヌ。
4. `V1=V2` で `Vout=0` となる条件は `R1R4=R2R3` → ホ。
5. この条件では `Vout=-(R2/R1)(V1-V2)` → リ。

### R1 一次 理論 問8

非反転入力が接地された理想反転加算回路としてKCLを立てた。

1. 仮想接地より反転入力節点電位は0 → ヨ。
2. `I1=V1/R1` → イ。
3. 入力端子へ流入しないので帰還抵抗電流は入力電流の和。帰還抵抗の電圧降下は `R3(I1+I2)` → ト。
4. `R1=R2=R3=R` なら `Vout=-(V1+V2)` → ロ。
5. 回路機能は加算 → ヲ。

### H29 一次 理論 問8

反転入力節点を仮想接地とし、T形帰還網を節点KCLで追った。

1. `IR1=Vin/R1` → カ。
2. `VB=-(R2/R1)Vin` → ハ。
3. `IR3=R2/(R1R3) Vin` → ロ。
4. `R4` の電圧降下は `(R4/R1)(1+R2/R3)Vin` → ホ。
5. `Vout=-(1/R1)[R2+R4(1+R2/R3)]Vin` → ヘ。

### H23 一次 理論 問8

非反転入力側の分圧を先に求め、仮想短絡後に反転側KCLを適用した。

1. `R2=R4=1 kΩ`、`V2=2 V` より `V+=V-=1.0 V` → ヌ。
2. `I1=(3-1)/5 kΩ=0.40 mA` → ト。
3. `R3=5 kΩ` の電圧降下は `2.0 V` → ル。
4. `Vout=1.0-2.0=-1.0 V` → ニ。
5. `Vout=0` とするには反転入力節点を `1.5 V` とすればよく、同じ分圧比から `V2=3.0 V` → ヲ。

### H21 一次 理論 問8

非反転入力接地の理想オペアンプとT形帰還網を節点KCLで解いた。

1. 仮想接地より `V3=0 V` → ル。
2. `Ia=0.1 V / 1 kΩ = 0.10 mA` → ニ。
3. `V4=0-0.10 mA×10 kΩ=-1.0 V` → ホ。
4. `Ib=(0-(-1.0 V))/2 kΩ=0.50 mA` → ハ。
5. `Rc` には `0.60 mA` が流れ、`Vout=-1.0 V-0.60 mA×5 kΩ=-4.0 V` → チ。
