## 5. 解説本文

### 5.1 このテーマで電験は何を問うか

本Topicは二種一次「理論」の電子回路分野で、理想オペアンプの条件を回路解析へ使い、反転・非反転・加算・差動の各回路をKCLから解けるかを中心に問う。固定過去問では、単純な公式代入だけでなく、非反転入力側の分圧、複数入力の重ね合わせ、T形帰還抵抗網の節点解析まで要求される。

最重要なのは回路名の暗記ではない。最初に負帰還かつ線形動作中かを確認し、次に入力端子電流0と仮想短絡を使って節点電位を決め、最後にKCLで出力まで追う。この順序を守れば、抵抗配置が変形された問題にも対応できる。

### 5.2 理想オペアンプの三つの条件

理想オペアンプは差動入力電圧 `V+ - V-` を増幅し、

`Vout = A(V+ - V-)`

と表す。理想条件では差動利得 `A→∞`、入力インピーダンス `→∞`、出力インピーダンス `→0` とする。

入力インピーダンスが無限大なので、二つの入力端子へ流れ込む電流は

`I+ = I- = 0`

とみなす。したがって、入力端子へ電流が吸い込まれる枝をKCLへ追加してはならない。

さらに負帰還が成立し、出力が飽和せず線形動作しているとき、有限の `Vout` を保つには差動入力電圧がほぼ0でなければならない。このため

`V+ = V-`

とみなす。これが仮想短絡である。電圧が等しいだけで、二つの入力端子が導線で短絡されているわけではなく、入力端子間に電流が流れるという意味でもない。

非反転入力が接地されている負帰還回路なら `V+=0` なので `V-=0` とみなせる。これを仮想接地という。

### 5.3 オペアンプ問題の共通解法

固定一次5問は、次の順で統一して解く。

1. 負帰還か、線形動作として扱う問題かを確認する。
2. 理想条件から `I+=I-=0` を置く。
3. 非反転入力側に分圧回路があれば、先に `V+` を求める。
4. 負帰還線形動作なら `V-=V+` を置く。
5. 反転入力節点および帰還抵抗網の各節点でKCLを立てる。
6. 未知の節点電位を順に求め、最後に `Vout` を求める。
7. 複数入力なら、直接KCLでまとめるか、線形回路として重ね合わせる。
8. 最後に符号、抵抗比、同相信号時の挙動を検算する。

コンパレータのように負帰還線形動作ではない回路では、4の仮想短絡を使わない。ここが最初の分岐である。

### 5.4 反転増幅回路

非反転入力を接地し、入力電圧 `Vin` を抵抗 `Rin` を介して反転入力へ加え、出力から反転入力へ帰還抵抗 `Rf` を接続する。

仮想接地より `V-=0`、入力端子電流0より、入力抵抗を流れる電流と帰還抵抗を流れる電流は等しい。

`Vin/Rin = (0-Vout)/Rf`

したがって

`Vout = -(Rf/Rin)Vin`

`Vout/Vin = -Rf/Rin`

となる。負号は出力が入力に対して反転することを表す。抵抗比だけを覚えるのではなく、「仮想接地→入力電流→同じ電流が帰還側へ流れる」という順で導けば、帰還網が変形されても対応できる。

### 5.5 非反転増幅回路

入力 `Vin` を非反転入力へ加え、反転入力には出力から `Rf`、接地側へ `Rg` を接続する。

入力端子電流0なので、反転入力の電圧は出力を抵抗分圧した

`V- = Rg/(Rf+Rg) Vout`

である。負帰還線形動作では `V-=V+=Vin` だから

`Vin = Rg/(Rf+Rg) Vout`

よって

`Vout/Vin = 1 + Rf/Rg`

となる。反転増幅と異なり符号は正で、利得は1以上である。

### 5.6 反転加算回路

複数の入力 `V1, V2, ...` をそれぞれ `R1, R2, ...` を介して反転入力へ接続し、非反転入力を接地する。反転入力は仮想接地なので、各入力枝の電流は

`I1=V1/R1`, `I2=V2/R2`, ...

である。入力端子へは電流が流れ込まないため、その和が帰還抵抗 `Rf` へ流れる。

`V1/R1 + V2/R2 + ... = -Vout/Rf`

したがって

`Vout = -Rf(V1/R1 + V2/R2 + ...)`

となる。各入力の係数 `-Rf/Ri` が重みである。`R1=R2=Rf=R` なら

`Vout=-(V1+V2)`

となり、R1一次理論問8の加算動作へ直接接続する。

### 5.7 差動・減算回路と重ね合わせ

反転側へ `V1` を `R1` で入力し、帰還抵抗を `R2`、非反転側へ `V2` を `R3` と `R4` の分圧で与える回路を考える。

まず非反転入力電圧は

`V+ = R4/(R3+R4) V2`

である。反転入力側から見れば、基準電位が0 Vではなく `V+` の反転増幅回路なので、KCLから

`Vout = (1+R2/R1)V+ - (R2/R1)V1`

したがって

`Vout = (1+R2/R1){R4/(R3+R4)}V2 - (R2/R1)V1`

となる。

この式は重ね合わせでも得られる。`V2=0` として反転側寄与を求め、次に `V1=0` として非反転側寄与を求め、最後に加える。

同相信号 `V1=V2` を打ち消す条件は

`R1 R4 = R2 R3`

である。これは

`R2/R1 = R4/R3`

と同値で、この条件を満たすと

`Vout = -(R2/R1)(V1-V2)`

となる。R8一次理論問8で必要な、反転側寄与・非反転側寄与・重ね合わせ・同相除去条件・出力式を一つの流れで導ける。

### 5.8 非反転側に分圧回路がある場合

H23一次理論問8型では、いきなり反転入力を0 Vとしてはいけない。非反転入力が接地されていないからである。

先に分圧から `V+` を求め、次に仮想短絡で

`V-=V+`

と置く。その後、反転側の入力抵抗と帰還抵抗についてKCLを立てる。出力を0にする条件を問われた場合も、まず必要な反転入力節点電位を逆算し、それと等しくなる `V+` を作る入力値へ戻る。

解法順は「分圧→仮想短絡→KCL→出力」で固定する。

### 5.9 T形など複数節点をもつ帰還抵抗網

H29・H21一次理論問8型では、帰還部分を一つの `Rf` に見立てて暗算しない。反転入力節点を仮想接地にした後、帰還網内部の節点を一つずつKCLで追う。

例えば、入力抵抗を `R1`、仮想接地点から帰還網内部節点Bまでを `R2`、節点Bから接地へ `R3`、節点Bから出力へ `R4` とするT形帰還網では、入力電流は

`Iin = Vin/R1`

であり、入力端子へ電流が流れないので同じ電流が `R2` 側へ流れる。節点B電位は

`VB = -(R2/R1)Vin`

となる。さらに節点BでKCLを立てると、最終的に

`Vout = -(1/R1){R2 + R4(1+R2/R3)}Vin`

を得る。

重要なのはこの式の暗記ではなく、仮想接地した節点から抵抗網の内部節点へ順番に電圧と電流を求めることにある。H21型の数値回路でも同じ手順を使う。

### 5.10 積分回路

反転増幅回路の帰還抵抗をコンデンサ `C` に置き換え、入力側を抵抗 `R` とした理想回路を考える。非反転入力を接地すれば反転入力は仮想接地である。

入力抵抗を流れる電流は

`i = Vin/R`

である。この電流がコンデンサへ流れるので

`Vin/R = -C dVout/dt`

したがって

`dVout/dt = -Vin/(RC)`

であり、時刻 `t0` の出力を `Vout(t0)` とすれば

`Vout(t) = Vout(t0) - (1/RC)∫[t0→t] Vin(τ)dτ`

となる。一定の正電圧を入力すると、理想モデルでは出力は負方向へ一定傾斜で変化する。

### 5.11 微分回路

入力側をコンデンサ `C`、帰還側を抵抗 `R` とした理想反転回路を考える。反転入力は仮想接地なので、入力コンデンサ電流は

`i = C dVin/dt`

となる。この電流が帰還抵抗へ流れるため

`Vout = -Ri`

よって

`Vout = -RC dVin/dt`

となる。入力が一定なら微分値は0なので出力も0、入力が時間とともに直線的に増加するなら一定の負出力になる。

### 5.12 コンパレータ

コンパレータでは、二つの入力電圧の大小を比較する。負帰還を使って線形増幅させる回路ではないため、反転・非反転増幅と同じ感覚で `V+=V-` を置いてはいけない。

理想的には

- `V+ > V-` なら出力は正側へ振れる。
- `V+ < V-` なら出力は負側へ振れる。

と判断する。実回路の出力は電源電圧等で制限されるが、本Topicでは比較動作の区別までとする。発振回路や電圧安定化回路へは広げない。

### 5.13 新幹線のセンサ信号への接続

新幹線・鉄道設備には各種の状態量を電気信号として扱う場面がある。本Topicでは特定の実車回路を断定せず、センサから得られた電圧信号を処理する教育用モデルとしてオペアンプを使う。

小さい信号を所定倍率へ変えるなら反転・非反転増幅、複数信号を合成するなら加算、二つの信号差を取り出すなら差動、時間変化を積算するなら積分、変化率を取り出すなら微分、基準値との大小を判定するならコンパレータという対応で考える。

ここではセンサ種類、実車の回路定数、測定精度、サンプリング方式を真値として追加しない。Topic 19・20の範囲も先取りしない。

### 5.14 頻出ミス・ひっかけ

- 負帰還かどうかを確認せず、すべてのオペアンプで `V+=V-` と置く。
- 仮想短絡を「入力端子間に電流が流れる短絡」と誤解する。
- 非反転入力が接地されていないのに、反転入力を0 Vと決める。
- 反転増幅の負号を落とす。
- 非反転増幅の利得を `Rf/Rg` とし、`1+` を落とす。
- 加算回路で各入力抵抗が異なるのに単純な算術和にする。
- 差動回路で抵抗比条件を確認せず、同相信号が必ず消えると思う。
- T形帰還網を単純な直列・並列合成だけで処理し、内部節点のKCLを省く。
- 積分回路と微分回路で、コンデンサが入力側か帰還側かを取り違える。
- コンパレータへ仮想短絡を適用する。

### 5.16 公式・解法まとめ

- 理想入力条件: `I+=I-=0`
- 負帰還・線形動作: `V+=V-`
- 反転増幅: `Vout/Vin=-Rf/Rin`
- 非反転増幅: `Vout/Vin=1+Rf/Rg`
- 反転加算: `Vout=-RfΣ(Vi/Ri)`
- 差動回路: まず `V+` を求め、`V-=V+` としてKCLを立てる
- 積分: `Vout(t)=Vout(t0)-(1/RC)∫Vin dt`
- 微分: `Vout=-RC dVin/dt`
- コンパレータ: 仮想短絡を使わず `V+` と `V-` の大小を比較する
- 変形回路: 「理想条件確認→節点電位→KCL→出力」で解く

## 6. 3段階例題

### 6.1 基礎例題: 反転増幅

非反転入力を接地した理想オペアンプの反転増幅回路で、`Vin=0.20 V`、`Rin=10 kΩ`、`Rf=50 kΩ` とする。`Vout` を求める。

負帰還線形動作なので `V+=V-=0`、入力端子電流は0である。したがって

`Iin = Vin/Rin`

`=0.20/(10×10^3)`

`=20 μA`

同じ電流が帰還抵抗へ流れるので

`Vout = -Rf Iin`

`=-(50×10^3)(20×10^-6)`

`=-1.0 V`

となる。利得で確認すると

`Vout/Vin=-Rf/Rin=-5`

であり、`0.20 V×(-5)=-1.0 V` と一致する。

### 6.2 本試験標準例題: 分圧をもつ差動回路

理想オペアンプで、`V1` を `R1=10 kΩ` を介して反転入力へ、出力から `R2=30 kΩ` を帰還し、`V2` を `R3=10 kΩ` と `R4=30 kΩ` の分圧で非反転入力へ加える。`V1=0.40 V`、`V2=1.00 V` のとき `Vout` を求める。

まず非反転入力側を先に計算する。

`V+ = R4/(R3+R4)V2`

`=30/(10+30)×1.00`

`=0.75 V`

負帰還線形動作なので

`V-=V+=0.75 V`

である。反転入力節点でKCLを立てると

`(V1-V-)/R1 = (V--Vout)/R2`

したがって

`Vout = (1+R2/R1)V- - (R2/R1)V1`

`=(1+3)×0.75-3×0.40`

`=3.00-1.20`

`=1.80 V`

となる。

この抵抗値では `R2/R1=R4/R3=3` なので

`Vout=-3(V1-V2)=3(V2-V1)`

とも書ける。`V1=V2` なら出力0となるため、同相信号除去条件の検算も通る。

### 6.3 複合・ひっかけ例題: T形帰還網

非反転入力を接地した理想オペアンプで、入力 `Vin=0.10 V` を `R1=10 kΩ` を介して反転入力へ接続する。帰還網は、仮想接地点から内部節点Bまで `R2=20 kΩ`、Bから接地へ `R3=10 kΩ`、Bから出力へ `R4=10 kΩ` のT形とする。`Vout` を求める。

反転入力は仮想接地なので、入力電流は

`Iin=Vin/R1`

`=0.10/(10×10^3)`

`=10 μA`

入力端子へ電流は流れないため、この電流が `R2` へ流れる。よって節点Bは

`VB=-R2 Iin`

`=-(20×10^3)(10×10^-6)`

`=-0.20 V`

となる。

節点Bから接地側へ見た `R3` の電流の大きさは

`0.20/(10×10^3)=20 μA`

であり、節点Bへ流れ込む向きになる。したがって `R4` には `10+20=30 μA` が流れ、出力側は節点Bよりさらに

`(10×10^3)(30×10^-6)=0.30 V`

低くなる。

よって

`Vout=-0.20-0.30=-0.50 V`

である。

一般式

`Vout = -(1/R1){R2+R4(1+R2/R3)}Vin`

へ代入しても

`Vout=-(1/10){20+10(1+20/10)}×0.10=-0.50 V`

となる。ひっかけは、T形帰還網を単純な一つの帰還抵抗として扱わず、内部節点BでKCLを立てる点にある。
