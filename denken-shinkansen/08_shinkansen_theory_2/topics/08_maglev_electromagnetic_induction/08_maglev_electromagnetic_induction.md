# 解説本文

## 1. このテーマで電験は何を問うか

このテーマの中心は「磁束が変化すると何が起こるか」を、式・向き・エネルギーまで一続きで扱うことである。一次「理論」では、磁束または鎖交磁束の変化量を読み取り、時間変化へ変換して誘導起電力を求める問題と、インダクタンスに蓄えられる磁気エネルギーを求める問題が直接対応する。

最低限、次を使い分ける。

```text
λ = NΦ
e = -dλ/dt = -N dΦ/dt
v = dl/dt
W = 1/2 LI²
```

`Φ` は磁束 [Wb]、`λ` は鎖交磁束 [Wb·turn]、`e` は誘導起電力 [V]、`v` は速度 [m/s]、`L` はインダクタンス [H]、`I` は電流 [A]、`W` はエネルギー [J] である。

## 2. ファラデーの法則

コイルを貫く磁束が時間とともに変化すると誘導起電力が生じる。1ターン当たりの磁束を `Φ`、巻数を `N` とすると鎖交磁束は `λ=NΦ` であり、

```text
e = -dλ/dt = -N dΦ/dt
```

となる。磁束そのものが大きいだけでは起電力は生じず、時間変化 `dΦ/dt` が必要である。一定時間内の平均値を扱う問題では

```text
|e| = N |ΔΦ| / Δt
```

としてよい。

## 3. 空間変化を時間変化へ変える

R5問2のようにコイルが移動し、鎖交磁束 `λ` が位置 `l` の関数として与えられる場合は、速度

```text
v = dl/dt
```

を使い、連鎖的に

```text
e = -dλ/dt = -(dλ/dl)(dl/dt) = -v dλ/dl
```

と変換する。試験では「位置に対する磁束の変化」と「時間に対する磁束の変化」を混同しないことが重要である。

## 4. レンツの法則と負号

ファラデーの法則の負号は、誘導作用が元の磁束変化を妨げる向きに生じることを表す。磁束がある正方向に増えているなら、誘導電流はその増加を打ち消す向きの磁界を作る。逆に磁束が減っているなら、減少を妨げるため元の磁束を保つ向きの磁界を作る。

向き問題では、最初に磁束の正方向と回路の正方向を決めてから符号を判断する。負号を単に「電圧が負」と暗記しない。

## 5. 誘導起電力から誘導電流へ

閉じた導体経路があれば、誘導起電力によって誘導電流が流れる。抵抗だけで表した単純な閉回路なら

```text
I = |e| / R
```

で大きさを求められる。向きはレンツの法則で決める。回路が開いていれば起電力は存在しても閉路電流は流れない。

## 6. 渦電流

電磁誘導は巻線だけでなく、塊状の導体内部でも起こる。導体を貫く磁束が変化すると、導体内部に閉じた経路を描くように電流が分布して流れる。これが渦電流である。

渦電流もファラデーの法則とレンツの法則に従う。独立した新しい法則ではなく、「導体内部に分布した誘導電流」として理解する。

## 7. 誘導電流と電磁力

誘導電流が外部磁界中に存在すると、電流と磁界の相互作用により電磁力が生じる。直線導体について、磁界と導体が直交する単純な場合は

```text
F = BIl
```

で大きさを表せる。向きは、まずレンツの法則で誘導電流の向きを決め、その電流と外部磁界の関係から判断する。

この順序にすると、`磁束変化 → 誘導起電力 → 誘導電流 → 電磁力` を一続きで追える。

## 8. 磁界に蓄えられるエネルギー

線形でインダクタンス `L` を一定とみなせるコイルでは、電流 `I` により磁界へ蓄えられるエネルギーは

```text
W = 1/2 LI²
```

である。単位はJ。電流が2倍ならエネルギーは4倍になる。

自己インダクタンス `L1`,`L2` と相互インダクタンス `M` が与えられた2コイルでは、磁束が互いに助け合う向きなら

```text
W = 1/2 L1 I1² + 1/2 L2 I2² + M I1 I2
```

互いに打ち消す向きなら相互項の符号が負になる。本Topicでは与えられた `L1`,`L2`,`M` からエネルギーを選ぶところまでとし、`M` の導出や仮想変位法へ広げない。

## 9. L0系への接続

本Topicでは超電導リニアを、電磁誘導の流れを具体化する題材として使う。

```text
車上の超電導磁石
  ↓ 相対運動で地上コイルを貫く磁束が変化
地上コイルに誘導起電力
  ↓
誘導電流
  ↓ 外部磁界との相互作用
電磁力
  ↓
浮上・案内
```

ここで学ぶ中心は、地上コイル側から見た `磁束変化 → 誘導起電力 → 誘導電流 → 電磁力` である。超電導材料、冷却方式、推進用電力変換、地上設備の詳細はこのTopicの固定範囲へ追加しない。

## 10. 問題を見たときの解法手順

1. どのコイル・導体を貫く磁束を扱うか決める。
2. 磁束または鎖交磁束が増加か減少かを判定する。
3. 位置依存なら `v=dl/dt` で時間変化へ変換する。
4. `e=-dλ/dt` または `e=-N dΦ/dt` で誘導起電力を求める。
5. 向きはレンツの法則で決める。
6. 閉回路なら必要に応じて誘導電流を求める。
7. 電磁力を問われる場合は誘導電流と外部磁界の関係を見る。
8. 磁気エネルギーなら `W=LI²/2`、結合コイルなら与えられた相互項を含む式を使う。
9. `V`,`A`,`H`,`J`,`Wb` の単位を検算する。

## 11. 頻出ミス

- 磁束 `Φ` と鎖交磁束 `λ=NΦ` を混同する。
- `dΦ/dl` をそのまま誘導起電力とし、速度 `dl/dt` を掛け忘れる。
- レンツの法則の負号を、基準方向を決めずに機械的に扱う。
- 開回路でも誘導電流が流れると考える。
- `W=LI²/2` の `1/2` を落とす。
- 結合コイルの相互項 `±MI1I2` の符号を、磁束が加勢か減勢か確認せず決める。

# 3段階例題

## 例題1 基礎: 磁束変化から誘導起電力

150ターンのコイルを貫く1ターン当たりの磁束が、6 msの間に1.2 mWbから0.4 mWbへ一定の割合で減少した。誘導起電力の大きさを求め、誘導作用の向きを説明せよ。

### 解答

磁束変化の大きさは

```text
|ΔΦ| = (1.2 - 0.4)×10^-3 = 0.8×10^-3 Wb
```

よって

```text
|e| = N|ΔΦ|/Δt
    = 150×0.8×10^-3 / (6×10^-3)
    = 20 V
```

磁束は減少しているので、誘導作用はその減少を妨げ、元の磁束を保つ向きになる。答えは `20 V`。

## 例題2 本試験標準: 位置変化を時間変化へ変換

ある移動コイルの鎖交磁束が位置 `l[m]` に対して

```text
λ(l) = 0.36 l  [Wb·turn]
```

で与えられる。コイルが `l` の正方向へ `v=4.0 m/s` で移動するとき、誘導起電力を求めよ。正方向の起電力を `l` 増加で `λ` が増える向きと整合するよう定義する。

### 解答

まず

```text
dλ/dl = 0.36
```

であり、`v=dl/dt=4.0` だから

```text
e = -dλ/dt
  = -(dλ/dl)(dl/dt)
  = -0.36×4.0
  = -1.44 V
```

大きさは `1.44 V`。負号は、`λ` の増加を妨げる向きに誘導起電力が生じることを示す。

## 例題3 複合・ひっかけ: 結合コイルの磁気エネルギー

2コイルについて `L1=0.20 H`、`L2=0.10 H`、`M=0.040 H`、`I1=2.0 A`、`I2=3.0 A` とする。両コイルの磁束が互いに助け合う向きのとき、蓄えられる磁気エネルギーを求めよ。また、互いに打ち消す向きならどうなるか。

### 解答

助け合う向きでは

```text
W = 1/2 L1 I1² + 1/2 L2 I2² + M I1 I2
  = 1/2×0.20×2.0² + 1/2×0.10×3.0² + 0.040×2.0×3.0
  = 0.40 + 0.45 + 0.24
  = 1.09 J
```

打ち消す向きでは相互項が負なので

```text
W = 0.40 + 0.45 - 0.24 = 0.61 J
```

`M I1 I2` の符号を無条件に正としないことがひっかけ点である。
