### R8 一次「理論」問1 (1)〜(3)

一様な体積電荷密度 `ρ` をもつ球の内部では、半径 `r` のガウス面が包む電荷は

`Q_enc = ρ(4/3)πr^3`

である。球対称なので

`E·4πr^2 = Q_enc/ε0`

より

`E = ρr/(3ε0)`

となる。負電荷 `-q` に働く力は `F=qE` の符号を含めて電界と逆向きになる。外側の球殻部分は球対称で、球殻内部への電界寄与は0。したがってx成分は

`F_x = -ρqx/(3ε0)`

となる。

### R4 一次「理論」問1 (1)〜(5)

### H30 一次「理論」問1 (1)〜(4)

`A=(-a,0)` の `+Q` から `B=(0,b)` への距離を `R=sqrt(a^2+b^2)` とすると、

`E_A = Q/(4πε0) · (a,b)/(a^2+b^2)^(3/2)`

よってx成分は `a/(a^2+b^2)^(3/2)`、y成分は `b/(a^2+b^2)^(3/2)` に比例する。

`C=(a,0)` に `-Q` を置く場合、BでのA・Cの電界はy成分が相殺し、x成分が加算される。大きさは `b=0` で最大となる。

Cを `+Q` とした場合はx成分が相殺し、y成分が加算されるため、合成電界は `2b/(a^2+b^2)^(3/2)` に比例する。

教材対応: §2、§3、§8

独立導出後の公式解答照合: `(1)ト / (2)ワ / (3)ヨ / (4)ル`

判定: 4/4 PASS

### H23 一次「理論」問1 (1)〜(3)

同軸円筒間では円筒ガウス面から

`E(r)=q/(2πεr)`

電位差は

`V = ∫_a^b E(r)dr = q/(2πε) ln(b/a)`

したがって

`q = 2πεV/ln(b/a)`

また `E∝1/r` なので最大電界は最小半径 `r=a` で生じ、

`E_max = V/{a ln(b/a)}`

となる。

教材対応: §6、§7、§12

独立導出後の公式解答照合: `(1)ト / (2)ル / (3)ワ`

判定: 3/3 PASS

### H21 一次「理論」問1 (1)〜(5)

正方形の配置で、`P1(0,a)` と `P3(0,-a)` に `+Q`、`P2(-a,0)` に `-2Q`、観測点を `P0(a,0)` とする。

(1) `P1-P3` 間距離は `2a` なので、クーロン力は

`F = Q^2/(4πε0) · 1/(4a^2)`

(2) `P2` に働く `P1`、`P3` からの力はy成分が相殺し、x成分が加算され、

`F = Q^2/(4πε0) · sqrt(2)/a^2`

(3) `P0` で `P1`、`P3` が作る電界もy成分が相殺し、

`E = Q/(4πε0) · 1/(sqrt(2)a^2)`

(4) `P2` の `-2Q` が作る左向き電界を加えると、

`E = Q/(4πε0) · (sqrt(2)-1)/(2a^2)`

(5) `-2Q` を `P_x=(sa,0)` に移動し `P0` の電界を0にする条件は

`2/(1-s)^2 = 1/sqrt(2)`

より

`s = 1-2^(3/4) ≈ -0.6818`

となる。

教材対応: §2、§3、§8、§10

独立導出後の公式解答照合: `(1)ホ / (2)ヌ / (3)ト / (4)ハ / (5)ニ`

判定: 5/5 PASS
