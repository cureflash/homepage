## 解説本文へ固定する解法手順

1. 電荷が点・線・面・体積のどの分布か判定する。
2. 対称性があるか確認し、ガウスの法則が直接使えるか判断する。
3. ガウス面内の包有電荷 `Q_enc` を求める。
4. `∮D·dS=Q_enc` または `∮E·dS=Q_enc/ε` から電界を求める。
5. 対称性がない点電荷配置ではクーロンの法則で各電界を求め、ベクトル合成する。
6. 電位が必要なら基準点を確認し、`V_A-V_B=-∫_B^A E·dl` を使う。
7. 向き、符号、単位 `N/C = V/m` を確認する。

## 頻出ミスとして固定する事項

- 電界をスカラーとして足し引きする。
- `1/r²` の点電荷と `1/r` の無限長線電荷を混同する。
- ガウス面の面積を球 `4πr²` と円筒側面 `2πrl` で取り違える。
- ガウス面内の電荷だけを数える条件を落とす。
- 体積電荷密度 `C/m³` と線電荷密度 `C/m` を混同する。
- 電位差の積分で負号を落とす。
- `E=-dV/dr` の符号を逆にする。
- `ε0` と一般媒質の `ε` を無条件に同一視する。
- 電界の単位 `V/m` と電位 `V` を混同する。

## 新幹線への接続範囲

架線を無限長線電荷とみなす教育用簡略モデルを用い、距離 `r` に対して

`E(r)=λ/(2πεr)`

となることを示す。必要なら基準半径 `r0` を置き、

`V(r)-V(r0)=-(λ/(2πε)) ln(r/r0)`

まで扱う。

これは実在の架線・車体・レール・大地の形状をそのまま表すものではない。実在設備の線電荷密度、周囲電界、離隔等を一次資料なしで真値化しない。

# 解説本文

## 1. このテーマで電験は何を問うか

本テーマでは、電荷配置から電界を求め、その電界から力や電位差を求める流れを扱う。一次「理論」では、点電荷ならクーロンの法則とベクトル合成、球対称・円筒対称ならガウスの法則を選べることが重要である。

試験で必要なのは式の暗記だけではない。電荷分布が点・線・体積のどれか、対称性があるか、ガウス面内に何Cの電荷が含まれるか、電位の基準をどこに置けるかを問題文から判断する必要がある。

この章を終えた段階で、点電荷の合成電界、球・球殻の領域別電界、無限長線電荷・同軸円筒の電界、電界の積分から電位差を求める問題へ接続できる状態を目標とする。

## 2. クーロンの法則と電界

一様な媒質中で、距離 `r` だけ離れた点電荷 `Q1`, `Q2` の間に働く力の大きさは

`F = |Q1Q2|/(4πεr²)`

である。真空なら `ε=ε0` とする。

同符号の電荷は反発し、異符号の電荷は引き合う。式で大きさだけを計算した後、符号から向きを判断する。

点電荷 `Q` が距離 `r` の位置につくる電界の大きさは

`E = |Q|/(4πεr²)`

である。正電荷が作る電界は電荷から外向き、負電荷が作る電界は電荷へ向かう。

ベクトル式では、電荷位置を `r_Q`、観測点を `r` として

`E(r) = Q/(4πε) · (r-r_Q)/|r-r_Q|³`

と書ける。

電界中に電荷 `q` を置いたとき、その電荷に働く力は

`F = qE`

である。`q<0` なら力の向きは電界と逆向きになる。R8で負電荷の力を扱うときは、この符号を落とさない。

単位は

`E: N/C = V/m`

である。

## 3. 複数の点電荷はベクトルで重ね合わせる

複数の点電荷があるとき、各電荷が作る電界を個別に求め、最後にベクトル和を取る。

`E_total = E1 + E2 + ...`

電界の大きさだけを足し引きしてはいけない。まずx成分、y成分に分解し、

`E_x = ΣE_ix`

`E_y = ΣE_iy`

としてから

`|E| = sqrt(E_x²+E_y²)`

を求める。

例えば、同じ正電荷 `Q` が `(a,0)` と `(-a,0)` にあり、観測点が `(0,b)` にあるとする。各電荷から観測点までの距離は

`R = sqrt(a²+b²)`

で等しい。左右のx成分は打ち消し合い、y成分だけが加算されるため

`E_y = 2 · {Q/(4πεR²)} · b/R`

`= Qb/{2πε(a²+b²)^(3/2)}`

となる。

H30やH21型では、対称性を利用して「どの成分が消えるか」を先に判断すると計算量が減る。

電界が0になる点を求めるときは、最初に向きを確認する。2つの電界が反対向きになる領域だけが候補であり、その後で大きさを等置する。

## 4. 電束・電束密度とガウスの法則

この章では、一様な線形媒質を考え、電束密度 `D [C/m²]` と電界 `E` の関係を

`D = εE`

とする。

ある面 `S` を貫く電束は

`Ψ = ∫_S D·dS`

で表す。閉曲面を外向き法線で積分したとき、ガウスの法則は

`∮_S D·dS = Q_enc`

である。`D=εE` を使えば

`∮_S E·dS = Q_enc/ε`

となる。

ここで数えるのは、閉曲面の内部に含まれる電荷 `Q_enc` だけである。閉曲面の外にある電荷は、その面を出入りする電束へ影響しても、正味の閉曲面電束には寄与しない。

ガウスの法則自体は常に成り立つが、電界を簡単に取り出せるのは対称性が高い場合である。球対称なら球面、無限長線電荷の円筒対称なら同軸円筒をガウス面に選ぶ。

## 5. 球対称の電荷分布

球対称なら、半径 `r` の球面上で電界の大きさ `E(r)` は一定で、向きは半径方向になる。したがって

`E(r) · 4πr² = Q_enc(r)/ε`

より

`E(r) = Q_enc(r)/(4πεr²)`

となる。

重要なのは、`Q_enc(r)` を先に求めることである。

### 5.1 一様な体積電荷を持つ半径aの球

体積電荷密度を `ρ [C/m³]` とする。

球内部 `0≤r<a` では

`Q_enc(r) = ρ · (4/3)πr³`

なので

`E(r) = ρr/(3ε)`

となる。内部では `E∝r` である。

球外部 `r≥a` では包有電荷は球全体の

`Q = ρ · (4/3)πa³`

で一定だから

`E(r) = ρa³/(3εr²)`

となる。外部では `E∝1/r²` である。

### 5.2 一様な体積電荷を持つ球殻

内半径 `a`、外半径 `b` の球殻部分 `a<r<b` に一様な体積電荷密度 `ρ` がある場合を考える。

`r<a` では包有電荷が0なので

`E=0`

である。

`a<r<b` では

`Q_enc(r) = ρ · (4/3)π(r³-a³)`

だから

`E(r) = ρ/(3ε) · (r-a³/r²)`

となる。

`r≥b` では

`Q_enc = ρ · (4/3)π(b³-a³)`

より

`E(r) = ρ(b³-a³)/(3εr²)`

となる。

R4型の領域別問題では、公式を一つ暗記するのではなく、各領域で `Q_enc(r)` を作り直す。

## 6. 円筒対称と無限長線電荷

無限長線電荷の線電荷密度を `λ [C/m]` とする。線電荷と同軸に、半径 `r`、長さ `l` の円筒ガウス面を取る。

電界は円筒側面に垂直で大きさ一定、両端面では電界が面に平行なので正味の電束は側面だけから出る。

包有電荷は

`Q_enc = λl`

円筒側面積は

`2πrl`

だから

`E · 2πrl = λl/ε`

より

`E(r) = λ/(2πεr)`

となる。

電束密度なら

`D(r) = λ/(2πr)`

である。

点電荷の `1/r²` と異なり、無限長線電荷では `1/r` で減少する。R5・H23型で最も重要な違いである。

同軸円筒間の電界も、内側導体の単位長さ当たり電荷を `λ` とみなせば、円筒対称領域で同じ形を使える。したがって `E∝1/r` なので、対象領域では半径が最も小さい側で電界が最大になる。

## 7. 電位・電位差・電位傾度

電位差は、電界に逆らって単位電荷を移動させる仕事に対応する。点Bから点Aまでの電位差は

`V_A - V_B = -∫_B^A E·dl`

である。

一次元・半径方向だけの問題では

`E = -dV/dr`

となる。電位が距離とともに減少する向きへ、正の電界が向く。

点電荷 `Q` について、無限遠を `V(∞)=0` と置ける場合、

`V(r) = Q/(4πεr)`

である。複数点電荷の電位はスカラーなので、各電位を符号付きで加える。

球対称分布でも、まず領域ごとの `E(r)` を求め、境界で電位が連続するように積分する。

一方、無限長線電荷では `E∝1/r` のため、無限遠まで積分すると対数が発散する。この教育用モデルでは無限遠を0 Vにせず、有限の基準半径 `r0` を置いて

`V(r)-V(r0) = -∫_(r0)^r λ/(2πεs) ds`

`= -(λ/(2πε)) ln(r/r0)`

とする。

H23型では、この `1/r` の積分から対数が出ることと、負号を落とさないことが重要である。

## 8. 問題を見たときの解法手順

1. 電荷分布を点電荷、線電荷、体積電荷のどれかに分類する。
2. 電界の方向を先に考える。
3. 球対称・円筒対称があればガウス面を選ぶ。
4. ガウス面内の `Q_enc` を求める。
5. `∮D·dS=Q_enc` または `∮E·dS=Q_enc/ε` から `E` を求める。
6. 対称性が使えない点電荷配置では、各電界を成分分解してベクトル合成する。
7. 力を問われたら `F=qE`。負電荷なら向きが逆になる。
8. 電位を問われたら基準点を確認し、`V_A-V_B=-∫E·dl` を使う。
9. `E [V/m]`、`D [C/m²]`、`ρ [C/m³]`、`λ [C/m]`、`V [V]` の単位を確認する。

## 9. 新幹線への接続

新幹線の25 kV架線の周囲には電界が存在する。ただし、実際の架線系にはトロリ線・ちょう架線・レール・車体・大地等があり、単独の無限長線電荷ではない。

この章では、電験の円筒対称計算を理解するため、架線を無限長線電荷 `λ` とみなす教育用簡略モデルだけを使う。このとき距離 `r` の電界は

`E(r)=λ/(2πεr)`

であり、有限の基準半径 `r0` に対する電位差は

`V(r)-V(r0)=-(λ/(2πε))ln(r/r0)`

である。

ここから「線状の電荷源では距離が増えると電界が `1/r` で弱くなる」という理論を具体化する。実在架線の線電荷密度、電界強度、離隔等は本段階では置かず、以下の例題は教材用仮定値とする。

## 10. 基礎例題 — 点電荷の電界と負電荷に働く力

真空中で、原点に `Q=+3.0 nC` の点電荷がある。x軸正方向へ `r=0.20 m` 離れた点の電界と、その点に `q=-2.0 nC` の電荷を置いたときの力を求める。`1/(4πε0)=8.99×10^9 N·m²/C²` とする。

点電荷が作る電界は

`E = Q/(4πε0r²)`

なので

`E = (8.99×10^9)(3.0×10^-9)/(0.20)²`

`= 6.74×10^2 V/m`

である。`Q>0` なので向きはx軸正方向。

次に

`F=qE`

より

`F = (-2.0×10^-9)(6.74×10^2)`

`= -1.35×10^-6 N`

となる。負号はx軸負方向を表す。

検算: 負電荷に働く力は電界と逆向きなので、方向判定と一致する。

## 11. 本試験標準例題 — 一様な体積電荷を持つ球

真空中に半径 `a=0.10 m`、体積電荷密度 `ρ=6.0×10^-6 C/m³` の一様に帯電した球がある。中心から `r1=0.050 m` と `r2=0.20 m` の点の電界を求める。`ε0=8.854×10^-12 F/m` とする。

### r1は球内部

半径 `r1` のガウス面が包む電荷は

`Q_enc = ρ(4/3)πr1³`

球対称なので

`E·4πr1² = Q_enc/ε0`

したがって

`E(r1)=ρr1/(3ε0)`

`=(6.0×10^-6)(0.050)/(3×8.854×10^-12)`

`=1.13×10^4 V/m`

となる。

### r2は球外部

球全体の電荷を包むので

`Q = ρ(4/3)πa³`

したがって

`E(r2)=ρa³/(3ε0r2²)`

`=(6.0×10^-6)(0.10)³/{3(8.854×10^-12)(0.20)²}`

`=5.65×10^3 V/m`

となる。

内部では `E∝r`、外部では `E∝1/r²` である。R8・R4型では、「球だから常に全電荷を包む」とせず、観測半径ごとに `Q_enc` を作る。

## 12. 複合・ひっかけ例題 — 線電荷の電界と電位差

真空中の無限長線電荷を教育用モデルとし、線電荷密度を `λ=50 nC/m` とする。半径 `r1=0.020 m` と `r2=0.080 m` の位置について、`r2` の電界、`r2` と `r1` の電位差 `V(r2)-V(r1)`、どちらで電界が大きいかを求める。`ε0=8.854×10^-12 F/m` とする。

円筒ガウス面から

`E(r)=λ/(2πε0r)`

である。

`r2=0.080 m` では

`E(r2)=50×10^-9/{2π(8.854×10^-12)(0.080)}`

`=1.12×10^4 V/m`

となる。

電位差は

`V(r2)-V(r1) = -∫_(r1)^(r2) λ/(2πε0r) dr`

`= -(λ/(2πε0))ln(r2/r1)`

`= -{50×10^-9/(2π×8.854×10^-12)}ln(4)`

`≈ -1.25×10^3 V`

である。

また `E∝1/r` なので

`E(r1)=4E(r2)`

となり、電界は小さい半径側 `r1` で大きい。

ひっかけは3点ある。

- 点電荷の `1/r²` を使わない。
- 電位差の積分の負号を落とさない。
- 無限長線電荷では `V(∞)=0` を置かず、有限の基準半径との電位差として扱う。

## 13. 頻出ミス

- 電界をスカラーとして足し引きする。
- 正負電荷で電界方向を逆にするのを忘れる。
- `F=qE` で `q<0` のとき力が電界と逆向きになることを落とす。
- 点電荷の `1/r²` と線電荷の `1/r` を混同する。
- 球面積 `4πr²` と円筒側面積 `2πrl` を取り違える。
- ガウス面の外側の電荷まで `Q_enc` に入れる。
- `ρ [C/m³]` と `λ [C/m]` を混同する。
- `D=εE` と `E` の単位を混同する。
- 電位差の積分で負号を落とす。
- `E=-dV/dr` の負号を落とす。
- 無限長線電荷に対して無限遠を0 Vと置く。
- `ε0` と一般媒質の `ε` を条件確認なしに置き換える。

## 15. 公式・解法まとめ

基本式:

- `F = |Q1Q2|/(4πεr²)`
- `E = Q/(4πεr²)`（点電荷。向きは符号で判断）
- `F = qE`
- `E_total = ΣE_i`（ベクトル和）
- `D = εE`
- `∮D·dS = Q_enc`
- `∮E·dS = Q_enc/ε`
- 球対称: `E(r)=Q_enc(r)/(4πεr²)`
- 一様帯電球内部: `E=ρr/(3ε)`
- 無限長線電荷: `E=λ/(2πεr)`
- `V_A-V_B=-∫_B^A E·dl`
- `E=-grad V`
- 半径方向: `E=-dV/dr`
- 点電荷、`V(∞)=0`: `V=Q/(4πεr)`
- 無限長線電荷: `V(r)-V(r0)=-(λ/(2πε))ln(r/r0)`

解法の順序:

1. 電荷分布と対称性を判定する。
2. 向きを先に決める。
3. 対称性が高ければガウス面を選び、`Q_enc` を求める。
4. 点電荷配置なら成分分解してベクトル合成する。
5. 力は `F=qE` へ接続する。
6. 電位は基準点を確認して電界を積分する。
7. 領域が変わる問題では領域ごとに式を作る。
8. 単位、符号、距離依存 `1/r²` と `1/r` を検算する。
