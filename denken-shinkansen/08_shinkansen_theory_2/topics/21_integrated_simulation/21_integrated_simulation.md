### 5.1 R8 一次 理論 問3 — 5答案要素

1. `(1) = ヨ`。二つのメッシュは共通抵抗 `r` を逆向きに共有するため、`[[R1+R2+r, -r],[-r,R1+R2+r]][Ia,Ib]^T=[E,0]^T`。
2. `(2) = ニ = ER2/(R1+R2)`。二式を加えると `(R1+R2)(Ia+Ib)=E`、したがって a-b 間開放電圧の大きさは `R2(Ia+Ib)=ER2/(R1+R2)`。
3. `(3) = リ = 相反`。線形受動回路で電圧源と応答枝を入れ替える相反定理を用いる。
4. `(4) = ロ = I1'`。電源を枝 ab へ移した図2で、元の電源枝 ac に対応する電流が `I1'`。
5. `(5) = ホ = E/(2R1)`。図2は `R1/R1=R2/R2` でブリッジ平衡し `r` に電流が流れず、左枝電流は `E/(R1+R1)`。

### 5.2 R8 一次 理論 問4 — 5答案要素

1. `(1) = カ = 直角相` ブリッジ。
2. `(2) = ワ = n/(16πRsCx)`。零位条件で `(n/8)U/Rs = 2πfCxU`。
3. `(3) = リ = 100.0 kΩ`。
4. `(4) = ホ = 5`。`Rs = n/(16πfCx)` に `f=1000 Hz, Cx=1 nF` を入れると `n=5` で `Rs≈99.47 kΩ` となり選択肢は `100.0 kΩ`。
5. `(5) = イ = 0.985 nF`。固定した `n=5, Rs=100.0 kΩ` と実平衡周波数 `1010 Hz` から `Cx=5/(16π×100000×1010)=0.98487 nF`。

### 5.3 R8 一次 理論 問6 — 5答案要素

1. `(1) = ト = 0`。S2投入前からRC枝は直流定常で `vC=E` のため、S2投入後もS1が閉じている間はRC枝に過渡電流を生じない。
2. `(2) = ホ = (E/R)(1-exp(-Rt/L))`。S2投入でRL直列枝へEが印加される一次遅れ応答。
3. `(3) = チ = iL(t)=-dq(t)/dt`。S1開放後の上側節点KCLより、RC枝電流とRL枝電流の和が0。
4. `(4) = ヨ = 2RiL + L diL/dt - q/C = 0`。S1開放後の閉ループで二つのRの電圧降下を含めてKVLを立てる。
5. `(5) = リ = (1/2)CE^2 + (1/2)L(E/R)^2`。`t0` が十分大きければ開放直前にCはE、L電流はE/Rであり、開放後の最終状態では蓄積エネルギーが0となるため初期蓄積エネルギー全量が二抵抗で消費される。

### 5.4 H24 一次 機械 問3 (4)(5) — 2答案要素

### 5.5 R2 二次 電力・管理 問6 (1)〜(3) — 4答案要素

## 6. 解説本文

### 6.1 このテーマで電験は何を問うか

Topic 21は新しい理論を追加する章ではない。回路網、交流電力、過渡、高調波、計測を一つの簡略モデルで順に接続し、途中の量を別の論点へ正しく受け渡せるかを確認する総合章である。

試験で必要なのは、ブロック名を覚えることではなく、`回路を等価化する → 電圧・電流をフェーザで求める → P・Q・力率を計算する → スイッチング直後の初期条件を処理する → 非正弦波を次数ごとに分ける → 測定値を基準量と比較する` という解析手順である。

整流器、DCリンク、PWMインバータは簡略モデル中の接続点として扱う。素子の詳細動作、制御則、実車のPWM方式・周波数は本Topicで新たに設定しない。PWM側ではTopic 14で扱った「非正弦周期波を基本波と高調波へ分解する」範囲だけを使う。

### 6.2 簡略モデルと量の受け渡し

各ブロックで見る量を混同しない。

| ブロック | 主に扱う入力 | 主に扱う出力 | 本Topicで使う理論 |
|---|---|---|---|
| 25kV電源・架線等価回路 | 電源電圧、周波数、R/L等 | 負荷側電圧・電流 | KCL/KVL、テブナン等価 |
| 主変圧器までの交流側 | 実効値電圧・電流、位相 | P、Q、S、力率 | フェーザ、複素電力 |
| スイッチングを含むR/L/C部 | R、L、C、初期条件 | 過渡電流・電圧 | 連続条件、微分方程式 |
| PWM波形 | 基本周波数、位相、既知または仮定した波形 | 基本波・高調波・FFT | フーリエ級数、同一次数合成 |
| センサ・測定 | 理想値、標準量、測定器条件 | 測定値、校正値、誤差 | 零位法、校正、誤差評価 |

25kVは系列SPECの簡略モデルに含まれる電源電圧である。それ以外の数値例は、出典付き実値でない限り教材上の仮定値として明記する。

### 6.3 回路網: KCL/KVLからテブナン等価まで

負荷端から見た線形回路は、開放端電圧 `Vth` と等価インピーダンス `Zth` の直列回路へ置き換えられる。

1. 負荷を外し、端子の開放電圧を求めて `Vth` とする。
2. 独立電圧源を短絡、独立電流源を開放し、端子から見た等価インピーダンスを `Zth` とする。
3. 負荷 `ZL` を接続したら `I=Vth/(Zth+ZL)`。
4. 負荷端電圧は `VL=IZL`。

複数閉路があるときは、メッシュ電流を定義してKVLを連立する。二つのメッシュが共通インピーダンスを逆向きに流れるなら、共通項は互いの式で負符号をもつ。R8一次理論問3型では、この符号を落とすと開放端電圧まで誤る。

相反定理は、線形・受動・双方向の回路で、ある枝に置いた一つの電源による別枝の応答と、電源位置と応答位置を入れ替えたときの対応応答が等しくなるという関係である。非線形回路や任意の能動回路へ無条件に拡張しない。

### 6.4 交流量: フェーザからP・Q・力率へ

正弦波定常状態では、電圧と電流を実効値フェーザで扱う。複素電力は

`S = V I* = P + jQ`

である。位相差を `φ=∠V-∠I` とすれば

`P = VI cosφ`

`Q = VI sinφ`

`|S| = VI = sqrt(P^2+Q^2)`

`cosφ = P/|S|`

となる。遅れ無効電力を正とする約束なら、誘導性負荷は `Q>0`、進み補償は `Q` を減らす向きで扱う。

複数負荷では皮相電力の大きさを直接足さない。各負荷の `P` と `Q` をそれぞれ加算し、最後に

`PΣ = ΣPk`

`QΣ = ΣQk`

`SΣ = sqrt(PΣ^2+QΣ^2)`

`pf = PΣ/SΣ`

とする。力率改善容量 `Qc` を入れるなら、補償後は `Q'=QΣ-Qc` として同じ式へ戻る。

### 6.5 過渡: t=0-、0+、∞を分ける

スイッチング問題では、まず三つの時刻を分ける。

- `t=0-`: 切替直前の定常状態。
- `t=0+`: 切替直後。インダクタ電流 `iL` とコンデンサ電圧 `vC` は有限な回路では瞬時に飛ばない。
- `t→∞`: 切替後の新しい直流定常状態。

RL一次回路なら

`i(t)=I∞+(I0-I∞) exp(-t/τ)`

`τ=L/R`

RC一次回路なら

`vC(t)=V∞+(V0-V∞) exp(-t/τ)`

`τ=RC`

である。

RLCでは回路図からKCL/KVLを立て、状態量をそろえて微分方程式を作る。例えば直列の自由応答なら、電荷 `q` を使って

`L d^2q/dt^2 + R dq/dt + q/C = 0`

となる。固定R8問6のように抵抗が二つ直列相当なら、抵抗項は問題の回路に合わせて `2R` になる。一般式を回路図確認なしに当てはめない。

蓄積エネルギーは

`WL = (1/2) L iL^2`

`WC = (1/2) C vC^2`

である。電源切離し後に最終的にエネルギーが0となる回路では、初期蓄積エネルギーと抵抗で消費される総エネルギーを対応させて検算できる。

### 6.6 PWM・高調波: 次数ごとに分けて合成する

非正弦周期波はフーリエ級数で基本波と高調波へ分ける。基本周波数を `f0` とすればn次高調波は

`fn = n f0`

である。

異なる次数は位相ベクトルで直接足さない。同じn次成分だけを同一周波数として合成する。大きさが同じ `An` のn次成分を二つもち、基本波に対する波形全体の位相差が `φ` なら、そのn次成分の位相差は `nφ` となり、合成振幅は

`|Vn| = 2 An |cos(nφ/2)|`

である。基本波は `n=1` なので `2A1|cos(φ/2)|` となる。H24一次機械問3型では、この次数依存の位相差を使って特定高調波が小さくなる条件を判断する。

FFTを使う場合も、FFTの棒グラフだけを正解としない。代表次数は既知のフーリエ係数、同一次数ベクトル合成、または別計算で独立確認する。縦軸が最大値、片振幅、実効値のどれかも明記する。

### 6.7 計測: 理想値と測定値を分ける

測定では、モデルが計算した理想値と、測定器が返す値を分ける。基準値を `x`、測定値を `xm` とすれば、符号付き相対誤差を

`ε = (xm-x)/x`

と定義できる。問題文が別定義を与えた場合はその定義を優先する。

零位法では、検出器の指示値そのものを未知量へ換算するのではなく、検出器両端差が0となる平衡条件から未知量を求める。

固定R8一次理論問4型の直角相ブリッジでは、問題の記号で分圧器出力を `nU/8`、標準抵抗を `Rs`、未知容量を `Cx` とすると、零位条件から

`nU/(8Rs) = 2π f Cx U`

したがって

`f = n/(16π Rs Cx)`

`Cx = n/(16π Rs f)`

となる。これは当該回路の平衡式であり、任意の容量測定へ無条件に流用しない。

### 6.8 一つの解析として解く手順

Topic 21では次の順で処理する。

1. 入力値を実値・計算値・仮定値に分類し、単位をそろえる。
2. 負荷側から見た回路を必要に応じてテブナン等価へ縮約する。
3. 正弦波定常部はフェーザで電圧・電流を求める。
4. `S=VI*` から `P,Q,pf` を計算する。
5. スイッチ切替がある区間は `0- / 0+ / ∞` を分けて初期条件を決める。
6. 非正弦波は基本波と高調波へ分け、同一次数成分だけを合成する。
7. 測定ブロックでは理想値、基準値、測定値を分け、零位・校正・誤差を処理する。
8. 数値プログラムを使う場合は、代表点を手計算または別手法で再計算する。
9. 最後に単位、符号、位相、桁、物理的妥当性を検算する。

### 6.10 頻出ミス・ひっかけ

- 開放端電圧 `Vth` と負荷接続後の端子電圧を混同する。

## 7. 3段階例題

以下の数値は、25kV電源を除いて教材上の仮定値であり、実車・East iの内部仕様ではない。

### 7.1 基礎例題: 架線等価回路からP・Qまで

25.0 kV実効値の教育用電源をテブナン等価し、`Vth=25.0 kV∠0°`、`Zth=1+j1 Ω` とする。負荷を `ZL=24+j18 Ω` としたとき、負荷電流、負荷端電圧、有効電力、無効電力、力率を求める。

合成インピーダンスは

`Z = Zth+ZL = 25+j19 Ω`

だから

`I = 25000/(25+j19)`

`= 633.9-j481.7 A`

`= 796.2∠-37.2° A`

となる。

負荷端電圧は

`VL = IZL`

`= (633.9-j481.7)(24+j18)`

`= 23884-j152 V`

したがって `|VL|≈23.885 kV`。

複素電力は

`SL = VL I*`

`≈ 15.213+j11.410 MVA`

なので

`P≈15.213 MW`

`Q≈11.410 Mvar`

`pf=P/|S|=0.800` 遅れである。

解法順は `等価回路 → I → VL → S=VI* → P,Q,pf` である。電源25kVと負荷端電圧を同じ値として扱わない。

### 7.2 本試験標準例題: 複数負荷と力率改善

教育用設備に、負荷1 `P1=4.0 MW, pf1=0.8遅れ`、既設進み補償 `1.0 Mvar`、負荷2 `P2=3.0 MW, pf2=0.6遅れ` がある。設備容量は `8.5 MVA` とする。新たな進み補償 `Qc` を追加するとき、容量を超えないための最小 `Qc` と、そのときの総合力率を求める。さらに総合力率を0.95遅れにする `Qc` も求める。

負荷1の無効電力は

`Q1 = 4.0 tan(cos^-1 0.8) = 3.0 Mvar`

既設補償後は `2.0 Mvar`。

負荷2は

`Q2 = 3.0 tan(cos^-1 0.6) = 4.0 Mvar`

だから、追加補償前の合計は

`PΣ=7.0 MW`

`QΣ=6.0 Mvar`

である。

設備容量8.5 MVAで許される遅れ無効電力の最大値は

`Qmax=sqrt(8.5^2-7.0^2)=4.822 Mvar`

したがって最小補償量は

`Qc,min=6.0-4.822=1.178 Mvar`

このとき容量境界上なので

`pf=7.0/8.5=0.824` 遅れ。

総合力率0.95遅れにする場合の残留無効電力は

`Qtarget=7.0 tan(cos^-1 0.95)=2.301 Mvar`

したがって

`Qc=6.0-2.301=3.699 Mvar`

である。

皮相電力の大きさを各負荷ごとに足すのではなく、PとQを別々に合算してから最終Sを作る。

### 7.3 複合・ひっかけ例題: 過渡・高調波・校正を別々に検算する

同じ教育用シミュレーションの三つの出力を独立検算する。

A. RL過渡: `E=100 V, R=2 Ω, L=0.5 H, i(0)=0`。投入後 `t=0.25 s` の電流を求める。

`τ=L/R=0.25 s`

`I∞=E/R=50 A`

`i(0.25)=50(1-exp(-1))=31.6 A`

となる。

B. 高調波: 同じ大きさの二つの波形成分を合成する。各ユニットの基本波振幅を `A1=100 V`、5次振幅を `A5=20 V`、波形全体の位相差を `φ=π/6` とする。

基本波合成振幅は

`2A1 cos(φ/2)=200 cos(π/12)=193.2 V`

5次は位相差が `5φ` なので

`2A5 |cos(5φ/2)|=40|cos(5π/12)|=10.35 V`

となる。5次でも位相差を `φ` のまま使うのが典型的な誤りである。

C. 校正: R8型の教育用直角相ブリッジで `n=4, Rs=100 kΩ`、零位周波数 `f=800 Hz` とする。未知容量は

`Cx=n/(16πRsf)`

`=4/{16π×100000×800}`

`=0.9947 nF`

となる。

三つの出力は同じ「シミュレーション結果」として表示されても、検算式はそれぞれ別である。過渡を定常交流式で確認したり、高調波を平均値だけで確認したり、校正値を零位条件なしに換算しない。
