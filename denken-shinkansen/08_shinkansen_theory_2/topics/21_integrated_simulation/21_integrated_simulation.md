公式標準解答・保存済み正答を参照せず、固定5問を問題文から独立再解答した。以下は公式照合前に確定した候補答案である。

### 5.1 R8 一次 理論 問3 — 5答案要素

1. `(1) = ヨ`。二つのメッシュは共通抵抗 `r` を逆向きに共有するため、`[[R1+R2+r, -r],[-r, R1+R2+r]][Ia,Ib]^T=[E,0]^T`。
2. `(2) = ニ = ER2/(R1+R2)`。二式を加えると `(R1+R2)(Ia+Ib)=E`、したがって a-b 間開放電圧の大きさは `R2(Ia+Ib)=ER2/(R1+R2)`。
3. `(3) = リ = 相反`。線形受動回路で電圧源と応答枝を入れ替える相反定理を用いる。
4. `(4) = ロ = I1'`。電源を枝 ab へ移した図2で、元の電源枝 ac に対応する電流が `I1'`。
5. `(5) = ホ = E/(2R1)`。図2は `R1/R1=R2/R2` でブリッジ平衡し `r` に電流が流れず、左枝電流は `E/(R1+R1)`。

### 5.2 R8 一次 理論 問4 — 5答案要素

1. `(1) = カ = 直角相` ブリッジ。
2. `(2) = ワ = n/(16πRsCx)`。零位条件で `(n/8)U/Rs = 2πfCxU`。
3. `(3) = リ = 100.0 kΩ`。
4. `(4) = ホ = 5`。`Rs = n/(16πfCx)` に `f=1000 Hz, Cx=1 nF` を入れると `n=5` で `Rs≈99.47 kΩ` となり選択肢は `100.0 kΩ`。
5. `(5) = イ = 0.985 nF`。固定した `n=5, Rs=100.0 kΩ` と実平衡周波数 `1010 Hz` から `Cx=5/(16π×100000×1010)=0.98487 nF`。

### 5.3 R8 一次 理論 問6 — 5答案要素

1. `(1) = ト = 0`。S2投入前からRC枝は直流定常で `vC=E` のため、S2投入後もS1が閉じている間はRC枝に過渡電流を生じない。
2. `(2) = ホ = (E/R)(1-exp(-Rt/L))`。S2投入でRL直列枝へEが印加される一次遅れ応答。
3. `(3) = チ = iL(t)=-dq(t)/dt`。S1開放後の上側節点KCLより、RC枝電流とRL枝電流の和が0。
4. `(4) = ヨ = 2RiL + L diL/dt - q/C = 0`。S1開放後の閉ループで二つのRの電圧降下を含めてKVLを立てる。
5. `(5) = リ = (1/2)CE^2 + (1/2)L(E/R)^2`。`t0` が十分大きければ開放直前にCはE、L電流はE/Rであり、開放後の最終状態では蓄積エネルギーが0となるため初期蓄積エネルギー全量が二抵抗で消費される。

### 5.4 H24 一次 機械 問3 (4)(5) — 2答案要素

1. `(4) = ヲ = π/6 rad`。n次成分の合成振幅は `2A_n cos(nφ/2)`。`φ=π/6` では5次・7次とも振幅係数の絶対値が `2|cos(5π/12)| = 2|cos(7π/12)|` となり大幅に低減する。
2. `(5) = ル = 2倍未満`。基本波合成振幅は単一ユニットの `2cos(φ/2)=2cos(π/12)<2` 倍。

### 5.5 R2 二次 電力・管理 問6 (1)〜(3) — 4答案要素

1. `(1) Q2最小 = 約2691 kvar`。既設負荷は `Qload1=6000 tan(cos^-1 0.8)=4500 kvar`、既設コンデンサ後は `Q=4500-2000=2500 kvar`。増設負荷は `Qload2=4500 tan(cos^-1 0.6)=6000 kvar`。総有効電力 `P=10500 kW` に対し変圧器容量12000 kVAを超えない最大遅れ無効電力は `sqrt(12000^2-10500^2)=5809.5 kvar`。よって `Q2=8500-5809.5=2690.5 kvar`。
2. `(1) 総合力率 cosθS = 0.875（遅れ）`。最小容量時は `S=12000 kVA` の境界なので `10500/12000=0.875`。
3. `(2) ベクトル図・θ2`。増設負荷は `P2=4500 kW` を右向き、`Qload2=6000 kvar` を遅れ方向、`θ2=cos^-1(0.6)=53.13°`。力率改善コンデンサ `Q2≈2691 kvar` は無効電力を逆方向へ戻し、合成点を `PT=12000 kVA` 円上へ置く。
4. `(3) Q2 = 約5049 kvar`。総合力率0.95遅れに必要な残留無効電力は `Qtarget=10500 tan(cos^-1 0.95)=3451.2 kvar`。したがって `Q2=8500-3451.2=5048.8 kvar`。
