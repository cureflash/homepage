# 問題

## 基礎

### 問1 テブナン等価回路の負荷電流

教育用等価回路で Vth=100 V、Rth=2.0 Ω、負荷 RL=8.0 Ω とする。負荷電流 I、負荷端電圧 VL、負荷消費電力 P の組合せとして正しいものを選べ。

1. 10 A / 80 V / 800 W
2. 8 A / 80 V / 640 W
3. 10 A / 100 V / 1.0 kW
4. 12.5 A / 100 V / 1.25 kW
5. 8 A / 64 V / 512 W

### 問2 複素電力と力率

単相交流の教育用負荷に、V=2.00 kV、I=100 A（いずれも実効値）、電流は電圧より36.87°遅れるとする。有効電力 P、無効電力 Q、力率の組合せとして正しいものを選べ。

1. 160 kW / 120 kvar / 0.80遅れ
2. 200 kW / 0 kvar / 1.00
3. 120 kW / 160 kvar / 0.60遅れ
4. 160 kW / -120 kvar / 0.80進み
5. 250 kW / 150 kvar / 0.80遅れ

### 問3 測定値と相対誤差

基準値 x=10.00 A を測定したところ xm=9.80 A であった。誤差 e=xm-x、相対誤差 ε=e/x と定義する。e と ε の組合せとして正しいものを選べ。

1. -0.20 A / -2.0 %
2. +0.20 A / +2.0 %
3. -0.20 A / +2.0 %
4. +0.20 A / -2.0 %
5. -2.0 A / -20 %

### 問7 スイッチング直後の連続条件とエネルギー

1. vC(0+)=100 V、iL(0+)=5 A、iL=-dq/dt、2RiL+L diL/dt-q/C=0、初期蓄積6.75 J
2. vC(0+)=0 V、iL(0+)=0 A、iL=dq/dt、RiL+L diL/dt+q/C=0、初期蓄積0 J
3. vCは連続だがiLは0へ飛ぶ、2RiL-L diL/dt-q/C=0、初期蓄積0.50 J

5. vCとiLは任意に不連続、式は定常交流のインピーダンスだけで決まる

### 問11 総合シミュレーションの検算順序

25kV電源から測定までの教育用簡略モデルを検算する。最も適切な手順を選べ。

1. 入力条件・単位・仮定を固定 → 回路等価化でV/I → フェーザからP/Q/pf → スイッチング前後の初期条件で過渡 → 同一次数ごとに高調波合成 → 理想値と測定値を分けて校正・誤差確認
2. FFTだけを先に実行 → 実車PWM周波数を推定 → その値を真値として全計算へ流用
3. 測定値を真値とみなす → 力率を|S|の単純加算で計算 → 過渡は定常インピーダンスで代用
4. 実車East i内部回路を推測 → 未公開センサ帯域を設定 → 公開値として扱う
5. 回路・交流・過渡・高調波を一つの式にまとめ、各段階の単位と初期条件を省略する

### 問12 二次記述型 - P-Qベクトルと力率改善

(1) 容量11.0 MVAを超えないための最小 Qc。
(2) (1)のときの総合力率。
(3) 負荷2のP-Qベクトルの角度 θ2 と、進み補償を加えたときのベクトルの動き。
(4) 総合力率を0.95遅れにする Qc。

# 解答・完全解説

選択式は正答番号だけでなく、使用式・選択理由・代表的な誤りを示す。記述式は途中式・単位・理由説明まで採点可能な形にする。

## 問1 正答: 1

I=Vth/(Rth+RL)=100/(2+8)=10 A。VL=IRL=80 V、P=I^2 RL=800 W。Vth は開放端電圧であり、負荷接続後の端子電圧 VL と同一ではない。

## 問2 正答: 1

P=VIcosφ=2000×100×0.8=160 kW、Q=VIsinφ=2000×100×0.6=120 kvar。遅れ負荷を Q>0 とする符号規約では S=P+jQ。複素電力は S=VI* で求め、I の共役を落とさない。

## 問3 正答: 1

e=9.80-10.00=-0.20 A、ε=-0.20/10.00=-0.020=-2.0 %。シミュレーションの理想値と測定値は分けて扱い、誤差の符号定義は問題文に従う。

## 問4 正答: 1

開放時は分圧より Vth=120×6/(4+6)=72 V。独立電圧源を短絡して Rth=R1||R2=2.4 Ω。したがって IL=72/(2.4+9.6)=6.0 A、VL=6.0×9.6=57.6 V。開放端電圧を負荷接続後もそのまま端子電圧としない。

## 問5 正答: 1

Q1=4.0 tan(cos^-1 0.8)=3.0 Mvar、Q2=3.0 tan(cos^-1 0.6)=4.0 Mvar。進み補償2.0 Mvarを差し引き Q=5.0 Mvar、P=7.0 MW。|S|=sqrt(7^2+5^2)=8.60 MVA、pf=7/8.60=0.814遅れ。各負荷の |S| を直接足さない。

## 問6 正答: 3

時定数 τ=L/R=0.30/6.0=0.050 s、定常値 I∞=E/R=20 A。i(t)=I∞+(I0-I∞)exp(-t/τ)=20(1-e^-1)=12.64 A。初期値・定常値・時定数の順で整理する。

## 問7 正答: 1

コンデンサ電圧とコイル電流は瞬時に飛ばないので vC(0+)=100 V、iL(0+)=5 A。向きの定義から iL=-dq/dt。閉ループには抵抗が2個あるため 2RiL+L diL/dt-q/C=0。初期エネルギーは (1/2)CV^2+(1/2)LI^2=0.5+6.25=6.75 J。切替前にCが電源電圧まで定常充電され、別枝投入で端子電圧が変わらないなら新しいRC過渡は生じない。

## 問8 正答: 1

Rs=n/(16πfCx)=99.47 kΩなので100.0 kΩを選べる。nは5。実平衡値では Cx=5/(16π×100000×1010)=0.9849 nF。零位法では検出器が零となる条件から未知量を逆算するので、周波数変化を無視しない。

## 問9 正答: 1

n次成分の位相差は nφ。基本波は2A1 cos(φ/2)=193.2 V。5次は位相差5φ=5π/6で、合成振幅は2A5|cos(5φ/2)|=40|cos(5π/12)|=10.35 V。異なる次数を同じフェーザとして足さない。

## 問10 正答: 1

共通抵抗を逆向きに通る二メッシュでは相互項は-r。線形・双方向回路で源と応答位置を交換する関係は相反定理であり、交換後は元の電源枝に現れる対応応答を読む。抵抗ブリッジが比率条件を満たして平衡すれば検出器枝電流は0。

## 問11 正答: 1

Topic 21は新論点を追加せず、既習の回路→交流→過渡→高調波→計測を順に接続する総合章である。各ブロックの入力・出力を分け、実車未公開値は真値化しない。代表点は手計算または別手法で独立検算する。

## 問12 正答: 記述

Q1=5.0 tan(cos^-1 0.8)=3.75 Mvar、既設補償後は2.75 Mvar。Q2=4.0 tan(cos^-1 0.6)=5.333 Mvar。したがって PΣ=9.0 MW、追加補償前QΣ=8.083 Mvar。設備容量11.0 MVAで許される遅れ無効電力は Qmax=sqrt(11.0^2-9.0^2)=6.325 Mvar なので、(1) Qc,min=8.083-6.325=1.759 Mvar（進み）。(2) 容量境界上では pf=9.0/11.0=0.818遅れ。(3) θ2=cos^-1(0.6)=53.13°。Pを右向き、遅れQを上向きとすれば負荷2は (4.0,5.333) の方向、進み補償はQを下向きへ減らして合成ベクトルをP軸へ近づける。(4) 0.95遅れで残すQは 9.0 tan(cos^-1 0.95)=2.958 Mvar。よって Qc=8.083-2.958=5.125 Mvar（進み）。
