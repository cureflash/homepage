## 1. R8 一次 理論 問3 — 回路網・テブナン・相反定理

完成教材の「メッシュ共通枝は相互項を負符号にする」「線形受動回路では相反定理を使える」を用いて再導出した。

1. 共通抵抗 `r` を二つのメッシュが逆向きに共有するため、閉路方程式は
   `[[R1+R2+r,-r],[-r,R1+R2+r]][Ia,Ib]^T=[E,0]^T`。よって `(1)=ヨ`。
2. 二式を加えると `(R1+R2)(Ia+Ib)=E`。a-b間開放電圧は `R2(Ia+Ib)=ER2/(R1+R2)`。よって `(2)=ニ`。
3. 電源位置と応答枝を入れ替えるので相反定理。よって `(3)=リ`。
4. 図2で元の電源枝acに対応する電流は `I1'`。よって `(4)=ロ`。
5. 図2は `R1/R1=R2/R2` の平衡ブリッジとなり中央枝に電流が流れない。左枝電流は `E/(2R1)`。よって `(5)=ホ`。

再答案: `ヨ / ニ / リ / ロ / ホ`。

## 2. R8 一次 理論 問4 — 零位法・静電容量校正

完成教材の直角相ブリッジ平衡式

`nU/(8Rs)=2πfCxU`

から

`f=n/(16πRsCx)`

を再導出した。

- `(1)=カ` 直角相ブリッジ
- `(2)=ワ` `n/(16πRsCx)`
- `f=1000 Hz, Cx=1 nF` では `Rs≈19.894n kΩ` なので `n=5` のとき `Rs≈99.47 kΩ`。したがって `(3)=リ` 100.0 kΩ、`(4)=ホ` 5
- `f=1010 Hz` では `Cx=5/(16π×100000×1010)=0.98487 nF`。よって `(5)=イ` 0.985 nF

再答案: `カ / ワ / リ / ホ / イ`。

## 3. R8 一次 理論 問6 — RC・RL・RLC過渡

完成教材の `0- / 0+ / ∞`、インダクタ電流・コンデンサ電圧の連続性、KCL/KVL、蓄積エネルギーを用いて再導出した。

1. S2投入前からコンデンサは直流定常で `vC=E`。S1が閉じている `0≤t<t0` では `iC=0`。よって `(1)=ト`。
2. RL枝は直流ステップ応答なので `iL=(E/R)(1-exp(-Rt/L))`。よって `(2)=ホ`。
3. S1開放後は上側節点KCLから `iL=-dq/dt`。よって `(3)=チ`。
4. 二つの抵抗を含む閉ループのKVLは `2RiL+L diL/dt-q/C=0`。よって `(4)=ヨ`。
5. `t0` が十分大きければ開放直前に `vC=E, iL=E/R`。最終的に蓄積エネルギー0なので抵抗消費エネルギーは `(1/2)CE^2+(1/2)L(E/R)^2`。よって `(5)=リ`。

再答案: `ト / ホ / チ / ヨ / リ`。

## 4. H24 一次 機械 問3 (4)(5) — 高調波合成

同じn次成分二つの位相差が `nφ` になることから、合成振幅は

`2An|cos(nφ/2)|`

である。

- `φ=π/6` では5次・7次とも `2|cos(5π/12)|=2|cos(7π/12)|≈0.5176` となり大幅に低減する。よって `(4)=ヲ`。
- 基本波は `2cos(π/12)=1.9319<2`。よって `(5)=ル`。

再答案: `ヲ / ル`。

## 5. R2 二次 電力・管理 問6 (1)〜(3) — P・Q・力率改善

負荷1:

`Q1load=6000 tan(cos^-1 0.8)=4500 kvar`

負荷2:

`Q2load=4500 tan(cos^-1 0.6)=6000 kvar`

既設コンデンサ `2000 kvar` を差し引く前の負荷無効電力合計は `10500 kvar`、既設補償後は `8500 kvar`。総有効電力は `P=10500 kW`。

### (1) 変圧器を過負荷にしない最小追加コンデンサ

変圧器容量 `12000 kVA` の境界で許容残留無効電力は

`sqrt(12000^2-10500^2)=5809.5 kvar`。

したがって

`Q2=8500-5809.5=2690.5 kvar`

であり、答案は約 `2700 kvar`。

総合力率は

`10500/12000=0.875`（遅れ）。

### (2) P-Qベクトル

増設負荷は `P2=4500 kW` を有効電力正方向、`Q2load=6000 kvar` を遅れ無効電力正方向へ置き、`θ2=cos^-1(0.6)=53.13°`。追加コンデンサは無効電力を逆方向へ減算し、最小補償時の合成点を `|S|=12000 kVA` の境界へ置く。

### (3) 総合力率0.95遅れ

必要な残留無効電力は

`Qtarget=10500 tan(cos^-1 0.95)=3451.2 kvar`。

したがって

`Q2=8500-3451.2=5048.8 kvar`

であり、答案は約 `5050 kvar`。

再答案4要素: `2700 kvar / 0.875遅れ / P-Qベクトル・θ2=53.13° / 5050 kvar`。
