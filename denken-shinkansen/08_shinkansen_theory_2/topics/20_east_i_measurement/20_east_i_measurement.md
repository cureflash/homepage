## 8. 解説本文

### 8.1 このテーマで電験は何を問うか

本Topicは二種一次「理論」の電気・電子計測を扱う。中心は、測定値の誤差をどう評価するか、零位法・ブリッジで未知量をどう基準量と比較するか、計器自身の内部抵抗・容量が測定対象をどう乱すか、波形をどう読み、連続信号をどう標本化するかである。

固定過去問では、零位検出、複素インピーダンス平衡、寄生容量、プローブ補償、電圧計・電流計の負荷効果まで問われる。したがって「公式を知っている」だけでは足りず、`測定対象確認 → 等価回路化 → 基準・平衡条件 → 誤差評価 → 指示値または未知量` の順で式を組み立てる必要がある。

### 8.2 測定誤差・絶対誤差・相対誤差

真値または基準値を `x`、測定値を `xm` とする。符号付き誤差を

`e = xm - x`

と定義するなら、`e>0` は高め、`e<0` は低めに測ったことを表す。問題文が逆向きの定義を与えた場合は、その定義を優先する。

絶対誤差は

`Δ = |xm-x| = |e|`

であり、元の量と同じ単位をもつ。相対誤差は

`δ = e/x`

で、百分率表示なら

`δ[%] = 100 e/x`

である。大きさだけを問う場合は `|δ|` を使う。

精度・許容誤差は問題文の仕様をそのまま式へ落とす。例えば「フルスケール `XFS` の±`p`%」なら許容絶対誤差は

`±(p/100)XFS`

である。「指示値の±`p`%」なら基準は `XFS` ではなくその指示値である。精度を有効数字の桁数と同一視しない。

### 8.3 有効数字

測定結果は、元データの精度を超える桁まで残さない。乗除では原則として有効数字の最も少ない量に合わせ、加減では原則として最も粗い小数位に合わせる。途中計算では丸めを遅らせ、最終段階で必要桁へ丸める。

例えば `12.4×3.1=38.44` でも、入力の少ない方が2桁なら結果は2有効数字の `38` とする。計算機が多くの桁を表示しても、それ自体は精度が高いことを意味しない。

### 8.4 零位法とブリッジの基本

ブリッジは、検出器に電流が流れない零位を作り、未知量を既知標準と比較する測定法である。検出器が零なら、その両端の電位は等しい。

電源をA-C間、検出器をB-D間に接続し、腕を `AB=Z1`、`BC=Z2`、`AD=Z3`、`DC=Z4` と定義する。平衡時は `VB=VD` だから

`Z1 Z4 = Z2 Z3`

となる。直流抵抗ブリッジなら `Zi=Ri` として未知抵抗を求める。交流ブリッジでは `Zi` が複素数なので、この複素方程式を満たすには大きさだけでなく位相条件も必要になる。実部・虚部をそれぞれ一致させてもよい。

零位法の利点は、検出器の指示値そのものを量へ換算するのではなく、零になる条件から標準量との比を求める点にある。

### 8.5 校正・インピーダンス比較の解き方

固定R7一次理論問4型では、誘導分圧器の全電圧を `E`、タップ比を `k`、標準インピーダンスを `Zs`、未知インピーダンスを `Zx` とすると、二枝の印加電圧が `(1-k)E` と `kE` になる。検出器零では枝電流が等しいので

`(1-k)E/Zs = kE/Zx`

したがって

`Zx/Zs = k/(1-k)`

である。重要なのは、分圧比を暗記するのではなく「零位 → 枝電流一致 → 複素インピーダンス比」の順に組み立てることである。

固定R8一次理論問4型の直角相ブリッジでは、90°位相差をもつ信号を用い、標準抵抗枝と未知容量枝の電流を零位で一致させる。問題の記号で誘導分圧器出力を `nU/8`、標準抵抗を `Rs`、未知容量を `Cx` とすれば

`nU/(8Rs) = ω Cx U`

より

`f = n/(16π Rs Cx)`

となる。周波数や分圧設定を調整して零位を得た後、この関係から未知容量を逆算する。これは当該回路に対する式であり、一般の容量測定へ無条件に流用しない。

### 8.6 寄生成分と交流ブリッジの誤差

実回路では配線や端子と大地の間に寄生容量ができ、理想ブリッジにはない漏れ電流が流れる。すると本来の枝電流関係が崩れ、理想平衡式だけで求めた未知量に誤差が入る。

固定R6一次理論問6型では、増幅器条件を `Vb=-A Vd`、検出器側を `Vd=Xd Id`、さらに `Vd-Vb=Z2 I2` と置くと

`Id/I2 = Z2/{(A+1)Xd}`

となる。`A` が十分大きければ検出器側へ流れる電流の影響を小さくでき、理想平衡へ近づく。補償やガードは、このような非理想な漏れ経路が測定結果へ入るのを抑えるために使う。

同問題のマクスウェルブリッジ型では

`Z2 = R2/(1+jωC2R2)`

を用い、平衡から

`Zx = (R1R3/R2)(1+jωC2R2)`

となるので

`Rx = R1R3/R2`

`Lx = C2R1R3`

を得る。交流ブリッジでは「抵抗分だけ」「リアクタンス分だけ」を片方しか合わせないのではなく、複素式全体を満たす必要がある。

### 8.7 電圧計・電流計の負荷効果と接続法

理想電圧計の入力抵抗は無限大、理想電流計の内部抵抗は0だが、実計器では有限値をもつ。そのため計器を接続したこと自体で回路状態が変化する。

固定H20一次理論問6型の一方の接続では、電流計が負荷電流と電圧計電流の和を読む。負荷抵抗を `R`、電圧計入力抵抗を `Rp`、電圧計指示を `Vm` とすると

`Im = Vm/R + Vm/Rp`

`Pm = Vm Im`

真の負荷電力 `Pt=Vm^2/R` に対する相対誤差は

`εa = (Pm-Pt)/Pt = R/Rp`

となる。

もう一方の接続では、電圧計が負荷と電流計内部抵抗 `Rc` の合計電圧を読む。電流計指示を `Im` とすると

`Vm = Im(R+Rc)`

`Pm = Im^2(R+Rc)`

`Pt = Im^2R`

より

`εb = Rc/R`

である。したがって `εa<εb` なら前者、`εb<εa` なら後者の方が誤差が小さい。この二式では境界が

`R = √(Rc Rp)`

となる。接続法を名前で暗記せず、どの計器の消費分が指示値へ混ざるかを等価回路から確認する。

### 8.8 波形計測とオシロスコープの読み方

オシロスコープでは縦軸感度と時間軸を別々に読む。縦軸感度を `Sv [V/div]`、波形の縦幅を `Nv [div]` とすれば、プローブ倍率を `Kp` として

`Vpp = Nv Sv Kp`

である。上下対称の正弦波なら `Vp=Vpp/2`、さらに

`Vrms = Vp/√2`

だが、`Vrms=Vp/√2` は正弦波に限る。

時間軸を `St [s/div]`、1周期の横幅を `Nt [div]` とすれば

`T = Nt St`

`f = 1/T`

である。振幅・実効値・周期・周波数を混同しない。

### 8.9 オシロスコープ入力とプローブ補償

プローブを付けると、プローブ抵抗・容量とオシロスコープの入力抵抗・入力容量で周波数依存の分圧回路ができる。固定H24一次理論問7型の記号で、プローブ側を `R1,C1`、オシロスコープ入力側を `R2,C2+C3` とする。

直流の10:1減衰なら

`R2/(R1+R2)=1/10`

なので `R1=9R2` である。

周波数が変わっても同じ減衰比にするには、抵抗分圧比と容量分圧比を一致させる必要があり、同問題の等価回路では

`C1R1 = (C2+C3)R2`

という時定数一致条件になる。補償容量 `C3` はこの式から求める。抵抗だけで10:1になっていても、時定数が合わなければ波形は周波数によって歪む。

### 8.10 A/D変換

A/D変換は、連続時間・連続値のアナログ信号をディジタル値へ移す過程として

`標本化 → 量子化 → 符号化`

に分けて考える。

標本化では時間を離散化し、量子化では振幅を有限個の段階へ丸め、符号化ではその段階をビット列で表す。理想一様 `N` bit ADCで入力範囲の幅を `Vspan` とすれば、量子化幅は

`q = Vspan/2^N`

である。最近傍へ丸める理想量子化なら量子化誤差の大きさは最大でおおむね `q/2` となる。これは一般的な教育用モデルであり、East iの実際のADC分解能を示すものではない。

### 8.11 サンプリング周期・標本化定理・エイリアシング

サンプリング周期を `Ts`、サンプリング周波数を `fs` とすると

`fs = 1/Ts`

である。

最高周波数成分を `fmax` とする帯域制限信号を理想的に復元するには、標本化定理より

`fs > 2 fmax`

が必要である。境界を等号で扱うかは問題設定に従う。`fs/2` をナイキスト周波数と呼ぶ。

入力成分がナイキスト周波数を超えると、サンプル列では低い周波数へ折り返して見える。単一正弦波なら、整数 `k` を選んで

`falias = |f - k fs|`

が `0 ≤ falias ≤ fs/2` に入る値を取ればよい。例えば `fs=10 kHz` で `f=7.2 kHz` を標本化すると

`falias = |7.2-10| = 2.8 kHz`

となる。標本化前に不要な高周波成分を十分抑えないと、サンプリング後のデータだけから元の周波数を区別できない。

### 8.12 計測問題の共通解法

固定一次5問は、次の順で整理する。

1. 何を測るか、何が基準量かを確認する。
2. 計器・ブリッジ・プローブを含む等価回路を描く。
3. 零位条件、分圧比、時定数一致など、その回路の基準条件を立てる。
4. 非理想要素として内部抵抗、入力容量、寄生容量を式へ入れる。
5. 指示値または未知量を求める。
6. 真値・基準値と比較し、必要なら誤差率を求める。
7. ディジタル計測では `Ts↔fs`、ナイキスト周波数、エイリアシングを確認する。
8. 単位、位相、桁、有効数字を検算する。

### 8.14 頻出ミス・ひっかけ

- 誤差の符号を確認せず、`xm-x` と `x-xm` を取り違える。
- 絶対誤差と相対誤差を同じ単位で扱う。
- フルスケール%と指示値%を取り違える。
- 計算機の表示桁をそのまま有効数字として残す。
- ブリッジ平衡を大きさだけで判定し、交流回路の位相条件を落とす。
- 零位で「電圧が0」なのは検出器両端差であり、各枝の電圧・電流がすべて0だと考える。
- 寄生容量を無視した理想式を、寄生成分を明示した問題へそのまま使う。
- 電圧計・電流計自身の消費電力を負荷の真値に含める。
- 10:1プローブで抵抗比だけ合わせ、RC時定数一致を忘れる。
- `Vpp`、`Vp`、`Vrms` を混同する。
- `Ts` と `fs` を同じ向きに変化すると考える。
- `fs>2fmax` を満たさないのに、サンプル列から元周波数を一意に復元できると考える。
- A/D・サンプリングに直接対応する固定過去問がないのに、存在しない年度・問番号を作る。

### 8.16 公式・解法まとめ

- 符号付き誤差: `e=xm-x`
- 絶対誤差: `Δ=|xm-x|`
- 相対誤差: `δ=e/x`、百分率は `100e/x`
- ブリッジ平衡: `Z1Z4=Z2Z3`
- R7型インピーダンス比較: `Zx/Zs=k/(1-k)`
- R8型容量校正: `f=n/(16πRsCx)`
- H20型接続誤差: `εa=R/Rp`、`εb=Rc/R`
- 正弦波: `Vrms=Vp/√2`
- 周期・周波数: `f=1/T`
- H24型プローブ補償: `C1R1=(C2+C3)R2`
- 理想一様ADC量子化幅: `q=Vspan/2^N`
- サンプリング: `fs=1/Ts`
- 標本化定理: `fs>2fmax`
- ナイキスト周波数: `fs/2`
- エイリアス: `falias=|f-kfs|` を `0〜fs/2` に入るよう `k` を選ぶ
- 共通手順: `測定対象確認 → 等価回路化 → 基準・平衡条件 → 誤差評価 → 指示値/未知量`

## 9. 3段階例題

以下の数値はすべて教材上の仮定値であり、East iの実機値ではない。

### 9.1 基礎例題: 誤差・相対誤差・有効数字

基準電圧 `x=100.0 V` を測定したところ `xm=99.2 V` だった。符号付き誤差、絶対誤差、相対誤差を求める。また、別の測定で `12.4 V` と `3.1 A` を得たとき、その積を有効数字に合わせて表せ。

符号付き誤差は

`e = xm-x = 99.2-100.0 = -0.8 V`

絶対誤差は

`Δ = |e| = 0.8 V`

相対誤差は

`δ = -0.8/100.0 = -0.008`

したがって `-0.8 %` である。

積は計算上

`12.4×3.1 = 38.44`

だが、乗算では有効数字の少ない `3.1` の2桁に合わせ、`38` と表す。計算機の余分な桁を測定精度と混同しない。

### 9.2 本試験標準例題: 零位校正から未知容量を求める

固定R8型と同じ教育用回路で、誘導分圧器出力を `nU/8`、標準抵抗を `Rs`、未知容量を `Cx` とする。`n=4`、`Rs=100 kΩ` とし、零位となる周波数が `800 Hz` だった。`Cx` を求める。

零位では標準抵抗枝と未知容量枝の電流が一致するので

`nU/(8Rs)=ωCxU`

である。`ω=2πf` より

`Cx = n/(16πRs f)`

`= 4/{16π×100×10^3×800}`

`= 9.947×10^-10 F`

したがって

`Cx ≒ 0.995 nF`

となる。解法は「零位条件を立てる → 共通電圧 `U` を消す → 周波数を角周波数へ変換する → 未知容量について解く」の順である。

### 9.3 複合・ひっかけ例題: プローブ補償とエイリアシング

教育用の10:1プローブで、オシロスコープ入力抵抗 `R2=1.0 MΩ`、入力容量 `C2=15 pF`、プローブ側容量 `C1=8 pF` とする。補償容量を `C3` とする。また、この測定系で `7.2 kHz` の正弦波を `fs=10 kHz` で標本化する。

まず直流10:1減衰より

`R2/(R1+R2)=1/10`

なので

`R1=9.0 MΩ`

である。

周波数補償条件

`C1R1=(C2+C3)R2`

へ代入すると

`8×9 = 15+C3`

より

`C3=57 pF`

となる。

次にサンプリング周期は

`Ts=1/fs=1/(10 kHz)=100 μs`

ナイキスト周波数は `5 kHz` であり、入力 `7.2 kHz` はこれを超える。したがって

`falias=|7.2-10|=2.8 kHz`

として観測される。

抵抗比だけ正しくてもプローブの時定数が合わなければ波形が歪み、プローブが補償されていてもサンプリング条件が不足すればエイリアシングは防げない。アナログ前段の補償と標本化条件は別々に確認する。
