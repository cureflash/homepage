## 1. R8 一次 理論 問4 — 静電容量校正

零位では標準抵抗枝と未知容量枝の電流が大きさ・位相とも一致する。90°位相差を与えるブリッジなので名称は直角相ブリッジ。

誘導分圧器の出力を `nU/8`、標準抵抗を `Rs`、未知容量を `Cx` とすると、零位条件の大きさから

`nU/(8Rs) = ω Cx U`

したがって

`f = n/(16π Rs Cx)`。

公称 `Cx=1.00 nF`、`f=1000 Hz` に対し、選択肢の組合せは `n=5`、`Rs=100.0 kΩ` が対応する。実際の平衡周波数が `1010 Hz` なら

`Cx = 5/{16π×100.0×10^3×1010} = 0.9849 nF ≒ 0.985 nF`。

解答: `カ / ワ / リ / ホ / イ`。

## 2. R7 一次 理論 問4 — インピーダンス校正

誘導分圧器の全電圧を `E`、下側タップ比を `k` とすると、二枝へ加わる電圧はそれぞれ `(1-k)E` と `kE`。検出器零では標準枝・未知枝の電流が等しいので

`(1-k)E/Zs = kE/Zx`

より

`Zx/Zs = k/(1-k)`。

この零位比較は変成器ブリッジとして整理でき、比測定は標準量との比較なので温度影響・経年変化を小さく保てる標準器が必要になる。

解答: `ル / チ / ヌ / ヲ / ヨ`。

## 3. R6 一次 理論 問6 — 交流ブリッジと浮遊容量

浮遊容量がなければ零位で4辺の対応電流が等しい。浮遊容量があると節点a,bからグランドへ漏れ電流が流れるため、`Ix=I1`、`I2=I3` の双方が崩れる。

図2はインダクタ校正に用いるマクスウェルブリッジ。増幅器条件

`Vb=-A Vd`

と

`Vd=Xd Id`

さらに

`Vd - Vb = Z2 I2`

から

`(A+1)Vd = Z2 I2`

したがって

`Id/I2 = Z2/{(A+1)Xd}`。

`A` が十分大きいと漏れ電流を無視でき、通常の平衡式へ戻る。`Z2=R2/(1+jωC2R2)` を用いると

`Zx = R1R3/Z2 = (R1R3/R2)(1+jωC2R2)`

なので

`Rx = R1R3/R2`

`Lx = C2R1R3`。

問題PDFの選択肢記号へ対応させると

解答: `ヘ / ハ / ワ / チ / ヲ`。

## 4. H24 一次 理論 問7 — オシロスコープ用プローブ

直流では容量を無視し、10:1減衰に対して

`V2/V1 = R2/(R1+R2)=1/10`。

`R2=1 MΩ` なので `R1=9 MΩ`。

容量を含むと、プローブ側とオシロスコープ入力側のRC分圧になる。減衰比を周波数非依存にする条件は時定数一致

`C1R1 = (C2+C3)R2`。

この条件では伝達比が再び `R2/(R1+R2)=1/10` となる。

`C1=10 pF`、`R1=9 MΩ`、`C2=20 pF`、`R2=1 MΩ` より

`(20+C3)×1 = 10×9`

なので `C3=70 pF`。

問題PDFの選択肢記号へ対応させると

解答: `ニ / ヨ / ヌ / イ / ヲ`。

## 5. H20 一次 理論 問6 — 電力測定誤差

現行の電気技術者試験センター公式過去問一覧はH21以降を掲載しており、H20問題本文は現行一覧から取得できない。そのため、H20問6は電験王の問題転記で本文・選択肢を復元して独立計算した。正答の最終権威として扱わず、計算式そのものを検証対象とした。

図1では電流計が負荷電流と電圧計電流の和を読むため

`Im = Vm/R + Vm/Rp`

`Pm = Vm Im = Vm^2(R+Rp)/(R Rp)`。

真値は `Pt=Vm^2/R` なので

`εa=(Pm-Pt)/Pt = R/Rp`。

図2では電圧計が負荷と電流計内部抵抗の合計電圧を読むため

`Vm=Im(R+Rc)`

`Pm=Im^2(R+Rc)`。

真値は `Pt=Im^2R` なので

`εb=Rc/R`。

`Rp=10 kΩ`、`Rc=2 Ω`、`R=100 Ω` では

`εa=0.01`、`εb=0.02`

よって `εa<εb`。

解答: `ニ / カ / ヨ / リ / ワ`。
