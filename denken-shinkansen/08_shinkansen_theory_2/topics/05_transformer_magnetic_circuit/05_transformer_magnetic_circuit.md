# 解説本文

## 1. このテーマで電験は何を問うか

この章の中心は、電流が作る磁界を `H`、磁束密度を `B`、磁束を `Φ` として切り分け、アンペアの周回積分と磁気回路の二つの見方で計算できるようにすることである。

本試験では、主に次の判断を要求される。

1. 対称性からアンペア経路を選び、経路が包む電流を正しく求める。
2. `H` から `B=μH`、さらに `Φ=∫B·dS` へ接続する。
3. 鉄心を磁気回路として近似し、`R_m=l/(μS)` と `Φ=NI/R_m` を使う。
4. 空隙を含むとき、鉄心と空隙の磁気抵抗を分けて加算する。
5. B-H曲線から飽和、残留磁束密度、保磁力、ヒステリシス損を読む。
6. 線形媒質で磁気エネルギー密度を作り、必要なら体積積分する。

0系主変圧器は、この「巻線電流が起磁力を作り、鉄心内に磁界・磁束が生じる」という流れを具体化する入口として使う。実車鉄心の寸法・透磁率・B-H値など、一次資料で確認していない数値は使用しない。

## 2. `H`、`B`、`Φ` を混同しない

磁気計算では三つの量を分ける。

| 量 | 意味 | 単位 | 基本関係 |
|---|---|---|---|
| `H` | 磁界の強さ | A/m | アンペアの周回積分で求める |
| `B` | 磁束密度 | T = Wb/m² | 線形媒質では `B=μH` |
| `Φ` | ある面を通る磁束 | Wb | `Φ=∫B·dS` |

透磁率は

`μ = μ0 μr`

で表す。`μ0` は真空の透磁率、`μr` は比透磁率である。試験計算では通常 `μ0 ≈ 4π×10^-7 H/m` を用いる。

`H` は電流配置から決まり、媒質の磁気的性質を `μ` で反映して `B` に変換する。面積を通過する `B` を積分したものが `Φ` である。この順序を崩さない。

## 3. アンペアの周回積分

基本式は

`∮ H·dl = I_enclosed`

である。対称性があり、選んだ閉路上で `H` の大きさが一定、かつ `H` と経路が接線方向にそろう場合は

`H l_c = I_enclosed`

まで簡単化できる。

解法は次の順で固定する。

1. 電流配置の対称性を見る。
2. `H` が一定になる閉路を選ぶ。
3. その閉路が包む電流 `I_enclosed` を求める。
4. `H × 閉路長 = I_enclosed` とする。
5. 必要なら `B=μH` へ進む。

特に円柱導体内部では、全電流 `I` をそのまま右辺へ入れてはいけない。半径 `r` の閉路が包む電流だけを使う。

## 4. 無限長直線電流の周囲

半径 `r` の円形経路を選ぶと、経路長は `2πr` である。経路が全電流 `I` を包むなら

`H(r) 2πr = I`

したがって

`H(r) = I/(2πr)`

真空中なら

`B(r) = μ0 I/(2πr)`

となる。距離を2倍にすると `H` と `B` は1/2になる。

ここで必要なのはビオ・サバールの法則ではなく、対称性を使ってアンペアの周回積分を適用する手順である。

## 5. 円柱導体内部では包む電流が変わる

半径 `a` の円柱導体に電流 `I` が断面内で一様に流れるとする。電流密度は

`J = I/(πa²)`

半径 `r (0≤r≤a)` のアンペア経路が包む面積は `πr²` なので

`I_enclosed = J πr² = I r²/a²`

よって

`H(r) 2πr = I r²/a²`

から

`H(r) = Ir/(2πa²)`

となる。導体内部では `H` は `r` に比例して増加し、表面 `r=a` で外部式 `I/(2πa)` と連続する。

この「包む電流を面積比で求める」操作がR6問2(1)の核心である。

## 6. 起磁力と磁気抵抗

巻数 `N` の巻線に電流 `I` が流れるとき、起磁力は

`F_m = NI`

である。磁路長 `l`、断面積 `S`、透磁率 `μ` が一様な磁路を考えると

`H = NI/l`

`B = μH = μNI/l`

`Φ = BS = μSNI/l`

よって

`R_m = l/(μS)`

と定義すれば

`Φ = NI/R_m`

となる。電気回路の `I=V/R` に似ているが、電気抵抗と磁気抵抗を同一物理量として扱ってはいけない。

磁気抵抗の単位は `A/Wb = H^-1` である。

## 7. 環状鉄心: 厳密積分と磁気回路近似

内半径 `a`、外半径 `b`、軸方向高さ `h` の環状鉄心に `N` 回巻線を巻き、電流 `I` を流す。半径 `r` の円周上では

`H(r) 2πr = NI`

したがって

`H(r)=NI/(2πr)`

線形・一様な透磁率 `μ` とすれば

`B(r)=μNI/(2πr)`

磁束は断面内で `B` が一定ではないため

`Φ = ∫_a^b B(r) h dr`

`= μNIh/(2π) ln(b/a)`

となる。

一方、磁気回路近似では代表半径 `r_m` を用い、

`l ≈ 2πr_m`

`S = h(b-a)`

`R_m ≈ l/(μS)`

`Φ ≈ NI/R_m`

とする。断面の半径方向幅が代表半径に比べて十分小さく、断面内の `B` の変化が小さいとみなせるとき、近似が有効になる。

R4問2では「位置で変わる `B` を積分する厳密な見方」と「代表磁路長・断面積へまとめる磁気回路近似」の両方を切り替えられることが必要である。

## 8. 空隙を含む磁気回路

鉄心と空隙を同一磁束 `Φ` が通り、漏れ磁束・空隙端部の広がりを無視する簡略モデルでは、磁気抵抗は直列加算できる。

鉄心部:

`R_fe = l_fe/(μ0 μr S)`

空隙部:

`R_g = g/(μ0 S)`

全磁気抵抗:

`R_total = R_fe + R_g`

したがって

`Φ = NI/R_total`

`B = Φ/S`

である。

比透磁率 `μr` が大きい鉄心では、短い空隙でも `R_g` が全磁気抵抗の大きな割合を占めることがある。比較するときは「長さ」だけでなく `l/μ` を見る。

## 9. B-H曲線と磁気飽和

線形媒質では `B=μH` と一定の `μ` で扱える。しかし強磁性体では一般に `B` と `H` の関係は非線形で、同じ一定 `μ` を全領域へ適用できない。

`H` を増加させても `B` の増加が次第に小さくなる領域が磁気飽和である。したがってB-H曲線の傾きが小さくなっている領域で、単純な一定透磁率モデルを使うのは不適切である。

本テーマでは、B-H曲線から状態を読み取ることを重視し、材料固有の詳細モデルへは広げない。

## 10. ヒステリシス、残留磁束密度、保磁力

強磁性体へ周期的に磁界を加えると、`B` は `H` の現在値だけでなく過去の磁化状態にも依存し、B-H平面上にループを描く。

- 残留磁束密度 `B_r`: `H=0` に戻しても残る `B`。
- 保磁力 `H_c`: 残留した磁化を打ち消して `B=0` にするために必要な逆向きの `H` の大きさ。
- ヒステリシスループ面積: 1周期・単位体積当たりの損失エネルギー `[J/m³]`。

ループ面積を `W_h [J/m³/cycle]`、磁性体体積を `V [m³]`、周波数を `f [Hz]` とすれば、ヒステリシスによる平均電力損失は

`P_h = W_h V f`

である。

永久磁石には一般に大きい保磁力が求められる。一方、変圧器鉄心では繰返し磁化に伴う損失を小さくするため、狭いヒステリシスループが望ましい。ここでは材料各論には踏み込まない。

## 11. 磁気エネルギー

線形媒質では、単位体積当たりの磁気エネルギーは

`w_m = BH/2`

`= μH²/2`

`= B²/(2μ)`

である。

磁界が位置によって変わる場合、全エネルギーは

`W_m = ∫_V w_m dV`

で求める。

R6問2の円柱導体内部では、単位長さを考えれば半径 `r`、厚さ `dr` の円筒殻の体積は

`dV = 2πr dr`

なので

`W'_m = ∫_0^a [μH(r)²/2] 2πr dr`

と置く。`H(r)=Ir/(2πa²)` を代入すると

`W'_m = μI²/(16π) [J/m]`

となる。

`BH/2` を使えるのは線形関係を仮定した範囲である。ヒステリシスを描く非線形過程の損失計算と混同しない。

## 12. 0系主変圧器との接続

0系主変圧器を本章で見るときは、変圧器の電圧比や等価回路ではなく、次の磁気側だけを見る。

`巻線電流 I → 起磁力 NI → 磁界 H → 磁束密度 B → 鉄心を通る磁束 Φ`

鉄心を磁気回路として近似すれば、磁路長・断面積・透磁率から磁気抵抗を作り、`Φ=NI/R_m` で磁束を評価できる。実際の変圧器の誘導起電力、自己・相互インダクタンス、漏れリアクタンス、等価回路は本Topicでは扱わず、後続Topicまたは機械編へ譲る。

## 13. 問題を見たときの解法手順

### アンペアの周回積分型

1. 対称性を確認する。
2. `H` が一定になる閉路を選ぶ。
3. 閉路が包む電流だけを求める。
4. `∮H·dl=I_enclosed` から `H` を求める。
5. 媒質が指定されれば `B=μH` へ進む。
6. 面を通る磁束なら `Φ=∫B·dS` を使う。

### 磁気回路型

1. 磁路を鉄心・空隙などに分ける。
2. 各部の `R_m=l/(μS)` を求める。
3. 同一磁束が通る直列部は磁気抵抗を加算する。
4. `Φ=NI/R_total` を使う。
5. 必要なら `B=Φ/S` へ変換する。
6. 一定透磁率の仮定が妥当かを確認する。

### B-H・ヒステリシス型

1. 横軸 `H`、縦軸 `B` を確認する。
2. `H=0` の切片から残留磁束密度を読む。
3. `B=0` の切片から保磁力を読む。
4. ループ面積が1周期・単位体積当たりの損失エネルギーであることを使う。
5. 電力損失なら体積と周波数を掛ける。

## 14. 頻出ミス

- 円柱導体内部で、包んでいない電流まで `I_enclosed` に入れる。
- `H [A/m]`、`B [T]`、`Φ [Wb]` を同じ量として扱う。
- `B=μH` を、強磁性体のヒステリシス全域で一定 `μ` のまま使う。
- 空隙の透磁率を鉄心と同じ `μ0μr` にする。
- 断面内で `B` が変化するのに `Φ=BS` を無条件で使う。
- ヒステリシスループ面積を電力 `[W]` と誤認する。まず `[J/m³/cycle]` で、電力には `Vf` を掛ける。
- 磁気エネルギー密度 `BH/2` の線形媒質という条件を落とす。

# 3段階例題

## 例題1 基礎: 無限長直線電流の磁束密度

真空中の無限長直線導体に `I=100 A` が流れている。導体中心から `r=5.0 cm` の点の `H` と `B` を求める。

### 解法

円形のアンペア経路を選ぶ。経路は全電流を包むので

`H 2πr = I`

`H = 100/(2π×0.050) = 3.18×10² A/m`

真空中では

`B = μ0H`

`= 4π×10^-7 × 3.18×10²`

`= 4.00×10^-4 T`

答え:

- `H = 3.18×10² A/m`
- `B = 4.00×10^-4 T`

検算: `r` を2倍にすれば `H`、`B` は1/2になる形になっている。

## 例題2 本試験標準: 空隙を含む磁気回路

断面積 `S=4.0×10^-4 m²` の一様な磁気回路を考える。鉄心磁路長 `l_fe=0.50 m`、比透磁率 `μr=2000`、空隙長 `g=0.50 mm`、巻数 `N=500`、電流 `I=0.40 A` とする。漏れ磁束と空隙端部の広がりは無視する。磁束 `Φ` と空隙の磁束密度 `B` を求める。

### 解法

起磁力は

`NI = 500×0.40 = 200 A`

鉄心の磁気抵抗:

`R_fe = l_fe/(μ0 μr S)`

`= 0.50/(4π×10^-7 × 2000 × 4.0×10^-4)`

`= 4.97×10^5 A/Wb`

空隙の磁気抵抗:

`R_g = g/(μ0S)`

`= 0.50×10^-3/(4π×10^-7 × 4.0×10^-4)`

`= 9.95×10^5 A/Wb`

したがって

`R_total = 1.49×10^6 A/Wb`

`Φ = NI/R_total`

`= 200/(1.49×10^6)`

`= 1.34×10^-4 Wb`

`B = Φ/S`

`= 1.34×10^-4/(4.0×10^-4)`

`= 0.335 T`

答え:

- `Φ = 1.34×10^-4 Wb`
- `B = 0.335 T`

空隙は鉄心よりはるかに短いが、透磁率が低いため `R_g > R_fe` となっている。長さだけで磁気抵抗の大小を判断しない。

## 例題3 複合・ひっかけ: 円柱導体内部の磁気エネルギーとヒステリシス

### (a) 円柱導体内部

半径 `a` の長い円柱導体に電流 `I=20 A` が一様に流れている。媒質は真空とし、導体内部に蓄えられる単位長さ当たりの磁気エネルギーを求める。

半径 `r` の閉路が包む電流は

`I_enclosed = I r²/a²`

したがって

`H(r) = Ir/(2πa²)`

線形媒質のエネルギー密度は

`w_m = μ0H²/2`

単位長さの円筒殻 `2πr dr` で積分する。

`W'_m = ∫_0^a [μ0/2 × (Ir/(2πa²))²] 2πr dr`

`= μ0I²/(16π)`

`= 4π×10^-7 × 20²/(16π)`

`= 1.00×10^-5 J/m`

半径 `a` が最終式から消えることも検算になる。途中で全電流 `I` を包むとしてしまうと、この結果にはならない。

### (b) ヒステリシス

ある磁性体のB-Hループ面積が `120 J/m³/cycle`、磁性体体積が `2.0×10^-2 m³`、周波数が `50 Hz` である。ヒステリシス損の平均電力を求める。

1周期の全損失エネルギーは

`120 × 2.0×10^-2 = 2.4 J/cycle`

したがって

`P_h = 2.4×50 = 120 W`

答え: `120 W`

B-H図で `H=0` のときに残る `B` が残留磁束密度 `B_r`、`B=0` に戻すために必要な逆向きの `H` の大きさが保磁力 `H_c` である。ループ面積そのものは電力ではなく、まず1周期・単位体積当たりのエネルギーである。
