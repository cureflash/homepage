# EXAM_ALIGNMENT

資格: 第二種電気主任技術者

中心科目: 一次試験「理論」

論点:
- アンペアの周回積分 `∮H·dl = I_enclosed`
- 磁界の強さ `H [A/m]`
- 磁束密度 `B = μH [T]`
- 磁束 `Φ = ∫ B·dS [Wb]`
- 透磁率 `μ = μ0 μr`
- 起磁力 `F_m = NI [A]`
- 磁気抵抗 `R_m = l/(μS) [A/Wb] = [H^-1]`
- 磁気回路 `Φ = NI/R_m`
- 空隙を含む磁気回路の磁気抵抗の加算
- B-H曲線、磁気飽和、残留磁束密度、保磁力
- ヒステリシスループと1周期当たりの損失エネルギー
- 磁気エネルギー密度 `w_m = BH/2 = μH^2/2`（線形媒質）と体積積分

## 過去問ごとの教材内必要説明

1. R6 問2(1)〜(2)
   - 一様電流密度の円柱導体では、半径 `r` のアンペア経路が包む電流が `I r²/a²` になること。
   - `H(r)·2πr = I r²/a²` から `H(r)=Ir/(2πa²)` を得ること。
   - 線形媒質の磁気エネルギー密度 `w_m=BH/2=μH²/2` と、円筒殻 `2πr dr` を用いた単位長さ当たりの体積積分。
2. R5 問2(1)
   - 無限長直線電流の周囲では円形のアンペア経路を選び、`H·2πr=I` とすること。
   - 真空中で `B=μ0H` とつなぎ、`B(r)=μ0I/(2πr)` を導くこと。
   - (2)〜(5)の鎖交磁束・ファラデーの法則は本Topicへ持ち込まないこと。
3. R4 問2(1)〜(5)
   - アンペアの周回積分から環状鉄心内の `H(r)` と `B(r)=μH(r)` を求めること。
   - 断面内で `B` が位置により変わる場合は `Φ=∫B dS` で磁束を求めること。
   - 磁気回路近似では代表磁路長 `l`、断面積 `S`、透磁率 `μ` から `R_m=l/(μS)` を作り、`Φ=NI/R_m` を使うこと。
   - 厳密積分と磁気回路近似の違いを、近似条件を含めて説明すること。
4. R3 問2(1)〜(5)
   - 強磁性体では `B` と `H` が単純比例せず、履歴を持つB-H曲線になること。
   - 残留磁束密度 `B_r`、保磁力 `H_c` の意味を図上で判定できること。
   - 永久磁石用材料と変圧器鉄心用材料で望ましいB-H特性が異なること。ただし材料各論へ広げないこと。
   - ヒステリシスループ面積 `[J/m³]` が1周期・単位体積当たりの損失エネルギーを表し、電力損失は体積と周波数を掛けて求めること。
5. H30 問2(1)〜(3)
   - 鉄心部と空隙部で `R_m=l/(μS)` を個別に作り、同一磁束が通る直列磁気回路では磁気抵抗を加算すること。
   - `μ0 << μ` の空隙が全磁気抵抗を大きく左右することを式で判断すること。
   - `Φ=NI/R_m` と `B=Φ/A` を接続して空隙磁束密度を求めること。
   - (4)(5)の自己・相互インダクタンスは本Topicへ追加しないこと。

## SPECから必須となる説明

- アンペアの周回積分と、対称性を使ったアンペア経路の選び方
- `H`、`B`、`Φ` の定義・単位と `B=μH`、`Φ=∫B·dS`
- 真空透磁率、比透磁率、透磁率 `μ=μ0μr`
- 起磁力 `NI`
- 磁気抵抗 `R_m=l/(μS)` と磁気回路 `Φ=NI/R_m`
- 複数磁路・空隙を含む磁気抵抗の扱い
- B-H曲線、磁気飽和、残留磁束密度、保磁力
- ヒステリシスとループ面積のエネルギー意味
- 線形範囲での磁気エネルギー密度 `BH/2=μH²/2` と体積積分
- 0系主変圧器は導入・具体例として用いるが、一次資料なしの実車鉄心寸法・B-H値等を真値化しない
