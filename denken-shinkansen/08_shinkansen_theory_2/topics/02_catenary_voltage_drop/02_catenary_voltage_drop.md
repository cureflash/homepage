- ジュール損 `P_loss = I²R`
- 分布負荷で電流が位置により変わる場合の損失・電圧降下の積分

### 過去問ごとの教材内必要説明

1. R6 問2(3)
   - 導電率 `σ` と抵抗率 `ρ` が逆数であること。
   - `R = ρl/S = l/(σS)` の記号、単位、成立条件。
   - 「単位長さ当たり」と指定されたら `l=1 m` として扱う読み替え。
   - 円形断面では `S=πa²` とすること。

2. R1 問5(1)
   - 電流密度は単位面積当たりの電流であり、一様なら `I=JS`。
   - 半径 `r` の円断面に流れる電流は `Jπr²`。
   - 電流密度が非一様なら単純な `JS` ではなく面積積分が必要になること。

3. H27 問1(3)(4)
   - 同軸形状で電流が半径方向に流れる場合、電流通過面積が位置で変わるため `J` も位置で変わること。
   - 局所オーム則 `J=σE` と、集中定数の `V=RI` のつながり。
   - 同問の静電容量部分はTopic 04、磁界・表皮効果は他Topicの範囲であり、本Topicへ持ち込まない。

4. R5 二次 問4(1)
   - 単位長さ当たりの線路定数から全長分へ `R=rL`, `X=xL` と換算する手順。
   - 三相電力から線電流を求める手順。
   - 電圧降下近似式では進み・遅れ力率で無効分の符号が変わること。
   - 本Topicでは「長くなるほど線路定数が増え、端子電圧差が生じる」接続を扱う。力率補償そのものは本Topicの主題にしない。

5. R1 二次 問4(2)
   - 分布負荷では線路電流 `I(x)` が位置で変わるので、全損失を端点電流だけで `I²R` としてはいけないこと。
   - 微小区間の損失 `dP=I(x)² r dx` を積分すること。単相2線式では2線分を数えること。
   - `P_loss ∝ I²` のため、同じ総負荷でも負荷分布・給電位置で損失が変わること。

6. H27 二次 問3
   - 負荷密度から線路電流を積分し、その線路電流から電圧降下をもう一度積分する二段階の手順。
   - 抵抗分だけを考える問題条件を読み落とさないこと。
   - 線路抵抗が単位長さ値 `R [Ω/m]` で与えられた場合、微小区間は `R dx` となること。

## 教材で必要な説明順

1. `ρ [Ω·m]`, `σ [S/m]`, `l [m]`, `S [m²]`, `R [Ω]` の定義と単位。
2. `R = ρl/S = l/(σS)` を、長さ・断面積・材料の3要因として説明する。
3. `J = I/S` と `J=σE` を結び、電流密度→電界→電圧降下へつなぐ。
4. 温度係数から温度上昇時の抵抗変化を計算する。
5. 基本の電圧降下 `ΔV=IR` を、`R∝l` と組み合わせて「長いほど落ちやすい」へ接続する。
6. 二次試験接続として、三相線路では抵抗だけでなくリアクタンスと力率で端子電圧差の符号・大きさが変わる例をR5問4(1)で示す。ただしRLC一般論へ拡張しない。
7. ジュール損 `P_loss=I²R` を導き、長さ・断面積・電流の影響を整理する。
8. 分布負荷では `I(x)` を作って `∫I(x)²r dx`、電圧降下では `∫I(x)r dx` とする解法手順を示す。
9. 新幹線側は教育用の架線導体モデルとして接続し、未確認の実車値を仮定値と混同しない。

## 頻出ミスとして扱う事項

- `ρ` と `σ` を同じ向きの量だと思う。実際は `σ=1/ρ`。
- `mm²` と `m²`、`km` と `m` の換算を落とす。
- 半径と直径を取り違えて断面積を4倍/1/4倍にする。
- 温度係数の基準温度を無視する。
- 電力損失を `IR` とする。電圧降下は `IR`、抵抗損は `I²R`。
- 分布負荷で全区間を同一電流とみなす。
- 三相線路の進み/遅れで電圧降下式の符号を誤る。
