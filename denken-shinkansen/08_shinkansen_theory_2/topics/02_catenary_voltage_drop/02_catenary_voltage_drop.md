# 解説本文

## 1. このテーマで電験は何を問うか

本テーマの中心は「導体の材料・長さ・断面積・温度・流れる電流から、抵抗、電流密度、電圧降下、抵抗損を求める」ことである。一次「理論」では `R=ρl/S`、`σ=1/ρ`、`J=I/S`、`J=σE` を相互に結び付ける力が必要になる。二次「電力・管理」では、単位長さ当たりの線路定数を全長へ直し、位置で電流が変わる分布負荷なら積分して電圧降下や損失を求める。

暗記すべきなのは式の形だけではない。どの量が「単位長さ値」なのか、断面積の単位は何か、電流が全区間で一定か位置で変わるかを問題文から判定する必要がある。

## 2. 抵抗率・導電率・導体抵抗

抵抗率 `ρ [Ω·m]` は材料固有の電流の流れにくさを表す。導電率 `σ [S/m]` は流れやすさを表し、

`σ = 1/ρ`

の関係にある。

一様な材料、一定の断面積 `S [m²]`、長さ `l [m]` の導体を、この章の抵抗モデルで扱うと

`R = ρl/S = l/(σS)`

となる。ここで `R [Ω]` は導体全体の抵抗である。

この式から次が直ちに分かる。

- 長さを2倍にすると抵抗は2倍。
- 断面積を2倍にすると抵抗は1/2。
- 抵抗率が大きい材料ほど抵抗が大きい。
- 導電率が大きい材料ほど抵抗が小さい。

円形断面で半径 `a` なら

`S = πa²`

である。直径 `d` が与えられたら `a=d/2` に直す。`1 mm² = 10^-6 m²` の換算を先に行う。

「単位長さ当たりの抵抗」を問われたら `l=1 m` と置けばよい。

`r = ρ/S = 1/(σS) [Ω/m]`

全長 `L` なら `R=rL` である。

## 3. 電流密度と局所オーム則

電流密度 `J [A/m²]` は、電流が断面内にどの程度集中して流れているかを表す。一様な電流密度なら

`J = I/S`

したがって

`I = JS`

である。

電流密度が位置で変わる場合は、単純に `JS` とせず、断面上で

`I = ∫ J·dS`

と積分する。

導電率 `σ` と電界 `E [V/m]` の間には局所形のオーム則

`J = σE`

が成り立つ。この章の一様な直線導体モデルなら

`E = J/σ = ρJ`

であり、電圧降下は

`ΔV = El`

だから、`J=I/S` を代入すると

`ΔV = ρ(I/S)l = IR`

となる。つまり `J=σE` は導体内部の局所的な関係、`V=RI` は導体全体へ積分した関係である。

H27一次のように電流通過面積が位置で変わる問題では、まず幾何からその位置の通過面積を作り、その後 `J=I/S(r)`、`J=σE` と進む。

## 4. 温度係数

系列SPECで明示されているため、抵抗の温度変化も扱う。基準温度 `T0` で抵抗 `R(T0)` が分かっており、対象温度範囲で一次近似を用いる場合、

`R(T) = R(T0){1 + α(T-T0)}`

である。`α [1/K]` は基準温度に対応する温度係数である。

温度差は K と ℃ で数値が同じなので、`T-T0` は温度差として扱える。重要なのは、どの温度を基準にした `R` と `α` なのかをそろえることである。

温度が上がって抵抗が増えれば、同じ電流を流した場合の `IR` 電圧降下と `I²R` 損失も増える。

## 5. 電圧降下

抵抗だけを考える基本モデルでは

`ΔV = IR`

である。`R=ρl/S` を代入すると

`ΔV = Iρl/S`

となる。同じ材料・断面積・電流なら、長さに比例して電圧降下が増える。これが「架線を抵抗体として見たとき、長くなるほど電圧が落ちる」基本理由である。

解法手順は次のとおり。

1. `ρ` または `σ`、長さ `l`、断面積 `S` の単位をそろえる。
2. `R=ρl/S` または `R=l/(σS)` で抵抗を求める。
3. 電流 `I` が一定なら `ΔV=IR`。
4. 電流が位置で変わるなら微小電圧降下を積分する。
5. 結果の単位が V であることを確認する。

## 6. 三相線路への最小接続

R5二次の対応に必要な範囲だけ、抵抗以外の線路定数を含む電圧降下へ接続する。単位長さ当たりの抵抗 `r [Ω/km]`、リアクタンス `x [Ω/km]`、線路長 `L [km]` なら

`R = rL`

`X = xL`

である。

受電端線間電圧 `V`、有効電力 `P`、力率 `cosφ` から三相線電流を求めるなら

`I = P/(√3 V cosφ)`

である。

短距離線路の近似として、遅れ力率では線間電圧降下を

`ΔV ≈ √3 I(R cosφ + X sinφ)`

と扱う。進み力率では無効分の符号が逆になり、

`ΔV ≈ √3 I(R cosφ - X sinφ)`

となる。ここでは「長さが増えると `R` と `X` が増え、端子電圧差へ効く」「進み・遅れで無効分の符号が変わる」ことまでを扱い、力率補償やRLC一般論へ広げない。

## 7. ジュール損と電力損失

抵抗 `R` に電流 `I` が流れると、抵抗で消費される電力は

`P_loss = VI = (IR)I = I²R`

である。`R=ρl/S` を代入すると

`P_loss = I²ρl/S`

となる。

したがって、同じ材料・断面積・電流なら損失は長さに比例する。断面積を大きくすれば損失は減る。特に重要なのは電流の二乗に比例することで、電流が2倍なら損失は4倍になる。

電圧降下 `IR` と電力損失 `I²R` を混同しない。

## 8. 分布負荷では電流を先に位置の関数にする

二次試験では、線路の途中に負荷が分布し、線路電流が位置で変わる問題がある。この場合、全線路へ同じ電流が流れるとして `I²R` を一発で使ってはいけない。

単位長さ当たり抵抗を `r [Ω/m]`、位置 `x` の線路電流を `I(x)` とすると、1本の導体の微小区間 `dx` の抵抗は

`dR = r dx`

である。

微小電圧降下は

`dV = I(x)r dx`

なので、全電圧降下は

`ΔV = ∫ I(x)r dx`

となる。

微小損失は

`dP = I(x)²r dx`

なので、全損失は

`P_loss = ∫ I(x)²r dx`

である。単相2線式なら往復2線分を数え、条件に応じて係数2を付ける。

分布負荷問題の基本手順は次のとおり。

1. 負荷密度または区間負荷から `I(x)` を作る。
2. 電圧降下なら `I(x)` を一次で積分する。
3. 抵抗損なら `I(x)²` を積分する。
4. 2線式など、何本分の抵抗を数えるか確認する。
5. 給電位置を求める問題では、左右の電圧降下条件を式にして等置する。

## 9. 新幹線への接続

新幹線の架線を、この章では「長さ `l`、断面積 `S`、抵抗率 `ρ` を持つ一様導体」という教育用モデルへ簡略化する。列車へ流れる電流が大きいほど `IR` 電圧降下と `I²R` 損失は増え、給電点から遠くなるほど抵抗成分は増える。

ただし、ここで使う単純な一様導体モデルを実在の新幹線き電回路そのものとみなさない。実在架線の抵抗値、温度、断面積、電流値は本段階では置かず、以下の例題はすべて教材用仮定値とする。

## 10. 基礎例題 — 導電率・円形断面・電流密度

教材用仮定値として、導電率 `σ=5.0×10^7 S/m`、半径 `a=2.0 mm` の円形導体に `I=10 A` が一様に流れる。単位長さ当たりの抵抗、電流密度、単位長さ当たりの電圧降下を求める。

まず半径をSI単位へ直す。

`a = 2.0×10^-3 m`

断面積は

`S = πa² = π(2.0×10^-3)² = 1.2566×10^-5 m²`

単位長さ `l=1 m` の抵抗は

`R_1m = 1/(σS)`

`= 1/{(5.0×10^7)(1.2566×10^-5)}`

`= 1.5915×10^-3 Ω`

電流密度は

`J = I/S = 10/(1.2566×10^-5)`

`= 7.96×10^5 A/m²`

局所オーム則から

`E = J/σ = (7.96×10^5)/(5.0×10^7)`

`= 1.5915×10^-2 V/m`

一方、`IR` でも

`ΔV_1m = 10×1.5915×10^-3 = 1.5915×10^-2 V`

となり一致する。

検算: `E×1 m` と `IR` が同じ値になるので、局所式と集中定数式の接続が確認できる。

## 11. 本試験標準例題 — 温度上昇を含む電圧降下と損失

教材用仮定値として、20 ℃で抵抗率 `ρ20=1.8×10^-8 Ω·m`、長さ `l=100 m`、断面積 `S=100 mm²` の一様導体を考える。温度係数を `α=4.0×10^-3 1/K` とし、導体温度が70 ℃のとき `I=200 A` が流れる。抵抗、電圧降下、抵抗損を求める。

断面積は

`100 mm² = 100×10^-6 m² = 1.0×10^-4 m²`

20 ℃での抵抗は

`R20 = ρ20 l/S`

`= (1.8×10^-8)×100/(1.0×10^-4)`

`= 0.018 Ω`

温度差は

`ΔT = 70-20 = 50 K`

したがって

`R70 = R20{1+αΔT}`

`= 0.018{1+(4.0×10^-3)×50}`

`= 0.0216 Ω`

電圧降下は

`ΔV = IR70 = 200×0.0216 = 4.32 V`

抵抗損は

`P_loss = I²R70 = 200²×0.0216 = 864 W`

検算: 温度上昇で抵抗は `0.018→0.0216 Ω` と20%増えているため、同じ電流なら電圧降下と損失も20%増える。

## 12. 複合・ひっかけ例題 — 分布負荷を一括電流で扱わない

教材用仮定値として、長さ `L=1000 m` の単相2線式線路があり、各導体の単位長さ当たり抵抗を `r=2.0×10^-4 Ω/m` とする。負荷は線路全体へ一様に分布し、給電端電流は `Is=100 A`、末端では0 Aになる。末端までの抵抗分電圧降下と全線路の抵抗損を求める。

給電端からの距離を `x` とすると、電流は線形に減少するので

`I(x) = Is(1-x/L)`

である。

2線分の電圧降下は

`ΔV = 2r∫_0^L I(x)dx`

`= 2rIs∫_0^L (1-x/L)dx`

`= 2rIs(L/2)`

`= rIsL`

数値を代入すると

`ΔV = (2.0×10^-4)×100×1000 = 20 V`

である。

全線路の抵抗損は

`P_loss = 2r∫_0^L I(x)²dx`

`= 2rIs²∫_0^L (1-x/L)²dx`

`= 2rIs²(L/3)`

`= (2/3)rIs²L`

したがって

`P_loss = (2/3)(2.0×10^-4)(100²)(1000)`

`= 1.33×10^3 W`

となる。

ひっかけは「給電端の100 Aが全長に流れる」としてしまうこと。その誤った扱いでは電圧降下40 V、損失4.0 kWとなり、どちらも過大になる。分布負荷では、まず `I(x)` を作る。

## 13. 三相線路の符号確認

二次試験接続では、同じ線路定数でも力率の進み・遅れで無効分の符号が変わる。問題文が進み力率なら、遅れ用の `+X sinφ` を機械的に使わない。

手順は

1. `r, x` が単位長さ値なら `R=rL, X=xL`。
2. `I=P/(√3Vcosφ)` で線電流を求める。
3. 進み・遅れを判定する。
4. 対応する符号で電圧降下近似式へ代入する。
5. 送受電端電圧の大小が物理的に不自然でないか確認する。

とする。

## 14. 頻出ミス

- `ρ` と `σ` を逆数にしない。
- `mm²→m²` を忘れる。
- 直径をそのまま半径として `πd²` としない。
- 「単位長さ当たり」を全長値と取り違えない。
- 温度係数の基準温度を無視しない。
- 電圧降下 `IR` と損失 `I²R` を混同しない。
- 分布負荷へ給電端電流を全長一様に適用しない。
- 単相2線式の往復2線分を落とさない。
- 三相線路で進み/遅れの符号を取り違えない。

## 16. 公式・解法まとめ

基本式:

- `σ = 1/ρ`
- `R = ρl/S = l/(σS)`
- `r = ρ/S [Ω/m]`
- `J = I/S`（一様）
- `I = ∫J·dS`（非一様）
- `J = σE`
- `R(T)=R(T0){1+α(T-T0)}`（一次近似）
- `ΔV = IR`
- `P_loss = I²R`
- `R=rL`, `X=xL`
- `I=P/(√3Vcosφ)`（三相有効電力から線電流）
- `ΔV ≈ √3I(Rcosφ ± Xsinφ)`（遅れ `+`、進み `-` の近似）
- `ΔV = ∫I(x)r dx`
- `P_loss = ∫I(x)²r dx`

解法の順序:

1. 単位をSIへそろえる。
2. 一様導体なら `R=ρl/S`、単位長さ値なら全長へ換算する。
3. 一様電流なら `J=I/S`、非一様なら積分する。
4. 温度指定があれば抵抗を指定温度へ補正する。
5. 電圧降下は `IR`、損失は `I²R`。
6. 分布負荷なら先に `I(x)` を作る。
7. 三相線路では進み/遅れの符号を確認する。
8. 単位と電圧・損失の増減方向で検算する。
