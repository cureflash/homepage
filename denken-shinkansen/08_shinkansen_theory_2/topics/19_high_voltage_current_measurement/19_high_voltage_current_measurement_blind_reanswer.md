## 根拠

### R5 一次 理論 問8

熱電形交流電力計の二つの抵抗に流れる電流を `i1+i2` と `i1-i2` として、各抵抗の平均消費電力差を展開した。

1. 異種金属接点の温度差で起電力が生じるのはゼーベック効果 → ハ。
2. 抵抗1の平均電力は `R/T ∫[i1(t)+i2(t)]^2 dt` → リ。
3. 抵抗2の平均電力は `R/T ∫[i1(t)-i2(t)]^2 dt` → ル。
4. 差を取ると `4R/T ∫i1(t)i2(t)dt` → チ。
5. `i1∝u(t)`、`i2∝i(t)` なので積は `u(t)i(t)`、周期平均は `UI cosθ` → ワ。

### R1 一次 理論 問4

コンデンサ分圧回路をA-B端子からテブナン等価化した。

1. 電源を零にすると `C1` と `C2` は並列となり、`Z0=1/{jω(C1+C2)}`。分母は `jω(C1+C2)` → ヲ。
2. 開放時A-B電圧は容量分圧より `V0=C1/(C1+C2)V1` → ル。
3. 電圧計から見た直列インピーダンスは `jωL+1/{jω(C1+C2)}` → ロ。
4. 電圧計内部インピーダンスへの依存を消すにはこの項を零にし、`ω^2L(C1+C2)=1` → ヌ。
5. これは `L,C1,C2` を共振させる条件 → カ。

### H29 一次 理論 問4

エアトン分流器はスイッチ位置ごとに負端子までの二枝を描き直し、両枝の電圧一致を用いた。

1. 位置aでは計器枝が `Rm+R2+R3`、分流枝が `R1` → ヘ。
2. 位置bの計器枝は `Rm+R3` → イ。
3. 位置bの分流枝は `R1+R2` → ニ。
4. 位置cの分流枝は `R1+R2+R3` → ル。
5. `Rm=100Ω, Im=0.05A, Ic=1.05A` から `R1+R2+R3=5Ω`。位置bの式と `R1=0.05Ω` を併用すると `R3=4.50Ω` → ヌ。

### H25 一次 理論 問8

最大目盛電流 `Im=20mA`、内部抵抗 `Rm=10Ω` より、計器最大目盛時の端子電圧は `0.2V`。

1. 0.1Aレンジでは分流電流0.08Aなので `R1+R2=0.2/0.08=2.50Ω` → ヲ。
2. 1Aレンジでは `R1` に0.98Aが流れ、`0.98R1=0.02(R2+10)` → ニ。
3. 上式と `R1+R2=2.50` から `R1=0.25Ω` → ロ。
4. `R2=2.25Ω` → ル。
5. 1Vレンジでは0.1Aレンジ部分の電圧が0.2Vなので、`R3` の電圧降下は0.8V、電流0.1Aより `R3=8.00Ω` → カ。

### H21 一次 理論 問6

平行板静電電圧計のエネルギーと、直列コンデンサによる容量分圧を用いた。

1. `W=ε0SV^2/(2r)`、`F=dW/dr=-ε0SV^2/(2r^2)` → ト。
2. 駆動力は測定電圧の2乗に比例 → ハ。
3. 静電電圧計は直流・交流の双方を測定できる → カ。
4. 30kVレンジでは44pF計器に8kV、`C1` に22kV。直列電荷一致から `C1×22=44×8`、`C1=16pF` → ロ。
5. 62kVレンジでは `C2` の電圧が32kV。`C2×32=44×8` より `C2=11pF` → ル。
