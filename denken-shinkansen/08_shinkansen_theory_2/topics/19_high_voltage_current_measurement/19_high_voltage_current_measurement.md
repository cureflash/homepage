## 5. 解説本文

### 5.1 このテーマで電験は何を問うか

本Topicは二種一次「理論」の電気計測で、計器を回路へどう接続するか、計器の内部抵抗・内部インピーダンスを含めてどう回路式を立てるか、測定範囲をどう拡大するか、高電圧・大電流をCT・VTでどう計測可能な量へ変成するかを問う。

固定過去問では、単純な分流器・倍率器だけでなく、切替形分流器、容量分圧と内部インピーダンスを含む計器用変圧器、静電電圧計、二信号の平均電力差から有効電力を取り出す交流電力計まで出題される。公式の暗記だけではなく、「接続確認→内部抵抗・変成比確認→回路式→指示値→一次側量」の順で解くことが重要である。

### 5.2 電圧計・電流計と内部抵抗

電圧計は測定対象の両端へ並列接続する。電圧計の入力抵抗が小さいと、電圧計自身が余分な電流を流して元の回路状態を変える。したがって理想電圧計は入力抵抗を無限大とし、実計器でも測定対象に比べ十分大きい入力抵抗・入力インピーダンスが望ましい。

電流計は測定する枝へ直列接続する。内部抵抗が大きいと、電流計を入れたことで枝の合成抵抗が増え、測りたい電流そのものが変わる。したがって理想電流計は内部抵抗0とし、実計器でも十分小さい内部抵抗が望ましい。

直流抵抗回路では内部抵抗 `Rm` を用い、交流回路では必要に応じて内部インピーダンス `Zm` として扱う。本Topicでは、その値を回路式へ入れて指示値を求めるところまでを扱い、一般的な測定誤差論へは広げない。

### 5.3 計測問題の共通解法

固定一次5問は、回路形式が違っても次の手順で整理する。

1. 電圧計は並列、電流計は直列という接続を確認する。
2. 計器の最大目盛電流、内部抵抗・内部インピーダンス、CT・VTの変成比を整理する。
3. 分流器・倍率器・容量分圧器など、計器の前段を含めて等価回路を描く。
4. 並列枝なら両端電圧一致とKCL、直列回路なら電流一致とKVLを使う。
5. 計器へ実際に加わる電圧・電流を求める。
6. CT・VTを介する場合は、最後に変成比を使って一次側量へ戻す。
7. 電力なら電圧と電流の積の周期平均、電力量なら電力の時間積分へ進む。
8. 単位、レンジ、一次側と二次側の取り違えがないか検算する。

### 5.4 分流器で電流測定範囲を広げる

最大目盛電流 `Im`、内部抵抗 `Rm` の電流計を、最大 `I` まで測れるようにする。計器と並列に分流器抵抗 `Rs` を接続する。

最大目盛時、計器には `Im`、分流器には `I-Im` が流れる。並列なので両端電圧は等しく、

`Im Rm = (I-Im)Rs`

したがって

`Rs = Im Rm/(I-Im)`

となる。倍率 `m=I/Im` を使えば

`Rs = Rm/(m-1)`

である。

分流器問題では「全電流 `I` が計器へ流れる」と置かない。計器が受け持つのは最大でも `Im` であり、残りを分流器へ逃がす。

### 5.5 倍率器で電圧測定範囲を広げる

最大目盛電流 `Im`、内部抵抗 `Rm` の計器を最大電圧 `V` の電圧計として使うには、直列に倍率器抵抗 `Rs` を入れる。

最大目盛時に回路全体へ `Im` が流れるので、

`V = Im(Rm+Rs)`

したがって

`Rs = V/Im - Rm`

となる。計器単体の最大目盛電圧を `Vm=Im Rm`、倍率を `n=V/Vm` とすれば

`Rs = (n-1)Rm`

である。

分流器は並列、倍率器は直列である。ここを逆にすると回路式全体が崩れる。

### 5.6 エアトン分流器

エアトン分流器は複数の抵抗を連続的な分流網として配置し、切替位置に応じて計器枝と分流枝に含まれる抵抗が変わる。固定過去問H29一次理論問4では、スイッチ位置ごとに回路を描き直すことが最重要である。

例えば抵抗を `R1,R2,R3`、計器内部抵抗を `Rm` とし、切替位置aで計器枝が `Rm+R2+R3`、分流枝が `R1`、位置bで計器枝が `Rm+R3`、分流枝が `R1+R2`、位置cで計器枝が `Rm`、分流枝が `R1+R2+R3` になる構成を考える。

各位置の最大測定電流を `Ia,Ib,Ic` とすると、計器には常に最大目盛電流 `Im` を流すから、並列枝の電圧一致より

`Im(Rm+R2+R3) = (Ia-Im)R1`

`Im(Rm+R3) = (Ib-Im)(R1+R2)`

`Im Rm = (Ic-Im)(R1+R2+R3)`

となる。

解法は「スイッチ記号を見て暗記公式を選ぶ」のではなく、各位置で負端子までの二枝を描き直し、計器枝電流を `Im`、もう一方を「レンジ電流−Im」として電圧一致を使う。これで未知抵抗も測定レンジも求められる。

### 5.7 CTで大電流を測る

CTは大きな一次電流を、計器へ扱いやすい二次電流へ変成する。理想CTではアンペアターンがつり合い、

`N1 I1 = N2 I2`

したがって

`I1/I2 = N2/N1 = kI`

と書ける。変流比を `kI=I1/I2` と定義すれば、二次電流 `I2` を測って

`I1 = kI I2`

で一次電流へ戻せる。

CT二次側は、一次電流が流れている状態で開放してはならない。二次電流が流れないと一次アンペアターンを打ち消せず、鉄心磁束が大きくなって二次側に高電圧が発生し得るため危険である。本Topicでは安全上のこの原則を必須事項として扱う。

### 5.8 VTで高電圧を測る

VTは高い一次電圧を、計器へ扱いやすい二次電圧へ変成する。理想VTでは巻数比と電圧比が等しく、

`V1/V2 = N1/N2 = kV`

と書ける。変圧比を `kV=V1/V2` と定義すれば、二次電圧 `V2` から

`V1 = kV V2`

で一次電圧を求められる。

VT二次側は短絡してはならない。低インピーダンスで短絡すると大電流が流れ、機器を損傷する危険がある。CTは二次開放禁止、VTは二次短絡禁止と対で整理する。

### 5.9 コンデンサ形計器用変圧器の回路解析

高電圧を二つの直列コンデンサ `C1,C2` で分圧し、その出力を計器へ与える理想化回路を考える。直列コンデンサの電荷は等しいため、開放時の出力電圧を `V0` とすると

`V0 = C1/(C1+C2) V1`

となる。

出力端子から見た等価回路を求めるときは、電圧源を零として考える。このとき `C1` と `C2` は出力端子から見て並列になり、等価インピーダンスは

`Z0 = 1/{jω(C1+C2)}`

である。

ここに直列リアクトル `L` と電圧計内部インピーダンス `Zm` が接続される場合、計器へ加わる電圧は等価電圧源 `V0` と直列インピーダンス

`jωL + 1/{jω(C1+C2)}`

を含む回路として求める。R1一次理論問4型では、計器内部インピーダンスへの依存を消す条件として、この直列リアクタンスを0にする

`ω²L(C1+C2)=1`

が現れる。

重要なのは容量分圧比だけで終わらず、電圧計内部インピーダンスを接続した後の等価回路まで追うことである。

### 5.10 静電電圧計と直列容量による高電圧測定

平行板形の静電電圧計を理想化すると、静電エネルギーは

`W = 1/2 CV²`

である。平行板間隔を `r`、極板面積を `S` とすれば `C=ε0S/r` なので、電圧によって生じる力の大きさは

`|F| = ε0 S V²/(2r²)`

となり、駆動力は電圧の2乗に比例する。このため極性によらず働き、直流・交流の電圧測定に使えるという性質へつながる。

測定範囲を直列コンデンサで広げる場合は、直列各コンデンサの電荷が同じことを使う。計器自身の静電容量を `Cm`、計器に加える許容電圧を `Vm`、直列コンデンサを `Cs` とすると、直列コンデンサ側の電圧を `Vs` として

`Cm Vm = Cs Vs`

である。総測定電圧は

`V = Vm + Vs`

なので、この2式から必要な `Cs` を求める。H21一次理論問6型では、この容量分圧と `V²` に比例する駆動力を同時に使う。

### 5.11 電力計と交流有効電力

交流の瞬時電力は

`p(t)=u(t)i(t)`

であり、周期 `T` にわたる平均電力は

`P = 1/T ∫[0→T] u(t)i(t)dt`

である。正弦波で電圧と電流の実効値を `U,I`、位相差を `φ` とすれば

`P = UI cosφ`

となる。

電力計は電圧と電流の両方を扱う。CT・VTを介して二次側で電力を測る教育用理想モデルでは、変流比 `kI=I1/I2`、変圧比 `kV=V1/V2` とすれば、一次側電力は

`P1 = kV kI P2`

として戻せる。本Topicでは理想変成比だけを扱い、変成器の誤差論へは進まない。

### 5.12 熱電形交流電力計

R5一次理論問8型では、電圧と電流に比例する二つの信号を作り、それらの和と差を二つの等しい抵抗へ流して平均消費電力を比較する。

二つの信号電流を `i1(t),i2(t)`、抵抗をともに `R` とすると、二抵抗の平均消費電力は

`P+ = R/T ∫[i1(t)+i2(t)]²dt`

`P- = R/T ∫[i1(t)-i2(t)]²dt`

である。その差は

`P+ - P- = 4R/T ∫i1(t)i2(t)dt`

となる。

`i1(t)` が電圧 `u(t)` に比例し、`i2(t)` が電流 `i(t)` に比例するよう変成されていれば、右辺は `u(t)i(t)` の周期平均、すなわち有効電力に比例する。熱電変換では温度差による起電力を利用し、固定過去問ではゼーベック効果の識別も必要になる。

ここで覚えるべき核は、平方した二信号の「和側−差側」を取ると交差項 `4i1i2` だけが残り、平均有効電力へつながることである。

### 5.13 電力量測定

電力量は電力を時間で積分した量で、

`W = ∫P(t)dt`

である。電力が一定なら

`W = Pt`

となる。SI単位はJだが、電力量の実務・問題ではWh、kWh、MWhも使う。例えば `1 kWh = 3.6 MJ` である。

CT・VTを介した教育用理想モデルで、二次側電力を積算して電力量 `W2` を得た場合は

`W1 = kV kI W2`

として一次側へ戻す。先に電力を一次側へ換算してから時間を掛けても同じである。

### 5.14 新幹線の25kV・大電流計測への接続

新幹線の25kV交流や主回路の大電流を、一般の計器へそのまま入力して測ると考えてはいけない。本Topicでは、CTで大電流を小さな二次電流へ、VTで高電圧を小さな二次電圧へ変成し、二次側の計器指示を変成比で一次側へ戻す教育用モデルとして理解する。

ここで用いる25kVという電圧値は系列の題材であり、特定車両・変電所のCT・VT定格、精度階級、結線、負担等を実値として追加しない。実設備値を教材へ入れる場合は別途一次資料で確認する。

### 5.15 頻出ミス・ひっかけ

- 電圧計を直列、電流計を並列につなぐ。
- 電圧計の入力抵抗は小さい方がよい、電流計の内部抵抗は大きい方がよいと逆に覚える。
- 分流器に全電流 `I` が流れるとしてしまい、`I-Im` を使わない。
- 倍率器を並列に接続する。
- エアトン分流器で切替位置ごとの枝構成を描き直さず、固定の合成抵抗として扱う。
- CTの変流比 `I1/I2` と巻数比 `N1/N2` を同じ向きで書く。理想CTでは `I1/I2=N2/N1` である。
- CT二次開放禁止とVT二次短絡禁止を逆にする。
- VTの二次指示値を一次電圧と取り違え、変圧比を掛け忘れる。
- 容量分圧で電圧比を抵抗分圧と同じ向きにしてしまう。直列コンデンサでは電圧は容量に反比例する。
- コンデンサ形VTで開放分圧だけを求め、計器内部インピーダンスを接続した後の等価回路を無視する。
- 交流電力を常に `UI` とし、位相差 `cosφ` を落とす。
- 電力と電力量を混同し、時間積分を忘れる。

### 5.17 公式・解法まとめ

- 電圧計: 測定対象へ並列、理想入力抵抗 `∞`
- 電流計: 測定枝へ直列、理想内部抵抗 `0`
- 分流器: `Rs=ImRm/(I-Im)=Rm/(m-1)`
- 倍率器: `Rs=V/Im-Rm=(n-1)Rm`
- CT: `I1/I2=N2/N1=kI`、`I1=kI I2`、二次開放禁止
- VT: `V1/V2=N1/N2=kV`、`V1=kV V2`、二次短絡禁止
- 容量分圧: `V0=C1/(C1+C2)V1`
- コンデンサ形VTの補償条件: `ω²L(C1+C2)=1`
- 静電電圧計: 駆動力 `∝V²`
- 交流有効電力: `P=1/T∫ui dt=UI cosφ`
- 電力量: `W=∫Pdt`、一定電力なら `W=Pt`
- CT・VTを介する理想モデル: `P1=kVkIP2`、`W1=kVkIW2`
- 共通手順: `接続確認→内部抵抗・変成比確認→回路式→指示値→一次側量`

## 6. 3段階例題

### 6.1 基礎例題: 分流器と倍率器

最大目盛電流 `Im=2.0 mA`、内部抵抗 `Rm=50 Ω` の計器がある。この計器を、(1) 最大0.10 Aの電流計、(2) 最大10 Vの電圧計として用いるとき、必要な分流器抵抗と倍率器抵抗を求める。

(1) 電流計では分流器を並列に入れる。計器へ `2.0 mA`、分流器へ

`0.10-0.002=0.098 A`

が流れる。両枝の電圧が等しいから

`Rs = ImRm/(I-Im)`

`=(0.002×50)/0.098`

`=1.02 Ω`

となる。

(2) 電圧計では倍率器を直列に入れる。10 Vで最大目盛電流 `2.0 mA` を流せばよいので

`Rs = V/Im - Rm`

`=10/0.002-50`

`=4950 Ω`

`=4.95 kΩ`

となる。

分流器は並列、倍率器は直列であることを回路式と一緒に確認する。

### 6.2 本試験標準例題: CT・VTを介した電力・電力量

教育用理想モデルとして、一次1000 Aに対して二次5 AとなるCTと、一次25 kVに対して二次100 VとなるVTを用いて単相交流電力を測る。二次側電力計が `120 W` を示し、この状態が15分続いた。一次側の有効電力と電力量を求める。

CTの変流比は

`kI=1000/5=200`

VTの変圧比は

`kV=25000/100=250`

である。理想変成比だけを考えるので、一次側有効電力は

`P1=kVkIP2`

`=250×200×120`

`=6.0×10^6 W`

`=6.0 MW`

となる。

15分は `0.25 h` だから、一次側電力量は

`W1=P1t`

`=6.0 MW×0.25 h`

`=1.5 MWh`

である。

解法順は「二次側指示値を読む→CT比・VT比を確認→一次側電力へ戻す→時間を掛けて電力量」である。

### 6.3 複合・ひっかけ例題: エアトン分流器の切替レンジ

最大目盛電流 `Im=10 mA`、内部抵抗 `Rm=100 Ω` の計器に、`R1=1 Ω`、`R2=9 Ω`、`R3=90 Ω` のエアトン分流器を接続する。切替位置aでは計器枝が `Rm+R2+R3`、分流枝が `R1`、位置bでは計器枝が `Rm+R3`、分流枝が `R1+R2`、位置cでは計器枝が `Rm`、分流枝が `R1+R2+R3` となる。各位置の最大測定電流を求める。

位置aでは計器枝の電圧は

`Va=Im(Rm+R2+R3)`

`=0.010×(100+9+90)`

`=1.99 V`

である。同じ電圧が `R1=1 Ω` に加わるので分流電流は `1.99 A`。したがって

`Ia=1.99+0.010=2.00 A`

となる。

位置bでは

`Vb=0.010×(100+90)=1.90 V`

分流枝は `R1+R2=10 Ω` だから分流電流は `0.190 A`。よって

`Ib=0.190+0.010=0.200 A`

となる。

位置cでは

`Vc=0.010×100=1.00 V`

分流枝は `R1+R2+R3=100 Ω` なので分流電流は `0.010 A`。よって

`Ic=0.010+0.010=0.020 A`

となる。

答えは `2.00 A / 0.200 A / 0.020 A`。ひっかけは、三位置で同じ分流抵抗を使うと考えず、切替ごとに計器枝と分流枝を描き直す点にある。
