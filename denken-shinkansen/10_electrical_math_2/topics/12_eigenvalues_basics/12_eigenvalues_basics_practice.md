# 解答・完全解説

## 問1 正答 1

特性方程式は

```text
det(λI-A)
= det([[λ-2,0],[0,λ+1]])
= (λ-2)(λ+1)
= 0
```

である。したがって固有値は

```text
λ=2, -1
```

であり、正答は1。

対角行列では対角成分が固有値になるが、本Topicでは特性方程式から確認できることを重視する。

## 問2 正答 2

`λ=3` を

```text
(A-λI)v=0
```

へ代入する。

```text
A-3I = [[-1,1],[1,-1]]
```

よって

```text
-v1+v2=0
```

から `v1=v2` である。したがって `[1,1]^T` は固有ベクトルであり、正答は2。

`[1,-1]^T` は `λ=1` に対応する。固有ベクトルは非零定数倍しても同じ固有方向を表す。

## 問3 正答 4

```text
λI-A
= [[λ-1,-2],[0,λ-3]]
```

なので、

```text
det(λI-A)
= (λ-1)(λ-3)
= λ^2-4λ+3
```

となる。正答は4。

2×2行列 `[[a,b],[c,d]]` の一般式 `λ^2-(a+d)λ+(ad-bc)` でも同じ結果になる。

## 問4 正答 3

```text
λI-A
= [[λ+2,3],[-3,λ+2]]
```

より、

```text
det(λI-A)
= (λ+2)^2+9
= λ^2+4λ+13
= 0
```

したがって

```text
λ=-2±3j
```

である。両固有値の実部は `-2<0` なので各モードは減衰し、原点は漸近安定である。正答は3。

複素固有値を含むこと自体は不安定条件ではない。見るべき量は実部である。

## 問5 正答 5

```text
det(λI-A)
= det([[λ,-1],[6,λ+5]])
= λ(λ+5)+6
= λ^2+5λ+6
= (λ+2)(λ+3)
```

より、

```text
λ=-2,-3
```

である。正答は5。

両方の実部が負なので、この行列を係数行列とする連続時間同次線形系は漸近安定である。

## 問6 正答 2

まず

```text
det(sI-Acl)
= det([[s,-1],[p,s+1+q]])
= s(s+1+q)+p
= s^2+(1+q)s+p
```

である。

指定固有値 `-4,-5` から目標特性多項式を作る。

```text
(s+4)(s+5)
= s^2+9s+20
```

係数比較すると、

```text
1+q=9
p=20
```

したがって

```text
p=20
q=8
```

であり、正答は2。

固定H28問4(1)と同じく、「対象行列の特性多項式を作る → 指定固有値から目標多項式を作る → 係数比較する」という手順を使う。

## 問7 正答 4

特性方程式を因数分解する。

```text
λ^2+5λ-6
= (λ-1)(λ+6)
```

したがって固有値は

```text
λ=1,-6
```

である。`λ=1` は実部が正なので増大するモードを持ち、線形系は不安定である。正答は4。

固有値の和が負であっても、正の実部を持つ固有値が1つあれば不安定である。

## 問8 正答 1

```text
λI-A
= [[λ,2],[-2,λ]]
```

より、

```text
det(λI-A)
= λ^2+4
= 0
```

したがって

```text
λ=±2j
```

である。実部は0であり、本Topicの基本判定では境界ケースとして扱う。少なくとも `Re(λ)<0` の条件を満たさないため、漸近安定とは判定しない。正答は1。

「複素固有値だから不安定」とする選択肢2は誤りである。複素固有値でも実部が負なら減衰する。

## 問9 解答

(1) 特性方程式は

```text
det(λI-A)
= det([[λ-4,-1],[-2,λ-3]])
= (λ-4)(λ-3)-2
= λ^2-7λ+10
= (λ-5)(λ-2)
= 0
```

よって

```text
λ=5,2
```

である。

(2) `λ=5` では、

```text
(A-5I)v
= [[-1,1],[2,-2]] [v1,v2]^T
= 0
```

より `v1=v2`。一例として

```text
v5=[1,1]^T
```

を取れる。

`λ=2` では、

```text
(A-2I)v
= [[2,1],[2,1]] [v1,v2]^T
= 0
```

より `2v1+v2=0`。一例として

```text
v2=[1,-2]^T
```

を取れる。

(3) `λ=5, v=[1,1]^T` について、

```text
Av
= [[4,1],[2,3]][1,1]^T
= [5,5]^T
= 5[1,1]^T
= λv
```

となり、検算できる。

## 問10 解答

(1)

```text
bf
= [[0],[1]][f1,f2]
= [[0,0],[f1,f2]]
```

したがって

```text
A-bf
= [[0,1],[-f1,-2-f2]]
```

である。

(2)

```text
sI-(A-bf)
= [[s,-1],[f1,s+2+f2]]
```

なので、

```text
det[sI-(A-bf)]
= s(s+2+f2)+f1
= s^2+(2+f2)s+f1
```

となる。

(3) 指定固有値 `-3,-6` から

```text
(s+3)(s+6)
= s^2+9s+18
```

を作る。係数比較より、

```text
2+f2=9
f1=18
```

したがって

```text
f1=18
f2=7
```

である。

(4) 代入後は

```text
A-bf = [[0,1],[-18,-9]]
```

であり、

```text
det[sI-(A-bf)]
= s^2+9s+18
= (s+3)(s+6)
```

となる。よって固有値は確かに `-3,-6` である。

この解法は固定H28問4(1)の要求事項を、数値だけ変えて反復するものである。

## 問11 解答

(1)

```text
λI-A
= [[λ+1,4],[-1,λ+1]]
```

より、

```text
det(λI-A)
= (λ+1)^2+4
= λ^2+2λ+5
= 0
```

したがって

```text
λ=-1±2j
```

である。

(2) `λ=-1+2j` に対して、

```text
A-λI
= [[-2j,-4],[1,-2j]]
```

なので、

```text
-2j v1 - 4v2 = 0
```

を満たす一例として

```text
v=[2j,1]^T
```

を取れる。実際、もう一方の式 `v1-2jv2=0` も満たす。

(3) 両固有値の実部は

```text
Re(λ)=-1<0
```

である。したがって各モードは減衰し、原点は漸近安定である。

## 問12 解答

(1)

```text
sI-Ag
= [[s,-1],[g1,s+1+g2]]
```

より、

```text
det(sI-Ag)
= s(s+1+g2)+g1
= s^2+(1+g2)s+g1
```

である。

(2) 指定固有値が `-1±2j` なので、

```text
[s-(-1+2j)][s-(-1-2j)]
= (s+1-2j)(s+1+2j)
= (s+1)^2+4
= s^2+2s+5
```

となる。

(3) 係数比較すると、

```text
1+g2=2
g1=5
```

よって

```text
g1=5
g2=1
```

である。

(4) 得られた固有値の実部はどちらも `-1<0` なので、対応する連続時間線形系の原点は漸近安定である。

この問題でも、一般的な状態フィードバック設計へ拡張せず、特性多項式と指定固有値の係数比較だけを扱っている。
