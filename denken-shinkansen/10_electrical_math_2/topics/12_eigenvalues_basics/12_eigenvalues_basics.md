## 過去問から固定する教材内必要説明

### 1. 固有値と特性方程式

正方行列 `A` に対して、零でないベクトル `v` が

```text
A v = λ v
```

を満たすとき、`λ` を固有値、`v` を対応する固有ベクトルとする。

これを

```text
(A-λI)v = 0
```

と書き、零でない `v` が存在する条件から

```text
det(λI-A)=0
```

を得る。これが特性方程式である。

2×2行列

```text
A = [[a,b],[c,d]]
```

では、

```text
det(λI-A)
= (λ-a)(λ-d)-bc
= λ^2-(a+d)λ+(ad-bc)
```

となる。

### 2. 固有ベクトル

固有値 `λ` を特性方程式から求めた後、

```text
(A-λI)v=0
```

を解いて対応する固有ベクトルを求める。

固有ベクトルは零ベクトルを除き、非零定数倍しても同じ方向を表す。正規化や抽象線形代数へ深入りせず、「その固有値に対応する状態変化の方向」として扱う。

### 3. 線形系の安定性との関係

連続時間の同次線形系

```text
xdot = A x
```

では、固有値 `λ` に対応するモードは基本的に `e^(λt)` の増減を持つ。

- すべての固有値の実部が負: 各モードが減衰し、原点は漸近安定。
- 実部が正の固有値が1つでもある: そのモードが増大し、不安定。
- 実部0の固有値を含む境界ケース: 固有値の重複や行列構造も関係するため、実部0だけで一律に漸近安定と判定しない。

本Topicではこの最低限までとし、Lyapunov法、可制御性・可観測性へ広げない。

### 4. H28 問4 (1) の解法アルゴリズム

与えられた

```text
A = [[0,1],[0,-1]]
b = [[0],[1]]
f = [f1,f2]
```

から、

```text
A-bf = [[0,1],[-f1,-1-f2]]
```

とする。

次に、

```text
det[sI-(A-bf)]
= det([[s,-1],[f1,s+1+f2]])
= s^2+(1+f2)s+f1
```

を得る。

指定固有値が `-3, -4` なので、必要な特性多項式は

```text
(s+3)(s+4)=s^2+7s+12
```

である。係数比較により

```text
1+f2 = 7
f1 = 12
```

したがって

```text
f = (12,6)
```

となる。

重要なのは答えを暗記することではなく、

```text
行列を作る
→ det(sI-Acl) を計算する
→ 指定固有値から特性多項式を作る
→ 係数比較する
```

という再利用可能な手順である。

## SPECから固定する必須説明

### 固有値

- 定義 `Av=λv`
- 特性方程式との関係
- 2×2での計算
- 複素固有値が現れる場合も固有値の実部で増減を見ること

### 固有ベクトル

- `(A-λI)v=0` から求める
- 零ベクトルは不可
- 非零定数倍は同じ固有方向
- モードの方向としての意味

### 特性方程式

- `det(λI-A)=0`
- 2×2行列での展開
- 根が固有値であること
- 指定固有値から逆に特性多項式を作れること

### 線形系の安定性との関係

- `xdot=Ax` のモードと `e^(λt)`
- `Re(λ)<0` と減衰
- `Re(λ)>0` と発散
- 実部0を含む場合の安易な断定を避ける
