## 過去問から固定する教材内必要説明

### 1. 固有値と特性方程式

正方行列 `A` に対して、零でないベクトル `v` が

```text
A v = λ v
```

を満たすとき、`λ` を固有値、`v` を対応する固有ベクトルとする。

これを

```text
(A-λI)v = 0
```

と書き、零でない `v` が存在する条件から

```text
det(λI-A)=0
```

を得る。これが特性方程式である。

2×2行列

```text
A = [[a,b],[c,d]]
```

では、

```text
det(λI-A)
= (λ-a)(λ-d)-bc
= λ^2-(a+d)λ+(ad-bc)
```

となる。

### 2. 固有ベクトル

固有値 `λ` を特性方程式から求めた後、

```text
(A-λI)v=0
```

を解いて対応する固有ベクトルを求める。

固有ベクトルは零ベクトルを除き、非零定数倍しても同じ方向を表す。正規化や抽象線形代数へ深入りせず、「その固有値に対応する状態変化の方向」として扱う。

### 3. 線形系の安定性との関係

連続時間の同次線形系

```text
xdot = A x
```

では、固有値 `λ` に対応するモードは基本的に `e^(λt)` の増減を持つ。

- すべての固有値の実部が負: 各モードが減衰し、原点は漸近安定。
- 実部が正の固有値が1つでもある: そのモードが増大し、不安定。
- 実部0の固有値を含む境界ケース: 固有値の重複や行列構造も関係するため、実部0だけで一律に漸近安定と判定しない。

本Topicではこの最低限までとし、Lyapunov法、可制御性・可観測性へ広げない。

### 4. H28 問4 (1) の解法アルゴリズム

与えられた

```text
A = [[0,1],[0,-1]]
b = [[0],[1]]
f = [f1,f2]
```

から、

```text
A-bf = [[0,1],[-f1,-1-f2]]
```

とする。

次に、

```text
det[sI-(A-bf)]
= det([[s,-1],[f1,s+1+f2]])
= s^2+(1+f2)s+f1
```

を得る。

指定固有値が `-3, -4` なので、必要な特性多項式は

```text
(s+3)(s+4)=s^2+7s+12
```

である。係数比較により

```text
1+f2 = 7
f1 = 12
```

したがって

```text
f = (12,6)
```

となる。

重要なのは答えを暗記することではなく、

```text
行列を作る
→ det(sI-Acl) を計算する
→ 指定固有値から特性多項式を作る
→ 係数比較する
```

という再利用可能な手順である。

# 解説本文

## 1. このテーマで電験は何を問うか

本Topicでは、抽象的な線形代数ではなく、2×2行列から特性方程式を作り、固有値を求め、必要なら指定固有値から特性多項式を逆に作って係数比較する力を扱う。第二種二次「機械・制御」では、行列が与えられたときに計算手順を崩さず記述できることが重要である。

この章を終えた時点で、次をできる状態を目標とする。

- `Av=λv` の意味を説明できる。
- `det(λI-A)=0` から2×2行列の固有値を求められる。
- 固有値を代入して `(A-λI)v=0` から固有ベクトルを求められる。
- 指定固有値から特性多項式を作り、未知係数を比較できる。
- 連続時間線形系では固有値の実部から減衰・発散を判断できる。
- 実部0を含む境界ケースを安易に漸近安定と断定しない。

## 2. 固有値と固有ベクトル

正方行列 `A` がベクトル `v` に作用したとき、方向が変わらず大きさだけが `λ` 倍される関係

```text
A v = λ v
```

が成り立つことがある。この `λ` が固有値、零でない `v` が対応する固有ベクトルである。

固有ベクトルは大きさそのものではなく方向が重要である。したがって `v` が固有ベクトルなら、`2v` や `-3v` のような非零定数倍も同じ固有値に対応する固有ベクトルである。零ベクトルはどの `λ` に対しても式を満たしてしまうため、固有ベクトルには含めない。

## 3. 特性方程式を作る

`Av=λv` を移項すると、

```text
(A-λI)v = 0
```

となる。零でない `v` が存在するためには、係数行列が逆行列を持たない必要がある。その条件を2×2行列では行列式を用いて

```text
det(λI-A)=0
```

と書く。これが特性方程式である。

一般の2×2行列

```text
A = [[a,b],[c,d]]
```

について、

```text
λI-A = [[λ-a,-b],[-c,λ-d]]
```

なので、

```text
det(λI-A)
= (λ-a)(λ-d)-bc
= λ^2-(a+d)λ+(ad-bc)
```

となる。この二次方程式の根が固有値である。

符号ミスを避けるため、いきなり展開式を暗記して使うより、まず `λI-A` を行列として書いてから2×2行列式を計算する。

## 4. 固有ベクトルを求める

固有値 `λ` が求まったら、

```text
(A-λI)v=0
```

へ代入する。`v=[v1,v2]^T` として連立一次方程式を解けばよい。

たとえば

```text
A = [[2,1],[1,2]]
```

の固有値 `λ=3` では、

```text
(A-3I)v
= [[-1,1],[1,-1]] [v1,v2]^T
= 0
```

より `v1=v2` である。したがって一例として

```text
v = [1,1]^T
```

を取れる。`[2,2]^T` でも同じ固有方向である。

## 5. 線形系のモードと安定性

連続時間の同次線形系

```text
xdot = A x
```

では、固有値 `λ` に対応する変化は基本的に `e^(λt)` の増減として現れる。

実固有値なら、

```text
λ < 0  → e^(λt) は減衰
λ > 0  → e^(λt) は増大
```

である。複素固有値

```text
λ = α ± jβ
```

なら、振動成分を持ちながら包絡の大きさは `e^(αt)` で決まる。したがって安定性を見るときは虚部ではなく実部 `α` を確認する。

連続時間線形系では、

- すべての固有値で `Re(λ)<0`: 各モードが減衰し、原点は漸近安定。
- `Re(λ)>0` の固有値が1つでもある: 増大するモードがあり、不安定。
- `Re(λ)=0` を含む: 境界ケースであり、重複や行列構造を確認せず漸近安定とは断定しない。

ここではこの判定関係までとし、Lyapunov法や一般的な状態空間設計へは進まない。

## 6. 指定固有値から特性多項式を作る

固有値が `λ1, λ2` と指定されているなら、その特性多項式は

```text
(s-λ1)(s-λ2)
```

で作れる。

たとえば指定固有値が `-3, -4` なら、

```text
(s+3)(s+4)
= s^2+7s+12
```

である。

一方、未知パラメータを含む行列から

```text
s^2 + p s + q
```

の形が得られたなら、係数比較で

```text
p=7
q=12
```

と置けばよい。H28 問4 (1) ではこの手順が中心になる。

## 7. H28 問4 (1) 型の解法手順

固定過去問で必要な手順は次の4段階である。

1. 与えられた行列から対象行列 `A-bf` を作る。
2. `det[sI-(A-bf)]` を計算し、未知係数を含む特性多項式を得る。
3. 指定固有値から目標特性多項式を作る。
4. 同じ次数の係数を比較し、未知数を求める。

固定問題では、

```text
A-bf = [[0,1],[-f1,-1-f2]]
```

なので、

```text
det[sI-(A-bf)]
= s^2+(1+f2)s+f1
```

となる。指定固有値 `-3,-4` から

```text
s^2+7s+12
```

を作り、

```text
1+f2=7
f1=12
```

より

```text
f=(12,6)
```

を得る。

このTopicでは、この行列がどのような状態フィードバック設計から導かれるかは扱わない。与えられた行列から固有値条件を満たす係数を求める計算だけを対象とする。

## 8. 頻出ミス

### `A-λI` と `λI-A` を途中で混ぜる

どちらを使っても根は同じになるが、途中の符号が変わる。1つの計算では表記を統一する。本章では特性方程式を `det(λI-A)=0` で統一する。

### 固有値を求めた後に固有ベクトルへ代入しない

固有値と固有ベクトルは別の量である。固有値を求めた後、必要なら `(A-λI)v=0` を解く。

### 指定固有値の符号を逆にする

固有値が `-3` なら因子は `(s+3)` である。`(s-3)` としない。

### 複素固有値は不安定だと決めつける

安定性は実部を見る。`-2±3j` なら実部は `-2` なので減衰する振動モードである。

### 実部0を漸近安定と断定する

実部0は境界ケースである。本Topicの範囲では追加条件を調べずに漸近安定とは判定しない。

## 9. 3段階例題

### 例題1 基礎: 固有値と固有ベクトル

次の行列の固有値と、それぞれに対応する固有ベクトルを1つずつ求める。

```text
A = [[2,1],[1,2]]
```

特性方程式は

```text
det(λI-A)
= det([[λ-2,-1],[-1,λ-2]])
= (λ-2)^2-1
= λ^2-4λ+3
= (λ-1)(λ-3)
= 0
```

したがって固有値は

```text
λ=1, 3
```

である。

`λ=3` では

```text
(A-3I)v=0
→ -v1+v2=0
```

より、

```text
v=[1,1]^T
```

を取れる。

`λ=1` では

```text
(A-I)v=0
→ v1+v2=0
```

より、

```text
v=[1,-1]^T
```

を取れる。どちらも非零定数倍してよい。

### 例題2 本試験標準: 指定固有値から係数を決める

次の行列

```text
Acl = [[0,1],[-f1,-2-f2]]
```

の固有値を `-2,-5` にしたい。`f1,f2` を求める。

まず、

```text
det(sI-Acl)
= det([[s,-1],[f1,s+2+f2]])
= s(s+2+f2)+f1
= s^2+(2+f2)s+f1
```

である。

指定固有値から目標特性多項式を作る。

```text
(s+2)(s+5)
= s^2+7s+10
```

係数比較すると、

```text
2+f2=7
f1=10
```

よって

```text
f1=10
f2=5
```

となる。

検算として、得られた行列の特性多項式は `s^2+7s+10` であり、根は確かに `-2,-5` である。

### 例題3 複合・ひっかけ: 複素固有値と安定性

次の行列について固有値を求め、対応する連続時間線形系 `xdot=Ax` の安定性を判定する。

```text
A = [[-2,-3],[3,-2]]
```

特性方程式は

```text
det(λI-A)
= det([[λ+2,3],[-3,λ+2]])
= (λ+2)^2+9
= λ^2+4λ+13
= 0
```

したがって、

```text
λ = -2 ± 3j
```

である。虚部があるため振動成分を持つが、実部は両方とも `-2<0` である。したがって各モードは減衰し、この線形系の原点は漸近安定である。

`λ=-2+3j` に対しては、

```text
(A-λI)v=0
```

から一例として

```text
v=[j,1]^T
```

を取れる。

「複素固有値だから不安定」ではなく、実部を見ることがひっかけ回避の要点である。

## 10. 新幹線への接続

新幹線の速度制御や電気機器の過渡現象を、実車値を用いない教育用の2変数線形モデル

```text
xdot = A x
```

で近似したとする。このとき、行列 `A` の固有値は、モデル内の変化が時間とともに減衰するか増大するかを読む手掛かりになる。

## 12. 公式・解法まとめ

固有値・固有ベクトル:

```text
Av=λv
(A-λI)v=0
```

特性方程式:

```text
det(λI-A)=0
```

2×2行列 `A=[[a,b],[c,d]]`:

```text
λ^2-(a+d)λ+(ad-bc)=0
```

指定固有値 `λ1,λ2` から作る特性多項式:

```text
(s-λ1)(s-λ2)
```

連続時間線形系の基本判定:

```text
全固有値 Re(λ)<0 → 漸近安定
Re(λ)>0 を1つでも含む → 不安定
Re(λ)=0 を含む → 境界ケース。追加条件なしに漸近安定と断定しない
```

本Topicの解法手順:

```text
対象行列を作る
→ det(λI-A) または det(sI-A) を計算
→ 特性方程式を解く／指定固有値から特性多項式を作る
→ 必要なら係数比較
→ 必要なら (A-λI)v=0 で固有ベクトル
→ 安定性は固有値の実部を確認
```
