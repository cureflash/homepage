## SPECから固定する必須説明

### 1. 行列・ベクトル

行列を「複数の一次方程式の係数を規則的に並べたもの」として導入し、行ベクトル・列ベクトルの役割、要素の位置を回路方程式と対応させる。

### 2. 行列積

`A x` の各成分が、係数×未知数の和になって一つの一次方程式を再現することを2×2例で確認する。掛ける順序を入れ替えられないことも回路式との対応で示す。

### 3. 逆行列

`A x=b` に左から `A^-1` を掛けて `x=A^-1b` を得る。2×2逆行列を実際に計算し、逆行列が存在しない場合はこの解法を使えないことだけを必要最小限に示す。

### 4. 連立一次方程式・係数行列

加減法・代入法で解ける連立一次方程式と行列法が同じ問題を解いていることを示す。未知数が増えたとき、係数行列を使う利点が大きくなることへ接続する。

### 5. アドミタンス行列の考え方

節点ごとのKCLを並べ、節点電流ベクトル `I`、節点電圧ベクトル `V`、アドミタンス行列 `Y` の関係 `I=YV` として表せることを示す。対角成分・非対角成分は簡単な抵抗回路の節点方程式から読み取る。

電力潮流の詳細アルゴリズム、Newton-Raphson法、系統の非線形方程式反復は扱わない。

## 解法アルゴリズム

1. 未知量と正方向を決める。
2. KCLまたはKVLで必要な一次方程式を立てる。
3. 未知数の並び順を固定する。
4. 各式を同じ未知数順に整理する。
5. 係数を行列 `A`、未知数をベクトル `x`、定数を `b` に並べて `A x=b` とする。

8. 回路問題では得られた電流・電圧の符号を、最初に仮定した向きと照合する。
9. 節点方程式では `I=YV` の形に整理し、係数配置がKCLと一致することを検算する。

# 解説本文

## 1. このテーマで電験は何を問うか

行列そのものの抽象的な性質を問うのではなく、KCL・KVLで得た複数の一次方程式を正しく並べ、未知電流・未知電圧を解く力を問う。第二種一次「理論」では、閉路電流法、節点電位法、交流定常回路の複素係数が同じ `A x=b` の形へ整理できることが重要である。

この章を終えた時点で、次をできる状態を目標とする。

- 回路図から未知量と正方向を決める。
- KCL・KVLから一次方程式を立てる。
- 複数の式を係数行列へ変換する。
- 2×2逆行列または加減法で未知量を求める。
- 負の電流・電圧を「仮定方向と逆」と読める。
- 交流回路の複素係数でも同じ行列計算を使える。
- 節点方程式を `I=YV` の形にまとめられる。

## 2. 行列は連立一次方程式をまとめる表記

次の2式を考える。

```text
2x + y  = 5
 x + 3y = 7
```

未知数の順を `x, y` に固定すると、

```text
A = [[2,1],[1,3]]
x = [x,y]^T
b = [5,7]^T
```

として、

```text
A x = b
```

と書ける。行列 `A` の1行目は第1式、2行目は第2式に対応する。列は未知数の順に対応するので、途中で `x, y` の並びを入れ替えてはいけない。

`A x` の1成分目は `2x+y`、2成分目は `x+3y` である。したがって行列積は、元の連立一次方程式をそのまま再現している。行列はKCL・KVLの代わりではなく、KCL・KVLで作った式を崩さず整理するための道具である。

また、行列積は順序を自由に交換できない。ここでは係数行列を未知ベクトルの左から掛ける `A x` が回路方程式を表す。

## 3. KVLから係数行列を作る

2つの閉路が抵抗 `r` を共有し、閉路電流を同じ回転方向に `Ia, Ib` と仮定する。左閉路の固有抵抗を `R1`、右閉路を `R2`、左側だけに電圧源 `E` があるとする。

共有抵抗を左閉路方向に流れる電流は `Ia-Ib` なので、KVLは

```text
R1 Ia + r(Ia-Ib) = E
R2 Ib + r(Ib-Ia) = 0
```

整理して、

```text
(R1+r)Ia - r Ib = E
-r Ia + (R2+r)Ib = 0
```

したがって、

```text
[[R1+r,-r],[-r,R2+r]] [Ia,Ib]^T = [E,0]^T
```

となる。非対角成分が `-r` になるのは暗記事項ではなく、共有枝の電流が差 `Ia-Ib` になるためである。

R8 問3のように左右の固有抵抗部分が同じ構成なら、対角成分も同じ形になる。重要なのは図の電流方向から各項の符号を作ることであり、行列の形を先に暗記して回路へ当てはめないことである。

## 4. 閉路電流と枝電流を区別する

閉路電流は計算のために置いた未知量であり、共有枝を実際に流れる枝電流とは一致しない場合がある。

2つの閉路電流 `I1, I3` が共有枝を逆向きに通るなら、その枝電流は基準方向に応じて

```text
Ibranch = I1 - I3
```

となる。別の共有枝で基準方向が両閉路電流と逆なら、

```text
Ibranch = -I2 - I3
```

のようになる。

先に矢印を決め、その矢印に沿う成分を正、逆を負として足し合わせる。答えが負になった場合は計算失敗ではなく、「実際の向きが最初の仮定と逆」である。

## 5. KCLから節点方程式を作る

節点電位を未知数 `V` とし、既知電位 `Ek` の節点と抵抗 `Rk` で接続されている枝を考える。既知側から未知節点へ流れ込む向きを正に取れば、各枝電流は

```text
Ik = (Ek - V)/Rk
```

である。外部へ流れる電流がなければKCLから

```text
Σ (Ek - V)/Rk = 0
```

となる。

たとえば全抵抗が同じ `R` で、既知電位が `E, 2E, 3E, 4E` なら、共通の `1/R` を除いて

```text
(E-V)+(2E-V)+(3E-V)+(4E-V)=0
```

すなわち

```text
10E - 4V = 0
V = 5E/2
```

となる。さらに同じ抵抗で接地枝を1本追加すると、その枝電流 `V/R` が加わるので

```text
10E - 4V = V
V = 2E
```

となる。

この手順は節点が複数でも同じで、各節点についてKCLを1本ずつ立てれば連立一次方程式になる。

## 6. アドミタンス行列 `I=YV`

2節点の電位を `V1, V2`、各節点から接地へのアドミタンスを `Y1, Y2`、節点間のアドミタンスを `Y12` とする。節点へ外部から注入する電流を `I1, I2` とすると、KCLから

```text
I1 = (Y1+Y12)V1 - Y12 V2
I2 = -Y12 V1 + (Y2+Y12)V2
```

したがって

```text
[I1,I2]^T
=
[[Y1+Y12,-Y12],[-Y12,Y2+Y12]] [V1,V2]^T
```

すなわち

```text
I = Y V
```

と書ける。

対角成分はその節点につながるアドミタンスの和、非対角成分は節点間アドミタンスの負値として、この簡単な回路ではKCLから直接読み取れる。ここでは線形な節点方程式を行列にまとめるところまで扱い、電力潮流の非線形方程式や反復計算には進まない。

新幹線のき電・車両回路を教育用の複数節点回路へ簡略化した場合も、各節点のKCLを同じ形式で整理できる。実設備固有値は使わず、行列化の考え方だけを接続する。

## 7. 2×2逆行列で解く

一般の2×2行列

```text
A = [[a,b],[c,d]]
```

について、分母 `ad-bc` が0でない場合、

```text
A^-1 = 1/(ad-bc) [[d,-b],[-c,a]]
```

を使える。`A x=b` の左から `A^-1` を掛けると、

```text
x = A^-1 b
```

となる。

`ad-bc=0` のときはこの逆行列による解法を使えない。本章ではこの条件以上の抽象的な行列論には進まない。

逆行列を使った結果は、2元程度なら加減法・代入法でも再計算し、一致を確認すると符号ミスを発見しやすい。

## 8. 交流回路では係数が複素数になる

交流定常状態では、実数の抵抗だけでなく複素インピーダンス・複素アドミタンスが係数に入るが、連立一次方程式と行列演算の手順は変わらない。

直列RLなら

```text
Z = R + jωL
```

であり、KVLでこの `Z` が電流の係数になる。抵抗とコンデンサが並列ならアドミタンスは

```text
Y = 1/R + jωC
```

であり、KCLでこの `Y` が節点電圧の係数になる。

したがって複素係数の `A x=b` をそのまま解けばよい。最後に求めたフェーザを極形式へ戻し、必要なら時間関数へ変換する。たとえば

```text
V = (4-j3)E/5
```

なら、大きさは `E`、偏角は `-tan^-1(3/4)` なので、実効値フェーザから瞬時値へ戻す場合は

```text
v(t) = √2 E cos(ωt - tan^-1(3/4))
```

となる。

## 9. 本試験で使う解法手順

1. 未知電流・未知電圧と正方向を決める。
2. KVLかKCLかを選び、回路図から式を立てる。
3. 未知数の並び順を固定する。
4. すべての式を同じ未知数順に整理する。
5. `A x=b` または `I=YV` へ変換する。
6. 2元なら加減法・代入法、必要なら2×2逆行列で解く。
7. 交流なら複素数のまま計算し、最後に大きさ・偏角へ戻す。
8. 負の解は仮定方向との関係で読む。
9. 元のKCL・KVLへ代入し、式を満たすか検算する。

## 10. 3段階例題

### 例題1 基礎: 連立一次方程式を行列で解く

次を行列で解く。

```text
2x + y  = 5
 x + 3y = 7
```

係数行列とベクトルは

```text
A = [[2,1],[1,3]]
xvec = [x,y]^T
b = [5,7]^T
```

である。

`ad-bc = 2×3-1×1=5` より、

```text
A^-1 = 1/5 [[3,-1],[-1,2]]
```

したがって

```text
[x,y]^T
= 1/5 [[3,-1],[-1,2]] [5,7]^T
= [8/5,9/5]^T
```

答えは

```text
x=8/5, y=9/5
```

である。元の2式へ代入すると両方を満たす。

### 例題2 本試験標準: 共有抵抗を含む2閉路

左閉路の固有抵抗 `R1=2 Ω`、右閉路の固有抵抗 `R2=3 Ω`、共有抵抗 `r=1 Ω`、左閉路の電圧源 `E=10 V` とする。閉路電流 `Ia, Ib` を同じ回転方向に取る。

KVLから

```text
3Ia - Ib = 10
-Ia + 4Ib = 0
```

よって

```text
[[3,-1],[-1,4]] [Ia,Ib]^T = [10,0]^T
```

逆行列は

```text
1/11 [[4,1],[1,3]]
```

なので、

```text
Ia = 40/11 A
Ib = 10/11 A
```

共有枝を `Ia` 向きに見た枝電流は

```text
Ia-Ib = 30/11 A
```

となる。非対角成分 `-1` と共有枝電流の差は、どちらも共有抵抗を2閉路が逆向きに通ることから生じる。

### 例題3 複合・ひっかけ: 複素アドミタンス行列

教育用の2節点交流回路を、単位をそろえた上で

```text
[[1+j,-j],[-j,1+j]] [V1,V2]^T = [1,0]^T
```

と表したとする。係数は複素数だが、解法は実数行列と同じである。

分母は

```text
(1+j)^2 - (-j)(-j) = 1+2j
```

したがって

```text
[V1,V2]^T
= 1/(1+2j) [[1+j,j],[j,1+j]] [1,0]^T
```

より

```text
V1 = (1+j)/(1+2j) = (3-j)/5
V2 = j/(1+2j)     = (2+j)/5
```

となる。ここで係数に `j` が含まれることを理由に実数部だけで先に計算してはいけない。複素数のまま連立式を解き、必要な場合だけ最後に極形式へ戻す。

## 13. 公式・解法まとめ

```text
A x = b
x = A^-1 b
```

2×2逆行列:

```text
[[a,b],[c,d]]^-1
= 1/(ad-bc) [[d,-b],[-c,a]]
```

ただし `ad-bc ≠ 0`。

共有抵抗を含む2閉路:

```text
(R1+r)Ia - rIb = E1
-rIa + (R2+r)Ib = E2
```

節点方程式:

```text
Σ Yk(V-Ek) = Iout
```

複数節点では

```text
I = YV
```

へ整理する。

交流でも係数が複素数になるだけで、`A x=b` の計算手順自体は同じである。
