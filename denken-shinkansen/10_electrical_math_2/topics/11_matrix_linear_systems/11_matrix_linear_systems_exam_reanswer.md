## R8 一次 理論 問3 (1)

閉路電流を `Ia, Ib` とすると、共有抵抗 `r` の電流は差で表されるため、KVLは

```text
(R1+R2+r)Ia - rIb = E
-rIa + (R1+R2+r)Ib = 0
```

となる。したがって

```text
[[R1+R2+r,-r],[-r,R1+R2+r]][Ia,Ib]^T=[E,0]^T
```

であり、選択肢は `ヨ`。

公式解答照合: `PASS`

```text
V_ba = E R2/(R1+R2)
```

となる。選択肢は `ニ`。

公式解答照合: `PASS`

## R6 一次 理論 問3 (1)

## R4 一次 理論 問3 (1)

節点aの電位を `V` とする。各抵抗が等しいのでKCLから

```text
(E-V)+(2E-V)+(3E-V)+(4E-V)=0
```

したがって

```text
10E-4V=0
V=5E/2
```

となる。選択肢は `ハ`。

公式解答照合: `PASS`

```text
V=2E
```

であり、選択肢は `ホ`。

```text
Y = 1/R+jωC
```

であり、KCLで電圧の係数となる。選択肢は `ロ`。

## R1 一次 理論 問2 (5)

問題条件 `R=ωL`、`1/R=ωC` を用いて2×2連立方程式を解くと

```text
V2/E = (2+j)/(1+2j)
     = (4-j3)/5
```

となる。大きさは `E`、偏角は `-tan^-1(3/4)` なので

```text
v2(t)=√2 E cos(ωt-tan^-1(3/4))
```

である。選択肢は `イ`。

公式解答照合: `PASS`

## R1 一次 理論 問6 (4)

対象枝では基準方向が `I2`, `I3` の双方と逆なので

```text
Ibranch = -I2-I3
```

となる。選択肢は `ハ`。

公式解答照合: `PASS`

## R1 一次 理論 問6 (5)

```text
D = R1R2+R2R3+R3R1
```

とおく。節点方程式から中央節点電位は

```text
V3 = E R2R3/D
```

なので、R2枝の電流は

```text
V3/R2 = E R3/D
```

である。またR4枝から `I3=E/R4`。前問の枝電流関係

```text
-I2-I3 = E R3/D
```

より

```text
I2 = E[-1/R4 - R3/D]
```

となる。選択肢は `イ`。

公式解答照合: `PASS`
