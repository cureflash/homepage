# 解答・完全解説

## 問1 正答 1

未知数の順を `[x,y]^T` に固定する。

第1式 `3x-2y=7` の係数は `[3,-2]`、第2式 `x+4y=5` の係数は `[1,4]` なので、

```text
A=[[3,-2],[1,4]]
b=[7,5]^T
```

である。

列を途中で入れ替えると元の連立方程式を再現できない。選択肢2は係数を列方向へ並べ替えており誤り、選択肢5は `-2` の符号を失っている。

## 問2 正答 2

行列積は各行と列ベクトルの積和で求める。

```text
Ax
=
[[2,-1],[3,4]][2,-1]^T
=
[2×2+(-1)×(-1), 3×2+4×(-1)]^T
=
[5,2]^T
```

よって正答は2。

`Ax` は元の一次方程式の左辺を再現する計算であり、要素ごとの単純な掛け算ではない。

## 問3 正答 2

係数行列は

```text
A=[[2,1],[1,3]]
```

である。2×2逆行列の分母は

```text
2×3-1×1=5
```

なので、

```text
A^-1=1/5 [[3,-1],[-1,2]]
```

したがって、

```text
[x,y]^T
=
1/5 [[3,-1],[-1,2]][5,7]^T
=
[8/5,9/5]^T
```

となる。

検算すると、

```text
2×8/5+9/5=5
8/5+3×9/5=7
```

で両式を満たす。よって正答は2。

## 問4 正答 1

共有抵抗 `r` を二つの閉路電流が逆向きに通るので、KVLは

```text
(R1+r)Ia-rIb=12
-rIa+(R2+r)Ib=0
```

である。数値を入れると、

```text
5Ia-2Ib=12
-2Ia+4Ib=0
```

したがって、

```text
[[5,-2],[-2,4]][Ia,Ib]^T=[12,0]^T
```

となる。

第2式から `Ia=2Ib`。これを第1式へ代入すると、

```text
10Ib-2Ib=12
8Ib=12
Ib=1.5 A
Ia=3 A
```

よって正答は1。

非対角成分が `-2` になるのは、共有抵抗の電流が差で表されるためである。

## 問5 正答 4

既知電位側から節点 `V` へ流れ込む向きを正とする。各抵抗が同じなので共通の `1/R` を除けば、KCLは

```text
(E-V)+(2E-V)+(4E-V)=0
```

である。

```text
7E-3V=0
V=7E/3
```

したがって正答は4。

節点電位は三つの既知電位の単純な和ではなく、KCLで求める。

## 問6 正答 1

問5の三枝に加え、節点 `V` から接地へ流れる電流 `V/R` が加わる。

```text
(E-V)+(2E-V)+(4E-V)=V
```

より、

```text
7E-3V=V
7E=4V
V=7E/4
```

したがって正答は1。

接地枝を追加した分だけ節点電位は問5の `7E/3` より低くなるので、この大小関係でも検算できる。

## 問7 正答 3

節点1では、

```text
I1=Y1V1+Y12(V1-V2)
=(Y1+Y12)V1-Y12V2
```

節点2では、

```text
I2=Y2V2+Y12(V2-V1)
=-Y12V1+(Y2+Y12)V2
```

である。

`Y1=1, Y2=2, Y12=3` を代入すると、

```text
Y=[[4,-3],[-3,5]]
```

となる。よって正答は3。

対角成分はその節点につながるアドミタンスの和、非対角成分は節点間アドミタンスの負値になる。

## 問8 正答 1

係数行列を

```text
A=[[2+j,-j],[-j,1+j]]
```

とする。2×2逆行列の分母は、

```text
(2+j)(1+j)-(-j)(-j)
```

である。

```text
(2+j)(1+j)=1+3j
(-j)(-j)=-1
```

なので、

```text
ad-bc=2+3j
```

である。

右辺が `[1,0]^T` なので、

```text
V2=j/(2+3j)
```

分母を実数化すると、

```text
V2
=j(2-3j)/13
=(3+2j)/13
```

よって正答は1。

選択肢5は分母を誤って `1+2j` としており、問の係数行列とは一致しない。

## 問9

### (1) KVLと行列表現

共有抵抗では閉路電流の差が流れる。したがって、

```text
(R1+r)Ia-rIb=10
-rIa+(R2+r)Ib=4
```

数値を代入すると、

```text
3Ia-Ib=10
-Ia+4Ib=4
```

行列では、

```text
[[3,-1],[-1,4]][Ia,Ib]^T=[10,4]^T
```

である。

### (2) 閉路電流

第1式から、

```text
Ib=3Ia-10
```

これを第2式へ代入する。

```text
-Ia+4(3Ia-10)=4
11Ia=44
Ia=4 A
```

したがって、

```text
Ib=3×4-10=2 A
```

である。

### (3) 共有枝電流

共有抵抗を `Ia` の向きを正に見るので、

```text
Ishared=Ia-Ib
=4-2
=2 A
```

である。

### (4) 検算

```text
3×4-2=10
-4+4×2=4
```

となり、元の二つのKVLをともに満たす。

## 問10

### (1) アドミタンス行列

節点1では接地 `2 S` と節点間 `1 S` が接続されるので、

```text
I1=(2+1)V1-1V2
=3V1-V2
```

節点2では、

```text
I2=-1V1+(1+1)V2
=-V1+2V2
```

したがって、

```text
[5,1]^T
=
[[3,-1],[-1,2]][V1,V2]^T
```

である。

### (2) 節点電位

連立方程式は、

```text
3V1-V2=5
-V1+2V2=1
```

第1式から `V2=3V1-5`。第2式へ代入すると、

```text
-V1+2(3V1-5)=1
5V1=11
V1=11/5 V
```

よって、

```text
V2=3×11/5-5
=8/5 V
```

となる。

### (3) KCL検算

節点1:

```text
3×11/5-8/5
=25/5
=5 A
```

節点2:

```text
-11/5+2×8/5
=5/5
=1 A
```

で、指定された注入電流と一致する。

この問題は線形な `I=YV` の範囲で完結しており、電力潮流の非線形反復計算は不要である。

## 問11

係数行列を

```text
A=[[2+j,-j],[-j,1+j]]
```

とする。

### (1) `V1, V2`

分母は問8と同じく、

```text
ad-bc=2+3j
```

である。逆行列は、

```text
A^-1
=
1/(2+3j)
[[1+j,j],[j,2+j]]
```

したがって、

```text
[V1,V2]^T
=
E/(2+3j)
[1+j,j]^T
```

である。

`V1` は、

```text
V1/E
=(1+j)/(2+3j)
=(1+j)(2-3j)/13
=(5-j)/13
```

よって、

```text
V1=(5-j)E/13
```

である。

`V2` は、

```text
V2/E
=j/(2+3j)
=j(2-3j)/13
=(3+2j)/13
```

よって、

```text
V2=(3+2j)E/13
```

である。

### (2) `V2` の大きさと偏角

```text
|V2|
=
E sqrt(3^2+2^2)/13
=
E sqrt(13)/13
=
E/sqrt(13)
```

偏角は、

```text
arg V2 = tan^-1(2/3)
```

である。

### (3) 瞬時値

`E=10 V` のとき実効値フェーザの大きさは、

```text
|V2|=10/sqrt(13) V
```

である。したがって瞬時値は、

```text
v2(t)
=
sqrt(2)×10/sqrt(13)
cos(ωt+tan^-1(2/3))
```

すなわち、

```text
v2(t)
=
(10sqrt(2)/sqrt(13))
cos(ωt+tan^-1(2/3)) V
```

となる。

複素係数を実数部だけに分けて先に解かず、複素数のまま連立方程式を解いて最後に大きさ・偏角へ戻す。

## 問12

### (1) `I1, I3`

連立方程式は、

```text
5I1-2I3=4
-2I1+3I3=5
```

である。

第1式を3倍、第2式を2倍すると、

```text
15I1-6I3=12
-4I1+6I3=10
```

加えて、

```text
11I1=22
I1=2 A
```

となる。

第1式へ戻すと、

```text
10-2I3=4
I3=3 A
```

である。

### (2) 共有枝a

```text
Ia=I1-I3
=2-3
=-1 A
```

負号は計算失敗ではなく、実際の枝電流が最初に定めた基準方向と逆向きに `1 A` 流れることを意味する。

### (3) 共有枝b

`I2=-1 A`、`I3=3 A` なので、

```text
Ib=-I2-I3
=-(-1)-3
=-2 A
```

である。

したがって実際の枝電流は、基準方向と逆向きに `2 A` 流れる。

このように閉路電流と枝電流を同一視せず、共有枝では基準方向に対して各閉路電流の符号を付けて合成する。
