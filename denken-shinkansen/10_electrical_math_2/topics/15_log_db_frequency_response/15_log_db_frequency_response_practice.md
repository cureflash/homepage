## 問12 [記述・複合]

ある負帰還系の開ループボード線図について、次が分かっている。

- 位相交差角周波数 `ω_pc=10 rad/s` でゲインは `-8 dB`
- ゲイン交差角周波数 `ω_gc=3 rad/s` で位相は `-140 deg`

また、閉ループ系AとBの `-3 dB` 帯域幅はそれぞれ `5 rad/s`, `20 rad/s` である。

(1) ゲイン余裕[dB]を求めよ。

(2) 位相余裕を求めよ。

(3) 他条件が同程度とすると、AとBのどちらが速応性の高い方向にあるか答えよ。

(4) ゲイン交差角周波数と位相交差角周波数を取り違えないため、それぞれの定義を式で示せ。

# 解答・完全解説

## 問1 正答 2

振幅比をdBへ変換する。

```text
L = 20log10(0.5)
  = -6.020599...
  ≈ -6.02 dB
```

したがって正答は2。

`10log10` は電力比を直接dB化するときに使う。本Topicの周波数伝達関数の振幅比には `20log10` を使う。

## 問2 正答 4

```text
A = 10^(L/20)
  = 10^(40/20)
  = 10^2
  = 100
```

したがって正答は4。`40 dB` を振幅比40と読むのは誤りである。

## 問3 正答 3

底の変換公式より

```text
log10 x = ln x / ln 10
```

である。したがって正答は3。

自然対数を独立した別単元へ広げず、SPECで要求された底の違いと相互変換だけを確認する。

## 問4 正答 5

積分要素では

```text
|G(jω)| = 1/(ωT_I)
```

である。`0 dB` は振幅比1なので

```text
1/(0.2 T_I)=1
T_I=5 s
```

となる。

また

```text
20log10|G|
= -20log10 T_I -20log10 ω
```

より、角周波数を10倍するとゲインは20 dB低下する。傾きは `-20 dB/dec`。よって正答は5。

## 問5 正答 3

一次遅れ `1/(1+Ts)` の折れ点は

```text
ω_b = 1/T
```

なので

```text
ω_b = 1/0.25 = 4 rad/s
```

である。折れ線近似では折れ点より上で `-20 dB/dec` が加わる。したがって正答は3。

## 問6 正答 1

`ω=1` で

```text
G(j)=1/(1+j)
|G(j)|=1/sqrt(2)
```

である。正弦波定常応答の振幅は

```text
A_out = A_in |G(jω)|
      = 3/sqrt(2)
      = 2.1213...
```

したがって正答は1。

## 問7 正答 4

高周波では最高次項だけを残して

```text
G(jω)
≈ 2jω/(jω)^2
= -2j/ω
```

となる。`-j` の偏角は `-90 deg` なので正答は4。

相対次数が1であることからも、高周波位相が `-90 deg` 方向になることを確認できる。

## 問8 正答 2

位相余裕は

```text
PM = 180 deg + arg G(jω_gc)
```

なので

```text
PM = 180 + (-130)
   = 50 deg
```

となる。正答は2。

## 問9 解答

折れ点は一次遅れの

```text
ω_b=1/T
```

なので

```text
1/T=2
T=0.5 s
```

である。

折れ点で低周波側漸近線ゲインが `6.0206 dB` だから、振幅比は

```text
A = 10^(6.0206/20)
  ≈ 2
```

である。低周波側では積分要素が支配するので

```text
1/(ωT_I)=2
1/(2T_I)=2
T_I=0.25 s
```

したがって

```text
G(s)=1/[0.25s(1+0.5s)]
```

となる。

傾きは、積分要素により低域で `-20 dB/dec`。`ω=2 rad/s` から一次遅れがさらに `-20 dB/dec` を加えるので、高域で `-40 dB/dec`。条件と一致する。

## 問10 解答

### (1) 因子分解

```text
C(s)
=5(1+1/(0.2s))
=5(0.2s+1)/(0.2s)
=5(s+5)/s
```

である。

### (2) 折れ点

零点 `s=-5` に対応して

```text
ω_b=5 rad/s
```

である。

### (3) 傾き

積分要素 `/s` は全域で `-20 dB/dec`。零点 `(s+5)` は `ω=5 rad/s` から `+20 dB/dec` を加える。

したがって

```text
ω<5 rad/s : -20 dB/dec
ω>5 rad/s : 0 dB/dec
```

となる。

### (4) ゲイン

低周波側では

```text
C(jω)≈25/(jω)
```

なので、`ω=1` で振幅比25。

```text
20log10 25
= 27.9588...
≈ 27.96 dB
```

高周波では

```text
C(jω)≈5
```

なので水平ゲインは

```text
20log10 5
= 13.9794...
≈ 13.98 dB
```

である。折れ点 `ω=5` では低周波側漸近線も `25/5=5` となり、13.98 dBで接続する。

## 問11 解答

位相余裕45 degなので、ゲイン交差点での位相は

```text
arg G(j2)=-180+45=-135 deg
```

である。

一方

```text
arg G(jω)
= -90 deg - atan(ωT)
```

だから

```text
-90 - atan(2T) = -135
atan(2T)=45
2T=1
T=0.5 s
```

となる。

次にゲイン交差点は0 dB、すなわち振幅比1なので

```text
|G(j2)|
= K/[2sqrt(1+(2T)^2)]
= 1
```

`T=0.5` より `2T=1` だから

```text
K/(2sqrt(2))=1
K=2sqrt(2)
 ≈2.828
```

である。

検算すると

```text
arg G(j2)=-90-45=-135 deg
PM=45 deg
|G(j2)|=1
```

で両条件を満たす。

## 問12 解答

### (1) ゲイン余裕

位相交差角周波数では位相が `-180 deg` であり、その点の開ループゲインが `-8 dB` である。

```text
GM_dB = -(-8)=8 dB
```

したがってゲイン余裕は `8 dB`。

### (2) 位相余裕

ゲイン交差角周波数ではゲインが0 dBであり、その点の位相が `-140 deg` なので

```text
PM = 180 + (-140)
   = 40 deg
```

となる。

### (3) 帯域幅と速応性

他条件が同程度なら、帯域幅が広いほど高い周波数の入力変化まで追従しやすく、速応性が高い方向になる。

```text
A: 5 rad/s
B: 20 rad/s
```

なのでB。

### (4) 交差角周波数の定義

ゲイン交差角周波数:

```text
|G(jω_gc)|=1
20log10|G(jω_gc)|=0 dB
```

位相交差角周波数:

```text
arg G(jω_pc)=-180 deg
```

である。両者は別の周波数であり、ゲイン余裕は `ω_pc`、位相余裕は `ω_gc` で読む。
