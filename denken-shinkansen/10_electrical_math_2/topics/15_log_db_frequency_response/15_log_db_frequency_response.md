# 解説本文

## 1. このテーマで電験は何を問うか

本Topicは、第二種「機械・制御」で伝達関数を周波数軸上に読み替えるための数学を扱う。試験では、単に対数を計算するのではなく、`s=jω` とした周波数伝達関数からゲインと位相を求め、ボード線図の傾き・折れ点から伝達関数を逆算し、ゲイン余裕・位相余裕や帯域幅を制御特性へ結び付ける。

本Topicを終えた時点で、少なくとも次をできるようにする。

1. 振幅比とdBを相互変換する。
2. 伝達関数を `s=jω` として `|G(jω)|` と `arg G(jω)` を求める。
3. 定数、積分要素、一次遅れ、一次進み零点のゲイン傾斜と位相を読む。
4. ボード線図の傾き・折れ点・基準点から伝達関数を復元する。
5. 正弦波定常応答の振幅比を `|G(jω)|` から求める。
6. 高周波近似から位相を求める。
7. ゲイン交差角周波数、位相交差角周波数、ゲイン余裕、位相余裕を読み取る。
8. 帯域幅を速応性へ接続する。

## 2. 常用対数・自然対数・dB

常用対数は底10の対数であり、`log10 x` と書く。自然対数は底 `e` の対数であり、`ln x` と書く。両者は

```text
log10 x = ln x / ln 10
```

で相互変換できる。本Topicのボード線図で使うのは常用対数である。

振幅比 `A>0` をdB表示すると

```text
L = 20 log10 A  [dB]
```

であり、逆変換は

```text
A = 10^(L/20)
```

である。したがって代表値は

```text
A = 10     ->  20 dB
A = 100    ->  40 dB
A = 1      ->   0 dB
A = 0.1    -> -20 dB
```

となる。

電力比をdB化するときは `10log10(P2/P1)` を使う。同じインピーダンス条件で振幅比を扱うと電力比が振幅比の2乗になるため、振幅比では係数20となる。本Topicでは周波数伝達関数の振幅比を扱うので `20log10|G(jω)|` を使用する。

## 3. 対数を使う理由: 積を和へ変える

対数には

```text
log10(ab) = log10 a + log10 b
log10(a/b) = log10 a - log10 b
```

が成り立つ。したがって伝達関数を

```text
G(jω) = G1(jω) G2(jω) G3(jω)
```

と因子分解できれば、ゲイン[dB]は

```text
20log10|G|
= 20log10|G1| + 20log10|G2| + 20log10|G3|
```

と加算できる。これがボード線図を要素ごとの直線で組み立てられる理由である。

## 4. 周波数応答: `s=jω` とする

伝達関数 `G(s)` に対し、正弦波定常状態の周波数応答は

```text
G(jω)
```

で表す。複素数

```text
G(jω) = a(ω) + jb(ω)
```

なら、振幅比と位相は

```text
|G(jω)| = sqrt(a^2+b^2)
arg G(jω) = atan2(b,a)
```

である。ボード線図は、横軸を対数角周波数 `ω [rad/s]` とし、縦軸に

```text
ゲイン: 20log10|G(jω)| [dB]
位相:   arg G(jω) [deg]
```

を描く。

`0 dB` は振幅比1を意味する。`-20 dB` は振幅比0.1、`40 dB` は振幅比100である。

## 5. 代表因子のゲインと位相

### 5.1 正の定数ゲイン `K`

```text
G(jω)=K  (K>0)
```

なら

```text
ゲイン = 20log10 K  [dB]
位相   = 0 deg
```

で、周波数によらない水平線になる。

### 5.2 積分要素 `1/(T_I s)`

```text
G(jω)=1/(jωT_I)
```

なので

```text
|G(jω)| = 1/(ωT_I)
20log10|G| = -20log10 T_I - 20log10 ω
arg G = -90 deg
```

となる。角周波数を10倍すると `log10 ω` が1増えるため、ゲインは20 dB低下する。したがって傾きは

```text
-20 dB/dec
```

である。

例えば `ω=0.1 rad/s` で `0 dB` なら

```text
1/(0.1 T_I)=1
T_I=10 s
G(s)=1/(10s)
```

となり、R5二次問4 (1)へ直接接続する。

### 5.3 一次遅れ `1/(1+Ts)`

```text
G(jω)=1/(1+jωT)
```

より

```text
|G| = 1/sqrt(1+(ωT)^2)
arg G = -atan(ωT)
```

である。折れ点角周波数は

```text
ω_b = 1/T
```

で、折れ線近似では

```text
ω << 1/T : 0 dB相当、傾き0 dB/dec
ω >> 1/T : 傾き-20 dB/dec
```

となる。積分要素と直列なら、折れ点より下で `-20 dB/dec`、上で `-40 dB/dec` になる。

### 5.4 一次零点 `1+Ts`

```text
G(jω)=1+jωT
```

より、折れ点は同じく `ω_b=1/T`。折れ線近似のゲイン傾斜は折れ点より上で `+20 dB/dec`、位相は `+atan(ωT)` となる。

この因子はH30二次問4のPI補償器を因子分解するために必要な範囲だけ扱う。

## 6. ボード線図から伝達関数を復元する

ゲイン折れ線から伝達関数を読むときは、次の順で行う。

```text
1. 低周波側の傾きを読む
2. 傾きが変わる角周波数を折れ点として読む
3. 傾き変化が -20 dB/dec なら一次遅れ、+20 dB/dec なら一次零点を1個対応させる
4. 指定周波数のdB値を振幅比へ戻す
5. 時定数または定数ゲインを求める
6. 伝達関数を組み立てる
7. 別の周波数点または傾きで検算する
```

R5二次問4 (4)型として、低域の傾きが `-20 dB/dec`、`ω=0.5 rad/s` で `-40 dB/dec` へ変わり、折れ線近似上のゲインが `14 dB` とする。

傾き変化から一次遅れの折れ点は

```text
1/T = 0.5
T = 2 s
```

である。低域には積分要素があるので

```text
G(s)=1/[T_I s(1+2s)]
```

と置く。折れ線近似では折れ点で低周波側の直線を使って

```text
20log10(1/(0.5 T_I)) = 14
1/(0.5 T_I) = 10^(14/20) = 10^0.7 = 5.0119
T_I = 1/(0.5×5.0119)
    = 0.39905 s
```

したがって

```text
G(s) ≈ 1/[0.399s(1+2s)]
```

となる。これはR5二次問4 (4)の公式値と一致する。

## 7. PI要素の折れ線近似

H30二次問4 (2)型の

```text
C(s)=K_P(1+1/(T_I s))
```

を

```text
C(s)=K_P(T_I s+1)/(T_I s)
```

と見る。`K_P=10`, `T_I=0.1 s` なら

```text
C(s)=10(s+10)/s
```

である。

積分要素 `/s` は `-20 dB/dec`、零点 `(s+10)` は `ω=10 rad/s` から `+20 dB/dec` を加える。よって合成傾斜は

```text
ω < 10 rad/s : -20 dB/dec
ω > 10 rad/s : 0 dB/dec
```

となる。さらに

```text
ω=1 rad/s  : 40 dB
ω=10 rad/s : 20 dB
ω>10 rad/s : 20 dBの水平線
```

となる。ここでは与えられたPI要素の周波数特性を読むところまでを扱い、補償器の設計一般へは広げない。

## 8. 正弦波定常応答と振幅比

安定な線形系へ

```text
u(t)=A sin(ωt)
```

を入力した定常応答は、同じ角周波数 `ω` の正弦波となり、その振幅は

```text
A_out = A |G(jω)|
```

となる。位相は `arg G(jω)` だけずれる。

R4二次問4 (5)型では、偏差伝達関数 `T_ER(s)` に対して `ω=1 rad/s` で

```text
|T_ER(j)| = sqrt(3202/26802) = 0.34564...
```

と求まる。入力振幅が2なら定常偏差振幅は

```text
B = 2|T_ER(j)|
  = 0.69128...
  ≈ 0.691
```

である。ここで必要なのは、複素伝達関数の絶対値が振幅比になることを使えることである。

## 9. 高周波域の位相

有理伝達関数では、`ω` が十分大きいと定数項より最高次項が支配的になる。そのため、固定R6二次問4 (5)の

```text
G(s)=(3s+14)/[(s+2)(s+3)]
```

に `s=jω` を代入すると、高周波では

```text
G(jω) ≈ 3jω/(jω)^2
       = -3j/ω
```

となる。`-j` の偏角は `-90 deg` なので、高周波位相は

```text
-90 deg
```

である。

この読み方は「分子・分母の最高次項へ絞る → `j` の次数から位相を読む」という手順で行う。本Topicではナイキスト線図による独立した安定判別へは広げない。

## 10. ゲイン交差・位相交差・安定余裕

通常の負帰還制御系で、開ループ周波数特性を用いて相対安定度を読むとき、次を使う。

ゲイン交差角周波数 `ω_gc`:

```text
|G(jω_gc)| = 1
20log10|G(jω_gc)| = 0 dB
```

位相余裕 `PM`:

```text
PM = 180 deg + arg G(jω_gc)
```

位相交差角周波数 `ω_pc`:

```text
arg G(jω_pc) = -180 deg
```

ゲイン余裕をdBで表すと

```text
GM_dB = -20log10|G(jω_pc)|
```

である。ゲイン余裕・位相余裕は開ループ周波数特性から安定性への余裕を見る尺度であり、交差周波数は応答速度との関係を読む尺度として扱う。

H23一次問7型の

```text
G(s)=K/[s(Ts+1)]
```

で `ω_gc=1 rad/s`, `PM=45 deg` とする。ゲイン交差点の位相は

```text
arg G(j) = -180+45 = -135 deg
```

一方

```text
arg G(j) = -90 deg - atan(T)
```

だから

```text
atan(T)=45 deg
T=1 s
```

となる。さらに0 dB条件 `|G(j)|=1` より

```text
K/sqrt(1+T^2)=1
K=sqrt(2)
```

となる。

## 11. 帯域幅と速応性

閉ループ周波数特性では、低周波ゲインから通常 `-3 dB`、すなわち振幅比 `1/sqrt(2)` まで低下する周波数を帯域幅の代表的な定義として使う。一般に、他条件が同程度なら帯域幅が広いほど高い周波数の入力変化まで追従でき、速応性が高い方向になる。

H23一次問7では、この「閉ループ周波数特性から速応性を表す代表尺度」として帯域幅を選べることが必要である。

## 12. 新幹線への接続

新幹線の速度制御を簡略化して伝達関数で表した場合、周波数応答は「速度指令や外乱がゆっくり変化するときにはどれだけ追従し、速く変化するときにはどれだけ減衰・位相遅れが生じるか」を見る道具になる。

本Topicでは実車固有の制御定数や帯域幅を未確認値で置かない。Topic 10で扱った簡略化制御モデルを、周波数軸で読む数学的接続だけを行う。

## 13. 本試験型の解法手順

```text
1. 伝達関数を因子分解する
2. s=jω を代入する
3. |G(jω)| と arg G(jω) のどちらが必要か確認する
4. ゲインなら 20log10|G| へ変換する
5. ボード線図なら低域傾斜と折れ点を読む
6. 傾斜変化から積分要素・一次遅れ・一次零点を対応付ける
7. 指定dB値を振幅比へ戻し、定数や時定数を決める
8. 安定余裕なら 0 dB点または -180 deg点を先に特定する
9. 正弦波定常応答なら入力振幅×|G(jω)|で出力振幅を求める
10. 別周波数点・傾斜・位相で検算する
```

## 14. 頻出ミス

- 振幅比なのに `10log10 A` を使う。
- `40 dB` を振幅比40と読む。正しくは100。
- `0 dB` をゲイン0と読む。正しくは振幅比1。
- 積分要素 `1/s` の傾きを `+20 dB/dec` とする。
- 一次遅れの折れ点 `ω=1/T` を `ω=T` とする。
- 折れ点で傾きが `-20 dB/dec` 変化する意味を、単なる定数ゲイン変化と取り違える。
- `|G(jω)|` と `arg G(jω)` を混同する。
- 位相余裕を `180 deg-arg G(jω_gc)` として符号を誤る。
- ゲイン交差角周波数と位相交差角周波数を取り違える。
- ボード線図の折れ線近似値と厳密値を混同する。

# 3段階例題

## 例題1 基礎: dBと振幅比を往復する

振幅比が `0.5` のときのゲイン[dB]を求めよ。また `40 dB` に対応する振幅比を求めよ。

### 解法

振幅比 `0.5` は

```text
L = 20log10(0.5)
  = -6.0206... dB
```

したがって約 `-6.02 dB`。

逆に `40 dB` は

```text
A = 10^(40/20)
  = 10^2
  = 100
```

である。

### 検算

```text
20log10(100)=40 dB
```

となるので往復一致する。

判定: `PASS`。

## 例題2 本試験標準: ゲイン折れ線から伝達関数を復元する

あるゲイン折れ線が低周波側で `-20 dB/dec`、`ω=0.5 rad/s` で `-40 dB/dec` へ変化し、その折れ点で低周波側直線のゲインが `14 dB` である。伝達関数を

```text
G(s)=1/[T_I s(1+Ts)]
```

としたとき `T`, `T_I` を求めよ。

### 解法

折れ点より

```text
1/T = 0.5
T = 2 s
```

である。

`14 dB` を振幅比へ戻す。

```text
A = 10^(14/20)
  = 10^0.7
  = 5.0119
```

折れ線近似の低周波側では

```text
1/(T_I×0.5)=5.0119
```

なので

```text
T_I = 1/(0.5×5.0119)
    = 0.39905 s
```

したがって

```text
G(s)≈1/[0.399s(1+2s)]
```

となる。

### 検算

低域傾斜は積分要素で `-20 dB/dec`、`0.5 rad/s` から一次遅れが加わり `-40 dB/dec` となる。線図条件と一致する。

判定: `PASS`。

## 例題3 複合・ひっかけ: 位相余裕と0 dB条件から `K`,`T` を求める

開ループ伝達関数

```text
G(s)=K/[s(Ts+1)]
```

のゲイン交差角周波数が `ω_gc=1 rad/s`、位相余裕が `45 deg` である。`K`,`T` を求めよ。

### 解法

位相余裕45 degなので、ゲイン交差点での位相は

```text
-180+45 = -135 deg
```

である。

`ω=1` で

```text
arg G(j)=-90 deg-atan(T)
```

だから

```text
-90-atan(T)=-135
atan(T)=45
T=1 s
```

となる。

次にゲイン交差点では0 dB、すなわち振幅比1である。

```text
|G(j)|=K/[1×sqrt(1+T^2)]=1
```

`T=1` を代入すると

```text
K/sqrt(2)=1
K=sqrt(2)
```

である。

### ひっかけ

`0 dB` はゲイン0ではなく振幅比1である。また位相余裕45 degを、そのまま `arg G(j)=45 deg` としてはならない。

### 検算

```text
arg G(j)=-90-45=-135 deg
PM=180-135=45 deg
|G(j)|=sqrt(2)/sqrt(2)=1 -> 0 dB
```

両条件を満たす。

判定: `PASS`。
