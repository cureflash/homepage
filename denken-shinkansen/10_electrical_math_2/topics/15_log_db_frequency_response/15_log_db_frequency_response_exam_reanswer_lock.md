## 1. R6 二次「機械・制御」問4 (5)

与えられた

```text
G1(s)=3/(s+2)
G2(s)=5/(s^2+5s+6)=5/((s+2)(s+3))
```

を並列結合すると

```text
Gp(s)=G1(s)+G2(s)
     =(3s+14)/((s+2)(s+3))
```

高周波では

```text
Gp(jω) ≈ 3jω/(jω)^2
        = -3j/ω
```

したがって十分高い周波数での位相は

```text
-90°
```

と固定する。

## 2. R5 二次「機械・制御」問4 (1)〜(4)

### (1)

図1は全域で `-20 dB/dec`、かつ `ω=0.1 rad/s` で `0 dB`。積分要素

```text
G1(s)=1/(T_I s)
```

に対し

```text
20log10(1/(T_I*0.1))=0
```

より

```text
T_I=10 s
G1(s)=1/(10s)
```

と固定する。

### (2)

図2は図1と同じ `-20 dB/dec` で、`ω=0.1 rad/s` のゲインが `40 dB`。図1の `G1` は同周波数で `0 dB` なので、残りの定数ゲインは

```text
20log10 G2 = 40
G2 = 100
```

したがって

```text
G2(s)=100
```

と固定する。

### (3)

図2を直接積分要素

```text
G(s)=1/(T_I1 s)
```

とみなす。`ω=0.1 rad/s` で `40 dB`、すなわち振幅比100なので

```text
1/(0.1 T_I1)=100
T_I1=0.1 s
```

よって

```text
G(s)=10/s
```

と固定する。

### (4)

図3は `ω=0.5 rad/s` で傾きが `-20 dB/dec` から `-40 dB/dec` へ変化する。したがって一次遅れ要素の折れ点から

```text
1/T = 0.5
T = 2 s
```

また折れ線近似上、`ω=0.5 rad/s` のゲインは `14 dB`。問題文指定の `10^0.7=5.019` を使うと

```text
1/(T_I2*0.5)=5.019
T_I2=1/(0.5*5.019)=0.3985 s ≈ 0.40 s
```

したがって

```text
G(s)=1/[T_I2 s(1+2s)]
    ≈1/[0.40s(1+2s)]
```

と固定する。

## 3. R4 二次「機械・制御」問4 (5)

開ループ伝達関数は

```text
L(s)=100K/[s(s+1)(s+40)]
```

なので、目標値から偏差までの伝達関数は

```text
T_ER(s)=1/(1+L(s))
       =s(s+1)(s+40)/[s(s+1)(s+40)+100K]
```

`K=2`, `ω=1 rad/s` では

```text
s(s+1)(s+40)|_(s=j) = -41 + j39
```

したがって

```text
|T_ER(j)|
 = sqrt(41^2+39^2)/sqrt(159^2+39^2)
 = sqrt(3202/26802)
```

入力 `r(t)=2sin t` の振幅が2なので、定常偏差の振幅は

```text
B=2|T_ER(j)|
 =2sqrt(3202/26802)
 ≈0.6913
```

と固定する。

## 4. H30 二次「機械・制御」問4 (2)

補償器

```text
C(s)=K_P(1+1/(T_I s))
```

に `K_P=10`, `T_I=0.1` を代入すると

```text
C(s)=10(1+10/s)=10(s+10)/s
```

折れ点は

```text
ω=10 rad/s
```

折れ線近似ゲイン特性は次のように固定する。

- `ω<10 rad/s`: 傾き `-20 dB/dec`
- `ω=1 rad/s`: `40 dB`
- `ω=10 rad/s`: `20 dB`
- `ω>10 rad/s`: `20 dB` の水平線

すなわち、低周波では積分要素、高周波では比例ゲイン10が支配する形とする。

## 5. H23 一次「機械」問7 (1)〜(5)

選択肢から独立に判定する。

### (1)

ゲイン余裕・位相余裕は開ループ周波数特性から安定性を測る尺度。

```text
(1) = ワ「安定性」
```

### (2)

ゲイン交差角周波数・位相交差角周波数は応答速度側の尺度として扱われる。

```text
(2) = チ「速応性」
```

### (3), (4)

```text
G(s)=K/[s(Ts+1)]
```

ゲイン交差角周波数 `ω_gc=1 rad/s`、位相余裕45°なので、交差点の位相は `-135°`。

```text
-90°-atan(T)=-135°
atan(T)=45°
T=1 s
```

よって

```text
(4) = ヘ「1」
```

さらに `ω=1` で0 dB、すなわち `|G(j)|=1` だから

```text
K/sqrt(1+T^2)=1
K=sqrt(2)
```

よって

```text
(3) = ハ「√2」
```

### (5)

閉ループ周波数特性で速応性を表す代表尺度は帯域幅。

```text
(5) = イ「帯域幅」
```
