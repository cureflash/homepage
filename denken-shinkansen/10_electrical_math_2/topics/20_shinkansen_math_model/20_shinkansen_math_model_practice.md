# 解答・完全解説

## 問1 正答 3

合力は

```text
Fnet = 14000 - 2000 - 4000
     = 8000 N
```

したがって

```text
a = Fnet/m
  = 8000/4000
  = 2 m/s^2
```

である。抵抗力と勾配抵抗は大きさを正で与え、運動方程式では減算する。よって正答は3。

## 問2 正答 3

Euler更新は

```text
v_(n+1)=5+1.5*2
       =8 m/s
```

である。`a_n Δt` の単位は `(m/s^2)*s=m/s` なので、速度へ加算できる。よって正答は3。

## 問3 正答 2

機械電力は

```text
P=Fv
 =6000*10
 =60000 W
 =60 kW
```

5秒間一定なので

```text
E=PΔt
 =60000*5
 =300000 J
 =300 kJ
```

である。`W` と `J`、`kW` と `kJ` を混同しない。よって正答は2。

## 問4 正答 3

台形則で

```text
Δx=(6+10)/2 * 2
   =8*2
   =16 m
```

である。`m/s` を時間積分して `m` になる。よって正答は3。

## 問5 正答 4

力から求める仕事は

```text
W=FΔx
 =8000*20
 =160000 J
 =160 kJ
```

端点電力は

```text
P0=8000*5 = 40000 W = 40 kW
P1=8000*15 = 120000 W = 120 kW
```

したがって台形積分は

```text
E=(40+120)/2 * 2
 =160 kJ
```

である。一定力で、位置と電力を整合する方法で積分しているため `F dx` と `P dt` が一致する。よって正答は4。

## 問6 正答 1

零初期条件でラプラス変換すると

```text
(8s+4)V(s)=F(s)
```

よって

```text
G(s)=V(s)/F(s)=1/(8s+4)
```

である。一次モデル `M dv/dt + Dv=F` の時定数は

```text
τ=M/D=8/4=2 s
```

なので正答は1。

選択肢2は `M` と `D` を入れ替えている。選択肢3は入力から出力への比を逆に扱っている。選択肢4は `M/D` を計算していない。選択肢5は抵抗項 `Dv` を落としている。

## 問7 正答 4

```text
2 f_max = 80 Hz
```

であり、教材で固定した条件は等号なしの

```text
f_s > 80 Hz
```

である。選択肢中、この条件を満たす最小値は `100 Hz`。よって正答は4。

`80 Hz` は `f_s>2f_max` を満たさない。

## 問8 正答 5

周波数間隔は

```text
Δf=f_s/N
   =120/12
   =10 Hz
```

`30 Hz` は

```text
k=30/10=3
```

である。したがって `Δf=10 Hz, k=3` の5が正答。

# 記述型解答

## 問9

### (1) 合力と加速度

```text
Fnet=18000-3000
    =15000 N
```

したがって

```text
a=15000/5000
 =3 m/s^2
```

### (2) Euler法による速度

`Δt=1 s` なので

```text
v1=4+3*1=7 m/s
v2=7+3*1=10 m/s
```

### (3) 位置

第1区間は

```text
Δx1=(4+7)/2 * 1
    =5.5 m
```

第2区間は

```text
Δx2=(7+10)/2 * 1
    =8.5 m
```

よって

```text
Δx=5.5+8.5
   =14 m
```

### (4) 仕事と運動エネルギー

牽引仕事は

```text
Wtraction=18000*14
         =252000 J
         =252 kJ
```

抵抗仕事の大きさは

```text
Wresistance=3000*14
           =42000 J
           =42 kJ
```

運動エネルギー変化は

```text
ΔK=(1/2)*5000*(10^2-4^2)
  =2500*(100-16)
  =210000 J
  =210 kJ
```

したがって

```text
ΔK+Wresistance
=210+42
=252 kJ
=Wtraction
```

となり、力学的エネルギー収支が一致する。

### (5) 電力積分

端点の牽引電力は

```text
P0=18000*4  =72000 W  =72 kW
P1=18000*7  =126000 W =126 kW
P2=18000*10 =180000 W =180 kW
```

2区間を台形積分すると

```text
E=(P0+2P1+P2)Δt/2
 =(72+2*126+180)*1/2
 =252 kJ
```

したがって

```text
∫Pdt = 252 kJ = Wtraction
```

である。`F dx`、`P dt`、運動エネルギー収支の3経路が整合している。

## 問10

### (1) 伝達関数

一般形を

```text
6 dv/dt + 3v = F
```

と見て、零初期条件でラプラス変換すると

```text
(6s+3)V(s)=F(s)
```

よって

```text
G(s)=V(s)/F(s)
    =1/(6s+3)
```

である。

### (2) 時定数と定常速度

```text
τ=M/D=6/3=2 s
```

一定入力 `F0=12` に対する定常速度は

```text
v_ss=F0/D
    =12/3
    =4 m/s
```

である。

### (3) 解析解

初期速度0なので

```text
v(t)=4(1-exp(-t/2))
```

`t=2 s` では

```text
v(2)=4(1-exp(-1))
    ≒2.5285 m/s
```

となる。

### (4) Euler法

微分方程式を

```text
dv/dt=(12-3v)/6
```

とする。`Δt=1 s` なので

```text
v0=0
v1=0+(12-3*0)/6 *1
  =2 m/s
```

次に

```text
v2=2+(12-3*2)/6 *1
  =2+1
  =3 m/s
```

解析値との差は

```text
3-2.5285
≒0.4715 m/s
```

である。

### (5) 差の理由

Euler法は各刻みの始点の傾きを区間全体へ使う近似であり、有限の刻み幅では離散化誤差を持つ。したがって解析解と完全一致しないこと自体は異常ではない。刻み幅を小さくすると、通常は解析解へ近づくことを確認する。
