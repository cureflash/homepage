## Case A 牽引力→速度・位置→仕事・電力量

教育用条件:

```text
m = 6000 kg
Ftraction = 21000 N
Fresistance = 3000 N
Fgrade = 0 N
v0 = 3 m/s
dt = 1 s
計算時間 = 3 s
```

合力と加速度は

```text
Fnet = 21000 - 3000 = 18000 N
a = 18000 / 6000 = 3 m/s^2
```

Euler更新により

```text
v = 3, 6, 9, 12 m/s
```

速度を台形積分すると各区間の移動距離は `4.5, 7.5, 10.5 m`、合計

```text
x = 22.5 m
```

となる。牽引仕事は

```text
Wtraction = 21000 * 22.5 = 472500 J
```

抵抗仕事の大きさと運動エネルギー変化は

```text
Wresistance = 3000 * 22.5 = 67500 J
Delta K = (1/2) * 6000 * (12^2 - 3^2) = 405000 J
```

なので

```text
Wtraction = Delta K + Wresistance
472500 = 405000 + 67500 J
```

が成立する。

さらに端点の牽引電力 `P=Ftraction v` を台形積分すると `472500 J` となり、`F dx` と `P dt` が一致する。

判定: `PASS`

## Case B 一次簡略制御モデル・解析解・Euler法

教育用一次モデル:

```text
5 dv/dt + 2v = 20
v(0)=0
```

零初期条件の伝達関数、時定数、定常速度は

```text
G(s) = 1/(5s+2)
tau = 5/2 = 2.5 s
v_ss = 20/2 = 10
```

である。解析解は

```text
v(t)=10(1-exp(-t/2.5))
```

なので `t=2.5 s` では

```text
v_exact = 6.321205588286
```

となる。Euler法では

```text
dt=0.50 s : v=6.723200000000, error=0.401994411714
dt=0.25 s : v=6.513215599000, error=0.192010010714
```

となり、この条件では刻み幅を半分にすると解析解との差が小さくなることを確認した。

判定: `PASS`

## Case C 回生符号→周期成分→サンプリング→周波数スペクトル

まず教育用回生区間を

```text
m = 5000 kg
Fregen = -5000 N
v0 = 12 m/s
dt = 1 s
計算時間 = 4 s
走行抵抗 = 0 N
```

とする。

```text
a = -1 m/s^2
v = 12, 11, 10, 9, 8 m/s
x = 40 m
```

よって符号付き機械エネルギーは

```text
E_signed = -5000 * 40 = -200000 J
```

であり、

```text
Delta K = (1/2) * 5000 * (8^2 - 12^2) = -200000 J
```

と一致する。回収量を正で表示する場合の機械側回生エネルギーは `200000 J` であり、変換効率等を置いていないため電気側実回収量とは扱わない。

次に実車PWM値ではない教育用代理波形

```text
x(t)=sin(2*pi*12.5t)+0.4 sin(2*pi*37.5t)
```

を使う。

```text
fs = 100 Hz
N = 8
Delta f = 12.5 Hz
fmax = 37.5 Hz
```

なので

```text
fs = 100 > 2*fmax = 75 Hz
```

を満たす。直接DFTで確認すると正周波数側の振幅は

```text
12.5 Hz : 1.0
37.5 Hz : 0.4
0, 25, 50 Hz : 数値丸め範囲で0
```

となり、時間波形で置いた2成分が対応する周波数ビンへ現れる。

判定: `PASS`
