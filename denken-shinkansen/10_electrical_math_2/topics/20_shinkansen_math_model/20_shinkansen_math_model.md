## 教材で必要な説明

### 1. モデルの変数・単位・符号を先に固定する

質量 `m [kg]`、位置 `x [m]`、速度 `v [m/s]`、加速度 `a [m/s^2]`、牽引力・抵抗力 `F [N]`、電力 `P [W]`、エネルギー `E [J]` を混同しない。力行と回生の電力符号、進行方向と抵抗力の符号を明示する。

### 2. 力から速度・位置へ一方向に計算する

簡略運動方程式を

```text
m dv/dt = Ftraction(v,t) - Fresistance(v,t) - Fgrade(t)
```

と置き、右辺から加速度を求め、既完了Topic 17の数値ODE手法で速度を更新する。位置は `dx/dt=v` を同じ時間刻みで積分する。新しい数値解法は追加しない。

### 3. 電力・エネルギーへ接続する

機械側の代表関係 `P_mech=Ftraction v` を使う場合は符号と単位を明示し、時間積分で仕事・電力量を求める。回生は負の電力または回収側を正とする別記号のどちらかに統一し、途中で規約を変えない。変換効率等を入れる場合は仮定値か出典付き実値かを明記する。

### 4. 簡略制御モデルを既完了の伝達関数へ接続する

Topic 10で扱った簡略式

```text
M dv/dt + Dv = F
```

を零初期条件でラプラス変換し、牽引力から速度への簡略伝達関数

```text
V(s)/F(s) = 1/(Ms + D)
```

へ接続する。補償器設計や最適制御へ拡張しない。

### 5. PWM波形からFFTまでの役割を分離する

周期PWM波形の基本波・高調波という時間波形側の説明はTopic 13、サンプリング後の離散波形を周波数スペクトルとして見る説明はTopic 14の範囲を使う。FFTを電験で直接要求される算法と誤記せず、波形の理解・可視化の道具として扱う。

### 6. 総合モデルの検算方法を示す

少なくとも次を相互に照合する。

- `F=ma` の次元整合
- `x` の差分と `v` の積分の整合

# 解説本文

## 1. このテーマで電験は何を問うか

確認済みの第二種公式過去問では、運動方程式・電力量積算・伝達関数・周期波形・サンプリングは個別に問われるが、これらを一つの新幹線モデルへ統合する問題は確認できていない。本Topicの目的は、個別の公式を増やすことではなく、既習の数学を

```text
物理量を決める
→ 方程式を立てる
→ 時間発展を計算する
→ 電力・エネルギーへ接続する
→ 制御・波形を別の数学表現で確認する
```

という一つの計算系として使えるようにすることである。

電験で重要なのは、各段階で何を入力し、何を出力し、どの単位と成立条件を保つかである。新幹線固有の性能値を暗記する章ではない。

## 2. 変数・単位・符号を最初に固定する

進行方向を正とする。教育用の簡略モデルでは、主な量を次のように置く。

| 量 | 記号 | 単位 | 符号・意味 |
|---|---|---|---|
| 質量 | `m` | kg | 正 |
| 位置 | `x` | m | 進行方向を正 |
| 速度 | `v` | m/s | 進行方向を正 |
| 加速度 | `a` | m/s^2 | 加速を正、減速を負 |
| 牽引力 | `Ftraction` | N | 進行方向を正 |
| 走行抵抗 | `Fresistance` | N | 大きさを正で置き、式では減算 |
| 勾配抵抗 | `Fgrade` | N | 進行を妨げる向きを正の大きさとして減算 |
| 機械電力 | `P` | W | `Fv` の符号に従う |
| エネルギー | `E` | J | `∫Pdt` |

したがって運動方程式は

```text
m dv/dt = Ftraction - Fresistance - Fgrade
```

となる。回生制動を `Ftraction<0` として同じ式に入れるなら、機械電力 `P=Ftraction*v` も負になる。回収量を正で表示したい場合だけ

```text
Eregen = -∫P dt
```

と別記号にする。途中で符号規約を変えない。

## 3. 力から速度・位置へ計算する

時刻 `t_n` の速度を `v_n` とし、時間刻みを `Δt` とする。まず運動方程式から

```text
a_n = (Ftraction,n - Fresistance,n - Fgrade,n) / m
```

を求める。Topic 17で扱ったEuler法を使えば

```text
v_(n+1) = v_n + a_n Δt
```

で速度を更新できる。

位置は `dx/dt=v` なので、同じ区間の速度を用いて積分する。区間内を台形則で処理するなら

```text
x_(n+1) = x_n + (v_n + v_(n+1)) Δt / 2
```

である。

この2式では、力から加速度、速度、位置へ計算の向きが一方向に定まる。`F` と `v` を同じ時刻の量として扱うのか、区間平均で扱うのかを曖昧にしないことが重要である。

## 4. 速度から電力・エネルギーへ接続する

牽引力と速度から機械電力を

```text
P_mech = Ftraction * v
```

と置く。単位は

```text
N * m/s = J/s = W
```

である。

区間の牽引力が一定なら、仕事は

```text
W = ∫F dx = F Δx
```

で求められる。一方、電力を時間積分して

```text
E = ∫P dt
```

としても同じ仕事になる。この一致は総合モデルの重要な検算である。

電気側の消費電力量へ変換効率を入れる場合は、その効率が仮定値か出典付き実値かを明記しなければならない。本Topicの例題では機械側だけを扱い、未確認の実車効率を置かない。

## 5. 同じ運動をラプラス領域で見る

速度に比例する抵抗をまとめた一次の簡略モデル

```text
M dv/dt + Dv = F
```

を考える。零初期条件でラプラス変換すると

```text
(Ms + D)V(s) = F(s)
```

なので

```text
G(s) = V(s)/F(s) = 1/(Ms + D)
```

である。

ここから

```text
時定数 τ = M/D
直流ゲイン = 1/D
一定入力 F0 に対する定常速度 = F0/D
```

を読める。これは時間領域の運動方程式と別の現象を扱っているのではなく、同じ一次モデルをラプラス領域で表したものである。

補償器設計、最適制御、状態フィードバック等へは拡張しない。

## 6. PWM波形とFFTの役割を分ける

周期波形はTopic 13の範囲で、基本波と高調波の和として読む。時間波形をサンプリングした後はTopic 14の範囲で周波数スペクトルとして読む。

最大周波数成分を `f_max`、サンプリング周波数を `f_s` とすれば、接続確認する条件は

```text
f_s > 2 f_max
```

である。標本数を `N` としたときの周波数間隔は

```text
Δf = f_s / N
```

となる。

FFTはDFTと同じ離散周波数成分を効率よく求める計算手段として扱う。FFTアルゴリズムの実装詳細やPWM制御方式の一般論は本Topicの範囲外である。

## 7. 総合問題の解法手順

総合モデルは次の順で解く。

```text
1. 進行方向、力、電力の符号規約を決める
2. m, x, v, F, P, E の単位をそろえる
3. Ftraction, Fresistance, Fgrade から合力を作る
4. F=ma から加速度を求める
5. 指定された数値積分法で速度を更新する
6. 速度を積分して位置を求める
7. P=Fv から電力を求め、時間積分してエネルギーを求める
8. F dx と ∫Pdt、運動エネルギー収支を照合する
9. 一次簡略制御モデルなら G(s)=1/(Ms+D) と時間応答を照合する
10. 波形解析では先に f_s>2f_max を確認してから周波数軸を読む
```

新しい数学手法を足さず、各既習Topicの結果を物理量の意味を保ったまま接続する。

## 8. 3段階例題

### 例題1 基礎 — 1区間の力・速度・位置・仕事

すべて教育用仮定値とする。

```text
m = 5000 kg
Ftraction = 15000 N
Fresistance = 5000 N
Fgrade = 0 N
v0 = 4 m/s
Δt = 2 s
```

合力は

```text
Fnet = 15000 - 5000 = 10000 N
```

だから

```text
a = Fnet/m = 10000/5000 = 2 m/s^2
```

である。Euler法で区間終端速度は

```text
v1 = 4 + 2*2 = 8 m/s
```

となる。

位置増分は台形則で

```text
Δx = (4+8)/2 * 2 = 12 m
```

である。牽引仕事は

```text
Wtraction = Ftraction Δx
          = 15000*12
          = 180000 J = 180 kJ
```

となる。

検算すると

```text
ΔK = (1/2)*5000*(8^2-4^2) = 120 kJ
Wresistance = 5000*12 = 60 kJ
ΔK + Wresistance = 180 kJ
```

であり、牽引仕事と一致する。

さらに区間端の機械電力は `60 kW` と `120 kW` なので、台形則による電力積分も

```text
E = (60+120)/2 * 2 = 180 kJ
```

となる。`F dx` と `P dt` が一致することまで確認する。

### 例題2 本試験標準想定 — 一次運動モデルと伝達関数

教育用の一次モデルを

```text
6 dv/dt + 2v = 12
v(0)=0
```

とする。

まず零初期条件で入力 `F` から速度 `v` への伝達関数を作ると

```text
G(s)=1/(6s+2)
```

である。したがって

```text
τ=M/D=6/2=3 s
定常速度=F/D=12/2=6 m/s
```

と読める。

一定入力に対する時間応答は

```text
v(t)=6(1-exp(-t/3))
```

なので、`t=3 s` では

```text
v(3)=6(1-exp(-1))
    =3.7927... m/s
```

である。

同じ式をEuler法、`Δt=1 s` で進めると

```text
v0 = 0
v1 = 2.0000
v2 = 3.3333
v3 = 4.2222 m/s
```

となる。解析解との差は約 `0.4295 m/s` である。数値解が解析解と完全一致しないことを異常とせず、刻み幅による差として確認する。

この例題では、微分方程式、時間応答、伝達関数が同じ一次モデルの別表現であることを確認する。

### 例題3 複合・ひっかけ — 回生符号とサンプリング条件

まず教育用の回生区間を

```text
m = 3000 kg
Fregen = -6000 N
v0 = 12 m/s
Δt = 1 s
計算時間 = 3 s
走行抵抗 = 0
```

とする。

加速度は

```text
a = -6000/3000 = -2 m/s^2
```

なので速度は

```text
12, 10, 8, 6 m/s
```

と変化する。台形則で走行距離は

```text
Δx = (12+10)/2 + (10+8)/2 + (8+6)/2
   = 11+9+7
   = 27 m
```

である。

符号付きの機械エネルギーは

```text
E_signed = Fregen Δx
         = -6000*27
         = -162000 J = -162 kJ
```

となる。運動エネルギー変化も

```text
ΔK=(1/2)*3000*(6^2-12^2)=-162 kJ
```

で一致する。回収量を正で表示するなら

```text
Eregen_mechanical = 162 kJ
```

とする。ただし、これは電気側の実回収電力量ではない。

次に、同じ教材内で波形解析用の教育用代理波形

```text
x(t)=sin(2π*10t)+(1/4)sin(2π*30t)
```

を扱う。最大周波数は `30 Hz` である。

`f_s=50 Hz` とすると

```text
50 > 2*30
```

を満たさないため不適切である。ここで数値スペクトルを先に計算してはいけない。

`f_s=80 Hz`, `N=8` なら

```text
80 > 60
Δf = 80/8 = 10 Hz
```

であり、10 Hzは `k=1`、30 Hzは `k=3` の周波数ビンに対応する。

この例のひっかけは、回生エネルギーの負符号を「回収量が負」と誤読することと、サンプリング条件を確認せずFFT結果だけを見ることである。
