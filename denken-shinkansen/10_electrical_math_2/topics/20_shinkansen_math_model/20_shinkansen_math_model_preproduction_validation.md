# Topic 20 制作前独立検証

作成日: 2026-09-19

対象: `20 新幹線を数式モデルだけで走らせる`

判定: `PASS / PREPRODUCTION_VALIDATION_COMPLETE`

## 1. 目的

`SPEC.md` と制作前EXAM_ALIGNMENTで固定した範囲だけを使い、牽引力・走行抵抗→運動方程式→数値積分→速度・位置→電力・エネルギー→一次の簡略制御モデル→周期波形・周波数スペクトルの接続を、教材本文作成前に独立検証する。

接続確認した第二種公式過去問5問は各要素が試験範囲から逸脱しないことを確認するためのもので、統合新幹線モデル自体を直接要求する過去問として扱わない。

本検証の数値はすべて教育用仮定値であり、実車値ではない。

## 2. Case A: 牽引力→速度・位置→仕事・電力量

教育用条件を

```text
m = 4000 kg
Ftraction = 12000 N
Fresistance = 2000 N
Fgrade = 0 N
v(0) = 0 m/s
dt = 1 s
計算時間 = 4 s
```

とする。

運動方程式から

```text
a = (12000 - 2000) / 4000 = 2.5 m/s^2
```

である。Euler更新では

```text
v = 0, 2.5, 5.0, 7.5, 10.0 m/s
```

となる。位置は同じ1秒刻みの速度を台形則で積分し、

```text
x = 20.0 m
```

を得る。

牽引側機械電力を `P=Ftraction v` とし、時間積分すると

```text
Etraction = 240000 J = 240 kJ
```

である。一方、距離積分では

```text
Wtraction = Ftraction x = 12000 * 20 = 240000 J
```

となり一致する。

抵抗仕事と運動エネルギー増加は

```text
Wresistance = 2000 * 20 = 40000 J
Delta K = (1/2) * 4000 * 10^2 = 200000 J
```

なので

```text
Etraction = Delta K + Wresistance
240000 = 200000 + 40000 J
```

も成立する。

判定: `PASS`。

## 3. Case B: 回生側の符号規約

機械側の符号確認だけを目的に、

```text
m = 4000 kg
Fregen = -4000 N
v(0) = 10 m/s
dt = 1 s
計算時間 = 4 s
```

と置く。走行抵抗や電力変換効率は入れない。

```text
a = -1.0 m/s^2
v = 10, 9, 8, 7, 6 m/s
x = 32 m
```

となる。`Pregen=Fregen v` を時間積分すると

```text
E_signed = -128000 J
```

であり、運動エネルギー変化

```text
Delta K = (1/2) * 4000 * (6^2 - 10^2) = -128000 J
```

と一致する。

回収側を正で表示する場合は

```text
Eregen_mechanical = -E_signed = 128000 J
```

とする。この値は機械側の符号確認用であり、電気側の実回収電力量を表すものではない。

判定: `PASS`。

## 4. Case C: 刻み幅・解析解・伝達関数の整合

既完了Topic 10 / 17と同じ一次モデル

```text
M dv/dt + Dv = F
```

に対し、教育用条件

```text
M = 4
D = 1
F = 8
v(0) = 0
```

を使う。

解析解は

```text
v(t) = 8(1 - exp(-t/4))
```

なので、`t=4 s` では

```text
v_exact = 5.056964470628...
```

である。Euler法で同じ時刻まで計算すると、

```text
dt = 1.00 s : 5.468750000000, error = 0.411785529372
dt = 0.50 s : 5.251128673553, error = 0.194164202925
dt = 0.25 s : 5.151406956386, error = 0.094442485757
```

となり、この検証条件では刻み幅を小さくすると誤差が単調に減少した。

零初期条件でラプラス変換すると

```text
G(s) = V(s)/F(s) = 1/(4s + 1)
```

であり、時定数 `tau=M/D=4 s`、直流ゲイン `1/D=1`、定常速度 `F/D=8` を時間応答と整合させられる。

さらに解析応答を元の微分方程式へ代入し、`M dv/dt + Dv = F` が数値的に成立することを確認した。

判定: `PASS`。

## 5. Case D: 周期成分→サンプリング→周波数スペクトル

FFTアルゴリズムの実装詳細へ入らず、Topic 13 / 14の接続だけを確認するため、基本波10 Hzと第3高調波30 Hzだけを残した教育用周期波形

```text
x(t) = sin(2*pi*10*t) + (1/3) sin(2*pi*30*t)
```

を使う。これは実車PWM波形ではなく、PWMの基本波・高調波を周波数軸で読むための帯域制限した代理波形である。

```text
fs = 80 Hz
N = 8
Delta f = fs/N = 10 Hz
fmax = 30 Hz
```

なので

```text
fs = 80 > 2*fmax = 60 Hz
```

を満たす。

直接DFTで確認すると、正周波数側の振幅は

```text
10 Hz : 1.000000000000
30 Hz : 0.333333333333
0, 20, 40 Hz : 数値丸め範囲で0
```

となり、時間波形で置いた基本波・第3高調波が対応する周波数ビンへ現れることを確認した。

FFTはこのDFTと同じ離散スペクトルを効率よく求める手段としてのみ扱い、アルゴリズム詳細は追加しない。

判定: `PASS`。
