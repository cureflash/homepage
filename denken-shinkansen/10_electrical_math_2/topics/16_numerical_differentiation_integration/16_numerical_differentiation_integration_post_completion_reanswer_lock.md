## 独立答案

### 1. R6 一次「法規」問4 (1)〜(2)

図の3負荷を区分一定値として時間積分する。

負荷aの1日電力量:

`3×6 + 5×4 + 6×2 + 7×2 + 6×6 + 5×2 + 3×2 = 116 MWh`

負荷b:

`2×8 + 4×4 + 3×2 + 4×6 + 2×4 = 70 MWh`

負荷c:

`1×10 + 2×2 + 1×2 + 2×4 + 1×6 = 30 MWh`

したがって総電力量は

`116 + 70 + 30 = 216 MWh`

平均需要電力は

`216 / 24 = 9.00 MW`

各時刻帯の合成需要を確認すると最大需要電力は `12 MW`。したがって総合負荷率は

`9.00 / 12 × 100 = 75.0 %`

固定答案:

- (1) `9.00 MW`
- (2) `75.0 %`

### 2. R4 二次「電力・管理」問1

有効貯水量 `V=180×10^3 m^3`、自然流量 `Q0=20 m^3/s`、有効落差 `H=60 m`。

ピークは16〜22時の6 h、オフピークは18 h。調整池を最大限活用し、日ごとに同じ運転を繰り返すので、オフピークで全有効貯水量を貯め、ピークで全量を放出する。

ピーク時流量:

`Q_peak = 20 + 180000/(6×3600) = 28.333... m^3/s`

オフピーク時流量:

`Q_off = 20 - 180000/(18×3600) = 17.222... m^3/s`

水車・発電機合成効率はピーク85 %、オフピーク80 %。`P=ρgQHη`、`ρ=1000 kg/m^3`、`g=9.8 m/s^2` より

`P_peak = 1000×9.8×28.333...×60×0.85 = 1.4161×10^7 W`

`P_off = 1000×9.8×17.222...×60×0.80 = 8.1013×10^6 W`

3桁で固定する。

固定答案:

- ピーク負荷時出力: `1.42×10^4 kW`
- オフピーク負荷時出力: `8.10×10^3 kW`

### 3. H23 二次「電力・管理」問6

送電端電力は等時間幅で `1, 3, 5, 4, 2`、最大値は `5`。

(1)a 送電端負荷率:

`F = (1+3+5+4+2)/(5×5) = 15/25 = 0.600`

送電端電圧・力率一定、損失は抵抗分のみなので各時刻の損失は `P^2` に比例する。

(1)b 損失係数:

`F_L = (1^2+3^2+5^2+4^2+2^2)/(5×5^2)`

`= 55/125 = 0.440`

(2) 一般式:

期間を `T`、最大送電端電力を `P_m`、最大損失を `P_Lm` とする。

`送電電力量 = P_m T F`

`損失電力量 = P_Lm T F_L`

したがって

`kWh損失率 = (P_Lm T F_L)/(P_m T F)`

一方

`kW損失率 = P_Lm/P_m`

よって

`(kWh損失率)/(kW損失率) = F_L/F`

固定答案:

- (1)a `0.600`
- (1)b `0.440`
- (2) `(kWh損失率)/(kW損失率)=損失係数/送電端負荷率`

### 4. H22 二次「電力・管理」問3 (4)

力率0.8一定。全損失[kW]を全負荷 `P[MW]` で表す。

変圧器Aのみ:

`P_LA = 40 + 216×(P/(0.8×45))^2 = 40 + P^2/6`

変圧器Bのみ:

`P_LB = 30 + 144×(P/(0.8×30))^2 = 30 + P^2/4`

A,B並列では同一%インピーダンスのため容量比45:30=3:2で分担し、両器の負荷率は等しい。

`P_LAB = 40+30 + (216+144)×(P/(0.8×75))^2 = 70 + P^2/10`

各時間帯で損失最小かつ定格内となる運転は:

- 0〜8時、`P=12 MW`: Aのみ、損失 `64 kW`
- 8〜12時、`P=18 MW`: Aのみ、損失 `94 kW`
- 12〜20時、`P=25 MW`: A+B並列、損失 `132.5 kW`
- 20〜24時、`P=10 MW`: Bのみ、損失 `55 kW`

1日負荷電力量:

`E_out = 12×8 + 18×4 + 25×8 + 10×4 = 408 MWh`

1日損失電力量:

`E_loss = (64×8 + 94×4 + 132.5×8 + 55×4)/1000`

`= 2.168 MWh`

全日効率:

`η_d = 408/(408+2.168)×100 = 99.471... %`

3桁で固定する。

固定答案:

- (4) `η_d = 99.5 %`
