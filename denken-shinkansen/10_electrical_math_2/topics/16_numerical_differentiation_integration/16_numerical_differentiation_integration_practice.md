# 解答・完全解説

## 問1 正答 3

前進差分は

```text
a ≈ {v(t+h)-v(t)}/h
```

である。したがって

```text
a ≈ (21-18)/(4.5-4.0)
  = 3/0.5
  = 6.0 m/s^2
```

正答は3。速度差だけでなく、時間差 `0.5 s` で割る。

## 問2 正答 3

中心差分では、前後の点を使う。

```text
a(10)
≈ {v(11)-v(9)}/(11-9)
= (30-24)/2
= 3.0 m/s^2
```

正答は3。1秒間隔でも、中心差分の分母は前後を合わせた `2 s` になる。

## 問3 正答 2

台形則より

```text
E ≈ Δt(P_0+P_1)/2
  = 0.5(6+10)/2
  = 4 MWh
```

正答は2。`MW × h = MWh` となる。

## 問4 正答 3

まず区分一定の電力を時間積算する。

```text
E
= 8×6 + 12×10 + 4×8
= 48 + 120 + 32
= 200 MWh
```

平均電力は

```text
P_avg = E/24
      = 200/24
      = 8.333... MW
```

よって正答は3。時間幅が異なるので、`(8+12+4)/3` の単純平均にはしない。

## 問5 正答 3

等間隔3点なのでSimpson則

```text
E ≈ h/3(P_0+4P_1+P_2)
```

を使う。`h=1 h` より

```text
E
= 1/3(4+4×10+8)
= 52/3
= 17.333...
≈ 17.33 MWh
```

正答は3。

## 問6 正答 4

期間全体で電力量を積算する。

```text
E_out
= 10×8 + 6×16
= 80 + 96
= 176 MWh
```

```text
E_loss
= 0.10×8 + 0.06×16
= 0.80 + 0.96
= 1.76 MWh
```

したがって

```text
η
= 176/(176+1.76)
= 0.990099...
≈ 99.0 %
```

正答は4。瞬時効率を単純平均せず、出力電力量と損失電力量を期間全体で積算する。

## 問7 正答 2

複合Simpson則では、基本形 `1,4,2,4,...,2,4,1` を等間隔データへ適用するため、区間数は偶数でなければならない。したがって正答は2。

非等間隔データへ等間隔用の係数をそのまま適用しない。

## 問8 正答 4

前進差分を、真値 `y` と測定誤差 `ε` に分けて書くと

```text
{(y_(i+1)+ε_(i+1))-(y_i+ε_i)}/h
```

となる。誤差成分も

```text
(ε_(i+1)-ε_i)/h
```

として `h` で割られる。したがって `h` を小さくすることで離散化誤差が減っても、測定ノイズの影響が増える場合がある。正答は4。

## 問9 解答

(1) 各時間帯は区分一定なので、長方形の面積和で求める。

```text
E
= 5×6 + 10×12 + 7×6
= 30 + 120 + 42
= 192 MWh
```

(2) 平均電力は

```text
P_avg = 192/24 = 8.0 MW
```

(3) 負荷率は

```text
F = P_avg/P_max
  = 8/10
  = 0.80
  = 80 %
```

答え: `192 MWh`, `8.0 MW`, `80 %`。

## 問10 解答

(1) 1日の貯留量が変化しないので、1日の流入量と放流量の時間積算が等しい。

```text
20×24 = 6Q_peak + 18Q_off
```

両辺を6で割ると

```text
Q_peak + 3Q_off = 80
```

である。

(2) 条件

```text
Q_peak - Q_off = 10
```

より `Q_peak=Q_off+10`。これを収支式へ代入する。

```text
Q_off + 10 + 3Q_off = 80
4Q_off = 70
Q_off = 17.5 m^3/s
```

したがって

```text
Q_peak = 27.5 m^3/s
```

(3) 与えられた比例式だけを使う。

```text
P_peak = 0.50×27.5 = 13.75 MW
P_off  = 0.50×17.5 = 8.75 MW
```

答え: `Q_peak=27.5 m^3/s`, `Q_off=17.5 m^3/s`, `P_peak=13.75 MW`, `P_off=8.75 MW`。

R4二次「電力・管理」問1への接続は、設備固有理論ではなく「時間帯ごとの率を時間積算して収支式を作り、二つの運転値を求める」部分に限定する。

## 問11 解答

(1) 3区間は同じ8時間なので、平均送電電力は

```text
P_avg
= (12×8 + 8×8 + 4×8)/24
= (12+8+4)/3
= 8 MW
```

負荷率は

```text
F = P_avg/P_max
  = 8/12
  = 2/3
  ≈ 0.6667
```

(2) `P_loss=kP^2` なので、最大損失電力は

```text
P_loss,max = k×12^2 = 144k
```

平均損失電力は

```text
P_loss,avg
= k(12^2+8^2+4^2)/3
= k(144+64+16)/3
= (224/3)k
```

したがって

```text
F_L
= P_loss,avg/P_loss,max
= {(224/3)k}/(144k)
= 224/432
= 14/27
≈ 0.5185
```

(3) 全時間を `T` とすると

```text
E_loss = P_loss,max F_L T
E      = P_max F T
```

よって

```text
kWh損失率
= E_loss/E
= (P_loss,max/P_max)(F_L/F)
```

一方

```text
kW損失率 = P_loss,max/P_max
```

だから

```text
(kWh損失率)/(kW損失率)
= F_L/F
```

となる。数値は

```text
F_L/F
= (14/27)/(2/3)
= 14/18
= 7/9
≈ 0.7778
```

答え: `P_avg=8 MW`, `F=2/3`, `F_L=14/27≈0.5185`, 比 `7/9≈0.7778`。

重要なのは `平均(P^2)` を使うことであり、`(平均P)^2` ではない。

## 問12 解答

(1) `t=1 s` の中心差分は

```text
a(1)
≈ {v(2)-v(0)}/(2-0)
= (18-10)/2
= 4.0 m/s^2
```

(2) 電力データは等間隔3点なので、Simpson則を使う。

出力電力量:

```text
E_out
= 1/3(6 + 4×9 + 12)
= 54/3
= 18.0 MWh
```

損失電力量:

```text
E_loss
= 1/3(0.12 + 4×0.18 + 0.24)
= 1.08/3
= 0.36 MWh
```

(3) 期間全体の効率は

```text
η
= 18.0/(18.0+0.36)
= 18/18.36
= 0.980392...
≈ 98.04 %
```

答え: `4.0 m/s^2`, `E_out=18.0 MWh`, `E_loss=0.36 MWh`, `η≈98.04 %`。
