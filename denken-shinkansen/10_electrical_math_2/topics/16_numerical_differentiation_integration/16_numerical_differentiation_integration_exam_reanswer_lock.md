## 1. R6 一次「法規」問4 (1)〜(2)

図の日負荷曲線を各負荷ごとに時間積分する。

負荷a:

```text
3×6 + 5×4 + 6×2 + 7×2 + 6×6 + 5×2 + 3×2 = 116 MWh
```

負荷b:

```text
2×8 + 4×4 + 3×2 + 4×6 + 2×4 = 70 MWh
```

負荷c:

```text
1×10 + 2×2 + 1×2 + 2×4 + 1×6 = 30 MWh
```

したがって1日の総電力量は

```text
116 + 70 + 30 = 216 MWh
```

平均需要電力は

```text
216/24 = 9.00 MW
```

総合負荷の最大値は、10〜12時および14〜18時で

```text
12 MW
```

なので総合負荷率は

```text
9.00/12 × 100 = 75.0 %
```

固定回答:

```text
(1) 9.00 MW
(2) 75.0 %
```

## 2. R4 二次「電力・管理」問1

調整池の有効貯水量は `180×10^3 m^3`、自然流量は `20 m^3/s`。ピーク6 h、オフピーク18 hで、毎日同じ運転を繰り返し、調整池を最大限活用する。

オフピーク時には越流させないため、18 hで有効貯水量を満たす流量差は

```text
(20-Q_off)×18×3600 = 180000
Q_off = 17.222... m^3/s
```

ピーク時には6 hで同じ貯水量を使い切るので

```text
(Q_peak-20)×6×3600 = 180000
Q_peak = 28.333... m^3/s
```

水力出力を

```text
P = ρgQHη
```

とし、`ρ=1000 kg/m^3`, `g=9.8 m/s^2`, `H=60 m` を用いる。

ピーク時 (`η=0.85`):

```text
P_peak = 1000×9.8×28.333...×60×0.85
       = 1.4161×10^7 W
       ≈ 1.42×10^4 kW
```

オフピーク時 (`η=0.80`):

```text
P_off = 1000×9.8×17.222...×60×0.80
      = 8.101×10^6 W
      ≈ 8.10×10^3 kW
```

固定回答:

```text
ピーク時出力 ≈ 14.2 MW = 1.42×10^4 kW
オフピーク時出力 ≈ 8.10 MW = 8.10×10^3 kW
```

## 3. H23 二次「電力・管理」問6

送電端電力は5等時間区間で

```text
1, 3, 5, 4, 2
```

と読む。

### (1)a 送電端負荷率

平均電力は

```text
(1+3+5+4+2)/5 = 3
```

最大電力は `5` なので

```text
送電端負荷率 = 3/5 = 0.60
```

### (1)b 損失係数

送電損失が電力の二乗に比例するので、最大損失を基準とした平均損失の比は

```text
(1^2+3^2+5^2+4^2+2^2)/(5×5^2)
= 55/125
= 0.44
```

したがって

```text
損失係数 = 0.44
```

### (2) kWh損失率とkW損失率の比

最大送電電力を `P_m`、負荷率を `F`、損失係数を `L`、期間を `T`、損失を `P_loss=kP^2` とする。

```text
kWh損失率
= [k P_m^2 L T]/[P_m F T]
= k P_m (L/F)

kW損失率
= [k P_m^2]/P_m
= k P_m
```

よって

```text
(kWh損失率)/(kW損失率) = L/F
```

すなわち、kWh損失率とkW損失率の比は、損失係数と送電端負荷率の比に等しい。

固定回答:

```text
(1)a 0.60
(1)b 0.44
(2) (kWh損失率)/(kW損失率) = 損失係数/送電端負荷率
```

## 4. H22 二次「電力・管理」問3 (4)

力率0.8一定。変圧器Aは45 MVA、無負荷損40 kW、定格負荷時負荷損216 kW。Bは30 MVA、無負荷損30 kW、定格負荷時負荷損144 kW。両機の短絡インピーダンスは同一10 %なので、並列時の負荷分担は定格容量比 `45:30=3:2`。

全負荷を `P [MW]` とすると、各運転方式の全損失は

```text
A単独:   P_LA = 40 + 216(P/36)^2 = 40 + P^2/6  [kW]
B単独:   P_LB = 30 + 144(P/24)^2 = 30 + P^2/4  [kW]
A+B並列: P_LAB = 70 + 360(P/60)^2 = 70 + 0.1P^2 [kW]
```

各時間帯で損失最小かつ容量内となる運転は

```text
0〜8時,  P=12 MW: A単独, 損失64 kW
8〜12時, P=18 MW: A単独, 損失94 kW
12〜20時,P=25 MW: A+B並列, 損失132.5 kW
20〜24時,P=10 MW: B単独, 損失55 kW
```

負荷側の1日電力量は

```text
E_out = 12×8 + 18×4 + 25×8 + 10×4
      = 408 MWh
      = 408000 kWh
```

損失電力量は

```text
E_loss = 64×8 + 94×4 + 132.5×8 + 55×4
       = 2168 kWh
```

したがって全日効率は

```text
η_d = 408000/(408000+2168)×100
    = 99.471... %
    ≈ 99.5 %
```

固定回答:

```text
η_d ≈ 99.5 %
```
