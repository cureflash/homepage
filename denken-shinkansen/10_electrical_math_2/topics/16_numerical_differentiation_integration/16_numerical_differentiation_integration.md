## 公式問題から逆算した教材内必要説明

### 1. 離散データと差分

時刻 `t_i` ごとの観測値 `y_i` を連続関数そのものと混同しない。隣接点の変化量

```text
Δy = y_(i+1) - y_i
Δt = t_(i+1) - t_i
```

を出発点とし、速度データなら `Δv/Δt` が区間の加速度近似になることを説明する。

等間隔データでは、前進差分・中心差分を数値微分の基本形として扱う。高次公式の体系化には進まない。

### 2. 数値積分と電力量

連続量では

```text
E = ∫ P(t) dt
```

であることを確認し、時間帯ごとに一定なら `Σ P_i Δt_i` が厳密な面積になることをR6/H23/H22へ接続する。

実測点の間が未知の場合は台形則

```text
∫[a,b] f(x) dx ≈ Σ (h/2)(f_i + f_(i+1))
```

で折れ線近似の面積を求めることを示す。

### 3. Simpson則の基本

等間隔3点を1組として二次曲線で近似する基本形

```text
∫[x_0,x_2] f(x) dx ≈ (h/3)(f_0 + 4f_1 + f_2)
```

までを扱う。適用条件として等間隔であること、複合Simpson則では区間数が偶数であることを明示する。高次Newton-Cotes公式へは広げない。

### 4. 誤差と刻み幅

刻み幅を小さくすると一般に離散化誤差は減る一方、測定ノイズを含む数値微分では差分がノイズを増幅し得ることを説明する。解析値が分かる簡単な関数で近似値との差を検算し、算法名の暗記だけにしない。

### 5. 電験問題への解法接続

固定過去問については、次の共通手順へ落とす。

```text
1. 横軸の単位と刻みを読む
2. 縦軸の量と単位を読む
3. 求める量が「変化率」か「積算量・平均量」か判定する
4. 変化率なら差分、積算量なら面積として式を選ぶ
5. 区分一定・折れ線・等間隔3点などデータ形状に応じて和・台形則・Simpson則を選ぶ
6. 単位を確認する
7. 刻み幅を変えたときの値の変化を誤差の手掛かりとして確認する
```

# 解説本文

## 1. このテーマで電験は何を問うか

本Topicの中心は「離散データから、変化率または積算量を正しく求める」ことである。第二種本試験で台形則やSimpson則の名称を直接問う問題は今回確認できなかったが、日負荷曲線、時間帯別電力、損失、流量などを時間方向へ集計する処理は繰り返し現れる。

問題文を読んだら最初に、求める量を次の二つへ分ける。

- 変化率: `dy/dt` に対応する。離散データでは差分で近似する。
- 積算量: `∫ y dt` に対応する。区分一定なら和、測定点だけが与えられるなら台形則やSimpson則で近似する。

電力量では `MW × h = MWh`、平均電力では `MWh / h = MW` になる。数値計算法より前に、横軸・縦軸・単位を読むことが重要である。

## 2. 離散データと差分

連続関数 `y(t)` の微分は一点での瞬間的な変化率だが、実測データでは時刻 `t_i` ごとの値 `y_i` しか持たない。そのため、近い二点または三点から傾きを近似する。

等間隔 `h` のデータに対する前進差分は

```text
(dy/dt)_i ≈ (y_(i+1) - y_i) / h
```

である。これは点 `i` と次の点を結んだ直線の傾きであり、端点付近でも使いやすい。

点 `i` の前後にデータがあるなら中心差分

```text
(dy/dt)_i ≈ (y_(i+1) - y_(i-1)) / (2h)
```

を使える。同じ滑らかな関数・同じ刻み幅なら、中心差分は通常、前進差分より離散化誤差が小さい。ただし測定ノイズがあると、分母 `h` が小さいほどノイズによる差も大きな変化率として現れやすい。

速度データ `v_i` なら

```text
a_i ≈ Δv / Δt
```

として加速度を求める。速度が `m/s`、時間が `s` なら加速度は `m/s^2` になる。

## 3. 刻み幅と誤差

刻み幅 `h` は、測定点または計算点の間隔である。一般に滑らかな関数では `h` を小さくすると離散化誤差は小さくなる。ただし「小さければ無条件に良い」とは限らない。

数値微分では、二つの近い測定値の差をさらに `h` で割るため、測定ノイズや丸め誤差の影響を受けやすい。したがって実測データでは、刻み幅を細かくしたことだけを理由に結果を真値とみなさない。

解析値が分かる教育用関数なら、近似値と解析値を比較して誤差を確認できる。本試験で必要なのは高次誤差解析ではなく、刻み幅と近似精度の関係を理解し、結果の桁・単位・物理的妥当性を検算することである。

## 4. 積分を「面積」として読む

電力 `P(t)` を時間積分すると電力量 `E` になる。

```text
E = ∫ P(t) dt
```

時間帯ごとに電力が一定なら、各区間は長方形なので

```text
E = Σ P_i Δt_i
```

で正確に求められる。これは数値積分の近似ではなく、問題文が「その区間では一定」と与えたモデルに対する正確な面積である。

平均電力は

```text
P_avg = E / T
```

負荷率は、最大需要電力を `P_max` として

```text
load factor = P_avg / P_max
```

で求める。日負荷曲線では「曲線下の面積 → 1日の電力量 → 24時間で割る → 平均需要電力」という順で考える。

## 5. 台形則

実測点 `f_i` の間の真の曲線が分からず、隣接点間を直線で近似するときは台形則を使う。等間隔 `h` なら一区間の面積は

```text
A_i ≈ h (f_i + f_(i+1)) / 2
```

複数区間では

```text
∫[x_0,x_n] f(x) dx
≈ h { f_0/2 + f_1 + f_2 + ... + f_(n-1) + f_n/2 }
```

となる。

非等間隔なら各区間ごとに幅を使う。

```text
A_i ≈ (x_(i+1)-x_i)(f_i+f_(i+1))/2
```

電力データなら縦軸が `MW`、横軸が `h` のため、台形の面積は `MWh` になる。

## 6. Simpson則の基本

等間隔3点 `x_0, x_1, x_2` を二次曲線で近似するSimpson則は

```text
∫[x_0,x_2] f(x) dx
≈ h/3 (f_0 + 4f_1 + f_2)
```

である。ここで `h=x_1-x_0=x_2-x_1`。

複数区間へ適用する場合は、区間数が偶数でなければならない。等間隔でないデータへ、この係数 `1,4,1` をそのまま当てはめてはいけない。

台形則とSimpson則で値が異なるとき、元の連続曲線を知らなければ、計算結果だけから真値を断定できない。滑らかな曲線に対してSimpson則は一般に高精度だが、適用条件を確認することが先である。

## 7. 何を積分するかを先に決める

損失電力が `P` に比例するとは限らない。例えば損失が

```text
P_loss = k P^2
```

で与えられるなら、時間平均する対象は `P` ではなく `P^2` である。

```text
P_loss,avg = (1/T) ∫ kP(t)^2 dt
```

区分一定なら

```text
P_loss,avg = (1/T) Σ kP_i^2 Δt_i
```

となる。`(平均P)^2` と `平均(P^2)` は一般に一致しない。H23問6に接続する重要なひっかけである。

同様に全日効率を求めるときは、瞬時効率の単純平均ではなく、期間全体の出力電力量と損失電力量を積算して

```text
η = E_out / (E_out + E_loss)
```

の形にする。H22問3 (4)への接続点である。

## 8. 時間収支を積算する

流量やエネルギー収支も同じ考え方で扱える。ある量の流入と流出が時間帯ごとに一定なら

```text
ΔV = Σ (Q_in,i - Q_out,i) Δt_i
```

で期間全体の増減を求める。

R4問1では水力設備固有の詳細を本Topicへ持ち込まず、「時間帯ごとの率を時間で積算して収支を作る」という数学だけを接続する。

## 9. 新幹線データへの接続

ここでは実車値を使わず、教育用の速度・電力データだけを使う。

速度の時系列データからは差分で加速度を求められる。電力の時系列データからは面積を求めることで消費・回生電力量を計算できる。実測点しかない場合は台形則等で近似し、区間一定と明示されたモデルなら `ΣP_iΔt_i` を使う。

この章で必要なのは車両固有の数値を覚えることではなく、「変化率なら差分、積算量なら面積」という判断を電験問題へ転用できることである。

## 10. 問題を見たときの解法手順

```text
1. 横軸の量・単位・刻み幅を確認する。
2. 縦軸の量・単位を確認する。
3. 求める量が変化率か積算量かを判定する。
4. 変化率なら前進差分または中心差分を選ぶ。
5. 積算量なら、区分一定・折れ線近似・等間隔3点のどれかを判定する。
6. 区分一定なら Σy_iΔt_i、折れ線近似なら台形則、条件を満たす場合のみSimpson則を使う。
7. 平均量なら積算値を全時間Tで割る。
8. 損失がP^2等に比例する場合は、積分する関数そのものを取り違えない。
9. 単位を確認する。
10. 刻み幅、桁、符号、物理的妥当性を検算する。
```

## 11. 頻出ミス・ひっかけ

- `MW` と `MWh` を混同する。
- 平均電力を単純な算術平均で出し、時間幅の違いを無視する。
- 区分一定データに不要な台形補間を入れる。
- 非等間隔データへ等間隔用のSimpson則を使う。
- 複合Simpson則で区間数が偶数か確認しない。
- `平均(P^2)` を `(平均P)^2` としてしまう。
- 全日効率で瞬時効率の単純平均を取る。
- 数値微分で `Δv/Δt` の時間幅を取り違える。
- 刻み幅を小さくすれば測定ノイズまで必ず減ると考える。

# 3段階例題

## 例題1 基礎: 速度データから加速度

教育用の速度データが次のように得られたとする。

| t [s] | 0 | 2 | 4 |
|---:|---:|---:|---:|
| v [m/s] | 0 | 4 | 10 |

`t=2 s` における加速度を中心差分で求める。

中心差分は

```text
a(2) ≈ {v(4)-v(0)} / (4-0)
     = (10-0)/4
     = 2.5 m/s^2
```

ここで分母は前後2区間を合わせた `4 s` である。`h=2 s` だから中心差分の分母は `2h=4 s` になる。

答え: `2.5 m/s^2`

## 例題2 本試験標準: 区分一定の電力から電力量・平均電力・負荷率

24時間を4時間ずつ6区間に分け、各区間の電力が次のように一定だったとする。

```text
6, 8, 10, 12, 9, 7 MW
```

総電力量は

```text
E = 4(6+8+10+12+9+7)
  = 4×52
  = 208 MWh
```

平均電力は

```text
P_avg = 208/24
      = 8.666... MW
      ≈ 8.67 MW
```

最大需要電力は `12 MW` なので負荷率は

```text
8.666.../12 = 0.7222...
```

したがって

```text
load factor ≈ 72.2 %
```

区分ごとに電力が一定と与えられているため、ここでは台形則ではなく長方形の面積和 `ΣP_iΔt_i` を使う。

答え: `208 MWh`, `8.67 MW`, `72.2 %`

## 例題3 複合・ひっかけ: 台形則とSimpson則

1時間間隔の測定値が

| t [h] | 0 | 1 | 2 | 3 | 4 |
|---:|---:|---:|---:|---:|---:|
| P [MW] | 0 | 6 | 8 | 6 | 0 |

と得られた。測定点間の連続曲線は未知とする。

台形則では

```text
E_T
= 1{0/2 + 6 + 8 + 6 + 0/2}
= 20 MWh
```

区間数は4で偶数、データは等間隔なのでSimpson則も適用できる。

```text
E_S
= (1/3){0 + 4×6 + 2×8 + 4×6 + 0}
= 64/3
≈ 21.33 MWh
```

二つの値は一致しない。元の連続曲線が与えられていないため、この情報だけで真の電力量を断定してはいけない。確認すべき点は「台形則は折れ線近似」「Simpson則は等間隔かつ偶数区間で二次曲線近似」という前提である。

答え: 台形則 `20 MWh`、Simpson則 `21.33 MWh`
