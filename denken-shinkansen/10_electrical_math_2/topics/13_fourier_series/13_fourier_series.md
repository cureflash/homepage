### H28 二次「機械・制御」問3 (3)

相電圧 `v_RO` は半周期ごとに `+Ed/2`, `-Ed/2` を取る周期波形である。

フーリエ正弦係数は

```text
b_n = Ed/(nπ) {1-(-1)^n}
```

となるため、偶数次は0、奇数次は `2Ed/(nπ)` となる。したがって3次、9次等の3n次高調波を含む。

一方、線間電圧は相電圧同士の120°位相差の差であり、三相で同相となる3n次成分は差を取ると打ち消される。

結論: 3n次高調波を含むのは `v_RO`。公式標準解答と一致。`PASS`。

### H28 二次「機械・制御」問3 (4)

`v_RS` は1周期 `2π` のうち、絶対値 `Ed` となる区間の合計が `4π/3`、残りは0である。

```text
E0
= sqrt{ (1/(2π)) Ed^2 (4π/3) }
= sqrt(2/3) Ed
```

公式標準解答と一致。`PASS`。

### H24 一次「機械」問3 (4)

5次成分を完全に打ち消す位相差は

```text
cos(5φ/2)=0
→ φ=π/5
```

7次成分では同様に `φ=π/7`。両者を同時に0にはできないため、その中間として選択肢 `π/6` を選ぶ。

結論: `ヲ`。公式標準解答と一致。`PASS`。

### H24 一次「機械」問3 (5)

二つの基本波を位相差 `φ` で加えると

```text
sin θ + sin(θ-φ)
= 2 cos(φ/2) sin(θ-φ/2)
```

したがって合成振幅は1ユニットの `2 cos(φ/2)` 倍。`φ=π/6` では `2 cos(π/12)<2`。

結論: `2倍未満` → `ル`。公式標準解答と一致。`PASS`。

### H22 一次「機械」問3 (3)

相電圧基本波の振幅が

```text
(Ed/2) k
```

なので、相電圧基本波実効値は

```text
Ed k/(2sqrt(2))
```

三相平衡の線間電圧はその `sqrt(3)` 倍であるから

```text
sqrt(3) Ed k/(2sqrt(2))
```

結論: `ト`。公式標準解答と一致。`PASS`。

## 過去問から固定する教材内必要説明

### 1. 周期関数とフーリエ級数

周期 `2π` の関数について、少なくとも次の一貫した係数定義を使えるようにする。

```text
f(θ)=a0/2 + Σ[an cos(nθ)+bn sin(nθ)]

a0=(1/π)∫[-π,π] f(θ)dθ
an=(1/π)∫[-π,π] f(θ)cos(nθ)dθ
bn=(1/π)∫[-π,π] f(θ)sin(nθ)dθ
```

係数規約を途中で混在させない。

### 2. 奇関数・偶関数と半波対称

- 偶関数では正弦係数 `bn=0`。
- 奇関数では直流成分と余弦係数 `a0=an=0`。
- `f(θ+π)=-f(θ)` の半波対称を持つ波形では偶数次高調波が消える。

H28問3 (3)を、全係数を機械的に積分する方法と対称性から絞る方法の両方で追えるようにする。

### 3. 基本波と高調波

- `n=1` が基本波。
- `n=2,3,...` が高調波。
- 各次数の周波数は基本周波数の `n` 倍。
- 三相の3n次成分が線間差で打ち消される理由を、位相と差分から説明する。

### 4. 非正弦波の実効値

周期波形の実効値を定義から計算できるようにする。

```text
X_rms=sqrt{(1/T)∫[0,T] x(t)^2 dt}
```

区分一定波形では、各区間の `x^2` と継続時間を積算する手順を示す。H28問3 (4)へ直接接続する。

### 5. 同次数成分の位相合成

H24問3 (4)〜(5)に必要な範囲で、同じ次数の正弦波を位相差付きで加えると振幅が変化することを扱う。

```text
sin nθ + sin n(θ-φ)
= 2 cos(nφ/2) sin(nθ-nφ/2)
```

この式から特定次数の低減条件と、基本波振幅への影響を読めるようにする。

### 6. PWM波形への接続

PWM・多段インバータの出力を「周期波形＝基本波＋高調波」として読む数学までを扱う。

- 基本波振幅
- 基本波実効値
- 高調波次数
- 位相合成による特定高調波の低減

キャリア設計、変調方式の比較、スイッチング損失、FFTによるスペクトル計算は本Topicでは扱わない。

# 解説本文

この章を終えた時点で、次をできる状態を目標とする。

- 周期 `2π` の波形を一貫した係数定義でフーリエ級数展開できる。
- 偶関数・奇関数・半波対称から、計算前に消える係数を判断できる。
- 基本波と高調波を次数で区別できる。
- 三相の3n次高調波が線間差で消える理由を説明できる。
- 区分波形の実効値を定義から計算できる。
- 位相差を持つ同次数成分の合成振幅を求められる。
- PWM波形について、与えられた基本波振幅から相実効値・線間実効値へ変換できる。

## 2. 周期関数とフーリエ級数

周期 `2π` の関数 `f(θ)` を、本Topicでは

```text
f(θ)=a0/2 + Σ[n=1..∞]{an cos(nθ)+bn sin(nθ)}
```

と表す。係数は

```text
a0=(1/π)∫[-π,π] f(θ)dθ
an=(1/π)∫[-π,π] f(θ)cos(nθ)dθ
bn=(1/π)∫[-π,π] f(θ)sin(nθ)dθ
```

で定義する。

`a0/2` は直流成分、`n=1` の成分が基本波、`n=2,3,...` が高調波である。基本周波数を `f1` とすれば、`n` 次高調波の周波数は `n f1` となる。

係数規約には別表記もあるため、問題を解く途中で `a0` の係数や積分区間を混在させない。本章では上の定義に統一する。

## 3. 対称性を先に見る

フーリエ係数を毎回すべて積分する必要はない。波形の対称性から、多くの係数を計算前に0と判断できる。

偶関数 `f(-θ)=f(θ)` では、`f(θ)sin(nθ)` が奇関数になるため

```text
bn=0
```

となる。

奇関数 `f(-θ)=-f(θ)` では、直流成分と余弦成分が消えるので

```text
a0=0
an=0
```

となる。

さらに

```text
f(θ+π)=-f(θ)
```

を満たす半波対称があると、偶数次高調波が消える。H28二次問3の相電圧型の方形波はこの性質を使える。

したがって解法では、

```text
周期を確認
→ 偶・奇・半波対称を確認
→ 残る係数だけ積分
```

の順で進めると計算量と符号ミスを減らせる。

## 4. 方形波から奇数次高調波を出す

半周期ごとに `+E/2`, `-E/2` を取る奇関数

```text
f(θ)=+E/2   (0<θ<π)
f(θ)=-E/2   (-π<θ<0)
```

を考える。奇関数なので `a0=an=0` であり、正弦係数だけを求めればよい。

```text
bn
=(1/π)∫[-π,π]f(θ)sin(nθ)dθ
=E/(nπ){1-(-1)^n}
```

よって

```text
nが偶数 → bn=0
nが奇数 → bn=2E/(nπ)
```

となる。基本波は `n=1`、3次・5次・7次…が高調波である。

ここで重要なのは、「方形波だから何となく奇数次」と暗記するのではなく、半波対称で偶数次が消え、実際の係数積分で奇数次が残ることを説明できるようにすることである。

## 5. 三相の3n次高調波が線間差で消える理由

相Rと相Sの同じ `n` 次高調波を、120°の相差を持つ成分として考える。基本波で120°ずれているため、`n` 次成分の位相差は

```text
n × 120°
```

となる。

`n=3m` のとき、位相差は

```text
3m × 120° = m × 360°
```

なので、R相とS相の3n次成分は同相になる。線間電圧は相電圧の差

```text
v_RS=v_RO-v_SO
```

であるため、同相・同振幅の3n次成分は差を取ると0になる。

振幅だけを式で見るなら、相差 `2πn/3` の二つの同振幅正弦波の差の大きさは `2|sin(nπ/3)|` に比例する。`n=3m` では `sin(mπ)=0` となり、同じ結論を得る。

H28二次問3 (3)では、相電圧には3次、9次などを含み得るが、線間電圧ではそれらが打ち消されることを記述できればよい。

## 6. 非正弦周期波形の実効値

正弦波でなくても、実効値の定義は同じである。

```text
X_rms=sqrt{(1/T)∫[0,T]x(t)^2dt}
```

角度 `θ` で1周期を `2π` として扱う場合は

```text
X_rms=sqrt{(1/(2π))∫[0,2π]x(θ)^2dθ}
```

となる。

区分一定波形では、各区間の値を二乗し、その区間長を掛けて足せばよい。例えば、1周期 `2π` のうち絶対値 `E` の区間が合計 `4π/3`、残りが0なら、

```text
X_rms
=sqrt{(1/(2π)) E^2(4π/3)}
=sqrt(2/3)E
```

である。

平均値では符号が打ち消し合うが、実効値では二乗してから平均する。正負が対称だから実効値が0になることはない。

## 7. 同次数成分を位相差付きで合成する

同じ次数 `n`、同じ振幅の二つの成分を

```text
sin(nθ)
sin[n(θ-φ)]
```

とする。和積公式より、

```text
sin(nθ)+sin[n(θ-φ)]
=2cos(nφ/2)sin(nθ-nφ/2)
```

となる。

したがって合成振幅の倍率は符号を含めて

```text
2cos(nφ/2)
```

であり、振幅の大きさは

```text
2|cos(nφ/2)|
```

である。

特定次数を完全に打ち消したいなら

```text
cos(nφ/2)=0
```

となる `φ` を選ぶ。一方、実際の問題では5次と7次のように複数次数を同時に小さくしたい場合があり、一つの次数だけを0にする角度が最適とは限らない。H24一次問3では、選択肢の位相差を各次数へ代入し、5次・7次の低減と基本波への影響を同時に読む。

## 8. PWM基本波の振幅・実効値・線間値

PWM波形そのものは非正弦波でも、フーリエ級数で見れば

```text
周期波形 = 基本波 + 高調波
```

と考えられる。本TopicではPWM制御方式やキャリア設計には進まず、問題文で与えられた基本波振幅を電圧実効値へ変換する数学だけを扱う。

相電圧基本波の最大値が

```text
V_phase,peak = k Ed/2
```

と与えられたなら、正弦波の実効値は最大値の `1/sqrt(2)` なので

```text
V_phase,rms = k Ed/(2sqrt(2))
```

である。

さらに平衡三相の基本波では線間実効値は相実効値の `sqrt(3)` 倍だから、

```text
V_line,rms
=sqrt(3)V_phase,rms
=sqrt(3)Ed k/(2sqrt(2))
```

となる。H22一次問3 (3)はこの変換を要求する。

## 9. 本試験型の解法手順

本Topicでは、問題文を見たら次の順で処理する。

1. 波形の周期と1周期の区間を確定する。
2. 偶関数・奇関数・半波対称を確認し、消える係数を先に決める。
3. 必要な次数だけフーリエ係数を積分する。
4. 基本波か高調波か、必要な次数を特定する。
5. 三相なら相電圧か線間電圧かを確認し、3n次の打消しを判断する。
6. 位相合成なら `2cos(nφ/2)` を使って次数ごとの倍率を求める。
7. 実効値なら波形そのものを二乗平均するか、与えられた正弦波最大値を `sqrt(2)` で割る。
8. 三相平衡の基本波で相値から線間値へ移る場合だけ `sqrt(3)` を掛ける。
9. 次数、最大値／実効値、相値／線間値の取り違えがないか検算する。

## 10. 頻出ミス

### `a0` と `a0/2` を混同する

本章では `f(θ)=a0/2+...` と定義する。別規約の式を途中で混ぜない。

### 対称性を見ずに全係数を積分する

計算自体は可能だが、不要な積分が増えて符号ミスを起こしやすい。まず偶・奇・半波対称を確認する。

### 3次高調波がどこでも消えると思う

相電圧には3n次高調波を含み得る。三相の線間差を取ると同相の3n次成分が消えるのであり、相電圧そのものから消えるわけではない。

### 平均値と実効値を混同する

正負対称波形の平均値は0になり得るが、実効値は二乗平均平方根なので0ではない。

### 位相差 `φ` をそのまま高調波へ使う

`n` 次高調波では位相差は `nφ` になる。合成倍率は `2cos(nφ/2)` である。

### 最大値と実効値を混同する

正弦基本波では `V_rms=V_peak/sqrt(2)`。PWM波形全体の実効値と、基本波だけの実効値も別物である。

### 相電圧と線間電圧を混同する

平衡三相の正弦基本波では線間実効値は相実効値の `sqrt(3)` 倍である。非正弦波全体について無条件に各高調波へ同じ換算を機械適用しない。

## 11. 3段階例題

### 例題1 基礎: 方形波のフーリエ係数

周期 `2π` で

```text
f(θ)=+E/2   (0<θ<π)
f(θ)=-E/2   (-π<θ<0)
```

とする。直流成分、余弦係数、正弦係数を求める。

この波形は奇関数なので、

```text
a0=0
an=0
```

である。

正弦係数は

```text
bn
=(1/π)∫[-π,π]f(θ)sin(nθ)dθ
=(E/π)∫[0,π]sin(nθ)dθ
=E/(nπ){1-(-1)^n}
```

したがって、

```text
n 偶数: bn=0
n 奇数: bn=2E/(nπ)
```

である。よって

```text
f(θ)
=(2E/π){sinθ+(1/3)sin3θ+(1/5)sin5θ+...}
```

となる。

検算として、半波対称なので偶数次が消えており、奇関数なので余弦項もない。

### 例題2 本試験標準: 線間波形の実効値と3n次打消し

ある三相インバータの線間電圧 `v_RS` が、1周期 `2π` のうち合計 `4π/3` の区間で `+Ed` または `-Ed`、残り `2π/3` で0を取るとする。実効値を求める。また、相電圧に含まれる3n次高調波が線間電圧でどうなるか説明する。

実効値は

```text
V_RS,rms
=sqrt{(1/(2π))∫[0,2π]v_RS^2 dθ}
```

である。`v_RS^2=Ed^2` の区間長が合計 `4π/3` なので、

```text
V_RS,rms
=sqrt{(1/(2π))Ed^2(4π/3)}
=sqrt(2/3)Ed
```

となる。

次に3n次成分を考える。相間の基本位相差は120°なので、3n次では位相差が

```text
3n×120°=n×360°
```

となり同相である。線間電圧は相電圧同士の差なので、この同相成分は打ち消される。

この例題では、実効値の積分と三相高調波の位相関係を別々に処理してから結論を合わせる。

### 例題3 複合・ひっかけ: 5次・7次を低減しつつ基本波を確認する

等しい振幅を持つ二つの周期波形を位相差 `φ=π/6` で加える。基本波、5次、7次について、1ユニットの振幅を1としたときの合成振幅倍率を求める。

同次数成分の合成倍率の大きさは

```text
2|cos(nφ/2)|
```

である。

基本波 `n=1`:

```text
2cos(π/12)
≈1.932
```

5次 `n=5`:

```text
2|cos(5π/12)|
≈0.518
```

7次 `n=7`:

```text
2|cos(7π/12)|
≈0.518
```

したがって `φ=π/6` では、5次・7次は完全には0にならないが、両方とも大きく低減される。一方で基本波は2倍より少し小さい `約1.932倍` が残る。

ここで `φ` をそのまま5次・7次へ使わず、必ず `nφ` の位相差になることがひっかけ回避の要点である。

## 14. 公式・解法まとめ

フーリエ級数:

```text
f(θ)=a0/2+Σ[an cos(nθ)+bn sin(nθ)]

a0=(1/π)∫[-π,π]f(θ)dθ
an=(1/π)∫[-π,π]f(θ)cos(nθ)dθ
bn=(1/π)∫[-π,π]f(θ)sin(nθ)dθ
```

対称性:

```text
偶関数 → bn=0
奇関数 → a0=an=0
半波対称 f(θ+π)=-f(θ) → 偶数次高調波=0
```

周期波形の実効値:

```text
X_rms=sqrt{(1/T)∫[0,T]x(t)^2dt}
```

同次数成分の位相合成:

```text
sin(nθ)+sin[n(θ-φ)]
=2cos(nφ/2)sin(nθ-nφ/2)
```

平衡三相の正弦基本波:

```text
V_phase,rms=V_phase,peak/sqrt(2)
V_line,rms=sqrt(3)V_phase,rms
```

本Topicの解法手順:

```text
周期を確定
→ 対称性で消える係数を判定
→ 必要次数の係数だけ計算
→ 基本波／高調波を識別
→ 三相なら3n次と線間差を確認
→ 位相合成なら nφ を使う
→ 実効値・最大値・相値・線間値を区別
→ 検算
```
