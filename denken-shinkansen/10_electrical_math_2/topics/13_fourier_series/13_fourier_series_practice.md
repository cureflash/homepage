# 問題

## 問1 [一次型・基礎]

周期 `2π` の関数 `f(θ)` が奇関数で、さらに

```text
f(θ+π)=-f(θ)
```

を満たす。フーリエ級数

```text
f(θ)=a0/2+Σ[an cos(nθ)+bn sin(nθ)]
```

について正しいものはどれか。

1. `a0=0`, `an=0` であり、偶数次の `bn` も0になる。
2. `a0` だけが残り、すべての高調波は0になる。
3. `bn=0` であり、余弦項だけが残る。
4. 偶数次だけが残り、奇数次はすべて0になる。
5. 対称性だけではどの係数も0と判定できない。

## 問2 [一次型・基礎]

周期 `2π` で

```text
f(θ)=+E/2   (0<θ<π)
f(θ)=-E/2   (-π<θ<0)
```

とする。基本波の正弦係数 `b1` として正しいものはどれか。

1. `E/π`
2. `E/(2π)`
3. `2E/π`
4. `4E/π`
5. `0`

## 問3 [一次型・基礎]

周期 `2π` の波形 `x(θ)` が、1周期のうち合計 `4π/3` の区間で `+E` または `-E`、残りの区間で0を取る。実効値として正しいものはどれか。

1. `E/2`
2. `E/sqrt(2)`
3. `sqrt(1/3) E`
4. `sqrt(2/3) E`
5. `E`

## 問4 [一次型・標準]

平衡三相の各相に同じ振幅の3n次高調波が含まれている。相Rと相Sの基本波位相差は120°である。相電圧と線間電圧の3n次高調波について正しいものはどれか。

1. 相電圧でも線間電圧でも必ず0になる。
2. 相電圧には含まれ得るが、線間電圧では同相成分の差となるため打ち消される。

4. 相電圧にも線間電圧にも必ず同じ振幅で残る。
5. 3n次だけは相間位相差が120°のままなので打ち消されない。

# 解答・完全解説

## 問1 正答 1

奇関数では

```text
a0=0
an=0
```

である。さらに半波対称

```text
f(θ+π)=-f(θ)
```

を持つため偶数次高調波が消え、偶数次の `bn` も0になる。したがって残り得るのは奇数次の正弦項であり、正答は1。

誤答ポイントは、奇関数なら「正弦項がすべて残る」と考えること。半波対称が加わると偶数次はさらに消える。

## 問2 正答 3

この波形は奇関数なので正弦係数だけを求める。

```text
b1
=(1/π)∫[-π,π] f(θ)sinθ dθ
=(E/π)∫[0,π]sinθ dθ
=2E/π
```

よって正答は3。

一般には

```text
bn=E/(nπ){1-(-1)^n}
```

であり、奇数次で `2E/(nπ)`、偶数次で0となる。

## 問3 正答 4

実効値の定義を用いる。

```text
X_rms
=sqrt{(1/(2π))∫[0,2π]x(θ)^2 dθ}
```

`x^2=E^2` の区間長が合計 `4π/3` なので、

```text
X_rms
=sqrt{(1/(2π))E^2(4π/3)}
=sqrt(2/3)E
```

となる。正答は4。

正負の符号は二乗で消える。平均値と実効値を混同しない。

## 問4 正答 2

基本波の相間位相差が120°なら、`n` 次高調波の相間位相差は

```text
n×120°
```

である。`n=3m` では

```text
3m×120°=m×360°
```

となるため、各相の3n次成分は同相になる。相電圧そのものには3n次成分を含み得るが、線間電圧は相電圧の差なので、同相・同振幅の3n次成分は打ち消される。正答は2。

## 問5 正答 5

同じ次数 `n` の二成分を位相差 `φ` で加えると、

```text
sin(nθ)+sin[n(θ-φ)]
=2cos(nφ/2)sin(nθ-nφ/2)
```

である。5次、`φ=π/6` では振幅の大きさは

```text
2|cos(5π/12)|
=2cos(5π/12)
≈0.518
```

となる。正答は5。

`φ` をそのまま使わず、高調波では `nφ` になることが重要である。

## 問6 正答 3

相電圧基本波の最大値は

```text
V_phase,peak=kEd/2
```

である。正弦基本波の実効値は最大値の `1/sqrt(2)` なので、

```text
V_phase,rms=kEd/(2sqrt(2))
```

平衡三相の基本波では線間実効値が相実効値の `sqrt(3)` 倍だから、

```text
V_line,rms
=sqrt(3)kEd/(2sqrt(2))
```

となる。正答は3。

## 問7 正答 2

偶関数なので

```text
bn=0
```

である。まず

```text
a0
=(1/π)∫[-π,π]f(θ)dθ
=(1/π)E·π
=E
```

したがって直流成分は

```text
a0/2=E/2
```

である。次に

```text
a1
=(1/π)∫[-π/2,π/2]E cosθ dθ
=2E/π
```

よって正答は2。

係数 `a0` と実際の直流成分 `a0/2` を取り違えない。

## 問8 正答 4

線間差に現れる同振幅 `A` の `n` 次成分の振幅は、相差 `2πn/3` に対して

```text
2A|sin(nπ/3)|
```

となる。

`n=3` では

```text
2A|sinπ|=0
```

`n=5` では

```text
2A|sin(5π/3)|
=sqrt(3)A
```

である。したがって正答は4。

3n次だけが同相となって線間差で消える一方、5次は消えない。

## 問9 解答

(1) この波形は奇関数なので、

```text
a0=0
an=0
```

である。

(2) 正弦係数は

```text
bn
=(1/π)∫[-π,π]f(θ)sin(nθ)dθ
=(E/π)∫[0,π]sin(nθ)dθ
=E/(nπ){1-(-1)^n}
```

となる。したがって

```text
n 偶数: bn=0
n 奇数: bn=2E/(nπ)
```

である。

(3) 基本波、3次、5次まで書くと、

```text
f(θ)
≈(2E/π){sinθ+(1/3)sin3θ+(1/5)sin5θ}
```

となる。

(4) 半波対称 `f(θ+π)=-f(θ)` を持つ波形では、半周期後に符号が反転する。この対称性により偶数次成分の寄与が相殺されるため、偶数次高調波は0になる。

検算として、奇関数なので余弦項がなく、半波対称なので偶数次もない。固定H28問3 (3)の相電圧型波形へ直接接続する。

## 問10 解答

(1) `v_RO` は問9と同じ半波対称の方形波型である。奇数次の正弦係数が残るため、3次、9次など奇数の3n次高調波を含み得る。

例えば一般係数は

```text
bn=Ed/(nπ){1-(-1)^n}
```

で、奇数 `n` では0ではない。

(2) 相Rと相Sの基本波位相差は120°なので、`n` 次高調波では位相差が `n×120°` となる。`n=3m` なら

```text
3m×120°=m×360°
```

で同相となる。線間電圧

```text
v_RS=v_RO-v_SO
```

では同相・同振幅の3n次成分が差で打ち消される。

(3) `v_RS^2=Ed^2` の区間長が合計 `4π/3` なので、

```text
V_RS,rms
=sqrt{(1/(2π))Ed^2(4π/3)}
=sqrt(2/3)Ed
```

となる。

検算: `sqrt(2/3)<1` なので、0区間を含むこの波形の実効値が `Ed` 未満になることと整合する。固定H28問3 (3)〜(4)へ接続する。

## 問11 解答

(1) 和積公式より、

```text
sin(nθ)+sin[n(θ-φ)]
=2cos(nφ/2)sin(nθ-nφ/2)
```

したがって合成振幅の大きさは

```text
M_n=2|cos(nφ/2)|
```

である。

(2) `φ=π/6` を代入する。

基本波 `n=1`:

```text
M_1=2cos(π/12)
=(sqrt(6)+sqrt(2))/2
≈1.932
```

5次 `n=5`:

```text
M_5=2|cos(5π/12)|
=(sqrt(6)-sqrt(2))/2
≈0.518
```

7次 `n=7`:

```text
M_7=2|cos(7π/12)|
=(sqrt(6)-sqrt(2))/2
≈0.518
```

(3) `M_5` と `M_7` はともに約0.518で、元の2ユニットを同相加算した場合の2より大幅に小さい。ただし0ではないため、完全打消しではない。

(4) 基本波も位相差を持つため、同相加算の2にはならず、

```text
M_1=2cos(π/12)<2
```

となる。固定H24問3 (4)〜(5)の「高調波低減と基本波への影響」を同時に確認する問題である。

## 問12 解答

(1) 相電圧基本波の最大値は

```text
V_phase,peak
=kEd/2
=0.80×600/2
=240 V
```

である。

(2) 正弦基本波の実効値は

```text
V_phase,rms
=240/sqrt(2)
≈169.7 V
```

である。

(3) 平衡三相の基本波について線間実効値は相実効値の `sqrt(3)` 倍だから、

```text
V_line,rms
=sqrt(3)×169.7
≈293.9 V
```

式をまとめれば

```text
V_line,rms
=sqrt(3)kEd/(2sqrt(2))
```

である。

(4) 一意には求められない。ここで与えられているのは基本波の最大値だけであり、PWM波形全体の実効値には高調波成分も寄与する。したがって、基本波実効値 `293.9 V` とPWM波形全体の実効値を同一視してはならない。全波形の区分値・デューティ等が追加で与えられない限り、波形全体の実効値は確定しない。

固定H22問3 (3)の最大値→相実効値→線間実効値の変換へ直接接続する。
