## 2. 共通ベンチマーク

教育用の非線形方程式

```text
f(x) = x^3 - x - 2 = 0
```

を用いる。これは数値解法そのものを検証するための無次元ベンチマークであり、新幹線実車値ではない。

`f(1)=-2`、`f(2)=4` なので、連続性から `[1,2]` に少なくとも1根がある。

## 3. 二分法

初期区間 `[1,2]`、区間半幅の許容誤差 `1e-6` とした。

停止条件:

```text
(b-a)/2 <= 1e-6
```

検証結果:

```text
反復回数 = 20
近似根   = 1.5213804244995117
最終区間半幅 = 9.5367431640625e-7
|f(x)|   = 4.265829404825894e-6
```

残差は停止閾値より大きいが、本ケースは区間半幅を停止条件に採用しているため矛盾しない。符号変化を保った区間内に根が存在し、近似値から根までの距離は最終区間半幅以下である。

## 4. Newton法

同じ `f(x)` に対し、

```text
f'(x) = 3x^2 - 1
x_(n+1) = x_n - f(x_n)/f'(x_n)
```

とし、初期値 `x0=1.5`、残差許容誤差 `1e-10` とした。

| n | x_n | x_(n+1) | `|f(x_(n+1))|` |
|---:|---:|---:|---:|
| 1 | 1.500000000000000 | 1.521739130434783 | 2.136927755405e-3 |
| 2 | 1.521739130434783 | 1.521379805964786 | 5.893874259755e-7 |
| 3 | 1.521379805964786 | 1.521379706804575 | 4.529709940471e-14 |

3反復で停止条件を満たした。

## 5. 初期値依存

複数の根を持つ

```text
g(x) = x^3 - x = 0
```

にNewton法を適用した。

- `x0=0.2` → 3反復で `x=-3.484564795996209e-15`、すなわち根 `0` へ収束
- `x0=0.8` → 5反復で `x=1.0000000000000417`、すなわち根 `1` へ収束

同じ方程式でも初期値により到達する根が変わることを確認した。

また `x=1/sqrt(3)` では `g'(x)=0` となるため、Newton更新式の分母が0となる。導関数が0または極端に小さい点を避ける必要があることも数値的に確認した。
