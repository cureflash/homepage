## Case A 二分法・許容誤差

新規検証問題:

```text
f(x)=cos x-x
初期区間 [0,1]
停止条件 (b-a)/2 <= 1e-6
```

`f(0)=1`、`f(1)=cos 1-1<0` なので符号反転区間である。

検証結果:

```text
反復回数 = 19
近似根 = 0.7390851974487305
最終区間半幅 = 9.5367431640625e-7
残差 = -1.0750207668497325e-7
```

根を挟む区間を維持したまま停止条件を満たし、残差も十分小さい。

判定: `PASS`

## Case B Newton法・初期値依存・導関数ゼロ

新規検証問題:

```text
g(x)=(x-1)(x-2)(x+3)=x^3-7x+6
g'(x)=3x^2-7
停止条件 |g(x)| <= 1e-12
```

異なる初期値からNewton法を適用した。

```text
x0=0.5 -> 5反復で x=1.0, 残差 0
x0=2.5 -> 5反復で x=2.0000000000000906, 残差 4.5297099404706387e-13
```

同じ方程式でも初期値によって異なる根へ収束することを確認した。

また

```text
g'(x)=0
x=±sqrt(7/3)
```

ではNewton更新式の分母が0となり、その点では更新できない。

判定: `PASS`

## Case C 電力式への接続

未確認実車値を使わない教育用1変数条件:

```text
P=K sin δ
K=3.0 p.u.
P=1.7 p.u.
対象範囲 0<δ<π/2
```

完成教材どおり

```text
f(δ)=3 sin δ-1.7
f'(δ)=3 cos δ
```

とし、`δ0=0.4 rad`、残差許容誤差 `1e-12` でNewton法を適用した。

```text
反復回数 = 4
δ = 0.6024546333849905 rad
残差 = 0
```

独立な整合確認として `arcsin(1.7/3)=0.6024546333849905 rad` と一致し、対象範囲内である。

判定: `PASS`
