## 教材で必要な説明

### 1. 非線形方程式を `f(x)=0` にする

電圧・電流・位相角・動作点等について、与えられた関係式を一方へ移項し、求めたい量を未知数とする `f(x)=0` を作る。式を変形しただけで根の意味が変わらないこと、単位と定義域を先に確認することを説明する。

### 2. 二分法

連続な `f(x)` に対し、初期区間 `[a,b]` で `f(a)f(b)<0` を確認し、中点

```text
c = (a+b)/2
```

を求める。`f(c)` の符号で根を含む側だけを残し、区間を半分ずつ狭める手順を示す。

必要説明:
- 初期区間が根を挟む条件
- 1反復ごとに区間幅が1/2になること
- 区間幅または残差を用いた停止判定
- 許容誤差と反復回数の関係
- 符号が変わらない重根等では単純な二分法条件を使えないこと

### 3. Newton法

微分可能な `f(x)` に対して接線近似から

```text
x_(n+1) = x_n - f(x_n)/f'(x_n)
```

と更新する。公式暗記だけにせず、点 `(x_n,f(x_n))` における接線と `x` 軸の交点を次の近似値にすることから導く。

必要説明:
- 初期値 `x0` が必要
- `f'(x_n)` が0または極端に小さい場合の問題
- 初期値によって別の根へ収束したり収束しない場合があること
- 二分法との「収束の確実性／速さ／導関数要否」の違い

### 4. 収束・初期値依存・許容誤差

反復値が出たことだけで終了せず、教材内では少なくとも次を確認する。

```text
|x_(n+1)-x_n| <= tolerance
```

または

```text
|f(x_n)| <= tolerance
```

のような停止条件を明示する。停止条件を満たした近似値を元の式へ代入し、残差が十分小さいことを検算する。

### 5. 電験二種への接続

接続確認した5問は、三角関数を含む送電電力式や平衡点・調相量を解析的に処理する問題であり、二分法・Newton法を公式解答の代替として扱わない。

教材では、同型の非線形関係が解析的に解きにくい場合に `f(x)=0` として反復計算する考え方を説明し、電力潮流や非線形動作点へ概念的に接続する。本格的な多母線Newton-Raphson潮流計算は第一種相当の内容へ踏み込むため、本Topicの固定範囲へ追加しない。

# 解説本文

## 1. このテーマで電験は何を問うか

確認済みの第二種公式過去問では、二分法・Newton法そのものを解法として指定する問題は確認できていない。一方、二次「電力・管理」では、送電電力・受電端電圧・位相角・調相量などが三角関数や積を含む非線形関係で結ばれる問題が出題される。

本Topicでは、こうした関係が解析的に簡単には解けない場合に、未知量を根として

```text
f(x)=0
```

へ整理し、反復計算で近似解を得るための基礎を扱う。確認済み5問の公式解答を二分法・Newton法で置き換えるのではなく、非線形関係を数値的に扱う考え方への接続として学ぶ。

解法の流れは次のとおりである。

```text
求める未知量を決める
↓
関係式を f(x)=0 に整理する
↓
定義域・単位・求める根の範囲を確認する
↓
二分法またはNewton法を選ぶ
↓
停止条件まで反復する
↓
元の式へ代入して残差を確認する
```

## 2. 非線形方程式を `f(x)=0` にする

たとえば未知量 `x` について

```text
A = B sin x
```

という関係があれば、反復計算では

```text
f(x)=B sin x-A
```

として `f(x)=0` の根を求める。式を一方へ移項しても、元の方程式を満たす `x` と `f(x)=0` の根は同じである。

計算前に次を固定する。

```text
1. 未知量は何か
2. 未知量の単位は何か
3. 物理的に許される範囲はどこか
4. どの根を求めるのか
5. どの精度で止めるのか
```

同じ `f(x)=0` に複数の根がある場合、数値計算が返した根が問題で求める動作点とは限らない。したがって定義域や対象範囲の確認は、反復式へ数値を入れる前に行う。

## 3. 二分法は「根を挟む区間を半分にする」

連続な関数 `f(x)` について、区間 `[a,b]` で

```text
f(a)f(b)<0
```

なら、区間内で符号が変わるため、その間に少なくとも1つ根がある。中点

```text
c=(a+b)/2
```

を計算し、`f(c)` の符号を調べる。

- `f(a)f(c)<0` なら次の区間を `[a,c]` とする。
- `f(c)f(b)<0` なら次の区間を `[c,b]` とする。
- `f(c)=0` ならその時点で根が得られる。

1回反復するごとに区間幅は1/2になる。初期区間幅を `L0=b-a` とすれば、`n` 回後の区間幅は

```text
Ln = L0/2^n
```

である。最終区間の中点を近似根とする場合、その根が区間内にあることが分かっていれば中点から根までの距離は区間幅の半分以下である。

二分法の長所は、連続性と符号反転区間が確保できれば根を挟んだまま区間を縮められることである。短所は、Newton法に比べて反復回数が多くなりやすいことである。また、たとえば

```text
f(x)=(x-1)^2
```

の根 `x=1` のように根の両側で符号が変わらない場合、単純な `f(a)f(b)<0` の条件では根を挟めない。

## 4. Newton法は「接線とx軸の交点へ進む」

現在の近似値を `x_n` とする。点 `(x_n,f(x_n))` における接線は

```text
y = f(x_n) + f'(x_n)(x-x_n)
```

である。この接線と `x` 軸の交点では `y=0` だから

```text
0 = f(x_n) + f'(x_n)(x_(n+1)-x_n)
```

となり、整理すると

```text
x_(n+1)=x_n-f(x_n)/f'(x_n)
```

を得る。

計算手順は次のとおりである。

```text
1. f(x)=0 を作る
2. f'(x) を求める
3. 初期値 x0 を決める
4. f(x_n), f'(x_n) を計算する
5. x_(n+1)=x_n-f(x_n)/f'(x_n) で更新する
6. 停止条件を確認する
7. 未達なら4〜6を繰り返す
8. 元の式へ代入し残差を確認する
```

Newton法は良い初期値から出発すれば少ない反復で高精度な近似を得やすい。一方、`f'(x_n)=0` なら分母が0となり更新できない。`f'(x_n)` が非常に小さい場合も更新量が大きくなり、別の根へ飛ぶ、あるいは収束しない場合がある。

## 5. 収束・初期値依存・許容誤差

反復値が計算できたことと、必要な精度へ収束したことは別である。停止条件を先に決める。

代表的には

```text
|x_(n+1)-x_n| <= εx
```

または

```text
|f(x_n)| <= εf
```

を使う。前者は近似値の変化量、後者は元の方程式からのずれである。両者は同じ量ではないので、教材例ではどちらを停止条件にしたか明記する。

停止後は必ず近似値を元の式へ戻し、残差

```text
r=f(x)
```

が十分小さいことを確認する。電力式のように未知量の物理的範囲がある場合は、その範囲内の根かも確認する。

Newton法では初期値依存がある。複数根を持つ関数では、初期値を変えると別の根へ収束することがある。したがって「数値が収束した」だけで正しい動作点と判定せず、対象範囲と根の意味を照合する。

## 6. 二分法とNewton法の使い分け

| 項目 | 二分法 | Newton法 |
|---|---|---|
| 必要条件 | 連続性と符号反転区間 | 微分可能性と初期値 |
| 導関数 | 不要 | 必要 |
| 収束の追跡 | 根を含む区間を保持しやすい | 初期値に依存する |
| 反復の速さ | 区間幅を毎回1/2 | 良い初期値では少反復になりやすい |
| 典型的注意 | 重根等で符号が変わらない | `f'(x)=0` 付近、別根への収束 |

区間を決められ、確実に根を挟んで進みたい場合は二分法が扱いやすい。導関数を求められ、適切な初期値を与えられる場合はNewton法が効率的である。

## 7. 電験二種の送電電力式への接続

送電線を単純化した関係として

```text
P = (Vs Vr / X) sin δ
```

のように、位相角 `δ` が三角関数の中に入る式が現れる。`P, Vs, Vr, X` が与えられ、`δ` を数値的に求めるなら

```text
f(δ) = (Vs Vr / X) sin δ - P
```

と置けば `f(δ)=0` の根を探す問題になる。

接続確認したR5、R4、R1、H30、H23の二次「電力・管理」は、送電電力・電圧・位相差・調相量等を非線形な関係で扱う。ただし、それらの確認済み公式解答は解析的な式変形や図的関係を用いており、本Topicでは二分法・Newton法を公式解答の代替としない。

本格的な多母線電力潮流では複数未知量を同時に反復するが、その多変数Newton-Raphson法、ヤコビ行列の一般理論は本Topicへ追加しない。

## 8. 問題を見たときの解法手順

```text
1. 求める未知量 x を決める
2. 元の関係式を f(x)=0 に整理する
3. 単位・定義域・求める根の範囲を確認する
4. 二分法なら f(a)f(b)<0 を確認する
5. Newton法なら f'(x) と初期値 x0 を確認する
6. 反復計算を行う
7. 指定した許容誤差で停止判定する
8. 元の式へ代入して残差を確認する
9. 得られた根が問題で求める動作点か確認する
```

## 9. 頻出ミス・ひっかけ

- `f(x)=0` へ整理せず、元の式の左右を混在させたまま反復式を作る。
- 二分法で `f(a)f(b)<0` を確認せずに中点計算を始める。
- 二分法の区間幅と中点誤差上限を取り違える。
- Newton法で `f'(x_n)=0` または極小であることを確認しない。
- 角度を度で与えられたまま、計算式の三角関数へラジアンとして代入する。
- 近似値の変化量と残差を同じものとして扱う。
- 複数根があるのに、収束した根が物理的に必要な根か確認しない。
- 接続確認問題が解析解を要求しているのに、反復法を本試験の公式解答として置き換える。

# 3段階例題

## 例題1 基礎: 二分法で `sqrt(2)` を求める

```text
f(x)=x^2-2
```

の正の根を二分法で求める。初期区間を `[1,2]` とする。

```text
f(1)=-1
f(2)=2
```

なので `f(1)f(2)<0` であり、根を挟んでいる。

反復すると

```text
1回目: c=1.5       f(c)= 0.25       -> [1,1.5]
2回目: c=1.25      f(c)=-0.4375     -> [1.25,1.5]
3回目: c=1.375     f(c)=-0.109375   -> [1.375,1.5]
4回目: c=1.4375    f(c)= 0.06640625 -> [1.375,1.4375]
5回目: c=1.40625   f(c)=-0.02246094 -> [1.40625,1.4375]
6回目: c=1.421875  f(c)= 0.02172852 -> [1.40625,1.421875]
```

6回後の区間幅は

```text
1.421875-1.40625 = 0.015625
```

だから、最終区間の中点

```text
x = (1.40625+1.421875)/2 = 1.4140625
```

を近似根とすると、根までの距離は高々

```text
0.015625/2 = 0.0078125
```

である。`sqrt(2)=1.41421356...` とも整合する。

## 例題2 本試験標準: 送電電力式の位相角をNewton法で求める

教育用の単純化した1変数例として、すべてp.u.で

```text
Vs = 1.0
Vr = 1.0
X  = 0.5
P  = 1.0
```

とする。関係式

```text
P = (Vs Vr/X) sin δ
```

から

```text
1 = 2 sin δ
```

である。対象範囲を `0<δ<π/2` とし、

```text
f(δ)=2 sin δ-1
f'(δ)=2 cos δ
```

と置く。

初期値を

```text
δ0=0.500000 rad
```

とし、残差許容誤差を

```text
|f(δ)| <= 1.0×10^-6
```

とする。Newton法では

```text
δ_(n+1)=δ_n-(2 sin δ_n-1)/(2 cos δ_n)
```

だから

```text
δ0 = 0.5000000000
f(δ0) = -4.1148923×10^-2

δ1 = 0.5234444738
f(δ1) = -2.6727043×10^-4

δ2 = 0.5235987687
f(δ2) = -1.1901338×10^-8
```

となる。`δ2` で残差許容誤差を満たすので

```text
δ ≈ 0.52359877 rad
```

で停止する。これは

```text
π/6 = 0.5235987756... rad
```

と一致する。

本試験で解析的に逆三角関数を使って解ける場合は解析解を用いる。この例は、同型の非線形関係を数値的に処理する手順を確認するための教育用例である。

## 例題3 複合・ひっかけ: Newton法の初期値依存と導関数ゼロ

```text
g(x)=x^3-x=x(x-1)(x+1)
```

は

```text
x=-1, 0, 1
```

の3根を持つ。Newton法は

```text
x_(n+1)=x_n-(x_n^3-x_n)/(3x_n^2-1)
```

である。

まず `x0=0.2` とすると

```text
x0 = 0.2
x1 = -0.018181818...
x2 = 0.00001203297...
x3 ≈ 0
```

となり、根 `0` へ収束する。

一方 `x0=0.8` とすると

```text
x0 = 0.8
x1 = 1.113043478...
x2 = 1.015175458...
x3 = 1.000333632...
x4 = 1.000000167...
```

となり、根 `1` へ収束する。同じ関数でも初期値によって到達する根が変わる。

さらに

```text
g'(x)=3x^2-1
```

なので

```text
x = 1/sqrt(3) ≈ 0.577350269
```

では `g'(x)=0` となる。この点を初期値にするとNewton更新式の分母が0になり、そのままでは次の近似値を計算できない。

したがってNewton法では、初期値・対象範囲・導関数・収束先を確認する必要がある。「反復が止まった」「数値が一定になった」だけで正しい根と判断しない。

# 公式・解法まとめ

```text
非線形方程式:
  元の関係式を f(x)=0 に整理する

二分法:
  条件: f(a)f(b)<0
  中点: c=(a+b)/2
  n回後の区間幅: (b-a)/2^n

Newton法:
  x_(n+1)=x_n-f(x_n)/f'(x_n)

停止条件の例:
  |x_(n+1)-x_n| <= εx
  または
  |f(x_n)| <= εf

停止後:
  元の式へ代入し残差と対象範囲を確認する
```

使い分け:
- 二分法は根を挟む区間を確保できると追跡しやすい。
- Newton法は導関数と適切な初期値が必要だが、良い初期値では少ない反復で高精度へ進みやすい。
- 本Topicでは多変数Newton-Raphson潮流計算へ拡張しない。
