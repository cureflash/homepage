## 教材で必要な説明

### 1. 非線形方程式を `f(x)=0` にする

電圧・電流・位相角・動作点等について、与えられた関係式を一方へ移項し、求めたい量を未知数とする `f(x)=0` を作る。式を変形しただけで根の意味が変わらないこと、単位と定義域を先に確認することを説明する。

### 2. 二分法

連続な `f(x)` に対し、初期区間 `[a,b]` で `f(a)f(b)<0` を確認し、中点

```text
c = (a+b)/2
```

を求める。`f(c)` の符号で根を含む側だけを残し、区間を半分ずつ狭める手順を示す。

必要説明:
- 初期区間が根を挟む条件
- 1反復ごとに区間幅が1/2になること
- 区間幅または残差を用いた停止判定
- 許容誤差と反復回数の関係
- 符号が変わらない重根等では単純な二分法条件を使えないこと

### 3. Newton法

微分可能な `f(x)` に対して接線近似から

```text
x_(n+1) = x_n - f(x_n)/f'(x_n)
```

と更新する。公式暗記だけにせず、点 `(x_n,f(x_n))` における接線と `x` 軸の交点を次の近似値にすることから導く。

必要説明:
- 初期値 `x0` が必要
- `f'(x_n)` が0または極端に小さい場合の問題
- 初期値によって別の根へ収束したり収束しない場合があること
- 二分法との「収束の確実性／速さ／導関数要否」の違い

### 4. 収束・初期値依存・許容誤差

反復値が出たことだけで終了せず、教材内では少なくとも次を確認する。

```text
|x_(n+1)-x_n| <= tolerance
```

または

```text
|f(x_n)| <= tolerance
```

のような停止条件を明示する。停止条件を満たした近似値を元の式へ代入し、残差が十分小さいことを検算する。

### 5. 電験二種への接続

接続確認した5問は、三角関数を含む送電電力式や平衡点・調相量を解析的に処理する問題であり、二分法・Newton法を公式解答の代替として扱わない。

教材では、同型の非線形関係が解析的に解きにくい場合に `f(x)=0` として反復計算する考え方を説明し、電力潮流や非線形動作点へ概念的に接続する。本格的な多母線Newton-Raphson潮流計算は第一種相当の内容へ踏み込むため、本Topicの固定範囲へ追加しない。
