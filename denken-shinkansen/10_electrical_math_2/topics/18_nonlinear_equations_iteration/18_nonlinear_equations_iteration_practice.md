# 解答・完全解説

## 問1 正答 4

二分法では、連続な `f(x)` について

```text
f(a)f(b)<0
```

なら区間端で符号が異なるため、その間に少なくとも1つ根がある。よって正答は4。

ただし重根など、根の両側で符号が変わらない場合はこの条件だけでは根を挟めない。

## 問2 正答 2

```text
f(1)=-2
f(1.5)=-0.75
f(2)=1
```

だから符号が変わるのは `1.5` と `2` の間である。次の区間は

```text
[1.5,2]
```

なので正答は2。

## 問3 正答 3

点 `(x_n,f(x_n))` における接線

```text
y=f(x_n)+f'(x_n)(x-x_n)
```

と `x` 軸の交点を次の近似値とすると

```text
x_(n+1)=x_n-f(x_n)/f'(x_n)
```

を得る。正答は3。

## 問4 正答 5

```text
f(x)=x^2-2
f'(x)=2x
```

だから

```text
x1
=1.5-(1.5^2-2)/(2×1.5)
=1.5-0.25/3
=1.416666666...
```

よって正答は5。

## 問5 正答 4

初期区間幅が1なら、`n` 回後の区間幅は

```text
1/2^n
```

である。最終区間の中点を近似根とすると、中点誤差上限は

```text
1/2^(n+1)
```

だから

```text
1/2^(n+1) <= 1.0×10^-3
```

を満たす最小の `n` を求める。

```text
n=8:  1/2^9  = 0.001953125 > 0.001
n=9:  1/2^10 = 0.0009765625 <= 0.001
```

したがって最小反復回数は9回、正答は4。

## 問6 正答 1

`|f(x_n)|` は、現在の近似値を元の方程式 `f(x)=0` に代入したときのずれ、すなわち残差である。正答は1。

残差が小さいことと、真の根との距離がその数値以下であることは一般には同じではない。

## 問7 正答 2

```text
g'(x)=3x^2-1
```

に `x=1/sqrt(3)` を代入すると

```text
g'(1/sqrt(3))=0
```

である。Newton更新式の分母が0になるため、そのままでは更新できない。正答は2。

## 問8 正答 5

```text
Vs Vr/X
=1.0×0.98/0.40
=2.45
```

だから元の式は

```text
1.20=2.45 sin δ
```

であり、左辺へ移項すれば

```text
f(δ)=2.45 sin δ-1.20=0
```

となる。正答は5。

## 問9

### (1)

```text
f(1)=1-1-2=-2
f(2)=8-2-2=4
```

したがって

```text
f(1)f(2)=-8<0
```

で、初期区間 `[1,2]` は根を挟む。

### (2)

1回目:

```text
c1=(1+2)/2=1.5
f(c1)=1.5^3-1.5-2=-0.125
```

`f(1.5)<0`, `f(2)>0` だから次は `[1.5,2]`。

2回目:

```text
c2=(1.5+2)/2=1.75
f(c2)=1.75^3-1.75-2=1.609375
```

次は `[1.5,1.75]`。

3回目:

```text
c3=(1.5+1.75)/2=1.625
f(c3)=1.625^3-1.625-2=0.666015625
```

次は `[1.5,1.625]`。

4回目:

```text
c4=(1.5+1.625)/2=1.5625
f(c4)=1.5625^3-1.5625-2=0.252197265625
```

次は

```text
[1.5,1.5625]
```

である。

### (3)

4回反復後の区間の中点は

```text
x=(1.5+1.5625)/2
 =1.53125
```

区間幅は

```text
1.5625-1.5=0.0625
```

なので、根が区間内にあることを使えば中点誤差上限は

```text
0.0625/2=0.03125
```

である。

## 問12

### (1)

```text
f(x)=x^2-4x+3
f'(x)=2x-4
```

Newton法は

```text
x_(n+1)=x_n-(x_n^2-4x_n+3)/(2x_n-4)
```

である。`x0=0` から

```text
x1=0.75
x2=0.975
x3=0.99969512195...
```

となり、根 `x=1` へ収束する。

### (2)

`x0=4` からは

```text
x1=3.25
x2=3.025
x3=3.00030487805...
```

となり、根 `x=3` へ収束する。

### (3)

`x0=2` では

```text
f'(2)=2×2-4=0
```

なのでNewton更新式の分母が0となる。そのままでは次の近似値を計算できない。

### (4)

同じ方程式でも初期値によって `1` と `3` の異なる根へ進む。このため、複数根を持つ問題では、反復が収束したかだけでなく、問題で求める対象範囲にある根かを確認する必要がある。
