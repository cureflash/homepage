# 解答・完全解説

## 問1 正答 3

Euler法は

```text
y_(n+1)=y_n+h f(t_n,y_n)
```

である。初期点では `f(0,1)=-1` なので、

```text
y(0.20) ≈ 1 + 0.20×(-1)
        = 0.80
```

よって正答は3。`h` を掛けずに傾きをそのまま足さない。

## 問2 正答 4

初期点で

```text
f(0,1)=0+1=1
```

だから、

```text
y(0.10) ≈ 1 + 0.10×1
        = 1.10
```

よって正答は4。Euler法ではこの1刻みについて始点 `(t_0,y_0)` の傾きを使う。

## 問3 正答 2

数値初期値問題は

```text
dy/dt=f(t,y)
y(t0)=y0
```

の組で開始する。微分方程式だけでは、どの解軌道をたどるか決まらない。よって正答は2。

## 問4 正答 3

RL回路式を微分方程式へ直す。

```text
di/dt = (V-Ri)/L
```

初期点では

```text
di/dt = (100-10×0)/2
      = 50 A/s
```

したがって

```text
i(0.10)
= 0 + 0.10×50
= 5.0 A
```

よって正答は3。

## 問5 正答 3

`i=5.0 A` の時点の傾きは

```text
di/dt
= (100-10×5.0)/2
= 25 A/s
```

よって

```text
i(0.20)
= 5.0 + 0.10×25
= 7.5 A
```

正答は3。前の刻みの `50 A/s` をそのまま使い続けない。

## 問6 正答 4

解析解 `0.367879...` との差は

```text
h=0.50: |0.25-0.367879...| = 0.117879...
h=0.25: |0.31640625-0.367879...| = 0.051473...
```

したがって、この計算では `h=0.25` の方が解析解に近い。正答は4。

「刻み幅を小さくすればどんな問題でも必ず単調に改善する」と一般化するのではなく、この問題・この計算結果について比較する。

## 問7 正答 4

Runge-Kutta法は、1刻みの途中を含む複数の傾きを評価して次の値を決める方法として理解する。よって正答は4。

本Topicでは `SPEC.md` の指定どおり概念までとし、高階法の一般理論や各種RK公式の体系的展開へ広げない。

## 問8 正答 2

合力は

```text
F = 100 kN - 40 kN
  = 60 kN
  = 6.0×10^4 N
```

加速度は

```text
a = F/m
  = 6.0×10^4 / 2.0×10^5
  = 0.30 m/s^2
```

Euler法で2秒進めると

```text
v_1 = 10 + 2.0×0.30
    = 10.6 m/s
```

よって正答は2。`kN` を `N` に直してから質量で割る。

## 問10

(1) 微分方程式は

```text
di/dt=(100-10i)/2
```

なので、Euler法の更新式は

```text
i_(n+1)
= i_n + h(100-10i_n)/2
```

である。

(2) `h=0.10 s` では

```text
i_0=0
i_1=5.0
i_2=7.5
i_3=8.75
i_4=9.375 A
```

よって

```text
i(0.40)≈9.375 A
```

(3) 解析解は

```text
i(0.40)
=10(1-e^(-2))
=8.646647167... A
```

したがって絶対誤差は

```text
|9.375-8.646647167...|
=0.728352832... A
```

(4) `h=0.05 s` で8刻み進めると

```text
i(0.40)≈8.998870850 A
```

絶対誤差は

```text
|8.998870850-8.646647168|
=0.352223682 A
```

である。この問題では刻み幅を半分にすると、`t=0.40 s` の誤差は `0.728353 A` から `0.352224 A` へ減少した。

## 問11

力をNへ直すと

```text
Ftraction = 240000 N
Fresistance = 40000 + 4000v N
```

したがって

```text
dv/dt
= {240000-(40000+4000v)}/200000
= 1-0.02v
```

となる。

初期点 `v_0=0` では

```text
a_0=1.00 m/s^2
v_1=0+10×1.00=10.0 m/s
```

次に

```text
a_1=1-0.02×10=0.80 m/s^2
v_2=10.0+10×0.80=18.0 m/s
```

さらに

```text
a_2=1-0.02×18=0.64 m/s^2
v_3=18.0+10×0.64=24.4 m/s
```

よって

```text
v(10)=10.0 m/s
v(20)=18.0 m/s
v(30)=24.4 m/s
```

である。速度が上がると走行抵抗が増え、各刻みの加速度が小さくなることも確認する。このモデルは教育用であり、新幹線実車値ではない。

## 問12

更新式は

```text
v_(n+1)=v_n+h(10-v_n)
```

である。

(1) `h=0.50` では

```text
v_0=0
v_1=0+0.5×10=5.0
v_2=5.0+0.5×5.0=7.5
```

したがって

```text
v(1.0)≈7.5
```

(2) `h=0.25` では

```text
v_0=0
v_1=2.5
v_2=4.375
v_3=5.78125
v_4=6.8359375
```

したがって

```text
v(1.0)≈6.8359375
```

(3) 解析解は

```text
v(1.0)
=10(1-e^(-1))
=6.321205588...
```

絶対誤差は

```text
h=0.50: |7.5-6.321205588...| = 1.178794412...
h=0.25: |6.8359375-6.321205588...| = 0.514731912...
```

である。この問題では `h=0.25` の方が解析解に近い。数値解法は値を出して終わりではなく、刻み幅変更、解析解、定常値などで妥当性を確認する。
