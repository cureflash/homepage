## 1. 目的

第二種公式過去問5問は「常微分方程式＋初期条件」への接続確認用であり、Euler法・Runge-Kutta法を直接要求する固定過去問として扱わない。

## 2. 検証問題

解析解が既知の正規化一次減衰系を使う。

```text
dy/dt = -y
y(0) = 1
```

解析解は

```text
y(t) = e^(-t)
```

したがって

```text
y(1) = e^(-1) = 0.367879441171...
```

これはRC/RL一次過渡を正規化した教育用モデルであり、新幹線実車値ではない。

Euler法は

```text
y_(n+1) = y_n + h(-y_n)
          = (1-h)y_n
```

として計算する。

## 3. 手計算チェック

`h=0.25` とすると、`t=1` まで4刻み。

```text
y0 = 1

y1 = 1 - 0.25×1
   = 0.75

y2 = 0.75 - 0.25×0.75
   = 0.5625

y3 = 0.5625 - 0.25×0.5625
   = 0.421875

y4 = 0.421875 - 0.25×0.421875
   = 0.31640625
```

よって

```text
Euler: y(1) = 0.31640625
解析解: y(1) = 0.367879441171...
絶対誤差 = 0.051473191171...
```

手計算値と検証スクリプトの値は一致した。

## 4. 刻み幅依存

同じ初期値問題を4種類の刻み幅で計算した。

| h | Euler `y(1)` | 絶対誤差 | 相対誤差 |
|---:|---:|---:|---:|
| 0.5 | 0.250000000000 | 0.117879441171 | 32.042954289 % |
| 0.25 | 0.316406250000 | 0.051473191171 | 13.991864021 % |
| 0.125 | 0.343608915806 | 0.024270525366 | 6.597412807 % |
| 0.0625 | 0.356074130452 | 0.011805310720 | 3.209016161 % |

刻み幅を半分にするたびに、この検証問題では `y(1)` が解析解へ近づき、絶対誤差が単調に減少した。
