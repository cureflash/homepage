## 教材で必要な説明

### 1. 初期値問題

数値解法の出発点を

```text
dy/dt = f(t,y)
y(t0) = y0
```

とし、微分方程式だけでなく初期値が必要であることを説明する。RC/RL過渡ではスイッチ切替直前のコンデンサ電圧・コイル電流が初期値になることへ接続する。

### 2. Euler法

刻み幅 `h` を用いて

```text
t_(n+1) = t_n + h
y_(n+1) = y_n + h f(t_n,y_n)
```

と逐次更新する。各刻みの始点の傾きをその区間で一定とみなす近似であることを説明する。

### 3. Runge-Kutta法の概念

Euler法の1点の傾きだけでなく、1刻みの途中を含む複数の傾きを評価して次の値を決める方法として説明する。`SPEC.md` の「概念」を越えて高階法の一般理論へ拡張しない。

### 4. 刻み幅と誤差

同じ初期値問題を複数の刻み幅で計算し、刻み幅を小さくしたときに値がどの程度変わるかを確認する。解析解が得られるRC/RL一次応答では解析解との誤差も比較し、数値が出たことだけを正解判定にしない。

### 5. 電験への接続

接続確認した公式過去問は解析解を要求するため、Euler法・Runge-Kutta法を公式解答の代替として扱わない。教材では、過去問から得られる回路微分方程式と初期条件を数値解法へ入力し、解析解・定常値・時定数と照合する「検算・理解」の役割として使う。

### 6. 新幹線への接続

`SPEC.md` の式

```text
m dv/dt = Ftraction(v) - Fresistance(v)
```

を初期値 `v(0)=v0` とともに数値積分し、速度を時間方向へ求める。位置を求める場合も、未確認の実車性能値を使わず教育用モデルで扱う。実車値を使用する場合は一次資料で確認できた値に限る。

# 解説本文

## 1. このテーマで電験は何を問うか

第二種の確認済み過去問では、Euler法やRunge-Kutta法の算法名そのものを要求する問題は確認できていない。一方、RC・RL過渡では、回路方程式を常微分方程式に直し、初期条件から時間応答を求める力が必要になる。本Topicでは、その微分方程式を解析的に解けない、または実測・モデルの形が複雑で閉形式にしにくい場合に、時間を小刻みに進めて近似解を得る考え方を扱う。

したがって電験への接続は次の順で行う。

```text
回路・運動モデルを立てる
↓
微分方程式 dy/dt=f(t,y) を作る
↓
初期値 y(t0)=y0 を決める
↓
解析解が求まる問題では解析解を本試験解答に使う
↓
数値解法で時間応答を再現し、解析解・定常値・時定数と照合する
```

数値解法を使ったから、元の微分方程式や初期条件を立てなくてよいわけではない。むしろ、式と初期値が正しくなければ数値計算も正しい物理を表さない。

## 2. 初期値問題を数値計算の形へ直す

一階常微分方程式を

```text
dy/dt = f(t,y)
y(t0) = y0
```

と書く。`t` は独立変数、`y` は求める状態量、`f(t,y)` はその時点の変化率である。数値解法では、連続した時間をそのまま扱わず、刻み幅 `h` を決めて

```text
t0, t1=t0+h, t2=t0+2h, ...
```

という離散時刻で近似値を計算する。

電気回路では、たとえばRL回路

```text
L di/dt + Ri = V
```

を

```text
di/dt = (V-Ri)/L
```

と直せば、`y=i`、`f(t,i)=(V-Ri)/L` の初期値問題になる。初期電流 `i(0)` を与えて初めて時間発展を計算できる。RC回路でも同じで、スイッチ切替直前のコンデンサ電圧やコイル電流が初期値を決める手掛かりになる。

## 3. Euler法は「始点の傾きで一歩進む」

時刻 `t_n` で値 `y_n` が分かっているとする。その点の傾きは

```text
f(t_n,y_n)
```

である。短い時間 `h` の間はこの傾きが変わらないと近似すれば、増分は

```text
Δy ≈ h f(t_n,y_n)
```

となる。よってEuler法は

```text
t_(n+1) = t_n + h
y_(n+1) = y_n + h f(t_n,y_n)
```

で逐次更新する。

計算手順は次のとおりである。

```text
1. 微分方程式を dy/dt=f(t,y) の形にする
2. 初期値 (t0,y0) を決める
3. 刻み幅 h を決める
4. 現在点の傾き f(t_n,y_n) を計算する
5. y_(n+1)=y_n+h f(t_n,y_n) で一歩進む
6. 必要な時刻まで4〜5を繰り返す
7. 刻み幅を変える、または解析解・定常値と照合する
```

Euler法で重要なのは、`f` の単位と `h` の単位を掛けると `y` の単位に戻ることである。たとえば `di/dt` がA/s、`h` がsなら、`h(di/dt)` はAになる。

## 4. 刻み幅と誤差

Euler法は各区間で始点の傾きを固定するため、実際には区間内で傾きが変化する系では誤差が生じる。刻み幅 `h` を小さくすれば、一般に1回の近似区間が短くなり、同じ問題では近似値が解析解へ近づくか確認しやすい。

ただし、「小さくすれば必ず十分」という判定はしない。最低限、同じ問題を異なる `h` で計算して結果の変化を見る。解析解が分かる問題なら

```text
絶対誤差 = |数値解 - 解析解|
```

を計算する。定常値が分かる回路なら、長時間後の値がその定常値の方向へ進んでいるかも確認する。

制作前検証の `dy/dt=-y, y(0)=1` では、`t=1` の絶対誤差が

```text
h=0.5    : 0.117879...
h=0.25   : 0.051473...
h=0.125  : 0.024270...
h=0.0625 : 0.011805...
```

と減少した。このように、刻み幅変更は数値結果の妥当性を点検する手段になる。

## 5. Runge-Kutta法の概念

Euler法は1刻みの始点の傾きだけを使う。これに対しRunge-Kutta法は、1刻みの途中を含む複数の位置で傾きを評価し、それらを組み合わせて次の値を決める。区間内で傾きが変化する情報を取り込むため、同じ刻み幅でもEuler法より高い精度を得やすい。

本Topicではこの考え方までを扱う。Runge-Kutta法の次数一般論、各種公式の体系的比較、適応刻み、多段法などへは広げない。試験問題で解析解が要求される場合は、Runge-Kutta法を公式解答の代替にはしない。

## 6. 電験過渡問題への接続

接続確認したR8〜R4の第二種一次「理論」は、RC/RL等の過渡現象を解析的に扱う問題である。本Topicでは、それらに現れる次の要素を数値解法の入力として読む。

- 回路方程式から `dy/dt=f(t,y)` を作る
- コンデンサ電圧・コイル電流等の初期値を確定する
- 定常値と時定数を解析的に確認する
- 同じ初期値問題をEuler法で計算し、時間応答の向きと大きさを検算する

接続確認5問は直接Euler法・Runge-Kutta法を要求しないため、数値解法で解答を置き換えない。過去問対応の目的は「常微分方程式と初期条件を正しく読み取れること」にある。

## 7. 新幹線の運動を初期値問題として読む

`SPEC.md` の簡略モデル

```text
m dv/dt = Ftraction(v) - Fresistance(v)
```

を `dv/dt` について解けば

```text
dv/dt = {Ftraction(v)-Fresistance(v)}/m
```

となる。速度 `v(0)=v0` を与えれば、Euler法では

```text
v_(n+1) = v_n + h {Ftraction(v_n)-Fresistance(v_n)}/m
```

と時間方向へ速度を求められる。

位置も同時に求める場合は

```text
dx/dt = v
```

を加え、同じ刻みの始点値を使うEuler法なら

```text
x_(n+1) = x_n + h v_n
```

と更新する。教材例では教育用の仮定値を明記し、未確認の実車質量・牽引力・走行抵抗を実値として扱わない。

## 8. 問題を見たときの解法手順

数値ODE問題は次の順で処理する。

```text
1. 状態量 y と独立変数 t を決める
2. 微分方程式を dy/dt=f(t,y) に整理する
3. 初期値 y(t0)=y0 を確定する
4. 刻み幅 h と計算終了時刻を確認する
5. 現在点の傾き f(t_n,y_n) を計算する
6. Euler法なら y_(n+1)=y_n+h f(t_n,y_n) で更新する
7. 単位と符号を確認する
8. 刻み幅変更、解析解、定常値のいずれかで検算する
```

特に、微分方程式を立てる前に更新式へ数値を入れ始めない。電気回路ではKCL/KVL、列車運動では運動方程式が先である。

## 9. 頻出ミス・ひっかけ

- 初期値を入れず、微分方程式だけで数値計算を始める。
- `dy/dt` の式を `y` の式と取り違え、`h` を掛け忘れる。
- `h` の単位を秒へそろえず、msやminをそのまま代入する。
- Euler法で1ステップ更新した後、その新しい値を同じステップの別状態量へ無断で使う。どの時点の値で更新するかをそろえる。
- 刻み幅1種類の結果だけを見て正確だと判断する。
- RC/RLの解析問題を、数値解法で解けば十分だと誤解する。本試験が解析解を要求する場合は解析解を使う。
- 教育用列車モデルの係数を実車値として扱う。

# 3段階例題

## 例題1 基礎: Euler法で一次減衰を4ステップ進める

初期値問題

```text
dy/dt = -y
y(0)=1
```

を、刻み幅 `h=0.25` のEuler法で `t=1` まで求める。

Euler法は

```text
y_(n+1)=y_n+0.25(-y_n)=0.75y_n
```

だから

```text
y0 = 1
y1 = 0.75
y2 = 0.5625
y3 = 0.421875
y4 = 0.31640625
```

よって

```text
y(1) ≈ 0.31640625
```

である。解析解は `y=e^(-t)` なので

```text
y(1)=e^(-1)=0.367879441...
```

絶対誤差は

```text
|0.31640625-0.367879441...| = 0.051473191...
```

となる。数値が出ただけで終わらず、解析解との差まで確認する。

## 例題2 本試験標準: RL過渡を数値計算して解析解を検算する

教育用RL回路として

```text
V = 100 V
R = 10 Ω
L = 2 H
i(0)=0 A
```

とする。回路方程式

```text
L di/dt + Ri = V
```

から

```text
di/dt = (100-10i)/2 = 50-5i
```

を得る。

まず `h=0.10 s` のEuler法では

```text
i_(n+1)=i_n+0.10(50-5i_n)=0.5i_n+5
```

だから

```text
t=0.00 s : i=0 A
t=0.10 s : i=5.000 A
t=0.20 s : i=7.500 A
t=0.30 s : i=8.750 A
t=0.40 s : i=9.375 A
```

一方、解析解は時定数 `τ=L/R=0.20 s`、定常電流 `V/R=10 A` より

```text
i(t)=10(1-e^(-t/0.20))
```

であり、`t=0.40 s` では

```text
i(0.40)=10(1-e^(-2))=8.646647... A
```

したがって `h=0.10 s` の絶対誤差は

```text
0.728353 A
```

である。同じ問題を `h=0.05 s` で計算すると `t=0.40 s` で

```text
i ≈ 8.998871 A
```

となり、絶対誤差は

```text
0.352224 A
```

まで減る。本試験では解析解を求めるが、数値解法により「0 Aから10 Aへ近づく」「刻み幅を小さくすると解析解へ近づく」という時間応答を検算できる。

## 例題3 複合・ひっかけ: 速度と位置を同じ刻みで更新する

未確認実車値を使わない教育用列車モデルとして

```text
m = 4.0×10^5 kg
Ftraction(v) = 2.0×10^5 N
Fresistance(v) = 1.0×10^3 v N
v(0)=0 m/s
x(0)=0 m
h=20 s
```

とする。

運動方程式は

```text
4.0×10^5 dv/dt = 2.0×10^5 - 1.0×10^3 v
```

したがって

```text
dv/dt = 0.5 - 0.0025v
```

Euler法で速度を更新し、位置は同じ刻みの始点速度 `v_n` を使って

```text
v_(n+1)=v_n+20(0.5-0.0025v_n)
x_(n+1)=x_n+20v_n
```

とする。

`t=0` では `v0=0`, `x0=0` なので

```text
t=20 s:
v1 = 0 + 20(0.5) = 10.0 m/s
x1 = 0 + 20×0 = 0 m
```

次に

```text
t=40 s:
v2 = 10 + 20(0.5-0.0025×10) = 19.5 m/s
x2 = 0 + 20×10 = 200 m
```

さらに

```text
t=60 s:
v3 = 19.5 + 20(0.5-0.0025×19.5) = 28.525 m/s
x3 = 200 + 20×19.5 = 590 m
```

となる。

ひっかけは、`x_(n+1)` の更新に同じステップで求めた新しい `v_(n+1)` を無断で使わないことである。ここでは「各刻みの始点の値を使うEuler法」として更新時点を統一した。Runge-Kutta法では1刻みの途中の傾きも評価して次の値を決めるため、Euler法とは更新の考え方が異なる。

# 公式・解法まとめ

```text
初期値問題:
dy/dt=f(t,y), y(t0)=y0

Euler法:
t_(n+1)=t_n+h
y_(n+1)=y_n+h f(t_n,y_n)

列車速度:
dv/dt={Ftraction(v)-Fresistance(v)}/m
v_(n+1)=v_n+h{Ftraction(v_n)-Fresistance(v_n)}/m

位置:
dx/dt=v
x_(n+1)=x_n+h v_n
```

Runge-Kutta法は、1刻み内の複数の傾きを評価して次の値を決める方法として理解する。本Topicでは高階法の一般理論へ進まない。
