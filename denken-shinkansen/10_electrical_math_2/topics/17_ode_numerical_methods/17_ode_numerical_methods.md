## 教材で必要な説明

### 1. 初期値問題

数値解法の出発点を

```text
dy/dt = f(t,y)
y(t0) = y0
```

とし、微分方程式だけでなく初期値が必要であることを説明する。RC/RL過渡ではスイッチ切替直前のコンデンサ電圧・コイル電流が初期値になることへ接続する。

### 2. Euler法

刻み幅 `h` を用いて

```text
t_(n+1) = t_n + h
y_(n+1) = y_n + h f(t_n,y_n)
```

と逐次更新する。各刻みの始点の傾きをその区間で一定とみなす近似であることを説明する。

### 3. Runge-Kutta法の概念

Euler法の1点の傾きだけでなく、1刻みの途中を含む複数の傾きを評価して次の値を決める方法として説明する。`SPEC.md` の「概念」を越えて高階法の一般理論へ拡張しない。

### 4. 刻み幅と誤差

同じ初期値問題を複数の刻み幅で計算し、刻み幅を小さくしたときに値がどの程度変わるかを確認する。解析解が得られるRC/RL一次応答では解析解との誤差も比較し、数値が出たことだけを正解判定にしない。

### 5. 電験への接続

接続確認した公式過去問は解析解を要求するため、Euler法・Runge-Kutta法を公式解答の代替として扱わない。教材では、過去問から得られる回路微分方程式と初期条件を数値解法へ入力し、解析解・定常値・時定数と照合する「検算・理解」の役割として使う。

### 6. 新幹線への接続

`SPEC.md` の式

```text
m dv/dt = Ftraction(v) - Fresistance(v)
```

を初期値 `v(0)=v0` とともに数値積分し、速度を時間方向へ求める。位置を求める場合も、未確認の実車性能値を使わず教育用モデルで扱う。実車値を使用する場合は一次資料で確認できた値に限る。

解析解が既知の正規化一次減衰系

```text
dy/dt = -y
y(0) = 1
y(1) = e^(-1) = 0.367879441171...
```

をEuler法で独立計算した。

```text
1 -> 0.75 -> 0.5625 -> 0.421875 -> 0.31640625
```

で、スクリプトと一致した。

`t=1` の絶対誤差は

```text
h=0.5    : 0.117879441171
h=0.25   : 0.051473191171
h=0.125  : 0.024270525366
h=0.0625 : 0.011805310720
```

となり、この検証問題では刻み幅を半分にするごとに誤差が単調減少した。
