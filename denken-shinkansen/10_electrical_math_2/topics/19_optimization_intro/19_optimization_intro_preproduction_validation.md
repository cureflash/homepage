## 2. Case A: 一変数・境界に最適点がある例

教育用関数

```text
f(x) = (x - 3)^2 + 1
0 <= x <= 2
```

を最小化する。

停留条件は `f'(x)=2(x-3)=0` から `x=3` だが、制約 `0<=x<=2` を満たさない。したがって境界を確認する。

```text
f(0) = 10
f(2) = 2
```

よって制約下の最小値は

```text
x = 2
f_min = 2
```

である。停留条件だけで解を確定せず、実行可能性と境界を確認する必要があることを検証した。

## 3. Case B: 二変数等式制約とラグランジュ未定乗数法

教育用の配分問題として

```text
F(x,y) = x^2 + 2y^2 + 4x + 2y
x + y = 12
x >= 0, y >= 0
```

を最小化する。実機の燃料費曲線や設備値ではない。

ラグランジュ関数を

```text
L = F + lambda(x + y - 12)
```

とすると、候補条件は

```text
2x + 4 + lambda = 0
4y + 2 + lambda = 0
x + y = 12
```

である。前2式から

```text
2x + 4 = 4y + 2
```

となり、制約式と連立して

```text
x = 23/3 = 7.666666...
y = 13/3 = 4.333333...
lambda = -58/3
```

を得る。目的関数値は

```text
F = 407/3 = 135.666666...
```

である。

## 4. 独立確認: 一変数への消去

`y=12-x` を代入すると

```text
phi(x) = 3x^2 - 46x + 312
phi'(x) = 6x - 46
```

となる。`phi'(x)=0` から

```text
x = 23/3
y = 13/3
```

となり、ラグランジュ法と一致する。さらに `phi''(x)=6>0` なので最小候補であり、境界値

```text
F(0,12) = 312
F(12,0) = 432
```

より小さい。

また最適点では

```text
partial F/partial x = 58/3
partial F/partial y = 58/3
```

となり、等式制約下の内部最適点で限界量が一致することを確認した。

## 5. Case C: 新幹線への概念接続用の無次元モデル

未確認の実車値を使わず、固定した運行条件の下で操作配分を変えるという考え方だけを確認するため、無次元教育モデル

```text
E(u,v) = u^2 + 3v^2
u + v = 10
```

を置く。これは実車の消費エネルギー式ではない。

ラグランジュ条件から

```text
2u = 6v
u + v = 10
```

なので

```text
u = 7.5
v = 2.5
E = 75
```

となる。比較として `(u,v)=(5,5)` および `(10,0)` では `E=100`、`(0,10)` では `E=300` である。

固定条件を満たす候補の中で配分を変えると目的関数が変化する、という最適化の見方だけを新幹線の省エネ運転へ概念接続する。最適制御理論や実車運転曲線へは進まない。
