## 教材で必要な説明

### 1. 目的関数と制約条件を分離する

最小化・最大化したい量を目的関数、守る必要がある条件を制約条件として明示する。電力需給、水量、出力範囲、所要時間などを目的関数と混同しない。

### 2. 一変数最適化はTopic 04の既知事項として使う

制約条件から変数を1つ消去できる場合は一変数関数へ帰着し、Topic 04で学習済みの微分による極値判定を利用する。一般的な一変数極値論を再講義しない。

### 3. 多変数最適化の概念

複数の操作量へ配分する問題を、目的関数 `f(x,y,...)` と制約式 `g(x,y,...)=0` の組として表現する。まず実行可能な組だけを候補にする考え方を説明する。

### 4. ラグランジュ未定乗数法の入口

等式制約 `g(x,y)=0` の下で目的関数 `f(x,y)` を最適化するとき、

```text
L(x,y,λ) = f(x,y) + λ g(x,y)
```

を置き、

```text
∂L/∂x = 0
∂L/∂y = 0
∂L/∂λ = g(x,y) = 0
```

を同時に満たす候補を求める入口まで扱う。一般的なKKT条件や数値最適化アルゴリズムへは進まない。

### 5. 制約・境界・単位を検算する

停留条件を満たしても制約条件、変数の許容範囲、単位を満たさなければ解として採用しない。境界に最適点がある可能性も確認する。

### 6. 電験と新幹線への接続

確認済み5問では需給・水量・負荷・損失等の条件を読み分ける力が要求される。これらを「目的関数＋制約条件」という見方へ接続するが、公式過去問がラグランジュ法を要求したとは扱わない。

新幹線例は、所要時間を制約として消費エネルギーを抑える加速・惰行・制動パターンを概念的に扱う。未確認の実車値は使用しない。

# 解説本文

## 1. このテーマで電験は何を問うか

確認済みの第二種公式過去問では、最適化やラグランジュ未定乗数法そのものを直接要求する問題は確認できていない。一方、二次「電力・管理」では、需給、水量、発電出力、負荷、損失、経済性など複数の条件を同時に読み分ける問題が出題される。

本Topicでは、そのような工学問題を

```text
何を良くしたいか → 目的関数
守るべき条件は何か → 制約条件
動かせる量は何か → 変数
```

に分けて表す考え方を学ぶ。公式過去問の解法をラグランジュ法へ置き換えるのではなく、複数条件を整理する数学的な見方への接続として扱う。

## 2. 目的関数・変数・制約条件を分ける

最適化では、まず「何を変えられるか」と「何を最小または最大にしたいか」を分離する。

たとえば2つの操作量を `x,y` とし、損失を減らしたいなら、目的関数を

```text
J=f(x,y)
```

と置く。ここで `J` は最小化したい損失、`x,y` は配分できる操作量である。

一方、総量を一定に保つ条件が

```text
x+y=P
```

なら、これは目的関数ではなく制約条件である。さらに

```text
x_min <= x <= x_max
```

のような許容範囲も制約である。

問題文を読んだら、最初に次を分ける。

```text
変数: 自分で配分・選択できる量
目的関数: 最小化または最大化する量
等式制約: 必ず一致させる条件
範囲制約: 上限・下限・非負条件
```

目的関数と制約条件を混同すると、微分する式そのものを誤る。

## 3. 実行可能な点だけが候補になる

制約をすべて満たす変数の組を実行可能な点と考える。たとえば

```text
x+y=10
x>=0, y>=0
```

なら、`(x,y)=(6,4)` は実行可能だが `(8,5)` は総量条件を満たさないので候補にならない。

最適化では、まず実行可能な点へ候補を限定し、その中で目的関数を比較する。目的関数だけ小さくても、制約を破る点は解ではない。

## 4. 1変数へ消去できるならTopic 04へ戻す

等式制約から一方の変数を消せる場合は、複数変数の問題を一変数へ落とせる。

たとえば

```text
x+y=P
```

なら

```text
y=P-x
```

として

```text
J=f(x,P-x)
```

を一変数関数として扱える。ここから先の停留点、増減、端点の判定はTopic 04で学習済みの内容を使う。

重要なのは、変数を消した後も制約から生じる範囲を引き継ぐことである。`x>=0, y>=0` なら `0<=x<=P` を忘れてはならない。

## 5. 多変数最適化とラグランジュ未定乗数法の入口

変数を消去せず、等式制約

```text
g(x,y)=0
```

の下で

```text
f(x,y)
```

を最適化する入口として、ラグランジュ未定乗数法を使う。

```text
L(x,y,λ)=f(x,y)+λg(x,y)
```

と置き、候補点を

```text
∂L/∂x=0
∂L/∂y=0
∂L/∂λ=g(x,y)=0
```

から求める。

`λ` は制約を式の中へ組み込むための未知数である。本Topicでは、この連立条件から候補点を求めるところまでを扱う。KKT条件、一般的な数値最適化、最適制御理論へは進まない。

制約が `x+y=P`、目的関数が `f(x,y)` なら

```text
L=f(x,y)+λ(x+y-P)
```

である。`∂L/∂x=0` と `∂L/∂y=0` から、最適候補では2つの変数を少し動かしたときの目的関数の変化率が、同じ制約の下で釣り合う形になる。

## 6. 解法手順

等式制約を持つ最適化問題では、次の順に整理する。

```text
1. 変数と単位を決める
2. 最小化・最大化する目的関数を書く
3. 等式制約、上下限、非負条件を書く
4. 1変数へ消去できるならTopic 04の方法で解く
5. 多変数のまま扱うなら L=f+λg を作る
6. 偏微分条件と制約式を同時に解く
7. 得られた候補が上下限・非負条件を満たすか確認する
8. 境界候補があれば目的関数を比較する
9. 元の制約へ代入し、総量・単位・物理的妥当性を検算する
```

停留条件を満たすだけでは不十分である。候補点が範囲外なら、許容境界を確認しなければならない。

## 7. 3段階例題

### 例題1 基礎 — 一変数の制約と境界

教育用目的関数

```text
J(x)=(x-4)^2+1
```

を

```text
0<=x<=3
```

の範囲で最小化する。

微分すると

```text
J'(x)=2(x-4)
```

であり、停留点は `x=4` だが制約範囲外である。したがって、この点は採用できない。

範囲内では `x<4` なので `J'(x)<0`、つまり `J` は右へ進むほど減少する。端点を確認すると

```text
J(0)=17
J(3)=2
```

よって

```text
x=3, J_min=2
```

である。

ここでの要点は「微分して出た停留点が制約外なら解ではない」ことである。一変数極値の一般論はTopic 04を使い、本Topicでは制約との組合せだけを確認する。

### 例題2 本試験標準想定 — 2つの出力配分

2つの設備出力を `P1,P2 [MW]` とし、合計12 MWを分担する教育用モデルを考える。目的関数を

```text
C=P1^2+2P2^2
```

とする。係数1,2には、`C` がコスト指標となるために必要な単位を含むものとする。これは実設備の燃料費係数ではない。

制約は

```text
P1+P2=12
P1>=0, P2>=0
```

である。

ラグランジュ関数を

```text
L=P1^2+2P2^2+λ(P1+P2-12)
```

と置く。

偏微分条件は

```text
∂L/∂P1 = 2P1+λ = 0
∂L/∂P2 = 4P2+λ = 0
∂L/∂λ = P1+P2-12 = 0
```

である。上2式から

```text
2P1=4P2
P1=2P2
```

となる。制約へ代入して

```text
2P2+P2=12
P2=4 MW
P1=8 MW
```

を得る。

目的関数は

```text
C=8^2+2*4^2=64+32=96
```

である。

確認のため `P2=12-P1` として一変数化すると

```text
C(P1)=P1^2+2(12-P1)^2
      =3P1^2-48P1+288
```

なので

```text
dC/dP1=6P1-48=0
P1=8 MW
```

となり、同じ解を得る。

### 例題3 複合・ひっかけ — ラグランジュ解が範囲外

同じ教育用目的関数

```text
C=P1^2+2P2^2
```

で合計10 MWを分担する。ただし設備1には

```text
8<=P1<=10 MW
0<=P2<=2 MW
```

という運転範囲があるものとする。

まず上下限を無視して等式制約 `P1+P2=10` だけでラグランジュ条件を解くと

```text
P1=2P2
P1+P2=10
```

より

```text
P1=20/3 ≈ 6.67 MW
P2=10/3 ≈ 3.33 MW
```

となる。しかし、これは `P1>=8 MW` と `P2<=2 MW` を満たさないため不採用である。

制約から `P2=10-P1` と置けば、実行可能範囲は

```text
8<=P1<=10
```

である。目的関数は

```text
C(P1)=P1^2+2(10-P1)^2
      =3P1^2-40P1+200
```

だから

```text
dC/dP1=6P1-40
```

である。停留点 `P1=20/3` は実行可能範囲より左にあり、`8<=P1<=10` では `dC/dP1>0` で単調増加する。したがって最小値は左端

```text
P1=8 MW
P2=2 MW
C=8^2+2*2^2=72
```

で得られる。右端 `P1=10 MW, P2=0 MW` では `C=100` なので、境界比較でも `72<100` を確認できる。

この例のひっかけは「ラグランジュ条件から得た値を、そのまま最終解にしない」ことである。上下限を破る候補は捨て、実行可能な境界を調べる。

## 9. 新幹線への概念的接続

新幹線の運転では、同じ駅間を走る場合でも加速、惰行、制動の配分によって消費エネルギーや所要時間が変わり得る。最適化の見方では、たとえば

```text
目的関数: E(u,v,w) = 消費エネルギーを表すモデル
制約条件: T(u,v,w) = T0
変数: u,v,w = 加速・惰行・制動パターンを表す教育用パラメータ
```

のように整理できる。

ここで重要なのは「所要時間を保つ」という条件と「エネルギーを小さくする」という目的を分離することである。本Topicではこの問題設定までを扱い、実車の運転曲線、制御入力の時間関数、最適制御理論、未確認の車両値へは進まない。

## 10. 頻出ミス・検算

- 目的関数と制約条件を逆にしない。
- `P1+P2=P` のような等式制約をラグランジュ関数へ入れ忘れない。
- 偏微分条件だけでなく `g=0` も同時に解く。
- 停留候補が上下限、非負条件、定義域を満たすか確認する。
- 候補が範囲外なら境界を調べる。
- 一変数へ消去したとき、元の制約から生じる変数範囲を引き継ぐ。
- 出力MW、電力量MWh、費用など、異なる次元の量を同じものとして扱わない。
- 教育用係数や無次元モデルを実設備値と誤認しない。
