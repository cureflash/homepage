## 教材で必要な説明

### 1. 時間領域と周波数領域

同じ信号を、時間に対する波形 `x(t)` と、含まれる周波数成分 `X(f)` の両側から見る意味を説明する。

連続フーリエ変換は概念と対応関係を理解するため、少なくとも次の形を示す。

```text
X(f) = ∫ x(t) exp(-j 2π f t) dt
```

Topic 13のフーリエ級数との違いは、周期信号の離散高調波列から、一般の時間信号の周波数表現へ進む点に限定して整理する。

### 2. サンプリング

連続時間信号を一定周期 `T_s` で標本化するとき、

```text
f_s = 1 / T_s
```

を使えるようにする。

最高周波数 `f_max` を含む信号を扱うための条件として、

```text
f_s > 2 f_max
```

を説明し、`f_s/2` を超える成分が折り返して別の低い周波数に見えるエイリアシングへ接続する。

### 3. DFT

有限長の離散データ `x[n]` を離散周波数成分へ変換する基本式を示す。

```text
X[k] = Σ[n=0..N-1] x[n] exp(-j 2π k n / N)
```

サンプル数 `N`、サンプリング周波数 `f_s` のとき、周波数刻みを

```text
Δf = f_s / N
f_k = k Δf
```

として読めるようにする。

### 4. FFT

FFTは別の変換ではなく、DFTと同じ `X[k]` を効率よく計算するためのアルゴリズムであることを固定する。バタフライ演算や実装方式の詳細は試験必須事項として追加しない。

### 5. PWM波形のスペクトル

計算プログラムで仮定したPWM波形を生成し、DFT/FFTでスペクトル化する。基本波と高調波がどの周波数に現れるかを可視化し、Topic 13で扱った「基本波＋高調波」を周波数軸で読み直す。

実在車両のキャリア周波数等を未確認のまま真値として使わない。

# 解説本文

## 1. このテーマで電験は何を問うか

本Topicは第二種一次「機械」の信号処理・制御周辺へ接続する。固定公式過去問で直接要求されるのはサンプリング定理であり、最高周波数成分 `f_max` とサンプリング周波数 `f_s` の大小関係を判定できることが必須である。

本Topicを終えた時点で、少なくとも次をできるようにする。

1. 時間波形と周波数スペクトルの違いを説明する。
2. `T_s` と `f_s` を相互変換する。
3. `f_s > 2 f_max` を使い、標本化条件を判定する。
4. サンプリング不足で起こるエイリアシングを周波数の折返しとして説明する。
5. DFTの添字 `k` を実周波数 `f_k` へ対応付ける。
6. FFTがDFTそのものではなく、DFTを効率よく計算するアルゴリズムであることを区別する。
7. PWM等の波形をFFTしたスペクトルから基本波・高調波の位置を読む。

## 2. 時間領域と周波数領域

時間領域では信号を `x(t)` として、「いつ、どの大きさを取るか」を見る。周波数領域では同じ信号を `X(f)` として、「どの周波数成分をどれだけ含むか」を見る。

連続時間信号のフーリエ変換を、本Topicでは次の規約で表す。

```text
X(f) = ∫[-∞,∞] x(t) exp(-j 2π f t) dt
```

逆方向は

```text
x(t) = ∫[-∞,∞] X(f) exp(j 2π f t) df
```

である。ここで `f` の単位は `Hz`、`t` の単位は `s` である。

Topic 13のフーリエ級数では、周期信号を基本周波数の整数倍の離散的な高調波列へ分解した。本Topicでは、時間波形をより一般に周波数軸上で見る。周期波形を十分長く観測した場合には基本波・高調波に対応する周波数位置へ成分が現れるため、Topic 13の内容を周波数スペクトルとして読み直せる。

## 3. サンプリング周期とサンプリング周波数

連続信号 `x(t)` を一定時間ごとに取り出した離散データを

```text
x[n] = x(n T_s)
```

とする。`T_s` はサンプリング周期であり、サンプリング周波数は

```text
f_s = 1 / T_s
```

である。

単位換算を含めて扱う。

```text
T_s = 100 μs = 100×10^-6 s
f_s = 1/(100×10^-6) = 10 kHz
```

`T_s` が短いほど、1秒間に取る標本数 `f_s` は大きくなる。

## 4. サンプリング定理とナイキスト周波数

信号に含まれる最高周波数を `f_max` とする。本Topicと固定R3一次「機械」問8 (1)では、エイリアシングを避けて元信号を扱う条件を

```text
f_s > 2 f_max
```

とする。

逆に、ある `f_s` で表現できる周波数の上限は

```text
f_N = f_s / 2
```

であり、ここではナイキスト周波数と呼ぶ。

本試験では、次のどちら向きにも変形できる必要がある。

```text
必要なサンプリング周波数: f_s > 2 f_max
扱える最高周波数:         f_max < f_s / 2
```

固定過去問R3問8 (1)は、この係数 `2` を直接問う。

## 5. エイリアシング

`f_s/2` を超える周波数成分をそのまま標本化すると、その成分は離散データ上で別の低い周波数に見える。この折返しがエイリアシングである。

サンプリング後は、元の連続時間信号がどの周波数だったかを離散データだけから一意に戻せない場合がある。したがって「FFTを使えば不足したサンプリングを後から修復できる」という考え方は誤りである。FFTは与えられた離散データのDFTを効率よく計算するだけであり、標本化時点で失われた情報を復元する機能ではない。

## 6. DFT: 有限個の標本を周波数成分へ変える

`N` 個の標本 `x[0],x[1],...,x[N-1]` に対するDFTを

```text
X[k] = Σ[n=0..N-1] x[n] exp(-j 2π k n / N)
```

とする。

`k=0,1,...,N-1` は周波数ビンの番号である。サンプリング周波数が `f_s` のとき、周波数刻みは

```text
Δf = f_s / N
```

であり、正の周波数側では

```text
f_k = k Δf
```

として読める。

例えば `f_s=12.8 kHz`, `N=1024` なら、

```text
Δf = 12800 / 1024 = 12.5 Hz
```

である。50 Hz成分は `k=4`、250 Hz成分は `k=20` に対応する。

本TopicではDFTの定義式と周波数ビンの読み方を扱う。窓関数設計、スペクトル推定法、フィルタ設計一般へは拡張しない。

## 7. FFT: DFTを速く計算する方法

FFTはFourier Transformとは別の新しい変換ではない。

```text
入力 x[n]
↓
DFTで定義される X[k]
↓
その X[k] を効率よく計算する方法がFFT
```

という関係である。

したがって、同じ有限データへ正しくDFTとFFTを適用した結果は同じ `X[k]` になる。FFTのバタフライ演算や実装方式は、本Topicの試験必須事項として扱わない。

## 8. FFTスペクトルの読み方

実数の時間波形をFFTしたとき、本Topicでは主として `0` から `f_s/2` までの正の周波数側を読む。

手順は次のとおり。

1. `f_s` と `N` を確認する。
2. `Δf=f_s/N` を求める。
3. ピークのビン番号 `k` を確認する。
4. `f_k=kΔf` で周波数へ直す。
5. 基本波周波数と、その整数倍位置に現れる高調波を区別する。
6. `f_s/2` を超える元信号成分が想定される場合は、エイリアシングの可能性を先に疑う。

振幅の正規化方法は計算プログラム側で定義を明記し、グラフと数値が同じ規約を使う。未定義のままFFT出力値を実効値や波高値と同一視しない。

## 9. PWM波形への接続

SPECに従い、後工程の計算プログラムでは教育用に仮定したPWM波形等をFFTし、基本波と高調波を周波数軸上で可視化する。

ここで確認するのは次の数学的対応である。

```text
時間波形
↓ サンプリング
離散データ x[n]
↓ FFT
周波数成分 X[k]
↓ f_k = k f_s/N
基本波・高調波の周波数位置
```

実在新幹線のキャリア周波数・スイッチング方式等は、一次資料で確認しない限り真値として使わない。PWM制御方式の比較やキャリア設計一般も本Topicへ追加しない。

## 10. 本試験型の解法手順

サンプリング・DFT問題では、次の順で処理する。

```text
1. 問題文から f_max, T_s, f_s, N のどれが与えられているか確認する
2. 必要なら f_s=1/T_s へ変換する
3. サンプリング条件は f_s > 2 f_max で判定する
4. DFTの周波数刻みが必要なら Δf=f_s/N を求める
5. ビン番号と実周波数を f_k=kΔf で対応付ける
6. f_s/2 を超える成分があればエイリアシングを疑う
7. FFTを使ったかどうかと、サンプリング条件を満たすかどうかを混同しない
```

## 11. 頻出ミス

- `T_s` と `f_s` を同じ量とみなす。
- `μs` を `s` に直さず `f_s=1/T_s` へ代入する。
- サンプリング条件を `f_s>f_max` として係数2を落とす。
- ナイキスト周波数 `f_s/2` とサンプリング周波数 `f_s` を混同する。
- `Δf=f_s/N` の `N` をビン番号 `k` と混同する。
- FFTならエイリアシングを防げると思い込む。
- FFTをDFTとは別の変換だと解釈する。
- 未定義のFFT振幅を、そのまま実効値・波高値と読む。

# 3段階例題

## 例題1 基礎: サンプリング定理

最高周波数成分が `3.2 kHz` の信号を標本化する。エイリアシングを避けるために必要なサンプリング周波数の条件を求めよ。また `8 kHz` で標本化できるか判定せよ。

### 解法

サンプリング定理を使う。

```text
f_s > 2 f_max
    > 2×3.2 kHz
    > 6.4 kHz
```

したがって必要条件は

```text
f_s > 6.4 kHz
```

である。`8 kHz > 6.4 kHz` なので条件を満たす。

### 検算

`8 kHz` のナイキスト周波数は

```text
8/2 = 4 kHz
```

であり、`3.2 kHz < 4 kHz`。同じ結論になる。

判定: `PASS`。

## 例題2 本試験標準: DFTの周波数刻み

`f_s=12.8 kHz` で `N=1024` 点を標本化した。50 Hz成分と250 Hz成分がDFTのどのビンへ現れるか求めよ。また最高成分が250 Hzなら、サンプリング条件を満たすか確認せよ。

### 解法

まず周波数刻みを求める。

```text
Δf = f_s/N
   = 12800/1024
   = 12.5 Hz
```

したがって

```text
50/12.5  = 4
250/12.5 = 20
```

なので、50 Hz成分は `k=4`、250 Hz成分は `k=20` に対応する。

サンプリング条件は

```text
f_s > 2 f_max
12800 > 2×250 = 500
```

で明らかに満たす。ナイキスト周波数も `6.4 kHz` であり、250 Hzより十分高い。

判定: `PASS`。

## 例題3 複合・ひっかけ: FFTでは直せないエイリアシング

次の連続時間信号を `f_s=8 kHz` で標本化する。

```text
x(t) = cos(2π×1000 t) + 0.5 cos(2π×7000 t)
```

FFTを行ったとき、7 kHz成分を元の7 kHzとして識別できるか説明せよ。

### 解法

ナイキスト周波数は

```text
f_s/2 = 4 kHz
```

である。7 kHzはこれを超えるので、サンプリング条件を満たさない。

標本時刻 `t=n/f_s` で7 kHz成分を見ると、

```text
cos(2π×7000 n/8000)
= cos(2π×7n/8)
= cos(2πn - 2πn/8)
= cos(2π×1000 n/8000)
```

となる。したがって標本列は

```text
x[n]
= cos(2π×1000 n/8000)
  + 0.5 cos(2π×1000 n/8000)
= 1.5 cos(2π×1000 n/8000)
```

となり、7 kHz成分は1 kHzへ折り返して見える。FFTはこの離散データを周波数分解するため、元が1 kHzと7 kHzの二成分だったという情報を復元できない。

### ひっかけ

「FFTを使えば高い周波数まで見える」ではない。まずサンプリング段階で `f_s > 2 f_max` を満たす必要がある。

判定: `PASS`。
