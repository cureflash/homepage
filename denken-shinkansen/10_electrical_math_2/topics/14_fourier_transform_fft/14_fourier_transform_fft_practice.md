# 解答・完全解説

## 問1 正答 4

```text
T_s = 125 μs = 125×10^-6 s
f_s = 1/T_s
    = 1/(125×10^-6)
    = 8000 Hz
    = 8 kHz
```

したがって正答は4。

誤答ポイントは `μs` を秒へ直さず逆数を取ること、または `T_s` と `f_s` を同じ量とみなすことである。

## 問2 正答 2

```text
f_s > 2 f_max
    > 2×2.4
    > 4.8 kHz
```

したがって `4.8 kHz` ちょうどではなく、4.8 kHzを超える必要がある。選択肢では `5.0 kHz` が条件を満たすため正答は2。

固定R3一次「機械」問8 (1)で直接要求される係数 `2` と同じ判定である。

## 問3 正答 5

FFTはDFTと別の物理変換ではなく、DFTで定義される `X[k]` を効率よく求めるアルゴリズムである。同じデータに正しく適用すれば、DFTとFFTが表す周波数成分は同じである。

また、FFTは標本化後のデータを処理するので、標本化時点で生じたエイリアシングを元に戻せない。正答は5。

## 問4 正答 3

ナイキスト周波数は

```text
f_N = f_s/2 = 10/2 = 5 kHz
```

である。本文では

```text
f_max < f_s/2
```

を条件とするため、5.0 kHzちょうどではなく5.0 kHz未満である必要がある。選択肢では4.8 kHzが適切なので正答は3。

## 問5 正答 1

周波数刻みは

```text
Δf = f_s/N
   = 12000/600
   = 20 Hz
```

したがって

```text
k = 340/20 = 17
```

であり、正答は1。

## 問6 正答 4

`f_s=8 kHz` のナイキスト周波数は4 kHzであり、6.5 kHzはこれを超える。標本時刻 `t=n/f_s` では

```text
cos(2π×6500 n/8000)
= cos(2πn - 2π×1500 n/8000)
= cos(2π×1500 n/8000)
```

となるので、1.5 kHzへ折り返して見える。正答は4。

## 問7 正答 2

`k=0` では指数因子がすべて1なので

```text
X[0]=1+1+1+1=4
```

となる。

`k=1,2,3` では4点の複素指数の和が1周期分で相殺されるため0となる。

```text
X[0]=4
X[1]=X[2]=X[3]=0
```

したがって正答は2。

## 問8 正答 5

```text
Δf = f_s/N
   = 6400/1280
   = 5 Hz
```

したがって

```text
50 Hz  -> k=50/5=10
150 Hz -> k=150/5=30
250 Hz -> k=250/5=50
```

となり、正答は5。

ここで扱うのはピークの周波数位置であり、PWM制御方式や実車キャリア周波数を追加していない。

## 問9 解答

### (1) サンプリング周波数

```text
T_s = 50 μs = 50×10^-6 s
f_s = 1/T_s
    = 20000 Hz
    = 20 kHz
```

### (2) サンプリング条件

```text
2 f_max = 2×7.5 = 15 kHz
f_s = 20 kHz > 15 kHz
```

よって条件を満たす。ナイキスト周波数は10 kHzであり、7.5 kHzより大きいことからも確認できる。

### (3) 周波数刻み

```text
Δf = f_s/N
   = 20000/2000
   = 10 Hz
```

### (4) 1.20 kHzのビン番号

```text

```

したがって `k=120`。

## 問10 解答

DFT定義へ直接代入する。

### (1) `X[k]`

`k=0`:

```text
X[0]=1+0-1+0=0
```

`k=1`:

```text
X[1]
=1+0+(-1)exp(-jπ)+0
=1+1
=2
```

`k=2`:

```text
X[2]
=1+0+(-1)exp(-j2π)+0
=1-1
=0
```

`k=3`:

```text
X[3]
=1+0+(-1)exp(-j3π)+0
=1+1
=2
```

よって

```text
X[0]=0, X[1]=2, X[2]=0, X[3]=2
```

である。

### (2) 周波数刻み

```text
Δf = 4000/4 = 1000 Hz
```

### (3) 正の周波数側

0〜`f_s/2=2 kHz` の範囲では、`k=1` が

```text
f_1 = 1×1000 = 1000 Hz
```

に対応する。したがって正の周波数側で読む非零成分は1 kHzである。

## 問11 解答

### (1) ナイキスト周波数

```text
f_N = f_s/2 = 8/2 = 4 kHz
```

### (2) 7 kHz成分の折返し

標本時刻では

```text
cos(2π×7000 n/8000)
= cos(2πn - 2π×1000 n/8000)
= cos(2π×1000 n/8000)
```

となる。したがって7 kHz成分は1 kHzへ折り返す。

### (3) 周波数刻みとビン番号

```text
Δf = 8000/800 = 10 Hz
k = 1000/10 = 100
```

1 kHzの元成分と、7 kHzから折り返した成分は同じ `k=100` へ重なる。

### (4) 復元可否

一意には復元できない。標本化後の二つの成分は同じ1 kHzの離散正弦波として現れるため、FFTはその標本列からDFTを計算できても、「元は1 kHzと7 kHzだった」という失われた情報を復元できない。

## 問12 解答

### (1) 周波数刻み

```text
Δf = 12800/1280 = 10 Hz
```

### (2) ビン番号

```text
50 Hz  -> k=5
250 Hz -> k=25
350 Hz -> k=35
```

### (3) 高調波次数

基本波を50 Hzとすると

```text
250/50 = 5
350/50 = 7
```

なので250 Hzは5次、350 Hzは7次高調波である。

### (4) サンプリング条件

```text
2 f_max = 2×350 = 700 Hz
f_s = 12800 Hz > 700 Hz
```

よって350 Hzまでの成分についてサンプリング条件を満たす。ナイキスト周波数6.4 kHzとの比較でも確認できる。

### (5) 実車値・振幅解釈の境界

このデータは教育用の仮定波形なので、実在新幹線のキャリア周波数やスイッチング方式を断定できない。またFFTの振幅値を実効値・波高値として読むには、計算プログラム側で振幅正規化の定義が必要である。ピーク位置だけから実効値を断定してはならない。
