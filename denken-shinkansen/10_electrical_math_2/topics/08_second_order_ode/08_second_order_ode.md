## 過去問ごとの教材内必要説明

### 1. R8 一次 理論 問1 (4)〜(5)

- 変位に比例し、向きが逆の力 `F=-kx` が復元力であること。
- 運動方程式 `m x''=-kx` を `x''+(k/m)x=0` へ整理すること。
- 特性方程式 `r^2+k/m=0` は複素共役根を持ち、減衰のない振動解になること。
- 固有角周波数 `ω_n=sqrt(k/m)`、周期 `T=2π/ω_n` を導くこと。
- 本問では一様体積電荷密度から得られる復元力係数が `k=ρq/(3ε0)` となるため、`ω_n=sqrt(ρq/(3ε0 m))` へ接続すること。

### 2. R8 一次 理論 問6 (3)〜(4)

- スイッチ切替後の枝電流とコンデンサ電荷の向きを明確にし、`i_L=-dq/dt` と置くこと。
- 回路式 `2R i_L + L di_L/dt - q/C = 0` を立てること。
- 上式を時間微分し `dq/dt=-i_L` を代入すると
  `L d^2i_L/dt^2 + 2R di_L/dt + i_L/C = 0`
  となること。
- 特性方程式 `Lr^2+2Rr+1/C=0` から根の種類を判断できること。
- この回路では `ω_n=1/sqrt(LC)`、`ζ=R sqrt(C/L)` と読めること。

### 3. R3 一次 理論 問5 (1)〜(4)

- 切替前の定常状態からコンデンサ電圧とコイル電流の初期値を決めること。
- コンデンサ電圧とコイル電流は切替瞬間に不連続変化しないこと。
- 電源から切り離された直列RLC回路では
  `L di/dt + Ri + v_C = 0`
  と書けること。
- `i=C dv_C/dt` を使い、電荷または電流を未知量として二階方程式へ整理できること。
- 初期微分値は回路方程式へ `t=0+` の値を代入して求めること。

### 4. H28 一次 理論 問3 (1)〜(5)

- 回路定数から二階方程式を作ること。
- 本問の条件では `q''+6q'+5q=0` となり、特性方程式 `(r+1)(r+5)=0` から異なる二実根 `-1,-5` を得ること。
- 電流を `i=Ae^{-t}+Be^{-5t}` と置き、`i(0)` と `i'(0)` の二つの初期条件から定数を決めること。
- 応答中の符号変化や特定時刻を、得られた指数応答から求めること。
- 異なる実根が過減衰形の応答を作ることを一般化して説明すること。

### 5. H24 一次 理論 問3 (1)〜(2)

- 直列RLC回路でKVLを立て、抵抗電圧・コイル電圧・コンデンサ電圧の符号をそろえること。
- `i=C dv_C/dt` を使い、KVLを時間微分して二階微分方程式へ進む手順を説明すること。
- 本Topicではエネルギー条件へ進まず、二階方程式を作るところまでを固定範囲とすること。

## SPECから固定する必須説明

### 1. 二階線形微分方程式

定数係数形

`a y'' + b y' + c y = f(t)`

を基本形とする。まず同次方程式 `a y''+b y'+cy=0` を時間領域で解く。

### 2. 特性方程式と根

`y=e^{rt}` を代入して

`a r^2 + b r + c = 0`

を得る。

判別式 `D=b^2-4ac` により、

- `D>0`: 異なる二実根
- `D=0`: 重根
- `D<0`: 複素共役根

に分ける。

### 3. 根ごとの同次解

- 異なる実根 `r1,r2`: `y=C1 e^{r1t}+C2 e^{r2t}`
- 重根 `r`: `y=(C1+C2 t)e^{rt}`
- 複素共役根 `-α±jω_d`: `y=e^{-αt}(C1 cos ω_d t+C2 sin ω_d t)`

### 4. 固有角周波数・減衰比

標準形

`y'' + 2ζω_n y' + ω_n^2 y = forcing`

から、

- 固有角周波数 `ω_n`
- 減衰比 `ζ`

を読む。

根の分類は、

- `ζ>1`: 過減衰
- `ζ=1`: 臨界減衰
- `0<ζ<1`: 不足減衰
- `ζ=0`: 無減衰

とする。

不足減衰では `ω_d=ω_n sqrt(1-ζ^2)` を使い、`ω_n` と減衰後の振動角周波数 `ω_d` を混同しない。

### 5. 直列RLC回路

電荷 `q` を未知量にすると、自然応答は

`L q'' + R q' + q/C = 0`

となる。

標準形と比較して、

`ω_n=1/sqrt(LC)`

`ζ=(R/2)sqrt(C/L)`

を得る。

電流 `i=q'` を未知量にした場合も、条件に応じて二階方程式へ整理する。

### 6. 機械系

ばね・質量・粘性減衰系

`m x'' + c x' + kx = F(t)`

を扱う。

`ω_n=sqrt(k/m)`

`ζ=c/(2sqrt(km))`

となり、RLC回路と同じ二階方程式の構造を持つことを示す。

### 7. 二次遅れ

伝達関数を使わず、時間領域の標準形

`y'' + 2ζω_n y' + ω_n^2 y = Kω_n^2 u(t)`

までを扱う。ラプラス変換・伝達関数・極・零点はTopic 09〜10へ送る。

## 頻出ミスとして固定する項目

- 一階方程式と二階方程式を混同しない。
- `i=dq/dt` の符号は電流方向・電荷定義から決める。
- コンデンサ電圧とコイル電流の初期値連続性を逆にしない。
- 特性方程式の根の符号を取り違えない。
- `D=b^2-4ac` と減衰比による分類が同じ根分類を表すことを理解する。
- `ω_n` と `ω_d` を混同しない。
- 直列RLCの減衰比に単一の抵抗値を機械的に入れず、対象方程式の減衰係数から読む。
- 共振角周波数の公式を、条件確認なしに過渡応答の減衰振動角周波数へ流用しない。
- Topic 09のラプラス変換、Topic 10の伝達関数を本Topicの解法前提にしない。

### R8 問1 (4)〜(5)

一様体積電荷中では変位に比例する電界となり、負電荷への力は変位と逆向きになる。

`m x'' = -(ρq/(3ε0))x`

`ω_n=sqrt(ρq/(3ε0 m))`

`T=2π sqrt(3ε0 m/(ρq))`

となる。

照合: (4)ラ、(5)ロ → `2 / 2 PASS`

### R8 問6 (3)〜(4)

電流方向から `i_L=-dq/dt`。

KVLより

`2R i_L + L di_L/dt - q/C = 0`

となる。さらに微分すれば

`L i_L'' + 2R i_L' + i_L/C = 0`

であり、本Topicの二階方程式へ接続できる。

照合: (3)チ、(4)ヨ → `2 / 2 PASS`

### R3 問5 (1)〜(4)
