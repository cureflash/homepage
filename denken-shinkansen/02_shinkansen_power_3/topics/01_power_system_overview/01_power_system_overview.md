## 過去問から確定した教材必須範囲

### 1. 電力系統の一本の流れ
`発電所 → 送電線 → 変電所 → き電回路 → 電車線 → パンタグラフ → 新幹線`

一般系統としては `発電 → 送電 → 変電 → 配電 → 需要家` を先に示し、新幹線を大口需要家の一つとして位置付ける。

### 2. 発電・送電・変電・配電の役割
- 発電: 一次エネルギーを電気エネルギーへ変換する。
- 送電: 発電所と主要変電所の間などで大電力を遠距離輸送する。
- 変電: 電圧を変換し、電力の分岐・開閉・保護を行う。
- 配電: 変電所から需要家へ電力を分配する。
- 新幹線では一般配電ではなく、鉄道用変電所からき電回路を通じて交流25 kVを車両へ供給する流れを地図として示す。

### 3. 電圧・電流・電力の基本関係
Topic 01では公式の意味だけを扱い、詳細な線路計算は後続章へ送る。

- 直流・力率1の単相の入口: `P=VI`
- 単相交流有効電力: `P=VI cosφ`
- 三相交流有効電力: `P=√3 VI cosφ`
- 同じ電力を送る場合、電圧を高くすると必要電流を小さくできる。
- 線路損失が概ね `I^2R` に比例するため、高電圧送電が使われる。

### 4. 三相交流と単相交流の位置付け
- 発電・一般送電では三相交流が基本。
- 新幹線の電車線は単相交流25 kV。
- 「三相を作る側」と「単相で受ける鉄道側」の間に変電・き電設備があることを示す。
- 三相→単相変換の詳細はTopic 07で扱う。

### 5. 変電所の基本機器
Topic 01では名称と役割まで。
- 主変圧器: 電圧を変える。
- 遮断器: 通常電流・事故電流を開閉する。
- 断路器: 無電流状態で回路を確実に切り離す。
- 避雷器: 雷・開閉サージなどの過電圧から設備を保護する。
- 保護継電器: 異常を検出して遮断器へ動作指令を出す。

## 本文作成時の解法アルゴリズム
1. 問題が発電・送電・変電・配電のどの区間を扱っているか判定する。
2. 問われている量が電圧・電流・電力・力率のどれかを確認する。
3. 単相か三相かを判定する。
4. 必要なら `P=VI cosφ` または `P=√3 VI cosφ` を選ぶ。
5. 高電圧化と電流低減、`I^2R` 損失の関係を確認する。
6. 機器問題では、その機器が「変圧・開閉・保護・計測」のどの役割か判定する。

## 典型的なひっかけ
- 送電と配電を同じ意味で扱う。
- 三相と単相で電力式の `√3` を取り違える。
- 高電圧化で電力そのものが自動的に増えると誤解する。
- 変電所を「電圧を変えるだけの施設」と理解する。
- 新幹線の25 kV単相交流を、発電所からそのまま送っていると誤解する。
