## 過去問から確定した教材必須範囲

### 1. 電力系統の一本の流れ
`発電所 → 送電線 → 変電所 → き電回路 → 電車線 → パンタグラフ → 新幹線`

一般系統としては `発電 → 送電 → 変電 → 配電 → 需要家` を先に示し、新幹線を大口需要家の一つとして位置付ける。

### 2. 発電・送電・変電・配電の役割
- 発電: 一次エネルギーを電気エネルギーへ変換する。
- 送電: 発電所と主要変電所の間などで大電力を遠距離輸送する。
- 変電: 電圧を変換し、電圧調整・系統切換え・系統保護を担う。
- 配電: 変電所から需要家へ電力を分配する。
- 新幹線では一般配電ではなく、鉄道用変電所からき電回路を通じて交流25 kVを車両へ供給する流れを地図として示す。

### 3. 電圧・電流・電力の基本関係
Topic 01では基本式の意味と適用までを扱い、電圧降下などの詳細線路計算は後続章へ送る。

- 直流・力率1の単相の入口: `P=VI`
- 単相交流有効電力: `P=VI cosφ`
- 三相交流有効電力: `P=√3 VI cosφ`
- 三相3線式の抵抗損失: `P_loss=3I^2R`
- 同じ電力・力率なら電圧を高くすると必要電流を小さくできる。
- 電流が小さくなると `I^2R` 損失を小さくできる。

### 4. 三相交流と単相交流の位置付け
- 発電・一般送配電では三相交流が基本。
- 平衡三相では三相全体の瞬時電力が一定になる。
- 三相方式は回転磁界を得やすく、発電・送配電・動力利用に適する。
- 新幹線の電車線は単相交流25 kV。
- 「三相を作る側」と「単相で受ける鉄道側」の間に変電・き電設備があることを示す。
- 結線や三相→単相変換の詳細はTopic 06・07へ送る。

### 5. 変電所の基本役割
Topic 01では役割と系統上の位置付けまで。
- 送電効率向上のための昇圧、需要家側で必要な電圧への降圧。
- 変圧器タップ等による電圧調整。
- 開閉装置による系統切換え・潮流調整。
- 短絡・地絡事故時の事故回線切離しによる系統保護。
- 送電用変電所・配電用変電所・周波数変換所・交直変換所など、用途による分類があること。
- 個別機器の構造・定格・保護協調はTopic 06・11へ送る。

## 本文作成時の解法アルゴリズム
1. 問題が発電・送電・変電・配電のどの区間を扱っているか判定する。
2. 問われている量が電圧・電流・電力・力率のどれかを確認する。
3. 単相か三相かを判定する。
4. 必要なら `P=VI cosφ` または `P=√3 VI cosφ` を選ぶ。
5. 三相線路損失では `P_loss=3I^2R` を使う。
6. 高電圧化と電流低減、`I^2R` 損失の関係を確認する。
7. 変電所の問題では「昇降圧・電圧調整・系統切換え・系統保護」のどの役割か判定する。

## 典型的なひっかけ
- 送電と配電を同じ意味で扱う。
- 三相と単相で電力式の `√3` を取り違える。
- 三相線路損失で3線分の `3I^2R` を落とす。
- 高電圧化で電力そのものが自動的に増えると誤解する。
- 変電所を「電圧を変えるだけの施設」と理解する。
- 新幹線の25 kV単相交流を、発電所からそのまま送っていると誤解する。
