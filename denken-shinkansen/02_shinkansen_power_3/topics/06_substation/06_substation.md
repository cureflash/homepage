## 過去問から逆算した教材必須事項

### 1. 変電所の役割と電力の流れ
- 受電、変圧、開閉、計測、保護を一つの流れとして示す。
- `電力系統 → 特別高圧受電 → 新幹線変電所 → き電用変圧器 → 交流25kV` の各段階で何をしているかを区別する。
- 受電電圧とき電電圧を混同しない。

### 2. 変圧器
- 変圧器が交流電圧を変成する原理を説明する。
- 巻数比と電圧比 `V1/V2 = N1/N2`、理想変圧器での電流比の逆関係、容量の考え方を扱う。
- 本テーマでは変圧器の「電圧を変える役割」を主に扱い、三相→単相の結線・相変換はTopic 07へ送る。

- 母線が受電・変圧・き電側の複数回路を接続・分岐する共通導体であることを、変電所の単線結線の読み方と結び付ける。
- 母線固有の保護方式や短絡容量計算へは広げない。

### 4. 遮断器
- 通常の開閉に加え、事故電流を遮断して故障区間を切り離す機器であることを説明する。

- 無負荷状態で回路を機械的に切り離し、点検・修理時の安全な絶縁区間を作る役割を説明する。

## 解説本文

### 1. このテーマで電験は何を問うか
電験三種「電力」の変電所分野では、変電所の機器名を暗記するだけでなく、「何を変える機器か」「何を測る機器か」「何が事故電流を切るのか」「どの機器が保護判断をするのか」を区別できることが重要である。

このテーマでは、次の5系統を判定できるようにする。

1. 変圧器: 交流電圧を変える。
2. 母線: 複数回路を共通導体で接続・分岐する。
3. 遮断器・断路器: 電流遮断と機械的切離しを区別する。
4. VT・CT・保護リレー: 電圧・電流を安全な大きさへ変換して異常を検出する。
5. 避雷器: 雷・開閉サージなどの過電圧から絶縁を保護する。

新幹線への接続では、275kVを「受電側の例」、交流25kVを「き電側」として区別する。275kVから25kVへ至る途中の三相→単相変換方式はTopic 07で扱うため、本テーマでは変圧・開閉・計測・保護に限定する。

### 2. 変電所の仕事を一つの流れで見る
変電所の機能は、受電・変圧・開閉・計測・保護に分けると整理しやすい。

```text
電力系統
  ↓ 受電
受電側母線
  ↓ 開閉・保護
変圧器
  ↓ 変圧
き電側母線
  ↓ 開閉・計測・保護
交流25kV側
```

「変電所＝電圧を下げる場所」だけでは不十分である。変圧器の前後に母線、遮断器、断路器、計器用変成器、保護リレー、避雷器が配置され、通常運転と事故時の双方で電力の通り道を管理する。

受電電圧は電力系統から変電所が受け取る側の電圧、き電電圧は鉄道側へ送り出す側の電圧である。題名の275kVと25kVを同じ場所の電圧だと考えない。

### 3. 変圧器: 巻数比で交流電圧を変える
交流を一次巻線へ加えると、鉄心の磁束が時間変化し、その磁束変化が二次巻線に誘導起電力を生じさせる。同じ磁束を鎖交する理想変圧器では、電圧比は巻数比に等しい。

`V1 / V2 = N1 / N2`

- `V1`: 一次電圧 [V]
- `V2`: 二次電圧 [V]
- `N1`: 一次巻数
- `N2`: 二次巻数

したがって、降圧では `N1 > N2`、昇圧では `N1 < N2` になる。

理想変圧器では損失を無視するので入力と出力の皮相電力が等しいとみなせる。

`V1 I1 ≈ V2 I2`

よって電流比は電圧比と逆になる。

`I1 / I2 = N2 / N1`

この式は理想化した一つの巻線対の関係を理解するために使う。本テーマでは275kV系統から交流25kVき電へ至る「電圧を変える役割」を扱い、実際の三相→単相結線方式は扱わない。

解法手順は、(1) 一次・二次を決める、(2) 電圧比と巻数比を対応させる、(3) 降圧か昇圧かで大小関係を検算する、の順で行う。

### 4. 母線: 複数回路の共通接続点
母線は、変電所内で複数の受電回路、変圧器回路、き電回路などを接続・分岐する共通導体である。単線結線図では、太い一本の線へ複数機器が接続されている形で表されることが多い。

母線そのものが電圧を変えるわけでも、異常を判定するわけでもない。試験では「接続・分岐の共通点」という役割を他機器と混同しないことが重要である。

### 5. 遮断器と断路器を混同しない
遮断器は、通常の負荷電流の開閉に加え、保護リレーから動作指令を受けて事故電流を遮断し、故障区間を系統から切り離す機器である。

断路器は、原則として電流を遮断した後の無負荷状態で回路を機械的に切り離し、点検・修理に必要な絶縁区間を作る。断路器は負荷電流を切るための機器ではない。

停止して切り離すときの基本順序は次である。

`遮断器を開く → 電流が切れたことを前提に断路器を開く`

復旧時は逆に、断路器を閉じて回路を構成してから遮断器を閉じる。誤操作で断路器に負荷電流を遮断させないよう、遮断器と断路器の操作にはインターロックを設ける。

#### 真空遮断器 VCB
真空遮断器は、接点を高真空中に置き、アークを消弧して電流を遮断する。電験三種で押さえる特徴は次である。

- 高真空の高い絶縁耐力を利用する。
- 小形・軽量で、多頻度動作に適する。
- 圧縮空気を吹き付けて消弧する方式ではないため、空気遮断器に比べ動作騒音は小さい。
- 電流裁断などに伴う開閉サージが問題になる場合があり、必要に応じて対策する。

「真空遮断器は騒音が大きい」「断路器でも事故電流を遮断できる」は典型的な誤りである。

### 6. 計器用変成器: VTとCT
高電圧・大電流をそのまま計器や保護リレーへ入れることはできない。計器用変成器は、測定・保護に使える大きさへ電圧・電流を変換し、一次系統と計測回路を分離する。

#### VT: 計器用変圧器
VTは電圧を変成する。一次側を被測定回路へ並列に接続し、二次側を計器・リレーへ接続する。変圧器と同様に電圧比で考える。

VT二次側は短絡してはいけない。低インピーダンスで短絡すると大電流が流れる危険がある。

#### CT: 変流器
CTは大電流を測定・保護用の小電流へ変成する。一次側は被測定線路へ直列に接続する。理想的な電流比は巻数比の逆関係で表せる。

`I1 / I2 = N2 / N1`

CTの二次側は通常、電流計やリレーなどの低インピーダンス負荷につながる。一次通電中に二次回路を開放すると、二次電流が流れなくなって磁束が大きくなり、二次側に危険な高電圧が生じ、鉄心の鉄損・発熱増大を招くおそれがある。このためCT二次は開放禁止である。

試験では次の対比を固定する。
- VT: 一次は並列、二次短絡禁止。
- CT: 一次は直列、二次開放禁止。

### 7. 避雷器: 過電圧を大地へ逃がす
避雷器は、雷サージや開閉サージなどの過電圧から変圧器などの絶縁を保護する。通常電圧ではほとんど電流を流さず、過電圧時には電流を大地へ流して機器端子の電圧上昇を抑える。

現在の代表的な酸化亜鉛形避雷器では、ZnO特性要素の強い非線形電圧電流特性を利用する。通常電圧では高抵抗、過電圧時には低抵抗となるため、サージ電流を放流できる。過電圧が消滅すると再び高抵抗となり、商用周波数の続流を抑制する。そのため直列ギャップを必要としないギャップレス構造が成立する。

覚える語を分離しない。

`ZnO → 非線形抵抗 → 過電圧時に放流 → 過電圧消滅後は高抵抗 → 続流を抑制 → ギャップレス`

### 8. 保護リレー: 異常を判断し、遮断器へ指令する
事故を検出して最終的に電流を切るまでの役割分担は次の通りである。

`CT・VTで検出 → 保護リレーで異常判定 → 遮断器へ開放指令 → 故障区間を切離し`

保護リレー自身が主回路の事故電流を直接遮断するわけではない。遮断するのは遮断器である。

#### 過電流継電器の限時特性
横軸を電流または動作電流倍数、縦軸を動作時間とすると、次を識別する。

- 反限時: 電流が大きいほど動作時間が短くなる。
- 反限時定限時: 小〜中電流域では反限時だが、大電流域では動作時間が一定値へ近づく。
- 定限時: 整定値を超えると、電流の大小にかかわらずほぼ一定の設定時間で動作する。
- 瞬時: 意図的な時間遅れをほとんど設けず、整定値を超えると速やかに動作する。

グラフ問題では、まず「電流増加で時間が下がるか」「大電流域で水平に近づくか」「全体がほぼ水平か」「ほぼゼロ時間か」を順に見る。

### 9. 新幹線変電所へ接続する
本テーマの流れは次のように整理する。

```text
電力系統
↓
275kV級などの特別高圧で受電する場合がある
↓
受電側の母線・開閉機器・計測保護
↓
き電用変圧器で必要な電圧へ変成
↓
き電側の母線・開閉機器・計測保護
↓
交流25kVき電
```

ここで275kVは題名上の受電側例であり、すべての新幹線変電所が275kV受電だと一般化しない。また、275kVの三相系統をどの結線で単相き電へ変換するかはTopic 07で扱う。

このテーマで重要なのは、変電所の各機器を「変圧」「接続」「遮断」「切離し」「計測変成」「過電圧保護」「異常判定」に役割分解して読めることである。

### 10. 問題を見たときの解法手順

#### 機器機能の正誤問題
1. 問題文の動詞を見る。「変圧」「測定」「遮断」「切離し」「保護」「判定」のどれかに分類する。
2. 機器名と機能を対応させる。
3. 遮断器と断路器、VTとCT、リレーと遮断器を重点的に逆チェックする。
4. 「負荷電流を切る」「二次を開放する」など危険な操作が書かれていないか確認する。

#### 変圧器比の計算
1. 一次・二次を決める。
2. `V1/V2 = N1/N2` を置く。
3. 未知量について式を解いてから数値代入する。
4. 降圧なら一次巻数・一次電圧の方が大きいことを確認する。

#### CTの計算・取扱い
1. 一次電流と定格比を確認する。
2. 比例計算で二次電流を求める。
3. 一次直列、二次低インピーダンスを確認する。
4. 「一次通電中の二次開放」は即座に誤りと判定する。

#### 過電流継電器のグラフ
1. 電流増加で動作時間が低下するか確認する。
2. 大電流域で一定時間へ移行するか確認する。
3. 全域で一定なら定限時、ほぼ時間遅れなしなら瞬時と判定する。

### 11. 頻出ミス・ひっかけ
- 受電電圧とき電電圧を同一視する。
- 「変電所＝変圧器だけ」と考え、開閉・計測・保護機器を無視する。
- 断路器を事故電流・負荷電流の遮断器だと考える。
- 保護リレーが主回路電流を直接切ると考える。
- VTとCTの一次接続、二次禁止事項を逆に覚える。
- CT二次を「電流を止めるため開放してよい」と考える。
- ZnO、非線形抵抗、続流、ギャップレスを別々の暗記事項として覚え、因果関係を説明できない。
- 反限時と定限時を「名前」だけで判断し、グラフの傾きを見ない。
- 真空遮断器を空気遮断器と混同し、圧縮空気・大騒音を特徴とする。

## 3段階例題

### 基礎例題: 275kVから25kVへ降圧する巻数比
教材用の理想変圧器で、一次電圧を275kV、二次電圧を25kVとする。二次巻数が1000回のとき、一次巻数を求めよ。

使用式:

`V1 / V2 = N1 / N2`

代入:

`275 / 25 = N1 / 1000`

`11 = N1 / 1000`

したがって、

`N1 = 11000 回`

検算すると、一次電圧は二次電圧の11倍なので、一次巻数も11倍である。これは「電圧を変える役割」だけを確認する教材用計算であり、実際の三相→単相結線方式を表すものではない。

### 標準例題: CTの指示値と禁止操作
定格比1000A / 5AのCTがあり、一次電流が600Aである。理想CTとして二次電流を求め、一次通電中に二次回路を開放してよいか答えよ。

定格比から、一次1000Aのとき二次5Aである。

`I2 = 600 × 5 / 1000 = 3.0 A`

よって二次電流は `3.0 A`。

一次通電中に二次を開放してはいけない。二次電流が流れなくなると磁束が増大し、二次側に危険な高電圧が発生し、鉄損・発熱も増大するおそれがある。

解法の要点は、「比の計算」と「CT二次開放禁止」を別問題として覚えず、CTが大電流を低電流へ変成して計器・リレーへ渡す機器であることから一続きで理解することである。

### 複合・ひっかけ例題: 点検時の操作と事故時の保護
次の記述A〜Dのうち、正しいものをすべて選べ。

A. 負荷電流が流れている回路を点検のため切り離すとき、最初に断路器を開く。
B. CTが過電流を検出した情報を保護リレーが判定し、遮断器へ開放指令を出す。
C. 避雷器は過電圧時にZnO特性要素へ電流を流して機器端子の過電圧を抑える。
D. 真空遮断器は圧縮空気を吹き付けてアークを消弧するため、動作騒音が大きい。

判定:

- A: 誤り。先に遮断器で電流を切り、その後に断路器を開く。
- B: 正しい。検出→判定→遮断の役割分担である。
- C: 正しい。ZnOの非線形特性を利用する。
- D: 誤り。真空遮断器は高真空中で消弧し、圧縮空気方式ではない。

正しいのは `B、C`。

この問題は、断路器と遮断器、CTと保護リレー、避雷器、真空遮断器を同時に識別する。本試験の正誤問題では、機器名ではなく「その動作を誰が行うか」を確認すると誤りを見抜きやすい。

## 公式・解法まとめ
- 変圧器: `V1/V2 = N1/N2`。理想変圧器では電流比は巻数比の逆。
- 母線: 複数回路の共通接続・分岐点。
- 遮断器: 負荷電流・事故電流を遮断する。
- 断路器: 無負荷状態で回路を機械的に切り離す。遮断器→断路器の順で開放する。
- VT: 電圧変成、一次並列、二次短絡禁止。
- CT: 電流変成、一次直列、二次開放禁止。
- 避雷器: ZnO非線形特性で過電圧電流を放流し、絶縁を保護する。
- 保護リレー: CT・VTから入力を受けて異常を判定し、遮断器へ指令する。
- 過電流継電器: 反限時、反限時定限時、定限時、瞬時をグラフ形状で識別する。
- 新幹線接続: 受電側電圧と交流25kVき電側を区別し、三相→単相変換方式はTopic 07へ残す。
