### 1. R8上 電力 問3
教材対応: `03_thermal_power.md` §3「復水器・真空度・タービン効率」。

復水器はタービン排気を凝縮して水へ戻し、内部の真空度を高く保つ。これによりタービン出口圧力が低下し、入口・出口の圧力差を大きくして効率を高める。

したがって、
- (ア) 凝縮
- (イ) 真空度
- (ウ) 圧力差
- (エ) 効率

再解答: `(1)`

公式解答: `(1)`

判定: PASS

### 2. R7下 電力 問15(a)
教材対応: §5「発熱量・発電電力量・発電端熱効率」。

発電電力量:

`45000 MWh = 45000×3.6×10^6 = 1.62×10^11 kJ`

燃料質量:

`9.1×10^3 t = 9.1×10^6 kg`

投入熱量:

`Qin = 9.1×10^6×44000 = 4.004×10^11 kJ`

発電端効率:

`ηg = 1.62×10^11 / 4.004×10^11 = 0.4046 ≒ 40.5 %`

### 4. R6上 電力 問3
教材対応: §8「ガスタービン発電とコンバインドサイクル」。

教材には、コンバインドサイクルは汽力発電より始動・停止が速く、負荷追従性が高く、排熱利用により高効率になりやすいこと、同一出力の汽力発電より復水器側の処理熱量を抑えやすいことがある。一方、ガスタービンは吸入外気の状態に影響され、外気温上昇時は空気密度低下により最大出力が低下する方向となる。

したがって「外気温の最大出力に与える影響が小さい」が誤り。
