## 過去問から逆算した教材必須事項

### §1 このテーマで何を解けるようにするか
- 長い線路ほど、同じ電流でも電圧降下と抵抗損が増えることを式で説明できる。
- 「遠方まで1か所の変電所から送ればよい」とならない理由を、電圧降下・損失・受電端電圧の観点から説明できる。
- 実設備の間隔を未確認の数値で説明しない。

### §2 抵抗・リアクタンス・インピーダンスと距離
- `Z = R + jX` のR・Xが線路の電圧降下にどう寄与するかを区別する。
- 問題文で単位長さ当たり `r [Ω/km]`, `x [Ω/km]` が与えられたとき、`R = rl`, `X = xl` とする。
- R6上問13に必要な範囲で、同一材質なら抵抗が長さに比例し断面積に反比例することを扱う。
- インダクタンス・静電容量そのものの詳細計算へは進まない。

### §3 三相電力・電流・力率
- 平衡三相の有効電力 `P = √3 V I cosφ` を、線間電圧V・線電流Iで用いる。
- `cosφ` から `sinφ = √(1-cos²φ)` を求める。
- 電力、電圧、力率から電流を逆算する。
- 線路損失一定なら、線路抵抗が不変の条件で `P_loss = 3I²R` から電流一定と判断する。

### §4 三相3線式の電圧降下
- 送電端線間電圧 `Vs`、受電端線間電圧 `Vr` とし、相差角が小さい条件で `ΔV = Vs - Vr ≒ √3 I(R cosφ + X sinφ)` を使う。
- 電圧降下率の分母が問題文でどの電圧基準かを必ず確認する。
- 遅れ力率ではR項とX項を加える標準形を扱う。

### §5 電力損失と効率
- 三相3線式の抵抗損を `P_loss = 3I²R` とする。
- 2回線では各回線の電流を先に求め、各回線の損失を合計する。
- 損失率 `P_loss / P_r` と送電効率 `η = P_r / (P_r + P_loss)` を区別する。
- 電流が増えると損失がIの2乗で増えることを、変電所間隔の説明へ接続する。

### §6 複数負荷・分岐線路
- 力率の異なる電流は大きさを単純加算せず、`I cosφ` と `I sinφ` に分解してから合成する。
- 各線路区間には、その区間より下流側にある負荷電流だけが流れる。
- 区間ごとにR・Xと下流電流成分を対応させ、送電端側から受電端側へ順に電圧降下を積み上げる。

### §7 変電所間隔への接続
- 一定の単位長さ当たりR・Xを仮定すれば、距離が長くなるほど総R・Xが増える。
- 同じ受電電力を保つ条件では、線路が長くなるほど電圧降下・損失の制約が厳しくなることを示す。
- 実際の新幹線変電所間隔は一次資料で確認した値だけを使用し、確認前に「数十km」を具体値へ展開しない。

### §8 再利用できる解法手順
1. 単相か三相か、1回線か2回線か、分岐があるかを確認する。
2. `Ω/km` が与えられたら区間長を掛け、各区間のR・Xへ直す。
3. 力率から `sinφ` を求める。
4. 必要なら `P = √3 V I cosφ` から線電流を求める。
5. 複数負荷なら `I cosφ`、`I sinφ` を区間ごとに集計する。
6. 電圧降下なら `√3(RI_P + XI_Q)`、単一負荷なら `√3 I(R cosφ + X sinφ)` を使う。
7. 損失なら `3I²R` を使い、回線数を取り違えない。
8. 電圧降下率・損失率・効率の分母を確認する。
9. V/kV、W/kW/MW、Ω/kmとkmをそろえて計算する。
10. 結果が選択肢と整合するか、電圧降下・損失が負になっていないかを検算する。

### §9 典型ミス
- 線間電圧を使う三相電力式の `√3` を落とす。
- こう長を掛けず `Ω/km` の値をそのままR・Xにする。
- `sinφ` と `cosφ` を逆にする。
- 力率の違う負荷電流をスカラー和する。
- `P_loss = I²R` として3相分の係数3を落とす。
- 2回線で総電力を1回線へ流す。
- 電圧降下率の基準電圧を送電端・受電端で取り違える。
