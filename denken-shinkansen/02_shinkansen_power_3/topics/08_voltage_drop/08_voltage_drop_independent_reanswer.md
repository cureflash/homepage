## ブラインド再解答

### R7下 電力 問16(a)

教材から使用:
- `R=rl`, `X=xl`
- `ΔV ≒ √3 I(R cosφ + X sinφ)`
- `P = √3 V I cosφ`

`R=0.5×5=2.5 Ω`, `X=0.4×5=2.0 Ω`, `cosφ=0.70`, `sinφ=√(1-0.70²)≒0.7141`。

`150 = √3 I(2.5×0.70 + 2.0×0.7141)` より `I≒27.25 A`。

`W1 = √3×6450×27.25×0.70 ≒ 213 kW`。

独立答案: `(4)`。

### R7下 電力 問16(b)

教材から `P_loss=3I²R`。線路条件が同じで損失一定なのでI一定、端子電圧も同じため `P∝cosφ`。

`W2 = 213.09×0.80/0.70 ≒ 243.5 kW`。

独立答案: `(2)`。

### R7下 電力 問17(a)

教材から、力率が異なる負荷は有効分 `I_P=I cosφ` を成分加算する。

S-A区間の有効分は `200×0.8 + 100×0.6 = 220 A`。

独立答案: `(3)`。

### R7下 電力 問17(b)

教材から、各負荷を有効分・無効分へ分け、区間ごとに下流負荷を集計する。

A点負荷: `I_P=160 A`, `I_Q=120 A`。

B点負荷: `I_P=60 A`, `I_Q=80 A`。

各2 kmなので `R=X=0.3×2=0.6 Ω`。

S-A区間:
`ΔV_SA ≒ √3(0.6×220 + 0.6×200) ≒ 436.5 V`。

A-B区間:
`ΔV_AB ≒ √3(0.6×60 + 0.6×80) ≒ 145.5 V`。

`V_B ≒ 6600 - 436.5 - 145.5 = 6018 V`。

独立答案: `(1)`。

### R7上 電力 問13

教材から `P_loss=3I²R`。線路損失一定・R一定なのでI一定。端子電圧一定なら `P=√3VIcosφ` より `P∝cosφ`。

`W2/W1 = 0.91/0.70 = 1.30`。

独立答案: `(2)`。

### R6上 電力 問13

教材から、2回線では総電力を各回線へ分担してから `P=√3VIcosφ` と `P_loss=3I²R` を各回線へ適用する。また `R∝l/A`。

各回線の電流:
`I = (6600×10³/2)/(√3×33×10³×0.9) ≒ 64.15 A`。

許容総損失:
`0.05×6600 kW = 330 kW`。

2回線合計で `330000 = 2×3×I²×R` より `R≒13.365 Ω/線`。

問題文の導体条件から `R = 20000/(35A)` なので、
`A = 20000/(35×13.365) ≒ 42.76 mm²`。

独立答案: `(4)`。

### R5上 電力 問12

教材から `R=rl`, `X=xl`, `ΔV ≒ √3I(R cosφ + X sinφ)`, `P=√3VIcosφ`。

`R=0.45×2=0.90 Ω`, `X=0.25×2=0.50 Ω`, `cosφ=0.85`, `sinφ≒0.5268`。

受電端基準5.0%なので許容電圧降下は `ΔV=6600×0.05=330 V`。

`330 = √3 I(0.90×0.85 + 0.50×0.5268)` より `I≒185.27 A`。

`P = √3×6600×185.27×0.85 ≒ 1800 kW`。

最も近い選択肢は1799 kW。

独立答案: `(2)`。
