### R8上 電力 問2
面積 `6500 km² = 6.5×10^9 m²`、降水量 `1.1 m`、流出係数1より、

`V = 6.5×10^9 × 1.1 = 7.15×10^9 m³`

平均標高 `H=750 m` として理論位置エネルギーは、

`E = ρgVH = 1000×9.8×7.15×10^9×750 ≈ 5.26×10^16 J`

`1 TWh = 3.6×10^15 J` より、

`E ≈ 14.6 TWh`

したがって答案は `(5)`。

### H30 電力 問8
変圧器の定格比から、二次線間電圧が210 Vではなく200 Vのときの一次線間電圧は、

`V1 = 6600×200/210 ≈ 6286 V`

平衡三相有効電力は、

`P = √3 V1 I cosφ`

`= √3×6286×20×0.8 ≈ 174 kW`

したがって答案は `(3)`。

### R7下 電力 問16(a)
線路長5 kmなので1線当たり、

`R = 0.5×5 = 2.5 Ω`

`X = 0.4×5 = 2.0 Ω`

受送電端の電圧差は `6600-6450=150 V`、`cosφ=0.70`、`sinφ≈0.714`。近似電圧降下式

`ΔV ≒ √3 I(R cosφ + X sinφ)`

より、

`I ≈ 150 / {√3(2.5×0.70 + 2.0×0.714)} ≈ 27.25 A`

したがって負荷電力は、

`P = √3×6450×27.25×0.70 ≈ 213 kW`

答案は `(4)`。

### R7下 電力 問16(b)
線路損失 `P_loss=3I²R` が(a)と同じで、線路抵抗も同じなので、線電流 `I` は(a)と同じである。力率0.8なので `sinφ=0.6`。送り出し電圧6600 Vは同じため、新しい電圧降下と受電端電圧は、

`ΔV₂ ≒ √3×27.25×(2.5×0.8 + 2.0×0.6) ≈ 151 V`

`V₂ ≈ 6600-151 = 6449 V`

したがって、

`P₂ = √3×6449×27.25×0.8 ≈ 243.5 kW`

選択肢では243 kWの `(2)`。

### R7下 電力 問12
電源側と変圧器の%インピーダンスは同一基準容量なので、

`%Z_total = 1.1 + 10.6 = 11.7 %`

二次側基準電流は、

`I_n = 20×10^6 /(√3×6600) ≈ 1.75 kA`

三相短絡電流は、

`I_sc = 1.75×100/11.7 ≈ 14.95 kA`

計算短絡電流以上の遮断電流が必要なので、候補中の最小適合値20 kA、答案は `(3)`。

### R7上 法規 問13(a)
太陽光発電出力は6時0 kW、12時600 kW、18時0 kWの直線変化。負荷との交点から余剰電力区間を分ける。

- 7〜10時: `(0+300)/2×3 = 450 kWh`
- 10〜12時: `(100+300)/2×2 = 400 kWh`
- 12〜15時: `(300+0)/2×3 = 450 kWh`

余剰送電電力量は、

`450+400+450 = 1300 kWh`

したがって答案は `(2)`。

### R7上 法規 問13(b)
太陽光発電量は三角形の面積から、

`W_gen = 12×600/2 = 3600 kWh`

(a)の送電量1300 kWhを差し引くと自家消費は、

`W_self = 3600-1300 = 2300 kWh`

全負荷電力量は、

`100×10 + 300×7 + 400×4 + 100×3 = 5000 kWh`

よって自給率は、

`2300/5000×100 = 46 %`

答案は `(3)`。
