## §2 発電所からN700Sまでの電力フロー
通常の供給方向は次のように整理する。

```text
水力・火力・原子力・再エネ
↓
発電機
↓
変圧器
↓
送電線
↓
新幹線変電所
↓
三相→単相
↓
交流25kV
↓
き電回路
↓
架線
↓
パンタグラフ
↓
N700S
```

発電方式が違っても、発電機以降は「電圧を変える」「電力を送る」「負荷へ供給する」という共通の系統として扱える。N700Sはこの電力フローの到達点であり、本章では車両内部主回路へは入らない。

回生時は列車側が発生側になるため、電力の向きが逆になる。重要なのは設備名ではなく、各地点で発生電力・負荷電力・損失の収支を追うことである。

## §3 発電方式の違いを「入力エネルギー」で整理する
発電方式は入口のエネルギーが異なるが、最終的には電気エネルギーとして同じ系統へ接続される。

- 水力: 水の位置エネルギーを水車・発電機で電気へ変換する。
- 火力: 燃料の化学エネルギーを熱、機械エネルギーを経て電気へ変換する。
- 原子力: 核分裂で得た熱を蒸気・タービン・発電機へつなぐ。
- 再エネ: 太陽光、風力、地熱などで入口のエネルギーは異なるが、発電後は電力系統へ接続される。

水力で流量 `Q [m³/s]`、有効落差 `H [m]`、総合効率 `η` を使うとき、発電出力の基本は

`P = ρgQHη`

である。貯水量など体積 `V [m³]` から位置エネルギーを求める場合は、理論値として

`E = ρgVH`

を使い、実際に取り出せる電力量を問う条件で効率が与えられればその条件を反映する。

## §4 電力と電力量を混同しない
電力 `P [W, kW, MW]` はエネルギー移動の速さ、電力量 `W [Wh, kWh, MWh]` はその時間積分である。

一定電力なら、

`W = Pt`

時間変化するなら、

`W = ∫P(t)dt`

となる。グラフ問題では、横軸が時間、縦軸が電力なら面積が電力量である。

JとWhの換算は

`1 Wh = 3600 J`

を使う。`kW` と `kWh`、`MW` と `MWh` を同じ量として扱わない。

## §5 変圧器から三相電力へつなぐ
理想変圧器では巻数比と電圧比を

`V1 / V2 = N1 / N2`

で扱う。問題文で二次電圧から一次実電圧を逆算する場合も、この比をそのまま使う。

平衡三相回路の有効電力は、線間電圧 `V_L [V]`、線電流 `I_L [A]`、力率 `cosφ` を用いて

`P = √3 V_L I_L cosφ`

である。線間電圧と相電圧を取り違えず、力率を掛け忘れない。電流を求めるなら

`I_L = P / (√3 V_L cosφ)`

へ変形する。

## §6 送配電では電流が電圧降下と損失を決める
三相3線式の線路で、1線当たりの抵抗を `R [Ω]`、リアクタンスを `X [Ω]`、遅れ力率を `cosφ` とすると、近似電圧降下は

`ΔV ≒ √3 I(R cosφ + X sinφ)`

である。

抵抗による三相線路損失は

`P_loss = 3I²R`

となる。したがって、同じ有効電力を送るなら電流が増えるほど電圧降下も損失も大きくなり、特に損失は電流の二乗に比例する。

この種の問題は、まず `P=√3VIcosφ` から電流を求め、次に電圧降下、最後に線路損失を求めると整理しやすい。

## §7 変電・相変換・き電・電線・配電を流れの中へ置く
電力会社側の三相交流は、新幹線変電所で必要な電圧へ変圧され、既習の相変換を経て単相のき電回路へ接続される。その後、架線を通ってパンタグラフから列車へ供給される。

架線や送配電線は電気を運ぶ電線であり、抵抗があるため損失と電圧降下が生じる。駅・トンネル等の設備は列車走行用とは別の配電負荷として系統から電力を受ける。本章では、これらを総合フロー内へ配置するだけとし、個別設備の新規詳細は追加しない。

## §8 短絡電流を求めて遮断へつなぐ
短絡時は通常負荷時より大きな電流が流れる。電源側と変圧器の%インピーダンスが同一基準容量で与えられている場合は、直列部分を加えて合成%インピーダンスを求める。

`%Z_total = %Z1 + %Z2 + ...`

基準となる三相定格電流は

`I_n = S / (√3 V)`

で求める。合成%インピーダンスが `%Z_total` なら、短絡電流の大きさは

`I_sc = I_n × 100 / %Z_total`

として求められる。遮断器は、計算された短絡電流を安全に遮断できる定格遮断電流を選ぶ。

%インピーダンスの基準容量が異なる場合に、そのまま足してはいけない。本章の固定問題・例題では、同一基準容量であることを確認してから加算する。

## §9 回生時は電力の向きを反転して同じ収支で考える
通常時は発電所・系統側から列車へ電力が流れるが、回生時には列車が発生側になる。

発生電力を `Pg`、同時刻の負荷電力を `PL` とすると、

- `Pg > PL`: 差 `Pg-PL` は余剰で、受入可能なら外部系統側へ送る。
- `Pg < PL`: 差 `PL-Pg` は不足で、外部系統側から受ける。
- `Pg = PL`: 正味の送受電は0。

時間変化する場合は差の面積を積算する。

`Wsend = ∫max(Pg-PL, 0)dt`

`Wreceive = ∫max(PL-Pg, 0)dt`

発電電力量から外部へ送った電力量を差し引けば、自家消費電力量を

`Wself = Wgen - Wsend`

で求められる。回生も特別な別計算ではなく、「発生側と負荷側の電力収支」として同じ考え方で処理する。

## §10 本試験での総合解法アルゴリズム
1. どこが発生側、どこが負荷側かを決める。
2. 発電量を問うなら、入力エネルギーと効率から発電電力・電力量を求める。
3. 変圧器があれば、巻数比・電圧比で必要な電圧をそろえる。
4. 三相側では `P=√3VIcosφ` から電流または電力を求める。
5. 送配電線では `R`、`X`、力率から電圧降下を求め、`3I²R` で損失を求める。
6. 短絡時は%インピーダンスを同一基準で合成し、短絡電流と必要遮断定格を求める。
7. 発電・負荷が時間変化する場合は、交点で区間を分け、差の面積から送受電電力量を求める。
8. 回生時は発生側を列車に置き換えて同じ収支を取る。
9. 最後に `W/kW/kWh`、`V/kV`、`A/kA` の単位と桁を検算する。

## §11 頻出ミス・ひっかけ
- 発電電力 `kW` と発電電力量 `kWh` を混同する。
- JからWhへ換算するときに3600で割る方向を逆にする。
- 変圧器の電圧比を逆に使う。
- 三相電力で `√3` または力率を落とす。
- 線間電圧と相電圧を混同する。
- 電圧降下式の `R cosφ + X sinφ` の符号・項を取り違える。
- 線路損失を `I²R` のままにし、三相分の3を落とす。
- %インピーダンスを基準容量確認なしで加算する。
- 計算した短絡電流より小さい遮断定格を選ぶ。
- 発生電力が負荷より大きい区間と小さい区間を逆に読む。
- 回生電力が常に全量外部へ流れると断定する。

## §12 3段階例題

### 基礎例題 — 水力発電の出力と電力量
学習用仮定値として、流量 `Q=20 m³/s`、有効落差 `H=50 m`、総合効率 `η=0.90` の水力発電を考える。`ρ=1000 kg/m³`、`g=9.8 m/s²` とし、10分間この条件が一定だったときの発電出力と発電電力量を求める。

使用式は

`P = ρgQHη`

である。

`P = 1000×9.8×20×50×0.90 = 8.82×10^6 W = 8.82 MW`

10分は `1/6 h` なので、

`W = 8.82×1/6 = 1.47 MWh`

となる。出力と電力量を区別し、時間をhへ直してから掛ける。

### 本試験標準例題 — 三相電力から電圧降下と線路損失まで
学習用仮定値として、受電端線間電圧 `V=6.6 kV`、有効電力 `P=3.0 MW`、遅れ力率 `cosφ=0.80` の平衡三相負荷を考える。送電線1線当たりの `R=0.40 Ω`、`X=0.30 Ω` とする。線電流、近似電圧降下、三相線路損失を求める。

まず三相有効電力から線電流を求める。

`I = P/(√3 V cosφ)`

`I = 3.0×10^6 /(√3×6600×0.80) ≈ 328 A`

`cosφ=0.80` なので `sinφ=0.60`。したがって、

`ΔV ≒ √3×328×(0.40×0.80 + 0.30×0.60)`

`ΔV ≈ 284 V`

三相線路損失は、

`P_loss = 3×328²×0.40 ≈ 1.29×10^5 W = 129 kW`

となる。受電端6.6 kVを維持する近似では、送電端線間電圧は `6.6 kV + 0.284 kV ≈ 6.88 kV` と見積もれる。

### 複合・ひっかけ例題 — %インピーダンスと遮断器
学習用仮定値として、三相 `10 MVA`、`6.6 kV` を基準とし、電源側 `%Z=4.0%`、変圧器 `%Z=8.5%` が同一基準容量で与えられている。短絡点から見て両者が直列であるとする。三相短絡電流を求め、定格遮断電流の候補が `5 kA、8 kA、10 kA、12.5 kA、20 kA` のとき、最小の適切な候補を選ぶ。

同一基準容量なので、

`%Z_total = 4.0 + 8.5 = 12.5%`

基準電流は、

`I_n = 10×10^6 /(√3×6600) ≈ 875 A`

したがって、

`I_sc = 875×100/12.5 ≈ 7000 A = 7.00 kA`

である。遮断定格は短絡電流以上が必要なので、候補中の最小値は `8 kA` となる。

ひっかけは、%インピーダンスの基準容量を確認せず加算することと、短絡電流より小さい遮断定格を選ぶことである。

## §13 新幹線への接続
この章では、発電所で生まれた電力を変圧・送電し、新幹線変電所で相変換して交流25kVのき電回路へ送り、架線・パンタグラフを経てN700Sへ届くところまでを一つの系統として見る。

通常時は系統側から列車へ、回生時は列車側から架線・系統側へ向きが変わる。しかし、電験として行うことは同じで、各区間の電圧・電流・電力・損失と、時間積分した電力量の収支を追う。

本sourceではN700Sの列車電力、実変電所間隔、実き電回路定数、実回生電力量等を新たに数値化しない。一次資料未確認の実設備値を真値として扱わない。
