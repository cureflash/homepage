# 解答・完全解説

## 問1
正答: 3

位置エネルギーは、

`E=ρgVH`

`=1000×9.8×1.0×10^6×50`

`=4.90×10^11 J`

である。`1 MWh=3.6×10^9 J` なので、

`4.90×10^11 / 3.6×10^9 ≈136 MWh`

となる。JからWhへ換算するときは3600で割る。正答は3。

検算として、`136 MWh×3.6×10^9 J/MWh≈4.90×10^11 J` と元へ戻る。

## 問2
正答: 3

理想変圧器では、

`V1/V2=N1/N2`

なので、

`V1=220×6000/200=6600 V=6.60 kV`

となる。巻数比を逆にしない。正答は3。

## 問3
正答: 2

通常時は、発電機で作られた電力を変圧し、送電線で送り、新幹線変電所で必要な変圧・相変換を行ってき電回路へ接続し、架線・パンタグラフを経て車両へ供給する。したがって2が正しい。

1、3、4、5は、変圧・送電・変電所・架線・パンタグラフの順序を入れ替えている。回生時は列車側が発生側となり、同じ系統を逆方向へ電力が流れ得る。

## 問4
正答: 3

平衡三相有効電力は、

`P=√3VIcosφ`

である。

`P=√3×6600×120×0.85≈1.166×10^6 W`

よって約 `1.17 MW`。正答は3。

三相電力では `√3` と力率を落とさない。

## 問5
正答: 3

`cosφ=0.80`、`sinφ=0.60` より、近似電圧降下は、

`ΔV≒√3×150×(0.30×0.80+0.20×0.60)`

`=√3×150×0.36≈93.5 V`

三相線路損失は、

`P_loss=3I²R=3×150²×0.30=20250 W≈20.3 kW`

となる。正答は3。

電圧降下では `R cosφ+X sinφ`、線路損失では三相分の3を確認する。

## 問6
正答: 2

まず線路損失から電流を逆算する。

`P_loss=3I²R`

`I=√(30000/(3×0.50))≈141 A`

次に三相有効電力は、

`P=√3×6600×141.4×0.80≈1.29 MW`

近似電圧降下は、

`ΔV≒√3×141.4×(0.50×0.80+0.40×0.60)`

`≈157 V`

となる。正答は2。

線路損失が固定され、抵抗も同じなら `3I²R` から電流が決まる。その電流と力率を用いて負荷電力・電圧降下へつなぐ。

## 問7
正答: 4

同一基準容量なので、直列の%インピーダンスを加える。

`%Z_total=3.5+6.5=10.0%`

基準三相電流は、

`I_n=20×10^6/(√3×6600)≈1.75 kA`

したがって三相短絡電流は、

`I_sc=1.75×100/10.0≈17.5 kA`

である。遮断器は短絡電流以上を安全に遮断できる定格が必要なので、候補の最小値は `20 kA`。正答は4。

`16 kA` は計算した短絡電流を下回るため選べない。

## 問8
正答: 3

各区間は0.5時間なので、

- 第1区間: 不足 `400-200=200 kW` → 受電 `100 kWh`
- 第2区間: 余剰 `500-300=200 kW` → 送電 `100 kWh`
- 第3区間: 余剰 `700-500=200 kW` → 送電 `100 kWh`
- 第4区間: 不足 `600-300=300 kW` → 受電 `150 kWh`

よって、

`Wsend=200 kWh`

`Wreceive=250 kWh`

となる。正答は3。

## 問9
正答: 2

問8の条件から、総発生電力量は、

`Wgen=(200+500+700+300)×0.5=850 kWh`

総負荷電力量は、

`Wload=(400+300+500+600)×0.5=900 kWh`

自家消費電力量は、

`Wself=Wgen-Wsend=850-200=650 kWh`

したがって、

`自家消費比率=650/850×100≈76.5%`

`自給率=650/900×100≈72.2%`

となる。正答は2。

検算すると、正味受電 `250-200=50 kWh` は `900-850=50 kWh` と一致する。

## 問10
正答: 3

水力・火力・原子力・再エネは入口のエネルギー変換が異なるが、発電後は電力として変圧・送電等の下流系統へ接続して扱える。したがって3が正しい。

1は一次エネルギーが同じとする点が誤り。2は原子力発電の熱・蒸気・タービンを介する流れを否定している。4は再エネを一律に蒸気タービン方式としており誤り。5は下流の電圧・電流・電力の共通的な扱いを否定しており誤り。

## 問11
正答: 2

まず理想変圧器の電圧比から、

`V1=330×20=6600 V=6.6 kV`

三相有効電力は、

`P=√3×6600×180×0.80≈1.65 MW`

近似電圧降下は、

`ΔV≒√3×180×(0.20×0.80+0.15×0.60)`

`=√3×180×0.25≈78 V`

三相線路損失は、

`P_loss=3×180²×0.20=19440 W≈19.4 kW`

となる。正答は2。

変圧 → 三相有効電力 → 電圧降下 → 線路損失の順に処理すると、総合問題でも式の選択を崩しにくい。

## 問12
正答: 1

第1区間では、

`Pg-PL=900-600=300 kW`

なので、0.5時間の送電電力量は、

`300×0.5=150 kWh`

第2区間では、

`PL-Pg=1000-200=800 kW`

なので、受電電力量は、

`800×0.5=400 kWh`

総発生電力量は、

`Wgen=(900+200)×0.5=550 kWh`

総負荷電力量は、

`Wload=(600+1000)×0.5=800 kWh`

自家消費電力量は、

`Wself=550-150=400 kWh`

したがって自給率は、

`400/800×100=50.0%`

となる。正答は1。

回生を含む場合も、列車側を発生側に含めて `Pg` と `PL` の大小を比較すれば、通常の発電・負荷と同じ収支で扱える。
