# 解説本文

## §1 このテーマで電験は何を問うか
このテーマは電験三種「電力」の配電・地中電線路を扱う。本試験で問われる中心は、単相三線式の電流と電圧降下、配電変圧器の一次・二次関係、三相三線式の電圧降下と導体断面積、地中ケーブルの布設方式、放熱と許容電流の関係である。

暗記だけで済ませるのではなく、回路の電流方向を決めてから `IR` 降下を追うこと、三相三線式では成立条件を確認して `√3` を付けること、地中線では施工方式と熱の逃げ方を結び付けることが必要である。本章を終えると、固定5問・6答案要素の要求事項を教材内の説明だけで再現できる状態を目標とする。

## §2 駅・トンネルへ届く配電の流れ
列車走行用の交流25 kVき電とは別に、駅、トンネル、車両基地、信号、照明、ポンプ、空調、防災設備にも電力を配る必要がある。本章では個別設備の制御方式には入らず、これらを配電先の負荷として見る。

学習用の一般モデルは次のように整理できる。

```text
高圧配電
↓
配電変圧器
↓
低圧配電
↓
駅・トンネル・車両基地等の負荷
```

高圧で運び、負荷の近くで配電変圧器により低圧へ変換して使うという流れを押さえる。ここでは新幹線設備の実電圧、実ケーブルサイズ、実許容電流を未確認のまま真値として使わない。

## §3 高圧配電・低圧配電と配電変圧器
配電では、同じ電力を送るなら電圧を高くするほど電流を小さくできるため、線路で生じる `I²R` 損失や電圧降下を抑えやすい。一方、最終的な負荷では使用に適した低い電圧が必要になる。その間をつなぐのが配電変圧器である。

理想変圧器近似では、一次・二次の巻数を `N1, N2`、電圧を `V1, V2`、電流を `I1, I2` とすると、

`V1/V2 = N1/N2`

`I1/I2 = N2/N1`

`V1 I1 = V2 I2`

が成り立つ。損失を無視した近似なので、一次電力と二次電力が等しい。問題では、どの端子間の電圧と電流を対応させているかを確認して使う。

## §4 単相三線式の構成
単相三線式は、変圧器二次側の中点を中性線として取り出し、2本の電圧線と1本の中性線で配電する方式である。中性点を基準にすると、一方の電圧線は `+V0`、他方は `-V0` とみなせる。

したがって、

- 電圧線－中性線間: `V0`
- 2本の電圧線間: `2V0`

の2種類の電圧を利用できる。

両側の負荷電流が同じなら、中性線では電流が打ち消し合い、理想的には中性線電流は0になる。負荷が不平衡なら、その差に相当する電流が中性線を流れる。

中性線が断線した状態で不平衡負荷が接続されると、2つの負荷が2本の電圧線間に直列につながる形となり、各負荷電圧が等分されず偏る。このため「中性線は平衡時に電流0だから常に不要」と判断してはいけない。

## §5 単相三線式の電圧降下
固定過去問型では、まず各電線の電流を決め、その後で各線の `IR` 降下を追う。

送電端の電位を、

- 上側電圧線: `+V0`
- 中性線: `0`
- 下側電圧線: `-V0`

とする。上側負荷電流を `IA`、下側負荷電流を `IB`、各線抵抗を `RA, RN, RB` とする。正方向を、上側は送電端→負荷、下側と中性線は負荷→送電端として、`IN = IA - IB` とおくと、負荷端の各電位は、

`VA' = V0 - IA RA`

`VN' = IN RN`

`VB' = -V0 + IB RB`

となる。したがって負荷端電圧は、

`VA'N' = V0 - IA RA - IN RN`

`VN'B' = V0 - IB RB + IN RN`

で求められる。

`IA = IB` なら `IN = 0` となり、中性線の電圧降下は0になる。不平衡時は中性点電位が移動するため、一方の負荷電圧が低下し、他方が相対的に高くなることがある。符号を暗記するのではなく、電流方向と各点の電位を順に決める。

## §6 単相三線式＋配電変圧器の解法手順
固定過去問の計算は次の順で処理する。

1. 各負荷に流れる電流 `IA, IB` を求める。
2. 中性線電流 `IN = IA - IB` を符号付きで求める。
3. 各電線の抵抗と電流から電圧降下 `IR` を求める。
4. 送電端の `+V0, 0, -V0` から負荷端各点の電位を求める。
5. 点間の差を取り、各負荷端電圧を求める。
6. 必要なら負荷電力を合計する。
7. 理想変圧器近似なら `V1I1 = V2I2` または電力保存を使い、一次電流へ換算する。
8. 電流・電圧の向きと桁を検算する。

ここで、二つの負荷電流を単純に足して中性線電流とする誤り、各線で同じ電圧降下を使う誤りを避ける。

## §7 三相三線式の電圧降下
平衡三相、線路リアクタンス無視、力率100%という条件では、三相三線式の線間電圧降下を、

`ΔV = √3 I R`

で扱える。`I [A]` は線電流、`R [Ω]` は1相分の線路抵抗である。受電端線間電圧は近似的に、

`Vr = Vs - ΔV`

と求める。

この式は条件付きである。本章では固定過去問に必要な「リアクタンス無視・力率100%」の場合に限定し、より一般的な力率・リアクタンスを含む式へは広げない。

## §8 線路抵抗と導体断面積の逆算
長さ `l [m]`、断面積 `A [mm²]` の導体について、抵抗率を `ρ [Ω·mm²/m]` で与える場合、

`R = ρl/A`

で1相分の線路抵抗を求められる。`ρ` の単位に `mm²` が含まれているなら、断面積を `m²` へ変換せず `mm²` のままそろえる。

三相三線式で許容電圧降下を `ΔVmax` とすると、

`Rmax = ΔVmax/(√3 I)`

さらに、

`Amin = ρl/Rmax = √3 I ρl/ΔVmax`

と逆算できる。選択肢から断面積を選ぶ場合は、`Amin` 以上となる最小の選択肢を選ぶ。

`R=ρl/A` の `l` は1本の線路の長さであり、三相三線式の `ΔV=√3IR` と組み合わせるときに勝手に往復2倍しない。

## §9 ケーブル・CVケーブル・地中電線路
地中電線路では、裸電線ではなく絶縁されたケーブルを用いる。CVケーブルは、架橋ポリエチレン絶縁ビニルシースケーブルであり、地中電線路で用いられる代表的なケーブルの一つとして押さえる。

本章では、CVケーブルの基本位置付けまでとし、OFケーブルやCVTとの詳細比較、シース損・誘電体損等の損失機構には広げない。

## §10 地中電線路の布設方式と許容電流
固定過去問では、直接埋設式・管路式・暗きょ式の特徴を比較する。

| 布設方式 | 基本構造 | 特徴 |
|---|---|---|
| 直接埋設式 | ケーブルを地中に直接埋設する | 構造が比較的単純。後からの交換・増設や点検は容易ではない |
| 管路式 | 管路を地中に設け、その中へケーブルを引き入れる | 予備管路があれば交換・増設をしやすいが、放熱条件は管路・周囲条件の影響を受ける |
| 暗きょ式 | 人が入れる、または多数のケーブルを収容できる地下空間に敷設する | 点検・保守・増設を行いやすい一方、建設規模が大きくなる |

ケーブルの許容電流は、導体で発生する熱と外部へ逃げる熱の釣合いで制約される。電流が増えると `I²R` 発熱が増え、同じ許容導体温度なら、放熱しにくい条件ほど許容電流は小さくなる方向である。

したがって「管路へ入れれば必ず冷却が良くなり、送電容量が増える」と一律に判断してはいけない。布設方式だけでなく、土壌、管路、周囲温度、ケーブル相互の熱影響等の条件が関係するが、本章では定量的な熱計算へは広げない。

## §11 本試験での解法アルゴリズム

### A. 単相三線式の正誤問題
1. 2本の電圧線と中性線の役割を確認する。
2. 線－中性線間と線間の2種類の電圧を確認する。
3. 平衡時は中性線電流0、不平衡時は差電流が流れることを確認する。
4. 中性線断線時は不平衡負荷の電圧偏りに注意する。
5. 電線利用上の利点・欠点を回路構成から判定する。

### B. 単相三線式の計算問題
1. 負荷電流を求める。
2. 中性線電流を差で求める。
3. 各電線の `IR` 降下を求める。
4. 各点の電位を求める。
5. 点間電圧として負荷端電圧を求める。
6. 必要なら負荷電力を合計し、理想変圧器の一次電流へ換算する。

### C. 三相三線式の電圧降下・断面積
1. 平衡三相、リアクタンス無視、力率100%の条件を確認する。
2. `R=ρl/A` で1相分の線路抵抗を求める。
3. `ΔV=√3IR` で線間電圧降下を求める。
4. `Vr=Vs-ΔV` で受電端電圧を求める。
5. 断面積逆算なら `Rmax=ΔVmax/(√3I)`、`Amin=ρl/Rmax` の順で求める。
6. 選択肢では `Amin` 以上の最小値を選ぶ。

### D. 地中電線路の正誤問題
1. 直接埋設・管路・暗きょの構造を区別する。
2. 工事、点検、交換、増設のしやすさを比較する。
3. 放熱条件と許容電流の因果を確認する。
4. 「管路だから必ず放熱良好」等の断定を疑う。
5. CVケーブルは本章では基本構造・用途までで判定する。

## §12 頻出ミス・ひっかけ
- 単相三線式で中性線電流を `IA+IB` とする。平衡負荷では打ち消し合うため差で考える。
- 中性線電流が0になるのは平衡時であり、常に0ではない。
- 不平衡時に中性線の電圧降下を無視する。
- 各電線の電流方向を決めず、`V0-IR` を機械的に当てはめる。
- 理想変圧器で電圧比と電流比を同じ向きにする。電流比は逆比である。
- 三相三線式の線間電圧降下で `√3` を落とす。
- `ρ [Ω·mm²/m]` と `A [m²]` を混在させる。
- `R=ρl/A` の線路長を根拠なく2倍する。
- 許容電圧降下から断面積を求める問題で、計算値以下の断面積を選ぶ。
- 管路式の方が直接埋設式より必ず放熱が良いとする。

## §13 3段階例題

### 基礎例題 — 配電変圧器の一次電流
理想変圧器の一次電圧を `6600 V`、二次の両端電圧を `210 V`、二次側に `40 A` の負荷電流が流れているとする。一次電流を求める。力率1、損失なしとする。

二次側の皮相電力は、

`S = V2 I2 = 210×40 = 8400 VA = 8.40 kVA`

理想変圧器なので一次側も同じ皮相電力で、

`I1 = S/V1 = 8400/6600 ≈ 1.27 A`

また、

`I1/I2 = V2/V1 = 210/6600`

から求めても同じ結果になる。

検算すると、一次電圧は二次電圧より高いため、同じ電力なら一次電流は二次電流より小さくなる。結果の向きも妥当である。

### 本試験標準例題 — 単相三線式の不平衡負荷
学習用仮定値として、送電端電位を上側電圧線 `+100 V`、中性線 `0 V`、下側電圧線 `-100 V` とする。各電線の抵抗は `0.05 Ω`。上側負荷電流 `IA=40 A`、下側負荷電流 `IB=30 A` が与えられている。各負荷端電圧を求める。

まず中性線電流は、

`IN = IA-IB = 40-30 = 10 A`

で、負荷側から電源側へ流れる。

上側電圧線の負荷端電位は、

`VA' = 100 - 40×0.05 = 98.0 V`

中性線の負荷端電位は、

`VN' = 10×0.05 = 0.5 V`

下側電圧線は負荷側から電源側へ `30 A` 流れるため、

`VB' = -100 + 30×0.05 = -98.5 V`

したがって、上側負荷端電圧は、

`VA'N' = 98.0-0.5 = 97.5 V`

下側負荷端電圧は、

`VN'B' = 0.5-(-98.5) = 99.0 V`

となる。不平衡のため中性点が移動し、二つの負荷端電圧は同じにならない。

### 複合・ひっかけ例題 — 三相三線式の断面積逆算
学習用仮定値として、送電端線間電圧 `6600 V`、線電流 `180 A`、線路長 `1800 m`、導体抵抗率 `ρ=0.018 Ω·mm²/m` とする。平衡三相、リアクタンス無視、力率100%とし、許容電圧降下を送電端電圧の `3%` 以下とする。選択肢 `38, 50, 60, 80, 100 mm²` から最小断面積を選ぶ。

許容電圧降下は、

`ΔVmax = 6600×0.03 = 198 V`

許容される最大線路抵抗は、

`Rmax = 198/(√3×180) ≈ 0.635 Ω`

必要断面積は、

`Amin = ρl/Rmax`

`= 0.018×1800/0.635`

`≈ 51.0 mm²`

よって選択肢中の最小断面積は `60 mm²` である。

確認すると、`50 mm²` では `R=0.648 Ω`、`ΔV≈202 V` で許容値を超える。一方 `60 mm²` では `R=0.540 Ω`、`ΔV≈168 V` で許容値以内になる。

## §14 新幹線への接続
駅、トンネル、車両基地、信号設備、照明、ポンプ、空調、防災設備は、列車の主回路とは別に電力を必要とする。本章ではこれらを配電先の負荷としてまとめ、

`高圧配電 → 配電変圧器 → 低圧配電 → 各設備`

という流れで理解する。

地下区間や構内ではケーブルによる配電が必要になる場面を考えやすいが、実際の新幹線設備の電圧、ケーブル種別、断面積、許容電流は設備ごとに異なり得る。本sourceでは一次資料で確認していない値を真値として追加せず、電験標準モデルと学習用仮定値だけで試験論点を説明する。
