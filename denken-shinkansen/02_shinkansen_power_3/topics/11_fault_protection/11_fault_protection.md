- 短絡・地絡は、事故電流の発生、短絡電流計算、保護リレーによる検出、遮断器による事故区間切離しへ接続する。

- 遮断器は、事故電流以上の定格遮断電流・遮断容量を選ぶ考え方まで扱う。
- 保護リレーは、過電流継電器の整定・限時特性と、事故区間だけを切り離す選択遮断の考え方まで扱う。
- 接地は、地絡時の健全相電圧、地絡電流、保護リレー動作との関係を理解する範囲とする。

## 解説本文

## §1 このテーマで電験は何を問うか
Topic 11で中心になるのは、「事故が起きたら大電流が流れる」という説明ではなく、事故電流を数値で求め、検出し、必要な遮断能力と動作時間を決めることである。

本試験では主に次を問われる。

1. 容量・電圧・百分率インピーダンスから三相短絡電流を求める。
2. 異なる容量基準の `%Z` を共通基準へ換算して合成する。
3. 想定短絡電流以上を遮断できる遮断器を選ぶ。
4. CT比で一次事故電流を継電器二次電流へ換算し、過電流継電器の整定・限時特性を読む。
5. 主保護と後備保護の時間差から選択遮断を考える。
6. 中性点接地方式による地絡電流・健全相対地電圧・保護継電器動作の違いを判断する。
7. 避雷器と遮断器の役割を区別する。

この章を終えると、固定5問・7答案要素で要求される計算・正誤判断を、問題文の条件から組み立てられることを目標とする。

## §2 短絡・地絡・過電流を区別する
短絡は、本来異なる電位にある導体間が低いインピーダンスで接続される事故である。三相回路では相間短絡や三相短絡などがあり、電源側から大きな短絡電流が流れる。

地絡は、充電部が大地または接地された部分へ接触する事故である。地絡電流の大きさや健全相の対地電圧は中性点接地方式の影響を受ける。

過電流は、設備に許容範囲を超える電流が流れる状態の総称である。短絡や地絡は過電流を生じる代表的な事故原因だが、三者は同義ではない。

保護の基本的な流れは、

```text
事故発生
→ 異常な電流を保護リレーが検出
→ 遮断器へ動作指令
→ 事故区間を切り離す
```

である。保護リレーは「判断する装置」、遮断器は「電流を実際に切る装置」と区別する。

## §3 百分率インピーダンスと基準電流
三相回路で基準容量を `S_base [VA]`、基準線間電圧を `V [V]` とすると、基準電流は、

`I_base = S_base / (√3 V)`

である。

合成百分率インピーダンスを `%Z_total` とすると、端子での三相短絡を基準とした標準計算では、

`I_sc = I_base / (%Z_total/100)`

となる。

逆に短絡電流から百分率インピーダンスを求めるなら、

`%Z_total = 100 I_base / I_sc`

である。

たとえば `%Z_total=10%` なら、短絡電流は基準電流の `1/0.10=10` 倍になる。`10%` をそのまま10として割らず、必ず `0.10` へ直す。

## §4 %Zは共通容量基準へそろえてから加算する
電源・変圧器など複数要素の `%Z` を直列に合成するとき、容量基準が異なる値をそのまま足してはいけない。

同じ電圧側へ換算済みで、旧基準容量 `S_old` で `%Z_old` が与えられ、新基準容量を `S_new` とすると、

`%Z_new = %Z_old × (S_new / S_old)`

で換算する。

すべてを同じ基準容量へそろえた後、直列部分なら、

`%Z_total = %Z1 + %Z2 + ...`

と合成する。

典型ミスは容量比を逆にすることである。基準容量を小さくすれば、同じ実インピーダンスに対する `%Z` も比例して小さくなる。

## §5 三相短絡電流の標準解法
三相短絡電流問題は次の順で解く。

1. 共通の基準容量 `S_base` を決める。
2. 問題で短絡点側の線間電圧 `V` を確認する。
3. 各機器の `%Z` を共通容量基準へ換算する。
4. 直列部分の `%Z` を合成する。
5. `I_base=S_base/(√3V)` で基準電流を求める。
6. `I_sc=I_base/(%Z_total/100)` で短絡電流を求める。
7. kAへの換算と桁を確認する。

三相電力式と同様、ここでの `V` は線間電圧であり、`√3` を落とさない。

## §6 遮断器の定格遮断電流・遮断容量
短絡電流を計算したら、遮断器はその想定事故電流を安全に遮断できなければならない。

問題で定格遮断電流 `I_break` の候補が与えられた場合は、原則として、

`I_break ≥ I_sc`

を満たす定格を選ぶ。計算値と同じ定格を無条件に選ぶのではなく、候補のうち必要遮断能力を満たすことを確認する。

三相の遮断容量を扱う場合、線間電圧 `V` と定格遮断電流 `I_break` から、

`P_break = √3 V I_break`

と結べる。`V[kV]` と `I_break[kA]` を使えば結果は `MVA` になる。

遮断器は短絡・地絡事故時の大電流を実際に切る装置であり、事故を検出して判断する保護リレーや、過電圧を制限する避雷器とは役割が異なる。

## §7 過電流継電器とCT比
過電流継電器は、回路電流が整定値を超えたことを検出し、定められた特性に従って遮断器へ動作指令を出す。

問題でCT比 `I_pn/I_sn` が与えられ、一次電流を `I_p` とすると、継電器側の二次電流は、

`I_s = I_p × I_sn / I_pn`

で換算する。

例としてCT比 `600/5 A` なら、一次600 Aが二次5 Aに対応する。一次2400 Aなら二次は、

`2400 × 5/600 = 20 A`

である。

整定問題では、正常時最大電流では不要動作せず、保護対象事故では動作できる範囲に整定されているかを確認する。CTはここでは換算条件としてだけ扱い、構造・取扱いへ範囲を広げない。

## §8 限時特性と選択遮断
過電流継電器は、事故電流の大きさと整定値の比に応じて動作時間が決まる限時特性を使う問題が出る。試験では特性曲線、電流整定、タイムレバー等の条件が与えられるので、それを順番に読む。

基本手順は、

1. CT比で事故電流を継電器二次電流へ換算する。
2. 二次事故電流を電流整定値で割り、整定倍数を求める。
3. 問題の限時特性曲線から基準動作時間を読む。
4. 問題文でタイムレバーと動作時間が比例する条件なら、比例計算で必要整定を求める。

選択遮断では、事故点に近い主保護を先に動作させ、上位側は後備保護として時間を遅らせる。これにより事故区間だけを切り離し、健全部分への停電影響を限定する。

上位側を速くしすぎると広い範囲が先に停電し、逆に下位側が遅すぎると事故継続時間が長くなる。試験では与えられた協調時間差を満たすように動作時間を比較する。

## §9 地絡と中性点接地方式
地絡事故では、中性点をどのように接地しているかで、地絡電流と健全相の対地電圧が変わる。

| 接地方式 | 地絡電流 | 健全相対地電圧 | 保護上の特徴 |
|---|---|---|---|
| 非接地 | 小さい | 地絡時に上昇しやすい | 地絡電流が小さく、検出が容易とは限らない |
| 直接接地 | 大きい | 上昇を抑えやすい | 大きな地絡電流を利用して保護リレーを確実に動作させやすい |
| 抵抗接地 | 抵抗で制限 | 非接地より異常電圧を抑えやすい | 地絡電流を制限しつつ保護動作に必要な電流を確保する考え方 |
| 消弧リアクトル接地 | 地絡時の容量性電流を補償して小さくする | 異常電圧抑制との関係で扱う | 地絡電流を小さくする方向に働く |

電験では「地絡電流を小さくすれば常に良い」と単純化しない。異常電圧の抑制と保護継電器を確実に動作させることの両方を見る。

## §10 避雷器とZnO素子
避雷器は、雷や開閉などによる異常電圧を制限し、変圧器などの機器絶縁を保護する装置である。短絡電流を遮断する遮断器とは目的が異なる。

ZnO素子は強い非線形抵抗特性を持つ。通常電圧では抵抗が大きく、異常な高電圧が加わると抵抗が急減してサージ電流を大地側へ流し、機器端子の電圧上昇を制限する。

異常電圧が収まれば再び高抵抗となるため、商用周波数の続流を抑える。ZnO素子を用いたギャップレス避雷器では、この非線形特性を利用して保護する。

覚えるべき役割分担は、

- 保護リレー: 異常を検出・判断する。
- 遮断器: 事故電流を切る。
- 避雷器: 異常電圧を制限する。

である。

## §11 新幹線への接続
25kV架線が地絡した場面を考えると、「事故があるから電源全部を止める」のではなく、事故を検出し、事故区間に対応する遮断器を動作させ、健全部分を可能な限り残すという選択遮断の考え方につながる。

この章で扱う新幹線側の役割は、一般の電力保護を具体化することだけである。実際の新幹線の保護整定値、事故電流値、遮断器定格、リレー内部ロジック、事故点標定方式は一次資料で確認していないため、本教材では真値として置かない。

## §12 本試験での解法アルゴリズム

### A. 短絡電流・遮断器
1. 各機器の `%Z` の容量基準を確認する。
2. 共通容量基準へ `%Z` を換算する。
3. 直列要素の `%Z` を合成する。
4. `I_base=S_base/(√3V)` を求める。
5. `I_sc=I_base/(%Z_total/100)` を求める。
6. 定格遮断電流の候補から `I_break≥I_sc` を満たすものを選ぶ。
7. 遮断容量なら `√3VI_break` で確認する。

### B. 過電流継電器・選択遮断
1. 一次事故電流をCT比で二次電流へ換算する。
2. 電流整定値に対する倍数を求める。
3. 与えられた限時特性から動作時間を読む。
4. タイムレバー等の比例条件が問題文にあれば必要値へ換算する。
5. 下位主保護が上位後備保護より先に動作し、指定協調時間差を満たすか確認する。

### C. 地絡・接地・避雷器
1. 問題が事故電流、健全相対地電圧、保護動作のどれを比較しているか確認する。
2. 非接地・直接接地・抵抗接地・消弧リアクトル接地の方向性を比較する。
3. 過電圧問題なら避雷器、短絡・地絡の大電流遮断なら遮断器と役割を区別する。
4. ZnO、非線形抵抗、続流、ギャップレスの語の関係を確認する。

## §13 頻出ミス
- `%Z_new=%Z_old(S_new/S_old)` の容量比を逆にする。
- `%Z=10%` を `10` のまま式へ入れる。
- 三相の基準電流で線間電圧を使うとき `√3` を落とす。
- 容量基準の異なる `%Z` をそのまま加える。
- 計算した事故電流と遮断器の定格遮断電流を「同値でなければならない」と考える。
- CT一次電流と継電器二次電流を混同する。
- 限時特性の電流倍数を一次側電流のまま読む。
- 主保護と後備保護の時間順序を逆にする。
- 短絡と地絡を同義として扱う。
- 地絡電流が小さい接地方式ほど常に優れると決めつける。
- 避雷器を短絡電流を切る装置と誤認する。

## §14 3段階例題

### 例題1 基礎 — %Zから三相短絡電流
基準容量20 MVA、線間電圧6.6 kV、短絡点から見た合成百分率インピーダンスが10%である。三相短絡電流を求める。

基準電流は、

`I_base = 20×10^6 / (√3 × 6.6×10^3)`

`≒ 1749.5 A`

短絡電流は、

`I_sc = 1749.5 / 0.10`

`≒ 17495 A = 17.5 kA`

である。

`10%` を `0.10` に直し、線間電圧を使う三相式の `√3` を落とさないことが要点である。

### 例題2 本試験標準 — 共通容量換算から遮断器選定
6.6 kV母線の短絡計算を行う。電源インピーダンスは50 MVA基準で12%、変圧器インピーダンスは20 MVA基準で7%とする。両者は短絡点から見て直列で、同一電圧側へ換算済みとする。20 MVA基準で三相短絡電流を求め、定格遮断電流の候補 `12.5 kA、16 kA、20 kA` から最小の適合値を選ぶ。また選んだ遮断器の三相遮断容量を求める。

まず電源の `%Z` を20 MVA基準へ換算する。

`%Z_source = 12 × 20/50 = 4.8%`

変圧器はすでに20 MVA基準なので、

`%Z_total = 4.8 + 7.0 = 11.8%`

基準電流は、

`I_base = 20×10^6 / (√3 × 6.6×10^3) ≒ 1749.5 A`

したがって、

`I_sc = 1749.5 / 0.118 ≒ 14827 A = 14.8 kA`

となる。

候補のうち `I_break≥14.8 kA` を満たす最小定格は `16 kA` である。

遮断容量は、

`P_break = √3 × 6.6 kV × 16 kA ≒ 182.9 MVA`

である。

容量基準をそろえる前に `%Z` を足さないこと、短絡電流計算後に必要遮断能力以上の定格を選ぶことが要点である。

### 例題3 複合・ひっかけ — CT換算と選択遮断
一次事故電流が2400 A、CT比が600/5 A、過電流継電器の電流整定値が二次5 Aである。正常時最大一次電流は480 Aとする。事故時の整定倍数を求める。また、この整定倍数でタイムレバー1.0の動作時間が2.4 sで、同じ整定倍数では動作時間がタイムレバーに比例するものとする。上位後備保護が1.2 sで動作し、0.3 s以上の協調時間差が必要なとき、候補 `0.2、0.3、0.4、0.5` から使える最大タイムレバーを選ぶ。

正常時最大のCT二次電流は、

`480 × 5/600 = 4.0 A`

であり、5 A整定未満なので、この条件では正常最大電流で動作しない。

事故時CT二次電流は、

`2400 × 5/600 = 20 A`

である。整定倍数は、

`20 / 5 = 4`

倍となる。

上位後備保護が1.2 s、必要協調時間差が0.3 sなので、下位主保護に許される最大動作時間は、

`1.2 - 0.3 = 0.9 s`

である。

タイムレバーを `T` とすると、問題条件より、

`2.4 T ≤ 0.9`

`T ≤ 0.375`

である。候補のうち使える最大値は `0.3`。そのとき動作時間は、

`2.4 × 0.3 = 0.72 s`

で、上位1.2 sとの差は0.48 sとなり、必要な0.3 s以上を満たす。

一次電流のまま限時特性を読まず、CT二次電流へ換算してから整定倍数を求めること、主保護を後備保護より先に動作させることが要点である。
