使用する主要式・判断:

- `σ = 1/ρ`
- `R = ρl/A = l/(σA)`
- `R2 ≈ R1{1 + α1(θ2-θ1)}`
- `ρ2 ≈ ρ1{1 + α1(θ2-θ1)}`
- 同一長さ・同一抵抗では `A_B/A_A = ρ_B/ρ_A`
- `m_B/m_A = (δ_B/δ_A)(ρ_B/ρ_A)`
- 軟銅は硬銅より導電性・柔軟性が高く、引張強度は低い。
- 絶縁材料は気体・液体・固体と用途を対応させる。

- アモルファス磁性材料は非晶質で低鉄損化に有利だが、加工性・使用磁束密度に制約がある。

# 問題

## 基礎

### 問1
抵抗率 `ρ`、導電率 `σ`、長さ `l`、断面積 `A` の一様な導体の抵抗 `R` に関する式として正しいものはどれか。

1. `σ = ρ`、`R = ρA/l`
2. `σ = 1/ρ`、`R = ρl/A`
3. `σ = ρ^2`、`R = l/(ρA)`
4. `σ = 1/ρ`、`R = ρA/l`
5. `σ = ρ`、`R = l/(ρA)`

### 問2
抵抗率を練習用仮定値 `ρ = 2.0×10^-8 Ω·m`、長さ `l = 40 m`、断面積 `A = 8.0 mm²` とする導体の抵抗として最も近いものはどれか。

1. `0.010 Ω`
2. `0.050 Ω`
3. `0.100 Ω`
4. `0.200 Ω`
5. `1.00 Ω`

### 問3
20℃での抵抗が `10.0 Ω`、20℃における温度係数を練習用仮定値 `α20 = 4.0×10^-3 /℃` とする金属導体がある。50℃での抵抗を一次近似で求めた値として最も近いものはどれか。

1. `8.8 Ω`
2. `9.2 Ω`
3. `10.0 Ω`
4. `11.2 Ω`
5. `12.0 Ω`

1. 軟銅は硬銅より引張強度が高く、導電性は低い。
2. 軟銅は硬銅より導電性と柔軟性が高いが、引張強度は低い。
3. 硬銅は軟銅より柔軟性が高く、引張強度は低い。
4. 硬銅を焼きなますと、一般に引張強度と硬さが増加する。

1. `SF6` は気体絶縁材料として用いられ、高い絶縁性能とアーク消弧性能を持つ。

3. 架橋ポリエチレンは固体絶縁材料で、架橋によって耐熱変形性を高めている。
4. OFケーブルでは、絶縁油を含浸した紙絶縁を用い、油圧を保って絶縁性能を確保する方式がある。

### 問7

## 複合・応用

### 問11
20℃での抵抗率を練習用仮定値 `ρ20 = 2.0×10^-8 Ω·m`、20℃での温度係数を `α20 = 4.0×10^-3 /℃` とする金属導体がある。長さ `l = 60 m`、断面積 `A = 12 mm²` とする。70℃での抵抗率 `ρ70` と抵抗 `R70` の組合せとして最も近いものはどれか。

1. `ρ70 = 2.0×10^-8 Ω·m`、`R70 = 0.100 Ω`
2. `ρ70 = 2.2×10^-8 Ω·m`、`R70 = 0.110 Ω`
3. `ρ70 = 2.4×10^-8 Ω·m`、`R70 = 0.120 Ω`
4. `ρ70 = 2.4×10^-8 Ω·m`、`R70 = 1.20 Ω`
5. `ρ70 = 3.0×10^-8 Ω·m`、`R70 = 0.150 Ω`

### 問12
電気材料に関する次の記述のうち、誤っているものはどれか。

1. 導電率と抵抗率は逆数の関係にあり、同じ材料なら導体の抵抗は長さに比例し断面積に反比例する。
2. 軟銅は硬銅より導電性・柔軟性が高い一方、引張強度は低い。
3. 同じ長さ・同じ抵抗で比較すると、抵抗率が大きい材料はより大きな断面積が必要だが、密度が十分小さければ質量を小さくできる場合がある。
4. 薄い鋼板を互いに絶縁して積層する主目的は、磁化反転をなくしてヒステリシス損を低減することである。
5. アモルファス磁性材料は非晶質で、低鉄損化に有利だが、加工性や使用磁束密度にも注意が必要である。

# 解答・完全解説

## 問1
正答: 2

抵抗率と導電率は、

`σ = 1/ρ`

の逆数関係にある。一様な導体では、

`R = ρl/A`

なので、長くなるほど抵抗は大きく、断面積を大きくするほど抵抗は小さくなる。正答は2。

## 問2
正答: 3

断面積をSI単位へ直す。

`A = 8.0 mm² = 8.0×10^-6 m²`

したがって、

`R = ρl/A`

`= (2.0×10^-8×40)/(8.0×10^-6)`

`= 8.0×10^-7 / 8.0×10^-6`

`= 0.100 Ω`

となる。`mm²` を `10^-3 m²` と誤換算しない。正答は3。

## 問3
正答: 4

温度差は、

`Δθ = 50-20 = 30℃`

である。一次近似より、

`R50 = 10.0{1 + 4.0×10^-3×30}`

`= 10.0×1.12`

`= 11.2 Ω`

となる。正の温度係数を持つ金属なので、温度上昇後に抵抗が増える方向も検算になる。正答は4。

## 問4
正答: 2

軟銅は硬銅を焼きなまして得られ、柔軟性と導電性が高くなる一方、引張強度は低くなる。硬銅は機械的強度が必要な用途に向く。したがって2が正しい。

1は導電性と引張強度の方向が逆、3は柔軟性と強度の方向が逆、4は焼きなましの作用が逆、5は電気的・機械的性質の差を無視している。

## 問5
正答: 4

同じ長さ・同じ抵抗では、

`A_B/A_A = ρ_B/ρ_A = 1.50`

である。

質量 `m = δAl` なので、

`m_B/m_A = (δ_B/δ_A)(A_B/A_A)`

`= 0.35×1.50`

`= 0.525`

となる。抵抗率だけで質量を判断せず、必要断面積と密度を組み合わせる。正答は4。

## 問6
正答: 5

1〜4は正しい。SF6は気体絶縁材料、絶縁油は絶縁と冷却、架橋ポリエチレンは固体絶縁材料、OFケーブルは油含浸紙絶縁と油圧維持を用いる方式として整理できる。

5が誤り。がいしは電気絶縁だけでなく、電線等を支持するための機械的役割も関係する。材料問題では絶縁性能だけでなく、用途で同時に要求される特性を見る。正答は5。

## 問7
正答: 3

渦電流損は、時間的に変化する磁束により鉄心内部に誘導起電力が生じ、導電性の鉄心内部を循環する電流が流れてジュール損失を生じることで発生する。薄い鋼板を互いに絶縁して積層すると電流経路が分断され、渦電流を流れにくくできる。したがって3が正しい。

B-Hループ面積はヒステリシス損に対応する。積層の主目的をヒステリシス損低減と取り違えない。鉄損は主にヒステリシス損と渦電流損からなる。

## 問8
正答: 3

アルミニウムは銅より導電率が低いため、同一長さ・同一抵抗なら一般により大きな断面積が必要になる。一方、密度が小さいため、断面積を増やしても質量を小さくできる場合がある。したがって3が正しい。

ACSRでは中心の鋼より線が主に機械的強度を受け持ち、周囲のアルミニウムより線が主に導電を担うので1は逆である。合金化や架空電線の材料選択では導電性だけでなく機械的強度等も見る。

## 問9
正答: 5

アモルファス磁性材料は結晶構造を持たない非晶質材料で、低鉄損化に有利である。一方、一般に硬く加工しにくく、けい素鋼板より使用できる磁束密度が低いため、同じ容量では鉄心断面積が大きくなる方向に働く。したがって1〜4は正しく、5が誤りである。正答は5。

## 問10
正答: 2

半導体材料は導体と絶縁体の中間的な電気伝導を示し、温度や不純物の影響で導電性が大きく変化する。したがって2が正しい。

本Topicの固定範囲は材料としての基本性質までであり、pn接合、整流回路、インバータ等へ範囲を広げる必要はない。1、4、5は半導体の基本性質と矛盾する。

## 問11
正答: 3

温度差は、

`Δθ = 70-20 = 50℃`

である。抵抗率の一次近似より、

`ρ70 = ρ20{1 + α20Δθ}`

`= 2.0×10^-8{1 + 4.0×10^-3×50}`

`= 2.0×10^-8×1.20`

`= 2.4×10^-8 Ω·m`

断面積は、

`A = 12 mm² = 12×10^-6 m²`

なので、

`R70 = ρ70l/A`

`= (2.4×10^-8×60)/(12×10^-6)`

`= 1.44×10^-6 / 12×10^-6`

`= 0.120 Ω`

となる。正の温度係数により抵抗率と抵抗が20℃時より増える方向も確認する。正答は3。

## 問12
正答: 4

1は `σ=1/ρ` と `R=ρl/A` の関係で正しい。2は軟銅と硬銅の比較として正しい。3は同一長さ・同一抵抗で `A∝ρ`、`m=δAl` を合わせて考える説明として正しい。5はアモルファス磁性材料の基本特性として正しい。

4が誤り。積層鉄心の主目的は、鉄心内の渦電流経路を分断して渦電流損を低減することである。ヒステリシス損は磁化反転とB-Hループ等に関係する。正答は4。
