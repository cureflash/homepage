### 過去問要求事項の分解
教材本文では、少なくとも次を欠落させない。

- 用語・定義: 最大需要電力、設備容量、平均需要電力、需要率、負荷率、不等率、力率、有効電力、無効電力、皮相電力、電圧降下、電圧降下率、線路損失。
- 指標関係: `最大需要電力 = 設備容量 × 需要率`、`平均需要電力 = 最大需要電力 × 負荷率`、`合成最大需要電力 = 個々の最大需要電力合計 / 不等率`。
- 電力量: `W = P_avg t`。kW と kWh を混同しない。
- 交流電力: `S²=P²+Q²`、`cosφ=P/S`、`Q=P tanφ`。
- 三相電力: `P=√3VIcosφ`。線間電圧・線電流を使う条件を明記する。
- 電力損失: 平衡三相で1線当たり抵抗を `R` としたとき `P_loss=3RI²`。
- 電圧変動: 位相差が小さく静電容量を無視する短い三相線路で `ΔV ≒ √3 I(R cosφ + X sinφ)` を用いる条件。
- 力率の影響: 同じ有効電力・電圧なら力率低下で電流が増え、`I²R` 損失と電圧降下が増えやすいこと。
- 負荷追加: 複数負荷は有効電力と無効電力をそれぞれ合算してから `S` と総合力率を求めること。
- 最大負荷計算: 設備容量のkVA/MVAと負荷のkW/MWを力率で結ぶこと。
- 典型ミス: 需要率と負荷率の分母、常に1以上となる不等率、kW/kVA/kvarの混同、百分率の100倍、1線分損失と三相合計損失、`sinφ` と `cosφ` の取り違え。
- 新幹線接続: 複数列車の同時加速を「負荷増加」の具体例としてのみ使い、未確認の列車・変電所実値を前提にしない。

# 解説本文

## §1 このテーマで電験は何を問うか

電験では、負荷が増えたときに「設備が何kWまで供給できるか」「電流・損失・電圧降下がどう変わるか」「複数需要家の最大需要をどう合成するか」を数値で判断させる。

このテーマでは次の順序で解く。

1. 需要率・負荷率・不等率から、設備容量・最大需要電力・平均需要電力・合成最大需要電力を結ぶ。
2. `P`、`Q`、`S` と力率から、負荷が必要とする電流と設備容量を求める。
3. 三相線路では、その電流から `3RI²` 損失と電圧降下を求める。
4. 設備容量または電圧降下率が上限として与えられたら、逆算して最大負荷を求める。

新幹線では「複数列車が同時に加速する」を負荷増加の具体例とするだけで、未確認の実設備値は使わない。

## §2 需要率・負荷率・不等率

設備容量を `P_e [kW]`、最大需要電力を `P_max [kW]`、平均需要電力を `P_avg [kW]` とする。

### 需要率

`需要率 = P_max / P_e`

したがって、

`P_max = P_e × 需要率`

設備を全部同時に最大出力で使うとは限らないため、需要率は設備容量から実際の最大需要を見積もる指標である。

### 負荷率

`負荷率 = P_avg / P_max`

したがって、

`P_avg = P_max × 負荷率`

負荷率は「最大需要に対して、期間中の平均負荷がどれだけ高いか」を表す。需要率と違い、分母は設備容量ではなく最大需要電力である。

### 不等率

複数需要家について、各需要家の最大需要電力の合計を `ΣP_max,i`、全体を同時に見た合成最大需要電力を `P_max,total` とすると、

`不等率 = ΣP_max,i / P_max,total`

よって、

`P_max,total = ΣP_max,i / 不等率`

各需要家の最大時刻は一致しないことがあるため、不等率は通常1以上となる。

## §3 平均需要電力と電力量

一定期間 `t [h]` の需要電力量 `W [kWh]` は、

`W = P_avg t`

で求める。`kW` は電力、`kWh` は電力量であり単位を混同しない。

需要率と負荷率が与えられると、

`W = P_e × 需要率 × 負荷率 × t`

まで一続きに計算できる。

## §4 有効電力P・無効電力Q・皮相電力Sと力率

交流負荷では、

- `P [kW, MW]`: 有効電力
- `Q [kvar, Mvar]`: 無効電力
- `S [kVA, MVA]`: 皮相電力

を区別する。

関係は、

`S² = P² + Q²`

`cosφ = P / S`

`Q = P tanφ`

である。設備容量が `kVA` または `MVA` で与えられ、負荷が `kW` または `MW` で与えられる問題では、力率を介して両者を結ぶ。

同じ有効電力 `P` と電圧なら、力率が低いほど必要な `S` と電流が大きくなる。

## §5 三相3線式の有効電力と線電流

平衡三相3線式で、線間電圧を `V [V]`、線電流を `I [A]`、力率を `cosφ` とすると、

`P = √3 V I cosφ`

したがって、

`I = P / (√3 V cosφ)`

である。この式では `V` に線間電圧、`I` に線電流を使う。

同じ `P` と `V` なら、`cosφ` が低下すると `I` は増加する。これが損失増加と電圧降下増加につながる。

## §6 複数負荷を追加するときはPとQを別々に足す

負荷1、負荷2があるとき、皮相電力の大きさ `S` をそのまま足さない。

各負荷について、

`Q_i = P_i tanφ_i`

を求め、

`P_total = ΣP_i`

`Q_total = ΣQ_i`

`S_total = √(P_total² + Q_total²)`

`cosφ_total = P_total / S_total`

の順で合成する。

設備容量上限を `S_rated` とすると、`S_total ≤ S_rated` であることが必要である。力率改善を扱う場合は、設備の種類へ踏み込まず、必要な無効電力低減量だけを計算する。

## §7 三相線路の電力損失

平衡三相で1線当たり抵抗が `R [Ω]`、線電流が `I [A]` のとき、三相合計の銅損は、

`P_loss = 3 R I²`

である。

重要なのは電流の二乗に比例する点である。負荷増加や力率低下で電流が1.2倍になると、損失は `1.2² = 1.44` 倍になる。

「1線分の `RI²`」と「三相合計の `3RI²`」を取り違えない。

## §8 三相3線式の電圧降下近似

短い三相線路で、静電容量を無視でき、送受電端の位相差が小さい条件では、1線当たり抵抗 `R [Ω]`、リアクタンス `X [Ω]`、遅れ力率 `cosφ` に対し、線間電圧の電圧降下を近似的に、

`ΔV ≒ √3 I (R cosφ + X sinφ)`

と表せる。

電圧降下率を受電端線間電圧 `V_r` 基準で表すなら、

`e = ΔV / V_r`

百分率なら `100e [%]` とする。

同じ有効電力では、力率低下により電流が増え、遅れ負荷では `X sinφ` 項も効くため、電圧降下が増えやすい。

## §9 設備容量から最大需要電力を逆算する

設備の皮相電力容量を `S_rated`、許容倍率を `k`、負荷力率を `cosφ` とすると、供給可能な有効電力の上限は、

`P_available = k S_rated cosφ`

で結べる。

負荷切替後に元の総負荷の割合 `a` がその設備へ残る条件なら、

`a P_total ≤ P_available`

より、

`P_total,max = P_available / a`

と逆算する。容量の単位がMVAで負荷がMWなら、力率を掛けて有効電力へそろえてから比較する。

## §10 電圧降下率上限から最大負荷を逆算する

電圧降下率の上限 `e_max` が与えられたら、まず、

`ΔV_max = e_max V_r`

を求める。

次に、

`ΔV_max ≒ √3 I_max (R cosφ + X sinφ)`

から `I_max` を求め、

`P_max = √3 V_r I_max cosφ`

へ戻す。

「負荷→電流→電圧降下」の順だけでなく、「許容電圧降下→許容電流→最大負荷」と逆向きにも解けることが重要である。

## §11 新幹線への接続

複数列車が同時に加速すると、き電系統から見た負荷が増えた状態として考えられる。この章ではSPECどおり、

```text
列車負荷増加
→ 電流増加
→ 電圧降下増加
→ 損失増加
```

という因果だけを使う。

列車数、列車1編成の消費電力、変電所容量などの実値はここでは仮定しない。電験問題では、問題文で与えられた設備容量、負荷、力率、線路定数から計算する。

## §12 本試験での解法アルゴリズム

### A. 需要率・負荷率・不等率
1. 設備容量、各最大需要、平均需要、合成最大需要のどれが与えられているか確認する。
2. 需要率・負荷率・不等率の分母を確認する。
3. 設備容量→最大需要→平均需要の順に変換する。
4. 電力量なら最後に時間を掛ける。
5. 不等率なら各最大需要の合計を合成最大需要で割る。

### B. 力率・設備容量・負荷追加
1. 各負荷の `P` と力率から `Q=P tanφ` を求める。
2. `P` と `Q` をそれぞれ合算する。
3. `S=√(P²+Q²)` を求める。
4. 設備定格 `S_rated` と比較する。
5. 力率改善量を問うなら、許容 `Q` を `√(S_rated²-P²)` から逆算する。

### C. 損失・電圧降下
1. `P=√3VIcosφ` から線電流を求める。
2. `P_loss=3RI²` で三相合計損失を求める。
3. `ΔV≒√3I(Rcosφ+Xsinφ)` で電圧降下を求める。
4. 電圧降下率は基準電圧で割る。
5. 最大負荷問題では式を逆向きにたどる。

## §13 頻出ミス

- 需要率の分母は設備容量、負荷率の分母は最大需要電力。
- 不等率を逆数にしない。不等率は通常1以上。
- `kW`、`kVA`、`kvar` を同じ量として足さない。
- 皮相電力は負荷ごとに大きさを足さず、`P` と `Q` を合成してから求める。
- 三相電力式では線間電圧・線電流を使う。
- 線路損失は三相合計なら `3RI²`。
- 電圧降下率を百分率で答えるときは100倍する。
- 遅れ力率の電圧降下式で `R cosφ + X sinφ` の `sinφ`、`cosφ` を入れ替えない。

## §14 3段階例題

### 例題1 基礎 — 需要率・負荷率・電力量

設備容量1200 kW、需要率75%、1日の負荷率60%の需要設備がある。最大需要電力、平均需要電力、1日の需要電力量を求める。

最大需要電力:

`P_max = 1200 × 0.75 = 900 kW`

平均需要電力:

`P_avg = 900 × 0.60 = 540 kW`

1日の需要電力量:

`W = 540 × 24 = 12960 kWh`

需要率は「設備容量→最大需要」、負荷率は「最大需要→平均需要」に使う。

### 例題2 本試験標準 — 三相負荷の電流・損失・電圧降下

線間電圧6.6 kV、三相有効電力2.00 MW、遅れ力率0.80の平衡負荷がある。1線当たりの線路抵抗を0.15 Ω、リアクタンスを0.25 Ωとする。線電流、三相線路損失、近似電圧降下、受電端電圧基準の電圧降下率を求める。

`sinφ = √(1-0.80²) = 0.60`

線電流:

`I = 2.00×10^6 / (√3 × 6600 × 0.80) ≒ 218.7 A`

三相線路損失:

`P_loss = 3 × 0.15 × 218.7² ≒ 21.5 kW`

電圧降下:

`ΔV ≒ √3 × 218.7 × (0.15×0.80 + 0.25×0.60)`

`= √3 × 218.7 × 0.27 ≒ 102.3 V`

電圧降下率:

`102.3 / 6600 × 100 ≒ 1.55 %`

有効電力からまず電流へ変換し、その同じ電流を損失式と電圧降下式へ入れる。

### 例題3 複合・ひっかけ — 負荷追加と設備容量

既設負荷が `1.20 MW`、遅れ力率0.80、追加負荷が `0.80 MW`、遅れ力率0.60である。設備容量上限が `2.50 MVA` のとき、そのまま接続できるか判定し、設備容量内へ収めるために必要な無効電力低減量を求める。

既設負荷:

`Q1 = 1.20 × tan(cos^-1 0.80) = 1.20 × 0.75 = 0.90 Mvar`

追加負荷:

`tan(cos^-1 0.60) = 0.80/0.60 = 1.333...`

`Q2 = 0.80 × 1.333... ≒ 1.067 Mvar`

合計:

`P = 1.20 + 0.80 = 2.00 MW`

`Q = 0.90 + 1.067 = 1.967 Mvar`

`S = √(2.00² + 1.967²) ≒ 2.805 MVA`

よって `2.805 > 2.50` なので、そのままでは設備容量を超える。

設備容量2.50 MVA内で許される無効電力は、

`Q_allow = √(2.50² - 2.00²) = 1.50 Mvar`

したがって必要な無効電力低減量は、

`1.967 - 1.50 ≒ 0.467 Mvar`

である。皮相電力 `S1+S2` を直接足さず、`P` と `Q` を別々に合算するのが要点である。
