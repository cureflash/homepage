### 範囲境界
- 回生電力が架線へ戻った後、他の負荷で消費される、電力系統側へ流れる、蓄電設備へ蓄えられる、受入先がなく回生できない、という電力の流れを中心にする。
- 電力と電力量を区別し、時間変化する発電・負荷のグラフから余剰・不足・送受電電力量を求めるところまで扱う。
- 蓄電池は「充電して電力を貯蔵し、必要時に放電する設備」として扱う。電極反応、電解質、充電方式、UPS設計、セル詳細は追加しない。
- 需給バランスでは、固定過去問に現れる太陽光、揚水発電、運転予備力、火力発電は「需給調整の例」として必要最小限に触れる。各発電方式の詳細計算・設備設計へ広げない。
- 分散型電源の系統連系保護、配電電圧制御、パワーコンディショナ詳細、法令上の広域運営・供給計画は追加しない。
- 回生失効は、回生電力の受入先・受入余力がない場合に回生できなくなる現象として扱う。具体的な車両制御、ブレーキ切替条件、実設備の回生融通方式は一次資料で確認できる範囲を後工程で使い、推測しない。

### 過去問要求事項の分解
教材本文では、少なくとも次を欠落させない。

- 回生電力: 列車の運動エネルギーを電気エネルギーへ戻し、架線側へ返すというエネルギーの流れ。
- 負荷と受入先: 回生電力と同時刻に消費する負荷があれば、その負荷へ電力が流れ得ること。
- 電力系統・電力融通: 発生電力が負荷を上回ると余剰、下回ると不足になり、系統との送受電で差を埋めるという収支。
- 電力と電力量: `P[kW]` と `W[kWh]` を区別し、一定電力では `W=Pt`、時間変化時は `W=∫Pdt`。折れ線グラフでは面積として求める。
- 余剰・不足の判定: `P発生-P負荷` の符号から送電側・受電側を判断し、交点で時間区間を分ける。
- 自家消費: 発生電力量から外部へ送った電力量を差し引き、内部で使われた電力量を求める。
- 蓄電池・電力貯蔵: 余剰時に充電し、不足時に放電することで発電と需要の時間差を緩和する。
- 需給バランス: 需要と供給を一致させる必要があり、貯蔵や調整可能な電源等が時間変動を吸収する。
- 回生失効: 回生電力を受け入れられる負荷・系統・蓄電設備等がない、または受入条件を満たさない場合には回生できないこと。具体的制御方式は一次資料確認前に断定しない。
- 省エネルギー: 回生電力を別の負荷や蓄電設備で有効利用できれば、外部から新たに供給する電力量や熱として捨てるエネルギーを減らせるというエネルギー収支で説明する。
- 典型ミス: kWとkWhの混同、発電曲線と負荷曲線の上下を逆に読む、余剰区間の面積だけで総発電量とする、送電量と自家消費量を混同する、再出題問題を別論点として水増しする。

# 解説本文

## §1 このテーマで電験は何を問うか
このテーマでは、電験三種「電力」を中心に、発生側と負荷側の瞬時の電力差、時間積分した電力量、余剰・不足時の送受電、蓄電池による電力貯蔵、需給バランスを扱う。関連する法規の電気施設管理計算では、発電曲線と負荷曲線から送電量・受電量・自家消費量・比率を求める問題が出る。

本章の中心は、`発生電力 - 負荷電力` の符号を判定し、その差を時間で積算することである。新幹線の回生は、この一般的な発生源と負荷の関係を理解する入口として使う。

## §2 回生電力の流れ
列車が回生すると、主電動機側で得た電気エネルギーが主変換装置を通って架線側へ戻る。本章では、その先を次の一般モデルで扱う。

```text
回生する列車
↓
架線側
├→ 同時刻に電力を使う他の負荷
├→ 電力系統側
└→ 蓄電設備
```

重要なのは、回生した電力そのものを「消える・残る」と考えず、同じ時刻にどこが受け取れるかという電力収支で見ることである。受入先・受入余力がない場合は回生できず、本章ではこれを回生失効として扱う。具体的な車両制御方式や実設備構成は断定しない。

## §3 電力と電力量を区別する
電力 `P [kW]` は、その瞬間のエネルギー移動の速さである。電力量 `W [kWh]` は、電力を時間で積算した量である。

一定電力なら、

`W = Pt`

時間で変化するなら、

`W = ∫P(t)dt`

となる。横軸が時間、縦軸が電力のグラフでは、面積が電力量になる。時間を秒で与えられたときに `kWh` を求めるなら、`3600 s = 1 h` へ換算する。

## §4 発生電力と負荷電力の差で向きを決める
発生電力を `Pg`、負荷電力を `PL` とする。

`Pg > PL` のとき、差 `Pg-PL` は余剰である。内部負荷で使い切れない分は、受入可能なら外部へ送る、または蓄電設備へ充電する。

`Pg < PL` のとき、差 `PL-Pg` は不足である。不足分は系統等から受電する、または蓄電設備から放電して補う。

`Pg = PL` なら、その時点では外部との正味の送受電は0である。

固定過去問型では、まず発電曲線と負荷曲線の交点を求め、符号が変わる時刻で区間を分ける。

## §5 グラフから送電量・受電量を求める
電力量は電力差の面積で求める。

送電電力量は、

`Wsend = ∫max(Pg-PL, 0)dt`

受電電力量は、

`Wreceive = ∫max(PL-Pg, 0)dt`

で整理できる。

折れ線グラフなら、長方形・三角形・台形に分けて面積を足す。総発電電力量だけを求めて送電量と取り違えないこと、余剰区間だけを総発電量としないことが重要である。

## §6 自家消費量・自家消費比率・自給率
発生した電力量のうち外部へ送らず内部で使った量を自家消費電力量とすると、

`Wself = Wgen - Wsend`

で求められる。

自家消費比率は、発生した電力量のうちどれだけ内部で使ったかを見る比率なので、

`自家消費比率 = Wself / Wgen × 100 [%]`

とする。

一方、自給率は、総消費電力量のうち内部発生でどれだけ賄ったかを見る比率なので、

`自給率 = Wself / Wload × 100 [%]`

となる。分母が異なるため、両者を混同しない。

## §7 蓄電池・電力貯蔵・負荷平準化
蓄電池は、余剰時に充電し、不足時に放電することで、発生と需要の時間差を埋める設備である。電力系統では、出力が時間変動する発電と負荷の差を緩和し、負荷平準化や需給調整に利用できる。

本章で必要な電池知識は役割と出題上の基本分類までである。

- 二次電池: 充電して繰り返し使用できる。
- リチウムイオン電池: 代表的な二次電池で、一般にエネルギー密度が高い側の電池として扱われる。
- NAS電池: 大規模な定置用電力貯蔵の例として扱われる。

電極反応、電解質、セル電圧、充電方式、UPS設計へは広げない。

## §8 需給バランスと調整手段
電力系統では、需要と供給を継続的に釣り合わせる必要がある。需要が小さい時間帯に余剰が生じ、需要が大きい時間帯に不足が生じるなら、時間差を吸収する設備や調整可能な電源が必要になる。

固定過去問に出る範囲では、次のように整理する。

- 蓄電池: 余剰時に充電し、不足時に放電する。
- 揚水発電: 余剰電力を位置エネルギーとして貯蔵し、必要時に発電する例。
- 運転予備力: 需要増加や発電力低下へ対応できる余力。
- 火力発電: 出力調整可能な電源の例として扱う。

本章では各方式の設備設計や詳細計算には入らない。

## §9 回生失効と省エネルギー
回生電力を受け取る負荷、系統側の受入余力、蓄電設備等がなければ、回生電力を有効利用できない。本章ではその状態を回生失効として扱う。

逆に、同時刻の他負荷で消費する、外部へ電力融通する、蓄電設備へ一時的に貯蔵することができれば、外部から新たに受け取る電力量を減らし、回生で得たエネルギーを有効利用できる。省エネルギー効果は、回生した電力量そのものではなく、実際に有効利用できた電力量で評価する。

## §10 本試験での解法アルゴリズム

### A. 発電・負荷グラフの計算
1. 縦軸の単位が `kW` または `MW`、横軸の単位が `h` か確認する。
2. 発生曲線と負荷曲線の交点を求める。
3. 各区間で `Pg>PL` か `Pg<PL` か判定する。
4. `Pg>PL` の差の面積を送電量、`Pg<PL` の差の面積を受電量として積算する。
5. 総発電電力量と総負荷電力量も別に面積で求める。
6. `Wself=Wgen-Wsend` で自家消費量を求める。
7. 求められた比率の分母が `Wgen` か `Wload` か確認する。
8. `kW×h=kWh`、`MW×h=MWh` の単位を検算する。

### B. 蓄電・需給バランスの正誤問題
1. 余剰時と不足時を分ける。
2. 蓄電設備が余剰を充電し、不足時に放電する役割を確認する。
3. 二次電池と一次電池を混同しない。
4. リチウムイオン電池、NAS電池は本章で必要な基本位置付けだけで判定する。
5. 揚水・運転予備力・火力は需給調整の例として判定し、詳細論点へ広げない。

### C. 回生電力の流れ
1. 回生する列車を発生側として見る。
2. 同時刻の他負荷が受け取れるか確認する。
3. 余剰があれば系統側または蓄電設備へ流せるかを考える。
4. 受入先・受入余力がなければ回生失効として整理する。
5. 有効利用できた電力量が外部供給削減へどうつながるかを電力量収支で確認する。

## §11 頻出ミス・ひっかけ
- `kW` と `kWh` を同じ量として扱う。
- 秒を時間へ直さず `W=Pt` に代入する。
- 発生電力が負荷より大きい区間と小さい区間を逆に読む。
- 余剰部分の面積を総発電電力量とする。
- `Wgen-Wsend` で求める自家消費量と、外部から受ける受電量を混同する。
- 自家消費比率の分母を総負荷電力量にする。
- 自給率の分母を総発電電力量にする。
- 二次電池を「放電だけを行う電池」と考える。
- 蓄電池があれば常に余剰を全量吸収できると断定する。実際には受入余力という条件がある。
- 回生した電力が常に他列車へ全量使われる、または常に系統へ戻ると断定する。

## §12 3段階例題

### 基礎例題 — 一定回生電力を電力量へ直す
学習用仮定値として、ある列車が `400 kW` で `90 s` 回生し、同時刻に近くの負荷が `250 kW` を消費しているとする。損失と蓄電設備の制約は無視し、余剰分は外部へ送れるものとする。回生電力量、負荷で使われる電力量、余剰電力量を求める。

まず時間を時間単位へ直す。

`t = 90/3600 = 0.025 h`

回生電力量は、

`Wreg = 400×0.025 = 10.0 kWh`

同時刻の負荷で使われる電力量は、

`Wload,use = 250×0.025 = 6.25 kWh`

余剰電力は `400-250=150 kW` なので、

`Wsurplus = 150×0.025 = 3.75 kWh`

検算すると、`6.25+3.75=10.0 kWh` で回生電力量と一致する。

### 本試験標準例題 — 三角形の発生曲線と一定負荷
学習用仮定値として、発生電力が `t=0 h` で `0 kW`、`t=2 h` で `400 kW`、`t=4 h` で `0 kW` と直線的に変化する。負荷は4時間を通じて `200 kW` 一定とする。送電電力量、受電電力量、自家消費電力量、自給率を求める。

総発生電力量は三角形面積より、

`Wgen = 1/2×4×400 = 800 kWh`

総負荷電力量は、

`Wload = 200×4 = 800 kWh`

発生電力と負荷電力の交点は `t=1 h, 3 h` である。`1〜3 h` は発生電力が負荷を上回る。余剰部分は左右2つの三角形なので、

`Wsend = 2×(1/2×1×200) = 200 kWh`

自家消費電力量は、

`Wself = 800-200 = 600 kWh`

総負荷は800 kWhなので、不足して外部から受ける電力量は、

`Wreceive = 800-600 = 200 kWh`

自給率は、

`600/800×100 = 75%`

となる。

### 複合・ひっかけ例題 — 送受電と二つの比率
学習用仮定値として、6時間を2時間ずつ3区間に分ける。各区間の発生電力と負荷電力は一定で、順に `100/250 kW`、`400/250 kW`、`200/300 kW` とする。系統との送受電は可能、蓄電池は使用しない。送電量、受電量、自家消費量、自家消費比率、自給率を求める。

総発生電力量は、

`Wgen = 100×2 + 400×2 + 200×2 = 1400 kWh`

総負荷電力量は、

`Wload = 250×2 + 250×2 + 300×2 = 1600 kWh`

第2区間だけ発生が負荷を上回るので、送電量は、

`Wsend = (400-250)×2 = 300 kWh`

第1・第3区間では不足するので、受電量は、

`Wreceive = (250-100)×2 + (300-200)×2 = 500 kWh`

自家消費量は、

`Wself = 1400-300 = 1100 kWh`

自家消費比率は発生量を分母にするため、

`1100/1400×100 ≈ 78.6%`

自給率は総負荷量を分母にするため、

`1100/1600×100 = 68.75%`

となる。二つの比率で分母が異なることがひっかけである。

## §13 新幹線への接続
本章では、新幹線が回生した電力を「時間変化する発生電力」とみなし、同時刻の他列車や設備を「負荷」とみなす。これにより、回生電力の利用先を電験の発電・負荷・系統との送受電・蓄電という一般問題へ置き換えられる。

新幹線の実回生電力、実蓄電池容量、実設備配置、具体的な回生融通方式は本sourceでは数値化しない。一次資料で確認していない実設備値を真値として扱わない。
