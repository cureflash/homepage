## ブラインド再解答

### R7上 電力 問12

初期径間 `S1=200 m`、初期弛度 `D1=3.0 m`。同じ電線で単位長さ当たり荷重と水平張力が同じなので、教材の `D∝S^2` を使う。

`D2 = 3.0 × (240/200)^2 = 4.32 m`

続いて電線実長式、

`L ≈ S + 8D^2/(3S)`

より、

`L2 ≈ 240 + 8×4.32^2/(3×240) = 240.20736 m`

したがって約 `240.21 m`。

独立答案: `(4)`。

### R6下 電力 問13

径間 `S=100 m`、30 ℃で弛度 `D0=2.0 m`。まず初期実長を求める。

`L0 ≈ 100 + 8×2.0^2/(3×100) = 100.1067 m`

温度上昇は `Δθ=60-30=30 ℃`、線膨張係数は `α=1.5×10^-5 /℃` なので、

`L1 = L0(1+αΔθ)`

`L1 ≈ 100.1067 × (1+1.5×10^-5×30) = 100.1517 m`

実長から新しい弛度を逆算する。

`D1 = √{3S(L1-S)/8}`

`D1 ≈ √{3×100×(100.1517-100)/8} ≈ 2.385 m`

したがって約 `2.39 m`。

独立答案: `(3)`。

### R3 電力 問16(a)

径間 `S=150 m`、-10 ℃で弛度 `D0=3.5 m`。初期実長は、

`L0 ≈ 150 + 8×3.5^2/(3×150) = 150.2178 m`

温度差は `Δθ=35-(-10)=45 ℃`、線膨張係数は `α=18×10^-6 /℃` なので、

`L1 = L0(1+αΔθ)`

`L1 ≈ 150.2178 × (1+18×10^-6×45) = 150.3395 m`

したがって約 `150.34 m`。

独立答案: `(4)`。

### R3 電力 問16(b)

(a)で求めた温度上昇後の実長から新しい弛度を求める。

`D1 = √{3×150×(150.3395-150)/8} ≈ 4.370 m`

単位長さ当たり荷重 `w=20 N/m` より、水平張力は、

`T = wS^2/(8D)`

`T ≈ 20×150^2/(8×4.370) ≈ 1.287×10^4 N`

選択肢では `12863 N` が対応する。

独立答案: `(2)`。

### H29 電力 問8

同じ電線なので `w` は共通で、教材の `T∝S^2/D` を使う。

`T2/T1 = (S2/S1)^2 × (D1/D2)`

`T2/T1 = (200/180)^2 × (3.0/4.0) = 0.9259`

したがって新しい水平張力は元の約 `92.6 %`。

独立答案: `(2)`。

### H24 電力 問13

径間 `S=100 m`、30 ℃で弛度 `D0=2.0 m`。教材の温度問題標準手順どおり、

`L0 ≈ 100 + 8×2.0^2/(3×100) = 100.1067 m`

`L1 ≈ 100.1067 × (1+1.5×10^-5×30) = 100.1517 m`

`D1 = √{3×100×(100.1517-100)/8} ≈ 2.385 m`

したがって約 `2.39 m`。

独立答案: `(3)`。
