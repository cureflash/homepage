## 解説本文

## §1 このテーマで電験は何を問うか
Topic 12の中心は、架線の種類を覚えることではなく、支持点間に張られた電線の弛度・実長・張力・温度伸縮を計算できるようにすることである。

本試験では主に次を問われる。

1. 径間、単位長さ当たり荷重、水平張力から弛度を求める。
2. 径間や張力が変わったとき、比例関係から新しい弛度や張力比を求める。
3. 弛度から電線実長を求め、逆に実長から弛度を求める。
4. 温度変化による電線伸縮を実長へ反映し、新しい弛度を求める。
5. 弛度から水平張力を逆算する。

この章を終えると、固定5問・6答案要素で要求される一連の逆算を、問題文の条件から組み立てられることを目標とする。

## §2 用語と記号
同じ高さの二つの支持点に電線が張られている基本モデルを考える。

- `S [m]`: 径間。二つの支持点間の水平距離。
- `D [m]`: 弛度。支持点を結ぶ水平線から電線の最下点までの距離。
- `w [N/m]`: 電線に作用する単位長さ当たりの均一荷重。
- `T [N]`: 水平張力。弛度公式で用いる水平方向の張力成分。
- `L [m]`: 支持点間に存在する電線の実長。
- `α [1/℃]`: 線膨張係数。
- `Δθ [℃]`: 温度差。`新温度−旧温度` とする。

自重だけを考える場合、`w` は電線の単位長さ当たり重量である。風圧や着雪を考える場合は、問題文で与えられた荷重を単位長さ当たり荷重へそろえて扱う。

## §3 弛度公式と成立条件
弛度が径間に比べて十分小さく、荷重が径間に沿って一様、支持点が同一高さという近似では、電線形状を放物線として扱い、

`D = wS^2 / (8T)`

を使う。

この式から、他条件が同じなら、

- `D ∝ w`
- `D ∝ S^2`
- `D ∝ 1/T`

である。

したがって径間が2倍なら弛度は4倍、張力が2倍なら弛度は1/2になる。径間を一次比例で扱うのが典型的な誤りである。

単位確認は、

`(N/m)×m^2/N = m`

となり、弛度の単位がmになる。

## §4 弛度・張力・径間を相互に逆算する
弛度公式は未知量に応じて変形する。

水平張力を求めるなら、

`T = wS^2 / (8D)`

単位長さ当たり荷重を求めるなら、

`w = 8TD / S^2`

である。

同じ電線で `w` が変わらない二つの状態を比べると、

`D1/D2 = (S1^2/T1) / (S2^2/T2)`

したがって張力比は、

`T2/T1 = (S2/S1)^2 × (D1/D2)`

と書ける。比の問題では、数値を最初から全部代入するより、`T∝S^2/D` の比例関係を先に作ると誤りを減らせる。

## §5 電線実長
弛度があるため、支持点間の電線実長 `L` は径間 `S` より少し長い。弛度が小さい放物線近似では、

`L ≈ S + 8D^2/(3S)`

を使う。

補正項 `8D^2/(3S)` は必ず正なので `L>S` になる。この大小関係は計算後の検算に使える。

実長から弛度を逆算するときは、

`L-S = 8D^2/(3S)`

より、

`D = √{3S(L-S)/8}`

である。

`D` と `L` は別の量であり、温度問題ではまず実長を求めてから新しい弛度へ戻す。

## §6 温度変化と線膨張
温度による電線の長さ変化は、問題文が線膨張だけを考える条件なら、

`ΔL = αLΔθ`

で求める。

- 温度上昇: `Δθ>0` なので `ΔL>0`。
- 温度低下: `Δθ<0` なので `ΔL<0`。
- `α` が `×10^-6 /℃` で与えられたら、必ず `10^-6` を含めて代入する。

新しい実長は、

`L_new = L_old + ΔL = L_old(1+αΔθ)`

である。

問題文で「張力による伸びを無視する」と指定されている場合、弾性伸びを勝手に追加しない。逆に、固定範囲外の材料定数を仮定して補うこともしない。

## §7 温度問題の標準解法
温度上昇後の弛度を求める標準手順は次のとおり。

1. 初期径間 `S` と初期弛度 `D0` を確認する。
2. `L0≈S+8D0^2/(3S)` で初期実長を求める。
3. `ΔL=αL0Δθ` で温度による伸長量を求める。
4. `L1=L0+ΔL` で新しい実長を求める。
5. `D1=√{3S(L1-S)/8}` で新しい弛度を求める。
6. 必要なら `T1=wS^2/(8D1)` で新しい水平張力を逆算する。

温度上昇で実長が増え、径間が固定なら、他の条件を問題文どおり扱う限り弛度は増える方向になる。計算結果が逆なら温度差の符号や実長式を確認する。

## §8 複合問題の解法アルゴリズム
固定過去問の複合形は、次の順序にそろえると解きやすい。

```text
初期弛度 D0
↓
初期実長 L0
↓
温度変化による ΔL
↓
新実長 L1
↓
新弛度 D1
↓
必要なら新水平張力 T1
```

径間変更が先にある場合は、まず `D∝S^2/T` で新しい弛度を求め、その状態の実長を計算する。どの状態の `S,D,L,T` を使っているかを添字で区別する。

## §9 風圧荷重・着雪
着雪は鉛直方向の単位長さ当たり荷重を増やす。風圧荷重が水平方向に作用し、鉛直荷重 `w_v` と水平荷重 `w_h` が同時に与えられる基本問題では、合成荷重の大きさを、

`w = √(w_v^2 + w_h^2)`

として扱える。

この `w` が大きくなると、同じ径間・水平張力なら `D=wS^2/(8T)` により荷重合成方向の弛度も大きくなる。問題文が鉛直弛度・水平偏位を別々に求める条件なら各荷重成分を分けるが、本章では与えられた均一荷重を弛度・張力へ接続する基本までとする。

地域別の法定風圧荷重値、支持物設計、支線設計はこのTopicでは追加しない。

## §10 波動伝播の基本
張力を持つ理想的な線では、横波の伝播速度 `c` は基本的に、

`c = √(T/μ)`

で表される。ここで `T [N]` は張力、`μ [kg/m]` は線密度である。

この関係から、他条件が同じなら張力を大きくすると波動速度は上がり、線密度を大きくすると波動速度は下がる。実際の架線系は単純な一本の理想弦ではないため、この式だけで実設備の集電性能を決めることはできない。本章では「張力と線の質量が disturbance の伝わり方に関係する」という基本物理への接続に限る。

## §11 高速集電への接続
パンタグラフが架線に接触しながら高速で移動すると、接触点で架線に機械的な変位が生じ、その影響が線上を伝わる。したがって架線を電気導体としてだけでなく、張力を持つ機械系として考える必要がある。

320km/hという題材は、この必要性を具体化する入口である。電験三種で直接問われる中心は、弛度・径間・張力・実長・温度伸縮であるため、教材の主題はそこに置く。

パンタグラフ制御、空力、実車の接触力、架線方式ごとの詳細構造、未確認の架線張力・波動速度・構成寸法は扱わない。また、列車速度と `c=√(T/μ)` の大小だけで集電可否を判定しない。

## §12 本試験での解法手順

### A. 弛度・張力・径間
1. `w,S,T,D` のうち既知量と未知量を整理する。
2. 均一荷重、同一高さ支持点、小弛度近似の条件を確認する。
3. `D=wS^2/(8T)` を未知量について変形する。
4. 比較問題なら `D∝wS^2/T` を先に使う。
5. 径間を二乗したか、単位をそろえたか確認する。

### B. 実長・温度伸縮
1. `L0≈S+8D0^2/(3S)` で初期実長を求める。
2. `Δθ=新温度−旧温度` を確認する。
3. `ΔL=αL0Δθ` を求める。
4. `L1=L0+ΔL` とする。
5. `D1=√{3S(L1-S)/8}` で新弛度を求める。
6. 必要なら `T1=wS^2/(8D1)` へ進む。

### C. 風圧・着雪・波動
1. 荷重が鉛直か水平かを確認する。
2. 直交する均一荷重が同時に与えられたら `√(w_v^2+w_h^2)` で合成する。
3. 合成荷重を弛度・張力式へ接続する。
4. 波動速度は基本関係 `c=√(T/μ)` の方向性を確認する。
5. 実車固有値や固定範囲外の設計条件を推測して追加しない。

## §13 頻出ミス
- 径間が2倍になったとき弛度も2倍とする。正しくは同一`w,T`なら4倍。
- `T=wS^2/(8D)` の `S^2` を落とす。
- 弛度 `D` と電線実長 `L` を混同する。
- `L≈S+8D^2/(3S)` の補正項を落とす。
- 温度上昇なのに `Δθ` を負にする。
- `α=12×10^-6 /℃` の `10^-6` を落とす。
- mmをmへ直さず混在させる。
- 問題文が無視するとした張力による伸びを追加する。
- 風圧荷重と自重を単純加算し、方向が直交する条件を無視する。
- 理想弦の波動速度だけで実際の高速集電可否を断定する。

## §14 3段階例題

### 例題1 基礎 — 弛度と実長
単位長さ当たり荷重 `w=10 N/m`、径間 `S=50 m`、水平張力 `T=12.5 kN` の電線について、弛度 `D` と近似実長 `L` を求める。

まず張力をNへそろえる。

`T=12.5 kN=12500 N`

弛度は、

`D = 10×50^2 / (8×12500)`

`= 25000/100000`

`= 0.250 m`

である。

実長は、

`L ≈ 50 + 8×0.250^2/(3×50)`

`= 50 + 0.00333`

`≈ 50.0033 m`

である。`L>S` になっているので大小関係も妥当である。

### 例題2 本試験標準 — 温度上昇後の弛度
径間 `S=80 m`、初期弛度 `D0=0.800 m` の電線がある。線膨張係数を `α=12×10^-6 /℃`、温度上昇を `30℃` とする。支持点間距離は変わらず、張力による伸びは無視する。温度上昇後の弛度 `D1` を求める。

初期実長は、

`L0 ≈ 80 + 8×0.800^2/(3×80)`

`= 80.02133 m`

である。

温度による伸長量は、

`ΔL = 12×10^-6 × 80.02133 × 30`

`≈ 0.02881 m`

したがって新実長は、

`L1 = 80.02133 + 0.02881`

`= 80.05014 m`

である。

実長式を逆算すると、

`D1 = √{3×80×(80.05014-80)/8}`

`≈ 1.226 m`

となる。温度上昇で実長が増え、固定径間のもとで弛度が `0.800 m` から増えているので方向性も妥当である。

### 例題3 複合・ひっかけ — 着雪・風圧と波動伝播
電線自重による鉛直荷重が `10 N/m`、着雪による鉛直荷重が `2 N/m`、水平風圧荷重が `5 N/m` とする。径間 `S=60 m` で、合成荷重方向の弛度を `0.390 m` 以下にするために必要な水平張力を求める。さらに、線密度を `μ=1.30 kg/m` とした理想弦モデルで波動速度を求める。

鉛直荷重は、

`w_v = 10 + 2 = 12 N/m`

水平荷重は、

`w_h = 5 N/m`

なので、合成荷重は、

`w = √(12^2+5^2) = 13 N/m`

である。

必要張力は、

`T = wS^2/(8D)`

`= 13×60^2/(8×0.390)`

`= 15000 N = 15.0 kN`

である。

参考として風がなく鉛直荷重 `12 N/m` だけなら、同じ張力で、

`D = 12×60^2/(8×15000) = 0.360 m`

となる。風圧を含めた合成荷重の増加で弛度が増える方向が確認できる。

理想弦モデルの波動速度は、

`c = √(T/μ)`

`= √(15000/1.30)`

`≈ 107 m/s`

である。この数値は例題の仮定値から得た計算値であり、新幹線実設備の波動速度ではない。また、この波動速度と列車速度の大小だけで実際の集電可否を判定しない。
