# 解説本文

## 1. このテーマで電験は何を問うか
電験三種「電力」の原子力分野では、原子炉の細かな設計を暗記するより、次の4系統を結び付けて判断できることが重要である。

1. 原子核の質量欠損から `E=Δmc²` で核分裂エネルギーを計算する。
2. U-235、中性子、連鎖反応、制御棒の役割を説明する。
3. PWRとBWRの冷却材・蒸気系統・主要設備の違いを判別する。
4. 原子炉熱出力、発電端出力、熱効率、原子力用蒸気タービンの特徴を計算・正誤判定する。

この章では、これらを原子力船「むつ」のPWRを入口に一つのエネルギー変換としてつなぐ。

## 2. 質量欠損と核分裂エネルギー
原子核は陽子と中性子からできている。原子核として結合した後の質量は、ばらばらの陽子と中性子の質量を単純に合計した値よりわずかに小さい。この差を質量欠損 `Δm` といい、結合エネルギーと対応する。

核分裂前後で質量が減少したとき、その質量差に対応するエネルギーは

`E = Δm c²`

で求める。

- `E`: エネルギー `[J]`
- `Δm`: 質量欠損 `[kg]`
- `c`: 光速 `[m/s]`。計算では通常 `3.0×10^8 m/s`

電験で重要なのは桁と単位である。`g` をそのまま式へ入れず `kg` へ直す。発熱量が `kJ/kg` や `MJ/kg` で与えられたら、核分裂エネルギー側も同じエネルギー単位へそろえてから割る。

燃料全体の質量を `mf`、その中のU-235質量割合を `x`、U-235のうち質量欠損となる割合を `r` とすると、問題文の条件から

`m235 = mf x`

`Δm = m235 r = mf x r`

`E = mf x r c²`

と段階的に処理できる。`x` と `r` を百分率のまま掛けないことが重要である。

## 3. U-235、連鎖反応、制御棒
U-235の原子核が中性子を吸収して核分裂すると、エネルギーと新たな中性子が生じる。その中性子が別のU-235へ核分裂を起こし、反応が次々に続くのが連鎖反応である。

原子炉では、この反応を必要な出力に保つため中性子の数を制御する。制御棒は中性子を吸収する役割を持ち、挿入を深くすれば核分裂を起こす中性子が減る方向、引き抜けば増える方向に作用する。

軽水炉ではU-235の割合を天然ウランより高めた低濃縮ウラン燃料を用いる。ここでは濃縮工程や核燃料サイクルへは広げず、「核分裂しやすいU-235の割合を高めて燃料として使う」という試験上必要な関係だけを扱う。

## 4. 原子力発電は汽力発電の熱源を原子炉に置き換えたもの
火力の汽力発電は、燃料を燃やしてボイラで蒸気を作り、蒸気タービンを回し、同期発電機で電気へ変える。

原子力発電でもタービン以降の基本的なエネルギー変換は同じで、熱を作る部分が原子炉になる。

`核分裂 → 原子炉熱 → 冷却材 → 蒸気 → 蒸気タービン → 同期発電機 → 電力`

したがって、電験では原子炉を「汽力発電のボイラに相当する熱源」と対応させると整理しやすい。

同期発電機は蒸気タービンの機械出力を交流電力へ変換する。ここで、原子炉熱出力と発電端電気出力は同じものではない。タービン・発電機等で損失があるため、電気出力は熱出力より小さい。

## 5. PWRとBWR
軽水炉では軽水を冷却材として使う。試験ではPWRとBWRの蒸気の作り方を区別する。

### PWR: 加圧水型
PWRでは一次冷却材を高圧にして、原子炉内で沸騰しにくくする。原子炉で加熱された一次冷却材は蒸気発生器へ熱を渡し、二次側の水を蒸気にする。

`原子炉 → 一次冷却材 → 蒸気発生器 → 二次側蒸気 → タービン`

識別点は次のとおり。
- 加圧器がある。
- 蒸気発生器がある。
- 一次冷却材ポンプで一次系を循環させる。
- 原子炉内の一次冷却材をそのままタービンへ送らない。

「むつ」はこのPWRである。一次冷却系運転圧力110 kg/cm²G、蒸気発生器2基という実在仕様も、この系統構成と整合する。

### BWR: 沸騰水型
BWRでは原子炉内で水を沸騰させ、発生した蒸気を直接タービンへ送る。

`原子炉 → 蒸気 → タービン`

PWRのような一次系と二次系を熱交換する蒸気発生器は用いない。試験では再循環系・再循環ポンプと組み合わせて問われることがある。

### 判別法
問題文に「加圧器」「蒸気発生器」「一次側と二次側」が出ればPWRを疑う。「原子炉で発生した蒸気を直接タービンへ送る」「再循環系」が出ればBWRを疑う。

## 6. 原子力用蒸気タービンの特徴
電験では原子力発電所と一般的な火力発電所の蒸気条件の違いが問われる。

原子力側では高圧タービン入口が飽和蒸気であることが基本で、火力の高温・高圧な過熱蒸気に比べて圧力・温度が低い。そのため熱効率も火力より低く、同じ電気出力を得るにはより多くの蒸気を扱う必要がある。

高圧タービンで仕事をした後の蒸気は湿分を含みやすい。湿分はタービン翼を侵食するため、湿分分離器で除去して低圧タービンへ送る。低圧タービンの最終段は長大翼となり、湿分による翼侵食を抑えるため翼先端周速度を下げる必要がある。このため本試験では原子力用タービンの代表的回転速度として `1500 min^-1` または `1800 min^-1` が問われる。

「むつ」の蒸気発生器は蒸気圧力40 kg/cm²G、蒸気温度250.6 ℃、乾き度99.75%であり、実在するPWR蒸気系の具体例として使える。ただし大型発電所のタービン定格値と混同しない。

## 7. 原子炉熱出力・発電端出力・熱効率
原子炉が単位時間に発生する熱を原子炉熱出力 `Pth`、発電機端子で得られる電気出力を発電端出力 `Pe` とする。

両方を同じ出力単位にそろえれば、発電端までの熱効率は

`η = Pe / Pth`

で表せる。

逆算は

`Pe = η Pth`

`Pth = Pe / η`

である。

一定時間 `t` を考えるなら、エネルギーでも同じ比になる。

`Ee = η Eth`

ここで `W`、`kW`、`MW` は出力、`Wh`、`kWh`、`MWh`、`J` はエネルギーである。出力とエネルギーを混同しない。

電力量へ変換するときは

`1 kWh = 3.6×10^6 J`

`1 MWh = 3.6×10^9 J`

を使う。

## 8. 核分裂エネルギー計算の解法手順
質量欠損型の計算は次の順で固定すると誤りにくい。

1. 燃料全体の質量をkgへそろえる。
2. U-235の質量割合を掛け、U-235質量を出す。
3. 問題文で与えられた質量欠損割合を掛け、`Δm [kg]` を出す。
4. `E=Δmc²` で熱エネルギー `[J]` を求める。
5. 燃料等価量なら発熱量の単位へそろえて `E/H` を計算する。
6. 電気エネルギーなら熱効率を掛けて `Ee=ηE` とする。
7. 必要なら `3.6×10^6 J/kWh` で割ってkWhへ変換する。
8. 選択肢の桁と単位を確認する。

## 9. 架空の「原子力新幹線」へ接続する
東京駅を出発する架空列車には、「むつ」で確認されたPWR原子炉・一次冷却系・蒸気発生系を流用する設定とする。

実在仕様として使えるのは、少なくとも次である。
- 加圧水型原子炉1基
- 原子炉熱出力36 MWth
- 一次冷却水平均温度273.5 ℃
- 一次冷却系運転圧力110 kg/cm²G
- 蒸気発生器2基
- 蒸気圧力40 kg/cm²G
- 蒸気温度250.6 ℃、乾き度99.75%
- 蒸気流量合計61.2 t/h

実在の「むつ」では、この蒸気で主機タービンを回して船を推進した。教材上の列車では、その後段を同期発電機へ接続し、得られた電力で主電動機を動かす架空設定である。

したがって教材上のエネルギーの流れは

`U-235の核分裂 → 36 MWth級の原子炉熱 → 一次冷却材 → 蒸気発生器 → 蒸気 → 蒸気タービン → 同期発電機 → 電力 → 主電動機`

となる。36 MWthは確認済み実在値だが、列車の発電端出力や走行性能は本章で新たに仮定しない。

博多で1435 mmから1067 mmへ軌間変更する設定は物語上の接続であり、原子力発電の試験計算には混ぜない。

# 3段階例題

## 基礎例題: PWRとBWRを見分ける
次の設備構成A、BをPWR/BWRに分類せよ。

- A: 原子炉で加熱した高圧の一次冷却材を蒸気発生器へ送り、二次側の蒸気でタービンを回す。加圧器を備える。
- B: 原子炉内で発生した蒸気を直接タービンへ送り、再循環系を備える。

### 解法
Aは「加圧器」「蒸気発生器」「一次側と二次側」があるのでPWR。

Bは「原子炉で発生した蒸気を直接タービンへ送る」のでBWR。

答え: `A=PWR、B=BWR`

この判別はH27電力問4型の穴埋めにそのまま使える。

## 本試験標準例題: 質量欠損から石炭相当量を求める
U-235を1.00 g核分裂させ、その質量の0.090%が質量欠損になるとする。光速を `3.0×10^8 m/s`、石炭の発熱量を `30 MJ/kg` とすると、発生する核分裂エネルギーは石炭何kg分に相当するか。

### 解法
まずgをkgへ直す。

`1.00 g = 1.00×10^-3 kg`

質量欠損率は

`0.090% = 9.0×10^-4`

したがって

`Δm = 1.00×10^-3 × 9.0×10^-4 = 9.0×10^-7 kg`

`E = Δmc²`

`= 9.0×10^-7 × (3.0×10^8)²`

`= 8.1×10^10 J`

石炭の発熱量は

`30 MJ/kg = 3.0×10^7 J/kg`

なので

`m = 8.1×10^10 / 3.0×10^7 = 2.7×10^3 kg`

答え: `2.7×10^3 kg = 2.7 t`

重要なのは、質量欠損率を百分率から小数へ直し、エネルギーと発熱量の単位をそろえてから割ることである。

## 複合・ひっかけ例題: 燃料中U-235→核分裂熱→電力量
1.00 kgのウラン燃料中にU-235が4.0%含まれ、そのU-235がすべて核分裂するとする。核分裂したU-235質量の0.090%が質量欠損となり、熱エネルギーの32%を発電端電力量として取り出せるとする。`c=3.0×10^8 m/s` とすると、発電端電力量は何MWhか。

### 解法
U-235質量は

`m235 = 1.00 × 0.040 = 0.040 kg`

質量欠損は

`Δm = 0.040 × 0.00090 = 3.6×10^-5 kg`

核分裂熱は

`Eth = Δmc²`

`= 3.6×10^-5 × (3.0×10^8)²`

`= 3.24×10^12 J`

発電端で取り出す電気エネルギーは

`Ee = 0.32 × 3.24×10^12 = 1.0368×10^12 J`

`1 MWh = 3.6×10^9 J` なので

`Ee = 1.0368×10^12 / 3.6×10^9 = 288 MWh`

答え: `288 MWh`

ひっかけは、燃料1 kg全部に0.090%を掛けること、熱効率32%を掛け忘れること、JをkWh/MWhへ変換し忘れることである。

# 頻出ミス
1. `g` のまま `E=Δmc²` へ代入する。必ずkgへ変換する。
2. `0.090%` を `0.090` と扱う。正しくは `0.00090`。
3. 燃料全質量とU-235質量を混同する。先にU-235割合を掛ける。
4. 原子炉熱出力 `Pth` と発電端出力 `Pe` を同一視する。
5. PWRで原子炉内の一次冷却材がそのままタービンへ行くと考える。
6. BWRにもPWRと同じ蒸気発生器があると考える。
7. 原子力用蒸気タービンを火力と同じ高温高圧の過熱蒸気・同じ蒸気量と考える。
8. 「むつ」の主機タービン出力と、架空列車の同期発電機出力を同じ実在値として扱う。本教材では後者の実値を設定していない。
