## 2. H30 電力 問8

Topic 06教材の変圧比

`V1 / V2 = N1 / N2`

より、実際の一次線間電圧は

`V1 = 200 × 6600 / 210 = 6285.7 V`

`P = √3 V_L I_L cosφ`

を用いると、

`P = √3 × 6285.7 × 20 × 0.8`

`≈ 174.2 kW`

最も近い選択肢は174 kW。

## 3. H22 理論 問9

Y結線の対称三相電源にY結線の平衡三相抵抗負荷を接続した場合の正誤問題。

Topic 07教材より、

- `V_L = √3 V_phase`
- `I_L = I_phase`
- 抵抗負荷なので `I_phase = V_phase / R`
- 三相全体の有効電力は `P = 3 V_phase I_phase`（力率1）
- 平衡Y結線では中性線電流0

が成り立つ。

したがって、`P = √3 V_phase I_phase` とする選択肢(4)だけが誤り。正しくは `P = 3 V_phase I_phase`。
