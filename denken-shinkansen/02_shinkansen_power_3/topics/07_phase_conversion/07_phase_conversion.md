# 解説本文

## 1. このテーマで電験は何を問うか
このテーマでは、三相交流の線間値・相値と三相電力を計算できること、三相電源から大容量の単相負荷を取るときに負荷平衡が問題になる理由を説明できること、スコット結線の基本的な構成と二次側の位相関係を判定できることを目標とする。

新幹線は架線から単相交流を受け取る。一方、電力会社側の大規模な電力系統は三相交流である。そのため新幹線変電所では、単なる降圧だけでなく、三相側と単相き電側をつなぐ相変換が必要になる。

この章を終えた時点で、次を判断できればよい。

1. 線間電圧と相電圧を区別して式を選べる。
2. 平衡三相の有効電力を線間値から計算できる。
3. 大容量単相負荷を三相の一相だけへ集中させる問題点を説明できる。
4. スコット結線が三相から二つの単相出力を得る結線であると説明できる。
5. スコット二次の2回路が90°位相差であると判定できる。
6. 変形ウッドブリッジ結線とルーフ・デルタ結線を、新幹線用き電変圧器の相変換方式として概略比較できる。

## 2. 三相交流と単相交流
単相交流は、一つの交流電圧で負荷へ電力を供給する方式である。新幹線の車両は架線と帰路側の間に与えられる単相交流を受け取る。

三相交流は、同じ大きさ・同じ周波数で、互いに120°ずつ位相の異なる三つの交流を一組として扱う。平衡していれば三相を対称に使えるため、大電力の送配電に適している。

したがって、新幹線変電所では次の変換が必要になる。

```text
電力会社側
三相交流
   ↓
き電用変圧器
   ↓ 相変換
単相交流A回路  ＋  単相交流B回路
   ↓                  ↓
新幹線き電区間    新幹線き電区間
```

ここで重要なのは、「三相のうち適当な一相だけを大容量の鉄道負荷へ接続すればよい」とはしないことである。負荷が一相へ偏れば三相側の電流が不平衡になるため、二つの単相回路へ分けて負荷を分担し、三相側への偏りを抑える。

## 3. 線間電圧と相電圧
三相問題では、まず問題文の電圧が線間電圧か相電圧かを確認する。

Y結線では、線間電圧 `V_L` と相電圧 `V_phase` の大きさに次の関係がある。

`V_L = √3 V_phase`

したがって、

`V_phase = V_L / √3`

である。

Y結線では線電流と相電流は等しい。

`I_L = I_phase`

Δ結線では線間電圧と相電圧が等しい。

`V_L = V_phase`

また、平衡したΔ結線では線電流は相電流の `√3` 倍になる。

`I_L = √3 I_phase`

この章では複雑なベクトル導出は行わない。電験三種では、YかΔかを図から判定し、線間値と相値を混同しないことを優先する。

## 4. 平衡三相の有効電力
平衡三相負荷の有効電力は、各相の有効電力を3相分加えたものになる。

`P = 3 V_phase I_phase cosφ`

線間電圧と線電流で表すと、Y結線でもΔ結線でも平衡三相全体について次の式を使える。

`P = √3 V_L I_L cosφ`

- `P`: 三相有効電力 [W]
- `V_L`: 線間電圧 [V]
- `I_L`: 線電流 [A]
- `cosφ`: 力率

解法では、先に結線と「線間/相」を整理してから式を選ぶ。`√3` を機械的に掛けるのではなく、三相全体の式なのか一相分の式なのかを確認する。

## 5. 三相の一相だけに大容量単相負荷を接続するとどうなるか
平衡三相では、三つの相が対称に負荷を分担する。ところが、大容量の単相負荷を三相の一部だけへ集中させると、各相の電流がそろわなくなる。

新幹線のような大容量単相負荷では、この偏りを小さくすることが重要になる。そのため、き電用変圧器で三相から二つの単相回路を取り出し、二次側の二回路の負荷をできるだけ平衡させる。

この章では、不平衡率の数値計算や対称座標法は扱わない。試験上は「単相負荷の偏りが三相側不平衡につながる」「二つの単相回路へ分けて負荷を平衡させることが三相側不平衡の抑制につながる」という因果関係を押さえる。

## 6. スコット結線
スコット結線は、M変圧器とT変圧器の2台の単相変圧器を組み合わせ、三相交流から大きさの等しい二つの単相出力を取り出す代表的な相変換方式である。

概念図は次のように捉える。

```text
三相 U ─────────┐
                 │
三相 V ── M変圧器 ── 単相M座
          中点O
            │
            └─ T変圧器 ── 単相T座
                 │
三相 W ─────────┘
```

M変圧器の一次巻線中央にT変圧器の一次側を接続する構成により、二次側には互いに90°位相の異なる二つの単相電圧を得る。

ここが頻出判定点である。

- 180°ではない。
- 90°である。
- 二つの単相側負荷を平衡させると、三相側の不平衡を抑えられる。

基本的な巻数関係では、M側一次巻線全体の巻数を `N_M` とすると、同じ大きさの二次電圧を得るためのT側一次巻数は

`N_T = (√3 / 2) N_M`

に対応する。

数値としては `√3/2 ≈ 0.866` である。二種相当のベクトル導出までは行わず、三種では「T側一次がM側全巻数の約0.866倍」「二次2回路は90°」を基本関係として使う。

## 7. なぜ単相2回路を取り出すのか
スコット結線の目的は、単に「三相を単相へ変える」だけではない。二つの単相回路を作り、それぞれの負荷をできるだけ等しくすることで、一次の三相電源から見た負荷の偏りを抑えることに意味がある。

二次側A回路だけが大きな負荷、B回路がほぼ無負荷なら、三相側も理想的な平衡状態から外れる。反対にA/Bの負荷が同程度なら、三相側の不平衡を小さくできる。

したがって、正誤問題では次の組合せを一体で覚える。

`三相 → 二つの単相（直交二相） → 二次負荷を平衡 → 三相側不平衡を抑制`

## 8. 新幹線用き電変圧器の相変換方式
鉄道・運輸機構の公開資料では、新幹線変電所は電力会社から受電した特別高圧・超高圧の三相交流を、き電用変圧器で列車運転に必要な単相交流へ変換すると説明されている。

### スコット結線
交流き電用変圧器として広く用いられる方式である。三相から二つの単相回路を取り出し、両側の負荷を平衡させることで三相側不平衡を抑える。

### 変形ウッドブリッジ結線
新幹線で大容量電源を確保するため、超高圧受電へ適用する方式として開発・導入された。鉄道・運輸機構の説明では、一般的なスター・デルタ結線の組合せで構成しやすく、中性点電流の抑制もしやすい。一方、二次側A座・B座の出力電圧をそろえるため、B座側に別の昇圧変圧器を必要とする。
### ルーフ・デルタ結線
変形ウッドブリッジ結線で必要だった別置きの昇圧変圧器を不要にできる方式として実用化された。巻線構造を簡素化し、小型・軽量・低損失化を狙える。

この章では、三方式の厳密なベクトル解析や巻線設計までは扱わない。試験・教材上の比較点は次の範囲に限定する。

| 方式 | この章で押さえる点 |
|---|---|
| スコット | 三相→二つの単相、二次90°、二次負荷平衡で三相側不平衡を抑える |
| 変形ウッドブリッジ | 新幹線の超高圧受電で使われてきた相変換方式。B座側に昇圧変圧器を要する |
| ルーフ・デルタ | 別置き昇圧変圧器を不要にし、構造簡素化・小型軽量・低損失化を狙う |

## 9. 問題を見たときの解法手順

### 三相計算
1. 結線がYかΔか確認する。
2. 問題文の電圧・電流が線間値か相値か確認する。
3. 必要ならYの `V_phase=V_L/√3`、Δの `V_phase=V_L` を使う。
4. 一相分を計算するのか、三相全体を計算するのか決める。
5. 三相全体の有効電力なら `P=√3 V_L I_L cosφ` を使う。
6. 単位をV、A、Wへそろえ、最後にkW等へ換算する。
7. `√3` の付け忘れ・二重掛けがないか確認する。

### スコット結線の正誤判定
1. 三相から二つの単相を取り出す結線か確認する。
2. M/T変圧器2台という構成を確認する。
3. 二次側2回路の位相差は90°と判断する。
4. T側一次巻数の基本比が `√3/2` か確認する。
5. 二次側負荷を平衡させると三相側不平衡を抑えられると判断する。
6. 180°、単相1回路だけを得る、三相側不平衡を必ず増やす、などの記述を誤り候補として判定する。

# 3段階例題

## 例題1 基礎: 線間電圧から相電圧を求める
平衡三相Y結線で、線間電圧が200 Vである。相電圧を求めよ。

### 解法
Y結線では

`V_L = √3 V_phase`

なので、

`V_phase = V_L / √3`

`= 200 / √3`

`≈ 115.5 V`

答え: 約115 V。

### 検算
Y結線では線間電圧の方が相電圧より大きい。115.5 Vは200 Vより小さいので大小関係も妥当である。

## 例題2 本試験標準: 三相有効電力
線間電圧6.6 kV、線電流100 A、力率0.90の平衡三相負荷がある。三相有効電力を求めよ。

### 解法
三相全体の線間電圧・線電流が与えられているので、

`P = √3 V_L I_L cosφ`

を使う。

`P = √3 × 6600 × 100 × 0.90`

`≈ 1.029 × 10^6 W`

`≈ 1.03 MW`
答え: 約1.03 MW。

### 検算
皮相電力は `√3×6.6kV×100A≈1.143MVA`。力率0.90なので有効電力はその90%の約1.03 MWとなり整合する。

## 例題3 複合・ひっかけ: スコット結線
M変圧器の一次全巻数が1000巻のスコット結線を考える。次の問いに答えよ。

1. 同じ大きさの二次電圧を得るためのT変圧器一次巻数はいくらか。
2. M座とT座の二次電圧の位相差はいくらか。
3. M座とT座の負荷を同程度にすると、三相一次側の不平衡はどうなるか。

### 解法
T側一次巻数は

`N_T = (√3/2)N_M`

なので、

`N_T = 0.866 × 1000 ≈ 866巻`

二次側2回路は直交するため位相差は90°である。180°ではない。

M座・T座の負荷を同程度にすると、三相一次側の電流の偏りを抑えられる。

答え:
1. 約866巻
2. 90°
3. 三相側不平衡を抑えられる

### ひっかけ
- `√3` 倍の1732巻としない。
- 位相差を180°としない。
- 「単相負荷だから三相側の平衡とは無関係」と考えない。

# 頻出ミス・ひっかけ
- Y結線で `V_L=V_phase` としてしまう。
- Δ結線で `V_L=√3V_phase` としてしまう。
- 一相分の電力と三相合計電力を混同する。
- `P=√3V_LI_Lcosφ` へ相電圧を代入する。
- スコット二次2回路を180°位相差と覚える。
- T側一次巻数をM側と同じとする。
- 三相の一相だけから大容量単相負荷を取っても平衡は崩れないと判断する。
- 変形ウッドブリッジ結線・ルーフ・デルタ結線について、SPECにない厳密ベクトル関係や未確認設備定格まで暗記対象にする。
