# 解説本文

## 1. このテーマで電験は何を問うか
電験三種「電力」の水力発電では、水の位置エネルギーから取り出せる電力、落差・流量・効率の扱い、揚水発電、管路の流速と圧力、水車の種類が問われる。単に `P=9.8QH` を暗記するのではなく、どの落差を使うか、効率を掛けるか割るか、電力と電力量をどう区別するかまで判断できる必要がある。

この章を終えた時点で、次を自力で処理できることを目標とする。

1. 流量と落差から理論水力を求める。
2. 損失水頭を考慮して有効落差を決める。
3. 水車効率・発電機効率から発電出力を求める。
4. 揚水時の必要入力、必要時間、総合効率を求める。
5. 流域面積・降水量・流出率から年間水量と発電電力量を求める。
6. 連続の式とベルヌーイの定理を組み合わせて流速・圧力を求める。
7. 衝動水車と反動水車、代表的な水車形式を区別する。

## 2. 水が持つエネルギーと流量
高さ `H[m]` にある質量 `m[kg]` の水が持つ位置エネルギーは

`E = mgH [J]`

である。水が毎秒 `Q[m^3/s]` 流れるとき、水の密度を `ρ[kg/m^3]` とすれば毎秒流れる質量は `ρQ[kg/s]` だから、1秒当たりに取り出せる理論上のエネルギー、すなわち理論水力は

`P0 = ρgQH [W]`

となる。

水では通常 `ρ≈1000 kg/m^3`、重力加速度を `g≈9.8 m/s^2` とするので、

`P0 = 1000×9.8×Q×H [W] = 9.8QH [kW]`

と書ける。

単位を追うと、

`kg/m^3 × m/s^2 × m^3/s × m = kg·m^2/s^3 = W`

である。`kg·m/s^2=N`、`N·m=J`、`J/s=W` と追っても同じ結果になる。

流量は「単位時間当たりの体積」なので、一定流量なら

`V = Qt`

で体積 `V[m^3]` を求める。逆に、体積を時間で割れば流量になる。

### 単位体積当たりの運動エネルギー
流速 `v[m/s]` の水 `1 m^3` の質量は `ρ[kg]` なので、単位体積当たりの運動エネルギーは

`e_k = (1/2)ρv^2 [J/m^3]`

となる。`(1/2)v^2` だけでは単位質量当たりであり、単位体積当たりではない。

## 3. 総落差・損失水頭・有効落差
上下の水面の高さの差をここでは総落差 `H0` とする。管路を流れる途中では摩擦などによりエネルギーが失われ、その損失を高さに換算したものが損失水頭 `hL` である。

発電時に水車で利用できる有効落差は

`H = H0 - hL`

である。損失があるのに総落差をそのまま使うと、出力を過大評価する。

一方、下池から上池へ水を戻す揚水では、ポンプは高さ `H0` だけでなく管路損失も克服する必要があるため、必要揚程は

`Hp = H0 + hL`

となる。

この符号の違いは頻出である。

- 発電: 利用できる落差なので損失を引く。
- 揚水: 克服すべき抵抗なので損失を加える。

## 4. 水車出力・発電機出力・効率
理論水力 `P0=ρgQH` のすべてを軸出力へ変換できるわけではない。水車効率を `ηt` とすると、水車軸出力は

`Pt = ρgQHηt`

である。さらに発電機効率を `ηg` とすると、発電機出力は

`Pg = ρgQHηtηg`

となる。

総合効率を

`η = ηtηg`

とおけば、

`Pg = ρgQHη`

とまとめられる。

発電では、入力側の水力から出力側へ進むので効率を掛ける。逆に、揚水で水に与えるべき水力から電気入力を求める場合は、揚水側総合効率 `ηp` で割る。

`Pin = ρgQHp / ηp`

効率は1未満なので、揚水入力は水へ与える理論水力より大きくなる。ここで扱う `ηp` は問題文で与えられる揚水系の総合効率として用い、ポンプや電動機の詳細構造へは踏み込まない。

## 5. 水量から年間電力量を求める
流域面積 `A[m^2]`、降水量 `h[m]`、流出率 `c` が与えられたとき、発電に利用できる水量を理想化して

`V = Ahc`

とする。面積が `km^2` で与えられた場合は `1 km^2=10^6 m^2` に直す。

その水量が平均落差 `H` を流下するときの位置エネルギーは

`E = ρgVH [J]`

であり、効率 `η` を考えるなら発電電力量は

`Eout = ρgVHη`

である。

電力量換算では

- `1 kWh = 3.6×10^6 J`
- `1 MWh = 3.6×10^9 J`
- `1 GWh = 3.6×10^12 J`
- `1 TWh = 3.6×10^15 J`

を使う。

例えば `A=280 km^2`、年間降水量 `1.4 m`、流出率 `0.65` なら、利用水量は

`V=280×10^6×1.4×0.65=2.548×10^8 m^3`

である。平均落差 `160 m` とすると理論電力量は約 `111 GWh`、総合効率 `0.82` なら発電電力量は約 `91.0 GWh` となる。この数値例は計算訓練用の仮定値であり、信濃川発電所の実値ではない。

## 6. 揚水発電の解き方
揚水発電は、電力が余る時間帯に下池の水を上池へ戻し、必要な時間帯にその水を落として発電する。電験では、発電時と揚水時で落差・流量・効率が異なる計算が典型である。

### 発電側
1. `Hg = H0 - hLg` で有効落差を求める。
2. `Pg = ρgQgHgηg` で発電出力を求める。
3. 発電時間 `tg` から使用水量 `V=Qgtg` を求める。

### 揚水側
1. `Hp = H0 + hLp` で必要揚程を求める。
2. 同じ水量を戻す条件から `tp = V/Qp` を求める。
3. `Pin = ρgQpHp/ηp` で必要入力を求める。

### 揚水発電の電力量効率
一往復の総合効率は

`ηround = 発電電力量 / 揚水電力量`

で求める。出力比だけではなく、必ず時間を掛けた電力量で比較する。

## 7. 連続の式とベルヌーイの定理
定常に流れる非圧縮性の水では、同じ管路を毎秒通過する体積は等しい。断面積 `A`、流速 `v` なら

`A1v1 = A2v2 = Q`

である。管が細くなれば、同じ流量を通すため流速は大きくなる。

損失を無視する基本形のベルヌーイの定理は

`p/(ρg) + v^2/(2g) + z = const.`

である。

- `p/(ρg)`: 圧力水頭
- `v^2/(2g)`: 速度水頭
- `z`: 位置水頭

同じ高さの水平管なら `z1=z2` なので、管が細くなって流速が増えると、その分だけ圧力水頭が低下する。

例として、同じ高さで `v1=2.0 m/s`、断面積が下流で上流の `1/4` になるとする。連続の式より `v2=8.0 m/s`。上流圧力 `p1=280 kPa`、損失なしとすれば、

`p2 = p1 + (ρ/2)(v1^2-v2^2)`

より `p2=250 kPa` となる。

## 8. 水車の種類
水車は、水のエネルギーを回転軸の機械エネルギーへ変換する。

### 衝動水車
ノズル等で水の圧力エネルギーを主に速度エネルギーへ変え、その水流を羽根へ当てて回す。代表例はペルトン水車である。

### 反動水車
水車内部でも圧力が変化し、その反作用も利用して回転する。代表例はフランシス水車、プロペラ水車である。プロペラ水車は軸方向に水が流れる形式として整理する。

クロスフロー水車は、水流がランナを横切る形式で、小水力設備などで用いられる代表的な水車として区別する。本Topicでは比速度・キャビテーション・調速機へは広げない。

試験では、形式名と分類・流れ方の対応を取り違えないことが重要である。

## 9. 問題を見たときの解法手順
水力発電の計算問題は次の順で処理する。

1. `Q, H0, hL, η, t` など既知量を抜き出す。
2. `km^2→m^2`、`h→s`、`kW↔MW` など単位をそろえる。
3. 発電か揚水かを判定する。
4. 発電なら `H=H0-hL`、揚水なら `Hp=H0+hL` を求める。
5. `ρgQH` で理論水力を求める。
6. 発電出力なら効率を掛け、揚水入力なら効率で割る。
7. 時間が絡むなら `V=Qt`、`E=Pt` を使う。
8. 最後に桁・単位・効率の向きを検算する。

ベルヌーイ問題では、先に連続の式で流速を確定し、その後ベルヌーイの式へ入れる。

## 10. 3段階例題

### 基礎例題: 有効落差と発電出力
総落差 `55 m`、損失水頭 `5 m`、流量 `12 m^3/s`、水車効率 `0.90`、発電機効率 `0.96` とする。発電機出力を求める。

有効落差は

`H=55-5=50 m`

総合効率は

`η=0.90×0.96=0.864`

したがって

`Pg=9.8×12×50×0.864=5080 kW≈5.08 MW`

となる。`55 m` をそのまま使わないことが要点である。

### 本試験標準例題: 管径変化と圧力
水平な管路で、上流の直径 `d1=0.24 m`、下流の直径 `d2=0.12 m`、上流流速 `v1=2.0 m/s`、上流圧力 `p1=280 kPa` とする。水の密度を `1000 kg/m^3`、損失を無視して下流圧力を求める。

断面積は直径の2乗に比例するので、

`A1/A2=(0.24/0.12)^2=4`

連続の式から

`v2=v1(A1/A2)=2.0×4=8.0 m/s`

水平管なので位置水頭は相殺できる。ベルヌーイの定理より

`p1/ρ + v1^2/2 = p2/ρ + v2^2/2`

したがって

`p2=p1+(ρ/2)(v1^2-v2^2)`

`=280000+500(4-64)`

`=250000 Pa=250 kPa`

となる。管が細くなり流速が増えたので、圧力は低下する。

### 複合・ひっかけ例題: 揚水発電
上下池の水面差を `420 m` とする。発電時の損失水頭 `12 m`、流量 `48 m^3/s`、発電側総合効率 `0.88` で7時間発電した。揚水時も損失水頭 `12 m`、流量 `36 m^3/s`、揚水側総合効率 `0.84` とする。発電出力、揚水入力、揚水時間、一往復の電力量効率を求める。

発電有効落差は

`Hg=420-12=408 m`

よって発電出力は

`Pg=9.8×48×408×0.88≈168900 kW=168.9 MW`

7時間に使った水量は

`V=48×7×3600=1,209,600 m^3`

同じ水量を `36 m^3/s` で戻すので、

`tp=1,209,600/(36×3600)=9.33 h`

揚水時に必要な揚程は

`Hp=420+12=432 m`

であり、必要電気入力は

`Pin=9.8×36×432/0.84=181440 kW=181.44 MW`

発電電力量は

`Eg=168.892×7≈1182.25 MWh`

揚水電力量は

`Ep=181.44×9.33≈1693.44 MWh`

したがって一往復の電力量効率は

`ηround=1182.25/1693.44≈0.698=69.8%`

となる。ひっかけは、発電時と揚水時で損失水頭の符号が逆になること、揚水入力では効率を掛けずに割ること、効率を出力比ではなく電力量比で求めることである。

## 11. 新幹線への接続
JR東日本の一次資料では、信濃川発電所は千手発電所・小千谷発電所・小千谷第二発電所の3発電所の総称で、信濃川水系から取水した水を利用して発電している。発電した電気は首都圏や上越線、新幹線の電車・鉄道施設などへ送られている。

したがって「上越新幹線を水の力で走らせる」は比喩だけではない。ただし、本Topicでは各発電所の未確認の流量・落差・出力を仮定で真値化しない。実設備の役割を入口にして、試験では一般化した `ρgQHη`、有効落差、効率、電力量の計算へ戻る。

## 12. 頻出ミス・ひっかけ
- `P=9.8QH` の答えは `kW`。`W` と取り違えない。
- 発電時の有効落差は `H0-hL`。損失を足さない。
- 揚水時の必要揚程は `H0+hL`。損失を引かない。
- 発電出力は効率を掛ける。揚水入力は効率で割る。
- 水車効率と発電機効率が別々なら、総合効率は積 `ηtηg`。
- `Q[m^3/s]` は体積ではなく流量。水量は `V=Qt`。
- 電力 `kW, MW` と電力量 `kWh, MWh` を混同しない。
- `km^2` を `m^2` へ直すときは `10^6` 倍。
- 単位体積当たりの運動エネルギーでは密度 `ρ` が必要。
- ベルヌーイ問題では、断面積比と直径比を混同しない。面積は直径の2乗に比例する。

## 14. 公式・解法まとめ
- 理論水力: `P0=ρgQH [W]`
- 水の場合: `P0=9.8QH [kW]`
- 発電有効落差: `H=H0-hL`
- 発電出力: `Pg=ρgQHηtηg`
- 揚水必要揚程: `Hp=H0+hL`
- 揚水入力: `Pin=ρgQHp/ηp`
- 水量: `V=Qt`
- 流域水量: `V=Ahc`
- 位置エネルギー: `E=ρgVH`
- 連続の式: `A1v1=A2v2`
- ベルヌーイ: `p/(ρg)+v^2/(2g)+z=const.`
- 単位体積当たり運動エネルギー: `e_k=(1/2)ρv^2`
- 揚水一往復効率: `ηround=発電電力量/揚水電力量`
