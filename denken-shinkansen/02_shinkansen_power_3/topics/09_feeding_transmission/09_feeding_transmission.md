# 解説本文

## §1 このテーマで電験は何を問うか

この章の中心は「線路を理想的な導線として扱わず、抵抗R・インダクタンスL・静電容量Cを持つ回路として扱う」ことである。

本試験では主に次を問う。

1. 三相送電電力から線電流を求め、`I²R`損失を計算する。
2. R・L・Cから線路の性質を判断する。
3. T形・π形の一相等価回路をKVL・KCLで追う。
4. 静電容量による充電電流と、無負荷時の受電端電圧上昇を扱う。
5. 抵抗と静電容量を無視した線路で、有効電力と送受電端電圧・相差角の関係を使う。

暗記するべきなのは式そのものだけではない。線間値と相値、1線分の抵抗と三相合計損失、遅れ電流の位相、mSからSへの換算を区別できることが重要である。

## §2 送電端・受電端と新幹線の電流経路

送電線路では、電力を送り出す側を送電端、負荷へ届く側を受電端という。線路途中にインピーダンスがあるため、一般に送電端と受電端では電圧の大きさ・位相が一致しない。

新幹線側では、変電所から送り出された電流が、き電線・電車線を通ってパンタグラフへ届き、車両で使われた後、車輪・レールなどの帰線側を通って変電所へ戻る。電流は必ず閉回路を作るので、「パンタグラフまで送る」だけでなく「どこを通って戻るか」まで見る。

ATき電方式では、電車線と並行するき電側導体、AT、レール側を組み合わせて電流を分担させる。ここでは三種相当として、目的を「長いき電区間で電圧降下を抑え、帰線電流を適切に戻すための方式」と理解する。ATの詳細設計、保護方式、短絡解析へは進まない。

## §3 線路定数R・L・C

### 3.1 電線抵抗R

電線には抵抗があり、単位はΩである。直流で考える基本形は

`R = ρl/A`

であり、長さ`l`が長いほど大きく、断面積`A`が大きいほど小さい。

交流では表皮効果や近接効果によって電流分布が均一でなくなるため、交流実効抵抗は直流抵抗より大きくなる方向に働く。抵抗は温度でも変化するので、問題文で温度条件が与えられた場合は無視しない。

### 3.2 インダクタンスLとリアクタンスX

電流が流れる線路には磁界ができるため、インダクタンス`L [H]`を持つ。交流では

`X_L = ωL = 2πfL [Ω]`

として誘導性リアクタンスに置き換える。周波数`f`またはLが大きいほど`X_L`も大きい。

### 3.3 静電容量Cとアドミタンス

線路の導体どうし、または導体と大地の間には電位差があるので静電容量`C [F]`が生じる。交流では静電容量により充電電流が流れる。

容量性アドミタンスは

`Y_C = jωC = jB [S]`

と表せる。`B`はサセプタンスで単位はS（ジーメンス）である。

`1 mS = 10^-3 S`

なので、mSをSへ直さず計算しないこと。

### 3.4 架空線路と地中線路の定性的な違い

線路定数の大小は導体寸法・間隔・材質・絶縁物などで決まる。一般に地中線路は導体間隔が小さく誘電体を介するため、架空線路より静電容量が大きく、インダクタンスは小さくなる傾向がある。一方、抵抗は導体材質・断面積・温度などにも依存するため、「地中だから必ず大きい／小さい」とだけ覚えない。

## §4 インピーダンス・アドミタンスとフェーザ

抵抗とリアクタンスをまとめたものがインピーダンスで、

`Z = R + jX [Ω]`

と表す。逆数がアドミタンスで、

`Y = 1/Z [S]`

である。

受電端電圧を位相基準`V_r = |V_r|∠0°`とする。力率`cosφ`の遅れ負荷なら、電流は電圧よりφだけ遅れるので

`I = |I|∠(-φ) = |I|(cosφ - j sinφ)`

となる。

線路の直列インピーダンスが`Z`なら、受電端から送電端へ戻る基本式は

`V_s = V_r + ZI`

である。抵抗分`RI`とリアクタンス分`jXI`は位相が異なるため、交流では単純な実数の足し算にしない。

## §5 三相電力・線電流・電力損失

平衡三相3線式で、線間電圧`V`、線電流`I`、力率`cosφ`の有効電力は

`P = √3 V I cosφ`

である。したがって電流は

`I = P / (√3 V cosφ)`

と逆算できる。

1線あたりの抵抗が`R`なら、三相3線すべての抵抗損は

`P_L = 3 I² R`

となる。ここでRは1線分であり、3線合計の抵抗をさらに3倍してはいけない。

受電電力に対する損失率を求めるなら

`損失率 = P_L / P × 100 [%]`

とする。問題文が「送電端電力に対する割合」を指定する場合は分母が変わるので、何に対する割合かを先に確認する。

## §6 T形・π形一相等価回路

三相平衡回路では、一相分の等価回路で計算し、最後に必要なら線間値へ戻せる。

### 6.1 T形

T形では、直列インピーダンスを前半・後半に分け、その中央に線路の静電容量を表すアドミタンスを置く。

受電端から送電端へ戻る手順は次の通り。

1. 受電端相電圧`V_r`と負荷電流`I_r`を置く。
2. 受電端側の直列インピーダンス`Z/2`で中央電圧を求める。
   - `V_m = V_r + (Z/2)I_r`
3. 中央の分岐アドミタンス`Y`に流れる電流を求める。
   - `I_c = YV_m`
4. KCLで送電端側直列部の電流を求める。
   - `I_s = I_r + I_c`
5. KVLで送電端相電圧を求める。
   - `V_s = V_m + (Z/2)I_s`

順番を逆にすると未知量が増える。既知量が受電端側に与えられた問題では、受電端から一要素ずつ送電端へ戻る。

### 6.2 π形

π形では、直列インピーダンス`Z`の両端に、線路の静電容量を表すアドミタンス`Y/2`を分けて置く。

受電端側では

`I_c,r = (Y/2)V_r`

となる。負荷電流を`I_L`とすれば直列部電流は

`I_z = I_L + I_c,r`

で、送電端相電圧は

`V_s = V_r + ZI_z`

となる。送電端側の分岐電流が必要な場合は、最後に`(Y/2)V_s`を加える。

T形・π形とも、問題図で与えられたZ・Yの配置をそのままKVL/KCLへ落とし込むことが重要である。

## §7 充電電流と無負荷時電圧上昇

線路に負荷がなくても、静電容量があれば交流では充電電流が流れる。π形の受電端側なら

`I_c = j(B/2)V_r`

である。

抵抗を無視し直列リアクタンスを`jX`とすると、充電電流は電圧より90°進む。この電流がリアクタンスを流れると

`jX × jI = -XI`

となり、直列部の電圧変化が受電端電圧を押し上げる方向に働く。そのため軽負荷・無負荷では受電端電圧が送電端電圧より高くなる場合がある。これがフェランチ現象である。

ここで必要なのは「静電容量がある→充電電流が流れる→線路リアクタンスとの組合せで無負荷時の受電端電圧が上がり得る」という回路上のつながりである。

## §8 リアクタンスを介した有効電力伝送

線路抵抗と静電容量を無視し、平衡三相で1相あたりの直列リアクタンスを`X`、送受電端の線間電圧を`V_s`,`V_r`、両電圧の相差角を`δ`とすると、有効電力は

`P = (V_s V_r / X) sinδ`

で表せる。

この式を使える条件は次の通り。

- 三相平衡である。
- Rを無視する。
- 線路静電容量を無視する。
- Xは一相分の直列リアクタンスである。
- `V_s`,`V_r`は線間電圧である。

導出の考え方は、一相あたりで`I = (V_s∠δ - V_r)/(jX)`を作り、受電端有効電力`3 Re(V_r I*)`を求めることにある。相電圧が線間電圧の`1/√3`なので、三相分を掛けると上式になる。

`δ`が小さい範囲では`sinδ`も小さく、δが大きくなるほど送れる有効電力は増える。ただしこの章では安定度論へは広げず、固定過去問で必要な式と成立条件までとする。

## §9 新幹線のATき電方式と帰線へ接続する

新幹線のき電回路も、電験で扱う送電線路と同じく「電流が流れる導体にはR・Lがあり、導体間にはCがある」と見ればよい。

電流経路の基本は

```text
変電所
→ き電線・電車線側
→ パンタグラフ
→ 車両
→ 車輪
→ レールなどの帰線側
→ 変電所
```

で閉じる。

ATき電方式ではATを介して電車線側・き電側・帰線側の電流を分担させることで、長い区間をき電するときの電圧降下や帰線電流を抑える方向に働く。電験三種では、この回路も最終的には「線路インピーダンスに電流が流れれば電圧降下と損失が生じる」という一般原理で読む。

この章では実設備の個別距離、AT容量、詳細な電流分担率を仮定しない。

## §10 問題を見たときの解法手順

### A. 三相電力と損失
1. 線間電圧、受電電力、力率、1線分抵抗を確認する。
2. `I = P/(√3Vcosφ)`で線電流を出す。
3. `P_L = 3I²R`で三相合計損失を出す。
4. 必要なら指定された分母で損失率を出す。
5. W/kW/MWとV/kVをそろえて検算する。

### B. T形・π形等価回路
1. 線間値なら必要に応じて相値へ変換する。
2. 受電端電圧を位相基準に置く。
3. 遅れ力率なら電流角を負にする。
4. 受電端からKVLで一つずつ電圧を戻す。
5. 分岐点では`I = YV`を計算し、KCLで電流を合成する。
6. 最後に必要な送電端電圧・電流の絶対値を求める。

### C. 無負荷・静電容量問題
1. `mS → S`を行う。
2. π形なら受電端側アドミタンスが`Y/2`か確認する。
3. `I_c = (Y/2)V_r`で充電電流を出す。
4. 直列インピーダンスによる電圧変化を複素数で加える。
5. 受電端が送電端より高くなる結果でも、符号を勝手に反転しない。

### D. リアクタンスだけの送電電力
1. RとCを無視する条件か確認する。
2. `V_s`,`V_r`が線間電圧、Xが一相分か確認する。
3. `P = (V_sV_r/X)sinδ`へ代入する。
4. kVをVへ直すなど単位をそろえる。

## §11 3段階例題

### 例題1 基礎：三相送電の電流と抵抗損

平衡三相3線式で、受電端有効電力`P = 20 MW`、線間電圧`V = 66 kV`、力率`cosφ = 0.80`、1線あたりの抵抗`R = 0.15 Ω`とする。線電流、三相合計線路損失、受電電力に対する損失率を求める。

#### 解法
三相有効電力から電流を求めるので

`I = P/(√3Vcosφ)`

を使う。

`I = 20×10^6 / (√3 × 66×10^3 × 0.80)`

`I ≒ 218.7 A`

三相3線の抵抗損は

`P_L = 3I²R`

だから、

`P_L = 3 × (218.7)^2 × 0.15`

`P_L ≒ 2.15×10^4 W = 21.5 kW`

損失率は

`21.5×10^3 / 20×10^6 × 100 ≒ 0.108 %`

となる。

#### 検算
損失が受電電力20 MWに対して数十kWなので、0.1%程度という桁は整合する。`3I²R`の3を落とすと誤答になる。

### 例題2 本試験標準：T形等価回路を受電端から追う

一相分のT形等価回路を考える。受電端相電圧を`V_r = 100 kV∠0°`、負荷電流を`125 A`、力率0.80遅れとする。直列インピーダンスの各半分を`Z/2 = 2 + j4 Ω`、中央のアドミタンスを`Y = j1.0 mS`とする。送電端相電圧を求める。

#### 1. 負荷電流を複素数化
`cosφ = 0.80`なので`sinφ = 0.60`。遅れだから

`I_r = 125(0.8 - j0.6) = 100 - j75 A`

となる。

#### 2. 中央電圧

`V_m = V_r + (Z/2)I_r`

`(2+j4)(100-j75) = 500 + j250 V`

したがって

`V_m = 100500 + j250 V`

となる。

#### 3. 中央分岐電流

`Y = j1.0 mS = j0.001 S`

なので

`I_c = YV_m`

`I_c = j0.001(100500+j250)`

`I_c = -0.25 + j100.5 A`

となる。

#### 4. 送電端側直列電流

KCLより

`I_s = I_r + I_c`

`I_s = (100-j75)+(-0.25+j100.5)`

`I_s = 99.75+j25.5 A`

である。

#### 5. 送電端相電圧

`V_s = V_m + (Z/2)I_s`

`(2+j4)(99.75+j25.5) = 97.5+j450 V`

よって

`V_s = 100597.5+j700 V`

`|V_s| ≒ 100.6 kV`

となる。

#### 検算
受電端から「直列部→分岐→直列部」の順に進み、各分岐でKCLを使っている。アドミタンス`1.0 mS`を`1.0 S`としてしまうと電流が1000倍になる。

### 例題3 複合・ひっかけ：π形・充電電流・無負荷時電圧上昇

一相分のπ形等価回路で、抵抗を無視し、総直列リアクタンスを`X = 20 Ω`、総シャントサセプタンスを`B = 1.0 mS`とする。受電端は無負荷で、受電端相電圧を`V_r = 100 kV∠0°`とする。送電端相電圧を求め、受電端電圧と比較する。

#### 1. 受電端側充電電流

π形なので受電端側は`B/2`である。

`B/2 = 0.5 mS = 0.0005 S`

したがって

`I_c = j(B/2)V_r`

`I_c = j0.0005 × 100000 = j50 A`

となる。

#### 2. 直列リアクタンスの電圧変化

無負荷なので直列部を流れるのは受電端側充電電流である。

`V_s = V_r + jXI_c`

`jXI_c = j20 × j50 = -1000 V`

よって

`V_s = 100000 - 1000 = 99000 V = 99 kV`

となる。

受電端相電圧100 kVの方が送電端相電圧99 kVより高い。これは静電容量による充電電流と線路リアクタンスの組合せによる無負荷時電圧上昇である。

#### 典型ひっかけ
- `1.0 mS = 0.001 S`を忘れない。
- π形では総アドミタンスを両端に半分ずつ置く。
- `j×j = -1`なので電圧変化の向きを実数の足し算で決めない。
- 無負荷でも静電容量があれば線路電流は0とは限らない。

## §12 頻出ミス

- 三相有効電力`√3VIcosφ`でVに相電圧を入れる。
- `3I²R`でRを3線合計抵抗としてさらに3倍する。
- 遅れ力率なのに電流角を正にする。
- `mS`を`S`へ直さない。
- π形の`Y/2`を`Y`として使う。
- KVLとKCLを混同し、分岐点で電圧を足す。
- T形・π形の回路図を見ず、公式だけで一括計算する。
- `P = (V_sV_r/X)sinδ`をRやCを無視できない条件へそのまま使う。
- 線間値と相値を途中で混在させる。
- 交流実効抵抗を常に直流抵抗と同じとみなす。

## §14 公式・解法まとめ

- 誘導性リアクタンス: `X_L = 2πfL`
- インピーダンス: `Z = R + jX`
- 容量性アドミタンス: `Y_C = jωC = jB`
- 三相有効電力: `P = √3VIcosφ`
- 三相線路損失: `P_L = 3I²R`
- 直列線路の基本: `V_s = V_r + ZI`
- T形: 受電端→`Z/2`→中央`Y`→`Z/2`の順にKVL/KCL
- π形: 受電端`Y/2`→直列Z→送電端`Y/2`
- 充電電流: `I_c = YV`
- リアクタンスのみの三相送電電力: `P = (V_sV_r/X)sinδ`

解法の基本は「受電端の既知量を確定→単位と相／線間をそろえる→回路図どおりにKVL/KCL→最後に絶対値・三相量へ戻す」である。
