### R6下 電力 問12

教材から

`P = √3 V_r I cosθ`

より

`I = P / (√3 V_r cosθ)`。

3線合計の抵抗損は

`P_L = 3I²R`

なので、

`P_L = 3R {P² / [3(V_r cosθ)²]} = RP² / (V_r cosθ)²`。

したがって

`P_L / P = RP / (V_r cosθ)²`。

独立答案: `(2)`。

### R6下 電力 問16(a)

一相分T形回路。教材の手順どおり受電端から送電端へ戻る。

`r = 20 Ω`, `x = 80 Ω` なので

`Z/2 = 10 + j40 Ω`。

`V_r1 = 150 kV∠0°`, `I_r = 400 A`, `cosθ_r = √3/2` 遅れより、

`I_r = 400∠(-30°) = 346.41 - j200 A`。

中央電圧は

`V_c = V_r1 + (Z/2)I_r`

`= 150000 + (10+j40)(346.41-j200)`

`= 161464.10 + j11856.41 V`。

したがって

`|V_c| ≒ 161.90 kV`。

独立答案: `(3)`。

### R6下 電力 問16(b)

コンデンサ枝のアドミタンスは `jY = j0.0007 S`。

`I_c = j0.0007 V_c`

`= -8.299 + j113.025 A`。

KCLより

`I_s = I_r + I_c`

`= 338.111 - j86.975 A`。

送電端相電圧は

`V_s1 = V_c + (Z/2)I_s`

`= 168324.21 + j24511.08 V`。

したがって

`|V_s1| ≒ 170.10 kV`。

独立答案: `(4)`。

### R6下 電力 問17(a)

π形一相等価回路。`jX = j200 Ω`, `jB = j0.800 mS`、受電端は無負荷。

送電端相電圧を `V_s`、受電端相電圧を `V_r` とすると、受電端側の充電電流は

`I_c,r = j(B/2)V_r`。

直列部の電圧関係は

`V_s = V_r + jX I_c,r`

`= V_r + jX × j(B/2)V_r`

`= (1 - XB/2)V_r`。

`XB/2 = 200×0.0008/2 = 0.08` より

`V_r / V_s = 1/0.92`。

線間値でも同じ比なので

`V_r(line) = 66.0/0.92 ≒ 71.74 kV`。

独立答案: `(2)`。

### R6下 電力 問17(b)

`V_s(line)=66.0 kV` より

`V_s = 66.0/√3 ≒ 38.105 kV`。

(a)より

`V_r = 71.739/√3 ≒ 41.419 kV`。

受電端無負荷なので直列部電流は受電端側充電電流のみで、送電端電流は両端の充電電流の和になる。

`|I_s| = (B/2)(V_r + V_s)`

`= 0.0004×(41419 + 38105)`

`≒ 31.81 A`。

独立答案: `(4)`。

### R5上 電力 問10

教材のR・L・Cの定性的整理から判定する。

- 導体抵抗・インダクタンス・静電容量を線路定数として考える: 正しい。
- 交流実効抵抗は表皮効果・近接効果により直流抵抗より小さくなる: 誤り。実効抵抗は増加する。
- 導体抵抗は温度上昇で増加する: 正しい。
- 地中送電線路のインダクタンスは架空線路より小さい: 正しい。
- 地中送電線路の静電容量は架空線路より大きい: 正しい。

独立答案: `(2)`。

### R4下 電力 問9

教材の成立条件は、平衡三相、線路抵抗と静電容量を無視、一相当たりリアクタンス`X`、送受電端の線間電圧`V_s`,`V_r`を用いる場合、

`P = (V_s V_r / X) sinδ`

である。

独立答案: `(1)`。
