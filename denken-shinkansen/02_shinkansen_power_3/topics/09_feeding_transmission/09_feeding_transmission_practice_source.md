- `X_L = 2πfL`

- `Y_C = jωC = jB`

- `P_L = 3I²R`
- `V_s = V_r + ZI`
- T形: `V_m = V_r + (Z/2)I_r`、`I_c = YV_m`、`I_s = I_r + I_c`、`V_s = V_m + (Z/2)I_s`

- `P = (V_sV_r/X)sinδ`（R・Cを無視する平衡三相、Vは線間値、Xは一相分）

# 解答・完全解説

## 問1
正答: 3

誘導性リアクタンスは

`X_L = 2πfL`

である。`L = 3.0 mH = 0.003 H` なので、

`X_L = 2π × 50 × 0.003 ≒ 0.942 Ω`

となる。mHをHへ直すことが必要である。正答は3。

## 問2
正答: 4

複素数のまま掛ける。

`ZI = (0.8+j1.6)(80-j60)`

`= 64 - j48 + j128 + 96`

`= 160 + j80 V`

`j×(-j)=+1` を落とすと実部を誤る。正答は4。

## 問3
正答: 3

三相有効電力は

`P = √3VIcosφ`

なので、

`I = P/(√3Vcosφ)`

`= 10×10^6 /(√3 × 66×10^3 × 0.80)`

`≒ 109.3 A`

約109 Aなので正答は3。Vには線間電圧を使う。

## 問4
正答: 2

まず線電流を求める。

`I = 30×10^6 /(√3 × 66×10^3 × 0.90)`

`≒ 291.6 A`

三相合計抵抗損は、1線当たりの抵抗Rを使って

`P_L = 3I²R`

`= 3 × 291.6² × 0.40`

`≒ 1.020×10^5 W = 102 kW`

受電端有効電力に対する損失率は

`102×10^3 /(30×10^6) × 100 ≒ 0.340%`

である。`I²R`だけでは1線分の損失になる。正答は2。

## 問5
正答: 3

指定条件では

`P = (V_sV_r/X)sinδ`

を使える。

`P = ((66×10^3)^2 / 20) × sin10°`

`≒ 3.782×10^7 W`

`≒ 37.8 MW`

となる。Vは線間値、Xは一相分であり、ここでさらに3倍しない。正答は3。

## 問6
正答: 3

力率0.80遅れなので

`I_r = 100(0.8-j0.6) = 80-j60 A`

である。

中央電圧は

`V_m = V_r + (Z/2)I_r`

`= 100000 + (2+j4)(80-j60)`

`= 100400 + j200 V`

中央分岐電流は、`0.5 mS = 0.0005 S`より

`I_c = j0.0005(100400+j200)`

`= -0.1 + j50.2 A`

送電端側直列電流は

`I_s = I_r + I_c`

`= 79.9 - j9.8 A`

したがって

`V_s = V_m + (2+j4)I_s`

`= 100599 + j500 V`

`|V_s| ≒ 100.6 kV`

となる。受電端から直列部→分岐→直列部の順に追う。正答は3。

## 問7
正答: 3

線間電圧154 kVを相電圧へ直す。

`V_r = 154/√3 ≒ 88.91 kV`

π形の受電端側分岐は総サセプタンスの半分なので、

`B/2 = 0.6 mS = 0.0006 S`

充電電流の大きさは

`I_c = (B/2)V_r`

`= 0.0006 × 88.91×10^3`

`≒ 53.3 A`

となる。`1.2 mS`をそのまま使うと2倍になる。正答は3。

## 問8
正答: 2

問7より1相分の受電端相電圧は `88.91 kV`、受電端側充電電流は `j53.3 A` である。

無負荷なので直列部を流れるのはこの充電電流で、

`V_s = V_r + jXI_c`

`= 88.91 kV + j30 × j53.3 A`

`= 88.91 kV - 1.600 kV`

`≒ 87.31 kV`

これは相電圧なので、線間値へ戻すと

`V_s,line = √3 × 87.31 ≒ 151.2 kV`

となる。受電端154 kVの方が送電端151.2 kVより高く、無負荷時電圧上昇の向きと整合する。正答は2。

## 問9
正答: 3

静電容量がある交流線路では、負荷がなくても容量性の充電電流が流れ得るので3が正しい。

1は誤り。表皮効果・近接効果は交流実効抵抗を直流抵抗より増やす方向に働く。

2は誤り。`X_L = 2πfL`なので周波数が高いほど大きい。

4は誤り。一般に地中線路は導体間隔が小さく誘電体を介するため、架空線路より静電容量が大きい傾向がある。

5は誤り。RとXは位相が異なるため `Z=R+jX` と複素数で扱う。正答は3。

## 問10
正答: 4

電流は閉回路を作る。新幹線では、変電所から電車線・き電線側へ送られた電流がパンタグラフから車両へ入り、車輪・レール等の帰線側を経て変電所へ戻る流れとして理解する。

ATき電方式でも線路インピーダンスによる電圧降下・損失は存在する。詳細な短絡保護計算は本テーマの固定範囲ではない。正答は4。

## 問11
正答: 2

負荷電流は

`I_L = 100(0.8-j0.6) = 80-j60 A`

受電端側の分岐サセプタンスは

`B/2 = 0.5 mS = 0.0005 S`

なので、

`I_c,r = j0.0005 × 100000 = j50 A`

直列部電流は

`I_z = I_L + I_c,r`

`= 80 - j10 A`

である。

送電端相電圧は

`V_s = V_r + j20(80-j10)`

`= 100000 + 200 + j1600`

`= 100200 + j1600 V`

したがって

`|V_s| ≒ 100.213 kV`

で、最も近いのは100.2 kV。正答は2。

## 問12
正答: 3

受電端線間電圧は `100√3 kV` なので、相電圧はちょうど100 kVである。

三相有効電力から線電流を求める。

`I = 24.0×10^6 /(√3 × 100√3×10^3 × 0.80)`

`= 100 A`

力率0.80遅れより、

`I_r = 80-j60 A`

となる。

中央電圧は

`V_m = 100000 + (1+j2)(80-j60)`

`= 100200 + j100 V`

中央分岐電流は

`I_c = j0.0005(100200+j100)`

`= -0.05 + j50.1 A`

よって送電端側直列電流は

`I_s = 79.95 - j9.9 A`

である。

送電端相電圧は

`V_s = V_m + (1+j2)I_s`

`= 100299.75 + j250 V`

`|V_s| ≒ 100.300 kV`

線間値へ戻すと

`V_s,line = √3 × 100.300 ≒ 173.7 kV`

となる。三相電力→線電流→相値→T形回路→線間値の順に処理する。正答は3。
