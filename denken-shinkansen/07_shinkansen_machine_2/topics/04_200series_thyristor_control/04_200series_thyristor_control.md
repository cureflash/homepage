# 解説本文

## 1. このテーマで電験二種は何を問うか

このテーマの中心は、サイリスタの点弧を遅らせることで交流から得る平均直流電圧を変え、その電圧を直流電動機の電流・トルクへつなぐ計算である。一次試験では平均直流電圧、制御角、素子電流、基本波位相などを選択式で判断する。二次試験では平均値を積分から導き、有効電力・無効電力まで途中式を記述できることが必要になる。

200系は本章の題材として扱うが、回路定数・制御角・主電動機電流などの未確認値は実車値として使わない。本文と例題では一般式と教材上の仮定値だけで試験論点を学ぶ。

中心式は次である。

```text
V_d = (3√2/π)V cosα ≒ 1.35V cosα
V_d = E + I_aR_a
T = kΦI_a
```

ここで `V` は三相交流の線間実効値、`α` は制御遅れ角、`V_d` は平均直流電圧、`E` は直流電動機の逆起電力、`I_a` は電機子電流、`R_a` は電機子抵抗である。

## 2. サイリスタと制御角

サイリスタの主要端子はアノード、カソード、ゲートである。アノード側がカソード側より正で順方向電圧が加わっていても、ゲート信号を与えるまでは直ちに導通しない。適切なゲート信号でターンオンさせることで、交流波形のどの位相から電流を流すかを制御できる。

制御遅れ角 `α` は、自然に導通を開始する基準位相から点弧を何radまたは何度遅らせるかを表す。したがって、`α` を大きくすると出力側へ取り出す電圧波形の開始が遅れ、平均直流電圧が低下する。

R01一次問3型の逆並列サイリスタでは、一素子が交流電源へ接続されているため、理想化すると素子に現れ得る順・逆方向電圧の最大値は交流電圧の波高値である。交流実効値を `V` とすれば

```text
V_peak = √2V
```

である。実効値 `V` と波高値 `√2V` を取り違えない。

## 3. 三相全波位相制御整流器の平均直流電圧

三相全波サイリスタ整流器について、次の理想条件を置く。

- 三相線間電圧は正弦波
- 直流側電流は十分平滑で連続
- サイリスタは理想素子
- 電源側リアクタンスによる転流重なりを無視

線間実効値を `V` とし、1つの60°区間で出力へ現れる線間電圧片を

```text
v(θ) = √2V cosθ
```

と置く。制御角 `α` だけ遅らせると、この区間は

```text
α-π/6 ≤ θ ≤ α+π/6
```

となる。出力波形は同じ形が1周期に6回現れるため、平均値は

```text
V_d
= 6/(2π) ∫[α-π/6 → α+π/6] √2V cosθ dθ
= (3√2V/π){sin(α+π/6)-sin(α-π/6)}
```

ここで

```text
sin(α+π/6)-sin(α-π/6) = cosα
```

だから

```text
V_d = (3√2/π)V cosα
    ≒ 1.35V cosα
```

となる。二次試験では `1.35V cosα` を暗記して終わらず、「60°区間を積分し、1周期の6区間で平均する」という導出を書けるようにする。

## 4. 制御角―平均直流電圧特性

`α=0` のとき

```text
V_d0 = (3√2/π)V ≒ 1.35V
```

で最大になる。したがって正規化すると

```text
V_d/V_d0 = cosα
```

である。

| `α` | `cosα` | `V_d/V_d0` |
|---:|---:|---:|
| 0° | 1.000 | 1.000 |
| 30° | 0.866 | 0.866 |
| 60° | 0.500 | 0.500 |
| 90° | 0.000 | 0.000 |

本テーマで扱う整流側の非負平均電圧の範囲は `0 ≤ α ≤ π/2` とする。厳密に正の平均直流電圧を得るのは `0 ≤ α < π/2` で、`α=π/2` では平均値が0になる。

R05一次問4で問われる「ダイオード整流器相当」は、点弧を遅らせない `α=0` に対応する。

## 5. サイリスタ電流と平均値・実効値

電流問題では、何の電流を求めているかを先に確認する。

- 直流側電流 `I_d`
- 一素子に流れる電流
- その一素子電流の平均値
- その一素子電流の実効値
- 交流側線電流

これらは同じ値ではない。

R01一次問3型の抵抗負荷で、交流実効値を `V`、抵抗を `R` とする。一方のサイリスタが `α` から `π` まで導通するなら

```text
i(θ) = (√2V/R)sinθ
```

である。一素子について1周期 `2π` で平均すると

```text
I_T(av)
= 1/(2π) ∫[α → π] (√2V/R)sinθ dθ
= V/(√2πR)(1+cosα)
```

となる。導通区間の長さだけで平均値を決めず、電流波形を積分する。

一方、直流側電流が連続する理想三相全波ブリッジでは、各サイリスタは1周期の120°を導通する。各素子電流が導通中ほぼ `I_d` なら

```text
I_T(av) = I_d/3
I_T(rms) = I_d/√3
```

となる。これは前記の抵抗負荷の式とは条件が異なるため、問題文の回路と負荷条件を見て使い分ける。

## 6. 有効電力・無効電力・力率

H30二次問3の条件では、変換器損失を無視すると交流側有効電力と直流側電力が一致する。

```text
P = V_d I_d
```

平均直流電圧を代入すると

```text
P = (3√2/π)VI_d cosα
```

となる。

この条件で交流側線電流の基本波実効値は

```text
I_1 = (√6/π)I_d
```

である。基本波皮相電力は

```text
S_1 = √3VI_1
    = (3√2/π)VI_d
```

したがって基本波無効電力は

```text
Q_1 = S_1 sinα
    = (3√2/π)VI_d sinα
```

基本波については

```text
P/S_1 = cosα
```

となり、`α` を大きくするほど基本波力率は低下する。

ただし、位相制御された交流側実電流は一般に非正弦波で高調波を含む。したがって、実電流全体の実効値を使う総合力率と、基本波だけの `cosα` を同一視してはいけない。

またR01一次問3の純インダクタンス負荷では、基本波電流は電源電圧より90°遅れる。これは回路条件が異なる問題であり、上記H30型三相変換器の `α` と機械的に同一視しない。

## 7. 位相制御と高調波

サイリスタ整流器や変換器は、半導体素子を交流周期の途中から導通させるため、交流側電流が正弦波からずれる。正弦波でない周期波形には基本波以外の高調波成分が含まれる。

R05二次問3で必要な範囲では、次を説明できればよい。

- サイリスタ整流器などの半導体電力変換装置は高調波の発生源になり得る。
- 高調波電流は機器へ余分な損失を生じさせ、コンデンサ・リアクトル等の過熱や振動を招くことがある。
- 電圧波形へ影響すると、電子機器の誤動作などにつながることがある。

本テーマでは高調波の基本的な発生と影響までとし、能動フィルタの補償設計や詳細な高調波次数解析へは進まない。

## 8. 直流主電動機への接続

三相サイリスタ整流器の出力を直流主電動機へ与えると、平均値モデルでは

```text
V_d(α) = E + I_aR_a
```

だから

```text
I_a(α) = {V_d(α)-E}/R_a
        = {(3√2/π)V cosα-E}/R_a
```

となる。磁束を一定とすれば

```text
T(α) = kΦI_a(α)
     = (kΦ/R_a){(3√2/π)V cosα-E}
```

である。

したがって、同じ交流電圧、同じ回転速度、同じ磁束という比較条件なら

```text
制御角 α 増加
→ 平均直流電圧 V_d 低下
→ 電機子電流 I_a 低下
→ トルク T 低下
```

という順につながる。

このとき `E` は回転速度と磁束が同じという比較条件で固定される。速度まで同時に変わる過渡現象では `E` も変わるため、この単純な `α-I_a`、`α-T` 関係をそのまま使わない。

### 8.1 グラフ原稿

解説PDF・PowerPointで作る3グラフは、次の関係を正本とする。

```text
α-V_d:
V_d/V_d0 = cosα

α-I_a:
I_a = (V_d0 cosα-E)/R_a

α-T:
T = (kΦ/R_a)(V_d0 cosα-E)
```

`V_d0=(3√2/π)V` である。`α-I_a` と `α-T` は、`E`、`R_a`、`kΦ` を一定とした教材上の比較モデルで、`I_a≥0` の範囲だけを描く。200系の未確認値を実車値として代入しない。

## 9. 再利用できる解法手順

サイリスタ位相制御問題は次の順で処理する。

1. 単相か三相か、回路形式と負荷条件を確認する。
2. 与えられた交流電圧が実効値か波高値か、線間値か相値かを確認する。
3. 制御角 `α` の基準を確認する。
4. 三相全波なら、必要に応じ60°区間の積分から `V_d=(3√2/π)V cosα` を作る。
5. 電流問題では、直流側・交流側・一素子、さらに平均値・実効値のどれかを確認する。
6. 損失無視なら `P=V_dI_d` で交流有効電力へ接続する。
7. H30型の条件なら `I_1=(√6/π)I_d`、`S_1=√3VI_1`、`Q_1=S_1sinα` を使う。
8. 直流電動機へ接続する場合は `I_a=(V_d-E)/R_a` を求め、最後に `T=kΦI_a` とする。
9. `cosα`、単位、電圧の種類、平均値と実効値を検算する。
10. 高調波を含む実電流の総合力率と基本波力率を混同していないか確認する。

## 10. 二次試験型の記述手順

平均直流電圧を問われたら、最初から `1.35V cosα` とだけ書かず、次の順に示す。

```text
1. 1区間の線間電圧 v(θ)=√2V cosθ を置く
2. 積分区間 α-π/6 ～ α+π/6 を示す
3. 1周期に6区間あるので 6/(2π) を掛ける
4. 積分して V_d=(3√2/π)V cosα を得る
5. 損失無視なら P=V_dI_d
6. 必要なら I_1=(√6/π)I_d から S_1、Q_1 を求める
```

採点可能な記述にするため、式だけでなく「どの電圧を積分しているか」「なぜ交流有効電力と直流電力を等置できるか」という条件も短く添える。

## 11. 頻出ミス

- 線間実効値 `V` を相電圧と取り違える。
- `V` をそのまま波高値として使い、`√2` を落とす。
- `1.35V cosα` を条件なしでどの整流回路にも使う。
- `α=0` で出力0と誤解する。三相全波整流では `α=0` が最大平均直流電圧である。
- 一素子電流と直流側電流、平均値と実効値を混同する。
- 変換器損失無視という条件を確認せず `P_ac=P_dc` と置く。
- `Q_1` と高調波を含む実電流全体の無効・皮相電力を混同する。
- `cosα` を実電流全体の総合力率と断定する。
- 直流電動機で `V_d=E+I_aR_a` の抵抗降下を落とす。
- 200系の未確認回路定数を実車値として使う。

# 3段階例題

## 例題1 基礎: 制御角から平均直流電圧を求める

教材上の仮定値として、三相全波サイリスタ整流器の線間実効値を `V=400 V`、制御角を `α=30°` とする。直流電流は連続し、素子は理想、転流重なりは無視する。

(1) `α=0` の平均直流電圧を求める。

(2) `α=30°` の平均直流電圧を求める。

(3) (2) は (1) の何倍か。

### 解答

`α=0` では

```text
V_d0 = (3√2/π)×400
     ≒ 540 V
```

`α=30°` では

```text
V_d = (3√2/π)×400×cos30°
    ≒ 468 V
```

比は

```text
V_d/V_d0 = cos30°
          = 0.866
```

である。制御角を30°まで遅らせると、平均直流電圧は最大値の約86.6%になる。

## 例題2 本試験標準: 有効電力・無効電力・基本波力率

教材上の仮定値として、三相サイリスタ変換器の線間実効値を `V=1000 V`、平滑された直流電流を `I_d=500 A`、制御角を `α=30°` とする。変換器損失と転流重なりを無視する。

(1) 平均直流電圧 `V_d` を求める。

(2) 交流側有効電力 `P` を求める。

(3) 基本波線電流実効値 `I_1` と基本波皮相電力 `S_1` を求める。

(4) 基本波無効電力 `Q_1` と基本波力率を求める。

### 解答

平均直流電圧は

```text
V_d = (3√2/π)×1000×cos30°
    ≒ 1.170×10^3 V
```

したがって

```text
P = V_dI_d
  ≒ 1.1695×10^3×500
  ≒ 5.85×10^5 W
  = 585 kW
```

基本波線電流実効値は

```text
I_1 = (√6/π)I_d
    = (√6/π)×500
    ≒ 390 A
```

基本波皮相電力は

```text
S_1 = √3VI_1
    ≒ √3×1000×390
    ≒ 675 kVA
```

基本波無効電力は

```text
Q_1 = S_1sin30°
    ≒ 675×0.5
    ≒ 338 kvar
```

基本波力率は

```text
P/S_1 ≒ 585/675 ≒ 0.866
```

で、`cos30°` と一致する。これは基本波についての値であり、高調波を含む実電流全体の総合力率とは区別する。

## 例題3 二次相当: 位相制御から直流主電動機トルクまでつなぐ

教材上の仮定値として、三相線間実効値 `V=600 V`、制御角 `α=45°`、直流主電動機の逆起電力 `E=370 V`、電機子抵抗 `R_a=0.50 Ω`、`kΦ=1.20 N·m/A` とする。直流側電流は連続し、変換器損失、転流重なり、ブラシ電圧降下は無視する。比較時の回転速度と磁束は一定とする。

(1) 60°区間の積分から平均直流電圧の一般式を示す。

(2) `α=45°` の平均直流電圧を求める。

(3) 電機子電流と電磁トルクを求める。

(4) 直流側電流を電機子電流とみなし、この動作点の交流側有効電力と基本波無効電力を求める。

### 解答

1周期に同じ線間電圧片が6回現れるので

```text
V_d
= 6/(2π) ∫[α-π/6 → α+π/6] √2V cosθ dθ
= (3√2/π)V cosα
```

となる。

数値代入すると

```text
V_d
= (3√2/π)×600×cos45°
≈ 573 V
```

直流主電動機では

```text
V_d = E + I_aR_a
```

だから

```text
I_a = (V_d-E)/R_a
    = (573-370)/0.50
    ≒ 406 A
```

トルクは

```text
T = kΦI_a
  = 1.20×406
  ≒ 487 N·m
```

である。

変換器損失を無視し `I_d=I_a` とすれば

```text
P = V_dI_d
  ≒ 573×406
  ≒ 233 kW
```

基本波無効電力は

```text
Q_1 = (3√2/π)VI_d sinα
    = (3√2/π)×600×406×sin45°
    ≒ 233 kvar
```

となる。`α=45°` なので、同じ基本波皮相電力に対する有効成分と無効成分が等しい。
