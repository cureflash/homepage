# 教材で欠落不可の説明

1. 一次遅れ系 `K/(Ts+1)` について、`K` と時定数 `T` の意味、単位、ステップ応答、`t=T` での応答の読み方を説明する。
2. 時定数が大きいほど応答が遅くなることを式とステップ応答グラフの両方で示す。
3. 二次遅れ標準形 `Kω_n^2/(s^2+2ζω_n s+ω_n^2)` を示し、係数比較から `ζ` と `ω_n` を求められるようにする。
4. `ζ` の値によって応答が振動的か非振動的かを判定できるようにし、オーバーシュートとの関係を説明する。
5. 立上り時間、整定時間、オーバーシュートをステップ応答グラフ上で定義し、何を速応性・減衰性の指標として読むかを区別する。
6. ステップ入力、インパルス入力のラプラス変換を使い、`Y(s)=G(s)U(s)` から部分分数分解・逆ラプラス変換で `y(t)` を求める標準手順を示す。
7. 最終値の定理を用いて定常値・定常偏差を求める条件と手順を説明する。
8. 一次遅れでは時定数変更比較、二次遅れでは減衰係数変更比較のグラフを作り、式の係数変更が波形へどう現れるかを対応させる。
9. 新幹線側は速度指令に対する速度応答を一般的な一次・二次モデルとして図示する。一次資料で確認していない実車の時定数・ゲイン等は使わない。
10. Topic 19のPID調整、Topic 20の安定判別・周波数応答を使わなくても、固定5問・12答案要素へ到達できる構成にする。
