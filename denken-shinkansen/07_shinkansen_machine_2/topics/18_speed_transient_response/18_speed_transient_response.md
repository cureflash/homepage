# 解説source本文

## 1. このテーマで電験は何を問うか

Topic 17で求めた伝達関数に、ステップ・インパルス・指数関数などの入力を与え、「時間がたつと出力がどう変わるか」を求めるのが本テーマである。二種二次では、伝達関数の形を見て終わりではなく、入力のラプラス変換を掛け、部分分数分解し、逆ラプラス変換して `y(t)` を出すところまで必要になる。

この章では次を自力で処理できることを到達点とする。

1. 一次遅れの時定数とステップ応答を対応付ける。
2. 二次遅れの係数から `ω_n` と `ζ` を求める。
3. `ζ` から振動性とオーバーシュートの有無を判断する。
4. ステップ、インパルス、指数入力に対する `Y(s)` を作り、逆ラプラス変換する。
5. 指定時刻の応答値を `y(t)` へ代入して求める。
6. 最終値の定理から定常値・定常偏差を求める。
7. 立上り時間、整定時間、オーバーシュートをグラフから区別する。

Topic 19のPIDゲイン調整、Topic 20の安定判別・周波数応答は使わない。

## 2. 時間応答の基本式

零初期条件で伝達関数を

`G(s) = Y(s) / U(s)`

とする。入力のラプラス変換を `U(s)` とすれば

`Y(s) = G(s)U(s)`

である。ここから逆ラプラス変換して時間領域の出力 `y(t)` を得る。

時間応答は大きく、入力直後から変化している過渡部分と、十分時間が経過した後の定常部分に分けて読む。本テーマでは、過渡部分の速さを時定数・立上り時間・整定時間で、振動の大きさを減衰係数・オーバーシュートで、最終的なずれを定常偏差で扱う。

主な記号と単位は次のとおり。

| 記号 | 意味 | 単位 |
|---|---|---|
| `K` | 定常ゲイン | 入出力の単位比 |
| `T` | 一次遅れの時定数 | s |
| `ω_n` | 二次遅れの固有角周波数 | rad/s |
| `ζ` | 減衰係数 | 無次元 |
| `t_r` | 立上り時間 | s |
| `t_s` | 整定時間 | s |
| `M_p` | 最大オーバーシュート比 | 無次元、または%表示 |
| `e(∞)` | 定常偏差 | 偏差の単位 |

## 3. 一次遅れ `K/(Ts+1)`

一次遅れ系を

`G(s) = K/(Ts+1)`

とする。`K` は十分時間が経過したときの入力と出力の比、`T` は応答の速さを決める時定数である。`Ts` が無次元になるため、`s` の次元を `1/s` と見れば `T` の単位は秒である。

大きさ `A` のステップ入力では

`U(s) = A/s`

なので

`Y(s) = AK/{s(Ts+1)}`

となる。部分分数分解すると

`Y(s) = AK{1/s - T/(Ts+1)}`

であり、逆ラプラス変換して

`y(t) = AK(1-e^{-t/T})`

を得る。

最終値は `AK` である。`t=T` では

`y(T)/(AK) = 1-e^{-1} ≈ 0.632`

となるので、時定数 `T` は「最終値の約63.2%まで到達する時間」と読める。

代表値は次のとおり。

| 時刻 | 最終値に対する割合 |
|---|---:|
| `T` | 63.2% |
| `2T` | 86.5% |
| `3T` | 95.0% |
| `4T` | 98.2% |
| `5T` | 99.3% |

同じ `K` なら `T` が大きいほど指数関数の減衰が遅くなり、出力の立上りも遅くなる。

## 4. 一次遅れの立上り時間・整定時間

立上り時間は「最終値の何%から何%まで」を採用するかで定義が変わる。教材ではグラフに定義を併記し、無条件に一つの式だけを暗記しない。

一次遅れで10%から90%までを立上り時間とするなら

`0.1 = 1-e^{-t10/T}`

`0.9 = 1-e^{-t90/T}`

より

`t_r = t90-t10 = T ln 9 ≈ 2.20T`

となる。

整定時間も許容帯で変わる。一次遅れの誤差比は `e^{-t/T}` なので、最終値の±2%以内を整定とするなら

`e^{-t_s/T} = 0.02`

` t_s = -T ln 0.02 ≈ 3.91T`

であり、概算では約 `4T` と読める。±5%なら約 `3T` である。

「立上り時間」と「整定時間」はどちらも速応性の尺度だが、立上り時間は目標値付近へ到達するまで、整定時間は許容帯から再び外れなくなるまでを見る。

## 5. 二次遅れの標準形

二次遅れ系の標準形を

`G(s) = Kω_n^2 / (s^2 + 2ζω_n s + ω_n^2)`

とする。

分母が

`s^2 + a s + b`

まで整理されていれば、係数比較から

`ω_n = √b`

`ζ = a/(2ω_n) = a/(2√b)`

と求められる。`s^2` の係数が1でないときは、先に分母・分子をその係数で割って正規化してから比較する。

`ω_n` は応答の時間尺度を決める量で、単位は rad/s、`ζ` は振動の減衰の強さを表す無次元量である。

## 6. 減衰係数と振動性

標準的な二次遅れのステップ応答は `ζ` で形が変わる。

| `ζ` | 応答の特徴 |
|---:|---|
| `ζ = 0` | 減衰しない振動 |
| `0 < ζ < 1` | 振動しながら減衰する。オーバーシュートが生じる |
| `ζ = 1` | 臨界減衰。振動せずに収束する境界 |
| `ζ > 1` | 過減衰。振動せず、臨界減衰より緩やかに近づく |

`0<ζ<1` では減衰固有角周波数

`ω_d = ω_n√(1-ζ^2)`

を使うと、単位ステップ応答は

`y(t) = K[1 - e^{-ζω_n t}{cos(ω_d t) + ζ/√(1-ζ^2) sin(ω_d t)}]`

と表せる。

最大オーバーシュート比は

`M_p = exp{-πζ/√(1-ζ^2)}`

であり、百分率表示は `100M_p [%]` である。この式は `0<ζ<1` の標準二次遅れに使う。`ζ` が小さいほど振動性とオーバーシュートが大きくなる。

2%整定時間の代表的な近似は

`t_s ≈ 4/(ζω_n)`

5%整定時間なら

`t_s ≈ 3/(ζω_n)`

である。これは減衰包絡線を使う近似なので、問題が別の整定帯や定義を指定した場合はその条件を優先する。

## 7. ステップ・インパルス・指数入力を区別する

入力が変われば `U(s)` が変わる。伝達関数が同じでも時間応答は同じではない。

| 時間領域の入力 `u(t)` | `U(s)` |
|---|---|
| 単位ステップ `1` | `1/s` |
| 単位インパルス `δ(t)` | `1` |
| 指数入力 `e^{-at}` | `1/(s+a)` |

標準手順は次である。

1. 入力をラプラス変換して `U(s)` を作る。
2. `Y(s)=G(s)U(s)` を作る。
3. 分母を因数分解する。
4. 部分分数分解する。
5. 既知の変換対を使って逆ラプラス変換する。
6. `t=0`、`t→∞`、必要なら指定時刻を代入して検算する。

入力を掛け忘れて `G(s)` 自体を時間応答とみなす誤りを避ける。

## 8. 二次遅れのインパルス応答

`0<ζ<1` の二次遅れ標準形に単位インパルスを入力すると `U(s)=1` なので

`Y(s) = Kω_n^2 / {(s+ζω_n)^2 + ω_d^2}`

である。ここで

`ω_d = ω_n√(1-ζ^2)`

だから、逆ラプラス変換して

`y(t) = (Kω_n^2/ω_d)e^{-ζω_n t} sin(ω_d t)`

を得る。

同じ二次系でも、ステップ応答には最終値へ向かう定常成分があるのに対し、インパルス応答は入力後の過渡成分そのものを見る。設問でステップかインパルスかを最初に確認する。

## 9. 最終値の定理と定常偏差

応答が有限値へ収束する条件が満たされているとき、最終値は

`y(∞) = lim_{s→0} sY(s)`

で求められる。逆ラプラス変換を最後まで行わなくても定常値だけを直接求められる。

ただし、応答が収束しない場合に最終値の定理を機械的に使ってはいけない。本テーマでは「時間応答が収束することを確認してから使う」とし、収束性の詳しい判別法はTopic 20で扱う。

単位負帰還で目標値を `r(t)`、出力を `y(t)` とすれば

`e(t)=r(t)-y(t)`

である。したがって定常偏差は

`e(∞)=r(∞)-y(∞)`

または、偏差のラプラス変換 `E(s)` が得られていれば

`e(∞)=lim_{s→0}sE(s)`

で求める。

二種二次では、まず何の最終値を問われているかを区別する。出力の定常値 `y(∞)` と定常偏差 `e(∞)` は同じ量ではない。

## 10. グラフで読む三つの量

ステップ応答グラフでは次を区別する。

- 立上り時間 `t_r`: 出力が所定の低い割合から高い割合へ到達するまでの時間。速応性を見る。
- 整定時間 `t_s`: 出力が最終値の指定許容帯へ入り、その後外れなくなるまでの時間。速応性と減衰の両方が影響する。
- オーバーシュート: 応答の最大値が最終値をどれだけ上回ったか。二次遅れの減衰性を見る。

一次試験で「応答の速さ」に関する尺度を問われた場合、立上り時間や整定時間は速応性に対応する。オーバーシュートは速さそのものではなく、主に減衰の仕方を表す。

## 11. 時定数変更・減衰係数変更の比較条件

PDF・PowerPointで作る比較グラフは、実車値ではなく教材上の仮定値として次の条件で統一する。

一次遅れ:

`G(s)=1/(Ts+1)`

について `T=1 s, 2 s, 4 s` を比較する。定常値はすべて1で、`T` が大きいほど立上りが遅くなることだけを比較する。

二次遅れ:

`G(s)=ω_n^2/(s^2+2ζω_n s+ω_n^2)`

について `ω_n=1 rad/s` を固定し、`ζ=0.2, 0.5, 1.0` を比較する。`ζ` だけを変えて、オーバーシュート・振動性・整定の違いを見る。

この条件はグラフ比較用の教材仮定値であり、新幹線実車の制御定数ではない。

## 12. 新幹線の速度応答への接続

新幹線側では、速度指令の変化 `Δv_r(t)` に対する速度変化 `Δv(t)` を一般的な時間応答として考える。

最も単純な教材モデルとして

`ΔV(s)/ΔV_r(s) = 1/(Ts+1)`

と置けば、速度指令をステップ状に変えたとき

`Δv(t)=Δv_r(1-e^{-t/T})`

となる。ここで `T` は「どのくらい早く指令へ近づくか」を表すモデルパラメータである。

より振動性を持つ一般モデルは

`ΔV(s)/ΔV_r(s) = ω_n^2/(s^2+2ζω_n s+ω_n^2)`

と表せる。ただし、本教材は新幹線実車が必ず一次系または二次系そのものだと主張するものではない。一次・二次遅れを電験の時間応答問題へ結び付けるための一般化モデルであり、未確認の実車時定数・減衰係数・制御ゲインは置かない。

## 13. 問題を見たときの解法手順

1. 何の応答か確認する。ステップ、インパルス、指数入力を区別する。
2. 与えられた伝達関数の分母を整理する。二次系なら `s^2+2ζω_n s+ω_n^2` と係数比較できる形へ正規化する。
3. 入力をラプラス変換して `U(s)` を作る。
4. `Y(s)=G(s)U(s)` を作る。
5. 時間応答が必要なら部分分数分解し、逆ラプラス変換して `y(t)` を得る。
6. 指定時刻があれば `t` を代入する。
7. 定常値だけなら、収束条件を確認したうえで `lim sY(s)` を使う。
8. 定常偏差なら、目標値と出力の差なのか `E(s)` の最終値なのかを確認する。
9. グラフ問題なら、立上り時間・整定時間・オーバーシュートの定義を読み分ける。
10. `t=0`、`t→∞`、単位、最終値の大きさで検算する。

## 14. 基礎例題 — 一次遅れの時定数を読む

教材上の仮定モデル

`G(s)=1/(2s+1)`

へ単位ステップを入力する。時間応答、`t=2 s` の出力、10〜90%立上り時間、2%整定時間を求める。

### 解法

`K=1`、`T=2 s` なので

`y(t)=1-e^{-t/2}`

である。

`t=2 s` では

`y(2)=1-e^{-1}≈0.632`

となる。

10〜90%立上り時間は

`t_r=T ln9=2×2.197≈4.39 s`

2%整定時間は

`t_s=-T ln0.02=2×3.912≈7.82 s`

である。

検算すると、`t→∞` で `y(t)→1` となり、伝達関数の直流ゲイン1と一致する。

## 15. 本試験標準例題 — 二次遅れの係数比較

教材上の仮定モデル

`G(s)=25/(s^2+6s+25)`

について、固有角周波数 `ω_n`、減衰係数 `ζ`、減衰固有角周波数 `ω_d`、最大オーバーシュート比、2%整定時間の近似を求める。

### 解法1: 標準形と係数比較する

標準形の分母

`s^2+2ζω_n s+ω_n^2`

と比較する。

`ω_n^2=25`

より

`ω_n=5 rad/s`

である。

また

`2ζω_n=6`

なので

`ζ=6/(2×5)=0.6`

となる。

### 解法2: 振動に関わる量を求める

`0<ζ<1` なので減衰振動形である。

`ω_d=ω_n√(1-ζ^2)`

`=5√(1-0.36)`

`=5×0.8=4 rad/s`

最大オーバーシュート比は

`M_p=exp{-π×0.6/√(1-0.6^2)}`

`=exp(-0.75π)≈0.0948`

したがって約 `9.48%` である。

2%整定時間の近似は

`t_s≈4/(ζω_n)=4/(0.6×5)≈1.33 s`

となる。

## 16. 本試験標準例題 — 入力を掛けて逆ラプラス変換する

教材上の仮定伝達関数

`G(s)=4/(s+4)`

について、単位インパルス、単位ステップ、指数入力 `e^{-2t}` の各応答を求める。

### (1) 単位インパルス

`U(s)=1`

なので

`Y(s)=4/(s+4)`

よって

`y(t)=4e^{-4t}`

である。

### (2) 単位ステップ

`U(s)=1/s`

なので

`Y(s)=4/{s(s+4)}`

部分分数分解すると

`Y(s)=1/s-1/(s+4)`

したがって

`y(t)=1-e^{-4t}`

である。

### (3) 指数入力 `e^{-2t}`

`U(s)=1/(s+2)`

なので

`Y(s)=4/{(s+4)(s+2)}`

部分分数分解すると

`Y(s)=2/(s+2)-2/(s+4)`

よって

`y(t)=2e^{-2t}-2e^{-4t}`

となる。

同じ `G(s)` でも入力の `U(s)` を掛けると応答が変わる。設問で入力種別を読み落とさない。

## 17. 複合・ひっかけ例題 — 指定時刻と定常偏差を同時に求める

単位負帰還系の閉ループ伝達関数が教材上の仮定として

`Y(s)/R(s)=4/(s+5)`

で与えられ、単位ステップ目標値を入力する。`y(t)`、`t=0.4 s` の出力、定常値、定常偏差を求める。

### 解法1: 時間応答を求める

単位ステップなので

`R(s)=1/s`

したがって

`Y(s)=4/{s(s+5)}`

である。

部分分数分解すると

`Y(s)=0.8/s-0.8/(s+5)`

よって

`y(t)=0.8(1-e^{-5t})`

となる。

### 解法2: 指定時刻を代入する

`t=0.4 s` では

`y(0.4)=0.8(1-e^{-2})≈0.692`

である。

### 解法3: 定常値と定常偏差を求める

最終値の定理から

`y(∞)=lim_{s→0}sY(s)=4/5=0.8`

単位ステップ目標値の最終値は1なので

`e(∞)=1-0.8=0.2`

である。

「指定時刻の出力」「出力の定常値」「定常偏差」は別々の量である。最後に何を問われているかを取り違えない。

## 18. 頻出ミス

- 一次遅れ `K/(Ts+1)` で `T` と `1/T` を取り違える。
- `t=T` で100%到達すると考える。実際は約63.2%である。
- 二次遅れの分母を正規化せず、そのまま `2ζω_n` と係数比較する。
- `ω_n^2` の係数から `ω_n` を求めるとき平方根を取り忘れる。
- `ζ` と `ω_n` の単位を混同する。`ζ` は無次元、`ω_n` は rad/s である。
- ステップ入力で `1/s` を掛け忘れる。
- インパルス入力でも `1/s` を掛けてしまう。
- 指数入力 `e^{-at}` を `1/s` とする。
- 逆ラプラス変換前の `Y(s)` をそのまま時間応答とみなす。
- 最終値の定理を、収束しない応答へ機械的に使う。
- 出力の定常値と定常偏差を同じものとして扱う。
- オーバーシュートを速応性そのものと誤認する。
- 立上り時間や整定時間の許容帯・定義を問題文で確認しない。
- 教材上の仮定時定数や減衰係数を新幹線実車値として扱う。

## 20. 公式・解法まとめ

一次遅れ:

`G(s)=K/(Ts+1)`

ステップ応答:

`y(t)=AK(1-e^{-t/T})`

`t=T` で最終値の約63.2%。

`G(s)=Kω_n^2/(s^2+2ζω_n s+ω_n^2)`

係数比較:

`ω_n=√b`

`ζ=a/(2√b)`

ただし分母を `s^2+as+b` へ正規化してから使う。

減衰固有角周波数:

`ω_d=ω_n√(1-ζ^2)`

最大オーバーシュート比:

`M_p=exp{-πζ/√(1-ζ^2)}`

時間応答:

`Y(s)=G(s)U(s)`

入力:

- 単位ステップ `U(s)=1/s`
- 単位インパルス `U(s)=1`
- 指数入力 `e^{-at}` → `U(s)=1/(s+a)`

`y(∞)=lim_{s→0}sY(s)`

定常偏差:

`e(∞)=lim_{s→0}sE(s)`

または単位負帰還で `e(∞)=r(∞)-y(∞)`。
