基本関係は次で固定する。

`総損失 = 導通損失 + スイッチング損失`

公式過去問で要求されるスイッチング損失は、1周期当たりのターンオン・ターンオフ損失エネルギーから

`P_sw = (W_on + W_off) / T = f_sw (W_on + W_off)`

として扱う。

Topic 12以降の極数・同期速度・同期機・蓄電池・制御系論点、未確認の実車半導体定格・損失・温度・冷却性能は追加しない。GTO・IGBT・SiCの世代差を比較するときも、公開資料で確認できない数値を実値として補完しない。

# EXAM_ALIGNMENT

資格: 第二種電気主任技術者

主科目: 一次試験「機械」、二次試験「機械・制御」

論点:
- IGBT・MOSFET・SiC MOSFETなどパワー半導体素子の識別
- ON電圧・電流と導通損失の関係
- ターンオン／ターンオフ時の電圧・電流重なりとスイッチング損失
- 1回のスイッチング損失エネルギーとスイッチング周波数から平均損失を求める方法
- スイッチング周期／周波数と単位時間当たり損失の関係
- ソフトスイッチングによるスイッチング損失低減の考え方
- IGBT・逆並列ダイオードの導通区間と平均電流
- 素子損失を発熱・冷却・変換効率へ接続するために必要な損失集計

## 教材で欠落不可の説明

1. ON中の半導体には有限のON電圧があり、電流が流れるため導通損失が生じる。素子1個の導通損失を求めるときは、ON電圧モデルとその素子が実際に導通する区間・平均電流を対応させる。
2. ターンオン／ターンオフ中は素子電圧と素子電流が同時に非零となり、`p(t)=v(t)i(t)` の時間積分が1回のスイッチング損失エネルギーとなる。R02の線形波形モデルでは三角形面積から `W_off = V_dc I_dc T_2 / 2` を得る。
3. 1周期にターンオン・ターンオフが1回ずつある条件では、平均スイッチング損失は `P_sw=(W_on+W_off)/T=f_sw(W_on+W_off)`。1回当たり損失が同じならスイッチング周波数を上げるほど単位時間当たり損失は増える。
4. R04で問われるON電圧・漏れ電流・スイッチング損失・周期・ソフトスイッチングの関係を、一つの損失収支として説明する。漏れ電流によるOFF損失とスイッチング損失を混同しない。
5. H22二次型では、ゲート信号だけで平均素子電流を決めず、負荷電流の位相と正負からIGBT／逆並列ダイオードの導通区間を判定し、1周期平均を積分で求める。この平均電流を導通損失計算へ接続する。
6. 変換器全体の損失は、素子1個の損失と素子数・実際の導通／スイッチング条件を区別して集計する。素子単体値をそのまま装置全体損失としない。
7. `総損失 = 導通損失 + スイッチング損失` を起点に発熱・冷却・変換効率へ接続する。実車の損失、温度、冷却能力は一次資料等で確認できた値だけを実値として使う。
8. GTO・IGBT・SiCの比較では、耐圧・電流・スイッチング条件等が異なる資料値を無条件に横並びにしない。教材上の比較計算を行う場合は、入力条件と仮定値を明示し、同一条件で比較する。
