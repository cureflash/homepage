# EXAM_ALIGNMENT

資格: 第二種電気主任技術者

主科目: 一次試験「機械」、二次試験「機械・制御」

論点:
- 同期速度・滑り・電源周波数と回転速度の関係
- `N_s = 120 f / p`、`N = (1-s)N_s`、`f_2 = sf`
- 誘導電動機の磁束が概ね `V/f` に支配される理由
- V/f一定制御による磁束維持と速度制御
- 低速〜基底速度の定トルク領域
- 電圧上限到達後の弱め磁束・定出力領域
- ベクトル制御で磁束成分とトルク成分を分離して扱う概念
- d軸を磁束軸、q軸をそれと直交するトルク軸として捉える概念

## 教材で欠落不可の説明

1. 極数を `p` とすると同期速度は `N_s = 120f/p`、滑りは `s=(N_s-N)/N_s`、したがって `N=(1-s)N_s`。周波数を変えれば同期速度が変わり、インバータで連続速度制御できる。
2. 二次周波数は `f_2=sf`。固定子回転磁界と回転子巻線電流が作る回転磁界は、固定子から見ると同じ同期速度で回ることをR02二次型の相対速度計算で説明する。
3. 誘導起電力の基本関係 `E ≈ 4.44 f N Φ` から、巻数一定で電圧降下を無視できる範囲では `Φ ∝ V/f`。周波数だけ下げて電圧を保つと磁束が増え、飽和方向へ進むためV/fを保つ意味がある。
4. 基底周波数以下では `V/f` を概ね一定に保ち磁束をほぼ一定にすることで、電流制限内でほぼ定トルク領域を構成できる。
5. 定格電圧へ到達した後は電圧をそれ以上上げられないため、周波数増加に対して `V/f` が低下し磁束が弱まる。これを弱め磁束領域として扱い、概ね出力一定・トルクは速度に反比例する関係 `P=Tω` へ接続する。
6. H26型では、定加速域のV/f一定制御と定出力域の制御条件を区別して読めるようにする。高速度側の細部を新しい独立仕様へ広げない。
7. スカラーV/f制御は電圧と周波数を主に扱う。ベクトル制御は一次電流を磁束生成成分とトルク生成成分に分けて独立に扱う、という概念を説明する。
8. d軸は磁束軸、q軸はそれと直交する軸として導入し、磁束成分とトルク成分を分離して制御する意味まで説明する。厳密なPark/Clarke変換式は必須にしない。
9. 300系への接続は、インバータが電圧・周波数を可変して誘導主電動機を駆動するという範囲に限定する。未確認の実車制御定数・電圧値・周波数値は真値として追加しない。
