## 教材で欠落不可の説明

1. 極数を `p` とすると同期速度は `N_s = 120f/p`、滑りは `s=(N_s-N)/N_s`、したがって `N=(1-s)N_s`。周波数を変えれば同期速度が変わり、インバータで連続速度制御できる。
2. 二次周波数は `f_2=sf`。固定子回転磁界と回転子巻線電流が作る回転磁界は、固定子から見ると同じ同期速度で回ることをR02二次型の相対速度計算で説明する。
3. 誘導起電力の基本関係 `E ≈ 4.44 f N Φ` から、巻数一定で電圧降下を無視できる範囲では `Φ ∝ V/f`。周波数だけ下げて電圧を保つと磁束が増え、飽和方向へ進むためV/fを保つ意味がある。
4. 基底周波数以下では `V/f` を概ね一定に保ち磁束をほぼ一定にすることで、電流制限内でほぼ定トルク領域を構成できる。
5. 定格電圧へ到達した後は電圧をそれ以上上げられないため、周波数増加に対して `V/f` が低下し磁束が弱まる。これを弱め磁束領域として扱い、概ね出力一定・トルクは速度に反比例する関係 `P=Tω` へ接続する。
6. H26型では、定加速域のV/f一定制御と定出力域の制御条件を区別して読めるようにする。高速度側の細部を新しい独立仕様へ広げない。
7. スカラーV/f制御は電圧と周波数を主に扱う。ベクトル制御は一次電流を磁束生成成分とトルク生成成分に分けて独立に扱う、という概念を説明する。
8. d軸は磁束軸、q軸はそれと直交する軸として導入し、磁束成分とトルク成分を分離して制御する意味まで説明する。厳密なPark/Clarke変換式は必須にしない。
9. 300系への接続は、インバータが電圧・周波数を可変して誘導主電動機を駆動するという範囲に限定する。未確認の実車制御定数・電圧値・周波数値は真値として追加しない。

# 解説本文

## 1. このテーマで電験は何を問うか

誘導電動機の速度制御では、まず同期速度・滑り・二次周波数をつなぎ、その上でインバータの周波数と電圧をどう変えると磁束・トルク・速度が変わるかを判断する。一次試験では速度制御方式、`V/f`、磁束、定トルク・定出力、ベクトル制御の概念が選択式で問われる。二次試験では同期速度・回転子速度・滑り速度・二次周波数を順に計算する問題や、`V/f` 一定条件から電圧振幅・周期を求める問題へ接続する。

本章の解法経路は次で固定する。

`f → N_s → s → N・f_2 → V/f → Φ → 定トルク / 弱め磁束・定出力 → ベクトル制御概念`

## 2. 同期速度・滑り・二次周波数

教材内では総極数を `p`、電源周波数を `f [Hz]` とすると、同期速度 `N_s [min^-1]` は

`N_s = 120f/p`

である。滑り `s` は

`s = (N_s-N)/N_s`

なので、回転子速度は

`N = (1-s)N_s`

となる。また、回転子に誘導される二次電流の周波数は

`f_2 = sf`

である。

R02一次問3では総極数を `2p` と置く表記を採用している。この表記では同期角速度は `ω_s = 2πf/p`、回転角速度は `ω_m = 2πf(1-s)/p` となる。総極数を `p` と置く本教材の `N_s=120f/p` と矛盾するのではなく、記号の定義が違うだけである。

R02二次型では相対速度まで追う。固定子の回転磁界は固定子から見て `N_s` で回り、回転子は `N=(1-s)N_s` で回る。したがって回転子から見た固定子磁界の相対速度は

`N_s-N = sN_s`

である。回転子電流が作る回転磁界も回転子から見て `sN_s` で回るので、固定子から見ると

`N + sN_s = (1-s)N_s+sN_s = N_s`

となる。つまり固定子磁界と回転子磁界は、固定子から見れば同じ同期速度で回る。

## 3. 誘導電動機の速度を変える三つの入口

`N=(1-s)120f/p` から、速度を変える入口は極数 `p`、滑り `s`、周波数 `f` の三つである。

極数を切り替える方式は速度が段階的に変わるため、連続可変には向かない。滑りを変える方法の一つが一次電圧制御である。周波数と等価回路定数を同じとみなす範囲では誘導電動機の発生トルクは入力電圧のほぼ2乗に比例するため、一次電圧を下げると同じ負荷トルクを得るための滑りが大きくなり、回転速度が低下する。ただし滑り増加は二次銅損増加につながるため、高効率な広範囲速度制御には不利である。

インバータでは電源周波数 `f` を連続的に変えられるので、同期速度そのものを連続的に動かせる。これがV/f制御の出発点である。

## 4. なぜV/fを一定にするのか

正弦波磁束を仮定した誘導起電力の基本関係は

`E ≈ 4.44 f N_w Φ`

である。ここで `N_w` は巻数、`Φ` は磁束である。巻数一定、固定子の電圧降下を無視できる範囲で `V≈E` とみなせば、

`Φ ∝ V/f`

となる。

したがって周波数だけを半分にして電圧をそのままにすると `V/f` は2倍となり、磁束が増えて磁気飽和方向へ進む。逆に、電圧を固定したまま周波数だけ上げると `V/f` は小さくなり、磁束は弱くなる。

基底周波数以下では、周波数を変えるのに合わせて電圧も同じ比率で変え、`V/f` を概ね一定に保つ。これにより磁束をほぼ一定に維持できる。

R04二次型で50 Hzから25 Hzへ下げ、`V/f` を一定に保つなら、周波数は1/2なので電圧振幅も1/2とする。周期 `T=1/f` は逆比例するため2倍になる。

## 5. 基底速度以下の定トルク領域

基底周波数以下では `V/f` を概ね一定にして磁束 `Φ` をほぼ一定にする。誘導電動機のトルクは、概念的には磁束とトルクを作る電流成分の積に対応するため、磁束をほぼ一定に保ち、許容電流内でトルク成分を維持すれば、広い速度範囲でほぼ一定トルクを得られる。

鉄道用誘導電動機を扱うH26一次型では、可変電圧可変周波数装置で駆動する電動機として三相かご形誘導電動機を識別し、定加速域では `V/f` 一定制御を読む。ここで重要なのは、電圧だけ、または周波数だけを独立に変えるのではなく、磁束を維持するため両者の比を保つことである。

## 6. 基底速度を超えた弱め磁束・定出力領域

周波数を上げ続けると、やがてインバータ出力電圧が上限へ達する。そこから先は周波数を上げても電圧を同じ比率では上げられないため、`V/f` が低下し、磁束 `Φ` が弱くなる。これが弱め磁束領域である。

出力とトルクの関係は

`P = Tω`

である。高速度側で出力 `P` を概ね一定に保つなら

`T = P/ω`

なので、速度上昇に伴ってトルクはおおむね反比例して低下する。H26一次型の定出力域では、試験上の制御条件として `V一定・I_M一定・f_s可変` を識別する。ここで `I_M` は電動機電流、`f_s` は滑り周波数である。さらに高速度側の独立した制御則へは本Topicでは広げない。

## 7. V/f制御とベクトル制御の違い

V/f制御は、主に電圧と周波数の比を調整して磁束を保ち、定常的な速度制御を行うスカラー制御である。磁束とトルクを作る電流成分を個別に直接扱うのではなく、電圧・周波数という大きさを中心に制御する。

ベクトル制御では、一次電流を磁束生成成分とトルク生成成分に分けて扱う。概念上、磁束方向に合わせた軸をd軸、それと直交する軸をq軸とし、

- d軸成分: 磁束を主に担う
- q軸成分: トルクを主に担う

と考える。これにより磁束とトルクを分離して調整する考え方が得られる。H25一次型では「V/f制御は定常状態を主に扱う」「ベクトル制御はトルク成分と磁束成分を分ける」という区別まで押さえる。本TopicではPark変換・Clarke変換の式、磁束軸推定器、電流制御器の設計には進まない。

## 8. 問題を見たときの解法手順

### 同期速度・滑り・二次周波数

1. 総極数か極対数か、問題文の記号定義を確認する。
2. 総極数なら `N_s=120f/p` で同期速度を求める。
3. `N=(1-s)N_s` または `s=(N_s-N)/N_s` を使う。
4. 二次周波数は `f_2=sf`。
5. 回転磁界の相対速度を問われたら `N_s-N=sN_s` を使う。
6. 固定子から見た回転子磁界は `N+sN_s=N_s` で検算する。

### V/f・運転領域

1. 現在の周波数が基底周波数以下か以上かを判定する。
2. 基底周波数以下なら `V/f≈一定` を使い、電圧を周波数比で比例変更する。
3. 周期は `T=1/f` で求める。
4. 電圧上限到達後は `V一定 → V/f低下 → Φ低下` と追う。
5. 定出力なら `P=Tω` からトルクと速度の反比例関係を使う。

### ベクトル制御概念

1. V/f制御かベクトル制御かを区別する。
2. ベクトル制御なら「磁束生成成分」と「トルク生成成分」の分離を確認する。
3. d軸を磁束軸、q軸を直交するトルク軸として読む。
4. 厳密な座標変換式を要求されていない問題では、概念以上へ広げない。

## 9. 300系への接続

本教材では300系の誘導主電動機を、インバータが電圧と周波数を変えて誘導電動機の磁束・トルク・速度を制御する具体例として使う。ここで必要なのは「インバータ出力の `V` と `f` を変えれば、同期速度と磁束を制御できる」という電験の一般理論への接続である。公開一次資料で確認していない300系固有の電圧、周波数、制御定数、滑り周波数を真値として置かない。

## 10. 頻出ミス

- `p` が総極数か極対数かを確認せず、同期速度を2倍または1/2にする。
- 滑りを百分率のまま式へ代入し、`5%` を `5` としてしまう。式では `0.05` を使う。
- `f_2=sf` の `f_2` を固定子周波数と取り違える。
- 周波数だけを下げて電圧を一定にし、磁束一定と誤認する。
- `V/f` 一定で周波数を1/2にしたとき、電圧は1/2だが周期は2倍になる点を取り違える。
- 基底速度を超えても定トルクが続くと考える。電圧上限後は弱め磁束となり、定出力ならトルクは速度上昇に伴い低下する。
- ベクトル制御を「V/fをより細かく調整するだけ」と捉える。要点は磁束生成成分とトルク生成成分を分離して扱うことである。

# 3段階例題

## 例題1 基礎: 同期速度・滑り・二次周波数

4極、50 Hzの三相誘導電動機が滑り `s=0.04` で運転している。同期速度、回転子速度、二次周波数を求めよ。

### 解答

同期速度は

`N_s = 120×50/4 = 1500 min^-1`

回転子速度は

`N = (1-0.04)×1500 = 1440 min^-1`

二次周波数は

`f_2 = 0.04×50 = 2.0 Hz`

したがって、`N_s=1500 min^-1`、`N=1440 min^-1`、`f_2=2.0 Hz`。

検算として滑り速度は `1500-1440=60 min^-1`、`sN_s=0.04×1500=60 min^-1` で一致する。

## 例題2 標準: V/f一定制御

教材上の仮定として、50 Hzで400 Vを出力する誘導電動機駆動系を考える。磁束をほぼ一定に保ったまま25 Hzへ下げるとき、必要な出力電圧と交流周期を求めよ。

### 解答

基底周波数以下で `V/f` を一定にするので、

`400/50 = V/25`

より

`V = 200 V`

周期は

`T = 1/25 = 0.040 s = 40 ms`

である。50 Hz時の周期20 msと比べると2倍になっている。

したがって、25 Hzでは電圧200 V、周期40 msとする。周波数だけを半分にして400 Vのままにすると `V/f` が2倍になり、磁束が増える方向なので不適切である。

## 例題3 複合: 弱め磁束・定出力

教材上の仮定として、4極誘導電動機を60 Hz・400 Vで基底点とし、それより高い75 Hzで400 Vのまま運転する。75 Hz時の滑りを `s=0.03`、機械出力を300 kW一定とする。回転速度とトルクを求め、運転領域を説明せよ。

### 解答

75 Hzでの同期速度は

`N_s = 120×75/4 = 2250 min^-1`

回転速度は

`N = (1-0.03)×2250 = 2182.5 min^-1`

角速度は

`ω = 2πN/60 = 2π×2182.5/60 ≈ 228.55 rad/s`

出力一定なので

`T = P/ω = 300000/228.55 ≈ 1.31×10^3 N·m`

したがって回転速度は約 `2183 min^-1`、トルクは約 `1.31 kN·m`。

60 Hzで400 Vが電圧上限であるとすれば、75 Hzでも400 Vのため `V/f` は低下する。よって磁束は基底点より弱く、弱め磁束・定出力領域として扱う。速度が上がるほど、`P=Tω` を満たすためトルクは低下する。
