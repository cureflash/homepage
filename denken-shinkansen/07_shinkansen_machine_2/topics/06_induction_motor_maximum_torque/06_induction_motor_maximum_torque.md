## 教材で欠落不可の説明

1. 極数を `P`、極対数を `p` と区別し、`n_s=120f/P` と `ω_s=2πf/p` を混同しない。公式過去問では `p` の意味が問題ごとに異なるため、問題文の定義を必ず確認する。
2. `s=(n_s-n)/n_s`、`n=(1-s)n_s`、`f_2=sf` を相互に使えるようにする。
3. 一相分簡易等価回路から、`X=x_1+x_2'` と置いて
   `T=(3/ω_s)·[V_1^2(r_2'/s)]/[(r_1+r_2'/s)^2+X^2]`
   を導く手順を示す。
4. 最大条件を微分または分母最小条件から導き、
   `r_2'/s_m=sqrt(r_1^2+X^2)`、
   `s_m=r_2'/sqrt(r_1^2+X^2)`
   とする。
5. R03の定義（`p`は極対数）のもとで、
   `T_m=(3p/(4πf))·V_1^2/[r_1+sqrt(r_1^2+X^2)]`
   を導き、他条件一定なら最大トルク値は二次抵抗 `r_2'` に依存しないことを説明する。
6. 「停動トルク」が最大トルクを指す用語であることを一次問題へ接続する。
7. 同期速度近傍の小滑り領域では、条件を明示した上で `T∝s` と近似できることを説明し、この比例を全滑り域へ拡張しない。
8. 比例推移は、他の回路定数が同一ならトルク式が `r_2'/s` によって決まるため、二次抵抗を増やすと同一トルクを生じる滑りも同じ比率で増え、最大トルク値を保ったまま最大トルク点が高滑り側へ移ることとして説明する。
9. 周波数と回路定数を固定した電圧変更比較では `T(s)` と `T_m` が `V_1^2` に比例することを説明する。
10. 周波数変更比較では `n_s∝f` と `f_2=sf` を先に使う。インダクタンス一定の比較をする場合は `X=2πfL` によりリアクタンスも変化するため、電圧条件・抵抗・インダクタンスを何として固定するかを計算プログラムとグラフに明記する。暗黙にリアクタンス一定とはしない。
11. 速度―トルク特性には同期速度、最大トルク点、電動機運転域を示し、二次抵抗・電圧・周波数を変更した比較をSPEC指定どおり作る。
12. 頻出ミスとして、極数と極対数、同期速度と実回転速度、`f` と `f_2`、最大トルク値と最大トルク時滑り、`T∝s` の適用範囲を整理する。

# 解説本文

## 0. このテーマで電験二種は何を問うか

誘導電動機の問題では、回転速度を直接暗記するのではなく、`同期速度 → すべり → 二次周波数 → トルク式 → 最大トルク条件` を一続きで扱えることが必要になる。一次試験ではトルク式の係数、停動トルク、比例推移、同期速度近傍の比例関係などを選択式で判定する。二次試験では、与えられた極数・周波数・回路定数から同期速度、すべり、トルク、最大トルク時滑りまで途中式付きで導く。

この章では、速度―トルク特性を式で説明し、二次抵抗・電圧・周波数のいずれを変えたときに「最大トルクの大きさ」と「最大トルクが出る滑り」がどう変わるかを区別できる状態を目標とする。

## 1. 基礎関係式

極数を `P`、極対数を `p=P/2`、電源周波数を `f [Hz]` とする。同期速度は

`n_s = 120f/P = 60f/p  [min^-1]`

である。同期角速度は

`ω_s = 2πn_s/60 = 2πf/p  [rad/s]`

となる。過去問では `p` を極数として定義する場合と極対数として定義する場合があるため、記号そのものを暗記せず問題文の定義を確認する。

回転子速度を `n` とすると、すべりは

`s = (n_s-n)/n_s`

で、逆算すると

`n = (1-s)n_s`

である。通常の電動機運転では `0 < s < 1` となる。回転子から見た磁界の相対速度は `sn_s`、二次周波数は

`f_2 = sf`

である。したがって、速度問題は最初に `n_s` を求め、その後 `s` または `n`、最後に必要なら `f_2` を求めると崩れにくい。

## 2. トルク式の導出

一相分簡易等価回路で、一次相電圧を `V_1`、一次抵抗を `r_1`、二次抵抗一次換算値を `r_2'`、一次・二次漏れリアクタンスの和を

`X = x_1 + x_2'`

とする。負荷枝のインピーダンスは

`Z = r_1 + r_2'/s + jX`

なので、電流の大きさの二乗は

`|I|^2 = V_1^2 / [(r_1+r_2'/s)^2+X^2]`

となる。二次入力は

`P_2 = 3(r_2'/s)|I|^2`

であり、電磁トルクは同期角速度で割って

`T = P_2/ω_s`

と書ける。したがって

`T = (3/ω_s) · V_1^2(r_2'/s) / [(r_1+r_2'/s)^2+X^2]`

を得る。

この式では `r_2'/s` が重要である。すべりを変えたときのトルク変化も、二次抵抗を変えたときの比例推移も、この比を見ると整理できる。

## 3. 最大トルク

`y = r_2'/s` と置くと

`T = (3V_1^2/ω_s) · y / [(r_1+y)^2+X^2]`

となる。`y` について最大条件を求めると

`y^2 = r_1^2+X^2`

だから、最大トルク時には

`r_2'/s_m = sqrt(r_1^2+X^2)`

すなわち

`s_m = r_2'/sqrt(r_1^2+X^2)`

となる。この最大トルクを停動トルクという。

`a=sqrt(r_1^2+X^2)` と置けば、最大トルクは

`T_m = 3V_1^2 / [2ω_s(r_1+a)]`

である。`p` を極対数とするなら `ω_s=2πf/p` なので

`T_m = (3p/(4πf)) · V_1^2 / [r_1+sqrt(r_1^2+X^2)]`

となる。ここには `r_2'` が含まれない。したがって、他の条件を同じにして二次抵抗だけを変えると、最大トルク時滑り `s_m` は変わるが、最大トルク値 `T_m` は変わらない。

## 4. 比例推移

トルク式は、他の条件が一定なら `r_2'/s` が同じとき同じトルクになる。二次抵抗を `k` 倍にしたとき、同じトルクを得る滑りも `k` 倍にすれば

`(kr_2')/(ks) = r_2'/s`

となり、トルク式の値は変わらない。これが比例推移である。

特に最大トルク時滑りは

`s_m ∝ r_2'`

であるため、二次抵抗を増やすと最大トルク点は高滑り側、すなわち低速側へ移る。一方、最大トルク値は前節の式から変わらない。

同期速度近傍の小滑り領域では `r_2'/s` が `r_1` や `X` より十分大きいとみなせるので

`T ≈ 3V_1^2 s/(ω_s r_2')`

となり、条件一定なら `T ∝ s` と近似できる。この近似は同期速度近傍だけで使い、最大トルク点を越える広い範囲へ延長しない。

## 5. 電圧とトルク

周波数と回路定数を固定し、相電圧 `V_1` だけを変える。トルク式では `V_1^2` 以外は変わらないため

`T(s) ∝ V_1^2`

である。最大トルクも

`T_m ∝ V_1^2`

となる。一方、最大トルク時滑り

`s_m = r_2'/sqrt(r_1^2+X^2)`

には電圧が含まれないため変わらない。

例えば電圧を0.8倍にすれば、同じ滑りにおけるトルクと最大トルクは `0.8^2=0.64` 倍になるが、最大トルクが出る滑りは変わらない。

## 6. 周波数と速度―トルク特性

周波数を変える比較では、何を固定したかを必ず明示する。まず同期速度は

`n_s = 120f/P`

なので `n_s ∝ f` である。二次周波数は `f_2=sf` なので、同じ滑りでも電源周波数が変われば二次周波数も変わる。

さらに、一次・二次漏れインダクタンスの和を `L` として一定とする比較では

`X = 2πfL`

だから、周波数を変えるとリアクタンスも変わる。このとき

`s_m = r_2'/sqrt(r_1^2+(2πfL)^2)`

となり、周波数上昇時には一般に `s_m` は小さくなる。また `ω_s=2πf/p` も変わるため、最大トルクは単純な横移動だけでは表せない。

したがって周波数変更グラフでは、少なくとも「電圧一定」「抵抗一定」「インダクタンス一定」などの比較条件を明記し、リアクタンスだけを暗黙に一定としない。

## 7. 速度―トルク特性

速度軸で特性を見るときは、滑りとの向きを取り違えない。

- `s=0` は同期速度 `n=n_s`
- 電動機運転域では速度が下がるほど `s` は大きくなる
- 同期速度近傍では `T∝s` でトルクが増える
- `s=s_m` で停動トルク `T_m` に達する
- 二次抵抗を増やすと `s_m` が増え、最大トルク点は低速側へ移る
- 電圧だけを下げると、`s_m` は同じでトルク曲線の高さが `V_1^2` に従って低下する
- 周波数を変えると同期速度とリアクタンスの両方が変わるため、固定条件を明示して比較する

後続の計算プログラムと比較グラフでは、この対応関係を数値で確認する。

## 8. 解法アルゴリズム

過去問では次の順で処理する。

1. 問題文で `P`、`p` が極数か極対数かを確認する。
2. `n_s=120f/P` または `ω_s=2πf/p` を求める。
3. 回転速度が与えられたら `s=(n_s-n)/n_s` を求める。
4. 二次周波数が必要なら `f_2=sf` を使う。
5. トルク計算では `X=x_1+x_2'` と `r_2'/s` を先に作る。
6. 通常トルクは `T=(3/ω_s)V_1^2(r_2'/s)/[(r_1+r_2'/s)^2+X^2]` を使う。
7. 最大トルクなら、まず `s_m=r_2'/sqrt(r_1^2+X^2)` を判定する。
8. 二次抵抗変更は比例推移、電圧変更は `V_1^2`、周波数変更は `n_s` と `X=2πfL` の両方を見る。
9. 最後に `0<s<1`、単位、回転速度の大小関係を検算する。

## 9. 3段階例題

### 9.1 基礎例題: 同期速度・すべり・二次周波数

6極、50 Hzの三相誘導電動機が `960 min^-1` で回転している。同期速度、すべり、二次周波数を求める。

同期速度は

`n_s = 120×50/6 = 1000 min^-1`

である。したがって

`s = (1000-960)/1000 = 0.040`

であり、二次周波数は

`f_2 = sf = 0.040×50 = 2.0 Hz`

となる。

答え: `n_s=1000 min^-1`、`s=0.040=4.0 %`、`f_2=2.0 Hz`。

### 9.2 本試験標準例題: 最大トルクと比例推移

4極、50 Hz、相電圧 `V_1=200 V`、`r_1=0.20 Ω`、`r_2'=0.10 Ω`、`X=x_1+x_2'=0.80 Ω` の簡易等価回路を考える。最大トルク時滑りと最大トルクを求め、二次抵抗を `0.20 Ω` に増やした場合を比較する。

極対数は `p=2`、同期角速度は

`ω_s = 2πf/p = 50π ≈ 157.1 rad/s`

である。まず

`s_m = 0.10/sqrt(0.20^2+0.80^2)`

`= 0.10/0.8246 ≈ 0.121`

となる。最大トルクは

`T_m = 3×200^2 / [2×157.1×(0.20+0.8246)]`

`≈ 373 N·m`

である。

二次抵抗を2倍の `0.20 Ω` にすると

`s_m' = 0.20/0.8246 ≈ 0.243`

となり、最大トルク時滑りは2倍になる。一方、`T_m` の式には `r_2'` が含まれないため最大トルク値は約 `373 N·m` のままである。同期速度 `1500 min^-1` に対し、最大トルク点の速度は約 `1318 min^-1` から約 `1136 min^-1` へ低速側に移る。

### 9.3 複合・ひっかけ例題: 周波数変更時にリアクタンスを固定しない

4極誘導電動機で、相電圧 `200 V`、`r_1=0.20 Ω`、`r_2'=0.10 Ω` を一定とする。漏れインダクタンスの和 `L` も一定で、50 Hz時の `X=0.80 Ω` とする。周波数を60 Hzへ上げたときの同期速度、`X`、最大トルク時滑り、最大トルクを比較する。

50 Hzでは `n_s=1500 min^-1`、`X=0.80 Ω` である。60 Hzでは

`n_s = 120×60/4 = 1800 min^-1`

となる。`X=2πfL` なので

`X_60 = 0.80×60/50 = 0.96 Ω`

である。したがって

`s_m,50 = 0.10/sqrt(0.20^2+0.80^2) ≈ 0.121`

`s_m,60 = 0.10/sqrt(0.20^2+0.96^2) ≈ 0.102`

となる。

最大トルクは50 Hzで約 `373 N·m`、60 Hzでは

`T_m = (3×2/(4π×60))×200^2/[0.20+sqrt(0.20^2+0.96^2)]`

`≈ 270 N·m`

となる。この比較条件では周波数上昇によって同期速度が上がるだけでなく、リアクタンスも増え、最大トルク時滑りと最大トルク値も変化する。周波数変更を「速度軸だけの横移動」と考えるのが典型的な誤りである。

## 10. 頻出ミス

- `P` と `p` を記号だけで判断し、極数と極対数を取り違える。
- 同期速度 `n_s` と実回転速度 `n` を同じものとして扱う。
- 二次周波数を電源周波数 `f` のままとし、`f_2=sf` を忘れる。
- 最大トルク値 `T_m` と最大トルク時滑り `s_m` を同じ変化則で扱う。
- 二次抵抗を増やすと最大トルク自体も増えると誤解する。
- `T∝s` を全滑り域で使う。
- 電圧変更で `T∝V` とし、二乗則を落とす。
- 周波数変更時に、インダクタンス一定なのに `X` を固定する。

## 13. 公式・解法まとめ

- `n_s = 120f/P = 60f/p`
- `ω_s = 2πf/p`
- `s = (n_s-n)/n_s`
- `n = (1-s)n_s`
- `f_2 = sf`
- `X = x_1+x_2'`
- `T = (3/ω_s)·V_1^2(r_2'/s)/[(r_1+r_2'/s)^2+X^2]`
- `s_m = r_2'/sqrt(r_1^2+X^2)`
- `T_m = 3V_1^2/[2ω_s(r_1+sqrt(r_1^2+X^2))]`
- `p`を極対数とすると `T_m=(3p/(4πf))·V_1^2/[r_1+sqrt(r_1^2+X^2)]`
- 他条件一定で二次抵抗だけを変えると `s_m∝r_2'`、`T_m` は不変
- 同期速度近傍では条件付きで `T∝s`
- 周波数・回路定数一定の電圧変更では `T∝V_1^2`
- インダクタンス一定の周波数変更では `X=2πfL` も変化する
