## 答案ロック

### H25 一次 機械 問6 (2)

`K1 + K2/s + K3 s = Kp(1 + 1/(Ti s) + Td s)` より、`K1=Kp`, `K2=Kp/Ti`。

固定答案: `Ti=K1/K2`（解答群を「ヲ」と転記）

### R07 二次 機械・制御 問4 (1)

`Gc(s)=(2s+4)/s`, `Gp(s)=1/(s+3)`、単位負帰還より

`Ge(s)=1/[1+Gc(s)Gp(s)]=s(s+3)/(s^2+5s+4)`

固定答案: `Ge(s)=s(s+3)/(s^2+5s+4)`

### R07 二次 機械・制御 問4 (2)

`R(s)=a/s` と最終値の定理より

`e_ss=lim[s→0]sGe(s)R(s)=0`

固定答案: `0`

### R07 二次 機械・制御 問4 (3)

`R(s)=b/s^2` と最終値の定理より

`e_ss=b lim[s→0](s+3)/(s^2+5s+4)=3b/4`

固定答案: `3b/4`

### H30 二次 機械・制御 問4 (1)

固定答案:
- `Kp`: 比例ゲイン
- `Ti`: 積分時間

### H23 二次 機械・制御 問4 (4)

固定答案:
- 補償器名称: PID補償器
- `Kp`: 比例ゲイン
- `Ti`: 積分時間
- `Td`: 微分時間

### R02 二次 機械・制御 問4 (1)

`R(s)=0`, `C(s)=K`, `Gp(s)=1/[s(s+1)]` より

`E(s)=-D(s)/[1+KGp(s)]`

`D(s)=2/s^2` を代入すると

`E(s)=-2(s+1)/[s(s^2+s+K)]`

したがって

`e_v=lim[s→0]sE(s)=-2/K`

固定答案: `e_v=-2/K`

### R02 二次 機械・制御 問4 (2)

特性式 `s^2+s+K=0` と `s^2+2ζω_n s+ω_n^2=0` を比較し、`ζ=0.8` より

`K=[1/(2×0.8)]^2=0.390625`

固定答案: `K=0.391`
