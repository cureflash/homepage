# 解説source本文

## 1. このテーマで電験は何を問うか

Topic 17では制御系をブロック線図と伝達関数で表し、Topic 18ではその時間応答を読んだ。本テーマでは、その制御器をP、PI、PD、PIDへ変えたとき、偏差・定常偏差・オーバーシュート・応答速度がどう変わるかを扱う。

二種一次では、補償器の式を見てP・I・Dの各項を識別し、`Kp`、`Ki`、`Kd`、`Ti`、`Td` の関係を読み取れることが必要である。二次では、補償器とプラントから偏差伝達関数を作り、最終値の定理を使ってステップ・ランプ入力の定常偏差を求めるところまで要求される。

この章の到達点は次のとおり。

1. P、I、D各動作を時間領域とラプラス領域の両方で説明できる。
2. `Kp + Ki/s + Kd s` と `Kp(1+1/(Ti s)+Td s)` を相互変換できる。
3. P、PI、PD、PIDを式から判別できる。
4. 単位負帰還系の偏差伝達関数を作れる。
5. 最終値の定理でステップ・ランプ入力の定常偏差を求められる。
6. `Kp`、`Ki`、`Kd` を変えた応答を、定常偏差・オーバーシュート・応答速度で比較できる。

一般的な安定判別法、ラウス・フルビッツ、根軌跡、周波数応答はTopic 20で扱うため、この章では独立論点として扱わない。

## 2. 速度制御での偏差と操作量

目標速度を `r(t)`、実際の速度を `y(t)` とすると、偏差は

`e(t) = r(t) - y(t)`

である。制御器はこの偏差から操作量 `u(t)` を作る。

新幹線への接続は概念図として

`速度指令 r → 偏差 e → 制御器 C(s) → 駆動系・車両 G(s) → 速度 y → フィードバック`

とする。本教材で使う `C(s)` や `G(s)` の数値は電験の計算用・比較用の仮定値であり、実車のPIDゲイン、制御周期、速度制御アルゴリズムを表すものではない。

## 3. P・I・D各動作

### 3.1 P動作

比例動作は現在の偏差に比例して操作量を作る。

`u_P(t) = Kp e(t)`

ラプラス領域では

`U_P(s)/E(s) = Kp`

である。偏差が大きいほど大きく操作し、偏差が小さくなれば操作量も小さくなる。

### 3.2 I動作

積分動作は偏差を時間積分して蓄積する。

`u_I(t) = Ki ∫ e(t) dt`

ラプラス領域では零初期条件で

`U_I(s)/E(s) = Ki/s`

となる。偏差が残っている限り積分値が変化するため、定常偏差を小さくする、または条件を満たす系では0へするために用いられる。

### 3.3 D動作

微分動作は偏差の変化速度に比例して操作量を作る。

`u_D(t) = Kd de(t)/dt`

ラプラス領域では零初期条件で

`U_D(s)/E(s) = Kd s`

となる。一定偏差では微分値が0なので、D項は定常値そのものより過渡応答の形に影響する。本テーマでは、その影響を同一プラントの応答比較で確認する。

## 4. PIDの二つの標準表現

並列形を

`C(s) = Kp + Ki/s + Kd s`

とする。

一方、比例ゲイン・積分時間・微分時間で書けば

`C(s) = Kp(1 + 1/(Ti s) + Td s)`

である。展開して係数を比較すると

`Ki = Kp/Ti`

`Kd = Kp Td`

したがって `Kp ≠ 0` のとき

`Ti = Kp/Ki`

`Td = Kd/Kp`

である。

`Ti` と `Td` の単位は秒である。`Kp`、`Ki`、`Kd` の物理単位は偏差と操作量の単位に依存するが、`Ki` は比例係数を時間で割った次元、`Kd` は比例係数に時間を掛けた次元になる。

一次試験では、係数の文字が `K1`、`K2`、`K3` など別記号でも、`定数項`、`1/s` 項、`s` 項を見分ければよい。

## 5. P・PI・PD・PIDを式から判別する

| 制御器 | 伝達関数 | 含む動作 |
|---|---|---|
| P | `Kp` | 比例 |
| PI | `Kp + Ki/s` | 比例＋積分 |
| PD | `Kp + Kd s` | 比例＋微分 |
| PID | `Kp + Ki/s + Kd s` | 比例＋積分＋微分 |

積分時間・微分時間表示では

- PI: `Kp(1 + 1/(Ti s))`
- PD: `Kp(1 + Td s)`
- PID: `Kp(1 + 1/(Ti s) + Td s)`

と読める。

係数名を答える問題では、`Kp` は比例ゲイン、`Ti` は積分時間、`Td` は微分時間である。`Ki` を積分時間と呼ばないこと、`Kd` を微分時間と呼ばないことに注意する。

## 6. 単位負帰還系の基本式

制御器を `C(s)`、プラントを `G(s)` とし、単位負帰還とする。

`U(s) = C(s)E(s)`

`Y(s) = G(s)U(s)`

`E(s) = R(s) - Y(s)`

より

`E(s) = R(s) / {1 + C(s)G(s)}`

出力は

`Y(s) = C(s)G(s)R(s) / {1 + C(s)G(s)}`

である。

二種二次で定常偏差を問われたら、まず `E(s)` を作る。出力 `Y(s)` の最終値と偏差 `E(s)` の最終値を取り違えない。

## 7. 最終値の定理で定常偏差を求める

偏差が有限値へ収束する条件を満たすとき

`e(∞) = lim_{s→0} sE(s)`

を使う。

単位ステップ入力なら

`R(s) = 1/s`

なので

`e(∞) = lim_{s→0} 1/{1+C(s)G(s)}`

となる。

単位ランプ入力なら

`R(s) = 1/s^2`

なので

`e(∞) = lim_{s→0} 1/[s{1+C(s)G(s)}]`

となる。

最終値の定理は、応答が収束することを前提に使う。本テーマでは問題条件または扱う教材モデルで収束する場合だけ適用し、一般的な安定判別法はTopic 20へ送る。

## 8. P制御と定常偏差・応答速度

教材用の仮定プラントとして

`G(s) = 1/(2s+1)`

を考え、比例制御器を

`C(s) = Kp`

とする。単位負帰還の閉ループ伝達関数は

`Y(s)/R(s) = Kp/(2s+1+Kp)`

である。

単位ステップ入力に対する定常偏差は

`e(∞) = 1/(1+Kp)`

となる。この教材モデルでは `Kp` を大きくすると定常偏差が小さくなる。

また閉ループ伝達関数を

`Y(s)/R(s) = {Kp/(1+Kp)} / {2s/(1+Kp)+1}`

と書けば、時定数は

`T_cl = 2/(1+Kp)`

である。この教材モデルでは `Kp` を大きくすると応答も速くなる。

ただし、「`Kp` を大きくすれば常に望ましい応答になる」と一般化してはいけない。ゲイン変更の影響はプラントに依存するため、本テーマでは同一モデルで条件を一つずつ変えて比較する。

## 9. PI制御と定常偏差

同じ教材用プラント

`G(s) = 1/(2s+1)`

に

`C(s) = Kp + Ki/s = (Kp s + Ki)/s`

を接続する。

単位ステップ入力では

`e(∞) = lim_{s→0} 1/{1+C(s)G(s)}`

である。`Ki > 0` なら `s→0` で積分項 `Ki/s` が支配的になるので、収束条件を満たすこの教材モデルでは

`e(∞) = 0`

となる。

一方、単位ランプ入力では

`e(∞) = lim_{s→0} 1/[s{1+C(s)G(s)}]`

を使う。低周波極限では `G(0)=1`、`C(s)≈Ki/s` なので、この教材モデルでは

`e(∞) = 1/Ki`

となる。

ここで重要なのは、「積分項があるから全種類の入力で定常偏差が必ず0」ではないことである。入力の種類とループ内の積分要素数を確認して式から判断する。

## 10. PD・PIDと過渡応答

PD制御器は

`C_PD(s) = Kp + Kd s`

PID制御器は

`C_PID(s) = Kp + Ki/s + Kd s`

である。

D項は `s→0` で0になるため、定常偏差そのものを決める主役ではない。一方、時間変化する偏差に反応するので、同一プラント・同一入力で `Kd` を変えたとき、立上り、オーバーシュート、整定の形が変化する。

ただし、`Kd` を増やしたときの変化方向をプラント無関係の暗記にしない。本教材のグラフではプラントと他の係数を固定し、変えた係数だけに対する実際の応答を比較する。

## 11. 閉ループ分母をTopic 18の二次遅れへ接続する

教材用プラント

`G(s) = 1/(Ts+1)`

にPID制御器

`C(s) = Kp + Ki/s + Kd s`

を接続する。単位負帰還の特性分母は

`1 + C(s)G(s)`

から、分母・分子へ `s(Ts+1)` を掛けて整理すると

`(T+Kd)s^2 + (1+Kp)s + Ki`

となる。

`T+Kd > 0` で割れば

`s^2 + {(1+Kp)/(T+Kd)}s + Ki/(T+Kd)`

であり、Topic 18の標準二次形

`s^2 + 2ζω_n s + ω_n^2`

と係数比較できる。

したがって、この特定の教材モデルでは

`ω_n = √{Ki/(T+Kd)}`

`ζ = (1+Kp) / {2√{Ki(T+Kd)}}`

である。

この式は「PIDゲイン一般の効果」を断定する式ではない。固定した一次遅れプラントに対する教材上の比較式であり、実車の制御定数には使わない。

## 12. 基礎例題：PID係数を相互変換する

教材用の補償器を

`C(s) = 4 + 2/s + 0.8s`

とする。

並列形との比較から

`Kp = 4`

`Ki = 2`

`Kd = 0.8`

である。

積分時間と微分時間は

`Ti = Kp/Ki = 4/2 = 2 s`

`Td = Kd/Kp = 0.8/4 = 0.2 s`

となる。

逆に

`4(1 + 1/(2s) + 0.2s)`

を展開すれば元の式へ戻る。一次試験では、この係数比較を文字式のまま行えるようにする。

## 13. 本試験標準例題：P制御のステップ定常偏差

教材用プラントを

`G(s) = 1/(2s+1)`

比例制御器を

`C(s) = 3`

とし、単位負帰還、単位ステップ入力を考える。

偏差伝達関数は

`E(s) = R(s)/{1+C(s)G(s)}`

である。`R(s)=1/s` より

`e(∞) = lim_{s→0} sE(s)`

`= lim_{s→0} 1/{1+3/(2s+1)}`

`= 1/4 = 0.25`

となる。

閉ループ時定数は

`T_cl = 2/(1+3) = 0.5 s`

である。したがってこの例では、Pゲインが定常偏差と応答速度の両方へ現れることが確認できる。

## 14. 複合例題：PID閉ループを二次遅れとして読む

教材用プラントを

`G(s)=1/(2s+1)`

PID制御器を

`C(s)=2+1/s+0.5s`

とする。単位負帰還の閉ループ分母は

`(2+0.5)s^2 + (1+2)s + 1`

`= 2.5s^2 + 3s + 1`

である。2.5で割ると

`s^2 + 1.2s + 0.4`

となる。

Topic 18の標準形と比較して

`ω_n = √0.4 ≈ 0.632 rad/s`

`ζ = 1.2/(2√0.4) ≈ 0.949`

と求められる。

このように、PID係数を閉ループ分母へ反映し、二次遅れの係数へ変換すると、応答速度やオーバーシュートをTopic 18の指標へ接続できる。

## 15. `Kp`・`Ki`・`Kd`変更比較の計算条件

計算プログラムと解説PDFの応答比較では、実車値ではなく次の教材用仮定値を使う。

プラント:

`G(s) = 1/(2s+1)`

単位負帰還、単位ステップ入力とする。

基準PID:

`Kp = 2`

`Ki = 1`

`Kd = 0.5`

比較は一度に一つの係数だけを変える。

### Kp比較

`Ki=1`、`Kd=0.5` を固定し

- `Kp=1`
- `Kp=2`
- `Kp=4`

を比較する。

### Ki比較

`Kp=2`、`Kd=0.5` を固定し

- `Ki=0.5`
- `Ki=1`
- `Ki=2`

を比較する。

### Kd比較

`Kp=2`、`Ki=1` を固定し

- `Kd=0`
- `Kd=0.5`
- `Kd=1.0`

を比較する。

各グラフでは、最終値、10–90%立上り時間、2%整定時間、最大オーバーシュートを同じ定義で算出する。応答が単調な場合は最大オーバーシュートを0%とする。

これらは係数変更の影響を同一条件で比較する教材用パラメータであり、新幹線実車の制御値ではない。

## 16. P・PI・PD・PID比較の見方

同一プラント・同一入力で比較するときは、次の順に読む。

1. 最終値が目標値へ一致しているか。
2. 定常偏差が残るか。
3. 立上り時間が長いか短いか。
4. オーバーシュートがあるか、何%か。
5. 整定時間が長いか短いか。

P、PI、PD、PIDという名前だけから性能を断定せず、閉ループ式または計算結果で判定する。特に、係数変更で速応性とオーバーシュートが同時に変わる場合があるため、「速いほど常に良い」とは扱わない。

## 17. 新幹線の速度制御への接続

新幹線側では、運転・走行系から与えられる速度指令と実速度との差を偏差として考え、その偏差を減らす一般的なフィードバック制御の例としてPIDを接続する。

本教材で示す構成は

`速度指令 → PID制御器 → 駆動系・車両の教材モデル → 速度 → フィードバック`

である。

ここで説明するのは電験のPID制御を理解するための一般化モデルであり、特定形式の新幹線がこの連続時間PID式をそのまま実装していると主張するものではない。一次資料で確認していない実車PIDゲイン、制御周期、制御則、整定時間は使用しない。

## 18. 問題を見たときの解法手順

1. 補償器の式を `定数項`、`1/s` 項、`s` 項へ分ける。
2. P、PI、PD、PIDのどれかを判別する。
3. 必要なら `Kp`、`Ki`、`Kd` と `Ti`、`Td` を相互変換する。
4. 単位負帰還なら `E(s)=R(s)/{1+C(s)G(s)}` を作る。
5. 入力を確認する。ステップなら `1/s`、ランプなら `1/s^2` を使う。
6. 定常偏差なら `e(∞)=lim_{s→0}sE(s)` を使う。
7. 時間応答を問う場合は閉ループ伝達関数の分母を整理する。
8. 二次形へ整理できる場合はTopic 18の `ω_n`、`ζ`、オーバーシュート、立上り・整定時間へ接続する。
9. 何の値を答えるか確認する。`Ki` と `Ti`、`Kd` と `Td`、出力と偏差を取り違えない。
10. 問題が一般的な安定判別や周波数応答を要求する場合はTopic 20の論点として切り分ける。

## 19. 頻出ミス・ひっかけ

- `Ki` と `Ti` を同じ量だと思う。正しくは `Ki=Kp/Ti`。
- `Kd` と `Td` を同じ量だと思う。正しくは `Kd=Kp Td`。
- `Ti=Ki/Kp` と逆にする。正しくは `Ti=Kp/Ki`。
- `1/s` 項を微分、`s` 項を積分と取り違える。
- 定常偏差を求めるのに `Y(s)` の最終値だけを計算する。
- ステップ入力とランプ入力を同じ `R(s)` で扱う。
- 最終値の定理を、収束しない応答へ無条件に適用する。
- P制御でゲインを大きくすればどのプラントでも定常偏差が必ず0になると考える。
- 積分項があればどの入力に対しても定常偏差が0になると決め付ける。
- グラフ比較で `Kp`、`Ki`、`Kd` を同時に変え、どの係数の影響か分からなくする。
- 教材仮定値を新幹線実車の制御値として扱う。

## 21. 公式・解法まとめ

PID並列形:

`C(s)=Kp+Ki/s+Kd s`

時間定数表示:

`C(s)=Kp(1+1/(Ti s)+Td s)`

係数変換:

`Ki=Kp/Ti`

`Kd=Kp Td`

`Ti=Kp/Ki`

`Td=Kd/Kp`

単位負帰還の偏差:

`E(s)=R(s)/{1+C(s)G(s)}`

定常偏差:

`e(∞)=lim_{s→0}sE(s)`

入力:

- 単位ステップ: `R(s)=1/s`
- 単位ランプ: `R(s)=1/s^2`

教材用一次遅れプラント `G(s)=1/(Ts+1)` とPIDの閉ループ分母:

`(T+Kd)s^2+(1+Kp)s+Ki`

標準二次形への接続:

`ω_n=√{Ki/(T+Kd)}`

`ζ=(1+Kp)/{2√{Ki(T+Kd)}}`

この章では、式の名称だけでなく、補償器の判別、係数変換、偏差伝達関数、最終値の定理、時間応答比較までを一続きで処理する。
