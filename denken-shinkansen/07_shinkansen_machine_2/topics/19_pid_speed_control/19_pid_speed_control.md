# 教材で欠落不可の説明

1. P、I、D各動作について、偏差 `e(t)` から操作量 `u(t)` を作る意味を説明し、ラプラス領域で比例項・積分項・微分項へ対応させる。
2. `Gc(s)=Kp + Ki/s + Kd s` と `Gc(s)=Kp(1+1/(Ti s)+Td s)` の対応を示し、`Ki=Kp/Ti`、`Kd=Kp Td` を相互変換できるようにする。
3. P、PI、PD、PIDの各補償器を式とブロック線図で区別し、どの項を加えた構成かを説明する。
4. P制御について、比例ゲイン変更が閉ループ応答・定常偏差へどう現れるかを、同一の教材用制御対象とステップ応答で比較する。
5. I動作を加えたPI制御について、積分項が定常偏差へ与える効果を、R07二次のステップ・ランプ入力型へ接続して説明する。
6. D動作を加えたPD・PID制御について、微分項が過渡応答の形へ与える効果を、同一条件の応答比較で示す。
7. オーバーシュートと応答速度はTopic 18の定義を再使用し、P・PI・PD・PIDの比較指標としてグラフ上で読めるようにする。
8. 計算プログラムでは教材上の同一プラントを固定し、`Kp`、`Ki`、`Kd` のうち一つずつを変更して速度応答を比較する。教材用パラメータは仮定値と明記する。
9. 一般的な安定判別法をTopic 19へ追加せず、固定5問・12答案要素はTopic 20のラウス・フルビッツ、根軌跡、ボード線図等を使わず解ける構成にする。
10. 新幹線側は速度指令に対する速度制御の概念例として接続する。一次資料で確認していない実車PIDゲインや制御則は使用しない。
