# 解説source本文

## 1. このテーマで電験は何を問うか

Topic 22では、個別機器を暗記するのではなく、既習の式を同じ電力・速度・時間軸へ接続する。試験上の中心は次の6点である。

1. 変圧器で入力電力、出力電力、無負荷損、負荷損、効率を分けて扱う。
2. PWMコンバータとVVVFインバータで、信号波、キャリア、スイッチング、DCリンク、電力方向を区別する。
3. 誘導機で同期速度、滑り、電流、二次入力、トルク、機械出力を同じ符号規約で結ぶ。
4. モーター回転速度を歯車比と車輪径で列車速度へ変換し、トルクを駆動力へ変換する。
5. 速度指令と実速度の偏差からPI/PID制御を組み、閉ループ伝達関数、定常偏差、時間応答を読めるようにする。
6. 力行と回生を符号付き電力として同じ計算系列に載せる。

解法では、まず「どの段の量か」を決める。架線側電力、変圧器二次側電力、DCリンク電力、モーター電力、車輪側機械出力を混同しない。そのうえで、電気系は電力収支、回転系は角速度とトルク、走行系は力と加速度、制御系は偏差と伝達関数でつなぐ。

## 2. 主変圧器の電力収支と効率

### 2.1 損失を分ける

変圧器の規約効率では、出力を `P_out`、無負荷損を `P_0`、定格負荷時の負荷損を `P_cu,N`、負荷率を `x` とする。負荷損を巻線抵抗損中心の量として扱う基本問題では、負荷電流に比例する負荷率に対して

`P_cu(x) = x^2 P_cu,N`

となる。出力が定格容量 `S_N`、力率 `cosφ` を用いて

`P_out = x S_N cosφ`

と表せるなら、規約効率は

`η_tr = P_out / (P_out + P_0 + x^2 P_cu,N)`

である。

最大効率条件は、負荷率を変化させたとき固定損と負荷損が等しくなる条件

`P_0 = x^2 P_cu,N`

で判定する。これは「損失がゼロになる条件」ではない。

### 2.2 主回路へ渡す量

力行時は架線側から変圧器へ入った電力から損失を引き、次段へ渡す。

`P_tr,out = P_tr,in - P_loss,tr`

`P_loss,tr = P_0 + x^2 P_cu,N`

回生時は電力方向が逆になるが、損失自体は正の散逸量として扱う。したがって、符号付き電力と損失を同じ符号で足し引きしない。回生時に変圧器二次側から一次側へ戻せる電力は、二次側から戻る電力の絶対値から変圧器損失を差し引いて考える。

### 2.3 解法手順

1. 定格容量、負荷率、力率から出力を求める。
2. 無負荷損と負荷損を区別する。
3. 負荷損を `x^2` で換算する。
4. `出力 / (出力 + 損失)` で効率を求める。
5. 最大効率を問われたら `P_0 = x^2 P_cu,N` を使う。
6. 求めた出力または損失後電力をPWMコンバータ段へ渡す。

典型ミスは、負荷損を `x` 倍にすること、効率の分母に出力を入れ忘れること、定格容量[kVA]と有効電力[kW]を力率なしで同一視することである。

## 3. PWMコンバータ・DCリンク・VVVFインバータ

### 3.1 三つの役割を分ける

PWMコンバータは架線側交流とDCリンクの間、VVVFインバータはDCリンクと三相交流の主電動機の間に置く。DCリンクは直流側の中間段であり、交流周波数をそのまま通す場所ではない。

PWMでは、基準となる信号波と高周波のキャリアを比較してスイッチング状態を決める。信号波は得たい基本波の形・周波数に関係し、キャリアはスイッチングの時間尺度を決める。したがって「信号波周波数」と「キャリア周波数」と「出力基本波周波数」を同じ量として扱わない。

Topic 22の総合モデルでは、系列SPECに損失パラメータが指定されていないPWMコンバータとVVVFインバータについて、新たな実機損失値を作らない。基準計算では両段を理想電力変換器として扱い、変換損失を0と置く。この仮定は実車仕様ではなく、未指定値を真値化しないための教材用簡略化である。

### 3.2 電力方向

力行:

`架線 → 主変圧器 → PWMコンバータ → DCリンク → VVVFインバータ → 誘導電動機 → 車輪`

回生:

`車輪 → 誘導電動機 → VVVFインバータ → DCリンク → PWMコンバータ → 主変圧器 → 架線`

この二方向を同じモデルで扱うため、後述の符号規約では架線から車輪へ向かう電力を正、車輪から架線へ戻る電力を負とする。

### 3.3 インバータ周波数

誘導電動機の同期速度はインバータが与える電気周波数 `f` によって決まる。

`n_s = 120 f / p`

`n_s`: 同期速度[min^-1]

`f`: インバータ出力基本波周波数[Hz]

`p`: 極数

したがって、速度制御で周波数を変えることは、誘導機の同期速度を変えることに相当する。

## 4. 誘導電動機の電流・二次入力・トルク・出力

### 4.1 同期速度と滑り

回転子速度を `n` とすると滑りは

`s = (n_s - n) / n_s`

である。

- `0 < s < 1`: 電動機運転側
- `s = 0`: 同期速度
- `s < 0`: 回転子速度が同期速度を上回る発電機運転側

鉄道の回生制動へ接続するときは、負の滑りを「異常値」として捨てない。符号が電力方向を表す。

### 4.2 等価回路から電流を求める

一相分等価回路では、一次抵抗・一次漏れリアクタンスを `r_1`, `x_1`、二次側換算抵抗・漏れリアクタンスを `r_2'`, `x_2'` とする。二次枝の基本形は

`Z_2 = r_2'/s + j x_2'`

である。

L形等価回路を用いる問題では、励磁枝と二次枝を含む合成インピーダンスを作り、相電圧から一次電流、二次側換算電流を求める。三相量では、相電流と線電流、相電圧と線間電圧の結線関係を先に確定する。

二次側換算電流を `I_2'` とすると、二次入力は

`P_2 = 3 |I_2'|^2 r_2' / s`

二次銅損は

`P_cu2 = s P_2`

電磁変換される機械出力は

`P_m = (1 - s) P_2`

である。

### 4.3 トルク

同期角速度を

`ω_s = 2π n_s / 60`

回転子角速度を

`ω_m = 2π n / 60`

とすると、電磁トルクは

`T = P_2 / ω_s`

で求められる。機械損を無視する基本計算では

`T = P_m / ω_m`

とも整合する。軸出力が直接与えられた二次記述問題では、

`T_shaft = P_shaft / ω_m`

を用いる。kWをWへ、min^-1をrad/sへ直してから代入する。

### 4.4 発電機運転

`s < 0` では `r_2'/s` が負となり、二次入力と電磁トルクも発電機側の符号を取る。Topic 22では正負を消して絶対値だけにせず、力行・回生を同じ時系列で追えるよう符号付きで保持する。

### 4.5 解法手順

1. 極数と周波数から `n_s` を求める。
2. `n_s` と実回転速度から `s` を求める。
3. `r_2'/s` を含む等価回路を作る。
4. 電流を求める。
5. `P_2`、必要なら二次銅損と機械出力を求める。
6. `ω_s` または `ω_m` を使ってトルクへ変換する。
7. 符号を確認し、力行か回生かを判定する。

## 5. 歯車・車輪・列車速度・走行抵抗・加速度

### 5.1 回転速度から列車速度

本sourceでは歯車比を

`i = n_m / n_w`

と定義する。

`n_m`: 主電動機回転速度[min^-1]

`n_w`: 車輪回転速度[min^-1]

したがって

`n_w = n_m / i`

車輪径を `D`[m] とすると、滑りのない幾何学的な列車速度は

`v = π D n_w / 60`

よって

`v = π D n_m / (60 i)`

である。逆算は

`n_m = 60 i v / (π D)`

となる。

### 5.2 トルクから駆動力

歯車損失を未指定のため基準モデルでは理想歯車とする。車輪トルクは

`T_w = i T_m`

車輪半径 `D/2` を用いれば、レール方向の駆動力は

`F_tr = T_w / (D/2) = 2 i T_m / D`

である。

### 5.3 走行抵抗と加速度

列車質量を `M`、進行方向に逆らう走行抵抗の大きさを `F_R` とし、前進中を考えると

`M dv/dt = F_tr - F_R`

したがって

`a = (F_tr - F_R) / M`

である。

回生制動時は `T_m < 0` となるため `F_tr < 0` となり、加速度も減速側へ移る。数値積分では列車速度が0未満にならないよう停止条件を置くが、これは実車制御仕様ではなく数値計算上の境界条件である。

## 6. 速度フィードバックとPI/PID制御

### 6.1 ブロック線図

一般的な負帰還系を

`速度指令 r → 偏差 e → 制御器 C(s) → 制御対象 G(s) → 速度 y → フィードバック`

とする。単位フィードバックなら

`E(s) = R(s) - Y(s)`

である。

PI制御器は

`C(s) = K_p + K_i/s`

PID制御器は

`C(s) = K_p + K_i/s + K_d s`

で表す。時間領域では

`u(t) = K_p e(t) + K_i ∫e(t)dt + K_d de(t)/dt`

である。

### 6.2 閉ループ伝達関数

制御対象を `G(s)`、単位負帰還とすると、目標値から制御量への閉ループ伝達関数は

`Y(s)/R(s) = C(s)G(s) / {1 + C(s)G(s)}`

偏差伝達関数は

`E(s)/R(s) = 1 / {1 + C(s)G(s)}`

である。

定常偏差は、安定で最終値定理を適用できるとき

`e(∞) = lim[s→0] sE(s)`

で求める。ステップ入力とランプ入力では `R(s)` が異なるため、同じ制御器でも定常偏差の結論を機械的に流用しない。

### 6.3 インパルス応答と指定時刻出力

閉ループ伝達関数を `T(s)` とすると、単位インパルス入力に対する出力は

`y(t) = L^-1{T(s)}`

である。ステップ入力なら

`Y(s) = T(s)/s`

とし、逆ラプラス変換して `y(t)` を得る。指定時刻 `t=t_0` の値は、得られた時間関数へ `t_0` を代入する。

二次記述では「伝達関数を出して終わり」にせず、部分分数分解、逆ラプラス変換、初期値・最終値の整合まで示す。

### 6.4 Topic 22での制御入力

系列SPECの入力に「インバータ周波数」と「PI/PIDゲイン」が含まれるため、教材用総合モデルでは、基準インバータ周波数 `f_base(t)` にPI/PID出力による周波数補正 `u(t)` を加える。

`f_inv(t) = f_base(t) + u(t)`

これは実車の周波数指令生成アルゴリズムを再現したものではない。Topic 17〜19で扱った速度フィードバックを、Topic 22のインバータ周波数入力へ接続するための教材用簡略モデルである。

## 7. 力行・回生と電力フロー

### 7.1 符号規約

全時系列で次に統一する。

- 電力 `P > 0`: 架線側から車輪側へ流れる力行
- 電力 `P < 0`: 車輪側から架線側へ戻る回生
- トルク `T > 0`: 前進方向の駆動
- トルク `T < 0`: 前進中の制動

誘導機の二次入力は

`P_2 = T ω_s`

として符号付きで扱える。

基準モデルではPWMコンバータとVVVFインバータを理想変換器とするため、両段で電力値の符号と大きさを変えない。変圧器だけは §2 の損失を加える。

### 7.2 消費電力と回生電力

変圧器二次側から主回路へ流れる符号付き電力を `P_sec` とする。基準モデルでは誘導機側の符号付き電力と同じ向きで追跡する。

力行時:

`P_cat = P_sec + P_loss,tr`

回生時:

`P_cat = P_sec + P_loss,tr`

と同じ式を使う。ただし `P_sec < 0`、`P_loss,tr > 0` であるため、回生電力の絶対値は損失分だけ小さくなる。

出力列は

`P_consumption = max(P_cat, 0)`

`P_regeneration = max(-P_cat, 0)`

とし、両方を正の大きさ[kW]として保存する。これにより「時間―電力」と「時間―回生電力」を混同しない。

### 8.2 教材用速度指令

東京―新大阪の実速度曲線は未固定なので、基準計算では次の短縮した速度指令を用いる。

- `0 ≤ t < 120 s`: `0 → 40 m/s` の直線ランプ
- `120 ≤ t < 180 s`: `40 m/s` 一定
- `180 ≤ t < 300 s`: `40 → 0 m/s` の直線ランプ
- `300 ≤ t ≤ 330 s`: `0 m/s`

これは実路線の所要時間、最高速度、停車時分、勾配、距離を表さない。

### 8.3 基準インバータ周波数

速度指令 `v_ref` に対応して、滑り0ならその速度となるモーター回転速度を

`n_m,ref = 60 i v_ref / (πD)`

とする。対応同期周波数を

`f_base = p n_m,ref / 120`

で作り、§6のPI補正を加えて

`f_inv = f_base + u`

とする。`f_inv ≤ 0` となった計算点では周波数を0 Hzとして主電動機電流・トルクを0にする。これは数値計算の停止側境界条件であり、実車制御仕様ではない。

### 8.4 周波数によるリアクタンス換算

抵抗は基準モデルで一定とし、リアクタンスは

`x(f) = x_50 × f / 50`

で周波数換算する。

インバータ出力基本波線間電圧は教材用V/f近似として

`V_LL(f) = V_2LL × min(f/f_B, 1)`

とする。これはTopic 09で扱ったV/f制御の既習事項を総合モデルへ接続するための仮定であり、実車の変調率・電圧指令則ではない。

## 9. 時系列計算の手順

各時刻 `t_k = kΔt` で次を順に計算する。

1. 速度指令 `v_ref(t_k)` を求める。
2. 前時刻の列車速度 `v_k` から偏差 `e_k = v_ref - v_k` を求める。
3. 積分値を `I_e,k = I_e,k-1 + e_k Δt` で更新する。
4. PI/PID式から周波数補正 `u_k` を求める。
5. `f_base` と `u_k` から `f_inv` を求める。
6. `f_inv` と極数から同期速度 `n_s` を求める。
7. 列車速度から車輪回転速度、歯車比からモーター回転速度 `n_m` を逆算する。
8. `s=(n_s-n_m)/n_s` を求める。`f_inv=0` では停止側境界条件を使う。
9. 周波数換算した誘導機等価回路から主電動機電流を求める。
10. 二次入力 `P_2`、トルク `T_m`、機械出力を求める。
11. 歯車比と車輪径から駆動力 `F_tr` を求める。
12. `a_k=(F_tr-F_R)/M` で加速度を求める。
13. 前進速度を `v_{k+1}=max(0, v_k+a_kΔt)` で更新する。
14. 変圧器負荷率と損失を求め、架線側符号付き電力を計算する。
15. `P_consumption` と `P_regeneration` を分離して保存する。

プログラムでは、0除算、`s=0` 近傍、`f=0`、停止直前の符号反転に数値上のガードが必要である。ただしガードは物理モデルを変更するためではなく、式の特異点を数値計算で扱うために限定する。

## 10. 指定出力と6種類のグラフ、検算

### 10.1 保存列

CSVには最低限、次を保存する。

- `time_s`
- `speed_ref_mps`
- `speed_mps`
- `acceleration_mps2`
- `inverter_frequency_hz`
- `motor_speed_rpm`
- `slip`
- `motor_current_a`
- `motor_torque_nm`
- `motor_output_kw`
- `wheel_speed_rpm`
- `consumption_power_kw`
- `regeneration_power_kw`

これで系列SPECの出力「主電動機電流、トルク、出力、車輪速度、列車速度、加速度、消費電力、回生電力」を欠落なく保存できる。

### 10.2 グラフ

系列SPECどおり、次の6種類を作る。

1. 時間―速度
2. 時間―加速度
3. 時間―電流
4. 時間―トルク
5. 時間―電力
6. 時間―回生電力

時間―電力は消費電力を主に示し、時間―回生電力は回生区間の戻り電力を別図として示す。

### 10.3 数値QA

計算プログラム完成時に最低限次を確認する。

- `n_s = 120f/p` と保存値が一致する。
- `s = (n_s-n_m)/n_s` と保存値が一致する。
- `v = πDn_m/(60i)` と保存列車速度が丸め誤差内で一致する。
- `F_tr = 2iT/D` と力学計算が一致する。
- `a = (F_tr-F_R)/M` と保存加速度が一致する。
- 力行点ではトルク・主回路電力が力行側符号となる。
- 回生点では `s<0`、トルクが制動側符号となり、`regeneration_power_kw > 0` の点が存在する。
- 消費電力と回生電力が同一時刻に同時正値にならない。
- 速度が0未満にならない。
- 6グラフの元データがCSV列と一致する。
