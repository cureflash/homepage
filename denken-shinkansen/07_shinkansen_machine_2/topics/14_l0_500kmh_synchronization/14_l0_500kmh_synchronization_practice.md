使用する基本関係:

`E = V + jX_s I`

電動機（機内向き電流、`R_a≈0`）:

`V = E + jX_s I`

1相分:

`P_φ = VE/X_s × sinδ`

`P_3φ = 3VE/X_s × sinδ`

p.u.:

`P = VE/X_s × sinδ`

`P_max = VE/X_s`

`sinδ = PX_s/(VE)`

`K_s = I_fV/I_fI`

`X_s[p.u.] ≈ 1/K_s`

`Z_B = V_LL^2/S_3φ`

`X_s[Ω] = X_s[p.u.] Z_B`

# 一次試験型

## 問1 力率角と負荷角

同期機の角度の定義として最も適切なものを選べ。

1. 力率角 `θ` は `V` と `E` の位相差、負荷角 `δ` は `V` と `I` の位相差である。
2. 力率角 `θ` は `V` と `I` の位相差、負荷角 `δ` は `V` と `E` の位相差である。
3. `θ` と `δ` は常に同じ角である。
4. `θ` は同期リアクタンスだけで決まり、`δ` は電流に無関係である。
5. `δ` は必ず0°である。

### 正答

2

### 解説

力率角 `θ` は端子電圧 `V` と電機子電流 `I` の位相差であり、`cosθ` が力率である。負荷角 `δ` は端子電圧 `V` と内部起電力 `E` の位相差で、電力角式 `P=VE/X_s sinδ` に現れる。両者は一般に同じではない。

---

## 問2 同期電動機の励磁と力率

端子電圧と有効出力を一定とした同期電動機について、最も適切なものを選べ。

1. 不足励磁では進み力率、過励磁では遅れ力率となる。
2. 不足励磁では遅れ力率、過励磁では進み力率となる。
3. 励磁を変えても電機子電流は変化しない。
4. 適正励磁付近で電機子電流が最大になる。
5. 過励磁にすると必ず有効電力が0になる。

### 正答

2

### 解説

同期電動機では典型的に、不足励磁で遅れ力率、過励磁で進み力率となる。一定出力で界磁電流を変えると電機子電流はV字形に変化し、力率1付近で最小となる。

---

## 問3 同期発電機の励磁

無限大母線へ接続された同期発電機の一般的な励磁と電流の関係として最も適切なものを選べ。

1. 過励磁側では遅れ電流となり、無効電力を系統へ供給する側になる。
2. 過励磁側では必ず進み電流となる。
3. 不足励磁・過励磁に関係なく力率は常に1である。
4. 励磁を変えると同期速度だけが変化する。
5. 発電機では力率を定義できない。

### 正答

1

### 解説

発電機では電流を機外向きに取るため、電動機と同じ語感で遅れ／進みを丸暗記しない。一般的な無限大母線接続の発電機では、過励磁側で遅れ電流となり、無効電力を系統へ供給する側になる。

## 問4 p.u.電力角式

`V=1.0 p.u.`、`E=1.2 p.u.`、`X_s=0.60 p.u.`、`δ=30°` の同期機について、電力 `P` として正しいものを選べ。

1. 0.50 p.u.
2. 0.60 p.u.
3. 0.80 p.u.
4. 1.00 p.u.
5. 2.00 p.u.

### 正答

4

### 解説

p.u.では

`P=VE/X_s × sinδ`

より、

`P=1.0×1.2/0.60×sin30°=2×0.5=1.00 p.u.`

となる。p.u.式へ三相の係数3を追加しない。

## 問5 電力から負荷角を逆算

`V=1.0 p.u.`、`E=1.0 p.u.`、`X_s=0.50 p.u.` の同期機が `P=0.60 p.u.` を伝達している。負荷角 `δ` として最も近いものを選べ。

1. 8.63°
2. 17.46°
3. 30.00°
4. 36.87°
5. 53.13°

### 正答

2

### 解説

`sinδ=PX_s/(VE)`

より、

`sinδ=0.60×0.50/(1.0×1.0)=0.30`

したがって

`δ=sin^-1(0.30)≈17.46°`

である。

## 問6 最大出力

`V=1.0 p.u.`、`E=1.10 p.u.`、`X_s=0.55 p.u.` の同期機について、単純な円筒形・抵抗無視モデルでの最大出力 `P_max` として正しいものを選べ。

1. 0.50 p.u.
2. 0.605 p.u.
3. 1.10 p.u.
4. 1.65 p.u.
5. 2.00 p.u.

### 正答

5

### 解説

`P_max=VE/X_s`

より、

`P_max=1.0×1.10/0.55=2.00 p.u.`

である。最大出力は `sinδ=1`、すなわちこの単純モデルでは `δ=90°` で得られる。

## 問7 直列リアクタンス追加

端子電圧と内部起電力を一定とする。電力伝達に効く総リアクタンスが `0.50 p.u.` から `0.80 p.u.` に増加した。最大出力の変更後／変更前の比として正しいものを選べ。

1. 0.375
2. 0.500
3. 0.625
4. 1.250
5. 1.600

### 正答

3

### 解説

`P_max=VE/X` なので、`V,E` 一定なら最大出力はリアクタンスに反比例する。

`P_max,new/P_max,old = 0.50/0.80 = 0.625`

となる。

## 問8 無負荷試験と三相短絡試験

同期発電機の試験方法として最も適切なものを選べ。

1. 無負荷飽和曲線は端子短絡で測り、三相短絡特性は端子開放で測る。
2. 無負荷飽和曲線は端子開放で界磁電流と無負荷電圧を測り、三相短絡特性は三相端子を短絡して界磁電流と短絡電流を測る。
3. 両試験とも負荷抵抗を接続して測る。
4. 三相短絡特性は必ず強い磁気飽和を示すため直線にならない。
5. どちらの試験も同期リアクタンス評価には使わない。

### 正答

2

### 解説

無負荷試験では定格速度で電機子端子を開放し、界磁電流に対する無負荷端子電圧を測る。三相短絡試験では三相端子を短絡し、界磁電流に対する短絡電機子電流を測る。短絡時は一般に磁束が小さいため、短絡特性はほぼ直線となる。

## 問9 短絡比と同期リアクタンス

無負荷で定格電圧を生じる界磁電流が `I_fV=4.5 A`、三相短絡時に定格電機子電流を流す界磁電流が `I_fI=3.0 A` である。同期インピーダンス法で電機子抵抗を無視するとき、短絡比 `K_s` と同期リアクタンス `X_s[p.u.]` の組合せとして最も適切なものを選べ。

1. `K_s=0.667`、`X_s=1.50 p.u.`
2. `K_s=1.00`、`X_s=1.00 p.u.`
3. `K_s=1.50`、`X_s≈0.667 p.u.`
4. `K_s=1.50`、`X_s=1.50 p.u.`
5. `K_s=3.00`、`X_s≈0.333 p.u.`

### 正答

3

### 解説

`K_s=I_fV/I_fI=4.5/3.0=1.50`

である。同期インピーダンス法で電機子抵抗を無視する近似では、

`X_s[p.u.]≈1/K_s=1/1.50≈0.667 p.u.`

となる。

## 問10 p.u.からΩへの換算

三相基準で `V_LL=6.6 kV`、`S_3φ=3.0 MVA`、`X_s=0.80 p.u.` とする。同期リアクタンスの実単位値として最も近いものを選べ。

1. 5.81 Ω
2. 9.68 Ω
3. 11.62 Ω
4. 14.52 Ω
5. 18.15 Ω

### 正答

3

### 解説

基準インピーダンスは

`Z_B=V_LL^2/S_3φ`

なので、

`Z_B=6600^2/(3.0×10^6)=14.52 Ω`

したがって

`X_s=0.80×14.52=11.616 Ω≈11.62 Ω`

となる。kV・MVAをそのまま混在させず、単位をそろえる。

## 問11 同期電動機のフェーザから力率角と負荷角を分離する

同期電動機をp.u.で考える。端子電圧を `V=1∠0° p.u.`、同期リアクタンスを `X_s=0.50 p.u.`、電機子電流を `I=0.80∠-36.87° p.u.` とする。電機子抵抗は無視する。次に答えよ。

1. 電流を直交座標形式で表せ。
2. `jX_sI` を求めよ。
3. 内部起電力 `E` を求め、その大きさと偏角を求めよ。
4. 力率角 `θ` と負荷角 `δ` をそれぞれ求めよ。
5. `VI*` から得る有効電力と、電力角式から得る有効電力が一致することを確認せよ。

### 解答・完全解説

`cos36.87°≈0.8`、`sin36.87°≈0.6` なので、

`I=0.80(0.8-j0.6)=0.64-j0.48 p.u.`

である。

したがって、

`jX_sI=j×0.50×(0.64-j0.48)`

`=0.24+j0.32 p.u.`

となる。

電動機では

`V=E+jX_sI`

なので、

`E=V-jX_sI`

`=1-(0.24+j0.32)`

`=0.76-j0.32 p.u.`

である。

大きさは

`|E|=sqrt(0.76^2+0.32^2)≈0.8246 p.u.`

偏角は

`arg(E)=tan^-1(-0.32/0.76)≈-22.83°`

である。

したがって、力率角は `V` と `I` の角なので

`θ=-36.87°`

であり、電流は遅れである。一方、電動機の負荷角は `V` が `E` より進む角として

`δ=22.83°`

である。`θ` と `δ` は一致しない。

`VI*` から、

`P=Re(VI*)=Re(1×(0.64+j0.48))=0.64 p.u.`

となる。

電力角式でも、

`P=V|E|/X_s × sinδ`

`=1×0.8246/0.50×sin22.83°≈0.64 p.u.`

となり一致する。

### 検算

`jX_sI` は `I` より90°進む。さらに電動機では `E=V-jX_sI` とする。ここを発電機式と取り違えない。

## 問12 励磁低下と負荷角・最大出力

同期機をp.u.で考える。`V=1.0 p.u.`、`X_s=0.80 p.u.`、伝達電力 `P=0.75 p.u.` は一定とする。内部起電力が `E_1=1.20 p.u.` から `E_2=0.90 p.u.` へ低下した。電機子抵抗は無視する。

1. 変更前の負荷角 `δ_1` を求めよ。
2. 変更後の負荷角 `δ_2` を求めよ。
3. 変更前後の最大出力 `P_max1`,`P_max2` を求めよ。
4. 励磁低下が同一電力運転時の負荷角と最大出力へ与える影響を説明せよ。

### 解答・完全解説

変更前は、

`sinδ_1=PX_s/(VE_1)`

`=0.75×0.80/(1.0×1.20)=0.50`

より、

`δ_1=30.00°`

である。

変更後は、

`sinδ_2=0.75×0.80/(1.0×0.90)=0.6667`

より、

`δ_2≈41.81°`

である。

最大出力は、

`P_max1=VE_1/X_s=1.0×1.20/0.80=1.50 p.u.`

`P_max2=VE_2/X_s=1.0×0.90/0.80=1.125 p.u.`

となる。

したがって励磁低下で `E` が小さくなると最大出力は低下し、同じ電力を伝達するために必要な負荷角は増加する。この単純な定常モデルでは90°までの余裕が小さくなる。

### 検算

どちらも `P<P_max` であり、`sinδ≤1` を満たしている。

## 問13 無負荷・三相短絡試験から同期リアクタンスを求める

三相同期発電機について、線間定格電圧を `V_LL=6.6 kV`、定格線電流を `I_n=200 A` とする。無負荷で定格電圧を生じる界磁電流は `I_fV=5.0 A`、三相短絡時に定格電流を流す界磁電流は `I_fI=4.0 A` である。同期インピーダンス法を用い、電機子抵抗は無視する。

1. 短絡比 `K_s` を求めよ。
2. 同期リアクタンス `X_s[p.u.]` を求めよ。
3. 三相定格容量 `S_3φ` を求めよ。
4. 基準インピーダンス `Z_B` を求めよ。
5. 同期リアクタンス `X_s[Ω]` を求めよ。
6. 無負荷飽和曲線と三相短絡特性を得る試験状態をそれぞれ説明せよ。

### 解答・完全解説

短絡比は、

`K_s=I_fV/I_fI=5.0/4.0=1.25`

である。

したがって、

`X_s[p.u.]≈1/K_s=0.80 p.u.`

となる。

三相定格容量は、

`S_3φ=sqrt(3)V_LL I_n`

`=sqrt(3)×6600×200`

`≈2.286×10^6 VA=2.286 MVA`

である。

基準インピーダンスは、

`Z_B=V_LL^2/S_3φ`

`=6600^2/(2.286×10^6)`

`≈19.05 Ω`

となる。

よって、

`X_s=0.80×19.05≈15.24 Ω`

である。

無負荷飽和曲線は定格速度で電機子端子を開放し、界磁電流を変化させて無負荷端子電圧を測る。三相短絡特性は定格速度で三相端子を短絡し、界磁電流を変化させて短絡電機子電流を測る。

### 検算

短絡比が1.25なので `X_s[p.u.]` はその逆数で0.8程度となる。`X_s[Ω]` は `0.8×Z_B` なので `Z_B` より小さくなる。

## 問14 直列リアクタンス追加による電力角特性の変化

同期機をp.u.で考える。`V=1.0 p.u.`、`E=1.10 p.u.`、伝達電力 `P=0.80 p.u.` とする。初めの同期リアクタンスは `X_s=0.80 p.u.` である。ここへ外部直列リアクタンス `X_ext=0.30 p.u.` を追加し、電力伝達に効く総リアクタンスを `X_s+X_ext` とする。

1. 追加前の負荷角 `δ_1` を求めよ。
2. 追加後の負荷角 `δ_2` を求めよ。
3. 追加前後の最大出力を求めよ。
4. 最大出力の変更後／変更前の比を求めよ。
5. 同じ電力を伝達し続けるときの変化を説明せよ。

### 解答・完全解説

追加前は、

`sinδ_1=PX_s/(VE)`

`=0.80×0.80/(1.0×1.10)=0.5818`

より、

`δ_1≈35.58°`

である。

追加後の総リアクタンスは、

`X_total=0.80+0.30=1.10 p.u.`

であるから、

`sinδ_2=0.80×1.10/(1.0×1.10)=0.80`

より、

`δ_2≈53.13°`

となる。

最大出力は、

`P_max1=1.0×1.10/0.80=1.375 p.u.`

`P_max2=1.0×1.10/1.10=1.00 p.u.`

である。

比は、

`P_max2/P_max1=1.00/1.375≈0.7273`

となる。

直列リアクタンス追加により送れる最大出力は低下し、同じ0.80 p.u.を伝達するために必要な負荷角は大きくなる。

### 検算

追加後も `P=0.80 p.u.<P_max2=1.00 p.u.` なので、この単純モデルでは `sinδ≤1` を満たす。

## 問15 同期調相機の励磁と電機子電流

理想化した無負荷・損失無視の同期調相機をp.u.で考える。`V=1.0∠0° p.u.`、`X_s=0.40 p.u.`、`δ≈0` とし、機内向き電流を正とする。内部起電力の大きさを次の三条件とする。

- 条件A: `E=0.80 p.u.`
- 条件B: `E=1.00 p.u.`
- 条件C: `E=1.20 p.u.`

1. 各条件の電機子電流 `I=(V-E)/(jX_s)` を求めよ。
2. 各条件が不足励磁・適正励磁・過励磁のどれに対応するか示せ。
3. 各条件の電流が遅れ側・最小・進み側のどれに対応するか説明せよ。
4. 実機で条件Bでも電機子電流が完全な0 Aにならない理由を述べよ。

### 解答・完全解説

条件Aでは、

`I=(1.0-0.80)/(j0.40)`

`=0.20/(j0.40)=-j0.50 p.u.`

となる。これは不足励磁で、電流は端子電圧に対して90°遅れる側である。

条件Bでは、

`I=(1.0-1.00)/(j0.40)=0`

となる。理想化した損失無視モデルでは適正励磁で電流最小となる。

条件Cでは、

`I=(1.0-1.20)/(j0.40)`

`=-0.20/(j0.40)=+j0.50 p.u.`

となる。これは過励磁で、電流は進み側である。

実機では機械損、鉄損などを補う有効電流成分が必要であるため、`E≈V` でも電機子電流が完全な0 Aになるとは限らない。

### 検算

`E<V` では `V-E>0` なので `1/j=-j` により遅れ側、`E>V` では符号が反転して進み側になる。
