# 解説本文

## §1 このテーマで電験は何を問うか

Topic 14では、Topic 13で読めるようにした同期機の1相分等価回路とフェーザを、実際の二種一次・二次で要求される「角度・力率・励磁・電力」へ進める。

本試験で必要なのは、次の連鎖を一続きに扱えることである。

`フェーザ → θとδの区別 → 電力角式 → 励磁変化 → 最大出力 → 試験特性からX_sを求める`

式を暗記するだけでは不十分である。発電機か電動機か、電流の正方向、相値か線間値か、実単位かp.u.かを最初に整理し、電力角式が使える条件を確認してから計算する。

## §2 フェーザ、力率角θ、負荷角δ

電機子抵抗を同期リアクタンスに比べて無視できる円筒形同期機の基本モデルを使う。発電機で電流 `I` を機外向きに正とすると、1相分の関係は

`E = V + jX_s I`

である。発電運転では内部起電力 `E` が端子電圧 `V` より負荷角 `δ` だけ進む。

同期電動機で電流 `I` を電源から機内へ流れ込む向きに正とすると、

`V = E + jX_s I`

したがって

`E = V - jX_s I`

となる。電動運転では端子電圧 `V` が内部起電力 `E` より負荷角だけ進むと整理すると、電動機の入力電力も正の `δ` で扱える。

ここで二つの角を混同しない。

- 力率角 `θ`: `V` と `I` の位相差。`cosθ` が力率。
- 負荷角 `δ`: `V` と `E` の位相差。電力角式の `sinδ` に現れる。

`θ` と `δ` は一般に同じではない。フェーザ図で問題文の基準ベクトルを確認してから名称を付ける。

同期リアクタンス降下 `jX_sI` は `I` より90°進む。したがって、フェーザ問題では「`I` を描く→90°進めて `jX_sI` を描く→KVLで `E` を閉じる」の順が安全である。

## §3 電力角式をフェーザから導く

発電機で `V` を実軸基準とし、

`E = E(cosδ + j sinδ)`

とする。電機子抵抗を無視すると

`I = (E∠δ - V)/(jX_s)`

である。分子を実部と虚部に分けると、電流の有効分は

`Re(I) = E sinδ / X_s`

となる。したがって1相分の有効電力は

`P_φ = V Re(I) = VE/X_s sinδ`

である。

三相平衡機で `V`,`E` を相電圧、`X_s` を1相当たりの同期リアクタンスとして実単位で扱うなら、三相合計は

`P_3φ = 3VE/X_s sinδ`

である。一方、三相基準でp.u.化している場合は

`P[p.u.] = V[p.u.] E[p.u.] / X_s[p.u.] × sinδ`

と書ける。問題文が実単位かp.u.かを見ずに係数3を付け外ししない。

この式の主な成立条件は次である。

- 三相平衡
- 円筒形同期機の基本モデル
- 電機子抵抗を同期リアクタンスに対して無視
- 定常状態
- `V`,`E`,`X_s` の基準を一致させる

電動機では内部起電力が端子電圧より遅れる角を正の負荷角として定義すれば、吸収する有効電力の大きさを同じ形 `VE/X_s sinδ` で扱える。

逆算も頻出である。

`sinδ = PX_s/(VE)`

したがって、右辺が1を超えた場合は、この単純モデルではその条件で定常同期運転を維持できないことを示す。

## §4 励磁、力率、電機子電流

端子電圧 `V` と有効電力 `P` が一定のとき、界磁を変えると内部起電力の大きさ `E` が変わる。電力角式

`P = VE/X_s sinδ`

より、`P,V,X_s` を一定とすれば、`E` を下げるほど同じ電力を保つため `sinδ` を大きくする必要があり、負荷角 `δ` は増える。

同時に、フェーザ式から電機子電流の無効分が変わる。同期電動機では典型的に、

- 不足励磁: 遅れ力率側
- 適正励磁: 力率1付近で電機子電流が最小
- 過励磁: 進み力率側

となる。一定出力で界磁電流を横軸、電機子電流を縦軸に取るとV字形になるためV曲線と呼ぶ。

発電機では電流の正方向が機外向きになるため、遅れ／進みの対応を電動機と同じ語感で丸暗記しない。一般的な無限大母線接続の発電機では、過励磁側で遅れ電流として無効電力を系統へ供給し、不足励磁側で進み電流となる。

同期調相機の理想化した無負荷・損失無視では有効電力はほぼ0で `δ≈0` とでき、

`I = (V-E)/(jX_s)`

となる。このとき `E` と `V` の差が無効電流を決め、`E=V` で理想的には電機子電流が最小になる。実機損失を含む場合は有効分が残るため、完全な0 Aにはならない。

## §5 電力角特性と最大出力

`V,E,X_s` を一定とすると、

`P = P_max sinδ`

`P_max = VE/X_s`

である。単純な円筒形・抵抗無視モデルでは `δ=90°` で `sinδ=1` となり最大出力を取る。

したがって、

- `E` が大きいほど `P_max` は大きい。
- `X_s` が大きいほど `P_max` は小さい。
- 外部へ直列リアクタンス `X_ext` が追加されるなら、電力伝達に効くリアクタンスを `X_s+X_ext` として扱い、送れる電力は低下する。

同一電力を運ぶとき、`E` を下げる、または直列リアクタンスを増やすと必要な `δ` は大きくなる。`0<δ<90°` の上り側では `δ` が90°へ近づくほど、この単純モデル上の静的な同期余裕は小さくなる。

ここでは電力角特性の定常的な意味までを扱う。過渡安定度、等面積法、過渡／初期過渡リアクタンスはTopic 14固定範囲外なので追加しない。

## §6 無負荷飽和曲線、三相短絡特性、短絡比、同期インピーダンス

同期発電機の `X_s` は、無負荷試験と三相短絡試験から求める代表的な方法がある。

### 無負荷飽和曲線

定格速度で電機子端子を開放し、界磁電流 `I_f` を変化させて無負荷端子電圧を測る。横軸 `I_f`、縦軸無負荷電圧の曲線が無負荷飽和曲線である。低励磁域ではほぼ直線、高励磁域では鉄心飽和のため増加が鈍る。

### 三相短絡特性

定格速度で電機子三相端子を短絡し、界磁電流を変化させて短絡電機子電流を測る。短絡時は端子電圧がほぼ0で、一般に磁束が小さいため短絡特性はほぼ直線となる。

### 短絡比

無負荷で定格電圧を生じる界磁電流を `I_fV`、三相短絡時に定格電機子電流を流す界磁電流を `I_fI` とすると、短絡比は

`K_s = I_fV / I_fI`

で定義できる。

同期インピーダンス法で電機子抵抗を無視し、試験基準をそろえると、同期リアクタンスのp.u.値は概ね

`X_s[p.u.] ≈ 1/K_s`

の関係になる。

三相定格の基準インピーダンスは、線間電圧基準なら

`Z_B = V_LL^2 / S_3φ`

である。したがって

`X_s[Ω] = X_s[p.u.] × Z_B`

と換算する。相電圧・相電流で計算しても同じ基準インピーダンスになるよう、Y/Δと線間／相の取り違えを避ける。

同期インピーダンスを無負荷・短絡試験値から直接求める場合は、同じ界磁電流における無負荷相電圧 `E_0` と短絡電流 `I_sc` を用いて

`Z_s = E_0 / I_sc`

とし、`R_a` が十分小さいとき `X_s≈Z_s` とみなす。飽和の扱いと、どの界磁電流で対応させるかを問題文に合わせる。

## §7 L0系への接続

Topic 13で確認したJR東海一次資料の範囲では、ガイドウェイの推進コイルが進行方向へ移動する磁界を作り、車両側の超電導磁石との吸引・反発によって推進する。

Topic 14では、この同期機の電気的な考え方を定性的に一段進める。回転同期機で端子側磁界と界磁側の間に負荷角が生じて電力を授受するのと同様に、リニア同期モータでも移動磁界と車両側界磁の相対的な電気位相が推進力・電力授受を理解する鍵になる。

ただし、回転同期機の `P=VE/X_s sinδ` をそのままL0系実機の推力式として数値適用するものではない。公開資料から固定できない推進コイル寸法、極ピッチ、電圧、電流、等価リアクタンス、推力、500 km/h時の電気周波数は実値化しない。

## §8 問題を見たときの解法手順

1. 同期発電機か同期電動機かを判定し、電機子電流の正方向を確認する。
2. `V`,`I`,`E`,`jX_sI` をフェーザ上で識別する。
3. `θ` は `V` と `I`、`δ` は `V` と `E` の角であることを確認する。
4. 実単位なら相値／線間値、三相合計／1相分を整理し、p.u.なら基準をそろえる。
5. 電機子抵抗無視など電力角式の成立条件を確認する。
6. 必要ならフェーザ式から `P=VE/X_s sinδ` を導き、求める量に合わせて逆算する。
7. 励磁変化なら `E` の変化から `δ`、力率、電機子電流の向きを追う。
8. 最大出力なら `sinδ≤1` と `P_max=VE/X_s` を使い、必要な `δ` が90°へ近づき過ぎていないか確認する。
9. 無負荷／短絡試験なら曲線の意味、短絡比、p.u.→Ωの順に処理する。
10. 最後に単位、`|sinδ|≤1`、電力増減の向きが物理的に妥当か確認する。

## §9 3段階例題

以下の数値はすべて教材上の仮定値であり、L0系の実機値ではない。

### 例題1 基礎: 電力角式の意味

p.u.値で `V=1.0`、`E=1.20`、`X_s=1.50`、負荷角 `δ=30°` の円筒形同期機を考える。電機子抵抗は無視する。有効電力と最大出力を求める。

電力角式

`P = VE/X_s sinδ`

より

`P = 1.0×1.20/1.50×sin30° = 0.40 p.u.`

最大出力は

`P_max = VE/X_s = 1.0×1.20/1.50 = 0.80 p.u.`

である。現在の出力は最大出力の半分であり、`δ=30°` は `90°` より十分小さい。ここで使った `δ` は `V` と `E` の角であり、力率角 `θ` ではない。

### 例題2 本試験標準: 励磁低下と負荷角・最大出力

無限大母線に接続された円筒形同期機をp.u.で考える。`V=1.0`、`X_s=1.0`、有効電力 `P=0.75` を一定とする。初め `E=1.25` であったが、励磁低下により `E=1.00` になった。電機子抵抗は無視する。変更前後の負荷角と最大出力を求め、同期余裕の変化を説明する。

変更前:

`sinδ_1 = PX_s/(VE) = 0.75/(1.0×1.25) = 0.60`

`δ_1 ≈ 36.87°`

`P_max1 = VE/X_s = 1.25 p.u.`

変更後:

`sinδ_2 = 0.75/(1.0×1.00) = 0.75`

`δ_2 ≈ 48.59°`

`P_max2 = 1.00 p.u.`

励磁低下で `E` が小さくなると最大出力は低下し、同じ有効電力を送るために必要な負荷角は大きくなる。したがって、この単純な定常モデルでは90°までの余裕は小さくなる。

### 例題3 複合: 無負荷・短絡試験から同期リアクタンスと最大出力へ

三相同期発電機の教材用試験条件を、線間定格電圧 `V_LL=400 V`、定格線電流 `I_n=100 A` とする。無負荷で定格電圧を生じる界磁電流を `I_fV=4.0 A`、三相短絡時に定格電流を流す界磁電流を `I_fI=3.2 A` とする。電機子抵抗を無視し、短絡特性はこの範囲で直線とする。短絡比、同期リアクタンス[p.u.]、同期リアクタンス[Ω]を求める。さらに `V=1.0 p.u.`、`E=1.10 p.u.` としたときの最大出力を求める。

短絡比:

`K_s = I_fV/I_fI = 4.0/3.2 = 1.25`

したがって

`X_s[p.u.] ≈ 1/K_s = 0.80 p.u.`

三相定格容量は

`S_3φ = sqrt(3) V_LL I_n`

`= sqrt(3)×400×100 ≈ 69.28 kVA`

基準インピーダンス:

`Z_B = V_LL^2/S_3φ`

`= 400^2/69282 ≈ 2.309 Ω`

したがって

`X_s ≈ 0.80×2.309 ≈ 1.848 Ω`

最大出力はp.u.で

`P_max = VE/X_s = 1.0×1.10/0.80 = 1.375 p.u.`

となる。試験特性から得た `X_s` が電力角式の分母へ入り、`X_s` が大きいほど最大出力が小さくなることまで一つの計算鎖で確認できる。

## §10 頻出ミス

- 力率角 `θ` と負荷角 `δ` を同じ角として扱う。
- 発電機と電動機で電流の正方向を確認せず、`E=V+jX_sI` と `V=E+jX_sI` を機械的に混用する。
- `jX_sI` を `I` と同方向に描く。`j` は90°進みである。
- 実単位の三相合計で係数3を落とす、またはp.u.式へ不要な3を付ける。
- 線間電圧をそのまま相電圧式へ代入する。
- `sinδ=PX_s/(VE)` が1を超えても計算を続ける。
- `P_max` を現在の運転電力と取り違える。
- 励磁を下げても同一電力なら負荷角が変わらないと思い込む。
- 同期電動機の過励磁／不足励磁と、発電機の遅れ／進みの関係を同一方向で丸暗記する。
- 無負荷飽和曲線と三相短絡特性の測定状態を逆にする。
- 短絡比 `K_s` と `X_s[p.u.]` の近似的な逆数関係を取り違える。
- `Z_B=V_LL^2/S_3φ` でVAとkVAを混在させる。
- L0系へ未確認の極ピッチ・周波数・電流・推力を実値として補う。

## §12 公式・解法まとめ

- 発電機（機外向き電流、`R_a≈0`）: `E=V+jX_sI`
- 電動機（機内向き電流、`R_a≈0`）: `V=E+jX_sI`
- 力率角 `θ`: `V` と `I` の角、力率 `cosθ`
- 負荷角 `δ`: `V` と `E` の角
- 1相分: `P_φ=VE/X_s sinδ`
- 三相実単位: `P_3φ=3VE/X_s sinδ`（`V`,`E` は相値）
- p.u.: `P=VE/X_s sinδ`
- 最大出力: `P_max=VE/X_s`
- 逆算: `sinδ=PX_s/(VE)`
- 短絡比: `K_s=I_fV/I_fI`
- 同期リアクタンスの目安: `X_s[p.u.]≈1/K_s`（同期インピーダンス法・`R_a` 無視等の条件下）
- 三相基準インピーダンス: `Z_B=V_LL^2/S_3φ`
- 実単位換算: `X_s[Ω]=X_s[p.u.]Z_B`
