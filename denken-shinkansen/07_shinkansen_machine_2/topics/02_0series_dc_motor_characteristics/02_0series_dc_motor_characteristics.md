## 1. このテーマで電験二種は何を問うか

## 2. 電機子回路・ブラシ・逆起電力

直流電動機の電機子には、端子電圧 `V [V]`、電機子電流 `I_a [A]`、電機子抵抗 `R_a [Ω]`、逆起電力 `E [V]` が現れる。ブラシ電圧降下を無視できるとき、電動機運転の電圧収支は

```text
V = E + I_a R_a
```

である。ブラシ全体の電圧降下を `V_b [V]` として問題文で与えられた場合は

```text
V = E + I_a R_a + V_b
```

とする。したがって

```text
E = V - I_a R_a - V_b
```

である。

回転していない始動瞬間は `ω=0` なので、逆起電力 `E` も0である。このため同じ端子電圧を直接加えると電機子電流は大きくなりやすい。直流機でブラシは電機子と外部回路の電気的接続に関わる接触部であり、摩耗・交換対象となる点も一次試験で問われる。

## 3. 逆起電力・トルク・速度

磁束を `Φ [Wb]`、角速度を `ω [rad/s]`、機械角速度基準の機器定数を `k` とすると、基本関係は

```text
E = k Φ ω
T = k Φ I_a
```

である。`T` の単位は `N·m` である。同じ機器で界磁が一定なら `kΦ` は一定なので、

```text
E ∝ ω
T ∝ I_a
```

となる。

回転速度を `n [min^-1]` で扱う場合は

```text
ω = 2πn / 60
```

で変換する。比例計算では両方の速度を同じ単位にそろえれば、`E_2/E_1=n_2/n_1` としてよい。

電機子回路式と逆起電力式を組み合わせると

```text
ω = (V - I_a R_a - V_b) / (k Φ)
```

となる。この式から、端子電圧が上がれば速度は上がる方向、電流による内部電圧降下が増えれば速度は下がる方向、磁束を弱めれば速度は上がる方向であることが分かる。

## 4. 直巻電動機の始動トルクと速度特性

直巻電動機では、電機子と直巻界磁巻線に同じ電流が流れる。磁気回路が未飽和の範囲では、おおむね

```text
Φ ∝ I_a
```

とみなせる。これを `T=kΦI_a` に代入すると

```text
T ∝ I_a^2
```

となる。したがって、電流が大きい始動時に大きなトルクを得やすい。これが電気鉄道で直流直巻電動機が用いられてきた理由を理解する中心である。

ただし磁気飽和が進むと `Φ` は電流に比例して増えなくなるため、全電流域で `T∝I_a^2` としてはいけない。飽和域では、トルクは電流に対してより一次比例に近い増え方になる。

軽負荷になると必要トルクが減り、電機子電流が小さくなる。直巻機では同時に磁束も弱くなるため、

```text
ω = (V - I_aR_a - V_b)/(kΦ)
```

の分母が小さくなり、速度は上昇しやすい。したがって「負荷が軽いほど速度が低い」とは限らない。理想化した未飽和式では電流が0へ近づくほど速度が非常に大きくなるため、無負荷運転を単純な定格運転の延長として扱わない。

## 5. 弱め界磁

弱め界磁は、磁束 `Φ` を小さくして速度を上げる考え方である。同じ `V`、`I_a`、内部電圧降下なら分子はほぼ同じなので、

```text
ω ∝ 1/Φ
```

となる。一方、

```text
T = kΦI_a
```

だから、同じ電機子電流では磁束を弱めるほどトルクは小さくなる。

例えば磁束を元の80%とし、端子電圧・電機子電流・内部電圧降下を同一と仮定すると、速度は概ね `1/0.8=1.25` 倍、同じ電流でのトルクは0.8倍になる。弱め界磁は「速度を上げる代わりに、1 A当たりのトルクを下げる」操作として覚える。

## 6. 出力・損失・効率

電機子内で電気から機械へ変換される電磁変換電力は

```text
P_em = E I_a
```

であり、電磁トルクとの関係は

```text
P_em = Tω
```

である。

電機子銅損は

```text
P_cu = I_a^2 R_a
```

ブラシ損は

```text
P_b = V_b I_a
```

である。軸出力 `P_out` を求める場合は、電磁変換電力から鉄損・機械損などを差し引く。効率は

```text
η = P_out / P_in
```

である。

他励機で界磁を別電源から供給する問題では、問題文が「総入力」を求めているのか「電機子入力」を扱っているのかを区別する。界磁銅損を総入力へ含める必要がある問題で、電機子側だけを使って効率を出してはいけない。

損失から抵抗を逆算する場合は、まず損失を種類別に分ける。電機子銅損が分かれば

```text
R_a = P_cu / I_a^2
```

である。

## 7. 3つの特性グラフの読み方

### 7.1 速度―トルク

直巻機では負荷トルクが増えると電流が増え、内部電圧降下が増える一方、磁束も増えるため速度は下がる。未飽和近似では `T∝I_a^2` であり、低トルク・小電流側ほど磁束が弱く速度が高くなりやすい。

この教材で描く曲線は式の関係を示す模式図とし、0系実車の測定曲線とは扱わない。

### 7.2 速度―出力

軸出力は `P_out=Tω` である。低負荷ではトルクが小さいため出力も小さい。負荷を増やすとトルクは増えるが速度は下がり、さらに高電流域では銅損や電圧降下も増える。そのため速度と出力は単純な一次関係にはならない。

### 7.3 電流―速度

直巻機では電流が小さくなると磁束も弱まり、速度は上昇する。逆に電流が増えると速度は低下する方向となる。磁気飽和の前後で傾きは変わるので、全域を一つの比例式で表さない。

## 8. H24二次型を解く再利用可能な手順

直流電動機の二次試験型では、次の順番で処理すると式が混線しにくい。

1. 入力・出力・既知損失を整理し、電機子銅損を分離する。
2. `R_a=P_cu/I_a^2` で電機子抵抗を求める。
3. 定格点で `E=V-I_aR_a-V_b` を求める。
4. 一定界磁なら `E∝n` を使い、別速度での逆起電力を求める。
5. 一定界磁なら `T∝I_a` を使い、トルク比から電機子電流を求める。
6. 最後に `V=E+I_aR_a+V_b` へ戻り、必要な端子電圧を求める。
7. 電圧の大小、単位、損失の符号を検算する。

「速度を先に求める式」と「トルクから電流を求める式」を混ぜず、一定界磁という条件が使える区間を確認してから比例関係を使う。

本系列では0系の主電動機を題材に、電気鉄道で直流直巻電動機が採用された背景を電験の式へ接続する。重要なのは形式名や定格値の暗記ではなく、始動時に大トルクを得やすい直巻特性、速度上昇と磁束の関係、電圧・電流・トルク・速度の連鎖である。

# 3段階例題

## 例題1 基礎: 電圧収支から速度とトルクを求める

教材上の仮定値として、他励直流電動機の端子電圧を `220 V`、電機子電流を `40 A`、電機子抵抗を `0.40 Ω`、ブラシ全電圧降下を `2.0 V`、`kΦ=1.20` とする。逆起電力、回転速度、電磁トルク、電磁変換電力を求める。

### 解答

まず電機子回路式から

```text
E = 220 - 40×0.40 - 2.0
  = 202 V
```

逆起電力式より

```text
ω = E/(kΦ)
  = 202/1.20
  = 168.3 rad/s
```

したがって

```text
n = 168.3×60/(2π)
  ≒ 1.61×10^3 min^-1
```

トルクは

```text
T = kΦI_a
  = 1.20×40
  = 48.0 N·m
```

電磁変換電力は

```text
P_em = EI_a
     = 202×40
     = 8.08 kW
```

検算すると `Tω=48.0×168.3≒8.08 kW` で一致する。

## 例題2 標準: 直巻電動機の電流低下で速度はどう変わるか

教材上の未飽和モデルとして、直巻電動機を `V=200 V`、電機子と直巻界磁を合わせた抵抗を `0.20 Ω` とする。点1では `I_1=100 A`、`n_1=600 min^-1` で運転している。磁気回路は未飽和で `Φ∝I_a` とする。電流が `I_2=50 A` へ低下したときのトルク比 `T_2/T_1` と速度 `n_2` を求める。ブラシ電圧降下は無視する。

### 解答

未飽和の直巻機では

```text
T ∝ I_a^2
```

なので

```text
T_2/T_1 = (50/100)^2
          = 0.25
```

逆起電力は

```text
E_1 = 200 - 100×0.20 = 180 V
E_2 = 200 -  50×0.20 = 190 V
```

また `E∝Φn` であり `Φ∝I_a` だから

```text
n_2/n_1 = (E_2/E_1)×(Φ_1/Φ_2)
          = (190/180)×(100/50)
          = 2.111...
```

したがって

```text
n_2 ≒ 600×2.111
    ≒ 1.27×10^3 min^-1
```

電流が半分になると、未飽和近似ではトルクは1/4まで下がる一方、磁束低下により速度は大きく上昇する。この計算を磁気飽和域へそのまま外挿してはいけない。

## 例題3 二次相当: 損失から部分負荷端子電圧まで求める

教材上の仮定値として、一定界磁の直流電動機を考える。定格点は端子電圧 `240 V`、電機子電流 `60 A`、回転速度 `1200 min^-1`、軸出力 `12.0 kW` である。鉄損と機械損の合計を `1.20 kW`、ブラシ全電圧降下を `2.0 V` とする。界磁電力は別電源で、この問題の電機子損失収支には含めない。

(1) 電機子抵抗 `R_a` を求める。

(2) 定格時逆起電力 `E_N` を求める。

(3) 電機子電流を無視できる軽負荷近似で、同じ端子電圧・同じ磁束なら回転速度はいくらか。

(4) トルクを定格の50%、回転速度を `1000 min^-1` とするとき、必要な端子電圧を求める。

### 解答

定格時の電機子入力は

```text
P_in,a = 240×60
       = 14.4 kW
```

ブラシ損は

```text
P_b = 2.0×60
    = 0.120 kW
```

したがって電機子銅損は

```text
P_cu = 14.4 - 12.0 - 1.20 - 0.120
     = 1.08 kW
```

よって

```text
R_a = 1080/60^2
    = 0.300 Ω
```

定格時逆起電力は

```text
E_N = 240 - 60×0.300 - 2.0
    = 220 V
```

軽負荷近似では `I_aR_a≒0` とし、ブラシ電圧降下を同じ `2.0 V` とすれば

```text
E_0 ≒ 240 - 2.0
    = 238 V
```

一定界磁では `E∝n` なので

```text
n_0 = 1200×238/220
    ≒ 1.30×10^3 min^-1
```

次に、一定界磁では `T∝I_a` なので、50%トルク時の電機子電流は

```text
I_2 = 0.50×60
    = 30 A
```

`1000 min^-1` での逆起電力は

```text
E_2 = 220×1000/1200
    = 183.3 V
```

したがって必要な端子電圧は

```text
V_2 = E_2 + I_2R_a + V_b
    = 183.3 + 30×0.300 + 2.0
    = 194.3 V
```

この問題の順序は「損失→抵抗→逆起電力→速度比例→トルク比例で電流→端子電圧」であり、H24二次の対象(1)〜(4)と同じ解法骨格を練習するための独自例題である。

# 頻出ミスと公式まとめ

- 電動機運転では `V=E+I_aR_a+V_b`。逆起電力は端子電圧から内部電圧降下を引いて求める。
- 一定界磁なら `E∝n`、`T∝I_a`。
- 直巻未飽和なら `Φ∝I_a`、したがって `T∝I_a^2`。
- 弱め界磁では速度が上がり、同じ電流でのトルクは下がる。
- `P_em=EI_a=Tω` と軸出力を区別する。
- `R_a=P_cu/I_a^2` で損失から抵抗を逆算できる。
- 速度をrpmで直接 `E=kΦω` へ入れる場合は、定数の定義と単位を確認する。
