# 過去問から逆算した教材で必要な説明

1. 直流電動機の電機子回路を示し、端子電圧、逆起電力、電機子電流、電機子抵抗の関係 `V=E+I_a R_a` を説明する。問題でブラシ電圧降下が与えられる場合は、その分も端子電圧から差し引く。
2. `E=kΦω` の各記号と単位を示し、一定界磁なら逆起電力が回転速度に比例することを説明する。
3. `T=kΦI_a` の各記号と単位を示し、一定界磁ならトルクが電機子電流に比例することを説明する。
4. 1〜3を組み合わせ、`ω=(V-I_aR_a)/(kΦ)` を導き、端子電圧、負荷電流、磁束が速度をどう変えるか説明する。
5. 直巻電動機では界磁電流と電機子電流が同じで、未飽和領域では概ね `Φ∝I_a` となるため `T∝I_a^2` となり、大きな始動トルクを得やすいことを説明する。磁気飽和後はこの二乗比例がそのまま続かないことも明示する。
6. 直巻電動機は軽負荷になると電流・磁束が小さくなり速度が上昇しやすいことを、速度式と結び付けて説明する。
7. 弱め界磁では `Φ` を小さくすると同じ端子電圧条件で速度が上がる一方、同じ電機子電流に対するトルクは下がることを説明する。
8. `P_out=Tω`、電機子銅損 `P_cu=I_a^2R_a`、入力・出力・損失・効率の関係を扱い、損失から電機子抵抗を逆算できるようにする。
9. H24二次問1と同型の「損失→電機子抵抗→逆起電力→速度→部分負荷端子電圧」を途中式付きで再利用可能な解法手順にする。
10. `SPEC.md` 指定の速度―トルク、速度―出力、電流―速度グラフを、式と対応付けて読めるようにする。
11. 新幹線側の説明では、確認できない0系主電動機の実値を推測しない。形式・定格値・制御条件などを使う場合は本文制作時に鉄道・メーカー等の一次資料を確認し、公開値・計算値・仮定値を区別する。
12. 混合過去問に含まれるチョッパ、誘導機、VVVF、過渡制御は後続Topicの範囲として本テーマへ持ち込まない。

# 必須式

- 電機子回路: `V=E+I_aR_a`
- 逆起電力: `E=kΦω`
- 電磁トルク: `T=kΦI_a`
- 速度式: `ω=(V-I_aR_a)/(kΦ)`
- 機械出力: `P_out=Tω`
- 電機子銅損: `P_cu=I_a^2R_a`
- 効率: `η=P_out/P_in`
- 直巻・未飽和領域: `Φ∝I_a` より `T∝I_a^2`

ブラシ電圧降下が問題文で与えられる場合は、端子式にその電圧降下を加えて扱う。

# 必須グラフ

`SPEC.md` に従い、本文・解説画像では次を扱う。

- 速度―トルク
- 速度―出力
- 電流―速度

グラフは式との対応を説明し、実車の測定曲線として扱う場合は出典を要求する。根拠のない0系実車曲線を作らない。

# 典型ミス

- `V=E+I_aR_a` の符号を取り違え、電動機運転で `E>V` としてしまう。
- `E=kΦω` で角速度基準の定数を使うのに `min^-1` をそのまま代入する。比例計算なら同一単位の速度比で処理する。
- 一定界磁の問題で `T∝I_a` を使わず、トルク比と電流比の対応を落とす。
- 直巻電動機で全領域を `Φ∝I_a` とみなし、磁気飽和を無視する。
- 問題文で指定されたブラシ電圧降下を無視する。
- 電磁変換出力、軸出力、銅損を混同する。
- 弱め界磁を「磁束が弱いから遅くなる」と逆に判断する。
- 混合問題のチョッパ・誘導機部分までTopic 02の教材範囲だと誤認する。
