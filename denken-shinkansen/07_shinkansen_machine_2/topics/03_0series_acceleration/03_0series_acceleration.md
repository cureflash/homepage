# EXAM_ALIGNMENT

資格: 第二種電気主任技術者

主科目: 一次試験「機械」、二次試験「機械・制御」

論点:
- 直流電動機の端子電圧・逆起電力・界磁磁束と回転速度の関係
- 直流電動機のトルクと電機子電流
- 電圧制御と弱め界磁による速度制御
- 電気鉄道で始動時に大きなトルクを必要とする理由
- `P=Tω` と定トルク・定出力領域の関係
- `J dω/dt = T_M - T_L` による加速の考え方
- 歯車比・車輪径・モーター回転速度から列車速度への換算
- 駆動力、走行抵抗、質量から加速度を求める基本
- 0系のタップ制御は実車資料確認後に上記の一般式へ接続する

# 過去問から逆算した教材で必要な説明

1. `V=E+I_aR_a`、`E=kφω`、`T=kφI_a` を速度制御へ再接続し、`ω=(V-I_aR_a)/(kφ)` を使えるようにする。
2. 電圧を上げると速度を上げられる理由と、端子電圧が上限に達した後に弱め界磁を使う理由を式で説明する。
3. 弱め界磁では同じ電機子電流でも `T=kφI_a` によりトルクが低下することを明示する。
4. `P=Tω` から、定トルク領域では速度上昇とともに出力が増え、定出力領域では速度上昇とともにトルクが低下することを導く。
5. `J dω/dt=T_M-T_L` を、列車側では「駆動力−走行抵抗」が加速度を決める関係へつなぐ。走行抵抗は本テーマでは基本のみとし、SPECにない詳細抵抗式を追加しない。
6. 歯車比を `i=n_m/n_w` と定義し、`n_w=n_m/i`、`v=0.06πD n_w` [km/h]、したがって `v=0.06πD n_m/i` を途中式付きで扱う。
7. 車輪半径 `r=D/2` とし、理想的な歯車伝達では車輪トルクと接線力を `F=T_w/r` で結び、最終的に `a=(F-F_r)/m` へ接続する。損失・効率を入れる場合は問題文または実車資料で与えられた条件だけを用いる。
8. 定トルク領域と「ほぼ一定の駆動力」、定出力領域と「速度上昇に伴う駆動力低下」の対応を、成立条件を明記して説明する。
9. タップ制御はSPEC固定項目として扱うが、0系の実際の回路構成・段数・電圧値は一次資料確認前に推測しない。
10. `主電動機 → 歯車 → 車輪 → 列車速度 → 駆動力と走行抵抗 → 加速度` を一つの再利用可能な解法手順としてまとめる。
11. H24二次問1(4)型の記述計算を、使用式→比例関係→数値代入→単位→最終値まで採点可能な形で例題・練習へ反映する。
12. チョッパ、回生、誘導機V/f、ベクトル制御、厳密な過渡応答は後続Topicへ残す。

# 必須式

- 電機子回路: `V=E+I_aR_a`（ブラシ電圧降下が与えられる場合は `+V_b`）
- 逆起電力: `E=kφω`
- 電磁トルク: `T=kφI_a`
- 速度式: `ω=(V-I_aR_a)/(kφ)`
- 機械出力: `P=Tω`
- 回転運動: `J dω/dt=T_M-T_L`
- 歯車比: `i=n_m/n_w`
- 車輪回転速度: `n_w=n_m/i`
- 列車速度: `v=0.06πD n_w=0.06πD n_m/i` [km/h]（`D` [m]、`n` [min^-1]）
- 接線力: `F=T_w/r`
- 並進運動の基本: `a=(F-F_r)/m`
