# 過去問から逆算した教材で必要な説明

1. `V=E+I_aR_a`、`E=kφω`、`T=kφI_a` を速度制御へ再接続し、`ω=(V-I_aR_a)/(kφ)` を使えるようにする。
2. 電圧を上げると速度を上げられる理由と、端子電圧が上限に達した後に弱め界磁を使う理由を式で説明する。
3. 弱め界磁では同じ電機子電流でも `T=kφI_a` によりトルクが低下することを明示する。
4. `P=Tω` から、定トルク領域では速度上昇とともに出力が増え、定出力領域では速度上昇とともにトルクが低下することを導く。
5. `J dω/dt=T_M-T_L` を、列車側では「駆動力−走行抵抗」が加速度を決める関係へつなぐ。走行抵抗は本テーマでは基本のみとし、SPECにない詳細抵抗式を追加しない。
6. 歯車比を `i=n_m/n_w` と定義し、`n_w=n_m/i`、`v=0.06πD n_w` [km/h]、したがって `v=0.06πD n_m/i` を途中式付きで扱う。
7. 車輪半径 `r=D/2` とし、理想的な歯車伝達では車輪トルクと接線力を `F=T_w/r` で結び、最終的に `a=(F-F_r)/m` へ接続する。損失・効率を入れる場合は問題文または実車資料で与えられた条件だけを用いる。
8. 定トルク領域と「ほぼ一定の駆動力」、定出力領域と「速度上昇に伴う駆動力低下」の対応を、成立条件を明記して説明する。

# 解説本文

## 1. このテーマで電験二種は何を問うか

このテーマでは、直流主電動機の電気式を「列車が加速する」まで一続きに変換できることが目標である。電験では形式名の暗記ではなく、端子電圧・逆起電力・磁束・電機子電流・トルク・回転速度の関係と、そこから歯車・車輪・列車速度・加速度へ移る計算が問われる。

旧来の電気鉄道で直流直巻電動機が使われた理由として、始動時に大きなトルクを得やすいことが一次試験で繰り返し問われている。加えて二次試験では、一定界磁などの条件を読み、速度比・トルク比から逆起電力や電機子電流を求め、必要な端子電圧まで記述する力が必要になる。

本章で使う中心式は次の三つである。

```text
V = E + I_a R_a
E = kφω
T = kφI_a
```

ブラシ電圧降下 `V_b` が与えられる場合は

```text
V = E + I_a R_a + V_b
```

とする。

## 2. 直流主電動機の速度を決める式

逆起電力式を電機子回路式へ代入すると

```text
V = kφω + I_aR_a
```

したがって

```text
ω = (V - I_aR_a)/(kφ)
```

となる。この式から、同じ負荷電流・同じ磁束なら端子電圧 `V` を上げると速度 `ω` は上昇する。また端子電圧が一定でも磁束 `φ` を小さくすれば速度は上昇する。

ただし、式の分母だけを見て「磁束を弱めれば無制限に高速化できる」と考えてはいけない。トルクは

```text
T = kφI_a
```

であるため、同じ電機子電流なら磁束を弱めるほどトルクは低下する。速度制御とトルク制御は同じ `φ` を介して結び付いている。

## 3. 低〜中速域の電圧制御と0系のタップ制御

低速域では、必要な電機子電流を保ちながら主電動機へ加える電圧を段階的に上げ、逆起電力の増加に追従させるという見方が基本になる。

日本車輌製造の0系主要諸元では、力行制御として「主変圧器の低圧側タップ切換」が明記され、タップ切替器の制御段数は25段とされている。また2両1ユニットで8個の主電動機を制御し、主回路は4個直列の電動機群を2並列とする4S×2Pである。

ここで電験上重要なのは「25」という数字の暗記ではない。タップ切換により主変圧器低圧側の電圧を変え、その後の整流を経て主電動機側の電圧を段階的に調整するため、一般式

```text
ω = (V - I_aR_a)/(kφ)
```

の `V` を制御している、と理解することである。

一次資料から各タップの個別電圧値や切換順序までは確認していないため、本教材では均等25段などとは仮定しない。

## 4. 高速側の弱め界磁

端子電圧を上限まで使った後、さらに速度を上げる一般的方法が弱め界磁である。速度式

```text
ω = (V - I_aR_a)/(kφ)
```

で `V` と `I_aR_a` がほぼ決まっているとき、磁束 `φ` を小さくすれば `ω` は上昇する。

一方で

```text
T = kφI_a
```

なので、電機子電流を同じに保つならトルクは磁束に比例して低下する。したがって弱め界磁域では、「速度は上がるが、同じ電流で出せるトルクは小さくなる」という二つを同時に扱う。

0系が弱め界磁をどの回路・段数で実装したかについては、このrunで一次資料確認できていない。ここではSPECに指定された一般原理だけを扱い、実車固有の段数や抵抗値は置かない。

## 5. 定トルク領域と定出力領域

機械出力は

```text
P = Tω
```

である。

### 5.1 定トルク領域

低〜中速域で、磁束がほぼ一定、電機子電流の上限もほぼ一定なら

```text
T = kφI_a ≒ 一定
```

となる。このとき

```text
P = Tω
```

より、速度が上がるほど出力はほぼ比例して増加する。

### 5.2 定出力領域

電圧上限へ達した後、弱め界磁で速度を上げる領域では、電力上限・電流上限などの条件の下で出力をおおむね一定に保つ近似が使われる。このとき

```text
T = P/ω
```

なので、速度上昇に伴いトルクは反比例して低下する。

したがって、理想化すれば

```text
低速側: 定トルク → 出力は速度とともに増加
高速側: 定出力   → トルクは速度とともに低下
```

となる。これは一般化した試験用モデルであり、0系の実測特性曲線そのものではない。

## 6. モーター回転速度から列車速度へ

歯車比を

```text
i = n_m / n_w
```

と定義する。`n_m` はモーター回転速度、`n_w` は車輪回転速度である。したがって

```text
n_w = n_m / i
```

車輪径を `D` [m] とすると、車輪1回転で進む距離は `πD` [m] だから

```text
v = πD n_w × 60 / 1000
  = 0.06πD n_w
```

よって

```text
v = 0.06πD n_m / i    [km/h]
```

となる。

0系について一次資料で確認できた歯数比は

```text
29 : 63 = 1 : 2.17
```

なので、本教材の定義では

```text
i = 2.17
```

を実車値として使える。一方、車輪径と主電動機回転速度はこのrunで一次資料確認できていないため、0系の実値として代入しない。

日本車輌製造の資料は、2両1ユニットの連続定格速度を `167 km/h` としている。この実車値と歯車比だけを使えば

```text
D n_m = v i /(0.06π)
      = 167×2.17/(0.06π)
      ≒ 1.92×10^3 m/min
```

という積までは求められる。`D` または `n_m` のどちらかを未確認のまま決め打ちして、もう一方を0系実値として逆算してはいけない。

## 7. 駆動力・走行抵抗・加速度

モーターのトルクを車輪の接線力へ変換する。歯車損失を無視する理想モデルでは、減速比 `i` により車輪側トルクは

```text
T_w = i T_m
```

車輪半径 `r=D/2` だから、1軸の接線力は

```text
F = T_w/r
  = iT_m/r
```

複数の主電動機がある場合は、同条件なら各軸の力を合計する。歯車効率などが問題文で与えられた場合だけ、その効率を掛ける。

列車に作用する総駆動力を `F`、走行抵抗を `F_r`、質量を `m` とすると

```text
ma = F - F_r
```

よって

```text
a = (F-F_r)/m
```

である。本テーマでは走行抵抗は「駆動力から差し引く抵抗力」という基本に留め、SPECにない詳細な速度依存抵抗式は追加しない。

回転系だけを見るH28一次型では

```text
J dω/dt = T_M - T_L
```

列車全体の並進運動を見るときは

```text
m dv/dt = F - F_r
```

となる。どちらも「駆動側−負荷側=慣性×加速度」という同じ構造である。

## 8. 0系の一次資料値を電験式へ接続する

日本車輌製造の公開資料から、この章で直接使える0系の事実は次のとおりである。

| 項目 | 一次資料で確認した値・構成 | 教材での使い方 |
|---|---|---|
| 2両1ユニット | 8主電動機 | 1台当たり出力への換算、総駆動力の考え方 |
| 連続定格出力 | 1,480 kW / 2両 | `P=Tω`、`F=P/v` の接続 |
| 連続定格速度 | 167 km/h | 出力と速度から理想駆動力を求める |
| 歯数比 | 29:63=1:2.17 | `i=2.17` として速度・トルク換算 |
| 制御方式 | 主変圧器低圧側タップ切換 | 電圧制御の実車例 |
| タップ切替器 | 25段 | 段階的電圧制御の実車事実。各段電圧は推測しない |
| 最高速度 | 210 km/h | テーマの実車到達速度。計算で無理に再現しない |

2両1ユニットの連続定格出力1,480 kWと8主電動機から、単純割り算で

```text
1480/8 = 185 kW/台
```

と求められる。これは資料値からの計算値である。

また、損失を無視して1,480 kWがそのまま走行方向の機械出力になる理想化を置くと、167 km/hでの力は

```text
v = 167/3.6 = 46.39 m/s
F = P/v
  = 1.480×10^6 / 46.39
  ≒ 3.19×10^4 N
  = 31.9 kN
```

となる。これは資料に記載された実測牽引力ではなく、資料値を `P=Fv` へ代入した理想計算値である。

## 9. 再利用できる解法手順

新幹線の加速問題を見たら、次の順に処理する。

1. 電動機側の既知量 `V, I_a, R_a, φ` を整理する。
2. `V=E+I_aR_a(+V_b)` で逆起電力 `E` を求める。
3. `E=kφω` でモーター回転速度を求める。速度比だけなら比例関係を使う。
4. `T=kφI_a` でモータートルクを求める。弱め界磁時は磁束比を忘れない。
5. `i=n_m/n_w` で車輪回転速度へ変換する。
6. `v=0.06πDn_w` で列車速度へ変換する。
7. `T_w=iT_m`、`F=T_w/r` で駆動力へ変換する。効率は与えられたときだけ入れる。
8. `a=(F-F_r)/m` で加速度を求める。
9. 定トルクか定出力かを確認し、`P=Tω` で速度上昇時のトルク・出力の変化を検算する。
10. 単位、歯車比の向き、`min^-1` と `rad/s` を確認する。

## 10. 二次試験型の端子電圧計算

H24二次問1(4)型では、一定界磁なら次の二つの比例関係を先に使う。

```text
E ∝ n
T ∝ I_a
```

基準点を添字1、求める点を添字2とすると

```text
E_2/E_1 = n_2/n_1
I_a2/I_a1 = T_2/T_1
```

を求め、最後に

```text
V_2 = E_2 + I_a2 R_a + V_b
```

へ戻る。

弱め界磁が入る場合は比例式を

```text
E ∝ φn
T ∝ φI_a
```

へ戻し、磁束比を必ず含める。一定界磁の比例式を弱め界磁域へそのまま使わない。

## 11. 頻出ミス

- 歯車比 `i=n_m/n_w` を逆にして、減速後の車輪回転速度を大きくする。
- `n[min^-1]` と `ω[rad/s]` を混同する。
- `v=0.06πDn` の `0.06` を忘れ、m/minとkm/hを混在させる。
- 弱め界磁で速度だけ上がると考え、`T=kφI_a` によるトルク低下を忘れる。
- 定出力域でもトルク一定とする。定出力なら `T=P/ω` で低下する。
- 駆動力そのものを `ma` として、走行抵抗を引き忘れる。
- 実車の歯車効率、車輪径、回転速度を根拠なく補う。
- 0系のタップ25段を、25段の等間隔な主電動機端子電圧と勝手に解釈する。

# 3段階例題

## 例題1 基礎: 電圧を上げると回転速度はどう変わるか

教材上の仮定値として、一定界磁の直流電動機を考える。電機子電流 `I_a=200 A`、電機子抵抗 `R_a=0.15 Ω`、`kφ=1.50` とし、ブラシ電圧降下は無視する。

(1) 端子電圧 `V_1=300 V` のときの逆起電力、角速度、回転速度を求める。

(2) 電流と磁束を同じに保ったまま `V_2=360 V` へ上げたときの回転速度を求める。

### 解答

点1では

```text
E_1 = V_1 - I_aR_a
    = 300 - 200×0.15
    = 270 V
```

したがって

```text
ω_1 = E_1/(kφ)
    = 270/1.50
    = 180 rad/s
```

```text
n_1 = 180×60/(2π)
    ≒ 1.72×10^3 min^-1
```

点2では

```text
E_2 = 360 - 200×0.15
    = 330 V
```

```text
ω_2 = 330/1.50
    = 220 rad/s
```

```text
n_2 = 220×60/(2π)
    ≒ 2.10×10^3 min^-1
```

同じ電流・同じ磁束なら、端子電圧を上げることで逆起電力の許容値が上がり、回転速度も上がる。

## 例題2 標準: 歯車・車輪を通して列車速度と加速度まで求める

0系の一次資料で確認した実車値として歯車比 `i=2.17`、2両1ユニット8主電動機を使う。それ以外は教材上の仮定値とし、車輪径 `D=0.91 m`、各主電動機回転速度 `n_m=2200 min^-1`、各主電動機トルク `T_m=1000 N·m`、2両質量 `m=1.00×10^5 kg`、走行抵抗 `F_r=20.0 kN` とする。歯車損失は無視する。

(1) 列車速度を求める。

(2) 8主電動機の総駆動力を求める。

(3) 加速度を求める。

### 解答

まず車輪回転速度は

```text
n_w = n_m/i
    = 2200/2.17
    ≒ 1.014×10^3 min^-1
```

列車速度は

```text
v = 0.06πD n_w
  = 0.06π×0.91×1014
  ≒ 174 km/h
```

車輪半径は

```text
r = D/2
  = 0.455 m
```

1主電動機当たりの車輪側トルクは

```text
T_w = iT_m
    = 2.17×1000
    = 2170 N·m
```

したがって1軸の接線力は

```text
F_1 = T_w/r
    = 2170/0.455
    ≒ 4.77 kN
```

8主電動機では

```text
F = 8F_1
  ≒ 38.2 kN
```

正味加速力は

```text
F-F_r = 38.2-20.0
      = 18.2 kN
```

よって

```text
a = 18.2×10^3/(1.00×10^5)
  = 0.182 m/s^2
```

ここで0系実車値として使ったのは `i=2.17` と8主電動機だけであり、車輪径・回転速度・トルク・質量・走行抵抗は教材上の仮定値である。

## 例題3 二次相当: 弱め界磁で定出力を保つときの端子電圧

教材上の仮定値として、直流電動機の基準点を端子電圧 `V_1=220 V`、電機子電流 `I_a1=80 A`、回転速度 `n_1=1200 min^-1`、電機子抵抗 `R_a=0.25 Ω`、ブラシ全電圧降下 `V_b=2.0 V` とする。

高速側で磁束を基準の `75%` に弱め、回転速度を `1600 min^-1` とする。出力を基準点と同じに保つ理想化を置く。

(1) 高速点のトルクは基準点の何倍か。

(2) 高速点の電機子電流を求める。

(3) 高速点の逆起電力と必要端子電圧を求める。

### 解答

出力一定なら

```text
P = Tω = 一定
```

なので

```text
T_2/T_1 = n_1/n_2
          = 1200/1600
          = 0.75
```

トルク式 `T=kφI_a` より

```text
T_2/T_1 = (φ_2/φ_1)(I_a2/I_a1)
```

ここで `φ_2/φ_1=0.75` だから

```text
0.75 = 0.75×(I_a2/80)
```

したがって

```text
I_a2 = 80 A
```

まず基準点の逆起電力は

```text
E_1 = V_1 - I_a1R_a - V_b
    = 220 - 80×0.25 - 2.0
    = 198 V
```

逆起電力は `E∝φn` だから

```text
E_2/E_1 = (φ_2/φ_1)(n_2/n_1)
          = 0.75×1600/1200
          = 1.00
```

よって

```text
E_2 = 198 V
```

必要端子電圧は

```text
V_2 = E_2 + I_a2R_a + V_b
    = 198 + 80×0.25 + 2.0
    = 220 V
```

この例では、端子電圧と電機子電流を上げずに、磁束を75%へ弱めて速度を4/3倍にすると、トルクは75%へ下がり、`Tω` は同じになる。これが理想化した定出力・弱め界磁の関係である。
