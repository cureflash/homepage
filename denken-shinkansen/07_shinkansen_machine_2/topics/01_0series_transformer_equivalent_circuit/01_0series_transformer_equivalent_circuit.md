# 解説本文

## 1. このテーマで電験は何を問うか

変圧器問題で問われる中心は、銘板値を覚えることではなく、試験値や定格値から等価回路を組み立て、電圧変動率・損失・効率まで一貫して計算できるかである。

一次試験では、巻数比、換算抵抗、短絡試験、百分率インピーダンス、損失などを個別に問う。二次試験では、無負荷試験と短絡試験の測定値から `R, X, g0, b0` を求め、さらに `%r, %x`、電圧変動率、部分負荷効率まで連続して求める形が重要になる。

この章を終えた時点で、次を自力で行えることを目標とする。

1. 一次側・二次側の量を同一側へ換算する。
2. 無負荷試験から励磁枝、短絡試験から直列枝を求める。
3. オーム値と百分率量を相互変換する。
4. 遅れ・進み力率を区別して電圧変動率を求める。
5. 鉄損・銅損と負荷率から効率、最大効率条件を求める。
6. 並列運転時の基本的な負荷分担を判断する。
7. 二次試験で、前提・近似条件・途中式・単位を含む答案を書く。

## 2. 理想変圧器から実変圧器へ

### 2.1 巻数比・電圧比・電流比

一次巻数を `N1`、二次巻数を `N2` とし、巻数比を

```text
a = N1 / N2
```

とする。理想変圧器では

```text
V1 / V2 = N1 / N2 = a
```

であり、損失がなければ

```text
V1 I1 = V2 I2
```

だから

```text
I1 / I2 = 1 / a
```

となる。電圧は巻数比に比例し、電流は逆比になる。

### 2.2 実変圧器で追加される要素

実変圧器では、理想変圧器に対して次の要素が加わる。

- 一次巻線抵抗 `r1`
- 二次巻線抵抗 `r2`
- 一次漏れリアクタンス `x1`
- 二次漏れリアクタンス `x2`
- 鉄損を表す励磁コンダクタンス `g0`
- 磁化に必要な無効電流を表す励磁サセプタンス `b0`

巻線抵抗では `I²R` の銅損が生じる。漏れリアクタンスは、一次・二次の双方に完全には鎖交しない漏れ磁束を回路量で表したものである。励磁電流は無負荷でも流れ、鉄損電流と磁化電流に分けて扱う。

交流時の巻線抵抗は、表皮効果などにより直流抵抗より大きくなる場合がある。したがって、直流抵抗から得た抵抗値と短絡試験から得る交流等価抵抗が一致しない場合、それだけで計算誤りとは判断しない。

## 3. 一次換算・二次換算と簡易等価回路

二次側量を一次側へ換算すると、理想変圧器部分を消して同一電圧レベルの回路として扱える。

```text
V2' = a V2
I2' = I2 / a
```

したがって

```text
Z2' = V2' / I2'
    = a² Z2
```

となる。逆に一次側インピーダンスを二次側へ換算すると `1/a²` 倍になる。アドミタンスは逆数なので、二次側アドミタンスを一次側へ換算すると

```text
Y2' = Y2 / a²
```

である。

一次換算した直列等価定数は

```text
R = r1 + a² r2
X = x1 + a² x2
```

となる。励磁枝を一次側へ置く簡易等価回路では、一次端子に `g0 - j b0` の並列枝、その先に `R + jX` の直列枝がある形で扱う。

計算途中で換算側を変えない。`V, I, R, X, g0, b0` は同一側の値へそろえてから式へ代入する。

## 4. 無負荷試験・短絡試験

### 4.1 無負荷試験から励磁枝を求める

二次側を開放し、試験を行う側へ定格周波数の電圧を加える。測定値を `V0 [V]`, `I0 [A]`, `P0 [W]` とする。

無負荷電流が定格電流に比べて小さく、直列巻線での銅損・電圧降下を無視できるとき、入力電力はほぼ鉄損とみなせる。

```text
Y0 = I0 / V0  [S]
g0 = P0 / V0²  [S]
b0 = sqrt(Y0² - g0²)  [S]
```

誘導性の励磁枝を複素数で書けば `Y0 = g0 - j b0` である。必要なら

```text
Rc = 1 / g0  [Ω]
Xm = 1 / b0  [Ω]
```

へ変換できる。

### 4.2 短絡試験から直列枝を求める

二次側を短絡し、定格電流が流れる程度まで低い電圧を加える。測定値を `Vsc [V]`, `Isc [A]`, `Psc [W]` とする。

印加電圧が定格電圧より十分低く、磁束と励磁電流が小さいため鉄損を無視できるとき、入力電力はほぼ直列抵抗による銅損とみなせる。

```text
Z = Vsc / Isc  [Ω]
R = Psc / Isc²  [Ω]
X = sqrt(Z² - R²)  [Ω]
```

短絡試験が定格電流以外で行われた場合、`R=Psc/Isc²` は等価抵抗を求める式として使えるが、測定電力 `Psc` 自体を定格銅損としてそのまま使ってよいとは限らない。定格銅損へ直す場合は電流比の二乗で換算する。

## 5. `%Z / %r / %x` と基準量

### 5.1 基準インピーダンス

単相変圧器で、ある側の定格電圧を `VN`、定格容量を `SN` とすると

```text
IN = SN / VN
ZB = VN / IN
   = VN² / SN
```

である。同じ側へ換算した `R, X, Z` を使えば

```text
%r = 100 R / ZB
%x = 100 X / ZB
%Z = 100 Z / ZB
```

であり、

```text
%Z = sqrt((%r)² + (%x)²)
```

が成り立つ。

定格電流で短絡試験を行った場合、`%Z` は「定格電流を流すのに必要な短絡試験電圧が定格電圧の何%か」と一致する。

### 5.2 `%r` と銅損

定格電流時には

```text
Pcu,N = IN² R
```

である。一方 `SN=VN IN` なので

```text
%r = 100 Pcu,N / SN
```

となる。短絡試験電力と百分率抵抗降下は直接つながる。

### 5.3 基準容量を変更するとき

同じ物理インピーダンス `Z` を別の基準値へ換算する場合、単位法では

```text
zpu,new = zpu,old × (SB,new / SB,old) × (VB,old / VB,new)²
```

となる。同一基準電圧なら、基準容量を2倍にすると単位法インピーダンスも2倍になる。

変圧器の一次側・二次側で基準電圧を巻数比に合わせて選べば、理想変圧器をまたいでも単位法インピーダンスは同じ値として扱える。自己容量基準の `%Z` と、基準容量を変更した `%Z` を混在させない。

## 6. フェーザ図・電圧変動率・並列運転

### 6.1 電圧変動率の一次近似

百分率抵抗降下を `p [%]`、百分率リアクタンス降下を `q [%]`、力率を `cosφ` とする。

遅れ力率では

```text
ε ≈ p cosφ + q sinφ  [%]
```

進み力率では

```text
ε ≈ p cosφ - q sinφ  [%]
```

となる。進み力率では `ε` が負になり、負荷時端子電圧が無負荷時より高くなる場合がある。

負荷率を `k` とすると電流は定格の `k` 倍なので、同じ力率なら一次近似の電圧変動率も概ね `k` 倍となる。

### 6.2 二次項を残す場合

遅れ力率について

```text
A = k(p cosφ + q sinφ)
B = k(q cosφ - p sinφ)
```

とおくと、小さい電圧降下を仮定した二次近似は

```text
ε ≈ A + B² / 200  [%]
```

となる。

進み力率では

```text
A = k(p cosφ - q sinφ)
B = k(q cosφ + p sinφ)
```

として同じ形を使う。問題が厳密なフェーザ計算を要求している場合、近似式へ勝手に置き換えず、複素電圧の大きさから計算する。

### 6.3 並列運転の基本

二台の変圧器を並列運転するには、少なくとも二次側の無負荷電圧の大きさと位相が一致する必要がある。電圧比が異なると、外部負荷がなくても二台の間に循環電流が流れる。

同じ二次起電力を持つ二台A、Bを同一母線へ接続し、同一側換算インピーダンスを `ZA`, `ZB` とする。循環電流を無視できる条件では、負荷電流の分担は

```text
IA / IB = ZB / ZA
```

となり、インピーダンスの小さい変圧器ほど多く電流を負担する。

容量に比例して負荷を分担させるには、各変圧器の自己容量基準の百分率インピーダンスが概ね等しいことが重要である。また `%Z` の大きさだけでなく `X/R` 比が大きく異なると、有効電力・無効電力の分担が揃わない。

三相変圧器では、これに加えて相回転・位相変位・結線条件も一致させる必要がある。本テーマでは並列運転の基本として、電圧比、位相、百分率インピーダンス、インピーダンス角と負荷分担の関係までを扱う。

## 7. 鉄損・銅損・効率・負荷率

### 7.1 鉄損と銅損

定格付近で電圧・周波数が一定なら、鉄損 `Pi` は負荷によらずほぼ一定として扱う。一方、銅損は `I²R` なので負荷率 `k` の二乗に比例する。

```text
Pcu = k² Pcu,N
```

### 7.2 規約効率

定格容量 `SN [VA]`、負荷率 `k`、負荷力率 `cosφ` のとき

```text
Pout = k SN cosφ
η = Pout / (Pout + Pi + k² Pcu,N)
```

となる。`SN` を kVA、損失を kW で扱う場合、`Pout` も kW にそろえる。

### 7.3 最大効率条件

力率を一定として負荷率を変えるとき、効率最大条件は

```text
Pi = k² Pcu,N
```

したがって

```text
kmax = sqrt(Pi / Pcu,N)
```

である。最大効率点で等しいのは鉄損と、その負荷率における実際の銅損であり、鉄損と全負荷銅損が常に等しいわけではない。

## 8. 本試験標準の解法手順と3段階例題

### 8.1 再利用する解法手順

変圧器の複合問題では次の順に整理する。

1. 定格容量、定格電圧、巻数比から定格電流と換算側を決める。
2. 無負荷試験から `g0, b0` と鉄損を求める。
3. 短絡試験から `Z, R, X` と銅損を求める。
4. `ZB=VN²/SN` から `%r, %x, %Z` を求める。
5. 力率の遅れ・進みを判定し、電圧変動率を求める。
6. 負荷率が指定されていれば、電圧降下は概ね `k` 倍、銅損は `k²` 倍にする。
7. 出力有効電力と損失から効率を求める。
8. 並列運転なら、共通基準にそろえたインピーダンスから負荷分担を求める。
9. 指定桁へ丸める前の中間値を残し、単位と物理的妥当性を確認する。

### 8.2 基礎例題: 一次換算

教材用の仮定値として、巻数比 `a=10` の単相変圧器があり、二次巻線抵抗 `r2=0.020 Ω`、二次漏れリアクタンス `x2=0.030 Ω` とする。

```text
r2' = a² r2
    = 10² × 0.020
    = 2.00 Ω

x2' = a² x2
    = 10² × 0.030
    = 3.00 Ω
```

一次側に `r1=1.00 Ω`, `x1=2.00 Ω` があるなら

```text
R = r1 + r2' = 3.00 Ω
X = x1 + x2' = 5.00 Ω
```

となる。インピーダンスを単に巻数比 `a` 倍するのは誤りである。電圧が `a` 倍、電流が `1/a` 倍になるので、`Z=V/I` は `a²` 倍になる。

### 8.3 本試験標準例題: 無負荷・短絡試験から電圧変動率と効率まで

教材用の仮定値として、単相 `100 kVA`, `2000/200 V` の変圧器を考える。すべて2000 V側換算とし、次の試験値が得られたとする。

無負荷試験:

```text
V0 = 2000 V
I0 = 2.00 A
P0 = 1600 W
```

短絡試験:

```text
Vsc = 100 V
Isc = 50.0 A
Psc = 2500 W
```

定格電流は

```text
IN = 100000 / 2000
   = 50.0 A
```

なので、短絡試験は定格電流で行われている。

無負荷試験から

```text
g0 = 1600 / 2000²
   = 4.00×10^-4 S

Y0 = 2.00 / 2000
   = 1.00×10^-3 S

b0 = sqrt(Y0² - g0²)
   = 9.17×10^-4 S
```

短絡試験から

```text
Z = 100 / 50.0 = 2.00 Ω
R = 2500 / 50.0² = 1.00 Ω
X = sqrt(2.00² - 1.00²) = 1.73 Ω
```

基準インピーダンスは

```text
ZB = 2000² / 100000
   = 40.0 Ω
```

したがって

```text
%r = 2.50 %
%x = 4.33 %
%Z = 5.00 %
```

遅れ力率0.8では `sinφ=0.6` なので

```text
ε ≈ 2.50×0.8 + 4.33×0.6
  = 4.60 %
```

二次項まで残すと

```text
A = 4.598
B = 4.33×0.8 - 2.50×0.6
  = 1.964

ε ≈ A + B²/200
  ≈ 4.62 %
```

となる。

鉄損は約 `1.60 kW`、定格銅損は `2.50 kW` とみなせる。全負荷・力率0.8では

```text
Pout = 100×0.8 = 80.0 kW
η = 80.0 / (80.0 + 1.60 + 2.50)
  = 95.1 %
```

最大効率となる負荷率は

```text
kmax = sqrt(1.60 / 2.50)
     = 0.800
```

である。

この例では、一つの試験データから「励磁枝→直列枝→百分率量→電圧変動率→効率」まで連続して求めている。二次試験では、この接続を途中式付きで書く。

### 8.4 複合例題: 並列運転の負荷分担

教材用の仮定値として、同じ二次定格電圧を持つ単相変圧器A、Bを並列運転する。電圧比と位相は一致し、インピーダンス角も等しいものとする。

- A: `100 kVA`, `%ZA=4.0 %`
- B: `200 kVA`, `%ZB=5.0 %`

同じ二次電圧を `V` とすると、オーム値は

```text
ZA = 0.04 V² / 100000
ZB = 0.05 V² / 200000
```

したがって

```text
IA / IB = ZB / ZA
        = (0.05/200000) / (0.04/100000)
        = 0.625
```

となる。合計負荷が `240 kVA` なら、同一力率・同一インピーダンス角の条件で

```text
SA = 240 × 0.625 / (1 + 0.625)
   = 92.3 kVA

SB = 240 - 92.3
   = 147.7 kVA
```

となる。

相対負荷率は

```text
A: 92.3 / 100 = 92.3 %
B: 147.7 / 200 = 73.8 %
```

であり、自己容量基準の `%Z` が小さいAの方が相対的に重く負荷される。二台の定格容量比どおりに負荷分担させたい場合は、自己容量基準の百分率インピーダンスを概ね等しくする必要がある。

## 9. 0系主変圧器への接続

既存一次資料調査で確認済みの0系の値は次のとおりである。

- 電気方式: 交流60 Hz 25 kV
- 主変圧器容量: 1650 kVA
- 制御方式: 低圧タップ切換
- タップ制御: 25段

容量 `1650 kVA` と一次側 `25 kV` だけを使い、単相の皮相電力関係 `S=VI` で定格相当の一次電流を単純計算すると

```text
I = 1650 kVA / 25 kV
  = 66 A
```

となる。これは公開済みの容量・電圧から得た計算値であり、特定の走行状態で実測された架線電流を意味しない。

0系の主変圧器も、試験問題と同様に「架線側電圧を受け、巻数比とタップによって二次側電圧を作り、巻線抵抗・漏れリアクタンス・鉄損・銅損を持つ実変圧器」として考えられる。

一方、0系固有の `R, X, g0, b0, %Z`、鉄損、銅損については、このテーマで使える一次資料値を確認していない。したがって例題値を0系実値として扱わない。

## 10. 頻出ミス・二次答案の書き方

### 10.1 頻出ミス

- 換算側を混在させる。
- 電圧比の `a` とインピーダンス換算の `a²` を混同する。
- 無負荷試験と短絡試験の役割を逆にする。
- `Psc` を常に定格銅損とみなす。
- `%Z` とオーム値で基準電圧・基準容量を混在させる。
- 遅れ力率の `+q sinφ` と進み力率の `-q sinφ` を取り違える。
- 負荷率について、電圧降下の `k` と銅損の `k²` を混同する。
- `kVA` と `kW` を混同し、出力有効電力に力率を掛け忘れる。
- 最大効率条件を `Pi=Pcu,N` と誤読する。
- 表皮効果を無視し、交流等価抵抗と直流抵抗が必ず一致すると考える。
- 並列運転で自己容量基準の `%Z` だけを見て、共通電圧側のオーム値と容量差を無視する。
- 二次答案で近似条件や単位を書かない。

### 10.2 二次試験答案の形

二次試験では、最終値だけでなく採点可能な経路を残す。

```text
換算側を宣言
→ 既知量と単位を整理
→ 使用式を示す
→ 成立条件・近似条件を示す
→ 数値代入
→ 中間値を保持
→ 最終値と単位
→ 遅れ/進み、負荷率、基準量を再確認
```

## 12. 公式・解法まとめ

### 換算

```text
a = N1/N2 ≈ V1/V2
I1/I2 ≈ 1/a
Z2' = a² Z2
Y2' = Y2/a²
```

### 無負荷試験

```text
Y0 = I0/V0
g0 = P0/V0²
b0 = sqrt(Y0²-g0²)
```

成立条件: 無負荷電流が小さく、直列部の電圧降下・銅損を無視できること。

### 短絡試験

```text
Z = Vsc/Isc
R = Psc/Isc²
X = sqrt(Z²-R²)
```

成立条件: 短絡試験電圧が低く、励磁電流・鉄損を無視できること。

### 百分率量

```text
ZB = VN²/SN = VN/IN
%r = 100R/ZB
%x = 100X/ZB
%Z = sqrt((%r)²+(%x)²)
```

基準変更:

```text
zpu,new = zpu,old × (SB,new/SB,old) × (VB,old/VB,new)²
```

### 電圧変動率

```text
遅れ: ε ≈ k(p cosφ + q sinφ)
進み: ε ≈ k(p cosφ - q sinφ)
```

必要な問題ではフェーザの二次項または厳密式を使う。

### 効率

```text
Pout = k SN cosφ
Pcu = k² Pcu,N
η = Pout / (Pout + Pi + Pcu)
kmax = sqrt(Pi/Pcu,N)
```

### 並列運転

```text
IA/IB = ZB/ZA
```

前提: 無負荷二次電圧の大きさ・位相が一致し、同一側へ換算したインピーダンスで比較する。容量比例分担には自己容量基準の `%Z` とインピーダンス角をそろえることが基本となる。
