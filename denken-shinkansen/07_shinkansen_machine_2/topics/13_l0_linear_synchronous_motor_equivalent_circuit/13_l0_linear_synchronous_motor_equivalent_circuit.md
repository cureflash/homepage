# 解説本文

## §1 このテーマで電験は何を問うか

このテーマの中心は、同期機の「磁界を作る側」と「電流が流れる側」を区別し、電機子反作用を等価リアクタンスへ置き換え、1相分等価回路とフェーザを読めるようにすることである。

本試験では、単に同期機の名称を覚えるのではなく、次の連鎖を追えることが必要になる。

`界磁 → 界磁起磁力 → 無負荷誘導起電力`

`電機子電流 → 電機子反作用起磁力 → 合成起磁力 → 内部誘導起電力`

さらに、電機子反作用を `X_a`、漏れリアクタンスを `X_l` として表し、`X_s=X_a+X_l` にまとめると、端子電圧・内部起電力・電機子電流をフェーザで扱える。

Topic 13ではここまでを完成させる。負荷角、力率、電力角特性、最大出力はTopic 14へ送る。

## §2 同期機の構造と同期運転

同期機では、主磁束を作る側を界磁、電力を授受する巻線側を電機子として考える。典型的な三相同期機では、電機子三相巻線が作る回転磁界と界磁磁極が同期して回転する。

極数を `P`、電源周波数を `f [Hz]` とすると、回転磁界の同期速度は

`N_s = 120f/P  [min^-1]`

である。同期運転では界磁磁極はこの回転磁界と同期して運動する。誘導機のように、定常運転を説明するための「すべり」を基本変数にはしない。

界磁電流が作る界磁起磁力を `F_f` とすると、その主磁束によって電機子巻線に無負荷誘導起電力 `E_0` が生じる。R07一次問1では、界磁起磁力と無負荷誘導起電力を区別してフェーザ上で読めることが重要である。

## §3 電機子反作用

負荷時には電機子電流 `I` が流れ、その電流自身も起磁力 `F_a` を作る。この `F_a` が主磁束へ作用する現象が電機子反作用である。

磁気的には

`F = F_f + F_a`

と合成して考える。`F_a` の向きが `F_f` と同方向なら増磁作用、反対方向なら減磁作用、ほぼ直交方向なら交差磁化作用として整理できる。

- 増磁作用: 合成起磁力を大きくする向き。
- 減磁作用: 合成起磁力を小さくする向き。
- 交差磁化作用: 主磁束の向きを横から変形させる向き。

R06一次問1で必要なのは、この分類と誘導起電力への影響を結び付けることである。増磁なら合成磁束・誘導起電力を増加させる方向、減磁なら減少させる方向に働く。交差磁化は主として磁束分布を横方向へ変形させる。

界磁起磁力 `F_f` だけから生じるものを無負荷誘導起電力 `E_0`、`F_f` と電機子反作用起磁力 `F_a` の合成起磁力から生じるものを内部誘導起電力 `E_i` として区別すると、R07一次問1の起磁力と起電力の対応を追いやすい。

## §4 同期リアクタンスと1相分等価回路

電機子反作用は、回路計算では電機子反作用リアクタンス `X_a` による電圧降下として表す。電機子巻線には漏れ磁束による漏れリアクタンス `X_l` もあるため、円筒形同期機の基本モデルでは

`X_s = X_a + X_l`

とまとめ、`X_s` を同期リアクタンスと呼ぶ。

R07一次問1の磁気的な表現では、合成起磁力から内部誘導起電力 `E_i` が生じ、発電機で電機子抵抗を無視するなら

`V = E_i - jX_l I`

とみなせる。

一方、電機子反作用を `X_a` へ置き換えた等価回路では、無負荷誘導起電力 `E_0` と端子電圧 `V` の間に同期リアクタンス降下をまとめて置ける。電機子抵抗を無視し、発電機電流を機外向きに正とするなら

`E_0 = V + jX_s I`

である。

電動機では電流を電源から機内へ流れ込む向きに正とすると

`V = E + jX_s I`

したがって

`E = V - jX_s I`

となる。

試験では「発電機式を丸暗記して電動機へそのまま使う」ことを避け、電流の正方向とKVLから符号を決める。

## §5 フェーザの読み方

フェーザでは `j` を掛けるとベクトルは90°進む。したがって `jX_sI` は、電機子電流 `I` を90°進め、長さを `X_s` 倍したベクトルである。

同期電動機の基本関係

`V = E + jX_sI`

を読むときは、次の順で確認する。

1. 問題が電動機か発電機か確認する。
2. 電機子電流 `I` の正方向を確認する。
3. `I` を90°進めて `jX_sI` を作る。
4. 電動機なら `E = V-jX_sI`、発電機なら定義した電流方向に従ってKVLを立てる。
5. ベクトル名を、端子電圧 `V`、電機子電流 `I`、同期リアクタンス降下 `jX_sI`、内部／無負荷誘導起電力 `E` として識別する。

Topic 13ではベクトルの識別と加減算までに限定し、`V` と `E` の位相差を使った出力計算へ進まない。

## §6 回転同期機を直線状に展開する

リニア同期モータは、回転同期機の円周方向を直線方向へ展開したものとして概念的に理解できる。

回転同期機では、三相電機子が空間的に移動する回転磁界を作り、その磁界と界磁磁極が同期して回転する。これを直線状に展開すると、三相電機子が直線方向へ進む移動磁界を作り、界磁側がその移動磁界と同期して直線運動する、と読み替えられる。

この対応は「回転子をそのまま切って伸ばせばL0系実機になる」という意味ではない。電験で学ぶ同期機の役割分担を、リニア同期モータへ概念対応させるためのモデルである。

## §7 L0系への接続

JR東海の公式説明では、ガイドウェイの推進コイルへ電流を流してN極・S極の磁界を発生させ、車両側に交互配置された超電導磁石との吸引力・反発力で車両を推進する構成が示されている。

Topic 13では、この一次資料で確認できる範囲だけを同期機へ対応させる。

- ガイドウェイの推進コイル: 電機子側に対応し、進行方向へ磁界を作る側。

## §8 問題を見たときの解法手順

1. 同期発電機か同期電動機かを判定する。
2. 界磁、電機子、界磁起磁力、電機子反作用起磁力を区別する。
3. 必要なら `N_s=120f/P` で同期速度を確認する。
4. 電機子反作用は増磁・減磁・交差磁化のどの向きかを磁気的に判断する。
5. 回路計算では `X_s=X_a+X_l` で同期リアクタンスを作る。
6. `jX_sI` は `I` を90°進めたベクトルとして描く。
7. 電動機／発電機と電流の正方向を確認してKVLを立てる。
8. 最後に `V`,`I`,`E`,`jX_sI` の名称と向きを照合する。
9. 問題が負荷角・力率・電力角特性へ進んだら、Topic 13の固定範囲を超えていると切り分ける。

## §9 3段階例題

### 例題1 基礎: 極数と周波数から同期速度を求める

8極、50 Hzの三相同期機の同期速度を求める。

`N_s = 120f/P`

より

`N_s = 120×50/8 = 750 min^-1`

同期機では界磁磁極がこの回転磁界と同期して運動する。極数 `P=8` を極対数4と取り違えないことが要点である。

### 例題2 本試験標準: 同期リアクタンスと発電機フェーザ

一相当たり `X_a=1.2 Ω`、`X_l=0.3 Ω` の同期発電機がある。電機子抵抗を無視し、端子電圧を `V=200+j0 V`、機外へ流れる電機子電流を `I=10+j0 A` とする。同期リアクタンス、同期リアクタンス降下、無負荷誘導起電力を求める。数値は教材上の仮定値である。

同期リアクタンス:

`X_s = X_a + X_l = 1.2+0.3 = 1.5 Ω`

リアクタンス降下:

`jX_sI = j×1.5×10 = j15 V`

発電機のKVL:

`E_0 = V+jX_sI = 200+j15 V`

大きさは

`|E_0| = sqrt(200^2+15^2) ≒ 200.56 V`

である。`jX_sI` が `I` より90°進むこと、`X_a` と `X_l` を足して `X_s` とすることを同時に確認する。

### 例題3 複合: 電動機フェーザ・電機子反作用・リニア同期モータへの対応

一相当たり `X_s=1.5 Ω`、端子電圧 `V=200+j0 V`、機内へ流れ込む電機子電流 `I=10+j0 A` の同期電動機を考える。電機子抵抗は無視する。また、別の三つの運転状態で電機子反作用起磁力 `F_a` が界磁起磁力 `F_f` とそれぞれ同方向、反対方向、直交方向に作用するとする。数値は教材上の仮定値である。

同期リアクタンス降下は

`jX_sI = j15 V`

である。電動機では

`V = E+jX_sI`

なので

`E = V-jX_sI = 200-j15 V`

となる。大きさは約 `200.56 V` である。

電機子反作用は、`F_a` が `F_f` と同方向なら増磁、反対方向なら減磁、直交方向なら交差磁化作用である。

この回転同期機を直線状に読み替えると、電機子側が作る回転磁界は移動磁界、界磁側の磁極はその移動磁界と同期して進む側に対応する。L0系ではJR東海一次資料で確認できる範囲に限り、推進コイルを電機子側、車両側超電導磁石を界磁側として概念対応させる。

## §10 頻出ミス

- 界磁と電機子を逆に覚える。
- 界磁起磁力、電機子反作用起磁力、合成起磁力を同一視する。
- 無負荷誘導起電力と内部誘導起電力を区別しない。
- `X_s=X_a+X_l` のどちらかを落とす。
- `jX_sI` を `I` と同じ向きに描く。`j` は90°進みである。
- 発電機と電動機で電流の正方向を確認せず、フェーザ式の符号だけを暗記する。
- 同期機に誘導機のすべりをそのまま持ち込む。
- 増磁・減磁・交差磁化を力率の丸暗記だけで判定しようとする。本テーマでは起磁力の相対方向から整理する。
- リニア同期モータの移動磁界を、未確認の極ピッチ・周波数・推力実値へ勝手に展開する。
- Topic 14の負荷角・力率・電力角特性まで先取りする。

## §12 公式・解法まとめ

- 同期速度: `N_s=120f/P`
- 合成起磁力: `F=F_f+F_a`
- 同期リアクタンス: `X_s=X_a+X_l`
- `jX_sI`: `I` を90°進め、長さを `X_s` 倍したフェーザ
- 発電機（機外向き電流、`R_a≈0`）: `E_0=V+jX_sI`
- 電動機（機内向き電流、`R_a≈0`）: `V=E+jX_sI`、`E=V-jX_sI`
- リニア同期モータ: 回転磁界を直線方向の移動磁界へ概念的に読み替える
