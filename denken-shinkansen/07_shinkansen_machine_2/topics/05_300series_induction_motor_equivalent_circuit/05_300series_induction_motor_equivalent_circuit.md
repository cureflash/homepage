# 解説本文

## 1. このテーマで電験二種は何を問うか

このテーマでは、三相誘導電動機を一相分のL形等価回路へ置き換え、電流、入力、損失、機械出力、軸出力、トルク、効率を一つの流れで計算できることが中心になる。一次試験では等価回路中の式や損失の対応を選択式で判定し、二次試験では滑りを求めてから複素電流、電力、トルクまで途中式付きで計算する。

300系は誘導主電動機を具体化する題材として扱う。ただし、本章では300系実車の未確認回路定数を教材値として流用しない。例題はすべて「教材上の仮定値」であり、電験の一般問題へ転用できる式と解法を学ぶ。

解法の中心は次の順序である。

```text
線間電圧 → 相電圧
周波数・極数・回転速度 → 同期速度・滑り
L形等価回路 → I0, I2', I1
二次入力 P2 → 二次銅損 Pc2 → 機械出力 Pm → 軸出力 Pshaft
一次入力 P1 → 効率 η
P2/ω0 または Pshaft/ωm → トルク
```

## 2. 一相分L形等価回路と各定数

三相誘導電動機を対称三相として扱うと、三相全部を毎回描かず、一相分の等価回路で計算できる。星形結線で線間電圧が `VL` のとき、一相へ加わる相電圧は

```text
V1 = VL / √3
```

である。線間電圧をそのまま一相等価回路へ入れると、電流・電力が大きくずれる。

本テーマで使うL形等価回路は、入力端に励磁枝を置き、負荷電流が流れる直列枝を

```text
r1 + jx1 + r2'/s + jx2'
```

とする近似回路である。

各記号の意味は次のとおり。

- `r1 [Ω]`: 一次巻線抵抗。一次銅損に対応する。
- `x1 [Ω]`: 一次漏れリアクタンス。
- `g0 [S]`: 励磁枝のコンダクタンス。鉄損等をまとめた励磁損に対応する。
- `b0 [S]`: 励磁枝のサセプタンス。励磁無効電流を表す。
- `r2' [Ω]`: 二次抵抗の一次側換算値。
- `x2' [Ω]`: 二次漏れリアクタンスの一次側換算値。
- `s`: 滑り。無次元量で、百分率で与えられた場合は小数へ直す。

励磁アドミタンスは

```text
y0 = g0 - jb0
```

と書く。誘導性の励磁電流を負の虚数成分で表す約束である。

## 3. 同期速度・滑りと `r2'/s`

周波数 `f [Hz]`、極数 `p` の誘導電動機の同期速度は

```text
Ns = 120f/p   [min^-1]
```

である。回転子速度を `N [min^-1]` とすると滑りは

```text
s = (Ns - N)/Ns
```

である。例えば `s=0.03` は3 %を意味する。

L形等価回路では二次側の抵抗成分が `r2'/s` となる。これを

```text
r2'/s = r2' + ((1-s)/s)r2'
```

と分けると意味が見える。前半 `r2'` で消費される電力が二次銅損、後半 `((1-s)/s)r2'` に対応する電力が電気から機械へ変換された機械出力である。

ここでは `s` が小さいほど `r2'/s` が大きくなるという回路上の関係まで使う。最大トルク条件や比例推移へは進まない。

## 4. 励磁電流・二次電流・一次電流

L形等価回路では、まず励磁枝と負荷枝を別々に計算すると整理しやすい。

励磁電流は

```text
I0 = y0V1 = (g0 - jb0)V1
```

である。

負荷枝のインピーダンスを

```text
Z2 = r1 + r2'/s + j(x1+x2')
```

とおけば、二次電流一次換算値は

```text
I2' = V1 / Z2
```

となる。分母が複素数なので、二次試験では実部・虚部を保ったまま計算する。

一次電流はフェーザ和

```text
I1 = I0 + I2'
```

である。`|I0|+|I2'|` と絶対値同士を足してはいけない。実部同士、虚部同士を加えた後で必要なら

```text
|I1| = √{(Re I1)^2 + (Im I1)^2}
```

を求める。

励磁電流を無視すると問題文に明記されている場合だけ `I1 ≒ I2'` とできる。

## 5. 誘導電動機の電力フロー

誘導電動機では、電力の名前を順番で覚えると取り違えにくい。

```text
一次入力 P1
  ↓ 一次銅損・励磁損
二次入力 P2（空隙を越えて回転子へ渡る電力）
  ↓ 二次銅損 Pc2
機械出力 Pm（電磁変換された機械電力）
  ↓ 機械損 Wm
軸出力 Pshaft
```

問題ごとに「無視する損失」が異なる。機械損を無視するなら `Pshaft=Pm` だが、機械損 `Wm` が与えられれば差し引く。励磁損を無視する条件なら一次入力へ加えない。条件を勝手に追加しないことが重要である。

## 6. 二次入力・二次銅損・機械出力・軸出力

二次電流一次換算値 `I2'` が求まれば、二次入力は

```text
P2 = 3(r2'/s)|I2'|^2
```

である。三相分なので係数3を付ける。

二次銅損は

```text
Pc2 = 3r2'|I2'|^2
     = sP2
```

となる。したがって機械出力は

```text
Pm = P2 - Pc2
   = (1-s)P2
```

である。機械損 `Wm` を考えると軸出力は

```text
Pshaft = Pm - Wm
```

となる。

`P2`、`Pm`、`Pshaft` は同じではない。二次入力 `P2` から滑り分 `sP2` が二次銅損として失われ、さらに機械損があればその分だけ軸出力が減る。

## 7. トルク

トルクは「どの電力を、どの角速度で割るか」を区別する。

同期角速度は

```text
ω0 = 2πNs/60   [rad/s]
```

回転子の機械角速度は

```text
ωm = 2πN/60   [rad/s]
```

である。

電磁トルクは

```text
Te = P2/ω0
   = Pm/ωm
```

で求められる。`Pm=(1-s)P2`、`ωm=(1-s)ω0` なので両式は一致する。

一方、軸に実際に取り出される軸トルクは

```text
Tshaft = Pshaft/ωm
```

である。機械損がある場合、`Te` と `Tshaft` は同じではない。

また、励磁電流を無視したL形等価回路で

```text
D = (r1+r2'/s)^2 + (x1+x2')^2
```

とおけば

```text
|I2'|^2 = V1^2/D
```

だから

```text
P2 = 3V1^2(r2'/s)/D
Te = 3V1^2(r2'/s)/(ω0D)
```

と導ける。一次試験では、この導出途中の係数や分母を選ばせる形式に対応できるようにする。

## 8. 一次入力・損失・効率

L形等価回路での励磁損は

```text
WI = 3g0V1^2
```

一次銅損は

```text
Pc1 = 3r1|I2'|^2
```

二次銅損は

```text
Pc2 = 3r2'|I2'|^2
```

である。

このL形近似では一次入力を

```text
P1 = WI + Pc1 + P2
```

と整理できる。これは同じく

```text
P1 = Pshaft + Wm + Pc2 + Pc1 + WI
```

である。

効率は

```text
η = Pshaft/P1
```

である。百分率表示なら最後に100を掛ける。

問題で励磁損、機械損などを無視すると指定された場合は、その項だけを0として扱う。逆に、与えられている損失を勝手に捨てない。

## 9. 二種一次の選択式解法

一次試験の式選択問題では、数値計算を始める前に電力の意味と次元を確認する。

1. `I0` ならアドミタンス `[S] × 電圧 [V]` なので電流 `[A]` になるか確認する。
2. 損失なら `3I^2R` または `3gV^2` の形で `[W]` になるか確認する。
3. 二次入力なら抵抗成分が `r2'/s`、二次銅損なら `r2'` であることを確認する。
4. 機械出力なら `P2` に `(1-s)` が掛かる。
5. 効率は必ず `出力/入力` で1未満になるかを確認する。
6. トルク式では電力を角速度 `[rad/s]` で割り、単位が `[N·m]` になるか確認する。

この順で次元と物理的意味を見れば、似た式の選択肢を機械的に暗記せず絞り込める。

## 10. 二種二次の記述計算手順

二次試験では答えだけでなく、何をどの順に求めたかが採点対象になる。次の順を基本形とする。

1. 結線を確認し、星形なら `V1=VL/√3` と相電圧へ直す。
2. `Ns=120f/p` を求める。
3. `s=(Ns-N)/Ns` を求め、%なら小数へ直す。
4. `r2'/s` を計算して負荷枝インピーダンスを作る。
5. `I0=(g0-jb0)V1` を求める。
6. `I2'=V1/[r1+r2'/s+j(x1+x2')]` を複素数で求める。
7. 必要なら `I1=I0+I2'` として最後に大きさを取る。
8. `P2`、`Pc2`、`Pm`、`Pshaft` を電力フロー順に求める。
9. 一次入力と効率を求める。
10. トルクが問われたら、電磁トルクか軸トルクかを確認して対応する電力・角速度を使う。

単位換算は途中に残す。

```text
1 kW = 1000 W
N [min^-1] → ω [rad/s] : ω = 2πN/60
3 % → 0.03
```

## 11. 3段階例題

以下の数値はすべて教材上の仮定値であり、300系実車値ではない。

### 例題A 基礎: 滑りから二次入力まで

三相星形誘導電動機について、`VL=200 V`、`f=50 Hz`、`p=4`、`N=1440 min^-1`、`r1=0.20 Ω`、`x1=0.40 Ω`、`r2'=0.30 Ω`、`x2'=0.50 Ω` とする。励磁電流と機械損は無視する。相電圧、滑り、`I2'`、二次入力 `P2`、二次銅損 `Pc2`、機械出力 `Pm` を求める。

まず相電圧は

```text
V1 = 200/√3 = 115.47 V
```

同期速度は

```text
Ns = 120×50/4 = 1500 min^-1
```

したがって滑りは

```text
s = (1500-1440)/1500 = 0.040
```

負荷枝は

```text
Z2
= 0.20 + 0.30/0.040 + j(0.40+0.50)
= 7.70 + j0.90 Ω
```

よって

```text
I2' = 115.47/(7.70+j0.90)
    = 14.79 - j1.73 A
|I2'| = 14.89 A
```

二次入力は

```text
P2 = 3×(0.30/0.040)×14.89^2
   ≒ 4.99 kW
```

二次銅損は

```text
Pc2 = sP2 = 0.040×4.99 kW ≒ 0.200 kW
```

機械出力は

```text
Pm = (1-s)P2 = 0.960×4.99 kW ≒ 4.79 kW
```

検算すると `P2 ≒ Pc2+Pm = 0.200+4.79 = 4.99 kW` で一致する。

### 例題B 本試験標準: 励磁枝・入力電流・効率

三相星形誘導電動機について、`VL=400 V`、`f=50 Hz`、`p=4`、`N=1455 min^-1`、`r1=0.25 Ω`、`x1=0.50 Ω`、`r2'=0.18 Ω`、`x2'=0.40 Ω`、`g0=0.0008 S`、`b0=0.0040 S`、機械損 `Wm=100 W` とする。`I0`、`I2'`、一次電流の大きさ、二次入力、軸出力、一次入力、効率を求める。

相電圧、同期速度、滑りは

```text
V1 = 400/√3 = 230.94 V
Ns = 120×50/4 = 1500 min^-1
s = (1500-1455)/1500 = 0.030
```

励磁電流は

```text
I0 = (0.0008-j0.0040)×230.94
   = 0.185-j0.924 A
```

負荷枝は

```text
Z2 = 0.25 + 0.18/0.030 + j(0.50+0.40)
   = 6.25+j0.90 Ω
```

したがって

```text
I2' = 230.94/(6.25+j0.90)
    = 36.20-j5.21 A
```

一次電流は絶対値を先に足さず、フェーザで加える。

```text
I1 = I0+I2'
   = 36.38-j6.14 A
|I1| ≒ 36.90 A
```

二次入力は

```text
P2 = 3×(0.18/0.030)×|I2'|^2
   ≒ 24.08 kW
```

二次銅損と機械出力は

```text
Pc2 = sP2 ≒ 0.722 kW
Pm = (1-s)P2 ≒ 23.35 kW
Pshaft = Pm-0.100 ≒ 23.25 kW
```

励磁損と一次銅損は

```text
WI = 3×0.0008×230.94^2 = 0.128 kW
Pc1 = 3×0.25×|I2'|^2 ≒ 1.003 kW
```

一次入力は

```text
P1 = WI+Pc1+P2
   ≒ 0.128+1.003+24.077
   ≒ 25.21 kW
```

よって効率は

```text
η = 23.25/25.21 ≒ 0.923 = 92.3 %
```

`η<100 %` であり、`P1` と `Pshaft` の差も各損失の和と一致する。

### 例題C 複合・ひっかけ: 電磁トルクと軸トルク

例題Aの条件を使い、電磁トルク `Te` を `P2/ω0` と `Pm/ωm` の両方から求める。また、もし機械損が `120 W` ある場合の軸トルクを求める。

同期角速度と回転角速度は

```text
ω0 = 2π×1500/60 = 157.08 rad/s
ωm = 2π×1440/60 = 150.80 rad/s
```

例題Aより `P2=4.9917 kW`、`Pm=4.7920 kW` なので

```text
Te = 4991.7/157.08 = 31.78 N·m
```

別経路では

```text
Te = 4792.0/150.80 = 31.78 N·m
```

となり一致する。

機械損が `120 W` あるなら

```text
Pshaft = 4792.0-120 = 4672.0 W
Tshaft = 4672.0/150.80 = 30.98 N·m
```

である。`Pshaft/ω0` としてはいけない。また、機械損があるのに `Te=Tshaft` としてもいけない。

## 12. 300系への接続

本テーマでは300系の誘導主電動機を、一相分等価回路で理解するための題材として位置付ける。実機でも、端子電圧・周波数と電動機内部の抵抗・漏れリアクタンス・励磁成分が電流と損失を決め、二次入力から二次銅損を差し引いた分が機械出力へ変換されるという基本構造は同じである。

## 13. 頻出ミス・公式まとめ・過去問対応

頻出ミスは次のとおり。

- 星形結線なのに `VL` をそのまま一相等価回路へ入れる。
- `3 %` を `3` のまま使い、`0.03` へ直さない。
- 二次入力の抵抗を `r2'` とし、`r2'/s` を使わない。
- 二次銅損に `r2'/s` を使う。
- `I1` を `|I0|+|I2'|` で求める。
- `Pm` と `Pshaft` を同じとみなす。
- 電磁トルクで `P2/ωm` を使う。
- 軸トルクで同期角速度 `ω0` を使う。
- 効率の分子に機械出力 `Pm` を置き、機械損を引き忘れる。
- kWのまま `P/ω` を計算して `N·m` とする。トルク計算ではWへ直す。

主要公式は次である。

```text
V1 = VL/√3
Ns = 120f/p
s = (Ns-N)/Ns
I0 = (g0-jb0)V1
I2' = V1/{r1+r2'/s+j(x1+x2')}
I1 = I0+I2'

WI = 3g0V1^2
Pc1 = 3r1|I2'|^2
P2 = 3(r2'/s)|I2'|^2
Pc2 = 3r2'|I2'|^2 = sP2
Pm = (1-s)P2
Pshaft = Pm-Wm
P1 = WI+Pc1+P2
η = Pshaft/P1

ω0 = 2πNs/60
ωm = 2πN/60
Te = P2/ω0 = Pm/ωm
Tshaft = Pshaft/ωm
```
