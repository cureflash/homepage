# 解説本文

## §1 このテーマで電験は何を問うか

電験二種では、極数・周波数・同期速度・すべりを別々に暗記するのではなく、一つの計算鎖として扱う必要がある。二次試験ではさらに回転速度から角速度へ変換し、`P_m=Tω` で出力とトルクを接続する。一次試験では、滑りの符号や同期速度近傍の特性、電動機要求とインバータ定格・短時間過負荷耐量の関係が問われる。

本テーマの解法の中心は次の順序である。

1. 極数 `P_p` と周波数 `f` から同期速度 `N_s` を出す。
2. すべり `s` から実回転速度 `N`、または実回転速度から `s` を出す。
3. 必要なら滑り速度 `sN_s` と滑り周波数 `f_2=sf` を出す。
4. `N` を角速度 `ω` へ変換する。
5. `P_m=Tω` で出力またはトルクを求める。
6. 電動機の連続要求と短時間ピーク要求を分け、インバータ定格・過負荷耐量と照合する。

ここでは極数を `P_p`、機械出力を `P_m` と書き分ける。公式過去問などで極数を単に `P` と表す場合もあるため、記号の意味を必ず確認する。

## §2 極数・周波数・同期速度

三相誘導電動機の同期速度は

`N_s = 120f/P_p  [min^-1]`

である。`f` は電源周波数 `[Hz]`、`P_p` は極数であり極対数ではない。逆算は

`f = P_p N_s / 120`

で行う。

同じ同期速度を得たい場合、必要周波数は極数に比例する。したがって4極から6極へ変え、同期速度を同じに保つなら

`f_6/f_4 = 6/4 = 1.5`

となる。例えば同期速度1500 min^-1なら、4極では50 Hz、6極では75 Hzである。

この比較で重要なのは「6極だから回転速度が必ず高い／低い」と決めつけないことである。同期速度は極数と周波数の組合せで決まる。インバータ給電では周波数を変えられるため、極数だけで実回転速度は決まらない。

## §3 すべり・実回転速度・滑り周波数

誘導電動機のすべりは

`s = (N_s-N)/N_s`

で定義する。したがって

`N = (1-s)N_s`

である。

電動機運転では通常 `0<s<1` で、回転子は同期速度より少し遅い。`s=0` では同期速度、`s<0` では回転速度が同期速度を上回る。R07一次問2の固定範囲では、この符号判断を行えることが必要である。

同期速度と実回転速度の差は

`N_s-N = sN_s`

で、これを滑り速度として扱う。回転子側の滑り周波数は

`f_2 = sf`

である。

同期速度近傍で問題文が `T∝s` を条件として与える場合は、その比例関係をそのまま使う。本テーマでは最大トルク条件や等価回路からこの比例関係を導出しない。

## §4 回転速度・角速度・トルク・出力

回転速度 `N [min^-1]` を角速度へ変換すると

`ω = 2πN/60  [rad/s]`

である。機械出力は

`P_m = Tω`

であり、トルクを求めるなら

`T = P_m/ω`

となる。

計算では kW を W に直すことが重要である。例えば `240 kW = 240000 W` であり、`P_m` をW、`ω` をrad/sで代入すればトルクはN·mで得られる。

回転速度を同期速度のまま代入してはいけない。誘導電動機ではまず滑りを使って実回転速度 `N` を求め、その `N` から `ω` を計算する。

## §5 4極と6極を同一機械回転速度で比較する

同じ車輪速度を比較する場合、歯車比と車輪径が同じなら、同じ電動機回転速度を得ればよい。ここでは歯車比・車輪径の未確認実車値を使わず、「同一の機械回転速度 `N`、同一のすべり `s`」を比較条件とする。

まず

`N_s = N/(1-s)`

で必要な同期速度を求め、次に

`f = P_p N_s/120`

で周波数を求める。同じ `N` と `s` なら `N_s` は同じなので、6極機の必要周波数は4極機の1.5倍になる。

この結果は「6極化だけで出力密度が上がる」とは意味しない。出力密度には電磁設計、冷却、材料、寸法など複数の設計要因が関係する。本テーマでは未確認のN700S実機値や因果関係を追加しない。

## §6 インバータ定格と短時間過負荷耐量

電動機をインバータで駆動する場合、インバータは電動機の必要出力・運転状態と無関係には選べない。連続運転で必要な出力に対して定格容量を確認し、加速など短時間だけ大きな出力が必要なら、許容時間を含む短時間過負荷耐量も確認する。

例えば定格250 kW、短時間125%まで許容されるという教材上の条件なら、短時間の上限は

`250×1.25 = 312.5 kW`

である。連続要求が240 kW、短時間要求が300 kWなら、この数値条件だけでは連続・短時間とも範囲内である。ただし実機選定では電圧・電流・温度・許容時間等も必要であり、本テーマでは未提示条件を補完しない。

## §7 出力密度

出力密度は、限られた質量または体積からどれだけの出力を取り出せるかを見る設計指標である。代表的には

`質量当たり出力密度 = 出力 / 質量`

`体積当たり出力密度 = 出力 / 体積`

と表せる。同じ出力なら質量・体積が小さいほど出力密度は高い。

本テーマでは「出力密度」という設計観点だけを扱い、N700S主電動機の未確認質量・寸法・出力密度を実値として置かない。また、6極化だけを小型軽量化の唯一の原因とはしない。

## §8 N700Sへの接続

系列 `SPEC.md` ではN700S主電動機を6極として扱う。本テーマで確認するのは、その6極という条件を電験の式へ接続することだけである。

- 6極と周波数から同期速度を計算する。
- すべりから実回転速度を計算する。
- 実回転速度から角速度を求め、出力とトルクをつなぐ。
- 同じ機械回転速度を4極で得る場合と必要周波数を比較する。
- 出力密度とインバータ定格を設計上の確認項目として位置付ける。

未確認の実車定格・インバータ電圧電流・歯車比・車輪径は使わない。

## §9 問題を見たときの解法手順

1. 極数 `P_p`、周波数 `f`、回転速度 `N`、すべり `s` のどれが既知か確認する。
2. `N_s=120f/P_p` または `f=P_pN_s/120` で同期速度と周波数を結ぶ。
3. `s=(N_s-N)/N_s` または `N=(1-s)N_s` で実回転速度を求める。
4. 必要なら `sN_s` と `f_2=sf` を求める。
5. 出力・トルク問題なら `ω=2πN/60` を計算する。
6. `P_m=Tω` を使い、求める量について式を解く。
7. インバータ問題なら連続要求と短時間要求を分け、定格と過負荷耐量をそれぞれ照合する。
8. 単位、極数と極対数、同期速度と実回転速度の取り違えがないか検算する。

## §10 3段階例題

### 例題1 基礎: 6極誘導電動機の同期速度とすべり

6極、60 Hzの誘導電動機がすべり3%で運転している。同期速度、実回転速度、滑り周波数を求める。

同期速度:

`N_s = 120×60/6 = 1200 min^-1`

実回転速度:

`N = (1-0.03)×1200 = 1164 min^-1`

滑り周波数:

`f_2 = 0.03×60 = 1.8 Hz`

検算すると `N<N_s` であり、正のすべりをもつ電動機運転として整合する。

### 例題2 本試験標準: 回転速度からトルクまでつなぐ

6極、60 Hz、すべり2.5%で運転する誘導電動機の機械出力を240 kWとする。実回転速度とトルクを求める。数値は教材上の仮定値である。

同期速度:

`N_s = 120×60/6 = 1200 min^-1`

実回転速度:

`N = (1-0.025)×1200 = 1170 min^-1`

角速度:

`ω = 2π×1170/60 ≒ 122.52 rad/s`

トルク:

`T = 240000/122.52 ≒ 1.96×10^3 N·m`

同期速度1200 min^-1をそのまま `P_m=Tω` に入れないことが要点である。

### 例題3 複合: 4極・6極の必要周波数とインバータ余裕

同じ機械回転速度1800 min^-1を、すべり2%で得たい。4極機と6極機の必要周波数を比較する。また、連続要求240 kW、短時間要求300 kWに対し、定格250 kW・短時間125%という教材上のインバータ条件が与えられたとする。

必要同期速度:

`N_s = 1800/(1-0.02) ≒ 1836.73 min^-1`

4極:

`f_4 = 4×1836.73/120 ≒ 61.22 Hz`

6極:

`f_6 = 6×1836.73/120 ≒ 91.84 Hz`

したがって

`f_6/f_4 = 1.5`

である。

インバータの短時間上限は

`250×1.25 = 312.5 kW`

なので、与えられた容量条件だけでは連続240 kW、短時間300 kWの双方が範囲内である。短時間許容時間や電流上限など問題文にない条件は推測しない。

## §11 頻出ミス

- 極数と極対数を取り違える。
- `N_s=120f/P_p` の `120` を `60` と誤る。
- すべりを百分率のまま代入する。3%なら `0.03` とする。
- `s=(N_s-N)/N_s` の符号を逆にする。
- 滑り速度 `sN_s` と滑り周波数 `sf` を混同する。
- `P_m=Tω` に同期速度を直接入れ、実回転速度を使わない。
- kWをWへ換算せずトルクを計算する。
- 6極化だけを根拠に実車の小型軽量化・出力密度向上を断定する。
- インバータの定格容量と短時間過負荷耐量を同一視する。

## §13 公式・解法まとめ

- 同期速度: `N_s=120f/P_p`
- 周波数逆算: `f=P_pN_s/120`
- すべり: `s=(N_s-N)/N_s`
- 実回転速度: `N=(1-s)N_s`
- 滑り速度: `sN_s`
- 滑り周波数: `f_2=sf`
- 角速度: `ω=2πN/60`
- 機械出力: `P_m=Tω`
- トルク: `T=P_m/ω`
- 同じ `N_s` なら必要周波数は極数に比例し、6極は4極の1.5倍
- インバータは連続定格と短時間過負荷耐量を分けて確認する
- 出力密度は出力を質量または体積で除した設計指標として扱い、未確認実車値は置かない
