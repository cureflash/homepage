# EXAM_ALIGNMENT

資格: 第二種電気主任技術者

主科目: 一次試験「機械」、二次試験「機械・制御」

論点:

- `N_s = 120f/P` による極数・周波数・同期速度の関係
- `s = (N_s-N)/N_s`、`N=(1-s)N_s`
- 滑り速度 `sN_s` と滑り周波数 `f_2=sf`
- 回転角速度 `ω=2πN/60`
- 機械出力 `P=Tω` とトルクの相互換算
- 同じ機械回転速度を得る場合の4極・6極の必要周波数比較
- 電動機出力とインバータ容量・過負荷耐量の基本的な対応
- 出力密度は系列SPECの設計論点として扱うが、直接対応する公式過去問を件数合わせで捏造しない

# 教材で欠落不可の説明

1. 極数 `P` と極対数を混同せず、`N_s=120f/P` を単位 `[min^-1]` まで含めて使えること。
2. `s=(N_s-N)/N_s`、`N=(1-s)N_s`、`f_2=sf` を相互に使えること。
3. `ω=2πN/60` と `P=Tω` から、出力・トルク・回転速度を相互変換できること。
4. 同一機械回転速度を狙うとき、極数を4極から6極へ増やすと必要電源周波数がどう変わるかを `f=PN_s/120` で比較できること。
5. 誘導電動機では機械回転速度が同期速度そのものではなく、滑りを介して決まること。
6. インバータ定格は電動機の必要出力・運転状態と無関係に選べるものではなく、H25一次問3の範囲で定格容量／過負荷耐量との関係を説明すること。
7. 出力密度はSPEC固定項目として、同一出力をより小型・軽量な電動機で実現する設計指標として扱う。未確認のN700S寸法・質量・出力密度を実値化しないこと。
8. 4極・6極比較では車輪速度を同一条件とし、歯車比・車輪径などを使う場合は公式一次資料値または教材上の仮定値であることを明示すること。
