# 一次試験型

## 問1 6極誘導電動機の同期速度

6極、60 Hzの誘導電動機の同期速度として正しいものを選べ。

1. 600 min^-1
2. 900 min^-1
3. 1000 min^-1
4. 1200 min^-1
5. 1800 min^-1

### 正答

4

### 解説

同期速度は

`N_s=120f/P_p`

なので、

`N_s=120×60/6=1200 min^-1`

である。極数は極対数ではなく、ここでは6をそのまま使う。

---

## 問2 実回転速度からすべりを求める

6極、60 Hzの誘導電動機が1170 min^-1で回転している。すべりとして正しいものを選べ。

1. 1.5 %
2. 2.5 %
3. 3.0 %
4. 5.0 %
5. 7.5 %

### 正答

2

### 解説

まず

`N_s=120×60/6=1200 min^-1`

である。したがって

`s=(1200-1170)/1200=0.025=2.5 %`

となる。実回転速度を同期速度と取り違えないこと。

---

## 問3 滑り周波数

周波数50 Hz、すべり4 %で運転する誘導電動機の滑り周波数 `f_2` として正しいものを選べ。

1. 0.5 Hz
2. 1.0 Hz
3. 2.0 Hz
4. 4.0 Hz
5. 8.0 Hz

### 正答

3

### 解説

`f_2=sf`

より、

`f_2=0.04×50=2.0 Hz`

である。4 %を4のまま代入せず、0.04へ直す。

---

## 問4 すべり符号と同期速度近傍のトルク

誘導電動機について、問題文から「同期速度近傍ではトルク `T` はすべり `s` に比例する」と与えられた。最も適切な記述を選べ。

1. 通常の電動機運転では `s<0` であり、すべりを2倍にするとトルクは1/2になる。
2. 通常の電動機運転では `0<s<1` であり、同じ比例領域ならすべりを2倍にするとトルクも2倍になる。
3. 通常の電動機運転では常に `s=0` であり、トルクはすべりと無関係である。
4. `s>1` のときだけ電動機運転になり、トルクは `s^2` に比例する。
5. すべりの符号だけでは回転速度と同期速度の大小関係は判断できない。

### 正答

2

### 解説

通常の誘導電動機運転では回転速度 `N` が同期速度 `N_s` より低いため、

`0<s=(N_s-N)/N_s<1`

である。また問題条件として `T∝s` が与えられた範囲では、すべりを2倍にすればトルクも2倍になる。本テーマでは最大トルク条件や等価回路からこの比例関係を導出しない。

---

## 問5 回転速度とトルクから機械出力

回転速度1500 min^-1、トルク1000 N·mで回転している電動機の機械出力として最も近いものを選べ。

1. 78.5 kW
2. 104.7 kW
3. 157 kW
4. 188 kW
5. 314 kW

### 正答

3

### 解説

角速度は

`ω=2π×1500/60=50π≈157.08 rad/s`

したがって

`P_m=Tω=1000×157.08≈1.571×10^5 W≈157 kW`

である。

---

## 問6 機械出力からトルク

機械出力200 kW、回転速度1200 min^-1の電動機のトルクとして最も近いものを選べ。

1. 796 N·m
2. 1194 N·m
3. 1592 N·m
4. 2387 N·m
5. 3183 N·m

### 正答

3

### 解説

`ω=2π×1200/60=40π≈125.66 rad/s`

なので、

`T=P_m/ω=200000/125.66≈1592 N·m`

となる。kWはWへ直してから代入する。

---

## 問7 同一回転速度での4極・6極必要周波数

同じ機械回転速度1800 min^-1を、同じすべり2 %で得たい。4極機と6極機の必要周波数の組合せとして最も近いものを選べ。

1. 40.8 Hz、61.2 Hz
2. 61.2 Hz、91.8 Hz
3. 60.0 Hz、90.0 Hz
4. 61.2 Hz、61.2 Hz
5. 91.8 Hz、61.2 Hz

### 正答

2

### 解説

必要同期速度は

`N_s=N/(1-s)=1800/0.98≈1836.73 min^-1`

4極では

`f_4=4×1836.73/120≈61.22 Hz`

6極では

`f_6=6×1836.73/120≈91.84 Hz`

である。同じ `N` と `s` なら `N_s` は同じなので、必要周波数は極数に比例し、6極は4極の1.5倍になる。

---

## 問8 インバータ定格と短時間過負荷

連続要求240 kW、短時間要求300 kWの電動機負荷がある。インバータの連続定格は250 kW、短時間過負荷耐量は定格の125 %までとする。この数値条件だけから判断した記述として正しいものを選べ。

1. 連続要求だけが範囲内で、短時間要求は範囲外である。
2. 短時間要求だけが範囲内で、連続要求は範囲外である。
3. 連続要求、短時間要求とも範囲内である。
4. 連続要求、短時間要求とも範囲外である。
5. 定格容量と過負荷耐量は電動機要求出力と無関係なので判定できない。

### 正答

3

### 解説

連続要求は

`240 kW < 250 kW`

で範囲内である。短時間上限は

`250×1.25=312.5 kW`

なので、

`300 kW < 312.5 kW`

で短時間要求も範囲内である。実機選定では電圧・電流・許容時間・温度等も必要だが、問題文にない条件は補わない。

---

## 問9 質量当たり出力密度

機械出力300 kW、質量600 kgの電動機の質量当たり出力密度として正しいものを選べ。

1. 0.05 kW/kg
2. 0.30 kW/kg
3. 0.50 kW/kg
4. 2.0 kW/kg
5. 180 kW/kg

### 正答

3

### 解説

質量当たり出力密度は

`300/600=0.50 kW/kg`

である。本問の数値は教材用仮定値であり、N700S実機値ではない。

## 問10 同期速度・実回転速度・滑り速度・滑り周波数

4極、60 Hz、すべり5 %で運転する誘導電動機について、`同期速度、実回転速度、滑り速度、滑り周波数` の組合せとして正しいものを選べ。

1. `1500 min^-1, 1425 min^-1, 75 min^-1, 3 Hz`
2. `1800 min^-1, 1710 min^-1, 90 min^-1, 5 Hz`
3. `1800 min^-1, 1800 min^-1, 0 min^-1, 3 Hz`
4. `1800 min^-1, 1710 min^-1, 90 min^-1, 3 Hz`
5. `3600 min^-1, 3420 min^-1, 180 min^-1, 6 Hz`

### 正答

4

### 解説

同期速度は

`N_s=120×60/4=1800 min^-1`

実回転速度は

`N=(1-0.05)×1800=1710 min^-1`

滑り速度は

`sN_s=0.05×1800=90 min^-1`

滑り周波数は

`f_2=0.05×60=3 Hz`

である。

# 二次試験型

## 問11 6極機の同期速度・すべり・トルク

6極、60 Hzの誘導電動機が1140 min^-1で運転し、機械出力が240 kWである。次を求めよ。

1. 同期速度 `N_s`
2. すべり `s`
3. 回転角速度 `ω`
4. トルク `T`

### 解答・完全解説

同期速度は

`N_s=120×60/6=1200 min^-1`

すべりは

`s=(1200-1140)/1200=0.05=5 %`

回転角速度は実回転速度1140 min^-1を使い、

`ω=2π×1140/60≈119.38 rad/s`

機械出力240 kWを240000 Wへ直し、

`T=P_m/ω=240000/119.38≈2.01×10^3 N·m`

となる。

### 検算

`Tω≈2010×119.38≈2.40×10^5 W`

となり、元の240 kWと整合する。また `0<s<1` であり電動機運転として整合する。

---

## 問12 4極機の同期速度・滑り速度・滑り周波数

4極、60 Hz、すべり5 %で運転する誘導電動機について、次を求めよ。

1. 同期速度 `N_s`
2. 実回転速度 `N`
3. 滑り速度 `sN_s`
4. 滑り周波数 `f_2`

### 解答・完全解説

同期速度は

`N_s=120×60/4=1800 min^-1`

実回転速度は

`N=(1-0.05)×1800=1710 min^-1`

滑り速度は

`sN_s=0.05×1800=90 min^-1`

滑り周波数は

`f_2=sf=0.05×60=3 Hz`

である。

### 検算

`N_s-N=1800-1710=90 min^-1`

であり、`sN_s` と一致する。

---

## 問13 実回転速度からすべり・滑り周波数・トルクまで求める

4極、50 Hzの誘導電動機が1440 min^-1で運転し、機械出力が180 kWである。次を求めよ。

1. 同期速度 `N_s`
2. すべり `s`
3. 滑り周波数 `f_2`
4. 回転角速度 `ω`
5. トルク `T`

### 解答・完全解説

同期速度は

`N_s=120×50/4=1500 min^-1`

すべりは

`s=(1500-1440)/1500=0.04=4 %`

滑り周波数は

`f_2=0.04×50=2.0 Hz`

回転角速度は

`ω=2π×1440/60≈150.80 rad/s`

機械出力180 kWを180000 Wへ直して、

`T=180000/150.80≈1.19×10^3 N·m`

となる。

### 検算

`Tω≈1194×150.80≈1.80×10^5 W`

となり180 kWと整合する。

---

## 問14 4極・6極の必要周波数比較

同じ機械回転速度1800 min^-1を、同じすべり2 %で得たい。4極機と6極機について、次を求めよ。

1. 必要同期速度 `N_s`
2. 4極機の必要周波数 `f_4`
3. 6極機の必要周波数 `f_6`
4. `f_6/f_4`

### 解答・完全解説

実回転速度とすべりから必要同期速度を先に求める。

`N_s=N/(1-s)=1800/0.98≈1836.73 min^-1`

4極機では

`f_4=P_pN_s/120=4×1836.73/120≈61.22 Hz`

6極機では

`f_6=6×1836.73/120≈91.84 Hz`

したがって

`f_6/f_4≈91.84/61.22=1.50`

である。

### 解釈

同一の機械回転速度と同一すべりを保つなら必要同期速度は同じであり、必要周波数は極数に比例する。6極化だけで出力密度が高くなるとは結論しない。

---

## 問15 出力密度とインバータ定格

教材上の仮定値として、ある誘導電動機の連続機械出力を300 kW、質量を500 kgとする。短時間には390 kWが必要になる。これを連続定格320 kW、短時間過負荷耐量125 %のインバータで駆動するものとする。次を求め、判定せよ。

1. 電動機の質量当たり出力密度
2. インバータの短時間出力上限
3. 連続300 kW要求が定格内か
4. 短時間390 kW要求が与えられた過負荷耐量内か

### 解答・完全解説

質量当たり出力密度は

`300/500=0.60 kW/kg`

である。

インバータの短時間出力上限は

`320×1.25=400 kW`

である。

連続要求は

`300 kW < 320 kW`

なので、与えられた容量条件では定格内である。

短時間要求は

`390 kW < 400 kW`

なので、与えられた短時間過負荷条件では範囲内である。

### 注意

この判定は問題文で与えた出力容量条件だけに対するものである。実機選定に必要な電圧・電流・過負荷許容時間・温度等を推測して補わない。また300 kW、500 kg、320 kW等はN700S実機値ではない。
