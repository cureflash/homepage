# 解法アルゴリズム

1. 電流の向きを確認し、放電か充電かを判定する。
2. 起電力 `E`、内部抵抗 `r`、電流 `I` を抜き出し、放電なら `V=E-Ir`、充電なら電流を電池へ流れ込む向きに正として `V=E+Ir` を使う。
3. 容量がAhで与えられたら、まず `Q=It` またはC-rateから電流・時間を決める。
4. 電力量が必要なら、一定電圧では `W=VIt=VQ`、電圧変化がある場合は問題文で与えられた平均電圧を使う。
5. 内部抵抗損は電圧降下 `Ir` ではなく `I^2r` [W] で求める。
6. DC/DCや主変換装置を通るときは、各段で `P_out=ηP_in`、逆算では `P_in=P_out/η` とする。
7. `DC→DC` を行う装置がDC/DCコンバータであり、DCリンクは主変換装置へ渡す中間直流部であることを確認する。
8. 最後に A・h・Ah・W・Wh、電流方向、効率の掛け／割りを検算する。

# 解説本文

## §1 このテーマで電験は何を問うか

Topic 16の中心は、電池の化学反応を詳しく覚えることではない。試験では、蓄電池を「起電力＋内部抵抗」の直流電源として読み、電流、端子電圧、電気量、エネルギー、損失を一続きで計算できるかが問われる。

一次試験では、リチウムイオン二次電池の公称電圧、大電流時の電圧低下、Ah・Wh、DC/DCの識別、直流回路への蓄電池接続が主な判定点になる。二次試験では、C-rateから電流を出し、内部抵抗を含む端子電圧を求め、充放電時間と損失まで途中式付きで示せることが必要になる。

本テーマの計算鎖は次である。

`C-rate・Ah → 電流 I → 内部抵抗による端子電圧 V → Wh・I²r → DC/DC → DCリンク → 主変換装置`

## §2 起電力・内部抵抗・端子電圧

電池を最小限の等価回路で表すと、理想電圧源 `E` と内部抵抗 `r` の直列回路になる。

放電時、電池から外部へ流れる電流を `I>0` と定めれば、端子電圧は

`V = E - Ir`

である。

- `E`: 起電力 [V]
- `r`: 内部抵抗 [Ω]
- `I`: 放電電流 [A]
- `V`: 負荷から見た端子電圧 [V]

したがって放電電流を大きくすると、内部抵抗による電圧降下 `Ir` が増え、端子電圧は低くなる。大電流時に「公称電圧より端子電圧が下がる」という一次試験の知識問題は、この式で説明できる。

充電時は電流が逆向きである。電池へ流れ込む電流の大きさを `I>0` と定めれば

`V = E + Ir`

となり、充電器側は起電力より高い端子電圧を与える必要がある。

内部抵抗で熱になる電力は

`P_loss = I²r`

である。`Ir` は電圧 [V]、`I²r` は電力 [W] なので混同しない。電流を2倍にすると、同じ `r` なら内部抵抗損は4倍になる。

## §3 AhとWhを分ける

Ahは電気量、Whはエネルギーである。

一定電流なら

`Q[Ah] = I[A] × t[h]`

であり、

`1 Ah = 3600 C`

である。

例えば容量 `20 Ah` の電池を理想的に `5 A` 一定で使うなら、容量だけから求めた時間は

`t = Q/I = 20/5 = 4 h`

となる。ただし実際の利用可能容量、終止電圧、温度等はここでは扱わず、試験問題で与えられた条件に従う。

一定電圧 `V` であれば、電力量は

`W[Wh] = V[V] × I[A] × t[h] = VQ`

である。電圧が放電中に変化する問題で平均電圧 `V_avg` が与えられた場合は

`W = V_avg Q`

とする。逆に、総電力量 `W[Wh]` と通電電気量 `Q[Ah]` が分かれば

`V_avg = W/Q`

で平均電圧を求められる。

重量エネルギー密度 `e_m[Wh/kg]` が与えられたときは

`m = W/e_m`

で質量を求める。mAをAへ、gをkgへ直す単位換算が典型的なひっかけになる。

## §4 C-rateと充放電時間

容量を `C_Ah[Ah]`、C-rateを `kC` と書くと、理想化した一定電流は

`I = k C_Ah`

である。

理想充放電時間は

`t = C_Ah/I = 1/k [h]`

となる。

したがって、

- `0.5C` → 理想2 h
- `1C` → 理想1 h
- `2C` → 理想0.5 h

である。

二次記述問題では、充電と放電でC-rateが違うことがある。その場合は各区間の電流を別々に求める。内部起電力がSOCに応じて変わる理想モデルなら、定電流区間では端子電圧は

- 充電: `V_b = E_i(SOC) + Ir`
- 放電: `V_b = E_i(SOC) - Ir`

となる。つまり端子電圧波形は、内部起電力の波形を充電時は `+Ir`、放電時は `-Ir` だけ平行移動した形として読める。電流波形は、定電流条件なら各区間で一定値となる。

## §5 リチウムイオン二次電池で覚える最小範囲

固定過去問対応として、リチウムイオン二次電池は次だけ押さえる。

- 代表的な1セルの公称電圧は約 `3.6〜3.7 V` の範囲で扱われ、固定過去問では約 `3.7 V` が識別点になる。
- 大電流で放電すると、内部抵抗等の影響により端子電圧は公称電圧より低下する。
- 電池システムでは必要な電圧・電流に応じてセル／モジュールを組み合わせるが、Topic 16ではセル構成設計へ広げない。
- 電極材料や反応式は固定ゲートの除外部分であり、本テーマでは独立論点にしない。

N700Sについては、東芝インフラシステムズの公式資料で、SCiBリチウムイオン二次電池を用いた自走用バッテリー装置が量産車に採用され、長時間停電時に駆動システムへ電力を供給する構成が確認できる。一方、本教材では公表確認できていない電圧・容量・内部抵抗等を実車値として使わない。

## §6 DC/DCとDCリンク

DC/DCコンバータは、直流入力から別の直流電圧を作る電力変換装置である。

Topic 16では回路素子の導通状態や通流率の導出へは進まず、次の役割だけ扱う。

- 蓄電池側の直流電圧を、接続先の直流電圧レベルへ合わせる。
- 電力の流れを制御する。
- 変換には損失があるため、入力電力と出力電力は等しくない。

DCリンクは、主変換装置へ電力を受け渡す中間直流部として考える。教材上の一般化したブロックは

`蓄電池 → DC/DC → DCリンク → 主変換装置 → 主電動機`

である。

このブロックは電験のDC/DC・直流回路・変換効率を理解するための抽象化であり、N700S実車の未公表回路構成を断定するものではない。実車側について公式資料から確認できるのは、通常時に架線から補助電源装置を介してバッテリーへ充電し、自走時にはバッテリーシステムが駆動システムへ電力を供給するという系統関係までとする。

## §7 変換効率と内部抵抗損

変換器の効率は

`η = P_out/P_in`

である。

出力を求めるなら

`P_out = ηP_in`

必要入力を逆算するなら

`P_in = P_out/η`

とする。複数段の変換器を通る場合、総合効率は積になる。

`η_total = η_1 η_2 ...`

電池内部抵抗を含む単純モデルでは、放電時に理想電圧源が供給する電力 `EI` のうち、端子から取り出せる電力は `VI`、内部抵抗損は `I²r` なので

`EI = VI + I²r`

となる。

充電時は、端子から入る電力の一部が内部抵抗で失われる。内部抵抗損は常に `I²r` なので、同じ充電電力量を扱う比較では、必要以上に大きな電流が流れる区間を長く持つほど損失が増える。H23二次型では、低い電池電圧へ定電圧を加えた直後に大きな電流が流れる理想化条件と、電流を一定に抑える条件を比較し、`I²r` の大小からエネルギー効率を判断する。これは問題で与えられた理想モデルの比較であり、実車の充電制御方式を断定するものではない。

## §8 N700Sへの接続

N700Sは、停電等の異常時にバッテリーから駆動システムへ電力を供給して自走できるシステムを持つ。ここで電験の観点から重要なのは車両固有値ではなく、次の一般化である。

1. 電池は有限のAh・Whを持つ直流電源である。
2. 大電流を取り出すと内部抵抗で端子電圧が下がり、`I²r` の損失が増える。
3. 駆動側が必要とする直流電圧・電力へ電力変換し、中間直流部から主変換装置へ渡す。
4. 各段の効率が100%未満なら、モーターへ届く電力は電池端子電力より小さい。

したがって、非常走行用の電池を考えるときも、まず `Ah・C-rate → I → V → P → Wh` を求め、その後に変換効率を掛けて駆動側へ接続する。未確認のN700S実車定格を代入する必要はない。

## §9 頻出ミス・ひっかけ

- `Ah` と `Wh` を同じ量として扱う。
- `mA` をAへ換算せず `W=VIt` に代入する。
- 放電時に `V=E+Ir` としてしまう。
- 充電時も放電時も同じ符号を機械的に使う。
- 電圧降下 `Ir` [V] と損失 `I²r` [W] を混同する。
- `2C` を2時間と読む。理想時間は0.5 hである。
- 出力から必要入力を求めるときに効率を掛ける。逆算は効率で割る。
- DC/DCをAC/DCやDC/ACと取り違える。
- 教材用仮定値をN700S実車値と誤認する。

# 3段階例題

以下の数値は固定過去問の数値ではなく、すべて教材用仮定値である。

## 例題1 基礎 — 内部抵抗による端子電圧低下

起電力 `E=48 V`、内部抵抗 `r=0.08 Ω` の電池から `I=10 A` を放電する。端子電圧と内部抵抗損を求める。

放電なので

`V = E - Ir`

`V = 48 - 10×0.08 = 47.2 V`

内部抵抗損は

`P_loss = I²r = 10²×0.08 = 8 W`

となる。

検算として `EI=480 W`、`VI=472 W` であり、差は `8 W` なので電力収支が一致する。

## 例題2 本試験標準 — Ah・Wh・平均電圧・C-rate

容量 `24 Ah` の電池を `0.8C` の一定電流で放電する。平均端子電圧を `46 V` とする。放電電流、理想放電時間、取り出せる電力量を求める。

C-rateから

`I = 0.8×24 = 19.2 A`

理想放電時間は

`t = 24/19.2 = 1.25 h`

電力量は平均電圧を使って

`W = V_avg Q = 46×24 = 1104 Wh`

となる。

同じ関係を逆に使えば、電力量とAhが与えられた問題では `V_avg=W/Q` で平均電圧を求められる。

## 例題3 複合 — 電池からDCリンク、主変換装置まで

教材用仮定値として、電池の起電力 `E=360 V`、内部抵抗 `r=0.12 Ω`、容量 `50 Ah` とする。`1.2C` で放電し、DC/DC効率 `η_dc=0.96`、主変換装置効率 `η_inv=0.97` とする。電池端子電圧、端子電力、内部抵抗損、DCリンクへ渡る電力、主電動機へ供給される電気入力を求める。

まず放電電流は

`I = 1.2×50 = 60 A`

端子電圧は

`V = 360 - 60×0.12 = 352.8 V`

端子電力は

`P_bat = VI = 352.8×60 = 21.168 kW`

内部抵抗損は

`P_loss = I²r = 60²×0.12 = 432 W = 0.432 kW`

である。理想電圧源の電力 `EI=21.6 kW` と確認すると

`21.6 - 0.432 = 21.168 kW`

で一致する。

DC/DC後は

`P_DC = 21.168×0.96 = 20.32128 kW`

主変換装置後は

`P_motor,in = 20.32128×0.97 = 19.7116416 kW ≈ 19.7 kW`

となる。

容量だけから見た理想放電時間は

`t = 1/1.2 = 0.833... h ≈ 50 min`

である。ただし、この50分をN700Sの実自走時間とはみなさない。数値は教材用仮定値である。

# 公式・解法まとめ

- 放電端子電圧: `V=E-Ir`
- 充電端子電圧（電池へ流れ込む電流を正）: `V=E+Ir`
- 内部抵抗損: `P_loss=I²r`
- 電気量: `Q[Ah]=I[A]t[h]`
- 電力量: `W[Wh]=VIt=VQ`（一定電圧または平均電圧近似）
- 平均電圧: `V_avg=W[Wh]/Q[Ah]`
- C-rate電流: `I=k C_Ah`
- 理想充放電時間: `t=1/k [h]`
- 変換効率: `η=P_out/P_in`
- 多段総合効率: `η_total=η_1η_2...`
- DC/DC: 直流→直流
- DCリンク: 主変換装置へ電力を渡す中間直流部
