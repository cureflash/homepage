## 教材で欠落不可の説明

1. PWMでは正弦波信号波と高周波搬送波を比較してスイッチングパルスを作り、変調率によって交流基本波電圧を変えること。
2. H22の定義では、相電圧基本波振幅が `kE_d/2` となるため、三相線間電圧の基本波実効値が `√3·kE_d/(2√2)` となること。
3. 系統連系リアクトルを介した単相回路では、電流向き・電圧向きを問題文に合わせて `V̇_c=V̇_s+jXİ` 型のフェーザ式を立てること。
4. 力率1では交流側電流基本波を交流電圧と同相に制御し、単相では `P=VI` が使えること。
5. 有効電流 `I_P` と無効電流 `I_Q` を分け、PWM変換器の交流端子電圧の大きさを `√((V_L-XI_Q)^2+(XI_P)^2)` で扱えること。
6. PWM変換器の生成可能な交流基本波電圧にはDCリンク電圧と変調率による上限があり、交流側電流制御には十分なDCリンク電圧が必要であること。
7. 交流基本波電圧の位相を系統電圧に対して変えることで有効電力の向きを制御でき、回生では電力の流れが力行時と逆向きになること。
8. ダイオード整流器のように逆変換できない装置と、交流側へ電力を戻せる自励変換器の違いを、回生の文脈で説明すること。
9. 半導体スイッチングを用いる電力変換装置は高調波発生源になり得ること、高調波がリアクトル・コンデンサの過熱や電子機器の誤動作等を生じ得ること。
10. 指定波形として、交流電圧、PWM電圧、交流側電流、DCリンク電圧の対応を示すこと。波形は概念図として扱い、未確認の300系実車スイッチング周波数・リプル量を真値化しないこと。

# 解説本文

## 1. このテーマで電験二種は何を問うか

PWMコンバータの問題では、スイッチング回路の名称だけを覚えるのではなく、`DCリンク電圧 → PWMで生成できる交流基本波電圧 → リアクトルの電圧降下 → 交流側電流・力率 → 有効電力の向き` を一続きで扱えることが必要になる。一次試験では、搬送波、変調率、基本波電圧、逆変換、回生、高調波などを選択式で判定する。二次試験では、交流側電力から電流を求め、リアクトルを含むフェーザ式を立て、PWM変換器が必要とする交流端子基本波電圧とDCリンク電圧条件まで途中式付きで導く。

この章では、固定過去問で必要な一般式を中心に扱う。300系はPWMコンバータの役割を具体化する題材とするが、未確認の実車回路定数、スイッチング周波数、DCリンク電圧、リプル率は使わない。

## 2. PWMコンバータの役割

PWMコンバータは、交流側とDCリンクの間で電力を変換する自励式の電力変換器である。半導体スイッチをオン・オフし、直流電圧から交流側に必要な基本波電圧を作る。交流側にはリアクトルが入り、変換器端子の基本波電圧と系統電圧との差によって交流側電流が決まる。

本テーマで見る量は次の4つである。

- 交流電圧: 系統側のほぼ正弦波の基本波電圧。
- PWM電圧: スイッチングによるパルス列。平均的・基本波的には所望の交流電圧を作る。
- 交流側電流: リアクトルを介して流れ、力率制御では基本波を交流電圧と同相に近づける。
- DCリンク電圧: 直流側の電圧。交流基本波電圧を生成するための電圧源となる。

力行時と回生時で電力の向きは逆になる。PWMコンバータは交流→直流だけでなく、条件を満たせば直流→交流の逆変換もできる点が重要である。

## 3. 正弦波PWM・搬送波・変調率

正弦波PWMでは、低周波の正弦波信号波と高周波の三角波搬送波を比較し、その大小関係からスイッチングパルスを作る。パルス列そのものは正弦波ではないが、基本波成分を取り出すと信号波に対応した交流電圧を得られる。

固定過去問H22と同じ定義では、変調率 `k` は

`k = 信号波振幅 / 搬送波振幅`

である。線形変調範囲では、変調率を大きくすると交流基本波電圧も大きくなる。試験では「三角波＝搬送波」「正弦波＝信号波」「振幅比＝変調率」を入れ替えない。

搬送波周波数や300系実車のスイッチング周波数は本テーマの固定値として置かない。ここで必要なのは、PWMが基本波電圧を調整する原理と、スイッチングによって高調波成分も生じるという関係である。

## 4. DCリンク電圧と交流基本波電圧

PWM変換器が生成できる交流基本波電圧には、DCリンク電圧と変調率による上限がある。式は回路構成と問題文の電圧定義によって係数が変わるため、係数だけを一般公式として暗記してはいけない。

H22の定義では、相電圧基本波の振幅が

`V_phase,peak = kE_d/2`

と与えられる。このとき相電圧基本波実効値は

`V_phase = kE_d/(2√2)`

で、三相の線間電圧基本波実効値は

`V_LL = √3 · kE_d/(2√2)`

となる。

一方、H24・R01型の単相PWM変換器では、問題で用いる変調率を `K` としたとき

`V_v = K E_d/√2`

の形で扱う。`K≤1` なら

`V_v ≤ E_d/√2`

したがって、必要な交流端子基本波実効値 `V_v` を生成するためには

`E_d ≥ √2 V_v`

が必要になる。これは「交流側電流を制御できるだけのDCリンク電圧が必要」という条件を数式で表したものである。

## 5. 系統連系リアクトルとフェーザ式

交流側電流は、系統電圧とPWM変換器の交流端子基本波電圧を同じにするだけでは制御できない。両者の間にリアクトルを置き、電圧差をリアクトル電圧として持たせる。

固定過去問H24と同じ向きで、系統電圧を `V̇_L`、変換器端子基本波電圧を `V̇_v`、電流を変換器側から系統側へ流れる向きに `İ`、リアクトルのリアクタンスを `X` とし、抵抗を無視すると

`V̇_v = V̇_L + jX İ`

となる。

力率1で `İ` が `V̇_L` と同相なら、`jX İ` は系統電圧より90°進む。したがって

`V_v = √(V_L^2 + (XI)^2)`

となり、位相差 `φ` は

`tanφ = XI/V_L`

で求められる。

ここで重要なのは、電流矢印の向きを確認することである。問題文が電流を逆向きに定義すればフェーザ式の符号も変わる。「進み／遅れ」だけを暗記せず、電流向きとキルヒホッフの電圧則から式を立てる。

## 6. 力率1と有効・無効電流

単相交流の有効電力は

`P = VI cosθ`

である。力率1では `cosθ=1` なので、電力と電圧の大きさが与えられれば交流側電流の大きさは

`I = |P|/V`

で求められる。電力の正負は問題文の電力方向と電流矢印に従う。

H24型では、交流側電流を系統電圧と同相の有効電流 `I_P` と90°成分の無効電流 `I_Q` に分け、

`İ = I_P + jI_Q`

とする。このとき

`jX İ = -XI_Q + jXI_P`

だから

`V̇_v = (V_L-XI_Q) + jXI_P`

となる。よって変換器端子基本波電圧の大きさは

`V_v = √((V_L-XI_Q)^2 + (XI_P)^2)`

である。

力率1なら `I_Q=0` なので、式は前節の `√(V_L^2+(XI_P)^2)` に戻る。無効電流を含む問題では、`I_P` と `I_Q` の符号を問題文の定義どおりに置き、電流の大きさだけで処理しない。

## 7. DCリンク電圧条件と電圧制限

交流側電流を所望の値にするには、リアクトル電圧を作るために変換器端子基本波電圧 `V_v` が必要になる。しかしPWM変換器が作れる基本波電圧にはDCリンク電圧による上限がある。

H24・R01型の定義では

`V_v ≤ E_d/√2`

なので、解法は次の順になる。

1. 有効電力と力率から交流側電流を求める。
2. `XI` または `XI_P, XI_Q` を求める。
3. フェーザ式から必要な `V_v` を求める。
4. `E_d ≥ √2V_v` を満たすか確認する。

DCリンク電圧が不足すれば、必要な交流端子基本波電圧を生成できず、指定した交流側電流をその条件では実現できない。したがって、DCリンク電圧は単なる直流側の状態量ではなく、交流側電流制御の可否を決める制約になる。

H22のようにDCリンク電圧を設定値へ制御する問題では、交流側の有効電力を調整してDC側への入出力を釣り合わせる。ここでも、変調率と基本波電圧の関係、交流側の電力方向、DCリンク電圧を別々の量として整理する。

## 8. 有効電力の向き・逆変換・回生

PWMコンバータでは、変換器が作る交流基本波電圧の位相を系統電圧に対して調整することで、リアクトルを介して流れる有効電流と有効電力の向きを変えられる。

固定過去問H22の電流方向・式の約束では、有効電力を交流側へ送り出す側では変換器の交流基本波電圧を系統電圧より進ませる関係になる。ただし、問題文で電流矢印を逆に取れば進み・遅れの表現も逆になるため、位相関係はフェーザ式から判定する。

直流側から交流側へ電力を戻す動作を逆変換という。回生時には、車輪側から生じた電力が主電動機、主回路、DCリンクを経てPWMコンバータへ来て、交流側へ返される。ダイオード整流器のように交流→直流の一方向を基本とする回路では、この逆方向電力を同じようには扱えない。

鉄道の回生では、返した電力を他の力行車などが消費できる場合がある。受け側がなく、系統条件上回生電力を受け取れない場合には回生失効が起こり得る。本テーマでは電力貯蔵装置の種類や設置設計までは扱わない。

## 9. 高調波とリアクトル

PWM電圧はスイッチングされたパルス列なので、所望の基本波だけでなく高調波成分を含む。したがって半導体電力変換装置は高調波発生源になり得る。

高調波によって、コンデンサやリアクトルの過熱・振動、電子機器の誤動作などが生じることがある。R05型の記述問題では、発生源と影響を具体的に一つ以上説明できる必要がある。

交流側リアクトルは、基本波では `jXI` の電圧降下を作って電流を制御する要素である。同時に、急峻なPWM電圧がそのまま大きな電流変化になるのを抑える役割も持つ。ただし本テーマではリアクトル設計、フィルタ定数設計、能動フィルタの補償電流設計へは進まない。

指定4波形では、交流電圧を基準となる正弦波、PWM電圧をパルス列、交流側電流を基本波中心の波形、DCリンク電圧を直流成分中心の波形として対応付ける。具体的な300系実車スイッチング周波数やDCリンクリプル量は一次資料なしに真値化しない。

## 10. 二種問題の解法アルゴリズム

PWMコンバータの計算は次の順で処理する。

1. 問題文の回路が単相か三相か、電圧が相電圧か線間電圧かを確認する。
2. DCリンク電圧 `E_d` と変調率 `k` または `K` の定義を確認する。
3. 力率1なら `P=VI`、三相線量なら必要に応じて `P=√3V_LI_Lcosθ` を使い、交流側電流を求める。
4. 電流矢印を確認し、リアクトルについて `V̇_v=V̇_L+jXİ` 型の式を立てる。
5. 力率1なら `V_v=√(V_L^2+(XI)^2)`、有効・無効成分が与えられれば `V_v=√((V_L-XI_Q)^2+(XI_P)^2)` を使う。
6. 問題文のPWM定義に従って変調率または必要DCリンク電圧を求める。
7. `K≤1` などの電圧制限を確認する。
8. 電力方向の問題では、電流矢印とフェーザ式から力行／逆変換を判定する。
9. 高調波問題では「発生源」と「影響」を分けて答える。
10. 最後に、単相／三相、実効値／振幅、相電圧／線間電圧、電流方向の取り違えがないか検算する。

## 11. 3段階例題

### 11.1 基礎例題: 変調率から三相線間基本波電圧を求める

ある三相PWM変換器で、DCリンク電圧を `E_d=600 V`、変調率を `k=0.80` とする。H22型の定義として、相電圧基本波の振幅が `kE_d/2` で与えられるとき、三相線間電圧の基本波実効値を求める。

まず相電圧基本波の振幅は

`V_phase,peak = 0.80×600/2 = 240 V`

である。相電圧基本波実効値は

`V_phase = 240/√2 ≈ 169.7 V`

で、線間電圧実効値は

`V_LL = √3×169.7 ≈ 293.9 V`

となる。

まとめて

`V_LL = √3·kE_d/(2√2) ≈ 294 V`

である。振幅から実効値への `1/√2` と、相電圧から線間電圧への `√3` を逆にしないことが要点である。

### 11.2 本試験標準例題: 力率1・リアクトル・必要DCリンク電圧

単相交流系統 `V_s=200 V` にリアクタンス `X=2.5 Ω` のリアクトルを介してPWM変換器が接続されている。交流側有効電力の大きさを `5.0 kW`、力率を1とする。抵抗は無視し、H24・R01型の定義で `V_v≤E_d/√2` とする。必要な交流側電流、変換器端子基本波電圧、最小DCリンク電圧を求める。

力率1なので交流側電流の大きさは

`I = P/V_s = 5000/200 = 25.0 A`

である。リアクトル電圧の大きさは

`XI = 2.5×25.0 = 62.5 V`

となる。力率1では系統電圧と `jXI` が直交するため

`V_v = √(200^2+62.5^2) ≈ 209.5 V`

である。

生成可能電圧の条件 `V_v≤E_d/√2` から

`E_d ≥ √2×209.5 ≈ 296 V`

となる。したがって最小DCリンク電圧は約 `296 V` である。

この問題では `E_d≥√2V_s` として系統電圧だけを見ると不足する。リアクトル電圧 `XI` を含めて必要な変換器端子基本波電圧を先に求める必要がある。

### 11.3 複合・ひっかけ例題: 有効・無効電流と電圧上限

H24型の符号規約で、系統電圧 `V_L=100 V`、リアクタンス `X=0.40 Ω`、有効電流 `I_P=30 A`、無効電流 `I_Q=-10 A` とする。PWM変換器のDCリンク電圧は `E_d=160 V`、生成可能な基本波実効値は `V_v≤E_d/√2` とする。この運転点が電圧制限内か判定する。

変換器端子基本波電圧は

`V_v = √((V_L-XI_Q)^2+(XI_P)^2)`

なので

`V_L-XI_Q = 100-0.40×(-10) = 104 V`

`XI_P = 0.40×30 = 12 V`

したがって

`V_v = √(104^2+12^2) ≈ 104.7 V`

である。一方、PWM変換器が生成できる上限は

`E_d/√2 = 160/√2 ≈ 113.1 V`

なので

`104.7 < 113.1`

となり、この運転点は電圧制限内である。

ここで `I_Q=-10 A` の負号を落として `V_L-XI_Q=96 V` とすると別の運転点を計算してしまう。有効・無効電流の問題では、電流の大きさだけでなく問題文の符号規約をそのまま式へ入れる。

## 12. 300系への接続

300系の主回路では、架線から主変圧器を経て得た交流と車両内のDCリンクとの間で主変換装置が電力をやり取りする。このテーマでは、その交流側とDCリンクの間を担うPWMコンバータを、電験二種の一般的な系統連系PWM変換器として理解する。

力行では交流側からDCリンクへ電力を送り、回生ではDCリンク側から交流側へ電力を戻す。交流側電流を電圧と同相に近づければ力率を高くでき、リアクトルと変換器基本波電圧の位相・大きさによって電流を決められる。

ここでは300系の未確認実車回路定数や制御定数は使わない。また、DCリンクより後段で三相可変周波数交流を作る詳細はTopic 08の範囲なので扱わない。

## 13. 頻出ミス

- 三角波搬送波と正弦波信号波を逆にする。
- 変調率を周波数比と取り違える。
- 振幅と実効値の `√2` を落とす。
- 三相相電圧と線間電圧の `√3` を落とす。
- H22型とH24・R01型で異なるPWM電圧定義を一つの係数に決め打ちする。
- 力率1だからリアクトル電圧も系統電圧と同相だと考える。`jXI` は90°ずれる。
- `V_v=V_L+XI` とスカラー加算し、フェーザの直交関係を無視する。
- `I_P/I_Q` の符号を絶対値にしてしまう。
- 必要DCリンク電圧を系統電圧だけから決め、リアクトル電圧を無視する。
- 電流矢印を確認せず、進み／遅れだけで電力方向を暗記する。
- 逆変換と整流を同じ向きの電力変換として扱う。
- 高調波の発生源だけを書き、機器への影響を書かない。

## 15. 公式・解法まとめ

- 変調率: `k = 信号波振幅 / 搬送波振幅`
- H22型: `V_phase,peak=kE_d/2`
- H22型: `V_LL=√3·kE_d/(2√2)`
- 単相有効電力: `P=VIcosθ`
- 力率1: `I=|P|/V`
- H24型フェーザ式: `V̇_v=V̇_L+jXİ`
- 力率1: `V_v=√(V_L^2+(XI)^2)`
- `İ=I_P+jI_Q` のとき: `V_v=√((V_L-XI_Q)^2+(XI_P)^2)`
- H24・R01型PWM電圧上限: `V_v≤E_d/√2`
- 必要DCリンク電圧: `E_d≥√2V_v`
- 直流側→交流側: 逆変換
- 回生時は力行時と有効電力の向きが逆
- PWMスイッチングは高調波発生源になり得る
