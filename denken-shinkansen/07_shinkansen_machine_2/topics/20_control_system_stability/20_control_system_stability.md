# 解説source本文

## §1 このテーマで電験は何を問うか

このテーマで問われるのは「応答が振動して見える理由」そのものより、伝達関数から安定性を数学的に判定し、時間領域と周波数領域の指標を対応付ける力である。

本試験では主に次を行う。

1. フィードバック系から特性方程式を作る。
2. 極の位置から安定・減衰振動・持続振動・発散を判定する。
3. 三次程度の特性方程式へラウス・フルビッツを適用し、安定となるゲイン範囲を求める。
4. 二次特性方程式から複素共役根になる条件を求め、振動性を判定する。
5. 一巡伝達関数 `L(s)` から周波数応答を求め、ボード線図の傾き・折点・位相を読む。
6. ゲイン交差角周波数、位相交差角周波数、ゲイン余裕、位相余裕を求める。
7. 指定された交差角周波数や位相余裕を満たすパラメータを逆算する。

暗記だけでよいのは用語の定義ではなく、「どの式をどの順で使うか」である。二次試験では特性方程式、ラウス表、不等式、単位・角周波数まで途中式を残す。

## §2 特性方程式と極

### 2.1 閉ループ伝達関数から特性方程式を作る

負帰還系で、順方向伝達関数を `G(s)`、帰還伝達関数を `H(s)` とすると、閉ループ伝達関数は

`T(s) = G(s) / {1 + G(s)H(s)}`

である。一巡伝達関数を

`L(s) = G(s)H(s)`

と書けば、特性方程式は

`1 + L(s) = 0`

である。分母を多項式に整理した

`D(s) = a_n s^n + a_(n-1)s^(n-1) + ... + a_1 s + a_0 = 0`

の根が閉ループ極である。

試験では「閉ループ伝達関数そのものを全部求める」前に、安定判別だけなら分母 `D(s)` を作ればよい場合が多い。

### 2.2 極と零点

伝達関数を

`T(s) = N(s) / D(s)`

としたとき、`D(s)=0` の根が極、`N(s)=0` の根が零点である。

連続時間の有理伝達関数では、閉ループ極の実部が応答の減衰・発散を決める。

- すべての極の実部 `< 0`: 漸近安定
- 実部 `= 0` の極が残る: 安定限界になり得る
- 実部 `> 0` の極が1個でもある: 不安定

複素極 `s = -σ ± jω_d` なら、時間応答には

`e^(-σt) sin(ω_d t)`

型の成分が現れる。`σ>0` なら振動しながら減衰し、`σ=0` なら減衰しない持続振動、`σ<0` に相当する右半平面極なら振幅が増大する。

零点は応答形状や周波数特性へ影響するが、通常の最小実現された閉ループ系の安定性を直接決めるのは極である。極と零点を取り違えない。

### 2.3 指定極から特性多項式を作る

指定極が `p_1, p_2, ..., p_n` なら、対応する特性多項式は

`D_d(s) = (s-p_1)(s-p_2)...(s-p_n)`

である。実係数系で複素極がある場合は共役対になる。

例えば希望極が `-2 ± j3` なら

`D_d(s) = {s-(-2+j3)}{s-(-2-j3)}`

`= (s+2)^2 + 9`

`= s^2 + 4s + 13`

となる。実際の閉ループ特性多項式をこれと係数比較すれば、ゲイン等の未知パラメータを決められる。

### 2.4 主要極・代表根

安定な複数極のうち、虚軸に最も近く減衰が遅い極は時間応答へ長く残りやすい。これを主要極・代表根として近似に使う。

ただし「実部の絶対値が最小の極を機械的に1個選ぶ」のではなく、複素共役対なら対で扱う。十分左側にある速い極は、主要極に比べて影響が早く消える。

## §3 ラウス・フルビッツの安定判別

### 3.1 何のために使うか

高次方程式の根を毎回直接求めなくても、係数から右半平面極の有無を判定するために使う。電験二種では特に三次特性方程式からゲインの安定範囲を不等式で求める形が重要である。

### 3.2 三次式のラウス表

特性方程式を

`a_3 s^3 + a_2 s^2 + a_1 s + a_0 = 0`

とする。`a_3>0` としてラウス表を作る。

| 行 | 第1列 | 第2列 |
|---|---:|---:|
| `s^3` | `a_3` | `a_1` |
| `s^2` | `a_2` | `a_0` |
| `s^1` | `(a_2 a_1 - a_3 a_0)/a_2` | `0` |
| `s^0` | `a_0` | |

漸近安定の条件は第1列がすべて同符号になることである。`a_3>0` とすれば

- `a_2 > 0`
- `a_0 > 0`
- `a_2 a_1 - a_3 a_0 > 0`

が必要で、最後の不等式と正係数条件を合わせて判定する。これは三次式に対するラウス・フルビッツ条件と同じ結果になる。

### 3.3 Hurwitz条件との対応

三次多項式

`a_3 s^3 + a_2 s^2 + a_1 s + a_0`

で全係数が正なら、それだけでは十分ではない。さらに

`a_2 a_1 > a_3 a_0`

が必要である。「係数が全部正だから安定」と判断しない。

### 3.4 教材用例

時間を基準時間で無次元化した教材用一巡伝達関数を

`L(s) = K / {s(s+1)(s+2)}`

とする。これは新幹線実車のモデル・実測値ではない。

単位負帰還なら特性方程式は

`1 + K/{s(s+1)(s+2)} = 0`

より

`s^3 + 3s^2 + 2s + K = 0`

である。ラウス表は

| 行 | 第1列 | 第2列 |
|---|---:|---:|
| `s^3` | `1` | `2` |
| `s^2` | `3` | `K` |
| `s^1` | `(6-K)/3` | `0` |
| `s^0` | `K` | |

したがって第1列を正にする条件は

`K > 0`

かつ

`6-K > 0`

なので

`0 < K < 6`

で漸近安定となる。

`K=6` では `s^1` 行が0になり、補助多項式 `3s^2+6=0` から `s=±j√2` が現れる。これは安定限界の持続振動に対応する。`K>6` では第1列の符号変化が生じ、右半平面極を持つ。

## §4 発振とゲイン変更・根軌跡の概念

### 4.1 二次系が振動する条件

二次特性方程式

`s^2 + a s + b = 0`

の根は

`s = {-a ± √(a^2-4b)}/2`

である。判別式

`a^2 - 4b < 0`

なら複素共役極となり、時間応答に振動成分が現れる。

ただし「複素根だから安定」とは限らない。

- `a>0, b>0, a^2<4b`: 左半平面の複素共役極 → 減衰振動
- `a=0, b>0`: 虚軸上の共役極 → 持続振動
- `a<0, b>0, a^2<4b`: 右半平面の複素共役極 → 振幅が増える振動

標準二次系

`s^2 + 2ζω_n s + ω_n^2 = 0`

なら `0<ζ<1` で減衰振動、`ζ=0` で持続振動となる。Topic 18で扱った減衰係数を、ここでは安定性判定へ接続する。

### 4.2 根軌跡の概念

一巡伝達関数を `L(s)=K L_0(s)` とすると、閉ループ極は

`1 + K L_0(s) = 0`

を満たす。`K` を0から変化させたとき、閉ループ極が複素平面上をどのように移動するかを示すのが根軌跡である。

本テーマでは作図規則の詳細までは扱わず、次を理解する。

- ゲインを変えると閉ループ極が移動する。
- 左半平面内で虚軸へ近づくほど減衰が弱くなりやすい。
- 虚軸上へ到達すると安定限界になる。
- 右半平面へ入ると不安定になる。

§3の教材用モデルでは `K` を増やすと、安定な領域から `K=6` の安定限界を経て不安定領域へ移る。この同じ変化を、根の位置、時間応答、周波数応答の3通りで確認する。

## §5 周波数応答とボード線図

### 5.1 周波数応答

伝達関数 `G(s)` の `s` に `jω` を代入した

`G(jω)`

が周波数応答である。複素数なので大きさと位相を持つ。

- 振幅比: `|G(jω)|`
- ゲイン[dB]: `20 log10 |G(jω)|`
- 位相[deg]: `∠G(jω)`

ボード線図は横軸を対数角周波数 `ω [rad/s]` とし、上段にゲイン[dB]、下段に位相[deg]を描く。

### 5.2 基本因子

#### 正の定数ゲイン `K`

`20 log10 K [dB]` の一定値。`K>0` なら位相は `0°`。

#### 積分要素 `1/s`

`|1/(jω)|=1/ω`

なのでゲイン線図の傾きは `-20 dB/dec`、位相は `-90°`。

#### 一次遅れ `1/(1+sT)`

折点角周波数は

`ω_b = 1/T`

である。折れ線近似では折点より十分低い側は `0 dB/dec`、高い側は `-20 dB/dec`。位相は `0°` から `-90°` へ移る。

#### 一次零点 `1+sT`

折点は同じく `1/T`。高周波側で傾きが `+20 dB/dec` 増え、位相は `0°` から `+90°` へ移る。

複数因子のゲイン[dB]は加算、位相も加算する。これがボード線図を因子分解して描ける理由である。

### 5.3 PI補償器の折れ線近似

PI補償器を

`C(s) = K_p(1 + 1/(T_i s))`

とすると

`C(s) = K_p(T_i s+1)/(T_i s)`

なので、原点極1個と `ω=1/T_i` の零点1個を持つ。

低周波側では積分要素が支配的で `-20 dB/dec`、零点を越えると零点の `+20 dB/dec` が加わり、合成傾きは `0 dB/dec` になる。位相は低周波側のおよそ `-90°` から高周波側の `0°` へ移る。

ボード線図問題では、まず「定数、原点極、一次極、一次零点」に因数分解し、各折点と傾き変化を表にしてから描く。

## §6 安定余裕

以下は通常の負帰還で、一巡伝達関数 `L(s)` を用いる。

### 6.1 ゲイン交差角周波数

`|L(jω_gc)| = 1`

すなわちゲインが `0 dB` になる角周波数をゲイン交差角周波数 `ω_gc` とする。

### 6.2 位相交差角周波数

`∠L(jω_pc) = -180°`

となる角周波数を位相交差角周波数 `ω_pc` とする。

### 6.3 位相余裕

ゲイン交差角周波数での位相が `-180°` まであと何度あるかを

`PM = 180° + ∠L(jω_gc)`

で表す。

### 6.4 ゲイン余裕

位相交差角周波数での大きさが1になるまで何倍ゲインを増やせるかを

`GM = 1 / |L(jω_pc)|`

とする。dB表示なら

`GM_dB = -20 log10 |L(jω_pc)|`

である。

標準的な単一交差の負帰還問題では、正のゲイン余裕・位相余裕は安定限界まで余裕があることを示す。交差が複数ある一般系へこの単純判定を無条件に拡張しない。

### 6.5 指定 `ω_gc` と位相余裕からパラメータを逆算する

一次遅れ＋積分型の例として

`L(s) = K / {s(1+Ts)}`

を考える。ゲイン交差角周波数 `ω_c` と位相余裕 `PM` が指定されたとする。

位相は

`∠L(jω) = -90° - arctan(ωT)`

なので `ω=ω_c` で

`-90° - arctan(ω_c T) = -180° + PM`

したがって

`arctan(ω_c T) = 90° - PM`

`T = cot(PM) / ω_c`

を得る。

次にゲイン交差条件

`|L(jω_c)| = K / {ω_c √(1+(ω_c T)^2)} = 1`

から

`K = ω_c √(1+(ω_c T)^2)`

を求める。

試験では位相条件を先に使うと時定数を分離しやすく、その後に0 dB条件でゲインを決める。

## §7 同一モデルで安定性を比較する

### 7.1 教材用仮定モデル

SPEC指定の「ボード線図」「ゲイン変更時の応答」「安定・不安定応答比較」は、§3と同じ

`L(s) = K / {s(s+1)(s+2)}`

を使う。時間は基準時間で無次元化した教材用モデルで、新幹線実車の制御定数ではない。

閉ループ伝達関数は

`T(s) = K / {s^3+3s^2+2s+K}`

である。

### 7.2 ラウス判別

§3より

- `0<K<6`: 漸近安定
- `K=6`: 安定限界
- `K>6`: 不安定

となる。

### 7.3 周波数領域から同じ境界を確認する

一巡伝達関数の位相は

`∠L(jω) = -90° - arctan(ω) - arctan(ω/2)`

である。位相交差条件 `-180°` より

`arctan(ω) + arctan(ω/2) = 90°`

となり、加法定理から

`1 - ω^2/2 = 0`

したがって

`ω_pc = √2`

である。

このとき

`|L(j√2)| = K / {√2 · √3 · √6} = K/6`

なので

`GM = 6/K`

となる。したがって `K<6` なら `GM>1`、`K=6` なら `GM=1`、`K>6` なら `GM<1` となり、ラウス判別の境界と一致する。

### 7.4 グラフ化条件

後続のPDF・PowerPointでは、同一モデルで次を比較する。

- `K=1`: 安定
- `K=5`: 安定だが安定限界に近い
- `K=6`: 持続振動となる安定限界
- `K=8`: 不安定

作成する図:

1. `K=1,5,6,8` の単位ステップ閉ループ応答
2. `K=1,5,6,8` の一巡伝達関数ボード線図
3. `K` 増加で閉ループ極が虚軸へ近づき、越える概念図

この比較ではモデル・入力・時間軸を固定し、ゲイン `K` だけを変える。

## §8 新幹線への接続

新幹線の速度フィードバックを概念的に

`速度指令 → 制御器 → 主変換装置・主電動機・車両 → 速度 → センサ → 負帰還`

と見ると、制御器ゲインを大きくすれば必ず良いわけではない。閉ループ極が虚軸へ近づけば振動性が強まり、安定限界を越えれば偏差を減らすつもりのフィードバックが持続振動・発散へつながり得る。

ここで使う `K`、極、ゲイン余裕、位相余裕、時間応答はすべて教材用仮定モデルの値である。新幹線実車の速度制御ゲイン、制御周期、極配置、安定余裕、再粘着制御則を示すものではない。

新幹線との接続で覚えるべきなのは実車定数ではなく、「速度フィードバック系も一般の閉ループ制御系として、特性方程式・極・周波数応答で安定性を評価する」という点である。

## §9 問題を見たときの解法手順

### 9.1 特性方程式・ラウス型

1. `G(s)`、`H(s)` から `1+G(s)H(s)=0` を作る。
2. 分母を整理し、次数の降順に特性多項式を書く。
3. 三次なら `s^3, s^2, s^1, s^0` のラウス表を作る。
4. 第1列を求める。
5. 第1列が同符号となる条件を未知ゲイン等の不等式にする。
6. 係数の正負条件も忘れず共通範囲を取る。
7. 境界値では虚軸極・0極が出ないか確認する。

### 9.2 振動条件型

1. 二次特性方程式を `s^2+a s+b=0` または標準二次形へ整理する。
2. 複素共役根の条件 `a^2-4b<0` を立てる。
3. 実部の符号を `-a/2` で確認する。
4. 「減衰振動」「持続振動」「増大振動」を区別する。

### 9.3 ボード線図型

1. 伝達関数を定数、積分要素、一次極、一次零点に因数分解する。
2. 各折点 `ω=1/T` を並べる。
3. 低周波側の初期傾きを決める。
4. 極1個ごとに `-20 dB/dec`、零点1個ごとに `+20 dB/dec` だけ傾きを変える。
5. 位相を各因子の和で求める。
6. `0 dB` 交差と `-180°` 交差を区別する。

### 9.4 安定余裕・設計値逆算型

1. `ω_gc` では `|L|=1`、`ω_pc` では位相 `-180°` と書く。
2. 位相余裕は `PM=180°+∠L(jω_gc)`。
3. ゲイン余裕は `GM=1/|L(jω_pc)|`。
4. `ω_gc` と `PM` が指定されたら、位相条件から時定数等を先に求める。
5. その後 `|L(jω_gc)|=1` からゲインを求める。
6. rad/s と Hz を混同しない。

## §10 典型例題

### 例題1 基礎: 極から応答を判定する

閉ループ伝達関数の特性多項式が

`D(s)=s^2+4s+13`

であるとする。

根は

`s={-4±√(16-52)}/2`

`=-2±j3`

である。実部が負なので安定で、虚部を持つため減衰振動応答となる。

判定で使ったのは「複素根か」だけでなく「実部が負か」である。

### 例題2 本試験標準: 三次式の安定ゲイン範囲

教材用特性方程式

`s^3+3s^2+2s+K=0`

について安定な `K` の範囲を求める。

ラウス表第1列は

`1, 3, (6-K)/3, K`

だから

`K>0`

かつ

`(6-K)/3>0`

より

`0<K<6`

である。

「係数が全部正」だけでは `K>0` までしか分からず不十分で、三次では `a_2 a_1>a_3 a_0` に相当する条件が必要である。

### 例題3 複合: ラウス判別とゲイン余裕を一致させる

一巡伝達関数

`L(s)=K/{s(s+1)(s+2)}`

について、位相交差角周波数では

`ω_pc=√2`

となり、そのとき

`|L(jω_pc)|=K/6`

だから

`GM=6/K`

である。

安定限界 `GM=1` から `K=6` を得る。これはラウス表で第1列が0になる境界と一致する。

この例は、時間領域の特性方程式と周波数領域の安定余裕が同じ安定限界を表していることを確認するための教材用例である。

## §11 頻出ミス・ひっかけ

- 閉ループの安定性を、開ループ伝達関数の極だけで判定する。
- 極と零点を逆にする。
- 複素根なら無条件に「安定な振動」とする。
- 三次多項式で係数が全部正というだけで安定とする。
- ラウス表の第1列ではなく行全体の符号を見る。
- `ω_gc` と `ω_pc` を逆にする。
- 位相余裕を `180°-位相` と機械的に計算し、負の位相角の符号を崩す。
- ゲイン余裕をdB値と倍率で混同する。
- `20log10|G|` と `10log10|G|` を混同する。
- Hzとrad/sを混同する。`ω=2πf` を必要に応じて使う。
- PI補償器の零点を `1/T_i` ではなく `T_i` とする。
- ボード線図で極・零点ごとの傾き変化を折点前から適用する。
- 実車未確認のゲインや余裕を新幹線の実値として扱う。
