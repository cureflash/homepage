# 教材で欠落不可の説明

1. 閉ループ伝達関数の分母から特性方程式を作り、特性根が閉ループ極になることを説明する。
2. 極と零点を区別し、連続時間系では閉ループ極の位置が応答の減衰・振動・発散にどう対応するかを説明する。
3. H25一次問6へ接続できるよう、制御対象の極から安定性を判定し、指定極から特性多項式を組み立てて係数比較する手順を示す。
4. 三次特性方程式についてラウス表を自力で作り、第1列から安定条件を不等式として求める手順を示す。R03・R04二次型へ直接接続する。
5. 二次系の複素共役極と振動的応答の関係を示し、R03二次(3)のような「振動するゲイン条件」を判定できるようにする。
6. 根軌跡は、ゲインを変えると閉ループ極が移動し、虚軸を越えると安定性が変わるという概念を説明する。
7. `G(jω)` の大きさと位相を周波数応答として読み、ゲイン[dB]と位相[deg]をボード線図へ表す。
8. 一次遅れ、積分要素、比例要素、零点を含む基本因子から、折点・傾き・位相を組み合わせてボード線図を概算する。H30二次(2)へ接続する。
9. ゲイン交差角周波数、位相交差角周波数、ゲイン余裕、位相余裕を定義し、H23一次問7の設計尺度として使えるようにする。
10. ゲインを変えたとき、極位置・ボード線図・余裕・時間応答を同一の教材用モデルで対応付け、安定、減衰振動、持続振動、発散を区別する。
11. SPEC指定のグラフとして、ボード線図、ゲイン変更時の応答、安定・不安定応答比較を再現可能な条件で作る。実車未確認値は使わず、教材用仮定値と明記する。
12. 新幹線との接続は速度フィードバック系を具体例に留め、実車の非公開制御定数を推定しない。
