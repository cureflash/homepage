## 1. H23 一次 機械 問7 (1)〜(5)

開ループ周波数特性では、ゲイン余裕・位相余裕は安定性、交差角周波数は速応性の尺度である。閉ループ側でも共振ピークは安定性、帯域幅は速応性の尺度になる。

`G(s)=K/{s(Ts+1)}`、`ω_gc=1 rad/s`、位相余裕45°より、

`∠G(j1)=-90°-tan^-1(T)`

`45°=180°+∠G(j1)=90°-tan^-1(T)`

したがって `T=1 s`。

さらにゲイン交差条件 `|G(j1)|=1` より、

`K/sqrt(1+T^2)=1`

なので `K=sqrt(2)`。

ロック時点答案:
- (1) 安定性 = `ヲ` ← 解答群記号の転記ミス
- (2) 速応性 = `チ`
- (3) `sqrt(2)` = `ハ`
- (4) `1` = `ヘ`

訂正後記録:

- (2) 速応性 = `チ`

## 2. H25 一次 機械 問6 (1),(3),(4),(5)

制御対象 `10/(s^2-4)` は極 `s=±2` を持ち、右半平面極 `+2` があるので不安定。

PID補償器は

`C(s)=K1+K2/s+K3 s=(K3 s^2+K1 s+K2)/s`

である。単位負帰還の特性方程式は

`s(s^2-4)+10(K3 s^2+K1 s+K2)=0`

すなわち

`s^3+10K3 s^2+(10K1-4)s+10K2=0`。

希望極 `-30, -3±j4` の特性多項式は

`(s+30){(s+3)^2+16}`

`=(s+30)(s^2+6s+25)`

`=s^3+36s^2+205s+750`。

係数比較より

`10K3=36 -> K3=3.6`

`10K1-4=205 -> K1=20.9`

また `-30` は十分速く減衰する極で、`-3±j4` が応答を支配する代表根となる。

固定答案:
- (1) 不安定 = `ニ`
- (3) `K1=20.9` = `ル`
- (4) `K3=3.6` = `ヲ`
- (5) 代表根 = `ロ`

`ω_b=1/Ti=10 rad/s`。

## 4. R03 二次 機械・制御 問4 (3),(5)

内側の速度帰還を含む部分は、プラント `P(s)=1/{s(2s+1)}`、帰還要素 `s` なので、前向き入力から出力まで

`P/(1+Ps)=1/{2s(s+1)}`。

したがって外側ループの開ループ伝達関数は

`G(s)=K/{2s(s+1)(Ts+1)}`。

外側単位負帰還の特性方程式は

`2s(s+1)(Ts+1)+K=0`

すなわち

`2T s^3+2(T+1)s^2+2s+K=0`。

### (3) T=0

`2s^2+2s+K=0`。

ステップ応答が振動的になるには極が複素共役となればよいので、判別式

`2^2-4*2*K=4-8K<0`

より

`K>1/2`。

固定答案: `(3) K>1/2`。

### (5) T=2

特性方程式は

`4s^3+6s^2+2s+K=0`。

三次式のラウス条件より、第1列正条件は

`K>0`

かつ

`6*2 > 4K`

なので

`0<K<3`。

固定答案: `(5) 0<K<3`。

## 5. R04 二次 機械・制御 問4 (1),(2)

一巡伝達関数は

`L(s)=K/s * 100/{(s+1)(s+40)}`。

### (1) 特性方程式

`1+L(s)=0` より

`s(s+1)(s+40)+100K=0`

展開して

`s^3+41s^2+40s+100K=0`。

固定答案: `(1) s^3+41s^2+40s+100K=0`。

### (2) 安定条件

三次式 `s^3+41s^2+40s+100K` のラウス条件より、

`K>0`

かつ

`41*40 > 100K`。

したがって

`0<K<16.4`。

固定答案: `(2) 0<K<16.4`。
