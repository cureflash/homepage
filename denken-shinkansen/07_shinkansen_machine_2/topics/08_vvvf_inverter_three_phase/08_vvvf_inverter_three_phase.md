# 解説本文

## 1. このテーマで電験は何を問うか

このテーマの中心は、直流電圧 `E_d` を三相インバータで交流へ変換したとき、スイッチングの仕組み、PWMの信号波とキャリア、基本波電圧、相電圧と線間電圧、高調波を式と波形で扱えるようにすることである。

一次試験では、用語・変調率・周波数関係・基本波電圧式を選択肢から判定する形が中心となる。二次試験では、与えられた直流電圧と変調率から相電圧基本波・線間電圧基本波を計算したり、180°通電の波形から実効値や高調波の性質を説明したりする。

本章を終えた時点で、固定5過去問のゲート対象13小問に必要な次の経路を再現できることを目標とする。

`直流リンク → 6スイッチ → 三相のスイッチング → 相端電圧 → 線間電圧 → 基本波・高調波`

## 2. 三相2レベル電圧形インバータの6スイッチ

三相インバータはU・V・Wの3相にそれぞれ上側・下側のスイッチを1個ずつ持つため、主回路は6スイッチで構成される。各相の上下スイッチを切り替えることで、その相端を直流リンクの正側または負側へ接続する。

直流リンク電圧を `E_d`、直流中点Oを基準とする相端電圧を `v_uO` とすると、2レベル動作では

`v_uO = +E_d/2` または `-E_d/2`

となる。V相、W相も同じである。ここでいう相端電圧は直流中点基準であり、線間電圧は二つの相端電圧の差として求める。

三相交流を作るときは、U・V・W相の基準となる信号を互いに120°ずらす。したがって、三つの相の基本波は

- U相: 0°
- V相: -120°
- W相: +120°

という位相関係になる。

試験でスイッチ状態を読むときは、まず「どの相の上側／下側が導通しているか」を確認し、その相端が `+E_d/2` と `-E_d/2` のどちらになるかを決める。その後に相端同士の差を取れば線間電圧が決まる。

## 3. 正弦波PWM、信号波、三角波キャリア

正弦波PWMでは、出したい基本波を表す正弦波信号波と、高い周波数の三角波キャリアを比較してスイッチング状態を決める。

典型的には、

- 信号波 > キャリア: 上側状態
- 信号波 < キャリア: 下側状態

と対応させる。重要なのは二つの周波数の役割を混同しないことである。

- 信号波周波数 `f_s`: 出力基本波周波数を決める
- キャリア周波数 `f_c`: PWMのスイッチング周波数を決める

したがって、信号波が50 Hz、キャリアが1.5 kHzなら、出力基本波は50 Hzであり、スイッチングは1.5 kHzを基準として行われる。キャリア周波数を出力周波数と取り違えない。

正弦波信号の波高値を `V_s`、三角波キャリアの波高値を `V_c` とすると、変調率を

`k = V_s / V_c`

と定義する。線形変調範囲では、`k` を変えることで直流リンク電圧 `E_d` 自体を変えなくても出力基本波電圧を調整できる。H19一次型では、この「PWM電圧形インバータでは主回路の直流電圧を可変しなくても、変調率で基本波電圧を変えられる」という関係を押さえる。

## 4. PWM基本波電圧と直流電圧の関係

正弦波PWMの線形範囲で、直流リンク電圧を `E_d`、変調率を `k` とすると、相電圧基本波の波高値は

`V_phase,peak = kE_d/2`

である。

正弦波の実効値は波高値の `1/√2` だから、相電圧基本波実効値は

`V_phase,rms = kE_d/(2√2)`

となる。

平衡三相正弦波では、線間電圧実効値は相電圧実効値の `√3` 倍なので、

`V_LL1 = √3 × V_phase,rms`

`= √3 k E_d/(2√2)`

を得る。

これはH22一次、R04二次で直接使う式である。式を暗記するだけでなく、

`相電圧基本波の波高値 → 相電圧基本波の実効値 → 線間電圧基本波の実効値`

の順に作れば再導出できる。

## 5. 相端電圧から線間電圧を作る

線間電圧は二つの相端電圧の差である。たとえばU-V間なら

`v_uv = v_uO - v_vO`

である。

各相端電圧が `±E_d/2` の2値を取るので、差である線間電圧は

`+E_d, 0, -E_d`

の3値を取る。

例として、

- `v_uO = +E_d/2`、`v_vO = -E_d/2` なら `v_uv = +E_d`
- 両方が `+E_d/2` なら `v_uv = 0`
- `v_uO = -E_d/2`、`v_vO = +E_d/2` なら `v_uv = -E_d`

となる。

波形問題では、相端電圧を別々に追うより、各区間で二相の値を差し引いて線間電圧を作る方が確実である。

## 6. 180°通電と線間電圧実効値

H28二次型では、各相のスイッチ状態が180°ずつ切り替わる三相インバータを扱う。直流中点基準の各相端電圧は `+E_d/2` と `-E_d/2` を取り、線間電圧は `+E_d, 0, -E_d` の三値波形になる。

一周期360°の線間電圧について、絶対値が `E_d` となる区間は合計240°、0となる区間は合計120°である。したがって実効値 `E_0` は

`E_0 = √[(1/360°){240°×E_d^2 + 120°×0^2}]`

`= E_d√(2/3)`

となる。

ここでの頻出ミスは、相端電圧の `E_d/2` をそのまま線間電圧へ使うこと、または線間電圧が常に `±E_d` であるとして0区間を落とすことである。

## 7. 基本波、高調波、3の整数倍次数の相殺

方形波やPWM波は正弦波そのものではないため、基本波に高調波が重なっている。試験では「スイッチング波形をフーリエ分解すると、基本波と高調波に分かれる」という見方が必要になる。

三相平衡系では、3次、6次、9次のような3の整数倍次数成分は各相で同相になる。線間電圧は相電圧の差なので、同じ成分を引き算すると

`v_uv,n = v_u,n - v_v,n = 0`

となり、3の整数倍次数高調波は線間電圧では相殺される。

一方、3の整数倍でない高調波は一般に線間電圧へ残り得る。したがって「相電圧に高調波がある」ことと「線間電圧に同じ高調波がそのまま現れる」ことは同義ではない。

SPEC指定の後続計算プログラムでは、同一のスイッチング条件から相端電圧・線間電圧を作り、基本波を抽出し、FFTで高調波成分を確認する。ここではその計算原理だけを固定し、プログラム自体は次工程以降の成果物とする。
## 8. 問題を見たときの解法手順

### PWM・周波数問題

1. 正弦波信号波と三角波キャリアを区別する。
2. 信号波周波数を出力基本波周波数へ対応させる。
3. キャリア周波数をスイッチング周波数へ対応させる。
4. 変調率が問われたら `k = V_s/V_c` を使う。

### PWM基本波電圧問題

1. `E_d` と `k` を確認する。
2. 相電圧基本波波高値 `kE_d/2` を求める。
3. 必要なら `1/√2` を掛けて相電圧実効値へ変換する。
4. 線間電圧実効値ならさらに `√3` を掛ける。
5. `√3 kE_d/(2√2)` と一致するか検算する。

### 180°通電波形問題

1. 各相端が `+E_d/2` と `-E_d/2` のどちらかを区間ごとに読む。
2. `v_uv=v_uO-v_vO` で線間電圧を作る。
3. `+E_d,0,-E_d` の各区間長を確認する。
4. 実効値は波形の二乗平均平方根で求める。
5. 高調波問題では3の整数倍次数が線間差で消えることを確認する。

## 9. 新幹線への接続

本系列では、300系を題材に「DCリンクからインバータで三相交流を作り、誘導主電動機へ供給する」という主回路の役割へ接続する。ただし、本テーマで必要なのはインバータの一般原理と試験計算であり、公開根拠を確認していない300系のDCリンク電圧、キャリア周波数、スイッチング周波数等を真値として使わない。

# 3段階例題

## 例題1 基礎: 信号波とキャリアの周波数

正弦波PWMインバータで、正弦波信号波の周波数を50 Hz、三角波キャリアの周波数を1.5 kHzとする。出力基本波周波数と、PWMのスイッチング周波数を答えよ。

### 解答

出力基本波周波数は信号波周波数で決まるので、

`f_out = 50 Hz`

である。

スイッチング周波数はキャリア周波数で決まるので、

`f_sw = 1.5 kHz`

である。

キャリア周波数1.5 kHzを出力交流の周波数としないことがポイントである。

## 例題2 本試験標準: 正弦波PWMの基本波電圧

直流リンク電圧 `E_d=297 V`、変調率 `k=0.90` の三相正弦波PWMインバータを考える。相電圧基本波の波高値と、線間電圧基本波の実効値を求めよ。

### 解答

相電圧基本波の波高値は

`V_phase,peak = kE_d/2`

`= 0.90×297/2`

`= 133.65 V ≒ 134 V`

となる。

線間電圧基本波実効値は

`V_LL1 = √3 V_phase,peak/√2`

`= √3×133.65/√2`

`= 163.7 V ≒ 164 V`

である。

別解として、最初から

`V_LL1 = √3 kE_d/(2√2)`

へ代入しても同じ値を得る。R04二次型では、波高値と実効値、相電圧と線間電圧を順に変換することが重要である。

## 例題3 複合・ひっかけ: 180°通電の線間実効値と高調波

直流リンク電圧 `E_d=600 V` の三相2レベルインバータを180°通電で動作させる。線間電圧が一周期中、`+600 V` を120°、`0 V` を60°、`-600 V` を120°、`0 V` を60°取るとする。

1. 線間電圧実効値を求めよ。
2. 各相に同相で現れる3次高調波は線間電圧に残るか答えよ。

### 解答

1. 一周期360°のうち、電圧の絶対値が600 Vである区間は240°である。したがって

`V_LL,rms = √[{240×600^2 + 120×0^2}/360]`

`= 600√(2/3)`

`= 489.9 V ≒ 490 V`

となる。

2. 3次高調波は三相で同相になるため、線間電圧を作る差し引きで相殺される。したがって線間電圧には残らない。

この問題では、相端電圧 `±E_d/2` と線間電圧 `0,±E_d` を混同しないこと、0 V区間を実効値計算へ含めることがひっかけになる。

# 公式・解法まとめ

- 三相2レベル電圧形インバータ: 3相×上下アーム = 6スイッチ
- 相指令: 120°ずつ位相をずらす
- 変調率: `k=V_s/V_c`
- 出力基本波周波数: 信号波周波数
- スイッチング周波数: キャリア周波数
- 相電圧基本波波高値: `kE_d/2`
- 相電圧基本波実効値: `kE_d/(2√2)`
- 線間電圧基本波実効値: `√3 kE_d/(2√2)`
- 線間電圧: `v_uv=v_uO-v_vO`
- 180°通電の線間電圧: `0,±E_d`
- 180°通電の線間実効値: `√(2/3)E_d`
- 3の整数倍次数高調波: 平衡三相の線間電圧では相殺
