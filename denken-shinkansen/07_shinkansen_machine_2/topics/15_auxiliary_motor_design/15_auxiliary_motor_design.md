# 教材で欠落不可の説明

1. `P=Tω=2πNT/60` の記号・単位・逆算と、トルク／回転速度／機械出力の関係。
2. `T_M=Jdω/dt+T_L` で、加減速時だけ必要な慣性トルクと、連続運転で必要な負荷トルクを分けること。
3. ポンプ・ファンの相似則 `Q∝N`, `H∝N²`, `P∝N³` と、速度比から流量・圧力・動力比を求める手順。
4. ポンプ・ファン・コンプレッサを「必要な流体仕事→機械効率→電動機効率→電気入力」の順に捉え、効率を分母／分子で取り違えないこと。
5. ファン・ポンプ型の負荷トルクがおおむね速度の2乗に対応し、所要動力が速度の3乗で大きく変わること。
6. インバータ駆動で周波数を変えて回転速度を変えることと、定トルク領域では `V/f` を一定に保つ理由。
7. `V/f` 一定のまま周波数を比率変更したとき、電圧指令振幅と周期を同じ比率関係から決める手順。
8. 連続運転容量と短時間の加速トルク／過負荷耐量を区別してインバータ容量を判断すること。
9. 二次記述式で、`P`、`N` から `ω` を経由して `T=P/ω` を求め、単位まで明記すること。
10. 新幹線のコンプレッサ・ポンプ・ファン・空調は試験論点を具体化する題材として使い、未確認実車値を一般式の根拠にしないこと。

# 解法アルゴリズム

1. 負荷がファン／ポンプ型か、定トルク型かを判定する。
2. 与えられた回転速度・周波数・流量・圧力・出力・効率を整理し、単位をそろえる。
3. 速度変更問題なら速度比 `r=N_2/N_1` を作る。
4. 相似則問題なら `Q_2/Q_1=r`, `H_2/H_1=r²`, `P_2/P_1=r³` を順に使う。
5. 回転機出力問題なら `ω=2πN/60`, `P=Tω` を使う。
6. 効率がある場合は、機械側と電気側のどちらを求めているか確認して入出力をつなぐ。
7. インバータ可変速なら `V/f` 条件、連続容量、短時間過負荷のどれを問う問題か切り分ける。
8. 比・単位・物理的妥当性を検算する。ファン／ポンプ型では速度を下げているのに所要動力が増える解は再確認する。

# 解説本文

## §1 このテーマで電験は何を問うか

補機用電動機では、電動機そのものの等価回路よりも、負荷が何を要求し、その要求をどの出力・トルク・周波数で満たすかを問われる。Topic 15では次の計算鎖を作れることを到達点とする。

`流量・圧力・負荷トルク → 必要機械出力 → 効率を含む電気入力 → インバータ連続容量／短時間容量`

可変速問題では、

`周波数 → V/f → 回転速度域 → 負荷トルク・所要動力`

の順に追う。

一次試験では選択肢の正誤を短時間で判定する必要がある。二次試験では `P=Tω`、`ω=2πN/60`、`T_M=Jdω/dt+T_L` の途中式と単位を明示できることが必要になる。

## §2 回転機の機械出力と負荷トルク

回転軸の機械出力は

`P_m = Tω`

である。

- `P_m`: 機械出力 [W]
- `T`: トルク [N·m]
- `ω`: 角速度 [rad/s]

回転速度 `N [min^-1]` から角速度へ直すと

`ω = 2πN/60`

したがって

`P_m = 2πNT/60`

となる。逆算は

`T = 60P_m/(2πN)`

である。`P` をkWのまま代入しない。

定速運転では、損失を無視した力学式として電動機トルクと負荷トルクが釣り合う。

`T_M = T_L`

加速時は慣性トルクが必要なので

`T_M = J dω/dt + T_L`

となる。

- `J`: 電動機軸へ換算した慣性モーメント [kg·m²]
- `dω/dt`: 角加速度 [rad/s²]
- `T_L`: 負荷トルク [N·m]

ここで重要なのは、連続運転に必要なトルクと、加速中だけ必要なトルクを分けることである。平均所要出力だけでインバータや電動機の加速能力を決めない。

## §3 ポンプ・ファン・コンプレッサの負荷特性と相似則

系列SPECで固定されているポンプ・ファンの相似則は、同一または相似な機械で、同一流体を扱い、効率が大きく変わらない範囲を基本とする。

速度比を

`r = N_2/N_1`

とすると、

`Q_2/Q_1 = r`

`H_2/H_1 = r²`

`P_2/P_1 = r³`

となる。

- `Q`: 流量
- `H`: 揚程または圧力に対応する量
- `P`: 軸動力

`P=Tω` で `ω∝N` だから、ファン・ポンプ型負荷では

`T_L ∝ N²`

とも整理できる。速度を20%下げて `r=0.8` とすると、理想化した相似則では所要動力は `0.8³=0.512` 倍まで下がる。

ポンプでは流体へ与える有効動力を

`P_fluid = ρgQH`

と書ける。ポンプ効率を `η_p`、電動機効率を `η_m` とすれば、

`P_shaft = P_fluid/η_p`

`P_e = P_shaft/η_m`

である。出力から入力へ戻るときは効率で割る。入力から出力へ進むときは効率を掛ける。

ファンでは問題文に圧力差と流量が与えられる場合、流体へ与える動力は「圧力差×体積流量」で扱える。コンプレッサは圧縮過程・圧力比など問題ごとの条件が必要なので、ポンプ・ファンの三乗則を無条件に適用しない。Topic 15では、問題文で与えられる必要機械出力または効率から電動機側へ接続する。

## §4 インバータ駆動とV/f一定制御

誘導電動機の誘導起電力は、基本波で考えると概ね

`E ∝ fΦ`

である。固定子電圧降下を無視できる範囲で `V≈E` とみなせば、磁束は

`Φ ∝ V/f`

となる。したがって、定格周波数以下の定トルク領域では、磁束をほぼ一定に保つため `V/f` を一定にするのが基本である。

周波数比を

`k = f_2/f_1`

とすると、理想化したV/f一定条件では

`V_2 = kV_1`

である。

一方、電気周期は

`T_e = 1/f`

なので

`T_{e2}/T_{e1} = f_1/f_2 = 1/k`

となる。周波数を下げると電圧指令の大きさは下がるが、周期は長くなる。電圧と周期を同じ方向へ比例させない。

同期速度は

`N_s = 120f/P_p`

であり、極数一定なら周波数低下に比例して同期速度も下がる。実際の誘導電動機回転速度はすべりを伴うため、同期速度そのものと同一視しない。

低周波では固定子抵抗による電圧降下の影響が相対的に大きくなるが、本テーマの固定過去問で要求される基本V/f関係を越えて巻線抵抗補償の詳細へ広げない。

## §5 連続負荷と短時間加速負荷から容量を見る

ファン・ポンプを一定速度で運転しているとき、連続的に必要な機械出力は主として負荷トルクで決まる。

`P_cont = T_L ω`

加速中は

`T_M = T_L + Jα`

だから、同じ瞬時回転速度で必要な機械出力は

`P_acc = (T_L + Jα)ω`

となる。

したがって容量判定では、

- 連続運転で必要な出力・電流
- 加速時間中だけ必要なトルク・電流
- インバータに許容される短時間過負荷

を分けて確認する。

実際のインバータ選定ではkWだけでなく電流・皮相電力・過負荷時間などの定格条件が必要である。本教材では問題文に与えられた容量・過負荷条件だけで判定し、メーカー固有の未提示定格を仮定しない。

## §6 新幹線の補機へ接続する

新幹線には走行用主電動機とは別に、空気を扱うコンプレッサや空調用ファン、各種ポンプなどの補機がある。Topic 15ではこれらを実車諸元の暗記対象にせず、電動機応用の負荷モデルとして使う。

- ファン: 速度変更と `Q∝N`, `H∝N²`, `P∝N³` を対応させる。
- ポンプ: `ρgQH` から流体動力を求め、効率を通して電動機入力へ戻す。
- コンプレッサ: 問題文で与えられた必要軸動力・効率から電動機入力を求める。
- インバータ駆動: 必要な速度域に応じて周波数を変え、基本範囲では `V/f` を維持する。

未確認の新幹線補機定格値は使用しない。例題の数値はすべて教材用仮定値である。

## §7 問題を見たときの解法手順

1. 負荷がファン／ポンプ型、与えられた軸動力型、定トルク型のどれかを判定する。
2. 回転速度、周波数、流量、圧力、効率、慣性を整理し、SI単位へそろえる。
3. 速度変更なら `r=N_2/N_1` または `k=f_2/f_1` を作る。
4. 相似則を使う場合は `Q→r`, `H→r²`, `P→r³`, `T→r²` の対応を選ぶ。
5. 回転機の軸出力なら `ω=2πN/60`, `P=Tω` を使う。
6. 加速問題なら `T_M=Jα+T_L` で連続負荷と加速負荷を分ける。
7. 効率を含む場合は「入力→出力なら掛ける、出力→必要入力なら割る」を確認する。
8. V/f一定問題では `V∝f` と `T_e=1/f` を別々に処理する。
9. インバータ容量は連続条件と短時間過負荷条件を分離して判定する。
10. 最後に単位と増減方向を検算する。速度低下時にファン・ポンプ所要動力が増えていないか確認する。

## §8 3段階例題

以下の数値はすべて教材用仮定値であり、新幹線実車値ではない。

### 基礎例題: 出力と回転速度からトルクを求める

ある補機用電動機の軸出力を `22 kW`、回転速度を `1460 min^-1` とする。軸トルクを求める。

まず

`ω = 2π×1460/60 = 152.89 rad/s`

したがって

`T = P/ω = 22000/152.89 = 143.9 N·m`

となる。

検算として `143.9×152.89 ≈ 22.0 kW` なので一致する。

この型では、kW→W換算と `min^-1`→`rad/s` 換算を先に行う。

### 本試験標準例題: ポンプの速度低下と効率

水を送るポンプが `N_1=1500 min^-1` で `Q_1=0.060 m³/s`、`H_1=30 m` で運転している。回転速度を `N_2=1200 min^-1` に下げる。ポンプ効率を `η_p=0.75`、電動機効率を `η_m=0.90` とし、速度変更で効率は変わらないものとする。`ρ=1000 kg/m³`, `g=9.8 m/s²` として、変更後の流量、揚程、電気入力を求める。

速度比は

`r = 1200/1500 = 0.8`

相似則より

`Q_2 = 0.060×0.8 = 0.048 m³/s`

`H_2 = 30×0.8² = 19.2 m`

流体動力は

`P_fluid = ρgQ_2H_2`

`=1000×9.8×0.048×19.2`

`=9.032 kW`

必要軸入力は

`P_shaft = 9.032/0.75 = 12.04 kW`

電動機の必要電気入力は

`P_e = 12.04/0.90 = 13.38 kW`

である。

元の流体動力は `17.64 kW` なので、変更後との比は

`9.032/17.64 = 0.512 = 0.8³`

となり三乗則とも一致する。

### 複合・ひっかけ例題: V/fと加速容量を同時に確認する

4極誘導電動機を `200 V, 60 Hz` で運転している。V/f一定領域で指令周波数を `45 Hz` に変更する。さらに、実回転速度 `1200 min^-1` の瞬間に、負荷トルク `35 N·m`、慣性モーメント `J=1.5 kg·m²`、目標角加速度 `α=15 rad/s²` とする。電動機効率は `0.90`、インバータ損失は無視する。

周波数比は

`k=45/60=0.75`

なので、V/f一定の電圧指令は

`V_2=200×0.75=150 V`

周期は

`T_e=1/45=0.02222 s=22.22 ms`

である。周期は0.75倍ではなく、元の `16.67 ms` の `1/0.75=1.333` 倍になる。

4極の同期速度は

`N_s=120×45/4=1350 min^-1`

である。実回転速度1200 min^-1は同期速度と同じではない。

加速に必要な電動機トルクは

`T_M = Jα+T_L`

`=1.5×15+35=57.5 N·m`

実回転速度1200 min^-1で

`ω=2π×1200/60=125.66 rad/s`

だから、加速中の機械出力は

`P_acc=57.5×125.66=7.226 kW`

電動機入力は

`P_e=7.226/0.90=8.03 kW`

となる。

一方、同じ速度で定速運転だけなら

`P_cont=35×125.66=4.398 kW`

`P_e,cont=4.398/0.90=4.89 kW`

である。したがって、連続約4.89 kWだけを見て加速容量を判定してはいけない。問題文に与えられたインバータ短時間過負荷条件と約8.03 kW相当の加速要求を別に照合する。

## §9 頻出ミス

- `P=Tω` へ回転速度 `N[min^-1]` をそのまま入れる。
- kWをWへ直さず `T=P/ω` を計算する。
- ファン・ポンプで `Q`,`H`,`P` の指数1,2,3を取り違える。
- 速度を下げたとき、所要動力も速度に比例すると誤認する。
- 効率を出力から入力へ戻すときに掛けてしまう。
- コンプレッサへポンプ・ファンの三乗則を条件確認なしで適用する。
- `V/f` 一定で周波数を下げたとき、周期まで同じ比率で短くする。
- 同期速度と誘導電動機の実回転速度を同一視する。
- 連続容量だけで短時間加速能力まで満たすと判断する。

## §11 公式・解法まとめ

- `ω=2πN/60`
- `P_m=Tω`
- `T_M=Jα+T_L`
- `r=N_2/N_1`
- `Q_2/Q_1=r`
- `H_2/H_1=r²`
- `P_2/P_1=r³`
- ファン・ポンプ型では `T_L∝N²`
- ポンプ流体動力 `P_fluid=ρgQH`
- 出力から必要入力へ戻すとき `P_in=P_out/η`
- V/f一定の基本関係 `V_2/V_1=f_2/f_1`
- 電気周期 `T_e=1/f`
- 同期速度 `N_s=120f/P_p`
