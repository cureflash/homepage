# 解説本文

## §1 このテーマで電験は何を問うか

回生ブレーキでは、走行中の車両が持つ機械エネルギーを主電動機で電気エネルギーへ変え、主変換装置を通して電源側へ返す。電験二種では、単に「回生すると電気が戻る」と覚えるだけでは足りない。

本テーマでは次を解ける状態を目標にする。

1. 誘導機の同期速度と滑りから、電動機運転か発電機運転か判定する。
2. 速度とトルクの符号から、力行か回生かを判定する。
3. 主回路のどちら向きに有効電力が流れるか説明する。
4. DCリンク側から交流電源側へ電力を返すPWM変換器の基本計算を行う。
5. 段ごとの効率から架線へ返る電力を求める。

一次試験では用語・原理・滑りの符号を問う選択問題、二次試験ではフェーザ式と有効電力式を組み合わせる記述計算へ接続する。

## §2 誘導機の発電機運転

### 2.1 同期速度

極数を `p`、電源周波数を `f [Hz]` とすると、回転磁界の同期速度は

`N_s = 120 f / p [min^-1]`

である。

### 2.2 滑り

回転子速度を `N` とすると、滑りは

`s = (N_s - N) / N_s`

である。

- `0 < s < 1`: 回転子は回転磁界より遅い。通常の電動機運転。
- `s = 0`: 回転子速度と同期速度が一致。
- `s < 0`: 回転子が回転磁界より速い。発電機運転。

回生制動では車輪側から主電動機を回すため、誘導機を `s<0` の発電機領域へ移す。電磁トルクは回転方向と逆向きになり、車両を減速させる。

### 2.3 解法手順

誘導機の回生問題では次の順で処理する。

1. `f` と `p` から `N_s` を求める。
2. 実回転速度 `N` と比較する。
3. `s=(N_s-N)/N_s` を計算する。
4. `s<0` なら発電機運転、`s>0` なら電動機運転と判定する。
5. 発電機運転なら、機械側から電気側へエネルギーが移ることを確認する。

符号を見ずに「高速だから回生」と判断してはいけない。基準は同期速度との差である。

## §3 力行と回生の電力フロー

力行時は、電気エネルギーが車輪側へ向かう。

`架線 → コンバータ → DCリンク → インバータ → 誘導電動機 → 車輪`

回生時は逆向きである。

`車輪 → 誘導電動機 → インバータ → DCリンク → コンバータ → 架線`

回生では、車両の運動エネルギーが減ることで制動力が生じる。主電動機は発電機として働き、その電力をインバータ側からDCリンクへ渡す。さらにPWMコンバータが交流側へ有効電力を返す。

架線へ戻った回生電力は、同じ給電系統内で力行中の車両が存在すれば、その車両の電力として消費できる。ここではその電力授受までを扱い、回生失効対策や電力貯蔵設備へは広げない。

## §4 速度・トルクと四象限運転

回転速度を `ω [rad/s]`、電磁トルクを `T [N·m]` とし、機械電力を

`P_m = Tω`

とする。

この符号で四象限を整理できる。

| 象限 | `ω` | `T` | `P_m=Tω` | 状態 |
|---|---:|---:|---:|---|
| I | + | + | + | 正転・力行 |
| II | + | - | - | 正転・回生制動 |
| III | - | - | + | 逆転・力行 |
| IV | - | + | - | 逆転・回生制動 |

重要なのは、回生では速度とトルクの符号が反対になることである。`P_m<0` なら、電気機械が車輪へ機械出力を与えるのではなく、車輪側から機械入力を受けて電気側へ返す状態と判断できる。

新幹線の通常走行方向を正とすれば、制動中は `ω>0`、`T<0` なので第II象限に当たる。

## §5 DCリンクから架線への返送

### 5.1 DCリンクの役割

回生時、誘導機が発生した交流電力は主変換装置を経てDCリンクへ移り、さらに架線側のPWMコンバータによって交流電源側へ返される。ここではスイッチング素子の損失計算や熱設計は扱わない。

### 5.2 H24二次型のフェーザ関係

交流電源側電圧を `V_L`、変換器基本波電圧を `V_v`、連系リアクトルを `X`、交流電流を `I` とする。電流を変換器から交流電源へ出力する向きにとると、採用過去問の前提では

`V_v = V_L + jXI`

となる。

力率1で交流電流が `V_L` と同相なら、`V_L` と `jXI` は直交するので

`|V_v| = sqrt(V_L^2 + (XI)^2)`

である。

また、単相の有効電力は力率1なら

`P = V_L I`

なので

`I = P / V_L`

と求められる。

### 5.3 PWM変調率

採用したH24二次問題のPWMモデルでは、直流電圧を `E_d`、変調率を `K` とすると基本波実効値は

`V_v = E_d K / sqrt(2)`

で与えられる。したがって

`K = sqrt(2) V_v / E_d`

である。この関係は当該問題で与えられたモデルに基づく。一般の全PWM方式へ無条件に拡張しない。

### 5.4 二次記述問題の解法アルゴリズム

1. 電力の正方向を確認し、回生では変換器から交流電源へ電流を出す向きにとる。
2. 力率条件を確認する。
3. `P=V_L I` から電流を求める。
4. `V_v=V_L+jXI` をフェーザとして扱い、必要な電圧の大きさを求める。
5. 問題で与えられたPWM式へ代入し、変調率を求める。
6. `K` が問題設定上の妥当な範囲にあるか検算する。

## §6 回生効率

回生時に車輪側から主電動機へ入る機械電力の大きさを `P_mech,in`、架線へ返る有効電力を `P_return` とすると、回生効率を

`η_reg = P_return / P_mech,in`

と定義する。

主電動機の発電効率を `η_m`、インバータ段を `η_inv`、架線側コンバータ段を `η_conv` として各段の効率が与えられるなら、

`η_reg = η_m η_inv η_conv`

`P_return = P_mech,in η_m η_inv η_conv`

である。

効率を百分率で与えられた場合は小数へ直してから掛ける。ここで用いる数値は例題上の仮定値であり、新幹線実車の真値とはしない。

## §7 頻出ミス

- `N>N_s` なのに `s` を正としてしまう。
- 回生時に `車輪 → 架線` ではなく力行時と同じ向きで考える。
- `P_m=Tω` でトルクの符号を落とし、回生を力行と判定する。
- フェーザ式 `V_v=V_L+jXI` を実数の単純加算 `V_L+XI` として扱う。
- 単相有効電力式と三相電力式を混同する。
- `%` 表示の効率をそのまま掛ける。
- H24二次型のPWM式を、条件の異なるPWM方式へ一般化する。

# 3段階例題

## 例題1 基礎: 滑りから回生運転を判定する

4極、50 Hzの誘導機が1530 min^-1で正方向に回転している。電動機運転か発電機運転か判定せよ。

### 解答

同期速度は

`N_s = 120×50/4 = 1500 min^-1`

滑りは

`s = (1500-1530)/1500 = -0.020`

よって `s<0` である。回転子が回転磁界より速いため発電機運転であり、回生制動に使える領域である。

### 検算

`N=1530 > N_s=1500` なので、滑りが負になることと一致する。

## 例題2 本試験標準: DCリンク側から交流電源へ電力を返す

単相交流電源 `V_L=200 V` へ、PWM変換器からリアクトル `X=0.25 Ω` を介して力率1で `P=8.0 kW` を返す。直流電圧を `E_d=300 V` とし、基本波実効値が `V_v=E_d K/sqrt(2)` で与えられるとする。交流電流 `I`、変換器基本波電圧 `V_v`、変調率 `K` を求めよ。

### 解答

力率1なので

`I = P/V_L = 8000/200 = 40 A`

リアクトル電圧は

`XI = 0.25×40 = 10 V`

`V_L` と `jXI` は直交するから

`V_v = sqrt(200^2+10^2) = 200.25 V`

したがって

`K = sqrt(2)×200.25/300 = 0.944`

答えは

- `I = 40 A`
- `V_v ≈ 200.25 V`
- `K ≈ 0.944`

である。

### 式を選ぶ理由

交流電源へ返す有効電力と力率1条件から電流を先に決め、その電流によるリアクトル電圧降下をフェーザで加える。最後に問題で指定されたPWM基本波式から `K` を逆算する。

## 例題3 複合: 四象限判定と回生効率

正方向に `ω=120 rad/s` で回転している主電動機に、制動トルク `T=-8.0 kN·m` が生じている。主電動機の発電効率を0.94、インバータ段を0.98、架線側コンバータ段を0.97と仮定する。運転象限、車輪側から取り込む機械電力の大きさ、架線へ返る電力を求めよ。

### 解答

`ω>0`、`T<0` なので第II象限、正転回生である。

機械電力は

`P_m = Tω = (-8.0×10^3)×120 = -960 kW`

負号は回生方向を表す。車輪側から取り込む機械電力の大きさは

`P_mech,in = 960 kW`

総合回生効率は

`η_reg = 0.94×0.98×0.97 = 0.8936`

したがって

`P_return = 960×0.8936 = 857.8 kW`

よって架線へ返る電力は約 `858 kW` である。

### ひっかけ確認

`P_m` の負号を「電力が存在しない」と解釈しない。符号は電力の向きを表す。効率計算では電力の大きさを用いる。

# 公式・解法まとめ

- 同期速度: `N_s=120f/p`
- 滑り: `s=(N_s-N)/N_s`
- `s<0`: 誘導機の発電機運転
- 機械電力: `P_m=Tω`
- 回生電力フロー: `車輪 → 誘導電動機 → インバータ → DCリンク → コンバータ → 架線`
- H24二次型フェーザ式: `V_v=V_L+jXI`
- 力率1の単相有効電力: `P=V_L I`
- H24二次型PWM式: `V_v=E_d K/sqrt(2)`
- 回生効率: `η_reg=P_return/P_mech,in`
- 段効率が与えられる場合: `η_reg=η_m η_inv η_conv`
