# EXAM_ALIGNMENT

資格: 第二種電気主任技術者

主科目: 一次試験「機械」、二次試験「機械・制御」

論点:
- 誘導機の `s<0` における発電機運転と回生制動
- 力行時と回生時の機械エネルギー・電気エネルギーの向き
- 回転方向とトルク方向の符号から見る四象限運転
- DCリンクからPWMコンバータを介して交流電源側へ有効電力を返す経路
- 架線へ戻した回生電力を他の力行車が消費する関係
- 回生効率と各変換段の損失の扱い

## 教材で欠落不可の説明

1. 誘導機の同期速度 `N_s=120f/p` と滑り `s=(N_s-N)/N_s` を確認し、`N>N_s` なら `s<0` となる。回転磁界より回転子が速い領域では誘導機は発電機運転となり、トルクは回転方向と逆向きの制動トルクになる。
2. 力行では `架線 → コンバータ → DCリンク → インバータ → 誘導電動機 → 車輪`、回生ではそのエネルギー流が逆になり、`車輪 → 誘導電動機 → インバータ → DCリンク → コンバータ → 架線` となることを区別する。
3. 四象限運転は回転速度 `ω` とトルク `T` の符号で整理し、機械電力 `P_m=Tω` の符号から力行／回生を判定できるようにする。新たな座標変換や制御器設計には広げない。
4. H24二次型では、コンバータ側から交流電源へ電流を出力する向きを採用し、リアクトルを介したフェーザ関係 `Vv = VL + jXI` を使う。力率1では `P=VL I` から有効電流を求める。
5. H24二次問題で与えられたPWMモデルでは、基本波実効値は `Vv = Ed K / sqrt(2)` なので、`K=sqrt(2)Vv/Ed` と逆算する。この式は当該問題の前提に基づくものとして一般化し過ぎない。
6. 架線へ戻った回生電力は他の力行車で消費できることを説明する。ただしH27の回生失効対策、電力貯蔵設備、運行間隔は本Topicへ追加しない。
7. 回生効率は、機械側から取り込んだ電力に対して架線へ返せた電力の比として `η_reg=P_return/P_mech,in` と定義し、段ごとの効率を与えられた場合は積で扱う。未確認の新幹線実車効率は真値として置かない。
8. 電力・トルク・速度の符号規約を先に固定し、符号の取り違えで力行と回生を逆にしない解法手順を示す。
