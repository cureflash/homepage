# 一次試験型

## 問1 滑りと発電機運転

4極、60 Hzの三相誘導機が1890 min^-1で正方向に回転している。滑り `s` と運転状態の組合せとして正しいものを選べ。

1. `s=-0.05`、発電機運転
2. `s=-0.05`、電動機運転
3. `s=0.05`、発電機運転
4. `s=0.05`、電動機運転
5. `s=1.05`、発電機運転

### 正答

1

### 解説

同期速度は

`N_s=120f/p=120×60/4=1800 min^-1`

滑りは

`s=(N_s-N)/N_s=(1800-1890)/1800=-0.05`

である。`N>N_s` なので `s<0` となり、誘導機は発電機運転となる。2は滑りの符号と運転状態の対応が誤り、3と4は滑りの符号が逆、5は定義式に合わない。

---

## 問2 回生時の電力フロー

新幹線の誘導主電動機が回生制動しているときの電力フローとして正しいものを選べ。

1. 架線 → コンバータ → DCリンク → インバータ → 誘導電動機 → 車輪
2. 車輪 → 誘導電動機 → インバータ → DCリンク → コンバータ → 架線
3. 車輪 → コンバータ → DCリンク → インバータ → 架線
4. 架線 → 誘導電動機 → DCリンク → コンバータ → 車輪
5. DCリンク → 車輪 → 誘導電動機 → 架線

### 正答

2

### 解説

回生では車両の機械エネルギーを主電動機で電気エネルギーへ変え、主変換装置を通して電源側へ返す。したがって固定電力フローは

`車輪 → 誘導電動機 → インバータ → DCリンク → コンバータ → 架線`

である。1は力行時の向きである。3〜5は主回路要素の順序が誤っている。

---

## 問3 四象限運転

正方向を正とする。回転速度 `ω>0`、電磁トルク `T<0` のときの状態として正しいものを選べ。

1. 第I象限・正転力行
2. 第II象限・正転回生
3. 第III象限・逆転力行
4. 第IV象限・逆転回生
5. 停止状態

### 正答

2

### 解説

`P_m=Tω` なので、`ω>0`、`T<0` なら `P_m<0` である。速度とトルクの符号が反対なので正転回生、第II象限となる。

---

## 問4 機械電力の符号

正方向に `ω=100 rad/s` で回転している主電動機に `T=-6.0 kN·m` の制動トルクが生じている。機械電力 `P_m=Tω` として正しいものを選べ。

1. `+60 kW`
2. `-60 kW`
3. `+600 kW`
4. `-600 kW`
5. `-6.0 MW`

### 正答

4

### 解説

`T=-6.0×10^3 N·m` だから、

`P_m=Tω=(-6.0×10^3)×100=-6.0×10^5 W=-600 kW`

となる。負号は回生方向を表す。電力の大きさは600 kWである。

---

## 問5 回生効率

車輪側から主電動機へ入る機械電力が900 kW、架線へ返る有効電力が810 kWである。回生効率として正しいものを選べ。

1. 0.10
2. 0.81
3. 0.90
4. 1.11
5. 90

### 正答

3

### 解説

`η_reg=P_return/P_mech,in=810/900=0.90`

である。百分率なら90%である。5は百分率と小数を混同している。

---

## 問6 段効率の積

主電動機の発電効率0.95、インバータ段0.98、架線側コンバータ段0.97とする。総合回生効率として最も近いものを選べ。

1. 0.856
2. 0.903
3. 0.950
4. 0.967
5. 1.10

### 正答

2

### 解説

各段を直列に通るので、

`η_reg=0.95×0.98×0.97=0.90307≈0.903`

である。効率は足し算ではなく積で扱う。

---

## 問7 回生電力と力行車

交流き電系統へ返された回生電力について、本テーマの固定範囲で正しい説明を選べ。

1. 回生電力は必ず車上蓄電池へ蓄えられる。
2. 回生電力は必ず抵抗器で熱へ変換される。
3. 同じ給電系統で力行中の車両があれば、その車両の電力として消費できる。
4. 回生時はDCリンクから車輪へ有効電力が流れる。
5. 回生時も主電動機は必ず電動機運転である。

### 正答

3

### 解説

架線へ返した回生電力は、同じ給電系統内の力行車が消費できる。1と2は本テーマの固定範囲外の方式を「必ず」としており誤り。4は力行方向、5は回生時の誘導機発電運転と矛盾する。

## 問8 DCリンクの位置

回生時の主回路でDCリンクの位置として正しいものを選べ。

1. 車輪と誘導電動機の間
2. 誘導電動機とインバータの間
3. インバータと架線側コンバータの間
4. 架線側コンバータと架線の間
5. 架線の外部だけに存在する

### 正答

3

### 解説

固定電力フローは

`車輪 → 誘導電動機 → インバータ → DCリンク → コンバータ → 架線`

なので、DCリンクはインバータと架線側コンバータの間にある。

## 問9 H24二次型のフェーザ電圧

単相交流電源 `V_L=200 V` へ、リアクトル `X=0.40 Ω` を介してPWM変換器から力率1で `P=6.0 kW` を返す。採用過去問と同じ向きで `V_v=V_L+jXI` とする。変換器基本波電圧の大きさ `|V_v|` として最も近いものを選べ。

1. 188.0 V
2. 200.0 V
3. 200.36 V
4. 212.0 V
5. 224.0 V

### 正答

3

### 解説

力率1なので

`I=P/V_L=6000/200=30 A`

リアクトル電圧は

`XI=0.40×30=12 V`

である。`V_L` と `jXI` は直交するため、

`|V_v|=sqrt(200^2+12^2)=200.36 V`

となる。`200+12` と実数加算してはいけない。

---

## 問10 H24二次型のPWM変調率

問9の条件で直流電圧を `E_d=300 V` とし、採用過去問で与えられたPWMモデル `V_v=E_d K/sqrt(2)` を用いる。変調率 `K` として最も近いものを選べ。

1. 0.472
2. 0.667
3. 0.845
4. 0.945
5. 1.414

### 正答

4

### 解説

問9より `V_v=200.36 V`。したがって

`K=sqrt(2)V_v/E_d=sqrt(2)×200.36/300=0.9445≈0.945`

である。この式は採用したH24二次問題のPWMモデルに基づき、一般のPWM方式へ無条件に拡張しない。

# 二次試験型

## 問11 同期速度・滑り・回生判定

6極、50 Hzの三相誘導機が1020 min^-1で正方向に回転している。次を求め、運転状態を説明せよ。

1. 同期速度 `N_s`
2. 滑り `s`
3. 電動機運転か発電機運転か
4. 回生時のエネルギーの向き

### 解答・完全解説

1. 同期速度

`N_s=120f/p=120×50/6=1000 min^-1`

2. 滑り

`s=(N_s-N)/N_s=(1000-1020)/1000=-0.020`

3. 運転状態

`N>N_s` で `s<0` なので発電機運転である。電磁トルクは回転方向と逆向きとなり、制動トルクを生じる。

4. エネルギーの向き

回生時は機械側から電気側へ流れ、主回路では

`車輪 → 誘導電動機 → インバータ → DCリンク → コンバータ → 架線`

となる。

### 検算

回転子速度1020 min^-1は同期速度1000 min^-1より大きいので、滑りが負になる結果と一致する。

## 問12 四象限判定と架線返送電力

正方向に `ω=90 rad/s` で回転する主電動機に `T=-8.0 kN·m` の制動トルクが生じている。主電動機の発電効率を0.94、インバータ段を0.98、架線側コンバータ段を0.97とする。次を求めよ。

1. 運転象限
2. 機械電力 `P_m`
3. 車輪側から取り込む機械電力の大きさ
4. 総合回生効率
5. 架線へ返る有効電力

### 解答・完全解説

1. `ω>0`、`T<0` なので第II象限、正転回生である。

2. 機械電力

`P_m=Tω=(-8.0×10^3)×90=-720 kW`

3. 車輪側から取り込む機械電力の大きさ

`P_mech,in=720 kW`

4. 総合回生効率

`η_reg=0.94×0.98×0.97=0.893564≈0.894`

5. 架線返送電力

`P_return=720×0.893564=643.37 kW≈643 kW`

### 検算

返送電力643 kWは入力機械電力720 kWより小さく、各段効率が1未満であることと整合する。

---

## 問13 PWM変換器から交流電源へ有効電力を返す

単相交流電源 `V_L=100 V` へ、PWM変換器からリアクトル `X=0.40 Ω` を介して力率1で `P=3.0 kW` を返す。直流電圧を `E_d=150 V` とし、採用過去問と同じモデル

`V_v=V_L+jXI`

`V_v=E_d K/sqrt(2)`

を用いる。次を求めよ。

1. 交流電流 `I`
2. リアクトル電圧 `XI`
3. 変換器基本波電圧の大きさ `|V_v|`
4. 変調率 `K`
5. `V_v` と `V_L` の位相差を `φ` としたときの `tanφ`

### 解答・完全解説

1. 力率1なので

`I=P/V_L=3000/100=30 A`

2. リアクトル電圧

`XI=0.40×30=12 V`

3. `V_L` と `jXI` は直交するから

`|V_v|=sqrt(100^2+12^2)=100.717 V≈101 V`

4. PWM変調率

`K=sqrt(2)V_v/E_d`

`=sqrt(2)×100.717/150=0.94957≈0.950`

5. フェーザ直角三角形より

`tanφ=XI/V_L=12/100=0.120`

### 検算

`V_v` は `V_L` よりわずかに大きく、`K<1` である。フェーザ式を `100+12=112 V` と実数加算しない。

---

## 問14 架線返送電力から機械入力を逆算する

架線へ700 kWを返している。主電動機の発電効率0.96、インバータ段0.98、架線側コンバータ段0.97とする。車輪側から主電動機へ入る機械電力 `P_mech,in` を求めよ。

### 解答・完全解説

総合回生効率は

`η_reg=0.96×0.98×0.97=0.912576`

回生効率の定義

`η_reg=P_return/P_mech,in`

より、

`P_mech,in=P_return/η_reg=700/0.912576=767.06 kW`

したがって

`P_mech,in≈767 kW`

である。

### 検算

損失があるので、機械入力767 kWは架線返送700 kWより大きくなる。大小関係が逆なら式の向きを取り違えている。

---

## 問15 回生主回路の論述

誘導主電動機を用いる交流電気車が正方向へ走行中に回生制動する場合について、次の語をすべて用いて電力変換の流れを説明せよ。

`滑り`、`発電機運転`、`インバータ`、`DCリンク`、`PWMコンバータ`、`架線`、`力行車`

### 解答・完全解説

回生制動では、誘導主電動機の回転子速度を同期速度より高い領域とし、滑りを負にして発電機運転させる。車輪側の機械エネルギーは誘導主電動機で電気エネルギーへ変換され、インバータを介してDCリンクへ移る。DCリンクの電力はPWMコンバータによって交流側へ変換され、架線へ返される。架線へ返った回生電力は、同じ給電系統内で力行中の力行車が存在すれば、その車両の電力として消費できる。

この説明で必要な固定電力フローは

`車輪 → 誘導電動機 → インバータ → DCリンク → コンバータ → 架線`

である。回生失効対策、電力貯蔵設備、運行間隔は本テーマでは論じない。
