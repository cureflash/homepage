# 一次試験型

## 問1 メカトロニクス機器の信号の流れ

車輪回転を検出し、その結果に応じて主電動機トルクを調整する教材用制御系を考える。構成要素の役割として最も適切なものを選べ。

1. センサがトルクを発生し、アクチュエータが車輪速度を計測する。
2. センサが機械量を電気信号へ変換し、制御器が演算し、アクチュエータが機械作用を生じさせる。
3. 制御器は計測だけを行い、操作量はセンサが決める。
4. アクチュエータは偏差を計算し、センサは電力を増幅する。
5. フィードバック系ではセンサを用いない。

### 正答

2

### 解説

メカトロニクスでは、センサが速度・角度などの機械量を制御器が扱える電気信号へ変換する。制御器は測定値と指令値等から操作量を計算し、アクチュエータが力・トルク・変位などの機械作用へ変換する。

再粘着の一般モデルでは

`センサ → 制御演算 → アクチュエータ → 車輪・駆動系 → センサ`

という閉ループで考える。

## 問2 シーケンス制御とフィードバック制御

次の説明のうち最も適切なものを選べ。

1. シーケンス制御は常に出力を連続測定して偏差をゼロにする制御である。
2. フィードバック制御は決められた順番だけで動き、出力状態を利用しない。
3. シーケンス制御は順序・条件に従って動作を進め、フィードバック制御は出力側の状態を戻して操作量を修正する。
4. シーケンス制御とフィードバック制御は同義である。
5. 再粘着では車輪状態を測定しないため、フィードバック制御とは関係しない。

### 正答

3

### 解説

シーケンス制御は所定の順序・条件で動作を進める制御である。フィードバック制御は出力側の状態を測定して入力側へ戻し、その結果に応じて操作量を修正する。

再粘着では「状態検出 → トルク抑制 → 回復確認 → トルク回復」という順序を持つ一方、車輪状態を再検出して操作を修正する点がフィードバックの本質である。

## 問3 エンコーダのパルス数から回転速度を求める

有効カウント数 `P=2400 count/rev` のロータリエンコーダで、`Δt=0.050 s` の間に `N=300 count` を観測した。回転速度 `n` と角速度 `ω` の組合せとして正しいものを選べ。

1. `n=75 min^-1, ω=2.5π rad/s`
2. `n=120 min^-1, ω=4π rad/s`
3. `n=150 min^-1, ω=5π rad/s`
4. `n=300 min^-1, ω=10π rad/s`
5. `n=600 min^-1, ω=20π rad/s`

### 正答

3

### 解説

`n=60N/(PΔt)` より

`n=60×300/(2400×0.050)=150 min^-1`

である。

また

`ω=2πN/(PΔt)`

`=2π×300/(2400×0.050)=5π rad/s`

となる。

`150 min^-1=2.5 rev/s` なので `ω=2π×2.5=5π rad/s` と検算できる。

## 問4 2相信号を持つロータリエンコーダ

A相・B相の位相差を持つインクリメンタル形ロータリエンコーダについて正しいものを選べ。

1. 一定時間内のカウント数から回転速度、A相とB相の先行関係から回転方向、累積カウント数から回転角を求められる。
2. A相とB相の振幅差だけで回転方向を求め、カウント数は角度に利用できない。
3. 回転速度は測れるが、回転方向と回転角は原理上測れない。
4. 回転角は光量から求め、回転速度は磁束密度から求める。
5. A相・B相の位相差は回転状態の検出には使わない。

### 正答

1

### 解説

一定時間内のパルス数は回転速度に対応する。A相とB相のどちらが先行するかで回転方向を判定でき、累積カウント数は回転角に対応する。

同一センサで「速度・方向・角度」をどう取り出すかを関係付けて理解することが重要である。

## 問5 センサ原理・物理量・具体例

センサ原理と入力物理量、具体例の組合せとして最も適切なものを選べ。

1. 磁気 — 光量 — フォトダイオード、光電 — 磁界 — ホール素子
2. 磁気 — 圧力 — 熱電対、光電 — 温度 — ひずみゲージ
3. 磁気 — 磁界・磁束の変化 — ホール素子、光電 — 光量・遮光状態 — フォトダイオード
4. 磁気 — 回転角 — フォトトランジスタ、光電 — 磁束 — 磁気抵抗素子
5. 磁気 — 音圧 — CdS、光電 — 加速度 — ホール素子

### 正答

3

### 解説

磁気系センサでは、磁界・磁束の変化をホール素子や磁気抵抗素子などで電気量へ変換する。光電系では、光量や遮光状態をフォトダイオードやフォトトランジスタなどで電気信号へ変換する。

センサ名だけでなく「何の物理量を何の原理で電気量へ変えるか」を対応付ける。

## 問6 空転と滑走の判定

教材用モデルで車体側基準速度を `v_ref=20.0 m/s` とする。力行中、半径 `r=0.40 m` の車輪が `ω=55 rad/s` で回転している。最も適切な判定を選べ。

1. `v_w=18 m/s` なので滑走を疑う。
2. `v_w=20 m/s` なので基準速度と一致する。
3. `v_w=22 m/s` で基準速度より高いため、空転を疑う。
4. `v_w=22 m/s` で基準速度より高いため、滑走を疑う。
5. 車輪周速度は `ω/r` なので `137.5 m/s` となる。

### 正答

3

### 解説

`v_w=rω=0.40×55=22.0 m/s`

である。

力行中に車輪周速度が車体側基準速度より過大になる側は空転を疑う。制動時に車輪周速度が基準側より過小になる側が滑走である。

## 問7 車輪周速度の差分から加速度を推定する

教材用モデルで、車輪半径 `r=0.40 m`、観測間隔 `Δt=0.050 s` とする。車輪角速度が `50.0 rad/s` から `51.5 rad/s` へ変化した。車輪周速度の変化率 `a_w` として正しいものを選べ。

1. `0.60 m/s^2`
2. `3.0 m/s^2`
3. `6.0 m/s^2`
4. `12 m/s^2`
5. `30 m/s^2`

### 正答

4

### 解説

`a_w≒r{ω[k]-ω[k-1]}/Δt`

より

`a_w≒0.40×(51.5-50.0)/0.050`

`=12 m/s^2`

である。

これは車輪周速度の変化率であり、空転中には車体加速度そのものとは限らない。

## 問8 粘着限界と車輪トルク

教材用単純モデルで、1輪軸相当の輪重を `N_w=80 kN`、有効粘着係数を `μ=0.12`、車輪半径を `r=0.45 m` とする。最大伝達力と、その力に対応する車輪トルクの組合せとして最も適切なものを選べ。

1. `F=6.4 kN, T=2.88 kN·m`
2. `F=8.0 kN, T=3.60 kN·m`
3. `F=9.6 kN, T=4.32 kN·m`
4. `F=12 kN, T=5.40 kN·m`
5. `F=80 kN, T=36.0 kN·m`

### 正答

3

### 解説

`F_adh,max≒μN_w`

`=0.12×80=9.6 kN`

である。

対応する車輪トルクは

`T=rF=0.45×9.6=4.32 kN·m`

となる。

この式は粘着限界の存在を理解する教材用単純モデルであり、粘着係数を一定の実車値として扱うものではない。

## 問9 再粘着制御の一般的な流れ

力行中に空転を検出した場合の教材用一般モデルとして、最も適切な流れを選べ。

1. 空転検出 → トルク増加 → 回転加速度増加 → トルク固定
2. 空転検出 → トルク抑制 → 車輪状態の回復確認 → トルク回復
3. 空転検出 → センサ無効化 → トルク最大化 → 開ループ化
4. 空転検出 → 制御器停止 → 回転速度を無視 → トルク回復
5. 空転検出 → 車輪径を変更 → トルク増加 → 回復確認

### 正答

2

### 解説

一般的な再粘着の因果関係は

`状態検出 → トルク抑制 → 車輪状態の回復確認 → トルク回復`

である。

重要なのは、一度トルクを下げて終わりではなく、その後の状態を再検出して回復操作へつなげることである。これは教材用一般モデルであり、特定車両の判定しきい値や抑制率を示すものではない。

## 問10 負帰還系の閉ループ伝達関数

教材用制御系で

`G_c(s)=2`

`G_p(s)=1/(s+2)`

を直列に接続し、単位負帰還をかける。目標値から制御量までの閉ループ伝達関数として正しいものを選べ。

1. `2/(s+2)`
2. `2/(s+4)`
3. `1/(s+4)`
4. `2/(s+1)`
5. `(s+2)/(s+4)`

### 正答

2

### 解説

一巡伝達関数は

`L(s)=G_c(s)G_p(s)=2/(s+2)`

である。単位負帰還なので

`G_y(s)=L(s)/{1+L(s)}`

`={2/(s+2)}/{1+2/(s+2)}`

`=2/(s+4)`

となる。

## 問11 エンコーダから回転速度・角度・車輪加速度を求める

教材用モデルで、有効カウント数 `P=4096 count/rev` のロータリエンコーダを用いる。観測間隔は `Δt=0.080 s`、車輪半径は `r=0.43 m` とする。

ある観測窓で `N_1=256 count`、次の観測窓で `N_2=288 count` を得た。また基準位置からの累積カウント数が `1024 count` であった。

次を求めよ。

(1) 第1観測窓の回転速度 `n_1 [min^-1]`

(2) 第1観測窓の角速度 `ω_1 [rad/s]` と車輪周速度 `v_1 [m/s]`

(3) 累積カウント数に対応する回転角

(4) 第2観測窓との比較から車輪周速度の変化率 `a_w [m/s^2]`

### 解答

(1)

`n_1=60N_1/(PΔt)`

`=60×256/(4096×0.080)`

`=46.875 min^-1`

(2)

`ω_1=2πN_1/(PΔt)`

`=2π×256/(4096×0.080)`

`≒4.909 rad/s`

したがって

`v_1=rω_1=0.43×4.909≒2.111 m/s`

である。

(3)

1回転4096 countなので

`θ=2π×1024/4096=π/2 rad=90°`

である。

(4)

第2観測窓では

`ω_2=2π×288/(4096×0.080)≒5.522 rad/s`

`v_2=0.43×5.522≒2.375 m/s`

よって

`a_w≒(v_2-v_1)/Δt`

`=(2.375-2.111)/0.080`

`≒3.30 m/s^2`

となる。

### 検算

第2観測窓のカウント数は第1観測窓の `288/256=1.125` 倍なので、角速度と車輪周速度も1.125倍になる。`2.111×1.125≒2.375 m/s` で一致する。

この `a_w` は車輪周速度の変化率であり、車体加速度そのものと断定しない。

## 問12 粘着限界を超えたときの車輪角加速度

教材用単純モデルで、輪重 `N_w=85 kN`、有効粘着係数 `μ=0.10`、車輪半径 `r=0.43 m`、車輪・駆動系の等価慣性 `J=120 kg·m^2` とする。駆動トルク `T_m=4.50 kN·m` が加わったとき、接触部の伝達力は粘着限界 `F_t=F_adh,max` に達してそれ以上増えないものとする。

次を求めよ。

(1) `F_adh,max`

(2) 接触部が車輪回転へ及ぼす抵抗側トルク `rF_t`

(3) `J dω/dt=T_m-rF_t` から車輪角加速度

(4) 力行時の一般的な再粘着操作の方向

### 解答

(1)

`F_adh,max≒μN_w`

`=0.10×85=8.5 kN`

である。

(2)

`rF_t=0.43×8.5=3.655 kN·m`

である。

(3)

余剰トルクは

`T_m-rF_t=4.50-3.655=0.845 kN·m=845 N·m`

したがって

`dω/dt=845/120≒7.04 rad/s^2`

となる。

(4)

駆動トルクの一部が車輪回転加速へ回っているため、一般的な再粘着操作は駆動トルクを増やす側ではなく抑制側である。その後、車輪状態の回復を確認してトルクを戻す。

### 検算

`T_m=4.50 kN·m` は粘着限界に対応する `3.655 kN·m` より大きいので、右辺 `T_m-rF_t` は正となる。角加速度が正になる計算結果と整合する。

## 問13 非線形性・飽和・応答速度を説明する

再粘着の教材用一般モデルについて、次を説明せよ。

(1) 粘着係数を一定値だけで扱うと不十分な理由

(2) トルク指令に上限・下限があるときの飽和とは何か

(3) 車輪速度の変動を強く平滑化した場合に生じる利点と欠点

(4) 空転検出後、トルク抑制だけでなく回復確認が必要な理由

### 解答

(1)

車輪とレールの接触状態、速度、水分などで伝達可能な接線力は変化し、相対運動と伝達力の関係も一般に非線形である。そのため `F_adh,max≒μN_w` は粘着限界の存在を理解する近似であり、一定 `μ` だけで実車の全状態を表すことはできない。

(2)

制御器が計算した操作量がアクチュエータや主回路の許容範囲を超えても、実際の出力が上限または下限で頭打ちになる現象が飽和である。飽和中は「指令をさらに増減すれば比例して実出力も変わる」という線形関係が成り立たない。

(3)

平滑化を強くすると測定ノイズや細かな変動を抑えやすい。一方、急な空転・滑走変化の検出が遅れやすくなる。検出の安定性と応答速度のトレードオフがある。

(4)

トルクを下げた後に車輪状態が基準側へ戻ったかを確認しなければ、必要以上にトルクを下げ続けたり、まだ滑っているのに早く戻したりする可能性がある。したがって状態再検出を含むフィードバックとして扱う。

### 検算

4項目とも、実車固有のしきい値・制御周期・抑制率・回復率を仮定せず、系列SPECで指定された非線形性、飽和、応答速度、フィードバックの一般論だけで説明している。

## 問14 閉ループ伝達関数からインパルス応答・ステップ応答を求める

教材用単位負帰還系で

`G_c(s)=3`

`G_p(s)=1/(s+1)`

とする。次を求めよ。

(1) 一巡伝達関数 `L(s)`

(2) 目標値から制御量までの閉ループ伝達関数 `G_y(s)`

(3) 単位インパルス入力に対する応答 `g_y(t)`

(4) 単位ステップ入力に対する応答 `y(t)`

(5) `t=0.50 s` の制御量

### 解答

(1)

`L(s)=G_c(s)G_p(s)=3/(s+1)`

である。

(2)

`G_y(s)=L(s)/{1+L(s)}`

`={3/(s+1)}/{1+3/(s+1)}`

`=3/(s+4)`

である。

(3)

単位インパルス入力では

`Y(s)=G_y(s)=3/(s+4)`

なので

`g_y(t)=3e^(-4t)`

となる。

(4)

単位ステップ入力では入力が `1/s` なので

`Y(s)=3/{s(s+4)}`

`=3/4×{1/s-1/(s+4)}`

したがって

`y(t)=3/4(1-e^(-4t))`

である。

(5)

`t=0.50 s` を代入して

`y(0.50)=3/4(1-e^-2)`

`≒0.6485`

となる。

### 検算

`t→∞` では `y(t)→3/4`。これは閉ループ伝達関数の直流ゲイン

`G_y(0)=3/4`

と一致する。

## 問15 トルク操作の飽和と一次遅れを区別する

教材用アクチュエータについて、正規化トルク指令 `u` の許容範囲を `0≤u≤1` とし、飽和後の指令を `u_s` とする。動特性は教材用一次遅れ

`G_a(s)=1/(0.20s+1)`

で表す。

空転検出前に制御器が `u=1.20` を要求し、その後 `t=0` で `u=0.40` へ変更したとする。`t=0` 直前にはアクチュエータ出力が飽和後指令に十分追従していたものとする。

次を求めよ。

(1) 空転検出前の飽和後指令 `u_s`

(2) `t=0` 直後からのアクチュエータ出力 `y(t)`

(3) 出力が `y=0.50` まで低下する時刻

(4) この例で「飽和」と「応答速度」が別の性質であることを説明せよ。

### 解答

(1)

許容上限が1なので

`u=1.20` に対して

`u_s=1.00`

である。

(2)

時定数は `0.20 s`、初期値は `y(0)=1.00`、新しい定常値は `0.40` である。したがって一次遅れ応答は

`y(t)=0.40+(1.00-0.40)e^(-t/0.20)`

`=0.40+0.60e^(-5t)`

となる。

(3)

`0.50=0.40+0.60e^(-5t)`

より

`e^(-5t)=1/6`

したがって

`t=ln6/5≒0.358 s`

である。

(4)

飽和は、制御器の要求値 `1.20` が許容上限1を超えても実指令が1で頭打ちになる非線形な制限である。一方、応答速度は、指令が許容範囲内へ変わった後もアクチュエータ出力が時定数に従って有限時間で追従する動特性である。

### 検算

`t=0` では `y(0)=0.40+0.60=1.00`、`t→∞` では `y(t)→0.40` となり、初期値・最終値とも設定条件と一致する。
