# 解説source本文

## §1 電験で問うメカトロニクス

### 1.1 このテーマで何を解けるようにするか

メカトロニクスは、機械だけ、電気だけ、制御だけを別々に扱う分野ではない。電験二種一次では、検出するセンサ、判断する制御部、実際に機械を動かすアクチュエータの役割と組合せが問われる。二次では、同じ閉ループをブロック線図として表し、伝達関数と時間応答を計算する。

本テーマでは再粘着制御を例に、次の流れを一続きで理解する。

`車輪状態を測る → 状態を判断する → トルクを変える → 車輪状態が変わる → 再び測る`

一次では「何を測る装置か」「何を操作する装置か」「シーケンスかフィードバックか」を識別できること、二次では「閉ループ伝達関数を作る → 入力を掛ける → 逆ラプラス変換する → 指定時刻を代入する」ことが到達点である。

### 1.2 メカトロニクスの基本構成

一般的な閉ループは次の要素で整理する。

| 要素 | 役割 | 再粘着制御での一般的な対応 |
|---|---|---|
| センサ | 物理量を電気信号へ変換する | 車輪回転速度などを検出する |
| 制御演算部 | 測定値と目標・基準を比較し操作量を決める | 空転・滑走状態を判断しトルク指令を変更する |
| アクチュエータ | 電気的な指令を機械的作用へ変える | 主電動機の発生トルクを変える |
| 制御対象 | 操作によって状態が変化する対象 | 車輪・駆動系・車両 |
| フィードバック | 出力側の状態を入力側へ戻す | 変化した車輪状態を再検出する |

アクチュエータは「センサの反対側」とだけ覚えず、制御器から受けた信号に従って力、トルク、変位などを発生させる要素と理解する。電動機やサーボモータは代表的な電気式アクチュエータである。

### 1.3 シーケンス制御とフィードバック制御

シーケンス制御は、あらかじめ決めた順序・条件に従って動作を進める。現在の出力値と目標値の偏差を常時小さくすること自体が本質ではない。

フィードバック制御は、出力側の状態を検出して入力側へ戻し、その偏差などに応じて操作量を修正する。再粘着では車輪状態を検出し、その結果で主電動機トルクを変え、変化後の車輪状態を再び検出するため、中心となる考え方はフィードバックである。

ただし「状態検出後にトルクを下げ、回復を確認して戻す」という段階的処理は論理的には状態遷移を持つ。ここで実車の内部ロジックを推測してシーケンス表を作ってはならない。

## §2 再粘着制御の基本構成

### 2.1 観測量と操作量を分ける

再粘着制御を考えるときは、まず測る量と動かす量を混同しない。

- 観測量: 車輪角速度 `ω [rad/s]`、車輪周速度 `v_w [m/s]`、その変化率など
- 基準量: 車体側の基準速度 `v_ref [m/s]` など
- 操作量: 主電動機トルク指令など
- 制御対象: 車輪・駆動系とレールとの粘着状態

車輪半径を `r [m]` とすると、車輪周速度は

`v_w = rω`

である。基準速度との差を教材上

`Δv = v_w - v_ref`

と置けば、力行中に `Δv` が正方向へ大きくなる状態は空転を疑う材料になる。一方、制動中に車輪周速度が基準速度より小さくなる状態は滑走を疑う材料になる。

`Δv` の具体的なしきい値や `v_ref` の作り方は車両方式ごとの設計事項であり、公開根拠なしに実車仕様へ置き換えない。

### 2.2 一般モデルの信号の流れ

本教材では次の一般モデルだけを使う。

`車輪速度検出 → 状態推定 → 空転・滑走判定 → トルク抑制 → 車輪状態変化 → 回復確認 → トルク回復`

この流れは、再粘着という現象をメカトロニクスとして理解するための教材用一般モデルである。個別新幹線系列の制御周期、判定ロジック、抑制率、回復率を示すものではない。

## §3 車輪速度検出とセンサ

### 3.1 回転を電気信号に変える

車輪速度を制御に使うには、回転という機械量を制御器が扱える電気信号へ変換する必要がある。これが回転センサの役割である。

ロータリエンコーダは回転に応じたパルス列を出力する。1回転あたりの有効カウント数を `P [count/rev]`、時間窓 `Δt [s]` に数えたパルス数を `N [count]` とすると、平均回転速度は

`n = 60N/(PΔt) [min^-1]`

角速度は

`ω = 2πN/(PΔt) [rad/s]`

で求められる。ここで `P` は実際に計数する立上り・立下りを含めた「有効カウント数」と定義して使う。

### 3.2 2相信号で回転方向を読む

インクリメンタル形エンコーダでは、位相をずらしたA相・B相を用いる構成がある。A相がB相より先行するか、B相がA相より先行するかで回転方向を判別できる。パルスを累積すれば回転角、一定時間内のパルス数から回転速度を求められる。

電験では「回転速度」「回転方向」「回転角」を同じセンサからどう取り出すかを関係付けて理解する。

### 3.3 センサ原理と物理量を対応させる

センサ名を単独で暗記せず、何を電気量へ変換しているかで整理する。

| 原理 | 入力物理量の例 | センサ例 | 出力として扱う電気量の例 |
|---|---|---|---|
| 磁気 | 磁界・磁束の変化 | ホール素子、磁気抵抗素子など | 電圧・抵抗変化 |
| 光電 | 光量・遮光状態 | フォトダイオード、フォトトランジスタなど | 光電流・電圧 |
| 回転パルス | 回転角・回転速度 | ロータリエンコーダ | パルス列 |

本テーマではA-D変換器方式の詳細へは進まない。

### 3.4 基礎例題: パルス数から回転速度を求める

教材用仮定値として、エンコーダの有効カウント数を `P=2048 count/rev`、`Δt=0.10 s` の間に `N=512 count` を観測したとする。

回転速度は

`n = 60×512/(2048×0.10) = 150 min^-1`

角速度は

`ω = 2π×512/(2048×0.10) = 5π ≒ 15.7 rad/s`

である。

検算として `150 min^-1 = 2.5 rev/s` だから、`ω=2π×2.5=5π rad/s` と一致する。

頻出ミスは、`min^-1` と `s^-1` の換算で60を逆に掛けること、1回転あたりパルス数と有効カウント数を混同することである。

## §4 車輪速度から加速度を推定する

### 4.1 差分で速度変化率を求める

連続時間なら加速度は速度の時間微分である。

`a = dv/dt`

ディジタル制御では連続な微分をそのまま得るのではなく、時刻 `k` と `k-1` の測定値から差分で近似できる。

`a_w[k] ≒ {v_w[k]-v_w[k-1]}/Δt`

`v_w=rω` なので

`a_w[k] ≒ r{ω[k]-ω[k-1]}/Δt`

とも書ける。

これは「車輪周速度の変化率」であり、空転・滑走中に車輪と車体が同じ運動をしていないときは車体加速度そのものではない。

### 4.2 教材用計算例

教材用仮定値として `r=0.43 m`、`Δt=0.05 s`、車輪角速度が `40 rad/s` から `42 rad/s` へ変化したとする。

`a_w ≒ 0.43×(42-40)/0.05 = 17.2 m/s^2`

この値を見て直ちに「車体が17.2 m/s²で加速した」としてはいけない。車輪側の変化率が大きいことは空転検出に使える情報になり得るが、車体速度・他軸速度・指令状態などとの比較が必要である。

### 4.3 差分と応答速度

差分は測定値の小さな変動も強調する。観測時間を長くしたり平滑化したりすれば変動を抑えやすいが、その分だけ急な状態変化の検出は遅くなる。したがって検出器は「ノイズを抑えること」と「早く変化を捉えること」の両立が必要になる。

本教材では特定のフィルタ形式やサンプリング周期を実車仕様として置かない。

## §5 空転・滑走と粘着

### 5.1 粘着力には上限がある

鉄道車両が加減速できるのは、車輪とレールの接触部で接線方向の力を伝えられるからである。この伝達力には上限があり、輪重を `N [N]`、有効な粘着係数を `μ` とした単純化では、最大伝達力の目安を

`F_adh,max ≒ μN`

と表せる。

ただし `μ` を常に一定の材料定数として扱ってはいけない。接触状態、速度、水分などの影響を受け、車輪とレールの相対運動に対する伝達力の関係は非線形である。本テーマではこの式を「一定値の厳密な実車モデル」ではなく、粘着限界の存在を理解する近似として使う。

### 5.2 空転

力行時、主電動機が車輪へ与えるトルクに対して接触部が十分な力を伝えられなくなると、車輪の回転だけが車体の進みより速くなる。これを空転と呼ぶ。

車輪の回転運動を簡略化して

`J dω/dt = T_m - rF_t`

と書く。`J [kg·m^2]` は車輪・駆動系の等価慣性、`T_m [N·m]` は駆動トルク、`F_t [N]` は接触部が実際に伝える接線力である。

`T_m` が大きいのに `F_t` が粘着限界で増えにくくなると、余ったトルクが `dω/dt` を大きくし、車輪速度が急上昇する。これが加速度推定を空転検出へ使える物理的理由である。

### 5.3 滑走

制動時は逆に、制動トルクが接触部で伝えられる限界を超えると、車輪回転速度が車体速度に対応する値より過度に低くなる。これを滑走と呼ぶ。

空転と滑走を「どちらも車輪が滑る」で一括せず、力行時と制動時、車輪周速度が基準速度より大きい側か小さい側かを区別する。

### 5.4 頻出ミス

- `v_w=rω` の `r` を直径と取り違えない。
- 車輪周速度の変化率を、そのまま車体加速度としない。
- 粘着係数を常に一定の実車値として扱わない。
- 空転と滑走の符号関係を逆にしない。

## §6 トルク抑制から再粘着まで

### 6.1 なぜトルクを下げるのか

空転中に駆動トルクをそのまま維持すると、粘着限界を超えた状態が続き、車輪回転速度がさらに増える可能性がある。そこで一般モデルでは、空転を検出したら主電動機トルクを一時的に抑える。

`トルク抑制 → 車輪の過大な角加速度を減らす → 車輪とレールの相対運動を小さくする → 粘着状態へ戻る`

という因果関係で理解する。

滑走時も考え方は同様で、制動トルクを調整して車輪回転を回復させる。

### 6.2 一般的な再粘着フィードバック

教材用一般モデルは次の4段階とする。

1. 車輪速度・変化率などから異常状態を検出する。
2. トルク指令を抑制する。
3. 車輪状態が基準側へ戻ったことを確認する。
4. トルクを再び回復させる。

重要なのは、トルクを一度下げて終わりではなく、状態を再検出しながら回復操作へつなげる点である。

### 6.3 センサとアクチュエータを一つのループで見る

センサが車輪速度を測っても、制御部が判断してアクチュエータへ操作量を出さなければ制御にはならない。一方、アクチュエータだけでトルクを変えても、結果を再検出しなければ閉ループにはならない。

再粘着は

`センサ → 制御演算 → インバータ・主電動機 → 車輪 → センサ`

という閉ループとして捉える。

### 6.4 複合例題: 観測値から操作の方向を判断する

教材用モデルで、力行中に基準速度 `v_ref` に対して車輪周速度 `v_w` が上側へ離れ、同時に `a_w` が急増したとする。

1. `Δv=v_w-v_ref` が正方向へ増えているため、空転を疑う。
2. `a_w` の急増は、駆動トルクの一部が車体加速ではなく車輪回転加速へ回っている可能性を示す。
3. 一般的な再粘着操作として、駆動トルクを増やすのではなく抑制側へ動かす。
4. その後、`v_w` が基準側へ戻ることを観測してからトルク回復へ移る。

ここでは「何km/h差で判定するか」「何％トルクを下げるか」は与えていない。そこを勝手に補う必要はない。

## §7 非線形性・飽和・応答速度

### 7.1 粘着は非線形である

制御対象が線形なら、入力を2倍にすれば出力も常に2倍になる。しかし粘着力は車輪とレールの相対運動に対して単純な比例関係を保たない。小さなすべり領域では伝達力が増えても、限界を超えると同じ比率では増えず、条件によっては低下する。

したがって、再粘着制御を一つの一定ゲインだけで完全に表すことはできない。本テーマで伝達関数を使う部分は、二次試験の線形フィードバック解析を学ぶための局所的・一般的モデルとして扱う。

### 7.2 飽和

アクチュエータには出せる力やトルクに上限・下限がある。制御器が大きなトルク指令を出しても、主電動機や電力変換器が実際に出せる範囲を超えれば出力は飽和する。

教材用に

`T_out = sat(T_cmd)`

と書けば、`sat` は上限・下限で切り取る非線形要素を表す。飽和中は「指令を2倍にすれば出力も2倍」という線形関係が成立しない。

実車のトルク上限値は公開根拠なしに置かない。

### 7.3 応答速度

再粘着では、状態が変わってから操作量が変わるまでに

- センサで検出する時間
- 制御演算に要する時間
- インバータ・主電動機のトルクが変化する時間
- 車輪状態が変化する時間

がある。

検出・操作が遅ければ空転・滑走が大きくなる余地が増える。一方、測定値の変動へ過敏に反応すれば不要なトルク変動を生む。したがって応答速度は「速いほど無条件に良い」ではなく、検出の確かさと操作の安定性を合わせて考える。

## §8 二次試験型のフィードバック応答

### 8.1 閉ループ伝達関数を作る

単位負帰還で、補償器を `G_c(s)`、制御対象を `G_p(s)` とする。一巡伝達関数は

`L(s)=G_c(s)G_p(s)`

である。目標値 `R(s)` から制御量 `Y(s)` までの閉ループ伝達関数は

`G_y(s)=Y(s)/R(s)=L(s)/{1+L(s)}`

となる。

二次試験では、ブロック線図からいきなり最終式を書かず、まず前向き経路を掛け合わせ、次に `1+L(s)` を作り、分母を整理する。

### 8.2 PI形補償器を含む一般形

試験で扱いやすい一般形として

`G_c(s)=K_c(s+z)/s`

`G_p(s)=1/(s+p)`

を考える。ここで `K_c>0, z>0, p>0` とする。

一巡伝達関数は

`L(s)=K_c(s+z)/{s(s+p)}`

閉ループ伝達関数は

`G_y(s)=K_c(s+z)/{s(s+p)+K_c(s+z)}`

`=K_c(s+z)/{s^2+(p+K_c)s+K_c z}`

となる。

この形まで整理したら、分母を因数分解または解の公式で極を求め、部分分数分解して時間応答へ移る。

### 8.3 インパルス応答

単位インパルス入力なら `R(s)=1` なので

`Y(s)=G_y(s)`

である。したがってインパルス応答は

`g_y(t)=L^-1{G_y(s)}`

で求める。

例えば分数が

`G_y(s)=A/(s+a)+B/(s+b)`

まで分解できれば

`g_y(t)=Ae^(-at)+Be^(-bt)`

となる。

### 8.4 単位ステップ応答と指定時刻の値

単位ステップ入力では

`R(s)=1/s`

だから

`Y(s)=G_y(s)/s`

となる。これを部分分数分解し、逆ラプラス変換して `y(t)` を求め、最後に指定時刻を代入する。

二次試験型の解法手順は次で固定する。

1. `L(s)=G_c(s)G_p(s)` を作る。
2. `G_y(s)=L(s)/(1+L(s))` を作る。
3. 分母・分子を多項式に整理する。
4. インパルスなら `Y(s)=G_y(s)`、ステップなら `Y(s)=G_y(s)/s` とする。
5. 部分分数分解する。
6. 逆ラプラス変換する。
7. 指定時刻があれば最後に代入する。
8. 初期値・定常値が物理的に不自然でないか検算する。

### 8.5 本試験標準例題

教材用モデルとして、単位負帰還系の閉ループ伝達関数が

`G_y(s)=3/(s+3)`

まで求まったとする。これは実車再粘着制御の伝達関数ではない。

単位インパルス入力に対して

`g_y(t)=3e^(-3t)`

単位ステップ入力に対して

`Y(s)=3/{s(s+3)}=1/s-1/(s+3)`

したがって

`y(t)=1-e^(-3t)`

である。

指定時刻 `t=t_0` では

`y(t_0)=1-e^(-3t_0)`

と最後に代入する。ここで必要なのは数値暗記ではなく、「インパルスは閉ループ伝達関数そのものを逆ラプラス、ステップはさらに `1/s` を掛ける」という入力の違いである。

### 8.6 二次試験での頻出ミス

- 負帰還なのに分母を `1-L(s)` とする。
- `G_c(s)` と `G_p(s)` を直列なのに足す。
- 単位ステップ入力の `1/s` を掛け忘れる。
- インパルス応答とステップ応答を取り違える。
- 部分分数分解後、逆ラプラス変換せず指定時刻を `s` へ代入する。

## §9 新幹線への接続

### 9.1 公開論文で確認できる高速新幹線の例

電気学会論文誌Dの1996年論文「高速新幹線電車の空転・再粘着制御―各駆動軸電動機個別制御方式の場合―」では、JR東日本・東芝関係者が、STAR21の953形試験車を用いた高速域の空転・再粘着試験を報告している。

論文抄録で公開されている範囲では、200〜300 km/hで空転を観測して制御パラメータを調整し、基準速度との差が1%以内の段階で空転検知が可能であったこと、再粘着には電動機電流を急減させる速いトルク低減が必要であったこと、再通電前の約1秒の待ち時間と、時定数4秒の指数関数的な電流回復が有効だったことが報告されている。

出典:
- 関本正直ほか「高速新幹線電車の空転・再粘着制御―各駆動軸電動機個別制御方式の場合―」電気学会論文誌D, 116巻7号, 1996, pp.749-757
- https://www.jstage.jst.go.jp/article/ieejias1987/116/7/116_7_749/_article/-char/ja/

これらはSTAR21 953形の公開試験結果であり、現在のN700S等へ同じ検出差、待ち時間、回復時定数をそのまま適用してよいことを意味しない。本教材では「速度検出 → 空転判定 → トルク抑制 → 再粘着確認 → トルク回復」という制御の因果関係を具体化する実例としてのみ使う。

### 9.2 電験への戻し方

新幹線固有の数値を覚えることは試験対策の中心ではない。公開実例から電験へ戻すと、対応は次のようになる。

| 新幹線・鉄道の現象 | 電験で問われる一般論 |
|---|---|
| 車輪速度を測る | センサ、ロータリエンコーダ、物理量→電気信号 |
| 空転状態を判断する | フィードバック、測定値と基準値の比較 |
| 主電動機トルクを下げる | アクチュエータ、操作量 |
| 粘着限界を超える | 非線形性、飽和に近い制限要素 |
| トルクを戻して追従させる | 応答速度、閉ループ時間応答 |

## 公式・解法まとめ

### 一次試験

- センサ: 物理量を電気信号へ変換する。
- アクチュエータ: 制御信号を力・トルク・変位などの機械作用へ変換する。
- ロータリエンコーダ: パルス数から回転速度、累積数から回転角、2相信号の位相関係から回転方向を扱える。
- シーケンス制御: 決められた順序・条件で動作を進める。
- フィードバック制御: 出力側の状態を戻し、偏差等に応じて操作量を修正する。

### 車輪速度・加速度

`v_w=rω`

`n=60N/(PΔt)`

`ω=2πN/(PΔt)`

`a_w[k]≒{v_w[k]-v_w[k-1]}/Δt`

### 二次試験

`L(s)=G_c(s)G_p(s)`

`G_y(s)=L(s)/{1+L(s)}`

インパルス:

`Y(s)=G_y(s)`
