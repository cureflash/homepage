# 教材で欠落不可の説明

1. メカトロニクス機器を「センサ → 制御演算 → アクチュエータ → 制御対象 → センサ」の閉ループとして整理し、各要素の役割を説明する。
2. シーケンス制御とフィードバック制御を区別し、再粘着では車輪状態を検出してトルク指令を変えるフィードバックが中心となることを説明する。ただし実車の非公開ロジックは推定しない。
3. 車輪速度検出に必要な「回転速度を電気信号へ変換する」というセンサの役割を説明し、ロータリエンコーダのパルス・2相信号から速度・方向・角度を読み取る一般原理へ接続する。実車新幹線のセンサ方式とは断定しない。
4. 加速度推定は、時刻の異なる車輪速度から速度変化率を求めるという一般的な差分の考え方まで説明する。未確認の実車サンプリング周期や判定しきい値は置かない。
5. 空転と滑走を、車輪周速度と車体側の基準速度とのずれとして区別する。力行時の過大な車輪周速度側を空転、制動時の過小な車輪周速度側を滑走として説明し、粘着限界を超えたときに生じる現象として扱う。
6. 再粘着の一般的な制御の流れを「状態検出 → トルク抑制 → 車輪状態の回復確認 → トルク回復」として示す。この流れは教材上の一般モデルであり、実車アルゴリズムとして断定しない。
7. 粘着特性の非線形性、トルク指令・アクチュエータの飽和、検出から操作までの応答速度が制御結果へ影響することを定性的に説明する。数値特性は公開資料がない限り実車値化しない。
8. R07二次問4へ接続できるよう、一般的な負帰還系で閉ループ伝達関数を作り、時間応答を求め、指定時刻の制御量を計算する手順を再利用できる形で示す。Topic 17〜20の内容を必要以上に再展開しない。
9. 一次試験ではセンサ・アクチュエータ・制御方式の語句選択に対応し、二次試験ではブロック線図→伝達関数→時間応答の途中式を省略しない。
10. 新幹線への接続は公開資料で確認できる事実だけを実車記述とし、センサ方式、検出しきい値、制御周期、トルク抑制率・回復率など確認できない値は教材用モデルと明示する。
