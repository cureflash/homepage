# 教材で欠落不可の説明

1. 目標値 `R(s)`、出力 `Y(s)`、偏差 `E(s)` を区別し、負帰還では「目標値－フィードバック量」が偏差になること。
2. 制御器、インバータ・モーター・車両を表すプラント、速度センサをブロックとして読み、各ブロックの入力と出力を対応付けること。
3. 伝達関数を「入力に対する出力の比」として定義し、各ブロックの入出力から式を立てられること。
4. 直列接続では各ブロックの伝達関数を掛け合わせること。
5. 前向き伝達関数を `G(s)`、フィードバック伝達関数を `H(s)` とした負帰還系について、閉ループ伝達関数を `G(s)/(1+G(s)H(s))` として導けること。
6. 同じ負帰還系で、目標値から偏差までの伝達関数を `1/(1+G(s)H(s))` として導けること。
7. 外乱は印加位置を先に確認し、他の入力を0として重ね合わせ、外乱から求める信号までの伝達関数をブロック線図から導くこと。
8. 新幹線側では、`速度指令 → 制御器 → インバータ → モーター → 車両 → 速度センサ → フィードバック` を試験の一般的なブロック線図へ対応付けること。未確認の実車制御定数は使わないこと。
