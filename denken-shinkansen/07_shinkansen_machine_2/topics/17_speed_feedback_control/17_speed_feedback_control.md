# 解説source本文

## 1. このテーマで電験は何を問うか

このテーマで最優先するのは、ブロック線図を見て「どの信号がどこへ入り、どの伝達関数を通って、どこへ戻るか」を式にできることである。二種二次では、完成した公式を暗記して代入するだけではなく、加え合わせ点とブロックの関係から伝達関数を自力で導く必要がある。

本テーマでは次の6種類を解けることを到達点とする。

1. 各ブロックの入力と出力を読み、伝達関数を定義する。
2. 直列ブロックを積でまとめる。
3. 開ループ時の経路上の伝達関数を求める。
4. 負帰還系の閉ループ伝達関数を導く。
5. 目標値から偏差までの伝達関数を導く。
6. 外乱の印加位置を読み、外乱から偏差または出力までの伝達関数を導く。

Topic 18以降で扱う時間応答、PID、安定判別、周波数応答はここでは扱わない。

## 2. まず信号とブロックを区別する

標準的な負帰還系を次の記号で表す。

| 記号 | 意味 |
|---|---|
| `R(s)` | 目標値。速度制御なら速度指令に対応する |
| `E(s)` | 偏差。目標値とフィードバック量との差 |
| `U(s)` | 制御器からプラントへ与える操作側の信号 |
| `Y(s)` | 制御対象の出力。速度制御なら車両速度に対応する |
| `B(s)` | センサを通って戻るフィードバック量 |
| `G(s)` | 前向き経路の伝達関数 |
| `H(s)` | フィードバック経路・センサの伝達関数 |
| `D(s)` | 外乱 |

負帰還では加え合わせ点の式が最初の出発点になる。

`E(s) = R(s) - B(s)`

フィードバック量は

`B(s) = H(s)Y(s)`

である。したがって

`E(s) = R(s) - H(s)Y(s)`

となる。ここで符号を逆にすると、その後の分母の符号まで誤る。

## 3. 伝達関数とは何か

あるブロックの入力を `X(s)`、出力を `Y(s)` とすると、零初期条件のもとで伝達関数 `G(s)` は

`G(s) = Y(s) / X(s)`

で定義される。したがってブロックの式は

`Y(s) = G(s)X(s)`

と書ける。

試験では「式の形」だけでなく、分子が出力、分母が入力であることを毎回確認する。伝達関数は扱う信号の種類によって単位を持つことがあり、必ずしも無次元ではない。

## 4. 直列接続は掛け算

入力 `X(s)` が `G1(s)`、`G2(s)` を順番に通るとする。

`Z(s) = G1(s)X(s)`

`Y(s) = G2(s)Z(s)`

よって

`Y(s) = G2(s)G1(s)X(s)`

したがって全体の伝達関数は

`Y(s)/X(s) = G1(s)G2(s)`

である。

ブロックが3個以上でも同じで、直列経路上の伝達関数をすべて掛け合わせる。二種二次では、まずこの積を一つの `G(s)` と置いてから帰還計算へ進むと式が崩れにくい。

## 5. 開ループ伝達関数を読む

ループを閉じる前に、指定された入力から出力まで経路をたどる。制御器 `C(s)` とプラント `P(s)` が直列なら前向き経路は

`G(s) = C(s)P(s)`

である。

フィードバック要素 `H(s)` まで含めて一周する積は

`L(s) = G(s)H(s)`

となる。問題文で「開ループ伝達関数」「一巡伝達関数」などの呼び方が使われる場合は、名称だけで決めず、どの二点間の比を求めるか、ループをどこで開いているかを図で確認して経路上のブロックを掛ける。

## 6. 負帰還系の閉ループ伝達関数

前向き経路を `G(s)`、フィードバック経路を `H(s)` とする。

`Y(s) = G(s)E(s)`

`E(s) = R(s) - H(s)Y(s)`

第2式を第1式へ代入すると

`Y(s) = G(s){R(s) - H(s)Y(s)}`

整理して

`Y(s) + G(s)H(s)Y(s) = G(s)R(s)`

`Y(s){1 + G(s)H(s)} = G(s)R(s)`

したがって目標値から出力までの閉ループ伝達関数は

`Y(s)/R(s) = G(s) / {1 + G(s)H(s)}`

である。

負帰還なので分母は `1 + G(s)H(s)` になる。ここを `1 - G(s)H(s)` とする誤りが頻出する。

## 7. 目標値から偏差までの伝達関数

偏差を求める問題では、出力 `Y(s)` ではなく `E(s)` を分子にする。

`E(s) = R(s) - H(s)Y(s)`

かつ

`Y(s) = G(s)E(s)`

なので

`E(s) = R(s) - H(s)G(s)E(s)`

`E(s){1 + G(s)H(s)} = R(s)`

したがって

`E(s)/R(s) = 1 / {1 + G(s)H(s)}`

となる。

単位負帰還なら `H(s)=1` なので

`E(s)/R(s) = 1 / {1 + G(s)}`

である。閉ループ出力 `Y/R` と偏差 `E/R` を取り違えないことが重要である。

## 8. 外乱は「印加位置」を先に読む

外乱問題では、公式を先に選ばず、外乱 `D(s)` がどの加え合わせ点へ入っているかを確認する。次に、求めたい入力以外を0とする。

たとえば前向き経路を `G1(s)` と `G2(s)` に分け、外乱 `D(s)` がその間へ加算される負帰還系を考える。

`Y(s) = G2(s){G1(s)E(s) + D(s)}`

外乱から偏差までを求めるときは目標値を `R(s)=0` とするので

`E(s) = -H(s)Y(s)`

である。代入すると

`E(s) = -H(s)G2(s){G1(s)E(s) + D(s)}`

整理して

`E(s){1 + G1(s)G2(s)H(s)} = -H(s)G2(s)D(s)`

したがって

`E(s)/D(s) = -H(s)G2(s) / {1 + G1(s)G2(s)H(s)}`

となる。

同じ条件で外乱から出力までを求めれば

`Y(s)/D(s) = G2(s) / {1 + G1(s)G2(s)H(s)}`

である。

外乱が出力端へ直接加わるなら式は変わる。したがって外乱問題は「外乱位置を確認 → 他入力を0 → 信号式を立てる」の順で処理し、外乱用の式を丸暗記しない。

## 9. 新幹線の速度制御を一般的なブロック線図へ置き換える

系列SPECの基本構成は

`速度指令 → 制御器 → インバータ → モーター → 車両 → 速度センサ → フィードバック`

である。

電験の標準ブロック線図へ置き換えると、速度指令が `R(s)`、速度センサから戻る量が `B(s)`、両者の差が `E(s)`、制御器から車両までの前向き経路が `G(s)`、速度センサが `H(s)`、車両速度が `Y(s)` に対応する。

ここで必要なのは実車の制御定数を暗記することではなく、複数の実機要素を一つまたは複数のブロックとして整理し、入出力関係を伝達関数で表す考え方である。本教材では一次資料で確認していない新幹線の制御ゲイン、時定数、センサ定数を実車値として用いない。

## 10. 問題を見たときの解法手順

1. 求める比を確認する。`Y/R`、`E/R`、`E/D` など分子・分母を先に固定する。
2. 加え合わせ点の `+` と `-` を確認する。
3. 直列ブロックを積でまとめる。
4. 外乱問題なら、外乱の印加位置を確認し、求める入力以外を0にする。
5. 各信号について `出力 = 伝達関数 × 入力` の式を書く。
6. 求めたい出力以外の中間信号を消去する。
7. 求める比の形へ整理する。
8. 分母が負帰還なら `1 + ループ積` になっているか、経路上のブロックを落としていないかを検算する。

## 11. 基礎例題 — 直列ブロックを一つにまとめる

制御器

`C(s) = 2`

プラント

`P(s) = 3/(s+4)`

が直列接続されている。制御器入力を `E(s)`、プラント出力を `Y(s)` とする。`Y(s)/E(s)` を求める。

### 解法

求める経路には `C(s)` と `P(s)` が直列に並ぶので掛け合わせる。

`Y(s)/E(s) = C(s)P(s)`

`= 2 × 3/(s+4)`

`= 6/(s+4)`

ここでは時間応答を求めず、直列経路の伝達関数を積でまとめるところまでを扱う。
## 12. 本試験標準例題 — 閉ループ出力と偏差を分ける

前向き伝達関数

`G(s) = 6/{(s+1)(s+2)}`

フィードバック伝達関数

`H(s) = 1/2`

の負帰還系について、`Y(s)/R(s)` と `E(s)/R(s)` を求める。

### 解法1: ループ積を作る

`G(s)H(s) = 3/{(s+1)(s+2)}`

### 解法2: 目標値から出力まで

`Y(s)/R(s) = G(s)/{1+G(s)H(s)}`

`= [6/{(s+1)(s+2)}] / [1 + 3/{(s+1)(s+2)}]`

分母分子に `(s+1)(s+2)` を掛けると

`Y(s)/R(s) = 6 / {(s+1)(s+2)+3}`

`= 6/(s^2+3s+5)`

### 解法3: 目標値から偏差まで

`E(s)/R(s) = 1/{1+G(s)H(s)}`

`= {(s+1)(s+2)} / {(s+1)(s+2)+3}`

`= (s^2+3s+2)/(s^2+3s+5)`

同じブロック線図でも、出力を求めるのか偏差を求めるのかで分子が異なる。

## 13. 複合・ひっかけ例題 — 外乱位置を読む

負帰還系で

`G1(s) = 2/(s+1)`

`G2(s) = 5/(s+2)`

`H(s) = 1`

とする。外乱 `D(s)` は `G1(s)` の後、`G2(s)` の前へ加算される。目標値は `R(s)=0` とし、`E(s)/D(s)` を求める。

### 解法1: 外乱位置を含む式を書く

`Y(s) = G2(s){G1(s)E(s)+D(s)}`

単位負帰還で `R(s)=0` だから

`E(s) = -Y(s)`

### 解法2: `Y(s)` を消去する

`E(s) = -G2(s){G1(s)E(s)+D(s)}`

`E(s){1+G1(s)G2(s)} = -G2(s)D(s)`

したがって

`E(s)/D(s) = -G2(s)/{1+G1(s)G2(s)}`

### 解法3: 数式を整理する

`G1(s)G2(s) = 10/{(s+1)(s+2)}`

よって

`E(s)/D(s)`

`= -[5/(s+2)] / [1+10/{(s+1)(s+2)}]`

`= -5(s+1)/{(s+1)(s+2)+10}`

`= -5(s+1)/(s^2+3s+12)`

外乱の前にある `G1(s)` を分子へ入れてはいけない。外乱は `G1(s)` を通過せず、`G2(s)` だけを通って出力側へ進むからである。

## 14. 頻出ミス

- `E(s)=R(s)-H(s)Y(s)` の符号を逆にする。
- `Y/R` と `E/R` を同じ式にする。
- 直列ブロックを足し算する。
- ループに含まれないブロックを `G(s)H(s)` へ入れる。
- 外乱位置を見ずに、どの問題でも同じ `E/D` の式を使う。
- 外乱問題で目標値 `R(s)` を0にせず、二つの入力を同時に残して式を複雑にする。
- 単位負帰還 `H(s)=1` と一般のセンサ `H(s)` を混同する。
- 「開ループ」という名称だけで経路を決め、問題が指定する入力・出力を確認しない。

## 16. 公式・解法まとめ
伝達関数:

`G(s) = 出力 / 入力`

直列接続:

`G_series(s) = G1(s)G2(s)…`

負帰還:

`E(s) = R(s) - H(s)Y(s)`

閉ループ出力:

`Y(s)/R(s) = G(s)/{1+G(s)H(s)}`

目標値から偏差:

`E(s)/R(s) = 1/{1+G(s)H(s)}`

外乱問題:

1. 外乱の印加位置を確認する。
2. 外乱以外の入力を0にする。
3. 各信号の式を立てる。
4. 中間信号を消去して `求める信号 / 外乱` を作る。
