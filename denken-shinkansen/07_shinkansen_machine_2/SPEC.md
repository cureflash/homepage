# 新幹線・電験二種「機械・制御」教材仕様書

## 1. 目的

新幹線車両の主変圧器、主電動機、主変換装置、回生ブレーキ、補機、蓄電池、速度制御、再粘着制御などを題材に、電験二種一次「機械」および二次「機械・制御」で必要となる電気機器、パワーエレクトロニクス、自動制御、メカトロニクスを学習する。

電験三種「機械」で扱った「何をしている機器か」という理解を、二種では以下へ発展させる。

- 等価回路
- フェーザ図
- 特性式の導出
- 速度―トルク特性
- 損失・効率・熱設計
- PWM波形・高調波
- 回生・四象限運転
- 過渡応答
- PID制御
- 安定判別
- メカトロニクス

新幹線側の物語は、0系→200系→300系→N700S→L0系という技術進化を軸にする。

---

## 2. 成果物

各テーマで以下を制作する。

- 解説プリント
- 練習プリント
- 解説画像PowerPoint
- 必要に応じて計算プログラム
- 必要に応じて計算結果CSV
- 必要に応じて特性曲線・波形・過渡応答グラフ

解説プリントでは実在する新幹線車両・主回路・機器を優先して扱う。

練習プリントは通常の電験二種問題とし、新幹線を題材にする必要はない。

実車・実機器の数値は出典付き実在値として扱い、資料値から算出した値は「計算値」、教材上設定した値は「仮定値」と明記する。

## 26. 計算プログラム・グラフの使用基準

二種機械では、手計算だけでは全体特性を理解しにくいテーマで計算プログラムを積極的に作成する。

優先対象は以下。

- 変圧器の負荷率―効率
- 直流機の速度―トルク
- 誘導機の速度―トルク
- PWM波形
- FFT・高調波
- V/f制御特性
- 半導体損失比較
- 回生電力
- ステップ応答
- PID応答
- ボード線図
- 総合走行シミュレーション

プログラムには入力値、使用式、単位、条件を明記し、同じ条件から再現可能にする。

グラフには以下を必須とする。

- タイトル
- 軸ラベル
- 単位
- 凡例
- 計算条件
- 実在値・計算値・仮定値の区別

プログラムを使っても、代表点の手計算、式の導出、単位確認を省略しない。

代表点は手計算または別方法で独立再計算する。

## 28. 三種機械との役割分担

三種機械は、

- 機器の役割
- 基本公式
- 基本計算

を中心とする。

二種機械は、

- 等価回路
- 特性式導出
- ベクトル・フェーザ
- 損失・熱
- 波形
- 過渡応答
- 制御系解析

を中心とする。

同じ300系を使う場合でも、三種では「なぜ誘導電動機・VVVFになったか」、二種では「等価回路からトルクや損失をどう導くか」を主題とする。

## 30. 練習プリント

- 等価回路から式を立てる
- 条件を整理する
- 導出過程を書く
- フェーザ・ブロック線図を読む
- 特性を文章で説明する
- 複数段階の計算を行う

新幹線を題材にする必要はない。
