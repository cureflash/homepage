# 問題

## 問1 基礎・一次型: 蒸気の状態変化

一定圧力のもとで水を加熱するときの記述として正しいものを選べ。

1. 飽和水が蒸発している間に与える熱は主として顕熱である。
2. 乾き飽和蒸気をさらに加熱すると過熱蒸気になる。
3. 湿り蒸気は液相を全く含まない。
4. 臨界点は飽和液線と飽和蒸気線が最も離れる点である。
5. T-s線図では横軸が絶対温度、縦軸が比エントロピーである。

## 問2 基礎・一次型: ランキンサイクルの熱効率

蒸気タービン仕事が `36 MJ/kg`、給水ポンプ仕事が `2 MJ/kg`、外部からの加熱量が `100 MJ/kg` である。熱効率として正しいものを選べ。

2. `34%`
3. `36%`
4. `38%`

## 問3 基礎・一次型: 所内率と外部利用可能出力

1. `2%`, `48 MW`
2. `4%`, `48 MW`
3. `4%`, `50 MW`
4. `4.17%`, `48 MW`
5. `25%`, `48 MW`

## 問4 基礎・一次型: 非常用電源

通常の所内交流電源を喪失した場合の考え方として正しいものを選べ。

1. 発電機出力がゼロなら保護・制御回路への直流給電も直ちに不要となる。
2. 蓄電池容量は負荷電流だけで決まり、停電継続時間を考慮しない。
3. 交流駆動が必要な重要補機には、非常用交流電源から給電する。
4. 主機停止後は全補機を一斉停止することが安全停止の原則である。
5. 非常用交流電源は通常運転中の発電端出力を増加させるために用いる。

## 問5 本試験標準・一次型: T-s線図

T-s線図と蒸気状態に関する記述として正しいものを選べ。

1. 可逆過程では `δq = T ds` であり、T-s線図上の過程下側の面積は単位質量当たり熱量に対応する。
2. 潜熱は、乾き飽和蒸気を過熱蒸気へするためだけに必要な熱である。
3. 飽和液線と飽和蒸気線の間では、必ず全量が液体である。
4. 臨界点より十分低い圧力でも、飽和水から乾き飽和蒸気になる間に温度は大きく単調上昇する。
5. T-s線図の面積は常に機械仕事を表し、熱量を表さない。

## 問6 本試験標準・一次型: 再熱・再生

ランキンサイクルの効率改善に関する記述として正しいものを選べ。

1. 再熱は、高圧タービンで膨張した蒸気を途中で再加熱してから低圧側で再び膨張させる。
2. 再熱の主目的は給水ポンプ仕事を増やすことである。
3. 再生は復水器出口の水を外部ヒータだけで加熱する方式で、タービン抽気は用いない。
4. 再生では給水温度を下げるほど外部加熱量が減少する。
5. タービン入口圧力を高めれば、排気湿り度を含む全ての性能が必ず改善する。

# 解答・完全解説

## 問1

正答: `2`

乾き飽和蒸気を同じ圧力帯でさらに加熱すると過熱蒸気になる。飽和水から蒸気へ相変化する際の熱は潜熱であり、湿り蒸気は液滴を含む二相状態である。臨界点は飽和液線と飽和蒸気線が合流する点。T-s線図は縦軸 `T`、横軸 `s` である。

## 問2

正答: `2`

熱効率は

`η_th = (W_t - W_p) / Q_in`

より、

`η_th = (36 - 2) / 100 = 0.34 = 34%`

タービン仕事だけを分子に置くと36%となり、ポンプ仕事を差し引けていない。

## 問3

正答: `2`

所内率は

`a = P_aux / P_g = 2 / 50 = 0.04 = 4%`

外部利用可能出力は

`P_out = P_g - P_aux = 50 - 2 = 48 MW`

所内率の分母は発電端出力である。

## 問4

正答: `3`

通常交流電源を失っても、安全停止・停止後処置に必要な負荷は残る。保護・制御などの直流重要負荷は蓄電池、交流駆動が必要な重要補機は非常用交流電源で維持する。蓄電池容量は負荷だけでなく必要継続時間も考慮する。

## 問5

正答: `1`

可逆過程では `δq = T ds` なので、T-s線図の過程下側の面積は単位質量当たり熱量に対応する。潜熱は相変化に使われる熱であり、飽和液線と飽和蒸気線の間は液相と蒸気相が共存する。臨界点より低圧の相変化中は飽和温度で進むため、温度が大きく単調上昇するわけではない。

## 問6

正答: `1`

再熱は高圧タービンで途中まで膨張した蒸気を再加熱し、低圧側で再膨張させる。後段の湿りを減らし、熱効率改善にも使われる。再生はタービン途中から抽気し、その熱で給水を加熱して外部から必要な加熱量を減らす。入口圧力上昇は熱効率改善方向へ働き得るが、排気蒸気が湿り側へ入りやすくなる場合がある。

## 問7

正答: `3`

まずタービン軸出力は

`P_t = 36 × 0.28 = 10.08 MW`

発電端出力は

`P_g = 10.08 × 0.96 = 9.6768 MW`

所内率5%を差し引いた外部利用可能出力は

`P_out = 9.6768 × 0.95 = 9.19296 MW`

車輪出力は

`P_wheel = 9.19296 × 0.97 × 0.95 × 0.98`

`= 8.3019 MW ≒ 8.30 MW`

所内率を後段機器効率と同じように扱うのではなく、まず発電端から所内消費を差し引く。

## 問8

正答: `2`

停止後もタービン車室やロータは高温である。静止状態で不均一に冷却すると熱偏心・曲がりを生じ得るので、ターニングギヤで低速回転させ均一冷却を図る。水素冷却発電機では、機内水素を抜き安全な圧力状態になるまで軸封部へ密封油を供給し、水素の機外漏えいを防ぐ必要がある。

## 問9

正答: `3`

速度調定率を小数で `R = 0.05` とすると、出力―周波数特性の傾きは

`K = P_n / (f_n R)`

`= 100 / (50 × 0.05) = 40 MW/Hz`

負荷が20 MW増加すると、速度設定を変えない一次調速だけでは

`Δf = -20 / 40 = -0.5 Hz`

したがって

`f = 50 - 0.5 = 49.5 Hz`

負荷増加時に周波数は低下する。

## 問10

正答: `4`

Aの傾きは

`K_A = 100 / (50 × 0.05) = 40 MW/Hz`

Bは

`K_B = 60 / (50 × 0.04) = 30 MW/Hz`

合計は `70 MW/Hz`。負荷35 MW増加に対し

`Δf = -35 / 70 = -0.5 Hz`

よって出力増加は

`ΔP_A = -K_A Δf = 20 MW`

`ΔP_B = -K_B Δf = 15 MW`

合計35 MWで負荷増加と一致する。

## 問11

(1) タービン軸出力

`P_t = 200 × 0.35 = 70 MW`

(2) 発電端出力

`P_g = 70 × 0.97 = 67.9 MW`

(3) 所内電力

`P_aux = 67.9 × 0.04 = 2.716 MW`

外部利用可能出力

`P_out = 67.9 - 2.716 = 65.184 MW`

(4) 総合効率

`η = 65.184 / 200 = 0.32592`

`η = 32.592% ≒ 32.6%`

熱効率、発電機効率、所内率は別段階の量なので、発電端出力と外部利用可能出力を区別する。

## 問12

(1) 再熱では、高圧タービンで途中まで膨張した蒸気を再加熱し、低圧側で再び膨張させる。これにより後段で蒸気が過度に湿るのを抑え、熱効率改善にも寄与する。

(2) 再生では、タービン膨張途中の蒸気を抽気し、その熱で給水を加熱する。蒸気発生器へ入る給水温度を高めることで、外部から追加すべき熱量を減らし、サイクル熱効率を改善する。

(3) タービン入口圧力を高めることは一般に平均加熱温度を高め、熱効率改善方向へ働く。一方、条件によっては膨張後の蒸気が湿り側へ入りやすくなるため、「圧力上昇なら全て改善」とは判断しない。

## 問13

(1) 発電機が停止しても保護・制御回路など安全停止・停止後処置に必要な直流負荷は残るため、蓄電池等の直流非常用電源が必要である。必要容量は負荷と必要継続時間を考える。

(2) ポンプや電動機など、交流で継続駆動する必要がある重要補機が存在するため、非常用ディーゼル発電機等の非常用交流電源が必要である。

(3) 停止後もタービン車室・ロータは高温である。ロータを静止させたまま不均一に冷却すると熱偏心・曲がりを生じ得る。したがってターニングギヤで一定時間低速回転させ、均一に冷却する。

(4) 水素冷却発電機では、停止後も機内に水素が残り得る。軸封部への密封油供給を失うと水素が機外へ漏れるおそれがある。機内水素を抜き圧力を安全な状態まで下げるまで密封油ポンプを継続運転する。

二次記述では単に機器名を挙げず、`残留状態 → 放置時の問題 → 継続運転目的` をつなげる。

## 問14

(1) 傾き

`K_A = 100 / (50 × 0.05) = 40 MW/Hz`

`K_B = 60 / (50 × 0.04) = 30 MW/Hz`

(2) 負荷は28 MW減少するので周波数は上昇する。

`ΔP_load = -28 MW`

線形速度調定特性では

`ΔP_A + ΔP_B = (K_A + K_B)(-Δf)`

したがって

`-28 = -70 Δf`

`Δf = +0.4 Hz`

新周波数は

`50 + 0.4 = 50.4 Hz`

(3) 各機出力変化

`ΔP_A = -40 × 0.4 = -16 MW`

`ΔP_B = -30 × 0.4 = -12 MW`

新出力は

A: `60 - 16 = 44 MW`

B: `40 - 12 = 28 MW`

(4)

`ΔP_A + ΔP_B = -16 - 12 = -28 MW`

系統負荷減少 `-28 MW` と一致する。

## 問15

(1) タービン軸出力

`P_t = 36 × 0.30 = 10.8 MW`

(2) 発電端出力

`P_g = 10.8 × 0.96 = 10.368 MW`

所内電力

`P_aux = 10.368 × 0.05 = 0.5184 MW`

外部利用可能出力

`P_out = 10.368 - 0.5184 = 9.8496 MW`

(3) 車輪出力

`P_wheel = 9.8496 × 0.97 × 0.95 × 0.98`

`= 8.8949 MW ≒ 8.895 MW`

(4) 総合効率

`η_total = 8.8949 / 36 = 0.24708`

`η_total ≒ 24.7%`

(5) 車輪出力余裕

`8.8949 - 8.0 = 0.8949 MW`

したがって約 `0.895 MW` の余裕がある。

この問題の各効率は教材上の仮定値であり、「むつ」の実設備効率として扱わない。
