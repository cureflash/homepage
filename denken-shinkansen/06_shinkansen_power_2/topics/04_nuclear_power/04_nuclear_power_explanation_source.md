## 0. このテーマで電験二種は何を問うか

対象は第二種電気主任技術者の一次「電力」と二次「電力・管理」。固定済みEXAM_ALIGNMENTの5問から、次の6点を解けることを到達条件とする。

1. 蒸気の状態変化、T-s線図、潜熱、過熱蒸気、臨界点を判定する。
2. ランキンサイクル、再熱・再生、タービン入口条件と熱効率の関係を説明する。
3. 原子炉熱出力からタービン軸出力、発電端出力、外部利用可能出力までを熱収支・多段効率で計算する。
4. 所内電源喪失時にも必要な非常用電源と重要補機を説明する。
5. 主機トリップ後もターニングギヤや発電機密封油ポンプ等を継続運転する理由を記述する。
6. 速度調定率から周波数変化と並列発電機の負荷分担を計算する。

新幹線設定は上記論点を具体化するためだけに使う。核燃料サイクル、放射線・遮蔽、法規制、新型炉等へは拡張しない。

## 2. 原子炉熱出力から蒸気へ

PWRでは一次冷却水が炉心で受け取った熱を蒸気発生器へ運び、二次側の水を蒸気へ変える。電験では炉物理ではなく、熱がどの状態変化へ使われるかを読む。

### 2.1 T-s線図

縦軸を絶対温度 `T [K]`、横軸を比エントロピー `s [kJ/(kg·K)]` とする。可逆過程では

`δq = T ds`

なので、T-s線図上で過程の下側の面積は単位質量当たりの熱量に対応する。

水を一定圧力で加熱すると、概念的には

`圧縮水 → 飽和水 → 湿り蒸気 → 乾き飽和蒸気 → 過熱蒸気`

と進む。沸点に達した後、温度をほぼ一定に保ちながら相変化へ使われる熱が潜熱である。飽和液線と飽和蒸気線が合流する頂点が臨界点である。

R7一次問5では、用語だけでなく「T-s線図の面積＝熱量」「相変化時の熱＝潜熱」「全量蒸発後の追加加熱＝過熱蒸気」という関係を識別できる必要がある。

## 3. ランキンサイクルと熱効率

汽力発電の基本はランキンサイクルである。固定範囲では次の流れを押さえる。

`給水 → 蒸気発生器 → 蒸気タービン → 復水器 → 給水ポンプ → 蒸気発生器`

タービンで得る仕事を `W_t`、ポンプ仕事を `W_p`、外部から加えた熱を `Q_in` とすれば、理想化した熱効率は

`η_th = (W_t - W_p) / Q_in`

である。

### 3.1 タービン入口条件

入口温度を一定としたまま入口圧力を高めると、一般に平均加熱温度が上がり熱効率改善方向へ働く。一方で、膨張後の蒸気が湿り側へ入りやすくなる場合がある。したがって「圧力を上げれば全て改善」とは判断しない。

### 3.2 再熱

高圧タービンで途中まで膨張させた蒸気を再び加熱し、その後に低圧側で再膨張させる。再熱はタービン後段の湿りを減らし、熱効率改善に使われる。

### 3.3 再生

タービン膨張途中から蒸気を抽気し、その熱で給水を加熱する。蒸気発生器へ入る前の給水温度を上げることで、外部から与える熱量を減らし、サイクル熱効率を改善する。

H22一次問1では、`抽気 → 給水加熱 → 再生` のつながりを選択肢上で判別する。

## 4. 熱出力・軸出力・電気出力を区別する

原子炉熱出力 `P_r [MW]` と、タービン軸出力・発電端出力・車輪出力は同じ量ではない。

単純化した熱→軸変換を

`P_t = η_th P_r`

とする。ただし `η_th` は熱から軸仕事へ変換される割合であり、後段の電気機器効率とは別である。

架空の主発電機効率を `η_g`、主変換装置効率を `η_c`、主電動機効率を `η_m`、機械伝達効率を `η_d` とすると

`P_wheel = P_t η_g η_c η_m η_d`

したがって総合効率は

`η_total = η_th η_g η_c η_m η_d`

となる。

### 4.1 所内電力

発電端出力を `P_g`、所内消費を `P_aux` とすると、外部へ使える電力は

`P_out = P_g - P_aux`

である。百分率の所内率 `a = P_aux / P_g` を使えば

`P_out = P_g(1-a)`

となる。

「発電端」と「外部利用可能出力」を混同しないことが重要である。

## 5. 所内電源・非常用電源・停止時補機

発電出力がゼロへ向かっても、停止処置に必要な補機負荷は直ちにゼロにはならない。R3一次問5とR1二次問1では、この点が問われる。

### 5.1 直流非常用電源

蓄電池は、外部交流電源喪失時にも必要な保護・制御回路などの重要負荷へ給電する。必要容量は、対象負荷と停電の想定継続時間から考える。

### 5.2 非常用交流電源

交流で駆動し続けなければならない重要補機には、非常用ディーゼル発電機等から給電する。

### 5.3 ターニングギヤ電動機

停止後もタービン車室やロータは高温である。ロータを静止させたまま不均一に冷却すると熱偏心・曲がりを生じ得るため、一定時間、低速回転させて均一に冷却する。

### 5.4 発電機密封油ポンプ電動機

水素冷却発電機では、発電機内部の水素を抜き、機内圧を安全な状態まで下げるまで、ロータ軸封部へ密封油を供給して水素の機外漏えいを防ぐ必要がある。そのため停止後も継続給電が必要となる。

二次試験では機器名だけでは不十分で、`停止後に残る状態 → 放置した場合の問題 → 継続運転の目的` の順に理由を書く。

## 6. 負荷変動・負荷追従・速度調定率

発車・加速時には列車負荷が増え、惰行・停車では低下する。この負荷変化を、原子炉設備の成立性評価ではなく、発電機の負荷追従を学ぶ入力として扱う。

「むつ」では、原子炉全出力の約6%程度までの比較的小さい負荷変動に対し、原子炉プラントの自己制御性で良好に追従したことがJAEA資料で確認されている。ここから先の具体的制御限界は推測しない。

### 6.1 速度調定率

定格周波数を `f_n`、無負荷から定格出力までの周波数差を `Δf_0` とすれば、速度調定率 `R` は

`R = Δf_0 / f_n × 100 [%]`

である。

定格出力を `P_n` とすると、出力―周波数特性の傾きの大きさは

`K = P_n / (f_n R)`

ただし `R` は小数で代入する。単位は `MW/Hz`。

負荷が減少すると発電機出力も下がり、調速機特性上は周波数が上昇する。負荷増加時は逆に周波数が低下する。

### 6.2 並列発電機の負荷分担

発電機A、Bの傾きを `K_A, K_B` とし、系統負荷が `ΔP_L` だけ減少したとする。周波数上昇量を `Δf` とすれば

`(K_A + K_B)Δf = ΔP_L`

より

`Δf = ΔP_L / (K_A + K_B)`

各機の出力減少量は

`ΔP_A = K_A Δf`

`ΔP_B = K_B Δf`

である。並列機では「同じ周波数変化を共有する」ことが連立の核心である。

## 7. 3段階例題

### 例題1 基礎: 熱出力と多段効率

「むつ」の原子炉熱出力 `36 MW` を使う。ここから列車用の架空主発電機へつなぐ教材モデルとして、熱→タービン軸効率を `20%`、発電機効率を `96%` と仮定する。発電端出力を求める。

実値:
- 原子炉熱出力 `P_r = 36 MW`

教材用仮定値:
- `η_th = 0.20`
- `η_g = 0.96`

まずタービン軸出力は

`P_t = 36 × 0.20 = 7.20 MW`

発電端出力は

`P_g = 7.20 × 0.96 = 6.912 MW`

答え: `約6.91 MW`

重要点: `36 MW` は熱出力であり、そのまま電気出力として扱わない。

### 例題2 標準: 発電端・所内電力・車輪出力

発電端出力 `6.912 MW`、所内電力 `0.80 MW`、主変換装置効率 `97%`、主電動機効率 `94%`、機械伝達効率 `98%` とする。効率・所内電力はいずれも教材用仮定値である。車輪へ届く出力を求める。

外部利用可能出力は

`P_out = 6.912 - 0.80 = 6.112 MW`

車輪出力は

`P_wheel = 6.112 × 0.97 × 0.94 × 0.98`

`= 5.46 MW`（約）

答え: `約5.46 MW`

検算: 各段の効率は1未満なので、出力は段階を進むごとに増えない。

### 例題3 複合: 並列発電機の速度調定率

50 Hz系統で発電機A、Bが並列運転している。

- A: 定格 `100 MW`、速度調定率 `4%`、初期出力 `80 MW`
- B: 定格 `60 MW`、速度調定率 `5%`、初期出力 `50 MW`

系統負荷が `24 MW` 減少した。周波数と各発電機出力を求める。調速機特性は線形、基準周波数は50 Hzとする。

Aの傾き:

`K_A = 100 / (50 × 0.04) = 50 MW/Hz`

Bの傾き:

`K_B = 60 / (50 × 0.05) = 24 MW/Hz`

負荷減少24 MWを両機で分担するので

`(50 + 24)Δf = 24`

`Δf = 24 / 74 = 0.324 Hz`

したがって系統周波数は

`f = 50 + 0.324 = 50.324 Hz`

Aの出力減少:

`ΔP_A = 50 × 0.324 = 16.2 MW`

`P_A = 80 - 16.2 = 63.8 MW`

Bの出力減少:

`ΔP_B = 24 × 0.324 = 7.78 MW`

`P_B = 50 - 7.78 = 42.2 MW`

検算:

`16.2 + 7.78 ≈ 24.0 MW`

答え:
- 周波数 `約50.32 Hz`
- A出力 `約63.8 MW`
- B出力 `約42.2 MW`

## 8. 本試験での解法手順

### 蒸気状態・サイクル問題

1. 問題がT-s線図、蒸発、過熱、臨界点のどこを聞いているか判定する。
2. `δq = T ds` と線図面積の関係を使う。
3. 相変化なら潜熱、全量蒸発後なら過熱蒸気と切り分ける。
4. ランキンサイクルでは、再熱と再生を混同しない。
5. 再生は `抽気 → 給水加熱` と覚える。

### 熱収支・多段効率問題

1. 熱出力、軸出力、発電端出力、所内消費、外部利用可能出力を別変数にする。
2. 所内電力は効率積へ混ぜず、指定された位置で差し引く。
3. 後段効率は積でつなぐ。
4. 単位をMWへ統一する。
5. 出力が段階ごとに不自然に増えていないか検算する。

### 非常用電源・停止補機の論説

1. 何が停止したかを書く。
2. 停止後にも残る熱・回転体・発電機内部状態を書く。
3. そのまま放置した場合の不具合を書く。
4. 継続すべき補機と目的を書く。

### 速度調定率・並列負荷分担

1. `%` を小数へ直す。
2. 各機の `K = P_n/(f_nR)` を求める。
3. 同一系統なので周波数変化 `Δf` は共通とする。
4. `ΣK_i Δf = |ΔP_L|` を解く。
5. 各機出力を更新する。
6. 各機出力変化の合計が系統負荷変化と一致するか検算する。

## 9. 頻出ミス

- 原子炉熱出力をそのまま発電電力とする。
- 発電端出力と所内消費差引後の出力を混同する。
- 所内率を百分率のまま掛ける。
- 再熱と再生を混同する。
- `抽気` と `給水` の関係を逆にする。
- 負荷減少なのに周波数低下と判断する。
- 速度調定率4%を `4` と代入する。
- 並列機で機ごとに別の周波数変化を置く。
- ターニングギヤや密封油ポンプについて、機器名だけを書き継続理由を書かない。
