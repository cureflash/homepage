## スライド対応
1. 原子炉熱出力・蒸気状態・T-s線図
   - R7一次「電力」問5
   - `δq = T ds`
   - 潜熱 / 過熱蒸気 / 臨界点
   - 「むつ」実値: PWR、原子炉熱出力36 MW、一次冷却水約270 ℃・約110 kg/cm²、二次蒸気約250 ℃・約40 kg/cm²、主機タービン10,000馬力
2. ランキンサイクル・熱効率・多段効率
   - H22一次「電力」問1
   - `η_th = (W_t - W_p) / Q_in`
   - 再熱 / 再生（抽気→給水加熱）
   - 架空教材モデル: 36 MW → 7.20 MW → 6.912 MW → 6.112 MW → 5.46 MW
   - 36 MW以外の効率・所内電力は仮定値と明示
3. 所内電源・非常用電源・停止時補機
   - R3一次「電力」問5
   - R1二次「電力・管理」問1
   - 蓄電池 / 非常用交流電源 / ターニングギヤ / 発電機密封油ポンプ
   - 論説の因果: `停止後に残る状態 → 放置時の問題 → 継続運転の目的`
4. 負荷変動・速度調定率・並列負荷分担
   - R3二次「電力・管理」問6
   - `R = Δf_0 / f_n × 100 [%]`
   - `K = P_n / (f_n R)`
   - `(K_A + K_B)Δf = |ΔP_L|`
   - 例題: `Δf = 0.324 Hz`、`f = 50.324 Hz`、A=`63.8 MW`、B=`42.2 MW`
   - 「むつ」実績: 原子炉全出力の約6%程度までの比較的小さな負荷変動に自己制御性で良好に追従。これ以上の限界値は推測しない。
