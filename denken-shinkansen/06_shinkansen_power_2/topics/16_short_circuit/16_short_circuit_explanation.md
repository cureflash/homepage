## 1. このテーマで電験は何を問うか

短絡計算で問われる本質は、故障点から電源側を見た等価インピーダンスを正しく作り、そのインピーダンスと故障条件から電流を求めることである。三相短絡だけなら正相回路で解けるが、一線地絡・線間短絡・二線地絡では対称座標法を使い、正相・逆相・零相回路の接続を故障条件に応じて変える。

Topic 16の到達点は次のとおり。

1. 短絡電流と短絡容量を区別し、`S_sc = √3 V I_sc` を使える。
2. 基準容量・基準電圧から基準電流・基準インピーダンスを求められる。
3. 実インピーダンス、p.u.、％インピーダンスを相互変換できる。
4. 発電機・変圧器・送電線を共通基準へ換算し、故障点から見た等価インピーダンスを作れる。
5. 正相・逆相・零相インピーダンスの意味を説明できる。
6. 三相短絡、一線地絡、線間短絡、二線地絡で使う対称分回路を区別できる。
7. p.u.で求めた故障電流を実電流[A]へ戻せる。
8. 系統構成が直列・並列に変わったとき、等価インピーダンスと短絡電流の変化を追える。
9. 短絡電流上限から、未知の機器容量や許容インピーダンスを逆算できる。
10. 新幹線き電回路では、故障点が遠ざかり直列インピーダンスが増えると故障電流が小さくなることを簡略モデルで説明できる。

## 2. 短絡とは何か

### 2.1 故障点までのインピーダンスが小さくなる

正常時の負荷電流は、電源から負荷までのインピーダンスと負荷そのものによって制限される。短絡が起きると、負荷を通らず低いインピーダンスの経路ができるため、大きな電流が流れる。

故障点から電源側をテブナン等価すると、基本関係は

```text
I_f = E_th / Z_th
```

である。

- `I_f`: 故障電流[A]
- `E_th`: 故障前の等価電源電圧[V]
- `Z_th`: 故障点から電源側を見た等価インピーダンス[Ω]

したがって、同じ電圧なら `|Z_th|` が小さいほど故障電流は大きい。

### 2.2 電磁力・熱・電磁誘導障害

短絡電流が大きいほど、導体・機器には大きな電磁力と熱的ストレスが生じる。概念的には、電磁力は電流の二乗に強く依存し、熱影響は `I^2 t` で評価する考え方につながる。

一次試験では「短絡電流が大きいと何が厳しくなるか」を問われるため、次を分けて覚える。

- 瞬時の大電流: 電磁力による機械的ストレス
- 一定時間流れる大電流: ジュール熱による熱的ストレス
- 大きな故障電流が作る磁界: 近接する通信線などに誘導電圧を生じさせ、電磁誘導障害を大きくすることがある

`電磁力` は短絡電流が機器・導体自身へ及ぼす機械的作用、`電磁誘導障害` は大電流が作る磁界によって周辺回路へ電圧が誘導される障害であり、同じものではない。

遮断器の定格選定や保護協調はTopic 17で扱うため、ここでは短絡現象と一次固定問題の選択肢判定に必要な関係までとする。

### 2.3 短絡電流を抑える考え方

`I_f = E_th/Z_th` から、短絡電流を小さくする基本は故障点から見たインピーダンスを大きくする、または短絡電流が流れ込む交流連系経路を分けることである。一次過去問理解に必要な範囲では、次の考え方が対応する。

- 限流リアクトル: 故障電流経路のリアクタンスを増やす。
- 母線分割・系統分割: 並列に故障電流を供給する経路を減らし、故障点から見た系統を弱くする。
- 電圧階級の上昇と系統分割: 上位の電圧階級で電力を受け渡し、下位系統を分割して運用することで、下位系統同士を強く並列連系したときの短絡容量増大を避ける考え方である。
- BTB (Back to Back): 交流をいったん直流へ変換し、再び交流へ変換して二つの交流系統を結ぶ。直流リンクを介するため、一方の交流系統の短絡電流が他方の交流系統へ交流短絡電流として直接流れ込まない。

BTBの制御や変換器設計、遮断器の定格選定・保護協調は本Topicの範囲外とする。

## 3. 三相短絡と短絡容量

### 3.1 三相短絡は平衡故障

三相が対称に短絡する三相短絡は平衡故障である。故障前電圧が平衡し、各相のインピーダンスが対称で、故障インピーダンスを0とする基本問題では、正相回路だけで計算できる。

相電圧基準の等価回路なら

```text
I_3φ = E_phase / Z_1th
```

線間電圧 `V_LL` を使うなら

```text
I_3φ = V_LL / (√3 Z_1th)
```

である。

### 3.2 短絡容量

三相短絡時の短絡容量 `S_sc` は

```text
S_sc = √3 V_LL I_3φ
```

である。ここで `V_LL` は短絡点の電圧階級に対応する基準線間電圧、すなわち故障前電圧を基準に扱う。ボルト短絡後の故障点電圧を代入する式ではない。

したがって

```text
I_3φ = S_sc / (√3 V_LL)
```

とも書ける。

故障点から見た一相当たり等価インピーダンスを `Z_1th` とすれば、電圧・電流の大きさで

```text
S_sc = V_LL^2 / |Z_1th|
```

となる。

短絡容量は通常運転時に送っている有効電力ではない。故障点から見た系統の「強さ」を示す故障レベルである。

一次固定問題の選択肢判定に必要な範囲では、`遮断容量` は遮断器が安全に遮断できる故障電流を容量で表した能力と考える。想定される短絡容量が遮断器の遮断容量を上回れば、その遮断器では安全に遮断できない。ここではこの大小関係だけを扱い、遮断器の定格選定・保護協調はTopic 17へ留保する。

## 4. 単位法・％インピーダンス

### 4.1 基準量

三相系統で、基準三相容量 `S_B` と基準線間電圧 `V_B` を決めると、基準電流と基準インピーダンスは

```text
I_B = S_B / (√3 V_B)
Z_B = V_B^2 / S_B
```

である。

例えば `S_B=100 MVA`, `V_B=66 kV` なら

```text
I_B = 100×10^6 / (√3×66×10^3)
    = 874.8 A

Z_B = (66×10^3)^2 / (100×10^6)
    = 43.56 Ω
```

となる。

### 4.2 実値、p.u.、％Z

```text
Z_pu = Z_actual / Z_B
%Z = 100 Z_pu
```

である。

例えば `Z_pu=0.12` なら `%Z=12 %` である。

### 4.3 基準容量・基準電圧の変更

旧基準を `S_Bold, V_Bold`、新基準を `S_Bnew, V_Bnew` とすると

```text
Z_pu,new
= Z_pu,old
  × (S_Bnew / S_Bold)
  × (V_Bold / V_Bnew)^2
```

である。

変圧器をまたぐ各電圧基準を変圧比に合わせて選んだ場合は、電圧基準比が整合するため、容量基準の換算だけで処理できる場面が多い。

変圧器の `%Z` が自己定格容量基準で与えられ、電圧基準が整合しているなら

```text
Z_pu,common = (%Z/100) × (S_B,common / S_rated)
```

で共通基準へ換算する。

### 4.4 p.u.で短絡電流を求める

故障前正相電圧を `1.0 p.u.` と近似し、三相ボルト短絡なら

```text
I_3φ,pu = 1 / Z_1th,pu
```

実電流は

```text
I_3φ[A] = I_3φ,pu × I_B
```

である。

同じ基準容量上では

```text
S_sc,pu = 1 / Z_1th,pu
S_sc = S_B / Z_1th,pu
```

という対応も使える。

## 5. 系統図を故障計算用等価回路へ変える

### 5.1 まず故障点を決める

故障計算では、最初に「どこで故障したか」を固定する。次に故障点から電源側へ向かって、電流が通る経路だけを残す。

Topic 16の基本モデルは

```text
電源系統
↓
受電変圧器
↓
き電用変圧器
↓
き電回路
↓
故障点
```

である。

試験問題では、これをそのまま足し算してはいけない。各機器を同一基準へ換算してから、接続状態に従って直列・並列合成する。

### 5.2 直列合成

同じ故障電流が順番に流れる経路なら

```text
Z_eq = Z_1 + Z_2 + ...
```

である。

### 5.3 並列合成

同じ両端電圧を持つ複数経路なら

```text
1/Z_eq = 1/Z_a + 1/Z_b + ...
```

二枝なら

```text
Z_eq = Z_a Z_b / (Z_a + Z_b)
```

となる。

系統を連系すると並列電源経路が増え、一般に故障点から見た等価インピーダンスは小さくなる。その結果、短絡電流は増大し得る。

### 5.4 CBはこのTopicでは「接続状態」だけを見る

平成21年度二次問6のように図中にCBがある場合、本Topicでは開放・投入によって回路接続がどう変わるかだけを読む。

- 開放: その枝は電流経路から外れる
- 投入: 枝が接続され、直列・並列関係を再構成する

`遮断容量` は一次固定問題の選択肢判定に必要な「短絡容量との大小関係」だけを§3.2で扱う。遮断器定格の選定、遮断動作、保護協調はTopic 17へ留保する。

## 6. 正相・逆相・零相インピーダンス

### 6.1 正相インピーダンス `Z1`

正常な相順と同じ正相成分が見るインピーダンスである。三相短絡では基本的に正相回路だけを使う。

### 6.2 逆相インピーダンス `Z2`

正相と逆の相順で回転する逆相成分が見るインピーダンスである。線間短絡、一線地絡、二線地絡では逆相回路が必要になる。

### 6.3 零相インピーダンス `Z0`

三相が同位相となる零相成分が見るインピーダンスである。零相電流には大地・中性線・接地された中性点などの帰路が必要であり、零相回路は変圧器結線と中性点接地条件に強く依存する。

一般的な読み方:

- 接地された中性点が零相電流の帰路を作る場合がある。
- 非接地側には零相線電流が流れられない場合がある。
- Δ巻線では零相電流が巻線内を循環できる場合がある一方、外部三線側へ零相線電流をそのまま通さない。

したがって「`Z0` はいつも `Z1` と同じ」と置いてはいけない。問題文の結線・接地条件から零相回路を作る。

## 7. 故障種別と対称分回路

以下は故障前正相電圧を `E`、故障インピーダンスを0とした基本式である。`Z1, Z2, Z0` はすべて故障点から見た各相順の等価インピーダンスとする。

### 7.1 三相短絡

平衡故障なので

```text
I1 = E / Z1
I2 = 0
I0 = 0
```

である。

相電流の大きさは `|I1|` で決まる。

### 7.2 一線地絡

a相地絡を考えると、故障条件は

```text
Ib = 0
Ic = 0
Va = 0
```

となる。正相・逆相・零相回路が直列に接続され、

```text
I1 = I2 = I0
   = E / (Z1 + Z2 + Z0)
```

である。

故障相電流は

```text
Ia = I0 + I1 + I2
   = 3E / (Z1 + Z2 + Z0)
```

となる。

故障インピーダンス `Zf` を含める一般形では分母に `3Zf` を加える。

### 7.3 線間短絡

b-c線間短絡の基本条件では零相成分が現れず、

```text
I0 = 0
I2 = -I1
I1 = E / (Z1 + Z2)
```

となる。

故障相電流の大きさは

```text
|Ib| = |Ic| = √3 |I1|
```

である。

「線間短絡だから三相短絡式をそのまま使う」のは誤りである。

### 7.4 二線地絡

b相・c相が同時に地絡するボルト故障では、正相回路に対して逆相回路と零相回路が並列に接続される。

```text
I1 = E / { Z1 + (Z2 Z0)/(Z2 + Z0) }

I2 = - Z0/(Z2 + Z0) × I1

I0 = - Z2/(Z2 + Z0) × I1
```

各相電流へ戻すときは、Topic 13で既習の逆対称座標変換を使う。

```text
Ia = I0 + I1 + I2
Ib = I0 + a^2 I1 + a I2
Ic = I0 + a I1 + a^2 I2
```

b-c地絡では未故障a相について `Ia=0` になることを検算に使える。地絡電流の合計は

```text
Ia + Ib + Ic = 3I0
```

で確認できる。

### 7.5 故障種別の整理

| 故障種別 | 使う対称分 | 基本接続 |
|---|---|---|
| 三相短絡 | 正相のみ | 正相回路 |
| 一線地絡 | 正相・逆相・零相 | 3回路直列 |
| 線間短絡 | 正相・逆相 | 正相＋逆相、零相なし |
| 二線地絡 | 正相・逆相・零相 | 正相＋`逆相 || 零相` |

この表は接続を選ぶ入口であり、零相回路そのものは結線・接地条件から個別に作る。

## 8. 本試験標準の解法アルゴリズム

1. 故障種別を判定する。
2. 故障点を固定する。
3. 問題文から基準容量 `S_B`、基準電圧 `V_B` を決める。
4. `I_B=S_B/(√3V_B)`、`Z_B=V_B^2/S_B` を求める。
5. 発電機、変圧器、送電線などを同一p.u.基準へ換算する。
6. 故障点から見た正相・逆相・零相インピーダンスを作る。
7. 三相短絡・一線地絡・線間短絡・二線地絡のどの回路接続を使うか決める。
8. p.u.故障電流を求める。
9. 必要なら `I=I_pu I_B` で実電流へ戻す。
10. 短絡容量を求めるなら `S_sc=√3VI_sc` で確認する。
11. 逆算問題なら、電流上限をp.u.へ直して必要等価インピーダンスを先に求める。
12. 桁、単位、故障種別、接地条件、連系状態を再確認する。

## 9. 短絡電流上限から逆算する

令和3年度二次問3のように、短絡電流の上限から未知の機器容量を逆算する問題では、最後から逆にたどる。

短絡電流上限を `I_lim` とすると

```text
I_lim,pu = I_lim / I_B
```

三相短絡・故障前電圧1 p.u.なら、必要な全等価インピーダンスは

```text
Z_total,pu >= 1 / I_lim,pu
```

である。

固定部分を `Z_fixed`、未知機器の自己定格基準インピーダンスを `x_u`、未知容量を `S_u`、共通基準容量を `S_B` とする。電圧基準が整合していれば未知機器の共通基準インピーダンスは

```text
Z_u,common = x_u × S_B / S_u
```

となる。

よって

```text
x_u S_B / S_u + Z_fixed >= 1/I_lim,pu
```

から

```text
S_u <= x_u S_B / {1/I_lim,pu - Z_fixed}
```

と逆算できる。

分母が正であること、`x_u` を％値のまま使わずp.u.へ直していることを必ず確認する。

## 10. 新幹線き電回路への接続

### 10.1 上位三相系統と25kVき電側を混同しない

電験の正式品質ゲートで扱う三相短絡・対称座標法は、主として三相電力系統の故障計算である。一方、新幹線の架線側は単相き電である。

したがって、25kV架線の単相故障電流を考えるときに、三相短絡式 `I=V_LL/(√3Z)` を無条件に当てはめてはいけない。

新幹線側は、教材上の概念接続として

```text
電源系統
↓
受電変圧器
↓
き電用変圧器
↓
き電回路等価インピーダンス
↓
故障点
```

を一つのテブナン等価回路にまとめ、単相側の等価電圧と等価インピーダンスで考える。

### 10.2 故障位置―短絡電流の教材用仮定モデル

以下は実設備値ではなく、故障位置による傾向を示すためだけの仮定値である。

```text
き電電圧 V_feed = 25 kV
上位側等価インピーダンス Z_up = j1.50 Ω
き電回路等価インピーダンス z = j0.080 Ω/km
故障抵抗 = 0 Ω
```

変電所からの距離を `x[km]` とすると

```text
Z_th(x) = Z_up + z x
I_f(x) = V_feed / |Z_th(x)|
```

となる。

| 故障位置 `x` [km] | `|Z_th|` [Ω] | `I_f` [kA] |
|---:|---:|---:|
| 0 | 1.50 | 16.67 |
| 5 | 1.90 | 13.16 |
| 10 | 2.30 | 10.87 |
| 20 | 3.10 | 8.06 |
| 30 | 3.90 | 6.41 |

この表を「故障位置―短絡電流」可視化の元データとする。実際のATき電回路は複数導体、帰線、AT配置などを含み、この単純な直線インピーダンスモデルより複雑である。本Topicでは実設備値の真値化をしない。

## 11. 3段階例題

### 11.1 基礎例題: 短絡容量から三相短絡電流を求める

ある三相系統の故障点で、短絡容量が `S_sc=1000 MVA`、線間電圧が `V_LL=66 kV` とする。

使用式は

```text
S_sc = √3 V_LL I_sc
```

なので

```text
I_sc
= 1000×10^6 / (√3×66×10^3)
= 8.75×10^3 A
= 8.75 kA
```

となる。

短絡容量はMVA、電圧はkV、電流はkAの組合せでも整合するが、式の途中で単位系を混在させない。

### 11.2 本試験標準例題: ％Zを共通基準へ換算して三相短絡

共通基準を

```text
S_B = 100 MVA
V_B = 66 kV
```

とする。故障点までに次の正相インピーダンスが直列にあるとする。

- 電源系統: `j0.15 p.u.`（100 MVA基準）
- 変圧器: `%Z=10 %`（自己定格50 MVA、電圧基準整合）
- 線路: `j0.05 p.u.`（100 MVA基準）

変圧器を共通基準へ換算すると

```text
Z_T = 0.10 × 100/50
    = 0.20 p.u.
```

全正相インピーダンスは

```text
Z_1th = j(0.15+0.20+0.05)
      = j0.40 p.u.
```

したがって三相短絡電流は

```text
I_sc,pu = 1/0.40 = 2.50 p.u.
```

基準電流は

```text
I_B = 100×10^6/(√3×66×10^3)
    = 0.8748 kA
```

なので

```text
I_sc = 2.50×0.8748
     = 2.19 kA
```

短絡容量で検算すると

```text
S_sc = S_B/0.40 = 250 MVA
```

また

```text
√3×66 kV×2.19 kA ≒ 250 MVA
```

となり一致する。

### 11.3 複合・ひっかけ例題: 一線地絡と三相短絡を比較する

同じ故障点について、100 MVA基準で

```text
Z1 = j0.20 p.u.
Z2 = j0.20 p.u.
Z0 = j0.10 p.u.
E = 1.0 p.u.
```

とする。故障抵抗0のa相一線地絡では

```text
I1 = I2 = I0
   = 1 / j(0.20+0.20+0.10)
   = -j2.0 p.u.
```

故障相電流は

```text
Ia = 3I0 = -j6.0 p.u.
```

66 kV基準なら `I_B=0.8748 kA` なので

```text
|Ia| = 6.0×0.8748
     = 5.25 kA
```

一方、同じ地点の三相短絡は

```text
I_3φ = 1/Z1 = 5.0 p.u.
      = 4.37 kA
```

である。

この例では `Z0` が小さいため、一線地絡電流の方が三相短絡電流より大きい。したがって「三相短絡が必ず最大」と暗記してはいけない。故障種別と `Z1, Z2, Z0` の値で比較する。

## 12. 頻出ミス・ひっかけ

- 線間電圧をそのまま一相等価回路へ入れ、`√3` を落とす。
- 短絡容量式の電圧に、ボルト短絡後の故障点電圧を入れる。使うのは電圧階級に対応する基準電圧・故障前電圧である。
- `S_sc` を通常運転の有効電力とみなす。
- `電磁誘導障害` と、導体自身に働く電磁力・熱的ストレスを同じものとみなす。
- 短絡容量と遮断容量の大小関係を逆にする。
- BTBを交流母線の直接連系とみなし、交流短絡電流がそのまま通過すると考える。
- 変圧器の `%Z` を異なる容量基準のまま足す。
- `%Z=10` を `10 p.u.` として扱う。正しくは `0.10 p.u.`。
- 基準電流 `I_B=S_B/(√3V_B)` と単相の `I=S/V` を混同する。
- p.u.故障電流を[A]へ戻すとき `I_B` を掛け忘れる。
- 三相短絡に逆相・零相回路まで接続する。
- 一線地絡で正相・逆相・零相を並列にする。基本は直列である。
- 線間短絡に零相回路を入れる。
- 二線地絡を一線地絡と同じ直列回路で解く。
- 零相インピーダンスを変圧器結線・中性点接地条件を見ずに決める。
- CB開放・投入で系統接続が変わっているのに、同じ等価インピーダンスを使う。
- 短絡電流上限から逆算するとき、不等号の向きを逆にする。
- 25kVき電側の単相等価回路へ三相短絡式をそのまま適用する。

## 13. 公式・解法まとめ

### 三相基準量

```text
I_B = S_B/(√3V_B)
Z_B = V_B^2/S_B
```

### p.u.・％Z

```text
Z_pu = Z/Z_B
%Z = 100Z_pu

Z_pu,new
= Z_pu,old
× (S_Bnew/S_Bold)
× (V_Bold/V_Bnew)^2
```

### 三相短絡

```text
I_3φ = V_LL/(√3Z_1th)
I_3φ,pu = 1/Z_1th,pu
S_sc = √3V_LL I_3φ
S_sc = V_LL^2/|Z_1th|
```

`V_LL` は短絡点の電圧階級に対応する基準線間電圧・故障前電圧であり、ボルト短絡後の故障点電圧ではない。

### 一線地絡

```text
I1 = I2 = I0 = E/(Z1+Z2+Z0)
Ia = 3E/(Z1+Z2+Z0)
```

### 線間短絡

```text
I0 = 0
I2 = -I1
I1 = E/(Z1+Z2)
|I_fault phase| = √3|I1|
```

### 二線地絡

```text
I1 = E/{Z1+(Z2Z0)/(Z2+Z0)}
I2 = -Z0/(Z2+Z0) × I1
I0 = -Z2/(Z2+Z0) × I1
```
