## (1) CB3開放

変電所Aから変電所C・発電所側を見る直列リアクタンス:

`25.0 + 12.0 + 1.0 + 10.0 + 2.0 = 50.0 %`

上位系統 `2.5 %` と発電所側 `50.0 %` の並列合成:

`Z_A = 1 /(1/2.5 + 1/50.0) = 2.38095 %`

事故点から見た等価インピーダンス:

`Z_g = 1.5 + 10.0 + 0.5 + 2.38095 = 14.38095 %`

三相短絡電流:

`I_sc = (100 / 14.38095) x 0.87477 = 6.08286 kA`

答案: `6.08 kA`

## (2) CB3投入

A-B-C間の三角形リアクタンス:
- `X_AB = 10.5 %`
- `X_AC = 12.0 %`
- `X_BC = 1.0 %`

Δ-Y変換。分母は `10.5 + 12.0 + 1.0 = 23.5`。

- A側: `10.5 x 12.0 / 23.5 = 5.36170 %`
- B側: `10.5 x 1.0 / 23.5 = 0.44681 %`
- C側: `12.0 x 1.0 / 23.5 = 0.51064 %`

Y中心から電源側を見た2枝:
- 上位系統側: `5.36170 + 2.5 = 7.86170 %`
- 発電所側: `0.51064 + 1.0 + 12.0 + 25.0 = 38.51064 %`

並列合成を含む事故点等価インピーダンス:

`Z_g = 1.5 + 0.44681 + 1 /(1/7.86170 + 1/38.51064) = 8.47568 %`

三相短絡電流:

`I_sc = (100 / 8.47568) x 0.87477 = 10.32098 kA`

答案: `10.3 kA`
