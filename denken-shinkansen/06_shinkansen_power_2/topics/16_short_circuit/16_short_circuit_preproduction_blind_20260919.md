blind結果: `5 / 5 PASS`

独立再解答:
1. 系統容量
2. 電磁誘導障害
3. インピーダンス
4. 限流リアクトル
5. 母線分離

選択肢記号: `ト / ヌ / ハ / ヨ / ヘ`

根拠:
- 電源・送電線の増強や連系強化は故障点から見た等価インピーダンスを相対的に小さくし、短絡電流を増やす。
- 短絡大電流は電力設備だけでなく近傍通信線へ電磁誘導障害を与え得る。
- 短絡電流を抑えるには直列インピーダンスを増やす。発変電機器のインピーダンス増、限流リアクトル、母線分離はいずれもこの方向に作用する。

## 3. 令和7年度 二次「電力・管理」問2

独立再解答:
- `Z1 = 0.005 + j0.22 p.u.`
- `Z2 = 0.005 + j0.22 p.u.`
- `Z0 = 45 + j0.3 p.u.`
- 一線地絡電流: `|Ia| = 0.0701 p.u.`
- 実電流: `263 A`

根拠:
- 故障点Fは線路中点なので正相・逆相線路インピーダンスは半分。
- 一線地絡では正相・逆相・零相回路を直列接続する。
- 中性点抵抗15 p.u.は零相回路で `3Rn = 45 p.u.` として現れる。
- 故障前電圧は `162/154 = 1.0519 p.u.`、`Ia = 3I0`。
- 基準電流 `1000 MVA /(sqrt(3)×154 kV)` を用いてAへ換算する。

## 4. 令和3年度 二次「電力・管理」問3

blind結果: `6 / 6 PASS`

独立再解答:
- 基準電流: `0.375 kA`
- 基準インピーダンス: `237 ohm`
- 送電線: `j0.0337 p.u.`
- 変圧器: `j0.0667 p.u.`
- 25 kA: `28.6 p.u.`
- 発電機最大容量: `498 MVA`

根拠:
- `Ib = Sb /(sqrt(3)Vb)`、`Zb = Vb^2/Sb`。
- 送電線実リアクタンスを154 kV・100 MVA基準へ換算する。
- 変圧器10%を150 MVA自己容量基準から100 MVA基準へ換算する。
- 2回線送電線は並列なので送電線p.u.値を1/2にする。
- 66 kV側25 kAを100 MVA基準へ換算し、系統側寄与と発電機側寄与の和が28.6 p.u.以下となる条件から容量を逆算する。

公式標準解答照合: `6 / 6一致`
