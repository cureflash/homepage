## 3. 令和7年度 第二種二次「電力・管理」問2

故障点Fは送電線中点なので正相・逆相線路インピーダンスは半分を用いる。

```text
Z1 = Z2
   = j0.2 + (0.01+j0.04)/2
   = 0.005+j0.22 p.u.
```

零相では電源側Y中性点接地抵抗に零相電流3I0が流れるため、接地抵抗は零相回路で `3×15=45 p.u.`。負荷側Y中性点は非接地なので零相電流経路にならない。

```text
Z0 = 3×15 + j0.2 + j0.2/2
   = 45+j0.3 p.u.
```

故障前電圧:

```text
Ea = 162/154 = 1.05195 p.u.
```

一線地絡では正相・逆相・零相回路を直列接続する。

```text
I0 = Ea/(Z0+Z1+Z2)
|I0| = 0.02337 p.u.
|Ia| = 3|I0| = 0.0701 p.u.
```

基準電流:

```text
IB = 1000 MVA/(√3×154 kV) = 3749 A
|Ia| = 0.0701×3749 = 263 A
```

候補:
- `Z0 = 45+j0.3 p.u.`
- `Z1 = 0.005+j0.22 p.u.`
- `Z2 = 0.005+j0.22 p.u.`
- `|Ia| = 0.0701 p.u.`
- `|Ia| = 263 A`

公式標準解答照合: `5 / 5一致`
判定: `5 / 5 PASS`

## 4. 令和3年度 第二種二次「電力・管理」問3

100 MVA、154 kV基準:

```text
IB = 100/(√3×154) = 0.3749 kA → 0.375 kA
ZB = 154^2/100 = 237.16 Ω → 237 Ω
```

送電線20 km:

```text
X = 0.400×20 = 8.00 Ω
Xpu = 8/237.16 = 0.033733 p.u. → j0.0337 p.u.
```

変圧器150 MVA、10 %:

```text
Xpu = 0.10×100/150 = 0.066667 p.u. → j0.0667 p.u.
```

66 kV側25 kAのp.u.値:

```text
IB,66 = 100/(√3×66) = 0.8748 kA
25/0.8748 = 28.579 p.u. → 28.6 p.u.
```

154 kV送電線2回線なので線路は並列となる。

```text
Xfixed = 0.033733/2 + 0.066667
       = 0.083534 p.u.
I∞ = 1/0.083534 = 11.971 p.u.
```

発電機等価リアクタンスは自己容量S MVA基準で0.30 p.u.なので、100 MVA共通基準では `30/S p.u.`。短絡電流を28.579 p.u.以下とする条件:

```text
11.971 + S/30 <= 28.579
S <= 498.2 MVA
```

候補:
- 基準電流: `0.375 kA`
- 基準インピーダンス: `237 Ω`
- 送電線: `j0.0337 p.u.`
- 変圧器: `j0.0667 p.u.`
- 25 kA: `28.6 p.u.`
- 発電機最大容量: `498 MVA`

公式標準解答照合: `6 / 6一致`
判定: `6 / 6 PASS`

## 5. 平成21年度 第二種二次「電力・管理」問6

100 MVA基準、66 kV側基準電流:

```text
IB = 100/(√3×66) = 0.8748 kA
```

### (1) CB3開放

B母線からA側は `TL2+TR2 = 0.5+10.0 = 10.5 %`。A母線から見て、上位系統 `2.5 %` と、C側から発電機までの `TL5+TR3+TL4+TR1+G = 2+10+1+12+25 = 50 %` が並列。

```text
Zth
= 1.5 + 10.5 + (2.5 || 50)
= 1.5 + 10.5 + 2.38095
= 14.38095 %

Isc = (100/14.38095)×0.8748
    = 6.08 kA
```

### (2) CB3投入

A-B-C間の三角形 `AB=10.5 %`, `AC=12.0 %`, `BC=1.0 %` を等価変換する。

```text
Zcenter = 10.5×12/(10.5+12+1) = 5.362 %
ZB      = 10.5×1/(10.5+12+1)  = 0.447 %
ZC      = 12×1/(10.5+12+1)    = 0.511 %
```

B側から見た等価インピーダンス:

```text
Zth
= 1.5 + 0.447 + {(2.5+5.362) || (0.511+38.0)}
= 8.476 %

Isc = (100/8.476)×0.8748
    = 10.3 kA
```

候補:
- CB3開放: `6.08 kA`
- CB3投入: `10.3 kA`

公式標準解答照合: `2 / 2一致`
判定: `2 / 2 PASS`
