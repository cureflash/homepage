## 一次選択肢判定用ミニ整理

完成後blindで不足した一次知識は次の5点だけを補う。

- 短絡容量 `S_sc = √3 V_LL I_sc` の `V_LL` は短絡点の電圧階級に対応する基準線間電圧、すなわち故障前電圧であり、ボルト短絡後の故障点電圧0 Vを代入する式ではない。
- 短絡電流が大きいと、導体・機器自身には電磁力による機械的ストレスと `I^2 t` に対応する熱的ストレスが増える。また、大電流が作る磁界により近接通信線などへ誘導電圧が生じ、電磁誘導障害が大きくなることがある。電磁力と電磁誘導障害は別の現象である。
- 遮断容量は、遮断器が安全に遮断できる故障電流を容量で表した能力である。想定短絡容量が遮断器の遮断容量を上回ると安全に遮断できない。本Topicではこの大小関係だけを扱う。
- 電圧階級を上げて上位系統で電力を受け渡し、下位系統を分割して運用すると、下位系統同士を強く並列連系したときの短絡容量増大を避ける方向に働く。
- BTB (Back to Back) は交流をいったん直流へ変換し、再び交流へ変換して二つの交流系統を結ぶ。直流リンクを介するため、一方の交流系統の短絡電流が他方へ交流短絡電流として直接流れ込まない。

## 問2 基礎・一次型: 短絡電流と系統インピーダンス

短絡現象と短絡電流抑制に関する説明として最も適切なものを選べ。

1. BTBは二つの交流系統を交流のまま直結するため、一方の短絡電流を他方へ直接通過させる。
2. 同じ電圧なら、故障点から見た等価インピーダンスが小さいほど短絡電流は大きい。大電流は電磁力・熱的ストレスを増やし、周辺通信線などへの電磁誘導障害も大きくし得る。短絡電流抑制には、系統インピーダンスを大きくする、系統を分割する、直流リンクを介して交流短絡電流の直接流入を断つなどの考え方がある。
3. 想定短絡容量が遮断器の遮断容量を上回っていても、安全な遮断には影響しない。
4. 電磁誘導障害とは、短絡電流が導体自身に生じさせる電磁力による機械的ストレスそのものである。

# 解答・完全解説

## 問1

正答: 4

三相短絡容量は

```text
S_sc = √3 V_LL I_sc
     = √3 × 66×10^3 × 10×10^3
     = 1.143×10^9 VA
     ≈ 1.14 GVA
```

ここで `V_LL` は短絡点の電圧階級に対応する基準線間電圧、すなわち故障前電圧を用いる。ボルト短絡後の故障点電圧0 Vを代入する式ではない。

短絡容量は通常運転時の有効電力ではなく、故障点から見た系統の故障レベルを表す。一次選択肢判定に必要な範囲では、想定短絡容量が遮断器の遮断容量を上回ると、その遮断器では安全に遮断できない。遮断器の定格選定・保護協調はTopic 17で扱う。

## 問2

正答: 2

故障点から電源側をテブナン等価すれば

```text
I_f = E_th / Z_th
```

である。同じ電圧なら `|Z_th|` が小さいほど故障電流は大きい。連系経路が増えて並列化すると一般に等価インピーダンスが小さくなり、短絡電流は増大し得る。

短絡電流が大きいほど、瞬時には電磁力による機械的ストレスが増え、一定時間流れれば `I^2 t` に対応する熱的ストレスが増える。さらに大電流が作る磁界によって近接通信線などへ誘導電圧が生じ、電磁誘導障害が大きくなることがある。電磁力は導体・機器自身への機械的作用、電磁誘導障害は周辺回路へ電圧が誘導される障害であり、同じものではない。

短絡電流抑制の考え方は、故障点から見たインピーダンスを大きくする、または交流短絡電流の流入経路を分けることである。限流リアクトルはリアクタンスを増やし、母線分割・系統分割は並列供給経路を減らす。上位の電圧階級で電力を受け渡して下位系統を分割する方法も、下位系統同士を強く並列連系したときの短絡容量増大を避ける方向に働く。BTBは交流を直流へ変換してから再び交流へ変換して系統を結ぶため、一方の交流系統の短絡電流が他方へ交流短絡電流として直接流れ込まない。

誤答肢の確認:
- 1: BTBは交流直結ではなく直流リンクを介するため誤り。
- 3: 想定短絡容量が遮断容量を上回ると安全な遮断ができないため誤り。
- 4: 電磁力と電磁誘導障害は別の現象なので誤り。

## 問14

### (1) 三相短絡

平衡故障なので正相回路だけを使う。

```text
I1 = 1/Z1 = 1/(j0.20) = -j5.0 p.u.
```

各相の短絡電流の大きさは `5.0 p.u.`。

### (2) 一線地絡

正相・逆相・零相回路を直列接続する。

```text
I_a = 3/(Z1+Z2+Z0)
    = 3/(j0.50)
    = -j6.0 p.u.
```

よって `|I_a|=6.0 p.u.`。

### (3) 線間短絡

零相電流は0。正相回路と逆相回路を接続する。

```text
I1 = 1/(Z1+Z2)
   = 1/(j0.40)
   = -j2.5 p.u.

I2 = -I1
```

故障相電流は

```text
|I_b|=|I_c|=√3|I1|=4.33 p.u.
```

### (4) 二線地絡

正相回路に `Z2` と `Z0` の並列回路を直列接続する。

```text
Z2||Z0 = j0.0667 p.u.
I1 = 1/[j(0.20+0.0667)]
   = -j3.75 p.u.
```

したがって `|I1|=3.75 p.u.`。

ボルト二線地絡では

```text
I2 = -I1 × Z0/(Z2+Z0)
I0 = -I1 × Z2/(Z2+Z0)
```

である。本問の値なら

```text
I2 = +j1.25 p.u.
I0 = +j2.50 p.u.
```

相電流への逆変換は

```text
I_a = I0 + I1 + I2
I_b = I0 + a^2 I1 + a I2
I_c = I0 + a I1 + a^2 I2
```

で、`a=e^{j120°}` とする。この条件では `I_a=0` となり、故障相b,cに電流が流れる。

故障種別ごとに対称分回路の接続が異なるため、同じ `Z1,Z2,Z0` でも計算式は同じにならない。

## 問15

### (1) 故障電流の式

故障点までの直列リアクタンスは

```text
X(x)=0.80+0.030x [Ω]
```

したがって大きさだけを扱えば

故障点が変電所から遠ざかるほど、故障点までに含まれるき電回路の直列リアクタンスが増える。電源電圧が同じなら `I=V/X` なので、故障電流は小さくなる。

実設備値として扱ってはならない。本問の `25 kV`, `0.80 Ω`, `0.030 Ω/km` は故障位置と短絡電流の関係を学ぶための教材用仮定値である。実際の新幹線き電系統の故障電流を求めるには、実系統構成、変圧器、ATき電回路、電源側短絡容量等の確認済みデータが必要である。
