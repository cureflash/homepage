## 問2 基礎・一次型: 短絡電流と系統インピーダンス

短絡現象に関する説明として最も適切なものを選べ。

1. 系統を強く連系するほど等価インピーダンスは必ず増え、短絡電流は減少する。
2. 同じ電圧なら、故障点から見た等価インピーダンスが小さいほど短絡電流は大きくなる。短絡電流が大きいと電磁力・熱的ストレスが増え、短絡電流を抑えるには等価インピーダンスを大きくする考え方が基本となる。
3. 短絡容量は通常時の有効電力そのものである。
4. 短絡電流による熱的影響は電流の大きさに無関係である。
5. 母線分割や限流リアクトルは等価インピーダンスを小さくして短絡電流を増やすために用いる。

# 解答・完全解説

## 問1

正答: 4

三相短絡容量は

```text
S_sc = √3 V_LL I_sc
     = √3 × 66×10^3 × 10×10^3
     = 1.143×10^9 VA
     ≈ 1.14 GVA
```

短絡容量は通常運転時の有効電力ではなく、故障点から見た系統の故障レベルを表す。

## 問2

正答: 2

故障点から電源側をテブナン等価すれば

```text
I_f = E_th / Z_th
```

である。同じ電圧なら `|Z_th|` が小さいほど故障電流は大きい。連系経路が増えて並列化すると一般に等価インピーダンスが小さくなり、短絡電流は増大し得る。

短絡電流が大きいほど、瞬時には電磁力による機械的ストレスが増え、一定時間流れれば `I^2 t` に対応する熱的ストレスが増える。限流リアクトルや母線分割などは、故障点から見た等価インピーダンスを大きくする方向で短絡電流を抑える考え方である。

## 問3

正答: 2

```text
I_B = S_B / (√3 V_B)
    = 100×10^6 / (√3×66×10^3)
    = 874.8 A
    = 0.875 kA

Z_B = V_B^2 / S_B
    = (66×10^3)^2 / (100×10^6)
    = 43.56 Ω
```

したがって `I_B≈0.875 kA`, `Z_B≈43.6 Ω`。

## 問4

正答: 4

自己容量基準では

```text
Z_old = 10 % = 0.10 p.u.
```

電圧基準が変圧比に整合しているので、容量基準だけを換算する。

```text
Z_new = 0.10 × (100/50)
      = 0.20 p.u.
```

したがって共通基準では20 %、すなわち `0.20 p.u.`。

## 問5

正答: 3

三相短絡では正相回路だけを使う。

```text
I_3φ,pu = 1 / 0.25 = 4.0 p.u.
```

100 MVA、66 kV基準の基準電流は問3より `0.8748 kA`。

```text
I_3φ = 4.0 × 0.8748
     = 3.499 kA
     ≈ 3.50 kA
```

## 問6

正答: 3

100 MVA基準で `Z_th=0.20 p.u.` だから

```text
S_sc = S_B / Z_th
     = 100 / 0.20
     = 500 MVA
```

また

```text
I_sc,pu = 1/0.20 = 5.0 p.u.
I_sc = 5.0 × 0.8748
     = 4.374 kA
```

したがって `500 MVA`, `4.37 kA`。

## 問7

正答: 5

一線地絡では正相・逆相・零相回路を直列に接続する。a相地絡電流は

```text
I_a = 3E / (Z1 + Z2 + Z0)
```

したがって大きさは

```text
|I_a| = 3 / (0.20+0.20+0.10)
      = 6.0 p.u.
```

基準電流は

```text
I_B = 100×10^6/(√3×22×10^3)
    = 2.624 kA
```

よって

```text
I_a = 6.0×2.624
    = 15.75 kA
```

## 問8

正答: 2

線間短絡では大地への電流経路がないため零相電流は0で、正相回路と逆相回路を用いる。

```text
I1 = E/(Z1+Z2)
|I1| = 1/(0.20+0.20) = 2.5 p.u.
```

故障相電流の大きさは

```text
|I_b| = |I_c| = √3 |I1|
      = √3×2.5
      = 4.33 p.u.
```

## 問9

正答: 4

二線地絡では、正相回路に「逆相回路と零相回路の並列合成」を直列に接続する。

```text
Z2 || Z0
= j(0.20×0.10)/(0.20+0.10)
= j0.0667 p.u.
```

したがって

```text
|I1| = 1/(0.20+0.0667)
      = 3.75 p.u.
```

一線地絡のように3回路を単純直列にはしない。

## 問10

正答: 2

簡略モデルでは

```text
I_f(x) = 25,000 / (0.80 + 0.030x) [A]
```

20 kmでは

```text
I_f(20)=25,000/(0.80+0.60)
       =17.86 kA
```

40 kmでは

```text
I_f(40)=25,000/(0.80+1.20)
       =12.50 kA
```

故障点が遠ざかると直列リアクタンスが増えるため、故障電流は小さくなる。

### (6) 発電機容量上限

```text
X_total >= 1/I_limit,pu
        = 1/9.526
        = 0.10497 p.u.
```

送電線と変圧器で

```text
X_line + X_tr = 0.0200+0.0300=0.0500 p.u.
```

したがって発電機には

```text
X_G,common >= 0.10497-0.0500
           = 0.05497 p.u.
```

が必要である。

発電機自己容量基準のリアクタンスは0.20 p.u.なので、100 MVA共通基準では

```text
X_G,common = 0.20×(100/S_G)
           = 20/S_G
```

よって

```text
20/S_G >= 0.05497
S_G <= 363.8 MVA
```

したがって許容発電機定格容量の上限は約 `364 MVA`。

検算として `S_G=363.8 MVA` なら `X_total≈0.10497 p.u.`、短絡電流は `9.526 p.u.×2.624 kA≈25.0 kA` となる。

## 問12

### (1) 各対称分インピーダンス

```text
Z1 = j(0.08+0.07+0.05) = j0.20 p.u.
Z2 = j(0.08+0.07+0.05) = j0.20 p.u.
Z0 = j(0.04+0.03+0.03) = j0.10 p.u.
```

### (2) a相地絡電流[p.u.]

一線地絡では正相・逆相・零相回路を直列接続する。

```text
I1 = I2 = I0
   = 1/(Z1+Z2+Z0)
   = 1/(j0.50)
   = -j2.0 p.u.
```

a相電流は

```text
I_a = I0+I1+I2 = 3I0
```

だから

```text
I_a = -j6.0 p.u.
|I_a| = 6.0 p.u.
```

### (3) 実電流

```text
I_B = 100×10^6/(√3×22×10^3)
    = 2.624 kA

|I_a| = 6.0×2.624
      = 15.75 kA
```

答案では、`Z1`, `Z2`, `Z0` の合成、地絡電流[p.u.]、基準電流から実電流への換算を分けて書く。

## 問13

基準電流は

```text
I_B = 2.624 kA
```

である。

### (1) 電源Aだけ

故障点から見た正相リアクタンスは `j0.20 p.u.`。

```text
I_3φ,pu = 1/0.20 = 5.0 p.u.
I_3φ = 5.0×2.624 = 13.12 kA
```

### (2) 電源A・Bを連系

同じ `j0.20 p.u.` の二経路が並列になる。

```text
X_eq = 0.20 || 0.20 = 0.10 p.u.
```

したがって

```text
I_3φ,pu = 1/0.10 = 10.0 p.u.
I_3φ = 10.0×2.624 = 26.24 kA
```

### (3) 理由

連系によって電源から故障点までの並列経路が増え、故障点から見た等価インピーダンスが `0.20 p.u.` から `0.10 p.u.` へ半減した。そのため `I=E/Z` に従って短絡電流は2倍になった。

ここで系統接続の変更だけを扱い、遮断器定格や保護協調へは進まない。

## 問14

### (1) 三相短絡

平衡故障なので正相回路だけを使う。

```text
I1 = 1/Z1 = 1/(j0.20) = -j5.0 p.u.
```

各相の短絡電流の大きさは `5.0 p.u.`。

### (2) 一線地絡

正相・逆相・零相回路を直列接続する。

```text
I_a = 3/(Z1+Z2+Z0)
    = 3/(j0.50)
    = -j6.0 p.u.
```

よって `|I_a|=6.0 p.u.`。

### (3) 線間短絡

零相電流は0。正相回路と逆相回路を接続する。

```text
I1 = 1/(Z1+Z2)
   = 1/(j0.40)
   = -j2.5 p.u.

I2 = -I1
```

故障相電流は

```text
|I_b|=|I_c|=√3|I1|=4.33 p.u.
```

### (4) 二線地絡

正相回路に `Z2` と `Z0` の並列回路を直列接続する。

```text
Z2||Z0 = j0.0667 p.u.
I1 = 1/[j(0.20+0.0667)]
   = -j3.75 p.u.
```

したがって `|I1|=3.75 p.u.`。

ボルト二線地絡では

```text
I2 = -I1 × Z0/(Z2+Z0)
I0 = -I1 × Z2/(Z2+Z0)
```

である。本問の値なら

```text
I2 = +j1.25 p.u.
I0 = +j2.50 p.u.
```

相電流への逆変換は

```text
I_a = I0 + I1 + I2
I_b = I0 + a^2 I1 + a I2
I_c = I0 + a I1 + a^2 I2
```

で、`a=e^{j120°}` とする。この条件では `I_a=0` となり、故障相b,cに電流が流れる。

故障種別ごとに対称分回路の接続が異なるため、同じ `Z1,Z2,Z0` でも計算式は同じにならない。

## 問15

### (1) 故障電流の式

故障点までの直列リアクタンスは

```text
X(x)=0.80+0.030x [Ω]
```

したがって大きさだけを扱えば

```text
I_f(x)=25,000/(0.80+0.030x) [A]
```

である。

### (2) 各位置の電流

```text
x=0 km:
I_f=25,000/0.80=31.25 kA

x=10 km:
I_f=25,000/1.10=22.73 kA

x=20 km:
I_f=25,000/1.40=17.86 kA

x=40 km:
I_f=25,000/2.00=12.50 kA
```

### (3) 距離と故障電流

故障点が変電所から遠ざかるほど、故障点までに含まれるき電回路の直列リアクタンスが増える。電源電圧が同じなら `I=V/X` なので、故障電流は小さくなる。

### (4) 実設備値か

実設備値として扱ってはならない。本問の `25 kV`, `0.80 Ω`, `0.030 Ω/km` は故障位置と短絡電流の関係を学ぶための教材用仮定値である。実際の新幹線き電系統の故障電流を求めるには、実系統構成、変圧器、ATき電回路、電源側短絡容量等の確認済みデータが必要である。
