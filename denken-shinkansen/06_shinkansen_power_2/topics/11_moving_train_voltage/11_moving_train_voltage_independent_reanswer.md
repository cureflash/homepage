問題文から、三相平衡の有効電力は

`P = √3 V I cosφ`

`R = ρL/A`

`G = 3σAL`

また `λ = 3RI²/P` を用いて消去すると、式(6)の分母は

`9σ²ρAL³`

## 2. 平成27年度 第二種二次「電力・管理」問3

A点から距離 `y` の負荷密度を `Iy/L` とする。

### (1)a

A-P間の位置 `y` を通る電流は

`i_A(y) = ∫[0→y] Iξ/L dξ = Iy²/(2L)`

したがって

`V_A = ∫[0→x] R i_A(y)dy = RIx³/(6L)`

候補: `V_A = RIx³/(6L)`

### (1)b

P-B間の位置 `y` を通る電流は

`i_B(y) = ∫[y→L] Iξ/L dξ = I(L²-y²)/(2L)`

したがって

`V_B = ∫[x→L] R i_B(y)dy`

`= RI(2L³-3L²x+x³)/(6L)`

`= RI(L-x)²(2L+x)/(6L)`

候補: `V_B = RI(2L³-3L²x+x³)/(6L)`

### (1)c

`V_A = V_B` より

`x³ = 2L³-3L²x+x³`

したがって

候補: `x = 2L/3`

### (2)

`x = 2L/3` のとき

`V_A = 4RIL²/81`

B点給電時は `x=L` とみなせるので

`V_A(B給電) = RIL²/6`

比は

`(4/81)/(1/6) = 8/27 = 0.296296...`

候補: `約29.6 %`

判定対象: `4答案要素`

## 3. 平成27年度 第二種二次「電力・管理」問4

`V̇1 = V1∠δ`, `V̇2 = V2∠0` とする。

### (1)

候補:

`V̇1 = V̇2 + (r+jx)İ`

### (2)

送電端複素電力 `S=P+jQ=V̇1 İ*` より

候補:

`İ = (P-jQ)/V̇1*`

### (3)

(1)(2)から `İ` を消去すると

候補:

`V1² - V1V2 e^(-jδ) = (r+jx)(P-jQ)`

### (4)

左辺を実部・虚部に分けると

`V1² - V1V2 cosδ + jV1V2 sinδ`

問題文に示された `x`,`r` の式と対応させるため、

候補:
- `α = V1V2 sinδ`
- `β = V1² - V1V2 cosδ`

### (5)

`V1=1.05`, `V2=1.01`, `δ=π/12`, `P=1.23`, `Q=0.195` より

`α = 1.05×1.01×0.25882 = 0.27447861`

`β = 1.05² - 1.05×1.01×0.96593 = 0.078131235`

したがって候補:
- `x ≈ 0.2275 p.u.`
- `r ≈ 0.02745 p.u.`

判定対象: `5答案要素`

## 4. 平成26年度 第二種二次「電力・管理」問4

電源線間電圧 `6.93 kV`、1線当たり `R=5 Ω`, `X=7 Ω`、三相抵抗負荷である。

### (1)

抵抗負荷なので `İr` と `Ėr` は同相。候補ベクトル関係は

`Ės = Ėr + R İr + jX İr`

であり、`Ėr` と `Rİr` を同一実軸方向、`jXİr` をそれらより90°進み、`Ės` を合成ベクトルとして描く。

### (2)

`|Ės| = 6.93/√3 = 4.0010 kV`

`I=50 A` なので `RI=0.250 kV`, `XI=0.350 kV`。

`|Ės|² = (|Ėr|+RI)² + (XI)²`

より

`|Ėr| ≈ 3.7357 kV`

候補:

`√3|Ėr| ≈ 6.470 kV`

### (3)

電圧降下率を `(送電端電圧-受電端電圧)/受電端電圧` として10 % とすると、受電端線間電圧は

`6.93/1.10 = 6.30 kV`

1相について

`|Ės|² = (|Ėr|+RI)² + (XI)²`

を解くと

候補:
- `I ≈ 67.2 A`
- 三相抵抗負荷電力 `P = √3×6.30 kV×67.2 A ≈ 733 kW`

判定対象: `3答案要素`
