### 3. R4 二次 電力・管理 問3 — PASS

教材第2・5・6・8節から再構成。

送電線 `j0.8` が2回線並列、変圧器 `j0.2` なので、

`X_total = 0.8/2 + 0.2 = 0.6 p.u.`

有効電力平衡から

`-V_0 V_d sinθ_d/X_total = 0.5`

`sinθ_d = -(0.5×0.6)/(1.10×1.05) = -0.25974 ≈ -0.260`

無効電力は

`Q = (1.10×1.05 cosθ_d - 1.05^2)/0.6`

`= 1.925 cosθ_d - 1.8375`

母線dの無効電力平衡

`Q = 0.2 - Y_d×1.05^2`

より

`Y_d = -1.7460 cosθ_d + 1.8481`

`|θ_d|<π/2` なので `cosθ_d=+√(1-sin^2θ_d)=0.96568` を採用し、

`Y_d = 0.162 p.u.`

公式標準解答と一致。教材外知識補完なし。

### 4. R5 二次 電力・管理 問4 — PASS

教材第2・6・8節から再構成。

4 km分の一相線路定数は

`R = 0.2×4 = 0.8 Ω`

`X = 0.6×4 = 2.4 Ω`

力率0.9進みなので

`tanφ = √(1-0.9^2)/0.9 = 0.4843`

`Q = -300×0.4843 = -145.3 kvar`

(1) 電圧降下近似

`ΔV ≈ (RP+XQ)/V_r`

`= [0.8×300000 + 2.4×(-145300)]/6600`

`= -16.47 V`

したがって

`V_s = 6600 - 16.47 = 6583.5 V ≈ 6.58 kV`

(2) 500 kWの分散型電源追加後は

`P_net = 300-500 = -200 kW`

送受電端をともに6600 Vにするので `ΔV=0`。

`RP_net + XQ_net = 0`

`Q_net = -(R/X)P_net = 66.67 kvar`

既設コンデンサを含む需要家無効電力は `-145.3 kvar` なので、必要リアクトル容量は

`Q_1 = 66.67 - (-145.3) = 211.97 kvar ≈ 212 kvar`

公式標準解答と一致。教材外知識補完なし。

### 5. R6 二次 電力・管理 問4 — PASS

教材第3・4・5・7・8節から再構成。

#### (1) 等しい送り出し電圧・等しい線路インピーダンス

開閉器投入前の500 Aと300 Aの差を、等しい2線路で均等化するループ電流は

`I_l = (500-300)/2 = 100 A`

よって

- A配電線: `500-100 = 400 A`
- B配電線: `300+100 = 400 A`

#### (2) 送り出し電圧6650 V / 6600 V

`Z_A=Z_B=0.5+j1.0 Ω`

節点電圧を等置すると

`6650/√3 - (500-I_l)Z = 6600/√3 - (300+I_l)Z`

したがって

`I_l = 100 - 50/[2√3(0.5+j1.0)]`

`= 94.226 + j11.547 A`

A配電線:

`I_A = 500-I_l = 405.774-j11.547 A`

`|I_A| = 405.94 A ≈ 406 A`

B配電線:

`I_B = 300+I_l = 394.226+j11.547 A`

`|I_B| = 394.40 A ≈ 394 A`

#### (3) 三相短絡

基準 `6.6 kV, 10 MVA` で、線路 `j0.5 Ω` は

`%Z_line = 0.5×10 MVA/(6.6 kV)^2 ×100 = 11.478 %`

各枝は

`7.5 + 11.478 = 18.978 %`

2枝並列と背後 `%Z_G=1%` より

`%Z_total = 1 + 18.978/2 = 10.489 %`

したがって

`I_sc = 10 MVA/[√3×6.6 kV×0.10489]`

`= 8.34 kA`

公式標準解答と一致。教材外知識補完なし。
