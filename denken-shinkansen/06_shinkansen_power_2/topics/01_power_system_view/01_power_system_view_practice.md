# 解答・完全解説

## 問1

正答: 3

三相基準電流は

`I_B = S_B/(√3 V_B)`

より

`I_B = 100×10^6/(√3×66×10^3) = 874.8 A`

基準インピーダンスは

`Z_B = V_B^2/S_B`

より

`Z_B = (66×10^3)^2/(100×10^6) = 43.56 Ω`

したがって選択肢3。三相容量と線間電圧を用いた `Z_B` に `√3` は入らない。

## 問2

正答: 4

問1より `Z_B=43.56 Ω` なので

`Z_pu = j8.712/43.56 = j0.200 p.u.`

`%Z = 100×0.200 = 20.0%`

したがって選択肢4。`20%` を `20 p.u.` としない。

## 問3

正答: 2

皮相電力は

`|S| = P/cosφ = 8/0.8 = 10 MVA`

`cosφ=0.8` なので `sinφ=0.6`, `tanφ=0.75` である。遅れ負荷なので `Q>0` とし、

`Q = P tanφ = 8×0.75 = 6 Mvar`

よって `S=8+j6 MVA`、正答は2。選択肢3は大きさは合うが進み負荷の符号である。

## 問4

正答: 3

同じ実インピーダンスの基準変更は

`Z_pu,new = Z_pu,old × (S_new/S_old) × (V_old/V_new)^2`

である。

`Z_pu,new = 0.10×(50/20)×(22/33)^2`

`=0.1111 p.u.`

したがって

`%Z_new = 11.11%`

で、正答は3。容量比だけで換算すると `25%` となるが、今回は基準電圧も変わるため誤りである。

## 問5

正答: 4

並列部は

`Z_p = j(0.30×0.60)/(0.30+0.60)`

`=j0.20 p.u.`

共通背後分を直列に加えると

`Z_th = j(0.20+0.20)=j0.40 p.u.`

短絡前電圧を `1.0 p.u.` とすれば

`S_sc = S_B/|Z_th| = 100/0.40 = 250 MVA`

したがって選択肢4。並列部を単純加算しないことが重要である。

## 問6

正答: 1

`Z_2=2Z_1` であり、両線路は同じ偏角を持つ。並列枝電流はインピーダンスに反比例するので

`I_1 = I Z_2/(Z_1+Z_2)`

`=300×2/(1+2)=200 A`

`I_2 = I Z_1/(Z_1+Z_2)`

`=300×1/(1+2)=100 A`

よって選択肢1。低インピーダンス側の線路1に多く流れる。

## 問7

正答: 2

短絡容量は

`S_sc = S_B/Z_th,pu = 10/0.125 = 80 MVA`

三相短絡電流は

`I_sc = S_sc/(√3 V)`

`=80×10^6/(√3×6.6×10^3)`

`=6.998×10^3 A ≈ 7.00 kA`

したがって選択肢2。

## 問8

正答: 4

力率 `0.8` では `tanφ=0.75`。進みなので

`Q = -P tanφ = -500×0.75 = -375 kvar`

電圧降下一次近似は

`ΔV ≈ (RP+XQ)/V_r`

`=[0.4×500000 + 0.8×(-375000)]/6600`

`=-15.15 V`

よって

`V_s ≈ 6600-15.15 = 6584.85 V ≈ 6.585 kV`

したがって選択肢4。進み無効電力を正にすると電圧変化の向きが逆になる。

## 問9

正答: 2

抵抗を無視した線路では

`P=(V_s V_r/X) sinδ`

より

`P=(1.0×1.0/0.50) sin10°`

`=2×0.173648=0.3473 p.u.`

したがって選択肢2。

## 問10

正答: 5

選択肢5が正しい。理想変圧器をまたぐ実インピーダンスは変圧比の二乗で換算されるが、基準電圧比を変圧比に合わせると基準インピーダンス `V_B^2/S_B` も同じ比率で変わるため、p.u.値を同じ値として扱える。

他の選択肢は以下の理由で誤り。

- 1: 三相基準では `Z_B=V_B^2/S_B`。
- 2: `8%=0.08 p.u.`。
- 3: 同じ基準電圧ならp.u.インピーダンスは基準容量に比例するため2倍になる。
- 4: 本教材では進み負荷を `Q<0` とする。

## 問11

(1) 共通基準への換算

電源リアクタンスは基準電圧が自己基準と一致しているので

`X_G = 0.20×(100/50)=0.400 p.u.`

変圧器リアクタンスも、各側の基準電圧を変圧比に合わせているので容量比だけを換算し、

`X_T = 0.10×(100/25)=0.400 p.u.`

66 kV側の基準インピーダンスは

`Z_B = 66^2/100 = 43.56 Ω`

ここでkVとMVAを用いれば結果はΩになる。したがって線路は

`X_L = 8.0/43.56 = 0.18365 p.u.`

(2) 等価リアクタンス

3要素は直列なので

`X_th = 0.400+0.400+0.18365`

`=0.98365 p.u.`

(3) 短絡容量・短絡電流

`S_sc = 100/0.98365 = 101.66 MVA`

`I_sc = 101.66×10^6/(√3×66×10^3)`

`=889 A ≈ 0.889 kA`

検算として `I_sc,pu=1/0.98365≈1.0166 p.u.` であり、100 MVA・66 kVの基準電流 `874.8 A` の約1.0166倍になっている。

## 問12

有効電力式から

`0.40 = -(1.00×0.98/0.40) sinθ_d`

したがって

`sinθ_d = -0.40×0.40/0.98 = -0.163265`

`cosθ_d>0` の解を用いて

`θ_d = -9.40°`

次に線路から受電端へ供給される無効電力は

`Q = [1.00×0.98 cos(-9.40°)-0.98^2]/0.40`

`=0.01613 p.u.`

無効電力収支

`Q = Q_L - B V_d^2`

より

`0.01613 = 0.15 - B×0.98^2`

`B = (0.15-0.01613)/0.98^2`

`=0.1394 p.u.`

よって

`θ_d≈-9.40°`, `B≈0.139 p.u.`

となる。正の `B` なので容量性調相設備が無効電力を供給している。

## 問13

まず有効電力の符号を決める。負荷は系統から `+200 kW` を受け、分散電源は系統へ `500 kW` を送り出すので、受電端での正味有効電力は

`P = 200-500 = -300 kW`

である。

`V_s≈V_r` とするには一次近似で

`RP+XQ=0`

だから

`Q = -RP/X`

`=-0.3×(-300)/0.9`

`=+100 kvar`

となる。本教材の規約では `Q>0` は誘導性無効電力の消費なので、必要なのは約 `100 kvar` を吸収する分路リアクトル等の誘導性設備である。

逆潮流なのに `P=+300 kW` と置くと必要Qの符号まで逆になる。

## 問14

線路1の電流は

`I_1 = I Z_2/(Z_1+Z_2)`

`=(500-j200)(0.6+j0.6)/[(0.4+j0.8)+(0.6+j0.6)]`

`=(500-j200)(0.6+j0.6)/(1.0+j1.4)`

`=227.03-j137.84 A`

極形式では

`|I_1|=265.6 A`

`∠I_1=-31.3°`

したがって

`I_1≈265.6∠-31.3° A`

線路2は

`I_2 = I Z_1/(Z_1+Z_2)`

`=272.97-j62.16 A`

`|I_2|=280.0 A`

`∠I_2=-12.8°`

よって

`I_2≈280.0∠-12.8° A`

確認すると

`I_1+I_2=(227.03+272.97)-j(137.84+62.16)`

`=500-j200 A`

となり、合計電流と一致する。複素インピーダンスの並列分担では、インピーダンスの大きさだけで比例配分してはならない。

## 問15

(1) 共通基準への換算

`X_s = 0.05×(100/50)=0.100 p.u.`

`X_B = 0.08×(100/50)=0.160 p.u.`

(2) 並列部と全等価リアクタンス

`X_p = 0.100×0.160/(0.100+0.160)`

`=0.061538 p.u.`

共通背後分を直列に加えると

`X_th = 0.100+0.061538`

`=0.161538 p.u.`

(3) 三相短絡容量・短絡電流

`S_sc = 100/0.161538`

`=619.05 MVA`

`I_sc = 619.05×10^6/(√3×66×10^3)`
