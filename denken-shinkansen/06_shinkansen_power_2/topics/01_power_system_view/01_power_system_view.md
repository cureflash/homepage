# 解説本文

このテーマは、後続の電力系統計算で共通して使う表現方法と基準量を固める章である。一次試験では単位法、基準量、短絡容量などの定義・関係を問われ、二次試験では一線結線図を等価回路へ変換し、複素数とp.u.で途中式を組み立てる力が必要になる。

## 1. フェーザと複素数表示

交流定常状態では、実効値 `X`、位相 `θ` の正弦波

`x(t) = √2 X cos(ωt + θ)`

をフェーザ
`X = X∠θ = X(cosθ + j sinθ)`

で表す。加減算は直交形式 `a+jb`、乗除算は極形式 `r∠θ` が便利である。

`r = √(a^2+b^2)`

`θ = atan2(b,a)`

インピーダンスは `Z=R+jX`、電流は `I=V/Z`。`X>0` は誘導性、`X<0` は容量性である。二次試験では基準とする電圧フェーザを最初に決め、途中で位相角の基準を変えない。

## 2. 複素電力とP/Q/S・力率

受動符号規約では

`S = V I* = P + jQ`

平衡三相では

`S = 3 V_phase I_phase* = √3 V_line I_line*`

である。

`|S| = √(P^2+Q^2)`

`cosφ = P/|S|`

`Q = P tanφ`

本教材では負荷が系統から有効電力を受ける向きを `P>0`、遅れ力率の誘導性負荷を `Q>0`、進み力率の容量性負荷を `Q<0` とする。逆潮流では `P<0` になり得る。

三相負荷の線電流は

`I = |S|/(√3 V_line) = P/(√3 V_line cosφ)`

で求める。

## 3. 基準量とp.u.

単位法では

`quantity_pu = quantity_actual / quantity_base`

とする。三相系で基準容量 `S_B` を三相容量、基準電圧 `V_B` を線間電圧として選ぶと

`I_B = S_B/(√3 V_B)`

`Z_B = V_B^2/S_B`

となる。`Z_B` に余分な `√3` は入らない。

### タービン発電機の直軸過渡リアクタンス

H29一次電力問6で問われる代表知識として、タービン発電機の直軸過渡リアクタンス `X_d'` は、おおむね `0.2～0.4 p.u.` が代表範囲である。

これは選択問題で用いる代表値である。個別の機器定数が問題文で与えられた場合は、代表値より問題文の値を優先する。

### 基礎例題

三相基準容量 `100 MVA`、基準線間電圧 `66 kV` とする。

`I_B = 100×10^6/(√3×66×10^3) = 874.8 A`

`Z_B = (66×10^3)^2/(100×10^6) = 43.56 Ω`

したがって `j8.712 Ω` は

`Z_pu = j8.712/43.56 = j0.200 p.u.`

である。

## 4. Ω ↔ p.u. ↔ % と基準変更

`Z_pu = Z_actual/Z_B`

`Z_actual = Z_pu Z_B`

`%Z = 100 Z_pu`

基準変更は

`Z_pu,new = Z_pu,old × (S_B,new/S_B,old) × (V_B,old/V_B,new)^2`

を用いる。基準電圧が同じならp.u.値は基準容量に比例する。

変圧器をまたぐ場合、各側の基準電圧を変圧比に合わせ、基準容量を共通にすれば、理想変圧器によるオーム換算を毎回行わず同じp.u.回路へ接続できる。

## 5. 一線結線図からp.u.等価回路

標準手順は次のとおり。

1. 対象範囲と電力の向きを決める。
2. 三相基準容量 `S_B` を一つ決める。
3. ある母線で基準線間電圧 `V_B` を決める。
4. 変圧器をまたぐ各母線の基準電圧を変圧比に合わせる。
5. 各機器の `Ω`、p.u.、％値を共通基準のp.u.へ換算する。
6. 一相等価回路として並べる。
7. 直列・並列合成を行う。
8. 負荷を `P+jQ` または対応する電流で表す。

`Z_series = Z_1+Z_2+...`

`Z_parallel = Z_1 Z_2/(Z_1+Z_2)`

二電源の電圧が異なる場合は循環電流が生じる。単純な二電源・二インピーダンスのループでは

`I_c = (E_A-E_B)/(Z_A+Z_B)`

が基本形である。

## 6. 電圧・位相差とP/Q

抵抗を無視したリアクタンス `jX` で、`δ=δ_s-δ_r` とすれば

`P = (V_s V_r/X) sinδ`

受電端で消費される無効電力を正に取ると

`Q = (V_s V_r cosδ - V_r^2)/X`

の形になる。符号は問題の正方向定義に依存するため、電圧フェーザと電流方向を先に固定する。

短い三相線路の電圧降下一次近似は

`ΔV ≈ (R P + X Q)/V_r`

である。`R`、`X` は一相分、`P`、`Q` は三相合計として単位をそろえる。

- 遅れ `Q>0`: 通常、電圧降下を増やす。
- 進み `Q<0`: 電圧降下を減らす。
- 逆潮流 `P<0`: 抵抗分の寄与も反転する。

### 本試験標準例題

`V_r=6.6 kV`、`P=400 kW`、力率 `0.9` 進み、`R=0.6 Ω`、`X=1.8 Ω` とする。

`tanφ=0.4843`

進みなので

`Q=-400×0.4843=-193.7 kvar`

`ΔV ≈ [0.6×400000 + 1.8×(-193700)]/6600 = -16.5 V`

`V_s ≈ 6.58 kV`

となる。

## 7. 短絡容量と駆動点インピーダンス

三相対称短絡の基本関係だけを扱う。短絡点から系統側を見た正相等価インピーダンスを `Z_th` とし、短絡前電圧を約 `1.0 p.u.` とすれば

`I_sc,pu = 1/Z_th,pu`

基準容量を `S_B` とすると

`S_sc = S_B/|Z_th,pu|`

実量では

`S_sc = √3 V I_sc`

である。

### 駆動点インピーダンスと節点インピーダンス行列

節点方程式を

`V = Z_bus I`

と書く。母線 `k` に電流を注入したとき、同じ母線 `k` の電圧応答を与える対角要素 `Z_kk` が、その母線から見た駆動点インピーダンスである。三相対称短絡では正相の駆動点インピーダンスを用いる。

### 短絡容量と系統の強さ・電圧維持能力

同じ基準容量なら、駆動点インピーダンスが小さいほど短絡容量は大きい。連系が密になり並列経路が増えると、一般に `Z_th` は小さくなり、`S_sc` は大きくなる。

短絡容量は事故電流の大きさだけでなく、その地点の系統の強さを表す一つの指標として読む。直観的には

`ΔV ≈ Z_th ΔI`

なので、同じ電流変化に対して `Z_th` が小さい系統ほど電圧変動が小さい。したがって短絡容量が大きい地点ほど、一般に電圧維持能力が高いと解釈できる。

ただし短絡容量だけで安定度全般を評価するわけではない。

### 複合例題

基準を `10 MVA, 6.6 kV` とする。共通背後リアクタンス `j0.05 p.u.` の先に `j0.15 p.u.` と `j0.25 p.u.` の二経路が並列にある。

`Z_p = j(0.15×0.25)/(0.15+0.25) = j0.09375 p.u.`

`Z_th = j(0.05+0.09375) = j0.14375 p.u.`

`S_sc = 10/0.14375 = 69.6 MVA`

`I_sc = 69.6×10^6/(√3×6.6×10^3) = 6.09 kA`

ここでは三相対称短絡までとし、対称座標法や一線地絡・線間短絡はTopic 16へ送る。
