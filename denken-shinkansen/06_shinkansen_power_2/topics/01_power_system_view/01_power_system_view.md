# 解説本文

このテーマは、後続の電力系統計算で共通して使う「表現方法」と「基準量」を固める章である。一次試験では単位法、基準量、短絡容量などの定義・関係を問われ、二次試験では一線結線図を等価回路へ変換し、複素数とp.u.で途中式を組み立てる力が必要になる。ここではTopic 01の範囲に限定し、本格的な潮流計算、故障種別計算、変圧器並列運転、過渡安定度は扱わない。

## 1. フェーザと複素数表示

交流定常状態では、同じ角周波数をもつ正弦波を大きさと位相で表すと計算しやすい。実効値を `X`、位相を `θ` とする正弦波

`x(t) = √2 X cos(ωt + θ)`

を、フェーザ

`X = X∠θ = X(cosθ + j sinθ)`

で表す。電験の交流計算では、特記がなければフェーザの大きさは実効値として扱う。

直交形式 `a + jb` と極形式 `r∠θ` は、

- 加減算: 直交形式が便利
- 乗除算: 極形式が便利

という使い分けをする。変換は

`r = √(a^2 + b^2)`

`θ = atan2(b, a)`

である。

インピーダンスは

`Z = R + jX`

と表す。`X>0` は誘導性、`X<0` は容量性である。電流は

`I = V/Z`

なので、抵抗だけなら電圧と同相、誘導性リアクタンスが支配的なら電流が遅れ、容量性なら電流が進む。

問題では最初に基準とする電圧フェーザを一つ決める。例えば受電端を `V_r∠0` と置けば、他の位相角はすべてこれに対する相対角として書ける。二次試験では、この基準方向を途中で変えないことが重要である。

## 2. 複素電力とP/Q/S・力率

負荷へ流れ込む電流を正とする受動符号規約では、単相の複素電力は

`S = V I* = P + jQ`

である。`I*` は電流フェーザの複素共役である。平衡三相では

`S = 3 V_phase I_phase*`

または線間電圧・線電流を用いて

`S = √3 V_line I_line*`

と書ける。ここで `S` の単位は VA、`P` は W、`Q` は var である。

大きさの関係は

`|S| = √(P^2 + Q^2)`

`力率 = cosφ = P/|S|`

`Q = P tanφ`

である。ただし最後の式では符号を別に判断する。

本教材では、負荷が系統から電力を受け取る向きを `P>0` とする。無効電力は

- 遅れ力率の誘導性負荷: `Q>0`
- 進み力率の容量性負荷: `Q<0`

とする。逆潮流では `P<0` になり得る。電圧降下や調相計算では、この符号を最後まで固定する。

三相負荷の線電流の大きさは

`I = |S|/(√3 V_line) = P/(√3 V_line cosφ)`

で求められる。二次試験では、まず `P` と力率から `Q` または `|S|` を求め、次に電流や電圧降下へ進む形が多い。

## 3. 基準量とp.u.

単位法では、基準値で実際の量を割って無次元化する。

`quantity_pu = quantity_actual / quantity_base`

三相系では、基準容量 `S_B` を三相容量、基準電圧 `V_B` を線間電圧として選ぶ。すると基準電流は

`I_B = S_B/(√3 V_B)`

である。

基準インピーダンスは

`Z_B = (V_B/√3)/(I_B)`

に `I_B = S_B/(√3 V_B)` を代入して

`Z_B = V_B^2/S_B`

となる。したがって `Z_B` に余分な `√3` は入らない。

p.u.値は、異なる電圧階級の機器を同じ尺度で扱えることが利点である。例えば `0.10 p.u.` のリアクタンスは、基準値に対して10%の大きさをもつことを表す。実際のオーム値は基準電圧・基準容量によって変わるため、p.u.値を使う前に基準値を必ず明記する。

### 基礎例題

三相基準容量を `100 MVA`、基準線間電圧を `66 kV` とする。基準電流と基準インピーダンスを求める。

`I_B = 100×10^6/(√3×66×10^3) = 874.8 A`

`Z_B = (66×10^3)^2/(100×10^6) = 43.56 Ω`

よって、同じ基準上で `j8.712 Ω` のリアクタンスは

`Z_pu = j8.712/43.56 = j0.200 p.u.`

である。

## 4. Ω ↔ p.u. ↔ % と基準変更

実インピーダンスとp.u.の変換は

`Z_pu = Z_actual/Z_B`

`Z_actual = Z_pu Z_B`

である。百分率インピーダンスは

`%Z = 100 Z_pu`

なので、`0.08 p.u. = 8%` である。

同じ実インピーダンスを別の基準へ換算するときは

`Z_pu,new = Z_pu,old × (S_B,new/S_B,old) × (V_B,old/V_B,new)^2`

を用いる。基準電圧が同じなら、p.u.値は基準容量に比例する。

変圧器をまたぐ場合、各側の基準電圧を変圧比に合わせて選び、基準容量を共通にすれば、理想変圧器によるオーム換算を毎回行わずに同じp.u.回路へ接続できる。これは、実インピーダンスが変圧比の二乗で換算される一方、基準インピーダンス `V_B^2/S_B` も同じ比率で変化するためである。

機器の銘板％インピーダンスは、その機器の定格容量・定格電圧を基準とすることが多い。系統共通基準へ移すときは、そのまま足さず、必要なら基準変更してから合成する。

## 5. 一線結線図からp.u.等価回路

一線結線図を二次試験で計算可能な等価回路へ変換する基本手順は次のとおり。

1. 対象範囲と電力の向きを決める。
2. 三相基準容量 `S_B` を一つ決める。
3. ある母線で基準線間電圧 `V_B` を決める。
4. 変圧器をまたぐ各母線の基準電圧を変圧比に合わせて決める。
5. 各機器の `Ω`、p.u.、％値を共通基準のp.u.へ換算する。
6. 発電機・系統背後インピーダンス、送電線、変圧器などを一相等価回路として並べる。
7. 直列・並列合成を行う。
8. 負荷は `P+jQ` または対応する電流で表す。

直列合成は

`Z_series = Z_1 + Z_2 + ...`

並列合成は二枝なら

`Z_parallel = Z_1 Z_2/(Z_1 + Z_2)`

である。

二つの電源から同じ母線へ給電しており、電源電圧が異なる場合は、負荷電流だけでなく循環電流が生じる。単純な二電源・二インピーダンスのループなら、電圧差による循環電流の基本形は

`I_c = (E_A - E_B)/(Z_A + Z_B)`

となる。実際の枝電流は、負荷分担電流と循環電流を複素数として加減して求める。

## 6. 電圧・位相差とP/Q

抵抗を無視したリアクタンス `jX` で、送電端 `V_s∠δ_s` と受電端 `V_r∠δ_r` が接続されているとする。`δ = δ_s - δ_r` と置けば、送電端から受電端へ送られる有効電力の基本形は

`P = (V_s V_r/X) sinδ`

である。

受電端で消費される無効電力を正に取ると

`Q = (V_s V_r cosδ - V_r^2)/X`

の形が得られる。問題によって電力の正方向や位相角の定義が逆なら符号も変わるため、公式だけを暗記せず、最初に電圧フェーザと電流の向きを図へ書く。

抵抗 `R` とリアクタンス `X` をもつ短い三相線路で、受電端線間電圧を `V_r`、受電端三相電力を `P+jQ` とすると、電圧降下の一次近似は

`ΔV ≈ (R P + X Q)/V_r`

である。`R`、`X` は一相分、`P`、`Q` は三相合計、各量は整合したSI単位で用いる。

この式から、

- 遅れ負荷 `Q>0` は通常、電圧降下を増やす。
- 進み負荷 `Q<0` は電圧降下を減らし、条件によっては電圧上昇になる。
- 逆潮流 `P<0` では抵抗分の寄与も反転する。

と読める。送り出し電圧と受電端電圧をほぼ等しくしたいなら、一次近似では

`R P + X Q ≈ 0`

が目安になる。

### 本試験標準例題

受電端線間電圧 `6.6 kV`、三相有効電力 `400 kW`、力率 `0.9` 進み、線路一相分 `R=0.6 Ω`、`X=1.8 Ω` とする。送り出し電圧を一次近似で求める。

`φ = cos^-1(0.9)` より

`tanφ = 0.4843`

進みなので

`Q = -P tanφ = -400×0.4843 = -193.7 kvar`

したがって

`ΔV ≈ [0.6×400000 + 1.8×(-193700)]/6600`

`ΔV ≈ -16.5 V`

よって

`V_s ≈ 6600 - 16.5 = 6583.5 V ≈ 6.58 kV`

となる。進み無効電力を正として代入すると符号が逆になり、誤答する。

## 7. 短絡容量とp.u.インピーダンス

三相対称短絡の基本関係だけを扱う。短絡点から系統側を見た等価インピーダンスを `Z_th` とし、短絡前電圧を約 `1.0 p.u.` とすれば

`I_sc,pu = 1/Z_th,pu`

である。

基準容量を `S_B` とすると短絡容量は

`S_sc = S_B/|Z_th,pu|`

また、実量では

`S_sc = √3 V I_sc`

である。

したがって、同じ基準容量なら駆動点インピーダンスが小さいほど短絡容量は大きい。系統連系が増えて短絡点から見た並列経路が増えると、一般に等価インピーダンスは低下し、短絡容量は増加する。

ここでは三相対称短絡に必要な基本関係までとし、対称座標法や一線地絡・線間短絡などの故障種別計算はTopic 16へ送る。

### 複合例題

基準を `10 MVA, 6.6 kV` とする。母線までの共通背後リアクタンスが `j0.05 p.u.`、その先に `j0.15 p.u.` と `j0.25 p.u.` の二経路が並列にある。末端母線の三相短絡容量と短絡電流を求める。

並列部は

`Z_p = j(0.15×0.25)/(0.15+0.25) = j0.09375 p.u.`

したがって

`Z_th = j(0.05 + 0.09375) = j0.14375 p.u.`

短絡容量は

`S_sc = 10/0.14375 = 69.6 MVA`

短絡電流は

`I_sc = 69.6×10^6/(√3×6.6×10^3) = 6.09 kA`

となる。％表示なら `14.375%` であり、`0.14375%` ではない。

## 8. 二次試験の記述手順

二次試験では最終数値だけでなく、どの前提からどの式を選んだかが採点対象になる。Topic 01の問題では次の順序を基本形とする。

1. 基準容量、基準電圧、電力・電流の正方向を明記する。
2. 力率があれば遅れ・進みを確認し、`Q` の符号を確定する。
3. 必要なら `I_B`、`Z_B` を計算する。
4. すべてのインピーダンスを共通のp.u.または％基準へそろえる。
5. 一線結線図を一相等価回路へ変換する。
6. 直列・並列合成、またはフェーザ方程式を立てる。
7. 求める量について式を整理してから数値代入する。
8. 単位を付け、桁を確認する。
9. 遅れ/進み、潮流方向、電圧上昇/降下など物理的な向きが結果と矛盾しないか検算する。

記述では、例えば `Q<0 because leading power factor` のような判断を式の直前に日本語で一言書くだけでも、符号の根拠が明確になる。近似式を使う場合は「電圧降下が小さいとして一次近似」など、成立条件も書く。

頻出ミスは次のとおり。

- 線間電圧と相電圧を混ぜる。
- 三相容量なのに `√3` を二重に入れる。
- ％値をp.u.としてそのまま使う。
- 基準容量だけ変更して基準電圧の変更を落とす。
- 進み力率の `Q` を正にする。
- 逆潮流でも `P` を正のままにする。
- 複素インピーダンスの並列合成を大きさだけで行う。

## 9. 新幹線系統モデルへの接続

SPECの基本モデルは

```text
発電機
↓
送電線
↓
受電変電所
↓
き電用変圧器
↓
ATき電回路
↓
列車負荷
```

である。Topic 01では、これを次の計算モデルへ変換する。

```text
E∠δ
  |
  Z_source
  |
  Z_transmission
  |
  Z_transformer
  |
  Z_feeder
  |
  S_train = P + jQ
```

手順は一般の電力系統と同じである。まず共通基準容量を決め、各電圧階級の基準電圧を変圧比に合わせる。次に、発電側・送電線・変圧器・き電回路のインピーダンスを共通p.u.へそろえ、列車負荷を `P+jQ` で置く。

この段階で重要なのは、実車・実設備の数値を覚えることではない。新幹線の電力供給系統も、電験で扱う一般の電力系統と同じく、

`電源フェーザ + 系統インピーダンス + 複素負荷`

へ落とせることを理解することである。

実際の変圧器％インピーダンスの詳細はTopic 08、本格的な潮流計算はTopic 12、故障種別計算はTopic 16、安定度はTopic 20で扱う。Topic 01では、その全てに共通する表現・基準・符号・等価回路化までを確実にする。
