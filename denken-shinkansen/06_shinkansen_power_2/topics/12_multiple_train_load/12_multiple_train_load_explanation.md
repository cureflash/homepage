## 1. このテーマで電験は何を問うか

Topic 12では、複数の負荷を同時に系統へ接続したときに、最大需要、線路電流、線路潮流、ノード電圧、線路損失がどう変化するかを計算できることを到達点とする。

電験二種では「列車が増えれば負荷が増える」で終わらない。次を区別して式でつなぐ必要がある。

1. 設備容量と実際の最大需要を需要率で区別する。
2. 個々の最大需要の発生時刻が一致しない場合、不等率で合成最大需要を求める。
3. 平均需要と最大需要を負荷率で区別する。
4. 各負荷の `P+jQ` から複素電流を求める。
5. 複数枝では各負荷電流と区間電流をKCLで分ける。
6. `I=(V_s-V_r)/Z` と `S=V_r I*` から簡易潮流・ノード電圧を求める。
7. 線路電流から `I^2R` 損失を求め、負荷増加で損失が非線形に増えることを説明する。
8. 時間変化する負荷では、負荷率と損失係数を区別する。

扱うのは複数負荷・需要率・不等率・負荷率・簡易電力潮流・ノード電圧・線路潮流である。対称座標法、調相設備、逆潮流、短絡、保護、安定度、周波数制御へは進まない。

## 2. 最大需要・需要率・不等率・負荷率

### 2.1 最大需要

ある期間内で実際に現れた最大の需要電力を最大需要電力 `P_max` とする。設備容量をそのまま最大需要とみなしてはいけない。

設備容量が `S_rated [kV·A]`、力率が `cosφ`、需要率が `d` のとき、需要率の基準が設備の有効電力換算値である問題では

`P_max = S_rated cosφ × d`

とする。

問題文が需要率の分母を別に定義している場合は、その定義を優先する。

### 2.2 需要率

`需要率 d = 最大需要電力 / 設備容量側の基準電力`

通常 `0 <= d <= 1` である。設備容量全部が同時に使われないことを表す。

### 2.3 不等率

複数負荷の個別最大需要の和を、合成最大需要で割ったものを不等率 `F_d` とする。

`F_d = ΣP_max,i / P_max,total`

したがって

`P_max,total = ΣP_max,i / F_d`

である。通常 `F_d >= 1` であり、最大需要の発生時刻が完全に一致する場合は1に近づく。

需要率と不等率を同じ係数として扱ってはいけない。需要率は「設備容量→個別最大需要」、不等率は「個別最大需要の和→合成最大需要」に使う。

### 2.4 負荷率

`負荷率 F_L = 平均需要電力 P_avg / 最大需要電力 P_max`

である。最大需要が同じでも、平均需要が大きいほど負荷率は高い。

複数負荷の総合負荷率を求めるときは、各負荷率を単純平均しない。まず各負荷の平均需要を求めて足し、その合計を総合最大需要で割る。

## 3. 複素電力と進み・遅れの符号規約

本Topicの負荷側符号規約を

`S = P + jQ`

とする。

- 有効電力を消費する負荷: `P > 0`
- 遅れ無効電力を消費する負荷: `Q > 0`
- 進み無効電力の負荷: `Q < 0`

ここを文章の「進み」「遅れ」だけで処理せず、必ず `Q` の符号へ変換してから複素数計算へ進む。

### 3.1 単相等価回路

受電端電圧 `V`、負荷電流 `I` に対して

`S = VI*`

なので

`I = (S/V)*`

である。`V` を基準位相0の実数とすれば

`I = (P - jQ)/V`

となる。

### 3.2 平衡三相負荷

線間電圧の実効値を `V` とし、本教材の三相電力表現を

`S = √3 V I*`

と置くと、基準電圧位相を0とした負荷電流は

`I = (P - jQ)/(√3 V)`

となる。

ここで共役があるため、`S=P+jQ` の虚部の符号がそのまま `I` の虚部へ入るのではなく反転する。

- 遅れ `Q>0` → `I` の虚部は負
- 進み `Q<0` → `-jQ` が正の虚部になる

制作前独立再解答で検出した2要素の不足はこの符号規約である。

### 3.3 文章から式へ変換する手順

例として「有効電力4 MW、進み無効電力1 Mvar」と与えられたら、

1. `P=4 MW`
2. 進みなので `Q=-1 Mvar`
3. `S=4-j1 MVA`
4. `I=(P-jQ)/(√3V)=(4+j1)×10^6/(√3V)`

の順で処理する。

「進みだから電流の虚部を負にする」と暗記してはいけない。最初に `Q` を符号付きで決め、共役を通して電流を求める。

## 4. 定電力負荷では電圧低下で電流が増える

負荷が定電力 `S=P+jQ` としてモデル化される場合、

`|I| = |S|/(√3|V|)`

である。したがって `P,Q` が一定なら、ノード電圧が下がるほど電流は増える。

これは一定インピーダンス負荷とは異なる。定電力負荷では「電圧が下がったから電流も下がる」とは限らない。

列車本数が増えると総負荷が増え、線路電流が増える。さらに線路電圧が低下すると、定電力モデルでは電流が追加的に増える。このため線路損失は単純な負荷電力比例より強く増加し得る。

## 5. 複数負荷の合成と区間電流

### 5.1 同一ノードに接続された負荷

同じノード電圧へ接続された複数負荷なら、複素電力は

`S_total = ΣS_i = ΣP_i + jΣQ_i`

と加算できる。

ただし、最大需要を扱う問題で各負荷の最大発生時刻が一致しない場合は、個別最大値をそのまま足さず不等率を使う。

### 5.2 放射状線路の区間電流

```text
電源 ── 区間1 ── 負荷A ── 区間2 ── 負荷B
```

負荷電流を `I_A, I_B` とすると、KCLから

- 区間2: `I_2 = I_B`
- 区間1: `I_1 = I_A + I_B`

となる。

各区間の電圧降下は

`ΔV_k = Z_k I_k`

で求める。負荷電流と線路区間電流を同じものとして扱わない。

## 6. 複数枝・連系時の線路潮流

複数枝では、まず各負荷電流の符号を確定し、その後にKCL・KVLを使う。

二つの枝インピーダンスを `Z_a, Z_b`、連系前に各枝が受け持つ負荷電流を `I_A, I_B` とする。連系後のループ電流 `J` を「枝a側から枝b側へ正」と定義し、両負荷ノードが理想連系で同電位になる単純モデルなら

`Z_a(I_A + J) = Z_b(I_B - J)`

なので

`J = (Z_b I_B - Z_a I_A)/(Z_a + Z_b)`

となる。

この式は向きの定義に依存するため、符号だけ暗記しない。解法順は固定する。

1. 各負荷の `P,Q` の符号を決める。
2. `S=√3VI*` から各負荷電流を求める。
3. ループ電流の正方向を図に置く。
4. 各枝電流を `I_A+J`, `I_B-J` のように表す。
5. KVLを立てる。
6. `J` を解く。
7. 得られた符号が仮定した向きと一致するか確認する。

進み負荷の `Q` 符号を誤ると、負荷電流だけでなくKVLで求めるループ電流まで連鎖して誤る。

## 7. 1枝1負荷の簡易電力潮流

複数負荷へ進む前に、1枝1負荷の潮流式を再利用できる形にする。

送電端電圧を `V_s∠δ`、受電端電圧を `V_r∠0`、線路を純リアクタンス `jX` とすると

`I = (V_s∠δ - V_r)/(jX)`

受電端で

`S = P + jQ = V_r I*`

である。整理すると

`P = V_s V_r sinδ / X`

`Q = (V_s V_r cosδ - V_r^2)/X`

となる。

この符号規約では受電負荷の遅れ無効電力を正とする。

二次試験では式を暗記するだけでなく、`I=(V_s-V_r)/jX` → 共役 → `S=V_rI*` の順に導出できることが必要である。

### ノード電圧を求める流れ

1. 既知の `P,Q,V_s,X` を整理する。
2. 上のP式・Q式を立てる。
3. `sinδ`, `cosδ` を含む連立関係にする。
4. `sin^2δ+cos^2δ=1` を使って `V_r` を求める。
5. `V_r` から `δ` を求める。
6. 電圧の大きさ、位相差、P・Qの符号を元式へ戻して検算する。

本Topicでは簡易潮流までとし、反復潮流法や安定限界解析へは進まない。

## 8. 列車本数→線路電流→電圧→損失

同一条件の負荷を `n` 個、1負荷あたり `S_1=P_1+jQ_1` とする単純モデルでは

`S_total = nS_1`

である。

電圧を一定と近似できる範囲では

`|I| = |S_total|/(√3V) ∝ n`

となる。1線あたり抵抗を `R` とする平衡三相線路では

`P_loss = 3|I|^2R`

なので

`P_loss ∝ n^2`

となる。

ただし定電力負荷で電圧低下を無視できない場合は `|I|=|S|/(√3|V|)` であるため、`V` 自体を潮流計算で更新する必要がある。

小さな電圧降下の近似では、三相線路の線間電圧降下は

`ΔV ≈ √3 I(Rcosφ + Xsinφ)`

であり、三相合計の `P,Q` を使えば

`ΔV ≈ (RP + XQ)/V`

と書ける。遅れ `Q>0` ではリアクタンス項が電圧降下を増やす。進み `Q<0` の扱いは符号規約に従うだけで、本Topicでは調相設備による電圧制御へ拡張しない。

## 9. 負荷パターン・負荷率・損失係数

列車本数や同時加速状態は時間で変化する。そのため最大時点だけでなく、期間平均も区別する。

時間帯 `k` の継続時間を `t_k`、有効電力を `P_k` とすると

`P_avg = Σ(P_k t_k) / Σt_k`

`F_L = P_avg/P_max`

である。

電圧・力率・線路抵抗が一定とみなせる場合

`I ∝ P`

`P_loss ∝ I^2 ∝ P^2`

なので

`P_loss,avg = Σ(P_loss,k t_k)/Σt_k`

`損失係数 F_loss = P_loss,avg/P_loss,max`

と定義する。

同一期間で、最大需要時のkW損失率を `r_kW=P_loss,max/P_max`、期間のkWh損失率を `r_kWh=E_loss/E_load` とすれば

`r_kWh = (F_loss/F_L) r_kW`

となる。

負荷率と損失係数は同じではない。損失が電流の二乗に比例するため、時間変化を二乗した平均が必要になる。

## 10. 本試験標準の解法アルゴリズム

1. 設備容量、最大需要、平均需要のどれが与えられているかを分ける。
2. 需要率・不等率・負荷率の定義と分子・分母を確認する。
3. 複数負荷の `P,Q` を符号付きで整理する。進みなら `Q<0`、遅れなら `Q>0`。
4. 負荷モデルが定電力かを確認する。
5. `S=VI*` または `S=√3VI*` から負荷電流を求める。
6. KCLで区間電流を求める。
7. 複数枝・連系ならループ電流の正方向を定義してKVLを解く。
8. 1枝潮流なら `I=(V_s-V_r)/Z` と `S=V_rI*` を連立する。
9. ノード電圧を求める。
10. 各線路電流から `I^2R` 損失を求める。
11. 時間パターン問題なら平均負荷・最大負荷・平均損失・最大損失を別々に求める。
12. 単位、力率、進み/遅れ、電流方向、電圧大小、損失の正値を検算する。

## 11. 3段階例題

### 11.1 基礎例題: 需要率・不等率・負荷率

二つの需要設備A、Bがある。Aは設備容量10 MVA、力率0.90、需要率0.80、Bは設備容量8 MVA、力率0.95、需要率0.75とする。両設備の不等率は1.25、期間平均有効電力はAが4.0 MW、Bが3.0 MWとする。

Aの最大需要:

`P_A,max = 10×0.90×0.80 = 7.20 MW`

Bの最大需要:

`P_B,max = 8×0.95×0.75 = 5.70 MW`

個別最大の和:

`ΣP_max = 12.90 MW`

合成最大需要:

`P_total,max = 12.90/1.25 = 10.32 MW`

合成平均需要:

`P_total,avg = 4.0+3.0 = 7.0 MW`

総合負荷率:

`F_L = 7.0/10.32 = 0.678 ≈ 67.8%`

要点は、需要率で個別最大を出してから不等率を使い、最後に平均需要との比で総合負荷率を出すことである。

### 11.2 本試験標準例題: 進み・遅れを含む複素負荷電流

66 kV平衡三相母線に二つの定電力負荷が接続されているとする。仮定値として、負荷Aは `P_A=6 MW, Q_A=+3 Mvar`、負荷Bは `P_B=4 MW`、進み無効電力1 Mvarとする。母線電圧を基準位相とする。

負荷Bは進みなので

`Q_B=-1 Mvar`

である。

三相負荷電流は

`I=(P-jQ)/(√3V)`

より、

`I_A=(6-j3)×10^6/(√3×66×10^3)`

`=52.49-j26.24 A`

負荷Bは

`I_B=(4-j(-1))×10^6/(√3×66×10^3)`

`=34.99+j8.75 A`

したがって合成電流は

`I_total=I_A+I_B=87.48-j17.50 A`

`|I_total|≈89.21 A`

である。

進み負荷Bで虚部が正になるのは、先に `Q_B=-1` とした後、共役関係によって `P-jQ` を使うためである。

### 11.3 複合例題: 負荷数と電圧降下・損失

66 kV平衡三相系統に、同じ仮定負荷を1〜4個接続する。1負荷あたり `P_1=2 MW`、力率0.90遅れ、線路1線あたり `R=0.50 Ω, X=1.00 Ω` とし、まず受電電圧を66 kV一定と近似する。

1負荷あたり

`Q_1=P_1 tan(cos^-1 0.90)≈0.969 Mvar`

である。

`n` 個では

`P=nP_1, Q=nQ_1`

`|I|=sqrt(P^2+Q^2)/(√3V)`

`P_loss=3I^2R`

`ΔV≈(RP+XQ)/V`

を用いる。

| n | 総P [MW] | 総Q [Mvar] | |I| [A] | 線路損失 [kW] | 近似ΔV [V] |
|---:|---:|---:|---:|---:|---:|
| 1 | 2 | 0.969 | 19.44 | 0.567 | 29.8 |
| 2 | 4 | 1.937 | 38.88 | 2.267 | 59.7 |
| 3 | 6 | 2.906 | 58.32 | 5.102 | 89.5 |
| 4 | 8 | 3.875 | 77.76 | 9.069 | 119.3 |

電圧一定近似では電流は `n` に比例し、損失はほぼ `n^2` に比例する。実際の定電力潮流では負荷増加により受電電圧も変わるため、次工程の計算プログラムではノード電圧を更新して評価する。

## 12. 新幹線への接続

SPECの主題に沿って、複数の列車を同時負荷として配置する。未確認のN700S実車最大出力やき電設備定格は真値として置かない。

計算プログラム段階では、値を置く場合は明示的に仮定値とし、少なくとも次を可視化対象にする。

- 列車本数―変電所負荷
- 列車本数―最低電圧
- 列車位置―損失
- 同時加速条件の比較

新幹線は複数負荷・潮流・損失を具体化する題材であり、実車性能そのものを暗記対象にしない。

## 13. 頻出ミス

- 設備容量をそのまま最大需要とする。
- 需要率と不等率を同じ係数として使う。
- 各負荷率を単純平均して総合負荷率とする。
- 「進み1 Mvar」を `Q=+1 Mvar` とする。
- `S=P+jQ` から電流を求めるとき共役を忘れ、`I=(P+jQ)/(√3V)` とする。
- 定電力負荷を一定インピーダンス負荷と同じように扱う。
- 負荷電流と上流区間の合成電流を混同する。
- KVLを立てる前にループ電流の正方向を決めない。
- `P_loss` が電流ではなく電流の二乗に比例することを忘れる。
- 負荷率と損失係数を混同する。
- 線間電圧・相電圧、単相式・三相式を混在させる。
