## 問1 基礎・一次型: 力行と回生の正味電力

3. `0 MW`
4. `-3 MW`、すなわち `3 MW` の逆潮流
5. `-13 MW`、すなわち `13 MW` の逆潮流

## 問5 本試験標準・一次型: 二次電池の用途・特徴・用語

二次電池電力貯蔵設備について、最も適切な説明を選べ。

1. NaS電池は代表的な常温作動型電池であり、SOCは充放電速度を表す。
2. リチウムイオン電池は一般にエネルギー密度が低く、Cレートは蓄電残量を百分率で示す。
3. NaS電池は代表的に約300 ℃程度で作動し、リチウムイオン電池は高いエネルギー密度を持つ。レドックスフロー電池ではエネルギー容量を主に電解液・タンク量、出力を主にセルスタック側で設計できる。自己放電は外部負荷がなくても蓄電量が減る現象で、蓄電設備は負荷平準化、バックアップ、出力変動吸収、短時間の周波数調整等に利用できる。
4. レドックスフロー電池では出力をタンク容量だけで決め、エネルギー容量をセルスタックだけで決める。
5. 自己放電とは、需要ピーク時に計画的に負荷へ放電する運用をいう。

## 問7 本試験標準・一次型: 系統受容性と回生失効の概念

教材用仮定値として、同時刻に力行 `2.0 MW`、回生 `6.0 MW`、蓄電設備への充電 `1.5 MW` があり、放電はない。上位系統は逆潮流を最大 `1.0 MW` まで受け入れられるとする。最も適切な説明を選べ。

1. 正味電力は `+5.5 MW` なので、上位系統から受電する。
2. 正味電力は `-2.5 MW` である。上位系統が `1.0 MW` しか受け入れられず他の受入先もなければ、残る `1.5 MW` は受入先がない。逆潮流は電圧上昇の要因になり得、受入余地が尽きれば回生失効の概念につながるが、具体的なしきい値はこの条件からは決められない。

4. 回生電力が力行電力を上回っても、蓄電池があれば必ず全量を吸収できる。
5. 回生失効は短絡電流が遮断器定格を超えた状態をいう。

# 解答・完全解説

## 問1 解答: 4

正味列車電力は

`P_train,net = P_traction - P_regen = 5 - 8 = -3 MW`

である。負号は、教材の符号規約では列車側から上位系統側へ電力が戻る向きを示す。したがって `3 MW` の逆潮流であり、4が正しい。

ひっかけは、力行と回生を足して `13 MW` としないこと。回生電力は逆向きなので差し引く。

## 問2 解答: 3

30秒を時間へ直す。

`30/3600 = 1/120 h`

したがって

`E = Pt = 6.0 MW × 1/120 h = 0.050 MWh = 50 kWh`

であり、3が正しい。MWは電力、MWh・kWhは電力量である。

## 問3 解答: 3

`SOC = E_now / E_rated × 100 [%]`

なので

`E_now = 4.0 MWh × 0.35 = 1.4 MWh`

であり、3が正しい。SOC `35 %` をそのまま `0.35 MWh` としない。

## 問4 解答: 2

単純化したエネルギー基準では

`C-rate ≒ P / E_rated = 1.0 MW / 2.0 MWh = 0.5 1/h`

なので `0.5C` である。理想化時間は

`2.0 MWh / 1.0 MW = 2 h`

となる。したがって2が正しい。

## 問5 解答: 3

3が正しい。

- NaS電池は高温作動型で、代表的な作動温度は約300 ℃程度。
- リチウムイオン電池は高いエネルギー密度を持つ。
- レドックスフロー電池は、エネルギー容量を主に電解液・タンク側、出力を主にセルスタック側で設計できる。
- 自己放電は、外部負荷へ供給していなくても蓄電量が減る現象。
- 電池電力貯蔵設備は、負荷平準化、バックアップ、再生可能エネルギー等の出力変動吸収、短時間の周波数調整等に利用できる。

1はNaSの温度とSOCの意味が誤り。2はリチウムイオン電池、Cレートの意味が誤り。4はレドックスフロー電池の出力側とエネルギー側を逆にしている。5は自己放電の定義ではない。

## 問6 解答: 4

初期蓄電量は

`E0 = 3.0 × 0.40 = 1.20 MWh`

30分充電で実際に増える蓄電量は

`ΔE_ch = 0.90 × 1.0 × 0.5 = 0.45 MWh`

放電時に負荷側へ `0.60 MW` を30分供給するには、蓄電池内部から

`ΔE_dis = (0.60/0.80) × 0.5 = 0.375 MWh`

減る。よって

`E1 = 1.20 + 0.45 - 0.375 = 1.275 MWh`

`SOC1 = 1.275/3.0 × 100 = 42.5 %`

となり、4が正しい。充電時は効率を掛け、設備出力側の放電電力から内部減少量を求めるときは放電効率で割る。

## 問7 解答: 2

正味系統電力は

`P_grid = 2.0 - 6.0 + 1.5 = -2.5 MW`

であり、上位側へ `2.5 MW` 戻そうとする状態である。仮定された上位系統の受入可能量は `1.0 MW` なので、他の受入先がなければ

`2.5 - 1.0 = 1.5 MW`

が受け入れられない。

Topic 15では、余剰回生の逆向き潮流が電圧上昇の要因になり得ること、同時刻の負荷・蓄電・上位系統のいずれにも受入余地がなくなれば回生を電気側で継続できず回生失効の概念につながることまで扱う。実設備の電圧しきい値や失効条件はこの仮定から決めない。

1は符号計算が誤り、3は電圧変化を逆に断定、4は蓄電容量・充電電力制約を無視、5は回生失効を故障計算と混同している。

## 問8 解答: 3

発電時有効落差は

`H_gen = 150 - 10 = 140 m`

発電機出力は

`P_gen = ρgQH_genη_tη_g`

`= 1000×9.8×30×140×0.90×0.98`

`= 36.30312 MW ≒ 36.3 MW`

である。したがって3が正しい。発電時は静落差から損失水頭を差し引き、効率を掛ける。

## 問9 解答: 3

揚水時全揚程は

`H_pump = 150 + 10 = 160 m`

揚水時電動機入力は

`P_pump,in = ρgQH_pump/(η_pη_m)`

`= 1000×9.8×30×160/(0.85×0.95)`

`= 58.2539 MW ≒ 58.3 MW`

同一流量・同一時間で比較できるので

`η_total = P_gen/P_pump,in = 36.30312/58.2539 = 0.623 ≒ 62.3 %`

となり、3が正しい。揚水側は必要な水動力を得るため効率で割る。効率を掛けると入力が過小評価される。

## 問10 解答: 3

固定過去問の選択肢判定上、識別対象となるのは `相反転断路器` である。したがって3が正しい。

分路リアクトルは無効電力・電圧調整、負荷時タップ切換器は変圧器のタップ切換、避雷器はサージ保護、進相コンデンサは力率改善・無効電力補償の機器であり、この識別要素とは異なる。

## 問11 解答

### (1) 各区間の正味系統電力

区間A:

`P_grid = 5.0 - 1.0 = 4.0 MW`

正なので `4.0 MW` の受電。

区間B:

`P_grid = 2.0 - 7.0 + 3.0 = -2.0 MW`

負なので `2.0 MW` の逆潮流。

区間C:

`P_grid = 6.0 - 1.5 = 4.5 MW`

正なので `4.5 MW` の受電。

### (2) 区間Bの逆潮流電力量

2分は

`2/60 = 1/30 h`

なので

`E_reverse = 2.0 MW × 1/30 h = 0.0667 MWh = 66.7 kWh`

である。

### (3) 実際に蓄えられる電力量

充電設備へ入る電力量は

`E_in = 3.0 MW × 1/30 h = 0.100 MWh`

充電効率 `0.90` なので

`E_stored = 0.90 × 0.100 = 0.090 MWh = 90 kWh`

である。

この問題では、瞬時の電力収支と時間積分した電力量を分けることが要点である。

## 問12 解答例

### (1) 広域連系と年負荷率

地域ごとに最大需要の発生時刻が異なれば、一方が最大の時に他方は最大未満である。そのため連系後の同時最大電力は各地域最大電力の単純和より小さくなり得る。年間電力量が同程度でも分母となる合成最大電力が抑えられるので、`年負荷率 = 年間電力量/(年最大電力×8760 h)` は改善する方向となる。

### (2) 揚水と可変速揚水

揚水発電は軽負荷時の電力で下池から上池へ揚水し、重負荷時に発電して電力を時間シフトする。これによりピーク対応・負荷平準化に寄与する。可変速方式は固定速方式に比べて揚水時入力を調整でき、余剰電力の吸収量を調整しやすい。

### (3) 需要家側蓄電池

例:
- ピークカット・負荷平準化
- 契約電力低減
- 受電設備容量の低減
- 非常用電源

このうち2つを、低需要時充電→ピーク時放電という時間シフトと結び付けて書けばよい。経済負荷配分や周波数制御の詳細へは広げない。

## 問13 解答

### (1) 発電時有効落差と発電機出力

`H_gen = 180 - 12 = 168 m`

`P_gen = 1000×9.8×35×168×0.91×0.97`

`= 50.8647 MW ≒ 50.9 MW`

### (2) 揚水時全揚程

`H_pump = 180 + 12 = 192 m`

### (3) 主回路切替機器

`相反転断路器`

固定過去問の選択肢判定に必要な機器名として識別する。

### (4) 揚水時電動機入力

`P_pump,in = 1000×9.8×35×192/(0.86×0.95)`

`= 80.6071 MW ≒ 80.6 MW`

### (5) 総合効率

`η_total = 50.8647/80.6071 = 0.6310 ≒ 63.1 %`

検算:
- 発電時は損失水頭を差し引く。
- 揚水時は損失水頭を加える。
- 発電側は効率を掛け、揚水側は効率で割る。
- 総合効率が100 %を超えていない。

## 問14 解答例

### (1) 電池電力貯蔵

貯蔵エネルギーの形: 化学エネルギー。

原理: 交流を変換器で直流へ変換して二次電池を充電し、電気エネルギーを化学エネルギーとして蓄える。放電時は逆に電気エネルギーへ戻し、変換器を介して交流側へ供給する。

特徴: エネルギー密度を高くしやすく、モジュール化しやすい。方式に応じて温度管理、電解液管理、寿命管理等が必要になる。

### (2) フライホイール電力貯蔵

貯蔵エネルギーの形: 回転運動エネルギー。

原理: 充電時は電動機でフライホイールを加速し、放電時は回転エネルギーで発電機を駆動して電力を取り出す。

特徴: 応答が速く、繰返し充放電に向く一方、機械損失による自己放電があり長時間貯蔵には不利になりやすい。

### (3) SMES

貯蔵エネルギーの形: 磁気エネルギー。

原理: 交流を変換器で直流へ変換し、超電導コイルへ電流を流して磁気エネルギーとして蓄える。放電時はコイル側から変換器を介して交流系統へ戻す。

特徴: 応答が速く、超電導コイル自体の抵抗損失は非常に小さいが、冷凍機と電力変換器が必要である。

採点時は3方式それぞれについて「原理」と「特徴」を別答案要素として確認し、`6 / 6` を満たす。

## 問15 解答

### (1) 最大充電電力

単純化したエネルギー基準で

`P_ch,max = C-rate × E_rated = 0.5 1/h × 4.0 MWh = 2.0 MW`

である。

### (2) 蓄電量増分とSOC

10分は

`10/60 = 1/6 h`

設備入力側の充電電力量は

`E_in = 2.0 × 1/6 = 0.3333 MWh`

実際に増える蓄電量は

`ΔE = 0.90 × 0.3333 = 0.300 MWh`

初期蓄電量は

`E0 = 4.0 × 0.80 = 3.20 MWh`

したがって

`E1 = 3.20 + 0.30 = 3.50 MWh`

`SOC1 = 3.50/4.0 × 100 = 87.5 %`

である。`3.50 MWh < 4.0 MWh` なので定格容量上限には達しない。

### (3) 正味系統電力

`P_grid = 2.5 - 7.0 + 2.0 = -2.5 MW`

よって上位側へ `2.5 MW` 戻そうとする状態である。

### (4) 受け入れられない余剰

上位系統が受け入れられるのは `1.0 MW` までなので

`2.5 - 1.0 = 1.5 MW`

が他の受入先を必要とする余剰である。

### (5) Topic 15の範囲での整理

余剰回生による逆潮流は、線路・系統のインピーダンスと潮流条件によって受電点側の電圧上昇の要因になり得る。同時刻の他負荷、蓄電設備、上位系統のいずれにも `1.5 MW` を受け入れる余地がなくなれば、電気側で回生を継続できず、回生失効の概念につながる。

ただし、この教材用仮定値から実際の新幹線設備の電圧しきい値、受入可能量、失効条件を推定してはならない。保護・FRT、安定度、需給制御一般は後続Topicの範囲である。
