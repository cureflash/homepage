# 問題

## 問1 基礎・一次型: `a` 演算子

対称座標法で `a = exp(j120°)` とする。正しい関係を選べ。

1. `a^2 = 1`
2. `a^3 = -1`
3. `1 + a + a^2 = 0`
4. `a` を掛けると `-120°` 回転する
5. `a = 1/2 + j√3/2`

## 問2 基礎・一次型: 三相不平衡の原因

三相系統の不平衡原因について正しいものを選べ。

1. 平衡三相負荷と平衡三相電源は、それだけで大きな逆相を発生させる。
2. 交流式電気鉄道のような大容量単相負荷や、地絡・断線など各相条件の不一致は不平衡原因になり得る。
3. 相順が `a-b-c` なら、負荷の大きさに関係なく不平衡は発生しない。
4. 単相負荷は三相系統へ接続しても必ず正相だけになる。
5. 三相不平衡は電流にだけ現れ、電圧には現れない。

## 問3 基礎・一次型: 線間単相負荷の対称分

三線式の理解用モデルで、a-b線間の単相負荷により

```text

Ib = -120∠0° A
Ic = 0 A
```

3. `(40.0, 40.0, 40.0) A`
4. `(69.3, 0, 69.3) A`
5. `(120, 69.3, 0) A`

## 問5 本試験標準・一次型: 逆相電流と同期機

同期発電機へ逆相電流が流れた場合の説明として最も適切なものを選べ。

1. 逆相磁界は回転子と同じ向き・同じ速度で回るため、回転子には影響しない。
2. 逆相磁界は回転子から見て大きな相対速度を持ち、回転子表面などへ誘導電流・渦電流を生じ、局部加熱の原因になる。
3. 逆相電流は必ず零相電流へ変換されるため、同期機では問題にならない。
4. 逆相電流は有効電力を0にするだけで、熱的影響はない。
5. 逆相電流は変圧器で必ず完全除去される。

## 問6 本試験標準・一次型: 零相電流

三線式の線電流について `Ia + Ib + Ic = 0` が成り立つ。線電流の零相成分 `I0` として正しいものを選べ。

1. `I0 = Ia + Ib + Ic`
2. `I0 = (Ia + Ib + Ic)/2`
3. `I0 = (Ia + Ib + Ic)/3 = 0`
4. `I0 = I1 + I2`
5. `I0` は必ず `I1` と同じ大きさになる。

# 解答・完全解説

## 問1

正答: `3`

`a = exp(j120°)` なので

```text
a^2 = exp(j240°)
a^3 = exp(j360°) = 1
1 + a + a^2 = 0
```

である。`a` を掛ける操作は `+120°` 回転である。

重要な誤答: `a` と `a^2` の回転方向を取り違えると、正相と逆相を逆にする。

## 問2

正答: `2`

交流式電気鉄道は大容量単相負荷であり、三相系統の一部へ負荷が偏る原因になり得る。また、地絡・断線などで各相条件が異なれば三相不平衡となる。

重要な誤答: 相順が正しくても、各相の大きさ・位相関係が崩れれば不平衡である。

## 問3

正答: `2`

対称座標変換より

```text
I0 = (Ia + Ib + Ic)/3
   = (120 - 120 + 0)/3
   = 0

I1 = (Ia + aIb + a^2Ic)/3
   = 120(1-a)/3

I2 = (Ia + a^2Ib + aIc)/3
   = 120(1-a^2)/3
```

`|1-a| = |1-a^2| = √3` なので

```text
|I1| = |I2| = 120√3/3
       = 120/√3
       = 69.28 A
```

よって `(0, 69.3, 69.3) A`。

検算: 三線式で `Ia + Ib + Ic = 0` なので零相線電流は0。一方、逆相は0ではない。

## 問4

正答: `3`

```text
電圧不平衡率
= |V2|/|V1| × 100
= 2.5/100 × 100
= 2.5 %
```

H28一次法規問6へ接続する代表値 `3 %` と比べると、この仮定例は3 %未満である。

重要な誤答: 比をそのまま `0.025 %` としない。`0.025` は無次元比であり、百分率では `2.5 %`。

## 問5

正答: `2`

逆相成分は正相と逆の相順を持つ。同期機から見ると逆相磁界は回転子に対して大きな相対速度を持つため、回転子表面、くさび、保持環などへ誘導電流・渦電流を生じ、局部加熱・損傷要因になる。

重要な誤答: 逆相は単なる「各相電流値のばらつき」ではなく、逆相順の対称三相成分である。

## 問6

正答: `3`

零相成分は

`I0 = (Ia + Ib + Ic)/3`

である。問題条件より和が0なので `I0 = 0`。

ただし、これは三線式の線電流モデルである。中性線や大地など零相電流の帰路を持つ系統まで「零相は常に0」としてはいけない。

## 問7

正答: `4`

逆変換は

```text
Ia = I0 + I1 + I2
Ib = I0 + a^2I1 + aI2
Ic = I0 + aI1 + a^2I2
```

よって

```text
Ia = 80 + 20 = 100 A

Ib = 80∠-120° + 20∠120°
   = (-40-j69.282) + (-10+j17.321)
   = -50-j51.962 A
```

したがって

`|Ib| = √(50^2 + 51.962^2) = 72.11 A`

よって最も近いのは `72.1 A`。

## 問8

正答: `2`

変換式

```text
V0 = (Va + Vb + Vc)/3
V1 = (Va + aVb + a^2Vc)/3
V2 = (Va + a^2Vb + aVc)/3
```

へ代入すると

```text
V0 = 10∠-60° V
V1 = 80∠0° V
V2 = 10∠60° V
```

よって

`(|V0|, |V1|, |V2|) = (10, 80, 10) V`。

検算では逆変換し、元の `Va, Vb, Vc` に戻ることを確認する。

## 問9

正答: `2`

大容量単相負荷を一つの相・線間へ集中させると三相側の偏りが大きくなり得る。相振り分けや、スコット結線・変形ウッドブリッジ結線・ルーフ・デルタ結線などTopic 07で扱った相変換結線を使って負荷を配分することで不平衡を小さくできる。

ただし、単相側負荷が設計上の平衡条件から外れれば残留不平衡は生じ得る。「変圧器を入れれば必ず0」は誤り。

## 問10

正答: `2`

同じ不平衡負荷電流を流しても、短絡容量の大きい上位系統は一般に系統インピーダンスが相対的に小さく、負荷による電圧変化を小さく抑えやすい。Topic 13では短絡容量を「系統の強さ」の指標としてのみ使う。

故障電流の算定へ進むのはTopic 16であり、本問では扱わない。

## 問11

### (1) 零相成分

```text
I0 = (Ia + Ib + Ic)/3
   = (150 - 150 + 0)/3
   = 0 A
```

### (2) 正相・逆相成分

```text
I1 = (Ia + aIb + a^2Ic)/3
   = 150(1-a)/3

I2 = (Ia + a^2Ib + aIc)/3
   = 150(1-a^2)/3
```

### (3) 大きさ

`|1-a| = |1-a^2| = √3` なので

```text
|I1| = |I2|
     = 150/√3
     = 86.60 A
```

位相まで書けば

```text
I1 = 86.60∠-30° A
I2 = 86.60∠30° A
```

### (4) 解釈

単一線間の単相負荷では `I2 = 0` にならず、正相と同じ大きさの逆相成分が生じている。したがって「単相負荷を三相系統へ載せても正相だけ」ではない。三線式なので本モデルの零相線電流は0である。

## 問12

### (1) 相電流

```text
Ia = I0 + I1 + I2
   = 100∠0° A
```

`Ib` は

```text
Ib = a^2I1 + aI2
   = 80∠-120° + 20∠120°
   = -50-j51.962 A
   = 72.11∠-133.90° A
```

`Ic` は

```text
Ic = aI1 + a^2I2
   = 80∠120° + 20∠-120°
   = -50+j51.962 A
   = 72.11∠133.90° A
```

### (2) 検算

```text
Ia + Ib + Ic
= 100 + (-50-j51.962) + (-50+j51.962)
= 0
```

よって `I0 = 0` と整合する。

### (3) 平衡判定

平衡正相だけなら `I2 = 0` である。本問は `I2 = 20 A` が存在するため不平衡である。

## 問13

### (1) 電圧不平衡率

```text
ε = |V2|/|V1| × 100
  = 1.32/66.0 × 100
  = 2.00 %
```

### (2) 3 %との比較

`2.00 % < 3 %` なので、本教材で扱うH28一次法規問6の代表基準との比較では3 %以下である。

### (3) 同期発電機への影響

逆相電流は逆向きの回転磁界を作る。回転子から見た相対速度が大きく、回転子表面などへ誘導電流・渦電流を生じ、局部加熱や損傷の原因となる。

### (4) 不平衡を小さくする方策

Topic 13固定範囲では、例えば次の二つである。

- 単相負荷を複数の相・線間へ時間的・空間的に振り分ける。
- き電用変圧器の相変換結線と負荷配分を組み合わせる。

また、短絡容量の大きい強い上位系統から供給して不平衡電圧の影響を小さくする考え方も固定範囲内である。

## 問14

### (1) 最大三相平衡負荷

V結線で三相平衡負荷を供給するとき、小容量側 `Ta = 40 kVA` が先に上限となる。力率1なので

```text
P3,max = √3 × 40
       = 69.282 kW
       ≒ 69.3 kW
```

### (2) 単相負荷合計の最大値

二つの単相負荷を同一にした最大条件では、`Ta` には三相負荷電流のみが流れ、`Tb` には三相負荷電流と単相負荷電流の合成が流れる。

与えられたベクトル関係

`P1 + 40 cos30° = 70`

より

```text
P1,max = 70 - 40 cos30°
       = 70 - 40 × 0.866025
       = 35.359 kW
       ≒ 35.4 kW
```

### (3) 変圧器利用率

```text
α = (69.282 + 35.359)/(40 + 70) × 100
  = 104.641/110 × 100
  = 95.13 %
```

したがって `約95.1 %`。

### (4) なぜ `70 - 40` ではないか

`Tb` の負担は三相負荷電流と単相負荷電流のフェーザ合成で決まる。三相負荷側の寄与を単相負荷方向へ投影すると `40 cos30°` となるため、容量を単純なスカラー和・差として扱えない。制作前blind再解答で不足したのはこのフェーザ整理である。

## 問15

### (1) 各相線電流

各線間負荷の相電流への寄与は

```text
a-b負荷:
Ia += Iab
Ib -= Iab

b-c負荷:
Ib += Ibc
Ic -= Ibc

c-a負荷:
Ic += Ica
Ia -= Ica
```

したがって

```text
Ia = 100∠30° - 100∠150°
   = 100∠30° + 100∠-30°
   = 173.205∠0° A

Ib = -100∠30° + 100∠-90°
   = 100∠-150° + 100∠-90°
   = 173.205∠-120° A

Ic = -100∠-90° + 100∠150°
   = 100∠90° + 100∠150°
   = 173.205∠120° A
```

### (2) 対称分

三相の大きさが等しく、相順が `a-b-c` で120°ずつずれているため、これは正相平衡三相電流である。

```text
I0 = 0
I1 = 173.205∠0° A
I2 = 0
```

変換式へ代入しても同じ結果になる。

### (3) 解釈

一つの線間へ単相負荷を集中させる問11では `|I2| = |I1|` となった。一方、同一の単相負荷をa-b、b-c、c-aへ均等に振り分ける本問では、三相側線電流が正相平衡となり `I2 = 0` まで低下した。

これは「単相負荷だから必ず大きな逆相が残る」のではなく、どの相・線間へどう配分するかが三相側不平衡を左右することを示す。実際のき電系統では負荷が常に完全一致するわけではないため、相振り分けや相変換結線を用いて不平衡を小さくする。
