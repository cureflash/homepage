## 1. このテーマで電験は何を問うか

単相負荷を三相系統の一部へ接続すると、三相電流・電圧は一般に平衡しない。電験二種では「各相の値が違う」で終わらず、不平衡を正相・逆相・零相へ分解し、どの成分が機器へ悪影響を与えるか、どのような結線・負荷配分で不平衡を小さくできるかまで説明・計算できることが必要である。

Topic 13の到達点は次のとおり。

1. 三相平衡と三相不平衡を区別できる。
2. `a` 演算子を使い、三相量を正相・逆相・零相へ分解できる。
3. 正相・逆相・零相の物理的意味を説明できる。
4. 単相負荷が三相系統へ逆相成分を生じさせることを計算で確認できる。
5. 逆相電流が同期機へ与える影響を説明できる。
6. 単相負荷の相振り分け、き電用変圧器、強い上位系統からの供給が不平衡緩和へつながる理由を説明できる。
7. 異容量V結線では各変圧器の電流をフェーザで追い、容量上限を同時に満たす負荷条件を求められる。

ここでは調相設備による電圧制御、逆潮流、故障時の対称分等価回路、短絡・地絡電流、保護リレー、安定度へは進まない。

## 2. 三相平衡と三相不平衡

### 2.1 三相平衡

三相量 `Xa, Xb, Xc` が同じ大きさで、互いに120°ずつ位相がずれている状態を三相平衡という。相順を `a-b-c` とすれば、正相の代表形は

```text
Xa = X∠0°
Xb = X∠-120°
Xc = X∠+120°
```

である。

### 2.2 三相不平衡

三相の大きさまたは位相関係が上の関係から崩れた状態を三相不平衡という。代表原因は次のように整理する。

- 電気炉、溶接機などの大容量不平衡負荷
- 交流式電気鉄道のような大容量単相負荷
- 三相線路インピーダンスの非対称
- 断線、地絡などによる各相条件の不一致

新幹線側では、列車へ供給する負荷が単相であるため、そのまま一組の相へ集中させれば三相側へ不平衡を与え得る。そこで相変換結線や区間ごとの相振り分けを使い、三相側での偏りを小さくする。

## 3. `a` 演算子

対称座標法では

`a = exp(j 2π/3) = -1/2 + j√3/2`

と定義する。

性質:

```text
a を掛ける = +120°回転

a^2 = exp(j4π/3) = -1/2 - j√3/2

a^3 = 1
1 + a + a^2 = 0
```

`a` と `a^2` の位置を入れ替えると正相と逆相を取り違えるため、相順 `a-b-c` を最初に固定する。

## 4. 正相・逆相・零相

任意の三相不平衡量は、次の三つの平衡成分の和として表せる。

### 4.1 正相成分

相順が元の系統と同じ `a-b-c` の対称三相成分である。正常な平衡三相運転の基本成分になる。

### 4.2 逆相成分

相順が正相と逆の `a-c-b` となる対称三相成分である。

同期機では逆相電流が正相と逆向きに回転する磁界を作る。回転子から見ると大きな相対速度を持つ磁界となり、回転子表面、くさび、保持環などへ誘導電流・渦電流を生じさせ、局部加熱や損傷の原因になる。このため同期機では逆相電流に制限が設けられる。

### 4.3 零相成分

三相が同じ大きさ・同じ位相となる成分である。

```text
Xa0 = Xb0 = Xc0
```

三線式で線電流の和が

`Ia + Ib + Ic = 0`

となるモデルでは、線電流の零相成分は

`I0 = (Ia + Ib + Ic)/3 = 0`

である。ただし中性線や大地など零相電流の帰路が存在する系統まで「零相は常に0」としてはいけない。

## 5. 対称座標変換

### 5.1 相量から対称分へ

相順を `a-b-c` とすると、

```text
[X0]   1 [1  1   1 ] [Xa]
[X1] = - [1  a  a^2] [Xb]
[X2]   3 [1 a^2  a ] [Xc]
```

である。

すなわち

```text
X0 = (Xa + Xb + Xc)/3
X1 = (Xa + aXb + a^2Xc)/3
X2 = (Xa + a^2Xb + aXc)/3
```

である。

### 5.2 対称分から相量へ

```text
[Xa]   [1  1    1 ] [X0]
[Xb] = [1 a^2   a ] [X1]
[Xc]   [1  a   a^2] [X2]
```

よって

```text
Xa = X0 + X1 + X2
Xb = X0 + a^2X1 + aX2
Xc = X0 + aX1 + a^2X2
```

となる。

電圧でも電流でも同じ変換を使う。

### 5.3 検算

対称分を求めたら、逆変換して元の `Xa, Xb, Xc` に戻ることを確認する。行列の `a` と `a^2` を取り違えた場合、この検算で発見できる。

## 6. 単相負荷を三相系統へ接続すると何が起きるか

理解用の三線モデルとして、a-b線間へ単相負荷電流 `I` が流れ、

```text
Ia = I
Ib = -I
Ic = 0
```

とする。

零相成分は

`I0 = (I - I + 0)/3 = 0`

である。

正相成分は

`I1 = (I - aI)/3 = I(1-a)/3`

逆相成分は

`I2 = (I - a^2I)/3 = I(1-a^2)/3`

となる。

`|1-a| = |1-a^2| = √3`

なので

`|I1| = |I2| = |I|/√3`

である。

単一線間へ集中した単相負荷は、正相だけでなく逆相を明確に発生させる。この基本モデルでは三線式なので零相線電流は0である。

## 7. 電圧不平衡率と強い系統

不平衡の評価では、正相電圧 `V1` と逆相電圧 `V2` の比を使う。

`電圧不平衡率 = |V2| / |V1| × 100 [%]`

正式品質ゲートの平成28年度一次「法規」問6で扱われる受電点の制限値は `3 %以下` である。本Topicではこの数値を法令学習へ広げず、逆相成分を評価する代表指標として扱う。

同じ大きさの単相不平衡負荷でも、上位系統の短絡容量が大きい、すなわち系統が強いほど、その負荷電流によって生じる系統電圧の変化は相対的に小さくなる。このため不平衡負荷を短絡容量の大きい上位系統から供給することは、不平衡電圧を抑える基本方策の一つになる。

ここで短絡容量は「故障電流を計算するため」に使わず、系統の強さを表す指標としてのみ扱う。故障計算はTopic 16へ留保する。

## 8. 不平衡を小さくする考え方

### 8.1 単相負荷を相へ振り分ける

単相負荷を一つの相・線間へ集中させず、複数の相へ時間的・空間的に振り分けると、三相側で見た偏りを小さくできる。

### 8.2 き電用変圧器を使う

Topic 07で扱ったスコット結線、変形ウッドブリッジ結線、ルーフ・デルタ結線などは、単相き電負荷を三相系統へ接続するときの相変換・負荷配分に使われる。

重要なのは「変圧器を入れれば不平衡が0になる」と覚えることではない。各単相側の負荷が設計上の平衡条件から外れれば、三相側にも残留不平衡が現れ得る。結線と負荷配分をセットで考える。

### 8.3 新幹線への接続

交流式電気鉄道は大容量単相負荷である。新幹線き電系統では、相変換結線と区間ごとの相振り分けを使って三相受電系統への不平衡を抑える。

本sourceでは実際の列車電力、受電系統短絡容量、逆相電流実測値を未確認実値として置かない。新幹線は対称座標法と不平衡緩和を具体化する題材として使う。

## 9. 異容量V結線をフェーザで読む

制作前blind独立再解答で不足した部分である。ここではTopic 07で既習のV結線を、不平衡負荷配分の観点から再利用する。

二台の単相変圧器 `Ta`, `Tb` をV結線し、定格容量を

```text
Ta: Sa [kV·A]
Tb: Sb [kV·A]
Sa < Sb
```

とする。まず力率1の三相平衡負荷を最大まで接続し、その後、図示された二つの単相負荷を追加する型を考える。

### 9.1 三相平衡負荷だけを接続したとき

三相平衡負荷の線電流実効値を `I3`、線間電圧を `V`、負荷力率角を `θ` とすると

`P3 = √3 V I3 cosθ`

である。

V結線の各変圧器には同じ大きさの電流が流れるため、先に容量上限へ達するのは小容量側 `Ta` である。

`V I3 <= Sa`

最大有効電力は `cosθ=1` のときなので

`P3,max = √3 Sa`

となる。

### 9.2 二つの単相負荷を同一にする意味

正式過去問の回路では、二つの単相負荷を同一にしたとき、単相側の偏りによる余分な中点電流を生じさせず、二つをまとめた単相負荷電流を一つの線間電流として整理できる。この条件で単相負荷合計を最大化できる。

このとき回路電流を追うと、

- `Ta` には三相平衡負荷電流だけが流れる。
- `Tb` には三相平衡負荷電流と単相負荷電流のフェーザ和が流れる。

となる。

二つの単相負荷を「それぞれTa, Tbへ独立に加える」とみなしてはいけない。制作前再解答ではここを誤った。

## 10. `Tb` の容量制約をフェーザから立てる

三相平衡負荷を最大まで載せた時点で、`Ta` は定格 `Sa` まで使っている。`Tb` には三相平衡負荷電流成分と追加単相負荷電流が流れる。

V結線のフェーザ関係では、`Tb` の端子電圧 `Vcb` に対し、三相平衡負荷電流の `Vcb` 方向成分は30°の幾何関係を持つ。したがって有効方向成分は

`Sa cos30°`

に相当する。

単相負荷合計を `P1` とし、最大利用条件では単相負荷電流の有効方向成分を `Vcb` と同相に取る。`Tb` の容量上限 `Sb` は

`Sb = Sa cos30° + P1,max`

となるので、

`P1,max = Sb - Sa cos30°`

を得る。

ここで重要なのは、`Sa + P1 <= Sb` のようなスカラー加算ではないことである。三相平衡負荷電流と単相負荷電流は、端子電圧に対する位相関係を持つため、フェーザ図から `cos30°` が現れる。

### 10.1 設備利用率

変圧器2台の定格容量合計は

`Sa + Sb`

である。最大時の有効負荷合計は

`P3,max + P1,max`

なので、利用率 `ηu` は

`ηu = (P3,max + P1,max)/(Sa + Sb) × 100 [%]`

である。

したがって一般式は

`ηu = {√3 Sa + Sb - Sa cos30°}/(Sa + Sb) × 100 [%]`

となる。

## 11. 本試験標準の解法アルゴリズム

### 11.1 対称座標法の問題

1. 相順 `a-b-c` を確認する。
2. `a = exp(j2π/3)` を置く。
3. `Xa, Xb, Xc` を複素フェーザで書く。
4. 変換式で `X0, X1, X2` を求める。
5. 正相・逆相・零相のどれが発生しているか解釈する。
6. 三線式なら `Ia+Ib+Ic=0` かを確認し、零相線電流を判定する。
7. 必要なら逆変換し、元の三相量へ戻ることを検算する。
8. 故障条件・対称分等価回路へは進まない。

### 11.2 不平衡の知識問題

1. 不平衡原因が負荷・線路・事故のどれかを分ける。
2. 大容量単相負荷が三相系統へ逆相を生じさせることを確認する。
3. 同期機への影響は逆相磁界→回転子誘導電流→加熱の順で説明する。
4. 緩和策は相振り分け、相変換結線、強い上位系統からの供給に整理する。
5. 数値基準が問われる場合は、正式ゲート範囲の受電点電圧不平衡率 `3 %以下` を使う。

### 11.3 異容量V結線＋単相負荷

1. 小容量側を `Sa`、大容量側を `Sb` と整理する。
2. 三相平衡負荷の最大値を `P3,max=√3 Sa` で求める。
3. 二つの単相負荷を同一にした最大条件を回路電流から確認する。
4. `Ta` は三相平衡負荷電流のみ、`Tb` は三相平衡＋単相負荷の合成電流になることを確認する。
5. `Tb` の端子電圧方向へ三相電流を射影し、`Sa cos30°` を得る。
6. `P1,max=Sb-Sa cos30°` を求める。
7. `ηu=(P3,max+P1,max)/(Sa+Sb)×100` を計算する。
8. 各変圧器定格を超えていないか検算する。

## 12. 3段階例題

### 12.1 基礎例題: 線間単相負荷を対称分へ分解

三線式系統で

```text
Ia = 90∠0° A
Ib = -90∠0° A
Ic = 0 A
```

とする。

零相:

`I0=(Ia+Ib+Ic)/3=0`

正相:

`I1=90(1-a)/3`

`1-a=1.5-j0.866`

より

`I1=45-j25.98 = 51.96∠-30° A`

逆相:

`I2=90(1-a^2)/3`

`1-a^2=1.5+j0.866`

より

`I2=45+j25.98 = 51.96∠+30° A`

正相と逆相が同じ大きさで現れ、零相は0である。単相線間負荷が逆相を生じることを数値で確認できる。

### 12.2 本試験標準例題: 電圧不平衡率と機器影響

ある受電点の正相電圧が `V1=100 %`、逆相電圧が `V2=2.0 %` 相当であるとする。

`電圧不平衡率 = |V2|/|V1|×100 = 2.0 %`

となる。

この値は正式ゲートで扱う `3 %以下` の範囲内である。ただし「基準内なら逆相の影響が存在しない」という意味ではない。同期機には逆相電流が流れ得るため、逆回転磁界による回転子加熱を考慮する。

負荷側の対策は単相負荷の相振り分け、相変換結線による負荷配分であり、系統側では短絡容量の大きい上位系統から供給すると同じ不平衡電流による電圧偏差を小さくしやすい。

### 12.3 複合例題: 異容量V結線＋単相負荷

仮定値として、V結線の二台を

```text
Sa = 20 kV·A
Sb = 35 kV·A
```

とし、力率1の三相平衡負荷を最大まで接続した後、正式過去問と同じ回路関係で二つの同一単相負荷を追加する。

三相最大平衡負荷:

`P3,max = √3×20 = 34.64 kW`

大容量側変圧器に残る単相負荷の有効方向余裕は

`P1,max = 35 - 20 cos30°`

`=35 - 17.32`

`=17.68 kW`

である。

利用率:

`ηu=(34.64+17.68)/(20+35)×100`

`=95.13 %`

となる。

この問題で `35-20=15 kW` としてはいけない。三相平衡負荷電流と単相負荷電流のフェーザ関係により、三相側の成分は `20 cos30°` として容量方向へ効く。

## 13. 頻出ミス

- `a` と `a^2` を入れ替え、正相と逆相を逆にする。
- 相順を決めずに変換行列だけ暗記する。
- 三相不平衡を単なる電流値の大小差と考える。
- 三線式で `I0=0` となる条件を、すべての系統へ一般化する。
- 逆相磁界が同期機回転子へ加熱を生じさせる流れを説明できない。
- き電用変圧器があれば不平衡が必ず0になると考える。
- 系統の短絡容量が大きいことを、Topic 16の故障計算へ展開する。
- V結線の二つの単相負荷を、各変圧器へ独立に足す。
- `Tb` の容量をスカラー加算で処理し、`cos30°` を落とす。
- 三相最大平衡負荷 `√3 Sa` と、変圧器二台の単純容量和を混同する。
- 利用率の分母を負荷合計にする。分母は変圧器定格容量の合計である。

## 15. 制作前不足2要素の改善箇所

制作前再解答でFAILした平成23年度二次問4の(2)(3)について、次を本文へ固定した。

1. 二つの単相負荷を同一にした最大条件: §9.2
2. `Ta` と `Tb` の回路電流の違い: §9.2
3. スカラー加算ではなくフェーザで容量を判定する理由: §10
