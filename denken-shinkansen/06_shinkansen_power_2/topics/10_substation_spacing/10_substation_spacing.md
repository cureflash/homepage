# 解説本文

## 1. このテーマで電験は何を問うか

このテーマの中心は「線路が長くなるほど直列インピーダンスが増え、同じ負荷電流でも電圧降下と抵抗損失が大きくなる」という関係を、一次の比例関係から二次のフェーザ・積分計算まで一貫して扱うことである。到達点は次の4点とする。

1. 単位長さ当たりの線路定数から区間の `R, X, Z` を求める。
2. 送電端・受電端の1相集中定数等価回路で `V_s = V_r + ZI` を使う。
3. 静的な分布負荷では、区間電流を積分して最大電圧降下と給電点位置を求める。
4. 送電電圧、導体量、損失率を固定した比較から、送電可能電力の比例関係を導く。

新幹線側では、変電所からパンタグラフまでの等価線路長を増やしたときに、同一負荷条件でパンタグラフ電圧と線路損失がどう変わるかへ接続する。実際の変電所間隔を未確認値で置くことはしない。

## 2. 線路定数は「1 km当たり」から区間値へ直す

単位長さ当たりの直列線路定数を

`z' = r' + jx' [Ω/km]`

とする。長さ `l [km]` の一様な区間なら

`R = r'l`

`X = x'l`

`Z = z'l = R + jX`

である。抵抗は導体の体積抵抗率 `ρ [Ω·m]`、長さ `L [m]`、断面積 `A [m²]` を使えば

`R = ρL/A`

となる。

ここで最初に確認すべきなのは、問題文の `R` が「1線当たり」「1相当たり」「往復を含む等価値」のどれかである。与え方が違えば損失式の係数も変わる。勝手に2倍・3倍しない。

## 3. 抵抗・リアクタンス・インピーダンスの役割

抵抗 `R` は有効電力損失を生み、リアクタンス `X` は電流に対して90°ずれた電圧降下成分を作る。交流線路では

`Z = R + jX`

として同時に扱う。

区間電流を `I` とすると、フェーザとしての電圧降下は

`ΔV = ZI`

である。`|Z||I|` をそのまま受電端電圧から実数減算するのではない。送受電端電圧の位相関係まで含めてベクトルで処理する。

## 4. 集中定数等価回路と送電端・受電端

分路アドミタンスを無視できる条件では、1相分を直列 `R+jX` だけで表せる。

```text
送電端 Vs ── R ── jX ── 受電端 Vr ── 負荷
                 → I
```

電流正方向を送電端から受電端へ取れば

`V_s = V_r + (R+jX)I`

である。二次試験では、この1本の式に複素電力の関係を組み合わせ、未知の受電端電圧、電流、あるいは `R, X` を逆算する。

## 5. 抵抗負荷ではフェーザ図から受電端電圧を求める

平衡三相の抵抗負荷を1相分で扱い、受電端相電圧 `E_r` を基準位相とする。負荷電流 `I` は `E_r` と同相なので

`E_s = (E_r + RI) + jXI`

となり、大きさについて

`|E_s|² = (E_r + RI)² + (XI)²`

が成り立つ。送電端線間電圧 `V_s` が与えられるときは

`E_s = V_s/√3`

とし、電流 `I` が既知なら

`E_r = √(E_s² - (XI)²) - RI`

`V_r = √3 E_r`

の順に受電端線間電圧を求める。

電圧降下率は名称だけで分母を決めない。送電端基準なら

`d_s = (V_s - V_r)/V_s`

受電端基準なら

`d_r = (V_s - V_r)/V_r`

である。受電端基準なら `V_r = V_s/(1+d_r)` としてから上式へ戻る。平成26年度二次問4型では、この定義確認を飛ばすと逆算電流・負荷電力がずれる。

## 6. 小さい電圧降下では力率を含む近似式が使える

受電端電圧を基準に、遅れ力率 `cosφ` の電流を考える。電圧降下が十分小さく、送受電端電圧の位相差も小さい場合、1相当たりの電圧降下の大きさは近似的に

`ΔV ≈ I(R cosφ + X sinφ)`

で表せる。平衡三相の線間電圧降下なら

`ΔV_line ≈ √3 I(R cosφ + X sinφ)`

となる。

同じ有効電力・同じ受電電圧なら、力率が低いほど必要電流が増えるため、抵抗損失も増えやすい。ただし本Topicでは力率を比較パラメータとして使うだけで、コンデンサ等の改善設備へは進めない。

## 7. 電力損失は電流の二乗で増える

1相当たりの線路抵抗を `R` とする平衡三相3線式では

`P_loss = 3I²R`

である。単相の等価回路で `R_eq` が往復を含む直列等価抵抗として定義されていれば

`P_loss = I²R_eq`

を使う。

線路長を2倍にして単位長さ抵抗と電流を同じに保てば `R` も2倍なので、損失も2倍になる。一方、電流を2倍にすると損失は4倍になる。距離だけでなく負荷電流が強く効くことを区別する。

## 8. なぜ高い送電電圧で大きな電力を送れるか

平衡三相3線式では

`P = √3 V I cosφ`

である。線路損失率を `λ=P_loss/P` とすると

`λ = 3RI²/P`

である。1線の抵抗を `R=ρL/A`、三相3線の全導体質量を `G=3σAL` とする。`σ` は導体の質量密度である。

上の式から `I` と `A` を消去すると

`P = V² G λ cos²φ /(3σρL²)`

を得る。したがって、距離 `L`、導体質量 `G`、損失率 `λ`、力率、材料を同じに保てば

`P ∝ V²`

である。平成30年度一次問7型では、個々の式を暗記するより、`P=√3VIcosφ`、`P_loss=3I²R`、`R=ρL/A`、`G=3σAL` を順に連結して導く。

## 9. 静的な分布負荷では「その地点より先の負荷」を電流にする

線路上に負荷が連続分布する場合、微小区間の電圧降下は

`dV = R' i(s) ds`

である。ここで `R' [Ω/m]` は単位長さ当たり等価抵抗、`i(s)` はその地点を通過する線電流である。

重要なのは、負荷密度そのものを `i(s)` としないことである。ある地点の線電流は、その地点より末端側にある負荷電流を積分した値になる。その線電流をさらに距離について積分して電圧降下を求める。

平成27年度二次問3型では、A点からB点へ負荷密度が直線的に増える。Aを `s=0`、Bを `s=L` とし、負荷密度を

`q(s)=I_B s/L [A/m]`

と置けば、積分を2段階に使う。

## 10. 給電点位置は両側の最大電圧降下をそろえて決める

Aから距離 `x` のP点で給電する。A側で位置 `s (0≤s≤x)` を流れる電流は

`i_A(s)=∫_0^s q(u)du = I_B s²/(2L)`

だから、PからAまでの電圧降下は

`V_A = ∫_0^x R' i_A(s) ds = R'I_B x³/(6L)`

となる。

B側で位置 `s (x≤s≤L)` を流れる電流は

`i_B(s)=∫_s^L q(u)du = I_B(L²-s²)/(2L)`

なので

`V_B = ∫_x^L R'i_B(s)ds`

`= R'I_B(2L³-3L²x+x³)/(6L)`

となる。

両端の最大電圧降下をそろえるには `V_A=V_B` とし、

`x = 2L/3`

を得る。このときの最大電圧降下は、B端だけから全線を給電する場合の `8/27` になる。これは「給電点を負荷分布に合わせて置くと最大電圧降下を抑えられる」という静的配置問題であり、列車位置を時間変化させるTopic 11とは分ける。

## 11. 送受電端の測定値からRとXを逆算する

平成27年度二次問4型では、送電端電圧を

`V_1 = V_1∠δ`

受電端電圧を

`V_2 = V_2∠0`

とする。直列線路なので

`V_1 = V_2 + (r+jx)I`

である。送電端複素電力が

`S=P+jQ=V_1 I*`

なら

`I = (P-jQ)e^{jδ}/V_1`

となる。

電流を消去するため

`α = V_1V_2 sinδ`

`β = V_1² - V_1V_2 cosδ`

と置けば

`x = (Pα + Qβ)/(P²+Q²)`

`r = (Pβ - Qα)/(P²+Q²)`

を得る。

解法順序は、(1)直列回路式、(2)複素電力式から電流、(3)電流消去、(4)実部・虚部へ分離、(5)数値代入である。位相差 `δ` の符号、電力と電流の正方向、遅れ無効電力を正とする約束を問題文で確認する。

## 12. π形等価回路は「直列Z＋両端の分路Y/2」という概念まで

線路の充電電流まで考慮する代表的な集中定数表現がπ形等価回路である。中央に直列インピーダンス `Z`、両端に分路アドミタンス `Y/2` を置く。

```text
          Z
Vs ─────/\/\/───── Vr
 |                  |
Y/2                Y/2
 |                  |
┴                  ┴
```

問題文で分路アドミタンスを無視すると指定された場合は、§4の直列 `R+jX` モデルへ戻す。本Topicではπ形の構造と、何を追加しているモデルかを理解するところまでとし、四端子定数や分布定数線路の厳密計算は扱わない。

## 13. 新幹線では「長い等価き電線路ほど電圧降下・損失が増える」と読む

新幹線側へ接続するときも、未確認の実線路値を置かず、単位長さ当たりの等価き電線路インピーダンス `z'` が与えられた簡略モデルを使う。変電所からパンタグラフまでの等価距離を `l` とすれば

`Z(l)=z'l`

である。固定した単一列車負荷・固定した力率で比較するなら、距離が長いほど `|ZI|` が増え、抵抗分による損失も増える。

したがって、本Topicの題名「なぜ変電所を何十kmも離せない？」に対する電気回路上の答えは、線路が長いほど直列インピーダンスが増え、負荷点電圧を維持しにくくなり、損失も増えるからである。ただし実際の変電所間隔は電気回路以外の設計条件も関わるため、ここでは具体的な実間隔を推定しない。

## 14. 問題を見たときの解法手順

1. 問題が「単位長さ定数」「送受電端フェーザ」「損失」「分布負荷」のどれかを分類する。
2. `Ω/km`、`Ω/m` を区間長と掛けて区間の `R, X, Z` に直す。
3. `R` が1線・1相・往復等価のどれかを確認する。
4. 送受電端問題なら `V_s=V_r+ZI` を立てる。
5. 三相なら線間値と相値を `√3` で正しく変換する。
6. 力率があるなら電流位相を決める。近似式を使う場合は電圧降下が小さい条件を確認する。
7. 損失は回路定義に応じて `3I²R` または `I²R_eq` とする。
8. 分布負荷なら負荷密度→線電流→電圧降下の順に2回積分する。
9. 給電点配置なら両側の最大電圧降下を等置する。
10. 電圧降下率は分母を問題文の定義から決める。
11. 最後に単位、符号、位相、距離依存性を検算する。

## 15. 頻出ミス・過去問への接続・公式まとめ

頻出ミス:
- `Ω/km` をそのまま区間インピーダンスとして使う。
- 1相当たり抵抗と三相合計損失を混同する。
- `|ZI|` を受電端電圧から実数として引く。
- `R cosφ + X sinφ` の近似条件を無視する。
- 力率低下で電流が増えることを落とす。
- 分布負荷で負荷密度をそのまま線電流とみなす。
- 電圧降下率の分母を固定してしまう。
- π形等価回路から四端子定数へ勝手に広げる。
- 新幹線の実線路定数・変電所間隔を未確認のまま実値化する。

公式まとめ:
- `Z=(r'+jx')l`
- `R=ρL/A`
- `V_s=V_r+ZI`
- `P_loss=3I²R`（平衡三相・1相抵抗R）
- `ΔV_line≈√3I(R cosφ+X sinφ)`（平衡三相・小電圧降下近似）
- `P=√3VIcosφ`
- 同一距離・導体質量・損失率・力率・材料なら `P∝V²`
- 分布負荷は `負荷密度 → 線電流の積分 → 電圧降下の積分`

# 3段階例題

## 例題1 基礎: 距離からZ・電圧降下・損失を求める

学習用の単相等価き電線路で、単位長さ当たりインピーダンスを `z'=0.08+j0.12 Ω/km`、距離を `l=20 km`、電流を `I=300∠-36.87° A` とする。`R` はこの等価回路全体の直列抵抗とする。区間インピーダンス、電圧降下フェーザ、抵抗損失を求める。

### 解法

区間インピーダンスは

`Z=(0.08+j0.12)×20=1.6+j2.4 Ω`

である。`cos36.87°=0.8`、`sin36.87°=0.6` より

`I=300(0.8-j0.6)=240-j180 A`

だから

`ΔV=ZI=(1.6+j2.4)(240-j180)`

`=816+j288 V`

となる。大きさは約 `865 V` である。

抵抗損失は、この例では `R=1.6 Ω` が等価回路全体の抵抗なので

`P_loss=I²R=300²×1.6=144 kW`

である。

### 確認

距離を2倍にして電流を固定すれば `R, X, |ΔV|, P_loss` はいずれも2倍になる。値は学習用仮定値であり実設備値ではない。

## 例題2 本試験標準: 送電電圧を2倍にすると送電可能電力はどうなるか

平衡三相3線式で、送電距離、全導体質量、導体材料、線路損失率、力率をすべて同じとする。送電線間電圧を `66 kV` から `132 kV` にしたとき、同条件で送れる有効電力の比を求める。

### 解法

§8で導いた

`P = V² G λ cos²φ /(3σρL²)`

を使う。`G, λ, cosφ, σ, ρ, L` はすべて同じなので

`P_2/P_1=(V_2/V_1)²`

`=(132/66)²=4`

となる。

### 確認

「電圧が2倍だから電力も2倍」としない。導体量と損失率まで同じに固定した比較では、必要電流と許容抵抗の関係が重なり二乗比例になる。

## 例題3 複合: 分布負荷に対する給電点の最適位置

長さ `L` の抵抗線路で、A点からB点へ負荷密度が `q(s)=I_B s/L` と直線的に増える。単位長さ当たり等価抵抗を `R'` とし、Aから距離 `x` の点Pで給電する。A側とB側の最大電圧降下を等しくする `x` と、その最大電圧降下がB端だけから給電する場合の何倍かを求める。

### 解法

A側は

`V_A=R'I_B x³/(6L)`

B側は

`V_B=R'I_B(2L³-3L²x+x³)/(6L)`

である。`V_A=V_B` と置くと共通項 `x³` が消え、

`3L²x=2L³`

したがって

`x=2L/3`

となる。

このとき

`V_max=R'I_B(2L/3)³/(6L)=4R'I_BL²/81`

である。

B端だけから給電する場合は

`V_Bonly=∫_0^L R'×(I_B s²/(2L)) ds=R'I_BL²/6`

なので

`V_max/V_Bonly=(4/81)/(1/6)=8/27≈0.296`

となる。

### 確認

これは静的な負荷分布に対する給電点配置である。列車が時間とともに移動する解析や複数列車の潮流計算には進めない。
