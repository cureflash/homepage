## 2. 平成27年度 第二種二次「電力・管理」問3 — 4答案要素

負荷密度を `q(s)=Is/L`、単位長さ当たり等価抵抗を `R` とする。

### (1)a
A側の位置 `s` を流れる電流は `i_A(s)=∫_0^s q(u)du=Is²/(2L)`。

したがって

`V_A = ∫_0^x R i_A(s)ds = RIx³/(6L)`。

### (1)b
B側の位置 `s` を流れる電流は `i_B(s)=∫_s^L q(u)du=I(L²-s²)/(2L)`。

したがって

`V_B = ∫_x^L R i_B(s)ds = RI(2L³-3L²x+x³)/(6L)`。

### (1)c
`V_A=V_B` より

`x = 2L/3`。

### (2)
上記位置で

`V_A = 4RIL²/81`。

B点だけから給電する場合は

`V_Bonly = RIL²/6`。

よって比は

`(V_A/V_Bonly)×100 = (8/27)×100 ≈ 29.6 %`。

照合前判定: `4 / 4` を主張。

## 3. 平成27年度 第二種二次「電力・管理」問4 — 5答案要素

### (1)
`V̇1 = V̇2 + (r+jx) İ`

### (2)
送電端複素電力 `P+jQ = V̇1 İ*` より

`İ = (P-jQ)/V̇1* = (P-jQ)e^{jδ}/V1`。

### (3)
(1)(2)から電流を消去すると

`V1² - V1V2 e^{-jδ} = (r+jx)(P-jQ)`。

### (4)
`α = V1V2 sinδ`

`β = V1² - V1V2 cosδ`

とすれば

`x = (Pα+Qβ)/(P²+Q²)`

`r = (Pβ-Qα)/(P²+Q²)`。

### (5)
`V1=1.05`, `V2=1.01`, `δ=π/12`, `P=1.23`, `Q=0.195` より

`α = 0.27447861`

`β = 0.078131235`

`x ≈ 0.2275 p.u.`

`r ≈ 0.02745 p.u.`

照合前判定: `5 / 5` を主張。

## 4. 平成26年度 第二種二次「電力・管理」問4 — 3答案要素

条件: 送電端線間電圧 `6.93 kV`、1線当たり `R=5 Ω`, `X=7 Ω`、三相抵抗負荷。

### (1)
抵抗負荷なので `Ėr` と `İr` は同相。`RI` は同方向、`jXI` は90°進み、

`Ės = Ėr + Rİr + jXİr`

となるベクトル図。

### (2)
`I=50 A`。

`E_s = 6.93/√3 ≈ 4.001 kV`

`RI=250 V`, `XI=350 V` より

`E_r = √(E_s²-(XI)²)-RI ≈ 3.736 kV`

したがって受電端線間電圧は

`√3 E_r ≈ 6.47 kV`。

### (3)
電圧降下率10 %は受電端電圧基準なので

`(V_s-V_r)/V_r=0.10`

`V_r=6.93/1.10=6.30 kV`。

1相分で

`(E_r+RI)²+(XI)²=E_s²`

を解き、正の根

`I ≈ 67.2 A`。

三相抵抗負荷電力は

`P = √3 V_r I ≈ 733 kW`。

照合前判定: `3 / 3` を主張。
