# 解説本文

## 1. このテーマで電験は何を問うか

Topic 09の中心は、三導体系の電位・電流関係と、与えられたインピーダンスを使った電圧降下計算である。ATき電固有の名称だけを覚えても、正式固定した一次2問・二次1問は解けない。次の4段階を一つの回路問題として処理できることを到達点とする。

1. 中間導体を含む三導体系で、電位と電流の向きを定義する。
2. KCLで帰路電流・線電流の分担を求める。
3. 区間インピーダンスを既知量として `ΔV = ZI` を適用する。
4. AT点の電位拘束を加え、節点電位と区間電流を連立して求める。

一次では三線式の平衡・不平衡、二線式との比較、中間線開放時の電圧分担が問われる。二次では `R+jX` の等価回路、フェーザ図、受電端電圧、電圧降下率からの逆算が要求される。

## 2. 単相3線式はATき電を解くための「回路基礎」

正式一次2問は低圧単相3線式を扱う。これはATき電回路そのものではないが、「両外側導体＋中間導体」「平衡時の中間導体電流」「中間導体が失われたときの電圧分担」を理解するための基礎になる。

中間点電位を0、両外側を `+E`、`-E` とすると、両外側間電圧は `2E` である。左右の負荷電流を、同じ向きを正として `I_1`、`I_2` と定義すれば、中間導体電流はKCLから差電流になる。

`I_N = I_1 - I_2`

平衡負荷 `I_1 = I_2` なら `I_N = 0` である。不平衡なら差分だけが中間導体へ流れる。

### 単相2線式との比較

100 V単相2線式で総負荷電力を `P`、線電流を `I=P/100` とする。同じ総負荷を平衡した100/200 V単相3線式の二つの100 V枝へ半分ずつ分けると、各電圧線の電流は `I/2` になる。

各導体の長さ・太さが同じで1本当たり抵抗を `r` とすれば、2線式の電圧降下は `2rI`、平衡3線式の各100 V枝では中性線電流が0なので `r(I/2)` である。比は

`r(I/2) / (2rI) = 1/4`

となる。電力損失も

`2(I/2)^2 r / (2I^2 r) = 1/4`

である。

さらに、負荷容量・長さ・損失を同じにして導体断面積を変える比較では、3線式の各電圧線電流が半分なので、同じ損失に許される1本当たり抵抗は2線式の4倍、断面積は1/4でよい。3本と2本の導体本数まで含めた所要銅量比は

`3 × (1/4) / 2 = 3/8`

となる。

### 中間導体を開放したとき

中間導体が開放されると、二つの枝負荷は両外側電圧 `2E` に対する直列回路になる。純抵抗 `R_1, R_2` なら

`V_1 = 2E × R_1/(R_1+R_2)`

`V_2 = 2E × R_2/(R_1+R_2)`

となる。一般の交流負荷では抵抗ではなく複素インピーダンス `Z_1, Z_2` を用いる。負荷が不平衡なら一方が定格枝電圧を超え、過電圧になり得る。

平成25年度一次で現れるバランサは、この単相3線式の電圧不平衡を抑えるための装置として理解する。バランサをATの代用品とみなしてはならない。

## 3. ATき電回路の構成

ATき電方式では、少なくとも次の導体・機器を区別する。

- トロリ線 `T`: パンタグラフへ電力を供給する側。
- き電線 `F`: ATの反対側端子へ接続され、ATを介した電力伝送・帰路電流の吸上げに使われる側。
- レール `R`: 車両からの帰路の一部であり、AT中性点へ接続される。
- 帰線: 車両から電源へ戻る電流経路の総体として扱う。AT方式ではレールだけで全区間を戻ると決め打ちしない。
- オートトランス `AT`: 両端を `T` と `F`、中点を `R` に接続する。

理想ATの中点関係は、各AT点で

`V_T - V_R = -(V_F - V_R)`

したがって

`V_T + V_F = 2V_R`

である。`V_R=0` を基準に置けば `V_T=+E`、`V_F=-E`、両外線間は `V_T-V_F=2E` となる。

新幹線の交流き電電圧25 kVはメーカー資料で確認できる。ただし、このTopicでは特定区間のAT間隔・線路インピーダンス等を実値として置かない。

## 4. なぜATき電は長い区間へ電力を送りやすいか

列車がレール―トロリ線間の電圧 `E` で有効電力 `P` を受け、簡略化して力率を `cosφ` とすると、列車電流の大きさは

`I_L = P/(E cosφ)`

である。一方、理想化したATき電回路ではトロリ線―き電線間の電圧は約 `2E` である。同じ電力をこの外線間電圧で長手方向へ送る部分だけを取り出せば、必要電流の目安は

`I_line ≈ P/(2E cosφ) = I_L/2`

となる。

この「高い外線間電圧で長手方向へ送り、ATで中点をレールへ結ぶ」構成により、同じ電力に対する線路電流と `ZI` 電圧降下を小さくしやすい。またAT中性点がレールへ接続されるため、レールを流れる帰路電流をき電線側へ移す経路ができる。

ただし、実際の各区間電流が常に列車電流の正確な1/2になるわけではない。列車位置、AT位置、各区間インピーダンス、隣接給電条件で分担は変わる。Topic 09では「1/2」を理想対称モデルの説明にだけ使い、具体的な分担はKCLと与えられた回路条件から求める。

## 5. ATき電回路を等価回路へ落とす

回路化では、トロリ線・き電線・レールを三本の導体として描き、AT点・列車点を節点とする。区間インピーダンスは問題文または教材条件で与えられた既知量 `Z_T, Z_F, Z_R` として扱う。

同じ正方向を線路方向 `x` の増加方向に取る。枝分かれのない区間では各導体電流は一定で、区間端の電位は

`V_T,k+1 = V_T,k - Z_T,k I_T,k`

`V_F,k+1 = V_F,k - Z_F,k I_F,k`

`V_R,k+1 = V_R,k - Z_R,k I_R,k`

で求める。

列車がトロリ線からレールへ `I_L` を取る節点では、同じ正方向の定義なら

`I_T,right = I_T,left - I_L`

`I_R,right = I_R,left + I_L`

となる。列車が直接き電線へ接続されていなければ、その節点で `I_F` は変化しない。AT点では巻線を介して電流が再配分されるので、KCLと

`V_T + V_F = 2V_R`

を同時に使う。

重要なのは、レール電流やき電線電流を先に「この値のはず」と決めないことである。未知電流は節点方程式から解く。

## 6. 電圧降下は `ΔV = ZI` をフェーザで扱う

交流回路の区間インピーダンスを

`Z = R + jX`

電流を `I` とすると、区間電圧降下は

`ΔV = ZI`

である。`R I` と `jX I` は向きが異なるため、実数の電圧値だけを引き算してはいけない。

一相分の送受電端を扱う基本式は

`E_s = E_r + (R+jX)I`

である。

### 三相抵抗負荷として問われる場合

平成26年度二次のように、平衡三相抵抗負荷で `E_r` を基準フェーザに取ると `I` は `E_r` と同相になる。このとき

`E_s = (E_r + RI) + jXI`

なので大きさについて

`|E_s|^2 = (E_r + RI)^2 + (XI)^2`

が成り立つ。

送電端線間電圧 `V_s` が与えられれば `E_s=V_s/√3` とし、電流 `I` が与えられる問題では

`E_r = √(E_s^2 - (XI)^2) - RI`

`V_r = √3 E_r`

の順に受電端線間電圧を求められる。

電圧降下率は、名称だけから分母を決めず、問題文・定義で基準電圧を確認する。ここで電圧は大きさを用いる。

送電端基準で

`d_s = (V_s - V_r)/V_s`

と定義されるなら

`V_r = (1-d_s)V_s`

である。

受電端基準で

`d_r = (V_s - V_r)/V_r`

と定義されるなら

`V_r = V_s/(1+d_r)`

である。平成26年度二次「電力・管理」問4(3)は後者の受電端基準なので、`V_r=(1-d)V_s` を使わない。

基準を確認して `V_r` を決めたら

`E_r = V_r/√3`

を作り、

`(R^2+X^2)I^2 + 2R E_r I + (E_r^2-E_s^2) = 0`

の正の根から負荷電流を求める。三相抵抗負荷電力は

`P = 3E_r I = √3 V_r I`

である。

フェーザ図は、`E_r` と `RI` を同じ向き、`jXI` をそこから90°進み方向に描き、それらのベクトル和を `E_s` とする。

## 7. 距離―電位・距離―電流の読み方

Topic 09では線路定数を距離から導出しない。距離座標 `x_k` と、各区間の `Z_T,k, Z_F,k, Z_R,k` が既知として与えられた簡略モデルだけを扱う。

計算手順は次のとおりである。

1. `x=0` の基準電位を置く。
2. 各区間電流をKCLで求める。
3. `V_{k+1}=V_k-Z_k I_k` で次節点の電位を求める。
4. AT点では `V_T+V_F=2V_R` を満たすか確認する。
5. 列車点ではトロリ線電流とレール電流が `I_L` だけ変化することを確認する。
6. 各節点の `V_T,V_R,V_F` と `I_T,I_R,I_F` を距離順に並べる。

枝分かれのない区間では電流は一定なので、距離―電流図は節点で段差をもつ形になる。距離―電位図は計算した節点電位を距離順に示し、AT位置では中点電位関係を確認する。実線路の `Ω/km` を求めて連続分布へ展開するのはTopic 10で扱う。

## 8. 単純き電方式と比較するときの条件

比較は「同じ負荷」「同じ基準電圧」「与えられた同じ区間インピーダンス」という条件をそろえて行う。

単純き電モデルでは、トロリ線から列車へ流れた電流が主としてレール側を帰る二導体系として計算する。AT簡略モデルでは、き電線とAT中点を加え、KCLによって帰路電流が複数経路へ分担する。

理想対称モデルでは、外線間が `2E` となるため長手方向の電流を小さくでき、結果として `|ZI|` を小さくしやすい。ただし、実際の電圧降下低減率を固定値として暗記してはいけない。比較結果は与えられた `Z` と回路条件から計算する。

## 9. 問題を見たときの解法手順

1. 問題が「単相3線式の基礎」か「AT簡略回路」か「R+jXの送受電端問題」かを分類する。
2. 電位基準と電流正方向を図へ書く。
3. 三線式なら平衡・不平衡、中間導体の接続状態を確認する。
4. AT回路なら `T・F・R・AT・列車` を節点回路へ置く。
5. 与えられた区間インピーダンスだけを使う。
6. KCLで区間電流を求める。
7. `ΔV=ZI` で区間電位を求める。
8. AT点なら `V_T+V_F=2V_R` を適用する。
9. 三相送受電端問題なら線間値と相値を `√3` で変換し、フェーザ式を使う。電圧降下率が出たら分母が送電端か受電端かを定義から確認する。
10. 最後に電位極性、電流方向、単位、電圧降下率の基準を検算する。

## 10. 頻出ミス・ひっかけ

- 単相3線式とATき電を同じ回路とみなす。
- ATの中点がレールへ接続されることを落とす。
- き電線を単なるトロリ線の並列線とみなす。
- レール電流が全区間で列車電流と同じだと決める。
- 平衡3線式の中間線電流を二つの枝電流の和としてしまう。
- 中間線開放後も各枝電圧が元の値のままだと考える。
- `R+jX` を実数抵抗のように扱い、`jXI` の直交成分を落とす。
- 三相問題で線間電圧と相電圧を混同する。
- 電圧降下率の分母を送電端か受電端か確認せず使う。
- 問題文にない線路定数やAT間隔を補って計算する。

# 3段階例題

## 例題1 基礎: 理想ATの電位関係

学習用の理想ATで、中点のレール電位を `V_R=0`、トロリ線―レール間電圧の大きさを `E=25 kV` とする。AT両半巻線の電圧が等しく逆極性であるとき、`V_T, V_F, V_T-V_F` を求める。

### 解法

AT中点関係は

`V_T - V_R = -(V_F - V_R)`

である。`V_R=0`、`V_T-V_R=+25 kV` と置けば

`V_T = +25 kV`

`V_F = -25 kV`

したがって

`V_T - V_F = 25 - (-25) = 50 kV`

となる。

### 確認

列車が受けるのはトロリ線―レール間の25 kVであり、50 kVを直接受けるわけではない。25 kVは新幹線の交流き電電圧としてメーカー資料で確認した値で、特定区間の測定値ではない。

## 例題2 本試験標準: 複素インピーダンスによる電圧降下

学習用簡略区間で、送電側トロリ線―レール電圧を `V_s=25.0∠0° kV`、区間インピーダンスを `Z=0.20+j0.30 Ω`、区間電流を `I=300∠-30° A` とする。受電側電圧 `V_r` と電圧降下率を求める。

### 解法

まず電流を直交形式へ直す。

`I = 300(cos(-30°)+j sin(-30°))`

`= 259.8 - j150.0 A`

電圧降下は

`ΔV = ZI`

`= (0.20+j0.30)(259.8-j150.0)`

`= 96.96 + j47.94 V`

したがって

`V_r = V_s - ΔV`

`= 25000 - (96.96+j47.94)`

`= 24903.04 - j47.94 V`

大きさは

`|V_r| = 24.903 kV`

である。この例題では送電端基準と明示して

`d_s=(25.000-24.903)/25.000`

とするため、電圧降下率は

`0.388 %`

となる。

### 確認

`|ZI|` を単純に25 kVから引くのではなく、複素数としてベクトル差を取る。また、電圧降下率は分母を定義してから計算する。区間インピーダンスは学習用に与えた値で、実設備値ではない。

## 例題3 複合・ひっかけ: 中間導体開放時の電圧分担

単相100/200 V三線式の基礎モデルで、中間導体が開放された。両外側間電圧は200 V、二つの100 V枝の純抵抗負荷は `R_1=20 Ω`、`R_2=30 Ω` とする。各負荷電圧を求め、どちらが過電圧になるか判定する。

### 解法

中間導体が開放されたので、二つの負荷は200 Vに対する直列回路になる。

`I = 200/(20+30) = 4 A`

したがって

`V_1 = 4×20 = 80 V`

`V_2 = 4×30 = 120 V`

となる。もともと100 V枝として使う負荷なので、`R_2` 側は120 Vとなり過電圧である。

### ひっかけ

中間導体開放後も「両方100 V」と置いてはいけない。電圧は直列インピーダンス比で分担される。また、この単相3線式の故障状態をATき電回路へそのまま移植しない。ここでは正式一次問題に必要な三導体系の基礎として扱っている。
