### 3. H26 二次「電力・管理」問4 — NEEDS_REVISION

完成教材の三相抵抗負荷のフェーザ式

`E_s = E_r + (R+jX)I`

`|E_s|^2 = (E_r+RI)^2 + (XI)^2`

から再構成した。

#### (1) ベクトル関係 — PASS

抵抗負荷なので `E_r` と `I` は同相、`RI` は同相、`jXI` は90°進みであり、

`E_s = E_r + RI + jXI`

となる。公式標準解答と一致。

#### (2) 負荷電流50 A時の受電端線間電圧 — PASS

`E_s = 6930/√3 = 4001.0 V`

`RI = 5×50 = 250 V`

`XI = 7×50 = 350 V`

より

`E_r = √(E_s^2-(XI)^2)-RI = 3735.7 V`

`V_r = √3 E_r = 6470.4 V ≒ 6.47 kV`

公式標準解答 `6.47 kV` と一致。

#### (3) 電圧降下率10 %時 — FAIL

完成教材には電圧降下率 `d` について

`V_r = (1-d)V_s`

と記載されている。これだけを使うと `d=0.10`、`V_s=6.93 kV` から

`V_r = 6.237 kV`

となり、同じ二次方程式を解くと

`I ≒ 73.4 A`

`P = √3 V_r I ≒ 793 kW`

を得る。

しかし公式標準解答では電圧降下率を

`(|E_s|-|E_r|)/|E_r| = 0.1`

としており、

`V_r = 6.93/1.1 = 6.30 kV`

`I = 67.2 A`

`P = 733 kW`

となる。

したがって(3)の負荷電流・負荷電力の2答案要素は不一致であり、完成教材だけでは公式過去問を正答できない。

公式問題:
https://www.shiken.or.jp/chief/upload/20141123_ch_second_q01.pdf

公式標準解答:
https://www.shiken.or.jp/chief/upload/20141123_ch_second_a01.pdf

## 根本原因

Topic 09 source §6の「電圧降下率 `d` が与えられる問題では `V_r=(1-d)V_s`」という固定式が、H26二次「電力・管理」問4で用いられる電圧降下率の定義と一致していない。

問題文・分野によって電圧降下率の基準電圧を確認せず、送電端基準の式へ固定していることがFAILの原因である。
