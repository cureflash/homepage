### 3. H26 二次「電力・管理」問4 — PASS

修正後教材の三相抵抗負荷のフェーザ式

`E_s = E_r + (R+jX)I`

`|E_s|^2 = (E_r+RI)^2 + (XI)^2`

および電圧降下率の基準電圧確認手順から再構成した。

#### (1) ベクトル関係 — PASS

抵抗負荷なので `E_r` と `I` は同相、`RI` は同相、`jXI` は90°進みであり、

`E_s = E_r + RI + jXI`

となる。公式標準解答と一致。

#### (2) 負荷電流50 A時の受電端線間電圧 — PASS

`E_s = 6930/√3 = 4001.0 V`

`RI = 5×50 = 250 V`

`XI = 7×50 = 350 V`

より

`E_r = √(E_s^2-(XI)^2)-RI = 3735.7 V`

`V_r = √3 E_r = 6470.4 V ≒ 6.47 kV`

公式標準解答 `6.47 kV` と一致。

#### (3) 電圧降下率10 %時 — PASS

問題文の電圧降下率を受電端基準

`(|E_s|-|E_r|)/|E_r| = 0.1`

として、修正後教材の

`V_r = V_s/(1+d_r)`

を適用する。

`V_r = 6.93/1.1 = 6.30 kV`

`E_r = 6300/√3 V`

これを

`(R^2+X^2)I^2 + 2RE_rI + (E_r^2-E_s^2) = 0`

へ代入し、正の根を採用すると

`I = 67.197 A ≒ 67.2 A`

三相抵抗負荷電力は

`P = √3 V_r I ≒ 733 kW`

となる。公式標準解答 `67.2 A`, `733 kW` と一致。負荷電流・負荷電力の2答案要素ともPASS。

## 根本修正の再検証

前回FAILの原因だった「電圧降下率を送電端基準へ固定する」扱いは解消された。

- 送電端基準: `d_s=(V_s-V_r)/V_s` → `V_r=(1-d_s)V_s`
- 受電端基準: `d_r=(V_s-V_r)/V_r` → `V_r=V_s/(1+d_r)`
- H26二次問4(3): 受電端基準を選択
