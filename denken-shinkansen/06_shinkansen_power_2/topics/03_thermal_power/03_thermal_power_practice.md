## 問7 本試験標準・一次型: 大気温度上昇と最大出力

1. 吸気密度上昇 → 質量流量増加 → GT出力低下 → ST出力増加
2. 吸気密度低下 → 質量流量低下 → GT出力低下 → 排熱回収量低下 → ST出力低下

4. 吸気密度は変わらず、STだけが直接出力低下する

3. 蒸気タービンはガスタービン圧縮機を直接駆動するためだけに設置される。
4. 排熱回収設備は発電端出力を所内電力へ変換する装置である。
5. コンバインドサイクルではガスタービンと蒸気タービンの熱的な結び付きはない。

## 問9 本試験標準・一次型: 停止後も必要な補機

# 解答・完全解説

## 問1

正答: 2

コンバインドサイクルでは、空気を圧縮機で圧縮し、燃焼器で燃料を燃焼させ、高温ガスをガスタービンで膨張させて発電する。その排ガスに残る熱を排熱回収設備で回収して蒸気をつくり、蒸気タービンでも発電する。

したがって流れは

`圧縮機 → 燃焼器 → ガスタービン → 排熱回収設備 → 蒸気タービン`

である。

選択肢1・3・4・5は、圧縮、燃焼、GT膨張、排熱回収、ST膨張の物理的な順序が崩れている。

## 問2

正答: 2

まず発電端出力は

`P_g = P_GT + P_ST = 330 + 170 = 500 MW`

である。送電端出力は所内電力を差し引いて

`P_s = P_g - P_aux = 500 - 25 = 475 MW`

となる。

したがって正答は `475 MW`。

`500 MW` は所内電力控除前の発電端出力であり、送電端出力ではない。

検算すると所内率は `25/500=5.0%` なので、`500×0.95=475 MW` と一致する。

## 問3

正答: 3

所内電力は

`P_aux = 600 - 570 = 30 MW`

所内率は発電端出力を分母にして

`a = P_aux/P_g = 30/600 = 0.05 = 5.0%`

となる。

`30/570` として送電端出力を分母にすると約 `5.3%` となるが、本教材の所内率の定義とは異なる。

## 問4

正答: 3

起動前には排気側の必要な真空と軸封状態を整え、昇速中は振動を監視する。

主蒸気温度やタービン金属温度が急変すると部材内の温度差が大きくなり、熱応力は増えやすいので選択肢1は誤り。危険速度付近は振動が増大しやすいため不必要に長く滞在せず通過するので選択肢2は誤り。危険速度は定格速度そのものを意味しないので4も誤り。金属温度は熱応力に関係するので5も誤り。

## 問5

正答: 3

負荷率 `60%` なので発電端出力は

`P_g = 750×0.60 = 450 MW`

この負荷率での発電端効率は `η_g=0.42` だから、

`Q_f = P_g/η_g = 450/0.42 = 1071.43 MW`

となる。

したがって最も近いのは `1071 MW`。

所内率は燃料投入熱量の計算には直接使わない。所内率が必要になるのは発電端と送電端を換算するときである。

## 問6

正答: 2

主機を停止してもロータは惰性で回転し、停止後もしばらく高温状態が続く。ターニングギヤ電動機でロータを低速回転させることで、上下面の温度差による不均一な収縮と熱変形を抑え、ロータの曲がりを防ぐ。

選択肢1は、停止後にも惰性回転中の軸受潤滑が必要なので誤り。3は蓄電池容量で停電継続時間、温度、経年変化、電圧降下等を考慮するため誤り。4は非常用交流電源の役割と逆。5は制御・保護回路などの直流重要負荷を無視している。

## 問7

正答: 2

大気温度が上昇すると吸気密度が低下する。同じ吸気体積でも取り込める空気質量流量が低下し、ガスタービンで扱える燃料量・最大出力が低下する。さらに排ガス量・排熱回収量が減り、蒸気発生量が減るため蒸気タービン出力も低下する。

したがって

`大気温度上昇 → 吸気密度低下 → 空気質量流量低下 → GT出力低下 → 排熱回収量低下 → ST出力低下`

が正しい。

## 問8

正答: 1

コンバインドサイクルの中心は、ガスタービン排ガスに残る熱を回収して蒸気をつくり、汽力側でも仕事を得ることにある。これにより、同じ燃料投入から得られる総発電電力を増やせる。

選択肢2と5は排熱回収による熱的結合を否定しており誤り。3は蒸気タービンの役割を誤っている。4は排熱回収設備と所内電力の役割を混同している。

## 問9

正答: 2

タービン油ポンプは、主機停止後も惰性回転するロータの軸受へ潤滑油を供給し、油膜切れ、軸受過熱、損傷を防ぐ。

ターニングギヤ電動機はロータを低速で回し、停止後の不均一な冷却による熱変形・ロータ曲がりを防ぐ。定格速度で回して発電を続ける装置ではないため選択肢3は誤り。4と5はガスタービン吸気・排熱回収の機能との混同である。

## 問10

正答: 3

負荷増加後の送電端負荷は

`P_load = 640 + 20 = 660 MW`

所内率 `a=0.035` なので、必要発電端出力は

`P_g,req = P_load/(1-a)`

`= 660/0.965 = 683.94 MW`

である。

最大発電端出力 `700 MW` に対する余裕は

`700 - 683.94 = 16.06 MW`

したがって最も近い組合せは「必要 `683.9 MW`、余裕 `16.1 MW`」。

送電端負荷 `660 MW` と発電端上限 `700 MW` をそのまま差し引くと所内電力を無視するため誤る。

## 問11

(1) 発電端出力

`P_g = P_GT + P_ST`

`= 380 + 170 = 550 MW`

(2) 送電端出力

`P_s = P_g - P_aux`

`= 550 - 22 = 528 MW`

(3) 効率と所内率

発電端効率は

`η_g = P_g/Q_f = 550/1200 = 0.45833`

よって

`η_g = 45.83%`

送電端効率は

`η_s = P_s/Q_f = 528/1200 = 0.440`

よって

`η_s = 44.0%`

所内率は

`a = P_aux/P_g = 22/550 = 0.040`

よって

`a = 4.0%`

(4) 整合確認

`η_s = η_g(1-a)`

`= 0.45833×0.96 = 0.440`

となり、直接計算した `44.0%` と一致する。

検算では、所内電力が正なので `P_s < P_g`、したがって `η_s < η_g` になっていることも確認する。

## 問12

(1) 100%負荷時

発電端出力は

`P_g = 900 MW`

燃料投入熱量は

`Q_f = 900/0.45 = 2000 MW`

送電端出力は

`P_s = 900×(1-0.04) = 864 MW`

送電端効率は

`η_s = 864/2000 = 0.432 = 43.2%`

(2) 60%負荷時

発電端出力は

`P_g = 900×0.60 = 540 MW`

燃料投入熱量は

`Q_f = 540/0.405 = 1333.33 MW`

送電端出力は

`P_s = 540×0.96 = 518.4 MW`

送電端効率は

`η_s = 518.4/1333.33 = 0.3888 = 38.88%`

(3) 理由

部分負荷では発電端効率が `45.0%` から `40.5%` へ低下しているため、出力と燃料投入熱量は単純比例しない。

全負荷時燃料投入の60%は

`2000×0.60 = 1200 MW`

だが、実際には `1333.33 MW` 必要である。負荷率ごとの効率を使わず、出力比だけで燃料量を比例計算すると誤る。

## 問13

模範答案:

大気温度が上昇すると吸気密度が低下し、同じ吸気体積でもガスタービンへ流入する空気質量流量が減少する。そのためガスタービンで扱える燃料量と最大ガスタービン出力が低下する。さらに排ガス量が減って排熱回収量が低下し、蒸気発生量が減るため蒸気タービン出力も低下する。結果としてコンバインドサイクル全体の最大出力が低下する。対策としてガスタービン吸気を冷却し、吸気密度と空気質量流量の低下を緩和する。

採点上は、単に「暑いと効率が下がる」とだけ書くのではなく、`吸気密度 → 質量流量 → GT → 排熱回収 → ST` の因果を落とさない。

## 問14

(1) タービン油ポンプ

主機を停止してもロータは惰性で回転を続ける。この間に潤滑油供給を止めると軸受の油膜が失われ、摩擦、過熱、軸受損傷につながる。したがってタービン油ポンプを継続運転し、ロータが安全に停止するまで必要な潤滑を維持する。

(2) ターニングギヤ電動機

停止後の高温ロータは冷却途中で上下面に温度差が生じる。静止したまま不均一に冷却すると熱変形が偏り、ロータが曲がるおそれがある。そこでターニングギヤ電動機でロータを低速回転させ、周方向の温度差をならして不均一収縮と曲がりを抑える。

二次答案では補機名だけでは不足する。`補機名 → 停止後も残る物理現象 → 放置時の損傷 → 継続運転目的` の順で書く。

## 問15

(1) 最大送電端出力

最大発電端出力 `680 MW`、所内率 `a=0.04` なので

`P_s,max = 680×(1-0.04)`

`= 652.8 MW`

(2) 負荷増加後に必要な発電端出力

送電端負荷は

`P_load = 630 + 30 = 660 MW`

必要発電端出力は

`P_g,req = 660/0.96 = 687.5 MW`

利用可能な最大発電端出力は `680 MW` なので

`687.5 - 680 = 7.5 MW`

発電端で `7.5 MW` 不足する。

(3) 送電端での不足

`660 - 652.8 = 7.2 MW`

したがって送電端では `7.2 MW` 不足する。

(4) 必要燃料投入熱量

仮に必要発電端出力 `687.5 MW` を確保できるとし、発電端効率 `η_g=0.41` を使うと

`Q_f,req = 687.5/0.41 = 1676.83 MW`

となる。

ただし、この値は必要熱入力の計算値であり、問題条件では最大発電端出力が `680 MW` に制約されているため、燃料をこの値まで投入すれば実際に `687.5 MW` を出せると意味しない。

(5) 大気温度上昇の因果と対策

`大気温度上昇 → 吸気密度低下 → 空気質量流量低下 → GT最大出力低下 → 排ガス量・排熱回収量低下 → 蒸気発生量低下 → ST出力低下 → コンバインド最大出力低下`

改善策として吸気冷却を行い、吸気密度と質量流量の低下を緩和する。

(6) 無制限に同時追従できない理由

ガスタービン側の燃料投入と出力が変化すると、その後に排ガス熱量が変わり、排熱回収設備を介して蒸気発生量が変化し、さらに蒸気タービン出力が変わる。蒸気側には熱容量があり時間差が生じる。また蒸気タービンでは温度変化に伴う熱応力や、回転機械としての振動等の運転制約がある。したがって、需要増加と同時にGT・排熱回収・STの全出力が無制限の速さで同率変化すると扱ってはならない。
