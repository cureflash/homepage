# 解説本文

このテーマでは、コンバインドサイクルの構成、燃料投入から送電端までの熱収支、部分負荷、負荷追従、所内電力、蒸気タービン発電機の運用を一つにつなげる。一次試験では機器と熱サイクルの対応、非常用電源・補機、起動時の運転判断を選択肢から判定する力が必要である。二次試験では、熱・空気・出力の因果を順に記述し、発電端と送電端を区別して計算する力が必要になる。

## 1. コンバインドサイクルの構成

コンバインドサイクルは、燃料の熱をまずガスタービンで仕事へ変え、その高温排ガスがまだ持つ熱を回収して蒸気をつくり、さらに蒸気タービンで仕事へ変える発電方式である。

基本的なエネルギーの流れは次のようになる。

```text
空気
 ↓
圧縮機
 ↓
燃焼器 ← 燃料
 ↓
ガスタービン → 発電機 → 電力
 ↓ 高温排ガス
排熱回収設備
 ↓ 蒸気
蒸気タービン → 発電機 → 電力
```

ガスタービン側は圧縮・加熱・膨張・放熱からなるブレイトンサイクル、蒸気タービン側は給水の加熱・蒸発、蒸気の膨張、凝縮を基本とするランキンサイクルとして整理できる。H27一次問1では、機器名だけでなく温度―エントロピー線図上のどの過程に対応するかを見分ける必要がある。

試験で重要なのは「二つの発電機がある」と暗記することではなく、ガスタービンで捨てるはずだった排熱を汽力側へ渡すことで、同じ燃料投入から得られる総発電電力を増やし、熱効率を上げる点である。

## 2. 熱収支と効率

燃料が単位時間に与える熱量を `Q_f [MW]`、ガスタービン発電機出力を `P_GT [MW]`、蒸気タービン発電機出力を `P_ST [MW]` とする。発電端出力は

`P_g = P_GT + P_ST`

である。

発電所内でポンプ、ファン、油ポンプ、制御設備などが使う所内電力を `P_aux [MW]` とすると、系統へ送り出せる送電端出力は

`P_s = P_g - P_aux`

となる。

発電端効率と送電端効率はそれぞれ

`η_g = P_g / Q_f`

`η_s = P_s / Q_f`

である。所内率を

`a = P_aux / P_g`

と定義すれば

`P_s = P_g(1-a)`

`η_s = η_g(1-a)`

と書ける。百分率で与えられた所内率は、式へ代入する前に小数へ直す。

「発電機で発生した電力」と「発電所から外へ送れる電力」を混同しない。新幹線負荷と比較するのは、問題文で別の指定がない限り発電所外へ出せる送電端側の電力である。

### 基礎例題

あるコンバインドサイクル発電設備について、燃料投入熱量 `Q_f=900 MW`、ガスタービン発電機出力 `300 MW`、蒸気タービン発電機出力 `150 MW`、所内電力 `20 MW` とする。発電端出力、送電端出力、発電端効率、送電端効率、所内率を求める。

まず発電端出力は

`P_g = 300 + 150 = 450 MW`

である。

送電端出力は

`P_s = 450 - 20 = 430 MW`

となる。

発電端効率は

`η_g = 450 / 900 = 0.500 = 50.0%`

送電端効率は

`η_s = 430 / 900 = 0.4778 ≈ 47.8%`

所内率は

`a = 20 / 450 = 0.0444 ≈ 4.44%`

である。

検算として `η_s = η_g(1-a)` を使うと

`0.500 × (1-0.0444) ≈ 0.4778`

となり一致する。

## 3. 蒸気タービン発電機の運用

蒸気タービン発電機は、蒸気を供給すれば直ちに定格速度まで上げてよい機械ではない。H25一次問1では、起動前から回転上昇までの運転判断が問われている。

起動前には、蒸気タービンの排気側で必要な真空を確立し、軸封を適切な状態にして空気の侵入や蒸気漏れを抑える。ここでは復水・給水設備の詳細構成までは扱わないが、「真空と軸封を整えてから蒸気を入れる」という順序を押さえる。

主蒸気温度やタービン金属温度が急に変わると、部材内部に温度差が生じて熱応力が大きくなる。したがって起動・負荷変化時には、単に目標出力へ最短時間で到達させるのではなく、温度変化を監視しながら昇速・増負荷する必要がある。

また、回転系には固有振動数があり、回転速度が対応する危険速度付近に入ると振動が増大しやすい。回転上昇時は振動を監視し、危険速度付近に長時間滞在しない。

試験では「ゆっくり回せば常に安全」と決めつけない。熱応力を抑えるためには温度変化を緩やかにする必要がある一方、危険速度域は不必要に長く通過しない、という異なる制約を区別する。

## 4. 所内電力と重要補機

火力発電所は発電中だけでなく、安全に停止する途中にも電力を必要とする。外部交流電源や通常の所内交流電源を失った場合でも、プラントを安全に停止させるため、直流非常用電源と非常用交流電源を備える。

蓄電池による直流電源は、重要な制御・保護回路や必要最小限の非常用負荷へ電力を供給する。蓄電池容量は、停電中に必要な負荷だけでなく、想定する停電継続時間、経年変化、温度変化、電圧降下を考慮して決める。

非常用交流電源には非常用ディーゼル発電機などを用い、電源喪失時にも運転を継続すべき補機へ給電する。蒸気タービン又はタービン発電機に関する代表的な重要補機は次の二つである。

- タービン油ポンプ: 主機を停止してもロータは惰性で回転を続けるため、軸受へ潤滑油を供給し、油膜切れや軸受過熱・損傷を防ぐ。
- ターニングギヤ電動機: タービン停止後にロータを低速で回し、上下面の温度差による不均一な収縮と熱変形を抑え、ロータの曲がりを防ぐ。

R3一次問5は非常用電源の役割を選択肢から判断する問題、R1二次問1は補機名と「なぜ停止できないか」を文章で説明する問題である。設備名だけを列挙しても二次答案としては不足する。

## 5. 負荷率と部分負荷効率

定格発電端出力を `P_r`、実際の発電端出力を `P_g` とすると、ここでは負荷率を

`L = P_g / P_r`

とする。

火力発電設備では一般に、負荷率が変わると熱効率も変化する。そのため、出力が半分になったから燃料投入も必ず半分になるとは限らない。問題で負荷率―効率曲線または表が与えられた場合は、まず現在の負荷率を求め、その負荷率に対応する効率を読んでから燃料投入熱量へ戻す。

### 本試験標準例題

定格発電端出力 `800 MW` の設備について、教材上の仮定値として次の負荷率―発電端効率を与える。所内率は全負荷域で `4.0%` と仮定する。

| 負荷率 | 発電端効率 |
|---|---:|
| 100% | 45.0% |
| 50% | 40.0% |

全負荷時と50%負荷時について、発電端出力、燃料投入熱量、送電端出力、送電端効率を求める。

全負荷時は

`P_g = 800 MW`

`Q_f = 800 / 0.45 = 1777.8 MW`

`P_s = 800 × (1-0.04) = 768 MW`

`η_s = 768 / 1777.8 = 0.432 = 43.2%`

となる。

50%負荷時は

`P_g = 800 × 0.50 = 400 MW`

`Q_f = 400 / 0.40 = 1000 MW`

`P_s = 400 × (1-0.04) = 384 MW`

`η_s = 384 / 1000 = 0.384 = 38.4%`

となる。

出力は半分だが、燃料投入は `1777.8 MW` の半分である `888.9 MW` ではなく `1000 MW` 必要になる。部分負荷効率を無視して比例計算すると誤る。

## 6. 負荷追従

コンバインドサイクルで負荷を変えるときは、ガスタービン、排熱回収設備、蒸気タービンが同時に無制限の速さで追従するわけではない。ガスタービン側の燃料投入と出力が変化すると排ガスの熱量も変わり、その変化を受けて蒸気発生量と蒸気タービン出力が変わる。蒸気側には熱容量があるため、出力変化には時間差が生じる。

H29二次問1で重要なのは、大気温度上昇時の因果を途中で飛ばさないことである。試験上の基本的な連鎖は次のように整理できる。

```text
大気温度上昇
  ↓
吸気密度低下
  ↓
同じ吸気体積でも空気質量流量低下
  ↓
ガスタービンで扱える燃料量・出力が低下
  ↓
排ガス量・排熱回収量が低下
  ↓
蒸気発生量が低下
  ↓
蒸気タービン出力も低下
  ↓
コンバインドサイクル最大出力が低下
```

改善策としては、ガスタービン吸気を冷却し、吸気密度と質量流量の低下を緩和する方法がある。

二次試験では「暑いと効率が悪くなる」だけでは不足する。`原因 → 空気密度 → 質量流量 → GT出力 → 排熱回収 → ST出力 → 総出力 → 対策` の順に書けば、要求される因果を落としにくい。

急な負荷変化では、蒸気タービン側の熱応力や振動など運転上の制約も無視できない。したがって「需要が増えたので瞬時に全出力を同じ比率で増やす」とは扱わず、どの段がどの物理量を介して追従するかを区別する。

## 7. 川崎発電所と新幹線負荷への接続

JR東日本の一次資料で、川崎発電所について次を確認できる。

- 神奈川県川崎市にある自営火力発電所で、現在は天然ガス主体の燃料を使い、発電機4台で列車運行に必要な電力を供給している。
- 自営火力発電所の総出力は `80.9万kW = 809 MW`。
- 燃料は都市ガス及び天然ガス。
- 2024年度の自営火力発電所の発電効率は `43.1%`。
- 複合サイクル発電設備の導入が進められ、2021年6月に新しい1号機が運転開始した。

`809 MW` は発電所全体の総出力であり、任意時刻にその全量を新幹線へ割り当てられることや、全量が送電端で利用可能であることを意味しない。また `43.1%` はJR東日本が公表する自営火力発電所の年度発電効率であり、個々の負荷率での瞬時効率曲線として使わない。

新幹線負荷への接続は、未確認の実車電力を置かず、次の一般式で扱う。

新幹線等の負荷へ必要な送電端電力を `P_load`、所内率を `a` とすれば、損失等を別途無視する教材上の条件では必要な発電端出力は

`P_g,req = P_load / (1-a)`

である。

さらに発電端効率 `η_g` が与えられれば必要な燃料投入熱量は

`Q_f,req = P_g,req / η_g`

となる。

### 複合・ひっかけ例題

あるコンバインドサイクル発電設備について、すべて教材上の仮定値として、夏季の大気温度上昇により利用可能な最大発電端出力が `720 MW` に低下している。所内率は `4.0%`。現在の送電端負荷は `670 MW` で、新幹線等の負荷増加によりさらに `35 MW` 増えるとする。

1. 利用可能な最大送電端出力を求める。
2. 負荷増加後に必要な発電端出力を求める。
3. 供給余力の有無を判定する。
4. 大気温度上昇からコンバインド出力低下までの因果と改善策を記述する。

最大送電端出力は

`P_s,max = 720 × (1-0.04) = 691.2 MW`

である。

負荷増加後の送電端負荷は

`P_load = 670 + 35 = 705 MW`

必要な発電端出力は

`P_g,req = 705 / 0.96 = 734.375 MW`

となる。利用可能な最大発電端出力 `720 MW` を `14.375 MW` 上回るので、仮定条件のままでは供給余力がない。送電端で見れば

`705 - 691.2 = 13.8 MW`

不足する。

記述は次の因果で組み立てる。

`大気温度上昇 → 吸気密度低下 → 空気質量流量低下 → GT最大出力低下 → 排ガス量・排熱回収量低下 → 蒸気発生量低下 → ST出力低下 → コンバインド最大出力低下`

改善策として吸気冷却を行い、吸気密度・質量流量の低下を緩和する。

この問題では `720 MW` と `809 MW` を混同しない。`720 MW` は問題文で与えた夏季の仮定上限、`809 MW` は川崎発電所について一次資料で確認した総出力である。また、送電端負荷 `705 MW` と発電端必要出力 `734.375 MW` を直接比較しない。

## 8. 二種一次・二次の解法

### 一次試験

一次の多肢選択では、機器名を個別暗記するより、エネルギー・電力・運転状態の流れを先に作る。

コンバインドサイクルなら

`圧縮機 → 燃焼器 → GT → 排熱回収 → ST`

非常用電源なら

`通常電源喪失 → 安全停止に必要な負荷を選ぶ → 直流/交流の非常用電源へ対応付ける`

蒸気タービン起動なら

`起動前条件 → 蒸気・金属温度 → 振動 → 危険速度`

の順で判断する。

### 二次試験の論説

論説では、設問が求める項目数を最初に分ける。H29二次問1型なら、現象と改善策を次の順で書く。

1. 原因
2. 中間現象
3. 出力への影響
4. 改善策

R1二次問1型なら

1. 補機名
2. 停止後も生じる物理現象
3. 継続運転しない場合の損傷
4. 継続運転の目的

まで書く。

### 二次試験の計算

発電端・送電端を扱う計算では次の順を固定する。

1. 問題文の出力が発電端か送電端か確認する。
2. 所内率の定義を確認する。
3. `P_s=P_g(1-a)` で端点をそろえる。
4. 必要なら `η=P/Q_f` で燃料投入熱量へ変換する。
5. 部分負荷では、その負荷率に対応する効率を使う。
6. 最後にMW、kW、%、小数を検算する。
