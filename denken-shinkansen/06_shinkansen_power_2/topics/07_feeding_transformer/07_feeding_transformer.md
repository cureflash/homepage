# 解説本文

## 1. このテーマで電験は何を問うか

このTopicの核は、三相交流をフェーザで扱い、三相側から2組の単相負荷へ電力を渡す相変換結線を電圧・電流関係から説明できることである。

正式過去問との接続は二本立てになる。

- H23一次「理論」問6: 120°位相差をもつ三相フェーザを複素数で表し、相間量と節点電流を差・和で求める。
- H23二次「機械・制御」問2: スコット結線の幾何からT座一次電圧、巻数比、一次電流、巻線容量、利用率まで求める。

したがって、暗記対象は結線名だけではない。`120°の三相 → フェーザ差 → スコットの90°二出力 → 電流のフェーザ合成 → 平衡条件` までを一続きで扱う。

## 2. 対称三相交流とフェーザ

対称三相交流では、三つの相電圧の大きさが等しく、位相が120°ずつずれる。相電圧の実効値を `E` とし、U相を基準にすると、

- `E_U = E∠0° = E`
- `E_V = E∠-120° = E e^{-j2π/3}`
- `E_W = E∠120° = E e^{j2π/3} = E e^{-j4π/3}`

と置ける。

相間電圧は実数の差ではなくフェーザ差で求める。例えば、

`E_UV = E_U - E_V`

である。大きさは

`|E_UV| = √3 E`

となり、U相電圧に対して30°進む。同様に三つの線間電圧も大きさが等しく、互いに120°ずつずれる。

対称三相では

`1 + e^{-j2π/3} + e^{-j4π/3} = 0`

が成立する。この関係はH23一次理論問6のようなフェーザ合成を短く処理するときに使える。

## 3. 相間負荷の電流を求める基本形

U-V間に抵抗 `R` が接続されているなら、その枝電流は

`I_UV = (E_U - E_V)/R`

である。抵抗負荷なので枝電流は枝に掛かる相間電圧と同相になる。

同じ節点へ複数の枝が接続される場合、線電流は枝電流のフェーザ和で求める。H23一次理論問6の形なら、

`I_1 = I_12 + I_13`

であり、各電流を複素数のまま足す。絶対値だけを先に足してはいけない。

この処理は、スコット結線で一次側電流を合成するときにもそのまま使う。

## 4. なぜ三相から単相へ相変換するのか

新幹線変電所では、受電した三相交流から列車へ供給する単相交流を作る。1組の単相負荷だけを三相系統へ直接ぶら下げれば、三相の各線に同じ大きさ・120°位相差の電流を流せない。

そこで、き電用変圧器では三相電力を2組の単相電力へ変換し、二つの単相負荷を組み合わせて三相側の不平衡を抑える。スコット結線では、二次側に互いに90°位相差の単相二回路を作り、二回路を等容量・同一力率で負荷すると一次側を対称三相電流にできる。

Topic 07では、この平衡化が成立する電圧・電流フェーザまでを扱う。負荷が崩れた後の逆相成分の定量分解はTopic 13へ送る。

## 5. スコット結線の構成

スコット結線は主座変圧器 `T_m` とT座変圧器 `T_t` の2台で構成する。

主座一次巻線は三相の二線間、例えばV-W間へ接続し、その中点をOとする。T座一次巻線は残るU相とO点の間へ接続する。

三相線間電圧を `V_L` とすると、

- 主座一次電圧: `V_m = V_L`
- T座一次電圧: `V_t = (√3/2)V_L`

となる。

`√3/2` は暗記値ではない。三相線間電圧のフェーザ三角形は正三角形になり、U点からV-W辺の中点Oへ引いた高さが `√3/2` 倍になるためである。また、この高さ方向はV-W方向と90°になる。したがって、主座とT座の二次側も適切な極性で90°位相差の単相二回路を得られる。

## 6. スコット結線の巻数比

二次側単相電圧を両座とも `V_s` とする。一次巻数/二次巻数の巻数比を `a` とすれば、理想変圧器では `a = V_1/V_2` である。

主座:

`a_m = V_L / V_s`

T座:

`a_t = [(√3/2)V_L] / V_s = (√3/2)a_m`

ここで最も多い誤りは、T座にも `V_L` がそのまま掛かると考えることだ。T座一次の基準電圧は `V_L` ではなく `√3/2 V_L` である。

## 7. 電流比と一次三相電流

理想変圧器では、電圧比と電流比は逆になる。

`I_1 = I_2/a`

である。

二次二回路の皮相電力がともに `S`、二次電圧が `V_s` なら、各二次電流の大きさは

`I_s = S/V_s`

となる。

T座一次線電流は

`I_U = I_s/a_t`

である。

主座では、その二次電流による起磁力を打ち消す一次成分を

`I'_m = I_s/a_m`

とおく。さらにT座一次電流は主座一次の両半巻線へ `I_U/2` ずつ分かれて加わる。主座負荷による成分とT座由来成分は90°ずれるため、V相またはW相の線電流の大きさは

`I_V = I_W = √[(I'_m)^2 + (I_U/2)^2]`

となる。

等容量負荷なら

`a_t = (√3/2)a_m`

なので、

`I_U = (2/√3)I'_m`

である。したがって、

`I_V^2 = (I'_m)^2 + (I_U/2)^2`

`= (I'_m)^2 + (1/3)(I'_m)^2`

`= (4/3)(I'_m)^2`

より、

`I_V = I_U`

となる。W相も同じ大きさとなり、フェーザ配置は120°ずつになるので三相側は平衡する。

## 8. 巻線容量と結線利用率

結線利用率は、二次側から取り出す合計皮相電力が、一次巻線容量の合計をどれだけ有効に使っているかを見る量である。ここでは効率と混同しないため `k_u` と書く。

`k_u = 二次側合計皮相電力 / 一次巻線容量合計`

主座一次巻線容量は

`P_m = V_L I_V`

T座一次巻線容量は

`P_t = [(√3/2)V_L] I_U`

で求める。

H23二次問2の条件では、二次側10 MVAが2回路、主座一次巻線容量11.547 MVA、T座一次巻線容量10.0 MVAとなり、

`k_u = 20/(11.547+10) = 0.928`

となる。

## 9. 三相側不平衡と逆相電流

スコット結線で三相側が平衡するには、二つの単相出力の負荷条件が対応していなければならない。少なくとも本Topicで扱う理想化では、二回路が等容量・同一力率で負荷されると一次三相電流を平衡させられる。

一方、片側だけ負荷が大きい、あるいは二回路の力率が異なると、一次側3線の電流の大きさ・位相関係が対称にならない。この状態が三相側不平衡であり、逆相電流成分を含み得る。

逆相電流とは、正相とは逆の相順をもつ三相成分である。本Topicでは「不平衡になると逆相成分が生じ得る」と判断できればよい。正相・逆相を数値分解する対称座標法はTopic 13で扱う。

## 10. 変形ウッドブリッジ結線

変形ウッドブリッジ結線も、超高圧の三相交流から新幹線き電用の2組の単相交流を得るための相変換結線である。

JRTTの公開資料では、一般的なスター・デルタ結線の組合せで構成でき、中性点電流を抑えやすい一方、二次側2出力の電圧をそろえるため一方に別置きの昇圧変圧器を必要とする構成とされている。

Topic 07では内部巻線定数の計算へは進まず、スコット結線との比較対象として「三相→2組の単相」「超高圧受電への適用」「別置き昇圧変圧器を要する」という構成上の特徴を押さえる。

## 11. ルーフ・デルタ結線

ルーフ・デルタ結線も三相から2組の単相へ変換する新幹線き電用変圧器である。JRTT・明電舎の公開資料では、変形ウッドブリッジ結線で必要だった別置き昇圧変圧器を不要にし、巻線構造を簡素化することで小型・低損失化できる方式として説明されている。

明電舎の公開情報では、スコット結線は中性点非接地の特別高圧系統、ルーフ・デルタ結線は中性点接地の超高圧系統へ適用する区分が示されている。

このTopicでは、ルーフ・デルタの内部インピーダンス設計や保護方式には入らない。結線比較として役割と構成差だけを扱う。

## 12. 三つの結線を比較する

| 結線 | 共通する役割 | Topic 07で押さえる特徴 | このTopicで計算する範囲 |
|---|---|---|---|
| スコット | 三相から2組の単相へ相変換 | 主座＋T座、二次2回路は90°、等容量負荷で三相側平衡 | フェーザ、巻数比、一次電流、巻線容量、利用率 |
| 変形ウッドブリッジ | 三相から2組の単相へ相変換 | 超高圧受電で用いられ、出力電圧をそろえるため別置き昇圧変圧器を要する | 構成比較のみ |
| ルーフ・デルタ | 三相から2組の単相へ相変換 | 超高圧・中性点接地系統向け、別置き昇圧変圧器不要、構造簡素化 | 構成比較のみ |
比較の目的は方式名の暗記ではなく、「どのように三相から2組の単相を作り、受電側の不平衡を抑えるか」という共通目的と、結線構造の違いを区別することにある。

## 13. 問題を見たときの解法手順

1. 三相側の基準フェーザを一つ置く。
2. 残り二相を±120°で複素表示する。
3. 線間量・巻線電圧はフェーザ差から求める。
4. スコットなら主座 `V_L`、T座 `√3/2 V_L` を区別する。
5. 巻数比 `a=V_1/V_2` を求める。
6. 二次負荷電流を求め、`I_1=I_2/a` で一次へ戻す。
7. 主座側ではT座電流の半分が加わることを考え、90°成分としてフェーザ合成する。
8. `I_U=I_V=I_W` かつ120°位相差になるかを確認する。
9. 必要なら巻線容量と結線利用率を計算する。
10. 負荷条件が崩れていれば三相側不平衡・逆相発生の可能性を判断する。ただし対称座標法による分解は行わない。

## 14. 頻出ミス

- `120°`: 三相側の相差、`90°`: スコット二次二回路の相差。この二つを混同しない。
- `V_L` と `√3/2 V_L` を同じ一次電圧として扱わない。
- 電圧比 `a=V_1/V_2` に対し、電流は `I_1=I_2/a` となる。
- フェーザは絶対値同士を足さず、複素数または直交成分として合成する。
- 結線利用率を変圧器効率と混同しない。
- 不平衡から「逆相が生じ得る」と判断するところで止め、Topic 13の対称座標法を先取りしない。

## 15. 新幹線への接続

新幹線変電所では、電力会社等から受けた三相交流を、き電用変圧器で列車へ送る単相交流へ相変換する。系列SPECの主題である「三相電力をどう25kVの単相へ変えるか」は、単なる変圧比ではなく、三相側をできるだけ平衡に保ちながら2組の単相き電回路を作る問題として理解する。

ここで必要なのは実設備固有値の暗記ではない。三相フェーザ、相変換結線、平衡条件を一般式で解けることが電験対策上の中心である。

# 3段階例題

数値はすべて教材用仮定値であり、実設備値ではない。

## 例題1 基礎: 三相フェーザから相間電圧と枝電流を求める

対称三相の相電圧を `E=10.0 kV` とする。

`E_U=10.0∠0° kV`

`E_V=10.0∠-120° kV`

U-V間に `R=20.0 Ω` の抵抗を接続した。`E_UV` と枝電流 `I_UV` の大きさを求めよ。

### 解答

相間電圧はフェーザ差である。

`E_UV = E_U - E_V`

対称三相なので、その大きさは

`|E_UV| = √3 E = √3 × 10.0 = 17.32 kV`

抵抗枝なので、

`|I_UV| = |E_UV|/R`

`= 17.32×10^3 / 20.0`

`= 866 A`

答:
- `|E_UV| = 17.3 kV`
- `|I_UV| = 866 A`

検算: 相間電圧は相電圧より `√3` 倍になるので桁は妥当である。

## 例題2 本試験標準: スコット結線の巻数比・一次電流・利用率

三相線間電圧 `V_L=132 kV` から、スコット結線で二次電圧 `V_s=66.0 kV` の単相二回路を得る。各二次回路は皮相電力 `S=12.0 MVA` の等容量負荷で、理想変圧器とする。

次を求めよ。

1. 主座巻数比 `a_m`
2. T座巻数比 `a_t`
3. 二次電流 `I_s`
4. T座一次線電流 `I_U`
5. 主座二次負荷による一次成分 `I'_m`
6. V相線電流 `I_V`
7. 主座・T座一次巻線容量 `P_m, P_t`
8. 結線利用率 `k_u`

### 解答

主座一次電圧は線間電圧そのものなので、

`a_m = 132/66.0 = 2.00`

T座一次電圧は

`V_t = (√3/2)×132 = 114.315 kV`

よって、

`a_t = 114.315/66.0 = 1.732`

二次電流は

`I_s = 12.0×10^6 / (66.0×10^3)`

`= 181.82 A`

T座一次線電流は

`I_U = I_s/a_t = 181.82/1.732 = 104.97 A`

主座側の一次成分は

`I'_m = I_s/a_m = 181.82/2.00 = 90.91 A`

V相では `I'_m` と `I_U/2` が90°の関係で合成されるので、

`I_V = √[90.91^2 + (104.97/2)^2]`

`= 104.97 A`

したがって `I_U=I_V` となり、W相も同じ大きさになる。

主座一次巻線容量は

`P_m = 132×104.97/1000 = 13.856 MVA`

T座一次巻線容量は

`P_t = 114.315×104.97/1000 = 12.000 MVA`

結線利用率は

`k_u = (12.0+12.0)/(13.856+12.000)`

`= 0.928`

答:
- `a_m = 2.00`
- `a_t = 1.732`
- `I_s = 181.8 A`
- `I_U = 105.0 A`
- `I'_m = 90.91 A`
- `I_V = 105.0 A`
- `P_m = 13.86 MVA`
- `P_t = 12.00 MVA`
- `k_u = 0.928`

この問題では、T座一次電圧を `132 kV` と置かず `√3/2` 倍すること、電流比を電圧比と逆にすることが要点である。

## 例題3 複合・ひっかけ: 二つの単相負荷が等しくない場合

例題2と同じ `V_L=132 kV`、`V_s=66.0 kV` のスコット結線で、T座側を `12.0 MVA`、主座側を `6.00 MVA` とする。両負荷の力率条件は同じとする。

1. T座一次線電流 `I_U` を求めよ。
2. 主座二次負荷による一次成分 `I'_m` を求めよ。
3. V相線電流の大きさ `I_V` を求めよ。
4. 三相側は平衡か。不平衡なら逆相について何が言えるか。

### 解答

巻数比は例題2と同じで、

`a_m=2.00`

`a_t=1.732`

である。

T座二次電流は

`I_t = 12.0×10^6/(66.0×10^3) = 181.82 A`

したがって、

`I_U = 181.82/1.732 = 104.97 A`

主座二次電流は

`I_m = 6.00×10^6/(66.0×10^3) = 90.91 A`

よって主座一次成分は

`I'_m = 90.91/2.00 = 45.45 A`

V相線電流の大きさは、二成分が90°なので、

`I_V = √[45.45^2 + (104.97/2)^2]`

`= 69.43 A`

一方、U相は `104.97 A` である。したがって、三相線電流の大きさがそろわず、三相側は不平衡である。

不平衡三相電流には逆相成分が生じ得る。ここで逆相電流の数値まで求めるには対称座標法が必要になるため、本Topicでは計算しない。

答:
- `I_U = 105.0 A`
- `I'_m = 45.45 A`
- `I_V = 69.43 A`
- 三相側は不平衡で、逆相成分を含み得る

ひっかけは「スコット結線なら常に三相側が平衡する」と考えることにある。平衡化には二つの単相負荷条件が対応している必要がある。
