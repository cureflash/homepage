## 過去問から逆算した教材必須事項

### 用語・定義
- 対称三相交流
- 相電圧・線間電圧
- フェーザ（複素ベクトル）
- 単相負荷
- 相変換
- 主座変圧器、T座変圧器
- 平衡負荷、不平衡負荷
- 逆相電流の意味
- 結線利用率

### 原理・現象
- 三相電圧が120°ずつ位相差をもつこと
- スコット結線で互いに90°位相差の単相二回路を得る仕組み
- T座一次電圧 `√3/2` がフェーザ幾何から生じること
- 二次側二回路を等容量・90°位相差で負荷すると三相側電流を平衡させられること
- 負荷が崩れると三相側不平衡となり逆相成分を生じ得ること
- 変形ウッドブリッジ結線、ルーフ・デルタ結線をスコット結線と比較する観点

### 公式・計算
- `E_a = E∠0°`, `E_b = E∠-120°`, `E_c = E∠-240°`
- 相間量をフェーザ差で求める手順
- スコット主座の巻数比とT座の `√3/2` 電圧関係
- 理想変圧器としての電圧比・電流比
- フェーザ合成による一次三相電流
- 結線利用率の定義と計算

### 図・可視化
- 三相電圧フェーザ図
- スコット結線図
- 主座/T座一次電圧のフェーザ図
- 二次二回路90°と一次三相120°の対応
- スコット、変形ウッドブリッジ、ルーフ・デルタの結線比較図

### 解法アルゴリズム
1. 三相側の基準フェーザを置く。
2. 120°位相差で残りの相を複素表示する。
3. 結線図から各巻線に掛かる電圧をフェーザ差として求める。
4. 巻数比から二次電圧または一次電圧を求める。
5. 単相負荷電流を求め、変圧器の電流比で一次巻線電流へ戻す。
6. 一次側各線電流をフェーザ合成する。
7. 三相側が平衡する条件を確認する。
8. 問われた場合は巻線容量と利用率を計算する。
9. 不平衡時は逆相が生じ得ることまで判断し、対称座標法による定量解析はTopic 13へ送る。

### 頻出ミス
- 120°と90°を混同する
- 相電圧・線間電圧・巻線電圧を混同する
- T座の `√3/2` を暗記だけで使い、基準電圧を取り違える
- 電圧比と電流比を同方向に扱う
- 複素電流を実数として足す
- 不平衡と逆相の存在を、対称座標法の計算まで先取りしてしまう

### 1. 平成23年度 第二種一次試験 理論 問6

独立答案:
- (1) `ロ`: `E_3 = E e^{-j4π/3}`
- (2) `ヲ`: `I_12 = (E/R)(1-e^{-j2π/3})`
- (3) `リ`: `I_13 = (E/R)(1-e^{-j4π/3})`
- (4) `ホ`: `I_1 = 3E/R`
- (5) `ヨ`: `I_12 = I_13 = √3E/R`

検算:
- `I_1 = I_12 + I_13 = (E/R)(2-e^{-j2π/3}-e^{-j4π/3}) = 3E/R`
- `|1-e^{-j2π/3}| = |1-e^{-j4π/3}| = √3`

公式解答 `ロ・ヲ・リ・ホ・ヨ` と `5 / 5空欄 PASS`。三相フェーザ、相間量、節点電流の固定範囲だけで完答できる。

### 2. 平成23年度 第二種二次試験 機械・制御 問2

独立答案:

(1)a 巻数比
- 主座: `a_m = 110/60 = 1.833... → 1.83`
- T座: `a_t = (√3/2 × 110)/60 = 1.5877... → 1.59`

(1)b 一次巻線電流
- 二次電流: `I_u = I_v = 10000/60 = 166.667 A`
- T座一次: `I_U = I_u/a_t = 104.97 A → 105 A`
- 主座の二次負荷起磁力を打ち消す成分: `I'_m = I_v/a_m = 90.909 A`
- T座一次電流の半分は主座一次の各半巻線へ90°位相差で加わるので、`I_V = √[(I'_m)^2 + (I_U/2)^2] = 104.97 A → 105 A`

(1)c 一次巻線容量
- 主座: `P_m = 110 kV × 104.97 A = 11.547 MVA → 11.5 MVA`
- T座: `P_t = (√3/2 × 110 kV) × 104.97 A = 10.0 MVA`

(2) 総合利用率
- `η = (10 + 10)/(11.547 + 10) = 0.92820 → 0.928`

公式標準解答の `a_m=1.83`、`a_t=1.59`、`I_V=I_U=105 A`、`P_m=11.5 MVA`、`P_t=10.0 MVA`、利用率 `0.928` と一致。`7 / 7答案要素 PASS`。スコット結線、理想変圧器比、フェーザ合成、巻線容量、利用率の固定範囲だけで完答できる。
