# 解答・完全解説

## 問1

正答: 2

対称三相では三つの相電圧は同じ大きさで120°ずつ位相がずれるため、複素フェーザ和は0になる。

`1 + e^{-j2π/3} + e^{-j4π/3} = 0`

1はフェーザを同相量として足している。3は大きさだけなら等しいが複素数としては位相が異なる。4はスコット二次二回路の90°と混同している。5は対称三相の定義と逆である。

## 問2

正答: 3

`E_UV = E - E e^{-j2π/3}`

実部・虚部に分けると、

`E_UV = E[1-(-1/2-j√3/2)]`

`= E(3/2 + j√3/2)`

したがって、

`|E_UV| = √3E`

位相は

`tan^-1[(√3/2)/(3/2)] = 30°`

より `√3E∠30°` である。正答は3。

## 問3

正答: 4

スコット結線では主座一次巻線が三相の二線間へ接続され、T座一次巻線は残る相と主座中点の間へ接続される。フェーザ三角形の高さから、T座一次電圧は

`V_t = (√3/2)V_L`

となる。正答は4。

## 問4

正答: 1

A, B, CはいずれもTopic 07固定範囲の比較表と一致する。

- スコット: 主座＋T座で三相から2組の単相へ変換する。
- 変形ウッドブリッジ: 二つの出力電圧をそろえるため別置き昇圧変圧器を要する構成がある。
- ルーフ・デルタ: その別置き昇圧変圧器を不要にし、構造簡素化・小型低損失化を狙う。

したがって正答は1。

## 問5

正答: 3

相間電圧の大きさは

`|E_UV| = √3E`

`= √3 × 6.60 = 11.43 kV`

抵抗枝電流は

`|I_UV| = |E_UV|/R`

`= 11.43×10^3 / 15.0`

`= 762 A`

したがって正答は3。`6.60 kV / 15 Ω` として相電圧をそのまま使うと440 Aとなり、選択肢2の誤りになる。

## 問6

正答: 2

主座巻数比は

`a_m = V_L/V_s = 110/55.0 = 2.00`

T座一次電圧は `(√3/2)V_L` なので、

`a_t = [(√3/2)×110]/55.0`

`= 1.732`

よって正答は2。T座にも110 kVがそのまま加わるとして `a_t=2.00` とする選択肢3が典型的な誤りである。

## 問7

正答: 4

T座二次電流は

`I_s = S/V_s`

`= 8.00×10^6/(40.0×10^3)`

`= 200 A`

T座巻数比は

`a_t = [(√3/2)×80.0]/40.0 = 1.732`

理想変圧器では電流比は電圧比の逆なので、

`I_U = I_s/a_t`

`= 200/1.732`

`= 115.5 A`

正答は4。

## 問8

正答: 1

本Topicの理想化では、二つの単相出力を等容量・同一力率で負荷すると、スコット結線の一次側3線電流を等しい大きさ・120°位相差にできる。したがって1が正しい。

2, 4, 5は負荷条件を無視している。3は三相側120°とスコット二次二回路90°を混同している。

## 問9

等容量負荷時の理想スコット結線では、結線利用率は

これは変圧器の入出力損失から定義する効率ではなく、二次側合計皮相電力を一次巻線容量合計で割った結線利用率である。

正答: 2

二次二回路の負荷容量が `10 MVA` と `5 MVA` で等しくないため、本Topicの理想平衡条件を満たさない。三相側電流は不平衡となり、逆相成分を含み得る。

## 問11

(1) 相間電圧

`E_UV = E_U - E_V`

`= 10.0∠0° - 10.0∠-120°`

対称三相の関係から、

`E_UV = √3 × 10.0∠30°`

`= 17.32∠30° kV`

(2) 枝電流

抵抗負荷なので電流は相間電圧と同相である。

`I_UV = E_UV/R`

`= 17.32×10^3 / 25.0 ∠30°`

`= 692.8∠30° A`

(3) 理由

`E_U` と `E_V` は120°位相が異なるフェーザなので、実効値の絶対値だけを算術加算できない。複素数として差を取り、その後に大きさを求める必要がある。

答:
- `E_UV = 17.32∠30° kV`
- `I_UV = 692.8∠30° A`

## 問12

(1) 主座巻数比

`a_m = 110/55.0 = 2.00`

(2) T座巻数比

`a_t = [(√3/2)×110]/55.0`

`= 1.732`

(3) 二次電流

`I_s = 9.00×10^6/(55.0×10^3)`

`= 163.64 A`

(4) T座一次線電流

`I_U = I_s/a_t`

`= 163.64/1.732`

`= 94.48 A`

(5) 主座二次負荷による一次成分

`I'_m = I_s/a_m`

`= 163.64/2.00`

`= 81.82 A`

(6) V相線電流

主座成分 `I'_m` とT座由来成分 `I_U/2` は90°なので、

`I_V = √[(I'_m)^2 + (I_U/2)^2]`

`= √[81.82^2 + (94.48/2)^2]`

`= 94.48 A`

等容量条件なので `I_U = I_V = I_W` となる。

(7) 一次巻線容量

主座:

`P_m = V_L I_V`

`= 110×94.48/1000`

`= 10.39 MVA`

T座:

`P_t = [(√3/2)V_L]I_U`

`= [(√3/2)×110]×94.48/1000`

`= 9.00 MVA`

(8) 結線利用率

`k_u = (9.00+9.00)/(10.39+9.00)`

`= 0.928`

答:
- `a_m = 2.00`
- `a_t = 1.732`
- `I_s = 163.64 A`
- `I_U = 94.48 A`
- `I'_m = 81.82 A`
- `I_V = 94.48 A`
- `P_m = 10.39 MVA`
- `P_t = 9.00 MVA`
- `k_u = 0.928`

## 問13

(1) 巻数比

`a_m = 120/60.0 = 2.00`

`a_t = [(√3/2)×120]/60.0 = 1.732`

(2) T座一次線電流

T座二次電流は

`I_t = 10.0×10^6/(60.0×10^3) = 166.67 A`

したがって、

`I_U = 166.67/1.732 = 96.23 A`

(3) 主座二次負荷による一次成分

主座二次電流は

`I_m = 5.00×10^6/(60.0×10^3) = 83.33 A`

よって、

`I'_m = 83.33/2.00 = 41.67 A`

(4) V相線電流

`I_V = √[(I'_m)^2 + (I_U/2)^2]`

`= √[41.67^2 + (96.23/2)^2]`

`= 63.65 A`

(5) 平衡判定

U相線電流は `96.23 A`、V相線電流は `63.65 A` で大きさが一致しないため、三相側は平衡していない。不平衡三相電流には逆相成分が生じ得る。

本Topicでは逆相の存在可能性までを判定し、正相・逆相の数値分解は行わない。

## 問14

(1) 平衡時一次線電流

各二次回路の皮相電力を `S`、二次電圧を `V_s` とする。

`I_s = S/V_s`

`a_m = V_L/V_s`

`a_t = (√3/2)a_m`

したがってT座一次線電流は

`I = I_U = I_s/a_t`

`= (S/V_s) / [(√3/2)(V_L/V_s)]`

`= 2S/(√3 V_L)`

(2) 一次巻線容量

平衡時は主座側線電流も `I` なので、

`P_m = V_L I`

`= V_L × 2S/(√3 V_L)`

`= 2S/√3`

T座一次電圧は `(√3/2)V_L` なので、

`P_t = [(√3/2)V_L]I`

`= [(√3/2)V_L] × 2S/(√3 V_L)`

`= S`

(3) 結線利用率

二次側合計は `2S` だから、

`k_u = 2S / (2S/√3 + S)`

`= 2 / (1 + 2/√3)`

`= 0.9282`

したがって `k_u ≈ 0.928`。

(4) 効率との違い

結線利用率は、出力と損失の比ではなく、二次側合計皮相電力と一次巻線容量合計の比である。したがって変圧器効率とは別の量である。

## 問15

三方式はいずれも、三相交流から新幹線き電用の2組の単相交流を得る相変換結線である。

(2) スコット結線

主座変圧器とT座変圧器を用いる。主座一次電圧は `V_L`、T座一次電圧は `(√3/2)V_L` となり、適切な極性で二次側に互いに90°位相差の単相二回路を得る。二回路を等容量・同一力率で負荷すると、一次三相電流を平衡させられる。

(3) 変形ウッドブリッジ結線

Topic 07の比較範囲では、一般的なスター・デルタ結線の組合せで構成できる一方、二次側2出力の電圧をそろえるため一方に別置き昇圧変圧器を要する構成として押さえる。

(4) ルーフ・デルタ結線

変形ウッドブリッジ結線で必要だった別置き昇圧変圧器を不要にし、巻線構造を簡素化できる。その結果、小型化・低損失化につながる方式として扱う。

(5) 適用系統

本Topicで参照した明電舎公開情報では、スコット結線は中性点非接地の特別高圧系統、ルーフ・デルタ結線は中性点接地の超高圧系統への適用区分が示されている。
