### 1. H23 一次 理論 問6 — PASS

完成教材の§2「対称三相交流とフェーザ」、§3「相間負荷の電流を求める基本形」、§13「問題を見たときの解法手順」から再構成した。

対称三相を

- `E_1 = E e^{j0}`
- `E_2 = E e^{-j2π/3}`
- `E_3 = E e^{-j4π/3}`

と置く。

抵抗枝電流はフェーザ差から

- `I_12 = (E/R)(1-e^{-j2π/3})`
- `I_13 = (E/R)(1-e^{-j4π/3})`

となる。

節点電流は

`I_1 = I_12 + I_13`

`= (E/R)(2-e^{-j2π/3}-e^{-j4π/3})`

対称三相の関係

`1 + e^{-j2π/3} + e^{-j4π/3} = 0`

より

`I_1 = 3E/R`

となる。

また、

`|1-e^{-j2π/3}| = |1-e^{-j4π/3}| = √3`

なので

`I_12 = I_13 = √3E/R`

である。

再解答:
- (1) `ロ`
- (2) `ヲ`
- (3) `リ`
- (4) `ホ`
- (5) `ヨ`

公式解答 `ロ・ヲ・リ・ホ・ヨ` と一致。`5 / 5空欄 PASS`。

### 2. H23 二次 機械・制御 問2 — PASS

完成教材の§5「スコット結線の構成」、§6「巻数比」、§7「電流比と一次三相電流」、§8「巻線容量と結線利用率」、§13「解法手順」から再構成した。

与条件:
- 三相線間電圧 `V_L = 110 kV`
- 各二次電圧 `V_s = 60 kV`
- 各二次皮相電力 `S = 10 MVA`

#### (1)a 巻数比

主座:

`a_m = V_L/V_s = 110/60 = 1.833... → 1.83`

T座一次電圧は

`V_t = (√3/2)V_L`

なので

`a_t = [(√3/2)×110]/60 = 1.5877... → 1.59`

#### (1)b 一次巻線電流

二次電流:

`I_s = S/V_s = 10×10^6/(60×10^3) = 166.667 A`

T座一次:

`I_U = I_s/a_t = 104.97 A → 105 A`

主座負荷による一次成分:

`I'_m = I_s/a_m = 90.909 A`

T座一次電流の半分が主座一次の各半巻線へ90°位相差で加わるため、

`I_V = √[(I'_m)^2 + (I_U/2)^2]`

`= 104.97 A → 105 A`

#### (1)c 一次巻線容量

主座:

`P_m = 110 kV × 104.97 A = 11.547 MVA → 11.5 MVA`

T座:

`P_t = [(√3/2)×110 kV] × 104.97 A = 10.0 MVA`

#### (2) 総合利用率

`k_u = (10+10)/(11.547+10)`

`= 0.92820 → 0.928`

再解答:
- `a_m = 1.83`
- `a_t = 1.59`
- `I_V = 105 A`
- `I_U = 105 A`
- `P_m = 11.5 MVA`
- `P_t = 10.0 MVA`
- 利用率 `0.928`

公式標準解答と全要素一致。`7 / 7答案要素 PASS`。
