### R5二次「電力・管理」問4

```text
R = 4×0.2 = 0.8 Ω/相
X = 4×0.6 = 2.4 Ω/相
```

(1) 300 kW、0.9進みより
```text
Q = -300 tan(acos 0.9) = -145.30 kvar
Vs = Vr + (RP+XQ)/Vr
   = 6600 + {0.8×300000 + 2.4×(-145300)}/6600
   = 6583.5 V
```
候補解: `6.58 kV`。

(2) 分散型電源500 kW追加後は系統から見た有効電力 `P=-200 kW`。`Vs=Vr=6600 V` なので

既存の需要家無効電力は `-145.30 kvar` なので
```text
QL = 66.67 - (-145.30) = 211.97 kvar
```
候補解: 分路リアクトル `212 kvar`。

### R2二次「電力・管理」問6

負荷1:
```text
P1 = 6000 kW
QL1 = 6000×tan(acos 0.8) = 4500 kvar
```

増設負荷:
```text
P2 = 4500 kW
QL2 = 4500×tan(acos 0.6) = 6000 kvar
```

既設コンデンサ `Q1=2000 kvar` を差し引くと、追加コンデンサ投入前は
```text
P = 10500 kW
Qbefore = 4500+6000-2000 = 8500 kvar
```

(1a) 変圧器容量 `ST=12000 kVA` より
```text
Qlimit = sqrt(12000^2-10500^2) = 5809.475 kvar
Qc,min = 8500-5809.475 = 2690.525 kvar
```
最低必要量を不足側へ丸めない。候補解は `2691 kvar以上`、3有効数字表記なら `2.70×10^3 kvar`。

(1b)
```text
cosθs = 10500/12000 = 0.875
```

(2) 増設負荷の力率角:
```text
θ2 = acos 0.6 = 53.13°
```
ベクトルは `P2` を正の有効電力方向、遅れ無効電力を下向き、追加コンデンサ `Q2` を補償方向へ描く。

(3) 総合力率0.95遅れ:
```text
Qtarget = 10500×tan(acos 0.95) = 3451.18 kvar
Q2 = 8500-3451.18 = 5048.82 kvar
```
候補解: `5.05×10^3 kvar`。

公式標準解答照合: `2.70×10^3 kvar`, `0.875`, ベクトル図・`θ2`, `5.05×10^3 kvar`。

判定: `4 / 4 PASS`。

制作前blindで不足した「最低必要容量を不足側へ丸めない」は、今回 `PASS / 改善確認`。

### H23二次「電力・管理」問3

(1) 66 kV側へ換算した変圧器リアクタンス:
```text
Xt = 0.15×66^2/200 = 3.267 Ω
```
候補解: `3.27 Ω`。

(2) 合成リアクタンス:
```text
X = 3.267+4 = 7.267 Ω
```
`P=VsVr sinδ/X` から66 kV側等価の送電端電圧を
```text
Vs(eq) = 93×7.267/(68×0.15) = 66.258 kV
```
と求めた。

ここで問題は「一次母線電圧」を要求しているが、blind候補では `66.258 kV` をそのまま最終値として固定し、変圧器定格比 `154/66` で一次側へ戻す工程を落とした。

公式標準解答は
```text
66.258×154/66 = 154.6 kV ≒ 155 kV
```
である。

この答案要素は `FAIL`。

同じ条件から負荷無効電力は
```text
Qr = (VsVr cosδ - Vr^2)/X = -23.3 Mvar
```
で公式標準解答と一致。

(3) `Vr=66 kV` に変更すると
```text
sinδ' = 93×7.267/(66.258×66) = 0.15455
Q'r = -4.88 Mvar
Qc = Q'r-Qr = -4.88-(-23.3) ≒ 18.4 Mvar
```
遅相設備なので分路リアクトル、容量 `18.4 MVA`。公式標準解答と一致。

判定: `4 / 5 PASS`。
