## 問4 基礎・一次型: コンデンサとリアクトル

受電負荷基準で遅れ無効電力を正とする。正しい説明を選べ。

1. コンデンサ投入では `Qnet = Qload + Qc` となる。
2. 分路リアクトル投入では必ず力率が1になる。
3. コンデンサは遅れ無効電力を補償し、分路リアクトルは進み無効電力を吸収する方向に働く。

# 解答・完全解説

## 問1

正答: `2`

```text
|S| = sqrt(P^2 + Q^2)
    = sqrt(8^2 + 6^2)
    = 10 MVA

cosφ = P/|S|
     = 8/10
     = 0.80
```

`Q>0` なので遅れ力率である。力率の数値だけでは進み・遅れを区別できないため、Qの符号も確認する。

## 問2

正答: `3`

三相有効電力は

`P = sqrt(3) V I cosφ`

なので

```text
I = P/{sqrt(3)V cosφ}
  = 12×10^6/{sqrt(3)×66×10^3×0.80}
  = 131.22 A
```

力率1なら `104.97 A` であり、同じP・Vでは力率低下により電流が増える。

## 問3

正答: `2`

```text
Q1 = P tan(acos 0.80)
   = 6.0×0.75
   = 4.50 Mvar

Q2 = P tan(acos 0.95)
   = 6.0×0.328684
   = 1.972 Mvar

Qc = Q1-Q2
   = 2.528 Mvar
```

よって最も近いのは `2.53 Mvar`。力率の差 `0.95-0.80` にPを掛けるのは誤りである。

## 問4

正答: `3`

本教材の符号規約では

```text
コンデンサ投入: Qnet = Qload - Qc
リアクトル投入: Qnet = Qload + QL
```

である。コンデンサは遅れQを減らす方向、分路リアクトルは進みQを吸収して正方向へ戻す方向に働く。

## 問5

正答: `2`

PとV一定なら

```text
I ∝ 1/cosφ
Ploss ∝ I^2 ∝ 1/cos^2φ
```

したがって

```text
Ploss,after/Ploss,before
= (0.75/0.95)^2
= 0.6233
```

約 `0.62倍`。低減率は約 `37.7 %` である。

## 問6

正答: `2`

```text
ΔV ≒ (RP+XQ)/V
   = {0.20×10×10^6 + 0.60×6×10^6}/(66×10^3)
   = 84.85 V
   = 0.08485 kV
```

遅れQが正なので、Rによる有効電力項だけでなくXQ項も電圧降下側へ加わる。

## 問7

正答: `3`

分路リアクトル容量を正値 `QL=3.0 Mvar` とすると

```text
Qnet = Qbefore + QL
     = -4.0 + 3.0
     = -1.0 Mvar
```

進みQの絶対値が小さくなる。リアクトルは容量性無効電力を吸収し、電圧上昇を抑える方向に働く。

## 問8

正答: `3`

設備容量制約は

`sqrt(P^2 + Qafter^2) <= ST`

である。許容される遅れ無効電力は

```text
Qlimit = sqrt(ST^2-P^2)
       = sqrt(9.0^2-8.0^2)
       = 4.123 Mvar
```

よって境界となる最低コンデンサ容量は

```text
Qc,min = Qbefore-Qlimit
       = 6.0-4.123
       = 1.877 Mvar
```

`0.1 Mvar` 刻みなら `1.8 Mvar` は境界を下回るため不可で、最低採用容量は `1.9 Mvar`。

## 問9

正答: `3`

```text
Q1 = 10 tan(acos 0.80)
   = 7.50 Mvar

Q2 = 10 tan(acos 0.95)
   = 3.2868 Mvar

Qc = Q1-Q2
   = 4.2132 Mvar
```

よって `4.21 Mvar`。

## 問10

正答: `2`

軽負荷時は線路静電容量による容量性電流・進み無効電力の影響で、受電端電圧が送電端電圧より高くなる場合がある。分路リアクトルはその進み無効電力を吸収する方向に働き、電圧上昇を抑える。

この問題では送電線特性を既習事項として再利用するだけで、P-V曲線による電圧安定度解析へは進まない。

## 問11

### (1) 改善前後の線路電流

```text
Ibefore
= 18×10^6/{sqrt(3)×66×10^3×0.75}
= 209.95 A

Iafter
= 18×10^6/{sqrt(3)×66×10^3×0.95}
= 165.75 A
```

### (2) 三相線路銅損

```text
Ploss,before
= 3×(209.95)^2×0.25
= 33.06 kW

Ploss,after
= 3×(165.75)^2×0.25
= 20.60 kW
```

### (3) 損失低減率

```text
低減率
= (33.06-20.60)/33.06×100
= 37.67 %
```

### (4) 必要コンデンサ容量

```text
Qc
= 18{tan(acos 0.75)-tan(acos 0.95)}
= 9.958 Mvar
```

したがって約 `9.96 Mvar`。

## 問12

### (1) 設備容量制約

```text
Qlimit = sqrt(9.0^2-8.0^2)
       = 4.1231 Mvar

Qc,min = 6.0-4.1231
       = 1.8769 Mvar
```

連続値では `1.8769 Mvar` 以上必要。`0.1 Mvar` 刻みなら最低 `1.9 Mvar` を採用する。最低必要容量を不足側へ丸めてはいけない。

### (2) 1.9 Mvar投入後の総合力率

```text
Qafter = 6.0-1.9
       = 4.1 Mvar

|Safter| = sqrt(8.0^2+4.1^2)
         = 8.989 MVA

cosφafter = 8.0/8.989
          = 0.8899
```

したがって総合力率は約 `0.890 遅れ`。

### (3) P-Q関係

補償前は

`Sbefore = 8.0 + j6.0 MVA`

である。コンデンサ `Qc` を投入すると

`Safter = 8.0 + j(6.0-Qc) MVA`

となる。Pは一定のままQだけを下げる方向へ移動する。

### (4) 目標力率0.95の条件

```text
Qtarget
= 8.0 tan(acos 0.95)
= 2.6295 Mvar

Qc,target
= 6.0-2.6295
= 3.3705 Mvar
```

約 `3.37 Mvar`。設備容量制約から得た最低値 `1.8769 Mvar` とは別の条件である。

## 問13

### (1) 指定端電圧に必要なQ

```text
Vs-Vr = 22.3-22.0
      = 0.3 kV
      = 300 V
```

近似式より

```text
300
= {0.20×10×10^6 + 1.20×Qtarget}/(22×10^3)
```

したがって

```text
Qtarget
= {300×22×10^3 - 0.20×10×10^6}/1.20
= 3.833×10^6 var
= 3.833 Mvar
```

### (2) 調相設備種別と容量

補償前は `Qbefore=6.0 Mvar` なので、Qを減らす必要がある。

```text

   = 6.0-3.833
```

### (3) 符号による判定
