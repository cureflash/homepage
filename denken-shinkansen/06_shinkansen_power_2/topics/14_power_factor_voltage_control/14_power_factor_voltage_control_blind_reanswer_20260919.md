### R5二次「電力・管理」問4

線路定数:

```text
R = 4×0.2 = 0.8 Ω/相
X = 4×0.6 = 2.4 Ω/相
```

300 kW、力率0.9進みより

```text
Q = -300 tan(acos 0.9) = -145.30 kvar
Vs = Vr + (RP+XQ)/Vr
   = 6583.5 V
```

候補解(1): `6.58 kV`。

分散型電源500 kW追加後、系統から見た有効電力は `P=-200 kW`。`Vs=Vr` より

```text
RP + XQnet = 0
Qnet = +66.67 kvar
QL = 66.67 - (-145.30) = 211.97 kvar
```

候補解(2): 分路リアクトル `212 kvar`。

公式標準解答照合: `6580 V`, `212 kvar`。

判定: `2 / 2 PASS`。

### R2二次「電力・管理」問6

```text
P1 = 6000 kW
QL1 = 6000 tan(acos 0.8) = 4500 kvar
P2 = 4500 kW
QL2 = 4500 tan(acos 0.6) = 6000 kvar
P = 10500 kW
Qbefore = 4500 + 6000 - 2000 = 8500 kvar
```

受電設備容量 `ST=12000 kVA` より

```text
Qlimit = sqrt(12000^2-10500^2) = 5809.475 kvar
Qc,min = 8500-5809.475 = 2690.525 kvar
```

最低必要容量なので不足側へ丸めず、候補解(1a)は `2.70×10^3 kvar`。

```text
cosθs = 10500/12000 = 0.875
θ2 = acos 0.6 = 53.13°
Qtarget = 10500 tan(acos 0.95) = 3451.18 kvar
Q2 = 8500-3451.18 = 5048.82 kvar
```

候補解:
- (1a) `2.70×10^3 kvar`
- (1b) `0.875`
- (2) P-Qベクトル図、`θ2=53.1°`。増設負荷は `+P,+Q`、コンデンサ補償は `-Q` 方向。
- (3) `5.05×10^3 kvar`

公式標準解答と全要素一致。

判定: `4 / 4 PASS`。

制作前blindで不足した「最低必要容量を不足側へ丸めない」は今回も `PASS / 改善維持`。

### H23二次「電力・管理」問3

66 kV側へ換算した変圧器リアクタンス:

```text
Xt = 0.15×66^2/200 = 3.267 Ω
X = 3.267 + 4 = 7.267 Ω
```

候補解(1): `3.267 Ω`。

`P=VsVr sinδ/X` から66 kV側等価の送電端電圧を

```text
Vs(eq) = 93×7.267/(68×0.15) = 66.258 kV
```

と求める。現行教材の補強手順どおり、問題が要求する154 kV一次母線側へ定格電圧比で戻す。

```text
Vprimary = 66.258×154/66 = 154.6 kV ≒ 155 kV
```

候補解(2a): `155 kV`。

続いて

```text
Qr = (VsVr cosδ - Vr^2)/X = -23.3 Mvar
```

候補解(2b): `-23.3 Mvar`。

`Vr=66 kV` に変更すると

```text
sinδ' = 93×7.267/(66.258×66) = 0.15455
Q'r ≒ -4.88 Mvar
ΔQ = Q'r-Qr ≒ +18.4 Mvar
```

したがって候補解(3)は分路リアクトル、容量 `18.4 MVA`。

公式標準解答照合: `3.267 Ω`, `155 kV`, `-23.3 Mvar`, 分路リアクトル, `18.4 MVA`。

判定: `5 / 5 PASS`。

前回完成後blind blockerだった (2a) の `66 kV側等価値 → 154 kV一次側` 復元は今回 `PASS / 改善確認`。
