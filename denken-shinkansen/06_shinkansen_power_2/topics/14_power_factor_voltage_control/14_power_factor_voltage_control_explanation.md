## 1. このテーマで電験は何を問うか

電験二種では、力率を単なる `cosφ` の数値として扱うだけでは足りない。有効電力 `P`、無効電力 `Q`、皮相電力 `S` の関係から、線路電流、損失、電圧降下、調相設備容量まで一続きに計算できる必要がある。

Topic 14の到達点は次のとおり。

1. `P-Q-S` と力率を符号付きで整理できる。
2. 同じ有効電力を送るとき、力率低下で電流と損失が増えることを式で説明できる。
3. 遅れ負荷をコンデンサで補償する容量を `Q=P tanφ` から求められる。
4. 軽負荷時の進み無効電力と受電端電圧上昇を説明し、分路リアクトルを選べる。
5. 線路の `R, X` と `P, Q` から送受電端電圧を計算できる。
6. 指定電圧を保つための補償後 `Q` を逆算し、コンデンサかリアクトルかと必要容量を判定できる。
7. 変圧器の％リアクタンスをオーム値へ換算し、線路リアクタンスと合成して電圧・無効電力計算へ使える。
8. 受電設備容量制約と目標力率条件を区別し、それぞれから必要補償容量を求められる。
9. 「最低必要容量」は計算境界を下回らないように最終表記を決められる。
10. 変圧器を含む等価回路では、計算値がどの電圧側の値かを確認し、問題が別側の母線電圧を要求するときは定格電圧比で要求側へ戻してから答案化できる。

ここでは回生・逆潮流の一般論、故障計算、保護、サージ、P-V曲線による安定度、周波数制御へは進まない。

## 2. 有効電力・無効電力・皮相電力

### 2.1 複素電力

受電負荷を基準に、遅れ無効電力を正とする。

```text
S = P + jQ
|S| = sqrt(P^2 + Q^2)
```

単位は次のように区別する。

- `P`: W, kW, MW
- `Q`: var, kvar, Mvar
- `|S|`: VA, kVA, MVA

負荷が誘導性で電流が電圧より遅れるとき `Q>0`、進み負荷・容量性成分では `Q<0` とする。

### 2.2 力率

`P>=0` の通常の負荷では

```text
cosφ = P / |S|
Q = P tanφ
```

である。

遅れ・進みは `cosφ` の数値だけでは区別できない。例えば力率0.9でも、

- 遅れ0.9: `Q>0`
- 進み0.9: `Q<0`

である。電圧計算ではこの符号が直接結果を左右する。

### 2.3 電力三角形とP-Q平面

横軸を `P`、縦軸を `Q` とすると、通常の遅れ負荷は第1象限にある。コンデンサは負荷の遅れ無効電力を打ち消す方向、分路リアクトルは進み無効電力を吸収する方向に働く。

本sourceでは設備容量の大きさを正値で表し、

```text
Qc >= 0 : コンデンサ容量
QL >= 0 : 分路リアクトル容量
```

とする。負荷側の正味無効電力は

```text
コンデンサ投入: Qnet = Qload - Qc
リアクトル投入: Qnet = Qload + QL
```

と書く。この符号規約を途中で変えない。

## 3. 力率が線路電流を変える

平衡三相で線間電圧 `V`、線電流 `I` とすると、

```text
P = sqrt(3) V I cosφ
```

したがって、

```text
I = P / {sqrt(3) V cosφ}
```

である。

`P` と `V` が同じなら、線路電流は力率に反比例する。力率が低いほど、同じ有効電力を送るために大きな電流が必要になる。

### 3.1 仮定値による確認

仮定条件:
- `P = 20 MW`
- `V = 66 kV`

| 力率 | 線路電流 I [A] |
|---:|---:|
| 0.60 | 291.59 |
| 0.70 | 249.94 |
| 0.80 | 218.69 |
| 0.90 | 194.39 |
| 0.95 | 184.16 |
| 1.00 | 174.95 |

この表をSPEC指定「力率―線路電流」の可視化データとする。実設備値ではなく教材上の仮定値である。

## 4. 力率が線路損失を変える

一相当たり抵抗を `R` とすれば、三相線路の銅損は

```text
Ploss = 3 I^2 R
```

である。

`P` と `V` を一定とすると `I` は `1/cosφ` に比例するので、損失は概ね

```text
Ploss ∝ 1 / cos^2φ
```

となる。

### 4.1 仮定値による確認

3.1と同じ `P=20 MW`, `V=66 kV` に、一相当たり `R=0.20 Ω` を仮定する。

| 力率 | 線路電流 I [A] | 三相損失 [kW] |
|---:|---:|---:|
| 0.60 | 291.59 | 51.02 |
| 0.70 | 249.94 | 37.48 |
| 0.80 | 218.69 | 28.70 |
| 0.90 | 194.39 | 22.67 |
| 0.95 | 184.16 | 20.35 |
| 1.00 | 174.95 | 18.37 |

力率0.80から0.95へ改善した場合、損失比は

```text
(0.80 / 0.95)^2 = 0.709
```

で、同じ抵抗・有効電力・電圧なら約29 %低下する。この表をSPEC指定「力率―損失」の可視化データとする。

## 5. コンデンサによる力率改善

### 5.1 改善前後の無効電力

有効電力 `P` が一定で、改善前力率角を `φ1`、改善後を `φ2` とする。

```text
Q1 = P tanφ1
Q2 = P tanφ2
```

コンデンサが供給する進み無効電力の大きさ `Qc` は、遅れ無効電力の差なので

```text
Qc = Q1 - Q2
   = P(tanφ1 - tanφ2)
```

となる。

### 5.2 解法手順

1. 改善前後の力率から `φ1=acos(cosφ1)`, `φ2=acos(cosφ2)` を求める。
2. `Q1=P tanφ1`、`Q2=P tanφ2` を求める。
3. `Qc=Q1-Q2` を求める。
4. 改善後の `|S|=sqrt(P^2+Q2^2)` を求める。
5. 必要なら `cosφ=P/|S|` へ戻して検算する。

「力率の差」に `P` を掛けてもコンデンサ容量にはならない。必ず `tanφ` の差を使う。

## 6. 受電設備容量制約と最低必要容量

### 6.1 容量制約は不等式

受電設備の容量上限を `ST` とすると、補償後は

```text
sqrt(P^2 + Qafter^2) <= ST
```

でなければならない。

したがって許される無効電力の大きさは

```text
|Qafter| <= sqrt(ST^2 - P^2)
```

である。

補償前の遅れ無効電力を `Qbefore>0` とし、コンデンサ容量を `Qc` とすると

```text
Qafter = Qbefore - Qc
```

なので、最低必要容量は境界で

```text
Qc,min = Qbefore - sqrt(ST^2 - P^2)
```

となる。

### 6.2 目標力率条件とは別に解く

目標力率 `cosφt` が別に指定された場合は、設備容量制約とは別の式で

```text
Qtarget = P tanφt
Qc,target = Qbefore - Qtarget
```

を求める。

「設備容量を超えない最低容量」と「目標力率にする容量」は同じとは限らない。問題文がどちらを問うているかを分ける。

### 6.3 最低必要容量を不足側へ丸めない

制作前blindで不足した答案処理である。

`Qc,min` は「これ以上必要」という不等式の境界である。したがって設備容量を有限の桁数や離散容量で表すとき、最終採用値が境界を下回ってはいけない。

例として仮定値

```text
P = 8.0 MW
Qbefore = 6.0 Mvar
ST = 9.0 MVA
```

とする。

```text
Qlimit = sqrt(9.0^2 - 8.0^2)
       = 4.123 Mvar

Qc,min = 6.0 - 4.123
       = 1.877 Mvar
```

設備を0.1 Mvar刻みで選ぶなら `1.8 Mvar` は不足で、`1.9 Mvar` 以上を選ぶ。

正式ゲートの令和2年度二次問6では境界値が `2690.52 kvar` であり、公式標準解答は不足側へ丸めず `2.70×10^3 kvar` としている。完成後blindでは「境界値を出す」だけでなく「必要量を下回らない最終答案」を確認する。

### 6.4 P-Qベクトル図

P-Q平面では、負荷追加によるベクトルとコンデンサ補償による鉛直方向のベクトルを分けて描く。

- 有効電力増分: P軸方向
- 遅れ無効電力増分: +Q方向
- コンデンサ補償: -Q方向
- 力率角: 合成ベクトルとP軸の角度

数値計算とベクトル図は同じP-Q関係を別表現したものであり、図だけを暗記しない。

## 7. P-Qと電圧降下

### 7.1 三相線路の近似式

平衡三相、線路一相当たりインピーダンス `R+jX`、受電端線間電圧 `Vr`、受電端へ流入する三相有効電力 `P`、無効電力 `Q` とする。電圧位相差が小さい近似では、送電端線間電圧の大きさは

```text
Vs ≒ Vr + (R P + X Q) / Vr
```

である。

使用条件:
- `R, X`: 一相当たり Ω
- `P, Q`: 三相合計 W, var
- `Vs, Vr`: 線間電圧 V
- 電圧位相差が小さい近似

この式から、通常の `R>0`, `X>0` の系統では、遅れ無効電力 `Q>0` が大きいほど電圧降下が増えることが分かる。進み無効電力 `Q<0` は電圧降下を小さくし、条件によっては受電端側が高くなる方向へ働く。

### 7.2 指定電圧を保つ補償量

補償設備投入後の無効電力を `Qnet` とする。指定された `Vs`, `Vr` を満たすよう

```text
Vs - Vr = (R P + X Qnet) / Vr
```

へ代入し、`Qnet` を未知数として解く。

その後、

```text
Qdevice = Qnet - Qload
```

の符号を見て設備種別を決める。本sourceの符号規約では、

- `Qdevice<0`: コンデンサ側の補償
- `Qdevice>0`: リアクトル側の補償

である。

### 7.3 無効電力―受電点電圧の可視化

SPEC指定の可視化には、次の仮定モデルを用いる。

- 送電端線間電圧 `Vs=66 kV`
- 有効電力 `P=20 MW`
- 一相当たり `R=0.20 Ω`, `X=1.00 Ω`
- 小さな電圧変化として `Vr ≒ Vs-(RP+XQ)/Vs` を使用

| Q [Mvar] | 受電点電圧 Vr [kV] |
|---:|---:|
| -10 | 66.091 |
| -5 | 66.015 |
| 0 | 65.939 |
| +5 | 65.864 |
| +10 | 65.788 |

進み側 `Q<0` ほど受電点電圧が高く、遅れ側 `Q>0` ほど低くなる。この表は実設備値ではなく教材用仮定値である。

## 8. 軽負荷時の電圧上昇と分路リアクトル

### 8.1 充電電流とフェランチ効果

送電線・ケーブルには対地・線間静電容量がある。無負荷・軽負荷では負荷電流が小さいため、容量性の充電電流の影響が相対的に大きくなる。条件によって受電端電圧が送電端電圧より高くなる現象をフェランチ効果という。

ここでは固定過去問へ必要な範囲だけを扱い、分布定数線路の詳細導出は新規主題にしない。

### 8.2 フェーザでの判断

容量性充電電流は電圧より進む。線路リアクタンス `jX` による電圧変化 `jX I` は、電流を90°回転させた方向となる。軽負荷時はこの容量性電流による電圧変化が、受電端電圧を押し上げる方向に現れる。

一次試験では「充電電流」「受電端電圧が送電端より高い」「フェランチ効果」「適切なフェーザ図」を一組として判断できるようにする。

### 8.3 分路リアクトル

分路リアクトルは遅れ無効電力を吸収し、容量性の進み無効電力を相殺する方向へ働く。軽負荷時の電圧上昇抑制では、

```text
進み無効電力が過大
→ 分路リアクトルで遅れ無効電力を加える
→ 正味の進みQを小さくする
→ 電圧上昇を抑える
```

と整理する。

コンデンサとリアクトルを名称だけで覚えず、「正味Qをどちらへ動かしたいか」から選ぶ。

## 9. 変圧器％リアクタンスを電圧計算へ使う

### 9.1 オーム値への換算

Topic 08で既習の式を再利用する。基準容量 `Sbase [MVA]`、基準線間電圧 `Vbase [kV]`、リアクタンス `x [%]` なら

```text
X [Ω] = (x/100) Vbase^2 / Sbase
```

である。`kV^2/MVA = Ω` なので単位換算を別に掛けない。

線路リアクタンスと同じ側へ換算した後、

```text
Xtotal = Xt + Xline
```

として使う。一次側と二次側のオーム値をそのまま足してはいけない。

同時に「どの電圧側へ換算したか」を答案上で明示する。66 kV側へ換算した `Xt` と `Xline` で等価回路を作れば、その等価回路から直接求まる端電圧も66 kV側の等価値である。問題が一次側など別の電圧側の母線電圧を要求する場合は、そのまま最終答案にしない。

### 9.2 抵抗を無視した送受電端関係

等価直列リアクタンス `X`、送電端線間電圧 `Vs`、受電端線間電圧 `Vr`、位相差 `δ` とすると、三相合計で

```text
P = Vs Vr sinδ / X
Qr = (Vs Vr cosδ - Vr^2) / X
```

と表せる。

既知の `P, Vr, X, sinδ` から `Vs` を求め、その後 `Qr` を求める。`Qr<0` なら受電端負荷は進み無効電力を系統へ与える側である。

変圧器を含む問題では、ここで求めた `Vs` が「どの側の等価値か」を必ず確認する。例えば変圧器・線路リアクタンスを66 kV側へ換算して計算した結果が

```text
Vs(eq, 66 kV side) = 66.258 kV
```

で、問題が一次154 kV母線電圧を要求しているなら、定格電圧比で

```text
Vprimary
= Vs(eq) × 154/66
= 66.258 × 154/66
= 154.6 kV
≈ 155 kV
```

と一次側へ戻してから答案化する。`66.258 kV` は計算途中の等価側電圧であり、一次母線電圧の最終答案ではない。

一般に、等価回路を `Vbase,eq` 側へそろえ、要求側の定格電圧を `Vbase,req` とするなら、理想変圧器の定格電圧比を用いて

```text
Vreq = Veq × Vbase,req / Vbase,eq
```

と戻す。電圧比を逆にしないこと、線間電圧同士・同一基準側同士で比を取ることを確認する。

### 9.3 指定電圧へ変更する調相設備

送電端電圧と有効電力を一定とし、受電端電圧を `Vr2` へ変更する場合は

```text
sinδ2 = P X / (Vs Vr2)
```

を求め、

```text
Qnet2 = (Vs Vr2 cosδ2 - Vr2^2) / X
```

から新しい受電端正味Qを求める。

元の負荷無効電力を `Qload` とすれば

```text
Qdevice = Qnet2 - Qload
```

である。`Qdevice>0` なら遅れ無効電力を吸収するリアクトル、`Qdevice<0` なら進み無効電力を供給するコンデンサ側と判定する。

## 10. 本試験標準の解法アルゴリズム

### 10.1 力率改善容量

1. 有効電力 `P` を確認する。
2. 改善前後の力率から `tanφ` を求める。
3. `Qbefore=P tanφ1` を求める。
4. `Qafter=P tanφ2` を求める。
5. `Qc=Qbefore-Qafter` を求める。
6. `|S|=sqrt(P^2+Qafter^2)` と `P/|S|` で検算する。

### 10.2 受電設備容量制約

1. 合成した有効電力 `P` と補償前無効電力 `Qbefore` を求める。
2. 容量上限 `ST` に対して `Qlimit=sqrt(ST^2-P^2)` を求める。
3. `Qc,min=Qbefore-Qlimit` を求める。
4. 最終採用容量が `Qc,min` を下回らないように表記・設備刻みを決める。
5. 補償後に `sqrt(P^2+Qafter^2)<=ST` を再計算して検算する。

### 10.3 線路電圧と調相設備

1. 電力の正方向と `Q` の符号を最初に固定する。
2. `R, X` が一相当たりかを確認する。
3. `P, Q` をW, var、`V`をVへそろえる。
4. `Vs≒Vr+(RP+XQ)/Vr` へ代入する。
5. 指定電圧問題では `Qnet` を未知数として逆算する。
6. `Qdevice=Qnet-Qload` の符号で設備種別を決める。
7. 代入し直して指定電圧を満たすか検算する。

### 10.4 リアクタンスだけの送受電端計算

1. 変圧器％リアクタンスを問題指定側のΩ値へ換算し、換算した電圧側を答案に書く。
2. 線路リアクタンスと同じ電圧側で合成する。
3. `P=VsVr sinδ/X` から未知電圧または位相差を求める。この段階の電圧は等価回路を作った側の値である。
4. 問題が要求する母線・端子の電圧側を確認する。等価回路側と異なる場合は、変圧器の定格電圧比で要求側へ戻してから最終答案とする。
5. `Qr=(VsVr cosδ-Vr^2)/X` から受電端Qを求める。
6. 指定電圧へ変更した条件でもう一度 `δ` と `Qnet` を求める。
7. 元の負荷Qとの差から設備種別・容量を求める。

## 11. 3段階例題

### 11.1 基礎例題: 力率改善容量

三相負荷の有効電力を `P=5.0 MW`、力率を0.80遅れから0.95遅れへ改善する。

```text
tanφ1 = tan(acos 0.80) = 0.7500
tanφ2 = tan(acos 0.95) = 0.32868

Qc = 5.0×(0.7500-0.32868)
   = 2.1066 Mvar
```

必要コンデンサ容量は約 `2.11 Mvar` である。

線間電圧を仮に6.6 kVとすると、線路電流は

```text
I1 = 5.0×10^6 / (sqrt(3)×6600×0.80)
   = 546.7 A

I2 = 5.0×10^6 / (sqrt(3)×6600×0.95)
   = 460.4 A
```

となる。力率改善がコンデンサ容量だけでなく線路電流低下へつながることを確認できる。

### 11.2 本試験標準例題: 指定電圧を保つ補償

仮定条件:
- `Vr=6.6 kV`
- `R=0.50 Ω/相`
- `X=2.0 Ω/相`
- `P=1.0 MW`
- 負荷無効電力 `Qload=+0.60 Mvar`
- 送電端電圧を受電端と同じ `6.6 kV` にしたい

近似式で `Vs=Vr` とするには

```text
R P + X Qnet = 0
```

だから、

```text
Qnet = - R P / X
     = -(0.50×1.0×10^6)/2.0
     = -0.25 Mvar
```

必要設備の無効電力は

```text
Qdevice = Qnet - Qload
        = -0.25 - 0.60
        = -0.85 Mvar
```

である。負値なのでコンデンサ側、必要容量は `0.85 Mvar` である。

この例では「電圧を上げたいからコンデンサ」と暗記せず、指定電圧条件から `Qnet` を逆算して設備を決めている。

### 11.3 複合例題: 受電設備容量と丸め

6.3の仮定値を用いる。

```text
P = 8.0 MW
Qbefore = 6.0 Mvar
ST = 9.0 MVA
```

容量制約から

```text
Qlimit = sqrt(9.0^2 - 8.0^2)
       = 4.123 Mvar

Qc,min = 6.0 - 4.123
       = 1.877 Mvar
```

設備が0.1 Mvar刻みなら最小採用値は `1.9 Mvar` である。

`1.8 Mvar` を選ぶと

```text
Qafter = 6.0 - 1.8 = 4.2 Mvar
Safter = sqrt(8.0^2 + 4.2^2)
       = 9.035 MVA
```

となって9.0 MVAを超えるため不適切である。

`1.9 Mvar` なら

```text
Qafter = 4.1 Mvar
Safter = sqrt(8.0^2 + 4.1^2)
       = 8.989 MVA
```

で制約内に入る。不等式問題では最終設備容量を代入し直す検算が有効である。

## 12. 新幹線への接続

新幹線は単相の大容量列車負荷をき電系統から受ける。その上位の三相電力系統から見れば、列車・き電設備を含む負荷の有効電力 `P` と無効電力 `Q` が、受電電流、損失、電圧へ影響する。

このTopicで重要なのは、実際の特定変電所に何Mvarの調相設備があるかを暗記することではない。

```text
列車・き電側のP, Q
→ 上位系統から見た皮相電力と電流
→ 線路・変圧器での電圧変動
→ 必要ならQを補償
→ 電流・損失・電圧を所定範囲へ戻す
```

という電験共通の計算手順へ接続することである。

未確認の新幹線実設備の力率、調相設備容量、受電点電圧変動量は真値として置かない。本sourceの数値例・可視化条件はすべて教材用仮定値である。

## 13. 頻出ミス・ひっかけ

1. `cosφ` の数値だけ見て遅れ・進みを区別しない。
2. `Q=P tanφ` でなく `P×(力率差)` をコンデンサ容量にする。
3. コンデンサ容量 `Qc` の大きさと、複素電力中の容量性 `Q<0` を混同する。
4. 分路リアクトルを「力率を悪くするだけの設備」と覚え、軽負荷時の進みQ吸収・電圧上昇抑制を見落とす。
5. 三相線間電圧式へ相電圧用の係数を重ねて掛ける。
6. `R, X` の一相値と三相合計電力の対応を崩す。
7. 発電側条件で `P` の向きが変わっているのに正値固定で代入する。
8. 変圧器％リアクタンスを異なる電圧側のΩ値のまま線路リアクタンスへ加える。
9. 等価回路を一方の電圧側へ換算して求めた電圧を、問題が別側の母線電圧を要求しているのに定格電圧比で戻さずそのまま答案にする。
10. 最低必要容量の境界値を通常の四捨五入だけで不足側へ落とす。
11. 電圧が高い・低いという結果だけで設備を決め、補償後Qを再代入して検算しない。

## 16. 公式・解法まとめ

```text
S = P + jQ
|S| = sqrt(P^2 + Q^2)
cosφ = P / |S|
Q = P tanφ

I = P / (sqrt(3) V cosφ)
Ploss = 3 I^2 R

Qc = P(tanφ1 - tanφ2)

|Qafter| <= sqrt(ST^2 - P^2)
Qc,min = Qbefore - sqrt(ST^2 - P^2)

Vs ≒ Vr + (R P + X Q)/Vr

X[Ω] = (x[%]/100) Vbase[kV]^2 / Sbase[MVA]

P = Vs Vr sinδ / X
Qr = (Vs Vr cosδ - Vr^2) / X

Vreq = Veq × Vbase,req / Vbase,eq
```

答案では式だけで終わらず、符号規約、単位、換算した電圧側、問題が要求する電圧側、設備種別、容量制約、最終値が制約を満たすかまで確認する。
