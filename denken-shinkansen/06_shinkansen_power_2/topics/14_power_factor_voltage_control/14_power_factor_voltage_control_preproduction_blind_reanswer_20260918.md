## 1. 令和6年度 第二種一次「電力」問5

問題文から、無負荷・軽負荷時は線路静電容量による充電電流が支配的になり、受電端電圧が送電端より高くなるフェランチ効果が生じる。抑制には受電端の分路リアクトルを用いる。

候補:
- (1) `リ` 充電電流
- (2) `カ` よりも高く
- (3) `ヌ` フェランチ効果
- (4) `ハ` 図A
- (5) `ロ` 分路リアクトル

候補解: `(リ, カ, ヌ, ハ, ロ)`

## 2. 令和4年度 第二種一次「法規」問4

地中ケーブル拡大等で静電容量が増えると軽負荷時のフェランチ効果が顕著になり、分路リアクトルで無効電力を吸収して電圧を抑える。配電系統の並列コンデンサは力率改善により電圧降下と損失を抑える。必要容量は、有効電力一定なら改善前後の無効電力差

`Qc = P(tan φ1 - tan φ2)`

である。

候補:
- (1) `カ` 静電容量
- (2) `ヌ` フェランチ
- (3) `ヲ` 分路リアクトル
- (4) `リ` 電圧降下
- (5) `イ` `P(tan φ1 - tan φ2)`

候補解: `(カ, ヌ, ヲ, リ, イ)`

## 3. 令和5年度 第二種二次「電力・管理」問4

条件:
- 三相負荷有効電力 `P = 300 kW`
- 改善後力率 `cosφ = 0.9`、進み
- 線路: `R = 0.2×4 = 0.8 Ω/相`、`X = 0.6×4 = 2.4 Ω/相`
- 需要家端線間電圧 `Vr = 6600 V`

進み無効電力を負とすると、

`Q = -P tan(arccos 0.9) = -145.297 kvar`

三相線間電圧の近似式

`Vs ≒ Vr + (RP + XQ)/Vr`

より、

`Vs = 6600 + {0.8×300000 + 2.4×(-145296.6)}/6600`

`= 6583.53 V`

候補 (1): `6.58 kV`（約 `6580 V`）

分散型電源500 kW、力率100 %を追加すると、送電端から需要家側へ流れる有効電力を正とした線路有効電力は

`Pline = 300 - 500 = -200 kW`

既存の需要家無効電力は `-145.297 kvar`。リアクトル容量を `Q1 > 0` とすると、送受電端を同じ6600 Vに保つ条件は

`R Pline + X(Q + Q1) = 0`

したがって、

`0.8×(-200000) + 2.4×(-145296.6 + Q1) = 0`

`Q1 = 211963 var`

候補 (2): `212 kvar`

## 4. 令和2年度 第二種二次「電力・管理」問6

既設負荷:
- `P1 = 6000 kW`
- `cosθ1 = 0.8` 遅れ
- `Qload1 = 6000×tan(arccos 0.8) = 4500 kvar`
- 既設コンデンサ `Q1 = 2000 kvar`

増設負荷:
- `P2 = 4500 kW`
- `cosθ2 = 0.6` 遅れ
- `Qload2 = 4500×tan(arccos 0.6) = 6000 kvar`
- `θ2 = arccos 0.6 = 53.13°`

増設後の有効電力合計は `10500 kW`。増設用コンデンサ投入前の遅れ無効電力合計は

`Qbefore = 4500 + 6000 - 2000 = 8500 kvar`

変圧器容量 `PT = 12000 kVA` を超えない境界では、許される無効電力は

`Qlimit = sqrt(12000^2 - 10500^2) = 5809.48 kvar`

よって最小増設コンデンサ容量は

`Q2,min = 8500 - 5809.48 = 2690.52 kvar`

候補 (1a): 約 `2690 kvar`（丸め方により2691 kvar）

この境界で皮相電力は12000 kVAなので、

`cosθS = 10500/12000 = 0.875`

候補 (1b): `0.875`（遅れ）

候補 (2):
- 追加負荷の有効電力成分 `P2 = 4500 kW` は右向き
- 追加負荷の遅れ無効電力成分は `6000 kvar`
- 力率角 `θ2 = 53.13°`
- 増設コンデンサ `Q2` は遅れ無効電力を打ち消す向きに描く

総合力率を0.95遅れにする場合、許容される総合遅れ無効電力は

`Qtarget = 10500×tan(arccos 0.95) = 3451.18 kvar`

したがって、

`Q2 = 8500 - 3451.18 = 5048.82 kvar`

候補 (3): 約 `5050 kvar`

## 5. 平成23年度 第二種二次「電力・管理」問3

### (1) 変圧器リアクタンス

二次側66 kV換算で、

`Xt = 0.15×66^2/200 = 3.267 Ω`

候補 (1): `3.27 Ω`

線路リアクタンス4 Ωを加え、

`X = 3.267 + 4 = 7.267 Ω`

### (2) 一次母線電圧と負荷無効電力

受電端 `Vr=68 kV`、`P=93 MW`、`sinδ=0.15`。送電端電圧を二次側換算 `Vs'` とすると、抵抗を無視した三相系統で

`P = Vs' Vr sinδ / X`

より、

`Vs' = 93×10^6×7.267/(68×10^3×0.15) = 66.258 kV`

一次側へ戻すと、

`Vs = 66.258×154/66 = 154.60 kV`

候補 (2a): 約 `155 kV`

`cosδ = sqrt(1-0.15^2)` として、受電端負荷無効電力は

`Q = {Vs' Vr cosδ - Vr^2}/X`

`= -23.316 Mvar`

遅れを正とする指定なので負値は進みを意味する。

候補 (2b): `-23.3 Mvar`（進み）

### (3) 66 kVへ調整する調相設備

一次母線電圧を一定、負荷を定電力とする。新しい受電端電圧 `Vr2=66 kV` で

`sinδ2 = PX/(Vs' Vr2) = 0.154545`

このとき系統が受電端で要求する無効電力は

`Qnet = {Vs' Vr2 cosδ2 - Vr2^2}/X = -4.887 Mvar`

負荷自体は `-23.316 Mvar` のままなので、追加設備は

`Qdevice = Qnet - Qload = 18.429 Mvar`

の遅れ無効電力を吸収する必要がある。よって分路リアクトル。

候補 (3a): `分路リアクトル`

候補 (3b): 約 `18.4 Mvar`（設備容量表記では約 `18.4 MVA`）
