# 解説本文

このテーマでは、三種で用いる `P=ρgQHη` を出発点に、水量収支、水車の効率特性、調速機、負荷遮断、水撃作用までを一つの運用問題として扱う。一次試験では水車形式・効率特性・調速機・負荷遮断時の因果関係を選択肢から判定する力、二次試験では水量収支と出力を途中式付きで計算し、水撃の原因と対策設備を指定された形で記述する力が必要になる。

## 1. 水力発電の出力

水が持つ位置エネルギーを電力へ変換したときの基本式は

`P = ρgQHη`

である。

- `P`: 発電出力 `[W]`
- `ρ`: 水の密度 `[kg/m^3]`
- `g`: 重力加速度 `[m/s^2]`
- `Q`: 流量 `[m^3/s]`
- `H`: 有効落差 `[m]`
- `η`: 水車・発電機を含む問題文指定の効率

水について `ρ≈1000 kg/m^3`、`g≈9.8 m/s^2` とすれば、実務的な単位では

`P[kW] = 9.8 Q[m^3/s] H[m] η`

となる。

ここで使うのは総落差ではなく、取水口から水車までの損失水頭を差し引いた有効落差である。問題文が「水車効率」と「発電機効率」を別々に与える場合は `η=η_tη_g` とし、「水車・発電機合成効率」が与えられればその値を一つの `η` として使う。

逆算すると

`Q = P/(9.8Hη)`

`H = P/(9.8Qη)`

となる。`H` と `η` を一定とみなせる範囲では出力は流量に比例し、`Q` と `η` を一定とみなせる範囲では出力は有効落差に比例する。ただし実機の効率は負荷で変化するため、全運転範囲で完全な直線になるとは限らない。

### 基礎例題

有効落差 `70 m`、流量 `25 m^3/s`、水車・発電機合成効率 `0.88` の水力発電所の出力を求める。

水力発電の出力を直接求めるので

`P = 9.8QHη`

を使う。

`P = 9.8 × 25 × 70 × 0.88 = 15092 kW`

したがって

`P ≈ 15.1 MW`

である。

検算として、流量または落差を2倍にし、効率を同じと仮定すれば出力も2倍になる。単位を `W` と `kW` で混同しない。

## 2. 発電所運用と水量収支

調整池式発電所では、河川から常時流入する水をそのまま同じ流量で使うだけでなく、需要が小さい時間帯に調整池へ貯め、需要の大きい時間帯に放流して発電量を増やせる。

自然流量を `Q_n`、一日に移し替える調整池水量を `V`、ピーク時間を `T_p [h]`、オフピーク時間を `T_o=24-T_p [h]` とする。ピーク時に `V` を余分に使い、オフピーク時に同じ `V` を貯め直す条件なら

`Q_p = Q_n + V/(3600T_p)`

`Q_o = Q_n - V/(3600T_o)`

となる。時間を秒へ直すため `3600` を入れる。

各時間帯の有効落差と効率が与えられれば

`P_p = 9.8Q_pH_pη_p`

`P_o = 9.8Q_oH_oη_o`

で出力へ変換する。二次試験では、水量収支を先に解いてから出力式へ進むと途中式を追いやすい。

### 本試験標準例題

自然流量 `18 m^3/s`、調整池の有効利用水量 `216000 m^3`、ピーク時間6時間、有効落差 `55 m` とする。ピーク時合成効率を `0.86`、オフピーク時合成効率を `0.80` とする。ピーク時とオフピーク時の流量・出力を求める。

ピーク時は6時間なので

`Q_p = 18 + 216000/(3600×6) = 28.0 m^3/s`

オフピークは18時間なので

`Q_o = 18 - 216000/(3600×18) = 14.667 m^3/s`

よって

`P_p = 9.8×28.0×55×0.86 = 12979 kW ≈ 13.0 MW`

`P_o = 9.8×14.667×55×0.80 = 6324 kW ≈ 6.32 MW`

水量収支を確認すると

`(28.0-18)×6×3600 = 216000 m^3`

`(18-14.667)×18×3600 ≈ 216000 m^3`

となり、調整池から出した水量と貯め直した水量が一致する。

## 3. 水車種類と効率特性

水車は落差・流量・運転範囲に合わせて選ぶ。一次試験では「形式」「水の流れ」「出力調整方法」「部分負荷効率」を対応付けて覚える。

| 水車 | 分類・流れ | 主な出力調整 | 部分負荷で見る点 |
|---|---|---|---|
| ペルトン | 衝動水車。ノズルからの噴流をバケットへ当てる | ニードル等で噴流を調整。複数ノズルでは使用ノズル数も変える | ノズル数を切り替えて効率低下を抑えられる |
| フランシス | 反動水車。ランナ内を通って軸方向へ流出する | ガイドベーン開度で流量を調整 | 軽負荷では流れが設計点から外れ、効率が低下しやすい |
| カプラン | 反動水車。軸方向流 | ガイドベーンと可動ランナベーンを協調制御 | ランナベーン角を自動調整でき、部分負荷の効率低下が比較的小さい |

カプラン水車を円筒形の水路へ組み込む形式では、低い水車回転速度を発電機に適した速度へ合わせるため増速歯車を用いる構成がある。

河川流量は季節や時間で変わるので、設計点の最高効率だけを見て水車を決めるのではない。年間の流量変動と各負荷点の効率を合わせ、年間発電電力量を大きくする視点が必要である。

## 4. 比速度

比速度は、落差・出力・回転速度が異なる水車を相似則で比較する指標である。代表的な定義は

`n_s = n√P / H^(5/4)`

である。

- `n`: 回転速度 `[min^-1]`
- `P`: 定義に従う水車出力 `[kW]`
- `H`: 有効落差 `[m]`

問題では、出力を水車1台当たりとするか、ペルトン水車でノズル当たりとするか等の定義を問題文で確認する。

一般に高落差側ほど小さい比速度が適し、ペルトン水車は小さい側、フランシス水車は中間、カプラン水車は大きい側で用いられる。

R6一次問3で必要なのは、比速度が小さいフランシス水車ではランナが偏平になること、そのためクラウン側の円板摩擦損失の割合が増えて効率低下につながる、という対応である。

## 5. 調速機

水力発電機の調速機は、系統周波数・回転速度と出力指令を見ながら水車へ入る水量を調整する。電気式調速機では、選定過去問に対応する信号の流れを次のように整理できる。

```text
PMG等による周波数検出
        ↓
基準周波数・目標出力との比較
        ↓
周波数偏差・出力偏差
        ↓
PID演算
        ↓
アクチュエータ
        ↓
ガイドベーンサーボモータ
        ↓
ガイドベーン開度 → 流量 → 水車出力
        ↑
サーボ位置のリターン信号
```

比例要素 `P` は現在の偏差に応じて操作量を変え、積分要素 `I` は偏差が残り続けることを抑え、微分要素 `D` は偏差の変化を見て応答を整える。

一次試験では「目標出力」と「実出力との差である出力偏差」を混同しない。また、ガイドベーン開度はサーボモータからのリターン信号でフィードバックされる。

## 6. 負荷遮断と水撃作用

発電機の電気負荷が急に失われても、その瞬間には水車へ入る水のエネルギーは残っている。そのままでは機械入力が電気出力を上回って水車・発電機が加速するため、調速機はガイドベーンを閉じて流量を減らす。

しかし水圧管路を流れる大量の水には慣性がある。ガイドベーンを急に閉じて流れを急減速すると、流水の運動エネルギーの一部が圧力エネルギーへ変わり、ガイドベーン直前を中心に水圧が上昇し、その圧力変動が水圧管路・圧力トンネル側へ伝わる。これが水撃作用である。

ガイドベーン閉鎖を遅くすれば流量変化が緩やかになり、水圧上昇は小さくなる。一方、水車への機械入力が長く残るので、負荷遮断後の回転速度上昇は大きくなる。したがって

`閉鎖を速くする → 速度上昇を抑えやすいが水圧上昇が大きい`

`閉鎖を遅くする → 水圧上昇を抑えやすいが速度上昇が大きい`

というトレードオフを押さえる。

R8一次問5に現れるガイドベーン閉鎖時間の数値は、その設問で示された設計条件に対応する値であり、すべての水力発電所に共通する固定値として暗記しない。

## 7. 水撃対策と発電機連携

水撃対策では、設備名だけでなく「どこに設け、どう圧力変動を抑えるか」まで説明する。

### サージタンク

水圧管路と圧力トンネル・導水路の接続部付近に設け、自由水面を持つ水槽へ水を出入りさせる。急な流量変化をサージタンク側へ逃がし、水路内の圧力変動を緩和する。

### 制圧機

水車ケーシング付近または水圧管路末端に設け、ガイドベーンの急閉鎖に連動して弁を開く。水を一時的に放出して、水圧管路内の圧力上昇を抑える。

### `GD²` と無拘束速度

`GD²` は発電機回転体のはずみ車効果を表す量で、回転系の慣性と関係する。同じ機械入力と電気出力の不平衡なら、慣性が大きいほど角加速度は小さくなる。ただしR8一次問5の設計では、`GD²` を任意に増やすのではなく発電機固有の値として扱う点を区別する。

無拘束速度は、負荷がなく、水が供給された状態で水車が上昇し得る回転速度である。負荷遮断時の速度上昇を許容する設計では、水車・発電機の回転体が無拘束速度を考慮した機械強度を持つ必要がある。

水撃は水路側の圧力問題、速度上昇は水車・発電機回転体側の問題である。負荷遮断では両方が同時に生じるため、混同せず別々に対策を整理する。

### 複合・ひっかけ例題

負荷遮断時の水圧上昇を小さくして水圧鉄管の設計圧力を抑えるため、ガイドベーンの閉鎖を従来より遅くする設計を考える。この変更で生じる影響と、必要な水路側・回転体側の考慮事項を説明する。

1. 閉鎖を遅くすると流水の減速が緩やかになるため、水撃による最大水圧上昇は小さくなる。
2. 一方、水車への機械入力が残る時間が長くなり、負荷遮断後の回転速度上昇は大きくなる。
3. 水路側ではサージタンクや制圧機の位置と作用を踏まえて圧力変動を抑える。
4. 回転体側では発電機固有の `GD²` と無拘束速度を考慮し、許容する過速度に対する機械強度を確認する。

「水圧上昇を小さくすれば速度上昇も必ず小さくなる」と判断すると誤りである。閉鎖時間を介して両者は逆方向に動く。

## 8. 信濃川水系と新幹線への接続

JR東日本の一次資料では、信濃川発電所は千手発電所・小千谷発電所・小千谷第二発電所の3発電所からなり、発生した電力は首都圏の鉄道、上越線、新幹線などの列車運転・鉄道設備に用いられている。

またJR東日本は自営水力発電の総出力を `44.8万kW` と掲載している。これは鉄道用電力システム全体に関する実在値であり、「その全量を一つの新幹線列車だけへ自由に割り当てられる」という意味ではない。

2025年7月3日の水利権更新資料では、信濃川発電所の最大取水量は `316.96 m^3/s` とされている。この値も水利権上の最大取水量であり、常時流量や任意時刻の発電出力そのものではない。

したがって「新幹線を何本走らせられるか」は、実車の未確認値を置いて直接割り算せず、教材では次の関係として扱う。

新幹線へ割り当て可能な有効電力を `P_available`、同一運転条件で列車1本が必要とする有効電力を `P_train` とすれば

`N ≤ floor(P_available/P_train)`

である。

また、有効落差 `H`、総合効率 `η` を一定とみなし、列車 `N` 本分の電力を水力発電で賄うために必要な流量は

`Q_required = N P_train/(9.8Hη)`

となる。ここで `P_train` を `[kW]` とすれば `Q_required` は `[m^3/s]` になる。

この節で使用した値の区別は次のとおり。

- 実在値: JR東日本が掲載する自営水力発電総出力 `44.8万kW`
- 実在値: 2025年水利権更新資料の最大取水量 `316.96 m^3/s`
- 計算関係: `N` と `Q_required` の式
- 未設定: 列車1本の `P_train`。一次資料で条件を固定できていないため仮定値を置かない

## 9. 二種一次・二次の解法

### 一次試験の選択問題

1. 何を問う問題かを、水車形式・効率特性・調速機・負荷遮断のいずれかに分類する。
2. 主語を固定する。ペルトン・フランシス・カプランのどれか、目標値・偏差・サーボ位置のどれかを確認する。
3. 「原因 → 操作 → 結果」の順で因果関係をたどる。
4. 選択肢の一部だけが正しくても、主語や方向が逆なら除外する。

### 二次試験の計算問題

1. `V, Q_n, T, H, η` を問題文から抜き出す。
2. 時間を秒へ換算して一日の水量収支を書く。
3. `Q_p, Q_o` を先に求める。
4. 各時間帯について `P=9.8QHη` へ代入する。
5. `m^3/s`, `m`, `kW`, `MW` の単位を確認する。
6. 最後に、調整池から出した水量と貯めた水量が一致するか検算する。

### 二次試験の論説問題

1. 問われた個数・字数・項目数を先に確認する。
2. 原因説明は「負荷遮断 → ガイドベーン閉鎖 → 流水減速 → 圧力上昇 → 圧力変動の伝搬」の順で書く。
3. 対策設備は「設備名 → 設置場所 → 動作 → 効果」の順で書く。
4. 設備名だけ、または効果だけの記述で終わらせない。

## 3段階例題の品質確認

- 基礎例題: `P=9.8QHη` の式選択、単位、流量・落差・効率の意味を確認。
- 本試験標準例題: 調整池の一日水量収支からピーク・オフピーク流量を求め、出力へ接続。R4二次問1型の途中式を再利用できる構成。
