## 問5 本試験標準・一次型: 部分負荷効率

水車の部分負荷特性に関する記述として正しいものを選べ。

1. ペルトン水車は使用ノズル数を変えても部分負荷効率に影響しないため、ノズル切替は不要である。
2. フランシス水車は軽負荷でも常に設計点と同じ流れとなり、効率低下は生じない。
3. カプラン水車はガイドベーンと可動ランナベーンを協調させ、部分負荷での効率低下を抑えられる。
4. 年間発電電力量を最大化するには、最高効率点だけを見ればよく河川流量の変動は無視できる。
5. 円筒水車では低速の水車に合わせて発電機をさらに低速化する減速歯車を用いる。

## 問6 本試験標準・一次型: 比速度

比速度 `n_s = n√P/H^(5/4)` に関する記述として正しいものを選べ。

1. 同じ `n,P` なら有効落差 `H` が大きいほど比速度は大きくなる。
2. 一般にペルトン水車は比速度が大きい側、カプラン水車は小さい側で用いられる。
3. 比速度が小さいフランシス水車ではランナが偏平になり、円板摩擦損失の割合が増えやすい。
4. 比速度は効率そのものを表し、大きいほど必ず高効率である。
5. 比速度の計算では問題文にかかわらず必ず発電所全体出力を用いる。

## 問7 本試験標準・一次型: 電気式調速機

## 問8 本試験標準・一次型: PIDの役割

2. I要素は偏差が残り続けることを抑える働きを持つ。
3. D要素は目標出力そのものを記憶するだけである。
4. ガイドベーン位置はフィードバックしない。

## 問10 本試験標準・一次型: 水撃対策と回転体

# 解答・完全解説

## 問1

正答: 3

水力発電出力は

`P[kW] = 9.8QHη`

より、

`P = 9.8×24×80×0.90 = 16934.4 kW`

したがって `16.9 MW`。流量・落差・効率を掛ける前に、`Q[m^3/s]`, `H[m]` を確認する。

## 問2

正答: 3

必要流量なので式を `Q` について解く。

`Q = P/(9.8Hη)`

`= 12000/(9.8×65×0.88)`

`= 21.4 m^3/s`

`12.0 MW = 12000 kW` の換算を忘れない。

## 問3

正答: 2

ピーク時:

`Qp = 20 + 216000/(3600×6) = 30.0 m^3/s`

オフピーク時:

`Qo = 20 - 216000/(3600×18) = 16.667 m^3/s`

調整池から出す水量と貯める水量は同じである。

## 問4

正答: 3

カプラン水車は反動水車で、主として軸方向流を利用する。可動ランナベーンを持ち、ガイドベーンとの協調で流量変動時の効率低下を抑える。ペルトンは衝動水車、フランシスは反動水車である。

## 問5

正答: 3

カプラン水車はガイドベーンとランナベーン角を協調制御できるため、部分負荷効率を保ちやすい。ペルトンは使用ノズル数の切替が部分負荷効率維持に有効。フランシスは軽負荷で設計点から流れが外れ、効率が低下しやすい。年間発電電力量では河川流量の変動も考慮する。円筒水車では増速歯車を用いる構成がある。

## 問6

正答: 3

`n_s = n√P/H^(5/4)` なので、同じ `n,P` なら `H` が大きいほど `n_s` は小さくなる。一般にペルトンは小さい側、フランシスは中間、カプランは大きい側。比速度が小さいフランシス水車ではランナが偏平になり、円板摩擦損失の割合が増えやすい。出力の定義は問題文に従う。

## 問7

正答: 2

基本の流れは

`周波数検出 → 基準値・目標値との比較 → 偏差 → PID → アクチュエータ/サーボ → ガイドベーン`

である。ガイドベーン位置はリターン信号としてフィードバックされる。

## 問8

正答: 2

P要素は現在の偏差、I要素は偏差の累積、D要素は偏差の変化に応じて作用する。I要素は定常的に残る偏差を抑える役割を持つ。

## 問9

正答: 3

ガイドベーン閉鎖を遅くすると流量変化が緩やかになり、水撃による水圧上昇は小さくなる。一方、水車への機械入力が長く残るため、負荷を失った回転体の速度上昇は大きくなる。

## 問10

正答: 2

制圧機は水車ケーシング付近または水圧管路末端に設け、急閉鎖時に水を一時放出して圧力上昇を抑える。サージタンクは水路側の圧力変動を緩和する設備で、回転速度を直接制御しない。`GD²` が大きいほど同じ不平衡に対する角加速度は小さくなる。無拘束速度は無負荷で水が供給されたときに上昇し得る速度である。

## 問11

(1) 流量

ピーク時:

`Qp = 22 + 259200/(3600×8)`

`= 22 + 9 = 31.0 m^3/s`

オフピーク時:

`Qo = 22 - 259200/(3600×16)`

`= 22 - 4.5 = 17.5 m^3/s`

(2) 出力

ピーク時:

`Pp = 9.8×31.0×60×0.90 = 16405.2 kW ≈ 16.4 MW`

オフピーク時:

`Po = 9.8×17.5×58×0.85 = 8454.95 kW ≈ 8.45 MW`

(3) 水量収支

ピーク時の調整池放出量:

`(31-22)×8×3600 = 259200 m^3`

オフピーク時の貯留量:

`(22-17.5)×16×3600 = 259200 m^3`

一致するため、一日の終わりに調整池水量は元へ戻る。

## 問12

(1) 一日水量収支を立てる。

自然流入量:

`16×24×3600`

発電使用水量:

`28×5×3600 + Qo×19×3600`

両者を等置し、`3600` を消すと

`16×24 = 28×5 + 19Qo`

`Qo = (384-140)/19 = 12.842 m^3/s`

したがって `Qo ≈ 12.84 m^3/s`。

(2) ピーク時:

`Pp = 9.8×28×50×0.88 = 12073.6 kW ≈ 12.1 MW`

オフピーク時:

`Po = 9.8×12.842×50×0.82 ≈ 5160 kW ≈ 5.16 MW`

先に水量収支を確定し、その後に各時間帯の `H,η` を用いて出力へ変換する。

## 問13

解答例:

負荷遮断によって発電機の電気出力が急減すると、水車への機械入力を下げるため調速機がガイドベーンを閉じる。水圧管路を流れる水には慣性があるため、急な流量減少で流水の運動エネルギーの一部が圧力エネルギーへ変換され、ガイドベーン直前を中心に圧力上昇が生じる。この圧力変動が水圧管路や圧力トンネル側へ伝搬する現象が水撃作用である。

採点要点:
- 負荷遮断とガイドベーン閉鎖の因果関係
- 流水の運動エネルギーから圧力エネルギーへの変換
- 圧力上昇
- 管路側への圧力変動の伝搬

## 問14

(1) サージタンク

水圧管路と圧力トンネル・導水路の接続部付近に設ける。自由水面を持つ水槽へ水を出入りさせ、急な流量変化の一部をサージタンク側へ逃がすことで水路内の圧力変動を緩和する。

(2) 制圧機

水車ケーシング付近または水圧管路末端に設ける。ガイドベーンの急閉鎖に連動して弁を開き、水を一時的に放出することで水圧管路内の圧力上昇を抑える。

設備名だけでなく「設置位置 → 動作 → 効果」の順で書く。

## 問15

(1) ガイドベーン閉鎖時間を長くすると、流量変化が緩やかになるため水撃による最大水圧上昇は小さくなる。一方、負荷遮断後も水車への機械入力が長く残るので回転速度上昇は大きくなる。

(2) `GD²` は回転系のはずみ車効果を表し、慣性と関係する。同じ機械入力と電気出力の不平衡で比較すると、慣性が大きいほど角加速度は小さくなり、速度上昇は緩やかになる。ただし設計問題では発電機固有の値として扱う条件を確認する。

(3) 負荷がなくても水が供給され続ければ水車は加速し得る。したがって負荷遮断後に許容する過速度に対し、水車・発電機の回転体が無拘束速度を考慮した機械強度を持つ必要がある。
