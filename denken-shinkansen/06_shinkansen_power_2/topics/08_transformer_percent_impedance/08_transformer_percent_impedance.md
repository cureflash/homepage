## 過去問から逆算した教材必須事項

### 用語・定義
- 基準容量 `S_B`
- 基準電圧 `V_B`
- 基準電流 `I_B`
- 基準インピーダンス `Z_B`
- 単位法（p.u.）
- 百分率インピーダンス `%Z`
- 自己容量基準
- 三相短絡電流
- 短絡容量
- 変圧器並列運転
- 循環電流
- 負荷分担

### 公式・成立条件
- `I_B = S_B / (√3 V_B)`
- `Z_B = V_B^2 / S_B`
- `Z_pu = Z[Ω] / Z_B = S_B Z[Ω] / V_B^2`
- `%Z = 100 Z_pu`
- 同一基準電圧での基準容量変更: `Z_pu,new = Z_pu,old × S_B,new / S_B,old`
- 一般の基準変更: `Z_pu,new = Z_pu,old × (S_B,new/S_B,old) × (V_B,old/V_B,new)^2`
- 変圧器をまたぐ基準電圧は定格変圧比に対応させる
- `I_s = I_B / Z_pu = 100 I_B / %Z`
- `S_s = S_B / Z_pu = 100 S_B / %Z`
- インピーダンス直列・並列合成
- 複素電力 `S=P+jQ` と電流・電圧の関係を使った電圧降下計算
- 並列変圧器の負荷分担は、共通基準にそろえた等価インピーダンスに逆比例する
- 並列運転では変圧比・位相関係をそろえ、二次無負荷電圧差を小さくして循環電流を抑える
- 二次無負荷電圧差がある場合の基本形: `I_c = (E_A-E_B)/(Z_A+Z_B)`

### 解法アルゴリズム
1. 基準容量と各電圧階級の基準電圧を決める。
2. `I_B` と `Z_B` を求める。
3. Ω、p.u.、％Zを一つの基準へ統一する。
4. 変圧器の自己容量基準％Zは基準容量を換算する。
5. 変圧器をまたぐときは定格変圧比に対応する基準電圧へ切り替える。
6. 電源側インピーダンスを直列・並列合成する。
7. 短絡問題なら `I_s` または `S_s` を求める。
8. 電圧降下問題なら複素電力から電流を求め、インピーダンス降下をフェーザで加える。
9. 並列運転問題なら変圧比・位相・％Zを確認し、負荷分担と循環電流を判定する。
10. 単位、基準容量、基準電圧を最後に再確認する。

### 頻出ミス
- 自己容量基準％Zを共通基準へ換算せず加算する
- 基準容量変更の比を逆にする
- 基準電圧変更時の二乗比を落とす
- 三相の基準電流で `√3` を落とす
- `%` とp.u.を100倍／100分の1で取り違える
- 並列変圧器の負荷分担を％Zだけで比較し、容量基準をそろえない
- 変圧比差・位相差による循環電流条件を無視する

# 解説本文

## 1. このテーマで電験は何を問うか

電験二種では、変圧器や送電系統のインピーダンスがΩ、p.u.、％Z、異なる容量基準で混在して与えられる。受験者は、それらを同じ基準へそろえ、等価インピーダンスを作り、三相短絡電流・短絡容量・電圧降下・並列変圧器の負荷分担を計算できなければならない。

このTopicで到達する解法は次の4本である。

1. `S_B, V_B` を決め、`I_B, Z_B` を作る。
2. Ω、p.u.、％Zを共通基準へ換算して直列・並列合成する。
3. 合成インピーダンスから三相短絡電流・短絡容量・電圧降下を求める。
4. 並列変圧器では変圧比・位相・％Zを確認し、負荷分担と循環電流を判定する。

暗記すべき中心式は少ない。難所は「どの基準で書かれたインピーダンスか」を見失わないことである。

## 2. 基準量と単位法

三相系統で基準容量 `S_B`、線間基準電圧 `V_B` を決めると、基準電流と基準インピーダンスは

`I_B = S_B/(√3 V_B)`

`Z_B = V_B^2/S_B`

で決まる。

実インピーダンス `Z[Ω]` を単位法へ変えると

`Z_pu = Z/Z_B = S_B Z/V_B^2`

百分率表示は

`%Z = 100 Z_pu`

である。`0.08 p.u.` と `8 %` は同じインピーダンスを表す。

単位法を使う理由は、電圧階級が変わる変圧器を含む系統でも、基準を正しく選べば各機器のインピーダンスを同じ尺度で加減できるからである。

## 3. ％インピーダンスの意味

変圧器の％インピーダンスは、その変圧器の定格容量・定格電圧を基準にした等価インピーダンスの百分率表示である。例えば自己容量基準 `10 %` は `0.10 p.u.` を意味する。

重要なのは、数字だけを見て足さないことである。異なる容量の変圧器に同じ `10 %` と書かれていても、Ω値は同じとは限らない。直列・並列合成する前に必ず共通基準へ換算する。

三相短絡で、短絡点から見た合成インピーダンスが `Z_th,pu`、短絡前電圧を `1 p.u.` とみなせる場合、短絡電流は

`I_s,pu = 1/Z_th,pu`

`I_s = I_B/|Z_th,pu|`

となる。合成インピーダンスが純リアクタンスとして扱える問題では、その絶対値をそのまま用いる。

短絡容量は

`S_s = S_B/|Z_th,pu| = 100 S_B/|%Z_th|`

である。

## 4. 基準容量・基準電圧を変更する

元の基準を `S_B,old, V_B,old`、新しい基準を `S_B,new, V_B,new` とすると

`Z_pu,new = Z_pu,old × (S_B,new/S_B,old) × (V_B,old/V_B,new)^2`

となる。

同一電圧基準なら

`Z_pu,new = Z_pu,old × S_B,new/S_B,old`

だけでよい。

変圧器をまたぐときは、各側の基準電圧を定格変圧比に対応させる。これを守れば、変圧器の両側で単位法表示を一貫して扱える。

## 5. インピーダンスを合成して三相短絡を解く

手順は固定できる。

1. 共通基準容量を決める。
2. 各電圧階級の基準電圧を決める。
3. 全インピーダンスを同じp.u.または％Z基準へ換算する。
4. 直列は加算、並列は逆数和で合成する。
5. 短絡点から電源側を見た `Z_th` を求める。
6. `I_s=I_B/|Z_th,pu|` または `S_s=S_B/|Z_th,pu|` を使う。

並列合成は

`Z_eq = Z_1 Z_2/(Z_1+Z_2)`

であり、三枝以上なら

`1/Z_eq = 1/Z_1 + 1/Z_2 + ...`

を使う。

短絡電流上限から未知の％インピーダンスを逆算する問題では、先に許容される合成 `Z_th` を求め、その条件を満たすよう未知量を不等式で解く。

## 6. 電圧降下をフェーザで解く

電圧降下では、電圧の大きさだけを引き算しない。受電端電圧を `V_r`、受電電流を `I`、直列インピーダンスを `Z` とすれば

`V_s = V_r + ZI`

である。

複素電力が `S=P+jQ` のとき、単位法では

`S = V I*`

なので

`I = (S/V)*`

と求められる。

リアクタンス `jX` があるときは `jXI` を複素数として加え、最後に `|V_s|` を求める。この方法なら近似式を使わない二種記述問題へ接続できる。

## 7. 変圧器の並列運転・負荷分担・循環電流

並列運転では、二次側を同じ母線へ接続するため、少なくとも二次無負荷電圧の大きさと位相関係が一致している必要がある。変圧比が違えば無負荷電圧差が生じ、位相が違えばフェーザ差が生じる。どちらも負荷とは別の循環電流を生む。

二台A、Bの二次無負荷起電力を `E_A, E_B`、等価インピーダンスを `Z_A, Z_B` とすると、基本形は

`I_c = (E_A-E_B)/(Z_A+Z_B)`

である。

無負荷電圧が等しく循環電流を無視できるとき、負荷電流の分担はインピーダンスに逆比例する。

`I_A/I_B = Z_B/Z_A`

同じ二次定格電圧の二台が定格容量に比例して負担するには

`I_A/I_B = S_A/S_B`

となる必要がある。自己容量基準の％インピーダンスが等しく、インピーダンス角も整合していれば、この容量比例分担になる。

したがって一次試験の並列運転問題では、「変圧比・位相関係・％インピーダンス」の三点を別々に確認する。

## 8. 解法アルゴリズム

二種の記述問題では次の順を崩さない。

1. 与えられた容量、電圧、Ω、％Z、p.u.を一覧化する。
2. 共通基準容量 `S_B` を決める。
3. 各電圧階級の `V_B` を決める。
4. `I_B, Z_B` を計算する。
5. 各インピーダンスを共通p.u./％Zへ換算する。
6. 直列・並列合成する。
7. 短絡なら `I_s, S_s`、電圧降下なら `V_s=V_r+ZI` を適用する。
8. 並列運転なら変圧比・位相・％Zを確認する。
9. 必要なら循環電流または負荷分担を計算する。
10. kV、kA、MV·A、Ω、p.u.、％を最後に検算する。

途中式では「どの基準へ換算したか」を数値の横に書く。これだけで容量基準の取り違えを大きく減らせる。

## 10. 新幹線への接続

新幹線変電所を電力系統側から見ると、変圧器は上位系統と負荷側を結ぶインピーダンス要素でもある。電験では、その実設備の固有値を暗記するのではなく、与えられた容量・電圧・％インピーダンスを共通基準へ直し、短絡電流や電圧降下を計算する能力を問う。

複数変圧器を並列に扱う場合も同じである。自己容量基準の％Zをそのまま比較せず、必要なら共通基準へ直し、変圧比と位相関係も確認してから負荷分担を判断する。

このTopicでは実在変電所の未確認容量・％Z・短絡容量を真値として置かない。新幹線は系統モデルの位置関係を理解するために使い、計算は試験問題で与えられる値または明示した教材上の仮定値で行う。

## 11. 頻出ミス

- `10 % = 0.10 p.u.` を `0.10 %` と誤る。
- 異なる自己容量基準の％Zをそのまま足す。
- 基準容量変更で比を逆にする。
- 基準電圧変更の二乗比を落とす。
- 三相基準電流の `√3` を落とす。
- 短絡電流を求めるとき、短絡点までの全電源経路を合成し忘れる。
- 電圧降下で複素数を使わず電圧の大きさだけを算術加減する。
- 並列運転で％Zだけを見て、変圧比・位相条件を見ない。
- 循環電流と負荷電流を同じものとして扱う。

## 12. 公式・解法まとめ

- `I_B = S_B/(√3 V_B)`
- `Z_B = V_B^2/S_B`
- `Z_pu = Z/Z_B = S_B Z/V_B^2`
- `%Z = 100 Z_pu`
- `Z_pu,new = Z_pu,old × (S_B,new/S_B,old) × (V_B,old/V_B,new)^2`
- 同一電圧基準: `Z_pu,new = Z_pu,old × S_B,new/S_B,old`
- 三相短絡電流: `I_s = I_B/|Z_th,pu|`
- 短絡容量: `S_s = S_B/|Z_th,pu|`
- 電圧降下: `V_s = V_r + ZI`
- 複素電力: `I = (S/V)*`
- 循環電流: `I_c = (E_A-E_B)/(Z_A+Z_B)`
- 負荷分担: `I_A/I_B = Z_B/Z_A`

# 3段階例題

## 例題1 基礎 — 基準容量変更と三相短絡電流

### 問題

100 MV·A、66 kVを共通基準とする。電源リアクタンスはこの基準で `5 %`。その先に50 MV·A自己容量基準で％インピーダンス `10 %` の変圧器が直列に接続されている。変圧器二次側で三相短絡が起きたとき、短絡電流と短絡容量を求める。短絡前電圧は `1 p.u.` とする。

### 解法

変圧器は50 MV·A基準なので、まず100 MV·A基準へ直す。

`%Z_T = 10×100/50 = 20 %`

電源と直列だから

`%Z_th = 5+20 = 25 % = 0.25 p.u.`

66 kV側基準電流は

`I_B = 100×10^6/(√3×66×10^3) = 0.8748 kA`

したがって

`I_s = 0.8748/0.25 = 3.50 kA`

短絡容量は

`S_s = 100/0.25 = 400 MV·A`

### 答

- 三相短絡電流: `3.50 kA`
- 短絡容量: `400 MV·A`

### ひっかけ

`5 %+10 %=15 %` としてはいけない。10 %は50 MV·A自己容量基準なので、共通基準へ換算してから加算する。

## 例題2 本試験標準 — 複素電力から送電端電圧を求める

### 問題

100 MV·A、154 kV基準で、受電端電圧を `V_r=1∠0 p.u.`、受電電力を `S_r=0.8+j0.3 p.u.`、受送電端間のリアクタンスを `j0.08 p.u.` とする。送電端電圧の大きさを求める。

### 解法

まず電流を複素電力から求める。

`I = (S_r/V_r)*`

`= (0.8+j0.3)*`

`= 0.8-j0.3 p.u.`

電圧降下は

`jXI = j0.08(0.8-j0.3)`

`= 0.024+j0.064 p.u.`

したがって

`V_s = V_r+jXI`

`= 1.024+j0.064 p.u.`

大きさは

`|V_s| = √(1.024^2+0.064^2)`

`= 1.0260 p.u.`

実電圧は

`154×1.0260 = 158.0 kV`

### 答

送電端電圧の大きさは `約158 kV`。

### 本試験での意味

R7二次問3型では、`P+jQ` から電流フェーザを作り、`ZI` を複素数で加える。電圧の大きさだけを算術加算しない。

## 例題3 複合・ひっかけ — 並列変圧器の負荷分担と循環電流

### 問題

二台の変圧器A、Bを6.6 kV側で並列運転する。定格容量はAが40 MV·A、Bが60 MV·Aで、自己容量基準の％インピーダンスはいずれも `8 %` とする。位相関係は一致している。

(1) 無負荷二次電圧が等しいとき、合計80 MV·Aの負荷をどのように分担するか。

(2) 共通基準を100 MV·A、6.6 kVとし、AとBの無負荷二次電圧に `0.01 p.u.` の差が生じたとする。インピーダンスは純リアクタンスとみなし、循環電流の大きさを求める。

### 解法 (1)

100 MV·A基準へ換算すると

`Z_A = 0.08×100/40 = 0.20 p.u.`

`Z_B = 0.08×100/60 = 0.1333 p.u.`

負荷電流はインピーダンスに逆比例するので

`I_A/I_B = Z_B/Z_A = 0.1333/0.20 = 2/3`

これは定格容量比 `40/60=2/3` と一致する。したがって80 MV·Aの負荷は容量比で分担し

`S_A = 80×40/(40+60) = 32 MV·A`

`S_B = 80×60/(40+60) = 48 MV·A`

となる。

### 解法 (2)

循環電流は

`I_c = ΔE/(Z_A+Z_B)`

より

`|I_c| = 0.01/(0.20+0.1333) = 0.0300 p.u.`

100 MV·A、6.6 kV基準の基準電流は

`I_B = 100×10^6/(√3×6.6×10^3) = 8.748 kA`

したがって

`|I_c| = 0.0300×8.748 = 0.262 kA`

### 答

- 負荷分担: A `32 MV·A`、B `48 MV·A`
- 循環電流: `約0.262 kA`

### ひっかけ

二台の％インピーダンスが同じでも、共通容量基準に直したp.u.インピーダンスは同じ値にならない。自己容量基準の％Zが等しいからこそ、同一二次電圧では定格容量比に応じた負荷分担になる。また、負荷分担条件が良くても無負荷電圧差があれば循環電流は別に流れる。
