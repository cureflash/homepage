## 過去問から逆算した教材必須事項

### 用語・定義
- 基準容量 `S_B`
- 基準電圧 `V_B`
- 基準電流 `I_B`
- 基準インピーダンス `Z_B`
- 単位法（p.u.）
- 百分率インピーダンス `%Z`
- 自己容量基準
- 三相短絡電流
- 短絡容量
- 変圧器並列運転
- 循環電流
- 負荷分担

### 公式・成立条件
- `I_B = S_B / (√3 V_B)`
- `Z_B = V_B^2 / S_B`
- `Z_pu = Z[Ω] / Z_B = S_B Z[Ω] / V_B^2`
- `%Z = 100 Z_pu`
- 同一基準電圧での基準容量変更: `Z_pu,new = Z_pu,old × S_B,new / S_B,old`
- 一般の基準変更: `Z_pu,new = Z_pu,old × (S_B,new/S_B,old) × (V_B,old/V_B,new)^2`
- 変圧器をまたぐ基準電圧は定格変圧比に対応させる
- `I_s = I_B / Z_pu = 100 I_B / %Z`
- `S_s = S_B / Z_pu = 100 S_B / %Z`
- インピーダンス直列・並列合成
- 複素電力 `S=P+jQ` と電流・電圧の関係を使った電圧降下計算
- 並列変圧器の負荷分担は、共通基準にそろえた等価インピーダンスに逆比例する
- 並列運転では変圧比・位相関係をそろえ、二次無負荷電圧差を小さくして循環電流を抑える
- 二次無負荷電圧差がある場合の基本形: `I_c = (E_A-E_B)/(Z_A+Z_B)`

### 解法アルゴリズム
1. 基準容量と各電圧階級の基準電圧を決める。
2. `I_B` と `Z_B` を求める。
3. Ω、p.u.、％Zを一つの基準へ統一する。
4. 変圧器の自己容量基準％Zは基準容量を換算する。
5. 変圧器をまたぐときは定格変圧比に対応する基準電圧へ切り替える。
6. 電源側インピーダンスを直列・並列合成する。
7. 短絡問題なら `I_s` または `S_s` を求める。
8. 電圧降下問題なら複素電力から電流を求め、インピーダンス降下をフェーザで加える。
9. 並列運転問題なら変圧比・位相・％Zを確認し、負荷分担と循環電流を判定する。
10. 単位、基準容量、基準電圧を最後に再確認する。

### 頻出ミス
- 自己容量基準％Zを共通基準へ換算せず加算する
- 基準容量変更の比を逆にする
- 基準電圧変更時の二乗比を落とす
- 三相の基準電流で `√3` を落とす
- `%` とp.u.を100倍／100分の1で取り違える
- 並列変圧器の負荷分担を％Zだけで比較し、容量基準をそろえない
- 変圧比差・位相差による循環電流条件を無視する

### 1. 令和7年度 第二種二次試験 電力・管理 問3 — PASS

#### (1) 送電端電圧

100 MV·A、154 kVを基準とする。受電端を `V_r=1∠0 p.u.`、受電電力を `S_r=1+j0.2 p.u.` とする。

40 kmの送電線リアクタンスは、問題文で与えられた `0.16 %/km` から

`X = 0.16×40 = 6.4 % = 0.064 p.u.`

電流は

`I = (S_r/V_r)* = 1-j0.2 p.u.`

したがって、送電端電圧は

`V_s = V_r + jXI`

`= 1 + j0.064(1-j0.2)`

`= 1.0128 + j0.064 p.u.`

`|V_s| = 1.01482 p.u.`

よって

`154×1.01482 = 156.28 kV → 156 kV`

#### (2) 短絡容量

100 MV·A基準へ換算する。

- 電源A側リアクタンス: `0.3 % × 100/10 = 3.0 %`
- 送電線: `6.4 %`
- 変圧器B1: `16 %`
- 変圧器B2: `16 %`
- 変圧器B3: `18 % × 100/200 = 9.0 %`

三台並列の合成は

`X_B = 1/(1/16 + 1/16 + 1/9) = 4.235 %`

左側経路は

`X_L = 3.0 + 6.4 + 4.235 = 13.635 %`

右側電源のリアクタンスは

`X_R = 2.0 % × 100/10 = 20.0 %`

両経路の並列合成は

`X_eq = 13.635×20/(13.635+20) = 8.108 % = 0.08108 p.u.`

したがって短絡容量は

`S_s = 100/0.08108 = 1.233×10^3 MV·A`

`→ 1.23×10^3 MV·A`

公式標準解答の `156 kV`、`1.23×10^3 MV·A` と一致。`2 / 2答案要素 PASS`。送電線リアクタンスは与条件としてのみ使用し、線路定数の導出へは広げていない。

### 2. 令和3年度 第二種二次試験 電力・管理 問3 — PASS

#### (1)a 基準電流

`I_B = 100×10^6/(√3×154×10^3)`

`= 0.3749 kA → 0.375 kA`

#### (1)b 基準インピーダンス

`Z_B = 154^2/100 = 237.16 Ω → 237 Ω`

#### (2)a 送電線インピーダンス

20 km、`j0.400 Ω/km` なので

`Z = j8.00 Ω`

`Z_pu = j8.00/237.16 = j0.0337 p.u.`

#### (2)b 変圧器インピーダンス

150 MV·A自己容量基準10 %を100 MV·A基準へ換算する。

`Z_pu = j0.10×100/150 = j0.0667 p.u.`

#### (2)c 短絡電流上限のp.u.値

66 kV側の基準電流は

`I_B = 100×10^6/(√3×66×10^3) = 0.8748 kA`

したがって

`25/0.8748 = 28.6 p.u.`

#### (3) 発電機容量上限

二回線送電線の並列合成は

`j0.0337/2 = j0.0169 p.u.`

無限大母線側経路は

`X = 0.0169 + 0.0667 = 0.0835 p.u.`

短絡電流寄与は

`1/0.0835 = 11.97 p.u.`

発電機側は自己容量基準30 %なので、100 MV·A基準での短絡電流寄与は、発電機容量を `S_G [MV·A]` とすると `S_G/30 p.u.` である。

`11.97 + S_G/30 = 28.6`

より

`S_G = 498 MV·A`

公式標準解答の `0.375 kA`、`237 Ω`、`j0.0337 p.u.`、`j0.0667 p.u.`、`28.6 p.u.`、`498 MV·A` と全件一致。`6 / 6答案要素 PASS`。

### 4. 平成28年度 第二種二次試験 電力・管理 問6 — PASS

#### (1) 66 kV側合成インピーダンス

100 MV·A、66 kV基準で `j2.5 % + j3.5 % = j6.0 %`。
