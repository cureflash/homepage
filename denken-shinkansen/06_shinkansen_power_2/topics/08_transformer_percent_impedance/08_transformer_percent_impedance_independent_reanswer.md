### 1. R7 二次 電力・管理 問3 — PASS

完成教材の§2〜§8から再構成した。

#### (1) 送電端電圧

100 MV·A、154 kV基準で、40 kmの送電線リアクタンスは

`0.16 %/km × 40 km = 6.4 % = 0.064 p.u.`

受電端を `V_r=1∠0 p.u.`、受電電力を `S_r=1+j0.2 p.u.` とすると

`I=(S_r/V_r)*=1-j0.2 p.u.`

したがって

`V_s = V_r + j0.064 I`

`= 1 + j0.064(1-j0.2)`

`= 1.0128+j0.064 p.u.`

`|V_s| = 1.01482 p.u.`

`154×1.01482 = 156.28 kV`

よって `156 kV`。

#### (2) 短絡容量

100 MV·A共通基準へそろえる。

- 154 kV側電源: `0.3 % × 100/10 = 3.0 %`
- 送電線: `6.4 %`
- 変圧器B1: `16 %`
- 変圧器B2: `16 %`
- 変圧器B3: `18 % × 100/200 = 9.0 %`

三台変圧器の並列合成は

`1/%X_T = 1/16 + 1/16 + 1/9`

より

`%X_T = 4.2353 %`

154 kV側経路は

`3.0+6.4+4.2353 = 13.6353 %`

77 kV側電源は

`2.0 % × 100/10 = 20.0 %`

両電源経路の並列合成は

`%X_eq = 13.6353×20/(13.6353+20) = 8.1077 %`

短絡容量は

`S_s = 100×100/8.1077 = 1233.4 MV·A`

よって標準解答の丸めで `1 230 MV·A`。

再解答:
- (1) `156 kV`
- (2) `1 230 MV·A`

公式標準解答と一致。`2 / 2答案要素 PASS`。

### 2. R3 二次 電力・管理 問3 — PASS

完成教材の§2〜§5、§8から再構成した。

100 MV·A、154 kV基準で

`I_B = 100×10^6/(√3×154×10^3) = 0.3749 kA`

`Z_B = 154^2/100 = 237.16 Ω`

よって

- (1)a 基準電流: `0.375 kA`
- (1)b 基準インピーダンス: `237 Ω`

送電線1回線のリアクタンスは

`j0.400×20 = j8.0 Ω`

したがって

`j8.0/237.16 = j0.0337 p.u.`

変圧器は150 MV·A自己容量基準10 %なので

`0.10×100/150 = 0.0667 p.u.`

66 kV側基準電流は

`100×10^6/(√3×66×10^3) = 0.8748 kA`

25 kAをp.u.化すると

`25/0.8748 = 28.6 p.u.`

よって

- (2)a `j0.0337 p.u.`
- (2)b `j0.0667 p.u.`
- (2)c `28.6 p.u.`

二回線並列送電線と変圧器の固定側インピーダンスは

`0.0337/2 + 0.0667 = 0.08353 p.u.`

短絡電流25 kA以下に必要な全合成インピーダンスは

`Z_req = 1/28.6 = 0.03499 p.u.`

発電機側枝を `Z_g` とし

`0.08353 Z_g/(0.08353+Z_g)=0.03499`

を解くと

`Z_g = 0.06021 p.u.`

発電機リアクタンス30 %を100 MV·A基準へ換算すると

`0.30×100/S_G = 0.06021`

より

`S_G = 498.2 MV·A`

よって `498 MV·A`。

再解答:
- (1)a `0.375 kA`
- (1)b `237 Ω`
- (2)a `j0.0337 p.u.`
- (2)b `j0.0667 p.u.`
- (2)c `28.6 p.u.`
- (3) `498 MV·A`

公式標準解答と一致。`6 / 6答案要素 PASS`。

### 3. H30 一次 電力 問6(B) — PASS

完成教材の§3、§7から再構成した。

並列変圧器が容量に比例して負荷を分担するには、自己容量基準の短絡インピーダンスをそろえる必要がある。また、変圧比差は二次無負荷電圧差を生み、循環電流を流す。結線による位相差も同様に循環電流の原因になる。

再解答:
- (1) 容量 → `ト`
- (2) 循環電流 → `チ`
- (3) 短絡インピーダンス → `イ`
- (4) 変圧比 → `ヘ`
- (5) 位相 → `カ`

公式解答 `ト・チ・イ・ヘ・カ` と一致。`5 / 5空欄 PASS`。

### 4. H28 二次 電力・管理 問6 — PASS

完成教材の§2〜§5、§8から再構成した。

#### (1) CB3から電源側を見たインピーダンス

100 MV·A、66 kV基準で

`Z_B = 66^2/100 = 43.56 Ω`

電源側リアクタンスは

`(2.5+3.5)% = 6.0% = 0.06 p.u.`

したがって

`Z = 0.06×43.56 = 2.6136 Ω`

よって `2.61 Ω`。

#### (2) CB3の三相短絡電流

66 kV側基準電流は

`I_B = 100×10^6/(√3×66×10^3) = 0.8748 kA`

したがって

`I_s = 0.8748/0.06 = 14.58 kA`

よって `14.6 kA`。

#### (3) CB4の三相短絡電流

10 MV·A基準へそろえると

- 電源側: `0.25 %+0.35 % = 0.60 %`
- 20 MV·A変圧器8.8 %: `8.8×10/20 = 4.4 %`
- 与えられた6.6 kV側インピーダンス: `5+j7 %`

合成は

`5+j(0.6+4.4+7) = 5+j12 %`

大きさは `13 % = 0.13 p.u.`。

10 MV·A、6.6 kV基準電流は

`10×10^6/(√3×6.6×10^3) = 0.8748 kA`

したがって

`I_s = 0.8748/0.13 = 6.73 kA`

#### (4) 変圧器の必要％インピーダンス

CB3で電源側から流入する短絡電流は `14.58 kA`。

発電機側枝の100 MV·A基準リアクタンスを、発電機12 %と変圧器未知 `x %` の直列として

`(12+x)%`

とする。66 kV、100 MV·A基準では発電機側短絡電流は

`87.48/(12+x) kA`

CB3の遮断電流20 kA以下より

`14.58 + 87.48/(12+x) <= 20`

これを解くと

`x >= 4.14 %`

よって必要最小値は `4.14 %`。

再解答:
- (1) `2.61 Ω`
- (2) `14.6 kA`
- (3) `6.73 kA`
- (4) `4.14 %`

公式標準解答と一致。`4 / 4答案要素 PASS`。
