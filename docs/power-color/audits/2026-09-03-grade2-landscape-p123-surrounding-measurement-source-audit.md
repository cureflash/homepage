# Grade 2 Landscape p.123 `色を測ることによる周辺環境の把握` — source audit

Checked: 2026-09-03

## Result

Source-resolved for a narrow deterministic nonvisual measurement/representation boundary.

## Primary authority

The current Color Certification Association Grade 2 table of contents (`https://www.aft.or.jp/images/text_of-2st-grade_mokuji.pdf`) places `色を測ることによる周辺環境の把握` on p.123 immediately after `住宅の色彩設計プロセス`, followed by `配色計画` p.124 and `色彩管理` p.125. This confirms current Grade 2 scope/order, but the public table of contents does not expose the full official-text measurement procedure.

## Auditable corroboration

### Japan Paint Manufacturers Association

Current 2025 CCS practical training (`https://www.toryo.or.jp/jp/event/seminar/CCS2025ad.html`) explicitly includes `実際の周辺環境色彩調査（視感測色）` in a detached-house color-design exercise.

Accepted fact: actual surrounding-environment color investigation may be performed as visual colorimetry (`視感測色`).

### Ministry of Land, Infrastructure, Transport and Tourism

The current 2025/2026 PLATEAU landscape-policy implementation report (`https://www.mlit.go.jp/plateau/use-case/uc25-12/`) states that building/work color review uses quantitative Munsell values together with qualitative surrounding-landscape harmony, and that the conventional checking process used paper Munsell color charts. It explicitly describes a Munsell value as `色相・明度・彩度`.

Accepted facts:
- Munsell values provide a quantitative representation used in landscape color review;
- the three named Munsell components are hue, value/lightness, and chroma (`色相・明度・彩度`);
- paper Munsell color charts are an explicitly documented conventional comparison/checking medium;
- quantitative color values do not replace the separate qualitative check of harmony with surrounding landscape.

The older MLIT road-landscape technical material (`https://www.mlit.go.jp/river/shishin_guideline/bousai/saigai/measures-saigai/pdf/04.pdf`) independently identifies the JIS Z 8721 standard color chart as based on the Munsell system. This is used only as corroboration of the standardized representation, not to import unrelated road-specific color prescriptions.

### Japan Color Research Institute

Current JCRI product information for the JIS Standard Color Chart (`https://www.jcri.jp/product/jis_standard_color_chart`) states that it is based on Munsell values and conforms to JIS Z 8721; it includes a hue-circle chart, value scale and color-comparison masks.

Accepted fact: a standardized physical color-chart system exists for visual comparison using Munsell/JIS representation. Product-specific price, edition size and monitor-rendered appearance are outside the Grade 2 authoring boundary.

## Accepted authoring boundary

Authorize only text-only questions about these explicit relationships:

- the current Grade 2 scope includes understanding surrounding-environment color by measuring color;
- an actual surrounding-environment color survey is explicitly described as visual colorimetry in current professional training;
- conventional landscape color checking may use paper Munsell color charts;
- Munsell values represent color through hue, value/lightness and chroma;
- JIS Z 8721 standard color charts are based on the Munsell system;
- standardized physical color charts can support visual comparison;
- quantitative Munsell review and qualitative surrounding-landscape-harmony review are distinct and both may be relevant in landscape review.

## Prohibited inference

Do not infer or generate:

- RGB/HEX/display values or monitor swatches;
- any answer from screenshots, photographs, rendered 3D appearance or image pixels;
- specific measured Munsell values for a place/building not explicitly supplied by authority;
- a claim that the AFT official text mandates one specific commercial color-chart product;
- road-specific recommended colors or local regulatory limits as general Grade 2 rules;
- unstated observation geometry, lighting conditions, measurement distances or numerical tolerances;
- a claim that numerical compliance alone proves surrounding-landscape harmony.

## Decision

Authorize pending-first authoring for `pc2.landscape.surrounding_environment_measurement` using only the accepted facts above. Independently re-answer every item before promotion. Grade 3 source/display gates remain unchanged.
