## Auditable authority used
Current CIE authority:

- CIE S 017:2020 e-ILV `CIE 1931 standard colorimetric system [X, Y, Z]`: a system for determining tristimulus values of spectral power distributions using reference colour stimuli [X], [Y], [Z] and the three CIE colour-matching functions adopted by the CIE in 1931.
- The CIE definition notes that the Y colour-matching function is identical to V(λ), so tristimulus value Y is proportional to luminance.
- The CIE definition notes that the 1931 standard colorimetric system applies to centrally viewed fields with angular subtense about 1° to 4°.
- CIE S 017:2020 defines tristimulus values as the amounts of reference colour stimuli required in a trichromatic system to match the colour of the stimulus considered.
