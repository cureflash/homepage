# Grade 1 p.144 `色彩基準の示し方` source audit

Classification: `SOURCE_RESOLVED`

## Official scope
Current AFT Grade 1 textbook table of contents places `景観計画における色彩基準 — 色彩基準の示し方` at p.144, after p.143 `色彩基準における面積比の考え方` and before p.145 `色彩基準の適用除外`. The public TOC establishes membership/order only; unpublished AFT body wording and figures are not reconstructed.

- 横須賀市 `色彩協議（建築物等色彩協議要綱）`: https://www.city.yokosuka.kanagawa.jp/4821/keikan/catlog/nagare.html

## Resolved nonvisual fact boundary
The government sources explicitly show a deterministic way of expressing landscape color standards with the Munsell system. A color is represented through hue, value and chroma, and a landscape color-standard table can state permitted ranges by combining the applicable part/area category with hue, value and chroma conditions. Tokyo's official table separately lists exterior-wall basic color and emphasis color ranges, and the permitted chroma limit is not one universal number: it varies by hue group and, for some basic-color hue groups, by value range as well.

This resolves a narrow p.144 `色彩基準の示し方` slice without relying on screen appearance, unstated diagram geometry, RGB/HEX values or unpublished AFT wording.

## Exclusions
Do not universalize Tokyo's exact thresholds to all jurisdictions. Do not infer colors from the PDF swatches or graphs. Do not author monitor-facing identification, municipality-specific exceptions, p.145 `色彩基準の適用除外`, p.145 `屋外広告物の色彩基準`, or unpublished AFT examples/terminology. Exact Tokyo threshold values are not required for this p.144 authoring batch; only the explicit structural relation of how the standard is stated is used.
