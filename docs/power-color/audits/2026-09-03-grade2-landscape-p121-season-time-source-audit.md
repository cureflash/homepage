# Power Color Grade 2 — Landscape p.121 季節や時間の変化を感じさせる多様な色彩 source audit

Checked: 2026-09-03

## Official scope

The current Color Certification Association Grade 2 official-text table of contents places `季節や時間の変化を感じさせる多様な色彩` at Landscape p.121, immediately after p.120 `太陽光に影響される色彩` and before p.122 `生活環境における景観色彩設計 / 景観色彩設計の配慮事項`.

Primary scope source:
- https://www.aft.or.jp/images/text_of-2st-grade_mokuji.pdf

The current official Grade 2 sample page confirms that Grade 2 assesses practical color coordination across fields including exterior/landscape-related application, but it does not publish the p.121 detailed rule set.

- https://www.aft.or.jp/pages/feature/exam2

## Public-source search result

Current public-sector landscape material was checked for an explicit nonvisual rule set that could deterministically distinguish seasonal/time-varying landscape-color propositions. The checked material supports only broad propositions such as landscapes changing with season/time, surrounding context being relevant, or landscape planning requiring attention to local characteristics. It does not expose the official-text p.121 classifications, a closed example inventory, or deterministic mappings suitable for a distinct 12-question skill.

Checked examples include:
- Hiroshima City landscape-plan/guideline page: https://www.city.hiroshima.lg.jp/business/toshikeikaku/1014904/1026833/1015593.html
- Aomori Prefecture landscape-color training page: https://www.pref.aomori.lg.jp/soshiki/kendo/toshikei/keikan-shikisai.html

These sources do not authorize fixed season→color, time-of-day→color, hue/value/chroma shift, weather→color, RGB/HEX, monitor-display, or unstated illumination-geometry answers.

## Decision

`Landscape p.121 季節や時間の変化を感じさせる多様な色彩` is source-blocked for authoring.

Reason: the current official scope is confirmed, but publicly auditable authority does not expose a sufficiently rich, distinct, deterministic nonvisual rule set corresponding to the official-text topic. A question batch would otherwise require paraphrasing the heading, importing arbitrary outside examples, or inferring appearance from images/light conditions.

Do not author this skill unless new explicit auditable authority becomes available. Do not infer color shifts, hue/value/chroma changes, RGB/HEX/display values, season/time mappings, or illumination geometry.
