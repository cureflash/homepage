# Grade 1 p.157 資料・光と色（2） — 相関色温度と演色評価数 — Source Audit

## Classification
`SOURCE_RESOLVED`

## Official scope
AFT current official Grade 1 textbook table of contents places `資料・光と色（2） — 相関色温度と演色評価数` at p.157. Public CIE definitions and current Japanese lighting-industry/JIS guidance resolve a narrow deterministic nonvisual slice without reconstructing unpublished AFT wording.

## Accepted authority
1. AFT current official Grade 1 textbook table of contents: https://www.aft.or.jp/images/text_of-1st-grade_mokuji.pdf
2. CIE International Lighting Vocabulary, `correlated colour temperature [Tcp]`: https://cie.co.at/eilv/258
3. CIE International Lighting Vocabulary, `CIE 1974 general colour rendering index [Ra]`: https://cie.co.at/eilv/154
4. 一般社団法人日本照明工業会 `LED照明器具に関するQ&A`: https://www.jlma.or.jp/led/led_kigu_qa.htm
5. 一般社団法人日本照明工業会 `あかりに関する単語`: https://www.jlma.or.jp/led-navi/contents/cont25_glossary.php/cont25_glossary_word.php

CIE defines correlated colour temperature as the temperature of the Planckian radiator whose chromaticity is nearest the chromaticity associated with the test spectral distribution, with unit K. CIE defines general colour rendering index Ra as the mean of the CIE 1974 special colour rendering indices for a specified set of eight test colour samples. JLMA states that source-colour categories are defined by correlated colour temperature under JIS Z 9112 and explains that average colour rendering index Ra numerically expresses colour rendering / colour appearance reproducibility, with higher values indicating better reproducibility.

## Authoring boundary
Author only text-only questions testing:
- CCT relates a test source chromaticity to the nearest Planckian-radiator chromaticity;
- correlated colour temperature is expressed in kelvins (K);
- general colour rendering index Ra is the mean of eight CIE 1974 special colour rendering indices;
- average colour rendering index Ra is an index of colour appearance/reproducibility, with higher values indicating better reproducibility under the JLMA explanation.

Do not infer:
- unpublished AFT examples, diagrams, thresholds, or preferred-lamp recommendations;
- monitor-facing judgements of warmth/coolness or rendered object colours;
- current normative JIS wording beyond the public JLMA/CIE statements cited here;
- that Ra alone fully characterizes every aspect of perceived colour quality.

## Decision
The p.157 narrow nonvisual concept set is independently explicit in current CIE definitions and JLMA/JIS-facing public guidance. Classification is `SOURCE_RESOLVED`; a four-record text-choice batch is permitted.
