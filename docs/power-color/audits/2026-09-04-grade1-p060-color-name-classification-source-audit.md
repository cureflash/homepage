# Grade 1 p.060 色名 — 色を表す言葉の分類 source audit

## Classification
`SECONDARY_CORROBORATION_REQUIRED`

## Official scope/order
Current AFT Grade 1 official material places p.060 `色名 — 色を表す言葉の分類` immediately after p.059 NCS `色立体と色票集`, followed by p.061 `ISCC-NBS色名法` and p.062 JIS light-source color-name topics. AFT public material establishes the heading/order only; unpublished textbook wording is not reconstructed.

## Accepted corroborating authority
- AFT current Grade 1 level / official textbook TOC: topic membership and sequence only.
- 一般財団法人日本色彩研究所 `episode1：PCCS（日本色研配色体系）とは`: explicitly distinguishes system color names from 慣用色名/固有色名 and states that system color names cover the whole color space by rule, using familiar color names plus simple tone modifiers; it also states that 慣用色名/固有色名 derive from things/persons and that different such names can indicate the same color.
- 一般財団法人日本色彩研究所 `JIS色名帳（JIS Z 8102:2001準拠）`: independently confirms that the JIS color-name material contains both 系統色名 and 慣用色名 and provides a relationship/index between them.

## Source-resolved fact families
Only these deterministic nonvisual facts are accepted for authoring:
1. 系統色名 represents colors by a rule-based naming system rather than by isolated conventional names.
2. The cited JCRI explanation describes the system-name rule as familiar color names combined with simple modifiers such as `うすい` / `濃い` that describe tone.
3. 慣用色名/固有色名 can be names derived from things or persons.
4. Different 慣用色名/固有色名 can indicate the same color; by contrast, the system-name scheme is intended to cover the whole color space without unnamed regions.

## Explicit exclusions
Do not infer the exact AFT p.060 taxonomy, exact category count, exact wording, exact JIS Z 8102 definitions beyond the public corroborated boundary, lists of basic color names, numerical color counts, swatches, RGB/HEX, image appearance, or monitor-facing judgments.

## Decision
Authoring is allowed only for the four fact families above. Anything beyond them remains source-blocked pending explicit current auditable authority.
