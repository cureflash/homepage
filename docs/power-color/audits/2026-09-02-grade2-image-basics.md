## Detailed nonvisual rule authority

Current Adobe professional documentation explicitly states:

- raster images consist of a grid of pixels;
- raster images are resolution-dependent / contain a fixed number of pixels;
- enlarging raster images can lose detail or reveal pixelation;
- vector images are defined by mathematical equations and geometric components such as points, lines and curves;
- vector images can be scaled while retaining crisp edges;
- digital photographs are a standard raster use case;
- logos and technical illustrations that must be used at multiple sizes are standard vector use cases;
- Adobe lists formats such as JPEG and PNG as raster examples.
