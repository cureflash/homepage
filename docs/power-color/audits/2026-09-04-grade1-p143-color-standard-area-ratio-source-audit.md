# Grade 1 p.143 `色彩基準における面積比の考え方` source audit

Classification: `SOURCE_RESOLVED`

## Official scope
Current AFT Grade 1 textbook table of contents places `景観計画における色彩基準 — 色彩基準における面積比の考え方` at p.143. The public TOC establishes membership/order only.

## Accepted authority
- AFT current Grade 1 TOC: https://www.aft.or.jp/images/text_of-1st-grade_mokuji.pdf
- 東京都都市整備局 `東京都景観色彩ガイドライン` current distribution page: https://www.toshiseibi.metro.tokyo.lg.jp/ryokuchi_keikan/kekan_kese/keikan/machinami_01/1
- 東京都都市整備局 guideline file containing the official color-standard area allocation example: https://www.toshiseibi.metro.tokyo.lg.jp/documents/d/toshiseibi/pdf_keikaku_keikan_shingikai-045_tokyo_color_guideline_01_02

## Resolved nonvisual fact boundary
Tokyo's official guideline gives a concrete area-allocation model for applicable building exterior standards: basic color uses at least 4/5 of each exterior-wall face; emphasis color may use up to 1/5; accent color may use up to 1/20 where that category applies; emphasis color plus accent color together must remain within 1/5 of each exterior-wall face. The guideline also distinguishes the applicable categories/areas and notes that some landscape basic-axis standards set only a basic-color standard.

This is accepted only as an explicit Tokyo-government example of the p.143 area-ratio concept. It is not generalized into a nationwide universal numerical rule and is not claimed to reproduce unpublished AFT body text.

## Exclusions
No monitor-facing color judgment, no RGB/HEX conversion, no inference from diagrams, no municipality-independent universalization of Tokyo's ratios, and no import of p.144+ exact hue/value/chroma limits or exception rules.
