# 都道府県別・鉄道唱歌割当台帳

更新日: 2026-08-25

この台帳は、教材候補を先に都道府県へ振り分けるための索引である。歌詞本文の転載台帳ではない。
県境をまたぐ一番は複数都道府県に重複登録する。後工程の本文照合で境界が変わった場合はここを修正する。

## 対象作品

- 大和田建樹『地理教育鉄道唱歌』（1900）第1-5集、計334番。番単位で暫定割当済み。
- 鉄道省編『新鉄道唱歌』（1929）第1-10輯。全10輯の路線・地域範囲を都道府県へ割当済み。本文をオンラインで確認できない輯は、番単位の県境を推測せず `primary_text_pending` とする。
- 沖縄県は、現時点のこの2作品群では対象歌詞を確認できていない。

## 検証状態

- `verse_draft`: 番単位の初期割当。公開転写と路線・地名を基にした作業用で、教材採用前に本文・地名・読みを再照合する。
- `route_scope_confirmed`: 輯名と路線範囲から都道府県候補を確定したが、番ごとの県境は原本確認待ち。
- `primary_text_pending`: 推測で番番号を割り振らない。
