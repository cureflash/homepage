# 物理プリント制作計画

最優先分野。計算プリントを中心に大量生産する。難易度は基本事項とし、公式を理解していれば解けるレベルを基準にする。

## 中学1年

- 光: 反射・屈折の基本関係、像の位置など機械判定しやすい基本問題
- 音: 振動数・周期・波の基本的な数量関係を扱える範囲
- 力: 力の大きさ、ばねの伸びと力の比例関係、圧力の基本計算
- 単位換算を含む基本反復

## 中学2年

- 電流・電圧・抵抗
- オームの法則
- 直列回路・並列回路
- 合成抵抗の基本
- 電力
- 電力量
- 発熱量
- 電流による磁界・電磁誘導は、数量計算として自然な基本問題が作れる範囲のみ

## 中学3年

- 速さ
- 平均の速さ
- 等速直線運動の基本
- 力の合成・分解の基本
- 仕事
- 仕事率
- 位置エネルギー
- 運動エネルギー
- 力学的エネルギー
- エネルギー変換・効率の基本数値問題

## 出題方針

各技能について、`basic → reverse → unit → mixed → speed → review` のうち自然な系列を展開する。まず直接代入型を十分に作り、その後に求める量を入れ替えた問題、同単元混合、累積復習へ進む。
