# 物理プリント制作計画

最優先分野。計算プリントを中心に大量生産する。難易度は基本事項とし、公式を理解していれば解けるレベルを基準にする。

## 中学1年

現行学習指導要領では「身近な物理現象」の光・音・力を扱う。圧力は中1の制作対象にしない。

- 光: 反射・屈折、凸レンズによる像など、機械判定しやすい基本事項
- 音: 音の発生・伝わり方、音の大小・高低と振動などの基本事項
- 力: 力の大きさ、ばねの伸びと力の比例関係
- 質量と重力による力の大きさ: 中学理科で用いる近似 `100 g ≒ 1 N` の基本換算
- 2力のつり合いなど、基本事項の機械判定可能な反復

計算プリントは、まず「ばねの伸びと力」「100 g ≒ 1 N」を `basic → reverse` の順で量産する。光・音は、現行課程で明示された基本事項を短い機械判定可能な暗記反復として扱い、数量計算は自然な数量関係を確認できたものだけ追加する。

### 現在の公開済み範囲

- ばねの伸びと力: `basic` 3枚 + `reverse` 3枚
- `100 g ≒ 1 N` の質量・重力換算: `basic` 3枚 + `reverse` 3枚
- 力の基本事項: 用語→内容 3枚 + 内容→用語 3枚 + 正誤 3枚 + 穴埋め 3枚
- 光の基本事項: 事項→性質 3枚 + 性質→用語 3枚 + 関係穴埋め 3枚
- 音の基本事項: 事項→性質 3枚 + 性質→用語 3枚 + 関係穴埋め 3枚
- 光・音・力の横断混合: `mixed` 3枚
- 中1物理の累積総復習: `review` 3枚
- 中1物理の公開済み合計: 48枚

力の基本事項には、ニュートン（N）、質量と重さ、てんびん・ばねばかり、力の3要素、2力のつり合いを含む。

光の基本事項には、反射の規則、屈折角の定性的な大小、全反射、凸レンズの焦点、実像・虚像、焦点内の物体で見える拡大した虚像、白色光とプリズムを含む。

音の基本事項には、発音体の振動、物質中を波として伝わること、振幅と音の大小、振動数と音の高低を含む。

`mixed` は既存の検証済み事実プールから力・光・音を必ず横断する短い穴埋めを構成する。`review` は用語→内容、内容→用語、正誤、穴埋めを混ぜ、同じ事実を複数方向から累積確認する。いずれも単なるタイトル違いではなく、決定論的な別問題列として重複検査を通す。

中1の focused → mixed → review が揃ったため、中1制作サイクルは完了済み。

## 中学2年

- 電流・電圧・抵抗
- オームの法則
- 直列回路・並列回路
- 合成抵抗の基本
- 電力
- 電力量
- 発熱量
- 電流による磁界・電磁誘導は、数量計算として自然な基本問題が作れる範囲のみ

最初に現行課程上の位置付けを再確認し、電流・電圧・抵抗とオームの法則を `basic → reverse → unit → mixed` の自然な順で量産する。電力・電力量・発熱量は、現行中2で扱う単位・数量関係を確認してから追加する。

### 現在の公開済み範囲

- オームの法則 `V = I × R`: 電圧を求める `basic` 10枚
- オームの法則 `V = I × R`: 電流を求める逆算 10枚
- オームの法則 `V = I × R`: 抵抗を求める逆算 10枚
- 直列回路の電圧 `V全体 = V1 + V2`: `basic` 10枚
- 並列回路の電流 `I全体 = I1 + I2`: `basic` 10枚
- 直列回路の合成抵抗 `R全体 = R1 + R2`: `basic` 10枚
- 電力 `P = V × I`: `basic` 10枚
- 電力量 `E = P × t`: `basic` 10枚。時間は秒、答えはJに限定
- 電熱線の発熱量 `Q = P × t`: `basic` 10枚。時間は秒、答えはJに限定
- 上記90枚を横断する `mixed`: 15枚
- 中2「電流とその利用」の累積 `review`: 15枚
- 各プリント20問
- 中2物理の公開済み合計: 120枚

現行MEXTの「電流とその利用」で、分岐点のない回路では電流が等しいこと、分岐点では流入電流の和と流出電流の和が等しいこと、直列回路では各抵抗の両端電圧の和が全体電圧に等しいこと、並列回路では各抵抗の両端電圧が等しいことを再確認した。また、二つの抵抗をつなぐ場合の合成抵抗にも触れることが明記されている。

同じ現行解説で、電力は電流と電圧の積で表され単位Wを用いること、電力量は電力と時間の積で表され単位Jを用いること、発生する熱量もJで表して電力・時間との関係を扱うことを再確認した。電力量・発熱量のfocused系列はまず秒とJだけに限定し、単位換算だけを難しくした問題には広げていない。

`mixed` 15枚と `review` 15枚は、既存の検証済みJH2公式レジストリだけから生成する。各20問で、オームの法則の直接・逆算、直列回路の電圧、並列回路の電流、直列合成抵抗、電力、電力量、発熱量を横断する。各シートが少なくとも7公式IDを含み、V/A/Ω/W/Jを含むことをテストし、focused 90枚との問題内容ハッシュ重複も拒否する。

中2は focused → mixed → review が合計120枚で揃ったため、中2制作サイクルは完了済み。磁界・電磁誘導は中2課程内だが、自然な大量数値ドリルを無理に作らず、必要なretrievalを後の補完候補とする。

## 中学3年

- 速さ
- 平均の速さ
- 等速直線運動の基本
- 力の合成・分解の基本
- 仕事
- 仕事率
- 位置エネルギー
- 運動エネルギー
- 力学的エネルギー
- エネルギー変換・効率の基本

現行MEXT中3「運動とエネルギー」を再確認した。定量反復としては、速さ、仕事（力の大きさ×力の向きに移動した距離）、仕事率（単位時間当たりの仕事）が明確に扱えるため、この範囲を共有formula helperで公開した。位置エネルギー・運動エネルギーについては、現行中学解説では質量・高さ・速さとの規則性を実験で見いだす扱いが中心であるため、高校物理の `mgh` や `1/2 mv²` を中3の固定公式として先取り量産しない。

### 現在の公開済み範囲

#### focused 数値計算 60枚

- 速さ: 距離・時間から速さを求める `basic` 10枚
- 速さ: 速さ・時間から移動距離を求める `reverse` 10枚
- 平均の速さ: 全移動距離・全移動時間から求める `basic` 10枚
- 仕事 `W = F × d`: 仕事を求める `basic` 10枚
- 仕事 `W = F × d`: 力を求める `reverse` 10枚
- 仕事率: 仕事・時間から仕事率を求める `basic` 10枚
- 各プリント20問

#### 数値 mixed / review 30枚

- 既存6計算モードを横断する `mixed`: 15枚
- 中3「運動とエネルギー」の数値累積 `review`: 15枚
- 各プリント20問
- 速さ、距離逆算、平均の速さ、仕事、力逆算、仕事率を必ず横断する

#### 概念 retrieval 30枚

- 用語→内容 `forward`: 10枚
- 内容→用語 `reverse`: 10枚
- 関係・規則の穴埋め `fill`: 10枚
- 各プリント10問
- 等速直線運動・慣性、合力・分力、力の合成・分解、位置エネルギー、運動エネルギー、力学的エネルギー、力学的エネルギー保存、仕事・仕事率を有限回答で反復する

中3物理の公開済み合計: **120枚**。

すべて決定論的seed生成、独立正答再計算または有限accepted-set検証、normalized content hashによる重複拒否、共有PDF renderer、共有catalog validatorを通して公開する。数値答えの単位は `m/s`, `m`, `J`, `N`, `W` を明示する。

`mixed` / `review` は既存の検証済みJH3公式レジストリだけから生成し、retrievalは現行中学解説で確認した概念関係だけを有限回答化する。`mgh` と `1/2 mv²` は中3計算問題には使用しない。

中3の focused → mixed → review と必要な概念retrievalが揃ったため、中3制作サイクルは完了済み。次は正式科目 `物理基礎` へ進む。

- 位置・変位・速度・平均速度
- 加速度
- 等加速度直線運動
- 落下運動の基本
- 力のつり合い
- 運動方程式
- 摩擦力
- 仕事・仕事率
- 運動エネルギー・位置エネルギー・力学的エネルギー
- 熱量・比熱・熱容量
- 波の速さ・振動数・波長
- 音の基本数量関係
- 電流・電圧・抵抗

新しいformula relationが共有helperに必要な場合は、関係自体を独立テストしてから大量生成する。高校の学年は固定せず、全エントリで `formal_course=物理基礎`、`grade=null` を保持する。

### 現在の公開済み範囲

#### 運動の表し方 90枚

- 変位 `Δx = v平均 × t`: 変位10枚、平均速度逆算10枚
- 速度変化 `Δv = a × t`: 加速度10枚、速度変化逆算10枚
- 初速度・終速度 `v = v0 + Δv`: 終速度10枚、初速度逆算10枚
- 等加速度直線運動 `v = v0 + at`: 終速度・加速度・時間を各10枚
- 自由落下速度 `v = gt`: 速度・時間を各10枚

#### 様々な力とその働き 130枚

- 右向きを正とした1次元の合力: 合力・右向きの力・左向きの力を各10枚
- 運動方程式 `F = ma`: 合力・質量・加速度を各10枚
- 合力0 Nの2力のつり合い: 20枚
- 動摩擦力 `F = μ'N`: 動摩擦力・動摩擦係数・垂直抗力を各10枚

#### 力学的エネルギー 110枚

- 仕事 `W = Fd`: 力と変位が平行・同方向の場合に限定し、仕事・力・変位を各10枚
- 仕事率 `P = W/t`: 仕事率・時間を各10枚
- 重力による位置エネルギー `U = mgh`: 基準面を `U = 0` とし、`g = 9.8 m/s²` を明示して、位置エネルギー・質量・高さを各10枚
- 運動エネルギー `K = 1/2 mv²`: 運動エネルギー・質量・速さを各10枚

物理基礎の公開済み合計: **330枚**。各プリント20問。

`K = 1/2 mv²` は共有helperの `half-product-last-square` relationで扱う。実際の速さ `v` を入力としてseed生成し、helperが最後の入力を二乗するため、`v²` を独立した偽の変数としてサンプリングしない。逆算の速さも平方根を含む独立再計算で検証する。

現行MEXT解説では、力学的エネルギーで運動エネルギーと位置エネルギーを仕事と関連付け、位置エネルギーとして重力・弾性力による位置エネルギーを扱い、摩擦や空気抵抗がない場合を中心に力学的エネルギー保存を扱うことを再確認している。

次は弾性力による位置エネルギー `U = 1/2 kx²` を、新しい二乗対応relationで実装・独立検証する。その後、摩擦・空気抵抗なしという条件を明示した力学的エネルギー保存の基本反復を作る。力学的エネルギーのまとまりが揃った後、熱 → 波・音 → 電気 → エネルギー利用へ進む。

## 出題方針

各技能について、`basic → reverse → unit → mixed → speed → review` のうち自然な系列を展開する。まず直接代入型を十分に作り、その後に求める量を入れ替えた問題、同単元混合、累積復習へ進む。量産数は目的ではなく、実際の問題データ・出題方向・組合せが教育的に異なるものだけを追加する。
