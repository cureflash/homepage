# 物理プリント制作計画

最優先分野。計算プリントを中心に大量生産する。難易度は基本事項とし、公式を理解していれば解けるレベルを基準にする。

## 中学1年

現行学習指導要領では「身近な物理現象」の光・音・力を扱う。圧力は中1の制作対象にしない。

- 光: 反射・屈折、凸レンズによる像など、機械判定しやすい基本事項
- 音: 音の発生・伝わり方、音の大小・高低と振動などの基本事項
- 力: 力の大きさ、ばねの伸びと力の比例関係
- 質量と重力による力の大きさ: 中学理科で用いる近似 `100 g ≒ 1 N` の基本換算
- 2力のつり合いなど、基本事項の機械判定可能な反復

計算プリントは、まず「ばねの伸びと力」「100 g ≒ 1 N」を `basic → reverse` の順で量産する。光・音は、現行課程で明示された基本事項を短い機械判定可能な暗記反復として扱い、数量計算は自然な数量関係を確認できたものだけ追加する。

### 現在の公開済み範囲

- ばねの伸びと力: `basic` 3枚 + `reverse` 3枚
- `100 g ≒ 1 N` の質量・重力換算: `basic` 3枚 + `reverse` 3枚
- 力の基本事項: 用語→内容 3枚 + 内容→用語 3枚 + 正誤 3枚 + 穴埋め 3枚
- 光の基本事項: 事項→性質 3枚 + 性質→用語 3枚 + 関係穴埋め 3枚
- 音の基本事項: 事項→性質 3枚 + 性質→用語 3枚 + 関係穴埋め 3枚
- 光・音・力の横断混合: `mixed` 3枚
- 中1物理の累積総復習: `review` 3枚
- 中1物理の公開済み合計: 48枚

力の基本事項には、ニュートン（N）、質量と重さ、てんびん・ばねばかり、力の3要素、2力のつり合いを含む。

光の基本事項には、反射の規則、屈折角の定性的な大小、全反射、凸レンズの焦点、実像・虚像、焦点内の物体で見える拡大した虚像、白色光とプリズムを含む。

音の基本事項には、発音体の振動、物質中を波として伝わること、振幅と音の大小、振動数と音の高低を含む。

`mixed` は既存の検証済み事実プールから力・光・音を必ず横断する短い穴埋めを構成する。`review` は用語→内容、内容→用語、正誤、穴埋めを混ぜ、同じ事実を複数方向から累積確認する。いずれも単なるタイトル違いではなく、決定論的な別問題列として重複検査を通す。

中1の focused → mixed → review が揃ったため、次は中2物理へ進む。

- 電力量
- 発熱量
- 電流による磁界・電磁誘導は、数量計算として自然な基本問題が作れる範囲のみ

最初に現行課程上の位置付けを再確認し、電流・電圧・抵抗とオームの法則を `basic → reverse → unit → mixed` の自然な順で量産する。電力・電力量・発熱量は、現行中2で扱う単位・数量関係を確認してから追加する。

### 現在の公開済み範囲

- オームの法則 `V = I × R`: 電圧を求める `basic` 10枚
- オームの法則 `V = I × R`: 電流を求める逆算 10枚
- オームの法則 `V = I × R`: 抵抗を求める逆算 10枚
- 直列回路の電圧 `V全体 = V1 + V2`: `basic` 10枚
- 並列回路の電流 `I全体 = I1 + I2`: `basic` 10枚
- 直列回路の合成抵抗 `R全体 = R1 + R2`: `basic` 10枚
- 各プリント20問、各系列10個の決定論的seedを使用
- 中2物理の公開済み合計: 60枚

現行MEXTの「電流とその利用」で、分岐点のない回路では電流が等しいこと、分岐点では流入電流の和と流出電流の和が等しいこと、直列回路では各抵抗の両端電圧の和が全体電圧に等しいこと、並列回路では各抵抗の両端電圧が等しいことを再確認した。また、二つの抵抗をつなぐ場合の合成抵抗にも触れることが明記されている。

今回の追加30枚は共有の `sum` 関係生成器だけを使用し、新しい問題型・レンダラー・解答形式を追加していない。既存のオームの法則30枚のseed・ID・内容は変更していない。

次は電力 `P = V × I`、電力量 `E = P × t`、発熱量の基本数量関係を現行MEXTの単位・扱いに合わせて構造化する。その後、中2の回路・オーム則・電力/電力量/熱量を横断する `mixed` / `review` を追加する。並列回路の合成抵抗は、学習指導要領解説が「回路全体の電流と電圧から考えさせる」としているため、公式暗記の大量反復に先行して扱わない。

## 出題方針

各技能について、`basic → reverse → unit → mixed → speed → review` のうち自然な系列を展開する。まず直接代入型を十分に作り、その後に求める量を入れ替えた問題、同単元混合、累積復習へ進む。
