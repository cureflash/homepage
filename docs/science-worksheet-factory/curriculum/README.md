# 理科プリント制作マップ

対象は中学生以降。制作順は固定で、`物理 → 化学 → 生物 → 地学` とする。

## 学年・科目の扱い

中学校は現行学習指導要領の学年配当をそのまま使う。

- 中1: 第1分野(1)(2)、第2分野(1)(2)
- 中2: 第1分野(3)(4)、第2分野(3)(4)
- 中3: 第1分野(5)〜(7)、第2分野(5)〜(7)

高等学校は学年固定ではなく正式科目で管理する。制作順は各分野で `基礎科目 → 発展科目` とする。

- 物理基礎 → 物理
- 化学基礎 → 化学
- 生物基礎 → 生物
- 地学基礎 → 地学

サイト上で便宜的な学年グループを付ける場合でも、正式科目メタデータを必ず保持し、「高1で必ず物理基礎」などの固定表現はしない。

## 計算プリント

難易度は基本事項。公式や基本的な量的関係を理解していれば解けるものを大量生産する。

基本系列:
- `basic`: 直接代入
- `reverse`: 求める量を変える
- `unit`: 単位換算を含む基本問題
- `mixed`: 同じ単元の公式を混ぜる
- `speed`: 短時間反復
- `review`: 累積復習

## 暗記プリント

同じ知識を一方向だけでなく、複数方向から取り出させる。

基本系列:
- `forward`: 名称→性質・意味
- `reverse`: 性質・意味→名称
- `pair`: 名称↔記号・式など
- `classify`: 分類
- `tf`: 正誤
- `fill`: 穴埋め
- `order`: 順序
- `mixed`: 単元内混合
- `review`: 累積復習

1つの知識から自然に複数の問形式が作れる場合は、逆方向・混合も作る。ただし曖昧な自由記述は避け、機械的に正誤判定できる形式を優先する。
