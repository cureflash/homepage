# 生物プリント制作計画

計算できる分野は基本計算を作り、それ以外は用語・構造・機能・分類・順序・関係性を反復する。

## 中学1年

- 生物の分類
- 植物の分類
- 動物の分類
- 生物の共通点と相違点
- 部位名↔特徴
- 分類条件↔分類名

## 中学2年

- 細胞のつくり
- 植物と動物の体のつくり
- 光合成・呼吸
- 消化・吸収
- 血液循環
- 排出
- 刺激と反応
- 器官名↔機能
- 物質↔移動経路・役割

定量的な内容が自然に扱える場合だけ、比・割合・表データ読み取りなど基本計算を追加する。

## 中学3年

- 生殖
- 遺伝
- 遺伝子・染色体の基本
- 遺伝の規則性の基本比
- 生物の成長・発生
- 生態系
- 食物連鎖・食物網
- 生産者・消費者・分解者
- 炭素など物質循環の基本
- 生物と環境

遺伝の基本比など機械的に判定できる数量問題は計算プリント化する。

## 生物基礎

- 生物の共通性
- 細胞
- DNA・遺伝情報
- 遺伝子発現の基本
- 体内環境
- 神経・ホルモン
- 免疫
- 植生・バイオーム
- 生態系
- 物質循環・エネルギーの基本

用語↔機能、構造↔名称、ホルモン↔作用、免疫要素↔役割、バイオーム↔特徴などを多方向反復する。

## 生物

### 計算・数量分野

- 遺伝の比
- 連鎖・組換えの基本計算
- 個体群の増減に関する基本数量問題
- 生態系の物質生産
- 栄養段階・エネルギー収支
- 実験データ・表の基本的な数量処理で機械判定できるもの

### 暗記・関係分野

- 代謝経路の基本
- 遺伝情報の発現
- 発生
- 動物の反応・行動
- 植物の環境応答
- 生物群集・個体群
- 進化・系統
- 分類
- 構造↔機能
- 物質・酵素・ホルモン↔役割
- 過程の順序

## 出題方針

暗記は `forward/reverse/classify/tf/fill/order/mixed/review` を中心にする。図問題は共通レンダリングと位置ラベル検証が整ってから追加し、最初から図に依存しすぎない。
