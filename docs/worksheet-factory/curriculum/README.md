# 算数・数学プリント制作マップ

この配下は、小1〜高3相当までの「単純反復練習プリントとして何を作るか」を定義する。

## 調査根拠

優先順位は次の通り。

1. 文部科学省の現行学習指導要領・解説
2. 文部科学省の教科書編修資料等による現行科目の具体的な配置確認
3. ちびむすドリルの公開カテゴリを、反復練習ニーズの切り方の参考として確認

ちびむすドリルの問題文・レイアウト・問題セット自体はコピーしない。参考にするのは「繰り返し練習」「学年別」「単元別」「混合」「時間制限系」などの需要分類のみで、問題生成規則・数値・レイアウトは自前で作る。

## 共通のプリント系列

各計算技能は、必要に応じて次の系列へ展開する。

- `basic`: その技能だけを反復
- `step`: 数値範囲や桁数を段階化
- `mixed`: 同学年の既習計算を混合
- `speed`: 5分など短時間の計算練習向け
- `reverse`: □を含む逆算・欠損値補充が自然な単元のみ
- `review`: 学期・学年の計算総復習

各系列は seed で複数の実問題セットを生成し、問題内容の重複検査を通す。

## 高校の「学年」について

学習指導要領は高校数学を高1・高2・高3に固定配当していない。数学I→数学II→数学IIIの順を原則とし、数学Aは数学Iと並行または後、数学B/Cは数学Iの後が原則である。

このサイトでは利用者が探しやすいよう便宜的に:
- 高1相当: 主に数学I・数学A
- 高2相当: 主に数学II・数学B・数学C（ベクトル）
- 高3相当: 主に数学III・数学C（平面上の曲線・複素数平面）

として並べる。ただし各教材メタデータには正式科目名を必ず持たせ、「高2で必ず履修する」等の誤解を招く表現はしない。

## 優先方針

最初は自動採点しやすい計算技能を優先する。文章題・証明・作図・統計的推測などは、この計算プリント工場の主要範囲が埋まった後に扱う。
