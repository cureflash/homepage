### 簡単な分数

- 文部科学省「小学校学習指導要領（平成29年告示）解説 算数編」の第2学年を再確認した。
  - 第2学年では、具体物を2等分・3等分した1つ分を `1/2`、`1/3` などの簡単な分数として知ること、またその部分を2個・3個集めるともとの大きさになる関係を扱う。
  - 一般的な同値分数 `2/4 = 1/2` などは今回の小2教材には入れず、安全な範囲に限定した。
  - 参照: https://www.mext.go.jp/content/20211102-mxt_kyoiku02-100002607_04.pdf
- `scripts/publish_grade2_simple_fractions.py` を追加し、次の2技能を構造化した。
  - `簡単な分数の読み取り`
  - `簡単な分数ともとの大きさ`
- seed=2501/2602/2703 の3種類で各技能を決定的生成し、新規6PDFを公開した。
- 各プリントは20問で、2等分と3等分を各10問ずつ扱う。
- 図形・画像認識には依存せず、等分前の個数、等分数、1つ分の個数から答えを一意に再計算できる形式とした。
- `independent_answer()` で `1/2` / `1/3`、または「何個集めるともとに戻るか」を生成結果とは独立に再計算する。
- 問題番号は普通整数 `1`〜`20`。解答ページは問題ページと同じ配置を再掲し、赤字で答えを加える。
- 教材内の `(等分数, 全体個数)` 重複を拒否し、教材間は正規化 `content_hash` で重複を拒否する。
- `tests/test_grade2_simple_fractions_publisher.py` を追加し、決定性、2等分/3等分の均等分布、独立解答、variant差、重複、PDF2ページ、カタログ、冪等性を検証するようにした。
- GitHub Actions `Grade 2 worksheet factory checkpoint` run 32892804892 で新規6PDF生成と既存小2全生成器・共通ファクトリー回帰テストが成功した。
- 同runで公開コミット `80dbb7423135050f14b254c42d9a9aa81231c813` を main へ反映した。

- 24問全体をseedで混合し、既存単元プリントの単純な連結・並べ替えにはしていない。
