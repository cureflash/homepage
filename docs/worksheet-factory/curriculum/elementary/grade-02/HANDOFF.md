## 今回完了

### たし算・ひき算・かけ算混合

- 文部科学省「小学校学習指導要領（平成29年告示）解説 算数編」を再確認した。
  - 第2学年では2位数などの加法・減法と乗法九九を扱う。
  - 一方、四則を混合した式そのものは第4学年の内容なので、小2版は各設問で演算を1回だけ行い、1枚の中で加法・減法・乗法を切り替える形式に限定した。
  - 参照: https://www.mext.go.jp/content/20211102-mxt_kyoiku02-100002607_04.pdf
- `scripts/publish_grade2_mixed_operations.py` を追加した。
- seed=1901/2002/2103 の3種類で決定的生成し、新規3PDFを公開した。
- 各プリントは24問で、加法8問・減法8問・乗法8問を均等に出題する。
  - 加法は繰り上がりなし4問＋あり4問。
  - 減法は繰り下がりなし4問＋あり4問。
  - 乗法は2〜9の各段を1問ずつ扱う。
  - 24問全体をseedで混合し、単元別プリントの単純連結にはしていない。
- 加法・減法では既存の通常横書き版と筆算版ですでに公開した数値ペアを候補から除外し、既存教材の並べ替えにならないようにした。
- `independent_mixed_answer()` で生成器が保持する答えとは独立に再計算する。
- 教材内では `(演算種別, a, b)` の完全重複を拒否し、教材間は正規化 `content_hash` で重複を拒否する。
- 問題番号は普通整数 `1`〜`24`。解答ページは問題ページと同じ配置を再掲し、赤字で答えを追加する。
- カタログには `worksheet_series: mixed`、`worksheet_format: mixed-single-operation` を保存した。
- `tests/test_grade2_mixed_operations_publisher.py` を追加し、決定性、3演算の8問ずつ分布、繰り上がり/繰り下がり各4問、2〜9段の網羅、既存加減ペアとの非重複、独立解答、PDF2ページ、カタログ、冪等性を検証するようにした。
- GitHub Actions `Grade 2 worksheet factory checkpoint` run 32887226248 で全小2生成器・回帰テストが成功した。
- 同runで3PDFとカタログを公開。公開コミットは `a2c0d9b7b4848e83c88d1d2b9f739bdd39a64ca5`。

### 1000・10000までの位取り/数の大小

- 同じ文部科学省解説で、第2学年に4位数までの十進位取り記数法、数の大小・順序、および1万を扱うことを確認した。
- `scripts/publish_grade2_place_value.py` を追加し、次の3技能へ分割した。
  - `4桁の数の位取り`
  - `4桁の数の構成`
  - `1万までの数の大小`
- 各技能を seed=2201/2302/2403 の3種類で決定的生成し、新規9PDFを公開した。
- 各プリントは20問。
  - 位取り: 千・百・十・一の位を各5問ずつ出題する。
  - 数の構成: `3000 + 400 + 50 + 6 = □` 型で4桁の数を構成する。4桁の各数字の組合せを教材内で重複させない。
  - 大小: 1000〜10000の範囲で `<` 8問、`>` 8問、`=` 4問を出題する。
- `independent_answer()` で位の数字、展開形からの数、大小記号を独立再計算する。
- 問題番号は普通整数 `1`〜`20`。解答ページは同じ配置に赤字で答えを追加する。
- カタログのunitは `1000・10000までの数` とし、形式を `place-value-digit` / `expanded-form` / `number-comparison` に分けて保存した。
- `tests/test_grade2_place_value_publisher.py` を追加し、決定性、各技能の分布・範囲、独立解答、variant差、重複、PDF2ページ、カタログ、冪等性を検証するようにした。
- GitHub Actions `Grade 2 worksheet factory checkpoint` run 32887463884 で新規9PDF生成と、core・筆算・九九各種・簡単な2桁×1桁・3演算混合・共通ファクトリーの全回帰テストが成功した。
- 同runで9PDFとカタログを公開。公開コミットは `9777475a687cd58914ac234076542d660027fa81`。
