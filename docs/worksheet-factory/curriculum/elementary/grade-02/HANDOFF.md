# 小学2年 算数 — HANDOFF

更新: 2026-08-26

## 今回完了

- 文部科学省の現行小学校学習指導要領・算数編を再確認し、第2学年に「簡単な場合について，3位数などの加法及び減法」が配置されていることを確認した。
- 解説の例に合わせ、一般的な3位数筆算へ先取りしない範囲として次の4技能を `scripts/publish_grade2_core.py` に追加した。
  - 百を単位にした簡単なたし算
  - 百を単位にした簡単なひき算
  - 3桁 + 1〜2桁（百の位への繰り上がりなし）
  - 3桁 - 1〜2桁（百の位からの繰り下がりなし）
- 各技能を seed=101/202/303 の3種類で決定的生成し、新規12PDFを公開した。
- 既存の2桁加減4技能はID・URL・問題仕様を変更していない。
- 百単位のたし算では `a <= b` に限定し、交換法則だけが違う無意味な重複を避けた。
- 3桁を含む加法は下2桁と加数の和を99以下に限定し、百の位への繰り上がりを除外した。
- 3桁を含む減法は下2桁が減数以上の場合に限定し、百の位からの繰り下がりを除外した。
- 生成器が保持する答えとは別の `independent_answer()` で全問を再計算し、各技能固有の範囲条件も独立検証する。
- 各20問内の数値ペア重複を拒否し、全seed・全技能間と既存カタログに対して正規化 `content_hash` の重複検査を行う。
- 共通PDFレンダラーを使用し、普通整数の問題番号、問題ページと同じ配置の解答ページ、赤字解答という既存仕様を維持した。
- `tests/test_grade2_core_publisher.py` を8技能対応へ拡張し、決定性・条件適合・問題内重複なし・seed/技能間重複なし・既存教材との重複なし・PDF生成・カタログ整合性・冪等性を検証するようにした。

## 現在の公開範囲

- 小2算数: 8技能。
- 各技能20問 × seed=101/202/303 の3種類 = 24PDF。
- 内訳:
  - 2桁どうしの加減4技能 = 12PDF。
  - 簡単な3位数などの加減4技能 = 12PDF。
- 公開先: `materials/worksheets/elementary/grade-02/`。
- `worksheets/catalog.json` に登録し、既存の動的一覧/navigationから小2として表示される。
