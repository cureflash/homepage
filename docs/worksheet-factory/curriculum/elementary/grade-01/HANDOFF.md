# 小学1年 算数 — HANDOFF

更新: 2026-08-25

## 今回完了

- 文部科学省の現行小学校学習指導要領解説（算数編）で、第1学年の1位数どうしの加法とその逆の減法を確認。
- 決定的seedから再生成できる共通プリント生成器を追加。
- 問題生成とは別の `compute_answer()` で全解答を再計算して検証する処理を追加。
- 正規化した問題列SHA-256によるプリント単位の重複検査を追加。
- A4・問題1ページ＋解答1ページのPDF生成を実装し、レンダリング確認済み。
- 小1の最初の4技能について生成器を実装し、各技能のseed=101版を1枚ずつ、合計4枚を公開カタログへ登録。
  - 5までの数の合成・分解
  - 10までの数の合成・分解
  - 10までのたし算
  - 10までのひき算
- ローカル検証では各技能3seed、合計12枚を重複なく生成できることまで確認済み。追加seed版は未公開。
- `worksheets/index.html` と `worksheets/catalog.json` を追加し、公開済みPDFを一覧表示可能にした。

## 検証

- 同一skill/seedで問題列が完全一致することを確認。
- 全問題で独立再計算した答えと生成答えが一致することを確認。
- ローカル生成した12プリント間の正規化問題列ハッシュが重複しないことを確認。
- 代表PDF `e1-add-10-01.pdf` を150dpiで2ページともレンダリングし、文字欠け・重なり・クリップなしを目視確認。
