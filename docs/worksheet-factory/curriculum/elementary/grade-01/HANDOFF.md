# 小学1年 算数 — HANDOFF

更新: 2026-08-25

## 今回完了

- 文部科学省「小学校学習指導要領（平成29年告示）解説 算数編」で、第1学年の「1位数の加法とその逆の減法」「簡単な場合の2位数などの加法、減法」の範囲を再確認。
- 生成器へ以下3技能を追加。
  - 1桁 + 1桁 ランダム反復
  - 20までのたし算・ひき算混合
  - □に入る数（加減の簡単な逆算）
- `□に入る数` は `□ + a = b`、`a + □ = b`、`a - □ = b` の3形式を実装し、答えを独立再計算できる問題データ構造にした。
- 各新技能を seed=101/202/303 で決定性・独立解答再計算・値域・正規化ハッシュ重複なしを検証。
- 各新技能の seed=101 版を問題＋解答2ページPDFとして公開し、`worksheets/catalog.json` に登録。
- 公開カタログは小1の11技能・11プリントになった。
- 新規3PDFがGitHub上に存在することを確認。
- 既存 `sub-20-no-borrow` の `content_hash` をカタログ更新時の転記ミスから元の正しい値へ復旧。

## 検証

- 新3技能について seed=101/202/303 で同一seed再生成が一致。
- 新3技能の全問題で独立再計算結果と生成答えが一致。
- 1桁 + 1桁は両項0〜9、答え0〜18。
- 20までの加減混合は答え0〜20。
- □に入る数は空欄の答え0〜9。
- 新規3PDFはいずれも2ページ。
- 新規3PDFの公開パスとカタログURLが一致。
