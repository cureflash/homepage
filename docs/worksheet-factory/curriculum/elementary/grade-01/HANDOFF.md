# 小学1年 算数 — HANDOFF

更新: 2026-08-25

## 今回完了

- 文部科学省「小学校学習指導要領（平成29年告示）解説 算数編」で、第1学年に1位数どうしの加法とその逆の減法、繰り上がりのある加法・繰り下がりのある減法を扱うことを再確認。
- 生成器へ以下4技能を追加。
  - 20までの繰り上がりなしのたし算
  - 20までの繰り下がりなしのひき算
  - 20までの繰り上がりありのたし算
  - 20までの繰り下がりありのひき算
- 各技能を seed=101/202/303 の3種類で生成し、決定性・独立解答再計算・範囲条件を検証。
- 新4技能の seed=101 版を問題＋解答2ページPDFとして公開し、`worksheets/catalog.json` に登録。
- 公開カタログは小1の8技能・8プリントになった。
- 繰り上がりあり代表PDFをレンダリングし、文字欠け・重なり・クリップがないことを目視確認。

## 検証

- 全8技能について seed=101/202/303 で同一seed再生成が一致。
- 全問題で `compute_answer()` の独立再計算結果と生成答えが一致。
- 繰り上がりなしは1の位の和が10未満、繰り下がりなしは被減数の1の位以上を引かないことを検証。
- 繰り上がりありは1位数どうしで和11〜18、繰り下がりありは11〜18から1位数を引いて繰り下がりが発生することを検証。
- 新規公開4PDFはいずれも2ページ。
