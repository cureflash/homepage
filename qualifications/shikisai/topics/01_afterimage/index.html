COLOR VISION / NEUROSCIENCE

補色残像はなぜ見えるのか

赤を見続けたあと白い面を見ると、青緑系の色が浮かんで見える。これは単に「錐体が疲れる」だけでは説明しきれない。受容器の順応、網膜神経回路の時間応答、さらに皮質での処理が重なって生じる知覚現象である。

色彩検定との対応 色彩検定3級の公式テキスト目次では「色彩心理 → 色の視覚効果 → 補色残像」が明示されている。ここでは検定で扱う現象を、大学レベルの神経科学・心理物理学まで拡張する。

1. まず何が起きているのか

赤い図形を数十秒見続け、その後に白または灰色の背景を見ると、元の図形とほぼ同じ位置に赤とは反対方向の色が見える。これを負の残像、特に色については補色残像という。

重要なのは、残像の色が外界から新たに入ってきた光そのものではない点である。背景から眼に入る光がほぼ同じでも、その直前に何色へ順応したかによって見えが変わる。つまり、色は入力スペクトルだけでなく、視覚系の内部状態にも依存する。

2. 色覚の入口はL・M・S錐体

明所視では主に3種類の錐体が働く。L錐体は長波長側、M錐体は中波長側、S錐体は短波長側に相対的に高い感度を持つ。ただし「L錐体＝赤」「M錐体＝緑」「S錐体＝青」と一対一に色を感じているわけではない。色は、複数の錐体出力の比較によって符号化される。

簡略化すると、網膜以降では錐体信号の差を取る軸を考えられる。

rLM = wLL − wMM
rS = wSS − wLM(L + M)

これは生理学的回路を完全に表す式ではなく、錐体信号が「足し算」と「引き算」で再符号化されることを示す最小モデルである。実際の網膜神経節細胞には、異なる錐体入力を興奮性・抑制性に組み合わせるcone-opponent応答が存在する。

3. 「錐体が疲れる」は半分だけ正しい

強い光や持続光にさらされると、視細胞の感度は低下する。視物質の退色と再生、光情報伝達系の利得調整などが関与し、同じ光刺激に対する応答は時間とともに小さくなる。これは光順応の一部である。

したがって、赤系刺激でL錐体が相対的に強く刺激された後、白色背景に切り替わると、L系の応答は順応前より相対的に弱くなり得る。その結果、L・M・Sの比が順応前とは変わる。

ただし、補色残像を「視物質が退色したから」だけで説明するのは不十分である。残像には受容器より後段の神経適応も明確に関与する。

4. 網膜神経節細胞に「引き算の履歴」が残る

2012年の霊長類網膜を用いた電気生理学研究では、主要な3種類の網膜神経節細胞すべてで、持続刺激に対する減算的な順応が観測された。刺激を止めた瞬間には反対方向のリバウンド応答が生じ、残像信号の神経基盤になり得ることが示された。

これを単純な動的モデルにすると、順応状態aを

τ da/dt = x − a

出力を

y = x − a

と表せる。xは現在の入力、aは過去の入力を時間平均したような順応成分、τは順応の時定数である。

刺激を長く見続けるとaが大きくなる。そこで急に刺激を消すとxはすぐ低下するが、aは時定数τに従ってゆっくり戻る。この瞬間、yは一時的に反対符号へ振れる。これが「刺激がなくなった後に反対方向の信号が出る」という残像の基本形になる。

持続する色刺激 → 錐体・網膜回路が順応 → 刺激を除去 → 順応状態だけが一時的に残る → 錐体間の相対信号が反対方向へ偏る → 補色方向の残像

5. では「反対色説」で全部説明できるのか

色彩学では、赤―緑、黄―青といった反対関係を使って残像を説明することが多い。心理現象を整理するには有用だが、大学レベルでは「心理的な反対色」と「網膜のcone-opponent細胞」を同一視しない方が正確である。

網膜や外側膝状体にはL対M、S対(L+M)のような拮抗信号が存在するが、それらがそのまま「赤」「緑」「青」「黄」という主観的色カテゴリを表現しているわけではない。色の見えは皮質を含む後段処理でさらに変換される。

試験用の説明と科学的説明を分ける 色彩検定3級では、補色残像という現象と補色関係を押さえることが中心になる。発展学習では、三色型受容器・cone-opponent回路・順応・リバウンドを別階層として考える。

6. 残像は網膜だけの現象でもない

残像の形や強さは、注意、図と地、知覚的な面の補完などによっても変わる。知覚的に補完された面そのものに残像が生じる実験もあり、皮質レベルの表象が残像へ寄与することが示されている。

したがって現在の理解では、補色残像は単一の場所で生じる現象ではない。受容器の順応、網膜神経節細胞の順応とリバウンド、皮質の空間・表面処理が階層的に重なっていると考えるのが妥当である。

7. 色彩検定の知識へ戻す

検定で必要なのは「ある色を見続けた後、その色と補色関係にある色の残像が見える」という現象の理解である。理系的には、その背後に次の因果関係がある。

  • 色光はL・M・S錐体を異なる比率で刺激する。
  • 持続刺激によって受容器と神経回路が順応する。
  • 刺激除去後も順応状態は瞬時には消えない。
  • 錐体間の差分信号が一時的に反対方向へ偏る。
  • その信号を脳が色として解釈し、補色方向の残像が知覚される。

「補色残像」は、色が物理量だけでは決まらず、時間履歴を持つ神経系によって作られることを示す典型例である。
